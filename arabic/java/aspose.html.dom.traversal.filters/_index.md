الحزمة تمثل وظيفة تصفية العقد. الفلاتر هي كائنات تعرف كيفية "تصفية" العقد. إذا تم إعطاء مكرّر العقد أو متجول الشجرة مرشح عقد، فإنه يطبق المرشح قبل أن يُعيد العقدة التالية. إذا قال المرشح بقبول العقدة، تُعيد منطق التجوالها؛ وإلا، يبحث التجوال عن العقدة التالية ويتظاهر أن العقدة المرفوضة لم تكن موجودة.
