## NodeFilter.SHOW_ATTRIBUTE field

إظهار عقد Attr. هذا ذو معنى فقط عند إنشاء مكرّر أو متجول شجري مع عقدة سمة كجذر لها؛ في هذه الحالة، يعني أن عقدة السمة ستظهر في الموضع الأول من التكرار أو التجوال. نظرًا لأن السمات لا تكون أبدًا أبناء لعقد أخرى، فهي لا تظهر عند التجول عبر شجرة المستند.

```java
public const long SHOW_ATTRIBUTE;
```
