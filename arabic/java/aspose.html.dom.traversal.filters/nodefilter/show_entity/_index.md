## NodeFilter.SHOW_ENTITY field

إظهار عقد Entity. هذا ذو معنى فقط عند إنشاء مُكرِّر أو متجول شجري بجذر عقدة Entity؛ في هذه الحالة، يعني أن عقدة Entity ستظهر في الموضع الأول من التجوال. نظرًا لأن الكيانات ليست جزءًا من شجرة المستند، فهي لا تظهر عند التجول في شجرة المستند.

```java
public const long SHOW_ENTITY;
```
