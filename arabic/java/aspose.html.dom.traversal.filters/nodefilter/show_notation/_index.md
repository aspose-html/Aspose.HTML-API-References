## NodeFilter.SHOW_NOTATION field

إظهار عقد Notation. هذا ذو معنى فقط عند إنشاء iterator أو tree-walker مع عقدة Notation كجذر لها؛ في هذه الحالة، يعني ذلك أن عقدة Notation ستظهر في الموضع الأول من التجوال. نظرًا لأن الـ notations ليست جزءًا من شجرة المستند، فهي لا تظهر عند التجول عبر شجرة المستند.

```java
public const long SHOW_NOTATION;
```
