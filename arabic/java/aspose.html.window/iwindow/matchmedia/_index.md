## IWindow.MatchMedia method

يعيد كائن MediaQueryList جديد يمكن استخدامه لتحديد ما إذا كان المستند يطابق سلسلة استعلام الوسائط، وكذلك لمراقبة المستند لاكتشاف متى يطابق (أو يتوقف عن المطابقة) ذلك الاستعلام. راجع مواصفة وحدة عرض CSSOM: [https://www.w3.org/TR/cssom-view/#extensions-to-the-window-interface](https://www.w3.org/TR/cssom-view/#extensions-to-the-window-interface)

```java
public MediaQueryList MatchMedia(String query)
```

| معامل | نوع | الوصف |
