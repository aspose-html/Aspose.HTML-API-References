## IWindow.MatchMedia method

يُعيد كائن MediaQueryList جديد يمكن بعد ذلك استخدامه لتحديد ما إذا كان المستند يطابق سلسلة استعلام الوسائط، وكذلك لمراقبة المستند لاكتشاف متى يطابق (أو يتوقف عن المطابقة) ذلك الاستعلام. راجع مواصفة CSSOM View Module: [https://www.w3.org/TR/cssom-view/#extensions-to-the-window-interface](https://www.w3.org/TR/cssom-view/#extensions-to-the-window-interface)

```java
public MediaQueryList MatchMedia(String query)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| query | String | السلسلة التي تحتوي على استعلام وسائط؛ راجع [https://drafts.csswg.org/mediaqueries/](https://drafts.csswg.org/mediaqueries/) للتفاصيل. |
