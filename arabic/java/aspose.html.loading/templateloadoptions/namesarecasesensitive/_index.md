## TemplateLoadOptions.NamesAreCaseSensitive property

خاصية تحدد ما إذا كانت أسماء القالب وعناصر البيانات ستتم مطابقتها بغض النظر عن حالة الأحرف أم لا. إذا كانت true، يكون التطابق حساسًا لحالة الأحرف؛ إذا كانت false، يتم تجاهل حالة الأحرف. القيمة الافتراضية هي true.

```java
public bool NamesAreCaseSensitive { get; set; }
```
