## TemplateLoadOptions.NamesAreCaseSensitive property

الخاصية التي تحدد ما إذا كان سيتم مطابقة أسماء القالب وعناصر البيانات بغض النظر عن حالة الأحرف أم لا. إذا كانت true، يكون المطابقة حساسة لحالة الأحرف؛ إذا كانت false، سيتم تجاهل حالة الأحرف. القيمة الافتراضية هي true.

```java
public bool NamesAreCaseSensitive { get; set; }
```
