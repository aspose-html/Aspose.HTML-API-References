## Text.IsElementContentWhitespace property

تُعيد ما إذا كانت عقدة النص هذه تحتوي على مسافات محتوى العنصر، والتي تُسمى غالبًا "مسافات قابلة للتجاهل".

```java
public bool IsElementContentWhitespace { get; }
```

### Property Value

`true` إذا كان هذا الكائن مساحة بيانية محتوى العنصر؛ وإلا `false`.
