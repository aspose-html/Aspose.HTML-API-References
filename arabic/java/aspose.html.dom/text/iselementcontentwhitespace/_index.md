## Text.IsElementContentWhitespace property

تُعيد ما إذا كانت عقدة النص هذه تحتوي على مسافات محتوى العنصر، والتي تُسمّى غالباً "ignorable whitespace".

```java
public bool IsElementContentWhitespace { get; }
```

### Property Value

`true` إذا كان هذا المثال مسافة محتوى العنصر؛ وإلا، `false`.
