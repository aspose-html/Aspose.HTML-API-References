## Node.IsSameNode method

طريقة isSameNode() الخاصة بواجهة Node هي اسم مستعار قديم للمقارنة الصارمة ===. أي أنها تختبر ما إذا كانت عقدتان هي نفسها (بمعنى آخر، ما إذا كانتا تشير إلى نفس الكائن).

ملاحظة: لا حاجة لاستخدام isSameNode(); بل استخدم عامل المساواة الصارمة ===.

```java
public bool IsSameNode(Node otherNode)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| otherNode | Node | العقدة Node التي سيتم اختبارها ضدها. |

### قيمة الإرجاع

قيمة منطقية تكون true إذا كانت العقدتان متساويتين بدقة، وfalse إذا لم تكن.
