## Node.IsSameNode method

طريقة isSameNode() في واجهة Node هي اسم مستعار قديم للمشغل الصارم ===. أي أنها تختبر ما إذا كانت عقدتان هي نفسها (بمعنى آخر، ما إذا كانتا تشير إلى نفس الكائن).

ملاحظة: لا حاجة لاستخدام isSameNode(); استخدم بدلاً من ذلك عامل المساواة الصارمة ===.

```java
public bool IsSameNode(Node otherNode)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| otherNode | Node | العقدة Node التي سيتم اختبارها مقابلها. |

### قيمة الإرجاع

قيمة منطقية تكون true إذا كانت العقدتان متساويتين بدقة، وfalse إذا لم تكن كذلك.
