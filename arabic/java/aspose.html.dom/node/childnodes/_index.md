## Node.ChildNodes property

الخاصية للقراءة فقط childNodes لواجهة Node تُرجع [`NodeList`](../../../com.aspose.html.collections/nodelist/) حية لعقد الأطفال للعنصر المعطى حيث يُعطى الطفل الأول الفهرس 0. تشمل عقد الأطفال العناصر، النص والتعليقات.

ملاحظة: كون [`NodeList`](../../../com.aspose.html.collections/nodelist/) حية يعني أن محتواها يتغير في كل مرة تُضاف أو تُحذف فيها عقد جديدة.

```java
public NodeList ChildNodes { get; }
```

### Property Value

‏[`NodeList`](../../../com.aspose.html.collections/nodelist/) حية تحتوي على أطفال العقدة.

ملاحظة: عدة استدعاءات لـ childNodes تُعيد نفس [`NodeList`](../../../com.aspose.html.collections/nodelist/).
