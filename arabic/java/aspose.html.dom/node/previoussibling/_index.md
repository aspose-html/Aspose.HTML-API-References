## Node.PreviousSibling property

الخاصية للقراءة فقط previousSibling لواجهة [`Node`](../) تُرجع العقدة التي تسبق المحددة مباشرةً في قائمة [`childNodes`](../firstchild/) للوالد، أو null إذا كانت العقدة المحددة هي الأولى في تلك القائمة.

```java
public Node PreviousSibling { get; }
```

### Property Value

‏[`Node`](../) يمثل الأخ السابق للعقدة الحالية، أو null إذا لم يكن هناك أي منها.
