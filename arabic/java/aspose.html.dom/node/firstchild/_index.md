## Node.FirstChild property

الخاصية read-only firstChild لواجهة [`Node`](../) تُرجع الطفل الأول للعقدة في الشجرة، أو null إذا لم يكن للعقدة أي أطفال.

إذا كانت العقدة Document، فإن هذه الخاصية تُرجع أول عقدة في قائمة أطفالها المباشرين.

```java
public Node FirstChild { get; }
```

### Property Value

عقدة [`Node`](../)، أو null إذا لم يكن هناك أي منها.
