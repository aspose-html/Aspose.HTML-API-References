## Node.OwnerDocument property

الخاصية للقراءة فقط ownerDocument لواجهة Node تُرجع كائن المستند الأعلى مستوى للعقدة.

```java
public Document OwnerDocument { get; }
```

### Property Value

‏[`Document`](../../document/) هو الكائن الأعلى مستوى الذي يتم فيه إنشاء جميع العقد الفرعية.

إذا استُخدمت هذه الخاصية على عقدة هي نفسها مستند، فإن القيمة تكون null.
