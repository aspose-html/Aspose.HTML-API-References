## Node.IsEqualNode method

طريقة isEqualNode() في واجهة [`Node`](../) تختبر ما إذا كانت عقدتان متساويتان. تكون العقدتان متساويتين عندما يكون لهما نفس النوع والخصائص المحددة (بالنسبة للعناصر، سيكون ذلك معرفهما (ID)، عدد الأطفال، وما إلى ذلك)، وتطابق سماتها، وهكذا. مجموعة البيانات المحددة التي يجب أن تتطابق تختلف حسب نوع العقد.

```java
public bool IsEqualNode(Node otherNode)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| otherNode | Node | [`Node`](../) للمقارنة بالمساواة. |

### قيمة الإرجاع

قيمة منطقية تكون true إذا كانت العقدتان متساويتين، أو false إذا لم تكونا كذلك. إذا كان otherNode يساوي null، فإن isEqualNode() دائمًا تُعيد false.
