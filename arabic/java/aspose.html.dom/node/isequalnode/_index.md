## Node.IsEqualNode method

طريقة isEqualNode() في واجهة [`Node`](../) تختبر ما إذا كانت عقدتان متساويتان. تكون العقدتان متساويتين عندما يكون لهما نفس النوع والخصائص المحددة (بالنسبة للعناصر، قد تكون هذه هي المعرف، عدد الأطفال، وما إلى ذلك)، وتطابق سماتها، وما شابه. مجموعة البيانات المحددة التي يجب أن تتطابق تختلف حسب نوع العقد.

```java
public bool IsEqualNode(Node otherNode)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| otherNode | Node | العقدة [`Node`](../) للمقارنة بالمساواة. |

### قيمة الإرجاع

قيمة منطقية تكون true إذا كانت العقدتان متساويتين، أو false إذا لم تكن. إذا كان otherNode يساوي null، فإن isEqualNode() دائمًا تُعيد false.
