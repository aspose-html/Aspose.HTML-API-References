## Node.ParentElement property

الخاصية للقراءة فقط parentElement لواجهة [`Node`](../) تُرجع العنصر الأب لعقدة DOM وهو [`Element`](../../element/)، أو null إذا لم يكن للعقدة أب، أو إذا لم يكن أبها عنصر DOM.

```java
public Element ParentElement { get; }
```

### Property Value

‏[`Element`](../../element/) هو العنصر الأب للعقدة الحالية، أو null إذا لم يكن هناك أحد.
