## Node.BaseURI property

الخاصية baseURI للقراءة فقط في واجهة Node تُرجع عنوان URL الأساسي المطلق للمستند الذي يحتوي على العقدة.

يُستخدم عنوان URL الأساسي لحل عناوين URL النسبية عندما يحتاج المتصفح إلى الحصول على عنوان URL مطلق، على سبيل المثال عند معالجة سمة src لعنصر img في HTML أو سمات xlink:href أو href في SVG.

```java
public String BaseURI { get; }
```

### Property Value

تُعيد الدالة getter للخاصية baseURI عنوان URL الأساسي للمستند الخاص بالعقدة، بشكل مُسلسل.
