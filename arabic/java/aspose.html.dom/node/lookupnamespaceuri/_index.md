## Node.LookupNamespaceURI method

طريقة lookupNamespaceURI() الخاصة بواجهة Node تأخذ بادئة كمعامل وتُعيد عنوان الحزمة URI المرتبط بها على العقدة المعطاة إذا وُجد (وnull إذا لم يُوجد).

```java
public String LookupNamespaceURI(String prefix)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| بادئة | String | البادئة المراد البحث عنها. |

### قيمة الإرجاع

String يحتوي على URI الحزمة المقابل للبادئة. إذا لم تُعثر على البادئة، تُرجع null. إذا كانت البادئة المطلوبة null، تُرجع URI الحزمة الافتراضية.
