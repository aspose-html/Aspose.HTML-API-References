## Node.LookupNamespaceURI method

تأخذ طريقة lookupNamespaceURI() في واجهة Node بادئة كمعامل وتُعيد URI الحزمة المرتبط بها على العقدة المعطاة إذا وُجد (وnull إذا لم يُوجد).

```java
public String LookupNamespaceURI(String prefix)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| prefix | String | البادئة التي يجب البحث عنها. |

### قيمة الإرجاع

String يحتوي على URI الحزمة المقابل للبادئة. إذا لم تُعثر على البادئة، تُعيد null. إذا كانت البادئة المطلوبة null، تُعيد URI الحزمة الافتراضي.
