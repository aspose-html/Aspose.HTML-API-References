## Node.ReplaceChild method

يستبدل عقدة الطفل oldChild بـ newChild في قائمة الأطفال، ويُرجع عقدة oldChild. إذا كان newChild كائنًا من [`DocumentFragment`](../../documentfragment/)، يتم استبدال oldChild بجميع أطفال [`DocumentFragment`](../../documentfragment/) التي تُدرج بنفس الترتيب. إذا كان newChild موجودًا بالفعل في الشجرة، يُزال أولاً.

```java
public Node ReplaceChild(Node node, Node child)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| العقدة | Node | العقدة الجديدة لاستبدال oldChild. |
| العنصر الفرعي | Node | العنصر الطفل الذي سيُستبدل. |

### قيمة الإرجاع

العقدة المستبدلة. هذه هي نفس العقدة كـ oldChild.
