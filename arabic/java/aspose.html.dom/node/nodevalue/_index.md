## Node.NodeValue property

الخاصية nodeValue لواجهة [`Node `](../) تُعيد أو تُعيّن قيمة العقدة الحالية.

```java
public String NodeValue { get; set; }
```

### Property Value

String يحتوي على قيمة العقدة الحالية، إن وجدت. بالنسبة للمستند نفسه، تُعيد nodeValue قيمة null. بالنسبة لعقد النص، والتعليق، وCDATA، تُعيد nodeValue محتوى العقدة. بالنسبة لعقد السمات، تُعيد قيمة السمة.
