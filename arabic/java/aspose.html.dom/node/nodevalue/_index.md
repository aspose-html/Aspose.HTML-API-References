## Node.NodeValue property

الخاصية nodeValue لواجهة [`Node `](../) تُرجع أو تُعيّن قيمة العقدة الحالية.

```java
public String NodeValue { get; set; }
```

### Property Value

String يحتوي على قيمة العقدة الحالية، إن وجدت. بالنسبة للمستند نفسه، تُرجع nodeValue قيمة null. بالنسبة لعقد النص، والتعليق، وCDATA، تُرجع nodeValue محتوى العقدة. بالنسبة لعقد السمات، تُرجع قيمة السمة.
