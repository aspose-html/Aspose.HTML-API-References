## Node.LastChild property

الخاصية read-only lastChild لواجهة [`Node`](../) تُعيد العنصر الفرعي الأخير للعنصر. إذا كان الوالد عنصرًا، فإن العنصر الفرعي يكون عادةً عنصرًا، أو عنصر نص، أو عنصر تعليق. تُعيد null إذا لم توجد عناصر فرعية.

```java
public Node LastChild { get; }
```

### Property Value

[`Node`](../) هو العنصر الفرعي الأخير للعنصر، أو null إذا لم توجد عناصر فرعية.
