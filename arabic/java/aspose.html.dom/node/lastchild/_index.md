## Node.LastChild property

الخاصية read-only lastChild لواجهة [`Node`](../) تُرجع العنصر الفرعي الأخير للعنصر. إذا كان الوالد عنصرًا، فإن العنصر الفرعي يكون عادةً عنصرًا، أو عقدة نصية، أو عقدة تعليق. تُرجع null إذا لم يكن هناك عناصر فرعية.

```java
public Node LastChild { get; }
```

### Property Value

[`Node`](../) هو العنصر الفرعي الأخير للعنصر، أو null إذا لم يكن هناك عناصر فرعية.
