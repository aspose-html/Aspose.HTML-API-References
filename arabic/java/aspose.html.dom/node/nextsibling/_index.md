## Node.NextSibling property

خاصية nextSibling للقراءة فقط في واجهة [`Node`](../) تُعيد العقدة التي تلي المحددة مباشرةً في [`childNodes`](../childnodes/) الخاصة بالوالد، أو تُعيد null إذا كانت العقدة المحددة هي آخر عنصر فرعي في العنصر الأب.

```java
public Node NextSibling { get; }
```

### Property Value

كائن [`Node`](../) يُمثّل الأخ التالي للعقدة الحالية، أو null إذا لم يكن هناك أي منها.
