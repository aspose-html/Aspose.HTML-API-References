## Node.AppendChild method

طريقة appendChild() الخاصة بواجهة Node تُضيف عقدة إلى نهاية قائمة الأطفال للعقدة الأصلية المحددة. إذا كان الطفل المُعطى إشارة إلى عقدة موجودة بالفعل في المستند، فإن appendChild() تنقلها من موقعها الحالي إلى الموقع الجديد (ليس هناك حاجة لإزالة العقدة من عقدتها الأصلية قبل إلحاقها بعقدة أخرى).

هذا يعني أن العقدة لا يمكن أن تكون في نقطتين من المستند في آن واحد. لذا إذا كانت العقدة لديها بالفعل أب، فسيتم إزالتها أولاً، ثم إلحاقها بالموقع الجديد. يمكن استخدام طريقة [`Node.cloneNode()`](../clonenode/) لإنشاء نسخة من العقدة قبل إلحاقها تحت الأب الجديد. النسخ التي تم إنشاؤها باستخدام [`cloneNode`](../clonenode/) لا يتم مزامنتها تلقائيًا.

```java
public Node AppendChild(Node node)
```

### قيمة الإرجاع

عقدة Node هي الطفل الملحق (aChild)، باستثناء عندما يكون aChild هو [`DocumentFragment`](../../documentfragment/)، وفي هذه الحالة يتم إرجاع [`DocumentFragment`](../../documentfragment/) الفارغ.
