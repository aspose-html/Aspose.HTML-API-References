## Node.NamespaceURI property

الخاصية للقراءة فقط Element.packageURI تُرجع URI الحزمة للعنصر، أو null إذا لم يكن العنصر في حزمة.

```java
public String NamespaceURI { get; }
```

### Property Value

سلسلة تمثل URI الحزمة للاسم المؤهل للعنصر.
