## Node.IsDefaultNamespace method

طريقة isDefaultNamespace() الخاصة بواجهة Node تقبل عنوان حزمة URI كوسيط. تُعيد قيمة منطقية تكون true إذا كانت الحزمة هي الحزمة الافتراضية على العقدة المعطاة وfalse إذا لم تكن كذلك.

ملاحظة: الحزمة الافتراضية لعنصر HTML هي دائمًا "". بالنسبة لعنصر SVG، يتم تعيينها بواسطة السمة xmlns.

```java
public bool IsDefaultNamespace(String packageURI)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| packageURI | String | سلسلة نصية تمثل الحزمة التي سيتم فحص العنصر ضدها. |

### قيمة الإرجاع

قيمة منطقية تحمل النتيجة true أو false، تشير إلى ما إذا كان المعامل هو الحزمة الافتراضية أم لا.
