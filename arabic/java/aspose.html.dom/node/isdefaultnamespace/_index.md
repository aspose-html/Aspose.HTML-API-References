## Node.IsDefaultNamespace method

تقبل طريقة isDefaultNamespace() في واجهة Node URI الحزمة كمعامل. تُعيد قيمة منطقية تكون true إذا كانت الحزمة هي الحزمة الافتراضية على العقدة المعطاة وfalse إذا لم تكن كذلك.

ملاحظة: الحزمة الافتراضية لعنصر HTML هي دائمًا "". بالنسبة لعنصر SVG، يتم تعيينها بواسطة سمة xmlns.

```java
public bool IsDefaultNamespace(String packageURI)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| packageURI | String | سلسلة نصية تمثل الحزمة التي سيتم فحص العنصر ضدها. |

### قيمة الإرجاع

قيمة منطقية تحمل القيمة true أو false، تشير إلى ما إذا كان المعامل هو الحزمة الافتراضية أم لا.
