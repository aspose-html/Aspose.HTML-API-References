## DOMException.VALIDATION_ERR field

إذا كان استدعاء طريقة مثل insertBefore أو removeChild سيجعل العقدة غير صالحة بالنسبة إلى "الصلاحية الجزئية"، فسيتم رفع هذا الاستثناء ولن تُنفذ العملية. يُستخدم هذا الكود في [DOM Level 3 Validation]. راجع هذه المواصفة لمزيد من المعلومات.

```java
public const ushort VALIDATION_ERR;
```
