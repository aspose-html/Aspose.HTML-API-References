## ProcessingInstruction.TextContent property

هذه السمة تُرجع محتوى النص لهذه العقدة ونسلها. عندما تُحدد بأنها null، لا يؤثر تعيينها. عند التعيين، تُزال أي أطفال محتملين قد تكون للعقدة، وإذا لم تكن السلسلة الجديدة فارغة أو null، تُستبدل بعقدة نصية واحدة تحتوي على السلسلة التي تم تعيين هذه السمة إليها.

```java
public String TextContent { get; set; }
```

### Property Value

محتوى النص.
