## Document.StrictErrorChecking property

سمة تحدد ما إذا كان فحص الأخطاء مفروضًا أم لا. عندما يتم تعيينها إلى false، يكون التنفيذ حرًا في عدم اختبار كل حالة خطأ محتملة عادةً ما تُعرف في عمليات DOM، ولا يرفع أي DOMException على عمليات DOM أو لا يُبلغ عن أخطاء أثناء استخدام Document.normalizeDocument(). في حالة حدوث خطأ، يكون السلوك غير معرف. هذه السمة true بشكل افتراضي.

```java
public bool StrictErrorChecking { get; set; }
```

### Property Value

`true` إذا كان فحص الأخطاء صارمًا؛ وإلا `false`.
