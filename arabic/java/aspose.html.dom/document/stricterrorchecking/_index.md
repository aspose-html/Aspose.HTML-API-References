## Document.StrictErrorChecking property

سمة تحدد ما إذا كان فحص الأخطاء مفروضًا أم لا. عند تعيينها إلى false، يكون التنفيذ حرًا في عدم اختبار كل حالة خطأ محتملة عادةً ما تُعرّف في عمليات DOM، وعدم رفع أي DOMException على عمليات DOM أو الإبلاغ عن الأخطاء أثناء استخدام Document.normalizeDocument(). في حالة حدوث خطأ، يكون السلوك غير معرف. هذه السمة true بشكل افتراضي.

```java
public bool StrictErrorChecking { get; set; }
```

### Property Value

`true` إذا كان فحص الأخطاء صارمًا؛ وإلا `false`.
