## Document.CreateAttributeNS method

طريقة Document.createAttribute() تنشئ عقدة سمة جديدة وتعيدها. الكائن ينشئ عقدة تنفذ واجهة [Attr](T:com.aspose.html.dom.Attr). لا يفرض DOM نوع السمات التي يمكن إضافتها إلى عنصر معين بهذه الطريقة.

```java
public Attr CreateAttributeNS(String packageURI, String qualifiedName)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| packageURI | String | مسار URI الحزمة للخاصية. |
| qualifiedName | String | name هو String يحتوي على اسم السمة. |
