## Document.XmlVersion property

سمة تحدد، كجزء من إعلان XML، رقم الإصدار لهذا المستند. إذا لم يكن هناك إعلان وإذا كان هذا المستند يدعم ميزة "XML"، تكون القيمة "1.0". إذا كان هذا المستند لا يدعم ميزة "XML"، تكون القيمة دائمًا null.

```java
public String XmlVersion { get; set; }
```

### Property Value

إصدار XML.
