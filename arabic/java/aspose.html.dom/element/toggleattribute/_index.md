## ToggleAttribute(String) {#toggleattribute}

إذا لم يُعطَ force، فإنها "تبدّل" qualifiedName، بإزالته إذا كان موجودًا وإضافته إذا لم يكن موجودًا. إذا كان force صحيحًا، تُضيف qualifiedName. إذا كان force خاطئًا، تُزيل qualifiedName.

```java
public bool ToggleAttribute(String qualifiedName)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| qualifiedName | String | السمة QualifiedName. |

### قيمة الإرجاع

تُرجع true إذا كان qualifiedName موجودًا الآن؛ وإلا false.
