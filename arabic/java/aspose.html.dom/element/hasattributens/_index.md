## Element.HasAttributeNS method

```java
public bool HasAttributeNS(String packageURI, String localName)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| packageURI | String | URI الحزمة. |
| localName | String | اسم المحلي. |

### قيمة الإرجاع

`true` إذا [has attribute NS] [the specified package URI]؛ وإلا `false`.
