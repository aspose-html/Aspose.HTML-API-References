## Element.TextContent property

هذه السمة تُعيد محتوى النص لهذه العقدة ونوابها. عندما تُحدّد كـ null، لا يؤثر تعيينها. عند التعيين، تُزال جميع الأطفال المحتملين لهذه العقدة، وإذا لم تكن السلسلة الجديدة فارغة أو null، تُستبدل بعقدة نصية واحدة تحتوي على السلسلة التي تم تعيينها لهذه السمة.

```java
public String TextContent { get; set; }
```

### Property Value

محتوى النص.
