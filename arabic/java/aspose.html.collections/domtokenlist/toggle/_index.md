## Toggle(String, bool) {#toggle_1}

يزيل الرمز من القائمة إذا كان موجودًا، أو يضيفه إلى القائمة إذا لم يكن موجودًا.

```java
public bool Toggle(String token, bool force)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| الرمز | String | الرمز الذي تريد تبديله. |
| force | Boolean | قيمة منطقية، إذا تم تضمينها، تحول التبديل إلى عملية أحادية الاتجاه. إذا تم تعيينها إلى false، فسيتم إزالة الرمز فقط، دون إضافته. إذا تم تعيينها إلى true، فسيتم إضافة الرمز فقط، دون إزالته. |

### قيمة الإرجاع

قيمة منطقية تشير إلى ما إذا كان الرمز موجودًا في القائمة بعد الاستدعاء.
