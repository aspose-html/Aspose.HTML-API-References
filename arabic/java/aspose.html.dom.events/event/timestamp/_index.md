## Event.TimeStamp property

تُستخدم لتحديد الوقت (بالمللي ثانية بالنسبة إلى الحقبة) الذي تم إنشاء الحدث فيه. بسبب أن بعض الأنظمة قد لا توفر هذه المعلومات قد لا تكون قيمة timeStamp متاحة لجميع الأحداث. عندما لا تكون متاحة، سيتم إرجاع القيمة 0. أمثلة على وقت الحقبة هي وقت بدء النظام أو 0:0:0 UTC 1 يناير 1970.

```java
public ulong TimeStamp { get; }
```
