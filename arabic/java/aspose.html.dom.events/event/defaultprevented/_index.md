## Event.DefaultPrevented property

تُعيد true إذا تم استدعاء preventDefault() بينما كانت قيمة السمة cancelable هي true، وتُعيد false خلاف ذلك.

```java
public bool DefaultPrevented { get; }
```

### Property Value

`true` إذا تم [default prevented]؛ وإلا `false`.
