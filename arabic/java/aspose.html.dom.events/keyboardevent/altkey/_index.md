## KeyboardEvent.AltKey property

true إذا كان معدل مفتاح Alt (البديل) (أو "Option") نشطًا. يجب أن تكون القيمة غير المبدئية لهذا السمة false.

```java
public bool AltKey { get; }
```

### Property Value

`true` إذا كان Alt؛ وإلا `false`.
