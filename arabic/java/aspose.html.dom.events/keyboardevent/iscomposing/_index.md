## KeyboardEvent.IsComposing property

true إذا حدث حدث المفتاح كجزء من جلسة تركيب، أي بعد حدث compositionstart وقبل حدث compositionend المقابل. يجب أن تكون القيمة غير المهيأة لهذه الخاصية false.

```java
public bool IsComposing { get; }
```

### Property Value

`true` إذا كانت هذه الحالة في وضع التركيب؛ وإلا، `false`.
