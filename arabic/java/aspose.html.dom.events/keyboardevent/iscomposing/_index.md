## KeyboardEvent.IsComposing property

true إذا كان حدث المفتاح يحدث كجزء من جلسة تكوين، أي بعد حدث compositionstart وقبل حدث compositionend المقابل. يجب أن تكون القيمة غير المهيأة لهذه الخاصية false.

```java
public bool IsComposing { get; }
```

### Property Value

`true` إذا كانت هذه الحالة في وضع التكوين؛ وإلا `false`.
