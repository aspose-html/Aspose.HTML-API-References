## KeyboardEvent.Repeat property

true إذا تم ضغط المفتاح بطريقة مستمرة. يجب أن يؤدي الضغط المطول على مفتاح إلى تكرار أحداث keydown و beforeinput و input بهذا الترتيب بمعدل يحدده تكوين النظام. بالنسبة للأجهزة المحمولة التي تدعم سلوك الضغط المطول، يجب أن يكون أول حدث مفتاح يحمل قيمة repeat true دليلاً على ضغط مطول. مدة الضغط المطلوبة لبدء التكرار تعتمد على التكوين.

```java
public bool Repeat { get; }
```

### Property Value

`true` إذا كان repeat؛ وإلا `false`.
