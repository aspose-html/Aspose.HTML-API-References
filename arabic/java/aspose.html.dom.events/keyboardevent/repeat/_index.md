## KeyboardEvent.Repeat property

true إذا تم ضغط المفتاح بطريقة مستمرة. يجب أن يؤدي الضغط المستمر على مفتاح إلى تكرار أحداث keydown و beforeinput و input بهذا الترتيب بمعدل يحدده تكوين النظام. بالنسبة للأجهزة المحمولة التي لديها سلوك ضغط مفتاح طويل، يجب أن يكون أول حدث مفتاح مع قيمة سمة repeat تساوي true دليلاً على ضغط مفتاح طويل. المدة التي يجب ضغط المفتاح فيها للبدء في التكرار تعتمد على التكوين.

```java
public bool Repeat { get; }
```

### Property Value

`true` إذا كان repeat؛ وإلا `false`.
