## InputEvent.IsComposing property

`true` إذا حدث حدث الإدخال كجزء من جلسة تركيب، أي بعد حدث compositionstart وقبل حدث compositionend المقابل. يجب أن تكون القيمة غير المهيأة لهذا السمة `false`.

```java
public bool IsComposing { get; }
```

### Property Value

`true` إذا كانت هذه الحالة في وضع التكوين؛ وإلا `false`.
