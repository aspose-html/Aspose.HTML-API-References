## InputEvent.IsComposing property

true إذا حدث إدخال الحدث كجزء من جلسة تكوين، أي بعد حدث compositionstart وقبل حدث compositionend المقابل. يجب أن تكون القيمة غير المبدئية لهذه السمة false.

```java
public bool IsComposing { get; }
```

### Property Value

`true` إذا كانت هذه الحالة في وضع التركيب؛ وإلا، `false`.
