بالإضافة إلى أدوات الإدخال والإخراج (IO) القياسية، الحزمة **com.aspose.html.io** تحتوي على فئات مساعدة وواجهات.

## الفئات

| الفئة | الوصف |
| --- | --- |
| [FileCreateStreamProvider](./filecreatestreamprovider/) | يمثل تنفيذ FileStream لتوفير التدفقات إلى أجهزة العرض. |
## الواجهات

| الواجهة | الوصف |
| --- | --- |
| [IBlob](./iblob/) | كائن Blob يشير إلى تسلسل بايتات، وله خاصية size التي تمثل إجمالي عدد البايتات في التسلسل، وخاصية type التي هي سلسلة (String) مشفرة بترميز ASCII بحروف صغيرة تمثل نوع الوسائط للتسلسل. |
| [ICreateStreamProvider](./icreatestreamprovider/) | يمثل واجهة يمكن تنفيذها بواسطة الفئات التي توفر التدفقات لأجهزة العرض. |
| [IFile](./ifile/) | كائن File هو كائن Blob مع خاصية name، وهي سلسلة (String)؛ يمكن إنشاؤه داخل تطبيق الويب عبر مُنشئ، أو يكون إشارة إلى تسلسل بايتات من ملف في نظام الملفات الأساسي (OS). |
| [IFileList](./ifilelist/) | يمثل الواجهة لقائمة الملفات. |
