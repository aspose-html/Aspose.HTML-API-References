بالإضافة إلى أدوات الإدخال والإخراج (IO) القياسية، الحزمة **com.aspose.html.io** تحتوي على فئات ومواجهات مساعدة.

## الفئات

| فئة | الوصف |
| --- | --- |
| [FileCreateStreamProvider](./filecreatestreamprovider/) | يمثل تنفيذ FileStream لتوفير التدفقات إلى أجهزة العرض. |
## الواجهات

| واجهة | الوصف |
| --- | --- |
| [IBlob](./iblob/) | كائن Blob يشير إلى تسلسل بايتات، وله خاصية size التي تمثل إجمالي عدد البايتات في تسلسل البايتات، وخاصية type التي هي سلسلة مشفرة بـ ASCII بأحرف صغيرة تمثل نوع الوسائط لتسلسل البايتات. |
| [ICreateStreamProvider](./icreatestreamprovider/) | يمثل واجهة يمكن أن تُنفّذها الفئات التي توفر التدفقات إلى أجهزة العرض. |
| [IFile](./ifile/) | كائن File هو كائن Blob مع خاصية name التي هي سلسلة نصية؛ يمكن إنشاؤه داخل تطبيق الويب عبر مُنشئ، أو يكون إشارة إلى تسلسل بايتات من ملف في نظام الملفات الأساسي (OS). |
| [IFileList](./ifilelist/) | يمثل الواجهة لقائمة الملفات. |
