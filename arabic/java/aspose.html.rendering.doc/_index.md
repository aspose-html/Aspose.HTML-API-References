الحزمة **com.aspose.html.rendering.doc** توفر فئة جهاز محددة بالإضافة إلى بعض فئات خيارات العرض المسؤولة عن العرض إلى مستند DOCX.

## الفئات

| فئة | الوصف |
| --- | --- |
| [DocDevice](./docdevice/) | يمثل التصيير إلى مستند DOCX. |
| [DocRenderingOptions](./docrenderingoptions/) | يمثل خيارات التصيير لـ [`DocDevice`](../com.aspose.html.rendering.doc/docdevice/). |
## تعداد

| تعداد | الوصف |
| --- | --- |
| [DocumentFormat](./documentformat/) | يمثل تنسيق الملف للمستند الناتج. |
| [FontEmbeddingRule](./fontembeddingrule/) | يمثل قواعد تضمين الخط. |
