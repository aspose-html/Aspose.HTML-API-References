## DocDevice.MoveTo method

يبدأ مسارًا فرعيًا جديدًا بنقل النقطة الحالية إلى إحداثيات المعامل pt، متجنبًا أي قطعة خطية ربطية. إذا كانت طريقة إنشاء المسار السابقة في المسار الحالي هي أيضًا "MoveTo"، فإن "MoveTo" الجديد يتجاوزها؛ لا يبقى أي أثر لعملية "MoveTo" السابقة في المسار.

```java
public void MoveTo(PointF pt)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| pt | PointF | النقطة التي يُنقل المسار إليها. |
