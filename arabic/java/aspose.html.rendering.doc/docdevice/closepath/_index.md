## DocDevice.ClosePath method

يغلق المسار الفرعي الحالي بإضافة قطعة خط مستقيم من النقطة الحالية إلى نقطة بدء المسار الفرعي. إذا كان المسار الفرعي الحالي مغلقًا بالفعل، فإن "ClosePath" لا يفعل شيئًا. هذا المشغل ينهي المسار الفرعي الحالي. إضافة قطعة أخرى إلى المسار الحالي يبدأ مسارًا فرعيًا جديدًا، حتى وإن بدأت القطعة الجديدة عند نقطة النهاية التي وصل إليها أسلوب "ClosePath".
