الحزمة **com.aspose.html.rendering.pdf.encryption** تحتوي على فئات بيانات تصف تفاصيل تشفير PDF مثل كلمة المرور، خوارزمية التشفير وما إلى ذلك.

## الفئات

| فئة | الوصف |
| --- | --- |
| [PdfEncryptionInfo](./pdfencryptioninfo/) | يحتوي على تفاصيل لتشفير PDF. |
## تعداد

| تعداد | الوصف |
| --- | --- |
| [PdfEncryptionAlgorithm](./pdfencryptionalgorithm/) | تعداد وضع التشفير. يصف الاستخدام باستخدام الخوارزمية وطول المفتاح. يتم توسيع هذا التعداد لزيادة الوظائف. هذا التعداد ينفّذ نمط "Base-to-Core". |
| [PdfPermissions](./pdfpermissions/) | يمثل هذا التعداد أذونات المستخدم لملف PDF. |
