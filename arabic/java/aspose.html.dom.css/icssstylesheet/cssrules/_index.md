## ICSSStyleSheet.CSSRules property

خاصية CSSStyleSheet للقراءة فقط cssRules تُعيد [`CSSRuleList`](../../icssrulelist/) حيًّا يُوفر قائمة محدثة في الوقت الحقيقي بكل قاعدة CSS التي تُكوّن ورقة الأنماط. كل عنصر في القائمة هو [`CSSRule`](../../icssrule/) يعرّف قاعدة واحدة.

```java
public ICSSRuleList CSSRules { get; }
```

### Property Value

قائمة [`CSSRuleList`](../../icssrulelist/) تُحدّث حيًّا وتحتوي على كل قواعد CSS التي تُكوّن ورقة الأنماط. كل مدخل في قائمة القواعد هو كائن [`CSSRule`](../../icssrule/) يصف قاعدة واحدة تُكوّن ورقة الأنماط.
