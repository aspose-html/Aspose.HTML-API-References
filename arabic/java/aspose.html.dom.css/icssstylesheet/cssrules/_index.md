## ICSSStyleSheet.CSSRules property

خاصية CSSStyleSheet للقراءة فقط cssRules تُرجع [`CSSRuleList`](../../icssrulelist/) حي يوفّر قائمة محدثة في الوقت الحقيقي بكل قاعدة CSS التي تُكوّن ورقة الأنماط. كل عنصر في القائمة هو [`CSSRule`](../../icssrule/) يعرّف قاعدة واحدة.

```java
public ICSSRuleList CSSRules { get; }
```

### Property Value

قائمة [`CSSRuleList`](../../icssrulelist/) محدثة حيًا تحتوي على كل قواعد CSS التي تُكوّن ورقة الأنماط. كل إدخال في قائمة القواعد هو كائن [`CSSRule`](../../icssrule/) يصف قاعدة واحدة تُكوّن ورقة الأنماط.
