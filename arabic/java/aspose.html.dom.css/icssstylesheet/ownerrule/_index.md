## ICSSStyleSheet.OwnerRule property

الخاصية للقراءة فقط CSSStyleSheet ownerRule تُعيد [`CSSImportRule`](../../icssimportrule/) المقابلة لتعليمات @import التي استوردت ورقة الأنماط إلى المستند. إذا لم يتم استيراد ورقة الأنماط إلى المستند باستخدام @import، فإن القيمة المرجعة تكون null.

```java
public ICSSRule OwnerRule { get; }
```

### Property Value

CSSImportRule المقابلة لتعليمات @import التي استوردت ورقة الأنماط إلى المستند. إذا لم يتم استيراد ورقة الأنماط إلى المستند باستخدام @import، فإن القيمة المرجعة تكون null.
