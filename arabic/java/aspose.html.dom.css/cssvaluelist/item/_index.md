## CSSValueList indexer

طريقة item() في واجهة CSSValueList تُستخدم لاسترجاع CSSValue وفقًا للفهرس الترتيبي.

الترتيب في هذه المجموعة يمثل ترتيب القيم في خاصية نمط CSS. إذا كان الفهرس أكبر من أو يساوي عدد القيم في القائمة، تُرجع هذه الطريقة null.

```java
public CSSValue this[int index] { get; }
```

### قيمة الإرجاع

كائن CSSValue في موضع الفهرس داخل CSSValueList، أو null إذا لم يكن فهرسًا صالحًا.

### Property Value

عدد صحيح غير موقع يمثل فهرس قيمة CSS داخل المجموعة.
