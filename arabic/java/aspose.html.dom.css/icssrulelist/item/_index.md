## ICSSRuleList indexer

تُستخدم لاسترجاع قاعدة CSS بواسطة الطريقة item() (http://www.w3.org/TR/DOM-Level-2-Style/css.html#CSS-CSSRuleList). الترتيب في هذه المجموعة يمثل ترتيب القواعد في ورقة أنماط CSS. إذا كان الفهرس أكبر من أو يساوي عدد القواعد في القائمة، فإنها تُعيد null.

```java
public ICSSRule this[int index] { get; }
```

### قيمة الإرجاع

يجب أن تُعيد طريقة item(index) كائن CSSRule رقم الفهرس في المجموعة. إذا لم يكن هناك كائن بهذا الفهرس في المجموعة، يجب أن تُعيد الطريقة null.

### Property Value

الفهرس داخل مجموعة قواعد CSS.
