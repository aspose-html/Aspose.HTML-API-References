## ICSSRule.CSSText property

خاصية cssText في واجهة [`CSSRule`](../) تُعيد النص الفعلي لقاعدة نمط في [`CSSStyleSheet`](../../icssstylesheet/).

ملاحظة: لا تخلط بين هذه الخاصية وخصائص العنصر‑نمط CSSStyleDeclaration.cssText.

```java
public String CSSText { get; set; }
```

### Property Value

تُعيد تسلسلًا لقاعدة CSS. عند تعيين سمة cssText يجب ألا يحدث أي شيء.
