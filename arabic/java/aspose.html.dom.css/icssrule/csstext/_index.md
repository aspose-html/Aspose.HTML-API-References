ملاحظة: لا تخلط بين هذه الخاصية و CSSStyleDeclaration.cssText الخاص بالعنصر.

```java
public String CSSText { get; set; }
```

### Property Value

تُعيد تسلسل قاعدة CSS. عند تعيين خاصية cssText يجب ألا يحدث أي شيء.
