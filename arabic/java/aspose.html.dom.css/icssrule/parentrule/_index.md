## ICSSRule.ParentRule property

إذا كانت هذه القاعدة موجودة داخل قاعدة أخرى (مثل قاعدة نمط داخل كتلة @media)، فهذه هي القاعدة الحاوية. إذا لم تكن هذه القاعدة متداخلة داخل أي قواعد أخرى، فإنها تُعيد null.

```java
public ICSSRule ParentRule { get; }
```

### Property Value

كائن [`CSSRule`](../) هو نوع القواعد الحاوية. إذا كانت القاعدة الحالية داخل استعلام وسائط، فستُعيد [`CSSMediaRule`](../../icssmediarule/). وإلا فإنها تُعيد null.
