## ILinkStyle interface

واجهة LinkStyle توفر آلية يمكن من خلالها استرجاع ورقة نمط من العقدة المسؤولة عن ربطها بمستند. يمكن الحصول على مثال من واجهة LinkStyle باستخدام طرق تحويل خاصة بالربط على مثال من عقدة ربط (HTMLLinkElement،

HTMLStyleElement أو ProcessingInstruction في DOM المستوى 2).
