## IElementCSSInlineStyle interface

معلومات النمط المضمنة المرتبطة بالعناصر تُكشف عبر سمة style. هذا يمثل محتويات سمة STYLE لعناصر HTML (أو العناصر في مخططات أو DTDs أخرى التي تستخدم سمة STYLE بنفس الطريقة). من المتوقع أن يتم الحصول على مثال من واجهة ElementCSSInlineStyle باستخدام طرق تحويل خاصة بالربط على مثال من واجهة Element عندما يدعم العنصر معلومات نمط CSS مضمنة.
