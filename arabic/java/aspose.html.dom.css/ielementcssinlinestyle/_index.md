## IElementCSSInlineStyle interface

معلومات النمط المضمنة المرفقة بالعناصر تُعرض عبر سمة style. هذا يمثل محتويات سمة STYLE لعناصر HTML (أو العناصر في مخططات أو DTDs أخرى تستخدم سمة STYLE بنفس الطريقة). من المتوقع أنه يمكن الحصول على مثال من واجهة ElementCSSInlineStyle باستخدام طرق التحويل الخاصة بالربط على مثال من واجهة Element عندما يدعم العنصر معلومات نمط CSS مضمنة.

انظر أيضًا إلى [CSS Object Model (CSSOM) # IElementCSSInlineStyle](https://www.w3.org/TR/cssom-1/#the-elementcssinlinestyle-mixin)
