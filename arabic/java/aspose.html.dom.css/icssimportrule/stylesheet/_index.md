## ICSSImportRule.StyleSheet property

ورقة الأنماط المشار إليها بهذا القاعدة، إذا تم تحميلها. قيمة هذه السمة تكون null إذا لم يتم تحميل ورقة الأنماط بعد أو إذا لن يتم تحميلها (مثلاً إذا كانت ورقة الأنماط لنوع وسائط غير مدعوم من قبل وكيل المستخدم).

```java
public ICSSStyleSheet StyleSheet { get; }
```

### Property Value

يرجع ورقة الأنماط CSS المحددة بواسطة قاعدة @import. ستكون على شكل كائن [`CSSStyleSheet`](../../icssstylesheet/).
