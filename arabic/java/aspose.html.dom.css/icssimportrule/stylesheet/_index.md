## ICSSImportRule.StyleSheet property

ورقة الأنماط المشار إليها بهذه القاعدة، إذا تم تحميلها. قيمة هذه الخاصية تكون null إذا لم يتم تحميل ورقة الأنماط بعد أو إذا لن يتم تحميلها (على سبيل المثال إذا كانت ورقة الأنماط لنوع وسائط غير مدعوم من قبل وكيل المستخدم).

```java
public ICSSStyleSheet StyleSheet { get; }
```

### Property Value

يعيد ورقة الأنماط CSS المحددة بواسطة قاعدة @import. ستكون على شكل كائن [`CSSStyleSheet`](../../icssstylesheet/).
