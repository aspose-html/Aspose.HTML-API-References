## IStyleSheetList.Length property

يجب أن تُعيد خاصية الطول (length) عدد أوراق الأنماط CSS التي تمثلها المجموعة. النطاق الصالح لمؤشرات أوراق الأنماط الفرعية هو من 0 إلى length-1 شاملًا.

```java
public int Length { get; }
```

### Property Value

عدد صحيح يُشير إلى عدد العناصر في المجموعة.
