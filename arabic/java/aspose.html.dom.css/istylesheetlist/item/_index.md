## IStyleSheetList indexer

طريقة item(index) يجب أن تُعيد ورقة الأنماط [`CSS style sheet`](../../icssstylesheet/) ذات الفهرس المحدد في المجموعة. إذا لم يوجد كائن بالفهرس المحدد في المجموعة، يجب أن تُعيد الطريقة null.

```java
public ICSSStyleSheet this[int index] { get; }
```

### قيمة الإرجاع

كائن [`CSSStyleSheet`](../../icssstylesheet/)، أو null إذا لم يكن موجودًا لهذا الفهرس.

### Property Value

عدد صحيح يمثل فهرس العنصر في المجموعة الذي سيُعاد.
