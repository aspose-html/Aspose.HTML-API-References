## ICSSMediaRule.InsertRule method

طريقة insertRule() في واجهة CSSGroupingRule تضيف قاعدة CSS جديدة إلى قائمة قواعد CSS.

```java
public long InsertRule(String rule, long index)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| قاعدة | String | قاعدة الوسائط كـ CSSOMString. |
| index | Int64 | فهرس اختياري يُحدد موضع إدراج القاعدة؛ القيمة الافتراضية 0. |

### قيمة الإرجاع

طريقة insertRule(rule, index) تُرجِع نتيجة استدعاء إدراج قاعدة CSS في قواعد CSS الفرعية عند الفهرس.
