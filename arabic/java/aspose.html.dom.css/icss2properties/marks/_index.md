## ICSS2Properties.Marks property

في الطباعة عالية الجودة، غالبًا ما تُضاف العلامات خارج صندوق الصفحة. تحدد هذه الخاصية ما إذا كان يجب عرض علامات التقاطع أو علامات القص أو كليهما خارج حافة [page box](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#page-box).

تشير علامات القص إلى المكان الذي يجب قطع الصفحة فيه. تُستخدم علامات التقاطع (المعروفة أيضًا بعلامات التسجيل أو علامات التسجيل) لمحاذاة الأوراق.

تظهر العلامات فقط على صناديق الصفحات المطلقة (انظر خاصية ['size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-size)). في صناديق الصفحات النسبية، سيتم محاذاة صندوق الصفحة مع الهدف وستكون العلامات خارج المنطقة القابلة للطباعة.

يعتمد حجم وشكل وموقع علامات الصليب على وكيل المستخدم.

```java
public String Marks { get; set; }
```
