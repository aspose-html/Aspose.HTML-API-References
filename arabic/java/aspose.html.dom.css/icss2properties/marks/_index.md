## ICSS2Properties.Marks property

في الطباعة عالية الجودة، تُضاف العلامات غالبًا خارج صندوق الصفحة. تحدد هذه الخاصية ما إذا كانت علامات التقاطع أو علامات القص أو كلاهما يجب أن تُرسم خارج حافة [صندوق الصفحة](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#page-box).

تشير علامات القص إلى مكان قطع الصفحة. تُستخدم علامات التقاطع (المعروفة أيضًا باسم علامات التسجيل أو علامات التسجيل) لمحاذاة الأوراق.

تظهر العلامات فقط على صناديق الصفحات المطلقة (انظر خاصية ['size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-size)). في صناديق الصفحات النسبية، سيتم محاذاة صندوق الصفحة مع الهدف وستكون العلامات خارج المنطقة القابلة للطباعة.

يعتمد حجم ونمط وموقع علامات الصليب على وكيل المستخدم.

```java
public String Marks { get; set; }
```
