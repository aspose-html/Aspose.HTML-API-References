## ICSS2Properties.BackgroundRepeat property

إذا تم تحديد صورة خلفية، تحدد هذه الخاصية ما إذا كانت الصورة مكررة (مبلطة) وكيفية ذلك. جميع البلاط يغطي مناطق المحتوى والحشو في الصندوق. القيم لها المعاني التالية:

repeat - يتم تكرار الصورة أفقياً وعمودياً. repeat-x - يتم تكرار الصورة أفقياً فقط. repeat-y - يتم تكرار الصورة عمودياً فقط. no-repeat - لا يتم تكرار الصورة: يتم رسم نسخة واحدة فقط من الصورة.

```java
public String BackgroundRepeat { get; set; }
```

### قيمة الإرجاع

خاصية background-repeat

### Property Value

قيمة تكرار الخلفية من القائمة كما تم تعريفها أعلاه.
