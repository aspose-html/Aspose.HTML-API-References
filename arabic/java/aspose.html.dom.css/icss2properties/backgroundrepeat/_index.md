## ICSS2Properties.BackgroundRepeat property

إذا تم تحديد صورة خلفية، تحدد هذه الخاصية ما إذا كانت الصورة مكررة (متكررة) وكيفية ذلك. جميع التكرارات تغطي مناطق المحتوى والحشو للمربع. للقيم المعاني التالية:

repeat - تُكرر الصورة أفقياً وعمودياً. repeat-x - تُكرر الصورة أفقياً فقط. repeat-y - تُكرر الصورة عمودياً فقط. no-repeat - لا تُكرر الصورة: يتم رسم نسخة واحدة فقط من الصورة.

```java
public String BackgroundRepeat { get; set; }
```

خاصية background-repeat

### Property Value

قيمة تكرار الخلفية من القائمة كما تم تعريفها أعلاه.
