## ICSS2Properties.BorderSpacing property

تحدد الأطوال المسافة التي تفصل حدود الخلايا المتجاورة. إذا تم تحديد طول واحد، فإنه يعطي كلًا من التباعد الأفقي والرأسي. إذا تم تحديد طولين، الأول يعطي التباعد الأفقي والثاني يعطي التباعد الرأسي. لا يجوز أن تكون الأطوال سالبة.

```java
public String BorderSpacing { get; set; }
```
