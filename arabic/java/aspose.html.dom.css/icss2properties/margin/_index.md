## ICSS2Properties.Margin property

خاصية ['margin'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin) هي خاصية مختصرة لتعيين ['margin-top'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-top), ['margin-right'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-right), ['margin-bottom'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-bottom), و ['margin-left'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-left) في نفس الموضع في ورقة الأنماط.

إذا كان هناك قيمة واحدة فقط، فإنها تُطبق على جميع الجوانب. إذا كان هناك قيمتان، يتم تعيين هوامش الأعلى والأسفل إلى القيمة الأولى وتُعيّن هوامش اليمين واليسار إلى القيمة الثانية. إذا كان هناك ثلاث قيم، يُعيّن الأعلى إلى القيمة الأولى، واليمين واليسار إلى القيمة الثانية، والأسفل إلى القيمة الثالثة. إذا كان هناك أربع قيم، فإنها تُطبق على الأعلى، اليمين، الأسفل، واليسار على التوالي.

public String Margin { get; set; }
