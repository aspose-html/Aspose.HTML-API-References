## ICSS2Properties.Clear property

تُشير هذه الخاصية إلى أي جوانب صندوق(صناديق) العنصر قد لا تكون متجاورة مع صندوق عائم سابق. (قد يكون للعنصر نفسه سُبْنَات عائمة؛ خاصية 'clear' لا تؤثر على تلك.)

يمكن تحديد هذه الخاصية فقط للعناصر ذات المستوى الكتلي (بما في ذلك العوامات). بالنسبة لصناديق الـcompact والـrun-in، تُطبق هذه الخاصية على صندوق الكتلة النهائي الذي ينتمي إليه الصندوق الـcompact أو الـrun-in.

القيم لها المعاني التالية عند تطبيقها على صناديق الكتلة غير العائمة:

left - يُزاد الهامش العلوي للصندوق المُولد بما يكفي بحيث يكون حافة الحد العلوي أسفل الحافة الخارجية السفلية لأي صناديق عائمة إلى اليسار نتجت عن عناصر سابقة في وثيقة المصدر. right - يُزاد الهامش العلوي للصندوق المُولد بما يكفي بحيث يكون حافة الحد العلوي أسفل الحافة الخارجية السفلية لأي صناديق عائمة إلى اليمين نتجت عن عناصر سابقة في وثيقة المصدر. both - يُنقل الصندوق المُولد أسفل جميع الصناديق العائمة للعناصر السابقة في وثيقة المصدر. none - لا يوجد قيد على موضع الصندوق بالنسبة للعوامات.

```java
public String Clear { get; set; }
```
