## ICSS2Properties.Clear property

هذه الخاصية تشير إلى أي جوانب صندوق(صناديق) العنصر قد لا تكون متجاورة مع صندوق عائم سابق. (قد يكون للعنصر نفسه سُلالات عائمة؛ خاصية 'clear' لا تؤثر عليها.)

يمكن تحديد هذه الخاصية فقط للعناصر ذات المستوى الكتلي (بما في ذلك العناصر العائمة). بالنسبة للصناديق المدمجة والصناديق المتداخلة، تُطبق هذه الخاصية على الصندوق الكتلي النهائي الذي ينتمي إليه الصندوق المدمج أو المتداخل.

القيم لها المعاني التالية عند تطبيقها على صناديق الكتل غير العائمة:

left - يتم زيادة الهامش العلوي للصندوق المُولد بما يكفي بحيث يكون حافة الحد العلوي أسفل الحافة الخارجية السفلية لأي صناديق عائمة إلى اليسار نتجت عن عناصر سابقة في وثيقة المصدر. right - يتم زيادة الهامش العلوي للصندوق المُولد بما يكفي بحيث يكون حافة الحد العلوي أسفل الحافة الخارجية السفلية لأي صناديق عائمة إلى اليمين نتجت عن عناصر سابقة في وثيقة المصدر. both - يُنقل الصندوق المُولد أسفل جميع الصناديق العائمة للعناصر السابقة في وثيقة المصدر. none - لا يوجد قيد على موضع الصندوق بالنسبة للعوامات.

```java
public String Clear { get; set; }
```
