## ICSS2Properties.BackgroundImage property

تُحدد هذه الخاصية صورة الخلفية لعنصر. عند تعيين صورة خلفية، يجب على المؤلفين أيضًا تحديد لون خلفية سيُستخدم عندما تكون الصورة غير متاحة. عندما تكون الصورة متاحة، تُرسم فوق لون الخلفية. (وبالتالي، يكون اللون مرئيًا في الأجزاء الشفافة من الصورة).

```java
public String BackgroundImage { get; set; }
```

### قيمة الإرجاع

خاصية background-image

### Property Value

القيم لهذه الخاصية إما , لتحديد الصورة، أو 'none' عندما لا تُستخدم صورة.
