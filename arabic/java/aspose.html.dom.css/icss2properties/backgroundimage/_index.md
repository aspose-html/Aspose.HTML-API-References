## ICSS2Properties.BackgroundImage property

هذه الخاصية تحدد صورة الخلفية لعنصر. عند تعيين صورة خلفية، يجب على المؤلفين أيضًا تحديد لون خلفية يُستخدم عندما تكون الصورة غير متاحة. عندما تكون الصورة متاحة، تُعرض فوق لون الخلفية. (وبالتالي، يكون اللون مرئيًا في أجزاء الصورة الشفافة).

```java
public String BackgroundImage { get; set; }
```

### قيمة الإرجاع

خاصية background-image

### Property Value

القيم لهذه الخاصية إما , لتحديد الصورة، أو 'none' عندما لا تُستخدم صورة.
