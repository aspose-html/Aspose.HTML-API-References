## ICSS2Properties.CaptionSide property

تحدد هذه الخاصية موضع صندوق التسمية بالنسبة لصندوق الجدول. القيم لها المعاني التالية:

top - يضع صندوق التسمية فوق صندوق الجدول. bottom - يضع صندوق التسمية أسفل صندوق الجدول. left - يضع صندوق التسمية إلى يسار صندوق الجدول. right - يضع صندوق التسمية إلى يمين صندوق الجدول.

public String CaptionSide { get; set; }
