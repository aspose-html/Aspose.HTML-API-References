## ICSS2Properties.Direction property

تحدد هذه الخاصية اتجاه الكتابة الأساسي للكتل واتجاه الإدراجات والتجاوزات (انظر ['unicode-bidi'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-unicode-bidi)) لخوارزمية Unicode الاتجاهية. بالإضافة إلى ذلك، تحدد اتجاه تخطيط أعمدة [table](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html)، واتجاه [overflow](https://www.w3.org/TR/1998/REC-CSS2-19980512/visufx.html#overflow) الأفقي، وموقع السطر الأخير غير المكتمل في كتلة في حالة 'text-align: justify'.

```java
public String Direction { get; set; }
```
