## ICSS2Properties.FontVariant property

في خط small-caps، تبدو رموز الأحرف الصغيرة مشابهة للأحرف الكبيرة، ولكن بحجم أصغر ومع نسب مختلفة قليلاً. تطلب خاصية 'font-variant' مثل هذا الخط للخطوط ذات حالتين (bicameral) كما في النص اللاتيني. لا يكون لهذه الخاصية تأثير مرئي على الخطوط ذات حالة واحدة (unicameral) كما هو الحال في معظم أنظمة الكتابة في العالم.

```java
public String FontVariant { get; set; }
```
