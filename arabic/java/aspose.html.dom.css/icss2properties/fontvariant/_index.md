## ICSS2Properties.FontVariant property

في خط الحروف الصغيرة، تبدو الحروف الصغيرة مشابهة للحروف الكبيرة، ولكن بحجم أصغر وبنسب مختلفة قليلاً. تطلب خاصية 'font-variant' مثل هذا الخط للخطوط ذات الحرفين (لديها حالتين كما في الخط اللاتيني). لا تؤثر هذه الخاصية مرئياً على الخطوط التي هي unicameral (لديها حالة واحدة فقط كما في معظم أنظمة الكتابة في العالم).

```java
public String FontVariant { get; set; }
```
