## ICSS2Properties.SpeakPunctuation property

تحدد هذه الخاصية كيفية نطق علامات الترقيم. القيم لها المعاني التالية:

code - يجب نطق علامات الترقيم مثل الفواصل المنقوطة والأقواس وما إلى ذلك حرفيًا. none - لا يجب نطق علامات الترقيم، بل تُعرض طبيعيًا كفواصل مختلفة.

```java
public String SpeakPunctuation { get; set; }
```
