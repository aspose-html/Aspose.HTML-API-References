## ICSS2Properties.ListStyleType property

هذه الخاصية تحدد مظهر علامة عنصر القائمة إذا كان ['list-style-image'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-list-style-image) يملك القيمة 'none' أو إذا لم يتمكن من عرض الصورة المشار إليها بواسطة الـ URI. القيمة 'none' تعني عدم وجود علامة، وإلا فهناك ثلاثة أنواع من العلامات: رموز (glyphs)، أنظمة ترقيم، وأنظمة أبجدية. ملاحظة. القوائم المرقمة تحسن إمكانية الوصول إلى المستندات بجعل القوائم أسهل في التنقل.

يتم تحديد الرموز (glyphs) باستخدام disc و circle و square. يعتمد عرضها الدقيق على وكيل المستخدم.

يتم تحديد أنظمة الترقيم باستخدام:

decimal - أعداد عشرية، تبدأ بـ 1.decimal-leading-zero - أعداد عشرية مملوءة بأصفار أولية (مثال: 01، 02، 03، …، 98، 99).lower-roman - أرقام رومانية صغيرة (i, ii, iii, iv, v، إلخ).upper-roman - أرقام رومانية كبيرة (I, II, III, IV, V، إلخ).hebrew - ترقيم عبري تقليدي.georgian - ترقيم جورجي تقليدي (an, ban, gan, …, he, tan, in, in-an, …).armenian - ترقيم أرمني تقليدي.cjk-ideographic - أعداد إيديوغرافية بسيطة.hiragana - a, i, u, e, o, ka, ki, …katakana - A, I, U, E, O, KA, KI, …hiragana-iroha - i, ro, ha, ni, ho, he, to, …katakana-iroha - I, RO, HA, NI, HO, HE, TO, …
