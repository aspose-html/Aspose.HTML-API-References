## ICSS2Properties.Overflow property

تحدد هذه الخاصية ما إذا كان محتوى العنصر على مستوى الكتلة يُقَص عندما يتجاوز صندوق العنصر (الذي يعمل ككتلة حاوية للمحتوى). القيم لها المعاني التالية:

visible - تشير هذه القيمة إلى أن المحتوى غير مقطوع، أي يمكن عرضه خارج صندوق الكتلة. hidden - تشير هذه القيمة إلى أن المحتوى مقطوع ولا يجب توفير آلية تمرير لعرض المحتوى خارج منطقة القطع؛ لن يتمكن المستخدمون من الوصول إلى المحتوى المقطوع. يتم تحديد حجم وشكل منطقة القطع بواسطة خاصية ['clip'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visufx.html#propdef-clip). scroll - تشير هذه القيمة إلى أن المحتوى مقطوع وأنه إذا كان عميل المستخدم يستخدم آلية تمرير مرئية على الشاشة (مثل شريط تمرير أو أداة تحريك)، يجب عرض تلك الآلية للصندوق سواء كان أي من محتوياته مقطوعًا أم لا. هذا يتجنب أي مشكلة مع ظهور واختفاء أشرطة التمرير في بيئة ديناميكية. عندما تُحدد هذه القيمة وكان وسط الهدف هو 'print' أو 'projection'، يجب طباعة المحتوى المتجاوز. auto - سلوك القيمة 'auto' يعتمد على عميل المستخدم، لكنه يجب أن يسبب توفير آلية تمرير للصناديق المتجاوزة.

```java
public String Overflow { get; set; }
```
