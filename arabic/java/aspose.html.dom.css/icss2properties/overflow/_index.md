## ICSS2Properties.Overflow property

تحدد هذه الخاصية ما إذا كان محتوى العنصر على مستوى الصندوق يُقَص عندما يتجاوز صندوق العنصر (الذي يعمل ككتلة حاوية للمحتوى). القيم لها المعاني التالية:

visible - يشير هذا القيمة إلى أن المحتوى غير مقص، أي قد يُعرض خارج صندوق الكتلة. hidden - يشير هذا القيمة إلى أن المحتوى مقص وأنه لا ينبغي توفير آلية تمرير لعرض المحتوى خارج منطقة القص؛ لن يتمكن المستخدمون من الوصول إلى المحتوى المقص. حجم وشكل منطقة القص محدد بواسطة الخاصية ['clip'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visufx.html#propdef-clip). scroll - يشير هذا القيمة إلى أن المحتوى مقص وأنه إذا كان عميل المستخدم يستخدم آلية تمرير مرئية على الشاشة (مثل شريط تمرير أو أداة تحريك)، يجب عرض تلك الآلية للصندوق سواء كان أي من محتواه مقصًا أم لا. هذا يتجنب أي مشكلة مع ظهور واختفاء أشرطة التمرير في بيئة ديناميكية. عندما يتم تحديد هذه القيمة وكان وسيط الهدف 'print' أو 'projection'، يجب طباعة المحتوى المتجاوز. auto - سلوك القيمة 'auto' يعتمد على عميل المستخدم، لكنه يجب أن يسبب توفير آلية تمرير للصناديق المتجاوزة.

```java
public String Overflow { get; set; }
```
