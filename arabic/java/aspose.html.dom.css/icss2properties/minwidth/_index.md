## ICSS2Properties.MinWidth property

تسمح هاتان الخاصيتان للمؤلفين بتقييد عرض الصناديق إلى نطاق معين. للقيم المعاني التالية:

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - يحدد حدًا أدنى أو أقصى ثابتًا للعرض المحسوب.'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - يحدد نسبة مئوية لتحديد القيمة المحسوبة. تُحسب النسبة المئوية بالنسبة إلى عرض [الكتلة الحاوية](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#containing-block) للصندوق المُنشأ. none - (فقط على ['max-width'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-max-width)) لا حد للعرض الصندوق.

```java
public String MinWidth { get; set; }
```
