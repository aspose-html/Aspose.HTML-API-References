## ICSS2Properties.Stress property

تحدد ارتفاع "القمم المحلية" في منحنى النغمة الصوتية. على سبيل المثال، اللغة الإنجليزية لغة مشددة، ويتم تعيين مستويات الضغط الأولية أو الثانوية أو الثلاثية لأجزاء مختلفة من الجملة. قيمة ['stress'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-stress) تتحكم في مقدار الانحناء الناتج عن هذه العلامات. هذه الخاصية مرافقة لخاصية ['pitch-range'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pitch-range) وتُوفر للمطورين إمكانية استغلال عروض سمعية متقدمة.

```java
public String Stress { get; set; }
```
