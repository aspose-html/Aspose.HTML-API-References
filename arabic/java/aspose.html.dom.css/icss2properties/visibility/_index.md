## ICSS2Properties.Visibility property

خاصية ['visibility'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visufx.html#propdef-visibility) تحدد ما إذا كانت الصناديق التي يولدها العنصر تُعرض. الصناديق غير المرئية لا تزال تؤثر على التخطيط (اضبط خاصية ['display'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-display) إلى 'none' لقمع توليد الصناديق تمامًا). القيم لها المعاني التالية:

visible - الصندوق المُولد مرئي. hidden - الصندوق المُولد غير مرئي (شفاف بالكامل)، لكنه لا يزال يؤثر على التخطيط. collapse - يرجى الاطلاع على القسم الخاص بـ [dynamic row and column effects](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#dynamic-effects) في الجداول. إذا استُخدم على عناصر غير الصفوف أو الأعمدة، فإن 'collapse' يحمل نفس معنى 'hidden'.

```java
public String Visibility { get; set; }
```
