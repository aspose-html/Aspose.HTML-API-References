## ICSS2Properties.FontFamily property

هذه الخاصية تحدد قائمة ذات أولوية من أسماء عائلات الخطوط و/أو أسماء العائلات العامة. للتعامل مع مشكلة أن خطًا واحدًا قد لا يحتوي على رموز لعرض جميع الأحرف في المستند، أو أن جميع الخطوط غير متوفرة على جميع الأنظمة، تسمح هذه الخاصية للمؤلفين بتحديد قائمة من الخطوط، جميعها من نفس النمط والحجم، تُجرب بالتسلسل لمعرفة ما إذا كانت تحتوي على رمز لحرف معين. تُسمى هذه القائمة مجموعة خطوط.

```java
public String FontFamily { get; set; }
```
