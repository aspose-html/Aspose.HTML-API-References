## ICSS2Properties.FontFamily property

تحدد هذه الخاصية قائمة ذات أولوية بأسماء عائلات الخطوط و/أو الأسماء العامة للعائلات. لمعالجة مشكلة عدم احتواء خط واحد على الحروف اللازمة لعرض جميع الأحرف في المستند، أو عدم توفر جميع الخطوط على جميع الأنظمة، تسمح هذه الخاصية للمؤلفين بتحديد قائمة من الخطوط، جميعها ذات النمط والحجم نفسه، تُجرّب بالتتابع لمعرفة ما إذا كانت تحتوي على حرف معين. تُسمى هذه القائمة مجموعة خطوط.

```java
public String FontFamily { get; set; }
```
