## ICSS2Properties.TextTransform property

تتحكم هذه الخاصية في تأثيرات تحويل الحروف في نص العنصر. القيم لها المعاني التالية:

capitalize - يضع الحرف الأول من كل كلمة بحرف كبير. uppercase - يضع جميع أحرف كل كلمة بحروف كبيرة. lowercase - يضع جميع أحرف كل كلمة بحروف صغيرة. none - لا توجد تأثيرات تحويل حروف.

```java
public String TextTransform { get; set; }
```
