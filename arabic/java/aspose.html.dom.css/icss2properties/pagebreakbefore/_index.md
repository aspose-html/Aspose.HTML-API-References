## ICSS2Properties.PageBreakBefore property

القيم لهذه الخصائص لها المعاني التالية:

auto - لا يفرض ولا يمنع فاصل صفحة قبل (بعد، داخل) الصندوق المُنشأ. always - يفرض دائمًا فاصل صفحة قبل (بعد) الصندوق المُنشأ. avoid - يتجنب فاصل صفحة قبل (بعد، داخل) الصندوق المُنشأ. left - يفرض فاصل صفحة واحد أو اثنين قبل (بعد) الصندوق المُنشأ بحيث يتم تنسيق الصفحة التالية كصفحة يسار. right - يفرض فاصل صفحة واحد أو اثنين قبل (بعد) الصندوق المُنشأ بحيث يتم تنسيق الصفحة التالية كصفحة يمين.

```java
public String PageBreakBefore { get; set; }
```
