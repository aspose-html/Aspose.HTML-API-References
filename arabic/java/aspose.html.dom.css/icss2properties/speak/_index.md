## ICSS2Properties.Speak property

تحدد هذه الخاصية ما إذا كان سيتم عرض النص صوتيًا وإذا كان كذلك، بأي طريقة (تشبه إلى حد ما خاصية ['display'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-display)). القيم الممكنة هي:

none - يمنع العرض الصوتي بحيث لا يحتاج العنصر إلى وقت للعرض. لاحظ، مع ذلك، أن العناصر التابعة قد تتجاوز هذه القيمة وسيتم نطقها. (للتأكد من منع عرض عنصر وعناصره التابعة، استخدم خاصية ['display'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-display)). normal - يستخدم قواعد نطق تعتمد على اللغة لعرض العنصر وأطفاله. spell-out - يتهجى النص حرفًا بحرف (مفيد للاختصارات والملخصات).

```java
public String Speak { get; set; }
```
