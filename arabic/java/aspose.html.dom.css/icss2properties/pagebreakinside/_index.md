## ICSS2Properties.PageBreakInside property

القيم لهذه الخصائص لها المعاني التالية:

auto - لا يفرض ولا يمنع فاصل صفحة قبل (بعد، داخل) الصندوق المُنشأ. always - يفرض دائمًا فاصل صفحة قبل (بعد) الصندوق المُنشأ. avoid - يتجنب فاصل صفحة قبل (بعد، داخل) الصندوق المُنشأ. left - يفرض فاصل صفحة واحد أو اثنين قبل (بعد) الصندوق المُنشأ بحيث يتم تنسيق الصفحة التالية كصفحة يسرى. right - يفرض فاصل صفحة واحد أو اثنين قبل (بعد) الصندوق المُنشأ بحيث يتم تنسيق الصفحة التالية كصفحة يمنى.

```java
public String PageBreakInside { get; set; }
```
