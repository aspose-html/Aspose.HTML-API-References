## ICSS2Properties.CounterReset property

خاصية ['counter-reset'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-counter-reset) تحتوي أيضًا على قائمة من اسم واحد أو أكثر للعدادات، يمكن أن يتبع كل اسم عدد صحيح اختياريًا. يُعطي العدد القيمة التي يُضبط عليها العداد عند كل ظهور للعنصر. القيمة الافتراضية هي 0.

public String CounterReset { get; set; }
