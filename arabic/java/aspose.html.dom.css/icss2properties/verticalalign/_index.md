## ICSS2Properties.VerticalAlign property

تؤثر هذه الخاصية على التموضع العمودي داخل صندوق السطر للمربعات التي يولدها عنصر على مستوى السطر. القيم التالية لا معنى لها إلا بالنسبة لعنصر أب على مستوى السطر، أو لعنصر أب على مستوى الكتلة، إذا كان ذلك العنصر يولد [صناديق داخلية مجهولة](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#anonymous)؛ لا تأثير لها إذا لم يوجد مثل هذا الأب.

ملاحظة. قيم هذه الخاصية لها معانٍ مختلفة قليلاً في سياق الجداول. يرجى مراجعة القسم المتعلق بـ [خوارزميات ارتفاع الجدول](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#height-layout) للحصول على التفاصيل. baseline - محاذاة خط الأساس للمربع مع خط أساس المربع الأب. إذا لم يكن للمربع خط أساس، يتم محاذاة أسفل المربع مع خط أساس الأب. middle - محاذاة منتصف المربع العمودي مع خط أساس المربع الأب زائد نصف ارتفاع x للأب. sub - خفض خط أساس المربع إلى الموضع المناسب للكتابات السفلية للمربع الأب. (هذه القيمة لا تؤثر على حجم الخط لنص العنصر.) super - رفع خط أساس المربع إلى الموضع المناسب للكتابات العلوية للمربع الأب. (هذه القيمة لا تؤثر على حجم الخط لنص العنصر.) text-top - محاذاة أعلى المربع مع أعلى خط الخط للعنصر الأب. text-bottom - محاذاة أسفل المربع مع أسفل خط الخط للعنصر الأب. '[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - رفع (قيمة إيجابية) أو خفض (قيمة سلبية) المربع بهذه المسافة (نسبة مئوية من قيمة ['line-height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-line-height)). القيمة '0%' تعني نفس 'baseline'. '[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - رفع (قيمة إيجابية) أو خفض (قيمة سلبية) المربع بهذه المسافة. القيمة '0cm' تعني نفس 'baseline'. top - محاذاة أعلى المربع مع أعلى صندوق السطر. bottom - محاذاة أسفل المربع مع أسفل صندوق السطر.
