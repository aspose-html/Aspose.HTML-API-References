## ICSS2Properties.Height property

تحدد هذه الخاصية [ارتفاع المحتوى](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#content-height) للمربعات التي تُنشئها العناصر ذات المستوى الكتلي والعناصر [مستبدلة](https://www.w3.org/TR/1998/REC-CSS2-19980512/conform.html#replaced-element).

هذه الخاصية لا تنطبق على العناصر غير المستبدلة [مستوى مضمن](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) العناصر. ارتفاع صناديق العنصر غير المستبدل المضمن يُحدد بواسطة قيمة (الموروثة ربما) ['ارتفاع-السطر'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-line-height) للعنصر.

```java
public String Height { get; set; }
```
