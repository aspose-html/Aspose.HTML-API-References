## ICSS2Properties.Height property

تحدد هذه الخاصية [ارتفاع المحتوى](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#content-height) للمربعات التي تُنشئها العناصر ذات المستوى الكتلي و العناصر [المستبدلة](https://www.w3.org/TR/1998/REC-CSS2-19980512/conform.html#replaced-element).

هذه الخاصية لا تنطبق على العناصر غير المستبدلة [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level). يتم تحديد ارتفاع مربعات العنصر غير المستبدل داخل السطر بقيمة (قد تكون موروثة) ['line-height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-line-height) للعنصر.

```java
public String Height { get; set; }
```
