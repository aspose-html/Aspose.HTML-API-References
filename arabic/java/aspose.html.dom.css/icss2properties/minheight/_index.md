## ICSS2Properties.MinHeight property

تسمح هاتان الخاصيتان للمؤلفين بتقييد ارتفاعات الصناديق إلى نطاق معين. القيم لها المعاني التالية:

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - يحدد ارتفاعًا محسوبًا ثابتًا كحد أدنى أو أقصى.'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - يحدد نسبة مئوية لتحديد القيمة المحسوبة. تُحسب النسبة المئوية بالنسبة إلى ارتفاع [containing block](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#containing-block) للصندوق المُولد. إذا لم يُحدد ارتفاع كتلة الحاوية صراحةً (أي أنه يعتمد على ارتفاع المحتوى)، تُفسَّر قيمة النسبة المئوية كـ 'auto'.none - (فقط على ['max-height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-max-height)) لا حد لارتفاع الصندوق.

```java
public String MinHeight { get; set; }
```
