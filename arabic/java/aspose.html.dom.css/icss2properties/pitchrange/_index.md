## ICSS2Properties.PitchRange property

يحدد التباين في متوسط النغمة. تُحدد النغمة المُدركة للصوت البشري بواسطة التردد الأساسي وعادةً ما تكون قيمتها 120 هرتز للصوت الذكري و210 هرتز للصوت الأنثوي. تُنطق اللغات البشرية بنغمات وتغيّرات في النبرة؛ هذه التغيّرات تنقل معنى إضافي وتأكيد. وبالتالي، الصوت المتحمس للغاية، أي الذي يتضمن تغيّرات شديدة، يُظهر نطاق نغمة عالٍ. تُحدد هذه الخاصية النطاق الذي تحدث فيه هذه التغيّرات، أي مقدار انحراف التردد الأساسي عن متوسط النغمة.

```java
public String PitchRange { get; set; }
```
