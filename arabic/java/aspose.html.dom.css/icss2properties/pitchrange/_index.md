## ICSS2Properties.PitchRange property

يحدد التباين في النغمة المتوسطة. تُحدد النغمة المتصورة للصوت البشري بواسطة التردد الأساسي وعادةً ما تكون قيمتها 120 هرتز للصوت الذكري و210 هرتز للصوت الأنثوي. تُنطق اللغات البشرية بنغمات وتغيّرات مختلفة؛ هذه التغيّرات تنقل معنى إضافي وتأكيد. وبالتالي، الصوت المتحمس للغاية، أي الذي يتضمن الكثير من التغيّرات، يظهر نطاق نغمة عالٍ. تحدد هذه الخاصية النطاق الذي تحدث فيه هذه التغيّرات، أي مقدار انحراف التردد الأساسي عن النغمة المتوسطة.

```java
public String PitchRange { get; set; }
```
