## ICSS2Properties.FontWeight property

خاصية 'font-weight' تحدد وزن الخط. القيم لها المعاني التالية:

100 إلى 900 - تشكل هذه القيم تسلسلًا مرتبًا، حيث يشير كل رقم إلى وزن يكون أغمق على الأقل من سابقه. normal - نفس القيمة '400'. bold - نفس القيمة '700'. bolder - يحدد الوزن التالي الذي يُعطى لخط أغمق من الخط الموروث. إذا لم يوجد مثل هذا الوزن، ينتج ببساطة القيمة العددية الأغمق التالية (ويظل الخط دون تغيير)، ما لم تكن القيمة الموروثة '900'، وفي هذه الحالة يكون الوزن الناتج أيضًا '900'. lighter - يحدد الوزن التالي الذي يُعطى لخط أخف من الخط الموروث. إذا لم يوجد مثل هذا الوزن، ينتج ببساطة القيمة العددية الأخف التالية (ويظل الخط دون تغيير)، ما لم تكن القيمة الموروثة '100'، وفي هذه الحالة يكون الوزن الناتج أيضًا '100'.

```java
public String FontWeight { get; set; }
```
