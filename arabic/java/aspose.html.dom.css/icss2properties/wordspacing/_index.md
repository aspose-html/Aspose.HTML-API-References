## ICSS2Properties.WordSpacing property

تحدد هذه الخاصية سلوك التباعد بين الكلمات. القيم لها المعاني التالية:

normal - المسافة العادية بين الكلمات، كما يحددها الخط الحالي و/أو UA. ['length'](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length) - تشير هذه القيمة إلى مساحة بين الكلمات بالإضافة إلى المسافة الافتراضية بين الكلمات. قد تكون القيم سلبية، لكن قد توجد حدود خاصة بالتنفيذ.

```java
public String WordSpacing { get; set; }
```
