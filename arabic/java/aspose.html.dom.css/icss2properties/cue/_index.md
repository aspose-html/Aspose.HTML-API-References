## ICSS2Properties.Cue property

خاصية ['cue'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue) هي اختصار لتعيين ['cue-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-before) و ['cue-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-after). إذا تم إعطاء قيمتين، تكون القيمة الأولى ['cue-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-before) والثانية ['cue-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-after). إذا تم إعطاء قيمة واحدة فقط، تُطبق على الخاصيتين.

```java
public String Cue { get; set; }
```
