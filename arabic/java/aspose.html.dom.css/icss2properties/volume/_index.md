## ICSS2Properties.Volume property

يشير الحجم إلى متوسط حجم الموجة. بمعنى آخر، قد يصل صوت عالي النبرة عند مستوى حجم 50 إلى قمة أعلى من ذلك. من المحتمل أن تكون القيم القابلة للتعديل من قبل الإنسان للراحة، على سبيل المثال باستخدام تحكم حجم مادي (يزيد كلا من القيم 0 و100 بنسبة متناسبة)؛ ما تفعله هذه الخاصية هو تعديل النطاق الديناميكي.

القيم لها المعاني التالية:

'[number](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-number)' - أي رقم بين '0' و'100'. '0' تمثل الحد الأدنى لمستوى الصوت المسموع و100 تمثل الحد الأقصى المريح.'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - يتم حساب قيم النسبة المئوية نسبةً إلى القيمة الموروثة، ثم تُقَص إلى النطاق '0' إلى '100'.silent - لا صوت على الإطلاق. القيمة '0' لا تعني نفس 'silent'.x-soft - نفس '0'.soft - نفس '25'.medium - نفس '50'.loud - نفس '75'.x-loud - نفس '100'.
