## ICSS2Properties.SpeechRate property

تحدد هذه الخاصية معدل الكلام. لاحظ أن قيم الكلمات المفتاحية المطلقة والنسبية مسموح بها (قارن مع ['font-size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html#propdef-font-size)). للقيم المعاني التالية:

'[number](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-number)' - يحدد معدل الكلام بالكلمات في الدقيقة، وهو مقدار يختلف قليلًا حسب اللغة لكنه مدعوم على نطاق واسع من قبل محركات الكلام.

x-slow - يعادل 80 كلمة في الدقيقة.

slow - يعادل 120 كلمة في الدقيقة.

متوسط - نفس 180 - 200 كلمة في الدقيقة.

سريع - نفس 300 كلمة في الدقيقة.

سريع جدًا - نفس 500 كلمة في الدقيقة.

أسرع - يضيف 40 كلمة في الدقيقة إلى معدل الكلام الحالي.

أبطأ - يطرح 40 كلمة في الدقيقة من معدل الكلام الحالي.

```java
public String SpeechRate { get; set; }
```
