## ICSS2Properties.LineHeight property

إذا تم تعيين الخاصية على عنصر [block-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#block-level) يحتوي محتواه على عناصر [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level)، فإنها تحدد الحد الأدنى للارتفاع لكل صندوق مضمن مُولد.

إذا تم تعيين الخاصية على عنصر [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level)، فإنها تحدد الارتفاع الدقيق لكل صندوق يُولد بواسطة العنصر. (باستثناء عناصر [replaced](https://www.w3.org/TR/1998/REC-CSS2-19980512/conform.html#replaced-element) المضمنة، حيث يُعطى ارتفاع الصندوق بواسطة الخاصية ['height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-height).)

```java
public String LineHeight { get; set; }
```
