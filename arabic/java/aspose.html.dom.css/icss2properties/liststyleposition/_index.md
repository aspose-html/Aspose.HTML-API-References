## ICSS2Properties.ListStylePosition property

تحدد هذه الخاصية موضع صندوق العلامة في صندوق الكتلة الرئيسي. القيم لها المعاني التالية:

outside - صندوق العلامة خارج صندوق الكتلة الرئيسي. ملاحظة. لم يحدد CSS1 الموقع الدقيق لصندوق العلامة ولأسباب التوافق، لا يزال CSS2 غامضًا بنفس القدر. للحصول على تحكم أكثر دقة في صناديق العلامة، يرجى استخدام markers.inside - صندوق العلامة هو أول صندوق مضمن في صندوق الكتلة الرئيسي، وبعد ذلك يتدفق محتوى العنصر.

public String ListStylePosition { get; set; }
