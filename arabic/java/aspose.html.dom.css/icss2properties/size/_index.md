## ICSS2Properties.Size property

تحدد هذه الخاصية الحجم والاتجاه لصندوق الصفحة.

يمكن أن يكون حجم صندوق الصفحة إما "مطلق" (حجم ثابت) أو "نسبي" (قابل للتوسع، أي يتناسب مع أحجام الأوراق المتاحة). تسمح صناديق الصفحات النسبية لوكلاء المستخدم بتكبير المستند واستخدام الحجم المستهدف بأفضل شكل.

ثلاث قيم لخاصية ['size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-size) تُنشئ صندوق صفحة نسبي:

auto - سيتم ضبط صندوق الصفحة على حجم واتجاه الورقة المستهدفة. landscape - يتجاوز اتجاه الهدف. يكون صندوق الصفحة بنفس حجم الهدف، وتكون الجوانب الأطول أفقية. portrait - يتجاوز اتجاه الهدف. يكون صندوق الصفحة بنفس حجم الهدف، وتكون الجوانب الأقصر أفقية.

```java
public String Size { get; set; }
```
