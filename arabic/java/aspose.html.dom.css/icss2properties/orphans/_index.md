## ICSS2Properties.Orphans property

تحدد خاصية ['orphans'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-orphans) الحد الأدنى لعدد أسطر الفقرة التي يجب تركها في أسفل الصفحة. تحدد خاصية ['widows'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-widows) الحد الأدنى لعدد أسطر الفقرة التي يجب تركها في أعلى الصفحة. تُعطى أمثلة على كيفية استخدامها للتحكم في فواصل الصفحات أدناه.

```java
public String Orphans { get; set; }
```
