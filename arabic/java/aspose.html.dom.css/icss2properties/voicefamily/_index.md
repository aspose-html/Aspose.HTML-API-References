## ICSS2Properties.VoiceFamily property

القيمة هي قائمة مفصولة بفواصل، ذات أولوية، لأسماء عائلات الصوت (قارن مع ['font-family'](https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html#propdef-font-family)). للقيم المعاني التالية:

'generic-voice' - القيم هي عائلات صوت. القيم الممكنة هي 'male'، 'female'، و 'child'.'specific-voice' - القيم هي حالات محددة (مثال: comedian, trinoids, carlos, lani).

```java
public String VoiceFamily { get; set; }
```
