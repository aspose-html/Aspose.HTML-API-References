## ICSS2Properties.BackgroundAttachment property

إذا تم تحديد صورة خلفية، تحدد هذه الخاصية ما إذا كانت ثابتة بالنسبة إلى نافذة العرض ('fixed') أو تتحرك مع المستند ('scroll').

حتى إذا كانت الصورة ثابتة، فإنها لا تكون مرئية إلا عندما تكون في خلفية العنصر أو منطقة الحشو. وبالتالي، ما لم تكون الصورة مكررة ('background-repeat: repeat')، قد تكون غير مرئية.

```java
public String BackgroundAttachment { get; set; }
```
