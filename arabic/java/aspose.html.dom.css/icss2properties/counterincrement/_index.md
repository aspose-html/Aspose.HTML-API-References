## ICSS2Properties.CounterIncrement property

تقبل خاصية ['counter-increment'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-counter-increment) اسمًا أو أكثر من العدادات (المعرفات)، كل منها يمكن أن يتبع عددًا صحيحًا اختياريًا. يشير العدد إلى مقدار الزيادة التي يضيفها العداد لكل ظهور للعنصر. الزيادة الافتراضية هي 1. يُسمح بالأعداد الصفرية والسالبة.

```java
public String CounterIncrement { get; set; }
```
