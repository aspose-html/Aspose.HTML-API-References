## ICSS2Properties.Border property

خاصية 'border' هي خاصية مختصرة لتعيين نفس العرض واللون والنمط لجميع الحدود الأربعة لصندوق. على عكس الخصائص المختصرة 'margin' و 'padding'، لا يمكن لخاصية 'border' تعيين قيم مختلفة على الحدود الأربعة. للقيام بذلك، يجب استخدام واحدة أو أكثر من خصائص border الأخرى.

```java
public String Border { get; set; }
```
