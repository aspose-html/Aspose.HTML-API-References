## ICSS2Properties.OutlineColor property

الحد المُنشأ باستخدام خصائص outline يُرسم "فوق" الصندوق، أي أن الحد يكون دائمًا في الأعلى، ولا يؤثر على موضع أو حجم الصندوق أو أي صناديق أخرى. لذلك، عرض أو إخفاء الحدود لا يسبب إعادة تدفق.

```java
public String OutlineColor { get; set; }
```
