## ICSS2Properties.FontSizeAdjust property

في النصوص ذات الحرفين، يكون الحجم الظاهري الذاتي والقراءة للخط أقل اعتمادًا على قيمة 'font-size' مقارنةً بقيمة 'x-height'، أو بصورة أكثر فائدة على نسبة هاتين القيمتين المسماة قيمة الجانب (حجم الخط مقسومًا على x-height). كلما ارتفعت قيمة الجانب، زادت احتمالية أن يكون الخط مقروءًا بأحجام أصغر. وعلى العكس، الخطوط ذات قيمة الجانب الأقل ستصبح غير مقروءة بسرعة أكبر تحت حجم عتبة معين مقارنةً بالخطوط ذات قيمة الجانب الأعلى. قد يؤدي استبدال الخطوط البسيط الذي يعتمد فقط على حجم الخط إلى أحرف غير مقروءة.

```java
public String FontSizeAdjust { get; set; }
```
