## ICSS2Properties.Elevation property

قيم هذه الخاصية لها المعاني التالية:

'angle' - يحدد الارتفاع كزاوية، بين '-90deg' و '90deg'. '0deg' يعني على الأفق الأمامي، وهو ما يعني تقريبًا مستوى المستمع. '90deg' يعني مباشرة فوق الرأس و '-90deg' يعني مباشرة أسفل. below - نفس '-90deg'. level - نفس '0deg'. above - نفس '90deg'. higher - يضيف 10 درجات إلى الارتفاع الحالي. lower - يطرح 10 درجات من الارتفاع الحالي.

public String Elevation { get; set; }
