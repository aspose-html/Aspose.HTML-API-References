## ICSS2Properties.Outline property

الحد المُنشأ باستخدام خصائص outline يُرسم "فوق" المربع، أي أن الحد يكون دائمًا في الأعلى، ولا يؤثر على موضع أو حجم المربع أو أي مربعات أخرى. لذلك، عرض أو إخفاء الحدود لا يسبب إعادة تدفق.

```java
public String Outline { get; set; }
```
