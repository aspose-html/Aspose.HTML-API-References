## ICSS2Properties.TextIndent property

هذه الخاصية تحدد إزاحة السطر الأول من النص في كتلة. بدقة أكبر، تحدد إزاحة الصندوق الأول الذي يتدفق إلى أول [صندوق سطر](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#line-box) للكتلة. يُزاح الصندوق بالنسبة إلى الحافة اليسرى (أو اليمنى، لتخطيط من اليمين إلى اليسار) لحافة صندوق السطر. يجب على وكلاء المستخدم عرض هذه الإزاحة كمسافة فارغة.

القيم لها المعاني التالية:

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - المسافة البادئة ذات طول ثابت.'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - المسافة البادئة هي نسبة مئوية من عرض كتلة الحاوية.

```java
public String TextIndent { get; set; }
```
