## ICSS2Properties.TextIndent property

تُحدد هذه الخاصية إزاحة السطر الأول من النص في كتلة. بشكل أدق، تُحدد إزاحة الصندوق الأول الذي يتدفق إلى أول [line box](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#line-box) للكتلة. يُزاح الصندوق بالنسبة إلى الحافة اليسرى (أو اليمنى، لتخطيط من اليمين إلى اليسار) لحافة صندوق السطر. يجب على عوامل المستخدم عرض هذه الإزاحة كمسافة فارغة.

القيم لها المعاني التالية:

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - المسافة البادئة بطول ثابت.'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - المسافة البادئة بنسبة مئوية من عرض كتلة الحاوية.

```java
public String TextIndent { get; set; }
```
