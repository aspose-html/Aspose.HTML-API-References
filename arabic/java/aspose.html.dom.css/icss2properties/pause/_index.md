## ICSS2Properties.Pause property

خاصية ['pause'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause) هي اختصار لتعيين ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) و['pause-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-after). إذا تم إعطاء قيمتين، تكون القيمة الأولى هي ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) والثانية هي ['pause-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-after). إذا تم إعطاء قيمة واحدة فقط، فإنها تُطبق على الخاصيتين.

```java
public String Pause { get; set; }
```
