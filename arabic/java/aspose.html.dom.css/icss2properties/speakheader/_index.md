## ICSS2Properties.SpeakHeader property

تحدد هذه الخاصية ما إذا كان يتم نطق رؤوس الجدول قبل كل خلية، أو فقط قبل خلية عندما تكون تلك الخلية مرتبطة برأس مختلف عن الخلية السابقة. القيم لها المعاني التالية:

once - يُنطق الرأس مرة واحدة، قبل سلسلة من الخلايا. always - يُنطق الرأس قبل كل خلية ذات صلة.

public String SpeakHeader { get; set; }
