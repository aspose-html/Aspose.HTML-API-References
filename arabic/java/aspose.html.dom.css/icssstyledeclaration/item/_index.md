## ICSSStyleDeclaration indexer

تُستخدم لاسترجاع الخصائص التي تم تعيينها صراحةً في كتلة الإعلان هذه. لا يجب أن يكون ترتيب الخصائص المسترجعة باستخدام هذه الطريقة هو نفس ترتيب تعيينها. يمكن استخدام هذه الطريقة للتكرار على جميع الخصائص في كتلة الإعلان هذه.

```java
public String this[int index] { get; }
```

### قيمة الإرجاع

propertyName هو سلسلة تمثل اسم خاصية CSS في الفهرس المحدد.

### Property Value

index هو فهرس العقدة التي سيتم جلبها. الفهرس يبدأ من الصفر.
