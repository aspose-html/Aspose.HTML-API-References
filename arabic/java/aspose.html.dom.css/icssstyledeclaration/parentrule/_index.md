## ICSSStyleDeclaration.ParentRule property

خاصية CSSStyleDeclaration.parentRule للقراءة فقط تُرجع CSSRule التي هي الأصل لهذا كتلة النمط، على سبيل المثال [`CSSStyleRule`](../../icssstylerule/) التي تمثل النمط لمحدد CSS.

```java
public ICSSRule ParentRule { get; }
```

### Property Value

قاعدة CSS التي تحتوي على كتلة الإعلان هذه أو null إذا لم يكن هذا [`CSSStyleDeclaration`](../) مرتبطًا بـ [`CSSRule`](../../icssrule/).
