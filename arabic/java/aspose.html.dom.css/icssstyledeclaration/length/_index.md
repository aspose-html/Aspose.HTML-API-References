## ICSSStyleDeclaration.Length property

الخاصية للقراءة فقط تُعيد عددًا صحيحًا للخصائص التي تم تعيينها صراحةً في كتلة إعلان CSS هذه. نطاق الفهارس الصالحة هو من 0 إلى length-1 شاملًا.

```java
public int Length { get; }
```

### Property Value

عدد صحيح يوفر عدد الأنماط التي تم تعيينها صراحةً على الأصل (parent) للنسخة.
