## SetProperty(String, String) {#setproperty}

واجهة طريقة CSSStyleDeclaration.setProperty() تُستخدم لتعيين قيمة خاصية بأولوية افتراضية داخل كتلة الإعلان هذه. الأولوية الافتراضية ليست \"important\" أي String.Empty.

```java
public void SetProperty(String propertyName, String value)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| propertyName | String | String يمثل اسم خاصية CSS (بصيغة الشرطية) التي سيتم تعديلها. |
| القيمة | String | String يحتوي على قيمة الخاصية الجديدة. إذا لم يُحدد، يُعامل كـ String فارغ. |

## SetProperty(String, String, String) {#setproperty_1}

واجهة طريقة CSSStyleDeclaration.setProperty() تُستخدم لتعيين قيمة خاصية بأولوية افتراضية داخل كتلة الإعلان هذه. الأولوية الافتراضية ليست \"important\" أي String.Empty.

```java
public void SetProperty(String propertyName, String value, String priority)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| propertyName | String | String يمثل اسم خاصية CSS (بصيغة الشرطية) التي سيتم تعديلها. |
| القيمة | String | String يحتوي على قيمة الخاصية الجديدة. إذا لم يُحدد، يُعامل كـ String فارغ. |
| الأولوية | String | String يسمح بتعيين أولوية CSS "important". إذا لم يُحدد، يُعامل كـ String فارغ. القيم المقبولة هي: قيمة String "important"، أو الكلمة المفتاحية undefined أو قيمة String فارغة "". |
