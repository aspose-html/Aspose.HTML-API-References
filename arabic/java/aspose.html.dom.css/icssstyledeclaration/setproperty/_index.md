## SetProperty(String, String) {#setproperty}

واجهة طريقة CSSStyleDeclaration.setProperty() تُستخدم لتعيين قيمة خاصية بأولوية افتراضية داخل هذه الكتلة الإعلانية. الأولوية الافتراضية ليست \"important\" أي String.Empty.

```java
public void SetProperty(String propertyName, String value)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| propertyName | String | سلسلة تمثل اسم خاصية CSS (بصيغة الشرطية) التي سيتم تعديلها. |
| القيمة | String | سلسلة تحتوي على القيمة الجديدة للخاصية. إذا لم تُحدد، تُعامل كسلسلة فارغة. |

## SetProperty(String, String, String) {#setproperty_1}

واجهة طريقة CSSStyleDeclaration.setProperty() تُستخدم لتعيين قيمة خاصية بأولوية افتراضية داخل هذه الكتلة الإعلانية. الأولوية الافتراضية ليست \"important\" أي String.Empty.

```java
public void SetProperty(String propertyName, String value, String priority)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| propertyName | String | سلسلة تمثل اسم خاصية CSS (بصيغة الشرطية) التي سيتم تعديلها. |
| القيمة | String | سلسلة تحتوي على القيمة الجديدة للخاصية. إذا لم تُحدد، تُعامل كسلسلة فارغة. |
| الأولوية | String | سلسلة تسمح بتعيين أولوية CSS "important". إذا لم تُحدد، تُعامل كسلسلة فارغة. القيم المقبولة هي: قيمة السلسلة "important"، أو كلمة مفتاحية غير معرفة أو قيمة سلسلة فارغة "". |
