## ICSSStyleRule.Style property

الخاصية النمطية للقراءة فقط هي واجهة [`CSSStyleDeclaration`](../../icssstyledeclaration/) لكتلة الإعلان الخاصة بـ [`CSSStyleRule`](../).

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

يجب أن تُعيد خاصية النمط كائن CSSStyleDeclaration لقاعدة النمط، مع الخصائص التالية:

computed flag - Unset. declarations - الإعلانات المعلنة في القاعدة، بالترتيب المحدد. parent CSS rule - كائن السياق. owner node - Null.
