### Property Value

## ملاحظات

يُمثَّر لون كل بكسل كرقم 32‑بت: 8 بت لكل من ألفا، الأحمر، الأخضر، والأزرق (ARGB). يحدد مكوّن ألفا شفافية اللون: 0 يعني شفاف تمامًا، و255 يعني غير شفاف تمامًا. بالمثل، قيمة A تساوي 255 تمثل لونًا غير شفاف. قيمة A من 1 إلى 254 تمثل لونًا شبه شفاف. يصبح اللون أكثر غير شفافية كلما اقتربت قيمة A من 255.
