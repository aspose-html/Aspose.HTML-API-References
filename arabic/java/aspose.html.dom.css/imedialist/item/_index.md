## IMediaList indexer

يجب أن تُعيد طريقة item(index) تسلسل استعلام الوسائط في مجموعة استعلامات الوسائط المعطاة بالفهرس، أو null إذا كان الفهرس أكبر من أو يساوي عدد استعلامات الوسائط في المجموعة.

```java
public String this[int index] { get; }
```

### قيمة الإرجاع

تُعيد سلسلة تمثل استعلام وسائط كنص، بناءً على قيمة فهرس استعلام الوسائط داخل [`MediaList`](../).

### Property Value

عدد صحيح يمثل فهرس العنصر في المجموعة الذي سيُعاد.
