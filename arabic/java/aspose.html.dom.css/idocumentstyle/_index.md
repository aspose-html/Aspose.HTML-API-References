## IDocumentStyle interface

واجهة DocumentStyle توفر آلية يمكن من خلالها استرجاع أوراق الأنماط المدمجة في المستند. من المتوقع أنه يمكن الحصول على مثال من واجهة DocumentStyle باستخدام طرق التحويل الخاصة بالربط على مثال من واجهة Document.

انظر أيضًا إلى [Document Object Model (DOM) Level 2 Style Specification](http://www.w3.org/TR/2000/REC-DOM-Level-2-Style-20001113).
