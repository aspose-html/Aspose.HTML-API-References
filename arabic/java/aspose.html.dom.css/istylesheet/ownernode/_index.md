## IStyleSheet.OwnerNode property

العقدة التي تربط ورقة الأنماط هذه بالمستند. بالنسبة إلى HTML، قد تكون العنصر LINK أو STYLE المقابل. بالنسبة إلى XML، قد تكون تعليمات المعالجة للربط. بالنسبة لورق الأنماط التي تُضمّنها ورق أنماط أخرى، تكون قيمة هذه الخاصية null.

```java
public Node OwnerNode { get; }
```

### Property Value

يجب أن تُعيد خاصية ownerNode العقدة المالكة.
