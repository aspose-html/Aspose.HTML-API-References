## IStyleSheet.OwnerNode property

العقدة التي تربط هذه الورقة النمطية بالمستند. في HTML قد تكون العنصر LINK أو STYLE المقابل. في XML قد تكون تعليمات المعالجة للربط. للورقات النمطية التي تُضمّن بواسطة ورقات نمطية أخرى، تكون قيمة هذه الخاصية null.

```java
public Node OwnerNode { get; }
```

### Property Value

يجب أن تُعيد خاصية ownerNode العقدة المالكة.

## ملاحظات

بالنسبة للورقات النمطية التي تُضمّن بواسطة ورقات نمطية أخرى، مثل @import، تكون قيمة هذه الخاصية null.
