## IStyleSheet.Media property

تحدد خاصية media في واجهة [`StyleSheet`](../) الوسائط المستهدفة المقصودة لمعلومات النمط. إنها كائن [`MediaList`](../../imedialist/) يشبه المصفوفة ولا يمكن تعديلها ويمكن إزالتها باستخدام deleteMedium() وإضافتها باستخدام appendMedium().

```java
public IMediaList Media { get; }
```

### Property Value

يجب أن تُعيد خاصية media كائن [`MediaList`](../../imedialist/) المرتبط بورقة الأنماط CSS.
