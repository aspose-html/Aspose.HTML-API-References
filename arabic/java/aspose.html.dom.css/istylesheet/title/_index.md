## IStyleSheet.Title property

خاصية العنوان في واجهة [`StyleSheet`](../) تُعيد العنوان الاستشاري لورقة الأنماط الحالية.

غالبًا ما يتم تحديد العنوان في [`ownerNode`](../ownernode/).

```java
public String Title { get; }
```

### Property Value

يجب أن تُعيد خاصية parentStyleSheet ورقة الأنماط [`CSS style sheet`](../../icssstylesheet/) الأصلية.
