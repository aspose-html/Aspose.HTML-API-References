## IStyleSheet.Href property

خاصية href في واجهة [`StyleSheet`](../) تُرجع موقع الورقة النمطية.

```java
public String Href { get; }
```

### Property Value

uri هو سلسلة تحتوي على URI الخاص بالورقة النمطية.

## ملاحظات

إذا كانت الورقة النمطية ورقة نمطية مرتبطة، فإن قيمة الخاصية هي موقعها. بالنسبة للورقات النمطية المضمنة، تكون قيمة هذه الخاصية NULL.

هذه الخاصية للقراءة فقط في Firefox وOpera وGoogle Chrome وSafari، وتكون للقراءة/الكتابة في Internet Explorer.
