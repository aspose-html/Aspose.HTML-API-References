الحزمة **com.aspose.html.rendering.image** توفر فئة جهاز محددة بالإضافة إلى بعض فئات خيارات العرض المسؤولة عن العرض إلى صيغ نقطية: jpeg، png، bmp، gif، tiff.

## الفئات

| فئة | الوصف |
| --- | --- |
| [ImageDevice](./imagedevice/) | تمثل التصيير إلى صيغ نقطية: jpeg، png، bmp، gif، tiff. |
| [ImageRenderingOptions](./imagerenderingoptions/) | تمثل خيارات التصيير لـ [`ImageDevice`](../com.aspose.html.rendering.image/imagedevice/). تُستخدم هذه الخيارات لتحديد صيغة الصورة الناتجة، الضغط، الدقة، إلخ. |
| [TextOptions](./textoptions/) | تمثل خيارات تصيير النص لـ [`ImageDevice`](../com.aspose.html.rendering.image/imagedevice/). |
## تعداد

| تعداد | الوصف |
| --- | --- |
| [Compression](./compression/) | يحدد مخططات الضغط الممكنة لصور البت الممسوحة بتنسيق Tagged Image File Format (TIFF). |
| [ImageFormat](./imageformat/) | يحدد تنسيق ملف الصورة. |
