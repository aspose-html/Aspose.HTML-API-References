الحزمة **com.aspose.html.rendering.image** توفر فئة جهاز محددة بالإضافة إلى عدد قليل من فئات خيارات العرض المسؤولة عن العرض إلى صيغ نقطية: jpeg، png، bmp، gif، tiff.

## الفئات

| الفئة | الوصف |
| --- | --- |
| [ImageDevice](./imagedevice/) | يمثل العرض إلى صيغ نقطية: jpeg، png، bmp، gif، tiff. |
| [ImageRenderingOptions](./imagerenderingoptions/) | يمثل خيارات العرض لـ [`ImageDevice`](../com.aspose.html.rendering.image/imagedevice/). تُستخدم هذه الخيارات لتحديد تنسيق الصورة الناتج، الضغط، الدقة، إلخ. |
| [TextOptions](./textoptions/) | يمثل خيارات عرض النص لـ [`ImageDevice`](../com.aspose.html.rendering.image/imagedevice/). |
## تعداد

| تعداد | الوصف |
| --- | --- |
| [Compression](./compression/) | يحدد مخططات الضغط الممكنة لصور البتية بتنسيق Tagged Image File Format (TIFF). |
| [ImageFormat](./imageformat/) | يحدد تنسيق ملف الصورة. |
