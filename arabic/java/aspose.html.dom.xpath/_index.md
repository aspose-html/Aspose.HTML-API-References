الحزمة تحتوي على طرق للتنقل عبر العناصر والسمات في مستند XML.

## الواجهات

| واجهة | الوصف |
| --- | --- |
| [IXPathEvaluator](./ixpathevaluator/) | تقييم تعبيرات XPath يتم توفيره بواسطة [`IXPathEvaluator`](../com.aspose.html.dom.xpath/ixpathevaluator/). |
| [IXPathExpression](./ixpathexpression/) | الواجهة `XPathExpression` تمثل تعبير XPath تم تحليله وحله. |
| [IXPathNamespace](./ixpathpackage/) | واجهة XPathNamespace تُرجع بواسطة واجهات XPathResult لتمثيل نوع عقدة حزمة XPath التي يفتقر إليها DOM. |
| [IXPathNSResolver](./ixpathnsresolver/) | الواجهة `XPathNSResolver` تسمح بسلاسل `prefix` في التعبير بأن تُربط بشكل صحيح بسلاسل `packageURI`. يمكن لـ [`IXPathEvaluator`](../com.aspose.html.dom.xpath/ixpathevaluator/) إنشاء تنفيذ لـ [`IXPathNSResolver`](../com.aspose.html.dom.xpath/ixpathnsresolver/) من عقدة، أو قد تُنفذ الواجهة من قبل أي تطبيق. |
| [IXPathResult](./ixpathresult/) | الواجهة `XPathResult` تمثل نتيجة تقييم تعبير XPath 1.0 ضمن سياق عقدة معينة. بما أن تقييم تعبير XPath يمكن أن ينتج أنواعًا مختلفة من النتائج، يتيح هذا الكائن إمكانية اكتشاف نوع النتيجة وقيمتها ومعالجتها. |
## تعداد

| تعداد | الوصف |
| --- | --- |
| [XPathResultType](./xpathresulttype/) | قيمة قصيرة غير موقعة تشير إلى نوع النتيجة. إذا تم تحديد `type` معين، فسيتم إرجاع النتيجة كنوعه المقابل، باستخدام تحويلات نوع XPath حيثما يلزم وممكن. |
