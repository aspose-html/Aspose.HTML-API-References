الحزمة تحتوي على طرق للتنقل عبر العناصر والسمات في مستند XML.

## الواجهات

| الواجهة | الوصف |
| --- | --- |
| [IXPathEvaluator](./ixpathevaluator/) | تقييم تعبيرات XPath يتم توفيره بواسطة [`IXPathEvaluator`](../com.aspose.html.dom.xpath/ixpathevaluator/). |
| [IXPathExpression](./ixpathexpression/) | واجهة `XPathExpression` تمثل تعبير XPath تم تحليله وحله. |
| [IXPathNamespace](./ixpathpackage/) | واجهة XPathNamespace يتم إرجاعها بواسطة واجهات XPathResult لتمثيل نوع عقدة حزمة XPath التي يفتقر إليها DOM. |
| [IXPathNSResolver](./ixpathnsresolver/) | واجهة `XPathNSResolver` تسمح بسلاسل `prefix` في التعبير بأن تُربط بشكل صحيح بسلاسل `packageURI`. يمكن لـ [`IXPathEvaluator`](../com.aspose.html.dom.xpath/ixpathevaluator/) إنشاء تنفيذ لـ [`IXPathNSResolver`](../com.aspose.html.dom.xpath/ixpathnsresolver/) من عقدة، أو قد تُنفذ الواجهة من قبل أي تطبيق. |
| [IXPathResult](./ixpathresult/) | واجهة `XPathResult` تمثل نتيجة تقييم تعبير XPath 1.0 ضمن سياق عقدة معينة. بما أن تقييم تعبير XPath يمكن أن ينتج أنواعًا مختلفة من النتائج، فإن هذا الكائن يجعل من الممكن اكتشاف نوع النتيجة وقيمتها ومعالجتها. |
## تعداد

| تعداد | الوصف |
| --- | --- |
| [XPathResultType](./xpathresulttype/) | قيمة من نوع unsigned short تشير إلى نوع النتيجة. إذا تم تحديد `type` معين، فسيتم إرجاع النتيجة كنوعه المقابل، باستخدام تحويلات نوع XPath حيثما يكون ذلك مطلوبًا وممكنًا. |
