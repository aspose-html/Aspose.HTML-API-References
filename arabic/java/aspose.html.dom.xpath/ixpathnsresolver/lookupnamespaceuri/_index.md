## IXPathNSResolver.LookupNamespaceURI method

ابحث عن URI الحزمة المرتبط بالبادئة المحددة. يجب ألا يستدعي مُقيم XPath هذا أبداً مع معامل `null` أو فارغ، لأن نتيجة القيام بذلك غير معرفة.

```java
public String LookupNamespaceURI(String prefix)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| بادئة | String | البادئة المراد البحث عنها. |

### قيمة الإرجاع

يعيد URI الحزمة المرتبط أو `null` إذا لم يُعثر على أي شيء.
