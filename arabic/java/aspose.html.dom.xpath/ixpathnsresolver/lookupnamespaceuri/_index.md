## IXPathNSResolver.LookupNamespaceURI method

ابحث عن URI الحزمة المرتبط بالبادئة المحددة. يجب ألا يستدعي مقيم XPath هذا أبداً مع قيمة `null` أو فارغة، لأن نتيجة ذلك غير معرفة.

```java
public String LookupNamespaceURI(String prefix)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| prefix | String | البادئة التي يجب البحث عنها. |

### قيمة الإرجاع

يرجع عنوان URI المرتبط بالحزمة أو `null` إذا لم يُعثر على أي شيء.
