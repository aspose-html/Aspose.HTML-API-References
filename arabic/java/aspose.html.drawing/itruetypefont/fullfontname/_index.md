## ITrueTypeFont.FullFontName property

يجب أن يكون هذا مزيجًا من "FamilyName" و"SubFamilyName". استثناء: إذا كان الخط "Regular" كما هو موضح في "SubFamilyName"، فاستعمل فقط اسم العائلة الموجود في "FamilyName". استثناء آخر لتعريف اسم الخط الكامل هو لسلاسل منصة Microsoft لخطوط CFF OpenType: في هذه الحالة، يجب أن تكون سلسلة اسم الخط الكامل مطابقة تمامًا لـ PostScript FontName في فهرس CFF Name INDEX.

```java
public String FullFontName { get; }
```
