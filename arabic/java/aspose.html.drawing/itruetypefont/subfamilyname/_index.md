## ITrueTypeFont.SubFamilyName property

يميز اسم Font Subfamily الخط داخل مجموعة لها نفس اسم Font Family. يُفترض أن يعالج النمط (italic, oblique) والوزن (light, bold, black, إلخ). الخط الذي لا يختلف في الوزن أو النمط (مثل الوزن المتوسط، غير مائل وتعيين البت 6 في fsSelection) يجب أن يحتوي على السلسلة \"Regular\" مخزنة في هذا الموضع.

```java
public String SubFamilyName { get; }
```
