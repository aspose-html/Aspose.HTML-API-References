## ITrueTypeFont.SubFamilyName property

يتميز اسم الفئة الفرعية للخط الخط داخل مجموعة لها نفس اسم عائلة الخط. يُفترض أن يُعالج النمط (مائل، مائل) والوزن (خفيف، عريض، أسود، إلخ). يجب أن يحتوي الخط الذي لا يختلف في الوزن أو النمط (مثل الوزن المتوسط، غير مائل وتعيين البت 6 في fsSelection) على السلسلة "Regular" مخزنة في هذا الموضع.

```java
public String SubFamilyName { get; }
```
