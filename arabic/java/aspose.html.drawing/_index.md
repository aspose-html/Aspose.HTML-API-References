الحزمة **com.aspose.html.drawing** تحتوي على كائنات وواجهات لتحديد القياسات والوحدات بالإضافة إلى كائنات سمات الرسم مثل الفُرَش، الألوان والخطوط.

## الفئات

| الفئة | الوصف |
| --- | --- |
| [Angle](./angle/) | نوع البيانات الزاوية |
| [Color](./color/) | تتيح لك فئة Color تحديد الألوان كقيم Red-Green-Blue (RGB)، وقيم Hue-Saturation-Luminosity (HSL)، وقيم Hue-Saturation-Value (HSV)، وقيم Hue-Whiteness-Blackness (HWB)، وقيم lightness-A-B (LAB)، وقيم Luminance-Chroma-Hue (LCH)، وقيم Cyan-Magenta-Yellow-Key (CMYK)، وقيم Natural colors (NCOL)، أو باسم اللون. كما يتوفر قناة Alpha للإشارة إلى الشفافية. |
| [Dimension](./dimension/) | يوفر الفئة الأساسية للأبعاد. المصطلح العام 'dimension' يشير إلى رقم مع وحدة مرفقة به، ويتم تمثيله بواسطة [`UnitType`](../com.aspose.html.drawing/unittype/). |
| [Frequency](./frequency/) | وحدة 'frequency'. |
| [Length](./length/) | يمثل وحدة قياس الطول. |
| [LengthOrAuto](./lengthorauto/) | يمثل حاوية لتخزين الطول أو وحدات 'auto'.. |
| [Margin](./margin/) | يمثل هامش الصفحة. |
| [Numeric](./numeric/) | يوفر الفئة الأساسية للأنواع العددية. |
| [Page](./page/) | يمثل كائن صفحة يُستخدم لتكوين صفحة الإخراج. القيمة الفارغة لحجم الصفحة هي A4(210x297مم) |
| [Resolution](./resolution/) | يمثل وحدة الدقة. |
| [Size](./size/) | يخزن قيمًا تحدد الارتفاع والعرض. |
| [Time](./time/) | يمثل وحدة زمنية. |
| [Unit](./unit/) | يوفر الفئة الأساسية لوحدات القياس. |
| [UnitType](./unittype/) | يحدد وحدة القياس. |
