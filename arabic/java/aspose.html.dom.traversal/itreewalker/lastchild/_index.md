## ITreeWalker.LastChild method

ينقل TreeWalker إلى الطفل المرئي الأخير للعقدة الحالية، ويعيد العقدة الجديدة. إذا لم يكن للعقدة الحالية أطفال مرئيون، يُعيد null، ويحتفظ بالعقدة الحالية.

```java
public Node LastChild()
```

### قيمة الإرجاع

العقدة الجديدة، أو null إذا لم يكن للعقدة الحالية أطفال في العرض المنطقي للـ TreeWalker.
