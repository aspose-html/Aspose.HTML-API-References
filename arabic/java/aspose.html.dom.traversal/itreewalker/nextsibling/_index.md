## ITreeWalker.NextSibling method

ينقل TreeWalker إلى الأخ التالي للعقدة الحالية، ويعيد العقدة الجديدة. إذا لم يكن للعقدة الحالية أخ مرئي التالي، يُعيد null، ويحتفظ بالعقدة الحالية.

```java
public Node NextSibling()
```

### قيمة الإرجاع

العقدة الجديدة، أو null إذا لم يكن للعقدة الحالية أخ تالي في العرض المنطقي للـ TreeWalker.
