## ITreeWalker.NextNode method

ينقل TreeWalker إلى العقدة المرئية التالية بترتيب المستند بالنسبة للعقدة الحالية، ويعيد العقدة الجديدة. إذا لم تكن للعقدة الحالية عقدة تالية، أو إذا حاول البحث عن nextNode الصعود من عقدة الجذر الخاصة بـ TreeWalker، يُعيد null، ويحتفظ بالعقدة الحالية.

```java
public Node NextNode()
```

### قيمة الإرجاع

العقدة الجديدة، أو null إذا لم تكن للعقدة الحالية عقدة تالية في العرض المنطقي للـ TreeWalker.
