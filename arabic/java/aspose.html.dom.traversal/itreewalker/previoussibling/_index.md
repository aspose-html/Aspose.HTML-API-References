## ITreeWalker.PreviousSibling method

ينقل الـ TreeWalker إلى الأخ السابق للعقدة الحالية، ويعيد العقدة الجديدة. إذا لم تكن للعقدة الحالية أخ مرئي سابق، يُعيد null، ويحتفظ بالعقدة الحالية.

```java
public Node PreviousSibling()
```

### قيمة الإرجاع

العقدة الجديدة، أو null إذا لم يكن للعقدة الحالية أخ سابق في العرض المنطقي لـ TreeWalker.
