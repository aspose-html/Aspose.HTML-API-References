## ISVGAnimatedPathData.AnimatedPathSegList property

توفر وصولاً إلى المحتويات المتحركة الحالية للخاصية ‘d’ في صيغة تتطابق واحدًا لواحد مع بنية SVG. إذا كانت الخاصية أو السمة المحددة قيد التحريك، فإنها تحتوي على القيمة المتحركة الحالية للخاصية أو السمة، وكلا من الكائن نفسه ومحتوياته للقراءة فقط. إذا لم تكن الخاصية أو السمة المحددة قيد التحريك حاليًا، فإنها تحتوي على نفس القيمة كما في pathSegList.

```java
public SVGPathSegList AnimatedPathSegList { get; }
```

قائمة مقاطع المسار المتحركة.
