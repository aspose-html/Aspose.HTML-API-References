## SVGSVGElement.GetElementById method

يبحث في جزء مستند SVG هذا (أي أن البحث يقتصر على جزء من شجرة المستند) عن عنصر Element whose id is given by elementId. إذا تم العثور على عنصر، يتم إرجاع ذلك العنصر. إذا لم يوجد مثل هذا العنصر، يرجع null. السلوك غير معرف إذا كان هناك أكثر من عنصر يحمل هذا المعرف.

```java
public Element GetElementById(String elementId)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| elementId | String | القيمة الفريدة للمعرف لعنصر. |
