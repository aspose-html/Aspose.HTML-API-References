## SVGSVGElement.SetCurrentTime method

يضبط الساعة لهذا الجزء من مستند SVG، ويحدد وقتًا حاليًا جديدًا. إذا تم استدعاء setCurrentTime قبل أن يبدأ خط الزمن للمستند (على سبيل المثال، بواسطة برنامج نصي يعمل في عنصر ‘script’ قبل أن يتم إرسال حدث SVGLoad للمستند)، فإن قيمة الثواني في آخر استدعاء للطريقة تعطي الوقت الذي سيسعى المستند إلى الوصول إليه بمجرد بدء خط الزمن للمستند.

```java
public void SetCurrentTime(float seconds)
```
