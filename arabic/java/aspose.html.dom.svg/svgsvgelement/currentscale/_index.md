## SVGSVGElement.CurrentScale property

في عنصر svg الخارجي، تشير هذه السمة إلى عامل المقياس الحالي بالنسبة للعرض الأولي لتأخذ في الاعتبار تكبير المستخدم وعمليات الإزاحة، كما هو موضح تحت التكبير والإزاحة. سمات DOM currentScale و currentTranslate مكافئتان للمصفوفة 2x3 [a b c d e f] = [currentScale 0 0 currentScale currentTranslate.x currentTranslate.y]. إذا تم تمكين \"magnification\" (أي، zoomAndPan=\"magnify\"), فإن التأثير يكون كما لو تم وضع تحويل إضافي في المستوى الخارجي على جزء وثيقة SVG (أي، خارج عنصر svg الخارجي). عند الوصول إلى سمة على عنصر ‘svg’ ليس هو العنصر الخارجي، يكون سلوك هذه السمة غير معرف.

```java
public float CurrentScale { get; set; }
```
