## SVGSVGElement.CurrentScale property

في عنصر svg الخارجي، تشير هذه السمة إلى معامل التكبير الحالي بالنسبة للعرض الأولي لتأخذ في الاعتبار تكبير المستخدم وعمليات الإزاحة، كما هو موضح في قسم التكبير والإزاحة. سمات DOM currentScale و currentTranslate تعادل مصفوفة 2x3 [a b c d e f] = [currentScale 0 0 currentScale currentTranslate.x currentTranslate.y]. إذا تم تمكين \"magnification\" (أي، zoomAndPan=\"magnify\")، فإن التأثير يكون كما لو تم إضافة تحويل إضافي على المستوى الخارجي لمجزوء وثيقة SVG (أي، خارج عنصر svg الخارجي). عند الوصول إلى سمة على عنصر ‘svg’ ليس خارجيًا، يكون سلوك هذه السمة غير معرف.

```java
public float CurrentScale { get; set; }
```
