## ISVGAnimatedPoints interface

واجهة SVGAnimatedPoints تدعم العناصر التي لديها سمة ‘points’ التي تحتوي على قائمة من قيم الإحداثيات والتي تدعم القدرة على تحريك تلك السمة. بالإضافة إلى ذلك، سمة ‘points’ على العنصر الأصلي التي يتم الوصول إليها عبر XML DOM (مثلاً باستخدام استدعاء طريقة getAttribute()) ستعكس أي تغييرات تُجرى على النقاط.

```java
public interface ISVGAnimatedPoints
```
