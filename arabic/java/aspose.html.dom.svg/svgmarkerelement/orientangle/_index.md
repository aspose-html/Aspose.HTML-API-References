## SVGMarkerElement.OrientAngle property

يتطابق مع السمة ‘orient’ في العنصر ‘marker’ المعطى. إذا كان markerUnits يساوي SVG_MARKER_ORIENT_ANGLE، فإن قيمة الزاوية للسمة ‘orient’; وإلا سيتم تعيينها إلى الصفر.

```java
public SVGAnimatedAngle OrientAngle { get; }
```

### Property Value

السمة ‘orient’ للعنصر ‘marker’ المعطى.
