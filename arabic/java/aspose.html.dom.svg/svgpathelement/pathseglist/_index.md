## SVGPathElement.PathSegList property

يوفر الوصول إلى المحتويات الأساسية (أي الثابتة) للخاصية ‘d’ في صيغة تتطابق تمامًا مع صياغة SVG. وبالتالي، إذا كانت الخاصية ‘d’ تحتوي على أمر \"تحريك مطلق (M)\" وأمر \"قوس مطلق (A)\"، فإن pathSegList سيحتوي على مدخلين: SVG_PATHSEG_MOVETO_ABS و SVG_PATHSEG_ARC_ABS.

public SVGPathSegList PathSegList { get; set; }
