## SVGPathElement.AnimatedPathSegList property

يوفر الوصول إلى المحتويات المتحركة الحالية للخاصية ‘d’ في صيغة تتطابق تمامًا مع صياغة SVG. إذا كانت الخاصية أو السمة المحددة قيد التحريك، فإنها تحتوي على القيمة المتحركة الحالية للخاصية أو السمة، ويكون كل من الكائن نفسه ومحتوياته للقراءة فقط. إذا لم تكن الخاصية أو السمة قيد التحريك حاليًا، فإنها تحتوي على نفس القيمة الموجودة في pathSegList.

```java
public SVGPathSegList AnimatedPathSegList { get; }
```

### Property Value

قائمة مقاطع المسار المتحركة.
