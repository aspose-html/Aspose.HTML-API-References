## SVGPolygonElement.AnimatedPoints property

توفر الوصول إلى المحتويات المتحركة الحالية لخاصية ‘points’. إذا كانت السمة أو الخاصية المعطاة قيد التحريك، فإنها تحتوي على القيمة المتحركة الحالية للسمة أو الخاصية. إذا لم تكن السمة أو الخاصية المعطاة قيد التحريك حالياً، فإنها تحتوي على نفس قيمة points.

public SVGPointList AnimatedPoints { get; }
