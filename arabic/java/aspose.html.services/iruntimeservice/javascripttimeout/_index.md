## IRuntimeService.JavaScriptTimeout property

يحصل أو يضبط TimeSpan الذي يحد من وقت تنفيذ JavaScript. إذا تم تنفيذ السكريبت لأكثر من TimeSpan المقدم، سيتم إلغاؤه. يمكنك تحديد مهلة غير محدودة بتعيين TimeSpan إلى -1 مللي ثانية. القيمة الافتراضية هي دقيقة واحدة.

```java
public TimeSpan JavaScriptTimeout { get; set; }
```
