## IRuntimeService.JavaScriptTimeout property

يحصل على أو يضبط TimeSpan الذي يحد من وقت تنفيذ JavaScript. إذا تم تنفيذ النص البرمجي لأكثر من TimeSpan المحدد، سيتم إلغاؤه. يمكنك تحديد مهلة غير نهائية بتعيين TimeSpan إلى -1 مللي ثانية. القيمة الافتراضية هي دقيقة واحدة.

```java
public TimeSpan JavaScriptTimeout { get; set; }
```
