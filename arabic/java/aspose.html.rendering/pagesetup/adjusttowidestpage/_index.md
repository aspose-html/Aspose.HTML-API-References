## PageSetup.AdjustToWidestPage property

يحصل أو يضبط العلامة التي تحدد الحالة التي سيتم فيها تعديل حجم الصفحة إلى أوسع صفحة في المستند. هذا الخيار مستهلك للوقت لذا يمكن أن يزداد زمن معالجة المستند بمقدار الضعف. سيتم التعديل فقط إذا كانت أوسع صفحة في المستند أوسع من حجم الصفحة المحدد في [`PageSetup`](../). سيتم استخدام حجم الصفحة المعدل لجميع الصفحات في المستند.

```java
public bool AdjustToWidestPage { get; set; }
```
