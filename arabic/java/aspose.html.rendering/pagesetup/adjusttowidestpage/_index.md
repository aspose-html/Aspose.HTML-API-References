## PageSetup.AdjustToWidestPage property

يحصل أو يضبط العلم الذي يحدد الحالة التي يتم فيها تعديل حجم الصفحة إلى أوسع صفحة في المستند. هذا الخيار مستهلك للوقت لذا يمكن أن يتضاعف زمن معالجة المستند. سيجري التعديل فقط إذا كانت أوسع صفحة في المستند أوسع من حجم الصفحة المحدد في [`PageSetup`](../). سيُستخدم حجم الصفحة المعدل لجميع الصفحات في المستند.

```java
public bool AdjustToWidestPage { get; set; }
```
