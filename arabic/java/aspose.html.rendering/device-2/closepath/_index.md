## Device&lt;TGraphicContext,TRenderingOptions&gt;.ClosePath method

يغلق المسار الفرعي الحالي بإضافة مقطع خط مستقيم من النقطة الحالية إلى نقطة بدء المسار الفرعي. إذا كان المسار الفرعي الحالي مغلقًا بالفعل، فإن \"ClosePath\" لا يفعل شيئًا. هذا المشغل ينهي المسار الفرعي الحالي. إضافة مقطع آخر إلى المسار الحالي يبدأ مسارًا فرعيًا جديدًا، حتى إذا بدأ المقطع الجديد عند نقطة النهاية التي وصل إليها أسلوب \"ClosePath\".
