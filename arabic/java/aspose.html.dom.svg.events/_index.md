تتكون الحزمة من فئات للتفاعل القائم على الأحداث مثل أحداث الوقت والتكبير.

## الفئات

| فئة | الوصف |
| --- | --- |
| [SVGZoomEvent](./svgzoomevent/) | يحدث حدث التكبير عندما يبدأ المستخدم إجراءً يؤدي إلى إعادة قياس العرض الحالي لجزء وثيقة SVG. يتم التعرف على معالجات الأحداث فقط على عناصر ‘svg’. |
| [TimeEvent](./timeevent/) | توفر واجهة TimeEvent معلومات سياقية محددة مرتبطة بأحداث الوقت. الأنواع المختلفة للأحداث التي يمكن حدوثها هي: beginEvent، endEvent و repeatEvent. |
