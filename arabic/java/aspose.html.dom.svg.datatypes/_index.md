توفر الحزمة الوصول إلى جميع أنواع البيانات الخاصة بـ SVG.

## الفئات

| فئة | الوصف |
| --- | --- |

| [SVGAnimatedAngle](./svganimatedangle/) | تُستخدم لسمات نوع البيانات الأساسي angle التي يمكن تحريكها. |

| [SVGAnimatedEnumeration](./svganimatedenumeration/) | تُستخدم لسمات يجب أن تكون قيمتها ثابتة من تعداد معين ويمكن تحريكها. |
| [SVGAnimatedInteger](./svganimatedinteger/) | تُستخدم لسمات من النوع الأساسي integer التي يمكن تحريكها. |
| [SVGAnimatedLength](./svganimatedlength/) | تُستخدم لسمات من النوع الأساسي length التي يمكن تحريكها. |
| [SVGAnimatedLengthList](./svganimatedlengthlist/) | تُستخدم لسمات من النوع SVGLengthList التي يمكن تحريكها. |
| [SVGAnimatedNumber](./svganimatednumber/) | تُستخدم لسمات من النوع الأساسي number التي يمكن تحريكها. |
| [SVGAnimatedNumberList](./svganimatednumberlist/) | تُستخدم لسمات تأخذ قائمة من الأعداد ويمكن تحريكها. |

| [SVGAnimatedRect](./svganimatedrect/) | تُستخدم لسمات من النوع SVGRect التي يمكن تحريكها. |
| [SVGAnimatedString](./svganimatedString/) | تُستخدم لسمات من النوع DOMString التي يمكن تحريكها. |
| [SVGAnimatedTransformList](./svganimatedtransformlist/) | يُستخدم للسمات المتنوعة التي تحدد مجموعة من التحويلات، مثل السمة ‘transform’ المتوفرة للعديد من عناصر SVG، والتي يمكن تحريكها. |
| [SVGAnimatedValue&lt;T&gt;](./svganimatedvalue-1/) | يُستخدم لسمات الأنواع التي يمكن تحريكها. |

| [SVGLengthList](./svglengthlist/) | تُعرّف هذه الواجهة قائمة من كائنات SVGLength. |
| [SVGMatrix](./svgmatrix/) | تستخدم العديد من عمليات رسومات SVG مصفوفات 2×3 على الشكل: [a c e] [b d f] والتي، عند توسيعها إلى مصفوفة 3×3 لأغراض حساب المصفوفات، تصبح: [a c e] [b d f] [0 0 1] |
| [SVGNumber](./svgnumber/) | يُستخدم لسمات من النوع الأساسي number. |
| [SVGNumberList](./svgnumberlist/) | تُعرّف هذه الواجهة قائمة من كائنات SVGNumber. |
| [SVGPoint](./svgpoint/) | تشير العديد من واجهات SVG DOM إلى كائنات من الفئة SVGPoint. يُعد SVGPoint زوج إحداثيات (x, y). عند استخدامه في عمليات المصفوفات، يُعامل SVGPoint كمتجه على الشكل: [x] [y] [1]. إذا تم تعيين كائن SVGRect على أنه للقراءة فقط، فإن محاولة تعديل أحد سماته ستؤدي إلى رمي استثناء. |
| [SVGPointList](./svgpointlist/) | تُعرّف هذه الواجهة قائمة من كائنات SVGPoint. |
| [SVGPreserveAspectRatio](./svgpreserveaspectratio/) | واجهة SVGPreserveAspectRatio تتطابق مع السمة ‘preserveAspectRatio’ المتوفرة لبعض عناصر SVG. |
| [SVGRect](./svgrect/) | يمثل الهندسة المستطيلة. تُعرّف المستطيلات بأنها تتكون من زوج إحداثيات (x, y) يحدد قيمة X الدنيا، قيمة Y الدنيا، وعرض وارتفاع، عادةً ما تكون مقيدة بأن تكون غير سالبة. |
| [SVGStringList](./svgStringlist/) | تحتوي SVGStringList على نفس السمات والطرق مثل واجهات SVGxxxList الأخرى. قد يفكر المطورون في استخدام فئة أساسية واحدة لتنفيذ واجهات SVGxxxList المتنوعة. |
| [SVGTransform](./svgtransform/) | SVGTransform هي الواجهة لأحد التحويلات المكوّنة داخل SVGTransformList؛ وبالتالي، يتطابق كائن SVGTransform مع مكوّن واحد (مثل 'scale(…)' أو 'matrix(…)') داخل تحديد سمة ‘transform’. |
| [SVGTransformList](./svgtransformlist/) | تُعرّف هذه الواجهة قائمة من كائنات SVGTransform. |
| [SVGValueType](./svgvaluetype/) | يُستخدم النوع SVGValueType لتمثيل نوع قيمة أساسي في SVG. |
