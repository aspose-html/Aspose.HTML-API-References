## SVGPoint class

تشير العديد من واجهات SVG DOM إلى كائنات من الفئة SVGPoint. SVGPoint هو زوج إحداثيات (x, y). عند استخدامها في عمليات المصفوفات، تُعامل SVGPoint كمتجه بالشكل: [x] [y] [1]. إذا تم تعيين كائن SVGRect كقراءة فقط، فإن محاولة تعديل أحد سماته ستؤدي إلى رمي استثناء.

```java
public class SVGPoint : SVGValueType
```
