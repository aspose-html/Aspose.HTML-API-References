## ResourceHandlingOptions.MaxHandlingDepth property

يحصل أو يضبط الحد الأقصى لعمق الصفحات التي سيتم معالجتها. العمق 1 يعني أن الصفحات التي تم الإشارة إليها مباشرة من المستند المحفوظ فقط هي التي ستُعالج. ضبط هذه الخاصية إلى -1 سيؤدي إلى معالجة جميع الصفحات. القيمة الافتراضية هي 0.

```java
public int MaxHandlingDepth { get; set; }
```
