## TextSaveOptions.EnableListItemMarkers property

الخيار الذي يُطبق على عناصر OL, UL عند تحويل HTML إلى نص. في الواقع يحدد كيفية معالجة علامات القوائم الخارجية لعناصر OL و UL. إذا كان true تُضاف أرقام العناصر قبل عناصر OL، أو تُضاف نقاط قبل عناصر UL. إذا كان false لا تُضاف (السلوك الافتراضي يتبع المواصفة)

```java
public bool EnableListItemMarkers { get; set; }
```
