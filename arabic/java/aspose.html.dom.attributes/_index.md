حزمة **com.aspose.html.dom.attributes** تحتوي على فئات سمة موحدة تحدد أو تُؤهل أي خاصية أو سلوك لكائن (عقدة، عنصر، ...).

## الفئات

| الفئة | الوصف |
| --- | --- |
| [DOMConstructorAttribute](./domconstructorattribute/) | يحدد مُنشئًا تم تعريفه بواسطة W3C. |
| [DOMNameAttribute](./domnameattribute/) | يحدد الاسم الرسمي لكائن DOM كما تم تعريفه بواسطة W3C. |
| [DOMNamedPropertyGetterAttribute](./domnamedpropertygetterattribute/) | يحدد أن الطريقة ستُستخدم كجالب خاصية مسماة. |
| [DOMNoInterfaceObjectAttribute](./domnointerfaceobjectattribute/) | إذا ظهر سمة الامتداد [NoInterfaceObject] على واجهة، فهذا يشير إلى أن كائن الواجهة لن يكون موجودًا للواجهة في ربط ECMAScript. |
| [DOMNullableAttribute](./domnullableattribute/) | يحدد أنه يمكن تعيين قيمة null لكائن DOM. |
| [DOMObjectAttribute](./domobjectattribute/) | يحدد أن الكائن المعلَّم بهذه السمة تم تعريفه بواسطة W3C. |
| [DOMTreatNullAsAttribute](./domtreatnullasattribute/) | يشير إلى أن قيمة null للعضو ستُعامل كقيمة محددة. |
