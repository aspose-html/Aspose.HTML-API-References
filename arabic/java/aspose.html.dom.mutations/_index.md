توفر الحزمة **com.aspose.html.dom.mutations** فرصة لمراقبة تحولات الـ DOM والحصول على معلومات رد نداء محددة.

## الفئات

| فئة | الوصف |
| --- | --- |
| [MutationCallback](./mutationcallback/) | يمثل الطريقة التي ستتعامل مع أحداث التغيير. |
| [MutationObserver](./mutationobserver/) | يمكن استخدام كائن لمراقبة التغييرات في شجرة [`.`](../com.aspose.html.dom/node/) |
| [MutationObserverInit](./mutationobserverinit/) | هذه الفئة تمثل مجموعة خيارات تُستخدم لتكوين [`MutationObserver`](../com.aspose.html.dom.mutations/mutationobserver/). |
| [MutationRecord](./mutationrecord/) | تمثل MutationRecord تعديلًا فرديًا في DOM. وهو الكائن الذي يُمرَّر إلى [`MutationObserver`](../com.aspose.html.dom.mutations/mutationobserver/)'s [`MutationCallback`](../com.aspose.html.dom.mutations/mutationcallback/). |
