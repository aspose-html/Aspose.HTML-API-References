## HTMLInputElement.DefaultChecked property

عندما تكون سمة `type` ذات القيمة "radio" أو "checkbox"، فإنها تمثل سمة HTML checked للعنصر. لا تتغير قيمة هذه السمة إذا تغير حالة عنصر التحكم في النموذج المقابل في وكيل مستخدم تفاعلي. راجع تعريف سمة checked في HTML 4.01.

```java
public bool DefaultChecked { get; set; }
```
