## HTMLInputElement.DefaultChecked property

عندما تكون سمة `type` ذات القيمة \"radio\" أو \"checkbox\"، فإنها تمثل سمة checked في HTML للعنصر. لا تتغير قيمة هذه السمة إذا تغير حالة عنصر النموذج المقابل في عميل تفاعلي. راجع تعريف سمة checked في HTML 4.01.

```java
public bool DefaultChecked { get; set; }
```
