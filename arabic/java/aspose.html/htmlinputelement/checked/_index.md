## HTMLInputElement.Checked property

عندما تكون سمة `type` للعنصر لها القيمة "radio" أو "checkbox"، تمثل هذه السمة الحالة الحالية لعنصر التحكم في النموذج في وكيل مستخدم تفاعلي. تغيّر هذه السمة حالة عنصر التحكم في النموذج، ولكن لا يغيّر قيمة سمة HTML checked لعنصر INPUT. أثناء معالجة حدث النقر على عنصر input ذات سمة type التي لها القيمة "radio" أو "checkbox" قد تقوم بعض التطبيقات بتغيير قيمة هذه الخاصية قبل إرسال الحدث في المستند. إذا تم إلغاء الإجراء الافتراضي للحدث، قد تُعاد قيمة الخاصية إلى قيمتها الأصلية. هذا يعني أن قيمة هذه الخاصية أثناء معالجة أحداث النقر تعتمد على التنفيذ.

```java
public bool Checked { get; set; }
```
