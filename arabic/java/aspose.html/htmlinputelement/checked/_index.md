## HTMLInputElement.Checked property

عندما تكون سمة `type` للعنصر لها القيمة "radio" أو "checkbox", تمثل هذه السمة الحالة الحالية للتحكم في النموذج في عميل تفاعلي. تغيّر هذه السمة يغيّر حالة التحكم في النموذج، لكن لا يغيّر قيمة سمة HTML checked لعنصر INPUT. أثناء معالجة حدث النقر على عنصر input ذات سمة type لها القيمة "radio" أو "checkbox", قد تقوم بعض التطبيقات بتغيير قيمة هذه الخاصية قبل بث الحدث في المستند. إذا تم إلغاء الإجراء الافتراضي للحدث، قد تُعاد قيمة الخاصية إلى قيمتها الأصلية. هذا يعني أن قيمة هذه الخاصية أثناء معالجة أحداث النقر تعتمد على التنفيذ.

```java
public bool Checked { get; set; }
```
