## HTMLInputElement.Value property

عندما تكون سمة `type` للعنصر ذات القيمة \"text\" أو \"file\" أو \"password\"، فإنها تمثل المحتوى الحالي لعنصر النموذج المقابل في عميل تفاعلي. تغيير هذه السمة يغيّر محتوى عنصر النموذج، لكنه لا يغيّر قيمة سمة value في HTML للعنصر. عندما تكون سمة `type` للعنصر ذات القيمة \"button\" أو \"hidden\" أو \"submit\" أو \"reset\" أو \"image\" أو \"checkbox\" أو \"radio\"، فإنها تمثل سمة value في HTML للعنصر. راجع تعريف سمة value في HTML 4.01.

```java
public String Value { get; set; }
```
