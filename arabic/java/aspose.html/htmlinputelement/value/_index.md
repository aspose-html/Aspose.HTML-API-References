## HTMLInputElement.Value property

عندما تكون سمة `type` للعنصر ذات القيمة "text" أو "file" أو "password"، فإنها تمثل المحتوى الحالي لعنصر التحكم في النموذج المقابل في وكيل مستخدم تفاعلي. تغيير هذه السمة يغيّر محتوى عنصر التحكم، لكنه لا يغيّر قيمة سمة HTML value للعنصر. عندما تكون سمة `type` للعنصر ذات القيمة "button" أو "hidden" أو "submit" أو "reset" أو "image" أو "checkbox" أو "radio"، فإنها تمثل سمة HTML value للعنصر. راجع تعريف سمة value في HTML 4.01.

```java
public String Value { get; set; }
```
