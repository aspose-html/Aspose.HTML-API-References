## HTMLFormElement.Enctype property

نوع المحتوى للنموذج المرسل عادةً "application/x-www-form-urlencoded". راجع تعريف السمة enctype في HTML 4.01. لا يُضمن أن معالج الحدث onsubmit يتم استدعاؤه عند استدعاء هذه الطريقة. السلوك غير متسق لأسباب تاريخية ولا يجب على المؤلفين الاعتماد على أحد محدد.

```java
public String Enctype { get; set; }
```
