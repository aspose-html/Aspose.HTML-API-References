## HTMLDocument.Anchors property

مجموعة من جميع عناصر الربط (`A`) في المستند التي لها قيمة لخاصية `name`. لأسباب التوافق مع الإصدارات السابقة، تحتوي المجموعة المعادة فقط على تلك الروابط التي تم إنشاؤها باستخدام خاصية `name`، وليس تلك التي تم إنشاؤها باستخدام خاصية `id`. لاحظ أنه في [[XHTML 1.0](http://www.w3.org/TR/2002/REC-xhtml1-20020801)] خاصية `name` (انظر القسم 4.10) لا تحمل دلالة وتوجد فقط لأغراض الوكلاء المستخدمين القديمين: تُستبدل بخاصية `id`. يجب على المستخدمين تفضيل آليات التكرار التي يوفرها [[DOM Level 2 Traversal](http://www.w3.org/TR/2000/REC-DOM-Level-2-Traversal-Range-20001113)] بدلاً من ذلك.

```java
public HTMLCollection Anchors { get; }
```
