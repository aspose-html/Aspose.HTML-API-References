## HTMLDocument.Anchors property

مجموعة من جميع عناصر الربط (`A`) في المستند التي لها قيمة لخاصية `name`. لأسباب التوافق مع الإصدارات السابقة، مجموعة الروابط المرتجعة تحتوي فقط على الروابط التي تم إنشاؤها باستخدام خاصية `name`، وليس تلك التي تم إنشاؤها باستخدام خاصية `id`. لاحظ أنه في [[XHTML 1.0](http://www.w3.org/TR/2002/REC-xhtml1-20020801)]، خاصية `name` (انظر القسم 4.10) لا تحمل معنى وتوجد فقط لأجهزة المستخدم القديمة: يتم استخدام خاصية `id` بدلاً منها. يجب على المستخدمين تفضيل آليات التكرار التي يوفرها [[DOM Level 2 Traversal](http://www.w3.org/TR/2000/REC-DOM-Level-2-Traversal-Range-20001113)] بدلاً من ذلك.

```java
public HTMLCollection Anchors { get; }
```
