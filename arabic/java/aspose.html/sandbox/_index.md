## Sandbox enumeration

مجموعة علامات العزل هي مجموعة من صفر أو أكثر من العلامات التالية، تُستخدم لتقييد القدرات التي قد تمتلكها الموارد غير الموثوقة.

```java
[Flags]
public enum Sandbox
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| None | `0` | لم يتم تعيين أي علامة، تم قبول جميع ميزات العزل |
| Navigation | `1` | هذه العلامة تمنع المحتوى من التنقل إلى سياقات تصفح غير سياق التصفح المعزول نفسه (أو سياقات تصفح متداخلة داخله)، وسياقات التصفح المساعدة (التي تحمى بعلامة تنقل سياق التصفح المساعد المعزول المحددة لاحقًا)، وسياق التصفح الأعلى مستوى (الذي تحمى بعلامة تنقل سياق التصفح الأعلى المعزول المحددة أدناه). إذا لم يتم تعيين علامة تنقل سياق التصفح المساعد المعزول، ففي بعض الحالات تسمح القيود بفتح نوافذ منبثقة (سياقات تصفح أعلى مستوى جديدة). هذه السياقات دائمًا ما يكون لها متصفح معزول واحد مسموح به، يتم تعيينه عند إنشاء سياق التصفح، مما يسمح لسياق التصفح الذي أنشأها بالتنقل إليها فعليًا. (وإلا، كانت علامة تنقل سياق التصفح المعزول ستمنع تنقلها حتى لو تم فتحها.) |
| AuxiliaryNavigation | `2` | هذه العلامة تمنع المحتوى من إنشاء سياقات تصفح مساعدة جديدة، مثل استخدام سمة target، أو طريقة window.open(). |
| TopLevelNavigation | `4` | هذه العلامة تمنع المحتوى من التنقل في سياق التصفح الأعلى مستوى الخاص به وتمنع المحتوى من إغلاق سياق التصفح الأعلى مستوى الخاص به. عندما لا تكون علامة تنقل سياق التصفح الأعلى المعزول مفعلة، يمكن للمحتوى التنقل في سياق التصفح الأعلى مستوى الخاص به، لكن سياقات التصفح الأخرى لا تزال محمية بعلامة تنقل سياق التصفح المعزول وربما بعلامة تنقل سياق التصفح المساعد المعزول. |
| Plugins | `8` | هذه العلامة تمنع المحتوى من إنشاء ملحقات (plugins)، سواء باستخدام عنصر embed أو عنصر object أو عنصر applet، أو عبر التنقل في سياق تصفح متداخل، ما لم يمكن تأمين تلك الملحقات. |
| Origin | `10` | هذه العلامة تجبر المحتوى على أصل فريد، وبالتالي تمنعه من الوصول إلى محتوى آخر من نفس الأصل. |
| Forms | `20` | هذه العلامة تمنع إرسال النماذج. |
| PointerLock | `40` | هذه العلامة تعطل واجهة برمجة التطبيقات Pointer Lock. |
| Scripts | `80` | هذه العلامة تمنع تنفيذ السكريبت. |
| AutomaticFeatures | `100` | هذه العلامة تمنع الميزات التي تُفعل تلقائيًا، مثل تشغيل الفيديو تلقائيًا أو تركيز عنصر نموذج تلقائيًا. |
| Fullscreen | `200` | هذه العلامة تمنع المحتوى من استخدام طريقة requestFullscreen(). |
| DocumentDomain | `400` | هذه العلامة تمنع المحتوى من استخدام ميزة document.domain لتغيير أصل السكريبت الفعلي. |
| Images | `800` | هذه العلامة تعطل تحميل الصور. |
