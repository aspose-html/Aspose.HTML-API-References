## Sandbox enumeration

مجموعة علامات العزل هي مجموعة من صفر أو أكثر من العلامات التالية، تُستخدم لتقييد القدرات التي قد تمتلكها الموارد غير الموثوقة.

```java
[Flags]
public enum Sandbox
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| None | `0` | لم يتم تعيين أي علامة، يتم قبول كل ميزة عزل |
| Navigation | `1` | تمنع هذه العلامة المحتوى من التنقل بين سياقات التصفح بخلاف سياق التصفح المعزول نفسه (أو سياقات التصفح المتداخلة داخله)، وسياقات التصفح المساعدة (التي تحميها علامة سياق التصفح المساعدة المعزولة المحددة لاحقًا)، وسياق التصفح الأعلى مستوى (الذي تحميه علامة سياق التصفح العلوي المعزول المحددة أدناه). إذا لم يتم تعيين علامة سياق التصفح المساعدة المعزولة، فإن القيود في بعض الحالات تسمح بفتح النوافذ المنبثقة (سياقات تصفح جديدة من المستوى الأعلى). هذه السياقات دائمًا ما يكون لها متصفح معزول مسموح واحد، يتم تعيينه عند إنشاء سياق التصفح، مما يسمح لسياق التصفح الذي أنشأها بالتنقل فيها فعليًا. (وإلا، كانت علامة تنقل سياق التصفح المعزول ستمنع تنقلها حتى لو تم فتحها.) |
| AuxiliaryNavigation | `2` | تمنع هذه العلامة المحتوى من إنشاء سياقات تصفح مساعدة جديدة، مثل استخدام سمة target، أو طريقة window.open(). |
| TopLevelNavigation | `4` | تمنع هذه العلامة المحتوى من التنقل في سياق التصفح الأعلى مستوى الخاص به وتمنع المحتوى من إغلاق سياق التصفح الأعلى مستوى الخاص به. عندما لا تكون علامة تنقل سياق التصفح الأعلى مستوى المعزول مفعلة، يمكن للمحتوى التنقل في سياق التصفح الأعلى مستوى الخاص به، لكن سياقات التصفح الأخرى لا تزال محمية بعلامة تنقل سياق التصفح المعزول وربما بعلامة سياق التصفح المساعدة المعزولة. |
| Plugins | `8` | تمنع هذه العلامة المحتوى من إنشاء الإضافات، سواء باستخدام عنصر embed أو عنصر object أو عنصر applet، أو عبر التنقل في سياق تصفح متداخل، ما لم يمكن تأمين تلك الإضافات. |
| Origin | `10` | تجبر هذه العلامة المحتوى على أن يكون له أصل فريد، وبالتالي تمنعه من الوصول إلى محتوى آخر من نفس الأصل. |
| Forms | `20` | تمنع هذه العلامة إرسال النماذج. |
| PointerLock | `40` | تعطل هذه العلامة واجهة برمجة تطبيقات Pointer Lock. |
| Scripts | `80` | تمنع هذه العلامة تنفيذ النصوص البرمجية. |
| AutomaticFeatures | `100` | تمنع هذه العلامة الميزات التي تُفعَّل تلقائيًا، مثل تشغيل الفيديو تلقائيًا أو تركيز عنصر نموذج تلقائيًا. |
| Fullscreen | `200` | تمنع هذه العلامة المحتوى من استخدام طريقة requestFullscreen(). |
| DocumentDomain | `400` | تمنع هذه العلامة المحتوى من استخدام ميزة document.domain لتغيير أصل النص البرمجي الفعلي. |
| Images | `800` | تعطل هذه العلامة تحميل الصور. |
