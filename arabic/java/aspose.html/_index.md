حزمة Aspose.Html تحتوي على فئات وطرق لمعالجة [`HTML documents`](aspose.html/htmldocument/)، سواء كانت بسيطة أو معقدة وعلى الفور. يتيح Aspose.HTML for Java للمطورين إدراج، إزالة، استبدال عقد HTML، استخراج معلومات نمط CSS، والتنقل عبر [`HTML document`](aspose.html/htmldocument/) إما عبر [`NodeIterator`](aspose.html.dom.traversal/inodeiterator/) أو [`TreeWalker`](aspose.html.dom.traversal/itreewalker/) التي توفرها مواصفات Traversal أو استعلامات XPath أو محددات CSS. كما يوفر البرمجة النصية التي تسمح بالتعامل مع DOM HTML عبر JavaScript. بالإضافة إلى HTML، توفر هذه الواجهة القدرة على تحميل EPUB و MHTML. تشتهر واجهات Aspose بميزات تحويل صيغ الملفات بين بعضها، وتوفر هذه الواجهة القدرة على تحميل ملف HTML وعرض الناتج بصيغ PDF، XPS وصور نقطية بما في ذلك JPEG، PNG، BMP و TIFF.
