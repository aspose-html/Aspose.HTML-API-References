تحتوي حزمة Aspose.Html على فئات وطرق لمعالجة [`HTML documents`](aspose.html/htmldocument/)، سواء كانت بسيطة أو معقدة وعلى الفور. يتيح Aspose.HTML للـ Java للمطورين إدراج، إزالة، استبدال عقد HTML، استخراج معلومات نمط CSS، التنقل عبر [`HTML document`](aspose.html/htmldocument/) إما عبر [`NodeIterator`](aspose.html.dom.traversal/inodeiterator/)، [`TreeWalker`](aspose.html.dom.traversal/itreewalker/) التي تُوفرها مواصفات التجوال، أو استعلامات XPath أو محددات CSS. كما يوفر البرمجة النصية التي تسمح بمعالجة DOM للـ HTML عبر JavaScript. بالإضافة إلى HTML، توفر هذه الواجهة القدرة على تحميل ملفات EPUB و MHTML. تُعرف واجهات Aspose بميزات تحويل صيغ الملفات المتعددة، وتوفر هذه الواجهة أيضًا القدرة على تحميل ملف HTML وعرض الناتج بصيغ PDF، XPS وصور نقطية بما في ذلك JPEG، PNG، BMP و TIFF.
