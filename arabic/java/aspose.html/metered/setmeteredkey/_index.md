## Metered.SetMeteredKey method

يضبط المفتاح العام والخاص للترخيص القابل للقياس. إذا قمت بشراء ترخيص قابل للقياس، عند بدء التطبيق يجب استدعاء هذه الواجهة البرمجية، عادةً يكون ذلك كافيًا. ومع ذلك، إذا فشل دائمًا رفع بيانات الاستهلاك وتجاوز 24 ساعة، سيتم تعيين الترخيص إلى حالة التقييم؛ لتجنب ذلك، يجب عليك فحص حالة الترخيص بانتظام، وإذا كانت في حالة التقييم، استدعِ هذه الواجهة البرمجية مرة أخرى.

```java
public void SetMeteredKey(String publicKey, String privateKey)
```

| --- | --- | --- |
| publicKey | String | المفتاح العام |
| privateKey | String | المفتاح الخاص |
