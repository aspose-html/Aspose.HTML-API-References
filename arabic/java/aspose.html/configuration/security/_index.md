## Configuration.Security property

يحصل أو يعيّن علم العزل للتكوين. راجع المقال حول [sandboxing](https://docs.aspose.com/html/net/working-with-documents/environment-configuration/#sandboxing).

```java
public Sandbox Security { get; set; }
```

### Property Value

الأمان. مجموعة [`sandboxing flag`](../../sandbox/) هي مجموعة من صفر أو أكثر من العلامات، التي تُستخدم لتقييد القدرات التي قد تكون موارد غير موثوقة. سمة العزل (sandbox) تسمح لك بتعيين عدد من القيود على المحتوى المحمّل في الإطار، على سبيل المثال، حظر النماذج والسكربتات.
