الحزمة **com.aspose.html.accessibility** مخصصة لجميع عمليات تعديل إمكانية الوصول على الويب. تتوافق مع المعايير الدولية لمبادرة إمكانية الوصول على الويب من W3C

## الفئات

| فئة | الوصف |
| --- | --- |
| [AccessibilityRules](./accessibilityrules/) | مرجع سريع لإرشادات محتوى الويب لإمكانية الوصول (WCAG) 2 والمتطلبات (معايير النجاح) والتقنيات. يحتوي على قائمة بالمبادئ. https://www.w3.org/WAI/WCAG21/quickref/ |
| [AccessibilityValidator](./accessibilityvalidator/) | تتعامل فئة validator مع قواعد المرجع السريع. تحتوي على طريقة Validate للتحقق من إمكانية الوصول. |
| [Criterion](./criterion/) | يتم توفير معايير نجاح قابلة للتحقق لكل توصية، بحيث يمكن تطبيق WCAG 2.0 في المناطق التي يتطلب فيها اختبار الامتثال. https://www.w3.org/WAI/WCAG21/Understanding/understanding-techniques |
| [Guideline](./guideline/) | الإرشادات - المستوى التالي بعد المبادئ. ليست قابلة للاختبار، بل تُحدد الأطر العامة والأهداف التي تساعد المؤلفين على فهم معايير النجاح وتطبيق التقنيات بشكل أفضل. الإرشادات هي قائمة بمعايير القبول من النوع RuleDirectory{Criterion}. |
| [Principle](./principle/) | مبدأ إمكانية الوصول - أعلى المستويات التي تُوفر أساس إمكانية الوصول إلى الويب، وتحتوي على قائمة بالإرشادات من النوع RuleCollection{Guideline}. لا يُسمح بإنشاء الكائن خارج التجميع. https://www.w3.org/WAI/fundamentals/accessibility-principles/ |
| [Rule](./rule/) | فئة مجردة تُعرّف خصائص القاعدة وتنفّذ الواجهة IRule. |
| [Target](./target/) | الفئة تحتوي على عنصر من عنصر html أو css حيث تم العثور على الخطأ. |
| [ValidationBuilder](./validationbuilder/) | توفر فئة ValidationBuilder تطبيقات ملموسة لخطوات التكوين. تُحدد الطرق والإعدادات لفئة ValidationSettings. |
| [WebAccessibility](./webaccessibility/) | كائن لإرشادات محتوى الويب لإمكانية الوصول (WCAG) 2 والمتطلبات (معايير النجاح) والتقنيات. https://www.w3.org/WAI/WCAG21/quickref/ |
