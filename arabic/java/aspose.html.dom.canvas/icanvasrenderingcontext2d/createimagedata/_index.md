## CreateImageData(double, double) {#createimagedata_1}

ينشئ كائن ImageData جديد وفارغ بالأبعاد المحددة. جميع البكسلات في الكائن الجديد هي باللون الأسود الشفاف.

```java
public IImageData CreateImageData(double sw, double sh)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| sw | Double | العرض الذي سيُعطى لكائن ImageData الجديد. |
| sh | Double | الارتفاع الذي سيُعطى لكائن ImageData الجديد. |

### قيمة الإرجاع

كائن ImageData جديد بالعرض والارتفاع المحددين. يتم ملء الكائن الجديد بكسلات سوداء شفافة.
