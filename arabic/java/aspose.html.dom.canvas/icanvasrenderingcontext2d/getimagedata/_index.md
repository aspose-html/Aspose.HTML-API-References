## ICanvasRenderingContext2D.GetImageData method

يرجع كائن ImageData يمثل بيانات البكسل الأساسية للمنطقة على القماش المحددة بالمستطيل الذي يبدأ عند (sx, sy) وله عرض sw وارتفاع sh. لا تتأثر هذه الطريقة بمصفوفة تحويل القماش.

```java
public IImageData GetImageData(double sx, double sy, double sw, double sh)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| sx | Double | إحداثي x للزاوية العلوية اليسرى للمستطيل الذي سيتم استخراج ImageData منه. |
| sy | Double | إحداثي y للزاوية العلوية اليسرى للمستطيل الذي سيتم استخراج ImageData منه. |
| sw | Double | عرض المستطيل الذي سيتم استخراج ImageData منه. |
| sh | Double | ارتفاع المستطيل الذي سيتم استخراج ImageData منه. |

### قيمة الإرجاع

كائن ImageData يحتوي على بيانات الصورة للمستطيل المحدد في القماش.
