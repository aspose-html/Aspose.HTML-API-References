## IsPointInPath(double, double) {#ispointinpath_2}

يُبلغ عما إذا كان النقطة المحددة موجودة داخل المسار الحالي أم لا.


| معامل | نوع | الوصف |
| --- | --- | --- |
| x | Double | إحداثي X للنقطة المراد فحصها. |
