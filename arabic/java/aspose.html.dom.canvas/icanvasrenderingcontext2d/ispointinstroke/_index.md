## IsPointInStroke(double, double) {#ispointinstroke_1}

يُبلغ عما إذا كانت النقطة المحددة داخل المنطقة التي يحدّدها تخطيط مسار.

```java
public bool IsPointInStroke(double x, double y)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| x | Double | إحداثي X للنقطة المراد فحصها. |
| y | Double | إحداثي Y للنقطة التي يجب فحصها. |

### قيمة الإرجاع
