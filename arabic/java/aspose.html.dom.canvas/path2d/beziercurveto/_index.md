## Path2D.BezierCurveTo method

يضيف منحنى بيزيه مكعب إلى المسار. يتطلب ثلاث نقاط. النقطتان الأوليتان هما نقاط التحكم والنقطة الثالثة هي نقطة النهاية. نقطة البداية هي آخر نقطة في المسار الحالي، ويمكن تغييرها باستخدام moveTo() قبل إنشاء منحنى بيزيه.

```java
public void BezierCurveTo(double cp1x, double cp1y, double cp2x, double cp2y, double x, double y)
```

| cp1y | Double | محور y للإحداثي الخاص بنقطة التحكم الأولى. |
| cp2x | Double | محور x للإحداثي الخاص بنقطة التحكم الثانية. |
| cp2y | Double | محور y للإحداثي الخاص بنقطة التحكم الثانية. |
| x | Double | محور x للإحداثي الخاص بنقطة النهاية. |
