Το πακέτο **com.aspose.html.window** σχετίζεται με το αντικείμενο παραθύρου που αντιπροσωπεύει ένα παράθυρο που περιέχει ένα έγγραφο DOM. Περιλαμβάνει κλάσεις και διεπαφές σχετικές με τη διεύθυνση του ενεργού εγγράφου και το ιστορικό περιήγησης.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [Location](./location/) | Τα αντικείμενα Location παρέχουν μια αναπαράσταση της διεύθυνσης του ενεργού εγγράφου του πλαισίου περιήγησης του Document τους, και επιτρέπουν την αλλαγή της τρέχουσας καταχώρησης του ιστορικού συνεδρίας του πλαισίου περιήγησης, προσθέτοντας ή αντικαθιστώντας καταχωρήσεις στο αντικείμενο ιστορικού. |
| [MediaQueryList](./mediaquerylist/) | Ένα αντικείμενο MediaQueryList αποθηκεύει πληροφορίες σχετικά με ένα ερώτημα μέσων που εφαρμόζεται σε ένα έγγραφο, με υποστήριξη τόσο για άμεση όσο και για γεγονότα‑βασισμένη αντιστοίχιση με την κατάσταση του εγγράφου. Δείτε την προδιαγραφή του CSSOM View Module: [https://www.w3.org/TR/cssom-view/#the-mediaquerylist-interface](https://www.w3.org/TR/cssom-view/#the-mediaquerylist-interface) |
