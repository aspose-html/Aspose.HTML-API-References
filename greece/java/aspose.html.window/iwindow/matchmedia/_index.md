## IWindow.MatchMedia method

Επιστρέφει ένα νέο αντικείμενο MediaQueryList που μπορεί στη συνέχεια να χρησιμοποιηθεί για να προσδιορίσει εάν το έγγραφο ταιριάζει με τη συμβολοσειρά ερωτήματος μέσου (media query), καθώς και για να παρακολουθεί το έγγραφο ώστε να εντοπίζει πότε ταιριάζει (ή σταματά να ταιριάζει) με αυτό το ερώτημα μέσου. Δείτε την προδιαγραφή του CSSOM View Module: [https://www.w3.org/TR/cssom-view/#extensions-to-the-window-interface](https://www.w3.org/TR/cssom-view/#extensions-to-the-window-interface)

```java
public MediaQueryList MatchMedia(String query)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| query | String | Η String που περιέχει ένα media query· δείτε [https://drafts.csswg.org/mediaqueries/](https://drafts.csswg.org/mediaqueries/) για λεπτομέρειες. |
