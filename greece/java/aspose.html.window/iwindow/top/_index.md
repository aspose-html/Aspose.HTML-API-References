## IWindow.Top property

Το ανώτερο χαρακτηριστικό IDL στο αντικείμενο Window ενός Εγγράφου σε ένα περιβάλλον περιήγησης b πρέπει να επιστρέφει το αντικείμενο WindowProxy του ανώτερου επιπέδου περιβάλλοντος περιήγησης (το οποίο θα ήταν το δικό του αντικείμενο WindowProxy εάν ήταν ένα ανώτερο περιβάλλον περιήγησης), εάν έχει ένα, ή το δικό του αντικείμενο WindowProxy διαφορετικά (π.χ. εάν ήταν ένα αποσυνδεδεμένο ένθετο περιβάλλον περιήγησης).

```java
public IWindow Top { get; }
```
