## IWindow.Top property

Το top IDL attribute στο αντικείμενο Window ενός Document σε ένα browsing context b πρέπει να επιστρέφει το αντικείμενο WindowProxy του top-level browsing context (το οποίο θα ήταν το δικό του αντικείμενο WindowProxy αν ήταν ένα top-level browsing context από μόνο του), αν έχει ένα, ή το δικό του αντικείμενο WindowProxy διαφορετικά (π.χ. αν ήταν ένα αποσυνδεδεμένο nested browsing context).

```java
public IWindow Top { get; }
```
