## IWindow.Parent property

Το γονικό χαρακτηριστικό IDL στο αντικείμενο Window ενός Document σε ένα browsing context b πρέπει να επιστρέφει το αντικείμενο WindowProxy του γονικού browsing context, εάν υπάρχει (δηλαδή εάν το b είναι ένα child browsing context), ή το αντικείμενο WindowProxy του browsing context b ίδιο, διαφορετικά (δηλαδή εάν είναι ένα top-level browsing context ή ένα detached nested browsing context).

```java
public IWindow Parent { get; }
```
