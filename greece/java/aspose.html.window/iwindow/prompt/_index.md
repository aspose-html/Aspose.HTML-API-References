## IWindow.Prompt method

Εμφανίζει ένα μοντέλο παράθυρο διαλόγου με πεδίο κειμένου και το δοσμένο μήνυμα, περιμένει ο χρήστης να το κλείσει και επιστρέφει την τιμή που εισήγαγε ο χρήστης. Εάν ο χρήστης ακυρώσει τον διάλογο, τότε επιστρέφει null. Εάν υπάρχει το δεύτερο όρισμα, τότε η δοσμένη τιμή χρησιμοποιείται ως προεπιλογή.

```java
public String Prompt(String message, String @default)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| message | String | Το μήνυμα. |
| προεπιλογή | String | Η προεπιλογή. |
