## Location class

Τα αντικείμενα Location παρέχουν μια αναπαράσταση της διεύθυνσης του ενεργού εγγράφου του πλαισίου περιήγησης του Document τους, και επιτρέπουν την αλλαγή της τρέχουσας καταχώρησης του ιστορικού συνεδρίας του πλαισίου περιήγησης, προσθέτοντας ή αντικαθιστώντας καταχωρήσεις στο αντικείμενο ιστορικού.

```java
public sealed class Location : DOMObject
```
