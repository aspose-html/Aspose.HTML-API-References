## TemplateLoadOptions.NamesAreCaseSensitive property

Ιδιότητα που καθορίζει εάν τα ονόματα του προτύπου και των στοιχείων δεδομένων θα ταιριάζουν ανεξάρτητα από το αν είναι πεζά ή κεφαλαία. Εάν είναι true, η αντιστοίχιση είναι ευαίσθητη σε πεζά/κεφαλαία· εάν είναι false, η διάκριση πεζών/κεφαλαίων θα αγνοείται. Η προεπιλεγμένη τιμή είναι true.

```java
public bool NamesAreCaseSensitive { get; set; }
```
