## TemplateLoadOptions.NamesAreCaseSensitive property

Ιδιότητα που καθορίζει αν τα ονόματα του προτύπου και των στοιχείων δεδομένων θα ταιριάζουν ανεξάρτητα από τη διάκριση πεζών-κεφαλαίων. Εάν true, η αντιστοίχιση είναι ευαίσθητη σε πεζά-κεφαλαία· εάν false, η διάκριση πεζών-κεφαλαίων θα αγνοηθεί. Η προεπιλεγμένη τιμή είναι true.

```java
public bool NamesAreCaseSensitive { get; set; }
```
