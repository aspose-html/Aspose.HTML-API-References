## NodeFilter.SHOW_NOTATION field

Εμφάνιση κόμβων Notation. Αυτό έχει νόημα μόνο όταν δημιουργείται ένας iterator ή tree-walker με έναν κόμβο Notation ως ρίζα· σε αυτήν την περίπτωση, σημαίνει ότι ο κόμβος Notation θα εμφανιστεί στην πρώτη θέση της διαδρομής. Δεδομένου ότι οι σημειώσεις δεν αποτελούν μέρος του δέντρου εγγράφου, δεν εμφανίζονται κατά την περιήγηση του δέντρου εγγράφου.

```java
public const long SHOW_NOTATION;
```
