## NodeFilter.SHOW_ENTITY field

Εμφάνιση κόμβων Entity. Αυτό έχει νόημα μόνο όταν δημιουργείται ένας επαναλήπτης ή tree-walker με έναν κόμβο Entity ως ρίζα· σε αυτήν την περίπτωση, σημαίνει ότι ο κόμβος Entity θα εμφανιστεί στην πρώτη θέση της διαδρομής. Δεδομένου ότι οι οντότητες δεν αποτελούν μέρος του δένδρου του εγγράφου, δεν εμφανίζονται κατά την περιήγηση του δένδρου του εγγράφου.

```java
public const long SHOW_ENTITY;
```
