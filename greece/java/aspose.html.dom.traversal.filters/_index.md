Το πακέτο που αντιπροσωπεύει τη λειτουργία φιλτραρίσματος κόμβων. Τα φίλτρα είναι αντικείμενα που ξέρουν πώς να "αφαιρεί" κόμβους. Εάν ένας επαναλήπτης κόμβων ή ένας περιηγητής δέντρου λάβει ένα φίλτρο κόμβου, εφαρμόζει το φίλτρο πριν επιστρέψει τον επόμενο κόμβο. Εάν το φίλτρο λέει να αποδεχθεί τον κόμβο, η λογική διάσχισης τον επιστρέφει· διαφορετικά, η διάσχιση ψάχνει τον επόμενο κόμβο και προσποιείται ότι ο απορριφθέντας κόμβος δεν υπάρχει.
