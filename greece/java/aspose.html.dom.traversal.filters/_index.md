The πακέτο που αντιπροσωπεύει τη λειτουργικότητα φιλτραρίσματος κόμβων. Τα φίλτρα είναι αντικείμενα που ξέρουν πώς να \"αφαιρεί\" κόμβους. Εάν ένας επαναλήπτης κόμβων ή περιηγητής δέντρου λαμβάνει ένα φίλτρο κόμβου, εφαρμόζει το φίλτρο πριν επιστρέψει τον επόμενο κόμβο. Εάν το φίλτρο λέει να αποδεχθεί τον κόμβο, η λογική διαδρομής τον επιστρέφει· διαφορετικά, η διαδρομή ψάχνει τον επόμενο κόμβο και προσποιείται ότι ο απορριφθέντας κόμβος δεν υπήρχε.
