Το πακέτο Aspose.Html περιέχει κλάσεις και μεθόδους για τη διαχείριση των [`HTML documents`](aspose.html/htmldocument/), είτε απλά είτε σύνθετα και σε πραγματικό χρόνο. Το Aspose.HTML για Java επιτρέπει στους προγραμματιστές να Insert, Remove, Replace κόμβους HTML, να εξάγουν πληροφορίες στυλ CSS, να Navigate μέσω του [`HTML document`](aspose.html/htmldocument/) είτε με [`NodeIterator`](aspose.html.dom.traversal/inodeiterator/), είτε με [`TreeWalker`](aspose.html.dom.traversal/itreewalker/) που παρέχονται από τις Προδιαγραφές Περιήγησης, XPath ή ερωτήματα επιλογέα CSS. Προσφέρει επίσης σενάριο που επιτρέπει τη διαχείριση του HTML DOM μέσω JavaScript. Εκτός από το HTML, αυτό το API παρέχει επίσης τη δυνατότητα φόρτωσης EPUB και MHTML. Τα APIs της Aspose είναι γνωστά για τις δυνατότητες μετατροπής μεταξύ μορφών αρχείων και αυτό το API παρέχει επίσης τη δυνατότητα φόρτωσης αρχείου HTML και απόδοσης του αποτελέσματος σε PDF, XPS και μορφές raster εικόνας, συμπεριλαμβανομένων των JPEG, PNG, BMP και TIFF.
