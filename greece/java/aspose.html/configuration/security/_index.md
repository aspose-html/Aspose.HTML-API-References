## Configuration.Security property

Αποκτά ή ορίζει τη σημαία απομόνωσης της διαμόρφωσης. Ανατρέξτε στο άρθρο σχετικά με [sandboxing](https://docs.aspose.com/html/net/working-with-documents/environment-configuration/#sandboxing).

```java
public Sandbox Security { get; set; }
```

### Property Value

Η ασφάλεια. Ένα σύνολο [`sandboxing flag`](../../sandbox/) είναι ένα σύνολο μηδέν ή περισσότερων σημαδιών, που χρησιμοποιούνται για τον περιορισμό των δυνατοτήτων των πιθανώς μη αξιόπιστων πόρων. Το χαρακτηριστικό sandbox επιτρέπει να ορίσετε έναν αριθμό περιορισμών στο περιεχόμενο που φορτώνεται στο πλαίσιο, για παράδειγμα, να μπλοκάρετε φόρμες και σενάρια.
