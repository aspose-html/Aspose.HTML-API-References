## HTMLTableElement.Rows property

Επιστρέφει το `TFOOT` του πίνακα, ή `null` εάν δεν υπάρχει.

Επιστρέφει μια συλλογή όλων των γραμμών του πίνακα, συμπεριλαμβανομένων όλων των `THEAD`, `TFOOT` και όλων των στοιχείων `TBODY`.
