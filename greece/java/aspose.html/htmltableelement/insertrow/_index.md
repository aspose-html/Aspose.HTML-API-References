## HTMLTableElement.InsertRow method

Εισάγετε μια νέα κενή γραμμή στον πίνακα. Η νέα γραμμή εισάγεται αμέσως πριν και στην ίδια ενότητα με την τρέχουσα γραμμή `index` του πίνακα. Εάν το `index` είναι -1 ή ίσο με τον αριθμό των γραμμών, η νέα γραμμή προσαρτάται. Επιπλέον, όταν ο πίνακας είναι κενός, η γραμμή εισάγεται σε ένα `TBODY` που δημιουργείται και εισάγεται στον πίνακα. Μια γραμμή πίνακα δεν μπορεί να είναι κενή σύμφωνα με [[HTML 4.01](http://www.w3.org/TR/1999/REC-html401-19991224)].

```java
public Node InsertRow(int index)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| index | Int32 | Ο αριθμός γραμμής όπου θα εισαχθεί μια νέα γραμή. Αυτό το δείκτη ξεκινά από 0 και είναι σχετικό με τη λογική σειρά (όχι τη σειρά του εγγράφου) όλων των γραμμών που περιέχονται μέσα στον πίνακα. |

### Τιμή Επιστροφής

Η νεοδημιουργημένη γραμμή.
