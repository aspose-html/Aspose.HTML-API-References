## HTMLTextAreaElement.Value property

Αντιπροσωπεύει το τρέχον περιεχόμενο του αντίστοιχου στοιχείου φόρμας, σε έναν διαδραστικό πράκτορα χρήστη. Η αλλαγή αυτού του χαρακτηριστικού αλλάζει το περιεχόμενο του στοιχείου φόρμας, αλλά δεν αλλάζει το περιεχόμενο του στοιχείου. Εάν το σύνολο των δεδομένων δεν μπορεί να χωρέσει σε ένα ενιαίο `DOMString`, η υλοποίηση μπορεί να περικόψει τα δεδομένα.

```java
public String Value { get; set; }
```
