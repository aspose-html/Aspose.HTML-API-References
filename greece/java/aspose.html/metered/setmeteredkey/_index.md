## Metered.SetMeteredKey method

Ορίζει το δημόσιο και ιδιωτικό κλειδί του μετρητή. Εάν αγοράσετε άδεια μετρητή, κατά την εκκίνηση της εφαρμογής, θα πρέπει να κληθεί αυτό το API· συνήθως αυτό είναι επαρκές. Ωστόσο, εάν αποτυγχάνει συνεχώς η μεταφόρτωση δεδομένων κατανάλωσης και ξεπεραστούν 24 ώρες, η άδεια θα μετατραπεί σε κατάσταση αξιολόγησης· για να αποφύγετε αυτή την περίπτωση, θα πρέπει να ελέγχετε τακτικά την κατάσταση της άδειας· εάν είναι σε κατάσταση αξιολόγησης, καλέστε ξανά αυτό το API.

```java
public void SetMeteredKey(String publicKey, String privateKey)
```
