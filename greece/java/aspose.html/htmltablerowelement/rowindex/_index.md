## HTMLTableRowElement.RowIndex property

Αυτό είναι σε λογική σειρά και όχι σε σειρά εγγράφου. Το `rowIndex` λαμβάνει υπόψη τις ενότητες (`THEAD`, `TFOOT` ή `TBODY`) μέσα στον πίνακα, τοποθετώντας πρώτα τις σειρές `THEAD` στον δείκτη, ακολουθούμενες από τις σειρές `TBODY` και στη συνέχεια τις σειρές `TFOOT`. @version DOM Level 2

public int RowIndex { get; }
