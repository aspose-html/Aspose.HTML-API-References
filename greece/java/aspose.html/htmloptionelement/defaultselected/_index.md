## HTMLOptionElement.DefaultSelected property

Αντιπροσωπεύει την τιμή του χαρακτηριστικού HTML selected. Η τιμή αυτού του χαρακτηριστικού δεν αλλάζει εάν η κατάσταση του αντίστοιχου στοιχείου φόρμας, σε έναν διαδραστικό πράκτορα χρήστη, αλλάξει. Δείτε τον ορισμό του χαρακτηριστικού selected στο HTML 4.01. @version DOM Level 2

```java
public bool DefaultSelected { get; set; }
```
