## IHTMLOptionsCollection interface

Ένα `HTMLOptionsCollection` είναι μια λίστα κόμβων που αντιπροσωπεύουν το στοιχείο επιλογής HTML. Ένας μεμονωμένος κόμβος μπορεί να προσπελαστεί είτε με τον διατεταγμένο δείκτη είτε με τα χαρακτηριστικά `name` ή `id` του κόμβου. Οι συλλογές στο HTML DOM θεωρούνται ζωντανές, πράγμα που σημαίνει ότι ενημερώνονται αυτόματα όταν το υποκείμενο έγγραφο αλλάζει.

Δείτε επίσης το [Document object Model (DOM) Level 2 HTML Specification](http://www.w3.org/TR/2003/REC-DOM-Level-2-HTML-20030109). @since DOM Level 2

```java
public interface IHTMLOptionsCollection : IEnumerable<Element>
```
