## Sandbox enumeration

Ένα σύνολο σημαιών sandboxing είναι ένα σύνολο μηδέν ή περισσότερων από τις παρακάτω σημαίες, που χρησιμοποιούνται για τον περιορισμό των δυνατοτήτων των πιθανώς μη αξιόπιστων πόρων.

```java
[Flags]
public enum Sandbox
```

### Τιμές

| Όνομα | Τιμή | Περιγραφή |
| --- | --- | --- |
| None | `0` | Δεν έχει οριστεί καμία σημαία, κάθε δυνατότητα sandbox γίνεται αποδεκτή |
| Navigation | `1` | Αυτή η σημαία εμποδίζει το περιεχόμενο να πλοηγείται σε περιβάλλοντα περιήγησης διαφορετικά από το ίδιο το sandboxed browsing context (ή σε περιβάλλοντα περιήγησης που είναι περαιτέρω ενσωματωμένα μέσα σε αυτό), σε βοηθητικά περιβάλλοντα περιήγησης (που προστατεύονται από τη σημαία sandboxed auxiliary navigation browsing context που ορίζεται παρακάτω), και στο ανώτερο περιβάλλον περιήγησης (που προστατεύεται από τη σημαία sandboxed top-level navigation browsing context που ορίζεται παρακάτω). Εάν η σημαία sandboxed auxiliary navigation browsing context δεν είναι ορισμένη, τότε σε ορισμένες περιπτώσεις οι περιορισμοί επιτρέπουν παρόλα αυτά τα αναδυόμενα παράθυρα (νέα ανώτερα περιβάλλοντα περιήγησης) να ανοίγουν. Αυτά τα περιβάλλοντα περιήγησης έχουν πάντα έναν επιτρεπόμενο sandboxed navigator, ο οποίος ορίζεται όταν δημιουργείται το περιβάλλον περιήγησης, και επιτρέπει στο περιβάλλον που τα δημιούργησε να τα πλοηγηθεί πραγματικά. (Διαφορετικά, η σημαία sandboxed navigation browsing context θα τα εμπόδιζε να πλοηγηθούν ακόμη και αν είχαν ανοίξει.) |
| AuxiliaryNavigation | `2` | Αυτή η σημαία εμποδίζει το περιεχόμενο να δημιουργεί νέα βοηθητικά περιβάλλοντα περιήγησης, π.χ. χρησιμοποιώντας το χαρακτηριστικό target ή τη μέθοδο window.open(). |
| TopLevelNavigation | `4` | Αυτή η σημαία εμποδίζει το περιεχόμενο να πλοηγείται στο ανώτερο περιβάλλον περιήγησης του και να κλείνει το ανώτερο περιβάλλον περιήγησης του. Όταν η σημαία sandboxed top-level navigation browsing context δεν είναι ορισμένη, το περιεχόμενο μπορεί να πλοηγηθεί στο ανώτερο περιβάλλον περιήγησης του, αλλά άλλα περιβάλλοντα περιήγησης παραμένουν προστατευμένα από τη σημαία sandboxed navigation browsing context και ενδεχομένως από τη σημαία sandboxed auxiliary navigation browsing context. |
| Plugins | `8` | Αυτή η σημαία εμποδίζει το περιεχόμενο να δημιουργεί plugins, είτε χρησιμοποιώντας το στοιχείο embed, το στοιχείο object, το στοιχείο applet, είτε μέσω πλοήγησης σε ενσωματωμένο περιβάλλον περιήγησης, εκτός εάν αυτά τα plugins μπορούν να ασφαλιστούν. |
| Origin | `10` | Αυτή η σημαία αναγκάζει το περιεχόμενο σε μοναδική προέλευση, αποτρέποντάς το έτσι από το να προσπελάσει άλλο περιεχόμενο από την ίδια προέλευση. |
| Forms | `20` | Αυτή η σημαία εμποδίζει την υποβολή φόρμας. |
| PointerLock | `40` | Αυτή η σημαία απενεργοποιεί το Pointer Lock API. |
| Scripts | `80` | Αυτή η σημαία εμποδίζει την εκτέλεση σεναρίου. |
| AutomaticFeatures | `100` | Αυτή η σημαία εμποδίζει λειτουργίες που ενεργοποιούνται αυτόματα, όπως η αυτόματη αναπαραγωγή βίντεο ή η αυτόματη εστίαση σε στοιχείο φόρμας. |
| Fullscreen | `200` | Αυτή η σημαία εμποδίζει το περιεχόμενο να χρησιμοποιεί τη μέθοδο requestFullscreen(). |
| DocumentDomain | `400` | Αυτή η σημαία εμποδίζει το περιεχόμενο να χρησιμοποιεί τη δυνατότητα document.domain για να αλλάξει την αποτελεσματική προέλευση του σεναρίου. |
| Images | `800` | Αυτή η σημαία απενεργοποιεί τη φόρτωση εικόνων. |
