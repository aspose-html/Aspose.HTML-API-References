## Sandbox enumeration

Ένα σύνολο σημαιών απομονωτικού περιβάλλοντος είναι ένα σύνολο από μηδέν ή περισσότερες από τις παρακάτω σημαιές, οι οποίες χρησιμοποιούνται για τον περιορισμό των δυνατοτήτων που ενδέχεται να έχουν μη αξιόπιστοι πόροι.

```java
[Flags]
public enum Sandbox
```

### Τιμές

| Όνομα | Τιμή | Περιγραφή |
| --- | --- | --- |
| None | `0` | Δεν έχει οριστεί καμία σημαία, κάθε δυνατότητα sandbox γίνεται αποδεκτή |
| Navigation | `1` | Αυτή η σημαία εμποδίζει το περιεχόμενο να πλοηγείται σε περιβάλλοντα περιήγησης διαφορετικά από το ίδιο το sandboxed περιβάλλον περιήγησης (ή περιβάλλοντα περιήγησης που είναι περαιτέρω ενσωματωμένα μέσα σε αυτό), βοηθητικά περιβάλλοντα περιήγησης (που προστατεύονται από τη σημαία sandboxed auxiliary navigation browsing context που ορίζεται παρακάτω), και το περιβάλλον περιήγησης ανώτερου επιπέδου (που προστατεύεται από τη σημαία sandboxed top-level navigation browsing context που ορίζεται παρακάτω). Εάν η σημαία sandboxed auxiliary navigation browsing context δεν είναι ορισμένη, τότε σε ορισμένες περιπτώσεις οι περιορισμοί επιτρέπουν παρόλα αυτά τα αναδυόμενα παράθυρα (νέα περιβάλλοντα περιήγησης ανώτερου επιπέδου) να ανοίγουν. Αυτά τα περιβάλλοντα περιήγησης έχουν πάντα έναν επιτρεπόμενο sandboxed πλοηγό, ο οποίος ορίζεται όταν δημιουργείται το περιβάλλον περιήγησης, και επιτρέπει στο περιβάλλον που τα δημιούργησε να τα πλοηγηθεί πραγματικά. (Διαφορετικά, η σημαία sandboxed navigation browsing context θα τα εμπόδιζε να πλοηγηθούν ακόμη και αν ανοίχτηκαν. |
| AuxiliaryNavigation | `2` | Αυτή η σημαία εμποδίζει το περιεχόμενο να δημιουργεί νέα βοηθητικά περιβάλλοντα περιήγησης, π.χ. χρησιμοποιώντας το χαρακτηριστικό target ή τη μέθοδο window.open(). |
| TopLevelNavigation | `4` | Αυτή η σημαία εμποδίζει το περιεχόμενο να πλοηγείται στο ανώτερο επίπεδο του περιβάλλοντος περιήγησης και εμποδίζει το περιεχόμενο να κλείνει το ανώτερο επίπεδο του περιβάλλοντος περιήγησης. Όταν η σημαία sandboxed top-level navigation browsing context δεν είναι ορισμένη, το περιεχόμενο μπορεί να πλοηγηθεί στο ανώτερο επίπεδο του περιβάλλοντος περιήγησης, αλλά άλλα περιβάλλοντα περιήγησης παραμένουν προστατευμένα από τη σημαία sandboxed navigation browsing context και ενδέχεται από τη σημαία sandboxed auxiliary navigation browsing context. |
| Plugins | `8` | Αυτή η σημαία εμποδίζει το περιεχόμενο να δημιουργεί plugins, είτε χρησιμοποιώντας το στοιχείο embed, το στοιχείο object, το στοιχείο applet, είτε μέσω πλοήγησης σε ενσωματωμένο περιβάλλον περιήγησης, εκτός εάν αυτά τα plugins μπορούν να ασφαλιστούν. |
| Origin | `10` | Αυτή η σημαία αναγκάζει το περιεχόμενο σε μοναδική προέλευση, εμποδίζοντάς το έτσι από την πρόσβαση σε άλλο περιεχόμενο από την ίδια προέλευση. |
| Forms | `20` | Αυτή η σημαία εμποδίζει την υποβολή φόρμας. |
| PointerLock | `40` | Αυτή η σημαία απενεργοποιεί το Pointer Lock API. |
| Scripts | `80` | Αυτή η σημαία εμποδίζει την εκτέλεση script. |
| AutomaticFeatures | `100` | Αυτή η σημαία εμποδίζει λειτουργίες που ενεργοποιούνται αυτόματα, όπως η αυτόματη αναπαραγωγή βίντεο ή η αυτόματη εστίαση σε στοιχείο φόρμας. |
| Fullscreen | `200` | Αυτή η σημαία εμποδίζει το περιεχόμενο από τη χρήση της μεθόδου requestFullscreen(). |
| DocumentDomain | `400` | Αυτή η σημαία εμποδίζει το περιεχόμενο από τη χρήση της λειτουργίας document.domain για την αλλαγή της αποτελεσματικής προέλευσης του script. |
| Images | `800` | Αυτή η σημαία απενεργοποιεί τη φόρτωση εικόνων. |
