## HTMLDocument.Referrer property

Επιστρέφει το URI [[IETF RFC 2396](http://www.ietf.org/rfc/rfc2396.txt)] της σελίδας που συνδέθηκε σε αυτή τη σελίδα. Η τιμή είναι μια κενή συμβολοσειρά εάν ο χρήστης πήγε στη σελίδα απευθείας (όχι μέσω συνδέσμου, αλλά, για παράδειγμα, μέσω σελιδοδείκτη).

```java
public String Referrer { get; }
```
