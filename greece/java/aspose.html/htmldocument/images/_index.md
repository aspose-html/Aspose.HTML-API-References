## HTMLDocument.Images property

Μια συλλογή όλων των στοιχείων `IMG` σε ένα έγγραφο. Η συμπεριφορά περιορίζεται στα στοιχεία `IMG` για συμβατότητα με παλαιότερες εκδόσεις. Όπως προτείνεται από το [[HTML 4.01](http://www.w3.org/TR/1999/REC-html401-19991224)], για την ένταξη εικόνων, οι συγγραφείς μπορούν να χρησιμοποιήσουν το στοιχείο `OBJECT` ή το στοιχείο `IMG`. Συνεπώς συνιστάται να μην χρησιμοποιείται αυτό το χαρακτηριστικό για την εύρεση εικόνων στο έγγραφο, αλλά το `getElementsByTagName` με HTML 4.01 ή το `getElementsByTagNameNS` με XHTML 1.0.

```java
public HTMLCollection Images { get; }
```
