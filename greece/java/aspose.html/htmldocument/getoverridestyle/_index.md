## HTMLDocument.GetOverrideStyle method

Αυτή η μέθοδος χρησιμοποιείται για την ανάκτηση της δήλωσης στυλ παράκαμψης για ένα συγκεκριμένο στοιχείο και ένα συγκεκριμένο ψευδο-στοιχείο.

```java
public ICSSStyleDeclaration GetOverrideStyle(Element elt, String pseudoElt)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| elt | Στοιχείο | Το στοιχείο του οποίου το στυλ πρόκειται να τροποποιηθεί. Αυτή η παράμετρος δεν μπορεί να είναι null. |
| pseudoElt | String | Το ψευδο-στοιχείο ή null εάν δεν υπάρχει. |

### Τιμή επιστροφής

Η δήλωση παρακάμψης στυλ
