## HTMLInputElement.DefaultValue property

Όταν το χαρακτηριστικό `type` του στοιχείου έχει την τιμή "text", "file" ή "password", αυτό αντιπροσωπεύει το χαρακτηριστικό value του HTML για το στοιχείο. Η τιμή αυτού του χαρακτηριστικού δεν αλλάζει εάν το περιεχόμενο του αντίστοιχου ελέγχου φόρμας, σε έναν διαδραστικό πελάτη χρήστη, αλλάξει. Δείτε τον ορισμό του χαρακτηριστικού value στο HTML 4.01.

```java
public String DefaultValue { get; set; }
```
