## HTMLInputElement.Files property

Το χαρακτηριστικό IDL files επιτρέπει στα σενάρια να έχουν πρόσβαση στα επιλεγμένα αρχεία του στοιχείου. Κατά την ανάκτηση, εάν το χαρακτηριστικό IDL ισχύει, πρέπει να επιστρέφει ένα αντικείμενο FileList που αντιπροσωπεύει τα τρέχοντα επιλεγμένα αρχεία. Το ίδιο αντικείμενο πρέπει να επιστρέφεται μέχρι να αλλάξει η λίστα των επιλεγμένων αρχείων. Εάν το χαρακτηριστικό IDL δεν ισχύει, πρέπει να επιστρέφει null. [FILEAPI]

```java
public IFileList Files { get; }
```
