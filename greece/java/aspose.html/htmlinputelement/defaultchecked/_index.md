## HTMLInputElement.DefaultChecked property

Όταν το `type` έχει την τιμή "radio" ή "checkbox", αυτό αντιπροσωπεύει το χαρακτηριστικό checked του HTML στοιχείου. Η τιμή αυτού του χαρακτηριστικού δεν αλλάζει εάν η κατάσταση του αντίστοιχου ελέγχου φόρμας, σε έναν διαδραστικό πελάτη, αλλάξει. Δείτε τον ορισμό του χαρακτηριστικού checked στο HTML 4.01.

```java
public bool DefaultChecked { get; set; }
```
