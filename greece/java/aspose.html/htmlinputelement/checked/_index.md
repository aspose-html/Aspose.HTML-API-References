## HTMLInputElement.Checked property

Όταν το χαρακτηριστικό `type` του στοιχείου έχει την τιμή "radio" ή "checkbox", αυτό αντιπροσωπεύει την τρέχουσα κατάσταση του στοιχείου φόρμας σε έναν διαδραστικό πράκτορα χρήστη. Οι αλλαγές σε αυτό το χαρακτηριστικό αλλάζουν την κατάσταση του στοιχείου φόρμας, αλλά δεν αλλάζουν την τιμή του χαρακτηριστικού HTML checked του στοιχείου INPUT. Κατά τη διαχείριση ενός συμβάντος κλικ σε ένα στοιχείο input με χαρακτηριστικό type που έχει την τιμή "radio" ή "checkbox", ορισμένες υλοποιήσεις μπορεί να αλλάξουν την τιμή αυτής της ιδιότητας πριν το συμβάν διανεμηθεί στο έγγραφο. Εάν η προεπιλεγμένη ενέργεια του συμβάντος ακυρωθεί, η τιμή της ιδιότητας μπορεί να επανέλθει στην αρχική της τιμή. Αυτό σημαίνει ότι η τιμή αυτής της ιδιότητας κατά τη διαχείριση των συμβάντων κλικ εξαρτάται από την υλοποίηση.

```java
public bool Checked { get; set; }
```
