## HTMLSelectElement.SelectedIndex property

Ο διατεταγμένος δείκτης της επιλεγμένης επιλογής, ξεκινώντας από 0. Η τιμή -1 επιστρέφεται εάν δεν έχει επιλεγεί κανένα στοιχείο. Εάν επιλεγούν πολλαπλές επιλογές, επιστρέφεται ο δείκτης της πρώτης επιλεγμένης επιλογής.

```java
public int SelectedIndex { get; set; }
```
