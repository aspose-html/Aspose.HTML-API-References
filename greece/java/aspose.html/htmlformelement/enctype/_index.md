## HTMLFormElement.Enctype property

Ο τύπος περιεχομένου της υποβληθείσας φόρμας, γενικά application/x-www-form-urlencoded. Δείτε τον ορισμό του χαρακτηριστικού enctype στο HTML 4.01. Ο διαχειριστής συμβάντος onsubmit δεν εγγυάται ότι θα ενεργοποιηθεί κατά την κλήση αυτής της μεθόδου. Η συμπεριφορά είναι ασυνεπής για ιστορικούς λόγους και οι συγγραφείς δεν πρέπει να βασίζονται σε κάποιο συγκεκριμένο.

```java
public String Enctype { get; set; }
```
