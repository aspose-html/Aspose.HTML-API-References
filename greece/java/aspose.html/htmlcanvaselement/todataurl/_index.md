## ToDataURL() {#todataurl}

επιστρέφει ένα URI δεδομένων που περιέχει μια αναπαράσταση της εικόνας στη μορφή που καθορίζεται από την παράμετρο τύπου (προεπιλογή PNG). Η επιστρεφόμενη εικόνα έχει ανάλυση 96 dpi.

```java
public String ToDataURL()
```

### Τιμή Επιστροφής

Ένα DOMString που περιέχει το ζητούμενο data URI.

επιστρέφει ένα URI δεδομένων που περιέχει μια αναπαράσταση της εικόνας στη μορφή που καθορίζεται από την παράμετρο τύπου (προεπιλογή PNG). Η επιστρεφόμενη εικόνα έχει ανάλυση 96 dpi.

```java

```

| Παράμετρος | Τύπος | Περιγραφή |
