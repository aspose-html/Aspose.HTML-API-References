## HTMLCanvasElement.Width property

Είναι ένας θετικός ακέραιος που αντανακλά το χαρακτηριστικό width του HTML του στοιχείου καμβά, ερμηνευόμενο σε pixel CSS. Όταν το χαρακτηριστικό δεν έχει οριστεί ή αν έχει οριστεί σε μη έγκυρη τιμή, όπως μια αρνητική, χρησιμοποιείται η προεπιλεγμένη τιμή 300.

```java
public ulong Width { get; set; }
```
