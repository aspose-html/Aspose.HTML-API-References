## HTMLCanvasElement.GetContext method

Επιστρέφει ένα περιβάλλον σχεδίασης στο canvas, ή null εάν το ID του περιβάλλοντος δεν υποστηρίζεται. Ένα περιβάλλον σχεδίασης σας επιτρέπει να σχεδιάζετε στο canvas.

```java
public object GetContext(String contextId)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| contextId | String | Είναι ένα String που περιέχει το αναγνωριστικό context που ορίζει το context σχεδίασης που σχετίζεται με τον καμβά |

### Τιμή Επιστροφής

Ένα RenderingContext
