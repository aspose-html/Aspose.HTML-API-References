## HTMLCanvasElement.GetContext method

Επιστρέφει ένα πλαίσιο σχεδίασης στο canvas, ή null εάν το ID του πλαισίου δεν υποστηρίζεται. Ένα πλαίσιο σχεδίασης σας επιτρέπει να σχεδιάζετε στο canvas.

```java
public object GetContext(String contextId)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| contextId | String | Είναι ένα String που περιέχει το αναγνωριστικό του πλαισίου που ορίζει το πλαίσιο σχεδίασης που σχετίζεται με το καμβά |
