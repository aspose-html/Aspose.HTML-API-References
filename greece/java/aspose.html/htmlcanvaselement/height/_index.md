## HTMLCanvasElement.Height property

Είναι ένας θετικός ακέραιος που αντανακλά το χαρακτηριστικό height του HTML του στοιχείου καμβά, ερμηνευόμενο σε pixel CSS. Όταν το χαρακτηριστικό δεν έχει οριστεί ή αν έχει οριστεί σε μη έγκυρη τιμή, όπως μια αρνητική, χρησιμοποιείται η προεπιλεγμένη τιμή 150.

```java
public ulong Height { get; set; }
```
