## IXPathNamespace.OwnerElement property

Το [`Element`](../../../com.aspose.html.dom/element/) στο οποίο το πακέτο ήταν εντός εμβέλειας όταν ζητήθηκε. Αυτό δεν αλλάζει σε έναν επιστραφέν κόμβο πακέτου ακόμη και αν το έγγραφο αλλάξει έτσι ώστε το πακέτο να βγει εκτός εμβέλειας σε εκείνο το στοιχείο και αυτός ο κόμβος να μην βρίσκεται πλέον εκεί μέσω XPath.

```java
public Element OwnerElement { get; }
```
