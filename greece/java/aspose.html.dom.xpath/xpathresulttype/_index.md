## XPathResultType enumeration

Ένα unsigned short που υποδεικνύει ποιος τύπος αποτελέσματος είναι αυτός. Εάν καθοριστεί συγκεκριμένος `type`, τότε το αποτέλεσμα θα επιστραφεί ως ο αντίστοιχος τύπος, χρησιμοποιώντας μετατροπές τύπου XPath όπου απαιτείται και είναι δυνατόν.

```java
public enum XPathResultType
```

### Τιμές

| Όνομα | Τιμή | Περιγραφή |
| --- | --- | --- |
| Any | `0` | Αυτός ο κώδικας δεν αντιπροσωπεύει συγκεκριμένο τύπο. Μια αξιολόγηση μιας έκφρασης XPath δεν θα παράγει ποτέ αυτόν τον τύπο. Εάν ζητηθεί αυτός ο τύπος, η αξιολόγηση επιστρέφει οποιονδήποτε τύπο προκύπτει φυσικά από την αξιολόγηση της έκφρασης. Εάν το φυσικό αποτέλεσμα είναι σύνολο κόμβων όταν ζητήθηκε τύπος `Any`, τότε το `UnorderedNodeIterator` είναι πάντα ο τύπος που επιστρέφεται. Οποιαδήποτε άλλη αναπαράσταση ενός συνόλου κόμβων πρέπει να ζητηθεί ρητά. |
| Number | `1` | Το αποτέλεσμα είναι ένας αριθμός όπως ορίζεται από το [XPath 1.0]. Η τροποποίηση του εγγράφου δεν ακυρώνει τον αριθμό, αλλά μπορεί να σημαίνει ότι η επανεκτίμηση δεν θα δώσει τον ίδιο αριθμό. |
| String | `2` | Το αποτέλεσμα είναι ένα String όπως ορίζεται από το [XPath 1.0]. Η τροποποίηση του εγγράφου δεν ακυρώνει το String, αλλά μπορεί να σημαίνει ότι το String δεν αντιστοιχεί πλέον στο τρέχον έγγραφο. |

Η τροποποίηση του εγγράφου ακυρώνει την επανάληψη. Αυτός είναι ο προεπιλεγμένος τύπος που επιστρέφεται εάν το αποτέλεσμα είναι σύνολο κόμβων και ζητηθεί τύπος `Any`. |

| UnorderedNodeSnapshot | `6` | Το αποτέλεσμα είναι ένα σύνολο κόμβων όπως ορίζεται από το [XPath 1.0] που θα προσπελαστεί ως λίστα στιγμιότυπου κόμβων που μπορεί να μην είναι σε συγκεκριμένη σειρά. Η τροποποίηση του εγγράφου δεν ακυρώνει το στιγμιότυπο, αλλά μπορεί να σημαίνει ότι η επανεκτίμηση δεν θα δώσει το ίδιο στιγμιότυπο και οι κόμβοι στο στιγμιότυπο μπορεί να έχουν τροποποιηθεί, μετακινηθεί ή αφαιρεθεί από το έγγραφο. |

Η τροποποίηση του εγγράφου δεν ακυρώνει το στιγμιότυπο, αλλά μπορεί να σημαίνει ότι η επανεκτίμηση δεν θα δώσει το ίδιο στιγμιότυπο και οι κόμβοι στο στιγμιότυπο μπορεί να έχουν τροποποιηθεί, μετακινηθεί ή αφαιρεθεί από το έγγραφο. |

Η τροποποίηση του εγγράφου δεν ακυρώνει τον κόμβο, αλλά μπορεί να σημαίνει ότι ο κόμβος αποτελέσματος δεν αντιστοιχεί πλέον στο τρέχον έγγραφο.
