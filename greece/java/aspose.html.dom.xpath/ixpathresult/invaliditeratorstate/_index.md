## IXPathResult.InvalidIteratorState property

Δηλώνει ότι ο επαναλήπτης έχει γίνει άκυρος. Αληθές εάν `resultType` είναι τύπου `UnorderedNodeIterator` ή `OrderedNodeIterator` και το έγγραφο έχει τροποποιηθεί από τη στιγμή που επιστράφηκε αυτό το αποτέλεσμα.

```java
public bool InvalidIteratorState { get; }
```
