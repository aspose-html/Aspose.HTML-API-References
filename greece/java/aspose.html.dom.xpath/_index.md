Το πακέτο περιέχει μεθόδους για πλοήγηση μέσω στοιχείων και χαρακτηριστικών σε ένα έγγραφο XML.

## Διεπαφές

| Διεπαφή | Περιγραφή |
| --- | --- |
| [IXPathEvaluator](./ixpathevaluator/) | Η αξιολόγηση των εκφράσεων XPath παρέχεται από [`IXPathEvaluator`](../com.aspose.html.dom.xpath/ixpathevaluator/). |
| [IXPathExpression](./ixpathexpression/) | Η διεπαφή `XPathExpression` αντιπροσωπεύει μια αναλυμένη και επιλυμένη έκφραση XPath. |
| [IXPathNamespace](./ixpathpackage/) | Η διεπαφή XPathNamespace επιστρέφεται από τις διεπαφές XPathResult για να αντιπροσωπεύει τον τύπο κόμβου πακέτου XPath που λείπει από το DOM. |
| [IXPathNSResolver](./ixpathnsresolver/) | Η διεπαφή `XPathNSResolver` επιτρέπει στις συμβολοσειρές `prefix` στην έκφραση να δεσμευτούν σωστά με τις συμβολοσειρές `packageURI`. [`IXPathEvaluator`](../com.aspose.html.dom.xpath/ixpathevaluator/) μπορεί να δημιουργήσει μια υλοποίηση του [`IXPathNSResolver`](../com.aspose.html.dom.xpath/ixpathnsresolver/) από έναν κόμβο, ή η διεπαφή μπορεί να υλοποιηθεί από οποιαδήποτε εφαρμογή. |
| [IXPathResult](./ixpathresult/) | Η διεπαφή `XPathResult` αντιπροσωπεύει το αποτέλεσμα της αξιολόγησης μιας έκφρασης XPath 1.0 στο πλαίσιο ενός συγκεκριμένου κόμβου. Δεδομένου ότι η αξιολόγηση μιας έκφρασης XPath μπορεί να έχει διάφορους τύπους αποτελεσμάτων, αυτό το αντικείμενο καθιστά δυνατό τον εντοπισμό και τη διαχείριση του τύπου και της τιμής του αποτελέσματος. |
## Απαρίθμηση

| Απαρίθμηση | Περιγραφή |
| --- | --- |
| [XPathResultType](./xpathresulttype/) | Ένα unsigned short που υποδεικνύει ποιος τύπος αποτελέσματος είναι αυτός. Εάν καθοριστεί συγκεκριμένος `type`, τότε το αποτέλεσμα θα επιστραφεί ως ο αντίστοιχος τύπος, χρησιμοποιώντας μετατροπές τύπου XPath όπου απαιτείται και είναι δυνατόν. |
