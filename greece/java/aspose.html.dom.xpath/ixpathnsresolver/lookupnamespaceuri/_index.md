## IXPathNSResolver.LookupNamespaceURI method

Αναζητήστε το URI του πακέτου που σχετίζεται με το δεδομένο πρόθεμα πακέτου. Ο αξιολογητής XPath δεν πρέπει ποτέ να καλέσει αυτό με όρισμα `null` ή κενό, επειδή το αποτέλεσμα αυτής της κλήσης είναι ακαθόριστο.

```java
public String LookupNamespaceURI(String prefix)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| πρόθεμα | String | Το πρόθεμα προς αναζήτηση. |

### Τιμή επιστροφής

Επιστρέφει το σχετικό URI του πακέτου ή `null` εάν δεν βρεθεί κανένα.
