## IXPathNSResolver.LookupNamespaceURI method

Αναζητήστε το URI πακέτου που σχετίζεται με το δεδομένο πρόθεμα πακέτου. Ο αξιολογητής XPath δεν πρέπει ποτέ να το καλέσει με όρισμα `null` ή κενό, επειδή το αποτέλεσμα αυτής της κλήσης είναι ακαθόριστο.

```java
public String LookupNamespaceURI(String prefix)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| πρόθεμα | String | Το πρόθεμα προς αναζήτηση. |

### Τιμή Επιστροφής

Επιστρέφει το συσχετισμένο URI πακέτου ή `null` εάν δεν βρεθεί κανένα.
