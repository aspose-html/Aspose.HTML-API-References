## IXPathNSResolver interface

Η διεπαφή `XPathNSResolver` επιτρέπει στα Strings `prefix` στην έκφραση να δεσμεύονται σωστά με τα Strings `packageURI`. [`IXPathEvaluator`](../ixpathevaluator/) μπορεί να δημιουργήσει μια υλοποίηση του `IXPathNSResolver` από έναν κόμβο, ή η διεπαφή μπορεί να υλοποιηθεί από οποιαδήποτε εφαρμογή.

