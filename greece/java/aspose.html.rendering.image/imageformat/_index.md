
### Τιμές

| Όνομα | Τιμή | Περιγραφή |
| --- | --- | --- |
| Jpeg | `1` | Η μορφή εικόνας Joint Photographic Experts Group (JPEG). |
| Png | `2` | Η μορφή εικόνας W3C Portable Network Graphics (PNG). |
| Bmp | `3` | Η μορφή εικόνας bitmap (BMP). |
| Gif | `4` | Η μορφή εικόνας Graphics Interchange Format (GIF). |
| Tiff | `5` | Η μορφή εικόνας Tagged Image File Format (TIFF). |
| Webp | `6` | Η μορφή Web Picture (WebP), μια σύγχρονη μορφή εικόνας που παρέχει ανώτερη συμπίεση χωρίς απώλειες και με απώλειες για εικόνες στο διαδίκτυο. |
