## ImageRenderingOptions.HorizontalResolution property

Ορίζει ή λαμβάνει την οριζόντια ανάλυση για τις εξόδους και εσωτερικές (που χρησιμοποιούνται κατά την επεξεργασία φίλτρων) εικόνες, σε pixel ανά ίντσα. Από προεπιλογή αυτή η ιδιότητα είναι 300 dpi.

```java
public Resolution HorizontalResolution { get; set; }
```
