Το πακέτο **com.aspose.html.rendering.image** παρέχει συγκεκριμένη κλάση συσκευής καθώς και μερικές κλάσεις επιλογών απόδοσης υπεύθυνες για την απόδοση σε μορφές raster: jpeg, png, bmp, gif, tiff.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [ImageDevice](./imagedevice/) | Αντιπροσωπεύει την απόδοση σε μορφές raster: jpeg, png, bmp, gif, tiff. |
| [ImageRenderingOptions](./imagerenderingoptions/) | Αντιπροσωπεύει τις επιλογές απόδοσης για το [`ImageDevice`](../com.aspose.html.rendering.image/imagedevice/). Αυτές οι επιλογές χρησιμοποιούνται για τον καθορισμό της μορφής εξόδου της εικόνας, της συμπίεσης, της ανάλυσης κ.λπ. |
| [TextOptions](./textoptions/) | Αντιπροσωπεύει τις επιλογές απόδοσης κειμένου για το [`ImageDevice`](../com.aspose.html.rendering.image/imagedevice/). |
## Απαρίθμηση

| Απαρίθμηση | Περιγραφή |
| --- | --- |
| [Compression](./compression/) | Καθορίζει τα πιθανά σχήματα συμπίεσης για εικόνες bitmap σε μορφή Tagged Image File Format (TIFF). |
| [ImageFormat](./imageformat/) | Καθορίζει τη μορφή αρχείου της εικόνας. |
