## KeyboardEvent.CtrlKey property

true εάν ο τροποποιητής πλήκτρου Control (control) ήταν ενεργός. Η μη αρχικοποιημένη τιμή αυτού του χαρακτηριστικού ΠΡΕΠΕΙ να είναι false.

```java
public bool CtrlKey { get; }
```

### Property Value

`true` εάν Control· διαφορετικά, `false`.
