## KeyboardEvent.IsComposing property

true εάν το γεγονός πλήκτρου συμβαίνει ως μέρος μιας συνεδρίας σύνθεσης, δηλαδή μετά από γεγονός compositionstart και πριν από το αντίστοιχο γεγονός compositionend. Η μη αρχικοποιημένη τιμή αυτής της ιδιότητας ΠΡΕΠΕΙ να είναι false.

```java
public bool IsComposing { get; }
```

### Property Value

`true` εάν αυτή η παρουσία είναι σε σύνθεση· διαφορετικά, `false`.
