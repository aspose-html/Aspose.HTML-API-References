## KeyboardEvent.AltKey property

true εάν ο τροποποιητής πλήκτρου Alt (alternative) (ή "Option") ήταν ενεργός. Η μη αρχικοποιημένη τιμή αυτού του χαρακτηριστικού ΠΡΕΠΕΙ να είναι false.

```java
public bool AltKey { get; }
```

### Property Value

`true` αν Alt· διαφορετικά, `false`.
