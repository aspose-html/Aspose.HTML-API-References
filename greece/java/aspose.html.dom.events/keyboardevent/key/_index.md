## KeyboardEvent.Key property

Το key περιέχει την τιμή του πατημένου πλήκτρου. Εάν η τιμή έχει εκτυπώσιμη αναπαράσταση, ΠΡΕΠΕΙ να είναι μια μη κενή συμβολοσειρά Unicode χαρακτήρα, που συμμορφώνεται με τον αλγόριθμο καθορισμού της τιμής του πλήκτρου που ορίζεται σε αυτήν την προδιαγραφή. Εάν η τιμή είναι ένα πλήκτρο ελέγχου που δεν έχει εκτυπώσιμη αναπαράσταση, ΠΡΕΠΕΙ να είναι μία από τις τιμές πλήκτρου που ορίζονται στο σύνολο τιμών πλήκτρου, όπως καθορίζεται από τον αλγόριθμο καθορισμού της τιμής του πλήκτρου. Οι υλοποιήσεις που δεν μπορούν να αναγνωρίσουν ένα πλήκτρο ΠΡΕΠΕΙ να χρησιμοποιούν την τιμή πλήκτρου Unidentified.

```java
public String Key { get; }
```

### Property Value

Η τιμή του πλήκτρου.
