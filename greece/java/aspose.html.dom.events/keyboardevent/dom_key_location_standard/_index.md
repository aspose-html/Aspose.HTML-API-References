## KeyboardEvent.DOM_KEY_LOCATION_STANDARD field

Η ενεργοποίηση του πλήκτρου ΔΕΝ ΠΡΕΠΕΙ να διακρίνεται ως η αριστερή ή η δεξιά έκδοση του πλήκτρου, και (εκτός του πλήκτρου NumLock) δεν προήλθε από το αριθμητικό πληκτρολόγιο (ή δεν προήλθε από ένα εικονικό πλήκτρο που αντιστοιχεί στο αριθμητικό πληκτρολόγιο).

```java
public const ulong DOM_KEY_LOCATION_STANDARD;
```
