## KeyboardEvent.DOM_KEY_LOCATION_NUMPAD field

Η ενεργοποίηση του πλήκτρου προέρχεται από το αριθμητικό πληκτρολόγιο ή από ένα εικονικό πλήκτρο που αντιστοιχεί στο αριθμητικό πληκτρολόγιο (όταν υπάρχει περισσότερη από μία πιθανή θέση για αυτό το πλήκτρο). Σημειώστε ότι το πλήκτρο NumLock πρέπει πάντα να κωδικοποιείται με θέση DOM_KEY_LOCATION_STANDARD.

```java
public const ulong DOM_KEY_LOCATION_NUMPAD;
```
