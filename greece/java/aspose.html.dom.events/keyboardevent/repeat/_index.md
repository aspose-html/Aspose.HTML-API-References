## KeyboardEvent.Repeat property

true εάν το πλήκτρο έχει πατηθεί με διαρκή τρόπο. Η κράτηση ενός πλήκτρου ΠΡΕΠΕΙ να έχει ως αποτέλεσμα την επανάληψη των γεγονότων keydown, beforeinput, input με αυτή τη σειρά, με ρυθμό που καθορίζεται από τη διαμόρφωση του συστήματος. Για κινητές συσκευές που έχουν συμπεριφορά παρατεταμένου πατήματος, το πρώτο γεγονός πλήκτρου με τιμή repeat true ΠΡΕΠΕΙ να λειτουργεί ως ένδειξη παρατεταμένου πατήματος. Η διάρκεια χρόνου που ΠΡΕΠΕΙ να παραμείνει πατημένο το πλήκτρο για να αρχίσει η επανάληψη εξαρτάται από τη διαμόρφωση.

```java
public bool Repeat { get; }
```

### Property Value

`true` εάν repeat· διαφορετικά, `false`.
