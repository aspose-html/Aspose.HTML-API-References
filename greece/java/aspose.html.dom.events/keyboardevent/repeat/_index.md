## KeyboardEvent.Repeat property

true εάν το πλήκτρο έχει πατηθεί με διαρκή τρόπο. Η κράτηση ενός πλήκτρου MUST να έχει ως αποτέλεσμα την επανάληψη των συμβάντων keydown, beforeinput, input με αυτή τη σειρά, με ρυθμό που καθορίζεται από τη διαμόρφωση του συστήματος. Για κινητές συσκευές με συμπεριφορά παρατεταμένου πατήματος, το πρώτο συμβάν πλήκτρου με τιμή attribute repeat ίσο με true MUST να λειτουργεί ως ένδειξη παρατεταμένου πατήματος. Η διάρκεια χρόνου που το πλήκτρο MUST να παραμείνει πατημένο για να αρχίσει η επανάληψη εξαρτάται από τη διαμόρφωση.

```java
public bool Repeat { get; }
```

### Property Value

`true` εάν repeat; διαφορετικά, `false`.
