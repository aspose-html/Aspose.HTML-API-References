## WheelEvent.DeltaZ property

Σε πράκτορες χρήστη όπου η προεπιλεγμένη ενέργεια του συμβάντος τροχού είναι η κύλιση, η τιμή ΠΡΕΠΕΙ να είναι η μέτρηση κατά τον άξονα z (σε pixels, lines ή pages) που θα κυλιστεί στην περίπτωση που το συμβάν δεν ακυρωθεί. Διαφορετικά, αυτή είναι μια μέτρηση ειδική για την υλοποίηση (σε pixels, lines ή pages) της κίνησης μιας συσκευής τροχού γύρω από τον άξονα z.

```java
public double DeltaZ { get; }
```

Το χαρακτηριστικό deltaZ.
