## WheelEvent.DeltaMode property

Το χαρακτηριστικό deltaMode περιέχει ένδειξη των μονάδων μέτρησης για τις τιμές του delta. Η προεπιλεγμένη τιμή είναι DOM_DELTA_PIXEL (pixel).

```java
public ulong DeltaMode { get; }
```

### Property Value

Η λειτουργία delta.
