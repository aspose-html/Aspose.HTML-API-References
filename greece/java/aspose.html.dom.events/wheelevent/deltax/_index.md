## WheelEvent.DeltaX property

Σε πράκτορες χρήστη όπου η προεπιλεγμένη ενέργεια του γεγονότος τροχού είναι η κύλιση, η τιμή MUST να είναι η μέτρηση κατά τον άξονα x (σε pixel, γραμμές ή σελίδες) που θα κυλιστεί στην περίπτωση που το γεγονός δεν ακυρωθεί. Διαφορετικά, αυτή είναι μια ειδική για την υλοποίηση μέτρηση (σε pixel, γραμμές ή σελίδες) της κίνησης μιας συσκευής τροχού γύρω από τον άξονα x.

```java
public double DeltaX { get; }
```

### Property Value

Το χαρακτηριστικό deltaX.
