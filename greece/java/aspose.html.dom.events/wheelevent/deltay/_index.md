## WheelEvent.DeltaY property

Σε πράκτορες χρήστη όπου η προεπιλεγμένη ενέργεια του γεγονότος τροχού είναι η κύλιση, η τιμή ΠΡΕΠΕΙ να είναι η μέτρηση κατά τον άξονα y (σε pixel, γραμμές ή σελίδες) που θα κυλιστεί στην περίπτωση που το γεγονός δεν ακυρωθεί. Διαφορετικά, αυτή είναι μια ειδική για την υλοποίηση μέτρηση (σε pixel, γραμμές ή σελίδες) της κίνησης μιας συσκευής τροχού γύρω από τον άξονα y.

```java
public double DeltaY { get; }
```

### Property Value

Το χαρακτηριστικό deltaY.
