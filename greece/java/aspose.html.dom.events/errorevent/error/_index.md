## ErrorEvent.Error property

Η ιδιότητα error πρέπει να επιστρέφει την τιμή στην οποία αρχικοποιήθηκε. Όταν δημιουργείται το αντικείμενο, αυτή η ιδιότητα πρέπει να αρχικοποιηθεί σε null. Όπου είναι κατάλληλο, ορίζεται στο αντικείμενο που αντιπροσωπεύει το σφάλμα (π.χ. το αντικείμενο εξαίρεσης σε περίπτωση μη πιασμένης εξαίρεσης DOM).

```java
public object Error { get; }
```
