## ErrorEvent.LineNo property

Το χαρακτηριστικό lineno πρέπει να επιστρέφει την τιμή στην οποία αρχικοποιήθηκε. Όταν το αντικείμενο δημιουργείται, αυτό το χαρακτηριστικό πρέπει να αρχικοποιηθεί στο μηδέν. Αντιπροσωπεύει τον αριθμό γραμμής όπου συνέβη το σφάλμα στο script.

```java
public uint LineNo { get; }
```
