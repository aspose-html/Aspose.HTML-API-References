## ErrorEvent.LineNo property

Η ιδιότητα lineno πρέπει να επιστρέφει την τιμή στην οποία αρχικοποιήθηκε. Όταν δημιουργείται το αντικείμενο, αυτή η ιδιότητα πρέπει να αρχικοποιηθεί στο μηδέν. Αντιπροσωπεύει τον αριθμό γραμμής όπου συνέβη το σφάλμα στο script.

```java
public uint LineNo { get; }
```
