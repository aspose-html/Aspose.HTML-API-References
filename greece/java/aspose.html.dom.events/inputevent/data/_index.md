## InputEvent.Data property

Τα δεδομένα περιέχουν την τιμή των χαρακτήρων που δημιουργούνται από μια μέθοδο εισόδου. Αυτό ΜΠΟΡΕΙ να είναι ένας μοναδικός χαρακτήρας Unicode ή μια μη κενή ακολουθία χαρακτήρων [Unicode]. Οι χαρακτήρες ΠΡΕΠΕΙ να είναι κανονικοποιημένοι σύμφωνα με τον τύπο κανονικοποίησης Unicode NFC, που ορίζεται στο [UAX15]. Αυτό το χαρακτηριστικό ΜΠΟΡΕΙ να περιέχει το κενό String.

```java
public String Data { get; }
```
