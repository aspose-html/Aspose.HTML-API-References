## InputEvent.IsComposing property

true εάν το συμβάν εισόδου συμβαίνει ως μέρος μιας συνεδρίας σύνθεσης, δηλαδή μετά από ένα συμβάν compositionstart και πριν από το αντίστοιχο συμβάν compositionend. Η μη αρχικοποιημένη τιμή αυτού του χαρακτηριστικού ΠΡΕΠΕΙ να είναι false.

```java
public bool IsComposing { get; }
```

### Property Value

`true` εάν αυτή η παρουσία είναι σε σύνθεση· διαφορετικά, `false`.
