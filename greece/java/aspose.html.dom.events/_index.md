Το **com.aspose.html.dom.events** πακέτο παρέχει αντικείμενα για οποιαδήποτε γεγονότα σχετιζόμενα με την ενημέρωση του DOM. Περιλαμβάνει συνδρομή σε συγκεκριμένη παρατήρηση συμφραζομένων πληροφοριών που σχετίζονται με το γεγονός, καθώς και δημιουργία προσαρμοσμένων γεγονότων.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [CustomEvent](./customevent/) | Γεγονότα που χρησιμοποιούν τη διεπαφή CustomEvent μπορούν να χρησιμοποιηθούν για τη μεταφορά προσαρμοσμένων δεδομένων. |
| [DocumentLoadErrorEvent](./documentloaderrorevent/) | Το DocumentLoadErrorEvent εμφανίζεται όταν ο ζητούμενος πόρος δεν είναι διαθέσιμος. |
| [DOMEventHandler](./domeventhandler/) | Αναπαριστά έναν γενικό delegate κλήσης επιστροφής για τη διαχείριση γεγονότων του Document Object Model (DOM). |
| [ErrorEvent](./errorevent/) | Το ErrorEvent παρέχει συμφραζόμενες πληροφορίες σχετικά με σφάλματα που συνέβησαν κατά την εκτέλεση. |
| [Event](./event/) | Το χρησιμοποιείται για την παροχή συμφραζόμενων πληροφοριών σχετικά με ένα συμβάν στον επεξεργαστή που επεξεργάζεται το συμβάν. |
| [FocusEvent](./focusevent/) | Το FocusEvent interface παρέχει συγκεκριμένες συμφραζόμενες πληροφορίες που σχετίζονται με τα Focus events. |
| [InputEvent](./inputevent/) | Τα Input events αποστέλλονται ως ειδοποιήσεις όποτε το DOM ενημερώνεται. |
| [KeyboardEvent](./keyboardevent/) | Το KeyboardEvent interface παρέχει συγκεκριμένες συμφραζόμενες πληροφορίες που σχετίζονται με συσκευές πληκτρολογίου. Κάθε γεγονός πληκτρολογίου αναφέρεται σε ένα πλήκτρο χρησιμοποιώντας μια τιμή. Τα Keyboard events συνήθως κατευθύνονται προς το στοιχείο που έχει την εστίαση. |
| [MouseEvent](./mouseevent/) | Το MouseEvent interface παρέχει συγκεκριμένες συμφραζόμενες πληροφορίες που σχετίζονται με Mouse events. |
| [UIEvent](./uievent/) | Το UIEvent interface παρέχει συγκεκριμένες συμφραζόμενες πληροφορίες που σχετίζονται με User Interface events. |
| [WheelEvent](./wheelevent/) | Το WheelEvent interface παρέχει συγκεκριμένες συμφραζόμενες πληροφορίες που σχετίζονται με wheel events. Για να δημιουργήσετε μια παρουσία του WheelEvent interface, χρησιμοποιήστε τον κατασκευαστή WheelEvent, περνώντας ένα προαιρετικό λεξικό WheelEventInit. |
## Διεπαφές

| Διεπαφή | Περιγραφή |
| --- | --- |
| [IDocumentEvent](./idocumentevent/) | Το DocumentEvent interface παρέχει έναν μηχανισμό με τον οποίο ο χρήστης μπορεί να δημιουργήσει ένα Event τύπου που υποστηρίζεται από την υλοποίηση. Αναμένεται ότι το DocumentEvent interface θα υλοποιηθεί στο ίδιο αντικείμενο που υλοποιεί το Document interface σε μια υλοποίηση που υποστηρίζει το μοντέλο Event. |
| [IEventListener](./ieventlistener/) | Το interface είναι η κύρια μέθοδος για τη διαχείριση των events. Οι χρήστες υλοποιούν το interface και καταχωρούν τον ακροατή τους σε ένα χρησιμοποιώντας τη μέθοδο. Οι χρήστες θα πρέπει επίσης να αφαιρέσουν τον ακροατή τους από αυτό μετά την ολοκλήρωση της χρήσης του. |
| [IEventTarget](./ieventtarget/) | Το EventTarget interface υλοποιείται από όλους τους Nodes σε μια υλοποίηση που υποστηρίζει το DOM Event Model. Συνεπώς, αυτό το interface μπορεί να ληφθεί χρησιμοποιώντας μεθόδους μετατροπής ειδικές για binding σε μια παρουσία του Node interface. Το interface επιτρέπει την καταχώρηση και αφαίρεση των Event Listeners σε ένα και την αποστολή των events σε αυτό. |
