## IDocumentEvent interface

Το DocumentEvent interface παρέχει έναν μηχανισμό με τον οποίο ο χρήστης μπορεί να δημιουργήσει ένα Event τύπου που υποστηρίζεται από την υλοποίηση. Αναμένεται ότι το DocumentEvent interface θα υλοποιηθεί στο ίδιο αντικείμενο που υλοποιεί το Document interface σε μια υλοποίηση που υποστηρίζει το μοντέλο Event.

```java
public interface IDocumentEvent
```
