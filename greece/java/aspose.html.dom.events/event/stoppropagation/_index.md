## Event.StopPropagation method

Η μέθοδος `StopPropagation` χρησιμοποιείται για την αποτροπή περαιτέρω διάδοσης ενός συμβάντος κατά τη ροή του συμβάντος.

```java
public void StopPropagation()
```

## Παρατηρήσεις

Εάν αυτή η μέθοδος κληθεί από οποιονδήποτε [`IEventListener`](../../ieventlistener/), το συμβάν θα σταματήσει να διαδίδεται μέσω του δέντρου. Το συμβάν θα ολοκληρώσει την αποστολή σε όλους τους ακροατές στο τρέχον [`IEventTarget`](../../ieventtarget/) πριν η ροή του συμβάντος σταματήσει. Αυτή η μέθοδος μπορεί να χρησιμοποιηθεί σε οποιοδήποτε στάδιο της ροής του συμβάντος.
