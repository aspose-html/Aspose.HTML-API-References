## Event.Cancelable property

Χρησιμοποιείται για να υποδείξει εάν ένα συμβάν μπορεί ή όχι να έχει την προεπιλεγμένη του ενέργεια αποτραπεί. Εάν η προεπιλεγμένη ενέργεια μπορεί να αποτραπεί, η τιμή είναι true, αλλιώς η τιμή είναι false.

```java
public bool Cancelable { get; }
```
