## Event.IsTrusted property

Το χαρακτηριστικό isTrusted πρέπει να επιστρέφει την τιμή με την οποία αρχικοποιήθηκε. Όταν δημιουργείται ένα συμβάν, το χαρακτηριστικό πρέπει να αρχικοποιηθεί σε false.

```java
public bool IsTrusted { get; }
```

### Property Value

`true` εάν αυτή η παρουσία είναι αξιόπιστη· διαφορετικά, `false`.
