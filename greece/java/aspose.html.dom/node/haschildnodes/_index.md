## Node.HasChildNodes method

Η μέθοδος hasChildNodes() της διεπαφής Node επιστρέφει μια boolean τιμή που υποδεικνύει εάν ο δεδομένος [`Node`](../) έχει παιδικούς κόμβους ή όχι.

```java
public bool HasChildNodes()
```

### Τιμή επιστροφής

Μια boolean τιμή που είναι true εάν ο κόμβος έχει παιδικούς κόμβους, και false διαφορετικά.
