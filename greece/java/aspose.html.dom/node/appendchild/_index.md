## Node.AppendChild method

Η μέθοδος appendChild() του interface Node προσθέτει έναν κόμβο στο τέλος της λίστας των παιδιών ενός καθορισμένου γονικού κόμβου. Εάν το δοσμένο παιδί είναι αναφορά σε έναν υπάρχοντα κόμβο στο έγγραφο, η appendChild() τον μετακινεί από την τρέχουσα θέση του στη νέα θέση (δεν απαιτείται η αφαίρεση του κόμβου από τον γονικό του πριν την προσθήκη του σε κάποιον άλλο κόμβο).

Αυτό σημαίνει ότι ένας κόμβος δεν μπορεί να βρίσκεται σε δύο σημεία του εγγράφου ταυτόχρονα. Έτσι, εάν ο κόμβος έχει ήδη γονέα, πρώτα αφαιρείται και στη συνέχεια προσαρτάται στη νέα θέση. Η μέθοδος [`Node.cloneNode()`](../clonenode/) μπορεί να χρησιμοποιηθεί για να δημιουργηθεί αντίγραφο του κόμβου πριν προσαρτηθεί κάτω από τον νέο γονέα. Τα αντίγραφα που δημιουργούνται με το [`cloneNode`](../clonenode/) δεν διατηρούνται αυτόματα συγχρονισμένα.

```java
public Node AppendChild(Node node)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| κόμβος | Node | Ο κόμβος που θα προσαρτηθεί στον δοσμένο γονικό κόμβο (συνήθως ένα στοιχείο). |

### Τιμή επιστροφής

Ένας Node που είναι το προσαρτημένο παιδί (aChild), εκτός εάν το aChild είναι ένα [`DocumentFragment`](../../documentfragment/), στην οποία περίπτωση επιστρέφεται το κενό [`DocumentFragment`](../../documentfragment/).
