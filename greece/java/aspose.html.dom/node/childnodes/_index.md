## Node.ChildNodes property

Η μόνο για ανάγνωση ιδιότητα childNodes της διεπαφής Node επιστρέφει μια ζωντανή [`NodeList`](../../../com.aspose.html.collections/nodelist/) των παιδικών κόμβων του δεδομένου στοιχείου, όπου ο πρώτος παιδικός κόμβος έχει δείκτη 0. Τα παιδικά κόμβοι περιλαμβάνουν στοιχεία, κείμενο και σχόλια.

Σημείωση: Το ότι η [`NodeList`](../../../com.aspose.html.collections/nodelist/) είναι ζωντανή σημαίνει ότι το περιεχόμενό της αλλάζει κάθε φορά που προστίθενται ή αφαιρούνται νέα παιδιά.

```java
public NodeList ChildNodes { get; }
```

### Property Value

Μια ζωντανή [`NodeList`](../../../com.aspose.html.collections/nodelist/) που περιέχει τα παιδιά του κόμβου.

Σημείωση: Πολλές κλήσεις στο childNodes επιστρέφουν την ίδια [`NodeList`](../../../com.aspose.html.collections/nodelist/).
