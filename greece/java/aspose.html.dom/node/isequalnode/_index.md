## Node.IsEqualNode method

Η μέθοδος isEqualNode() της διεπαφής [`Node`](../) ελέγχει αν δύο κόμβοι είναι ίσοι. Δύο κόμβοι είναι ίσοι όταν έχουν τον ίδιο τύπο, χαρακτηριστικά ορισμού (για στοιχεία, αυτό θα ήταν το ID τους, ο αριθμός των παιδιών κ.λπ.), τα χαρακτηριστικά τους ταιριάζουν κ.ά. Το συγκεκριμένο σύνολο των δεδομένων που πρέπει να ταιριάζουν διαφέρει ανάλογα με τους τύπους των κόμβων.

```java
public bool IsEqualNode(Node otherNode)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| otherNode | Node | Το [`Node`](../) με το οποίο συγκρίνεται η ισότητα. |

### Τιμή επιστροφής

Μια λογική τιμή που είναι true εάν οι δύο κόμβοι είναι ίσοι, ή false εάν όχι. Εάν το otherNode είναι null, η isEqualNode() πάντα επιστρέφει false.
