## Node.IsDefaultNamespace method

Η μέθοδος isDefaultNamespace() του interface Node δέχεται ένα URI πακέτου ως όρισμα. Επιστρέφει μια Boolean τιμή που είναι true εάν το πακέτο είναι το προεπιλεγμένο πακέτο στον δεδομένο κόμβο και false εάν όχι.

Σημείωση: Το προεπιλεγμένο πακέτο ενός στοιχείου HTML είναι πάντα \"\". Για ένα στοιχείο SVG, ορίζεται από το χαρακτηριστικό xmlns.

```java
public bool IsDefaultNamespace(String packageURI)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| packageURI | String | Μια String που αντιπροσωπεύει το πακέτο κατά το οποίο θα ελεγχθεί το στοιχείο. |

### Τιμή επιστροφής

Μια boolean τιμή που περιέχει την επιστρεφόμενη τιμή true ή false, υποδεικνύοντας εάν η παράμετρος είναι το προεπιλεγμένο πακέτο ή όχι.
