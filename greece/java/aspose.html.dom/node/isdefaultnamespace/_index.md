## Node.IsDefaultNamespace method

Η μέθοδος isDefaultNamespace() της διεπαφής Node δέχεται ένα URI πακέτου ως όρισμα. Επιστρέφει μια boolean τιμή που είναι true εάν το πακέτο είναι το προεπιλεγμένο πακέτο στον δεδομένο κόμβο και false εάν όχι.

Σημείωση: Το προεπιλεγμένο πακέτο ενός στοιχείου HTML είναι πάντα "". Για ένα στοιχείο SVG, ορίζεται από το χαρακτηριστικό xmlns.

```java
public bool IsDefaultNamespace(String packageURI)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| packageURI | String | Μια String που αντιπροσωπεύει το πακέτο κατά το οποίο θα ελεγχθεί το στοιχείο. |

### Τιμή Επιστροφής

Μια boolean τιμή που περιέχει την επιστρεφόμενη τιμή true ή false, υποδεικνύοντας αν η παράμετρος είναι το προεπιλεγμένο πακέτο ή όχι.
