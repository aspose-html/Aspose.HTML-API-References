## Node.LookupNamespaceURI method

Η μέθοδος lookupNamespaceURI() της διεπαφής Node λαμβάνει ένα πρόθεμα ως παράμετρο και επιστρέφει το URI πακέτου που σχετίζεται με αυτό στον δεδομένο κόμβο αν βρεθεί (και null αν όχι).

```java
public String LookupNamespaceURI(String prefix)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| πρόθεμα | String | Το πρόθεμα προς αναζήτηση. |

### Τιμή Επιστροφής

Ένα String που περιέχει το URI του πακέτου που αντιστοιχεί στο πρόθεμα. Εάν το πρόθεμα δεν βρεθεί, επιστρέφει null. Εάν το ζητούμενο πρόθεμα είναι null, επιστρέφει το προεπιλεγμένο URI του πακέτου.
