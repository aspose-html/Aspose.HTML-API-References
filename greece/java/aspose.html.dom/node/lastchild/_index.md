## Node.LastChild property

Η μόνο για ανάγνωση ιδιότητα lastChild της διεπαφής [`Node`](../) επιστρέφει το τελευταίο παιδί του κόμβου. Εάν ο γονέας του είναι ένα στοιχείο, τότε το παιδί είναι γενικά ένας κόμβος στοιχείου, ένας κόμβος κειμένου ή ένας κόμβος σχολίου. Επιστρέφει null εάν δεν υπάρχουν παιδικοί κόμβοι.

```java
public Node LastChild { get; }
```

### Property Value

Ένα [`Node`](../) που είναι το τελευταίο παιδί του κόμβου, ή null εάν δεν υπάρχουν παιδικοί κόμβοι.
