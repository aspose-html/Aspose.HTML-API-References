## Node.IsSameNode method

Η μέθοδος isSameNode() του interface Node είναι ένα παλαιότερο ψευδώνυμο για τον τελεστή αυστηρής ισότητας ===. Δηλαδή, ελέγχει αν δύο κόμβοι είναι οι ίδιοι (δηλαδή, αν αναφέρονται στο ίδιο αντικείμενο).

Σημείωση: Δεν υπάρχει ανάγκη να χρησιμοποιήσετε το isSameNode(); αντί αυτού χρησιμοποιήστε τον τελεστή αυστηρής ισότητας ===.

```java
public bool IsSameNode(Node otherNode)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| otherNode | Node | Ο Node προς δοκιμή. |

### Τιμή επιστροφής

Μια boolean τιμή που είναι true εάν και οι δύο κόμβοι είναι αυστηρά ίσοι, false εάν όχι.
