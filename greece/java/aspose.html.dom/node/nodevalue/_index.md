## Node.NodeValue property

Η ιδιότητα nodeValue της διεπαφής [`Node `](../) επιστρέφει ή ορίζει την τιμή του τρέχοντος κόμβου.

```java
public String NodeValue { get; set; }
```

### Property Value

Ένα String που περιέχει την τιμή του τρέχοντος κόμβου, εάν υπάρχει. Για το ίδιο το έγγραφο, το nodeValue επιστρέφει null. Για κόμβους κειμένου, σχολίου και CDATA, το nodeValue επιστρέφει το περιεχόμενο του κόμβου. Για κόμβους χαρακτηριστικού, επιστρέφεται η τιμή του χαρακτηριστικού.
