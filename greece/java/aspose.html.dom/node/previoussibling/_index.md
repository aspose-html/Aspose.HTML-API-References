## Node.PreviousSibling property

Η μόνο για ανάγνωση ιδιότητα previousSibling της διεπαφής [`Node`](../) επιστρέφει τον κόμβο που ακολουθεί αμέσως πριν από τον καθορισμένο στη λίστα [`childNodes`](../firstchild/) του γονέα του, ή null εάν ο καθορισμένος κόμβος είναι ο πρώτος σε αυτή τη λίστα.

```java
public Node PreviousSibling { get; }
```

### Property Value

Ένα [`Node`](../) που αντιπροσωπεύει το προηγούμενο αδερφικό στοιχείο του τρέχοντος κόμβου, ή null εάν δεν υπάρχουν.
