## Node.NextSibling property

Η ιδιότητα μόνο για ανάγνωση nextSibling της διεπαφής [`Node`](../) επιστρέφει τον κόμβο που ακολουθεί αμέσως τον καθορισμένο στον γονέα του [`childNodes`](../childnodes/), ή επιστρέφει null εάν ο καθορισμένος κόμβος είναι το τελευταίο παιδί στο γονικό στοιχείο.

```java
public Node NextSibling { get; }
```

### Property Value

Ένα [`Node`](../) που αντιπροσωπεύει τον επόμενο αδελφό του τρέχοντος κόμβου, ή null εάν δεν υπάρχουν.
