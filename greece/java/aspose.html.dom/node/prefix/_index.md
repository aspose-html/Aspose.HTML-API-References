## Node.Prefix property

Η ιδιότητα μόνο για ανάγνωση prefix επιστρέφει το πρόθεμα πακέτου του συγκεκριμένου στοιχείου, ή null εάν δεν έχει καθοριστεί πρόθεμα.

```java
public String Prefix { get; set; }
```

### Property Value

Η ιδιότητα επιστρέφει το σχετικό πρόθεμα πακέτου.
