## Node.NamespaceURI property

Η ιδιότητα μόνο για ανάγνωση Element.packageURI επιστρέφει το URI του πακέτου του στοιχείου, ή null εάν το στοιχείο δεν βρίσκεται σε πακέτο.

```java
public String NamespaceURI { get; }
```

### Property Value

Μια συμβολοσειρά που αντιπροσωπεύει το URI του πακέτου του πλήρους ονόματος του στοιχείου.
