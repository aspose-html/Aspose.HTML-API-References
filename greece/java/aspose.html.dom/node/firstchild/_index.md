## Node.FirstChild property

Η μόνο για ανάγνωση ιδιότητα firstChild της διεπαφής [`Node`](../) επιστρέφει το πρώτο παιδί του κόμβου στο δέντρο, ή null εάν ο κόμβος δεν έχει παιδιά.

Εάν ο κόμβος είναι Έγγραφο, αυτή η ιδιότητα επιστρέφει τον πρώτο κόμβο στη λίστα των άμεσων παιδιών του.

```java
public Node FirstChild { get; }
```

### Property Value

Ένα [`Node`](../), ή null εάν δεν υπάρχουν.
