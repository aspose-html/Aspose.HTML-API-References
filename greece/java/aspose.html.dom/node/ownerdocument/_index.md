## Node.OwnerDocument property

Η ιδιότητα μόνο για ανάγνωση ownerDocument της διεπαφής Node επιστρέφει το αντικείμενο εγγράφου ανώτερου επιπέδου του κόμβου.

```java
public Document OwnerDocument { get; }
```

### Property Value

Ένα [`Document`](../../document/) που είναι το αντικείμενο ανώτερου επιπέδου στο οποίο δημιουργούνται όλοι οι υποκόμβοι.

Εάν αυτή η ιδιότητα χρησιμοποιηθεί σε έναν κόμβο που είναι ο ίδιος ένα έγγραφο, η τιμή είναι null.
