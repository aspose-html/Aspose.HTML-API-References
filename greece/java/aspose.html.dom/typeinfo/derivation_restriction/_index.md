## TypeInfo.DERIVATION_RESTRICTION field

Εάν το σχήμα του εγγράφου είναι ένα XML Schema [XML Schema Part 1], αυτή η σταθερά αντιπροσωπεύει την παράγωγο μέσω περιορισμού εάν εμπλέκονται σύνθετοι τύποι, ή έναν περιορισμό εάν εμπλέκονται απλοί τύποι.

```java
public const ulong DERIVATION_RESTRICTION;
```
