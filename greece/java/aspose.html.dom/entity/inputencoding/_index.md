## Entity.InputEncoding property

Ένα χαρακτηριστικό που καθορίζει την κωδικοποίηση που χρησιμοποιείται για αυτήν την οντότητα κατά την ανάλυση, όταν είναι εξωτερική αναλυμένη οντότητα. Είναι null εάν πρόκειται για οντότητα από το εσωτερικό υποσύνολο ή εάν δεν είναι γνωστή.

```java
public String InputEncoding { get; }
```

### Property Value

Η κωδικοποίηση εισόδου.
