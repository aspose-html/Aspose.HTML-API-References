## Document.StrictErrorChecking property

Ένα χαρακτηριστικό που καθορίζει εάν η έλεγχος σφαλμάτων επιβάλλεται ή όχι. Όταν οριστεί σε false, η υλοποίηση είναι ελεύθερη να μην δοκιμάσει κάθε πιθανή περίπτωση σφάλματος που ορίζεται κανονικά στις λειτουργίες DOM, και να μην προκαλέσει καμία DOMException στις λειτουργίες DOM ή να αναφέρει σφάλματα κατά τη χρήση του Document.normalizeDocument(). Σε περίπτωση σφάλματος, η συμπεριφορά είναι ακαθόριστη. Αυτό το χαρακτηριστικό είναι true εξ ορισμού.

```java
public bool StrictErrorChecking { get; set; }
```

### Property Value

`true` εάν είναι ενεργός ο αυστηρός έλεγχος σφαλμάτων· διαφορετικά, `false`.
