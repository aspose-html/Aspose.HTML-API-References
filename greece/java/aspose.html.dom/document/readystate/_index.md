## Document.ReadyState property

Επιστρέφει την ετοιμότητα του εγγράφου. Το "loading" ενώ το Document φορτώνεται, "interactive" όταν ολοκληρωθεί η ανάλυση αλλά εξακολουθούν να φορτώνονται υπο-πόροι, και "complete" όταν έχει φορτωθεί.

```java
public String ReadyState { get; }
```
