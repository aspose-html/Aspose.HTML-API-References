## Document.CreateAttributeNS method

Η μέθοδος Document.createAttribute() δημιουργεί έναν νέο κόμβο χαρακτηριστικού και τον επιστρέφει. Το αντικείμενο δημιουργεί έναν κόμβο που υλοποιεί το interface [Attr](T:com.aspose.html.dom.Attr). Το DOM δεν επιβάλλει ποιο είδος χαρακτηριστικών μπορεί να προστεθεί σε ένα συγκεκριμένο στοιχείο με αυτόν τον τρόπο.

```java
public Attr CreateAttributeNS(String packageURI, String qualifiedName)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| packageURI | String | Το URI του πακέτου του χαρακτηριστικού. |
| qualifiedName | String | Το name είναι μια String που περιέχει το όνομα του χαρακτηριστικού. |
