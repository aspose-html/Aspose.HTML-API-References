## Document.DefaultView property

Το χαρακτηριστικό IDL defaultView της διεπαφής Document, κατά την ανάγνωση, πρέπει να επιστρέφει το αντικείμενο WindowProxy του περιβάλλοντος περιήγησης αυτού του Document, εάν το Document έχει συσχετισμένο περιβάλλον περιήγησης, ή null διαφορετικά.
