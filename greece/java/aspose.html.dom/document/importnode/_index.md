## Document.ImportNode method

Εισάγει έναν κόμβο από άλλο έγγραφο σε αυτό το έγγραφο, χωρίς να τροποποιήσει ή να αφαιρέσει τον κόμβο προέλευσης από το αρχικό έγγραφο· αυτή η μέθοδος δημιουργεί ένα νέο αντίγραφο του κόμβου προέλευσης.

```java
public Node ImportNode(Node importedNode, bool deep)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| importedNode | Node | Ο εισαγόμενος κόμβος. |
| βαθύ | Boolean | αν οριστεί σε `true` [deep]. |
