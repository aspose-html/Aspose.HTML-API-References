## Document.XmlVersion property

Ένα χαρακτηριστικό που καθορίζει, ως μέρος της δήλωσης XML, τον αριθμό έκδοσης αυτού του εγγράφου. Εάν δεν υπάρχει δήλωση και εάν αυτό το έγγραφο υποστηρίζει τη δυνατότητα "XML", η τιμή είναι "1.0". Εάν αυτό το έγγραφο δεν υποστηρίζει τη δυνατότητα "XML", η τιμή είναι πάντα null.

```java
public String XmlVersion { get; set; }
```

### Property Value

Η έκδοση XML.
