## IDOMImplementation.CreateDocumentType method

Δημιουργεί έναν κενό κόμβο DocumentType. Οι δηλώσεις οντοτήτων και οι σημειώσεις δεν διατίθενται. Οι επεκτάσεις αναφορών οντοτήτων και οι προσθήκες προεπιλεγμένων χαρακτηριστικών δεν πραγματοποιούνται.
