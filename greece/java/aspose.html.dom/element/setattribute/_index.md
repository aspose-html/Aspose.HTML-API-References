## Element.SetAttribute method

Προσθέτει ένα νέο attribute. Εάν ένα attribute με αυτό το όνομα υπάρχει ήδη στο element, η τιμή του αλλάζει ώστε να είναι η τιμή του παραμέτρου value.

```java
public void SetAttribute(String qualifiedName, String value)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| name | String | Το όνομα του χαρακτηριστικού. |
| value | String | Η τιμή. |
