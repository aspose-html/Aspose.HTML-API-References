## Element.AttachShadow method

Δημιουργεί σκιώδη ρίζα και την επισυνάπτει στο τρέχον στοιχείο.

```java
public ShadowRoot AttachShadow(ShadowRootMode mode)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| mode | ShadowRootMode | Λειτουργία με την οποία θα δημιουργηθεί το shadow root. |

### Τιμή Επιστροφής

Δημιουργήθηκε [`ShadowRoot`](../../shadowroot/).

### Εξαιρέσεις

| εξαίρεση | συνθήκη |
| --- | --- |
| Σφάλμα | NotSupportedError: Το Element δεν υποστηρίζει shadow tree. |
| Σφάλμα | InvalidStateError: Το Element έχει ήδη shadow tree. |
