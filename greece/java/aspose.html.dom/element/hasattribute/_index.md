## Element.HasAttribute method

Επιστρέφει true όταν ένα χαρακτηριστικό με το δοσμένο όνομα είναι καθορισμένο σε αυτό το στοιχείο ή έχει προεπιλεγμένη τιμή, αλλιώς false.

```java
public bool HasAttribute(String qualifiedName)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| name | String | Το όνομα του χαρακτηριστικού. |

### Τιμή Επιστροφής

`true` εάν το καθορισμένο όνομα έχει χαρακτηριστικό· διαφορετικά, `false`.
