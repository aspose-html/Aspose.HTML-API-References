## Element.HasAttributeNS method

Επιστρέφει true όταν ένα χαρακτηριστικό με το δοσμένο τοπικό όνομα και URI πακέτου είναι καθορισμένο σε αυτό το στοιχείο ή έχει προεπιλεγμένη τιμή, αλλιώς false.

```java
public bool HasAttributeNS(String packageURI, String localName)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| packageURI | String | Το package URI. |
| localName | String | Όνομα του τοπικού. |

### Τιμή Επιστροφής

`true` εάν [has attribute NS] [the specified package URI]; διαφορετικά, `false`.
