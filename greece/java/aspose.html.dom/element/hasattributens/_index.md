## Element.HasAttributeNS method

Επιστρέφει true όταν ένα χαρακτηριστικό με το δεδομένο τοπικό όνομα και URI πακέτου είναι καθορισμένο σε αυτό το στοιχείο ή έχει προεπιλεγμένη τιμή, διαφορετικά false.

```java
public bool HasAttributeNS(String packageURI, String localName)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| packageURI | String | Το URI του πακέτου. |
| localName | String | Όνομα του τοπικού. |

### Τιμή επιστροφής

`true` αν [has attribute NS] [the specified package URI]; διαφορετικά, `false`.
