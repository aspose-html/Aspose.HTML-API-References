## ToggleAttribute(String) {#toggleattribute}

Εάν δεν δοθεί το force, «εναλλάσσει» το qualifiedName, αφαιρώντας το αν υπάρχει και προσθέτοντάς το αν δεν υπάρχει. Εάν το force είναι true, προσθέτει το qualifiedName. Εάν το force είναι false, αφαιρεί το qualifiedName.

```java
public bool ToggleAttribute(String qualifiedName)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| qualifiedName | String | Το χαρακτηριστικό QualifiedName. |

### Τιμή Επιστροφής

Επιστρέφει true εάν το qualifiedName είναι τώρα παρόν· διαφορετικά false.
