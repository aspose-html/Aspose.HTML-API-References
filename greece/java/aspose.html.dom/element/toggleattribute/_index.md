## ToggleAttribute(String) {#toggleattribute}

Εάν δεν δοθεί το force, κάνει "toggles" το qualifiedName, αφαιρώντας το εάν υπάρχει και προσθέτοντάς το εάν δεν υπάρχει. Εάν το force είναι true, προσθέτει το qualifiedName. Εάν το force είναι false, αφαιρεί το qualifiedName.

```java
public bool ToggleAttribute(String qualifiedName)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| qualifiedName | String | Το χαρακτηριστικό QualifiedName. |

### Τιμή επιστροφής

Επιστρέφει true εάν το qualifiedName είναι τώρα παρόν· διαφορετικά false.
