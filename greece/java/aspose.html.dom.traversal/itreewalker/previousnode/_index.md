## ITreeWalker.PreviousNode method

Μετακινεί το TreeWalker στον προηγούμενο ορατό κόμβο με τη σειρά του εγγράφου σε σχέση με τον τρέχοντα κόμβο και επιστρέφει τον νέο κόμβο. Εάν ο τρέχων κόμβος δεν έχει προηγούμενο κόμβο ή εάν η αναζήτηση για previousNode προσπαθήσει να ανέβει από τον ριζικό κόμβο του TreeWalker, επιστρέφει null και διατηρεί τον τρέχοντα κόμβο.

```java
public Node PreviousNode()
```

### Τιμή επιστροφής

Ο νέος κόμβος, ή null εάν ο τρέχων κόμβος δεν έχει προηγούμενο κόμβο στην λογική προβολή του TreeWalker.
