## ITreeWalker.NextNode method

Εάν ο τρέχων κόμβος δεν έχει επόμενο κόμβο, ή εάν η αναζήτηση για nextNode προσπαθήσει να ανέβει από τον ριζικό κόμβο του TreeWalker, επιστρέφει null και διατηρεί τον τρέχοντα κόμβο.

```java
public Node NextNode()
```

### Τιμή επιστροφής

Ο νέος κόμβος, ή null εάν ο τρέχων κόμβος δεν έχει επόμενο κόμβο στην λογική προβολή του TreeWalker.
