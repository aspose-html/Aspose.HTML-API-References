## ITreeWalker.PreviousSibling method

Μετακινεί το TreeWalker στον προηγούμενο αδερφό του τρέχοντος κόμβου και επιστρέφει τον νέο κόμβο. Εάν ο τρέχων κόμβος δεν έχει ορατό προηγούμενο αδερφό, επιστρέφει null και διατηρεί τον τρέχοντα κόμβο.

```java
public Node PreviousSibling()
```

### Τιμή επιστροφής

Ο νέος κόμβος, ή null εάν ο τρέχων κόμβος δεν έχει προηγούμενο αδερφό στην λογική προβολή του TreeWalker.
