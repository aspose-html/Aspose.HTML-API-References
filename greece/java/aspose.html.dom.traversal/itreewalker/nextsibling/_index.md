## ITreeWalker.NextSibling method

Μετακινεί το TreeWalker στον επόμενο αδερφό του τρέχοντος κόμβου και επιστρέφει τον νέο κόμβο. Εάν ο τρέχων κόμβος δεν έχει ορατό επόμενο αδερφό, επιστρέφει null και διατηρεί τον τρέχοντα κόμβο.

```java
public Node NextSibling()
```

### Τιμή Επιστροφής

Ο νέος κόμβος, ή null εάν ο τρέχων κόμβος δεν έχει επόμενο αδερφό στην λογική προβολή του TreeWalker.
