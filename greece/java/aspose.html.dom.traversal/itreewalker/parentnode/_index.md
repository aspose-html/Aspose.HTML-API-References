## ITreeWalker.ParentNode method

Μετακινείται και επιστρέφει τον πλησιέστερο ορατό γονικό κόμβο του τρέχοντος κόμβου. Εάν η αναζήτηση για parentNode προσπαθήσει να ανέβει από τον ριζικό κόμβο του TreeWalker, ή εάν δεν βρει ορατό γονικό κόμβο, αυτή η μέθοδος διατηρεί τη τρέχουσα θέση και επιστρέφει null.

```java
public Node ParentNode()
```

### Τιμή επιστροφής

Ο νέος γονικός κόμβος, ή null εάν ο τρέχων κόμβος δεν έχει γονέα στην λογική προβολή του TreeWalker.
