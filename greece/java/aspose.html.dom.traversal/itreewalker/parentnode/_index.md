## ITreeWalker.ParentNode method

Μετακινείται και επιστρέφει τον πλησιέστερο ορατό πρόγονο του τρέχοντος κόμβου. Εάν η αναζήτηση για τον γονικό κόμβο προσπαθήσει να ανέβει από τον ριζικό κόμβο του TreeWalker, ή εάν αποτύχει να βρει ορατό πρόγονο, αυτή η μέθοδος διατηρεί την τρέχουσα θέση και επιστρέφει null.

```java
public Node ParentNode()
```

### Τιμή Επιστροφής

Ο νέος γονικός κόμβος, ή null εάν ο τρέχων κόμβος δεν έχει γονέα στην λογική προβολή του TreeWalker.
