## INodeIterator.PointerBeforeReferenceNode property

Η τιμή αυτής της σημαίας καθορίζει αν τα παιδιά των κόμβων αναφοράς οντοτήτων είναι ορατά στον επαναλήπτη. Εάν είναι false, αυτά και οι απογόνους τους θα απορρίπτονται. Σημειώστε ότι αυτή η απόρριψη έχει προτεραιότητα έναντι του whatToShow και του φίλτρου. Επίσης, σημειώστε ότι αυτή είναι προς το παρόν η μόνη κατάσταση όπου οι NodeIterators μπορούν να απορρίψουν ολόκληρο υποδέντρο αντί να παραλείπουν μεμονωμένους κόμβους. Για να δημιουργήσετε μια προβολή του εγγράφου με επεκταμένες αναφορές οντοτήτων και χωρίς να εκθέτετε τον ίδιο τον κόμβο αναφοράς οντότητας, χρησιμοποιήστε τις σημαίες whatToShow για να κρύψετε τον κόμβο αναφοράς οντότητας και ορίστε expandEntityReferences σε true κατά τη δημιουργία του επαναλήπτη. Για να δημιουργήσετε μια προβολή του εγγράφου με κόμβους αναφοράς οντοτήτων αλλά χωρίς επέκταση οντοτήτων, χρησιμοποιήστε τις σημαίες whatToShow για να εμφανίσετε τον κόμβο αναφοράς οντότητας και ορίστε expandEntityReferences σε false.

```java
public bool PointerBeforeReferenceNode { get; }
```

### Property Value

`true` εάν [expand entity references]; διαφορετικά, `false`.
