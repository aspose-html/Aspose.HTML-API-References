Επιστρέφει τον επόμενο κόμβο στο σύνολο και προχωρά τη θέση του iterator στο σύνολο. Μετά τη δημιουργία ενός NodeIterator, η πρώτη κλήση στο nextNode() επιστρέφει τον πρώτο κόμβο στο σύνολο.

### Τιμή Επιστροφής

Ο επόμενος κόμβος στο σύνολο που επεξεργάζεται, ή null εάν δεν υπάρχουν άλλα μέλη σε αυτό το σύνολο.
