Το πακέτο **com.aspose.html.rendering.pdf** παρέχει συγκεκριμένη κλάση συσκευής καθώς και μερικές κλάσεις επιλογών απόδοσης υπεύθυνες για την απόδοση σε έγγραφο pdf.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [PdfDevice](./pdfdevice/) | Αντιπροσωπεύει την απόδοση σε ένα pdf έγγραφο. |
| [PdfDocumentInfo](./pdfdocumentinfo/) | Αντιπροσωπεύει τις πληροφορίες σχετικά με το PDF έγγραφο. |
| [PdfRenderingOptions](./pdfrenderingoptions/) | Αντιπροσωπεύει τις επιλογές απόδοσης για [`PdfDevice`](../com.aspose.html.rendering.pdf/pdfdevice/). |
## Απαρίθμηση

| Απαρίθμηση | Περιγραφή |
| --- | --- |
| [FormFieldBehaviour](./formfieldbehaviour/) | Αυτή η απαρίθμηση χρησιμοποιείται για τον καθορισμό της συμπεριφοράς των πεδίων φόρμας στο τελικό PDF έγγραφο. |
