Το **com.aspose.html.net.headers** παρέχει μερικές κλάσεις δεδομένων για την περιγραφή του περιεχομένου των κεφαλίδων στο δίκτυο.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [ContentDispositionHeaderValue](./contentdispositionheadervalue/) | Αναπαριστά την τιμή της κεφαλίδας Content-Disposition. |
| [ContentTypeHeaderValue](./contenttypeheadervalue/) | Αντιπροσωπεύει την τιμή της κεφαλίδας Content-Type. |
| [NameValueHeaderValue](./namevalueheadervalue/) | Αντιπροσωπεύει ένα ζεύγος όνομα/τιμή που περιγράφει μια τιμή κεφαλίδας. |
