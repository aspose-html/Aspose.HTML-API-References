## MarkdownFeatures enumeration

Ένα σύνολο σημαιών `MarkdownFeatures` είναι ένα σύνολο από μηδέν ή περισσότερες από τις παρακάτω σημαιές, που χρησιμοποιούνται για την επιλογή στοιχείων που μετατρέπονται σε markdown.

```java
[Flags]
public enum MarkdownFeatures
```

### Τιμές

| Όνομα | Τιμή | Περιγραφή |
| --- | --- | --- |
| InlineHTML | `1` | Αυτή η σημαιά ενεργοποιεί την ενσωμάτωση στοιχείων HTML. Εάν αυτή η σημαιά είναι ορισμένη, τότε τα στοιχεία επιπέδου μπλοκ (όπως `div`) των οποίων η τιμή του χαρακτηριστικού `markdown` είναι `inline` θα εισαχθούν στο τελικό markdown. |
| AutomaticParagraph | `2` | Αυτή η σημαιά ενεργοποιεί τη μετατροπή των στοιχείων `paragraph`. Το περιεχόμενο τέτοιων στοιχείων θα τοποθετηθεί σε ξεχωριστές γραμμές, ώστε οι επεξεργαστές markdown να το περιτυλίξουν. |
| Header | `4` | Αυτή η σημαιά ενεργοποιεί τη μετατροπή των στοιχείων `header`. |
| Blockquote | `8` | Αυτή η σημαιά ενεργοποιεί τη μετατροπή των στοιχείων `blockquote`. |
| List | `10` | Αυτή η σημαιά ενεργοποιεί τη μετατροπή των στοιχείων `list`. |
| CodeBlock | `20` | Αυτή η σημαιά ενεργοποιεί τη μετατροπή των μπλοκ κώδικα. Ένα μπλοκ κώδικα αποτελείται από 2 στοιχεία `pre` και `code`, το περιεχόμενο μιας τέτοιας κατασκευής επεξεργάζεται "as is". |
| HorizontalRule | `40` | Αυτή η σημαιά ενεργοποιεί τη μετατροπή των `horizontal rules`. |
| Link | `80` | Αυτή η σημαιά ενεργοποιεί τη μετατροπή των στοιχείων `a`. |
| Emphasis | `100` | Αυτή η σημαία ενεργοποιεί τη μετατροπή των στοιχείων `emphasis`. |
| InlineCode | `200` | Αυτή η σημαία ενεργοποιεί τη μετατροπή των στοιχείων `code`. |
| Image | `400` | Αυτή η σημαία ενεργοποιεί τη μετατροπή των στοιχείων `img`. |
| LineBreak | `800` | Αυτή η σημαία ενεργοποιεί τη μετατροπή των στοιχείων `br`. |
| Video | `1000` | Αυτή η σημαία ενεργοποιεί τη μετατροπή των στοιχείων `video`. |
| Table | `2000` | Αυτή η σημαία ενεργοποιεί τη μετατροπή των στοιχείων `table`. |
| TaskList | `4000` | Αυτή η σημαία ενεργοποιεί τη μετατροπή των λιστών εργασιών. Η λίστα εργασιών αποτελείται από το στοιχείο `input`, το οποίο πρέπει να είναι το πρώτο παιδί του στοιχείου `list` και η τιμή του χαρακτηριστικού `type` πρέπει να είναι `checkbox`. |
| Strikethrough | `8000` | Αυτή η σημαία ενεργοποιεί τη μετατροπή των στοιχείων `del`. |
| Strong | `10000` | Αυτή η σημαία ενεργοποιεί τη μετατροπή των στοιχείων `strong`. |
