Το πακέτο **com.aspose.html.saving** παρουσιάζεται από κλάσεις δεδομένων για την περιγραφή συγκεκριμένων επιλογών αποθήκευσης στη διαδικασία μετατροπής/αποθήκευσης.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [DocSaveOptions](./docsaveoptions/) | Συγκεκριμένη κλάση δεδομένων επιλογών. Αναθέτοντας ιδιότητες, μπορείτε να διαχειριστείτε χαρακτηριστικά απόδοσης όπως η ανάλυση, το μέγεθος σελίδας, το χρώμα φόντου καθώς και ειδικές επιλογές εγγράφου όπως η ενσωμάτωση γραμματοσειρών. Περισσότερες πληροφορίες στη τεκμηρίωση [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-docx/#save-options). |
| [HTMLSaveOptions](./htmlsaveoptions/) | Αναπαριστά τις επιλογές αποθήκευσης HTML. Αναθέτοντας συγκεκριμένες ιδιότητες, μπορείτε να διαχειριστείτε την επεξεργασία πόρων όπως το μέγιστο βάθος διαχείρισης κ.λπ. Περισσότερες πληροφορίες στη τεκμηρίωση [article](https://docs.aspose.com/html/net/working-with-documents/saving-a-document/). |
| [ImageSaveOptions](./imagesaveoptions/) | Συγκεκριμένη κλάση δεδομένων επιλογών. Παρέχει ιδιότητες για τη διαχείριση της ανάλυσης του αποτελέσματος εικόνας, της ποιότητας εξομάλυνσης, της μορφής καθώς και των ρυθμίσεων σελίδας κ.ά. Περισσότερες πληροφορίες μπορείτε να βρείτε στην τεκμηρίωση [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-jpg/#save-options). |
| [MarkdownSaveOptions](./markdownsaveoptions/) | Αναπαριστά τις επιλογές αποθήκευσης Markdown. Για παράδειγμα, μπορείτε να ορίσετε το στυλ μορφοποίησης markdown, να χρησιμοποιήσετε προκαθορισμένες συμβατές επιλογές GitLab Flavored Markdown και να διαμορφώσετε τη διαχείριση πόρων. Ανατρέξτε σε περισσότερες πληροφορίες στο [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-markdown/#save-options). |
| [MHTMLSaveOptions](./mhtmlsaveoptions/) | Αναπαριστά τις επιλογές αποθήκευσης MHTML. Αναθέτοντας συγκεκριμένες ιδιότητες, μπορείτε να διαχειριστείτε την επεξεργασία πόρων όπως το μέγιστο βάθος διαχείρισης κ.λπ. Περισσότερες πληροφορίες στη τεκμηρίωση [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-mhtml/#save-options). |
| [PdfSaveOptions](./pdfsaveoptions/) | Συγκεκριμένη κλάση δεδομένων παρέχει λίγες ιδιότητες για τη διαχείριση του αποτελέσματος μετατροπής. Για παράδειγμα, το [`PageSetup`](../com.aspose.html.rendering/pagesetup/) καθορίζει τα χαρακτηριστικά της σελίδας. Ανατρέξτε στην τεκμηρίωση [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-pdf/#convert-html-to-pdf-using-pdfsaveoptions). |
| [Resource](./resource/) | Αυτή η κλάση περιγράφει έναν πόρο και παρέχει μεθόδους για την επεξεργασία του. |
| [ResourceHandlingContext](./resourcehandlingcontext/) | Αυτή η κλάση περιέχει πληροφορίες που χρησιμοποιούνται κατά την επεξεργασία πόρων. |
| [ResourceHandlingOptions](./resourcehandlingoptions/) | Αναπαριστά τις επιλογές διαχείρισης πόρων. |
| [SaveOptions](./saveoptions/) | Αυτή είναι μια αφηρημένη βασική κλάση για κλάσεις που επιτρέπουν στον χρήστη να καθορίσει πρόσθετες επιλογές κατά την αποθήκευση ενός εγγράφου σε συγκεκριμένη μορφή. |
| [TextSaveOptions](./textsaveoptions/) | Αναπαριστά τις επιλογές αποθήκευσης κειμένου |
| [XpsSaveOptions](./xpssaveoptions/) | Συγκεκριμένη κλάση δεδομένων επιλογών παρέχει λίγες ιδιότητες για τη διαχείριση του αποτελέσματος μετατροπής. Για παράδειγμα, το [`PageSetup`](../com.aspose.html.rendering/pagesetup/) καθορίζει τα χαρακτηριστικά της σελίδας. Ανατρέξτε στην τεκμηρίωση [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-xps/#save-options). |
## Απαρίθμηση

| Απαρίθμηση | Περιγραφή |
| --- | --- |
| [HTMLSaveFormat](./htmlsaveformat/) | Καθορίζει τη μορφή στην οποία αποθηκεύεται το έγγραφο. Μπορείτε να βρείτε περισσότερες πληροφορίες για την αποθήκευση του [`HTMLDocument`](../com.aspose.html/htmldocument/) στο [article](https://docs.aspose.com/html/net/working-with-documents/saving-a-document/). |
| [MarkdownFeatures](./markdownfeatures/) | Ένα σύνολο σημαίας [`MarkdownFeatures`](../com.aspose.html.saving/markdownfeatures/) είναι ένα σύνολο μηδέν ή περισσότερων από τις παρακάτω σημαίες, που χρησιμοποιούνται για την επιλογή στοιχείων που μετατρέπονται σε markdown. |
| [MarkdownFormatter](./markdownformatter/) | Καθορίζει τον τρόπο μορφοποίησης της εξόδου. |
| [ResourceHandling](./resourcehandling/) | Αυτή η απαρίθμηση αντιπροσωπεύει επιλογές διαχείρισης πόρων. |
| [ResourceStatus](./resourcestatus/) | Δείχνει την κατάσταση του πόρου. |
| [UrlRestriction](./urlrestriction/) | Αυτή η απαρίθμηση αντιπροσωπεύει περιορισμό που εφαρμόζεται στα URL των επεξεργασμένων πόρων. |
