## TextSaveOptions.EnableListItemMarkers property

Επιλογή που εφαρμόζεται στα στοιχεία OL, UL κατά τη μετατροπή HTML σε κείμενο. Στην πραγματικότητα, ορίζει πώς να επεξεργαστεί τους εξωτερικούς δείκτες λίστας των στοιχείων OL και UL. Εάν είναι true, προστίθενται αριθμοί στοιχείων πριν από τα στοιχεία OL ή τελείες πριν από τα στοιχεία UL. Εάν είναι false, δεν προστίθενται (προεπιλεγμένη συμπεριφορά σύμφωνα με την προδιαγραφή).

```java
public bool EnableListItemMarkers { get; set; }
```
