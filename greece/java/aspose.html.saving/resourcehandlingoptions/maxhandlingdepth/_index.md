## ResourceHandlingOptions.MaxHandlingDepth property

Λαμβάνει ή ορίζει το μέγιστο βάθος των σελίδων που θα υποβληθούν σε επεξεργασία. Βάθος 1 σημαίνει ότι θα υποβληθούν σε επεξεργασία μόνο οι σελίδες που αναφέρονται άμεσα από το αποθηκευμένο έγγραφο. Ορίζοντας αυτήν την ιδιότητα σε -1 θα οδηγήσει στην επεξεργασία όλων των σελίδων. Η προεπιλεγμένη τιμή είναι 0.

```java
public int MaxHandlingDepth { get; set; }
```
