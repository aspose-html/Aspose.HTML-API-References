## InputElement.SetColorValue method

Αυτή η μέθοδος χρησιμοποιείται για να ορίσει το χρώμα ως τιμή για το στοιχείο εισόδου. Η μέθοδος είναι έγκυρη εάν ο τύπος του στοιχείου εισόδου είναι "color".

```java
public void SetColorValue(Color value)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| value | Color | Το αντικείμενο χρώματος. |
