## InputElement.SetMonthValue method

Αυτή η μέθοδος χρησιμοποιείται για τον ορισμό ενός αντικειμένου DateTime ως τιμή για το στοιχείο εισόδου. Η μέθοδος είναι έγκυρη μόνο εάν ο τύπος του στοιχείου εισόδου είναι "month".

```java
public void SetMonthValue(DateTime value)
```

| τιμή | DateTime | Το αντικείμενο ημερομηνίας. |
