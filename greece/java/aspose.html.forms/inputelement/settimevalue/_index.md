## InputElement.SetTimeValue method

Αυτή η μέθοδος χρησιμοποιείται για να ορίσει ένα αντικείμενο TimeSpan ως τιμή για το στοιχείο εισόδου. Η μέθοδος είναι έγκυρη εάν ο τύπος του στοιχείου εισόδου είναι "time".

```java
public void SetTimeValue(TimeSpan value)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| value | TimeSpan | Το αντικείμενο TimeSpan. |
