## InputElement.SetTimeValue method

Αυτή η μέθοδος χρησιμοποιείται για τον ορισμό ενός αντικειμένου TimeSpan ως τιμή για το στοιχείο εισόδου. Η μέθοδος είναι έγκυρη μόνο εάν ο τύπος του στοιχείου εισόδου είναι "time".

```java
public void SetTimeValue(TimeSpan value)
```

| τιμή | TimeSpan | Το αντικείμενο TimeSpan. |
