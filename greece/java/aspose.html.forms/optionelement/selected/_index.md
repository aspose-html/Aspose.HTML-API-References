## OptionElement.Selected property

Αντιπροσωπεύει την τρέχουσα κατάσταση του αντίστοιχου στοιχείου ελέγχου φόρμας, σε έναν διαδραστικό πράκτορα χρήστη. Η αλλαγή αυτού του χαρακτηριστικού αλλάζει την κατάσταση του στοιχείου ελέγχου φόρμας, αλλά δεν αλλάζει την τιμή του χαρακτηριστικού selected του HTML του στοιχείου.

```java
public bool Selected { get; set; }
```
