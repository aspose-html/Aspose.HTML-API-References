Το πακέτο παρέχει πρόσβαση σε πολυάριθμα αντικείμενα (στοιχεία) που είναι υπεύθυνα για την αλληλεπίδραση του χρήστη μέσα σε φόρμα ως στοιχείο ιστοσελίδας.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [ButtonElement](./buttonelement/) | Το ButtonElement αντιπροσωπεύει ένα περιτύλιγμα που σχετίζεται με το HTMLButtonElement. |
| [DataListElement](./datalistelement/) | Το DataListElement αντιπροσωπεύει ένα περιτύλιγμα που σχετίζεται με το HTMLDataListElement. |
| [FormEditor](./formeditor/) | Αυτή η κλάση αντιπροσωπεύει τον επεξεργαστή πάνω στο [`HTMLFormElement`](../com.aspose.html/htmlformelement/) που δημιουργεί έναν πιο εύκολο τρόπο για τους .net προγραμματιστές να επεξεργάζονται τις HTML φόρμες. |
| [FormElement](./formelement/) | Αντιπροσωπεύει τη βασική κλάση για στοιχεία φόρμας. |
| [FormElement&lt;T&gt;](./formelement-1/) | Το [`FormElement`](../com.aspose.html.forms/formelement/) αντιπροσωπεύει το γενικό πεδίο. |
| [FormSubmitter](./formsubmitter/) | Αυτή η κλάση επιτρέπει την προετοιμασία του καθορισμένου [`HTMLFormElement`](../com.aspose.html/htmlformelement/), συλλέγει τιμές από το στοιχείο φόρμας, τις υποβάλλει στον απομακρυσμένο διακομιστή και λαμβάνει μια απάντηση. |
| [InputElement](./inputelement/) | Το InputElement αντιπροσωπεύει ένα περιτύλιγμα που σχετίζεται με το HTMLInputElement. |
| [OptionCollection](./optioncollection/) | Το OptionElements αντιπροσωπεύει ένα περιτύλιγμα που σχετίζεται με το IHTMLOptionsCollection. |
| [OptionElement](./optionelement/) | Το OptionElement αντιπροσωπεύει ένα περιτύλιγμα που σχετίζεται με το HTMLOptionElement. |
| [SelectElement](./selectelement/) | Το SelectElement αντιπροσωπεύει ένα περιτύλιγμα που σχετίζεται με το HTMLSelectElement. |
| [SubmissionResult](./submissionresult/) | Αυτή η κλάση αντιπροσωπεύει το αποτέλεσμα της υποβολής δεδομένων φόρμας στον διακομιστή. |
| [TextAreaElement](./textareaelement/) | Το TextAreaElement αντιπροσωπεύει ένα περιτύλιγμα που σχετίζεται με το HTMLTextAreaElement. |
