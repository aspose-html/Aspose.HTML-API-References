## SelectElement.Multiple property

Εάν είναι true, μπορούν να επιλεγούν πολλαπλά στοιχεία `OPTION` σε αυτό το `SELECT`. Δείτε τον ορισμό του χαρακτηριστικού multiple στο HTML 4.01.

```java
public bool Multiple { get; set; }
```
