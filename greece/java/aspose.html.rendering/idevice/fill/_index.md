## IDevice.Fill method

Γεμίζει ολόκληρη την περιοχή που περιβάλλεται από το τρέχον μονοπάτι. Εάν το μονοπάτι αποτελείται από αρκετές αποσυνδεδεμένες υποδιαδρομές, γεμίζει τα εσωτερικά όλων των υποδιαδρομών, θεωρούμενα μαζί. Αυτή η μέθοδος τερματίζει το τρέχον μονοπάτι.

```java
public void Fill(FillRule rule)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| κανόνας | FillRule | Ο κανόνας γεμίσματος καθορίζει πώς γεμίζεται το εσωτερικό ενός κλειστού μονοπατιού |
