## AtPagePriority enumeration

Καθορίζει τις πιθανές σειρές εφαρμογής δηλώσεων μεγέθους σελίδας.

```java
public enum AtPagePriority
```

### Τιμές

| Όνομα | Τιμή | Περιγραφή |
| --- | --- | --- |
| OptionsPriority | `0` | Καθορίζει ότι οι τιμές του [`PageSetup`](../pagesetup/) που δηλώνονται στο [`RenderingOptions`](../renderingoptions/) θα αντικαταστήσουν τις τιμές που ορίζονται στο css από τους κανόνες `@page`. |
| CssPriority | `1` | Καθορίζει ότι οι κανόνες `@page` που ορίζονται στο css θα αντικαταστήσουν τις τιμές που ορίζονται στο [`PageSetup`](../pagesetup/). |
