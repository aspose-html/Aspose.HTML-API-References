## PageSetup.AdjustToWidestPage property

Λαμβάνει ή ορίζει τη σημαία που καθορίζει την περίπτωση όταν το μέγεθος σελίδας θα προσαρμοστεί στην πιο πλατιά σελίδα του εγγράφου. Αυτή η επιλογή είναι χρονοβόρα, έτσι ο χρόνος επεξεργασίας του εγγράφου μπορεί να αυξηθεί κατά δύο φορές. Η προσαρμογή θα γίνει μόνο εάν η πιο πλατιά σελίδα του εγγράφου είναι ευρύτερη από το μέγεθος σελίδας που καθορίζεται στο [`PageSetup`](../). Το προσαρμοσμένο μέγεθος σελίδας θα χρησιμοποιηθεί για όλες τις σελίδες του εγγράφου.

```java
public bool AdjustToWidestPage { get; set; }
```
