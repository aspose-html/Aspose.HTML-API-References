Το πακέτο **com.aspose.html.rendering** αποτελείται από πολυάριθμα αντικείμενα αποδίκτη καθώς και κατάλληλες κλάσεις επιλογών χαμηλού επιπέδου που είναι υπεύθυνες για την απόδοση εγγράφων/αρχείων σε υλοποίηση IDevice.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [CssOptions](./cssoptions/) | Αναπαριστά τις επιλογές απόδοσης css. |
| [Device](./device/) | Αναπαριστά μια βασική κλάση για την υλοποίηση συσκευών απόδοσης που χρησιμοποιούνται για τη σχεδίαση γραφικών σε διάφορες μορφές και περιβάλλοντα. |
| [Device&lt;TGraphicContext,TRenderingOptions&gt;](./device-2/) | Αναπαριστά τη βασική κλάση για την υλοποίηση συγκεκριμένων συσκευών απόδοσης. |
| [EpubRenderer](./epubrenderer/) | Αναπαριστά έναν renderer εγγράφων EPub. |
| [GraphicContext](./graphiccontext/) | Διατηρεί τρέχοντες παραμέτρους ελέγχου γραφικών. Αυτές οι παράμετροι ορίζουν το παγκόσμιο πλαίσιο μέσα στο οποίο εκτελούνται οι τελεστές γραφικών. |
| [HtmlRenderer](./htmlrenderer/) | Αναπαριστά έναν renderer εγγράφου HTML. |
| [MhtmlRenderer](./mhtmlrenderer/) | Αναπαριστά έναν renderer εγγράφου MHTML. |
| [PageSetup](./pagesetup/) | Αναπαριστά ένα αντικείμενο ρύθμισης σελίδας που χρησιμοποιείται για τη διαμόρφωση του συνόλου εξόδου σελίδας. |
| [Renderer](./renderer/) | Αναπαριστά μια βασική κλάση για όλους τους renderers και υλοποιεί τη διεπαφή IDisposable. |
| [Renderer&lt;TSource&gt;](./renderer-1/) | Αναπαριστά μια αφηρημένη κλάση για όλους τους renderers. |
| [RenderingOptions](./renderingoptions/) | Αναπαριστά τις επιλογές απόδοσης. |
| [SvgRenderer](./svgrenderer/) | Αναπαριστά έναν renderer εγγράφου SVG. |
| [TextInfo](./textinfo/) | Περιέχει πληροφορίες σχετικά με το κείμενο που αποδόθηκε. |
