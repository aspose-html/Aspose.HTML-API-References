Το πακέτο **com.aspose.html.drawing** περιέχει αντικείμενα και διεπαφές για τον καθορισμό μετρήσεων και μονάδων, καθώς και αντικείμενα χαρακτηριστικών σχεδίασης όπως πινέλα, χρώματα και γραμματοσειρές.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [Angle](./angle/) | Ο τύπος δεδομένων γωνίας |
| [Color](./color/) | Η κλάση Color σας επιτρέπει να καθορίζετε χρώματα ως τιμές Red-Green-Blue (RGB), Hue-Saturation-Luminosity (HSL), Hue-Saturation-Value (HSV), Hue-Whiteness-Blackness (HWB), lightness-A-B (LAB), Luminance-Chroma-Hue (LCH), Cyan-Magenta-Yellow-Key (CMYK), Natural colors (NCOL) ή με όνομα χρώματος. Ένα κανάλι Alpha είναι επίσης διαθέσιμο για να υποδεικνύει διαφάνεια. |
| [Dimension](./dimension/) | Παρέχει τη βασική κλάση για διαστάσεις. Ο γενικός όρος 'διάσταση' αναφέρεται σε έναν αριθμό με μονάδα συνδεδεμένη σε αυτόν, και σημειώνονται από [`UnitType`](../com.aspose.html.drawing/unittype/). |
| [Frequency](./frequency/) | Η μονάδα 'frequency'. |
| [Length](./length/) | Αντιπροσωπεύει μια μονάδα μέτρησης μήκους. |
| [LengthOrAuto](./lengthorauto/) | Αντιπροσωπεύει ένα δοχείο για αποθήκευση μήκους ή μονάδων 'auto'. |
| [Margin](./margin/) | Αντιπροσωπεύει το περιθώριο σελίδας. |
| [Numeric](./numeric/) | Παρέχει τη βασική κλάση για αριθμητικούς τύπους. |
| [Page](./page/) | Αντιπροσωπεύει ένα αντικείμενο σελίδας που χρησιμοποιείται για τη διαμόρφωση της εξόδου σελίδας. Η προεπιλεγμένη τιμή για το μέγεθος σελίδας είναι A4 (210x297mm) |
| [Resolution](./resolution/) | Αντιπροσωπεύει μια μονάδα ανάλυσης. |
| [Size](./size/) | Αποθηκεύει τιμές που καθορίζουν Ύψος και Πλάτος. |
| [Time](./time/) | Αντιπροσωπεύει μια μονάδα χρόνου. |
| [Unit](./unit/) | Παρέχει τη βασική κλάση για μονάδες μέτρησης. |
| [UnitType](./unittype/) | Καθορίζει τη μονάδα μέτρησης. |

| [IDrawingFactory](./idrawingfactory/) | Αντιπροσωπεύει ένα εργοστάσιο για τη δημιουργία αντικειμένων σχετικών με τη σχεδίαση. |
| [IGradientBrush](./igradientbrush/) | Δηλώστε μεθόδους για την λήψη κοινών ιδιοτήτων των διαβαθμισμένων πινέλων. |
| [IInterpolationColor](./iinterpolationcolor/) | Δηλώνει μεθόδους για τη λήψη του χρώματος παρεμβολής. |
| [ILinearGradientBrush](./ilineargradientbrush/) | Ορίζει τη διεπαφή πινέλου με γραμμική διαβάθμιση. |
| [IMatrix](./imatrix/) | Αναπαριστά έναν πίνακα που χρησιμοποιείται για μετασχηματισμούς. |
| [ISolidBrush](./isolidbrush/) | Ορίζει τη διεπαφή πινέλου ενός ενιαίου χρώματος. |
| [ITextureBrush](./itexturebrush/) | Ορίζει τη διεπαφή πινέλου που χρησιμοποιεί μια εικόνα για να γεμίσει το εσωτερικό ενός σχήματος. |
| [ITransformableBrush](./itransformablebrush/) | Δηλώνει μεθόδους για τη λήψη του πίνακα μετασχηματισμού και της λειτουργίας περιτύλιξης. |
| [ITrueTypeFont](./itruetypefont/) | Δηλώνει μεθόδους για εργασία με γραμματοσειρά TrueType. |
