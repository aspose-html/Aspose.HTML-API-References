## SpreadMode enumeration

Καθορίζει πώς τοποθετείται ένα υφή ή διαβάθμιση όταν είναι μικρότερο από την περιοχή που γεμίζεται.

```java
public enum SpreadMode
```

### Τιμές

| Όνομα | Τιμή | Περιγραφή |
| --- | --- | --- |
| Tile | `0` | Η υφή ή η διαβάθμιση επαναλαμβάνεται. |
| TileFlipX | `1` | Η υφή ή η διαβάθμιση επαναλαμβάνεται και αναστρέφεται οριζόντια. |
| TileFlipY | `2` | Η υφή ή η διαβάθμιση επαναλαμβάνεται και αναστρέφεται κάθετα. |
| TileFlipXY | `3` | Η υφή ή η διαβάθμιση επαναλαμβάνεται και αναστρέφεται τόσο οριζόντια όσο και κάθετα. |
| Clamp | `4` | Η υφή ή η διαβάθμιση περιορίζεται στην άκρη. |
