## ITextureBrush.ImageArea property

Καθορίζει το τμήμα της εικόνας που χρησιμοποιείται από το πινέλο. Εάν ισούται με RectangleF.Empty, τότε θα χρησιμοποιηθεί ολόκληρη η εικόνα. Οι συντεταγμένες είναι σε εικονοστοιχεία.

public RectangleF ImageArea { get; }
