## ITrueTypeFont.SubFamilyName property

Το όνομα Font Subfamily διακρίνει τη γραμματοσειρά σε μια ομάδα με το ίδιο όνομα Font Family. Αυτό θεωρείται ότι καλύπτει το στυλ (italic, oblique) και το βάρος (light, bold, black, κ.). Μια γραμματοσειρά χωρίς ιδιαίτερες διαφορές στο βάρος ή το στυλ (π.χ. medium weight, όχι italic και το bit 6 του fsSelection ορισμένο) θα πρέπει να έχει το String \"Regular\" αποθηκευμένο σε αυτή τη θέση.

```java
public String SubFamilyName { get; }
```
