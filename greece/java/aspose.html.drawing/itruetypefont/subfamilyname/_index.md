## ITrueTypeFont.SubFamilyName property

Το όνομα υποοικογένειας γραμματοσειράς διακρίνει τη γραμματοσειρά σε μια ομάδα με το ίδιο όνομα οικογένειας γραμματοσειράς. Αυτό θεωρείται ότι καλύπτει το στυλ (italic, oblique) και το βάρος (light, bold, black, κλπ.). Μια γραμματοσειρά χωρίς ιδιαίτερες διαφορές στο βάρος ή το στυλ (π.χ. μεσαίο βάρος, χωρίς πλάγιο και με το bit 6 του fsSelection ορισμένο) θα πρέπει να έχει τη συμβολοσειρά "Regular" αποθηκευμένη σε αυτή τη θέση.

```java
public String SubFamilyName { get; }
```
