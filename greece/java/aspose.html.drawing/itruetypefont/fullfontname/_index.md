## ITrueTypeFont.FullFontName property

Αυτό πρέπει να είναι ένας συνδυασμός του "FamilyName" και του "SubFamilyName". Εξαίρεση: εάν η γραμματοσειρά είναι "Regular" όπως υποδεικνύεται στο "SubFamilyName", τότε χρησιμοποιήστε μόνο το όνομα οικογένειας που περιέχεται στο "FamilyName". Μια εξαίρεση στην παραπάνω ορισμό του πλήρους ονόματος γραμματοσειράς αφορά τις συμβολοσειρές πλατφόρμας Microsoft για γραμματοσειρές CFF OpenType: σε αυτήν την περίπτωση, η συμβολοσειρά Full font name πρέπει να είναι ταυτοτική με το PostScript FontName στο CFF Name INDEX.

public String FullFontName { get; }
