## FromRgb(byte, byte, byte) {#fromrgb}

Επιστρέφει ένα νέο Color με τις ζητούμενες τιμές ged, green, blue. Όλα τα συστατικά χρώματος πρέπει να είναι στο εύρος 0-255.

```java
public static Color FromRgb(byte red, byte green, byte blue)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| κόκκινο | Byte | Ένα byte που αντιπροσωπεύει το κόκκινο συστατικό του χρώματος. |
| πράσινο | Byte | Ένα byte που αντιπροσωπεύει το πράσινο συστατικό του χρώματος. |
| μπλε | Byte | Ένα byte που αντιπροσωπεύει το μπλε συστατικό του χρώματος. |
