## FromRgba(byte, byte, byte, byte) {#fromrgba}

Επιστρέφει ένα νέο Color με τις ζητούμενες τιμές ged, green, blue, alpha. Όλα τα συστατικά χρώματος πρέπει να είναι στο εύρος 0-255.

```java
public static Color FromRgba(byte red, byte green, byte blue, byte alpha)
```
