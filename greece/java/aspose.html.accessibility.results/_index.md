Το **com.aspose.html.accessibility.results** πακέτο περιέχει κλάσεις που περιγράφουν τα αποτελέσματα της επικύρωσης κανόνων.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [RuleValidationResult](./rulevalidationresult/) | Κλάση - αποτέλεσμα ελέγχου κανόνα, περιέχει μια λίστα από [`ITechniqueResult`](../com.aspose.html.accessibility/itechniqueresult/), που είναι τρόποι για την ικανοποίηση των κριτηρίων επιτυχίας. |
| [ValidationResult](./validationresult/) | Η κύρια κλάση αποτελέσματος, που περιέχει τα Results για όλα τα Criterion από το αντικείμενο AccessibilityRules. |
