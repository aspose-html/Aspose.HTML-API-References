Το πακέτο **com.aspose.html.rendering.doc** παρέχει συγκεκριμένη κλάση συσκευής καθώς και μερικές κλάσεις επιλογών απόδοσης υπεύθυνες για την απόδοση σε έγγραφο DOCX.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [DocDevice](./docdevice/) | Αντιπροσωπεύει την απόδοση σε έγγραφο DOCX. |
| [DocRenderingOptions](./docrenderingoptions/) | Αντιπροσωπεύει τις επιλογές απόδοσης για [`DocDevice`](../com.aspose.html.rendering.doc/docdevice/). |
## Απαρίθμηση

| Απαρίθμηση | Περιγραφή |
| --- | --- |
| [DocumentFormat](./documentformat/) | Αντιπροσωπεύει τη μορφή αρχείου του εξαγόμενου εγγράφου. |
| [FontEmbeddingRule](./fontembeddingrule/) | Αντιπροσωπεύει τους κανόνες ενσωμάτωσης γραμματοσειρών. |
