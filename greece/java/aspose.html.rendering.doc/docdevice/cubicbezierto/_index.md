## DocDevice.CubicBezierTo method

Προσθέτει μια κυβική καμπύλη Bézier στην τρέχουσα διαδρομή. Η καμπύλη εκτείνεται από το τρέχον σημείο μέχρι το σημείο pt2, χρησιμοποιώντας τα pt1 και pt2 ως σημεία ελέγχου Bézier. Το νέο τρέχον σημείο είναι το pt3.

```java
public void CubicBezierTo(PointF pt1, PointF pt2, PointF pt3)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| pt1 | PointF | Συντεταγμένες του πρώτου σημείου |
| pt2 | PointF | Συντεταγμένες του δεύτερου σημείου |
| pt3 | PointF | Συντεταγμένες του τρίτου σημείου |
