## DocDevice.MoveTo method

Ξεκινά μια νέα υποδιαδρομή μετακινώντας το τρέχον σημείο στις συντεταγμένες της παραμέτρου pt, παραλείποντας οποιοδήποτε συνδετικό τμήμα γραμμής. Εάν η προηγούμενη μέθοδος κατασκευής μονοπατιού στο τρέχον μονοπάτι ήταν επίσης "MoveTo", το νέο "MoveTo" το αντικαθιστά· δεν απομένει κανένα ίχνος της προηγούμενης λειτουργίας "MoveTo" στο μονοπάτι.

```java
public void MoveTo(PointF pt)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| pt | PointF | Σημείο στο οποίο θα μετακινηθεί το μονοπάτι. |
