## DocDevice.Fill method

Γεμίζει ολόκληρη την περιοχή που περιβάλλεται από την τρέχουσα διαδρομή. Εάν η διαδρομή αποτελείται από αρκετές αποσυνδεδεμένες υποδιαδρομές, γεμίζει τα εσωτερικά όλων των υποδιαδρομών, θεωρούμενα μαζί. Αυτή η μέθοδος τερματίζει την τρέχουσα διαδρομή.

```java
public void Fill(FillRule mode)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| mode | FillRule | Η λειτουργία γεμίσματος καθορίζει πώς γεμίζεται το εσωτερικό μιας κλειστής διαδρομής. |
