## FontEmbeddingRule enumeration

Αντιπροσωπεύει τους κανόνες ενσωμάτωσης γραμματοσειρών.

```java
public enum FontEmbeddingRule
```

### Τιμές

| Όνομα | Τιμή | Περιγραφή |
| --- | --- | --- |
| Full | `1` | Όλες οι χρησιμοποιημένες γραμματοσειρές θα ενσωματωθούν όπως είναι. Να έχετε υπόψη ότι ορισμένες γραμματοσειρές μπορεί να είναι αδειοδοτημένες, κάτι που θα κάνει το τελικό έγγραφο μη επεξεργάσιμο. Επίσης, τα ενσωματωμένα αρχεία γραμματοσειρών μπορεί να αυξήσουν σημαντικά το μέγεθος του τελικού εγγράφου. |
| None | `2` | Οι γραμματοσειρές δεν θα ενσωματωθούν. |
