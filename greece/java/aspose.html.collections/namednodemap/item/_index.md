## NamedNodeMap indexer (1 of 2)

Επιστρέφει το στοιχείο με δείκτη index στο χάρτη. Εάν το index είναι μεγαλύτερο ή ίσο με τον αριθμό των κόμβων σε αυτόν τον χάρτη, επιστρέφει null.

```java
public Attr this[int index] { get; }
```

| Παράμετρος | Περιγραφή |
| --- | --- |
| index | Ο δείκτης. |
