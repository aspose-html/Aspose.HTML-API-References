Το **com.aspose.html.collections** πακέτο αποτελείται από κλάσεις για την αναπαράσταση, αποθήκευση και διαχείριση κόμβων και στοιχείων.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [DOMTokenList](./domtokenlist/) | Η κλάση DOMTokenList αντιπροσωπεύει ένα σύνολο διαχωρισμένων διαστήματος διακριτικών. Είναι ευρετηριασμένη ξεκινώντας από το 0 όπως στα αντικείμενα JavaScript Array. Η DOMTokenList είναι πάντα ευαίσθητη σε πεζά/κεφαλαία. |
| [HTMLCollection](./htmlcollection/) | Η [`HTMLCollection`](../com.aspose.html.collections/htmlcollection/) αντιπροσωπεύει μια γενική συλλογή από [`Element`](../com.aspose.html.dom/element/). |
| [NamedNodeMap](./namednodemap/) | Αντιπροσωπεύει συλλογές χαρακτηριστικών που μπορούν να προσπελαστούν με το όνομα. |
| [NodeList](./nodelist/) | Η NodeList παρέχει την αφαίρεση μιας διατεταγμένης συλλογής κόμβων, χωρίς να ορίζει ή να περιορίζει τον τρόπο υλοποίησης αυτής της συλλογής. |
