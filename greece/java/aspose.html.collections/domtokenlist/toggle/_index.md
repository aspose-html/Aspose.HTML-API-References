## Toggle(String) {#toggle}

Αφαιρεί το διακριτικό από τη λίστα εάν υπάρχει, ή προσθέτει το διακριτικό στη λίστα εάν δεν υπάρχει.

```java
public bool Toggle(String token)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| διακριτικό | String | Το διακριτικό που θέλετε να εναλλάξετε. |

### Τιμή επιστροφής

## Toggle(String, bool) {#toggle_1}

Αφαιρεί το διακριτικό από τη λίστα εάν υπάρχει, ή προσθέτει το διακριτικό στη λίστα εάν δεν υπάρχει.

```java
public bool Toggle(String token, bool force)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| διακριτικό | String | Το διακριτικό που θέλετε να εναλλάξετε. |
| force | Boolean | Ένα Boolean που, εάν συμπεριληφθεί, μετατρέπει την εναλλαγή σε λειτουργία μονοκατεύθυνσης. Εάν οριστεί σε false, τότε το διακριτικό θα αφαιρεθεί μόνο, αλλά δεν θα προστεθεί. Εάν οριστεί σε true, τότε το διακριτικό θα προστεθεί μόνο, αλλά δεν θα αφαιρεθεί. |

### Τιμή επιστροφής

Ένα Boolean που υποδεικνύει αν το διακριτικό βρίσκεται στη λίστα μετά την κλήση.
