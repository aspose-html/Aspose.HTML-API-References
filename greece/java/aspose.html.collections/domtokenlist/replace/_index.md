## DOMTokenList.Replace method

Αντικαθιστά ένα υπάρχον διακριτικό με ένα νέο διακριτικό. Δεν κάνει τίποτα εάν το πρώτο διακριτικό δεν υπάρχει.

```java
public bool Replace(String token, String newToken)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| διακριτικό | String | Το διακριτικό που θέλετε να αντικαταστήσετε. |
| newToken | String | Το διακριτικό με το οποίο θέλετε να αντικαταστήσετε το παλιό διακριτικό. |

### Τιμή επιστροφής

Boolean `true` εάν το διακριτικό βρέθηκε και αντικαταστάθηκε, `false` διαφορετικά.
