## NodeList class

Το NodeList παρέχει την αφαίρεση μιας διατεταγμένης συλλογής κόμβων, χωρίς να ορίζει ή να περιορίζει πώς υλοποιείται αυτή η συλλογή.

```java
public abstract class NodeList : DOMObject, IEnumerable<Node>
```
