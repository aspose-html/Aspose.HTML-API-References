## ICSS2Properties.TextDecoration property

Αυτή η ιδιότητα περιγράφει διακοσμήσεις που προστίθενται στο κείμενο ενός στοιχείου. Εάν η ιδιότητα οριστεί για ένα στοιχείο [block-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#block-level), επηρεάζει όλους τους απογόνους σε επίπεδο inline του στοιχείου. Εάν οριστεί (ή επηρεάσει) ένα στοιχείο [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level), επηρεάζει όλα τα κουτιά που δημιουργεί το στοιχείο. Εάν το στοιχείο δεν έχει περιεχόμενο ή κείμενο (π.χ., το στοιχείο IMG σε HTML), οι πράκτορες χρήστη πρέπει να το [ignore](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#ignore) αυτήν την ιδιότητα.

Οι τιμές έχουν τις ακόλουθες σημασίες:

none - Δεν παράγει καμία διακόσμηση κειμένου. underline - Κάθε γραμμή κειμένου είναι υπογραμμισμένη. overline - Κάθε γραμμή κειμένου έχει μια γραμμή πάνω της. line-through - Κάθε γραμμή κειμένου έχει μια γραμμή που τη διασχίζει στο μέσον. blink - Το κείμενο αναβοσβήνει (εναλλάσσεται μεταξύ ορατού και αόρατου).
