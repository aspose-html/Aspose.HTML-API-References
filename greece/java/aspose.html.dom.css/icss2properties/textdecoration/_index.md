## ICSS2Properties.TextDecoration property

Αυτή η ιδιότητα περιγράφει διακοσμήσεις που προστίθενται στο κείμενο ενός στοιχείου. Εάν η ιδιότητα καθοριστεί για ένα [block-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#block-level) στοιχείο, επηρεάζει όλους τους απογόνους σε επίπεδο inline του στοιχείου. Εάν καθοριστεί για (ή επηρεάζει) ένα [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) στοιχείο, επηρεάζει όλα τα κουτιά που δημιουργούνται από το στοιχείο. Εάν το στοιχείο δεν έχει περιεχόμενο ή κείμενο (π.χ., το στοιχείο IMG σε HTML), οι πελάτες χρήστη πρέπει να [αγνοήσουν](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#ignore) αυτήν την ιδιότητα.

Οι τιμές έχουν τις ακόλουθες σημασίες:

none - Δεν παράγει καμία διακόσμηση κειμένου. underline - Κάθε γραμμή κειμένου είναι υπογραμμισμένη. overline - Κάθε γραμμή κειμένου έχει μια γραμμή πάνω της. line-through - Κάθε γραμμή κειμένου έχει μια γραμμή διαγώματος στη μέση. blink - Το κείμενο αναβοσβήνει (εναλλάσσεται μεταξύ ορατού και αόρατου).
