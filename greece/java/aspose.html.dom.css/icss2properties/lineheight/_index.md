## ICSS2Properties.LineHeight property

Εάν η ιδιότητα οριστεί σε ένα στοιχείο [block-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#block-level) του οποίου το περιεχόμενο αποτελείται από στοιχεία [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level), καθορίζει το ελάχιστο ύψος κάθε παραγόμενου inline πλαισίου.

Εάν η ιδιότητα οριστεί σε ένα στοιχείο [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level), καθορίζει το ακριβές ύψος κάθε πλαισίου που δημιουργείται από το στοιχείο. (Εκτός από inline στοιχεία [replaced](https://www.w3.org/TR/1998/REC-CSS2-19980512/conform.html#replaced-element), όπου το ύψος του πλαισίου δίνεται από την ιδιότητα ['height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-height).)

```java
public String LineHeight { get; set; }
```
