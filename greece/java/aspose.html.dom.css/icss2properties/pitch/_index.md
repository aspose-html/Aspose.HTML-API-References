## ICSS2Properties.Pitch property

Καθορίζει τη μέση τονικότητα (μια συχνότητα) της φωνής. Η μέση τονικότητα μιας φωνής εξαρτάται από την οικογένεια φωνής. Για παράδειγμα, η μέση τονικότητα για μια τυπική αντρική φωνή είναι περίπου 120 Hz, ενώ για μια γυναικεία φωνή είναι περίπου 210 Hz.

```java
public String Pitch { get; set; }
```
