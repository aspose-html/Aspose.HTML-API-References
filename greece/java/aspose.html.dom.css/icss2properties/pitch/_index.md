## ICSS2Properties.Pitch property

Καθορίζει τον μέσο τόνο (μια συχνότητα) της φωνής. Ο μέσος τόνος μιας φωνής εξαρτάται από την οικογένεια φωνής. Για παράδειγμα, ο μέσος τόνος μιας τυπικής αντρικής φωνής είναι περίπου 120 Hz, ενώ για μια γυναικεία φωνή είναι περίπου 210 Hz.

```java
public String Pitch { get; set; }
```
