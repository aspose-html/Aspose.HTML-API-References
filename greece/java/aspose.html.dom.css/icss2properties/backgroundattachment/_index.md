## ICSS2Properties.BackgroundAttachment property

Εάν καθοριστεί μια εικόνα φόντου, αυτή η ιδιότητα καθορίζει αν είναι fixed σε σχέση με το viewport ('fixed') ή scrolls μαζί με το έγγραφο ('scroll').

Ακόμη και αν η εικόνα είναι fixed, είναι ορατή μόνο όταν βρίσκεται στο φόντο ή στην περιοχή padding του στοιχείου. Συνεπώς, εκτός εάν η εικόνα είναι επαναλαμβανόμενη ('background-repeat: repeat'), μπορεί να είναι αόρατη.

```java
public String BackgroundAttachment { get; set; }
```
