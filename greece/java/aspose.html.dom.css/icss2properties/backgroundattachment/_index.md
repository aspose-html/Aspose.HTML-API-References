## ICSS2Properties.BackgroundAttachment property

Εάν καθοριστεί μια εικόνα φόντου, αυτή η ιδιότητα καθορίζει εάν είναι σταθερή σε σχέση με το παράθυρο προβολής ('fixed') ή κυλάει μαζί με το έγγραφο ('scroll').

Ακόμα και αν η εικόνα είναι σταθερή, είναι ορατή μόνο όταν βρίσκεται στην περιοχή φόντου ή περιθώριο του στοιχείου. Συνεπώς, εκτός εάν η εικόνα είναι επαναλαμβανόμενη ('background-repeat: repeat'), μπορεί να είναι αόρατη.

```java
public String BackgroundAttachment { get; set; }
```
