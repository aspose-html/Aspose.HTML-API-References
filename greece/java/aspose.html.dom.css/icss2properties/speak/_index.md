## ICSS2Properties.Speak property

Αυτή η ιδιότητα καθορίζει εάν το κείμενο θα αποδοθεί ακουστικά και, εάν ναι, με ποιον τρόπο (κάπως ανάλογα με την ιδιότητα ['display'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-display) property). Οι πιθανές τιμές είναι:

none - Καταστέλλει την ακουστική απόδοση ώστε το στοιχείο να μην χρειάζεται χρόνο απόδοσης. Σημειώστε, ωστόσο, ότι οι απόγονοι μπορεί να παρακάμψουν αυτήν την τιμή και θα προφερθούν. (Για να εξασφαλίσετε την κατάσβεση της απόδοσης ενός στοιχείου και των απογόνων του, χρησιμοποιήστε την ιδιότητα ['display'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-display) property).normal - Χρησιμοποιεί κανόνες προφοράς εξαρτημένους από τη γλώσσα για την απόδοση ενός στοιχείου και των παιδιών του. spell-out - Προφέρει το κείμενο γράμμα-γράμμα (χρήσιμο για ακρωνύμια και συντομογραφίες).

```java
public String Speak { get; set; }
```
