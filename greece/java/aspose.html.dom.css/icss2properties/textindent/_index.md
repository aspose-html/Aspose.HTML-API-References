## ICSS2Properties.TextIndent property

Αυτή η ιδιότητα καθορίζει την εσοχή της πρώτης γραμμής κειμένου σε ένα μπλοκ. Πιο συγκεκριμένα, καθορίζει την εσοχή του πρώτου πλαισίου που ρέει στο πρώτο [line box](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#line-box) του μπλοκ. Το πλαίσιο είναι εσομένο σε σχέση με την αριστερή (ή δεξιά, για διάταξη από δεξιά προς αριστερά) άκρη του πλαισίου γραμμής. Οι πράκτορες χρήστη θα πρέπει να αποδίδουν αυτή την εσοχή ως κενό διάστημα.

Οι τιμές έχουν τις ακόλουθες σημασίες:

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - Η εσοχή είναι σταθερό μήκος.'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - Η εσοχή είναι ποσοστό του πλάτους του περιέχοντος μπλοκ.

```java
public String TextIndent { get; set; }
```
