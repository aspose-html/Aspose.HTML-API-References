## ICSS2Properties.BorderTopColor property

Η ιδιότητα 'border-color' ορίζει το χρώμα των τεσσάρων περιγραμμάτων. Οι τιμές έχουν τις ακόλουθες σημασίες:

color - Καθορίζει μια τιμή χρώματος.transparent - Το περίγραμμα είναι διαφανές (αν και μπορεί να έχει πλάτος).

```java
public String BorderTopColor { get; set; }
```
