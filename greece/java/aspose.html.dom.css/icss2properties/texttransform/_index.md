## ICSS2Properties.TextTransform property

Αυτή η ιδιότητα ελέγχει τα αποτελέσματα κεφαλαίων του κειμένου ενός στοιχείου. Οι τιμές έχουν τις ακόλουθες σημασίες:

capitalize - Τοποθετεί το πρώτο χαρακτήρα κάθε λέξης σε κεφαλαίο. uppercase - Τοποθετεί όλους τους χαρακτήρες κάθε λέξης σε κεφαλαίο. lowercase - Τοποθετεί όλους τους χαρακτήρες κάθε λέξης σε πεζό. none - Δεν εφαρμόζονται αποτελέσματα κεφαλαίων.

```java
public String TextTransform { get; set; }
```
