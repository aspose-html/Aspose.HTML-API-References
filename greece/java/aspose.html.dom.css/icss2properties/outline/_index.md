## ICSS2Properties.Outline property

Η γραμμή περιγράμματος που δημιουργείται με τις ιδιότητες outline σχεδιάζεται "πάνω" σε ένα πλαίσιο, δηλαδή το περίγραμμα είναι πάντα στην κορυφή και δεν επηρεάζει τη θέση ή το μέγεθος του πλαισίου ή οποιωνδήποτε άλλων πλαισίων. Επομένως, η εμφάνιση ή η κατάργηση των περιγραμμάτων δεν προκαλεί επαναροή.

```java
public String Outline { get; set; }
```
