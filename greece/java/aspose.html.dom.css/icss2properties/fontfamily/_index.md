## ICSS2Properties.FontFamily property

Αυτή η ιδιότητα καθορίζει μια προτεραιοποιημένη λίστα ονομάτων οικογενειών γραμματοσειρών και/ή γενικών οικογενειών. Για να αντιμετωπιστεί το πρόβλημα ότι μια μόνο γραμματοσειρά μπορεί να μην περιέχει γλύφους για την εμφάνιση όλων των χαρακτήρων σε ένα έγγραφο, ή ότι δεν είναι διαθέσιμες όλες οι γραμματοσειρές σε όλα τα συστήματα, αυτή η ιδιότητα επιτρέπει στους δημιουργούς να καθορίσουν μια λίστα γραμματοσειρών, όλες με το ίδιο στυλ και μέγεθος, που δοκιμάζονται διαδοχικά για να διαπιστωθεί αν περιέχουν γλύφο για έναν συγκεκριμένο χαρακτήρα. Αυτή η λίστα ονομάζεται σύνολο γραμματοσειρών.

```java
public String FontFamily { get; set; }
```
