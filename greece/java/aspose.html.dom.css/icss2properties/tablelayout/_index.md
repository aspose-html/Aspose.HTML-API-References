## ICSS2Properties.TableLayout property

Η ιδιότητα ['table-layout'](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#propdef-table-layout) ελέγχει τον αλγόριθμο που χρησιμοποιείται για τη διάταξη των κελιών, των σειρών και των στηλών του πίνακα. Οι τιμές έχουν την ακόλουθη σημασία:

fixed - Χρησιμοποιήστε τον σταθερό αλγόριθμο διάταξης πίνακα auto - Χρησιμοποιήστε οποιονδήποτε αυτόματο αλγόριθμο διάταξης πίνακα

```java
public String TableLayout { get; set; }
```
