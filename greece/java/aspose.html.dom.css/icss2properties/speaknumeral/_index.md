## ICSS2Properties.SpeakNumeral property

Αυτή η ιδιότητα ελέγχει πώς προφέρονται οι αριθμοί. Οι τιμές έχουν τις ακόλουθες σημασίες:

digits - Προφέρετε τον αριθμό ως ξεχωριστά ψηφία. Έτσι, το "237" προφέρεται "Δύο Τρία Επτά". continuous - Προφέρετε τον αριθμό ως ολόκληρο αριθμό. Έτσι, το "237" προφέρεται "Δύο εκατό τριάντα επτά". Οι λεκτικές αναπαραστάσεις εξαρτώνται από τη γλώσσα.

```java
public String SpeakNumeral { get; set; }
```
