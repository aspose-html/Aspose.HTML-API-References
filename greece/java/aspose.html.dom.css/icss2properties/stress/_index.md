## ICSS2Properties.Stress property

Καθορίζει το ύψος των \"τοπικών κορυφών\" στην εντονική καμπύλη μιας φωνής. Για παράδειγμα, τα αγγλικά είναι μια γλώσσα με έμφαση, και διαφορετικά τμήματα μιας πρότασης ανατίθενται πρωτεύουσα, δευτερεύουσα ή τριτοβάθμια έμφαση. Η τιμή του ['stress'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-stress) ελέγχει το ποσό της μεταβολής που προκύπτει από αυτά τα σημεία έμφασης. Αυτή η ιδιότητα είναι συνοδός της ['pitch-range'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pitch-range) ιδιότητας και παρέχεται για να επιτρέψει στους προγραμματιστές να αξιοποιήσουν προηγμένες ακουστικές εμφανίσεις.

```java
public String Stress { get; set; }
```
