## ICSS2Properties.ListStyleType property

Αυτή η ιδιότητα καθορίζει την εμφάνιση του δείκτη στοιχείου λίστας εάν το ['list-style-image'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-list-style-image) έχει την τιμή 'none' ή εάν η εικόνα στην οποία δείχνει το URI δεν μπορεί να εμφανιστεί. Η τιμή 'none' υποδεικνύει ότι δεν υπάρχει δείκτης, διαφορετικά υπάρχουν τρεις τύποι δεικτών: γλύφους, συστήματα αρίθμησης και αλφαβητικά συστήματα. Σημείωση. Οι αριθμημένες λίστες βελτιώνουν την προσβασιμότητα του εγγράφου καθιστώντας τις λίστες πιο εύκολες στην πλοήγηση.

Οι γλύφοι καθορίζονται με δίσκο, κύκλο και τετράγωνο. Η ακριβής απόδοσή τους εξαρτάται από τον πράκτορα χρήστη.

Τα συστήματα αρίθμησης καθορίζονται με:

decimal - Δεκαδικοί αριθμοί, αρχίζοντας από 1. decimal-leading-zero - Δεκαδικοί αριθμοί με αρχικά μηδενικά (π.χ., 01, 02, 03, ..., 98, 99). lower-roman - Πεζά ρωμαϊκά αριθμητικά (i, ii, iii, iv, v, κ.λπ.). upper-roman - Κεφαλαία ρωμαϊκά αριθμητικά (I, II, III, IV, V, κ.λπ.). hebrew - Παραδοσιακή εβραϊκή αρίθμηση. georgian - Παραδοσιακή γεωργιανή αρίθμηση (an, ban, gan, ..., he, tan, in, in-an, ...). armenian - Παραδοσιακή αρμενική αρίθμηση. cjk-ideographic - Απλοί ιδεογραφικοί αριθμοί. hiragana - a, i, u, e, o, ka, ki, ... katakana - A, I, U, E, O, KA, KI, ... hiragana-iroha - i, ro, ha, ni, ho, he, to, ... katakana-iroha - I, RO, HA, NI, HO, HE, TO, ...
