## ICSS2Properties.BorderSpacing property

Τα μήκη καθορίζουν την απόσταση που χωρίζει τα γειτονικά σύνορα κελιών. Εάν καθοριστεί ένα μήκος, παρέχει τόσο την οριζόντια όσο και την κάθετη απόσταση. Εάν καθοριστούν δύο, το πρώτο δίνει την οριζόντια απόσταση και το δεύτερο την κάθετη. Τα μήκη δεν επιτρέπεται να είναι αρνητικά.

```java
public String BorderSpacing { get; set; }
```
