## ICSS2Properties.Richness property

Καθορίζει την πλούσια, ή τη φωτεινότητα της φωνής ομιλίας. Μια πλούσια φωνή θα \"ακουστεί\" σε μεγάλο δωμάτιο, ενώ μια ομαλή φωνή δεν θα το κάνει. (Ο όρος \"ομαλή\" αναφέρεται στο πώς φαίνεται η κυματομορφή όταν σχεδιάζεται.)

```java
public String Richness { get; set; }
```
