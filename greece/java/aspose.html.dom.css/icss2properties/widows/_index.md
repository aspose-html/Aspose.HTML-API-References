## ICSS2Properties.Widows property

Η ιδιότητα ['orphans'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-orphans) καθορίζει τον ελάχιστο αριθμό γραμμών μιας παραγράφου που πρέπει να παραμείνουν στο κάτω μέρος μιας σελίδας. Η ιδιότητα ['widows'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-widows) καθορίζει τον ελάχιστο αριθμό γραμμών μιας παραγράφου που πρέπει να παραμείνουν στο πάνω μέρος μιας σελίδας. Παραδείγματα του πώς χρησιμοποιούνται για τον έλεγχο των αλλαγών σελίδας δίνονται παρακάτω.

```java
public String Widows { get; set; }
```
