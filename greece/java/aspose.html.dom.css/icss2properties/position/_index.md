## ICSS2Properties.Position property

Οι τιμές αυτής της ιδιότητας έχουν τις ακόλουθες σημασίες:

static - Το κουτί είναι ένα κανονικό κουτί, διαμορφωμένο σύμφωνα με τη [normal flow](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#normal-flow). Οι ιδιότητες ['left'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-left) και ['top'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-top) δεν εφαρμόζονται.

public String Position { get; set; }
