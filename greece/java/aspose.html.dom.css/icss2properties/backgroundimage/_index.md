## ICSS2Properties.BackgroundImage property

Αυτή η ιδιότητα ορίζει την εικόνα φόντου ενός στοιχείου. Κατά τον ορισμό μιας εικόνας φόντου, οι δημιουργοί πρέπει επίσης να καθορίσουν ένα χρώμα φόντου που θα χρησιμοποιείται όταν η εικόνα δεν είναι διαθέσιμη. Όταν η εικόνα είναι διαθέσιμη, αποδίδεται πάνω από το χρώμα φόντου. (Έτσι, το χρώμα είναι ορατό στα διαφανή τμήματα της εικόνας).

```java
public String BackgroundImage { get; set; }
```

### Τιμή επιστροφής

ιδιότητα background-image

### Property Value

Οι τιμές για αυτήν την ιδιότητα είναι είτε , για να καθορίσετε την εικόνα, είτε 'none', όταν δεν χρησιμοποιείται εικόνα.
