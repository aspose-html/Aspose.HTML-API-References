## ICSS2Properties.BorderRightWidth property

Αυτή η ιδιότητα είναι μια συντομευμένη ιδιότητα για τον ορισμό των 'border-top-width', 'border-right-width', 'border-bottom-width' και 'border-left-width' στο ίδιο σημείο στο φύλλο στυλ.

Εάν υπάρχει μόνο μία τιμή, εφαρμόζεται σε όλες τις πλευρές. Εάν υπάρχουν δύο τιμές, τα άνω και κάτω περιθώρια ορίζονται στην πρώτη τιμή και τα δεξιά και αριστερά στην δεύτερη. Εάν υπάρχουν τρεις τιμές, το άνω όριο ορίζεται στην πρώτη τιμή, τα αριστερά και δεξιά στην δεύτερη, και το κάτω στην τρίτη. Εάν υπάρχουν τέσσερις τιμές, εφαρμόζονται αντίστοιχα στο άνω, δεξί, κάτω και αριστερό.

```java
public String BorderRightWidth { get; set; }
```
