## ICSS2Properties.Font property

Η ιδιότητα 'font' είναι, εκτός από ό,τι περιγράφεται παρακάτω, μια συντομευμένη ιδιότητα για τον καθορισμό των 'font-style', 'font-variant', 'font-weight', 'font-size', 'line-height' και 'font-family', στο ίδιο σημείο του φύλλου στυλ. Η σύνταξη αυτής της ιδιότητας βασίζεται σε μια παραδοσιακή τυπογραφική συντομευμένη σημειογραφία για τον καθορισμό πολλαπλών ιδιοτήτων σχετικών με τις γραμματοσειρές.

```java
public String Font { get; set; }
```
