## ICSS2Properties.TextShadow property

Αυτή η ιδιότητα δέχεται μια λίστα, χωρισμένη με κόμματα, από εφέ σκιάς που θα εφαρμοστούν στο κείμενο του στοιχείου. Τα εφέ σκιάς εφαρμόζονται με τη σειρά που καθορίζεται και μπορεί έτσι να επικαλύπτονται μεταξύ τους, αλλά ποτέ δεν θα επικαλύπτουν το ίδιο το κείμενο. Τα εφέ σκιάς δεν αλλάζουν το μέγεθος ενός πλαισίου, αλλά μπορεί να εκτείνουν πέρα από τα όριά του. Το [stack level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#stack-level) των εφέ σκιάς είναι το ίδιο με αυτό του στοιχείου.

Κάθε εφέ σκιάς πρέπει να καθορίζει μια μετατόπιση σκιάς και μπορεί προαιρετικά να καθορίζει μια ακτίνα θολώματος και ένα χρώμα σκιάς.

Μια μετατόπιση σκιάς καθορίζεται με δύο τιμές '[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' που υποδεικνύουν την απόσταση από το κείμενο. Η πρώτη τιμή length καθορίζει την οριζόντια απόσταση προς τα δεξιά του κειμένου. Μια αρνητική οριζόντια τιμή length τοποθετεί τη σκιά προς τα αριστερά του κειμένου. Η δεύτερη τιμή length καθορίζει την κάθετη απόσταση κάτω από το κείμενο. Μια αρνητική κάθετη τιμή length τοποθετεί τη σκιά πάνω από το κείμενο.

Μια ακτίνα θολώματος μπορεί προαιρετικά να καθοριστεί μετά τη μετατόπιση σκιάς. Η ακτίνα θολώματος είναι μια τιμή length που υποδεικνύει τα όρια του εφέ θολώματος. Ο ακριβής αλγόριθμος για τον υπολογισμό του εφέ θολώματος δεν έχει καθοριστεί.

Μια τιμή χρώματος μπορεί προαιρετικά να καθοριστεί πριν ή μετά τις τιμές length του εφέ σκιάς. Η τιμή χρώματος θα χρησιμοποιηθεί ως βάση για το εφέ σκιάς. Εάν δεν καθοριστεί χρώμα, θα χρησιμοποιηθεί η τιμή της ιδιότητας ['color'](https://www.w3.org/TR/1998/REC-CSS2-19980512/colors.html#propdef-color) αντί αυτού.
