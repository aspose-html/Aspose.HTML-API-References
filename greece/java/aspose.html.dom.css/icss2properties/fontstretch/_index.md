## ICSS2Properties.FontStretch property

Η ['font-stretch'](https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html#propdef-font-stretch) ιδιότητα επιλέγει ένα κανονικό, συμπιεσμένο ή εκτεταμένο στυλ από μια οικογένεια γραμματοσειρών. Οι απόλυτες τιμές-λέξεις-κλειδιά έχουν την ακόλουθη σειρά, από τη στενότερη έως τη μεγαλύτερη:
