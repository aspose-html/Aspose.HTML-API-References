## ICSS2Properties.VoiceFamily property

Η τιμή είναι μια λίστα προτεραιοποιημένων ονομάτων οικογένειας φωνής χωρισμένη με κόμματα (συγκρίνετε με ['font-family'](https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html#propdef-font-family)). Οι τιμές έχουν τις ακόλουθες σημασίες:

'generic-voice' - Οι τιμές είναι οικογένειες φωνής. Πιθανές τιμές είναι 'male', 'female' και 'child'.'specific-voice' - Οι τιμές είναι συγκεκριμένα παραδείγματα (π.χ., comedian, trinoids, carlos, lani).

```java
public String VoiceFamily { get; set; }
```
