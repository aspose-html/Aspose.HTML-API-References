## ICSS2Properties.PitchRange property

Καθορίζει τη διακύμανση του μέσου τόνου. Ο αντιληπτός τόνος μιας ανθρώπινης φωνής καθορίζεται από τη θεμελιώδη συχνότητα και τυπικά έχει τιμή 120 Hz για αντρική φωνή και 210 Hz για γυναικεία φωνή. Οι ανθρώπινες γλώσσες εκφωνούνται με μεταβαλλόμενη έμφαση και τόνο· αυτές οι διακυμάνσεις μεταφέρουν πρόσθετο νόημα και έμφαση. Έτσι, μια πολύ ζωντανή φωνή, δηλαδή μια έντονα τονισμένη, εμφανίζει ευρύ φάσμα τόνου. Αυτή η ιδιότητα καθορίζει το εύρος εντός του οποίου εμφανίζονται αυτές οι διακυμάνσεις, δηλαδή πόσο η θεμελιώδης συχνότητα μπορεί να αποκλίνει από τον μέσο τόνο.

```java
public String PitchRange { get; set; }
```
