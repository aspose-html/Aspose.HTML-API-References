## ICSS2Properties.PitchRange property

Καθορίζει τη διακύμανση στη μέση τονικότητα. Η αντιληπτή τονικότητα μιας ανθρώπινης φωνής καθορίζεται από τη θεμελιώδη συχνότητα και συνήθως έχει τιμή 120 Hz για αντρική φωνή και 210 Hz για γυναικεία φωνή. Οι ανθρώπινες γλώσσες εκφωνούνται με μεταβαλλόμενη έμφαση και τονικότητα· αυτές οι διακυμάνσεις μεταφέρουν επιπλέον νόημα και έμφαση. Έτσι, μια πολύ ζωντανή φωνή, δηλαδή μια που είναι έντονα τονισμένη, εμφανίζει ευρύ φάσμα τονικότητας. Αυτή η ιδιότητα καθορίζει το εύρος μέσα στο οποίο εμφανίζονται αυτές οι διακυμάνσεις, δηλαδή πόσο η θεμελιώδης συχνότητα μπορεί να αποκλίνει από τη μέση τονικότητα.

```java
public String PitchRange { get; set; }
```
