## ICSS2Properties.PageBreakAfter property

Οι τιμές για αυτές τις ιδιότητες έχουν τις ακόλουθες σημασίες:

auto - Ούτε να επιβάλει ούτε να απαγορεύσει μια αλλαγή σελίδας πριν (αφού, εντός) του παραγόμενου πλαισίου. always - Πάντα να επιβάλλει μια αλλαγή σελίδας πριν (αφού) το παραγόμενο πλαίσιο. avoid - Να αποφεύγει μια αλλαγή σελίδας πριν (αφού, εντός) του παραγόμενου πλαισίου. left - Να επιβάλλει μία ή δύο αλλαγές σελίδας πριν (αφού) το παραγόμενο πλαίσιο ώστε η επόμενη σελίδα να μορφοποιηθεί ως αριστερή σελίδα. right - Να επιβάλλει μία ή δύο αλλαγές σελίδας πριν (αφού) το παραγόμενο πλαίσιο ώστε η επόμενη σελίδα να μορφοποιηθεί ως δεξιά σελίδα.

```java
public String PageBreakAfter { get; set; }
```
