## ICSS2Properties.BackgroundRepeat property

Εάν καθοριστεί μια εικόνα φόντου, αυτή η ιδιότητα καθορίζει εάν η εικόνα επαναλαμβάνεται (καθαρά) και πώς. Όλη η επικάλυψη καλύπτει τις περιοχές περιεχομένου και περιθώριου ενός πλαισίου. Οι τιμές έχουν τις ακόλουθες σημασίες:

repeat - Η εικόνα επαναλαμβάνεται οριζόντια και κάθετα. repeat-x - Η εικόνα επαναλαμβάνεται μόνο οριζόντια. repeat-y - Η εικόνα επαναλαμβάνεται μόνο κάθετα. no-repeat - Η εικόνα δεν επαναλαμβάνεται: σχεδιάζεται μόνο ένα αντίγραφο της εικόνας.

```java
public String BackgroundRepeat { get; set; }
```

### Τιμή Επιστροφής

ιδιότητα background-repeat

### Property Value

Η τιμή background repeat από τη λίστα όπως ορίζεται παραπάνω.
