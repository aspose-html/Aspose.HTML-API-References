## ICSS2Properties.FontWeight property

Η ιδιότητα 'font-weight' καθορίζει το βάρος της γραμματοσειράς. Οι τιμές έχουν τις ακόλουθες σημασίες:

100 έως 900 - Αυτές οι τιμές σχηματίζουν μια διατεταγμένη ακολουθία, όπου κάθε αριθμός υποδεικνύει ένα βάρος τουλάχιστον τόσο σκούρο όσο ο προηγούμενος. normal - Ίδιο με το '400'. bold - Ίδιο με το '700'. bolder - Καθορίζει το επόμενο βάρος που ανατίθεται σε μια γραμματοσειρά που είναι πιο σκούρα από την κληρονομημένη. Εάν δεν υπάρχει τέτοιο βάρος, οδηγεί απλώς στην επόμενη πιο σκούρα αριθμητική τιμή (και η γραμματοσειρά παραμένει αμετάβλητη), εκτός εάν η κληρονομημένη τιμή ήταν '900', οπότε το αποτέλεσμα είναι επίσης '900'. lighter - Καθορίζει το επόμενο βάρος που ανατίθεται σε μια γραμματοσειρά που είναι πιο ανοιχτή από την κληρονομημένη. Εάν δεν υπάρχει τέτοιο βάρος, οδηγεί απλώς στην επόμενη πιο ανοιχτή αριθμητική τιμή (και η γραμματοσειρά παραμένει αμετάβλητη), εκτός εάν η κληρονομημένη τιμή ήταν '100', οπότε το αποτέλεσμα είναι επίσης '100'.
