## ICSS2Properties.Cue property

Η ιδιότητα ['cue'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue) είναι συντομογραφία για τον ορισμό των ['cue-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-before) και ['cue-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-after). Εάν δοθούν δύο τιμές, η πρώτη τιμή είναι ['cue-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-before) και η δεύτερη είναι ['cue-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-after). Εάν δοθεί μόνο μία τιμή, εφαρμόζεται και στις δύο ιδιότητες.

```java
public String Cue { get; set; }
```
