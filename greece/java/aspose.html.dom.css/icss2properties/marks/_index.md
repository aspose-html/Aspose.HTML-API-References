## ICSS2Properties.Marks property

Σε υψηλής ποιότητας εκτύπωση, τα σημάδια συχνά προστίθενται έξω από το page box. Αυτή η ιδιότητα καθορίζει εάν θα αποδοθούν διαγώνια σημάδια ή σημάδια περικοπής ή και τα δύο ακριβώς έξω από την άκρη του [page box](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#page-box).

Τα σημάδια περικοπής υποδεικνύουν πού πρέπει να κοπεί η σελίδα. Τα διαγώνια σημάδια (γνωστά επίσης ως σημάδια καταγραφής ή σημάδια εγγραφής) χρησιμοποιούνται για την ευθυγράμμιση των φύλλων.

Τα σημάδια είναι ορατά μόνο σε απόλυτα page boxes (δείτε την ιδιότητα ['size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-size)). Σε σχετικά page boxes, το page box θα ευθυγραμμιστεί με τον στόχο και τα σημάδια θα βρίσκονται έξω από την εκτυπώσιμη περιοχή.

Το μέγεθος, το στυλ και η θέση των σταυροειδών σημείων εξαρτώνται από τον πράκτορα χρήστη.

```java
public String Marks { get; set; }
```
