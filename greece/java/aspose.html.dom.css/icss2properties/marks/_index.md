## ICSS2Properties.Marks property

Σε εκτυπώσεις υψηλής ποιότητας, τα σημάδια προστίθενται συχνά έξω από το κουτί σελίδας. Αυτή η ιδιότητα καθορίζει εάν πρέπει να αποδοθούν διαγώνια σημάδια, σημάδια περικοπής ή και τα δύο ακριβώς έξω από την άκρη του [page box](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#page-box).

Τα σημάδια περικοπής υποδεικνύουν πού πρέπει να κοπεί η σελίδα. Τα διαγώνια σημάδια (γνωστά επίσης ως σημάδια καταγραφής ή σημάδια εγγραφής) χρησιμοποιούνται για την ευθυγράμμιση των φύλλων.

Τα σημάδια είναι ορατά μόνο σε απόλυτα κουτιά σελίδας (δείτε την ιδιότητα ['size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-size)). Σε σχετικά κουτιά σελίδας, το κουτί σελίδας θα ευθυγραμμιστεί με τον στόχο και τα σημάδια θα βρίσκονται έξω από την εκτυπώσιμη περιοχή.

Το μέγεθος, το στυλ και η θέση των σταυροειδών σημείων εξαρτώνται από τον πράκτορα χρήστη.

```java
public String Marks { get; set; }
```
