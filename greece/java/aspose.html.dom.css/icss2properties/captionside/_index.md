## ICSS2Properties.CaptionSide property

Αυτή η ιδιότητα καθορίζει τη θέση του πλαισίου λεζάντας σε σχέση με το πλαίσιο του πίνακα. Οι τιμές έχουν τις ακόλουθες σημασίες:

top - Τοποθετεί το πλαίσιο λεζάντας πάνω από το πλαίσιο του πίνακα. bottom - Τοποθετεί το πλαίσιο λεζάντας κάτω από το πλαίσιο του πίνακα. left - Τοποθετεί το πλαίσιο λεζάντας στα αριστερά του πλαισίου του πίνακα. right - Τοποθετεί το πλαίσιο λεζάντας στα δεξιά του πλαισίου του πίνακα.

```java
public String CaptionSide { get; set; }
```
