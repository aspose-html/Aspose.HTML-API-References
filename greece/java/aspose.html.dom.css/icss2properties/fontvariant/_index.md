## ICSS2Properties.FontVariant property

Σε μια γραμματοσειρά μικρών κεφαλαίων, τα σύμβολα για τα πεζά γράμματα μοιάζουν με τα κεφαλαία, αλλά σε μικρότερο μέγεθος και με ελαφρώς διαφορετικές αναλογίες. Η ιδιότητα 'font-variant' ζητά μια τέτοια γραμματοσειρά για διπλοκαμεραλικές γλώσσες (με δύο μορφές, όπως η λατινική γραφή). Αυτή η ιδιότητα δεν έχει ορατό αποτέλεσμα για γλώσσες που είναι μονοκαμεραλικές (με μόνο μία μορφή, όπως στις περισσότερες γραπτές γλώσσες του κόσμου).

```java
public String FontVariant { get; set; }
```
