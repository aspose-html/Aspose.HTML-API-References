## ICSS2Properties.FontSizeAdjust property

Σε διπλογράμματα, το υποκειμενικό εμφανές μέγεθος και η αναγνωσιμότητα μιας γραμματοσειράς εξαρτώνται λιγότερο από την τιμή 'font-size' από ό,τι από την τιμή του 'x-height', ή, πιο χρήσιμα, από το λόγο αυτών των δύο τιμών, που ονομάζεται aspect value (font size divided by x-height). Όσο υψηλότερη είναι η aspect value, τόσο πιο πιθανό είναι μια γραμματοσειρά σε μικρότερα μεγέθη να είναι αναγνώσιμη. Αντίστροφα, γραμματοσειρές με χαμηλότερη aspect value θα γίνουν μη αναγνώσιμες πιο γρήγορα κάτω από ένα δεδομένο όριο μεγέθους από γραμματοσειρές με υψηλότερη aspect value. Η απλή αντικατάσταση γραμματοσειρών που βασίζεται μόνο στο μέγεθος γραμματοσειράς μπορεί να οδηγήσει σε μη αναγνώσιμους χαρακτήρες.

```java
public String FontSizeAdjust { get; set; }
```
