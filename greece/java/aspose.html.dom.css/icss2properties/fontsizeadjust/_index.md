## ICSS2Properties.FontSizeAdjust property

Σε διπλογράμματα, το υποκειμενικό εμφανές μέγεθος και η αναγνωσιμότητα μιας γραμματοσειράς εξαρτώνται λιγότερο από την τιμή του 'font-size' παρά από την τιμή του 'x-height', ή, πιο χρήσιμα, από το λόγο αυτών των δύο τιμών, που ονομάζεται aspect value (μέγεθος γραμματοσειράς διαιρεμένο με το x-height). Όσο υψηλότερη είναι η τιμή aspect value, τόσο πιο πιθανό είναι μια γραμματοσειρά σε μικρότερα μεγέθη να είναι αναγνώσιμη. Αντίστροφα, γραμματοσειρές με χαμηλότερη τιμή aspect value θα γίνουν μη αναγνώσιμες πιο γρήγορα κάτω από ένα δεδομένο όριο μεγέθους σε σύγκριση με γραμματοσειρές με υψηλότερη τιμή aspect value. Η απλή αντικατάσταση γραμματοσειράς που βασίζεται μόνο στο μέγεθος της γραμματοσειράς μπορεί να οδηγήσει σε μη αναγνώσιμους χαρακτήρες.

```java
public String FontSizeAdjust { get; set; }
```
