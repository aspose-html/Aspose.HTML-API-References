## ICSS2Properties.EmptyCells property

Στο μοντέλο χωριστών περιγραμμάτων, αυτή η ιδιότητα ελέγχει την απόδοση των περιγραμμάτων γύρω από κελιά που δεν έχουν ορατό περιεχόμενο. Τα κενά κελιά και τα κελιά με την ιδιότητα 'visibility' ορισμένη σε 'hidden' θεωρούνται ότι δεν έχουν ορατό περιεχόμενο.

```java
public String EmptyCells { get; set; }
```
