## ICSS2Properties.MaxHeight property

Αυτές οι δύο ιδιότητες επιτρέπουν στους συγγραφείς να περιορίζουν τα ύψη των πλαισίων σε ένα συγκεκριμένο εύρος. Οι τιμές έχουν τις ακόλουθες σημασίες:

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - Καθορίζει ένα σταθερό ελάχιστο ή μέγιστο υπολογιζόμενο ύψος.'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - Καθορίζει ένα ποσοστό για τον καθορισμό της υπολογιζόμενης τιμής. Το ποσοστό υπολογίζεται σε σχέση με το ύψος του περιέχοντος μπλοκ του παραγόμενου πλαισίου. Εάν το ύψος του περιέχοντος μπλοκ δεν καθορίζεται ρητά (π.χ., εξαρτάται από το ύψος του περιεχομένου), η τιμή ποσοστού ερμηνεύεται ως 'auto'.none - (Μόνο στο ['max-height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-max-height)) Δεν υπάρχει όριο στο ύψος του πλαισίου.

```java
public String MaxHeight { get; set; }
```
