## ICSS2Properties.MaxHeight property

Αυτές οι δύο ιδιότητες επιτρέπουν στους δημιουργούς να περιορίζουν τα ύψη των πλαισίων σε ένα συγκεκριμένο εύρος. Οι τιμές έχουν τις παρακάτω σημασίες:

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - Καθορίζει ένα σταθερό ελάχιστο ή μέγιστο υπολογιζόμενο ύψος.'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - Καθορίζει ένα ποσοστό για τον προσδιορισμό της υπολογιζόμενης τιμής. Το ποσοστό υπολογίζεται σε σχέση με το ύψος του παραγόμενου πλαισίου του [containing block](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#containing-block). Εάν το ύψος του περιέχοντος μπλοκ δεν καθορίζεται ρητά (π.χ., εξαρτάται από το ύψος του περιεχομένου), η τιμή ποσοστού ερμηνεύεται όπως το 'auto'.none - (Μόνο στο ['max-height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-max-height)) Κανένας περιορισμός στο ύψος του πλαισίου.

```java
public String MaxHeight { get; set; }
```
