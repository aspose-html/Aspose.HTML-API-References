## ICSS2Properties.WhiteSpace property

Αυτή η ιδιότητα δηλώνει πώς διαχειρίζεται το [whitespace](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#whitespace) μέσα στο στοιχείο. Οι τιμές έχουν τις ακόλουθες σημασίες:

normal - Αυτή η τιμή καθοδηγεί τους πράκτορες χρήστη να συμπτύξουν ακολουθίες κενών διαστημάτων και να σπάζουν γραμμές όπως απαιτείται για να γεμίσουν τα κουτιά γραμμής. Επιπλέον, μπορεί να δημιουργηθούν νέες αλλαγές γραμμής από εμφανίσεις του "\A" στο παραγόμενο περιεχόμενο (π.χ., για το στοιχείο BR σε HTML).pre - Αυτή η τιμή αποτρέπει τους πράκτορες χρήστη από το να συμπτύξουν ακολουθίες κενών διαστημάτων. Οι γραμμές σπάζονται μόνο στα νέα γραμμικά στο πηγαίο κείμενο ή στις εμφανίσεις του "\A" στο παραγόμενο περιεχόμενο.nowrap - Αυτή η τιμή συμπτύσσει τα κενά όπως η 'normal', αλλά καταστέλλει τις αλλαγές γραμμής μέσα στο κείμενο εκτός από εκείνες που δημιουργούνται από το "\A" στο παραγόμενο περιεχόμενο (π.χ., για το στοιχείο BR σε HTML).

public String WhiteSpace { get; set; }
