## ICSS2Properties.ListStylePosition property

Αυτή η ιδιότητα καθορίζει τη θέση του πλαισίου δείκτη στο κύριο πλαίσιο μπλοκ. Οι τιμές έχουν τις ακόλουθες σημασίες:

outside - Το πλαίσιο δείκτη βρίσκεται εκτός του κύριου πλαισίου μπλοκ. Σημείωση. Το CSS1 δεν καθόριζε την ακριβή θέση του πλαισίου δείκτη και για λόγους συμβατότητας, το CSS2 παραμένει εξίσου ασαφές. Για πιο ακριβή έλεγχο των πλαισίων δείκτη, παρακαλούμε χρησιμοποιήστε markers. inside - Το πλαίσιο δείκτη είναι το πρώτο ενσωματωμένο πλαίσιο στο κύριο πλαίσιο μπλοκ, μετά το οποίο ρέει το περιεχόμενο του στοιχείου.

```java
public String ListStylePosition { get; set; }
```
