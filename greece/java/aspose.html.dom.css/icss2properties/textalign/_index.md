## ICSS2Properties.TextAlign property

Αυτή η ιδιότητα περιγράφει πώς ευθυγραμμίζεται το ενσωματωμένο περιεχόμενο ενός μπλοκ. Οι τιμές έχουν τις ακόλουθες σημασίες:

αριστερά, δεξιά, κέντρο, και στοίχιση - Αριστερά, δεξιά, κέντρο, και διπλή στοίχιση κειμένου, αντίστοιχα.'[String](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-String)' - Καθορίζει ένα String στο οποίο τα κελιά σε μια στήλη πίνακα θα ευθυγραμμιστούν (δείτε την ενότητα για [horizontal alignment in a column](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#column-alignment) για λεπτομέρειες και ένα παράδειγμα). Η τιμή αυτή ισχύει μόνο για κελιά [table](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html). Εάν οριστεί σε άλλα στοιχεία, θα αντιμετωπιστεί ως 'left' ή 'right', ανάλογα με το αν το ['direction'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-direction) είναι 'ltr' ή 'rtl', αντίστοιχα.

public String TextAlign { get; set; }
