## ICSS2Properties.TextAlign property

Αυτή η ιδιότητα περιγράφει πώς ευθυγραμμίζεται το ενσωματωμένο περιεχόμενο ενός μπλοκ. Οι τιμές έχουν τις ακόλουθες σημασίες:

left, right, center, and justify - Αριστερά, δεξιά, κέντρο και πλήρης στοίχιση - Αριστερά, δεξιά, κέντρο και διπλή στοίχιση κειμένου, αντίστοιχα.'[String](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-String)' - Καθορίζει μια Σειρά στην οποία θα ευθυγραμμιστούν τα κελιά σε μια στήλη πίνακα (δείτε την ενότητα για [horizontal alignment in a column](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#column-alignment) για λεπτομέρειες και παράδειγμα). Αυτή η τιμή εφαρμόζεται μόνο σε κελιά [table](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html). Εάν οριστεί σε άλλα στοιχεία, θα αντιμετωπίζεται ως 'left' ή 'right', ανάλογα με το αν το ['direction'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-direction) είναι 'ltr' ή 'rtl', αντίστοιχα.

public String TextAlign { get; set; }
