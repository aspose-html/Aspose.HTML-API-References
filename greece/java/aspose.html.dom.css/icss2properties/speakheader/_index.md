## ICSS2Properties.SpeakHeader property

Αυτή η ιδιότητα καθορίζει αν οι κεφαλίδες πίνακα προφέρονται πριν από κάθε κελί, ή μόνο πριν από ένα κελί όταν αυτό το κελί συνδέεται με διαφορετική κεφαλίδα από την προηγούμενη κεφαλίδα. Οι τιμές έχουν τις ακόλουθες σημασίες:

once - Η κεφαλίδα προφέρεται μία φορά, πριν από μια σειρά κελιών. always - Η κεφαλίδα προφέρεται πριν από κάθε σχετικό κελί.

```java
public String SpeakHeader { get; set; }
```
