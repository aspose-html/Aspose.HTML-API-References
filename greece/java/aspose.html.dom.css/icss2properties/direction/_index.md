## ICSS2Properties.Direction property

Αυτή η ιδιότητα καθορίζει τη βασική κατεύθυνση γραφής των μπλοκ και την κατεύθυνση των ενσωματώσεων και παρακάμψεων (δείτε ['unicode-bidi'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-unicode-bidi)) για τον αλγόριθμο Unicode bidirectional. Επιπλέον, καθορίζει την κατεύθυνση διάταξης στηλών του [table](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html), την κατεύθυνση του οριζόντιου [overflow](https://www.w3.org/TR/1998/REC-CSS2-19980512/visufx.html#overflow), και τη θέση μιας ελλιπούς τελευταίας γραμμής σε ένα μπλοκ σε περίπτωση 'text-align: justify'.

```java
public String Direction { get; set; }
```
