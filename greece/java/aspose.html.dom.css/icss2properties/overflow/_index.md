## ICSS2Properties.Overflow property

Αυτή η ιδιότητα καθορίζει αν το περιεχόμενο ενός στοιχείου επιπέδου μπλοκ περικόπτεται όταν υπερβαίνει το κουτί του στοιχείου (που λειτουργεί ως περιβάλλον μπλοκ για το περιεχόμενο). Οι τιμές έχουν τις ακόλουθες σημασίες:

visible - Αυτή η τιμή υποδεικνύει ότι το περιεχόμενο δεν περικόπτεται, δηλαδή μπορεί να αποδοθεί εκτός του μπλοκ κουτιού. hidden - Αυτή η τιμή υποδεικνύει ότι το περιεχόμενο περικόπτεται και ότι δεν πρέπει να παρέχεται μηχανισμός κύλισης για την προβολή του περιεχομένου εκτός της περιοχής περικοπής· οι χρήστες δεν θα έχουν πρόσβαση στο περικομμένο περιεχόμενο. Το μέγεθος και το σχήμα της περιοχής περικοπής καθορίζεται από την ιδιότητα ['clip'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visufx.html#propdef-clip). scroll - Αυτή η τιμή υποδεικνύει ότι το περιεχόμενο περικόπτεται και ότι εάν ο πράκτορας χρήστη χρησιμοποιεί μηχανισμό κύλισης ο οποίος είναι ορατός στην οθόνη (όπως μια γραμμή κύλισης ή ένας πινέζα), αυτός ο μηχανισμός πρέπει να εμφανίζεται για ένα κουτί, ανεξάρτητα από το αν κάποιο από το περιεχόμενό του είναι περικομμένο. Αυτό αποτρέπει τυχόν προβλήματα με την εμφάνιση και εξαφάνιση των γραμμών κύλισης σε δυναμικό περιβάλλον. Όταν αυτή η τιμή καθορίζεται και το στοχευόμενο μέσο είναι 'print' ή 'projection', το υπερχειλισμένο περιεχόμενο πρέπει να εκτυπωθεί. auto - Η συμπεριφορά της τιμής 'auto' εξαρτάται από τον πράκτορα χρήστη, αλλά θα πρέπει να προκαλεί την παροχή μηχανισμού κύλισης για τα υπερχειλισμένα κουτιά.

```java
public String Overflow { get; set; }
```
