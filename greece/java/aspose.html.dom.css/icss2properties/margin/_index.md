## ICSS2Properties.Margin property

Η ιδιότητα ['margin'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin) είναι μια συντομευμένη ιδιότητα για τον ορισμό των ['margin-top'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-top), ['margin-right'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-right), ['margin-bottom'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-bottom), και ['margin-left'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-left) στην ίδια θέση στο φύλλο στυλ.

Αν υπάρχει μόνο μία τιμή, εφαρμόζεται σε όλες τις πλευρές. Αν υπάρχουν δύο τιμές, τα περιθώρια πάνω και κάτω ορίζονται στην πρώτη τιμή και τα δεξιά και αριστερά περιθώρια στην δεύτερη. Αν υπάρχουν τρεις τιμές, το πάνω περιθώριο ορίζεται στην πρώτη τιμή, τα αριστερά και δεξιά στην δεύτερη, και το κάτω περιθώριο στην τρίτη. Αν υπάρχουν τέσσερις τιμές, εφαρμόζονται αντίστοιχα στο πάνω, δεξί, κάτω και αριστερό.
