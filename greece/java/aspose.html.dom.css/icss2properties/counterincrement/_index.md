## ICSS2Properties.CounterIncrement property

Η ιδιότητα ['counter-increment'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-counter-increment) δέχεται ένα ή περισσότερα ονόματα μετρητών (ταυτοποιητών), το καθένα προαιρετικά ακολουθούμενο από έναν ακέραιο. Ο ακέραιος υποδεικνύει κατά πόσον ο μετρητής αυξάνεται για κάθε εμφάνιση του στοιχείου. Η προεπιλεγμένη αύξηση είναι 1. Επιτρέπονται μηδενικοί και αρνητικοί ακέραιοι.

```java
public String CounterIncrement { get; set; }
```
