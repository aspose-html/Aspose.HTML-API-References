## ICSS2Properties.Pause property

Η ['pause'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause) ιδιότητα είναι συντομογραφία για τον ορισμό των ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) και ['pause-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-after). Εάν δοθούν δύο τιμές, η πρώτη είναι ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) και η δεύτερη είναι ['pause-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-after). Εάν δοθεί μόνο μία τιμή, αυτή εφαρμόζεται και στις δύο ιδιότητες.

```java
public String Pause { get; set; }
```
