## ICSS2Properties.OutlineColor property

Το περίγραμμα που δημιουργείται με τις ιδιότητες outline σχεδιάζεται "πάνω" σε ένα πλαίσιο, δηλαδή το περίγραμμα είναι πάντα πάνω και δεν επηρεάζει τη θέση ή το μέγεθος του πλαισίου ή οποιουδήποτε άλλου πλαισίου. Συνεπώς, η εμφάνιση ή η απόκρυψη των περιγραμμάτων δεν προκαλεί επαναδιάταξη.

```java
public String OutlineColor { get; set; }
```
