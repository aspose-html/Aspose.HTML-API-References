## ICSS2Properties.ListStyleImage property

Αυτή η ιδιότητα ορίζει την εικόνα που θα χρησιμοποιηθεί ως δείκτης στοιχείου λίστας. Όταν η εικόνα είναι διαθέσιμη, θα αντικαταστήσει το σύνολο δεικτών με τον δείκτη ['list-style-type'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-list-style-type).

public String ListStyleImage { get; set; }
