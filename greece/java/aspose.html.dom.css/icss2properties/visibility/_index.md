## ICSS2Properties.Visibility property

Η ιδιότητα ['visibility'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visufx.html#propdef-visibility) καθορίζει αν τα κουτιά που δημιουργούνται από ένα στοιχείο αποδίδονται. Τα αόρατα κουτιά εξακολουθούν να επηρεάζουν τη διάταξη (ορίστε την ιδιότητα ['display'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-display) σε 'none' για να καταστεί λανθασμένη η δημιουργία των κουτιών εντελώς). Οι τιμές έχουν τις ακόλουθες σημασίες:

visible - Το παραγόμενο κουτί είναι ορατό. hidden - Το παραγόμενο κουτί είναι αόρατο (πλήρως διαφανές), αλλά εξακολουθεί να επηρεάζει τη διάταξη. collapse - Παρακαλούμε ανατρέξτε στην ενότητα για [dynamic row and column effects](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#dynamic-effects) στους πίνακες. Εάν χρησιμοποιηθεί σε στοιχεία εκτός των γραμμών ή στηλών, το 'collapse' έχει την ίδια σημασία με το 'hidden'.

```java
public String Visibility { get; set; }
```
