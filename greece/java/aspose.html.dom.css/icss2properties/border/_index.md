## ICSS2Properties.Border property

Η ιδιότητα 'border' είναι μια συντομευμένη ιδιότητα για τον ορισμό του ίδιου πλάτους, χρώματος και στυλ για όλα τα τέσσερα όρια ενός κουτιού. Σε αντίθεση με τις συντομευμένες ιδιότητες 'margin' και 'padding', η ιδιότητα 'border' δεν μπορεί να ορίσει διαφορετικές τιμές στα τέσσερα όρια. Για να γίνει αυτό, πρέπει να χρησιμοποιηθεί μία ή περισσότερες από τις άλλες ιδιότητες border.

```java
public String Border { get; set; }
```
