## ICSS2Properties.SpeakPunctuation property

Αυτή η ιδιότητα καθορίζει πώς προφέρεται η στίξη. Οι τιμές έχουν τις ακόλουθες σημασίες:

code - Η στίξη όπως τα ερωτηματικά, οι αγκύλες κ.λπ. πρέπει να προφέρεται κυριολεκτικά. none - Η στίξη δεν πρέπει να προφέρεται, αλλά να αποδίδεται φυσικά ως διάφορες παύσεις.

```java
public String SpeakPunctuation { get; set; }
```
