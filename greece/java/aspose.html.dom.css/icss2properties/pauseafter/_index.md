## ICSS2Properties.PauseAfter property

Αυτές οι ιδιότητες καθορίζουν μια παύση που πρέπει να τηρηθεί πριν (ή μετά) την εκφώνηση του περιεχομένου ενός στοιχείου. Οι τιμές έχουν τις ακόλουθες σημασίες:

'[time](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-time)' - Εκφράζει την παύση σε απόλυτες μονάδες χρόνου (δευτερόλεπτα και χιλιοστά του δευτερολέπτου).'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - Αναφέρεται στο αντίστροφο της τιμής της ιδιότητας ['speech-rate'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-speech-rate) property. Για παράδειγμα, αν το speech-rate είναι 120 λέξεις ανά λεπτό (δηλαδή μια λέξη διαρκεί μισό δευτερόλεπτο, ή 500ms) τότε ένα ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) του 100% σημαίνει παύση 500 ms και ένα ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) του 20% σημαίνει 100ms.
