## ICSS2Properties.Size property

Αυτή η ιδιότητα καθορίζει το μέγεθος και τον προσανατολισμό ενός πλαισίου σελίδας.

Το μέγεθος ενός πλαισίου σελίδας μπορεί να είναι είτε "απόλυτο" (σταθερό μέγεθος) είτε "σχετικό" (κλιμακώσιμο, δηλαδή προσαρμοσμένο στα διαθέσιμα μεγέθη φύλλων). Τα σχετικά πλαίσια σελίδας επιτρέπουν στους πράκτορες χρήστη να κλιμακώσουν ένα έγγραφο και να κάνουν βέλτιστη χρήση του στόχου μεγέθους.

Τρεις τιμές για την ιδιότητα ['size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-size) δημιουργούν ένα σχετικό πλαίσιο σελίδας:

auto - Το πλαίσιο σελίδας θα οριστεί στο μέγεθος και τον προσανατολισμό του στόχου φύλλου. landscape - Παρακάμπτει τον προσανατολισμό του στόχου. Το πλαίσιο σελίδας έχει το ίδιο μέγεθος με τον στόχο, και οι μεγαλύτερες πλευρές είναι οριζόντιες. portrait - Παρακάμπτει τον προσανατολισμό του στόχου. Το πλαίσιο σελίδας έχει το ίδιο μέγεθος με τον στόχο, και οι μικρότερες πλευρές είναι οριζόντιες.

```java
public String Size { get; set; }
```
