## ICSS2Properties.Elevation property

Οι τιμές αυτής της ιδιότητας έχουν τις ακόλουθες σημασίες:

'angle' - Καθορίζει το υψόμετρο ως γωνία, μεταξύ '-90deg' και '90deg'. '0deg' σημαίνει στον εμπρός ορίζοντα, που κατά περίπου σημαίνει επίπεδο με τον ακροατή. '90deg' σημαίνει άμεσα πάνω από το κεφάλι και '-90deg' σημαίνει άμεσα κάτω. below - Ίδιο με '-90deg'. level - Ίδιο με '0deg'. above - Ίδιο με '90deg'. higher - Προσθέτει 10 μοίρες στο τρέχον υψόμετρο. lower - Αφαιρεί 10 μοίρες από το τρέχον υψόμετρο.

public String Elevation { get; set; }
