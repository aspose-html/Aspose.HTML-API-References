## ICSS2Properties.Clear property

Αυτή η ιδιότητα υποδεικνύει ποιες πλευρές των πλαισίων ενός στοιχείου δεν μπορούν να είναι γειτονικές με ένα προηγούμενο αιωρούμενο πλαίσιο. (Ενδέχεται το ίδιο το στοιχείο να έχει αιωρούμενα απογόνους· η ιδιότητα 'clear' δεν έχει καμία επίδραση σε αυτά.)

Αυτή η ιδιότητα μπορεί να οριστεί μόνο για στοιχεία επιπέδου μπλοκ (συμπεριλαμβανομένων των αιωρούμενων). Για συμπαγή και ενσωματωμένα πλαίσια, η ιδιότητα αυτή εφαρμόζεται στο τελικό πλαίσιο μπλοκ στο οποίο ανήκει το συμπαγές ή ενσωματωμένο πλαίσιο.

Οι τιμές έχουν τις ακόλουθες σημασίες όταν εφαρμόζονται σε μη αιωρούμενα πλαίσια μπλοκ:

left - Το άνω περιθώριο του παραγόμενου πλαισίου αυξάνεται επαρκώς ώστε η άνω άκρη του περιγράμματος να βρίσκεται κάτω από την κάτω εξωτερική άκρη οποιουδήποτε αριστερά-αιωρούμενου πλαισίου που προέκυψε από στοιχεία νωρίτερα στο πηγαίο έγγραφο. right - Το άνω περιθώριο του παραγόμενου πλαισίου αυξάνεται επαρκώς ώστε η άνω άκρη του περιγράμματος να βρίσκεται κάτω από την κάτω εξωτερική άκρη οποιουδήποτε δεξιά-αιωρούμενου πλαισίου που προέκυψε από στοιχεία νωρίτερα στο πηγαίο έγγραφο. both - Το παραγόμενο πλαίσιο μετακινείται κάτω από όλα τα αιωρούμενα πλαίσια των προηγούμενων στοιχείων στο πηγαίο έγγραφο. none - Δεν υπάρχει περιορισμός στη θέση του πλαισίου σε σχέση με τα αιωρούμενα.

```java
public String Clear { get; set; }
```
