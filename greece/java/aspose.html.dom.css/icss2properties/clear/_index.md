## ICSS2Properties.Clear property

Αυτή η ιδιότητα υποδεικνύει ποιες πλευρές των κουτιών ενός στοιχείου δεν μπορούν να είναι γειτονικές με ένα προηγούμενο αιωρούμενο κουτί. (Μπορεί το στοιχείο να έχει αιωρούμενα απογόνους· η ιδιότητα 'clear' δεν έχει καμία επίδραση σε αυτά.)

Αυτή η ιδιότητα μπορεί να καθοριστεί μόνο για στοιχεία επιπέδου μπλοκ (συμπεριλαμβανομένων των αιωρούμενων). Για συμπαγή και ενσωματωμένα κουτιά, αυτή η ιδιότητα εφαρμόζεται στο τελικό μπλοκ κουτί στο οποίο ανήκει το συμπαγές ή ενσωματωμένο κουτί.

Οι τιμές έχουν τις ακόλουθες σημασίες όταν εφαρμόζονται σε μη αιωρούμενα κουτιά μπλοκ:

left - Το άνω περιθώριο του παραγόμενου κουτιού αυξάνεται αρκετά ώστε η άνω άκρη του περιγράμματος να βρίσκεται κάτω από την κάτω εξωτερική άκρη οποιουδήποτε αριστερά-αιωρούμενου κουτιού που προέκυψε από στοιχεία νωρίτερα στο πηγαίο έγγραφο. right - Το άνω περιθώριο του παραγόμενου κουτιού αυξάνεται αρκετά ώστε η άνω άκρη του περιγράμματος να βρίσκεται κάτω από την κάτω εξωτερική άκρη οποιουδήποτε δεξιά-αιωρούμενου κουτιού που προέκυψε από στοιχεία νωρίτερα στο πηγαίο έγγραφο. both - Το παραγόμενο κουτί μετακινείται κάτω από όλα τα αιωρούμενα κουτιά των προηγούμενων στοιχείων στο πηγαίο έγγραφο. none - Δεν υπάρχει περιορισμός στη θέση του κουτιού σε σχέση με τα αιωρούμενα.

```java
public String Clear { get; set; }
```
