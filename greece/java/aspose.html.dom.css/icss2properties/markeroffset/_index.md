## ICSS2Properties.MarkerOffset property

Αυτή η ιδιότητα καθορίζει την απόσταση μεταξύ των πλησιέστερων [border edges](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#border-edge) ενός πλαισίου δείκτη και του σχετικού [principal box](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#principal-box). Η μετατόπιση μπορεί να είναι είτε μήκος που καθορίζεται από τον χρήστη ([length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)) είτε επιλεγμένη από τον UA ('auto'). Τα μήκη μπορεί να είναι αρνητικά, αλλά ενδέχεται να υπάρχουν όρια ειδικά για την υλοποίηση.

```java
public String MarkerOffset { get; set; }
```
