## ICSS2Properties.CounterReset property

Η ιδιότητα ['counter-reset'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-counter-reset) περιέχει επίσης μια λίστα από ένα ή περισσότερα ονόματα μετρητών, το καθένα προαιρετικά ακολουθούμενο από έναν ακέραιο. Ο ακέραιος δίνει την τιμή στην οποία ο μετρητής ορίζεται σε κάθε εμφάνιση του στοιχείου. Η προεπιλογή είναι 0.

```java
public String CounterReset { get; set; }
```
