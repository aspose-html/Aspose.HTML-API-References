## ICSS2Properties.Height property

Αυτή η ιδιότητα καθορίζει το [ύψος περιεχομένου](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#content-height) των πλαισίων που δημιουργούνται από στοιχεία σε επίπεδο μπλοκ και [αντικατασταθέν](https://www.w3.org/TR/1998/REC-CSS2-19980512/conform.html#replaced-element) στοιχεία.

Αυτή η ιδιότητα δεν εφαρμόζεται σε μη-αντικατασταθέντα [επίπεδο inline](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) στοιχεία. Το ύψος των πλαισίων ενός μη-αντικατασταθέντος στοιχείου inline δίνεται από την τιμή της (ενδεχομένως κληρονομημένης) ['line-height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-line-height).

```java
public String Height { get; set; }
```
