## ICSS2Properties.Height property

Αυτή η ιδιότητα καθορίζει το [content height](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#content-height) των πλαισίων που δημιουργούνται από στοιχεία block-level και [replaced](https://www.w3.org/TR/1998/REC-CSS2-19980512/conform.html#replaced-element) στοιχεία.

Αυτή η ιδιότητα δεν εφαρμόζεται σε μη-αντικατεστημένα [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) στοιχεία. Το ύψος των πλαισίων ενός μη-αντικατεστημένου inline στοιχείου δίνεται από την τιμή της (ενδεχομένως κληρονομημένης) ['line-height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-line-height) ιδιότητας.

```java
public String Height { get; set; }
```
