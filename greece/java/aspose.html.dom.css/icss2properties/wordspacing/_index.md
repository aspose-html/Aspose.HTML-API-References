## ICSS2Properties.WordSpacing property

Αυτή η ιδιότητα καθορίζει τη συμπεριφορά απόστασης μεταξύ λέξεων. Οι τιμές έχουν τις ακόλουθες σημασίες:

normal - Ο κανονικός χώρος μεταξύ λέξεων, όπως ορίζεται από την τρέχουσα γραμματοσειρά και/ή το UA.'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - Αυτή η τιμή υποδεικνύει πρόσθετο χώρο μεταξύ λέξεων πέρα από τον προεπιλεγμένο χώρο μεταξύ λέξεων. Οι τιμές μπορεί να είναι αρνητικές, αλλά μπορεί να υπάρχουν όρια που εξαρτώνται από την υλοποίηση.

```java
public String WordSpacing { get; set; }
```
