## Rect class

Η διεπαφή Rect χρησιμοποιείται για την αναπαράσταση οποιασδήποτε τιμής rect. Αυτή η διεπαφή αντικατοπτρίζει τις τιμές στην υποκείμενη ιδιότητα style. Συνεπώς, οι τροποποιήσεις που γίνονται στα αντικείμενα [`CSSPrimitiveValue`](../cssprimitivevalue/) τροποποιούν την ιδιότητα style.
