## ICSSMediaRule.CSSRules property

Η ιδιότητα cssRules της διεπαφής CSSGroupingRule επιστρέφει ένα [`CSSRuleList`](../../icssrulelist/) που περιέχει μια συλλογή αντικειμένων [`CSSRule`](../../icssrule/).

```java
public ICSSRuleList CSSRules { get; }
```

### Property Value

Το χαρακτηριστικό cssRules πρέπει να επιστρέφει ένα αντικείμενο [`CSSRuleList`](../../icssrulelist/) για τους θυγατρικούς κανόνες CSS.
