## ICSSMediaRule.InsertRule method

Η μέθοδος insertRule() της διεπαφής CSSGroupingRule προσθέτει έναν νέο κανόνα CSS σε μια λίστα κανόνων CSS.

```java
public long InsertRule(String rule, long index)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| κανόνας | String | Ο κανόνας media ως CSSOMString. |
| index | Int64 | Ένας προαιρετικός δείκτης όπου θα εισαχθεί ο κανόνας· η προεπιλογή είναι 0. |

### Τιμή επιστροφής

Η μέθοδος insertRule(rule, index) επιστρέφει το αποτέλεσμα της κλήσης για την εισαγωγή ενός κανόνα CSS στους θυγατρικούς κανόνες CSS στο δείκτη.
