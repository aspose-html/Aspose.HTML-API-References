## ICSSMediaRule.Media property

Η ιδιότητα μόνο για ανάγνωση media του interface [`CSSMediaRule`](../) MediaList αντιπροσωπεύει το προοριζόμενο μέσο για τις πληροφορίες στυλ.

```java
public IMediaList Media { get; }
```

### Property Value

Το χαρακτηριστικό media πρέπει να επιστρέφει ένα αντικείμενο MediaList για τη λίστα των ερωτημάτων media που καθορίζονται με τον κανόνα @media.
