## ICSSImportRule.Href property

Η μόνο για ανάγνωση ιδιότητα href της διεπαφής CSSImportRule επιστρέφει το URL που καθορίζεται από τον κανόνα @import.

Το επιλυμένο URL θα είναι το χαρακτηριστικό href του σχετικού φύλλου στυλ.

```java
public String Href { get; }
```

### Property Value

Επιστρέφει το URL του σχετικού φύλλου στυλ που καθορίζεται από τον κανόνα @import.
