## ICSSImportRule.StyleSheet property

Το φύλλο στυλ που αναφέρεται από αυτόν τον κανόνα, εάν έχει φορτωθεί. Η τιμή αυτού του χαρακτηριστικού είναι null εάν το φύλλο στυλ δεν έχει ακόμη φορτωθεί ή εάν δεν θα φορτωθεί (π.χ. εάν το φύλλο στυλ είναι για τύπο μέσου που δεν υποστηρίζεται από τον πράκτορα χρήστη).

```java
public ICSSStyleSheet StyleSheet { get; }
```

### Property Value

Επιστρέφει το CSS Stylesheet που καθορίζεται από τον κανόνα @import. Αυτό θα είναι με τη μορφή ενός αντικειμένου [`CSSStyleSheet`](../../icssstylesheet/).
