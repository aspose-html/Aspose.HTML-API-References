## ICSSCounterStyleRule.Prefix property

Η ιδιότητα prefix της διεπαφής [`CSSCounterStyleRule`](../) λαμβάνει και ορίζει την τιμή του περιγραφέα προθέματος. Εάν ο περιγραφέας δεν έχει οριστεί τιμή, αυτό το χαρακτηριστικό επιστρέφει μια κενή συμβολοσειρά.

```java
public String Prefix { get; }
```

### Property Value

Λαμβάνει και ορίζει την τιμή του περιγραφέα προθέματος. Εάν ο περιγραφέας δεν έχει οριστεί τιμή, αυτό το χαρακτηριστικό επιστρέφει μια κενή συμβολοσειρά.
