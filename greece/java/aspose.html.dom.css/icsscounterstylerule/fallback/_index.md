## ICSSCounterStyleRule.Fallback property

Η ιδιότητα fallback του περιβάλλοντος [`CSSCounterStyleRule`](../) επιστρέφει και ορίζει την τιμή του περιγραφέα fallback. Εάν ο περιγραφέας δεν έχει οριστεί τιμή, αυτό το χαρακτηριστικό επιστρέφει μια κενή συμβολοσειρά.

```java
public String Fallback { get; }
```

### Property Value

Επιστρέφει και ορίζει την τιμή του περιγραφέα fallback. Εάν ο περιγραφέας δεν έχει οριστεί τιμή, αυτό το χαρακτηριστικό επιστρέφει μια κενή συμβολοσειρά.
