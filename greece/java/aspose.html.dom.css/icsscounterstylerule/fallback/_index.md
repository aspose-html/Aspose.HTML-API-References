## ICSSCounterStyleRule.Fallback property

Η ιδιότητα fallback του διεπαφής [`CSSCounterStyleRule`](../) λαμβάνει και ορίζει την τιμή του περιγραφέα fallback. Εάν ο περιγραφέας δεν έχει ορισμένη τιμή, αυτό το χαρακτηριστικό επιστρέφει μια κενή συμβολοσειρά.

```java
public String Fallback { get; }
```

### Property Value

Λαμβάνει και ορίζει την τιμή του περιγραφέα fallback. Εάν ο περιγραφέας δεν έχει ορισμένη τιμή, αυτό το χαρακτηριστικό επιστρέφει μια κενή συμβολοσειρά.
