## ICSSCounterStyleRule.Glyphs property

Η ιδιότητα glyphs της διεπαφής [`CSSCounterStyleRule`](../) λαμβάνει και ορίζει την τιμή του περιγραφέα symbols. Εάν ο περιγραφέας δεν έχει οριστεί τιμή, αυτό το χαρακτηριστικό επιστρέφει μια κενή συμβολοσειρά.

```java
public String Glyphs { get; }
```

### Property Value

Λαμβάνει και ορίζει την τιμή του περιγραφέα glyphs. Εάν ο περιγραφέας δεν έχει οριστεί τιμή, αυτό το χαρακτηριστικό επιστρέφει μια κενή συμβολοσειρά.
