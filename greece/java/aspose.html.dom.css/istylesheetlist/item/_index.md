## IStyleSheetList indexer

Η μέθοδος item(index) πρέπει να επιστρέφει το indexth [`CSS style sheet`](../../icssstylesheet/) στη συλλογή. Εάν δεν υπάρχει αντικείμενο με αυτόν τον δείκτη στη συλλογή, η μέθοδος πρέπει να επιστρέφει null.

```java
public ICSSStyleSheet this[int index] { get; }
```

### Τιμή Επιστροφής

Ένα αντικείμενο [`CSSStyleSheet`](../../icssstylesheet/), ή null εάν δεν υπάρχει για αυτόν τον δείκτη.

### Property Value

Ένας ακέραιος που είναι ο δείκτης του στοιχείου στη συλλογή που θα επιστραφεί.
