## IStyleSheetList.Length property

Το χαρακτηριστικό length πρέπει να επιστρέφει τον αριθμό των CSS style sheets που αντιπροσωπεύονται από τη συλλογή. Η περιοχή των έγκυρων δεικτών υποσυλλογών είναι από 0 έως length-1 συμπεριλαμβανομένου.

```java
public int Length { get; }
```

### Property Value

Ένας ακέραιος που υποδεικνύει τον αριθμό των στοιχείων στη συλλογή.
