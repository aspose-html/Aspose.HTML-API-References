## CSSPrimitiveValue.GetRectValue method

Αυτή η μέθοδος χρησιμοποιείται για την απόκτηση της τιμής Rect. Εάν αυτή η τιμή CSS δεν περιέχει τιμή rect, εγείρεται ένα DOMException. Η τροποποίηση της αντίστοιχης ιδιότητας στυλ μπορεί να επιτευχθεί χρησιμοποιώντας τη διεπαφή Rect.

```java
public abstract Rect GetRectValue()
```
