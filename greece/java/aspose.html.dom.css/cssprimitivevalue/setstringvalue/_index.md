## CSSPrimitiveValue.SetStringValue method

Μια μέθοδος για τον ορισμό της τιμής String με την καθορισμένη μονάδα. Εάν η ιδιότητα που συνδέεται με αυτήν την τιμή δεν μπορεί να αποδεχτεί την καθορισμένη μονάδα ή την τιμή String, η τιμή θα παραμείνει αμετάβλητη και θα εγερθεί ένα DOMException.

```java
public abstract void SetStringValue(ushort StringType, String StringValue)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| StringType | UInt16 | Τύπος του String. |
| StringValue | String | Η τιμή String. |
