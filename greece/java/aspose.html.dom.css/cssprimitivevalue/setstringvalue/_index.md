## CSSPrimitiveValue.SetStringValue method

Μια μέθοδος για τον ορισμό της τιμής String με την καθορισμένη μονάδα. Εάν η ιδιότητα που συνδέεται με αυτήν την τιμή δεν μπορεί να αποδεχτεί την καθορισμένη μονάδα ή την τιμή String, η τιμή θα παραμείνει αμετάβλητη και θα προκληθεί ένα DOMException.

```java
public abstract void SetStringValue(ushort StringType, String StringValue)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| StringType | UInt16 | Τύπος της συμβολοσειράς. |
| StringValue | String | Η τιμή της συμβολοσειράς. |
