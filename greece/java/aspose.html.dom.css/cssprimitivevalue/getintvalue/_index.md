## CSSPrimitiveValue.GetIntValue method

Αυτή η μέθοδος χρησιμοποιείται για την απόκτηση μιας τιμής int σε μια καθορισμένη μονάδα. Εάν αυτή η τιμή CSS δεν περιέχει τιμή int ή δεν μπορεί να μετατραπεί στην καθορισμένη μονάδα, εγείρεται ένα DOMException.

```java
public abstract int GetIntValue(ushort unitType)
```
