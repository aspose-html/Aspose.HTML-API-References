## CSSPrimitiveValue.GetFloatValue method

Αυτή η μέθοδος χρησιμοποιείται για την απόκτηση μιας τιμής float σε μια καθορισμένη μονάδα. Εάν αυτή η τιμή CSS δεν περιέχει τιμή float ή δεν μπορεί να μετατραπεί στην καθορισμένη μονάδα, εγείρεται ένα DOMException.

public abstract float GetFloatValue(ushort unitType)
