## CSSPrimitiveValue.SetFloatValue method

Μια μέθοδος για τον ορισμό της τιμής float με μια καθορισμένη μονάδα. Εάν η ιδιότητα που συνδέεται με αυτήν την τιμή δεν μπορεί να αποδεχτεί την καθορισμένη μονάδα ή την τιμή float, η τιμή θα παραμείνει αμετάβλητη και θα εγερθεί ένα DOMException.

```java
public abstract void SetFloatValue(ushort unitType, float floatValue)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| unitType | UInt16 | Τύπος της μονάδας. |
| floatValue | Single | Η τιμή float. |
