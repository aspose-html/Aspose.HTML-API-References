## CSSPrimitiveValue.SetIntValue method

Μια μέθοδος για τον ορισμό της τιμής int με συγκεκριμένη μονάδα. Εάν η ιδιότητα που συνδέεται με αυτήν την τιμή δεν μπορεί να αποδεχτεί την καθορισμένη μονάδα ή την τιμή int, η τιμή θα παραμείνει αμετάβλητη και θα προκληθεί ένα DOMException.

```java
public abstract void SetIntValue(ushort unitType, int intValue)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| unitType | UInt16 | Τύπος της μονάδας. |
| intValue | Int32 | Η τιμή int. |
