## CSSPrimitiveValue.GetCounterValue method

Αυτή η μέθοδος χρησιμοποιείται για την απόκτηση της τιμής Counter. Εάν αυτή η τιμή CSS δεν περιέχει τιμή counter, προκαλείται μια DOMException. Η τροποποίηση της αντίστοιχης ιδιότητας στυλ μπορεί να επιτευχθεί χρησιμοποιώντας τη διεπαφή Counter.

```java
public abstract Counter GetCounterValue()
```
