## CSSPrimitiveValue.GetRGBColorValue method

Αυτή η μέθοδος χρησιμοποιείται για την απόκτηση του χρώματος RGB. Εάν αυτή η τιμή CSS δεν περιέχει τιμή χρώματος RGB, προκαλείται ένα DOMException. Η τροποποίηση της αντίστοιχης ιδιότητας στυλ μπορεί να επιτευχθεί χρησιμοποιώντας τη διεπαφή RGBColor.

```java
public abstract RGBColor GetRGBColorValue()
```
