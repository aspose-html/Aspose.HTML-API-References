## ICSSRule.Type property

Ο τύπος του κανόνα, όπως ορίζεται στο [CSSOM # dom-cssrule-type](https://drafts.csswg.org/cssom/#dom-cssrule-type). Η προσδοκία είναι ότι οι μεθόδοι μετατροπής ειδικές για binding μπορούν να χρησιμοποιηθούν για να μετατρέψουν μια παρουσία της διεπαφής CSSRule στην συγκεκριμένη παράγωγη διεπαφή που υποδεικνύεται από τον τύπο.

```java
public short Type { get; }
```

### Property Value

Ένας μη αρνητικός ακέραιος που σχετίζεται με έναν συγκεκριμένο τύπο κανόνα. Αυτό το στοιχείο αρχικοποιείται όταν δημιουργείται ένας κανόνας και δεν μπορεί να αλλάξει.
