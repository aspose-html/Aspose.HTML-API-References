## ICSSRule.CSSText property

Η ιδιότητα cssText της διεπαφής [`CSSRule`](../) επιστρέφει το πραγματικό κείμενο ενός κανόνα στυλ [`CSSStyleSheet`](../../icssstylesheet/).

Σημείωση: Μην συγχέετε αυτήν την ιδιότητα με το element-style CSSStyleDeclaration.cssText.

```java
public String CSSText { get; set; }
```

### Property Value

Επιστρέφει μια σειριοποίηση του κανόνα CSS. Κατά τον ορισμό της ιδιότητας cssText δεν πρέπει να γίνει καμία ενέργεια.
