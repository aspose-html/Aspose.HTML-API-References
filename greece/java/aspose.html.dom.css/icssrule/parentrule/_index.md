## ICSSRule.ParentRule property

Εάν αυτός ο κανόνας περιέχεται μέσα σε άλλο κανόνα (π.χ. ένας κανόνας στυλ μέσα σε ένα μπλοκ @media), αυτός είναι ο κανόνας που περιέχει. Εάν αυτός ο κανόνας δεν είναι ενσωματωμένος μέσα σε κανέναν άλλο κανόνα, επιστρέφει null.

```java
public ICSSRule ParentRule { get; }
```

### Property Value

Ένα [`CSSRule`](../) που είναι ο τύπος των κανόνων που περιέχουν. Εάν ο τρέχων κανόνας βρίσκεται μέσα σε ερώτημα μέσων, αυτό θα επέστρεφε το [`CSSMediaRule`](../../icssmediarule/). Διαφορετικά επιστρέφει null.
