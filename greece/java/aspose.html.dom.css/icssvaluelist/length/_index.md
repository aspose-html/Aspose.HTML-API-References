## ICSSValueList.Length property

Η μόνο για ανάγνωση ιδιότητα length της διεπαφής CSSValueList αντιπροσωπεύει τον αριθμό των CSSValues στη λίστα. Το εύρος των έγκυρων τιμών των δεικτών είναι από 0 έως length-1, συμπεριλαμβανομένου.

```java
public int Length { get; }
```

### Property Value

Ένα unsigned long που αντιπροσωπεύει τον αριθμό των CSSValues.

## Παρατηρήσεις

Αυτή η δυνατότητα ορίστηκε αρχικά στην προδιαγραφή [DOM Style Level 2](https://www.w3.org/TR/DOM-Level-2-Style), αλλά έχει αφαιρεθεί από οποιαδήποτε προσπάθεια τυποποίησης από τότε.

Έχει αντικατασταθεί από ένα σύγχρονο, αλλά ασύμβατο, [CSS Typed Object Model API](https://developer.mozilla.org/en-US/docs/Web/API/CSS_Typed_OM_API) που τώρα βρίσκεται στην τυπική πορεία.
