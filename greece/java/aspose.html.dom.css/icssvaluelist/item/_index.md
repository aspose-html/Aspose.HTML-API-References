## ICSSValueList indexer

Αυτή η μέθοδος χρησιμοποιείται για την ανάκτηση ενός CSSValue με βάση το διατεταγμένο δείκτη. Η σειρά σε αυτή τη συλλογή αντιπροσωπεύει τη σειρά των τιμών στην ιδιότητα στυλ CSS. Εάν ο δείκτης είναι μεγαλύτερος ή ίσος με τον αριθμό των τιμών στη λίστα, επιστρέφει null.

Δείτε επίσης το [CSSOM](https://www.w3.org/TR/2000/REC-DOM-Level-2-Style-20001113/css.html#CSS-CSSValueList)[#CSSValueList](https://www.w3.org/TR/2000/REC-DOM-Level-2-Style-20001113/css.html#CSS-CSSValueList).

```java
public CSSValue this[int index] { get; }
```

### Τιμή επιστροφής

Το [`CSSValue`](../../cssvalue/) στη θέση του δείκτη στη [`CSSValueList`](../../cssvaluelist/), ή null εάν δεν είναι έγκυρος δείκτης.

### Property Value

Ο δείκτης στη συλλογή.

## Παρατηρήσεις

Αυτή η δυνατότητα ορίστηκε αρχικά στην προδιαγραφή [DOM Style Level 2](https://www.w3.org/TR/DOM-Level-2-Style), αλλά έχει αφαιρεθεί από οποιαδήποτε προσπάθεια τυποποίησης από τότε.

Έχει αντικατασταθεί από ένα σύγχρονο, αλλά ασύμβατο, [CSS Typed Object Model API](https://developer.mozilla.org/en-US/docs/Web/API/CSS_Typed_OM_API) που τώρα βρίσκεται στην τυπική πορεία.
