## ICSSKeyframeRule.Style property

Η ιδιότητα μόνο για ανάγνωση CSSKeyframeRule.style είναι η διεπαφή [`CSSStyleDeclaration`](../../icssstyledeclaration/) για το μπλοκ δηλώσεων του [`CSSKeyframeRule`](../).

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

Ένα αντικείμενο [`CSSStyleDeclaration`](../../icssstyledeclaration/), με τις ακόλουθες ιδιότητες:

σημαία υπολογισμού - Unset.declarations - Οι δηλωμένες δηλώσεις στον κανόνα, με τη σειρά που καθορίστηκαν, οι συντομευμένες ιδιότητες επεκτάθηκαν σε πλήρεις μορφές. parent CSS rule - Το αντικείμενο περιβάλλοντος, το οποίο είναι ψευδώνυμο για this.owner node - Null.
