### Property Value

Ένα αντικείμενο [`CSSStyleDeclaration`](../../icssstyledeclaration/), με τις ακόλουθες ιδιότητες:

σημαία υπολογισμού - Unset.declarations - Οι δηλωμένες δηλώσεις στον κανόνα, με τη σειρά που καθορίθηκαν, οι συντομευμένες ιδιότητες επεκτεινόμενες σε πλήρεις μορφές. γονικός κανόνας CSS - Το αντικείμενο περιβάλλοντος, το οποίο είναι ψευδώνυμο για this.owner. κόμβος - Null.
