## ICSSKeyframeRule interface

Η διεπαφή `CSSKeyframeRule` περιγράφει ένα αντικείμενο που αντιπροσωπεύει ένα σύνολο στυλ για ένα συγκεκριμένο keyframe. Αντιστοιχεί στα περιεχόμενα ενός μοναδικού keyframe μιας εντολής @keyframes at-rule.

```java
public interface ICSSKeyframeRule : ICSSRule
```
