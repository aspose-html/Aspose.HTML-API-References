## IElementCSSInlineStyle interface

Οι ενσωματωμένες πληροφορίες στυλ που συνδέονται με στοιχεία εκτίθενται μέσω του χαρακτηριστικού style. Αυτό αντιπροσωπεύει το περιεχόμενο του χαρακτηριστικού STYLE για στοιχεία HTML (ή στοιχεία σε άλλα σχήματα ή DTD που χρησιμοποιούν το χαρακτηριστικό STYLE με τον ίδιο τρόπο). Η προσδοκία είναι ότι μια παρουσία της διεπαφής ElementCSSInlineStyle μπορεί να ληφθεί χρησιμοποιώντας μεθόδους μετατροπής ειδικές για το binding σε μια παρουσία της διεπαφής Element όταν το στοιχείο υποστηρίζει ενσωματωμένες πληροφορίες στυλ CSS.
