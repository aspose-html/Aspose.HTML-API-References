## IElementCSSInlineStyle.Style property

Το χαρακτηριστικό style πρέπει να επιστρέφει ένα αντικείμενο μπλοκ δήλωσης CSS του οποίου η σημαία computed δεν είναι ορισμένη, του οποίου ο γονικός κανόνας CSS είναι null, και του οποίου ο ιδιοκτήτης κόμβος είναι το αντικείμενο περιβάλλοντος.

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

Το συσχετισμένο μπλοκ δήλωσης CSS για τον κόμβο ή null εάν δεν υπάρχει συσχετισμένο μπλοκ δήλωσης CSS.
