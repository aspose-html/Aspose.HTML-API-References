## IViewCSS interface

Η διεπαφή IViewCSS αντιπροσωπεύει μια επέκταση του αντικειμένου Window που παρέχει πρόσβαση στις τιμές όλων των ιδιοτήτων CSS ενός στοιχείου.

Το στυλ CSS για ένα δεδομένο στοιχείο μπορεί να ληφθεί χρησιμοποιώντας τη μέθοδο IViewCSS.GetComputedStyle().

```java
public interface IViewCSS : IAbstractView
```
