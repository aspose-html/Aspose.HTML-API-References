## CSSEngineMode enumeration

Καθορίζει τη λειτουργία CSSEngine. Οι τιμές έχουν την ακόλουθη σημασία:

default - Ο αναλυτής CSS θα λειτουργεί σύμφωνα με τις συστάσεις του w3c και δεν υποστηρίζει προσαρμοσμένες επεκτάσεις. not-strict - Όλες οι μη τεκμηριωμένες ιδιότητες θα αναλυθούν και μπορούν να προσπελαστούν μέσω.

```java
[Flags]
public enum CSSEngineMode
```

### Τιμές

| Όνομα | Τιμή | Περιγραφή |
| --- | --- | --- |
| Default | `0` | Ο αναλυτής CSS θα λειτουργεί σύμφωνα με τις συστάσεις του w3c και δεν υποστηρίζει τις προσαρμοσμένες επεκτάσεις. |
| NotStrict | `1` | Ο αναλυτής CSS θα λειτουργεί σε λειτουργία not strict. Όλες οι μη τεκμηριωμένες ιδιότητες θα αναλυθούν και μπορούν να προσπελαστούν μέσω. |
