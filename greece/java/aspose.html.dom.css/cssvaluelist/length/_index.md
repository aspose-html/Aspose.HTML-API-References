## CSSValueList.Length property

Η μόνο για ανάγνωση ιδιότητα length της διεπαφής CSSValueList αντιπροσωπεύει τον αριθμό των CSSValues στη λίστα. Το εύρος των έγκυρων τιμών των δεικτών είναι από 0 έως length-1 συμπεριλαμβανομένα.

```java
public int Length { get; }
```

### Property Value

Ένα unsigned long που αντιπροσωπεύει τον αριθμό των CSSValues στην τρέχουσα παρουσία.
