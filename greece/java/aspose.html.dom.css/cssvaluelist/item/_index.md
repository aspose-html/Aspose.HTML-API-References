## CSSValueList indexer

Η μέθοδος item() της διεπαφής CSSValueList χρησιμοποιείται για την ανάκτηση ενός CSSValue με βάση τον διατεταγμένο δείκτη.

Η σειρά σε αυτή τη συλλογή αντιπροσωπεύει τη σειρά των τιμών στην ιδιότητα στυλ CSS. Εάν ο δείκτης είναι μεγαλύτερος ή ίσος με τον αριθμό των τιμών στη λίστα, αυτή η μέθοδος επιστρέφει null.

```java
public CSSValue this[int index] { get; }
```

### Τιμή επιστροφής

Ένα αντικείμενο CSSValue στη θέση του δείκτη στη CSSValueList, ή null εάν αυτό δεν είναι έγκυρος δείκτης.

### Property Value

Ένα unsigned long που αντιπροσωπεύει τον δείκτη της τιμής CSS μέσα στη συλλογή.
