## CSSValueList class

Η διεπαφή CSSValueList παρέχει την αφαίρεση μιας ταξινομημένης συλλογής τιμών CSS.

Σημείωση: Αυτή η διεπαφή ήταν μέρος μιας προσπάθειας δημιουργίας ενός τυποποιημένου CSS Object Model. Η προσπάθεια αυτή έχει εγκαταλειφθεί, και οι περισσότερες προγράμματα περιήγησης δεν την υλοποιούν.

```java
public class CSSValueList : CSSValue, ICSSValueList, IEnumerable<CSSValue>
```
