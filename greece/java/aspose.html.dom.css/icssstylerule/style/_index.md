## ICSSStyleRule.Style property

Η ιδιότητα style μόνο για ανάγνωση είναι η διεπαφή [`CSSStyleDeclaration`](../../icssstyledeclaration/) για το μπλοκ δήλωσης του [`CSSStyleRule`](../).

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

Το χαρακτηριστικό style πρέπει να επιστρέφει ένα αντικείμενο CSSStyleDeclaration για τον κανόνα στυλ, με τις ακόλουθες ιδιότητες:

computed flag - Unset.declarations - Οι δηλωμένες δηλώσεις στον κανόνα, με την καθορισμένη σειρά. parent CSS rule - Το αντικείμενο περιβάλλοντος. owner node - Null.
