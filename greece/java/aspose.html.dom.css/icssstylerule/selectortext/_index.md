## ICSSStyleRule.SelectorText property

Η κειμενική αναπαράσταση του επιλογέα για το σύνολο κανόνων. Η υλοποίηση μπορεί να έχει αφαιρέσει ασήμαντα κενά κατά την ανάλυση του επιλογέα.

```java
public String SelectorText { get; }
```

### Property Value

Το χαρακτηριστικό style πρέπει να επιστρέφει ένα αντικείμενο CSSStyleDeclaration για τον κανόνα στυλ.
