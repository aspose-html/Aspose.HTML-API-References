## ICSSStyleRule interface

Η διεπαφή CSSStyleRule αντιπροσωπεύει έναν μοναδικό κανόνα στυλ CSS. Το χαρακτηριστικό selectorText, κατά την ανάκτηση, πρέπει να επιστρέφει το αποτέλεσμα της σειριοποίησης της σχετικής ομάδας επιλογέων.

```java
public interface ICSSStyleRule : ICSSRule
```
