## IStyleSheet.Title property

Η ιδιότητα title της διεπαφής [`StyleSheet`](../) επιστρέφει τον συμβουλευτικό τίτλο του τρέχοντος φύλλου στυλ.

Ο τίτλος συχνά καθορίζεται στο [`ownerNode`](../ownernode/).

```java
public String Title { get; }
```

### Property Value

Το χαρακτηριστικό parentStyleSheet πρέπει να επιστρέφει το γονικό [`CSS style sheet`](../../icssstylesheet/).
