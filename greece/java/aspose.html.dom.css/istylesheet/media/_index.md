## IStyleSheet.Media property

Η ιδιότητα media της διεπαφής [`StyleSheet`](../) καθορίζει το προοριζόμενο μέσο προορισμού για τις πληροφορίες στυλ. Είναι ένα αντικείμενο read‑only, παρόμοιο με πίνακα [`MediaList`](../../imedialist/) και μπορεί να αφαιρεθεί με deleteMedium() και να προστεθεί με appendMedium().

```java
public IMediaList Media { get; }
```

### Property Value

Το χαρακτηριστικό media πρέπει να επιστρέφει το αντικείμενο [`MediaList`](../../imedialist/) που σχετίζεται με το φύλλο στυλ CSS.
