## IStyleSheet.OwnerNode property

Ο κόμβος που συσχετίζει αυτό το φύλλο στυλ με το έγγραφο. Για HTML, αυτό μπορεί να είναι το αντίστοιχο στοιχείο LINK ή STYLE. Για XML, μπορεί να είναι η οδηγία επεξεργασίας σύνδεσης. Για φύλλα στυλ που περιλαμβάνονται από άλλα φύλλα στυλ, η τιμή αυτού του χαρακτηριστικού είναι null.

```java
public Node OwnerNode { get; }
```

### Property Value

Το χαρακτηριστικό ownerNode πρέπει να επιστρέφει τον ιδιοκτήτη κόμβο.

## Παρατηρήσεις

Για φύλλα στυλ που περιλαμβάνονται από άλλα φύλλα στυλ, όπως με @import, η τιμή αυτής της ιδιότητας είναι null.
