## IStyleSheet.ParentStyleSheet property

Για γλώσσες φύλλων στυλ που υποστηρίζουν την έννοια της ένθεσης φύλλων στυλ, αυτό το χαρακτηριστικό αντιπροσωπεύει το φύλλο στυλ που περιλαμβάνει, εάν υπάρχει. Εάν το φύλλο στυλ είναι ένα φύλλο στυλ ανώτερου επιπέδου ή η γλώσσα φύλλων στυλ δεν υποστηρίζει ένθεση, η τιμή αυτού του χαρακτηριστικού είναι null.

```java
public IStyleSheet ParentStyleSheet { get; }
```

### Property Value

Το χαρακτηριστικό parentStyleSheet πρέπει να επιστρέφει το γονικό [`CSS style sheet`](../../icssstylesheet/).

## Παρατηρήσεις

Αυτή η ιδιότητα επιστρέφει null εάν το τρέχον φύλλο στυλ είναι φύλλο στυλ ανώτερου επιπέδου ή εάν η ένθεση φύλλων στυλ δεν υποστηρίζεται.
