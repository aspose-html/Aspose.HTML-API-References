## IStyleSheet.Href property

Η ιδιότητα href της διεπαφής [`StyleSheet`](../) επιστρέφει τη θέση του φύλλου στυλ.

```java
public String Href { get; }
```

### Property Value

Το uri είναι μια String που περιέχει το URI του φύλλου στυλ.

## Παρατηρήσεις

Εάν το φύλλο στυλ είναι συνδεδεμένο φύλλο στυλ, η τιμή του χαρακτηριστικού του είναι η θέση του. Για ενσωματωμένα φύλλα στυλ, η τιμή αυτού του χαρακτηριστικού είναι NULL.

Αυτή η ιδιότητα είναι μόνο για ανάγνωση σε Firefox, Opera, Google Chrome και Safari, και είναι ανάγνωση/εγγραφή σε Internet Explorer.
