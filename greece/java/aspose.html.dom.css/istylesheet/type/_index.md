## IStyleSheet.Type property

Αυτό καθορίζει τη γλώσσα φύλλου στυλ για αυτό το φύλλο στυλ. Η γλώσσα φύλλου στυλ καθορίζεται ως τύπος περιεχομένου (π.χ. "text/css").

```java
public String Type { get; }
```

### Property Value

Το χαρακτηριστικό type πρέπει να επιστρέφει τον τύπο.
