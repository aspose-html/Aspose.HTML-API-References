## RGBColor.Red property

Λαμβάνει την τιμή του κόκκινου συστατικού αυτής της δομής Color.

```java
public CSSPrimitiveValue Red { get; }
```

### Property Value

Η τιμή του κόκκινου συστατικού αυτού του Color.

## Παρατηρήσεις

Το χρώμα κάθε pixel αναπαρίσταται ως ένας 32‑bit αριθμός: 8 bit για το άλφα, το κόκκινο, το πράσινο και το μπλε (ARGB). Το συστατικό άλφα καθορίζει τη διαφάνεια του χρώματος: 0 είναι πλήρως διαφανές, και 255 είναι πλήρως αδιαφανές. Αντίστοιχα, μια τιμή A ίση με 255 αντιπροσωπεύει ένα αδιαφανές χρώμα. Μια τιμή A από 1 έως 254 αντιπροσωπεύει ένα ημιδιαφανές χρώμα. Το χρώμα γίνεται πιο αδιαφανές καθώς το A πλησιάζει το 255.
