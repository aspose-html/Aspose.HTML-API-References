## RGBColor.Green property

Λαμβάνει την τιμή του πράσινου συστατικού αυτής της δομής Color.

```java
public CSSPrimitiveValue Green { get; }
```

### Property Value

Η τιμή του πράσινου συστατικού αυτού του Χρώματος.

## Παρατηρήσεις

Το χρώμα κάθε pixel αναπαρίσταται ως ένας 32-bit αριθμός: 8 bits για το alpha, το κόκκινο, το πράσινο και το μπλε (ARGB). Το συστατικό alpha καθορίζει τη διαφάνεια του χρώματος: 0 είναι πλήρως διαφανές, και 255 είναι πλήρως αδιαφανές. Ομοίως, μια τιμή A ίση με 255 αντιπροσωπεύει ένα αδιαφανές χρώμα. Μια τιμή A από 1 έως 254 αντιπροσωπεύει ένα ημιδιαφανές χρώμα. Το χρώμα γίνεται πιο αδιαφανές καθώς το A πλησιάζει το 255.
