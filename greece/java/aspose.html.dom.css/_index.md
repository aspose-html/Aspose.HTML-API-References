Παρέχει διεπαφές για την Προδιαγραφή Στυλ DOM Επίπεδο 2. Τα Cascading Style Sheets (CSS) είναι μια γλώσσα φύλλων στυλ που επιτρέπει στους δημιουργούς και χρήστες να προσθέτουν στυλ (π.χ. γραμματοσειρές και απόσταση) σε δομημένα έγγραφα (π.χ. έγγραφα HTML και εφαρμογές XML). Υποστηρίζει φύλλα στυλ ειδικά για μέσα, ώστε οι δημιουργοί να προσαρμόζουν την παρουσίαση των εγγράφων τους σε οπτικούς περιηγητές, ακουστικές συσκευές, εκτυπωτές, συσκευές braille, φορητές συσκευές κ.λπ. Υποστηρίζει επίσης τοποθέτηση περιεχομένου, διάταξη πινάκων, δυνατότητες διεθνοποίησης και ορισμένες ιδιότητες σχετικές με το περιβάλλον χρήστη. Διαχωρίζοντας το στυλ παρουσίασης των εγγράφων από το περιεχόμενό τους, το CSS απλοποιεί τη δημιουργία ιστοσελίδων και τη συντήρηση του ιστότοπου.
