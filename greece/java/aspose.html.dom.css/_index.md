Παρέχει διεπαφές για την Προδιαγραφή Στυλ DOM Επιπέδου 2. Τα Cascading Style Sheets (CSS) είναι μια γλώσσα φύλλων στυλ που επιτρέπει σε συγγραφείς και χρήστες να προσθέτουν στυλ (π.χ. γραμματοσειρές και απόσταση) σε δομημένα έγγραφα (π.χ. έγγραφα HTML και εφαρμογές XML). Υποστηρίζει φύλλα στυλ ειδικά για μέσα, ώστε οι συγγραφείς να προσαρμόζουν την παρουσίαση των εγγράφων τους σε οπτικούς περιηγητές, ακουστικές συσκευές, εκτυπωτές, συσκευές braille, φορητές συσκευές κ.λπ. Υποστηρίζει επίσης τοποθέτηση περιεχομένου, διάταξη πινάκων, δυνατότητες για διεθνοποίηση και ορισμένες ιδιότητες σχετικές με το περιβάλλον χρήστη. Διαχωρίζοντας το στυλ παρουσίασης των εγγράφων από το περιεχόμενό τους, το CSS απλοποιεί τη δημιουργία ιστοσελίδων και τη συντήρηση του ιστότοπου.
