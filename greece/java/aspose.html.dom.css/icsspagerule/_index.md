## ICSSPageRule interface

Η διεπαφή CSSPageRule αντιπροσωπεύει έναν κανόνα @page σε φύλλο στυλ CSS. Ο κανόνας @page χρησιμοποιείται για τον καθορισμό των διαστάσεων, του προσανατολισμού, των περιθωρίων κ.λπ. ενός πλαισίου σελίδας για έντυπα μέσα.

public interface ICSSPageRule : ICSSRule
