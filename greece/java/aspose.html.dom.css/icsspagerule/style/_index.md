## ICSSPageRule.Style property

Η μόνο για ανάγνωση ιδιότητα style της διεπαφής [`CSSPageRule`](../) επιστρέφει ένα αντικείμενο [`CSSStyleDeclaration`](../../icssstyledeclaration/). Αυτό αντιπροσωπεύει ένα αντικείμενο που είναι μπλοκ δήλωσης CSS και εκθέτει πληροφορίες στυλ και διάφορες μεθόδους και ιδιότητες σχετικές με το στυλ.

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

Ένα αντικείμενο [`CSSStyleDeclaration`](../../icssstyledeclaration/) που αντιπροσωπεύει ένα μπλοκ δήλωσης CSS.
