## ICSSPageRule.SelectorText property

Η ιδιότητα selectorText της διεπαφής [`CSSPageRule`](../) λαμβάνει και ορίζει τους επιλογείς που σχετίζονται με το [`CSSPageRule`](../).

```java
public String SelectorText { get; set; }
```

### Property Value

Το χαρακτηριστικό selectorText, κατά την ανάγνωση, πρέπει να επιστρέφει το αποτέλεσμα της σειριοποίησης της σχετικής λίστας επιλογέων σελίδας CSS.
