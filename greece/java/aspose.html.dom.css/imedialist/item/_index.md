## IMediaList indexer

Η μέθοδος item(index) πρέπει να επιστρέφει μια σειριοποίηση του ερωτήματος μέσων στη συλλογή ερωτημάτων μέσων που δίνεται από το index, ή null, εάν το index είναι μεγαλύτερο ή ίσο με τον αριθμό των ερωτημάτων μέσων στη συλλογή.

```java
public String this[int index] { get; }
```

### Τιμή Επιστροφής

Επιστρέφει ένα String που αντιπροσωπεύει ένα ερώτημα μέσων ως κείμενο, δεδομένης της τιμής index του ερωτήματος μέσα στο [`MediaList`](../).

### Property Value

Ένας ακέραιος που είναι ο δείκτης του στοιχείου στη συλλογή που θα επιστραφεί.
