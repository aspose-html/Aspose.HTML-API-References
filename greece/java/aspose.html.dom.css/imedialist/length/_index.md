## IMediaList.Length property

Το χαρακτηριστικό length πρέπει να επιστρέφει τον αριθμό των ερωτημάτων μέσων στη συλλογή ερωτημάτων μέσων. Η περιοχή των έγκυρων μέσων είναι από 0 έως length-1 συμπεριλαμβανομένα.

```java
public long Length { get; }
```

### Property Value

Επιστρέφει τον αριθμό των ερωτημάτων μέσων στη [`MediaList`](../).
