## ICSSStyleSheet.CSSRules property

Η ιδιότητα μόνο για ανάγνωση cssRules του CSSStyleSheet επιστρέφει μια ζωντανή [`CSSRuleList`](../../icssrulelist/) που παρέχει μια σε πραγματικό χρόνο, ενημερωμένη λίστα με κάθε κανόνα CSS που αποτελεί το φύλλο στυλ. Κάθε στοιχείο στη λίστα είναι ένα [`CSSRule`](../../icssrule/) που ορίζει έναν μοναδικό κανόνα.

```java
public ICSSRuleList CSSRules { get; }
```

### Property Value

Μια ζωντανά ενημερούμενη [`CSSRuleList`](../../icssrulelist/) που περιέχει όλους τους κανόνες CSS που συνθέτουν το φύλλο στυλ. Κάθε καταχώρηση στη λίστα κανόνων είναι ένα αντικείμενο [`CSSRule`](../../icssrule/) που περιγράφει έναν κανόνα του φύλλου στυλ.
