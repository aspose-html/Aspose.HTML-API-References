## ICSSStyleSheet.OwnerRule property

Η μόνο για ανάγνωση ιδιότητα ownerRule του CSSStyleSheet επιστρέφει το [`CSSImportRule`](../../icssimportrule/) που αντιστοιχεί στον κανόνα @import που εισήγαγε το φύλλο στυλ στο έγγραφο. Εάν το φύλλο στυλ δεν είχε εισαχθεί στο έγγραφο χρησιμοποιώντας @import, η επιστρεφόμενη τιμή είναι null.

```java
public ICSSRule OwnerRule { get; }
```

### Property Value

Ένα CSSImportRule που αντιστοιχεί στον κανόνα @import που εισήγαγε το φύλλο στυλ στο έγγραφο. Εάν το φύλλο στυλ δεν είχε εισαχθεί στο έγγραφο χρησιμοποιώντας @import, η επιστρεφόμενη τιμή είναι null.
