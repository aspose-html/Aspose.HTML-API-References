## ICSSStyleDeclaration.CSSText property

Η αναγνώσιμη κειμενική αναπαράσταση του μπλοκ δήλωσης (εξαιρουμένων των περιβάλλουσων αγκυλών). Η ρύθμιση αυτού του χαρακτηριστικού θα οδηγήσει στην ανάλυση της νέας τιμής και στην επαναφορά όλων των ιδιοτήτων στο μπλοκ δήλωσης, συμπεριλαμβανομένης της αφαίρεσης ή προσθήκης ιδιοτήτων.

```java
public String CSSText { get; set; }
```

### Property Value

Η ρύθμιση αυτού του χαρακτηριστικού αλλάζει το ενσωματωμένο στυλ. Εάν θέλετε μια κειμενική αναπαράσταση ενός υπολογισμένου μπλοκ δήλωσης, μπορείτε να το λάβετε με JSON.Stringify().
