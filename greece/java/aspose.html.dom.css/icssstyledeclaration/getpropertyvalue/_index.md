## ICSSStyleDeclaration.GetPropertyValue method

Η διεπαφή μεθόδου CSSStyleDeclaration.getPropertyValue() επιστρέφει ένα String που περιέχει την τιμή μιας συγκεκριμένης ιδιότητας CSS.

```java
public String GetPropertyValue(String propertyName)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| propertyName | String | propertyName είναι ένα String που αντιπροσωπεύει το όνομα της ιδιότητας (με παύλες) που θα ελεγχθεί. |

### Τιμή επιστροφής

value είναι ένα String που περιέχει την τιμή της ιδιότητας. Εάν δεν έχει οριστεί, επιστρέφει το κενό String.
