## SetProperty(String, String) {#setproperty}

Η διεπαφή μεθόδου CSSStyleDeclaration.setProperty() χρησιμοποιείται για να ορίσει μια τιμή ιδιότητας με προεπιλεγμένη προτεραιότητα μέσα σε αυτό το μπλοκ δήλωσης. Η προεπιλεγμένη προτεραιότητα δεν είναι "important", δηλαδή String.Empty.

```java
public void SetProperty(String propertyName, String value)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| propertyName | String | Μια String που αντιπροσωπεύει το όνομα της ιδιότητας CSS (με παύλες) που θα τροποποιηθεί. |
| τιμή | String | Μια String που περιέχει τη νέα τιμή της ιδιότητας. Εάν δεν καθοριστεί, θεωρείται κενή String. |

## SetProperty(String, String, String) {#setproperty_1}

Η διεπαφή μεθόδου CSSStyleDeclaration.setProperty() χρησιμοποιείται για να ορίσει μια τιμή ιδιότητας με προεπιλεγμένη προτεραιότητα μέσα σε αυτό το μπλοκ δήλωσης. Η προεπιλεγμένη προτεραιότητα δεν είναι "important", δηλαδή String.Empty.

```java
public void SetProperty(String propertyName, String value, String priority)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| propertyName | String | Μια String που αντιπροσωπεύει το όνομα της ιδιότητας CSS (με παύλες) που θα τροποποιηθεί. |
| τιμή | String | Μια String που περιέχει τη νέα τιμή της ιδιότητας. Εάν δεν καθοριστεί, θεωρείται κενή String. |
| προτεραιότητα | String | Μια String που επιτρέπει τον ορισμό της προτεραιότητας "important" του CSS. Εάν δεν καθοριστεί, θεωρείται κενή String. Οι ακόλουθες τιμές γίνονται αποδεκτές: τιμή String "important", λέξη-κλειδί undefined ή κενή τιμή String "". |
