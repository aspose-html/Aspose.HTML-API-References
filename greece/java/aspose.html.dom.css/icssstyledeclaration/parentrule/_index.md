## ICSSStyleDeclaration.ParentRule property

Η ιδιότητα μόνο για ανάγνωση CSSStyleDeclaration.parentRule επιστρέφει ένα CSSRule που είναι ο γονέας αυτού του μπλοκ στυλ, π.χ. ένα [`CSSStyleRule`](../../icssstylerule/) που αντιπροσωπεύει το στυλ για έναν CSS selector.

```java
public ICSSRule ParentRule { get; }
```

### Property Value

Ο κανόνας CSS που περιέχει αυτό το μπλοκ δήλωσης ή null εάν αυτό το [`CSSStyleDeclaration`](../) δεν είναι συνδεδεμένο με ένα [`CSSRule`](../../icssrule/).
