## ICSSStyleDeclaration.GetPropertyPriority method

Χρησιμοποιείται για την ανάκτηση της προτεραιότητας μιας ιδιότητας CSS (π.χ. ο προσδιοριστής \"important\" ) εάν η ιδιότητα έχει οριστεί ρητά σε αυτό το μπλοκ δήλωσης.

```java
public String GetPropertyPriority(String propertyName)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| propertyName | String | property είναι ένα DOMString που αντιπροσωπεύει το όνομα της ιδιότητας που θα ελεγχθεί. |

### Τιμή Επιστροφής

priority είναι ένα DOMString που αντιπροσωπεύει την προτεραιότητα (π.χ. \"important\") εάν υπάρχει. Εάν δεν υπάρχει, επιστρέφει το κενό String.
