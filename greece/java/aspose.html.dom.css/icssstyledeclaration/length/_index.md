## ICSSStyleDeclaration.Length property

Η ιδιότητα μόνο για ανάγνωση επιστρέφει έναν ακέραιο αριθμό ιδιοτήτων που έχουν οριστεί ρητά σε αυτό το μπλοκ δήλωσης CSS. Η περιοχή των έγκυρων δεικτών είναι από 0 έως length-1 συμπεριλαμβανομένου.

```java
public int Length { get; }
```

### Property Value

Ένας ακέραιος που παρέχει τον αριθμό των στυλ που έχουν οριστεί ρητά στον γονέα του αντικειμένου.
