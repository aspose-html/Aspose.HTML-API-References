## ICSSKeyframesRule.FindRule method

Η μέθοδος findRule επιστρέφει τον κανόνα με κλειδί που ταιριάζει με το δοσμένο κλειδί. Εάν δεν υπάρχει τέτοιος κανόνας, επιστρέφεται τιμή null.

```java
public ICSSKeyframeRule FindRule(String key)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| key | String | Το κλειδί που περιγράφει τον κανόνα προς εύρεση. Το κλειδί πρέπει να αντιστοιχεί σε αριθμό μεταξύ 0 και 1, αλλιώς ο κανόνας αγνοείται. |

### Τιμή Επιστροφής

Επιστρέφει το τελευταίο δηλωμένο [`CSSKeyframeRule`](../../icsskeyframerule/) που ταιριάζει με τον καθορισμένο επιλογέα keyframe. Εάν δεν υπάρχει κανένας ταιριαστός κανόνας, η μέθοδος δεν κάνει τίποτα.
