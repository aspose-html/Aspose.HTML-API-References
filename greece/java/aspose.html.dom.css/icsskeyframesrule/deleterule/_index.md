## ICSSKeyframesRule.DeleteRule method

Η μέθοδος deleteRule διαγράφει το [`CSSKeyframeRule`](../../icsskeyframerule/) με το δοσμένο κλειδί. Εάν δεν υπάρχει κανένας κανόνας με αυτό το κλειδί, η μέθοδος δεν κάνει τίποτα.

```java
public void DeleteRule(String key)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| κλειδί | String | Το κλειδί που περιγράφει τον κανόνα προς διαγραφή. Το κλειδί πρέπει να αντιστοιχεί σε αριθμό μεταξύ 0 και 1, αλλιώς ο κανόνας αγνοείται. |
