## IDocumentStyle interface

Η διεπαφή DocumentStyle παρέχει έναν μηχανισμό με τον οποίο μπορούν να ανακτηθούν τα φύλλα στυλ που είναι ενσωματωμένα σε ένα έγγραφο. Η προσδοκία είναι ότι μια παρουσία της διεπαφής DocumentStyle μπορεί να ληφθεί χρησιμοποιώντας μεθόδους μετατροπής ειδικές για το binding σε μια παρουσία της διεπαφής Document.

Δείτε επίσης την [Document Object Model (DOM) Level 2 Style Specification](http://www.w3.org/TR/2000/REC-DOM-Level-2-Style-20001113).
