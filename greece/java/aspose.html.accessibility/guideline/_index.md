## Guideline class

Οδηγίες - το επόμενο επίπεδο μετά τις αρχές. Δεν είναι δοκιμαστικές, αλλά περιγράφουν πλαίσια και γενικούς στόχους που βοηθούν τους συγγραφείς να κατανοήσουν τα κριτήρια επιτυχίας και να εφαρμόσουν καλύτερα τις τεχνικές. Οι οδηγίες είναι μια λίστα κριτηρίων αποδοχής με τύπο RuleDirectory{Criterion}.
