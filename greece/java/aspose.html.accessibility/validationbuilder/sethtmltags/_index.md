## ValidationBuilder.SetHTMLTags method

Λίστα με ετικέτες html για έλεγχο. Εάν οι ετικέτες δεν καθοριστούν ρητά, τότε ο πίνακας ετικετών είναι κενός και ο έλεγχος περνάει σε όλες.

```java
public ValidationBuilder SetHTMLTags(params String[] tags)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| ετικέτες | String[] | λίστα ετικετών html - όπου η τιμή είναι μια περιγραφή String της ετικέτας |

### Τιμή επιστροφής

ορίστε τις ετικέτες και αρχικοποιήστε στις ρυθμίσεις.
