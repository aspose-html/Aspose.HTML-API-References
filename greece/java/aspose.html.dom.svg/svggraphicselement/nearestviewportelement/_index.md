## SVGGraphicsElement.NearestViewportElement property

Το στοιχείο που καθόρισε το τρέχον viewport. Συχνά, το πιο κοντινό πρόγονο στοιχείο ‘svg’. Null εάν το τρέχον στοιχείο είναι το εξωτερικότερο στοιχείο svg.

```java
public SVGElement NearestViewportElement { get; }
```

### Property Value

Το πιο κοντινό στοιχείο viewport.
