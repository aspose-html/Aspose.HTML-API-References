## SVGGraphicsElement.GetScreenCTM method

Επιστρέφει τον πίνακα μετασχηματισμού από τις τρέχουσες μονάδες χρήστη (δηλαδή, μετά την εφαρμογή του χαρακτηριστικού ‘transform’, εφόσον υπάρχει) στην αντίληψη του γονικού πράκτορα χρήστη για ένα "pixel". Για συσκευές απεικόνισης, ιδανικά αυτό αντιπροσωπεύει ένα φυσικό pixel οθόνης. Για άλλες συσκευές ή περιβάλλοντα όπου τα φυσικά μεγέθη pixel δεν είναι γνωστά, μπορεί να χρησιμοποιηθεί ένας αλγόριθμος παρόμοιος με τον ορισμό του CSS2 για ένα "pixel". Σημειώστε ότι επιστρέφεται null εάν αυτό το στοιχείο δεν είναι συνδεδεμένο στο δέντρο του εγγράφου. Αυτή η μέθοδος θα μπορούσε να ονομαζόταν πιο κατάλληλα getClientCTM, αλλά το όνομα getScreenCTM διατηρείται για ιστορικούς λόγους.

```java
public SVGMatrix GetScreenCTM()
```

### Τιμή Επιστροφής

Ένα αντικείμενο SVGMatrix που ορίζει τον δεδομένο πίνακα μετασχηματισμού.
