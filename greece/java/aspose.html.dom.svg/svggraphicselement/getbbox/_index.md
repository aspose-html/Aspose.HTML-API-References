## SVGGraphicsElement.GetBBox method

Επιστρέφει το ακριβές πλαίσιο περιορισμού στο τρέχον χώρο χρήστη (δηλαδή, μετά την εφαρμογή του χαρακτηριστικού ‘transform’, εάν υπάρχει) στη γεωμετρία όλων των περιεχόμενων στοιχείων γραφικών, εξαιρουμένων των περιγράμματος, αποκοπής, μάσκας και εφέ φίλτρου). Σημειώστε ότι η μέθοδος getBBox πρέπει να επιστρέφει το πραγματικό πλαίσιο περιορισμού τη στιγμή που κλήθηκε, ακόμη και αν το στοιχείο δεν έχει ακόμη αποδοθεί.

```java
public SVGRect GetBBox()
```

### Τιμή επιστροφής

Ένα αντικείμενο SVGRect που ορίζει το πλαίσιο περιορισμού.
