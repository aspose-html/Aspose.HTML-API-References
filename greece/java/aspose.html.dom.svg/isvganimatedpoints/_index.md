## ISVGAnimatedPoints interface

Η διεπαφή SVGAnimatedPoints υποστηρίζει στοιχεία που έχουν ένα χαρακτηριστικό ‘points’ που περιέχει μια λίστα συντεταγμένων τιμών και που υποστηρίζει τη δυνατότητα animation αυτού του χαρακτηριστικού. Επιπλέον, το χαρακτηριστικό ‘points’ στο αρχικό στοιχείο που προσπελαύνεται μέσω του XML DOM (π.χ., χρησιμοποιώντας την κλήση μεθόδου getAttribute()) θα αντικατοπτρίζει τυχόν αλλαγές που έγιναν στα points.

```java
public interface ISVGAnimatedPoints
```
