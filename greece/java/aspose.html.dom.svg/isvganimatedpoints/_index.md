## ISVGAnimatedPoints interface

Η διεπαφή SVGAnimatedPoints υποστηρίζει στοιχεία που έχουν χαρακτηριστικό ‘points’ το οποίο περιέχει μια λίστα τιμών συντεταγμένων και υποστηρίζει τη δυνατότητα animation αυτού του χαρακτηριστικού. Επιπλέον, το χαρακτηριστικό ‘points’ στο αρχικό στοιχείο που προσπελάζεται μέσω του XML DOM (π.χ., χρησιμοποιώντας την κλήση μεθόδου getAttribute()) θα αντικατοπτρίζει τυχόν αλλαγές που έγιναν στα points.

```java
public interface ISVGAnimatedPoints
```
