## SVGElementInstance class

Το ριζικό αντικείμενο κάθε δέντρου σκιάς στοιχείου use υλοποιεί τη διεπαφή SVGUseElementShadowRoot. Αυτή η διεπαφή δεν ορίζει επί του παρόντος επεκτάσεις στις ιδιότητες και μεθόδους που ορίζονται για τη διεπαφή ShadowRoot και το μίξη DocumentOrShadowRoot. Ωστόσο, το δέντρο που ριζώνει σε αυτόν τον κόμβο είναι εντελώς μόνο για ανάγνωση από την προοπτική των σεναρίων του δημιουργού.

```java
public class SVGElementInstance : ShadowRoot
```
