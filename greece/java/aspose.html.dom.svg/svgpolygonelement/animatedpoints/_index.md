## SVGPolygonElement.AnimatedPoints property

Παρέχει πρόσβαση στα τρέχοντα κινούμενα περιεχόμενα της ιδιότητας ‘points’. Εάν η δεδομένη ιδιότητα ή ιδιότητα βρίσκεται σε κίνηση, περιέχει την τρέχουσα κινούμενη τιμή της ιδιότητας ή ιδιότητας. Εάν η δεδομένη ιδιότητα ή ιδιότητα δεν βρίσκεται αυτή τη στιγμή σε κίνηση, περιέχει την ίδια τιμή με το points.

```java
public SVGPointList AnimatedPoints { get; }
```

### Property Value

Τα κινούμενα points.
