## SVGMarkerElement.OrientAngle property

Αντιστοιχεί στο χαρακτηριστικό ‘orient’ στο δοσμένο στοιχείο ‘marker’. Εάν το markerUnits είναι SVG_MARKER_ORIENT_ANGLE, η τιμή γωνίας για το χαρακτηριστικό ‘orient’; διαφορετικά, θα οριστεί στο μηδέν.

```java
public SVGAnimatedAngle OrientAngle { get; }
```

### Property Value

Το χαρακτηριστικό ‘orient’ του δοσμένου στοιχείου ‘marker’.
