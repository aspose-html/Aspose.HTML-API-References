## SVGPathElement.AnimatedPathSegList property

Παρέχει πρόσβαση στα τρέχοντα κινούμενα περιεχόμενα του χαρακτηριστικού ‘d’ με μορφή που ταιριάζει ένα προς ένα με τη σύνταξη του SVG. Εάν το δεδομένο χαρακτηριστικό ή η ιδιότητα είναι υπό κίνηση, περιέχει την τρέχουσα κίνηση τιμή του χαρακτηριστικού ή της ιδιότητας, και τόσο το αντικείμενο όσο και τα περιεχόμενά του είναι μόνο για ανάγνωση. Εάν το δεδομένο χαρακτηριστικό ή η ιδιότητα δεν είναι υπό κίνηση, περιέχει την ίδια τιμή με το pathSegList.

```java
public SVGPathSegList AnimatedPathSegList { get; }
```

### Property Value

Η λίστα των κινούμενων τμημάτων διαδρομής.
