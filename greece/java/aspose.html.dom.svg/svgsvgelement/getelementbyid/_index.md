## SVGSVGElement.GetElementById method

Αναζητά σε αυτό το τμήμα εγγράφου SVG (δηλαδή, η αναζήτηση περιορίζεται σε ένα υποσύνολο του δένδρου εγγράφου) ένα Element του οποίου το id δίνεται από το elementId. Εάν βρεθεί ένα Element, αυτό επιστρέφεται. Εάν δεν υπάρχει τέτοιο στοιχείο, επιστρέφεται null. Η συμπεριφορά δεν ορίζεται εάν περισσότερα από ένα στοιχεία έχουν αυτό το id.

```java
public Element GetElementById(String elementId)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| elementId | String | Η μοναδική τιμή id για ένα στοιχείο. |
