## SVGSVGElement.CreateSVGTransformFromMatrix method

Δημιουργεί ένα αντικείμενο SVGTransform εκτός οποιουδήποτε δένδρου εγγράφου. Το αντικείμενο αρχικοποιείται στον δοσμένο μετασχηματισμό μητρώου (δηλαδή SVG_TRANSFORM_MATRIX). Οι τιμές από το παράμετρο μητρώου αντιγράφονται, το παράμετρο μητρώου δεν υιοθετείται ως SVGTransform::matrix.

```java
public SVGTransform CreateSVGTransformFromMatrix(SVGMatrix matrix)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| matrix | SVGMatrix | Η μήτρα μετασχηματισμού. |

### Τιμή Επιστροφής

Ένα αντικείμενο SVGTransform.
