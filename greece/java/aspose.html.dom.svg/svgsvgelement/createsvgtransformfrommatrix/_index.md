## SVGSVGElement.CreateSVGTransformFromMatrix method

Δημιουργεί ένα αντικείμενο SVGTransform εκτός οποιουδήποτε δέντρου εγγράφου. Το αντικείμενο αρχικοποιείται στον δεδομένο μετασχηματισμό μητρώου (δηλαδή SVG_TRANSFORM_MATRIX). Οι τιμές από το μητρώο παραμέτρου αντιγράφονται, η παράμετρος μητρώου δεν υιοθετείται ως SVGTransform::matrix.

```java
public SVGTransform CreateSVGTransformFromMatrix(SVGMatrix matrix)
```
