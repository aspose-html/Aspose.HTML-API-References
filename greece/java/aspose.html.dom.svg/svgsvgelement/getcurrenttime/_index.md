## SVGSVGElement.GetCurrentTime method

Επιστρέφει τον τρέχοντα χρόνο σε δευτερόλεπτα σε σχέση με τον χρόνο έναρξης του τρέχοντος τμήματος εγγράφου SVG. Εάν το getCurrentTime κληθεί πριν ξεκινήσει η χρονογραμμή του εγγράφου (π.χ., από script που εκτελείται σε στοιχείο ‘script’ πριν αποσταλεί το γεγονός SVGLoad του εγγράφου), τότε επιστρέφεται 0.

```java
public float GetCurrentTime()
```

### Τιμή επιστροφής

Η τρέχουσα ώρα σε δευτερόλεπτα, ή 0 εάν η χρονογραμμή του εγγράφου δεν έχει ακόμη ξεκινήσει.
