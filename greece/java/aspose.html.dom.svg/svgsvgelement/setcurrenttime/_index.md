## SVGSVGElement.SetCurrentTime method

Ρυθμίζει το ρολόι για αυτό το τμήμα εγγράφου SVG, καθορίζοντας μια νέα τρέχουσα ώρα. Εάν η μέθοδος setCurrentTime κληθεί πριν ξεκινήσει η χρονογραμμή του εγγράφου (για παράδειγμα, από σενάριο που εκτελείται σε στοιχείο ‘script’ πριν αποσταλεί το γεγονός SVGLoad του εγγράφου), τότε η τιμή των δευτερολέπτων στην τελευταία κλήση της μεθόδου δίνει τον χρόνο στον οποίο θα μεταβεί το έγγραφο μόλις ξεκινήσει η χρονογραμμή του εγγράφου.

```java
public void SetCurrentTime(float seconds)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| δευτερόλεπτα | Single | Η νέα τρέχουσα ώρα σε δευτερόλεπτα σε σχέση με την ώρα έναρξης του τρέχοντος τμήματος εγγράφου SVG. |
