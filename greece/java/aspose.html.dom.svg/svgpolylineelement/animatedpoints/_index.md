## SVGPolylineElement.AnimatedPoints property

Παρέχει πρόσβαση στα τρέχοντα κινούμενα περιεχόμενα του χαρακτηριστικού ‘points’. Εάν το δεδομένο χαρακτηριστικό ή η ιδιότητα βρίσκεται σε κίνηση, περιέχει την τρέχουσα κινούμενη τιμή του χαρακτηριστικού ή της ιδιότητας. Εάν το δεδομένο χαρακτηριστικό ή η ιδιότητα δεν βρίσκεται αυτή τη στιγμή σε κίνηση, περιέχει την ίδια τιμή με το points.

```java
public SVGPointList AnimatedPoints { get; }
```

### Property Value

Τα κινούμενα σημεία.
