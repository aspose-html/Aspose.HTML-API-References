## SVGViewElement.ViewTarget property

Αντιστοιχεί στο χαρακτηριστικό ‘viewTarget’ στο δεδομένο στοιχείο ‘view’. Μια λίστα τιμών DOMString που περιέχουν τα ονόματα που αναφέρονται στο χαρακτηριστικό ‘viewTarget’. Κάθε τιμή DOMString μπορεί να συσχετιστεί με το αντίστοιχο στοιχείο χρησιμοποιώντας την κλήση της μεθόδου getElementById().

```java
public SVGStringList ViewTarget { get; }
```

### Property Value

Το χαρακτηριστικό ‘viewTarget’ του δεδομένου στοιχείου ‘view’.
