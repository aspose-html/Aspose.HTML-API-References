## SVGUnitTypes enumeration

Η απαρίθμηση SVGUnitTypes ορίζει ένα κοινώς χρησιμοποιούμενο σύνολο σταθερών και αποτελεί βασική διεπαφή που χρησιμοποιείται από τα SVGGradientElement, SVGPatternElement, SVGClipPathElement, SVGMaskElement και SVGFilterElement.

```java
public enum SVGUnitTypes
```

### Τιμές

| Όνομα | Τιμή | Περιγραφή |
| --- | --- | --- |
| SVG_UNIT_TYPE_UNKNOWN | `0` | Ο τύπος δεν είναι ένας από τους προκαθορισμένους τύπους. Είναι μη έγκυρο να προσπαθήσετε να ορίσετε μια νέα τιμή αυτού του τύπου ή να προσπαθήσετε να αλλάξετε μια υπάρχουσα τιμή σε αυτόν τον τύπο. |
| SVG_UNIT_TYPE_USERSPACEONUSE | `1` | Αντιστοιχεί στην τιμή 'userSpaceOnUse'. |
| SVG_UNIT_TYPE_OBJECTBOUNDINGBOX | `2` | Αντιστοιχεί στην τιμή 'objectBoundingBox'. |
