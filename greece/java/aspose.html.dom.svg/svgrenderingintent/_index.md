## SVGRenderingIntent enumeration

Η απαρίθμηση SVGRenderingIntent ορίζει τη λίστα των πιθανών τιμών για τα χαρακτηριστικά ή περιγραφείς ‘rendering-intent’.

```java
public enum SVGRenderingIntent
```

### Τιμές

| Όνομα | Τιμή | Περιγραφή |
| --- | --- | --- |
| RENDERING_INTENT_UNKNOWN | `0` | Ο τύπος δεν είναι ένας από τους προκαθορισμένους τύπους. Είναι μη έγκυρο να προσπαθήσετε να ορίσετε μια νέα τιμή αυτού του τύπου ή να προσπαθήσετε να αλλάξετε μια υπάρχουσα τιμή σε αυτόν τον τύπο. |
| RENDERING_INTENT_AUTO | `1` | Αντιστοιχεί σε τιμή 'auto'. |
| RENDERING_INTENT_PERCEPTUAL | `2` | Αντιστοιχεί σε τιμή 'perceptual'. |
| RENDERING_INTENT_RELATIVE_COLORIMETRIC | `3` | Αντιστοιχεί σε τιμή 'relative-colorimetric'. |
| RENDERING_INTENT_SATURATION | `4` | Αντιστοιχεί σε μια τιμή του 'saturation'. |
| RENDERING_INTENT_ABSOLUTE_COLORIMETRIC | `5` | Αντιστοιχεί σε μια τιμή του 'absolute-colorimetric'. |
