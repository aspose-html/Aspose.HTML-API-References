## SVGTextContentElement.GetNumberOfChars method

Επιστρέφει το συνολικό αριθμό χαρακτήρων που είναι διαθέσιμοι για απόδοση εντός του τρέχοντος στοιχείου, συμπεριλαμβανομένων των χαρακτήρων που αναφέρονται από την αναφορά ‘tref’, ανεξάρτητα από το αν θα αποδοθούν. Στην ουσία, αυτό ισοδυναμεί με το μήκος του χαρακτηριστικού Node::textContent από το DOM Level 3 Core ([DOM3], ενότητα 1.4), εάν αυτό το χαρακτηριστικό επεκτείνει επίσης τα στοιχεία ‘tref’.

```java
public long GetNumberOfChars()
```
