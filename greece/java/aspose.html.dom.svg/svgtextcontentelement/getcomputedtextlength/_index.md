## SVGTextContentElement.GetComputedTextLength method

Το συνολικό άθροισμα όλων των τιμών προόδου από την απόδοση όλων των χαρακτήρων εντός αυτού του στοιχείου, συμπεριλαμβανομένης της τιμής προόδου στα γλύφους (οριζόντια ή κάθετη), της επίδρασης των ιδιοτήτων ‘kerning’, ‘letter-spacing’ και ‘word-spacing’ και των προσαρμογών λόγω των χαρακτηριστικών ‘dx’ και ‘dy’ στα στοιχεία ‘tspan’. Για περιβάλλοντα που δεν πραγματοποιούν απόδοση, ο πράκτορας χρήστη πρέπει να κάνει λογικές υποθέσεις σχετικά με τις μετρήσεις των γλύφων.

```java
public float GetComputedTextLength()
```
