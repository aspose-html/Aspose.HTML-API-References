Το πακέτο **com.aspose.html.services** περιέχει διεπαφές ως πρωτόκολλα για υλοποιήσεις υπηρεσιών.

## Διεπαφές

| Διεπαφή | Περιγραφή |
| --- | --- |
| [IDeviceInformationService](./ideviceinformationservice/) | Μια διεπαφή που περιγράφει ένα περιβάλλον στο οποίο το [`Document`](../com.aspose.html.dom/document/) παρουσιάζεται στον χρήστη. |
| [INetworkService](./inetworkservice/) | Παρέχει μια διεπαφή για τις λειτουργίες δικτύου. |
| [IRuntimeService](./iruntimeservice/) | Αυτή η υπηρεσία χρησιμοποιείται για τη διαμόρφωση ιδιοτήτων σχετικών με το χρόνο εκτέλεσης. |
| [IUserAgentService](./iuseragentservice/) | Μια διεπαφή που περιγράφει ένα περιβάλλον πράκτορα χρήστη. |
