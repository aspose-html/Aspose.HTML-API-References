## IRuntimeService.JavaScriptTimeout property

Λαμβάνει ή ορίζει το TimeSpan που περιορίζει το χρόνο εκτέλεσης JavaScript. Εάν το script εκτελείται περισσότερο από το δοσμένο TimeSpan, θα ακυρωθεί. Μπορείτε να ορίσετε απεριόριστο χρονικό όριο θέτοντας το TimeSpan ίσο με -1 χιλιοστά του δευτερολέπτου. Η προεπιλεγμένη τιμή είναι 1 λεπτό.

```java
public TimeSpan JavaScriptTimeout { get; set; }
```
