## IRuntimeService.JavaScriptTimeout property

Λαμβάνει ή ορίζει το TimeSpan που περιορίζει το χρόνο εκτέλεσης της JavaScript. Εάν το σενάριο εκτελεστεί περισσότερο από το παρεχόμενο TimeSpan, θα ακυρωθεί. Μπορείτε να ορίσετε απεριόριστο χρονικό όριο θέτοντας το TimeSpan ίσο με -1 χιλιοστό του δευτερολέπτου. Η προεπιλεγμένη τιμή είναι 1 λεπτό.

```java
public TimeSpan JavaScriptTimeout { get; set; }
```
