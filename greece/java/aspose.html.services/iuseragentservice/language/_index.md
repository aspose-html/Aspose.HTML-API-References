## IUserAgentService.Language property

Η `Language` καθορίζει την κύρια γλώσσα για το περιεχόμενο του στοιχείου και για οποιοδήποτε από τα χαρακτηριστικά του στοιχείου που περιέχουν κείμενο. Η τιμή της πρέπει να είναι μια έγκυρη ετικέτα γλώσσας BCP 47 () ή το κενό String. Ο ορισμός του χαρακτηριστικού στο κενό String υποδεικνύει ότι η κύρια γλώσσα είναι άγνωστη.

```java
public String Language { get; set; }
```

### Property Value

Η γλώσσα του user agent.
