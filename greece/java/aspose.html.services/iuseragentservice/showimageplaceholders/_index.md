## IUserAgentService.ShowImagePlaceholders property

Οι εικόνες μπορούν να έχουν εναλλακτικό περιεχόμενο: περιεχόμενο που πρέπει να χρησιμοποιείται όταν ένας εξωτερικός πόρος δεν μπορεί να χρησιμοποιηθεί (για παράδειγμα, επειδή βρίσκεται σε μη υποστηριζόμενη μορφή). Η ιδιότητα `ShowImagePlaceholders` καθορίζει εάν θα εμφανίζεται η εναλλακτική εικόνα (η προεπιλογή είναι true).

public bool ShowImagePlaceholders { get; set; }
