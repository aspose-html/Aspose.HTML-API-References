Το **com.aspose.html.dom.mutations** παρέχει τη δυνατότητα παρατήρησης μεταβολών του DOM και λήψης συγκεκριμένων πληροφοριών κλήσης επιστροφής.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [MutationCallback](./mutationcallback/) | Αντιπροσωπεύει τη μέθοδο που θα χειριστεί ένα γεγονός μετάλλαξης. |
| [MutationObserver](./mutationobserver/) | Ένα αντικείμενο μπορεί να χρησιμοποιηθεί για την παρατήρηση μεταβολών στο δέντρο του [`.`](../com.aspose.html.dom/node/) |
| [MutationObserverInit](./mutationobserverinit/) | Αυτή η κλάση αντιπροσωπεύει μια συλλογή επιλογών που χρησιμοποιείται για τη διαμόρφωση του [`MutationObserver`](../com.aspose.html.dom.mutations/mutationobserver/). |
| [MutationRecord](./mutationrecord/) | Ένα MutationRecord αντιπροσωπεύει μια μεμονωμένη μεταβολή DOM. Είναι το αντικείμενο που περνάει στο [`MutationObserver`](../com.aspose.html.dom.mutations/mutationobserver/)'s [`MutationCallback`](../com.aspose.html.dom.mutations/mutationcallback/). |
