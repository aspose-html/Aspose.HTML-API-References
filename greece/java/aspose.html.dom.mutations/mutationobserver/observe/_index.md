## Observe(Node) {#observe}

Οδηγεί τον πράκτορα χρήστη να παρακολουθεί έναν συγκεκριμένο στόχο (έναν κόμβο) και να αναφέρει τυχόν μεταβολές βάσει των κριτηρίων που δίνονται από τις επιλογές (ένα αντικείμενο). Το όρισμα options επιτρέπει τον ορισμό επιλογών παρακολούθησης μεταβολών μέσω μελών του αντικειμένου.

```java
public void Observe(Node target)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| στόχος | Node | Ο στόχος για την παρατήρηση. |
