## MutationObserver constructor

Δημιουργεί ένα αντικείμενο MutationObserver και ορίζει το [`MutationCallback`](../../mutationcallback/) του σε callback. Το callback καλείται με μια λίστα αντικειμένων MutationRecord ως πρώτο όρισμα και το δημιουργημένο αντικείμενο MutationObserver ως δεύτερο όρισμα. Καλείται μετά την μεταβολή των κόμβων που έχουν εγγραφεί με τη μέθοδο !:Observe(Node, IMutationObserverInit),

```java
public MutationObserver(MutationCallback callback)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| callback | MutationCallback | Το callback. |
