## MutationRecord.OldValue property

Η επιστρεφόμενη τιμή εξαρτάται από τον τύπο. Για "attributes", είναι η τιμή του τροποποιημένου χαρακτηριστικού πριν την αλλαγή. Για "characterData", είναι τα δεδομένα του τροποποιημένου κόμβου πριν την αλλαγή. Για "childList", είναι null.
