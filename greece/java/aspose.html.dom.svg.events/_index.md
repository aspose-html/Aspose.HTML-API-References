Το πακέτο αποτελείται από κλάσεις για διαδραστικότητα βασισμένη σε γεγονότα, όπως χρονικά γεγονότα και ζουμ.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [SVGZoomEvent](./svgzoomevent/) | Το συμβάν ζουμ εμφανίζεται όταν ο χρήστης εκκινεί μια ενέργεια που προκαλεί την επανακλιμάκωση της τρέχουσας προβολής του τμήματος του εγγράφου SVG. Οι χειριστές συμβάντων αναγνωρίζονται μόνο στα στοιχεία ‘svg’. |
| [TimeEvent](./timeevent/) | Η διεπαφή TimeEvent παρέχει συγκεκριμένες συμφραζόμενες πληροφορίες που σχετίζονται με τα χρονικά συμβάντα. Οι διαφορετικοί τύποι συμβάντων που μπορούν να εμφανιστούν είναι: beginEvent, endEvent και repeatEvent. |
