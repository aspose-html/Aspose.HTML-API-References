
| ModifyTextAnnotations | `20` | Προσθήκη ή τροποποίηση σχολίων κειμένου, συμπλήρωση διαδραστικών πεδίων φόρμας, και, εάν έχει οριστεί επίσης το ModifyContent, δημιουργία ή τροποποίηση διαδραστικών πεδίων φόρμας (συμπεριλαμβανομένων των πεδίων υπογραφής). |
| FillForm | `100` | (Διαχειριστές ασφαλείας έκδοσης 3 ή μεγαλύτερης) Συμπλήρωση υπαρχόντων διαδραστικών πεδίων φόρμας (συμπεριλαμβανομένων των πεδίων υπογραφής), ακόμη και αν το ModifyTextAnnotations είναι απενεργοποιημένο. |
| ExtractContentWithDisabilities | `200` | (Διαχειριστές ασφαλείας έκδοσης 3 ή μεγαλύτερης) Εξαγωγή κειμένου και γραφικών (υποστηρίζοντας την προσβασιμότητα για χρήστες με αναπηρίες ή για άλλους σκοπούς). |
| AssembleDocument | `400` | (Διαχειριστές ασφαλείας έκδοσης 3 ή μεγαλύτερης) Συναρμολόγηση του εγγράφου (εισαγωγή, περιστροφή ή διαγραφή σελίδων και δημιουργία σελιδοδεικτών ή μικρογραφιών), ακόμη και αν το ModifyContent είναι απενεργοποιημένο. |
| PrintingQuality | `800` | (Διαχειριστές ασφαλείας έκδοσης 3 ή μεγαλύτερης) Εκτύπωση του εγγράφου σε μια αναπαράσταση από την οποία μπορεί να παραχθεί μια πιστή ψηφιακή αντίγραφο του περιεχομένου PDF. Όταν αυτό το bit είναι απενεργοποιημένο (και το bit 3 είναι ενεργοποιημένο), η εκτύπωση περιορίζεται σε μια χαμηλού επιπέδου αναπαράσταση της εμφάνισης, πιθανώς με μειωμένη ποιότητα. |
