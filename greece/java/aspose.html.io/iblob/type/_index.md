## IBlob.Type property

Η συμβολοσειρά κωδικοποιημένη σε ASCII με πεζά γράμματα που αντιπροσωπεύει τον τύπο μέσου του Blob. Κατά την ανάκτηση, οι πράκτορες χρήστη πρέπει να επιστρέφουν τον τύπο ενός Blob ως συμβολοσειρά κωδικοποιημένη σε ASCII με πεζά, έτσι ώστε όταν μετατραπεί σε ακολουθία byte, να είναι ένας αναγνώσιμος τύπος MIME, ή η κενή συμβολοσειρά – 0 byte – εάν ο τύπος δεν μπορεί να προσδιοριστεί.

```java
public String Type { get; }
```
