## IBlob interface

Ένα αντικείμενο Blob αναφέρεται σε μια ακολουθία byte και έχει ένα χαρακτηριστικό size που είναι ο συνολικός αριθμός των byte στην ακολουθία, καθώς και ένα χαρακτηριστικό type, το οποίο είναι μια ASCII-encoded String σε πεζά γράμματα που αντιπροσωπεύει τον τύπο μέσου της ακολουθίας byte.

```java
public interface IBlob
```

## Ιδιότητες

| Όνομα | Περιγραφή |
| --- | --- |
| [getSize](../../com.aspose.html.io/iblob/size/) Επιστρέφει το μέγεθος της ακολουθίας byte σε αριθμό byte. Κατά την ανάκτηση, οι συμβατοί πράκτορες χρήστη πρέπει να επιστρέφουν το συνολικό αριθμό byte που μπορούν να διαβαστούν από ένα αντικείμενο FileReader ή FileReaderSync, ή 0 εάν το Blob δεν έχει byte προς ανάγνωση. |
| [getType](../../com.aspose.html.io/iblob/type/) Η ASCII‑κωδικοποιημένη String με πεζά γράμματα που αντιπροσωπεύει τον τύπο μέσου του Blob. Κατά την ανάκτηση, οι πράκτορες χρήστη πρέπει να επιστρέφουν τον τύπο ενός Blob ως ASCII‑κωδικοποιημένη String με πεζά, ώστε όταν μετατραπεί σε ακολουθία byte, να είναι ένας αναγνώσιμος τύπος MIME, ή η κενή String – 0 byte – εάν ο τύπος δεν μπορεί να προσδιοριστεί. |
