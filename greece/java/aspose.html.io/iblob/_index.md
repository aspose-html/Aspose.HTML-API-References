## IBlob interface

Ένα αντικείμενο Blob αναφέρεται σε μια ακολουθία byte και έχει ένα χαρακτηριστικό size που είναι ο συνολικός αριθμός των byte στην ακολουθία, καθώς και ένα χαρακτηριστικό type, το οποίο είναι μια κωδικοποιημένη σε ASCII συμβολοσειρά με πεζά γράμματα που αντιπροσωπεύει τον τύπο μέσου της ακολουθίας byte.

```java
public interface IBlob
```

## Ιδιότητες

| Όνομα | Περιγραφή |
| --- | --- |
| [getSize](../../com.aspose.html.io/iblob/size/) Επιστρέφει το μέγεθος της ακολουθίας byte σε αριθμό byte. Κατά την ανάκτηση, οι συμβατοί πράκτορες χρήστη πρέπει να επιστρέφουν τον συνολικό αριθμό byte που μπορούν να διαβαστούν από ένα αντικείμενο FileReader ή FileReaderSync, ή 0 εάν το Blob δεν έχει byte προς ανάγνωση. |
| [getType](../../com.aspose.html.io/iblob/type/) Το ASCII‑κωδικοποιημένο String πεζά που αντιπροσωπεύει τον τύπο μέσου του Blob. Κατά την ανάκτηση, οι πράκτορες χρήστη πρέπει να επιστρέφουν τον τύπο ενός Blob ως ASCII‑κωδικοποιημένο String πεζά, έτσι ώστε όταν μετατραπεί σε ακολουθία byte, να είναι ένα αναγνώσιμο MIME type, ή το κενό String – 0 byte – εάν ο τύπος δεν μπορεί να προσδιοριστεί. |
