## IBlob.Size property

Επιστρέφει το μέγεθος της ακολουθίας byte σε αριθμό byte. Κατά την ανάκτηση, οι συμβατοί πράκτορες χρήστη πρέπει να επιστρέφουν το συνολικό αριθμό byte που μπορούν να διαβαστούν από ένα αντικείμενο FileReader ή FileReaderSync, ή 0 εάν το Blob δεν έχει byte προς ανάγνωση.

```java
public ulong Size { get; }
```
