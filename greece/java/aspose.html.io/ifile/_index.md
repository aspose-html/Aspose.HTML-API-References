## IFile interface

Ένα αντικείμενο File είναι ένα αντικείμενο Blob με χαρακτηριστικό name, το οποίο είναι μια συμβολοσειρά· μπορεί να δημιουργηθεί μέσα στην εφαρμογή web μέσω κατασκευαστή, ή είναι μια αναφορά σε ακολουθία byte από ένα αρχείο του υποκείμενου (OS) συστήματος αρχείων.

```java
public interface IFile : IBlob
```
