## IFile interface

Ένα αντικείμενο File είναι ένα αντικείμενο Blob με ένα χαρακτηριστικό name, το οποίο είναι μια String· μπορεί να δημιουργηθεί εντός της web εφαρμογής μέσω ενός κατασκευαστή, ή είναι μια αναφορά σε μια ακολουθία byte από ένα αρχείο του υποκείμενου (OS) συστήματος αρχείων.

```java
public interface IFile : IBlob
```
