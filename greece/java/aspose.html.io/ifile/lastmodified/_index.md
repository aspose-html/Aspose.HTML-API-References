## IFile.LastModified property

Η ημερομηνία τελευταίας τροποποίησης του αρχείου. Κατά την ανάκτηση, εάν οι πράκτορες χρήστη μπορούν να κάνουν αυτή την πληροφορία διαθέσιμη, πρέπει να επιστρέφει ένα long long ορισμένο στην ώρα που το αρχείο τροποποιήθηκε ως αριθμός χιλιοστών του δευτερολέπτου από την εποχή Unix.

```java
public long LastModified { get; }
```
