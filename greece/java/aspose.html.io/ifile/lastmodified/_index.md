## IFile.LastModified property

Η ημερομηνία τελευταίας τροποποίησης του αρχείου. Κατά την ανάκτηση, εάν οι πράκτορες χρήστη μπορούν να παρέχουν αυτή την πληροφορία, πρέπει να επιστρέφει ένα long long ορισμένο στην ώρα που το αρχείο τροποποιήθηκε ως αριθμό χιλιοστών του δευτερολέπτου από την Εποχή Unix.

```java
public long LastModified { get; }
```
