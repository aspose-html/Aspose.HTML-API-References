Εκτός από τα τυπικά εργαλεία IO (εισόδου-εξόδου), το πακέτο **com.aspose.html.io** περιέχει βοηθητικές κλάσεις και διεπαφές.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [FileCreateStreamProvider](./filecreatestreamprovider/) | Αντιπροσωπεύει την υλοποίηση του FileStream για την παροχή ροών στις συσκευές απόδοσης. |
## Διεπαφές

| Διεπαφή | Περιγραφή |
| --- | --- |
| [IBlob](./iblob/) | Ένα αντικείμενο Blob αναφέρεται σε μια ακολουθία byte και έχει ένα χαρακτηριστικό size που είναι ο συνολικός αριθμός των byte στην ακολουθία, καθώς και ένα χαρακτηριστικό type, το οποίο είναι μια κωδικοποιημένη σε ASCII συμβολοσειρά με πεζά γράμματα που αντιπροσωπεύει τον τύπο μέσου της ακολουθίας byte. |
| [ICreateStreamProvider](./icreatestreamprovider/) | Αντιπροσωπεύει μια διεπαφή που μπορεί να υλοποιηθεί από κλάσεις που παρέχουν ροές στις συσκευές απόδοσης. |
| [IFile](./ifile/) | Ένα αντικείμενο File είναι ένα αντικείμενο Blob με χαρακτηριστικό name, το οποίο είναι μια συμβολοσειρά· μπορεί να δημιουργηθεί μέσα στην εφαρμογή web μέσω κατασκευαστή, ή είναι μια αναφορά σε ακολουθία byte από ένα αρχείο του υποκείμενου (OS) συστήματος αρχείων. |
| [IFileList](./ifilelist/) | Αντιπροσωπεύει τη διεπαφή για λίστα αρχείων. |
