## Path2D.ArcTo method

Προσθέτει ένα τόξο στο μονοπάτι με τα δεδομένα σημεία ελέγχου και την ακτίνα, συνδεδεμένο με το προηγούμενο σημείο μέσω μιας ευθείας γραμμής.

```java
public void ArcTo(double x1, double y1, double x2, double y2, double radius)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| x1 | Διπλό | Συντεταγμένες άξονα x για το πρώτο σημείο ελέγχου. |
| y1 | Διπλό | συντεταγμένες του άξονα y για το πρώτο σημείο ελέγχου. |
| x2 | Διπλό | συντεταγμένες του άξονα x για το δεύτερο σημείο ελέγχου. |
| y2 | Διπλό | συντεταγμένες του άξονα y για το δεύτερο σημείο ελέγχου. |
| ακτίνα | Διπλό | Η ακτίνα της καμπύλης. |
