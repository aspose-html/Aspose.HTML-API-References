## Ellipse(double, double, double, double, double, double, double) {#ellipse}

Προσθέτει μια έλλειψη στη διαδρομή που κεντράρεται στη θέση (x, y) με τις ακτίνες radiusX και radiusY, ξεκινώντας από την startAngle και λήγοντας στην endAngle, κινούμενη προς την καθορισμένη κατεύθυνση αντίστροφα από το ρολόι (προεπιλογή προς το ρολόι).

```java
public void Ellipse(double x, double y, double radiusX, double radiusY, double rotation, 
    double startAngle, double endAngle)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| x | Double | Ο άξονας x της συντεταγμένης για το κέντρο της έλλειψης. |
| y | Double | Ο άξονας y της συντεταγμένης για το κέντρο της έλλειψης. |
| radiusX | Double | Η ακτίνα του κύριου άξονα της έλλειψης. |
| radiusY | Double | Η ακτίνα του δευτερεύοντος άξονα της έλλειψης. |
| rotation | Double | Η περιστροφή για αυτήν την έλλειψη, εκφρασμένη σε ακτίνια. |
| startAngle | Double | Το αρχικό σημείο, μετρημένο από τον άξονα x, από το οποίο θα σχεδιαστεί, εκφρασμένο σε ακτίνια. |
| endAngle | Double | Η γωνία τέλους της έλλειψης στην οποία θα σχεδιαστεί, εκφρασμένη σε ακτίνια. |

## Ellipse(double, double, double, double, double, double, double, bool) {#ellipse_1}

Προσθέτει μια έλλειψη στη διαδρομή που κεντράρεται στη θέση (x, y) με τις ακτίνες radiusX και radiusY, ξεκινώντας από την startAngle και λήγοντας στην endAngle, κινούμενη προς την καθορισμένη κατεύθυνση αντίστροφα από το ρολόι (προεπιλογή προς το ρολόι).

```java
public void Ellipse(double x, double y, double radiusX, double radiusY, double rotation, 
    double startAngle, double endAngle, bool anticlockwise)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| x | Double | Ο άξονας x της συντεταγμένης για το κέντρο της έλλειψης. |
| y | Double | Ο άξονας y της συντεταγμένης για το κέντρο της έλλειψης. |
| radiusX | Double | Η ακτίνα του κύριου άξονα της έλλειψης. |
| radiusY | Double | Η ακτίνα του δευτερεύοντος άξονα της έλλειψης. |
| rotation | Double | Η περιστροφή για αυτήν την έλλειψη, εκφρασμένη σε ακτίνια. |
| startAngle | Double | Το αρχικό σημείο, μετρημένο από τον άξονα x, από το οποίο θα σχεδιαστεί, εκφρασμένο σε ακτίνια. |
| endAngle | Double | Η γωνία τέλους της έλλειψης στην οποία θα σχεδιαστεί, εκφρασμένη σε ακτίνια. |
| anticlockwise | Boolean | Ένα προαιρετικό boolean που, εάν είναι true, σχεδιάζει την έλλειψη αριστερόστροφα (counter-clockwise), διαφορετικά σε δεξιόστροφη κατεύθυνση. |
