## Ellipse(double, double, double, double, double, double, double) {#ellipse}

Προσθέτει μια έλλειψη στο μονοπάτι που είναι κεντραρισμένη στη θέση (x, y) με τις ακτίνες radiusX και radiusY, ξεκινώντας από τη startAngle και τελειώνοντας στη endAngle, κινούμενη στην καθορισμένη κατεύθυνση αριστερόστροφα (προεπιλογή δεξιόστροφα).

```java
public void Ellipse(double x, double y, double radiusX, double radiusY, double rotation, 
    double startAngle, double endAngle)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| x | Διπλό | Ο άξονας x της συντεταγμένης για το κέντρο της έλλειψης. |
| y | Διπλό | Ο άξονας y της συντεταγμένης για το κέντρο της έλλειψης. |
| radiusX | Διπλό | Η ακτίνα του κύριου άξονα της έλλειψης. |
| radiusY | Διπλό | Η ακτίνα του δευτερεύοντος άξονα της έλλειψης. |
| rotation | Διπλό | Η περιστροφή για αυτήν την έλλειψη, εκφρασμένη σε ακτίνια. |
| startAngle | Διπλό | Το αρχικό σημείο, μετρημένο από τον άξονα x, από το οποίο θα σχεδιαστεί, εκφρασμένο σε ακτίνια. |
| endAngle | Διπλό | Η γωνία λήξης της έλλειψης στην οποία θα σχεδιαστεί, εκφρασμένη σε ακτίνια. |

## Ellipse(double, double, double, double, double, double, double, bool) {#ellipse_1}

Προσθέτει μια έλλειψη στο μονοπάτι που είναι κεντραρισμένη στη θέση (x, y) με τις ακτίνες radiusX και radiusY, ξεκινώντας από τη startAngle και τελειώνοντας στη endAngle, κινούμενη στην καθορισμένη κατεύθυνση αριστερόστροφα (προεπιλογή δεξιόστροφα).

```java
public void Ellipse(double x, double y, double radiusX, double radiusY, double rotation, 
    double startAngle, double endAngle, bool anticlockwise)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| x | Διπλό | Ο άξονας x της συντεταγμένης για το κέντρο της έλλειψης. |
| y | Διπλό | Ο άξονας y της συντεταγμένης για το κέντρο της έλλειψης. |
| radiusX | Διπλό | Η ακτίνα του κύριου άξονα της έλλειψης. |
| radiusY | Διπλό | Η ακτίνα του δευτερεύοντος άξονα της έλλειψης. |
| rotation | Διπλό | Η περιστροφή για αυτήν την έλλειψη, εκφρασμένη σε ακτίνια. |
| startAngle | Διπλό | Το αρχικό σημείο, μετρημένο από τον άξονα x, από το οποίο θα σχεδιαστεί, εκφρασμένο σε ακτίνια. |
| endAngle | Διπλό | Η γωνία λήξης της έλλειψης στην οποία θα σχεδιαστεί, εκφρασμένη σε ακτίνια. |
| anticlockwise | Boolean | Ένα προαιρετικό boolean που, εάν είναι true, σχεδιάζει την έλλειψη αριστερόστροφα (counter-clockwise), διαφορετικά σε δεξιόστροφη κατεύθυνση. |
