## StrokeText(String, double, double) {#stroketext}

Σχεδίαζει (σχεδίαζει περιγράμματα) ένα δεδομένο κείμενο στη δοσμένη θέση (x, y).

```java
public void StrokeText(String text, double x, double y)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| text | String | Το κείμενο που θα σχεδιαστεί χρησιμοποιώντας την τρέχουσα γραμματοσειρά, τις τιμές textAlign, textBaseline και direction. |
| x | Double | Ο άξονας x της συντεταγμένης για το σημείο εκκίνησης του κειμένου. |
| y | Double | Ο άξονας y της συντεταγμένης για το σημείο εκκίνησης του κειμένου. |

## StrokeText(String, double, double, double?) {#stroketext_1}

Σχεδίαζει (σχεδίαζει περιγράμματα) ένα δεδομένο κείμενο στη δοσμένη θέση (x, y).

```java
public void StrokeText(String text, double x, double y, double? maxWidth)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| text | String | Το κείμενο που θα σχεδιαστεί χρησιμοποιώντας την τρέχουσα γραμματοσειρά, τις τιμές textAlign, textBaseline και direction. |
| x | Double | Ο άξονας x της συντεταγμένης για το σημείο εκκίνησης του κειμένου. |
| y | Double | Ο άξονας y της συντεταγμένης για το σημείο εκκίνησης του κειμένου. |
| maxWidth | Nullable`1 | Το μέγιστο πλάτος για τη σχεδίαση. Εάν καθοριστεί και το κείμενο υπολογιστεί ότι είναι ευρύτερο από αυτό το πλάτος, η γραμματοσειρά προσαρμόζεται ώστε να χρησιμοποιήσει μια πιο οριζόντια συμπυκνωμένη γραμματοσειρά (εάν υπάρχει ή εάν μπορεί να συντεθεί μια λογικά αναγνώσιμη γραμματοσειρά κλιμακώνοντας την τρέχουσα γραμματοσειρά οριζόντια) ή μια μικρότερη γραμματοσειρά. |
