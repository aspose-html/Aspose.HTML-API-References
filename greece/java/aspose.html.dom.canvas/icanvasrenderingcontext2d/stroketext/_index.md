## StrokeText(String, double, double) {#stroketext}

Σχεδιάζει (περιγράφει) ένα δεδομένο κείμενο στη δεδομένη θέση (x, y).

```java
public void StrokeText(String text, double x, double y)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| text | String | Το κείμενο που θα σχεδιαστεί χρησιμοποιώντας την τρέχουσα γραμματοσειρά, textAlign, textBaseline και τις τιμές direction. |
| x | Διπλό | Ο άξονας x της συντεταγμένης για το σημείο εκκίνησης του κειμένου. |
| y | Διπλό | Ο άξονας y της συντεταγμένης για το σημείο εκκίνησης του κειμένου. |

## StrokeText(String, double, double, double?) {#stroketext_1}

Σχεδιάζει (περιγράφει) ένα δεδομένο κείμενο στη δεδομένη θέση (x, y).

```java
public void StrokeText(String text, double x, double y, double? maxWidth)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| text | String | Το κείμενο που θα σχεδιαστεί χρησιμοποιώντας την τρέχουσα γραμματοσειρά, textAlign, textBaseline και τις τιμές direction. |
| x | Διπλό | Ο άξονας x της συντεταγμένης για το σημείο εκκίνησης του κειμένου. |
| y | Διπλό | Ο άξονας y της συντεταγμένης για το σημείο εκκίνησης του κειμένου. |
| maxWidth | Nullable`1 | Το μέγιστο πλάτος για τη σχεδίαση. Εάν καθοριστεί και το String υπολογιστεί ότι είναι ευρύτερο από αυτό το πλάτος, η γραμματοσειρά προσαρμόζεται ώστε να χρησιμοποιήσει μια πιο οριζόντια συμπυκνωμένη γραμματοσειρά (εάν υπάρχει ή εάν μπορεί να συντεθεί μια λογικά αναγνώσιμη με οριζόντια κλιμάκωση της τρέχουσας γραμματοσειράς) ή μια μικρότερη γραμματοσειρά. |
