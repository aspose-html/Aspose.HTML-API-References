## FillText(String, double, double) {#filltext}

Σχεδιάζει (γεμίζει) ένα δεδομένο κείμενο στη δεδομένη θέση (x,y).

```java
public void FillText(String text, double x, double y)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| text | String | Το κείμενο που θα σχεδιαστεί χρησιμοποιώντας την τρέχουσα γραμματοσειρά, textAlign, textBaseline και τις τιμές direction. |
| x | Διπλό | Ο άξονας x της συντεταγμένης για το σημείο εκκίνησης του κειμένου. |
| y | Διπλό | Ο άξονας y της συντεταγμένης για το σημείο εκκίνησης του κειμένου. |

## FillText(String, double, double, double) {#filltext_1}

Σχεδιάζει (γεμίζει) ένα δεδομένο κείμενο στη δεδομένη θέση (x,y).

```java
public void FillText(String text, double x, double y, double maxWidth)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| text | String | Το κείμενο που θα σχεδιαστεί χρησιμοποιώντας την τρέχουσα γραμματοσειρά, textAlign, textBaseline και τις τιμές direction. |
| x | Διπλό | Ο άξονας x της συντεταγμένης για το σημείο εκκίνησης του κειμένου. |
| y | Διπλό | Ο άξονας y της συντεταγμένης για το σημείο εκκίνησης του κειμένου. |
| maxWidth | Διπλό | Το μέγιστο πλάτος για τη σχεδίαση. Εάν καθοριστεί και το String υπολογιστεί ότι είναι ευρύτερο από αυτό το πλάτος, η γραμματοσειρά προσαρμόζεται ώστε να χρησιμοποιήσει μια πιο οριζόντια συμπυκνωμένη γραμματοσειρά (εάν υπάρχει ή εάν μπορεί να συντεθεί μια λογικά αναγνώσιμη με οριζόντια κλιμάκωση της τρέχουσας γραμματοσειράς) ή μια μικρότερη γραμματοσειρά. |
