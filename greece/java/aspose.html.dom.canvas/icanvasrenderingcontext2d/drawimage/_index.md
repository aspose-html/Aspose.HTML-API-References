| sx | Διπλό | Η συντεταγμένη X της επάνω αριστερής γωνίας του υπο-ορθογωνίου της πηγαίας εικόνας για σχεδίαση στο προορισμό πλαίσιο. |
| sy | Διπλό | Η συντεταγμένη Y της επάνω αριστερής γωνίας του υπο-ορθογωνίου της πηγαίας εικόνας για σχεδίαση στο προορισμό πλαίσιο. |

| sh | Διπλό | Το ύψος του υπο-ορθογωνίου της πηγαίας εικόνας για σχεδίαση στο προορισμό πλαίσιο. |
| dx | Διπλό | Η συντεταγμένη X στον προορισμό καμβά στην οποία τοποθετείται η επάνω αριστερή γωνία της πηγαίας εικόνας. |
| dy | Διπλό | Η συντεταγμένη Y στον προορισμό καμβά στην οποία τοποθετείται η επάνω αριστερή γωνία της πηγαίας εικόνας. |
| dw | Διπλό | Το πλάτος για τη σχεδίαση της εικόνας στον προορισμό καμβά. Αυτό επιτρέπει την κλιμάκωση της σχεδιασμένης εικόνας. Εάν δεν καθοριστεί, η εικόνα δεν κλιμακώνεται σε πλάτος κατά τη σχεδίαση. |
| dh | Διπλό | Το ύψος για τη σχεδίαση της εικόνας στον προορισμό καμβά. Αυτό επιτρέπει την κλιμάκωση της σχεδιασμένης εικόνας. Εάν δεν καθοριστεί, η εικόνα δεν κλιμακώνεται σε ύψος κατά τη σχεδίαση. |
