## DrawImage(HTMLImageElement, double, double, double, double, double, double, double, double) {#drawimage_5}

Σχεδιάζει την καθορισμένη εικόνα.

```java
public void DrawImage(HTMLImageElement image, double sx, double sy, double sw, double sh, 
    double dx, double dy, double dw, double dh)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| εικόνα | HTMLImageElement | Το HTMLImageElement για σχεδίαση στο πλαίσιο. |
| sx | Double | Η συντεταγμένη X της πάνω αριστερής γωνίας του υπο-ορθογωνίου της πηγαίας εικόνας που θα σχεδιαστεί στο προορισμένο πλαίσιο. |
| sy | Double | Η συντεταγμένη Y της πάνω αριστερής γωνίας του υπο-ορθογωνίου της πηγαίας εικόνας που θα σχεδιαστεί στο προορισμένο πλαίσιο. |
| sw | Double | Το πλάτος του υπο-ορθογωνίου της πηγαίας εικόνας για σχεδίαση στο προορισμένο πλαίσιο. Εάν δεν καθοριστεί, χρησιμοποιείται ολόκληρο το ορθογώνιο από τις συντεταγμένες που ορίζονται από sx και sy έως την κάτω δεξιά γωνία της εικόνας. |
| sh | Double | Το ύψος του υπο-ορθογωνίου της πηγαίας εικόνας για σχεδίαση στο προορισμένο πλαίσιο. |
| dx | Double | Η συντεταγμένη X στον προορισμένο καμβά στην οποία τοποθετείται η πάνω αριστερή γωνία της πηγαίας εικόνας. |
| dy | Double | Η συντεταγμένη Y στον προορισμένο καμβά στην οποία τοποθετείται η πάνω αριστερή γωνία της πηγαίας εικόνας. |
| dw | Double | Το πλάτος για τη σχεδίαση της εικόνας στον προορισμένο καμβά. Αυτό επιτρέπει την κλιμάκωση της σχεδιασμένης εικόνας. Εάν δεν καθοριστεί, η εικόνα δεν κλιμακώνεται σε πλάτος κατά τη σχεδίαση. |
| dh | Double | Το ύψος για τη σχεδίαση της εικόνας στον προορισμένο καμβά. Αυτό επιτρέπει την κλιμάκωση της σχεδιασμένης εικόνας. Εάν δεν καθοριστεί, η εικόνα δεν κλιμακώνεται σε ύψος κατά τη σχεδίαση. |
