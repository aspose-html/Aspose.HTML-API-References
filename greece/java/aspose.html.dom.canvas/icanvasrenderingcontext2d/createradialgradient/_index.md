## ICanvasRenderingContext2D.CreateRadialGradient method

Δημιουργεί μια ακτινική διαβάθμιση που καθορίζεται από τις συντεταγμένες των δύο κύκλων που αντιπροσωπεύονται από τις παραμέτρους.

```java
public ICanvasGradient CreateRadialGradient(double x0, double y0, double r0, double x1, double y1, 
    double r1)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| x0 | Διπλό | Ο άξονας x του συντεταγμένου του αρχικού κύκλου. |
| y0 | Διπλό | Ο άξονας y του συντεταγμένου του αρχικού κύκλου |
| r0 | Διπλό | Η ακτίνα του αρχικού κύκλου. |
| x1 | Διπλό | Ο άξονας x του συντεταγμένου του τελικού κύκλου. |
| y1 | Διπλό | Ο άξονας y του συντεταγμένου του τελικού κύκλου |
| r1 | Διπλό | Η ακτίνα του τελικού κύκλου. |

### Τιμή Επιστροφής

Μια ακτινική CanvasGradient που αρχικοποιείται με τους δύο καθορισμένους κύκλους.
