## ICanvasRenderingContext2D.CreateRadialGradient method

Δημιουργεί ακτινική διαβάθμιση που δίνεται από τις συντεταγμένες των δύο κύκλων που αντιπροσωπεύονται από τις παραμέτρους.

```java
public ICanvasGradient CreateRadialGradient(double x0, double y0, double r0, double x1, double y1, 
    double r1)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| x0 | Double | Ο άξονας x της συντεταγμένης του αρχικού κύκλου. |
| y0 | Double | Ο άξονας y της συντεταγμένης του αρχικού κύκλου |
| r0 | Double | Η ακτίνα του αρχικού κύκλου. |
| x1 | Double | Ο άξονας x της συντεταγμένης του τελικού κύκλου. |
| y1 | Double | Ο άξονας y της συντεταγμένης του τελικού κύκλου. |
| r1 | Double | Η ακτίνα του τελικού κύκλου. |

### Τιμή επιστροφής

Μια κυκλική CanvasGradient που αρχικοποιείται με τους δύο καθορισμένους κύκλους.
