## IsPointInPath(double, double) {#ispointinpath_2}

Αναφέρει εάν το καθορισμένο σημείο περιέχεται ή όχι στην τρέχουσα διαδρομή.

```java
public bool IsPointInPath(double x, double y)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| x | Διπλό | Η συντεταγμένη X του σημείου που πρέπει να ελεγχθεί. |
| y | Διπλό | Η συντεταγμένη Y του σημείου που πρέπει να ελεγχθεί. |

### Τιμή Επιστροφής

Επιστρέφει true εάν το σημείο βρίσκεται μέσα στην περιοχή που περιέχεται από τη γεμιστική λειτουργία μιας διαδρομής, διαφορετικά false.
