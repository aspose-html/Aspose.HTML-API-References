## IsPointInPath(double, double) {#ispointinpath_2}

Αναφέρει αν το καθορισμένο σημείο περιέχεται ή όχι στο τρέχον μονοπάτι.

```java
public bool IsPointInPath(double x, double y)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| x | Double | Η συντεταγμένη X του σημείου που πρέπει να ελεγχθεί. |
| y | Double | Η συντεταγμένη Y του σημείου προς έλεγχο. |

### Τιμή επιστροφής

Επιστρέφει true εάν το σημείο βρίσκεται εντός της περιοχής που περιέχεται από το γέμισμα μιας διαδρομής, διαφορετικά false.
