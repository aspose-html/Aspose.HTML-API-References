## ICanvasRenderingContext2D.ClearRect method

Ορίζει όλα τα pixel στο ορθογώνιο που ορίζεται από το σημείο εκκίνησης (x, y) και το μέγεθος (πλάτος, ύψος) σε διαφανές μαύρο, διαγράφοντας οποιοδήποτε προηγούμενο περιεχόμενο.

```java
public void ClearRect(double x, double y, double w, double h)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| x | Double | Ο άξονας x των συντεταγμένων για το σημείο εκκίνησης του ορθογωνίου. |
| y | Double | Ο άξονας y των συντεταγμένων για το σημείο εκκίνησης του ορθογωνίου. |
| w | Double | Το πλάτος του ορθογωνίου. |
| h | Double | Το ύψος του ορθογωνίου. |
