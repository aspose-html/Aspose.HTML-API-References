## IsPointInStroke(double, double) {#ispointinstroke_1}

Αναφέρει αν το καθορισμένο σημείο βρίσκεται ή όχι στην περιοχή που περιέχεται από το περίγραμμα ενός μονοπατιού.

```java
public bool IsPointInStroke(double x, double y)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| x | Double | Η συντεταγμένη X του σημείου που πρέπει να ελεγχθεί. |
| y | Double | Η συντεταγμένη Y του σημείου προς έλεγχο. |

### Τιμή επιστροφής

Επιστρέφει true εάν το σημείο βρίσκεται εντός της περιοχής που περιέχεται από το περίγραμμα μιας διαδρομής, διαφορετικά false.
