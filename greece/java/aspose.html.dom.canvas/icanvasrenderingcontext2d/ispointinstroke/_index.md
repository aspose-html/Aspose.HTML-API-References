## IsPointInStroke(double, double) {#ispointinstroke_1}

Αναφέρει εάν το καθορισμένο σημείο βρίσκεται ή όχι στην περιοχή που περιέχεται από το περίγραμμα μιας διαδρομής.

```java
public bool IsPointInStroke(double x, double y)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| x | Διπλό | Η συντεταγμένη X του σημείου που πρέπει να ελεγχθεί. |
| y | Διπλό | Η συντεταγμένη Y του σημείου που πρέπει να ελεγχθεί. |

### Τιμή Επιστροφής

Επιστρέφει true εάν το σημείο βρίσκεται μέσα στην περιοχή που περιέχεται από το περίγραμμα μιας διαδρομής, διαφορετικά false.
