## Clip() {#clip}

Δημιουργεί μια νέα περιοχή αποκοπής υπολογίζοντας τη διασταύρωση της τρέχουσας περιοχής αποκοπής και της περιοχής που περιγράφεται από το μονοπάτι, χρησιμοποιώντας τον κανόνα μη μηδενικού αριθμού περιδρόμου. Τα ανοιχτά υπο-μονοπάτια πρέπει να κλείνουν έμμεσα κατά τον υπολογισμό της περιοχής αποκοπής, χωρίς να επηρεάζουν τα πραγματικά υπο-μονοπάτια. Η νέα περιοχή αποκοπής αντικαθιστά την τρέχουσα περιοχή αποκοπής.

```java
public void Clip()
```
