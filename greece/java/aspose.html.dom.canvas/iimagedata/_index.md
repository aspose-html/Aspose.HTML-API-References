## IImageData interface

Δημιουργεί ένα αντικείμενο ImageData από έναν δεδομένο Uint8ClampedArray και το μέγεθος της εικόνας που περιέχει. Εάν δεν δοθεί πίνακας, δημιουργεί μια εικόνα με μαύρο ορθογώνιο.

```java
public interface IImageData
```

| [getData](../../com.aspose.html.dom.canvas/iimagedata/data/) είναι ένα Uint8ClampedArray που αντιπροσωπεύει έναν μονοδιάστατο πίνακα που περιέχει τα δεδομένα με τη σειρά RGBA, με ακέραιες τιμές μεταξύ 0 και 255 (συμπεριλαμβανομένων). |
