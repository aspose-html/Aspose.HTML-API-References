## Arc(double, double, double, double, double) {#arc}

Προσθέτει ένα τόξο στο μονοπάτι που είναι κεντραρισμένο στη θέση (x, y) με ακτίνα r, ξεκινώντας από τη startAngle και τελειώνοντας στη endAngle, κινούμενο στην καθορισμένη κατεύθυνση αριστερόστροφα (προεπιλογή δεξιόστροφα).

```java
public void Arc(double x, double y, double radius, double startAngle, double endAngle)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| x | Διπλό | Η συντεταγμένη x του κέντρου της καμπύλης. |
| y | Διπλό | Η συντεταγμένη y του κέντρου της καμπύλης. |
| ακτίνα | Διπλό | Η ακτίνα της καμπύλης. |
| startAngle | Διπλό | Η γωνία στην οποία ξεκινά η καμπύλη, μετρημένη δεξιόστροφα από τον θετικό άξονα x και εκφρασμένη σε ακτίνια. |
| endAngle | Διπλό | Η γωνία στην οποία τελειώνει η καμπύλη, μετρημένη δεξιόστροφα από τον θετικό άξονα x και εκφρασμένη σε ακτίνια. |

## Arc(double, double, double, double, double, bool) {#arc_1}

Προσθέτει ένα τόξο στο μονοπάτι που είναι κεντραρισμένο στη θέση (x, y) με ακτίνα r, ξεκινώντας από τη startAngle και τελειώνοντας στη endAngle, κινούμενο στην καθορισμένη κατεύθυνση αριστερόστροφα (προεπιλογή δεξιόστροφα).

```java
public void Arc(double x, double y, double radius, double startAngle, double endAngle, 
    bool counterclockwise)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| x | Διπλό | Η συντεταγμένη x του κέντρου της καμπύλης. |
| y | Διπλό | Η συντεταγμένη y του κέντρου της καμπύλης. |
| ακτίνα | Διπλό | Η ακτίνα της καμπύλης. |
| startAngle | Διπλό | Η γωνία στην οποία ξεκινά η καμπύλη, μετρημένη δεξιόστροφα από τον θετικό άξονα x και εκφρασμένη σε ακτίνια. |
| endAngle | Διπλό | Η γωνία στην οποία τελειώνει η καμπύλη, μετρημένη δεξιόστροφα από τον θετικό άξονα x και εκφρασμένη σε ακτίνια. |
| αντίστροφα | Boolean | Προκαλεί τη σχεδίαση της καμπύλης αντίστροφα μεταξύ των δύο γωνιών. Από προεπιλογή σχεδιάζεται δεξιόστροφα. |
