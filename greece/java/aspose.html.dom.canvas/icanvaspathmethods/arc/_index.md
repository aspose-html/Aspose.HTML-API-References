## Arc(double, double, double, double, double) {#arc}

Προσθέτει ένα τόξο στη διαδρομή που κεντράρεται στη θέση (x, y) με ακτίνα r, ξεκινώντας από την startAngle και λήγοντας στην endAngle, κινούμενο προς την καθορισμένη κατεύθυνση αντίστροφα από το ρολόι (προεπιλογή προς το ρολόι).

```java
public void Arc(double x, double y, double radius, double startAngle, double endAngle)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| x | Double | Η συντεταγμένη x του κέντρου της καμπύλης. |
| y | Double | Η συντεταγμένη y του κέντρου της καμπύλης. |
| ακτίνα | Double | Η ακτίνα της καμπύλης. |
| startAngle | Double | Η γωνία στην οποία ξεκινά η καμπύλη, μετρημένη δεξιόστροφα από τον θετικό άξονα x και εκφρασμένη σε ακτίνια. |
| endAngle | Double | Η γωνία στην οποία τελειώνει η καμπύλη, μετρημένη δεξιόστροφα από τον θετικό άξονα x και εκφρασμένη σε ακτίνια. |

## Arc(double, double, double, double, double, bool) {#arc_1}

Προσθέτει ένα τόξο στη διαδρομή που κεντράρεται στη θέση (x, y) με ακτίνα r, ξεκινώντας από την startAngle και λήγοντας στην endAngle, κινούμενο προς την καθορισμένη κατεύθυνση αντίστροφα από το ρολόι (προεπιλογή προς το ρολόι).

```java
public void Arc(double x, double y, double radius, double startAngle, double endAngle, 
    bool counterclockwise)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| x | Double | Η συντεταγμένη x του κέντρου της καμπύλης. |
| y | Double | Η συντεταγμένη y του κέντρου της καμπύλης. |
| ακτίνα | Double | Η ακτίνα της καμπύλης. |
| startAngle | Double | Η γωνία στην οποία ξεκινά η καμπύλη, μετρημένη δεξιόστροφα από τον θετικό άξονα x και εκφρασμένη σε ακτίνια. |
| endAngle | Double | Η γωνία στην οποία τελειώνει η καμπύλη, μετρημένη δεξιόστροφα από τον θετικό άξονα x και εκφρασμένη σε ακτίνια. |
| αντιδεξιόστροφα | Boolean | Προκαλεί την καμπύλη να σχεδιαστεί αντιδεξιόστροφα μεταξύ των δύο γωνιών. Από προεπιλογή σχεδιάζεται δεξιόστροφα. |
