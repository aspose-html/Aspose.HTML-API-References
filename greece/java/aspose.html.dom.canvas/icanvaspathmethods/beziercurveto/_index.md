## ICanvasPathMethods.BezierCurveTo method

Προσθέτει μια κυβική καμπύλη Bézier στη διαδρομή. Απαιτεί τρία σημεία. Τα πρώτα δύο σημεία είναι σημεία ελέγχου και το τρίτο είναι το σημείο λήξης. Το σημείο εκκίνησης είναι το τελευταίο σημείο στην τρέχουσα διαδρομή, το οποίο μπορεί να αλλάξει χρησιμοποιώντας τη moveTo() πριν δημιουργηθεί η καμπύλη Bézier.

```java
public void BezierCurveTo(double cp1x, double cp1y, double cp2x, double cp2y, double x, double y)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| cp1x | Double | Ο άξονας x της συντεταγμένης για το πρώτο σημείο ελέγχου. |
| cp1y | Double | Ο άξονας y της συντεταγμένης για το πρώτο σημείο ελέγχου. |
| cp2x | Double | Ο άξονας x της συντεταγμένης για το δεύτερο σημείο ελέγχου. |
| cp2y | Double | Ο άξονας y της συντεταγμένης για το δεύτερο σημείο ελέγχου. |
| x | Double | Ο άξονας x της συντεταγμένης για το σημείο λήξης. |
| y | Double | Ο άξονας y της συντεταγμένης για το σημείο λήξης. |
