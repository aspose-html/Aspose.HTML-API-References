## ICanvasPathMethods.BezierCurveTo method

Προσθέτει μια κυβική καμπύλη Bézier στο μονοπάτι. Απαιτεί τρία σημεία. Τα πρώτα δύο σημεία είναι σημεία ελέγχου και το τρίτο είναι το τελικό σημείο. Το αρχικό σημείο είναι το τελευταίο σημείο του τρέχοντος μονοπατιού, το οποίο μπορεί να αλλάξει χρησιμοποιώντας τη moveTo() πριν δημιουργηθεί η καμπύλη Bézier.

```java
public void BezierCurveTo(double cp1x, double cp1y, double cp2x, double cp2y, double x, double y)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| cp1x | Διπλό | Ο άξονας x της συντεταγμένης για το πρώτο σημείο ελέγχου. |
| cp1y | Διπλό | Ο άξονας y της συντεταγμένης για το πρώτο σημείο ελέγχου. |
| cp2x | Διπλό | Ο άξονας x της συντεταγμένης για το δεύτερο σημείο ελέγχου. |
| cp2y | Διπλό | Ο άξονας y της συντεταγμένης για το δεύτερο σημείο ελέγχου. |
| x | Διπλό | Ο άξονας x της συντεταγμένης για το σημείο λήξης. |
| y | Διπλό | Ο άξονας y της συντεταγμένης για το σημείο λήξης. |
