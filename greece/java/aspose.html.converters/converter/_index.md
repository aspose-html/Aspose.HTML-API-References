## Converter class

Κοινή πρόσοψη μόνο για τα πιο συχνά σενάρια μετατροπής. Παρέχει μια ευρεία γκάμα μετατροπών σε δημοφιλείς μορφές, όπως PDF, XPS, μορφές εικόνας κ.λπ. Πιο συγκεκριμένες περιπτώσεις χρήσης μετατροπής (απόδοση, αποθήκευση) παρουσιάζονται από γνωστές και τεκμηριωμένες λειτουργίες API χαμηλού επιπέδου.

Περισσότερες λεπτομερείς πληροφορίες σχετικά με τη μετατροπή μπορείτε να βρείτε στην [Aspose Documentation](https://docs.aspose.com/html/net/converting-between-formats/)

```java
public static class Converter
```
