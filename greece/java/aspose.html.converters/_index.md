Ο στόχος του **com.aspose.html.converters** πακέτου είναι η εύκολη πρόσβαση σε μεθόδους μετατροπής. Παρέχει ένα ευρύ φάσμα μετατροπών σε δημοφιλείς μορφές, όπως PDF, XPS, μορφές εικόνας κ.λπ. Πιο συγκεκριμένες περιπτώσεις χρήσης μετατροπής (απόδοση, αποθήκευση) παρουσιάζονται από καλά γνωστές και τεκμηριωμένες λειτουργίες API χαμηλού επιπέδου σε πακέτα προσανατολισμένα στο αντικείμενο.

Πιο συγκεκριμένες περιπτώσεις χρήσης μετατροπής (απόδοση, αποθήκευση) παρουσιάζονται από καλά γνωστές και τεκμηριωμένες λειτουργίες API χαμηλού επιπέδου. |
| [TemplateContentOptions](./templatecontentoptions/) | Αντικείμενο ενσωματωμένου περιεχομένου για επεξεργασία συγχώνευσης. |
| [TemplateData](./templatedata/) | Αντικείμενο δεδομένων συγχώνευσης (Χρήστη). |
