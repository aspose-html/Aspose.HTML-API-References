## RequestMessage.PreAuthenticate property

Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει αν θα σταλεί κεφαλίδα Authorization με το αίτημα.

```java
public bool PreAuthenticate { get; set; }
```

### Property Value

`true` για αποστολή κεφαλίδας HTTP Authorization με τα αιτήματα μετά την ολοκλήρωση του ελέγχου ταυτότητας· διαφορετικά, `false`. Η προεπιλογή είναι `false`.
