## SVGPoint class

Πολλές από τις διεπαφές SVG DOM αναφέρονται σε αντικείμενα της κλάσης SVGPoint. Ένα SVGPoint είναι ένα ζεύγος συντεταγμένων (x, y). Όταν χρησιμοποιείται σε πράξεις με πίνακες, ένα SVGPoint αντιμετωπίζεται ως διάνυσμα της μορφής: [x] [y] [1]. Εάν ένα αντικείμενο SVGRect οριστεί ως μόνο για ανάγνωση, τότε η προσπάθεια ανάθεσης σε κάποιο από τα χαρακτηριστικά του θα προκαλέσει την εμφάνιση μιας εξαίρεσης.

```java
public class SVGPoint : SVGValueType
```
