## SVGAnimatedValue&lt;T&gt;.AnimVal property

Εάν το δεδομένο χαρακτηριστικό ή η ιδιότητα είναι animated, περιέχει την τρέχουσα animated τιμή του χαρακτηριστικού ή της ιδιότητας. Εάν το δεδομένο χαρακτηριστικό ή η ιδιότητα δεν είναι αυτή τη στιγμή animated, περιέχει την ίδια τιμή με το baseVal.

```java
public T AnimVal { get; }
```

### Property Value

`true` εάν [anim value]; διαφορετικά, `false`.
