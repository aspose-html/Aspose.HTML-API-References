## SVGTransform.SetTranslate method

Ορίζει τον τύπο μετασχηματισμού σε SVG_TRANSFORM_TRANSLATE, με τις παραμέτρους tx και ty που καθορίζουν τα ποσά μετάφρασης.

```java
public void SetTranslate(float tx, float ty)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| tx | Single | Το ποσό μετατόπισης στον άξονα X. |
| ty | Single | Το ποσό μετάφρασης στον άξονα Y. |
