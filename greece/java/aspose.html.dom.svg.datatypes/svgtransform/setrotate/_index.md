## SVGTransform.SetRotate method

Ορίζει τον τύπο μετασχηματισμού σε SVG_TRANSFORM_ROTATE, με την παράμετρο angle που καθορίζει τη γωνία περιστροφής και τις παραμέτρους cx και cy που καθορίζουν το προαιρετικό κέντρο περιστροφής.

```java
public void SetRotate(float angle, float cx, float cy)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| γωνία | Single | Η γωνία περιστροφής. |
| cx | Single | Η συντεταγμένη x του κέντρου περιστροφής. |
| cy | Single | Η συντεταγμένη y του κέντρου περιστροφής. |
