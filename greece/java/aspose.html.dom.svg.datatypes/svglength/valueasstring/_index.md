## SVGLength.ValueAsString property

Η τιμή ως τιμή String, στις μονάδες που εκφράζονται από το unitType. Η ρύθμιση αυτού του χαρακτηριστικού θα προκαλέσει την αυτόματη ενημέρωση των value, valueInSpecifiedUnits και unitType ώστε να αντικατοπτρίζουν αυτή τη ρύθμιση.

```java
public String ValueAsString { get; set; }
```

### Property Value

Η τιμή ως String.
