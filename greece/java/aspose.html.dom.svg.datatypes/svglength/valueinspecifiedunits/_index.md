## SVGLength.ValueInSpecifiedUnits property

Η τιμή ως αριθμός κινητής υποδιαστολής, στις μονάδες που εκφράζονται από το unitType. Ο καθορισμός αυτού του χαρακτηριστικού θα προκαλέσει την αυτόματη ενημέρωση των value και valueAsString ώστε να αντικατοπτρίζουν αυτή τη ρύθμιση

```java
public float ValueInSpecifiedUnits { get; set; }
```

Η τιμή στις καθορισμένες μονάδες.
