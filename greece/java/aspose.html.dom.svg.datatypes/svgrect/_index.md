## SVGRect class

Αναπαριστά ορθογώνια γεωμετρία. Τα ορθογώνια ορίζονται ως ένα ζεύγος συντεταγμένων (x,y) που προσδιορίζει την ελάχιστη τιμή X, την ελάχιστη τιμή Y, καθώς και το πλάτος και το ύψος, τα οποία συνήθως περιορίζονται ώστε να είναι μη αρνητικά.

```java
public class SVGRect : SVGValueType
```
