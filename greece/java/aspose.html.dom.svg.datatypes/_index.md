Το πακέτο παρέχει πρόσβαση σε όλους τους τύπους δεδομένων ειδικούς για SVG.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [SVGAngle](./svgangle/) | Η διεπαφή SVGAngle αντιστοιχεί στον βασικό τύπο δεδομένων γωνίας. |
| [SVGAnimatedAngle](./svganimatedangle/) | Χρησιμοποιείται για ιδιότητες του βασικού τύπου δεδομένων γωνίας που μπορούν να αναπαραχθούν. |
| [SVGAnimatedBoolean](./svganimatedboolean/) | Χρησιμοποιείται για ιδιότητες τύπου boolean που μπορούν να αναπαραχθούν. |
| [SVGAnimatedEnumeration](./svganimatedenumeration/) | Χρησιμοποιείται για ιδιότητες των οποίων η τιμή πρέπει να είναι μια σταθερά από μια συγκεκριμένη απαρίθμηση και που μπορούν να αναπαραχθούν. |
| [SVGAnimatedInteger](./svganimatedinteger/) | Χρησιμοποιείται για ιδιότητες του βασικού τύπου integer που μπορούν να αναπαραχθούν. |
| [SVGAnimatedLength](./svganimatedlength/) | Χρησιμοποιείται για ιδιότητες του βασικού τύπου length που μπορούν να αναπαραχθούν. |
| [SVGAnimatedLengthList](./svganimatedlengthlist/) | Χρησιμοποιείται για ιδιότητες τύπου SVGLengthList που μπορούν να αναπαραχθούν. |
| [SVGAnimatedNumber](./svganimatednumber/) | Χρησιμοποιείται για ιδιότητες του βασικού τύπου number που μπορούν να αναπαραχθούν. |
| [SVGAnimatedNumberList](./svganimatednumberlist/) | Χρησιμοποιείται για ιδιότητες που δέχονται μια λίστα αριθμών και μπορούν να αναπαραχθούν. |
| [SVGAnimatedPreserveAspectRatio](./svganimatedpreserveaspectratio/) | Χρησιμοποιείται για ιδιότητες τύπου SVGPreserveAspectRatio που μπορούν να αναπαραχθούν. |
| [SVGAnimatedRect](./svganimatedrect/) | Χρησιμοποιείται για ιδιότητες τύπου SVGRect που μπορούν να αναπαραχθούν. |
| [SVGAnimatedString](./svganimatedString/) | Χρησιμοποιείται για ιδιότητες τύπου DOMString που μπορούν να αναπαραχθούν. |
| [SVGAnimatedTransformList](./svganimatedtransformlist/) | Χρησιμοποιείται για τα διάφορα χαρακτηριστικά που καθορίζουν ένα σύνολο μετασχηματισμών, όπως το χαρακτηριστικό ‘transform’ που είναι διαθέσιμο για πολλά στοιχεία του SVG και μπορεί να αναπαραχθεί με κίνηση. |
| [SVGAnimatedValue&lt;T&gt;](./svganimatedvalue-1/) | Χρησιμοποιείται για χαρακτηριστικά τύπων που μπορούν να αναπαραχθούν με κίνηση. |
| [SVGLength](./svglength/) | Η διεπαφή SVGLength αντιστοιχεί στον βασικό τύπο δεδομένων length. Ένα αντικείμενο SVGLength μπορεί να οριστεί ως μόνο για ανάγνωση, κάτι που σημαίνει ότι οι προσπάθειες τροποποίησης του αντικειμένου θα προκαλέσουν την εμφάνιση μιας εξαίρεσης, όπως περιγράφεται παρακάτω. |
| [SVGLengthList](./svglengthlist/) | Αυτή η διεπαφή ορίζει μια λίστα από αντικείμενα SVGLength. |
| [SVGMatrix](./svgmatrix/) | Πολλές από τις γραφικές λειτουργίες του SVG χρησιμοποιούν πίνακες 2x3 της μορφής: [a c e] [b d f] οι οποίοι, όταν επεκτείνονται σε πίνακα 3x3 για σκοπούς αριθμητικών πράξεων, γίνονται: [a c e] [b d f] [0 0 1] |
| [SVGNumber](./svgnumber/) | Χρησιμοποιείται για χαρακτηριστικά βασικού τύπου number. |
| [SVGNumberList](./svgnumberlist/) | Αυτή η διεπαφή ορίζει μια λίστα από αντικείμενα SVGNumber. |
| [SVGPoint](./svgpoint/) | Πολλές από τις διεπαφές SVG DOM αναφέρονται σε αντικείμενα της κλάσης SVGPoint. Ένα SVGPoint είναι ένα ζεύγος συντεταγμένων (x, y). Όταν χρησιμοποιείται σε πράξεις με πίνακες, ένα SVGPoint αντιμετωπίζεται ως διάνυσμα της μορφής: [x] [y] [1]. Εάν ένα αντικείμενο SVGRect οριστεί ως μόνο για ανάγνωση, τότε η προσπάθεια ανάθεσης σε κάποιο από τα χαρακτηριστικά του θα προκαλέσει την εμφάνιση μιας εξαίρεσης. |
| [SVGPointList](./svgpointlist/) | Αυτή η διεπαφή ορίζει μια λίστα από αντικείμενα SVGPoint. |
| [SVGPreserveAspectRatio](./svgpreserveaspectratio/) | Η διεπαφή SVGPreserveAspectRatio αντιστοιχεί στο χαρακτηριστικό ‘preserveAspectRatio’, το οποίο είναι διαθέσιμο για ορισμένα στοιχεία του SVG. |
| [SVGRect](./svgrect/) | Αναπαριστά ορθογώνια γεωμετρία. Τα ορθογώνια ορίζονται ως ένα ζεύγος συντεταγμένων (x,y) που προσδιορίζει την ελάχιστη τιμή X, την ελάχιστη τιμή Y, καθώς και το πλάτος και το ύψος, τα οποία συνήθως περιορίζονται ώστε να είναι μη αρνητικά. |
| [SVGStringList](./svgStringlist/) | Η SVGStringList έχει τα ίδια χαρακτηριστικά και μεθόδους με άλλες διεπαφές SVGxxxList. Οι υλοποιητές μπορεί να εξετάσουν τη χρήση μιας ενιαίας βασικής κλάσης για την υλοποίηση των διαφόρων διεπαφών SVGxxxList. |
| [SVGTransform](./svgtransform/) | Η SVGTransform είναι η διεπαφή για έναν από τους μετασχηματισμούς στοιχείου μέσα σε μια SVGTransformList· έτσι, ένα αντικείμενο SVGTransform αντιστοιχεί σε ένα μοναδικό στοιχείο (π.χ., 'scale(…)' ή 'matrix(…)') μέσα σε μια προδιαγραφή χαρακτηριστικού ‘transform’. |
| [SVGTransformList](./svgtransformlist/) | Αυτή η διεπαφή ορίζει μια λίστα από αντικείμενα SVGTransform. |
| [SVGValueType](./svgvaluetype/) | Ο τύπος SVGValueType χρησιμοποιείται για την αναπαράσταση ενός βασικού τύπου τιμής SVG. |
