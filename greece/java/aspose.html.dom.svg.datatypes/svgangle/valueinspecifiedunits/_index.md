## SVGAngle.ValueInSpecifiedUnits property

Η τιμή της γωνίας ως αριθμός κινητής υποδιαστολής, στις μονάδες που εκφράζονται από unitType. Ορίζοντας αυτό το χαρακτηριστικό θα προκαλέσει την αυτόματη ενημέρωση των value και valueAsString ώστε να αντανακλούν αυτή τη ρύθμιση.

```java
public float ValueInSpecifiedUnits { get; set; }
```
