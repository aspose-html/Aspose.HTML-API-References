## SVGAngle.ValueAsString property

Η τιμή της γωνίας ως τιμή String, στις μονάδες που εκφράζονται από unitType. Ορίζοντας αυτό το χαρακτηριστικό θα προκαλέσει την αυτόματη ενημέρωση των value, valueInSpecifiedUnits και unitType ώστε να αντανακλούν αυτή τη ρύθμιση.

```java
public String ValueAsString { get; set; }
```

### Property Value

Η τιμή ως String.
