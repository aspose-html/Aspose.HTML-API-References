## IXPathResult.InvalidIteratorState property

Indique que l'itérateur est devenu invalide. Vrai si `resultType` est de type `UnorderedNodeIterator` ou `OrderedNodeIterator` et que le document a été modifié depuis que ce résultat a été renvoyé.

```java
public bool InvalidIteratorState { get; }
```
