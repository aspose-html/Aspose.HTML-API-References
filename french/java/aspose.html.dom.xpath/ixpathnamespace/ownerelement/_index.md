## IXPathNamespace.OwnerElement property

L'[`Element`](../../../com.aspose.html.dom/element/) sur lequel le package était en portée lorsqu'il a été demandé. Cela ne change pas sur un nœud de package retourné même si le document change de façon à ce que le package ne soit plus en portée sur cet élément et que ce nœud ne soit plus trouvé par XPath.

```java
public Element OwnerElement { get; }
```
