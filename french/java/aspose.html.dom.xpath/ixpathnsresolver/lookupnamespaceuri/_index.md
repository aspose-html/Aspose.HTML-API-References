## IXPathNSResolver.LookupNamespaceURI method

Recherchez l'URI du package associé au préfixe de package donné. L'évaluateur XPath ne doit jamais appeler cela avec un argument `null` ou vide, car le résultat de cette opération est indéfini.

```java
public String LookupNamespaceURI(String prefix)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| préfixe | String | Le préfixe à rechercher. |

### Valeur de retour

Renvoie l'URI de package associé ou `null` si aucun n'est trouvé.
