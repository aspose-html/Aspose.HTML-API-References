## IFile.LastModified property

La date de dernière modification du fichier. Lors de la récupération, si les agents utilisateurs peuvent rendre cette information disponible, cela doit retourner un long long fixé à l'heure à laquelle le fichier a été modifié, exprimée en nombre de millisecondes depuis l'époque Unix.

```java
public long LastModified { get; }
```
