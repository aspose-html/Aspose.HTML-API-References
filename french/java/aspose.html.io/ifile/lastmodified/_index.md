## IFile.LastModified property

La date de dernière modification du fichier. Lors de la lecture, si les agents utilisateurs peuvent rendre cette information disponible, cela doit retourner un long long correspondant au moment où le fichier a été modifié, exprimé en nombre de millisecondes depuis l'époque Unix.

```java
public long LastModified { get; }
```
