## IBlob.Slice method

Renvoie un nouvel objet Blob contenant les octets allant du paramètre optionnel start jusqu'au paramètre optionnel end (exclu), et avec un attribut type dont la valeur correspond au paramètre optionnel contentType.

```java
public IBlob Slice(ulong start, ulong end, String contentType)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| début | UInt64 | Le paramètre est une valeur indiquant le point de départ d'une tranche |
| fin | UInt64 | Le paramètre est une valeur indiquant le point de départ d'une tranche |
| contentType | String | Le paramètre est un type MIME du Blob |

### Valeur de retour

Renvoie un nouvel objet Blob contenant les octets allant du paramètre optionnel start jusqu'au paramètre optionnel end (exclu), et avec un attribut type dont la valeur correspond au paramètre optionnel contentType.
