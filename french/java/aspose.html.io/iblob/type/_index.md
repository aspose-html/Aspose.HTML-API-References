## IBlob.Type property

La chaîne encodée en ASCII en minuscules représentant le type média du Blob. Lors de la lecture, les agents utilisateurs doivent retourner le type d'un Blob sous forme d'une chaîne encodée en ASCII en minuscules, de telle sorte que, lorsqu'elle est convertie en séquence d'octets, elle constitue un type MIME analysable, ou la chaîne vide – 0 octet – si le type ne peut être déterminé.

public String Type { get; }
