## IBlob.Size property

Retourne la taille de la séquence d'octets en nombre d'octets. Lors de la récupération, les agents utilisateurs conformes doivent retourner le nombre total d'octets pouvant être lus par un objet FileReader ou FileReaderSync, ou 0 si le Blob ne contient aucun octet à lire.

public ulong Size { get; }
