En plus des outils d'E/S (entrée-sortie) standard, le paquet **com.aspose.html.io** contient des classes et des interfaces d'aide.

## Classes

| Classe | Description |
| --- | --- |
| [FileCreateStreamProvider](./filecreatestreamprovider/) | Représente l'implémentation FileStream permettant de fournir des flux aux appareils de rendu. |
## Interfaces

| Interface | Description |
| --- | --- |
| [IBlob](./iblob/) | Un objet Blob fait référence à une séquence d'octets et possède un attribut size qui correspond au nombre total d'octets dans la séquence, ainsi qu'un attribut type, qui est une chaîne encodée en ASCII en minuscules représentant le type média de la séquence d'octets. |
| [ICreateStreamProvider](./icreatestreamprovider/) | Représente une interface pouvant être implémentée par des classes fournissant des flux aux appareils de rendu. |
| [IFile](./ifile/) | Un objet File est un objet Blob avec un attribut name, qui est une chaîne ; il peut être créé dans l'application web via un constructeur, ou constitue une référence à une séquence d'octets provenant d'un fichier du système de fichiers sous‑jacent (OS). |
| [IFileList](./ifilelist/) | Représente l'interface pour la liste des fichiers. |
