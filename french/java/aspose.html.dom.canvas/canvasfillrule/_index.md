## CanvasFillRule enumeration

Cette énumération est utilisée pour sélectionner l'algorithme de règle de remplissage permettant de déterminer si un point se trouve à l'intérieur ou à l'extérieur d'un chemin.

```java
public enum CanvasFillRule
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| NonZero | `0` | La valeur "nonzero" indique la règle de winding non nulle, selon laquelle un point est considéré comme étant à l'extérieur d'une forme si le nombre de fois qu'une demi‑ligne infinie tracée depuis ce point traverse le chemin de la forme dans une direction est égal au nombre de fois qu'elle le traverse dans l'autre direction. |
| EvenOdd | `1` | La valeur "evenodd" indique la règle pair‑impair, selon laquelle un point est considéré comme étant à l'extérieur d'une forme si le nombre de fois qu'une demi‑ligne infinie tracée depuis ce point traverse le chemin de la forme est pair. |
