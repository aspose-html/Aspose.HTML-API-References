## ICanvasRenderingContext2D.GetImageData method

Renvoie un objet ImageData représentant les données de pixels sous‑jacentes pour la zone du canevas désignée par le rectangle qui commence à (sx, sy) et possède une largeur sw et une hauteur sh. Cette méthode n'est pas affectée par la matrice de transformation du canevas.

```java
public IImageData GetImageData(double sx, double sy, double sw, double sh)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| sx | Double | La coordonnée x du coin supérieur gauche du rectangle à partir duquel l'ImageData sera extrait. |
| sy | Double | La coordonnée y du coin supérieur gauche du rectangle à partir duquel l'ImageData sera extrait. |
| sw | Double | La largeur du rectangle à partir duquel l'ImageData sera extrait. |
| sh | Double | La hauteur du rectangle à partir duquel l'ImageData sera extrait. |

### Valeur de retour

Un objet ImageData contenant les données d'image pour le rectangle donné du canvas.
