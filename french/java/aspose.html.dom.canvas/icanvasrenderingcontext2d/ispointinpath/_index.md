## IsPointInPath(double, double) {#ispointinpath_2}

Indique si le point spécifié est ou non contenu dans le chemin actuel.

```java
public bool IsPointInPath(double x, double y)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| x | Double | La coordonnée X du point à vérifier. |
| y | Double | La coordonnée Y du point à vérifier. |

### Valeur de retour

Renvoie vrai si le point se trouve à l'intérieur de la zone définie par le remplissage d'un chemin, sinon faux.
