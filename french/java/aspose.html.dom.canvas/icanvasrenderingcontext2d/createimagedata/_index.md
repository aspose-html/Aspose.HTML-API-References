## CreateImageData(double, double) {#createimagedata_1}

Crée un nouvel objet ImageData vierge avec les dimensions spécifiées. Tous les pixels du nouvel objet sont noirs transparents.

```java
public IImageData CreateImageData(double sw, double sh)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| sw | Double | La largeur à attribuer au nouvel objet ImageData. |
| sh | Double | La hauteur à attribuer au nouvel objet ImageData. |

### Valeur de retour

Un nouvel objet ImageData avec la largeur et la hauteur spécifiées. Le nouvel objet est rempli de pixels noirs transparents.

## CreateImageData(IImageData) {#createimagedata}

```java
public IImageData CreateImageData(IImageData imagedata)
```

| Paramètre | Type | Description |
| --- | --- | --- |
