## CreatePattern(HTMLImageElement, String) {#createpattern_1}

Crée un motif en utilisant l'image spécifiée (un CanvasImageSource). Il répète la source dans les directions spécifiées par l'argument de répétition.

```java
public ICanvasPattern CreatePattern(HTMLImageElement image, String repetition)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| image | HTMLImageElement | Un HTMLImageElement à utiliser comme image à répéter |
| repetition | String | Une chaîne indiquant comment répéter l'image. |

### Valeur de retour

Un objet opaque décrivant un motif.
