## IsPointInStroke(double, double) {#ispointinstroke_1}

Indique si le point spécifié est ou non à l'intérieur de la zone contenue par le tracé d'un chemin.

```java
public bool IsPointInStroke(double x, double y)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| x | Double | La coordonnée X du point à vérifier. |
| y | Double | La coordonnée Y du point à vérifier. |

### Valeur de retour

Renvoie vrai si le point se trouve à l'intérieur de la zone définie par le tracé d'un chemin, sinon faux.
