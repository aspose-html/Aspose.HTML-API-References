## Ellipse(double, double, double, double, double, double, double) {#ellipse}

Ajoute une ellipse au chemin centrée à la position (x, y) avec les rayons radiusX et radiusY, commençant à startAngle et se terminant à endAngle en suivant la direction donnée, en sens antihoraire (par défaut horaire).

```java
public void Ellipse(double x, double y, double radiusX, double radiusY, double rotation, 
    double startAngle, double endAngle)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| x | Double | L'axe x de la coordonnée du centre de l'ellipse. |
| y | Double | L'axe y de la coordonnée du centre de l'ellipse. |
| radiusX | Double | Le rayon du grand axe de l'ellipse. |
| radiusY | Double | Le rayon du petit axe de l'ellipse. |
| rotation | Double | La rotation de cette ellipse, exprimée en radians. |
| startAngle | Double | Le point de départ, mesuré à partir de l'axe x, à partir duquel il sera tracé, exprimé en radians. |
| endAngle | Double | L'angle de fin de l'ellipse auquel il sera tracé, exprimé en radians. |

## Ellipse(double, double, double, double, double, double, double, bool) {#ellipse_1}

Ajoute une ellipse au chemin centrée à la position (x, y) avec les rayons radiusX et radiusY, commençant à startAngle et se terminant à endAngle en suivant la direction donnée, en sens antihoraire (par défaut horaire).

```java
public void Ellipse(double x, double y, double radiusX, double radiusY, double rotation, 
    double startAngle, double endAngle, bool anticlockwise)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| x | Double | L'axe x de la coordonnée du centre de l'ellipse. |
| y | Double | L'axe y de la coordonnée du centre de l'ellipse. |
| radiusX | Double | Le rayon du grand axe de l'ellipse. |
| radiusY | Double | Le rayon du petit axe de l'ellipse. |
| rotation | Double | La rotation de cette ellipse, exprimée en radians. |
| startAngle | Double | Le point de départ, mesuré à partir de l'axe x, à partir duquel il sera tracé, exprimé en radians. |
| endAngle | Double | L'angle de fin de l'ellipse auquel il sera tracé, exprimé en radians. |
| antihoraire | Boolean | Un booléen optionnel qui, s'il est vrai, trace l'ellipse dans le sens antihoraire (contre‑horaire), sinon dans le sens horaire. |
