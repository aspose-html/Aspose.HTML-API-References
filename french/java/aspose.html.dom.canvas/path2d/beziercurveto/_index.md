## Path2D.BezierCurveTo method

Ajoute une courbe de Bézier cubique au chemin. Elle nécessite trois points. Les deux premiers points sont des points de contrôle et le troisième est le point d'arrivée. Le point de départ est le dernier point du chemin actuel, qui peut être modifié avec moveTo() avant de créer la courbe de Bézier.

```java
public void BezierCurveTo(double cp1x, double cp1y, double cp2x, double cp2y, double x, double y)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| cp1x | Double | L'axe x de la coordonnée du premier point de contrôle. |
| cp1y | Double | L'axe y de la coordonnée du premier point de contrôle. |
| cp2x | Double | L'axe x de la coordonnée du deuxième point de contrôle. |
| cp2y | Double | L'axe y de la coordonnée du deuxième point de contrôle. |
| x | Double | L'axe x de la coordonnée du point final. |
| y | Double | L'axe y de la coordonnée du point final. |
