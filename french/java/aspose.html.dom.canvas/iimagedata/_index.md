## IImageData interface

Crée un objet ImageData à partir d'un Uint8ClampedArray donné et de la taille de l'image qu'il contient. Si aucun tableau n'est fourni, il crée une image d'un rectangle noir.

```java
public interface IImageData
```

## Propriétés

| Nom | Description |
| --- | --- |
| [getData](../../com.aspose.html.dom.canvas/iimagedata/data/) est un Uint8ClampedArray représentant un tableau unidimensionnel contenant les données dans l'ordre RGBA, avec des valeurs entières comprises entre 0 et 255 (inclus). |
| [getHeight](../../com.aspose.html.dom.canvas/iimagedata/height/) est un entier non signé représentant la hauteur réelle, en pixels, de l'ImageData. |
| [getWidth](../../com.aspose.html.dom.canvas/iimagedata/width/) est un entier non signé représentant la largeur réelle, en pixels, de l'ImageData. |
