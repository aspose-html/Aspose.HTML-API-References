## ICanvasDrawingStyles.GetLineDash method

Renvoie le tableau du motif de tirets de ligne actuel contenant un nombre pair de nombres non négatifs.

```java
public double[] GetLineDash()
```

### Valeur de retour

Un tableau. Une liste de nombres qui spécifie les distances pour alterner le tracé d'une ligne et d'un espace (en unités d'espace de coordonnées).
