## CSSEngineMode enumeration

Spécifie le mode CSSEngine. Les valeurs ont la signification suivante :

par défaut - le parseur CSS fonctionnera selon la recommandation w3c et ne prend pas en charge les extensions personnalisées. non strict - Toutes les propriétés non documentées seront analysées et pourront être accessibles via.

```java
[Flags]
public enum CSSEngineMode
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Default | `0` | Le parseur CSS fonctionnera selon la recommandation w3c et ne prend pas en charge les extensions personnalisées. |
| NotStrict | `1` | Le parseur CSS fonctionnera en mode non strict. Toutes les propriétés non documentées seront analysées et pourront être accessibles via. |
