## Rect.Bottom property

Cet attribut est utilisé pour le bas du rectangle.

```java
public CSSPrimitiveValue Bottom { get; }
```

### Property Value

La valeur sur l'axe y du bas du rectangle. Si le rectangle est vide, la valeur est NegativeInfinity.
