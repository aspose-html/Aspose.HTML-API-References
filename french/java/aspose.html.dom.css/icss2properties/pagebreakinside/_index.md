## ICSS2Properties.PageBreakInside property

Les valeurs de ces propriétés ont les significations suivantes :

auto - Ne force ni n'interdit un saut de page avant (après, à l'intérieur) la boîte générée. always - Force toujours un saut de page avant (après) la boîte générée. avoid - Évite un saut de page avant (après, à l'intérieur) la boîte générée. left - Force un ou deux sauts de page avant (après) la boîte générée afin que la page suivante soit formatée comme une page de gauche. right - Force un ou deux sauts de page avant (après) la boîte générée afin que la page suivante soit formatée comme une page de droite.

public String PageBreakInside { get; set; }
