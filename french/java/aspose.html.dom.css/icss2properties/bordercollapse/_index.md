## ICSS2Properties.BorderCollapse property

Cette propriété sélectionne le modèle de bordure d'un tableau. La valeur 'separate' sélectionne le modèle de bordures séparées. La valeur 'collapse' sélectionne le modèle de bordures collapsées. Les modèles sont décrits ci-dessous.

```java
public String BorderCollapse { get; set; }
```

### Valeur de retour

propriété border-collapse
