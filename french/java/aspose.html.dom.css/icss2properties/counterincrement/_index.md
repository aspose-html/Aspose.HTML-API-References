## ICSS2Properties.CounterIncrement property

La propriété ['counter-increment'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-counter-increment) accepte un ou plusieurs noms de compteurs (identifiants), chacun éventuellement suivi d'un entier. L'entier indique de combien le compteur est incrémenté à chaque occurrence de l'élément. L'incrément par défaut est 1. Les entiers zéro et négatifs sont autorisés.

```java
public String CounterIncrement { get; set; }
```

### Valeur de retour

propriété counter-increment
