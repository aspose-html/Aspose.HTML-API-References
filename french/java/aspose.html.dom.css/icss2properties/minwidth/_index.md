## ICSS2Properties.MinWidth property

Ces deux propriétés permettent aux auteurs de contraindre la largeur des boîtes à une certaine plage. Les valeurs ont les significations suivantes :

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - Spécifie une largeur calculée fixe minimale ou maximale.'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - Spécifie un pourcentage pour déterminer la valeur calculée. Le pourcentage est calculé par rapport à la largeur du [bloc contenant](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#containing-block).none - (Uniquement sur ['max-width'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-max-width)) Pas de limite à la largeur de la boîte.

```java
public String MinWidth { get; set; }
```

### Valeur de retour

propriété min-width
