## ICSS2Properties.FontStretch property

La propriété ['font-stretch'](https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html#propdef-font-stretch) sélectionne une graisse normale, condensée ou étendue d’une famille de polices. Les valeurs de mots‑clés absolues sont ordonnées comme suit, de la plus étroite à la plus large :

ultra-condensedextra-condensedcondensedsemi-condensednormalsemi-expandedexpandedextra-expandedultra-expanded

```java
public String FontStretch { get; set; }
```

### Valeur de retour

propriété font-stretch
