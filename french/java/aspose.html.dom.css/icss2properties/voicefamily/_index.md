## ICSS2Properties.VoiceFamily property

La valeur est une liste prioritaire, séparée par des virgules, de noms de familles vocales (comparez avec ['font-family'](https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html#propdef-font-family)). Les valeurs ont les significations suivantes :

'generic-voice' - Les valeurs sont des familles vocales. Les valeurs possibles sont 'male', 'female' et 'child'.'specific-voice' - Les valeurs sont des instances spécifiques (par ex., comedian, trinoids, carlos, lani).

```java
public String VoiceFamily { get; set; }
```

### Valeur de retour

propriété voice-family
