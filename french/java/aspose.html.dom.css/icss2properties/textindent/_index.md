## ICSS2Properties.TextIndent property

Cette propriété spécifie l'indentation de la première ligne de texte dans un bloc. Plus précisément, elle spécifie l'indentation de la première boîte qui s'écoule dans la première [line box](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#line-box) du bloc. La boîte est indentée par rapport au bord gauche (ou droit, pour les mises en page de droite à gauche) de la boîte de ligne. Les agents utilisateurs doivent rendre cette indentation comme un espace vide.

Les valeurs ont les significations suivantes :

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - L'indentation est une longueur fixe.'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - L'indentation est un pourcentage de la largeur du bloc conteneur.

```java
public String TextIndent { get; set; }
```

### Valeur de retour

propriété text-indent
