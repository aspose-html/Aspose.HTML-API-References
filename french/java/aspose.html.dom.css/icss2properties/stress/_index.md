## ICSS2Properties.Stress property

Spécifie la hauteur des « pics locaux » dans le contour d’intonation d’une voix. Par exemple, l’anglais est une langue accentuée, et différentes parties d’une phrase sont assignées à un accent primaire, secondaire ou tertiaire. La valeur de ['stress'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-stress) contrôle la quantité d’inflexion résultant de ces marqueurs d’accent. Cette propriété est complémentaire à la propriété ['pitch-range'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pitch-range) et est fournie pour permettre aux développeurs d’exploiter des affichages auditifs haut de gamme.

```java
public String Stress { get; set; }
```

### Valeur de retour

propriété stress
