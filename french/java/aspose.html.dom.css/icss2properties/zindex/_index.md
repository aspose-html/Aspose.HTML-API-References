## ICSS2Properties.ZIndex property

Pour une boîte positionnée, la propriété ['z-index'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-z-index) spécifie :

Le niveau d'empilement de la boîte dans le contexte d'empilement actuel. Si la boîte établit un contexte d'empilement local.

```java
public String ZIndex { get; set; }
```

### Valeur de retour

propriété z-index
