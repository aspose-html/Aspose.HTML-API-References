## ICSS2Properties.TextDecoration property

Cette propriété décrit les décorations ajoutées au texte d'un élément. Si la propriété est spécifiée pour un élément [block-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#block-level), elle affecte tous les descendants en ligne de l'élément. Si elle est spécifiée pour (ou affecte) un élément [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level), elle affecte toutes les boîtes générées par l'élément. Si l'élément n'a aucun contenu ou aucun texte (par ex., l'élément IMG en HTML), les agents utilisateurs doivent [ignorer](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#ignore) cette propriété.

Les valeurs ont les significations suivantes :

none - Ne produit aucune décoration de texte.underline - Chaque ligne de texte est soulignée.overline - Chaque ligne de texte possède une ligne au-dessus.line-through - Chaque ligne de texte possède une ligne traversant le milieublink - Le texte clignote (alterne entre visible et invisible).

public String TextDecoration { get; set; }
