## ICSS2Properties.FontVariant property

Dans une police small-caps, les glyphes des lettres minuscules ressemblent aux majuscules, mais en plus petite taille et avec des proportions légèrement différentes. La propriété 'font-variant' demande une telle police pour les scripts bicaméraux (ayant deux cas, comme l'écriture latine). Cette propriété n'a aucun effet visible pour les scripts unicameraux (ayant un seul cas, comme la plupart des systèmes d'écriture du monde).

```java
public String FontVariant { get; set; }
```

### Valeur de retour

propriété font-variant
