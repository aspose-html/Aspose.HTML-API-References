## ICSS2Properties.BackgroundImage property

Cette propriété définit l'image d'arrière-plan d'un élément. Lors de la définition d'une image d'arrière-plan, les auteurs doivent également spécifier une couleur d'arrière-plan qui sera utilisée lorsque l'image n'est pas disponible. Lorsque l'image est disponible, elle est rendue au-dessus de la couleur d'arrière-plan. (Ainsi, la couleur est visible dans les parties transparentes de l'image).

```java
public String BackgroundImage { get; set; }
```

### Valeur de retour

propriété background-image

### Property Value

Les valeurs pour cette propriété sont soit , pour spécifier l'image, soit 'none', lorsqu'aucune image n'est utilisée.
