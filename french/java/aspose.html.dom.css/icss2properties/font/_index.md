## ICSS2Properties.Font property

La propriété 'font' est, sauf indication contraire ci‑dessous, une propriété raccourcie permettant de définir 'font-style', 'font-variant', 'font-weight', 'font-size', 'line-height' et 'font-family' au même endroit dans la feuille de style. La syntaxe de cette propriété repose sur une notation typographique traditionnelle raccourcie pour définir plusieurs propriétés liées aux polices.

```java
public String Font { get; set; }
```

propriété font
