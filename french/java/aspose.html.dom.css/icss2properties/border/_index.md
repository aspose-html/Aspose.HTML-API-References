## ICSS2Properties.Border property

La propriété 'border' est une propriété raccourcie permettant de définir la même largeur, couleur et style pour les quatre bordures d’une boîte. Contrairement aux propriétés raccourcies 'margin' et 'padding', la propriété 'border' ne peut pas définir des valeurs différentes sur les quatre bordures. Pour ce faire, une ou plusieurs des autres propriétés de bordure doivent être utilisées.

```java
public String Border { get; set; }
```

### Valeur de retour

propriété border
