## ICSS2Properties.Orphans property

La propriété ['orphans'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-orphans) spécifie le nombre minimum de lignes d'un paragraphe qui doivent rester en bas d'une page. La propriété ['widows'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-widows) spécifie le nombre minimum de lignes d'un paragraphe qui doivent rester en haut d'une page. Des exemples de leur utilisation pour contrôler les sauts de page sont présentés ci-dessous.

```java
public String Orphans { get; set; }
```

### Valeur de retour

propriété orphans
