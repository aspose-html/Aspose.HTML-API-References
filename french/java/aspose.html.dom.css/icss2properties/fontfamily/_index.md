## ICSS2Properties.FontFamily property

Cette propriété spécifie une liste prioritaire de noms de familles de polices et/ou de noms de familles génériques. Pour résoudre le problème qu’une police unique peut ne pas contenir les glyphes nécessaires pour afficher tous les caractères d’un document, ou que toutes les polices ne sont pas disponibles sur tous les systèmes, cette propriété permet aux auteurs de spécifier une liste de polices, toutes de même style et taille, qui sont essayées séquentiellement pour voir si elles contiennent un glyphe pour un caractère donné. Cette liste est appelée un ensemble de polices.

```java
public String FontFamily { get; set; }
```

### Valeur de retour

propriété font-family
