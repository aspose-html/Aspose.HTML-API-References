## ICSS2Properties.SpeakHeader property

Cette propriété spécifie si les en-têtes de tableau sont prononcés avant chaque cellule, ou uniquement avant une cellule lorsque cette cellule est associée à un en-tête différent de celui de la cellule précédente. Les valeurs ont les significations suivantes :

once - L'en-tête est prononcé une fois, avant une série de cellules. always - L'en-tête est prononcé avant chaque cellule pertinente.

```java
public String SpeakHeader { get; set; }
```

### Valeur de retour

propriété speak-header
