## ICSS2Properties.MarkerOffset property

Cette propriété spécifie la distance entre les [bords](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#border-edge) les plus proches d’une boîte de repère et sa [boîte principale](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#principal-box) associée. Le décalage peut être une ([longueur](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)) spécifiée par l’utilisateur ou choisi par l’UA (« auto »). Les longueurs peuvent être négatives, mais il peut exister des limites propres à l’implémentation.

```java
public String MarkerOffset { get; set; }
```

### Valeur de retour

propriété marker-offset
