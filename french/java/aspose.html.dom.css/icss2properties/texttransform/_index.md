## ICSS2Properties.TextTransform property

Cette propriété contrôle les effets de capitalisation du texte d'un élément. Les valeurs ont les significations suivantes :

capitalize - Met la première lettre de chaque mot en majuscule. uppercase - Met tous les caractères de chaque mot en majuscule. lowercase - Met tous les caractères de chaque mot en minuscule. none - Aucun effet de capitalisation.

```java
public String TextTransform { get; set; }
```

### Valeur de retour

propriété text-transform
