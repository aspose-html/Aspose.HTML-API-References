## ICSS2Properties.SpeechRate property

Cette propriété spécifie le débit de parole. Notez que les valeurs de mots‑clés absolues et relatives sont autorisées (comparez avec ['font-size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html#propdef-font-size)). Les valeurs ont les significations suivantes :

'[number](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-number)' - Spécifie le débit de parole en mots par minute, une quantité qui varie légèrement selon la langue mais qui est néanmoins largement prise en charge par les synthétiseurs vocaux.

x-slow - Identique à 80 mots par minute.

slow - Identique à 120 mots par minute.

moyen - Identique à 180 - 200 mots par minute.

rapide - Identique à 300 mots par minute.

x-rapide - Identique à 500 mots par minute.

plus rapide - Ajoute 40 mots par minute au taux de parole actuel.

plus lent - Soustrait 40 mots par minute du taux de parole actuel.

```java
public String SpeechRate { get; set; }
```

### Valeur de retour

propriété speech-rate
