## ICSS2Properties.Outline property

Le contour créé avec les propriétés de contour est dessiné "over" (au-dessus) d’une boîte, i.e., le contour est toujours au premier plan, et n’influence pas la position ou la taille de la boîte, ou de toute autre boîte. Ainsi, l’affichage ou la suppression des contours ne provoque pas de reflow.

```java
public String Outline { get; set; }
```

### Valeur de retour

propriété outline
