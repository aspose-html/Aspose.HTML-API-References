## ICSS2Properties.WordSpacing property

Cette propriété spécifie le comportement d'espacement entre les mots. Les valeurs ont les significations suivantes :

normal - L'espace inter-mots normal, tel que défini par la police actuelle et/ou l'UA. '[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - Cette valeur indique un espace inter-mots supplémentaire par rapport à l'espace par défaut entre les mots. Les valeurs peuvent être négatives, mais il peut exister des limites spécifiques à l'implémentation.

```java
public String WordSpacing { get; set; }
```

### Valeur de retour

propriété word-spacing
