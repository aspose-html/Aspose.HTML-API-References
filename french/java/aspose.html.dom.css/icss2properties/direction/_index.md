## ICSS2Properties.Direction property

Cette propriété spécifie la direction d’écriture de base des blocs ainsi que la direction des incorporations et des surcharges (voir ['unicode-bidi'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-unicode-bidi)) pour l’algorithme bidirectionnel Unicode. De plus, elle spécifie la direction de la disposition des colonnes de [table](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html), la direction du [overflow](https://www.w3.org/TR/1998/REC-CSS2-19980512/visufx.html#overflow) horizontal, et la position d’une dernière ligne incomplète dans un bloc en cas de 'text-align: justify'.

```java
public String Direction { get; set; }
```

### Valeur de retour

propriété direction
