## ICSS2Properties.Elevation property

Les valeurs de cette propriété ont les significations suivantes :

'angle' - Spécifie l'élévation sous forme d'angle, entre '-90deg' et '90deg'. '0deg' signifie à l'horizon avant, ce qui signifie approximativement au niveau de l'auditeur. '90deg' signifie directement au-dessus et '-90deg' signifie directement en dessous. below - Identique à '-90deg'. level - Identique à '0deg'. above - Identique à '90deg'. higher - Ajoute 10 degrés à l'élévation actuelle. lower - Soustrait 10 degrés à l'élévation actuelle.

```java
public String Elevation { get; set; }
```

propriété elevation
