## ICSS2Properties.BackgroundAttachment property

Si une image d'arrière-plan est spécifiée, cette propriété indique si elle est fixe par rapport à la fenêtre d'affichage (« fixed ») ou défile avec le document (« scroll »).

Même si l'image est fixe, elle n'est visible que lorsqu'elle se trouve dans l'arrière-plan ou la zone de remplissage de l'élément. Ainsi, à moins que l'image ne soit en mosaïque ('background-repeat: repeat'), elle peut être invisible.

```java
public String BackgroundAttachment { get; set; }
```

### Valeur de retour

propriété background-attachment
