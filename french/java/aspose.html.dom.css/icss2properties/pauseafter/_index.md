## ICSS2Properties.PauseAfter property

Ces propriétés spécifient une pause à observer avant (ou après) la lecture du contenu d'un élément. Les valeurs ont les significations suivantes :

'[time](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-time)' - Exprime la pause en unités de temps absolues (secondes et millisecondes). '[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - Se réfère à l'inverse de la valeur de la propriété ['speech-rate'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-speech-rate). Par exemple, si le speech-rate est de 120 mots par minute (c’est‑à‑dire qu’un mot dure une demi‑seconde, ou 500 ms), alors un ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) de 100 % signifie une pause de 500 ms et un ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) de 20 % signifie 100 ms.

```java
public String PauseAfter { get; set; }
```

### Valeur de retour

propriété pause-after
