## ICSS2Properties.Size property

Cette propriété spécifie la taille et l'orientation d'une boîte de page.

La taille d'une boîte de page peut être soit \"absolute\" (taille fixe) ou \"relative\" (extensible, c’est‑à‑dire adaptée aux tailles de feuilles disponibles). Les boîtes de page relatives permettent aux agents utilisateurs d'échelle un document et d'utiliser de façon optimale la taille cible.

Trois valeurs pour la propriété ['size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-size) créent une boîte de page relative :

auto - La boîte de page sera définie à la taille et à l'orientation de la feuille cible. landscape - Remplace l'orientation de la cible. La boîte de page a la même taille que la cible, et les côtés les plus longs sont horizontaux. portrait - Remplace l'orientation de la cible. La boîte de page a la même taille que la cible, et les côtés les plus courts sont horizontaux.

public String Size { get; set; }
