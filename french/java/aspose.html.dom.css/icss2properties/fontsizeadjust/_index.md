## ICSS2Properties.FontSizeAdjust property

Dans les scripts bicaméraux, la taille apparente subjective et la lisibilité d’une police dépendent moins de la valeur de son 'font-size' que de la valeur de son 'x-height', ou, plus utilement, du rapport de ces deux valeurs, appelé valeur d’aspect (taille de police divisée par x-height). Plus la valeur d’aspect est élevée, plus il est probable qu’une police à des tailles plus petites reste lisible. Inversement, les polices avec une valeur d’aspect plus faible deviendront illisibles plus rapidement en dessous d’une taille seuil donnée que les polices avec une valeur d’aspect plus élevée. Un remplacement de police simple qui ne repose que sur la taille de police peut entraîner des caractères illisibles.

public String FontSizeAdjust { get; set; }
