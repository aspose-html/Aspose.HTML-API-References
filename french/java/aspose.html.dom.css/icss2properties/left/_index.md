## ICSS2Properties.Left property

Cette propriété spécifie la distance à laquelle le bord gauche du contenu d’une boîte est décalé vers la droite du bord gauche du [bloc contenant](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#containing-block) de la boîte.

```java
public String Left { get; set; }
```
