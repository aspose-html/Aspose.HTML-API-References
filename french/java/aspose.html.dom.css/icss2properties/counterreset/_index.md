## ICSS2Properties.CounterReset property

La propriété ['counter-reset'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-counter-reset) contient également une liste d’un ou plusieurs noms de compteurs, chacun pouvant être suivi optionnellement d’un entier. L’entier indique la valeur à laquelle le compteur est réglé à chaque occurrence de l’élément. La valeur par défaut est 0.

```java
public String CounterReset { get; set; }
```

### Valeur de retour

propriété counter-reset
