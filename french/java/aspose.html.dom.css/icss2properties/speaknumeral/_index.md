## ICSS2Properties.SpeakNumeral property

Cette propriété contrôle la façon dont les chiffres sont prononcés. Les valeurs ont les significations suivantes:

digits - Prononcer le chiffre sous forme de chiffres individuels. Ainsi, "237" se lit "Deux Trois Sept". continuous - Prononcer le chiffre comme un nombre complet. Ainsi, "237" se lit "Deux cent trente‑sept". Les représentations en mots dépendent de la langue.

```java
public String SpeakNumeral { get; set; }
```

### Valeur de retour

propriété speak-numeral
