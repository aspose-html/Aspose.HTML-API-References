## ICSS2Properties.Marks property

Dans l'impression de haute qualité, des marques sont souvent ajoutées à l'extérieur de la boîte de page. Cette propriété spécifie si des marques de croix, des marques de coupe ou les deux doivent être rendues juste à l'extérieur du bord de la [boîte de page](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#page-box).

Les marques de coupe indiquent où la page doit être découpée. Les marques de croix (également appelées marques d'enregistrement ou marques de repérage) sont utilisées pour aligner les feuilles.

Les marques ne sont visibles que sur les boîtes de page absolues (voir la propriété ['size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-size)). Dans les boîtes de page relatives, la boîte de page sera alignée avec la cible et les marques seront à l'extérieur de la zone imprimable.

La taille, le style et la position des marques de croix dépendent de l'agent utilisateur.

public String Marks { get; set; }
