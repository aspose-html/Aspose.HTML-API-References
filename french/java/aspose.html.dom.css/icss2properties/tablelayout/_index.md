## ICSS2Properties.TableLayout property

La propriété ['table-layout'](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#propdef-table-layout) contrôle l'algorithme utilisé pour disposer les cellules, les lignes et les colonnes du tableau. Les valeurs ont la signification suivante :

fixed - Utiliser l'algorithme de mise en page de tableau fixe auto - Utiliser tout algorithme de mise en page de tableau automatique

```java
public String TableLayout { get; set; }
```

### Valeur de retour

propriété table-layout
