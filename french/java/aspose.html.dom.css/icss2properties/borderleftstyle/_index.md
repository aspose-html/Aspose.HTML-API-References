## ICSS2Properties.BorderLeftStyle property

La propriété 'border-style' définit le style des quatre bordures. Elle peut avoir d'une à quatre valeurs, et les valeurs sont appliquées aux différents côtés comme pour 'border-width' ci‑dessus.

```java
public String BorderLeftStyle { get; set; }
```

### Valeur de retour

propriété border-left-style
