## ICSS2Properties.PitchRange property

Spécifie la variation de la hauteur moyenne. La hauteur perçue d’une voix humaine est déterminée par la fréquence fondamentale et a généralement une valeur de 120 Hz pour une voix masculine et de 210 Hz pour une voix féminine. Les langues humaines sont parlées avec des inflexions et des hauteurs variables ; ces variations transmettent un sens supplémentaire et de l’emphase. Ainsi, une voix très animée, c’est‑à‑dire fortement inflectée, présente une large plage de hauteur. Cette propriété spécifie la plage sur laquelle ces variations se produisent, c’est‑à‑dire combien la fréquence fondamentale peut s’écarter de la hauteur moyenne.

```java
public String PitchRange { get; set; }
```
