## ICSS2Properties.BorderSpacing property

Les longueurs spécifient la distance qui sépare les bordures de cellules adjacentes. Si une longueur est spécifiée, elle fournit à la fois l'espacement horizontal et vertical. Si deux longueurs sont spécifiées, la première donne l'espacement horizontal et la seconde l'espacement vertical. Les longueurs ne peuvent pas être négatives.

```java
public String BorderSpacing { get; set; }
```

### Valeur de retour

propriété border-spacing
