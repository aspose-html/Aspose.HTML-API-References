## ICSS2Properties.Pause property

La propriété ['pause'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause) est un raccourci pour définir les propriétés ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) et ['pause-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-after). Si deux valeurs sont fournies, la première valeur correspond à ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) et la seconde à ['pause-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-after). Si une seule valeur est fournie, elle s’applique aux deux propriétés.

```java
public String Pause { get; set; }
```

### Valeur de retour

propriété pause
