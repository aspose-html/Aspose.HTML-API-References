## ICSS2Properties.Richness property

Spécifie la richesse ou la clarté de la voix parlée. Une voix riche « portera » dans une grande salle, une voix douce ne le fera pas. (Le terme « doux » fait référence à l’apparence de la forme d’onde lorsqu’elle est dessinée.)

```java
public String Richness { get; set; }
```

### Valeur de retour

propriété richness
