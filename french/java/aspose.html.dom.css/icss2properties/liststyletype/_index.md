## ICSS2Properties.ListStyleType property

Cette propriété spécifie l'apparence du marqueur d'élément de liste si ['list-style-image'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-list-style-image) a la valeur 'none' ou si l'image pointée par l'URI ne peut pas être affichée. La valeur 'none' indique aucun marqueur, sinon il existe trois types de marqueurs : glyphes, systèmes de numérotation et systèmes alphabétiques. Note. Les listes numérotées améliorent l'accessibilité du document en facilitant la navigation dans les listes.

Les glyphes sont spécifiés avec disc, circle et square. Leur rendu exact dépend de l'agent utilisateur.

Les systèmes de numérotation sont spécifiés avec :

decimal - Nombres décimaux, commençant à 1. decimal-leading-zero - Nombres décimaux remplis de zéros initiaux (p. ex., 01, 02, 03, ..., 98, 99). lower-roman - Nombres romains minuscules (i, ii, iii, iv, v, etc.). upper-roman - Nombres romains majuscules (I, II, III, IV, V, etc.). hebrew - Numérotation hébraïque traditionnelle. georgian - Numérotation géorgienne traditionnelle (an, ban, gan, ..., he, tan, in, in-an, ...). armenian - Numérotation arménienne traditionnelle. cjk-ideographic - Nombres idéographiques simples. hiragana - a, i, u, e, o, ka, ki, ... katakana - A, I, U, E, O, KA, KI, ... hiragana-iroha - i, ro, ha, ni, ho, he, to, ... katakana-iroha - I, RO, HA, NI, HO, HE, TO, ...

```java
public String ListStyleType { get; set; }
```

### Valeur de retour

propriété list-style-type
