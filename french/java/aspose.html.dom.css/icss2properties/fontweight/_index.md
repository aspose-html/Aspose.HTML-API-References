## ICSS2Properties.FontWeight property

La propriété 'font-weight' spécifie le poids de la police. Les valeurs ont les significations suivantes :

100 à 900 - Ces valeurs forment une séquence ordonnée, chaque nombre indiquant un poids au moins aussi foncé que le précédent. normal - Identique à '400'. bold - Identique à '700'. bolder - Spécifie le poids suivant attribué à une police plus foncée que celle héritée. S'il n'existe pas de tel poids, cela se traduit simplement par la prochaine valeur numérique plus foncée (et la police reste inchangée), sauf si la valeur héritée était '900', auquel cas le poids résultant reste '900'. lighter - Spécifie le poids suivant attribué à une police plus claire que celle héritée. S'il n'existe pas de tel poids, cela se traduit simplement par la prochaine valeur numérique plus claire (et la police reste inchangée), sauf si la valeur héritée était '100', auquel cas le poids résultant reste '100'.

public String FontWeight { get; set; }
