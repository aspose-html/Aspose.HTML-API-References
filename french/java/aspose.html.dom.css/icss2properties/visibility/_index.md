## ICSS2Properties.Visibility property

La propriété ['visibility'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visufx.html#propdef-visibility) spécifie si les boîtes générées par un élément sont rendues. Les boîtes invisibles affectent toujours la mise en page (définissez la propriété ['display'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-display) à 'none' pour supprimer complètement la génération de boîtes). Les valeurs ont les significations suivantes :

visible - La boîte générée est visible. hidden - La boîte générée est invisible (entièrement transparente), mais affecte toujours la mise en page. collapse - Veuillez consulter la section sur [dynamic row and column effects](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#dynamic-effects) dans les tableaux. Si utilisée sur des éléments autres que des lignes ou des colonnes, 'collapse' a la même signification que 'hidden'.

```java
public String Visibility { get; set; }
```

propriété visibility
