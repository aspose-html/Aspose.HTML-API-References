## ICSS2Properties.Position property

Les valeurs de cette propriété ont les significations suivantes :

static - La boîte est une boîte normale, disposée selon le [flux normal](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#normal-flow). Les propriétés ['left'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-left) et ['top'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-top) ne s'appliquent pas.
