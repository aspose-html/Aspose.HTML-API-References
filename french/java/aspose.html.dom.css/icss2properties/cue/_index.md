## ICSS2Properties.Cue property

La propriété ['cue'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue) est un raccourci pour définir ['cue-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-before) et ['cue-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-after). Si deux valeurs sont fournies, la première valeur est ['cue-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-before) et la seconde est ['cue-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-after). Si une seule valeur est fournie, elle s'applique aux deux propriétés.

```java
public String Cue { get; set; }
```

### Valeur de retour

propriété cue
