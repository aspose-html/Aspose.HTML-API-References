## ICSS2Properties.CaptionSide property

Cette propriété spécifie la position de la boîte de légende par rapport à la boîte du tableau. Les valeurs ont les significations suivantes :

top - Positionne la boîte de légende au-dessus de la boîte du tableau. bottom - Positionne la boîte de légende en dessous de la boîte du tableau. left - Positionne la boîte de légende à gauche de la boîte du tableau. right - Positionne la boîte de légende à droite de la boîte du tableau.

```java
public String CaptionSide { get; set; }
```
