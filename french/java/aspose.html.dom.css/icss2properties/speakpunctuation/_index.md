## ICSS2Properties.SpeakPunctuation property

Cette propriété spécifie comment la ponctuation est prononcée. Les valeurs ont les significations suivantes :

code - La ponctuation telle que les points-virgules, les accolades, etc. doit être prononcée littéralement. none - La ponctuation ne doit pas être prononcée, mais rendue naturellement sous forme de diverses pauses.

```java
public String SpeakPunctuation { get; set; }
```

### Valeur de retour

propriété speak-punctuation
