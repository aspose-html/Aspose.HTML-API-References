## ICSS2Properties.TextAlign property

Cette propriété décrit comment le contenu en ligne d'un bloc est aligné. Les valeurs ont les significations suivantes :

left, right, center, and justify - Gauche, droite, centre et justification double du texte, respectivement.'[String](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-String)' - Spécifie une chaîne sur laquelle les cellules d'une colonne de tableau seront alignées (voir la section sur [horizontal alignment in a column](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#column-alignment) pour les détails et un exemple). Cette valeur s'applique uniquement aux cellules de [table](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html). Si elle est définie sur d'autres éléments, elle sera traitée comme 'left' ou 'right', selon que le ['direction'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-direction) soit 'ltr' ou 'rtl', respectivement.

public String TextAlign { get; set; }
