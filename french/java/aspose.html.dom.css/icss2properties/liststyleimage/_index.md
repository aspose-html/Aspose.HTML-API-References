## ICSS2Properties.ListStyleImage property

Cette propriété définit l'image qui sera utilisée comme repère d'élément de liste. Lorsque l'image est disponible, elle remplacera le repère défini par le marqueur ['list-style-type'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-list-style-type).

```java
public String ListStyleImage { get; set; }
```

### Valeur de retour

propriété list-style-image
