## ICSS2Properties.LineHeight property

Si la propriété est définie sur un élément [block-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#block-level) dont le contenu est composé d'éléments [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level), elle spécifie la hauteur minimale de chaque boîte en ligne générée.

Si la propriété est définie sur un élément [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level), elle spécifie la hauteur exacte de chaque boîte générée par l'élément. (Sauf pour les éléments inline [replaced](https://www.w3.org/TR/1998/REC-CSS2-19980512/conform.html#replaced-element), où la hauteur de la boîte est donnée par la propriété ['height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-height).)

```java
public String LineHeight { get; set; }
```

### Valeur de retour

propriété line-height
