## ICSS2Properties.ListStyle property

La propriété ['list-style'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-list-style) est une notation abrégée permettant de définir les trois propriétés ['list-style-type'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-list-style-type), ['list-style-image'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-list-style-image) et ['list-style-position'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-list-style-position) au même endroit dans la feuille de style.

```java
public String ListStyle { get; set; }
```

### Valeur de retour

propriété list-style
