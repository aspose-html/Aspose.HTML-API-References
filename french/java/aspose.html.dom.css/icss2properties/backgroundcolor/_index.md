## ICSS2Properties.BackgroundColor property

Cette propriété définit la couleur d'arrière-plan d'un élément, soit une valeur, soit le mot‑clé « transparent », afin de laisser transparaître les couleurs sous‑jacentes.

```java
public String BackgroundColor { get; set; }
```

### Valeur de retour

propriété background-color

### Property Value

Une couleur est soit un mot‑clé, soit une spécification numérique RGB.
