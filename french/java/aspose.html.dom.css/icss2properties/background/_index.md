## ICSS2Properties.Background property

La propriété 'background' est une propriété raccourcie permettant de définir les propriétés d'arrière-plan individuelles (c.-à-d. 'background-color', 'background-image', 'background-repeat', 'background-attachment' et 'background-position') au même endroit dans la feuille de style.

```java
public String Background { get; set; }
```

### Valeur de retour

la propriété background

### Property Value

Obtient ou définit une propriété raccourcie permettant de définir les propriétés d'arrière-plan individuelles au même endroit dans la feuille de style.
