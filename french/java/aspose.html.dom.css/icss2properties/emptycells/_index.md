## ICSS2Properties.EmptyCells property

Dans le modèle de bordures séparées, cette propriété contrôle le rendu des bordures autour des cellules qui n'ont aucun contenu visible. Les cellules vides et les cellules dont la propriété 'visibility' est définie sur 'hidden' sont considérées comme n'ayant aucun contenu visible.

```java
public String EmptyCells { get; set; }
```

### Valeur de retour

propriété empty-cells
