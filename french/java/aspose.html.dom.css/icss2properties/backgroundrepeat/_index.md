## ICSS2Properties.BackgroundRepeat property

Si une image d’arrière-plan est spécifiée, cette propriété indique si l’image est répétée (carrelée) et comment. Toutes les répétitions couvrent les zones de contenu et de remplissage d’une boîte. Les valeurs ont les significations suivantes :

repeat - L’image est répétée à la fois horizontalement et verticalement. repeat-x - L’image est répétée uniquement horizontalement. repeat-y - L’image est répétée uniquement verticalement. no-repeat - L’image n’est pas répétée : une seule copie de l’image est dessinée.

```java
public String BackgroundRepeat { get; set; }
```

### Valeur de retour

propriété background-repeat

### Property Value

La valeur de répétition d’arrière-plan de la liste telle qu’elle est définie ci‑dessus.
