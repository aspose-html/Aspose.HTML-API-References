## ICSS2Properties.BorderColor property

La propriété 'border-color' définit la couleur des quatre bordures. Les valeurs ont les significations suivantes:

color - Spécifie une valeur de couleur. transparent - La bordure est transparente (bien qu'elle puisse avoir une largeur).

```java
public String BorderColor { get; set; }
```

### Valeur de retour

propriété border-color
