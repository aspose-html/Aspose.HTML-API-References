## ICSS2Properties.ListStylePosition property

Cette propriété spécifie la position de la boîte de repère dans la boîte de bloc principale. Les valeurs ont les significations suivantes :

outside - La boîte de repère est à l'extérieur de la boîte de bloc principale. Note. CSS1 n'a pas spécifié l'emplacement précis de la boîte de repère et, pour des raisons de compatibilité, CSS2 reste tout aussi ambigu. Pour un contrôle plus précis des boîtes de repère, veuillez utiliser markers.inside - La boîte de repère est la première boîte en ligne dans la boîte de bloc principale, après laquelle le contenu de l'élément s'écoule.

```java
public String ListStylePosition { get; set; }
```

### Valeur de retour

propriété list-style-position
