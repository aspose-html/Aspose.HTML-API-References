## ICSSImportRule.Href property

La propriété en lecture seule href de l'interface CSSImportRule renvoie l'URL spécifiée par la règle @import.

L'URL résolue sera l'attribut href de la feuille de style associée.

```java
public String Href { get; }
```

### Property Value

Renvoie l'URL de la feuille de style associée spécifiée par la règle @import.
