## ICSSImportRule.StyleSheet property

La feuille de style référencée par cette règle, si elle a été chargée. La valeur de cet attribut est null si la feuille de style n'a pas encore été chargée ou si elle ne sera pas chargée (par ex. si la feuille de style est destinée à un type de média non pris en charge par l'agent utilisateur).

```java
public ICSSStyleSheet StyleSheet { get; }
```

### Property Value

Renvoie la feuille de style CSS spécifiée par la règle @import. Elle sera sous la forme d'un objet [`CSSStyleSheet`](../../icssstylesheet/).
