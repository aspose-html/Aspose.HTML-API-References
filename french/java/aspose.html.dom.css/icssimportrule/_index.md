## ICSSImportRule interface

L'interface CSSImportRule représente une règle @import au sein d'une feuille de style CSS. La règle @import est utilisée pour importer des règles de style provenant d'autres feuilles de style.

```java
public interface ICSSImportRule : ICSSRule
```

## Propriétés

| Nom | Description |
| --- | --- |
| [getHref](../../com.aspose.html.dom.css/icssimportrule/href/) La propriété en lecture seule href de l'interface CSSImportRule renvoie l'URL spécifiée par la règle @import. |
| [getMedia](../../com.aspose.html.dom.css/icssimportrule/media/) La propriété en lecture seule media de l'interface CSSImportRule renvoie un objet MediaList contenant la valeur de l'attribut media de la feuille de style associée. |
| [getStyleSheet](../../com.aspose.html.dom.css/icssimportrule/stylesheet/) La feuille de style référencée par cette règle, si elle a été chargée. La valeur de cet attribut est null si la feuille de style n'a pas encore été chargée ou ne le sera pas (par ex. si la feuille de style est destinée à un type de média non pris en charge par l'agent utilisateur). |
