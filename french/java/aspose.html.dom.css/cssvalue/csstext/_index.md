## CSSValue.CSSText property

La propriété cssText de l'interface [`CSSValue`](../) représente la valeur actuelle calculée de la propriété CSS.

Remarque : Cette propriété faisait partie d’une tentative de créer un modèle d’objet CSS typé. Cette tentative a été abandonnée, et la plupart des navigateurs ne l’implémentent pas.

```java
public abstract String CSSText { get; set; }
```

### Property Value

Une DOMString représentant la valeur actuelle de la propriété CSS.
