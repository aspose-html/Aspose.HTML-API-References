## CSSValueList class

L'interface CSSValueList fournit l'abstraction d'une collection ordonnée de valeurs CSS.

Remarque : Cette interface faisait partie d'une tentative de créer un modèle d'objet CSS typé. Cette tentative a été abandonnée, et la plupart des navigateurs ne l'implémentent pas.

```java
public class CSSValueList : CSSValue, ICSSValueList, IEnumerable<CSSValue>
```
