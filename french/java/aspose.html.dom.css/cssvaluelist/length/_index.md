## CSSValueList.Length property

La propriété en lecture seule length de l'interface CSSValueList représente le nombre de CSSValues dans la liste. L'intervalle des valeurs valides des indices est de 0 à length‑1 inclus.

```java
public int Length { get; }
```

### Property Value

Un entier long non signé représentant le nombre de CSSValues dans l'instance actuelle.
