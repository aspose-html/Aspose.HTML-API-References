## CSSValueList indexer

La méthode item() de l’interface CSSValueList est utilisée pour récupérer un CSSValue par indice ordinal.

L’ordre dans cette collection représente l’ordre des valeurs de la propriété de style CSS. Si l’indice est supérieur ou égal au nombre de valeurs dans la liste, cette méthode renvoie null.

```java
public CSSValue this[int index] { get; }
```

### Valeur de retour

Un objet CSSValue à la position d’indice dans le CSSValueList, ou null si cet indice n’est pas valide.

### Property Value

Un unsigned long représentant l’indice de la valeur CSS au sein de la collection.
