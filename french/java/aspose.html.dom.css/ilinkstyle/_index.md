## ILinkStyle interface

L'interface LinkStyle fournit un mécanisme permettant de récupérer une feuille de style à partir du nœud responsable de son lien dans un document. Une instance de l'interface LinkStyle peut être obtenue en utilisant des méthodes de cast spécifiques au binding sur une instance d'un nœud de liaison (HTMLLinkElement,

HTMLStyleElement ou ProcessingInstruction dans DOM Level 2).

Voir également le [CSS Object Model (CSSOM) # ](https://www.w3.org/TR/cssom-1/#the-linkstyle-interface)[LinkStyle](https://www.w3.org/TR/cssom-1/#the-linkstyle-interface).
