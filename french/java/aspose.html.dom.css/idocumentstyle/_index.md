## IDocumentStyle interface

L'interface DocumentStyle fournit un mécanisme permettant de récupérer les feuilles de style intégrées dans un document. On s'attend à ce qu'une instance de l'interface DocumentStyle puisse être obtenue en utilisant des méthodes de cast spécifiques au binding sur une instance de l'interface Document.

Voir également la [Document Object Model (DOM) Level 2 Style Specification](http://www.w3.org/TR/2000/REC-DOM-Level-2-Style-20001113).

public interface IDocumentStyle
