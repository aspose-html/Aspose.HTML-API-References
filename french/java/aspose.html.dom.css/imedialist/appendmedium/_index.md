## IMediaList.AppendMedium method

Ajoute le média newMedium à la fin de la liste. Si le newMedium est déjà utilisé, il est d'abord supprimé.

```java
public void AppendMedium(String newMedium)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| newMedium | String | Le nouveau média à ajouter. |

| exception | condition |
