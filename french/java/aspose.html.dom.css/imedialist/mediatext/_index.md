## IMediaList.MediaText property

Un Stringifier qui renvoie un DOMString représentant le MediaList sous forme de texte, et permet également de définir un nouveau MediaList.

```java
public String MediaText { get; }
```

### Property Value

La représentation textuelle analysable de la liste des médias. Il s'agit d'une liste de médias séparés par des virgules.

### Exceptions

| exception | condition |
| --- | --- |
| DOMException | SYNTAX_ERR : Levé si la valeur String spécifiée possède une erreur de syntaxe et n'est pas analysable. NO_MODIFICATION_ALLOWED_ERR : Levé si cette liste de médias est en lecture seule. |
