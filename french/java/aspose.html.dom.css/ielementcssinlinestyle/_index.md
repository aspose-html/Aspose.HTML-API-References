## IElementCSSInlineStyle interface

Les informations de style en ligne attachées aux éléments sont exposées via l'attribut style. Cela représente le contenu de l'attribut STYLE pour les éléments HTML (ou les éléments d'autres schémas ou DTD qui utilisent l'attribut STYLE de la même manière). On s'attend à ce qu'une instance de l'interface ElementCSSInlineStyle puisse être obtenue en utilisant des méthodes de cast spécifiques au binding sur une instance de l'interface Element lorsque l'élément prend en charge les informations de style CSS en ligne.

Voir également le [CSS Object Model (CSSOM) # IElementCSSInlineStyle](https://www.w3.org/TR/cssom-1/#the-elementcssinlinestyle-mixin)
