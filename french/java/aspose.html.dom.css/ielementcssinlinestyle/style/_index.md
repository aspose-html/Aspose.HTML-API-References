## IElementCSSInlineStyle.Style property

L'attribut style doit renvoyer un objet bloc de déclaration CSS dont le drapeau calculé est désactivé, dont la règle CSS parente est nulle et dont le nœud propriétaire est l'objet contexte.

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

Le bloc de déclaration CSS associé au nœud ou null s'il n'existe aucun bloc de déclaration CSS associé.
