## ICSSPageRule interface

L'interface CSSPageRule représente une règle @page au sein d'une feuille de style CSS. La règle @page est utilisée pour spécifier les dimensions, l'orientation, les marges, etc. d'une boîte de page pour les médias paginés.

```java
public interface ICSSPageRule : ICSSRule
```
