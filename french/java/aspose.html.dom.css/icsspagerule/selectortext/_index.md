## ICSSPageRule.SelectorText property

La propriété selectorText de l'interface [`CSSPageRule`](../) obtient et définit les sélecteurs associés à [`CSSPageRule`](../).

```java
public String SelectorText { get; set; }
```

### Property Value

L'attribut selectorText, lors de la lecture, doit renvoyer le résultat de la sérialisation de la liste associée de sélecteurs de pages CSS.
