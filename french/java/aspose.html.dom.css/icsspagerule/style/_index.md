## ICSSPageRule.Style property

La propriété en lecture seule style de l'interface [`CSSPageRule`](../) renvoie un objet [`CSSStyleDeclaration`](../../icssstyledeclaration/). Cela représente un objet qui est un bloc de déclaration CSS et expose des informations de style ainsi que diverses méthodes et propriétés liées au style.

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

Un objet [`CSSStyleDeclaration`](../../icssstyledeclaration/) qui représente un bloc de déclaration CSS.
