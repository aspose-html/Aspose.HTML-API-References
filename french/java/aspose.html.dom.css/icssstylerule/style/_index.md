## ICSSStyleRule.Style property

La propriété de style en lecture seule est l'interface [`CSSStyleDeclaration`](../../icssstyledeclaration/) pour le bloc de déclaration du [`CSSStyleRule`](../).

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

L'attribut style doit renvoyer un objet CSSStyleDeclaration pour la règle de style, avec les propriétés suivantes :

drapeau calculé - Unset.declarations - Les déclarations déclarées dans la règle, dans l'ordre spécifié. parent CSS rule - L'objet contexte. owner node - Null.
