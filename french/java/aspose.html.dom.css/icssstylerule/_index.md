## ICSSStyleRule interface

L'interface CSSStyleRule représente une règle de style CSS unique. L'attribut selectorText, lors de la lecture, doit renvoyer le résultat de la sérialisation du groupe de sélecteurs associé.

```java
public interface ICSSStyleRule : ICSSRule
```

## Propriétés

| Nom | Description |
| --- | --- |
| [getSelectorText](../../com.aspose.html.dom.css/icssstylerule/selectortext/) La représentation textuelle du sélecteur pour l'ensemble de règles. L'implémentation peut avoir supprimé les espaces blancs insignifiants lors de l'analyse du sélecteur. |
| [getStyle](../../com.aspose.html.dom.css/icssstylerule/style/) La propriété de style en lecture seule est l'interface [`CSSStyleDeclaration`](../icssstyledeclaration/) pour le bloc de déclaration du `CSSStyleRule`. |
