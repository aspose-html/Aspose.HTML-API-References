## ICSSStyleDeclaration.ParentRule property

La propriété en lecture seule CSSStyleDeclaration.parentRule renvoie un CSSRule qui est le parent de ce bloc de style, par ex. un [`CSSStyleRule`](../../icssstylerule/) représentant le style d'un sélecteur CSS.

```java
public ICSSRule ParentRule { get; }
```

### Property Value

La règle CSS qui contient ce bloc de déclaration ou null si ce [`CSSStyleDeclaration`](../) n'est pas attaché à un [`CSSRule`](../../icssrule/).
