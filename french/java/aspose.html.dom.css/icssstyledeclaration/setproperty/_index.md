## SetProperty(String, String) {#setproperty}

L'interface de méthode CSSStyleDeclaration.setProperty() est utilisée pour définir la valeur d'une propriété avec la priorité par défaut dans ce bloc de déclaration. La priorité par défaut n'est pas "important", c'est‑à‑dire String.Empty.

```java
public void SetProperty(String propertyName, String value)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| propertyName | String | Une String représentant le nom de la propriété CSS (en casse avec tirets) à modifier. |
| valeur | String | Une String contenant la nouvelle valeur de la propriété. Si non spécifiée, elle est traitée comme une String vide. |

## SetProperty(String, String, String) {#setproperty_1}

L'interface de méthode CSSStyleDeclaration.setProperty() est utilisée pour définir la valeur d'une propriété avec la priorité par défaut dans ce bloc de déclaration. La priorité par défaut n'est pas "important", c'est‑à‑dire String.Empty.

```java
public void SetProperty(String propertyName, String value, String priority)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| propertyName | String | Une String représentant le nom de la propriété CSS (en casse avec tirets) à modifier. |
| valeur | String | Une String contenant la nouvelle valeur de la propriété. Si non spécifiée, elle est traitée comme une String vide. |
| priorité | String | Une String permettant de définir la priorité CSS "important". Si non spécifiée, elle est traitée comme une String vide. Les valeurs suivantes sont acceptées : valeur String "important", mot-clé undefined ou valeur String vide "" |
