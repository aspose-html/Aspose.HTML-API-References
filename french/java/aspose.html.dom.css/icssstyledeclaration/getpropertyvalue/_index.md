## ICSSStyleDeclaration.GetPropertyValue method

L'interface de méthode CSSStyleDeclaration.getPropertyValue() renvoie une chaîne contenant la valeur d'une propriété CSS spécifiée.

```java
public String GetPropertyValue(String propertyName)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| propertyName | String | propertyName est une String représentant le nom de la propriété (en casse avec tiret) à vérifier. |

### Valeur de retour

value est une String contenant la valeur de la propriété. Si elle n'est pas définie, renvoie la chaîne vide.
