## ICSSStyleDeclaration.Length property

La propriété en lecture seule renvoie un nombre entier de propriétés qui ont été explicitement définies dans ce bloc de déclaration CSS. L'intervalle des indices valides est de 0 à length-1 inclus.

```java
public int Length { get; }
```

### Property Value

Un entier qui indique le nombre de styles explicitement définis sur le parent de l'instance.
