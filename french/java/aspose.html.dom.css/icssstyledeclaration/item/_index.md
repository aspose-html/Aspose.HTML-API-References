## ICSSStyleDeclaration indexer

Utilisée pour récupérer les propriétés qui ont été explicitement définies dans ce bloc de déclaration. L'ordre des propriétés récupérées avec cette méthode n'a pas besoin d'être l'ordre dans lequel elles ont été définies. Cette méthode peut être utilisée pour parcourir toutes les propriétés de ce bloc de déclaration.

```java
public String this[int index] { get; }
```

### Valeur de retour

propertyName est une String qui est le nom de la propriété CSS à l'index spécifié.

### Property Value

index est l'index du nœud à récupérer. L'index commence à zéro.
