## ICSSStyleDeclaration.CSSText property

La représentation textuelle analysable du bloc de déclaration (excluant les accolades environnantes). La définition de cet attribut entraînera l'analyse de la nouvelle valeur et la réinitialisation de toutes les propriétés du bloc de déclaration, y compris la suppression ou l'ajout de propriétés.

```java
public String CSSText { get; set; }
```

### Property Value

Définir cet attribut modifie le style en ligne. Si vous souhaitez une représentation textuelle d'un bloc de déclaration calculé, vous pouvez l'obtenir avec JSON.Stringify().
