## ICSSKeyframesRule.FindRule method

La méthode findRule renvoie la règle dont la clé correspond à la clé fournie. Si aucune règle de ce type n'existe, une valeur null est renvoyée.

```java
public ICSSKeyframeRule FindRule(String key)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| key | String | La clé qui décrit la règle à trouver. La clé doit correspondre à un nombre compris entre 0 et 1, sinon la règle est ignorée. |

### Valeur de retour

Renvoie le dernier [`CSSKeyframeRule`](../../icsskeyframerule/) déclaré correspondant au sélecteur de trame clé spécifié. Si aucune règle correspondante n'existe, la méthode ne fait rien.
