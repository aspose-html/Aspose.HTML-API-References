## ICSSKeyframesRule.DeleteRule method

La méthode deleteRule supprime le [`CSSKeyframeRule`](../../icsskeyframerule/) correspondant à la clé fournie. Si aucune règle avec cette clé n’existe, la méthode ne fait rien.

```java
public void DeleteRule(String key)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| key | String | La clé qui décrit la règle à supprimer. La clé doit correspondre à un nombre compris entre 0 et 1, sinon la règle est ignorée. |
