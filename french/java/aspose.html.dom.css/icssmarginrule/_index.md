## ICSSMarginRule interface

L'interface CSSMarginRule représente une règle de marge (par ex. @top-left) dans une règle @page.

```java
public interface ICSSMarginRule : ICSSRule
```

| Nom | Description |
| --- | --- |
| [getName](../../com.aspose.html.dom.css/icssmarginrule/name/) L'attribut name doit renvoyer le nom de la règle d'agrément de marge. Le caractère @ n'est pas inclus dans le nom. |
| [getStyle](../../com.aspose.html.dom.css/icssmarginrule/style/) L'attribut style doit renvoyer un objet [`CSSStyleDeclaration`](../icssstyledeclaration/) pour la règle d'agrément de marge. |
