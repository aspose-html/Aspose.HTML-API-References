## IStyleSheetList.Length property

L'attribut length doit renvoyer le nombre de feuilles de style CSS représentées par la collection. L'intervalle des indices valides des feuilles de style enfants est de 0 à length-1 inclus.

```java
public int Length { get; }
```

### Property Value

Un entier indiquant le nombre d'éléments dans la collection.
