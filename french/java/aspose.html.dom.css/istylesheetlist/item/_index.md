## IStyleSheetList indexer

La méthode item(index) doit renvoyer le [`CSS style sheet`](../../icssstylesheet/) d'indice index dans la collection. S'il n'existe aucun objet d'indice index dans la collection, la méthode doit renvoyer null.

```java
public ICSSStyleSheet this[int index] { get; }
```

### Valeur de retour

Un objet [`CSSStyleSheet`](../../icssstylesheet/), ou null s'il n'existe pas pour cet indice.

### Property Value

Un entier correspondant à l'indice de l'élément dans la collection à renvoyer.
