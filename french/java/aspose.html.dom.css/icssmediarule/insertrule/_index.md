## ICSSMediaRule.InsertRule method

La méthode insertRule() de l'interface CSSGroupingRule ajoute une nouvelle règle CSS à une liste de règles CSS.

```java
public long InsertRule(String rule, long index)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| règle | String | La règle média en tant que CSSOMString. |
| index | Int64 | Un index optionnel où insérer la règle ; la valeur par défaut est 0. |

### Valeur de retour

La méthode insertRule(rule, index) renvoie le résultat de l'invocation de l'insertion d'une règle CSS dans les règles CSS enfants à l'index.
