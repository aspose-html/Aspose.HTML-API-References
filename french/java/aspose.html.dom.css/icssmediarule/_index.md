## ICSSMediaRule interface

L'interface CSSMediaRule représente une règle @media dans une feuille de style CSS. Une règle @media peut être utilisée pour délimiter des règles de style pour des types de médias spécifiques.

```java
public interface ICSSMediaRule : ICSSRule
```
