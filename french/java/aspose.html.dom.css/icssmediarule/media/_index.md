## ICSSMediaRule.Media property

La propriété en lecture seule media de l'interface [`CSSMediaRule`](../) MediaList représente le support de destination prévu pour les informations de style.

```java
public IMediaList Media { get; }
```

### Property Value

L'attribut media doit renvoyer un objet MediaList pour la liste des requêtes média spécifiées avec la règle @media.
