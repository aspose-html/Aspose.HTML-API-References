## IStyleSheet.Title property

La propriété title de l'interface [`StyleSheet`](../) renvoie le titre indicatif de la feuille de style actuelle.

Le titre est souvent spécifié dans le [`ownerNode`](../ownernode/).

```java
public String Title { get; }
```

### Property Value

L'attribut parentStyleSheet doit renvoyer le [`CSS style sheet`](../../icssstylesheet/) parent.
