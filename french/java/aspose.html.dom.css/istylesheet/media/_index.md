## IStyleSheet.Media property

La propriété media de l’interface [`StyleSheet`](../) spécifie le média de destination prévu pour les informations de style. C’est un objet [`MediaList`](../../imedialist/) en lecture seule, de type tableau, et il peut être supprimé avec deleteMedium() et ajouté avec appendMedium().

```java
public IMediaList Media { get; }
```

### Property Value

L’attribut media doit renvoyer l’objet [`MediaList`](../../imedialist/) associé à la feuille de style CSS.

## Remarques

[CSSOM](https://drafts.csswg.org/cssom/) defines APIs (including generic parsing and serialization rules) for Media Queries, Selectors, and of course CSS itself.
