## IStyleSheet.Type property

Cela spécifie le langage de feuille de style pour cette feuille de style. Le langage de feuille de style est indiqué sous forme de type de contenu (par ex. "text/css").

```java
public String Type { get; }
```

### Property Value

L'attribut type doit renvoyer le type.
