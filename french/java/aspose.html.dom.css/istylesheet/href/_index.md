## IStyleSheet.Href property

La propriété href de l'interface [`StyleSheet`](../) renvoie l'emplacement de la feuille de style.

```java
public String Href { get; }
```

### Property Value

uri est une chaîne contenant l'URI de la feuille de style.

## Remarques

Si la feuille de style est une feuille de style liée, la valeur de son attribut est son emplacement. Pour les feuilles de style en ligne, la valeur de cet attribut est NULL.

Cette propriété est en lecture seule dans Firefox, Opera, Google Chrome et Safari, et elle est en lecture/écriture dans Internet Explorer.
