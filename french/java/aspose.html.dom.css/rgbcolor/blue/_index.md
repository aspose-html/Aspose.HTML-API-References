## RGBColor.Blue property

Obtient la valeur du composant bleu de cette structure Color.

```java
public CSSPrimitiveValue Blue { get; }
```

### Property Value

La valeur du composant bleu de cette Color.

## Remarques

La couleur de chaque pixel est représentée par un nombre de 32 bits : 8 bits pour chaque canal alpha, rouge, vert et bleu (ARGB). Le composant alpha indique la transparence de la couleur : 0 est totalement transparent et 255 est totalement opaque. De même, une valeur A de 255 représente une couleur opaque. Une valeur A comprise entre 1 et 254 représente une couleur semi‑transparente. La couleur devient plus opaque à mesure que A approche de 255.
