## ICSSRule.CSSText property

La propriété cssText de l'interface [`CSSRule`](../) renvoie le texte réel d'une règle de style [`CSSStyleSheet`](../../icssstylesheet/).

Remarque : Ne confondez pas cette propriété avec le cssText de CSSStyleDeclaration au niveau de l'élément.

```java
public String CSSText { get; set; }
```

### Property Value

Renvoie une sérialisation de la règle CSS. La définition de l'attribut cssText ne doit rien faire.
