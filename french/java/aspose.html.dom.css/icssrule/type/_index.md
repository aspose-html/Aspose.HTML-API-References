## ICSSRule.Type property

Le type de la règle, tel que défini par [CSSOM # dom-cssrule-type](https://drafts.csswg.org/cssom/#dom-cssrule-type). L'attente est que les méthodes de cast spécifiques aux liaisons puissent être utilisées pour convertir une instance de l'interface CSSRule vers l'interface dérivée spécifique implicite du type.

```java
public short Type { get; }
```

### Property Value

Un entier non négatif associé à un type particulier de règle. Cet élément est initialisé lors de la création d'une règle et ne peut pas être modifié.
