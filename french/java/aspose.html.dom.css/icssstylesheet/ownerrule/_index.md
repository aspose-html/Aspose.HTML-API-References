## ICSSStyleSheet.OwnerRule property

La propriété en lecture seule ownerRule de CSSStyleSheet renvoie le [`CSSImportRule`](../../icssimportrule/) correspondant à la règle @import qui a importé la feuille de style dans le document. Si la feuille de style n'a pas été importée dans le document à l'aide de @import, la valeur renvoyée est null.

```java
public ICSSRule OwnerRule { get; }
```

### Property Value

Un CSSImportRule correspondant à la règle @import qui a importé la feuille de style dans le document. Si la feuille de style n'a pas été importée dans le document à l'aide de @import, la valeur renvoyée est null.
