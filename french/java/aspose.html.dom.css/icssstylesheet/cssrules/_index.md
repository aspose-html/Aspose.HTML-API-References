## ICSSStyleSheet.CSSRules property

La propriété en lecture seule cssRules de CSSStyleSheet renvoie une [`CSSRuleList`](../../icssrulelist/) dynamique qui fournit une liste en temps réel et à jour de chaque règle CSS composant la feuille de style. Chaque élément de la liste est un [`CSSRule`](../../icssrule/) définissant une règle unique.

```java
public ICSSRuleList CSSRules { get; }
```

### Property Value

Une [`CSSRuleList`](../../icssrulelist/) mise à jour en temps réel contenant chacune des règles CSS constituant la feuille de style. Chaque entrée de la liste de règles est un objet [`CSSRule`](../../icssrule/) décrivant une règle de la feuille de style.

## Remarques

[CSSOM](https://drafts.csswg.org/cssom/) defines APIs (including generic parsing and serialization rules) for Media Queries, Selectors, and of course CSS itself.
