## ICSSFontFaceRule interface

L'interface CSSFontFaceRule représente une règle @font-face dans une feuille de style CSS. La règle @font-face est utilisée pour contenir un ensemble de descriptions de polices.

```java
public interface ICSSFontFaceRule : ICSSRule
```
