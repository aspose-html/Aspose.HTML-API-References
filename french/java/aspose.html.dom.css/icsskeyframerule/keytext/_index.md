## ICSSKeyframeRule.KeyText property

La propriété keyText de l'interface CSSKeyframeRule représente le sélecteur de trame clé sous forme d'une liste séparée par des virgules de valeurs en pourcentage. Les mots-clés from et to correspondent à 0 % et 100 %, respectivement.

```java
public String KeyText { get; }
```

### Property Value

Renvoie le sélecteur de trame clé sous forme d'une liste séparée par des virgules de valeurs en pourcentage.
