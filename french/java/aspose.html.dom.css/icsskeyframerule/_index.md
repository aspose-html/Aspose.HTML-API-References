## ICSSKeyframeRule interface

L'interface `CSSKeyframeRule` décrit un objet représentant un ensemble de styles pour une trame clé donnée. Elle correspond au contenu d'une seule trame clé d'une règle @keyframes.

```java
public interface ICSSKeyframeRule : ICSSRule
```

## Propriétés

| Nom | Description |
| --- | --- |
| [getKeyText](../../com.aspose.html.dom.css/icsskeyframerule/keytext/) La propriété keyText de l'interface CSSKeyframeRule représente le sélecteur de trame clé sous forme de liste séparée par des virgules de valeurs en pourcentage. Les mots-clés from et to correspondent respectivement à 0 % et 100 %. |
| [getStyle](../../com.aspose.html.dom.css/icsskeyframerule/style/) La propriété en lecture seule CSSKeyframeRule.style est l'interface [`CSSStyleDeclaration`](../icssstyledeclaration/) du bloc de déclaration du `CSSKeyframeRule`. |
