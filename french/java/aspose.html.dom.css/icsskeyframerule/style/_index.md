## ICSSKeyframeRule.Style property

The read-only CSSKeyframeRule.style property is the [`CSSStyleDeclaration`](../../icssstyledeclaration/) interface for the declaration block of the [`CSSKeyframeRule`](../).

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

Un objet [`CSSStyleDeclaration`](../../icssstyledeclaration/), avec les propriétés suivantes :

computed flag - Unset.declarations - Les déclarations déclarées dans la règle, dans l'ordre où elles ont été spécifiées, les propriétés raccourcies développées en propriétés longues.parent CSS rule - L'objet de contexte, qui est un alias pour this.owner node - Null.
