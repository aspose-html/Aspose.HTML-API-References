## CSSPrimitiveValue.SetIntValue method

Une méthode pour définir la valeur entière avec une unité spécifiée. Si la propriété associée à cette valeur ne peut pas accepter l'unité spécifiée ou la valeur entière, la valeur restera inchangée et une DOMException sera levée.

```java
public abstract void SetIntValue(ushort unitType, int intValue)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| unitType | UInt16 | Type de l'unité. |
| intValue | Int32 | La valeur int. |
