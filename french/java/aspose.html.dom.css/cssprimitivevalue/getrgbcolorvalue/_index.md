## CSSPrimitiveValue.GetRGBColorValue method

Cette méthode est utilisée pour obtenir la couleur RGB. Si cette valeur CSS ne contient pas de valeur de couleur RGB, une DOMException est levée. La modification de la propriété de style correspondante peut être effectuée en utilisant l'interface RGBColor.

```java
public abstract RGBColor GetRGBColorValue()
```

### Valeur de retour

Renvoie la valeur de couleur RGB
