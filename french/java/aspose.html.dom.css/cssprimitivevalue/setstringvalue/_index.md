## CSSPrimitiveValue.SetStringValue method

Une méthode pour définir la valeur String avec l'unité spécifiée. Si la propriété associée à cette valeur ne peut pas accepter l'unité spécifiée ou la valeur String, la valeur restera inchangée et une DOMException sera levée.

```java
public abstract void SetStringValue(ushort StringType, String StringValue)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| StringType | UInt16 | Type de la String. |
| StringValue | String | La valeur de la String. |
