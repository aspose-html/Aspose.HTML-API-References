## CSSPrimitiveValue.GetRectValue method

Cette méthode est utilisée pour obtenir la valeur Rect. Si cette valeur CSS ne contient pas de valeur rect, une DOMException est levée. La modification de la propriété de style correspondante peut être effectuée en utilisant l'interface Rect.

```java
public abstract Rect GetRectValue()
```

### Valeur de retour

Renvoie la valeur Rect
