## SVGRect class

Représente la géométrie rectangulaire. Les rectangles sont définis comme constitués d'une paire de coordonnées (x, y) identifiant une valeur X minimale, une valeur Y minimale, ainsi que d'une largeur et d'une hauteur, généralement contraintes à être non négatives.

```java
public class SVGRect : SVGValueType
```
