## SVGLength.ValueInSpecifiedUnits property

La valeur en tant que nombre à virgule flottante, dans les unités exprimées par unitType. La définition de cet attribut entraînera la mise à jour automatique de value et valueAsString pour refléter ce réglage.

```java
public float ValueInSpecifiedUnits { get; set; }
```

### Property Value

La valeur dans les unités spécifiées.
