## SVGLength.ValueAsString property

La valeur en tant que chaîne, dans les unités exprimées par unitType. La définition de cet attribut entraînera la mise à jour automatique de value, valueInSpecifiedUnits et unitType pour refléter ce réglage.

```java
public String ValueAsString { get; set; }
```

### Property Value

La valeur en tant que String.
