## SVGLength.Value property

La valeur en tant que nombre à virgule flottante, en unités utilisateur. La définition de cet attribut entraînera la mise à jour automatique de valueInSpecifiedUnits et de valueAsString pour refléter ce réglage.

```java
public float Value { get; set; }
```

### Property Value

La valeur.
