## SVGAnimatedValue&lt;T&gt;.AnimVal property

Si l'attribut ou la propriété donnée est animée, contient la valeur animée actuelle de l'attribut ou de la propriété. Si l'attribut ou la propriété donnée n'est pas actuellement animée, contient la même valeur que baseVal.

```java
public T AnimVal { get; }
```

### Property Value

`true` si [valeur animée] ; sinon, `false`.
