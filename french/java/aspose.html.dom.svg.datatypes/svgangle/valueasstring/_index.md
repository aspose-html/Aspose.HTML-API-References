## SVGAngle.ValueAsString property

La valeur de l'angle en tant que valeur String, dans les unités exprimées par unitType. La définition de cet attribut entraînera la mise à jour automatique de value, valueInSpecifiedUnits et unitType pour refléter ce réglage.

```java
public String ValueAsString { get; set; }
```

### Property Value

La valeur en tant que String.
