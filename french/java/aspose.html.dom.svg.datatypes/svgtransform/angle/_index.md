## SVGTransform.Angle property

Un attribut de commodité pour SVG_TRANSFORM_ROTATE, SVG_TRANSFORM_SKEWX et SVG_TRANSFORM_SKEWY. Il contient l'angle spécifié. Pour SVG_TRANSFORM_MATRIX, SVG_TRANSFORM_TRANSLATE et SVG_TRANSFORM_SCALE, l'angle sera zéro.

```java
public float Angle { get; }
```

### Property Value

L'angle spécifié.
