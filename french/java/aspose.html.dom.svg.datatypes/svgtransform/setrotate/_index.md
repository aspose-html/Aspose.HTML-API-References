## SVGTransform.SetRotate method

Définit le type de transformation sur SVG_TRANSFORM_ROTATE, avec le paramètre angle définissant l'angle de rotation et les paramètres cx et cy définissant le centre de rotation optionnel.

```java
public void SetRotate(float angle, float cx, float cy)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| angle | Single | L'angle de rotation. |
| cx | Single | La coordonnée x du centre de rotation. |
| cy | Single | La coordonnée y du centre de rotation. |
