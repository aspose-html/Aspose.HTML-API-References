## ResourceHandlingOptions.MaxHandlingDepth property

Obtient ou définit la profondeur maximale des pages qui seront traitées. Une profondeur de 1 signifie que seules les pages directement référencées depuis le document enregistré seront traitées. Définir cette propriété à -1 entraînera le traitement de toutes les pages. La valeur par défaut est 0.

```java
public int MaxHandlingDepth { get; set; }
```
