## TextSaveOptions.EnableListItemMarkers property

Option appliquée aux éléments OL, UL lors de la conversion HTML en texte. En fait, elle définit comment traiter les marqueurs de liste externes des éléments OL et UL. Si vrai, des numéros d'éléments sont ajoutés avant les éléments OL, ou des points sont ajoutés avant les éléments UL. Si faux, ils ne sont pas ajoutés (comportement par défaut suivant la spécification)

```java
public bool EnableListItemMarkers { get; set; }
```
