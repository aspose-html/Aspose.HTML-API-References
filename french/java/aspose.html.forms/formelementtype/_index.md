## FormElementType enumeration

Représente une énumération des types d’éléments de formulaire et leurs correspondances avec les éléments HTML.


### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Unknown | `0` | Correspond à tout élément HTML qui n'a pas été converti en l'un des [`FormElement`](../formelement/) implémentés. |
| Input | `1` | Correspond à le [`HTMLInputElement`](../../com.aspose.html/htmlinputelement/). |
| Select | `2` | Correspond à le [`HTMLSelectElement`](../../com.aspose.html/htmlselectelement/). |
| TextArea | `3` | Correspond à le [`HTMLTextAreaElement`](../../com.aspose.html/htmltextareaelement/). |
| Option | `4` | Correspond à le [`HTMLOptionElement`](../../com.aspose.html/htmloptionelement/). |
| Button | `5` | Correspond à le [`HTMLButtonElement`](../../com.aspose.html/htmlbuttonelement/). |
| DataList | `6` | Correspond à le [`HTMLDataListElement`](../../com.aspose.html/htmldatalistelement/). |
