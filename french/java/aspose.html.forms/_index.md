Le paquet fournit l'accès à de nombreux objets (éléments) qui sont responsables de l'interactivité utilisateur au sein du formulaire en tant que composant de page Web.

## Classes

| Classe | Description |
| --- | --- |
| [ButtonElement](./buttonelement/) | Le ButtonElement représente un wrapper associé à l’HTMLButtonElement. |
| [DataListElement](./datalistelement/) | Le DataListElement représente un wrapper associé à l’HTMLDataListElement. |
| [FormEditor](./formeditor/) | Cette classe représente l’éditeur du [`HTMLFormElement`](../com.aspose.html/htmlformelement/) qui offre une méthode plus simple aux développeurs .net pour modifier les formulaires HTML. |
| [FormElement](./formelement/) | Représente la classe de base pour les éléments de formulaire. |
| [FormElement&lt;T&gt;](./formelement-1/) | Le [`FormElement`](../com.aspose.html.forms/formelement/) représente le champ générique. |
| [FormSubmitter](./formsubmitter/) | Cette classe permet de préparer le [`HTMLFormElement`](../com.aspose.html/htmlformelement/) spécifié, de collecter les valeurs du formulaire, de les soumettre au serveur distant et de recevoir une réponse. |
| [InputElement](./inputelement/) | Le InputElement représente un wrapper associé à l’HTMLInputElement. |
| [OptionCollection](./optioncollection/) | Le OptionElements représente un wrapper associé à l’IHTMLOptionsCollection. |
| [OptionElement](./optionelement/) | Le OptionElement représente un wrapper associé à l’HTMLOptionElement. |
| [SelectElement](./selectelement/) | Le SelectElement représente un wrapper associé à l’HTMLSelectElement. |
| [SubmissionResult](./submissionresult/) | Cette classe représente le résultat de la soumission des données du formulaire au serveur. |
| [TextAreaElement](./textareaelement/) | Le TextAreaElement représente un wrapper associé à l’HTMLTextAreaElement. |
## Énumération

| Énumération | Description |
| --- | --- |
| [ButtonType](./buttontype/) | Cette énumération représente les états du bouton. |
| [FormElementType](./formelementtype/) | Représente une énumération des types d’éléments de formulaire et leurs correspondances avec les éléments HTML. |
| [InputElementType](./inputelementtype/) | Représente les états du champ de saisie. |
