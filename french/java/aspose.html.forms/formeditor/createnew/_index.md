## FormEditor.CreateNew method

Crée un nouveau [`HTMLFormElement`](../../../com.aspose.html/htmlformelement/) et l'associe à [`FormEditor`](../). [`HTMLFormElement`](../../../com.aspose.html/htmlformelement/) est créé dans un état détaché du document ; afin de l'attacher au document, veuillez sélectionner l'emplacement approprié et utiliser la méthode [`AppendChild`](../../../com.aspose.html.dom/node/appendchild/).

```java
public static FormEditor CreateNew(HTMLDocument document)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| document | HTMLDocument | Le [`HTMLDocument`](../../../com.aspose.html/htmldocument/). |

### Valeur de retour

Renvoie une nouvelle instance de la classe [`FormEditor`](../)
