## FontEmbeddingRule enumeration

Représente les règles d'incorporation des polices.

```java
public enum FontEmbeddingRule
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Full | `1` | Toutes les polices utilisées seront incorporées telles quelles. Sachez que certaines polices peuvent être sous licence, ce qui rendra le document résultant non modifiable. De plus, les fichiers de polices incorporés peuvent augmenter de manière significative la taille du document résultant. |
| None | `2` | Les polices ne seront pas incorporées. |
