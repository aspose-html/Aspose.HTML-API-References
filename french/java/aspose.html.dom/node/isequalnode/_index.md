## Node.IsEqualNode method

La méthode isEqualNode() de l'interface [`Node`](../) teste si deux nœuds sont égaux. Deux nœuds sont égaux lorsqu'ils ont le même type, des caractéristiques définissant (pour les éléments, cela serait leur ID, le nombre d'enfants, etc.), que leurs attributs correspondent, etc. L'ensemble spécifique de points de données qui doivent correspondre varie selon les types de nœuds.

```java
public bool IsEqualNode(Node otherNode)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| otherNode | Node | Le [`Node`](../) à comparer pour l'égalité. |

### Valeur de retour

Une valeur booléenne qui est vraie si les deux nœuds sont égaux, ou fausse sinon. Si otherNode est null, isEqualNode() renvoie toujours false.
