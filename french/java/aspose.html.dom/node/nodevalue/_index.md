## Node.NodeValue property

La propriété nodeValue de l'interface [`Node `](../) renvoie ou définit la valeur du nœud actuel.

```java
public String NodeValue { get; set; }
```

### Property Value

Une chaîne contenant la valeur du nœud actuel, le cas échéant. Pour le document lui‑-même, nodeValue renvoie null. Pour les nœuds texte, commentaire et CDATA, nodeValue renvoie le contenu du nœud. Pour les nœuds attribut, la valeur de l'attribut est renvoyée.
