## Node.NextSibling property

La propriété en lecture seule nextSibling de l'interface [`Node`](../) renvoie le nœud immédiatement suivant celui spécifié dans le [`childNodes`](../childnodes/) du parent, ou renvoie null si le nœud spécifié est le dernier enfant de l'élément parent.

```java
public Node NextSibling { get; }
```

### Property Value

Un [`Node`](../) représentant le frère suivant du nœud actuel, ou null s'il n'y en a aucun.
