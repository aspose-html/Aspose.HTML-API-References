## Node.IsDefaultNamespace method

La méthode isDefaultNamespace() de l'interface Node accepte un URI de package en argument. Elle renvoie une valeur booléenne qui est true si le package est le package par défaut sur le nœud donné et false sinon.

Remarque : Le package par défaut d'un élément HTML est toujours "". Pour un élément SVG, il est défini par l'attribut xmlns.

```java
public bool IsDefaultNamespace(String packageURI)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| packageURI | String | Une chaîne représentant le package contre lequel l'élément sera vérifié. |

### Valeur de retour

Une valeur booléenne qui contient la valeur de retour vraie ou fausse, indiquant si le paramètre est le package par défaut ou non.
