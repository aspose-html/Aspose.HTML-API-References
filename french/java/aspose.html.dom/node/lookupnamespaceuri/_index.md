## Node.LookupNamespaceURI method

La méthode lookupNamespaceURI() de l'interface Node prend un préfixe en paramètre et renvoie l'URI de package qui lui est associé sur le nœud donné si trouvé (et null sinon).

```java
public String LookupNamespaceURI(String prefix)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| préfixe | String | Le préfixe à rechercher. |

### Valeur de retour

Une chaîne contenant l'URI du package correspondant au préfixe. Si le préfixe n'est pas trouvé, elle renvoie null. Si le préfixe demandé est null, elle renvoie l'URI du package par défaut.
