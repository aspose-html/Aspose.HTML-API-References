## Node.OwnerDocument property

La propriété en lecture seule ownerDocument de l'interface Node renvoie l'objet document de niveau supérieur du nœud.

```java
public Document OwnerDocument { get; }
```

### Property Value

Un [`Document`](../../document/) qui est l'objet de niveau supérieur dans lequel tous les nœuds enfants sont créés.

Si cette propriété est utilisée sur un nœud qui est lui-même un document, la valeur est null.
