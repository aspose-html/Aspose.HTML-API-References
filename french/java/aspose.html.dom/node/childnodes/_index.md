## Node.ChildNodes property

La propriété en lecture seule childNodes de l'interface Node renvoie une [`NodeList`](../../../com.aspose.html.collections/nodelist/) dynamique des nœuds enfants de l'élément donné, où le premier nœud enfant reçoit l'index 0. Les nœuds enfants comprennent les éléments, le texte et les commentaires.

Remarque : Le fait que la [`NodeList`](../../../com.aspose.html.collections/nodelist/) soit dynamique signifie que son contenu est modifié chaque fois que de nouveaux enfants sont ajoutés ou supprimés.

```java
public NodeList ChildNodes { get; }
```

### Property Value

Une [`NodeList`](../../../com.aspose.html.collections/nodelist/) dynamique contenant les enfants du nœud.

Remarque : Plusieurs appels à childNodes renvoient la même [`NodeList`](../../../com.aspose.html.collections/nodelist/).
