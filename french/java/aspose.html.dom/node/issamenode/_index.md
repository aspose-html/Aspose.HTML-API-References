## Node.IsSameNode method

La méthode isSameNode() de l'interface Node est un alias hérité de l'opérateur d'égalité stricte ===. Autrement dit, elle teste si deux nœuds sont identiques (c'est‑à‑dire s'ils font référence au même objet).

Remarque : Il n'est pas nécessaire d'utiliser isSameNode(); utilisez plutôt l'opérateur d'égalité stricte ===.

```java
public bool IsSameNode(Node otherNode)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| otherNode | Node | Le nœud à tester. |

### Valeur de retour

Une valeur booléenne qui est vraie si les deux nœuds sont strictement égaux, fausse sinon.
