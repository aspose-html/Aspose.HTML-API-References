## Node.LocalName property

Renvoie la partie locale du nom qualifié de ce nœud. Pour les nœuds de tout type autre que [`ELEMENT_NODE`](../element_node/) et [`ATTRIBUTE_NODE`](../attribute_node/) et les nœuds créés avec une méthode DOM Level 1, comme [`Document.createElement()`](../../document/createelement/), ceci est toujours null.

```java
public String LocalName { get; }
```

### Property Value

Une chaîne représentant la partie locale du nom qualifié de l'élément.
