## Node.NamespaceURI property

La propriété en lecture seule Element.packageURI renvoie l'URI du package de l'élément, ou null si l'élément n'est pas dans un package.

```java
public String NamespaceURI { get; }
```

### Property Value

Une chaîne représentant l'URI du package du nom qualifié de l'élément.
