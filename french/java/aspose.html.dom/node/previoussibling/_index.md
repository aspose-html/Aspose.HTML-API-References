## Node.PreviousSibling property

La propriété en lecture seule previousSibling de l'interface [`Node`](../) renvoie le nœud immédiatement précédant le nœud spécifié dans la liste [`childNodes`](../firstchild/) de son parent, ou null si le nœud spécifié est le premier de cette liste.

```java
public Node PreviousSibling { get; }
```

### Property Value

Un [`Node`](../) représentant le frère précédent du nœud actuel, ou null s'il n'y en a aucun.
