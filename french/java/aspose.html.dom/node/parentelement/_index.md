## Node.ParentElement property

La propriété en lecture seule parentElement de l'interface [`Node`](../) renvoie l'élément parent du nœud DOM [`Element`](../../element/), ou null si le nœud n'a pas de parent, ou si son parent n'est pas un élément DOM.

```java
public Element ParentElement { get; }
```

### Property Value

Un [`Element`](../../element/) qui est l'élément parent du nœud actuel, ou null s'il n'en existe pas.
