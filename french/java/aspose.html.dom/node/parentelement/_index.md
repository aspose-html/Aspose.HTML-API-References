## Node.ParentElement property

La propriété en lecture seule parentElement de l’interface [`Node`](../) renvoie le parent du nœud DOM [`Element`](../../element/), ou null si le nœud n’a aucun parent, ou si son parent n’est pas un Element DOM.

```java
public Element ParentElement { get; }
```

### Property Value

Un [`Element`](../../element/) qui est l'élément parent du nœud actuel, ou null s’il n’y en a pas.
