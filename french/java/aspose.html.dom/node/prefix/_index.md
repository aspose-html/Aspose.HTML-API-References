## Node.Prefix property

La propriété en lecture seule prefix renvoie le préfixe du package de l'élément spécifié, ou null si aucun préfixe n'est spécifié.

```java
public String Prefix { get; set; }
```

### Property Value

La propriété renvoie le préfixe de package associé.
