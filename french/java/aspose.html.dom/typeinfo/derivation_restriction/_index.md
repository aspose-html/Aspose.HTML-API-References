## TypeInfo.DERIVATION_RESTRICTION field

Si le schéma du document est un schéma XML [XML Schema Part 1], cette constante représente la dérivation par restriction si des types complexes sont impliqués, ou une restriction si des types simples sont impliqués.

```java
public const ulong DERIVATION_RESTRICTION;
```
