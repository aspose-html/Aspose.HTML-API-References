## TypeInfo.TypeNamespace property

Obtient le package du type. Le package du type déclaré pour l'élément ou l'attribut associé ou null si l'élément n'a pas de déclaration ou si aucune information de package n'est disponible.

```java
public String TypeNamespace { get; }
```

### Property Value

Le package du type.
