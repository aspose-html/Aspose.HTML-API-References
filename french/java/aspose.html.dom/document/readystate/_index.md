## Document.ReadyState property

Retourne l'état de disponibilité du document. Le "loading" pendant que le Document est en cours de chargement, "interactive" une fois le parsing terminé mais toujours en cours de chargement des sous‑ressources, et "complete" une fois chargé.

```java
public String ReadyState { get; }
```
