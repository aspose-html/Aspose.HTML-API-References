## Document.ReadyState property

Retourne l’état de disponibilité du document. "loading" pendant que le Document se charge, "interactive" une fois l’analyse terminée mais que les sous‑ressources sont encore en cours de chargement, et "complete" une fois le chargement terminé.

```java
public String ReadyState { get; }
```
