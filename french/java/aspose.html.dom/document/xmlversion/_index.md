## Document.XmlVersion property

Un attribut spécifiant, dans le cadre de la déclaration XML, le numéro de version de ce document. S'il n'y a pas de déclaration et si ce document prend en charge la fonctionnalité \"XML\", la valeur est \"1.0\". Si ce document ne prend pas en charge la fonctionnalité \"XML\", la valeur est toujours null.

```java
public String XmlVersion { get; set; }
```

### Property Value

La version XML.
