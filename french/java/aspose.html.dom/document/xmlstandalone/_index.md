## Document.XmlStandalone property

Un attribut spécifiant, dans le cadre de la déclaration XML, si ce document est autonome. C’est faux lorsqu’il n’est pas spécifié.

```java
public bool XmlStandalone { get; set; }
```

### Property Value

`true` si XML autonome ; sinon, `false`.
