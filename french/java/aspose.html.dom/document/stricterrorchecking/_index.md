## Document.StrictErrorChecking property

Un attribut spécifiant si la vérification des erreurs est appliquée ou non. Lorsqu'il est réglé sur false, l'implémentation est libre de ne pas tester chaque cas d'erreur possible normalement défini sur les opérations DOM, et de ne pas lever de DOMException lors des opérations DOM ou de signaler des erreurs lors de l'utilisation de Document.normalizeDocument(). En cas d'erreur, le comportement est indéfini. Cet attribut est true par défaut.

```java
public bool StrictErrorChecking { get; set; }
```

### Property Value

`true` si la vérification stricte des erreurs est activée ; sinon, `false`.
