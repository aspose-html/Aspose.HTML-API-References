## Document.WriteLn method

Écrit une chaîne de texte suivie d'un caractère de nouvelle ligne dans un flux de document ouvert par open(). Notez que la fonction produira un document qui n'est pas nécessairement piloté par une DTD et pourrait donc produire un résultat invalide dans le contexte du document.
