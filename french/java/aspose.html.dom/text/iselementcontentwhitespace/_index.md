## Text.IsElementContentWhitespace property

Retourne si ce nœud texte contient des espaces de contenu d'élément, souvent abusivement appelés « espaces ignorables ».

```java
public bool IsElementContentWhitespace { get; }
```

### Property Value

`true` si cette instance est un espace de contenu d'élément ; sinon, `false`.
