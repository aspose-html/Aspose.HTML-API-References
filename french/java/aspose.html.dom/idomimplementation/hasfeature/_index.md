## IDOMImplementation.HasFeature method

Teste si l'implémentation DOM prend en charge une fonctionnalité et une version spécifiques, comme indiqué dans DOM Features.

```java
public bool HasFeature()
```

### Valeur de retour

`true` si la fonctionnalité spécifiée possède la fonctionnalité ; sinon, `false`.
