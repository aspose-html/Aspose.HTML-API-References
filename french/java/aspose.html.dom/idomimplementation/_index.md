## IDOMImplementation interface

L'interface DOMImplementation fournit un certain nombre de méthodes pour effectuer des opérations indépendantes de toute instance particulière du modèle d'objet document.

```java
public interface IDOMImplementation
```

| --- | --- |

| [createDocumentType](../../com.aspose.html.dom/idomimplementation/createdocumenttype/)(String, String, String) | Crée un nœud DocumentType vide.
