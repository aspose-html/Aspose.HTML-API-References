## ToggleAttribute(String) {#toggleattribute}

Si force n'est pas fourni, « toggle » qualifiedName, le supprimant s'il est présent et l'ajoutant s'il ne l'est pas. Si force est vrai, ajoute qualifiedName. Si force est faux, supprime qualifiedName.

```java
public bool ToggleAttribute(String qualifiedName)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| qualifiedName | String | L'attribut QualifiedName. |

### Valeur de retour

Retourne true si qualifiedName est maintenant présent ; sinon false.
