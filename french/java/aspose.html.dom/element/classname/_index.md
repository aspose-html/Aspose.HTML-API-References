L'attribut class de l'élément. Cet attribut a été renommé en raison de conflits avec le mot-clé "class" exposé par de nombreux langages. Voir la définition de l'attribut class dans HTML 4.01.

```java
public String ClassName { get; set; }
```

### Property Value
