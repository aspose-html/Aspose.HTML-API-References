## Element.LocalName property

Retourne la partie locale du nom qualifié de ce nœud. Pour les nœuds de tout type autre que ELEMENT_NODE et ATTRIBUTE_NODE et les nœuds créés avec une méthode DOM Niveau 1, comme Document.createElement(), ceci est toujours null.

```java
public String LocalName { get; }
```

### Property Value

Le nom du local.
