## Element.AttachShadow method

Crée une racine d'ombre et l'attache à l'élément actuel.

```java
public ShadowRoot AttachShadow(ShadowRootMode mode)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| mode | ShadowRootMode | Mode dans lequel le shadow root sera créé. |

### Valeur de retour

Créé [`ShadowRoot`](../../shadowroot/).

### Exceptions

| exception | condition |
| --- | --- |
| Erreur | NotSupportedError : L'élément ne prend pas en charge l'arbre d'ombre. |
| Erreur | InvalidStateError : L'élément possède déjà un arbre d'ombre. |
