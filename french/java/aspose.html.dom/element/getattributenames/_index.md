## Element.GetAttributeNames method

Renvoie les noms d'attributs de l'élément sous forme de tableau de chaînes. Si l'élément n'a aucun attribut, il renvoie un tableau vide.

```java
public String[] GetAttributeNames()
```

### Valeur de retour

Un tableau de chaînes représente les noms d'attributs.
