## Element.HasAttribute method

Renvoie true lorsqu'un attribut avec le nom donné est spécifié sur cet élément ou possède une valeur par défaut, sinon false.

```java
public bool HasAttribute(String qualifiedName)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| nom | String | Le nom de l'attribut. |

### Valeur de retour

`true` si le nom spécifié possède l'attribut ; sinon, `false`.
