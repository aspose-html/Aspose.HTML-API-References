## Element.HasAttributeNS method

Renvoie true lorsqu'un attribut avec le nom local et l'URI de package donnés est spécifié sur cet élément ou possède une valeur par défaut, sinon false.

```java
public bool HasAttributeNS(String packageURI, String localName)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| packageURI | String | L'package URI. |
| localName | String | Nom du local. |

### Valeur de retour

`true` si [has attribute NS] [the specified package URI] ; sinon, `false`.
