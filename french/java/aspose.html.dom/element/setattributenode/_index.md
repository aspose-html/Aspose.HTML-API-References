## Element.SetAttributeNode method

Ajoute un nouveau nœud d'attribut. Si un attribut portant ce nom (nodeName) est déjà présent dans l'élément, il est remplacé par le nouveau.

```java
public Attr SetAttributeNode(Attr newAttr)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| newAttr | Attr | Le nouvel attribut. |

### Valeur de retour

Renvoie l'attribut
