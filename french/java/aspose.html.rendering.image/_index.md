Le paquet **com.aspose.html.rendering.image** fournit une classe d'appareil spécifique ainsi que quelques classes d'options de rendu responsables du rendu vers des formats raster : jpeg, png, bmp, gif, tiff.

## Classes

| Classe | Description |
| --- | --- |
| [ImageDevice](./imagedevice/) | Représente le rendu vers les formats raster : jpeg, png, bmp, gif, tiff. |
| [ImageRenderingOptions](./imagerenderingoptions/) | Représente les options de rendu pour [`ImageDevice`](../com.aspose.html.rendering.image/imagedevice/). Cette option est utilisée pour spécifier le format de sortie de l'image, la compression, la résolution, etc. |
| [TextOptions](./textoptions/) | Représente les options de rendu de texte pour [`ImageDevice`](../com.aspose.html.rendering.image/imagedevice/). |
## Énumération

| Énumération | Description |
| --- | --- |
| [Compression](./compression/) | Spécifie les schémas de compression possibles pour les images bitmap au format Tagged Image File Format (TIFF). |
| [ImageFormat](./imageformat/) | Spécifie le format de fichier de l'image. |
