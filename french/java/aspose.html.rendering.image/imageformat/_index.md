## ImageFormat enumeration

Spécifie le format de fichier de l'image.

```java
public enum ImageFormat
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Jpeg | `1` | Le format d'image Joint Photographic Experts Group (JPEG). |
| Png | `2` | Le format d'image W3C Portable Network Graphics (PNG). |
| Bmp | `3` | Le format d'image bitmap (BMP). |
| Gif | `4` | Le format d'image Graphics Interchange Format (GIF). |
| Tiff | `5` | Le format d'image Tagged Image File Format (TIFF). |
| Webp | `6` | Le format Web Picture (WebP), un format d'image moderne qui offre une compression sans perte et avec perte supérieure pour les images sur le web. |
