## ImageRenderingOptions.VerticalResolution property

Définit ou obtient la résolution verticale pour les images de sortie et internes (utilisées lors du traitement des filtres), en pixels par pouce. Par défaut, cette propriété est de 300 dpi.

public Resolution VerticalResolution { get; set; }
