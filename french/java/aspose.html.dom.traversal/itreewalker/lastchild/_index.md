## ITreeWalker.LastChild method

Déplace le TreeWalker vers le dernier enfant visible du nœud actuel et renvoie le nouveau nœud. Si le nœud actuel n’a aucun enfant visible, renvoie null et conserve le nœud actuel.

```java
public Node LastChild()
```

### Valeur de retour

Le nouveau nœud, ou null si le nœud actuel n'a aucun enfant dans la vue logique du TreeWalker.
