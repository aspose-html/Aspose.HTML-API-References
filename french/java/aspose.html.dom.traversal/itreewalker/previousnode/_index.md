## ITreeWalker.PreviousNode method

Déplace le TreeWalker vers le nœud visible précédent dans l'ordre du document par rapport au nœud actuel, et renvoie le nouveau nœud. Si le nœud actuel n'a pas de nœud précédent, ou si la recherche de previousNode tente de remonter depuis le nœud racine du TreeWalker, renvoie null et conserve le nœud actuel.

```java
public Node PreviousNode()
```

### Valeur de retour

Le nouveau nœud, ou null si le nœud actuel n'a pas de nœud précédent dans la vue logique du TreeWalker.
