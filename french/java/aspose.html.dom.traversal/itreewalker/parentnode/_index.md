## ITreeWalker.ParentNode method

Se déplace et renvoie le nœud ancêtre visible le plus proche du nœud actuel. Si la recherche de parentNode tente de remonter depuis le nœud racine du TreeWalker, ou si elle ne trouve pas de nœud ancêtre visible, cette méthode conserve la position actuelle et renvoie null.

```java
public Node ParentNode()
```

### Valeur de retour

Le nouveau nœud parent, ou null si le nœud actuel n'a pas de parent dans la vue logique du TreeWalker.
