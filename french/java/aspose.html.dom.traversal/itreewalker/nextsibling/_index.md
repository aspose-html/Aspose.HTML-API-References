## ITreeWalker.NextSibling method

Déplace le TreeWalker vers le frère suivant du nœud actuel et renvoie le nouveau nœud. Si le nœud actuel n’a pas de frère suivant visible, renvoie null et conserve le nœud actuel.

```java
public Node NextSibling()
```

### Valeur de retour

Le nouveau nœud, ou null si le nœud actuel n'a pas de frère suivant dans la vue logique du TreeWalker.
