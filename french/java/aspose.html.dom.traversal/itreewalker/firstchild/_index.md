## ITreeWalker.FirstChild method

Déplace le TreeWalker vers le premier enfant visible du nœud actuel et renvoie le nouveau nœud. Si le nœud actuel n'a aucun enfant visible, renvoie null et conserve le nœud actuel.

```java
public Node FirstChild()
```

### Valeur de retour

Le nouveau nœud, ou null si le nœud actuel n'a aucun enfant visible dans la vue logique du TreeWalker.
