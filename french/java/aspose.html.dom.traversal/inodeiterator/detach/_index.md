## INodeIterator.Detach method

Détache le NodeIterator de l'ensemble qu'il a parcouru, libérant toutes les ressources computationnelles et plaçant l'itérateur dans l'état INVALID. Après l'appel de detach, les appels à nextNode ou previousNode lèveront l'exception INVALID_STATE_ERR.
