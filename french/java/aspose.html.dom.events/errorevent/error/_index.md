## ErrorEvent.Error property

L'attribut error doit renvoyer la valeur à laquelle il a été initialisé. Lors de la création de l'objet, cet attribut doit être initialisé à null. Le cas échéant, il est défini sur l'objet représentant l'erreur (par ex. l'objet exception dans le cas d'une exception DOM non interceptée).

```java
public object Error { get; }
```

### Property Value

L'erreur.
