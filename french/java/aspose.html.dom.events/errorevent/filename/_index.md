## ErrorEvent.FileName property

L'attribut filename doit renvoyer la valeur à laquelle il a été initialisé. Lors de la création de l'objet, cet attribut doit être initialisé à la chaîne vide. Il représente l'URL absolue du script dans lequel l'erreur s'est produite à l'origine.

```java
public String FileName { get; }
```

### Property Value

Le nom de fichier.
