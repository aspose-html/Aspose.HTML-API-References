## KeyboardEvent.DOM_KEY_LOCATION_NUMPAD field

L'activation de la touche provient du pavé numérique ou d'une touche virtuelle correspondant au pavé numérique (lorsqu'il existe plusieurs emplacements possibles pour cette touche). Notez que la touche NumLock doit toujours être codée avec un emplacement de DOM_KEY_LOCATION_STANDARD.

```java
public const ulong DOM_KEY_LOCATION_NUMPAD;
```
