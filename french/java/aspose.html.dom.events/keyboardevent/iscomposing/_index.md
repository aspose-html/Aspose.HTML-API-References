## KeyboardEvent.IsComposing property

true si l'événement de touche se produit dans le cadre d'une session de composition, c.-à-d. après un événement compositionstart et avant l'événement compositionend correspondant. La valeur non initialisée de cet attribut DOIT être false.

```java
public bool IsComposing { get; }
```

### Property Value

`true` si cette instance est en cours de composition ; sinon, `false`.
