## KeyboardEvent.Repeat property

true si la touche a été enfoncée de manière soutenue. Maintenir une touche enfoncée DOIT entraîner la répétition des événements keydown, beforeinput, input dans cet ordre, à une fréquence déterminée par la configuration du système. Pour les appareils mobiles qui ont un comportement de pression longue, le premier événement de touche avec une valeur d'attribut repeat égale à true DOIT servir d'indication d'une pression longue. La durée pendant laquelle la touche DOIT être enfoncée pour commencer à se répéter dépend de la configuration.

```java
public bool Repeat { get; }
```

### Property Value

`true` si repeat ; sinon, `false`.
