## KeyboardEvent.Code property

Le code contient une String qui identifie la touche physique en cours de pression. La valeur n'est pas affectée par la disposition actuelle du clavier ou l'état des modificateurs, ainsi une touche particulière renverra toujours la même valeur.

```java
public String Code { get; }
```

### Property Value

Le code de la touche.
