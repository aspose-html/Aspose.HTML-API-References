## IDocumentEvent interface

L'interface DocumentEvent fournit un mécanisme permettant à l'utilisateur de créer un Event d'un type pris en charge par l'implémentation. Il est prévu que l'interface DocumentEvent soit implémentée sur le même objet qui implémente l'interface Document dans une implémentation qui prend en charge le modèle d'événements.

```java
public interface IDocumentEvent
```

## Méthodes

| Nom | Description |
| --- | --- |
| [createEvent](../../com.aspose.html.dom.events/idocumentevent/createevent/)(String) | La méthode createEvent est utilisée pour créer des Events lorsqu'il est soit peu pratique, soit inutile que l'utilisateur crée lui-même un Event. |

## Remarques

Il est prévu que l'interface soit implémentée sur le même objet qui implémente l'interface dans une implémentation qui prend en charge le modèle d'événements.
