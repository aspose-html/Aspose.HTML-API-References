## Event.TimeStamp property

Utilisée pour spécifier le temps (en millisecondes relatif à l'époque) auquel l'événement a été créé. En raison du fait que certains systèmes peuvent ne pas fournir cette information, la valeur de timeStamp peut ne pas être disponible pour tous les événements. Lorsqu'elle n'est pas disponible, une valeur de 0 sera renvoyée. Des exemples de temps d'époque sont le moment du démarrage du système ou 0:0:0 UTC 1er janvier 1970.

```java
public ulong TimeStamp { get; }
```
