## InputEvent.Data property

Les données contiennent la valeur des caractères générés par une méthode d'entrée. Cela PEUT être un caractère Unicode unique ou une séquence non vide de caractères Unicode [Unicode]. Les caractères DOIVENT être normalisés selon la forme de normalisation Unicode NFC, définie dans [UAX15]. Cet attribut PEUT contenir la chaîne vide.

```java
public String Data { get; }
```

Les données de l'événement.
