## WheelEvent.DeltaZ property

Dans les agents utilisateurs où l'action par défaut de l'événement de roulette est de faire défiler, la valeur DOIT être la mesure le long de l'axe z (en pixels, lignes ou pages) à faire défiler dans le cas où l'événement n'est pas annulé. Sinon, il s'agit d'une mesure spécifique à l'implémentation (en pixels, lignes ou pages) du mouvement d'un dispositif de roulette autour de l'axe z.

```java
public double DeltaZ { get; }
```

### Property Value

L'attribut deltaZ.
