## PdfEncryptionInfo.UserPassword property

Obtient ou définit le mot de passe Utilisateur.

```java
public String UserPassword { get; set; }
```

### Property Value

Le mot de passe utilisateur.

## Remarques

L'ouverture du document avec le mot de passe utilisateur correct (ou l'ouverture d'un document qui ne possède pas de mot de passe utilisateur) permet d'effectuer des opérations supplémentaires conformément aux autorisations d'accès utilisateur spécifiées dans le dictionnaire de chiffrement du document.
