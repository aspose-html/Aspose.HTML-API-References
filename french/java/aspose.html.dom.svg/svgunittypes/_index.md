## SVGUnitTypes enumeration

L'énumération SVGUnitTypes définit un ensemble de constantes couramment utilisées et constitue une interface de base utilisée par SVGGradientElement, SVGPatternElement, SVGClipPathElement, SVGMaskElement et SVGFilterElement.

```java
public enum SVGUnitTypes
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| SVG_UNIT_TYPE_UNKNOWN | `0` | Le type ne fait pas partie des types prédéfinis. Il est invalide de tenter de définir une nouvelle valeur de ce type ou d'essayer de changer une valeur existante vers ce type. |
| SVG_UNIT_TYPE_USERSPACEONUSE | `1` | Correspond à la valeur 'userSpaceOnUse'. |
| SVG_UNIT_TYPE_OBJECTBOUNDINGBOX | `2` | Correspond à la valeur 'objectBoundingBox'. |
