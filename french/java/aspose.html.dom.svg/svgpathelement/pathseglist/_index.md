## SVGPathElement.PathSegList property

Fournit l'accès au contenu de base (c’est‑à‑dire statique) de l'attribut ‘d’ sous une forme qui correspond un à un à la syntaxe de SVG. Ainsi, si l'attribut ‘d’ possède une « moveto absolue (M) » et une « arcto absolue (A) », alors pathSegList contiendra deux entrées : un SVG_PATHSEG_MOVETO_ABS et un SVG_PATHSEG_ARC_ABS.

```java
public SVGPathSegList PathSegList { get; set; }
```

### Property Value

La liste de segments de chemin.
