## SVGPathElement.AnimatedPathSegList property

Fournit l'accès au contenu animé actuel de l'attribut ‘d’ sous une forme qui correspond un à un à la syntaxe de SVG. Si l'attribut ou la propriété donné(e) est animé(e), contient la valeur animée actuelle de l'attribut ou de la propriété, et l'objet lui‑même ainsi que son contenu sont en lecture seule. Si l'attribut ou la propriété donné(e) n'est pas actuellement animé(e), contient la même valeur que pathSegList.

```java
public SVGPathSegList AnimatedPathSegList { get; }
```

### Property Value

La liste de segments de chemin animée.
