## SVGViewElement.ViewTarget property

Correspond à l'attribut ‘viewTarget’ sur l'élément ‘view’ donné. Une liste de valeurs DOMString qui contiennent les noms répertoriés dans l'attribut ‘viewTarget’. Chaque valeur DOMString peut être associée à l'élément correspondant en utilisant l'appel de méthode getElementById().

```java
public SVGStringList ViewTarget { get; }
```

### Property Value

L'attribut ‘viewTarget’ de l'élément ‘view’ donné.
