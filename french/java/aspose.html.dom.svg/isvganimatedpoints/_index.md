## ISVGAnimatedPoints interface

L'interface SVGAnimatedPoints prend en charge les éléments qui possèdent un attribut ‘points’ contenant une liste de valeurs de coordonnées et qui permettent d'animer cet attribut. De plus, l'attribut ‘points’ sur l'élément original accédé via le DOM XML (par exemple, en utilisant l'appel de méthode getAttribute()) reflétera toute modification apportée aux points.

```java
public interface ISVGAnimatedPoints
```

| [getAnimatedPoints](../../com.aspose.html.dom.svg/isvganimatedpoints/animatedpoints/) Fournit l'accès au contenu animé actuel de l'attribut ‘points’.
