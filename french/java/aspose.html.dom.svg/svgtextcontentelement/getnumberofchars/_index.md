## SVGTextContentElement.GetNumberOfChars method

Renvoie le nombre total de caractères disponibles pour le rendu dans l'élément actuel, incluant les caractères référencés depuis la référence ‘tref’, qu'ils soient rendus ou non. En pratique, cela équivaut à la longueur de l'attribut Node::textContent du DOM Niveau 3 Core ([DOM3], section 1.4), si cet attribut a également développé les éléments ‘tref’.

```java
public long GetNumberOfChars()
```

### Valeur de retour

Nombre total de caractères.
