## SVGTextContentElement.LENGTHADJUST_UNKNOWN field

L'énumération a été définie sur une valeur qui n'est pas l'une des types prédéfinis. Il est invalide de tenter de définir une nouvelle valeur de ce type ou d'essayer de basculer une valeur existante vers ce type.

```java
public const ushort LENGTHADJUST_UNKNOWN;
```
