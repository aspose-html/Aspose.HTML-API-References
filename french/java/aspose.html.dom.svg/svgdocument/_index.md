## SVGDocument class

Un `SVGDocument` est la racine de la hiérarchie SVG et contient l'intégralité du contenu. En plus de fournir l'accès à la hiérarchie, il offre également quelques méthodes pratiques pour accéder à certains ensembles d'informations du document. Lorsqu'un élément ‘svg’ est intégré en ligne comme composant d'un document provenant d'un autre paquet, par exemple lorsqu'un élément ‘svg’ est intégré en ligne dans un document XHTML [XHTML], alors aucun objet `SVGDocument` n'existe ; à la place, l'objet racine dans la hiérarchie d'objets du document sera un objet Document d'un type différent, tel qu'un objet HTMLDocument. Cependant, un objet `SVGDocument` existera bien lorsque l'élément racine de la hiérarchie du document XML est un élément ‘svg’, comme lors de la visualisation d'un fichier SVG autonome (c’est‑à‑d. un fichier avec le type MIME "image/svg+xml"). Dans ce cas, l'objet `SVGDocument` sera l'objet racine du modèle d'objets du document.

public class SVGDocument : Document, IDocumentCSS
