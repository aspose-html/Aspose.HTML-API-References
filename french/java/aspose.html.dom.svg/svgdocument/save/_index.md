## Save(Url) {#save_3}

Enregistre le document dans le fichier local spécifié par `url`. Toutes les ressources utilisées dans ce document seront enregistrées dans un dossier adjacent, dont le nom sera construit ainsi : output_file_name + "_files".

```java
public void Save(Url url)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| url | Url | URL locale vers le fichier de sortie. |

### Exceptions

| exception | condition |
| --- | --- |
| ArgumentException | Levée si le `url` spécifié n'est pas une URL de fichier local valide. |
