## SVGDocument.Referrer property

Retourne l'URI de la page qui a lié à cette page. La valeur est une String vide si l'utilisateur a navigué directement vers la page (pas via un lien, mais, par exemple, via un signet).

```java
public String Referrer { get; }
```

Le référent.
