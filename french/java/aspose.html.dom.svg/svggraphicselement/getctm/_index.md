## SVGGraphicsElement.GetCTM method

Renvoie la matrice de transformation des unités utilisateur actuelles (c’est‑à‑dire, après application de l'attribut ‘transform’, le cas échéant) vers le système de coordonnées du viewport pour nearestViewportElement.

```java
public SVGMatrix GetCTM()
```

### Valeur de retour

Un objet SVGMatrix qui définit le CTM.
