## SVGSVGElement.GetCurrentTime method

Renvoie le temps actuel en secondes par rapport au temps de départ du fragment de document SVG en cours. Si getCurrentTime est appelé avant le début de la chronologie du document (par exemple, par un script s'exécutant dans un élément ‘script’ avant que l'événement SVGLoad du document ne soit déclenché), alors 0 est renvoyé.

```java
public float GetCurrentTime()
```

### Valeur de retour

Le temps actuel en secondes, ou 0 si la chronologie du document n'a pas encore commencé.
