## SVGSVGElement.CurrentTranslate property

Sur un élément svg le plus externe, le facteur de translation correspondant qui prend en compte la \"magnification\" de l'utilisateur. Lorsqu'il est accédé sur un élément ‘svg’ qui n'est pas le plus externe, le comportement de cet attribut est indéfini.

```java
public SVGPoint CurrentTranslate { get; }
```

### Property Value

La translation actuelle.
