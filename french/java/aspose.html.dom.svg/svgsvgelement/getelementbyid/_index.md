## SVGSVGElement.GetElementById method

Recherche dans ce fragment de document SVG (c.-à-d. la recherche est limitée à un sous-ensemble de l'arbre du document) un Élément dont l'id est fourni par elementId. Si un Élément est trouvé, cet Élément est renvoyé. Si aucun élément de ce type n'existe, renvoie null. Le comportement n'est pas défini si plusieurs éléments portent cet id.

```java
public Element GetElementById(String elementId)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| elementId | String | La valeur d'identifiant unique pour un élément. |

### Valeur de retour

L'élément correspondant.
