## SVGPolylineElement.AnimatedPoints property

Fournit l'accès au contenu animé actuel de l'attribut ‘points’. Si l'attribut ou la propriété donné(e) est animé(e), contient la valeur animée actuelle de l'attribut ou de la propriété. Si l'attribut ou la propriété donné(e) n'est pas actuellement animé(e), contient la même valeur que points.

```java
public SVGPointList AnimatedPoints { get; }
```

### Property Value

Les points animés.
