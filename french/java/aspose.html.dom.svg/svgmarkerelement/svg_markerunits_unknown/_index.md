## SVGMarkerElement.SVG_MARKERUNITS_UNKNOWN field

Le type d'unité du marqueur n'est pas l'un des types prédéfinis. Il est invalide de tenter de définir une nouvelle valeur de ce type ou d'essayer de changer une valeur existante vers ce type.

```java
public const ushort SVG_MARKERUNITS_UNKNOWN;
```
