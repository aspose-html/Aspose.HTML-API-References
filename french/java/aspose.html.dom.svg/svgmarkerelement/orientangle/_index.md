## SVGMarkerElement.OrientAngle property

Correspond à l'attribut ‘orient’ de l'élément ‘marker’ donné. Si markerUnits est SVG_MARKER_ORIENT_ANGLE, la valeur d'angle pour l'attribut ‘orient’; sinon, elle sera mise à zéro.

```java
public SVGAnimatedAngle OrientAngle { get; }
```

### Property Value

L'attribut ‘orient’ de l'élément ‘marker’ donné.
