## SVGGeometryElement.GetPointAtLength method

Renvoie la coordonnée (x,y) dans l'espace utilisateur qui correspond à des unités de distance le long du chemin, en utilisant l'algorithme distance‑le‑long‑du‑chemin de l'agent utilisateur.

```java
public SVGPoint GetPointAtLength(float distance)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| distance | Single | La distance le long du chemin, relative au début du chemin, exprimée en distance dans le système de coordonnées utilisateur actuel. |

### Valeur de retour

Le point retourné dans l'espace utilisateur.
