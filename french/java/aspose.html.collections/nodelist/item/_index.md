## NodeList indexer

La méthode renvoie l'élément d'indice donné dans la collection. Si l'indice est supérieur ou égal au nombre de nœuds dans la liste, cela renvoie null.

```java
public abstract Node this[int index] { get; }
```

| Paramètre | Description |
| --- | --- |
| index | L'index. |

### Valeur de retour

Renvoie le nœud.
