## NamedNodeMap class

Représente des collections d'attributs qui peuvent être accessibles par leur nom.

```java
public class NamedNodeMap : DOMObject
```

## Propriétés

| Nom | Description |
| --- | --- |
| [getItem](../../com.aspose.html.collections/namednodemap/item/) Retourne l'élément d'indice index dans la carte. Si l'indice est supérieur ou égal au nombre de nœuds dans cette carte, cela retourne null. (2 indexeurs) |
| [getLength](../../com.aspose.html.collections/namednodemap/length/) Le nombre de nœuds dans cette carte. |

## Méthodes

| Nom | Description |

| [getNamedItemNS](../../com.aspose.html.collections/namednodemap/getnameditemns/)(String, String) | Récupère un nœud spécifié par le nom local et l'URI du package. |
