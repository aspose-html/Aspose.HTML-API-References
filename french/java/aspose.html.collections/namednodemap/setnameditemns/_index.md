## NamedNodeMap.SetNamedItemNS method

Ajoute un nœud en utilisant son packageURI et son localName. Si un nœud avec cet URI de package et ce nom local est déjà présent dans cette carte, il est remplacé par le nouveau. Remplacer un nœud par lui‑même n'a aucun effet.
