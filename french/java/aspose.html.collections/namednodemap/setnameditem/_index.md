## NamedNodeMap.SetNamedItem method

Ajoute un nœud en utilisant son attribut nodeName. Si un nœud portant ce nom est déjà présent dans cette carte, il est remplacé par le nouveau. Remplacer un nœud par lui‑même n'a aucun effet.

public Attr SetNamedItem(Attr attr)
