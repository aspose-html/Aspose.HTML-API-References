Le package **com.aspose.html.collections** se compose de classes permettant de représenter, stocker et manipuler des nœuds et des éléments.

## Classes

| Classe | Description |
| --- | --- |
| [DOMTokenList](./domtokenlist/) | La classe DOMTokenList représente un ensemble de jetons séparés par des espaces. Elle est indexée à partir de 0 comme les objets Array de JavaScript. DOMTokenList est toujours sensible à la casse. |
| [HTMLCollection](./htmlcollection/) | Le [`HTMLCollection`](../com.aspose.html.collections/htmlcollection/) représente une collection générique de [`Element`](../com.aspose.html.dom/element/). |
| [NamedNodeMap](./namednodemap/) | Représente des collections d'attributs qui peuvent être accessibles par leur nom. |
| [NodeList](./nodelist/) | Le NodeList fournit l'abstraction d'une collection ordonnée de nœuds, sans définir ni contraindre la manière dont cette collection est implémentée. |
