## DOMTokenList class

La classe DOMTokenList représente un ensemble de jetons séparés par des espaces. Elle est indexée à partir de 0 comme les objets Array de JavaScript. DOMTokenList est toujours sensible à la casse.

```java
public class DOMTokenList : DOMObject, IEnumerable<String>
```
