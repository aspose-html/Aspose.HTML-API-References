## Toggle(String, bool) {#toggle_1}

Supprime le jeton de la liste s'il existe, ou ajoute le jeton à la liste s'il n'existe pas.

```java
public bool Toggle(String token, bool force)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| jeton | String | Le jeton que vous souhaitez basculer. |
| force | Boolean | Un booléen qui, s'il est inclus, transforme le basculement en une opération à sens unique. S'il est défini sur false, le jeton sera uniquement supprimé, mais pas ajouté. S'il est défini sur true, le jeton sera uniquement ajouté, mais pas supprimé. |

### Valeur de retour

Un booléen indiquant si le jeton est dans la liste après l'appel.
