## DOMTokenList.Replace method

Remplace un jeton existant par un nouveau jeton. Ne fait rien si le premier jeton n'existe pas.

```java
public bool Replace(String token, String newToken)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| jeton | String | Le jeton que vous souhaitez remplacer. |
| newToken | String | Le jeton avec lequel vous voulez remplacer l'ancien jeton. |

### Valeur de retour

Booléen `true` si le jeton a été trouvé et remplacé, `false` sinon.
