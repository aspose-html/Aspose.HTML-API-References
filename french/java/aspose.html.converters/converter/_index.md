## Converter class

Facade partagée uniquement pour les scénarios de conversion les plus fréquents. Elle offre une large gamme de conversions vers les formats populaires, tels que PDF, XPS, formats d'image, etc. Des cas d'utilisation plus spécifiques de conversion (rendu, enregistrement) sont présentés par des fonctions API de bas niveau bien connues et documentées.
