## IColorComponents.ToString method

Convertit les composants de couleur en représentation sous forme de chaîne.

```java
public String ToString(bool includeAlpha, bool asDecimal, int digits)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| includeAlpha | Boolean | Spécifie si le composant Alpha doit être ajouté. |
| asDecimal | Boolean | Spécifie si les composants de couleur sont conservés sous forme de nombre décimal ou en pourcentage. |
| digits | Int32 | Définit la précision d'arrondi pour les composants de couleur. |

### Valeur de retour

Représentation String des composants de couleur.
