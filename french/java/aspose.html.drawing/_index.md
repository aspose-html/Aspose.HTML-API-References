Le paquet **com.aspose.html.drawing** contient des objets et des interfaces pour spécifier les mesures et les unités ainsi que des objets d'attributs de dessin tels que les pinceaux, les couleurs et les polices.

## Classes

| Classe | Description |
| --- | --- |
| [Angle](./angle/) | Le type de données angle |
| [Color](./color/) | La classe Color vous permet de spécifier les couleurs sous forme de valeurs Rouge-Vert-Bleu (RGB), de valeurs Teinte-Saturation-Luminosité (HSL), de valeurs Teinte-Saturation-Valeur (HSV), de valeurs Teinte-Blancheur-Noirceur (HWB), de valeurs clarté-A-B (LAB), de valeurs Luminance-Chroma-Teinte (LCH), de valeurs Cyan-Magenta-Jaune-Clé (CMYK), de valeurs Couleurs naturelles (NCOL), ou avec un nom de couleur. Un canal Alpha est également disponible pour indiquer la transparence. |
| [Dimension](./dimension/) | Fournit la classe de base pour les dimensions. Le terme général « dimension » désigne un nombre auquel est associée une unité, et elles sont indiquées par [`UnitType`](../com.aspose.html.drawing/unittype/). |
| [Frequency](./frequency/) | L'unité « fréquence ». |
| [Length](./length/) | Représente une unité de mesure de longueur. |
| [LengthOrAuto](./lengthorauto/) | Représente un conteneur pour la longueur de stockage ou les unités « auto ». |
| [Margin](./margin/) | Représente la marge de page. |
| [Numeric](./numeric/) | Fournit la classe de base pour les types numériques. |
| [Page](./page/) | Représente un objet page utilisé pour la configuration de la page de sortie. La valeur lacunaire pour la taille de la page est A4 (210 x 297 mm). |
| [Resolution](./resolution/) | Représente une unité de résolution. |
| [Size](./size/) | Stocke des valeurs qui spécifient une hauteur et une largeur. |
| [Time](./time/) | Représente une unité de temps. |
| [Unit](./unit/) | Fournit la classe de base pour les unités de mesure. |
| [UnitType](./unittype/) | Spécifie l'unité de mesure. |
## Interfaces

| Interface | Description |
| --- | --- |
| [IBrush](./ibrush/) | Déclare la méthode d'obtention du type de pinceau. |
| [IColorComponents](./icolorcomponents/) | Déclare la méthode et les propriétés pour le traitement des composants de couleur. |
| [IDrawingFactory](./idrawingfactory/) | Représente une fabrique pour créer des objets liés au dessin. |
| [IGradientBrush](./igradientbrush/) | Déclare les méthodes d'obtention des propriétés communes des pinceaux dégradés. |
| [IInterpolationColor](./iinterpolationcolor/) | Déclare des méthodes pour obtenir la couleur d’interpolation. |
| [ILinearGradientBrush](./ilineargradientbrush/) | Définit l'interface du pinceau avec un dégradé linéaire. |
| [IMatrix](./imatrix/) | Représente une matrice utilisée pour les transformations. |
| [ISolidBrush](./isolidbrush/) | Définit l'interface du pinceau d'une couleur unique. |
| [ITextureBrush](./itexturebrush/) | Définit l'interface du pinceau qui utilise une image pour remplir l'intérieur d'une forme. |
| [ITransformableBrush](./itransformablebrush/) | Déclare des méthodes pour obtenir la matrice de transformation et le mode d'enroulement. |
| [ITrueTypeFont](./itruetypefont/) | Déclare des méthodes pour travailler avec la police TrueType. |
