## FromRgb(byte, byte, byte) {#fromrgb}

Renvoie un nouveau Color avec les valeurs de ged, vert et bleu demandées. Tous les composants de couleur doivent être compris entre 0 et 255.

```java
public static Color FromRgb(byte red, byte green, byte blue)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| rouge | Byte | Un octet qui représente le composant rouge de la couleur. |
| vert | Byte | Un octet qui représente le composant vert de la couleur. |
| bleu | Byte | Un octet qui représente le composant bleu de la couleur. |

### Valeur de retour

Une nouvelle instance de la classe [`Color`](../)
