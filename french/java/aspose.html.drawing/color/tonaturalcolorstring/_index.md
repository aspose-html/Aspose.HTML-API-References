## Color.ToNaturalColorString method

Renvoie une couleur naturelle (NCol) spécifiée en utilisant une lettre de couleur avec un nombre pour indiquer la distance (en pourcentage) par rapport à la couleur.

```java
public String ToNaturalColorString(int digits)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| digits | Int32 | Définit la précision d'arrondi pour les composants de couleur. |

### Valeur de retour

Une chaîne de couleurs naturelles (NCol)
