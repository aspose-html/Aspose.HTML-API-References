## IDrawingFactory.CreateInterpolationColor method

Crée une couleur d'interpolation avec la couleur et la position spécifiées.

```java
public IInterpolationColor CreateInterpolationColor(Color color, float position)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| couleur | Color | Représente la couleur qui sera utilisée à la position correspondante du dégradé. |
| position | Single | La position, représentée en pourcentage de 0 à 1, à laquelle la couleur du dégradé correspondante sera utilisée. |

### Valeur de retour

Le [`IInterpolationColor`](../../iinterpolationcolor/) créé.
