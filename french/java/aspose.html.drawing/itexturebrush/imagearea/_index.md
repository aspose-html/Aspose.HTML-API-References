## ITextureBrush.ImageArea property

Spécifie la portion de l'image utilisée par le pinceau. Si elle est égale à RectangleF.Empty, alors l'image entière sera utilisée. Les coordonnées sont en pixels.

```java
public RectangleF ImageArea { get; }
```

### Valeur de retour

Zone d'image
