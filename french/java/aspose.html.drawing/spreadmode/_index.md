## SpreadMode enumeration

Spécifie comment une texture ou un dégradé est répété lorsqu'il est plus petit que la zone à remplir.

```java
public enum SpreadMode
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Tile | `0` | La texture ou le dégradé est répété. |
| TileFlipX | `1` | La texture ou le dégradé est répété et retourné horizontalement. |
| TileFlipY | `2` | La texture ou le dégradé est répété et retourné verticalement. |
| TileFlipXY | `3` | La texture ou le dégradé est répété et retourné à la fois horizontalement et verticalement. |
| Clamp | `4` | La texture ou le dégradé est limité au bord. |
