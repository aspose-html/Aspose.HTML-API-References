## ITrueTypeFont.SubFamilyName property

Le nom de sous-famille de police distingue la police dans un groupe portant le même nom de famille de police. Cela est censé couvrir le style (italique, oblique) et le poids (léger, gras, noir, etc.). Une police sans différences particulières de poids ou de style (par exemple poids moyen, non italique et le bit 6 de fsSelection activé) doit avoir la chaîne \"Regular\" stockée à cet emplacement.

```java
public String SubFamilyName { get; }
```

### Valeur de retour

Nom de sous-famille de police
