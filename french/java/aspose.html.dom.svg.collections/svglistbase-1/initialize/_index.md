## SVGListBase&lt;T&gt;.Initialize method

Efface tous les éléments actuels existants de la liste et réinitialise la liste pour contenir le seul élément spécifié par le paramètre.

```java
public T Initialize(T newItem)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| newItem | T | L'élément qui doit devenir le seul membre de la liste. |

### Valeur de retour

L'élément en cours d'insertion dans la liste.
