Le package **com.aspose.html.accessibility.results** contient des classes qui décrivent les résultats de la validation des règles.

## Classes

| Classe | Description |
| --- | --- |
| [RuleValidationResult](./rulevalidationresult/) | Classe – résultat de la vérification d'une règle, contient une liste de [`ITechniqueResult`](../com.aspose.html.accessibility/itechniqueresult/), qui sont des moyens de satisfaire les critères de réussite. |
| [ValidationResult](./validationresult/) | La classe principale de résultat, qui contient les Résultats pour tous les critères de l'objet AccessibilityRules. |
