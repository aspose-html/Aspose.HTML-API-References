## PageSetup.AdjustToWidestPage property

Obtient ou définit le drapeau qui détermine le cas où la taille de la page sera ajustée à la page la plus large du document. Cette option est gourmande en temps, de sorte que le temps de traitement du document peut être doublé. L'ajustement ne se produira que si la page la plus large du document est plus large que la taille de page déterminée dans [`PageSetup`](../). La taille de page ajustée sera utilisée pour toutes les pages du document.

```java
public bool AdjustToWidestPage { get; set; }
```
