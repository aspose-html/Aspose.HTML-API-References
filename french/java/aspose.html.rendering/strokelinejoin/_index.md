## StrokeLineJoin enumeration

Spécifie le style de jointure de ligne utilisé lors du rendu SVG et HTML.

```java
public enum StrokeLineJoin
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Miter | `0` | Les jointures de ligne sont pointues, s'étendant au-delà des extrémités. |
| Round | `1` | Les jointures de ligne sont arrondies. |
| Bevel | `2` | Les jointures de ligne sont biseautées. |
