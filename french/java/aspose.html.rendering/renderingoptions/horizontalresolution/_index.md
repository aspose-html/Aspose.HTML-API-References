## RenderingOptions.HorizontalResolution property

Définit ou obtient la résolution horizontale pour les images internes (utilisées lors du traitement des filtres), en pixels par pouce. Par défaut, cette propriété est de 300 dpi.

public Resolution HorizontalResolution { get; set; }
