## AtPagePriority enumeration

Spécifie les ordres possibles d'application des déclarations de taille de page.

```java
public enum AtPagePriority
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| OptionsPriority | `0` | Spécifie que les valeurs de [`PageSetup`](../pagesetup/) déclarées dans [`RenderingOptions`](../renderingoptions/) remplaceront les valeurs définies dans le CSS par les règles `@page`. |
| CssPriority | `1` | Spécifie que les règles `@page` définies dans le CSS remplaceront les valeurs définies dans [`PageSetup`](../pagesetup/). |
