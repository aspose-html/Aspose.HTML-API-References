Le paquet **com.aspose.html.rendering** se compose de nombreux objets de rendu ainsi que de classes d'options de bas niveau appropriées, responsables du rendu de documents/fichiers vers une implémentation IDevice.

## Classes

| Classe | Description |
| --- | --- |
| [CssOptions](./cssoptions/) | Représente les options de rendu CSS. |
| [Device](./device/) | Représente une classe de base pour implémenter des appareils de rendu utilisés pour dessiner des graphiques dans divers formats et environnements. |
| [Device&lt;TGraphicContext,TRenderingOptions&gt;](./device-2/) | Représente la classe de base pour l'implémentation d'appareils de rendu particuliers. |
| [EpubRenderer](./epubrenderer/) | Représente un moteur de rendu de document EPub. |
| [GraphicContext](./graphiccontext/) | Contient les paramètres de contrôle graphique actuels. Ces paramètres définissent le cadre global dans lequel les opérateurs graphiques s'exécutent. |
| [HtmlRenderer](./htmlrenderer/) | Représente un moteur de rendu de document HTML. |
| [MhtmlRenderer](./mhtmlrenderer/) | Représente un moteur de rendu de document MHTML. |
| [PageSetup](./pagesetup/) | Représente un objet de configuration de page utilisé pour configurer la sortie du jeu de pages. |
| [Renderer](./renderer/) | Représente une classe de base pour tous les moteurs de rendu et implémente l'interface IDisposable. |
| [Renderer&lt;TSource&gt;](./renderer-1/) | Représente une classe abstraite pour tous les moteurs de rendu. |
| [RenderingOptions](./renderingoptions/) | Représente les options de rendu. |
| [SvgRenderer](./svgrenderer/) | Représente un moteur de rendu de document SVG. |
| [TextInfo](./textinfo/) | Contient des informations sur le texte rendu. |
## Structures

| Structure | Description |
| --- | --- |
| [GlyphInfo](./glyphinfo/) | Contient des informations liées aux glyphes. |
## Interfaces

| Interface | Description |
| --- | --- |
| [IDevice](./idevice/) | Définit les méthodes et propriétés qui prennent en charge le rendu personnalisé des éléments graphiques tels que les chemins, le texte et les images. |
## Énumération

| Énumération | Description |
| --- | --- |
| [AtPagePriority](./atpagepriority/) | Spécifie les ordres possibles d'application des déclarations de taille de page. |
| [FillRule](./fillrule/) | Spécifie la règle de remplissage utilisée lors du rendu SVG et HTML. |
| [MediaType](./mediatype/) | Spécifie les types de médias possibles utilisés pendant le rendu. |
| [PageLayoutOptions](./pagelayoutoptions/) | Spécifie les indicateurs qui, avec d'autres options PageSetup, déterminent les tailles et la disposition des pages. Ces indicateurs peuvent être combinés selon leurs descriptions. |
| [StrokeLineCap](./strokelinecap/) | Spécifie le style d'extrémité de ligne utilisé lors du rendu SVG et HTML. |
| [StrokeLineJoin](./strokelinejoin/) | Spécifie le style de jointure de ligne utilisé lors du rendu SVG et HTML. |
