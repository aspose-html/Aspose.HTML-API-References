## Device&lt;TGraphicContext,TRenderingOptions&gt;.Fill method

Remplit toute la région délimitée par le chemin actuel. Si le chemin se compose de plusieurs sous‑chemins déconnectés, il remplit l’intérieur de tous les sous‑chemins, considérés ensemble. Cette méthode termine le chemin actuel.

```java
public void Fill(FillRule rule)
```

| --- | --- | --- |
| règle | FillRule | La règle de remplissage indique comment l'intérieur d'un chemin fermé est rempli |
