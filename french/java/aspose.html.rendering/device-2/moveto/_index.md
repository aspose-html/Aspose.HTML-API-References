## Device&lt;TGraphicContext,TRenderingOptions&gt;.MoveTo method

Commence un nouveau sous‑chemin en déplaçant le point actuel aux coordonnées du paramètre pt, en omettant tout segment de ligne de connexion. Si la méthode de construction de chemin précédente dans le chemin actuel était également \"MoveTo\", le nouveau \"MoveTo\" la remplace ; aucune trace de l’opération \"MoveTo\" précédente ne subsiste dans le chemin.

```java
public void MoveTo(PointF pt)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| pt | PointF | Point vers lequel déplacer le chemin. |
