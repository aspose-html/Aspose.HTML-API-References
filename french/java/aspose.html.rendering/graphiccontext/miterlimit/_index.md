## GraphicContext.MiterLimit property

Définit ou obtient la longueur maximale des jointures en onglet pour les chemins tracés. Ce paramètre limite la longueur des \"spikes\" produites lorsque des segments de ligne se rejoignent à des angles aigus.

```java
public float MiterLimit { get; set; }
```
