## FillRule enumeration

Spécifie la règle de remplissage utilisée lors du rendu SVG et HTML.

```java
public enum FillRule
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| EvenOdd | `0` | Détermine la zone de remplissage en utilisant la règle pair-impair. Le comportement correspond à System.Drawing.Drawing2D.FillMode.Alternate. |
| Nonzero | `1` | Détermine la zone de remplissage en utilisant la règle non nulle. Le comportement correspond à System.Drawing.Drawing2D.FillMode.Winding. |
