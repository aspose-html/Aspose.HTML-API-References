## TemplateLoadOptions.NamesAreCaseSensitive property

Propriété qui spécifie si les noms des modèles et des éléments de données seront comparés sans tenir compte de la casse ou non. Si vrai, la correspondance est sensible à la casse ; si faux, la casse sera ignorée. La valeur par défaut est true.

```java
public bool NamesAreCaseSensitive { get; set; }
```
