## Location class

Les objets Location fournissent une représentation de l'adresse du document actif de leur contexte de navigation du Document, et permettent de modifier l'entrée actuelle de l'historique de session du contexte de navigation, en ajoutant ou en remplaçant des entrées dans l'objet historique.

```java
public sealed class Location : DOMObject
```
