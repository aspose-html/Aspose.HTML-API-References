## IWindow.Prompt method

Affiche une boîte de dialogue modale avec un champ texte et le message fourni, attend que l'utilisateur la ferme, et renvoie la valeur saisie par l'utilisateur. Si l'utilisateur annule la boîte de dialogue, elle renvoie null. Si le deuxième argument est présent, la valeur fournie est utilisée comme valeur par défaut.

```java
public String Prompt(String message, String @default)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| message | String | Le message. |
| par défaut | String | La valeur par défaut. |

### Valeur de retour

Renvoie la valeur saisie par l'utilisateur
