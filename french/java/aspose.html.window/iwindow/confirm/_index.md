## IWindow.Confirm method

Affiche une boîte de dialogue modale OK/Annuler avec le message fourni, attend que l'utilisateur la ferme, et renvoie true si l'utilisateur clique sur OK et false s'il clique sur Annuler.

```java
public bool Confirm(String message)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| message | String | Le message. |

### Valeur de retour

Renvoie true si l'utilisateur clique sur OK et false s'il clique sur Annuler
