Le paquet représente la fonctionnalité de filtrage de nœuds. Les filtres sont des objets qui savent comment "filtrer" les nœuds. Si un itérateur de nœuds ou un parcours d'arbre reçoit un filtre de nœuds, il applique le filtre avant de renvoyer le nœud suivant. Si le filtre indique d'accepter le nœud, la logique de traversée le renvoie ; sinon, la traversée recherche le nœud suivant et fait comme si le nœud rejeté n'existait pas.
