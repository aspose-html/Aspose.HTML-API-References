## NodeFilter.SHOW_NOTATION field

Afficher les nœuds Notation. Cela n'a de sens que lors de la création d'un itérateur ou d'un tree-walker avec un nœud Notation comme racine ; dans ce cas, cela signifie que le nœud Notation apparaîtra en première position du parcours. Comme les notations ne font pas partie de l'arbre du document, elles n'apparaissent pas lors du parcours de l'arbre du document.

```java
public const long SHOW_NOTATION;
```
