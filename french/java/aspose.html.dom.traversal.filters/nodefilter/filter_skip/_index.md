## NodeFilter.FILTER_SKIP field

Ignorer ce nœud unique. Les méthodes de navigation définies pour NodeIterator ou TreeWalker ne renverront pas ce nœud. Pour les deux, NodeIterator et TreeWalker, les enfants de ce nœud seront toujours pris en compte.

```java
public const short FILTER_SKIP;
```
