Le package **com.aspose.html.dom.mutations** offre la possibilité d'observer les mutations du DOM et d'obtenir des informations de rappel spécifiques.

## Classes

| Classe | Description |
| --- | --- |
| [MutationCallback](./mutationcallback/) | Représente la méthode qui gérera les événements de mutation. |
| [MutationObserver](./mutationobserver/) | Un objet peut être utilisé pour observer les mutations de l'arbre de [`.`](../com.aspose.html.dom/node/) |
| [MutationObserverInit](./mutationobserverinit/) | Cette classe représente une collection d'options qui est utilisée pour configurer [`MutationObserver`](../com.aspose.html.dom.mutations/mutationobserver/). |
| [MutationRecord](./mutationrecord/) | Un MutationRecord représente une mutation DOM individuelle. C'est l'objet qui est transmis à la [`MutationCallback`](../com.aspose.html.dom.mutations/mutationcallback/) de [`MutationObserver`](../com.aspose.html.dom.mutations/mutationobserver/). |
