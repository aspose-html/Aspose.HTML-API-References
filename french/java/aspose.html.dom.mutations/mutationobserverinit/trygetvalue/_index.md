## MutationObserverInit.TryGetValue method

Obtient la valeur associée à la clé spécifiée.

```java

```

| Paramètre | Type | Description |
| --- | --- | --- |
| key | String | La clé de la valeur à obtenir. |
| valeur | Object& | Lorsque cette méthode retourne, elle contient la valeur associée à la clé spécifiée, si la clé est trouvée ; sinon null. |

### Valeur de retour
