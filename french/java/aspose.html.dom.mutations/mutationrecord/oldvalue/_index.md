## MutationRecord.OldValue property

La valeur de retour dépend du type. Pour "attributes", c’est la valeur de l’attribut modifié avant le changement. Pour "characterData", c’est les données du nœud modifié avant le changement. Pour "childList", c’est null.

```java
public String OldValue { get; }
```

### Property Value

L'ancienne valeur.
