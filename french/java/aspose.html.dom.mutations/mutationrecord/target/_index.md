## MutationRecord.Target property

Retourne le nœud affecté par la mutation, selon le type. Pour "attributes", il s'agit de l'élément dont l'attribut a changé. Pour "characterData", il s'agit du nœud CharacterData. Pour "childList", il s'agit du nœud dont les enfants ont changé.

```java
public Node Target { get; }
```

La cible.
