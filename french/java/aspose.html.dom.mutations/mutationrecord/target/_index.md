## MutationRecord.Target property

Renvoie le nœud affecté par la mutation, selon le type. Pour "attributes", c'est l'élément dont l'attribut a changé. Pour "characterData", c'est le nœud CharacterData. Pour "childList", c'est le nœud dont les enfants ont changé.

```java
public Node Target { get; }
```

### Property Value

La cible.
