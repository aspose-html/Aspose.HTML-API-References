## MutationObserver constructor

Construit un objet MutationObserver et définit son [`MutationCallback`](../../mutationcallback/) sur callback. Le callback est invoqué avec une liste d'objets MutationRecord comme premier argument et l'objet MutationObserver construit comme second argument. Il est invoqué après que les nœuds enregistrés avec la méthode !:Observe(Node, IMutationObserverInit) ont été mutés.
