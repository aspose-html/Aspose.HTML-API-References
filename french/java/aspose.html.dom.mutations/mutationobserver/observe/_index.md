## Observe(Node) {#observe}

Ordonne à l'agent utilisateur d'observer une cible donnée (un nœud) et de signaler toute mutation selon les critères fournis par les options (un objet). L'argument options permet de définir les options d'observation des mutations via les membres de l'objet.

```java
public void Observe(Node target)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| cible | Node | La cible pour observe. |
