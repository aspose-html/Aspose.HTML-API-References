## ResourceHandler class

Cette classe est responsable de la gestion des ressources. Elle fournit des méthodes qui vous permettent de contrôler ce qui sera fait avec le [`Resource`](../../com.aspose.html.saving/resource/), ainsi que la référence qui sera écrite dans la ressource parent [`Resource`](../../com.aspose.html.saving/resource/).

```java
public abstract class ResourceHandler
```

| Nom | Description |
| --- | --- |
| abstract [HandleResource](../../com.aspose.html.saving.resourcehandlers/resourcehandler/handleresource/)(Resource, ResourceHandlingContext) | Cette méthode est responsable du traitement de la ressource. Vous pouvez y enregistrer le [`Resource`](../../com.aspose.html.saving/resource/) dans le flux ou l’intégrer à la ressource parent. |
| [handleResourceReference](../../com.aspose.html.saving.resourcehandlers/resourcehandler/handleresourcereference/)(Resource, ResourceHandlingContext) | Cette méthode est responsable du traitement de la référence de la ressource. Dans cette méthode, vous pouvez définir à quoi ressemblera la référence à la ressource traitée. |
