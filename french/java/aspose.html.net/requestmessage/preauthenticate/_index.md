## RequestMessage.PreAuthenticate property

Obtient ou définit une valeur qui indique s'il faut envoyer un en-tête Authorization avec la requête.

```java
public bool PreAuthenticate { get; set; }
```

### Property Value

`true` pour envoyer un en-tête HTTP Authorization avec les requêtes après que l'authentification a eu lieu ; sinon, `false`. La valeur par défaut est `false`.
