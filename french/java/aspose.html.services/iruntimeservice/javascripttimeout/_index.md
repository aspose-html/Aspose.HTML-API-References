## IRuntimeService.JavaScriptTimeout property

Obtient ou définit le TimeSpan qui limite le temps d'exécution JavaScript. Si le script s'exécute plus longtemps que le TimeSpan fourni, il sera annulé. Vous pouvez spécifier un délai d'attente infini en définissant le TimeSpan à -1 milliseconde. La valeur par défaut est de 1 minute.

```java
public TimeSpan JavaScriptTimeout { get; set; }
```
