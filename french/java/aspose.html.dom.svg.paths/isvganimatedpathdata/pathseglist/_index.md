## ISVGAnimatedPathData.PathSegList property

Fournit l'accès au contenu de base (c’est‑à‑dire statique) de l'attribut ‘d’ sous une forme qui correspond un à un à la syntaxe SVG. Ainsi, si l'attribut ‘d’ possède un « déplacement absolu (M) » et un « arc absolu (A) », alors pathSegList contiendra deux entrées : un SVG_PATHSEG_MOVETO_ABS et un SVG_PATHSEG_ARC_ABS.

```java
public SVGPathSegList PathSegList { get; }
```

### Property Value

La liste de segments de chemin.
