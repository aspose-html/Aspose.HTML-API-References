## SVGPathSeg.PATHSEG_UNKNOWN field

Le type d'unité n'est pas l'un des types prédéfinis. Il est invalide de tenter de définir une nouvelle valeur de ce type ou d'essayer de basculer une valeur existante vers ce type.

```java
public const ushort PATHSEG_UNKNOWN;
```
