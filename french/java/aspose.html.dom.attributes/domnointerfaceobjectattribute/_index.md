## DOMNoInterfaceObjectAttribute class

Si l'attribut étendu [NoInterfaceObject] apparaît sur une interface, cela indique qu'aucun objet d'interface n'existera pour l'interface dans la liaison ECMAScript.

```java
[AttributeUsage(AttributeTargets.All)]
public sealed class DOMNoInterfaceObjectAttribute : Attribute
```
