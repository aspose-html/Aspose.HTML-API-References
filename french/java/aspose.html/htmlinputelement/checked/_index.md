## HTMLInputElement.Checked property

Lorsque l'attribut `type` de l'élément a la valeur "radio" ou "checkbox", cela représente l'état actuel du contrôle de formulaire, dans un agent utilisateur interactif. Les modifications de cet attribut changent l'état du contrôle de formulaire, mais ne modifient pas la valeur de l'attribut HTML checked de l'élément INPUT. Lors du traitement d'un événement click sur un élément input dont l'attribut type a la valeur "radio" ou "checkbox", certaines implémentations peuvent modifier la valeur de cette propriété avant que l'événement ne soit diffusé dans le document. Si l'action par défaut de l'événement est annulée, la valeur de la propriété peut être restaurée à sa valeur originale. Cela signifie que la valeur de cette propriété pendant le traitement des événements click dépend de l'implémentation.

```java
public bool Checked { get; set; }
```
