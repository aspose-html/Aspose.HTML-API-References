## HTMLInputElement.List property

L'attribut list est utilisé pour identifier un élément qui répertorie des options prédéfinies suggérées à l'utilisateur. S'il est présent, sa valeur doit être l'ID d'un élément datalist dans le même document.

public String List { get; set; }
