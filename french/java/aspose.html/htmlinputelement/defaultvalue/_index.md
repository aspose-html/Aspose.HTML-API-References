## HTMLInputElement.DefaultValue property

Lorsque l'attribut `type` de l'élément a la valeur "text", "file" ou "password", cela représente l'attribut HTML value de l'élément. La valeur de cet attribut ne change pas si le contenu du contrôle de formulaire correspondant, dans un agent utilisateur interactif, change. Voir la définition de l'attribut value dans HTML 4.01.

```java
public String DefaultValue { get; set; }
```
