## HTMLInputElement.Src property

Lorsque l'attribut `type` a la valeur \"image\", cet attribut spécifie l'emplacement de l'image à utiliser pour décorer le bouton de soumission graphique. Voir la définition de l'attribut src dans HTML 4.01.

public String Src { get; set; }
