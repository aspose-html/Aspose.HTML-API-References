## HTMLInputElement.Value property

Lorsque l’attribut `type` de l’élément a la valeur \"text\", \"file\" ou \"password\", cela représente le contenu actuel du contrôle de formulaire correspondant, dans un agent utilisateur interactif. Modifier cet attribut modifie le contenu du contrôle de formulaire, mais ne modifie pas la valeur de l’attribut HTML value de l’élément. Lorsque l’attribut `type` de l’élément a la valeur \"button\", \"hidden\", \"submit\", \"reset\", \"image\", \"checkbox\" ou \"radio\", cela représente l’attribut HTML value de l’élément. Voir la définition de l’attribut value dans HTML 4.01.

```java
public String Value { get; set; }
```
