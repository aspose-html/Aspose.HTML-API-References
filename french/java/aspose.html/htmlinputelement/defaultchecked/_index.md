## HTMLInputElement.DefaultChecked property

Lorsque le `type` a la valeur \"radio\" ou \"checkbox\", cela représente l’attribut HTML checked de l’élément. La valeur de cet attribut ne change pas si l’état du contrôle de formulaire correspondant, dans un agent utilisateur interactif, change. Voir la définition de l’attribut checked dans HTML 4.01.

```java
public bool DefaultChecked { get; set; }
```
