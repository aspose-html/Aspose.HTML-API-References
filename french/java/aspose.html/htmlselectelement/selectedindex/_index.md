## HTMLSelectElement.SelectedIndex property

L’indice ordinal de l’option sélectionnée, à partir de 0. La valeur -1 est renvoyée si aucun élément n’est sélectionné. Si plusieurs options sont sélectionnées, l’indice de la première option sélectionnée est renvoyé.

public int SelectedIndex { get; set; }
