## HTMLDocument.Images property

Une collection de tous les éléments `IMG` dans un document. Le comportement est limité aux éléments `IMG` pour des raisons de compatibilité descendante. Comme le suggère [[HTML 4.01](http://www.w3.org/TR/1999/REC-html401-19991224)], pour inclure des images, les auteurs peuvent utiliser l’élément `OBJECT` ou l’élément `IMG`. Ainsi, il est recommandé de ne pas utiliser cet attribut pour rechercher les images dans le document, mais d’utiliser `getElementsByTagName` avec HTML 4.01 ou `getElementsByTagNameNS` avec XHTML 1.0.

```java
public HTMLCollection Images { get; }
```
