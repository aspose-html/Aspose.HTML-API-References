## HTMLDocument.Anchors property

Une collection de tous les éléments d'ancre (`A`) dans un document avec une valeur pour l'attribut `name`. Pour des raisons de compatibilité descendante, l'ensemble d'ancres retourné ne contient que les ancres créées avec l'attribut `name`, pas celles créées avec l'attribut `id`. Notez que dans [[XHTML 1.0](http://www.w3.org/TR/2002/REC-xhtml1-20020801)], l'attribut `name` (voir section 4.10) n'a aucune sémantique et n'est présent que pour les agents utilisateurs hérités : l'attribut `id` est utilisé à la place. Les utilisateurs devraient préférer les mécanismes d'itération fournis par [[DOM Level 2 Traversal](http://www.w3.org/TR/2000/REC-DOM-Level-2-Traversal-Range-20001113)].

public HTMLCollection Anchors { get; }
