## HTMLDocument.Referrer property

Retourne l’URI [[IETF RFC 2396](http://www.ietf.org/rfc/rfc2396.txt)] de la page qui a lié à cette page. La valeur est une chaîne vide si l’utilisateur a navigué directement vers la page (pas via un lien, mais, par exemple, via un signet).

```java
public String Referrer { get; }
```
