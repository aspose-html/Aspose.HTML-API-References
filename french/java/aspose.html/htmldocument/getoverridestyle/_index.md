## HTMLDocument.GetOverrideStyle method

Cette méthode est utilisée pour récupérer la déclaration de style de substitution pour un élément spécifié et un pseudo‑élément spécifié.

```java
public ICSSStyleDeclaration GetOverrideStyle(Element elt, String pseudoElt)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| elt | Élément | L'élément dont le style doit être modifié. Ce paramètre ne peut pas être null. |
| pseudoElt | String | Le pseudo-élément ou null si aucun. |

### Valeur de retour

La déclaration de style de substitution
