## IUrlSearchParams.Set method

Définit la valeur de la première paire nom-valeur trouvée à la valeur spécifiée et supprime les autres. Si aucune paire nom-valeur avec le nom spécifié n'est trouvée, une nouvelle sera ajoutée à la liste.

```java
public void Set(String name, String value)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| nom | String | Clé qui sera utilisée pour trouver les paires nom-valeur. |
| valeur | String | Valeur qui sera définie. |
