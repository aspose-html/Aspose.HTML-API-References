## Metered.SetMeteredKey method

Définit la clé publique et privée mesurée. Si vous achetez une licence mesurée, lors du démarrage de l'application, cette API doit être appelée, normalement cela suffit. Cependant, si le téléchargement des données de consommation échoue constamment et dépasse 24 heures, la licence sera mise en statut d'évaluation ; pour éviter ce cas, vous devez vérifier régulièrement le statut de la licence, et si elle est en statut d'évaluation, appeler à nouveau cette API.

```java
public void SetMeteredKey(String publicKey, String privateKey)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| publicKey | String | clé publique |
| privateKey | String | clé privée |
