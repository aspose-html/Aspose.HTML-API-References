## HTMLCanvasElement.GetContext method

Retourne un contexte de dessin sur le canvas, ou null si l'ID de contexte n'est pas pris en charge. Un contexte de dessin vous permet de dessiner sur le canvas.

```java
public object GetContext(String contextId)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| contextId | String | Est une chaîne contenant l'identifiant du contexte définissant le contexte de dessin associé au canvas |

### Valeur de retour

Un RenderingContext
