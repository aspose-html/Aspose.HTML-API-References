## HTMLCanvasElement.Height property

Est un entier positif reflétant l'attribut HTML height de l'élément canvas interprété en pixels CSS. Lorsque l'attribut n'est pas spécifié, ou s'il est défini à une valeur invalide, comme un nombre négatif, la valeur par défaut de 150 est utilisée.

```java
public ulong Height { get; set; }
```
