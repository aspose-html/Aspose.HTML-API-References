## ToDataURL() {#todataurl}

renvoie un URI de données contenant une représentation de l'image dans le format spécifié par le paramètre type (par défaut PNG). L'image renvoyée a une résolution de 96 dpi.

```java
public String ToDataURL()
```

### Valeur de retour

Une DOMString contenant l'URI de données demandée.

## ToDataURL(String, double) {#todataurl_2}

renvoie un URI de données contenant une représentation de l'image dans le format spécifié par le paramètre type (par défaut PNG). L'image renvoyée a une résolution de 96 dpi.

```java
public String ToDataURL(String type, double encoderOptions)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| type | String | Une chaîne indiquant le format de l'image. Le type de format par défaut est image/png. |
| encoderOptions | Double | Un nombre compris entre 0 et 1 indiquant la qualité de l'image si le type demandé est image/jpeg ou image/webp. |

### Valeur de retour

Une DOMString contenant l'URI de données demandée.
