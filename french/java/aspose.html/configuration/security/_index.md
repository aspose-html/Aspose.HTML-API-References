## Configuration.Security property

Obtient ou définit le drapeau de sandboxing de la configuration. Consultez l'article sur le [sandboxing](https://docs.aspose.com/html/net/working-with-documents/environment-configuration/#sandboxing).

```java
public Sandbox Security { get; set; }
```

### Property Value

La sécurité. Un ensemble de [`sandboxing flag`](../../sandbox/) est un ensemble de zéro ou plusieurs des drapeaux, qui sont utilisés pour restreindre les capacités des ressources potentiellement non fiables. L'attribut sandbox vous permet de définir un certain nombre de restrictions sur le contenu chargé dans le cadre, par exemple, bloquer les formulaires et les scripts.
