## HTMLTableRowElement.DeleteCell method

Supprimer une cellule de la ligne actuelle.

```java
public void DeleteCell(int index)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| index | Int32 | L'index de la cellule à supprimer, en commençant à 0. Si l'index est -1, la dernière cellule de la ligne est supprimée. |

### Exceptions

| exception | condition |
| --- | --- |
| [dOMException](../../../com.aspose.html.dom/domexception/) | INDEX_SIZE_ERR: Levé si l'`index` spécifié est supérieur ou égal au nombre de cellules ou si l'index est un nombre négatif autre que -1. @version DOM Level 2 |
