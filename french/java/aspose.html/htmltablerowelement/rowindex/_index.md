## HTMLTableRowElement.RowIndex property

Ceci est dans l'ordre logique et non dans l'ordre du document. Le `rowIndex` prend en compte les sections (`THEAD`, `TFOOT` ou `TBODY`) au sein du tableau, plaçant d'abord les lignes `THEAD` dans l'index, suivies des lignes `TBODY`, puis des lignes `TFOOT`. @version DOM Level 2
