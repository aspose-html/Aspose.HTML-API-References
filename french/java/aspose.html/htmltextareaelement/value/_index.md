## HTMLTextAreaElement.Value property

Représente le contenu actuel du contrôle de formulaire correspondant, dans un agent utilisateur interactif. Modifier cet attribut modifie le contenu du contrôle de formulaire, mais ne modifie pas le contenu de l'élément. Si l'intégralité des données ne peut pas tenir dans une seule `DOMString`, l'implémentation peut tronquer les données.

```java
public String Value { get; set; }
```
