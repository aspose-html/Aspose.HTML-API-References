Le package Aspose.Html contient des classes et des méthodes pour manipuler les [`documents HTML`](aspose.html/htmldocument/), qu'ils soient simples ou complexes et en temps réel. Aspose.HTML for Java permet aux développeurs d'insérer, de supprimer et de remplacer des nœuds HTML, d'extraire les informations de style CSS, de naviguer à travers le [`document HTML`](aspose.html/htmldocument/) soit par le biais du [`NodeIterator`](aspose.html.dom.traversal/inodeiterator/), du [`TreeWalker`](aspose.html.dom.traversal/itreewalker/) fournis par les spécifications de traversée, XPath ou les requêtes de sélecteurs CSS. Il offre également le scripting qui permet de manipuler le DOM HTML via JavaScript. En plus du HTML, cette API fournit également la capacité de charger les formats EPUB et MHTML. Les API Aspose sont réputées pour leurs fonctionnalités de conversion inter‑formats de fichiers et cette API offre également la capacité de charger un fichier HTML et de rendre la sortie en PDF, XPS et formats d'images raster incluant JPEG, PNG, BMP et TIFF.
