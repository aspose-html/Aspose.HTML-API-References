## HTMLOptionElement.Selected property

Représente l'état actuel du contrôle de formulaire correspondant, dans un agent utilisateur interactif. Modifier cet attribut modifie l'état du contrôle de formulaire, mais ne change pas la valeur de l'attribut HTML selected de l'élément.

```java
public bool Selected { get; set; }
```
