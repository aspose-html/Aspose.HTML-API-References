## Uint8ClampedArray class

Représente un tableau d'entiers non signés sur 8 bits limité à 0-255 ; si vous spécifiez une valeur hors de l'intervalle [0,255], 0 ou 255 sera attribué à la place ;

```java
public class Uint8ClampedArray : TypedArray<byte>
```
