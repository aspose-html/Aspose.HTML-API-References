## HTMLTableElement.Rows property

Retourne le `TFOOT` du tableau, ou `null` s'il n'existe pas.

Retourne une collection de toutes les lignes du tableau, y compris celles de `THEAD`, `TFOOT` et tous les éléments `TBODY`.

```java
public HTMLCollection Rows { get; }
```
