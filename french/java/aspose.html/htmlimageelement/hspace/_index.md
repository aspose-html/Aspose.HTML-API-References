## HTMLImageElement.Hspace property

Espace horizontal à gauche et à droite de cette image en pixels. Voir la définition de l'attribut hspace dans HTML 4.01. Cet attribut est obsolète dans HTML 4.01. Notez que le type de cet attribut était `DOMString` dans DOM Level 1 HTML [[DOM Level 1](http://www.w3.org/TR/1998/REC-DOM-Level-1-19981001)]. @version DOM Level 2
