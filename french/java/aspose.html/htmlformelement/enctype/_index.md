## HTMLFormElement.Enctype property

Le type de contenu du formulaire soumis, généralement "application/x-www-form-urlencoded". Voir la définition de l'attribut enctype dans HTML 4.01. Le gestionnaire d'événement onsubmit n'est pas garanti d'être déclenché lors de l'appel de cette méthode. Le comportement est incohérent pour des raisons historiques et les auteurs ne devraient pas se fier à un cas particulier.

```java
public String Enctype { get; set; }
```
