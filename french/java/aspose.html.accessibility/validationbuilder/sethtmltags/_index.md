## ValidationBuilder.SetHTMLTags method

Liste des balises html à vérifier. Si les balises ne sont pas spécifiées explicitement, alors le tableau de balises est vide et la vérification passe à toutes.

```java
public ValidationBuilder SetHTMLTags(params String[] tags)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| tags | String[] | liste des balises html - où la valeur est une description String de la balise |

### Valeur de retour

définir les balises et initialiser dans les paramètres.
