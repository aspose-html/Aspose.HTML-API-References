## Guideline class

Directives - le niveau suivant après les principes. Elles ne sont pas testables, mais définissent des cadres et des objectifs généraux qui aident les auteurs à comprendre les critères de succès et à mieux appliquer les techniques. Les directives sont une liste de critères d'acceptation avec le type RuleDirectory{Criterion}.
