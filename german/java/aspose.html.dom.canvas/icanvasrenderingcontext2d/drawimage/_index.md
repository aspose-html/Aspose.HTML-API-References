## DrawImage(HTMLImageElement, double, double, double, double, double, double, double, double) {#drawimage_5}

```java
public void DrawImage(HTMLImageElement image, double sx, double sy, double sw, double sh, 
    double dx, double dy, double dw, double dh)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| Bild | HTMLImageElement | Das HTMLImageElement, das in den Kontext gezeichnet werden soll. |
| sx | Double | Die X‑Koordinate der oberen linken Ecke des Teilrechtecks des Quellbildes, das in den Ziel‑Kontext gezeichnet werden soll. |
| sy | Double | Die Y‑Koordinate der oberen linken Ecke des Teilrechtecks des Quellbildes, das in den Ziel‑Kontext gezeichnet werden soll. |
| sw | Double | Die Breite des Teilrechtecks des Quellbildes, das in den Ziel‑Kontext gezeichnet wird. Wenn nicht angegeben, wird das gesamte Rechteck von den durch sx und sy angegebenen Koordinaten bis zur rechten unteren Ecke des Bildes verwendet. |
| sh | Double | Die Höhe des Teilrechtecks des Quellbildes, das in den Ziel‑Kontext gezeichnet wird. |
| dx | Double | Die X‑Koordinate im Ziel‑Canvas, an der die obere linke Ecke des Quellbildes platziert werden soll. |
| dy | Double | Die Y‑Koordinate im Ziel‑Canvas, an der die obere linke Ecke des Quellbildes platziert werden soll. |
| dw | Double | Die Breite, mit der das Bild im Ziel‑Canvas gezeichnet wird. Dies ermöglicht das Skalieren des gezeichneten Bildes. Wenn nicht angegeben, wird das Bild in der Breite nicht skaliert, wenn es gezeichnet wird. |
| dh | Double | Die Höhe, mit der das Bild im Ziel‑Canvas gezeichnet wird. Dies ermöglicht das Skalieren des gezeichneten Bildes. Wenn nicht angegeben, wird das Bild in der Höhe nicht skaliert, wenn es gezeichnet wird. |
