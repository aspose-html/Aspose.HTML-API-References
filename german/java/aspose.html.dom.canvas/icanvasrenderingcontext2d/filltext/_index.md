## FillText(String, double, double, double) {#filltext_1}

Zeichnet (füllt) einen angegebenen Text an der angegebenen Position (x,y).

```java
public void FillText(String text, double x, double y, double maxWidth)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| text | String | Der zu zeichnende Text, der die aktuellen Werte für Schriftart, textAlign, textBaseline und direction verwendet. |
| x | Double | Die x-Achse der Koordinate für den Startpunkt des Textes. |
| y | Double | Die y-Achse der Koordinate für den Startpunkt des Textes. |
| maxWidth | Double | Die maximale Breite, die gezeichnet werden soll. Wenn angegeben und die Zeichenkette breiter als diese Breite berechnet wird, wird die Schriftart angepasst, um eine stärker horizontal kondensierte Schrift zu verwenden (falls verfügbar oder falls eine einigermaßen lesbare Schrift durch horizontales Skalieren der aktuellen Schrift synthetisiert werden kann) oder eine kleinere Schrift. |
