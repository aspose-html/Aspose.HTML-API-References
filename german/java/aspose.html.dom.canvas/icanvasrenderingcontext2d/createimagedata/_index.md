## CreateImageData(double, double) {#createimagedata_1}

Erstellt ein neues, leeres ImageData‑Objekt mit den angegebenen Abmessungen. Alle Pixel im neuen Objekt sind transparentes Schwarz.

```java
public IImageData CreateImageData(double sw, double sh)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| sw | Double | Die Breite, die dem neuen ImageData‑Objekt zugewiesen wird. |
| sh | Double | Die Höhe, die dem neuen ImageData‑Objekt zugewiesen wird. |

### Rückgabewert

Ein neues ImageData-Objekt mit der angegebenen Breite und Höhe. Das neue Objekt ist mit transparenten schwarzen Pixeln gefüllt.
