## StrokeText(String, double, double, double?) {#stroketext_1}

Zeichnet (strichelt) einen angegebenen Text an der angegebenen Position (x, y).

```java
public void StrokeText(String text, double x, double y, double? maxWidth)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| text | String | Der zu zeichnende Text unter Verwendung der aktuellen Schriftart, textAlign, textBaseline und direction‑Werte. |
| x | Double | Die x‑Achse der Koordinate für den Startpunkt des Textes. |
| y | Double | Die y‑Achse der Koordinate für den Startpunkt des Textes. |
| maxWidth | Nullable`1 | Die maximale Breite, die gezeichnet werden soll. Wenn angegeben und die Zeichenkette breiter als diese Breite berechnet wird, wird die Schriftart angepasst, um eine stärker horizontal komprimierte Schrift zu verwenden (falls verfügbar oder falls eine einigermaßen lesbare Schrift durch horizontales Skalieren der aktuellen Schrift synthetisiert werden kann) oder eine kleinere Schrift. |
