## ICanvasRenderingContext2D.GetImageData method

Gibt ein ImageData-Objekt zurück, das die zugrunde liegenden Pixeldaten für den Bereich der Leinwand darstellt, der durch das Rechteck definiert ist, das bei (sx, sy) beginnt und eine Breite sw sowie eine Höhe sh hat. Diese Methode wird nicht von der Transformationsmatrix der Leinwand beeinflusst.

```java
public IImageData GetImageData(double sx, double sy, double sw, double sh)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| sx | Double | Die x‑Koordinate der oberen linken Ecke des Rechtecks, aus dem das ImageData extrahiert wird. |
| sy | Double | Die y‑Koordinate der oberen linken Ecke des Rechtecks, aus dem das ImageData extrahiert wird. |
| sw | Double | Die Breite des Rechtecks, aus dem das ImageData extrahiert wird. |
| sh | Double | Die Höhe des Rechtecks, aus dem das ImageData extrahiert wird. |

### Rückgabewert

Ein ImageData-Objekt, das die Bilddaten für das angegebene Rechteck des Canvas enthält.
