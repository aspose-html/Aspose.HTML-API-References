## IsPointInStroke(double, double) {#ispointinstroke_1}

Gibt an, ob der angegebene Punkt innerhalb des Bereichs liegt, der durch das Strichzeichnen eines Pfades entsteht, oder nicht.

```java
public bool IsPointInStroke(double x, double y)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| x | Double | Die X‑Koordinate des zu prüfenden Punktes. |
| y | Double | Die Y‑Koordinate des zu prüfenden Punktes. |

### Rückgabewert

Gibt true zurück, wenn der Punkt innerhalb des durch das Strichzeichnen eines Pfades definierten Bereichs liegt, andernfalls false.
