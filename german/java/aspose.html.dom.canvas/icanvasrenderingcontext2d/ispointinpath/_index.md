## IsPointInPath(double, double) {#ispointinpath_2}

Gibt an, ob der angegebene Punkt im aktuellen Pfad enthalten ist oder nicht.

```java
public bool IsPointInPath(double x, double y)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| x | Double | Die X‑Koordinate des zu prüfenden Punktes. |
| y | Double | Die Y‑Koordinate des zu prüfenden Punktes. |

### Rückgabewert

Gibt true zurück, wenn der Punkt innerhalb des durch das Füllen eines Pfades definierten Bereichs liegt, andernfalls false.
