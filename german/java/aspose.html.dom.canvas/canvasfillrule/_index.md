## CanvasFillRule enumeration

Diese Aufzählung wird verwendet, um den Füllregel-Algorithmus auszuwählen, mit dem bestimmt wird, ob ein Punkt innerhalb oder außerhalb eines Pfades liegt.

```java
public enum CanvasFillRule
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| NonZero | `0` | Der Wert "nonzero" gibt die Non‑Zero‑Winding‑Regel an, bei der ein Punkt als außerhalb einer Form betrachtet wird, wenn die Anzahl der Schnitte einer halbunendlichen Geraden, die von diesem Punkt ausgeht, mit dem Pfad der Form in eine Richtung gleich der Anzahl der Schnitte in die andere Richtung ist. |
| EvenOdd | `1` | Der Wert "evenodd" gibt die Even‑Odd‑Regel an, bei der ein Punkt als außerhalb einer Form betrachtet wird, wenn die Anzahl der Schnitte einer halbunendlichen Geraden, die von diesem Punkt ausgeht, mit dem Pfad der Form gerade ist. |
