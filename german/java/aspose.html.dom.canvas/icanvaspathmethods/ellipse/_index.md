## Ellipse(double, double, double, double, double, double, double) {#ellipse}

Fügt dem Pfad eine Ellipse hinzu, die zentriert bei (x, y) mit den Radien radiusX und radiusY ist, beginnend bei startAngle und endend bei endAngle, in der angegebenen Richtung gegen den Uhrzeigersinn (standardmäßig im Uhrzeigersinn).

```java
public void Ellipse(double x, double y, double radiusX, double radiusY, double rotation, 
    double startAngle, double endAngle)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| x | Double | Die x-Achse der Koordinate für das Zentrum der Ellipse. |
| y | Double | Die y-Achse der Koordinate für das Zentrum der Ellipse. |
| radiusX | Double | Der Radius der Hauptachse der Ellipse. |
| radiusY | Double | Der Radius der Nebenachse der Ellipse. |
| rotation | Double | Die Drehung für diese Ellipse, ausgedrückt in Radianten. |
| startAngle | Double | Der Startpunkt, gemessen von der x-Achse, von dem aus sie gezeichnet wird, ausgedrückt in Radianten. |
| endAngle | Double | Der Endwinkel der Ellipse, zu dem sie gezeichnet wird, ausgedrückt in Radianten. |

## Ellipse(double, double, double, double, double, double, double, bool) {#ellipse_1}

Fügt dem Pfad eine Ellipse hinzu, die zentriert bei (x, y) mit den Radien radiusX und radiusY ist, beginnend bei startAngle und endend bei endAngle, in der angegebenen Richtung gegen den Uhrzeigersinn (standardmäßig im Uhrzeigersinn).

```java
public void Ellipse(double x, double y, double radiusX, double radiusY, double rotation, 
    double startAngle, double endAngle, bool anticlockwise)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| x | Double | Die x-Achse der Koordinate für das Zentrum der Ellipse. |
| y | Double | Die y-Achse der Koordinate für das Zentrum der Ellipse. |
| radiusX | Double | Der Radius der Hauptachse der Ellipse. |
| radiusY | Double | Der Radius der Nebenachse der Ellipse. |
| rotation | Double | Die Drehung für diese Ellipse, ausgedrückt in Radianten. |
| startAngle | Double | Der Startpunkt, gemessen von der x-Achse, von dem aus sie gezeichnet wird, ausgedrückt in Radianten. |
| endAngle | Double | Der Endwinkel der Ellipse, zu dem sie gezeichnet wird, ausgedrückt in Radianten. |
| gegen den Uhrzeigersinn | Boolean | Ein optionaler boolescher Wert, der, wenn true, die Ellipse gegen den Uhrzeigersinn (counter-clockwise) zeichnet, andernfalls in einer clockwise-Richtung. |
