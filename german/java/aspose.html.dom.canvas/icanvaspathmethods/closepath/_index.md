## ICanvasPathMethods.ClosePath method

Veranlasst den Stiftpunkt, zum Anfang des aktuellen Unterpfads zurückzukehren. Es versucht, eine gerade Linie vom aktuellen Punkt zum Anfang zu zeichnen. Wenn die Form bereits geschlossen ist oder nur einen Punkt hat, bewirkt diese Funktion nichts.

```java
public void ClosePath()
```
