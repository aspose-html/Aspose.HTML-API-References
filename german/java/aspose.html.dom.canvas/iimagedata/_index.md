## IImageData interface

Erstellt ein ImageData‑Objekt aus einem gegebenen Uint8ClampedArray und der Größe des darin enthaltenen Bildes. Wenn kein Array angegeben wird, erstellt es ein Bild eines schwarzen Rechtecks.

```java
public interface IImageData
```

## Eigenschaften

| Name | Beschreibung |
| --- | --- |
| [getData](../../com.aspose.html.dom.canvas/iimagedata/data/) ist ein Uint8ClampedArray, das ein eindimensionales Array darstellt, das die Daten in RGBA‑Reihenfolge enthält, mit ganzzahligen Werten zwischen 0 und 255 (einschließlich). |
| [getHeight](../../com.aspose.html.dom.canvas/iimagedata/height/) ist ein unsigned long, das die tatsächliche Höhe in Pixeln des ImageData darstellt. |
| [getWidth](../../com.aspose.html.dom.canvas/iimagedata/width/) ist ein unsigned long, das die tatsächliche Breite in Pixeln des ImageData darstellt. |
