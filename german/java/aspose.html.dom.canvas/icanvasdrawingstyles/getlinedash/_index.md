## ICanvasDrawingStyles.GetLineDash method

Gibt das aktuelle Array des Strichmuster für Linien zurück, das eine gerade Anzahl nicht‑negativer Zahlen enthält.

```java
public double[] GetLineDash()
```

### Rückgabewert

Ein Array. Eine Liste von Zahlen, die Abstände angibt, um abwechselnd eine Linie und eine Lücke zu zeichnen (in Einheiten des Koordinatenraums).
