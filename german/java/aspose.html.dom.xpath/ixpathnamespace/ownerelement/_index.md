## IXPathNamespace.OwnerElement property

Das [`Element`](../../../com.aspose.html.dom/element/) , auf dem das Paket beim Anfordern im Gültigkeitsbereich war. Dies ändert sich nicht bei einem zurückgegebenen Paketknoten, selbst wenn das Dokument so geändert wird, dass das Paket auf diesem Element außer Geltung tritt und dieser Knoten dort per XPath nicht mehr gefunden wird.

```java
public Element OwnerElement { get; }
```
