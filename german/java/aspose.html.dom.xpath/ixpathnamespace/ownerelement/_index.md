## IXPathNamespace.OwnerElement property

Das [`Element`](../../../com.aspose.html.dom/element/) , auf dem das Paket zum Zeitpunkt der Anforderung im Gültigkeitsbereich war. Dies ändert sich nicht bei einem zurückgegebenen Paketknoten, selbst wenn das Dokument so geändert wird, dass das Paket für dieses Element aus dem Gültigkeitsbereich fällt und dieser Knoten dort von XPath nicht mehr gefunden wird.

```java
public Element OwnerElement { get; }
```
