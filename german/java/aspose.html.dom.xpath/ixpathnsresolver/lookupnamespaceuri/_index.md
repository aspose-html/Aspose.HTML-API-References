## IXPathNSResolver.LookupNamespaceURI method

Sucht die dem angegebenen Paketpräfix zugehörige package‑URI. Der XPath‑Evaluator darf dies niemals mit einem `null`‑ oder leeren Argument aufrufen, da das Ergebnis dieses Aufrufs undefiniert ist.

```java
public String LookupNamespaceURI(String prefix)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| Präfix | String | Das zu suchende Präfix. |

### Rückgabewert

Gibt die zugehörige Paket-URI zurück oder `null`, wenn keine gefunden wird.
