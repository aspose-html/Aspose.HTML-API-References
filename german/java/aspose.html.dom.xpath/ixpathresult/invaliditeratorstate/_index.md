## IXPathResult.InvalidIteratorState property

Gibt an, dass der Iterator ungültig geworden ist. Wahr, wenn `resultType`is `UnorderedNodeIterator`-Typ oder `OrderedNodeIterator`-Typ und das Dokument seit der Rückgabe dieses Ergebnisses geändert wurde.

```java
public bool InvalidIteratorState { get; }
```
