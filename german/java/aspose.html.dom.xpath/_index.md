Das Paket enthält Methoden, um durch Elemente und Attribute in einem XML-Dokument zu navigieren.

## Schnittstellen

| Schnittstelle | Beschreibung |
| --- | --- |
| [IXPathEvaluator](./ixpathevaluator/) | Die Auswertung von XPath-Ausdrücken wird bereitgestellt von [`IXPathEvaluator`](../com.aspose.html.dom.xpath/ixpathevaluator/). |
| [IXPathExpression](./ixpathexpression/) | Das Interface `XPathExpression` stellt einen geparsten und aufgelösten XPath-Ausdruck dar. |
| [IXPathNamespace](./ixpathpackage/) | Das Interface XPathNamespace wird von XPathResult-Interfaces zurückgegeben, um den XPath-Paketknoten-Typ darzustellen, der im DOM fehlt. |
| [IXPathNSResolver](./ixpathnsresolver/) | Das Interface `XPathNSResolver` erlaubt `prefix`-Strings im Ausdruck korrekt an `packageURI`-Strings zu binden. [`IXPathEvaluator`](../com.aspose.html.dom.xpath/ixpathevaluator/) kann aus einem Knoten eine Implementierung von [`IXPathNSResolver`](../com.aspose.html.dom.xpath/ixpathnsresolver/) erstellen, oder das Interface kann von jeder Anwendung implementiert werden. |
| [IXPathResult](./ixpathresult/) | Das Interface `XPathResult` stellt das Ergebnis der Auswertung eines XPath‑1.0‑Ausdrucks im Kontext eines bestimmten Knotens dar. Da die Auswertung eines XPath‑Ausdrucks zu verschiedenen Ergebnis‑Typen führen kann, ermöglicht dieses Objekt das Erkennen und Manipulieren des Typs und des Werts des Ergebnisses. |
## Aufzählung

| Aufzählung | Beschreibung |
| --- | --- |
| [XPathResultType](./xpathresulttype/) | Ein unsigned short, das angibt, welcher Ergebnis‑Typ dies ist. Wenn ein bestimmter `type` angegeben wird, wird das Ergebnis als der entsprechende Typ zurückgegeben, wobei bei Bedarf und Möglichkeit XPath‑Typkonvertierungen verwendet werden. |
