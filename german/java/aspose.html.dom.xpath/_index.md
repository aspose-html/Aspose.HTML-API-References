Das Paket enthält Methoden, um durch Elemente und Attribute in einem XML-Dokument zu navigieren.

## Schnittstellen

| Schnittstelle | Beschreibung |
| --- | --- |
| [IXPathEvaluator](./ixpathevaluator/) | Die Auswertung von XPath-Ausdrücken wird bereitgestellt von [`IXPathEvaluator`](../com.aspose.html.dom.xpath/ixpathevaluator/). |
| [IXPathExpression](./ixpathexpression/) | Das `XPathExpression` Interface stellt einen geparsten und aufgelösten XPath-Ausdruck dar. |
| [IXPathNamespace](./ixpathpackage/) | Das XPathNamespace Interface wird von XPathResult-Interfaces zurückgegeben, um den XPath-Paketknotentyp darzustellen, den das DOM nicht besitzt. |
| [IXPathNSResolver](./ixpathnsresolver/) | Das `XPathNSResolver` Interface erlaubt es, `prefix` Strings im Ausdruck korrekt an `packageURI` Strings zu binden. [`IXPathEvaluator`](../com.aspose.html.dom.xpath/ixpathevaluator/) kann aus einem Knoten eine Implementierung von [`IXPathNSResolver`](../com.aspose.html.dom.xpath/ixpathnsresolver/) erstellen, oder das Interface kann von jeder Anwendung implementiert werden. |
| [IXPathResult](./ixpathresult/) | Das `XPathResult` Interface stellt das Ergebnis der Auswertung eines XPath‑1.0‑Ausdrucks im Kontext eines bestimmten Knotens dar. Da die Auswertung eines XPath‑Ausdrucks zu verschiedenen Ergebnis­typen führen kann, ermöglicht dieses Objekt das Erkennen und Manipulieren von Typ und Wert des Ergebnisses. |
## Aufzählung

| Aufzählung | Beschreibung |
| --- | --- |
| [XPathResultType](./xpathresulttype/) | Ein unsigned short, das angibt, um welchen Ergebnis­typ es sich handelt. Wenn ein bestimmter `type` angegeben ist, wird das Ergebnis als der entsprechende Typ zurückgegeben, wobei bei Bedarf und Möglichkeit XPath‑Typumwandlungen verwendet werden. |
