## FontEmbeddingRule enumeration

Stellt die Regeln für das Einbetten von Schriftarten dar.

```java
public enum FontEmbeddingRule
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Full | `1` | Alle verwendeten Schriftarten werden unverändert eingebettet. Beachten Sie, dass einige Schriftarten lizenziert sein könnten, was das resultierende Dokument nicht editierbar macht. Außerdem können die eingebetteten Schriftdateien die Größe des resultierenden Dokuments erheblich erhöhen. |
| None | `2` | Schriftarten werden nicht eingebettet. |
