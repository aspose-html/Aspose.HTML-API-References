## DocDevice.ClosePath method

Schließt den aktuellen Unterpfad, indem ein gerader Linienabschnitt vom aktuellen Punkt zum Startpunkt des Unterpfads angehängt wird. Wenn der aktuelle Unterpfad bereits geschlossen ist, bewirkt \"ClosePath\" nichts. Dieser Operator beendet den aktuellen Unterpfad. Das Anhängen eines weiteren Segments an den aktuellen Pfad startet einen neuen Unterpfad, selbst wenn das neue Segment am Endpunkt beginnt, der durch die Methode \"ClosePath\" erreicht wurde.
