## DocDevice.Clip method

Modifiziert den aktuellen Clipping‑Pfad, indem er mit dem aktuellen Pfad geschnitten wird, wobei die FillMode‑Regel zur Bestimmung des auszufüllenden Bereichs verwendet wird. Diese Methode beendet den aktuellen Pfad.

```java
public void Clip(FillRule mode)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| Modus | FillRule | Der Füllmodus gibt an, wie das Innere eines geschlossenen Pfades abgeschnitten wird. |
