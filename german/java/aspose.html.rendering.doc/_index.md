Das **com.aspose.html.rendering.doc** Paket stellt eine spezifische Geräteklasse sowie einige Rendering-Optionenklassen bereit, die für das Rendern in ein DOCX-Dokument verantwortlich sind.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [DocDevice](./docdevice/) | Stellt das Rendern in ein DOCX-Dokument dar. |
| [DocRenderingOptions](./docrenderingoptions/) | Stellt die Rendering-Optionen für [`DocDevice`](../com.aspose.html.rendering.doc/docdevice/) dar. |
## Aufzählung

| Aufzählung | Beschreibung |
| --- | --- |
| [DocumentFormat](./documentformat/) | Stellt das Dateiformat des Ausgabedokuments dar. |
| [FontEmbeddingRule](./fontembeddingrule/) | Stellt die Regeln für das Einbetten von Schriftarten dar. |
