Das Paket bietet Zugriff auf alle SVG‑spezifischen Datentypen.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [SVGAngle](./svgangle/) | Das SVGAngle-Interface entspricht dem Grunddatentyp Winkel. |
| [SVGAnimatedAngle](./svganimatedangle/) | Wird für Attribute des Grunddatentyps Winkel verwendet, die animierbar sind. |
| [SVGAnimatedBoolean](./svganimatedboolean/) | Wird für Attribute des Typs Boolean verwendet, die animierbar sind. |
| [SVGAnimatedEnumeration](./svganimatedenumeration/) | Wird für Attribute verwendet, deren Wert eine Konstante aus einer bestimmten Aufzählung sein muss und die animierbar sind. |
| [SVGAnimatedInteger](./svganimatedinteger/) | Wird für Attribute des Grundtyps Integer verwendet, die animierbar sind. |
| [SVGAnimatedLength](./svganimatedlength/) | Wird für Attribute des Grundtyps Length verwendet, die animierbar sind. |
| [SVGAnimatedLengthList](./svganimatedlengthlist/) | Wird für Attribute des Typs SVGLengthList verwendet, die animierbar sind. |
| [SVGAnimatedNumber](./svganimatednumber/) | Wird für Attribute des Grundtyps Number verwendet, die animierbar sind. |
| [SVGAnimatedNumberList](./svganimatednumberlist/) | Wird für Attribute verwendet, die eine Liste von Zahlen akzeptieren und animierbar sind. |
| [SVGAnimatedPreserveAspectRatio](./svganimatedpreserveaspectratio/) | Wird für Attribute des Typs SVGPreserveAspectRatio verwendet, die animierbar sind. |
| [SVGAnimatedRect](./svganimatedrect/) | Wird für Attribute des Typs SVGRect verwendet, die animierbar sind. |
| [SVGAnimatedString](./svganimatedString/) | Wird für Attribute des Typs DOMString verwendet, die animierbar sind. |
| [SVGAnimatedTransformList](./svganimatedtransformlist/) | Wird für die verschiedenen Attribute verwendet, die einen Satz von Transformationen festlegen, wie das ‘transform’-Attribut, das für viele SVG-Elemente verfügbar ist und animiert werden kann. |
| [SVGAnimatedValue&lt;T&gt;](./svganimatedvalue-1/) | Wird für Attribute von Typen verwendet, die animiert werden können. |
| [SVGLength](./svglength/) | Das SVGLength-Interface entspricht dem Grunddatentyp Länge. Ein SVGLength-Objekt kann als schreibgeschützt festgelegt werden, was bedeutet, dass Versuche, das Objekt zu ändern, eine Ausnahme auslösen, wie unten beschrieben. |
| [SVGLengthList](./svglengthlist/) | Dieses Interface definiert eine Liste von SVGLength-Objekten. |
| [SVGMatrix](./svgmatrix/) | Viele der Grafikoperationen von SVG verwenden 2x3-Matrizen der Form: [a c e] [b d f], die bei Erweiterung zu einer 3x3-Matrix für matrixarithmetische Zwecke werden: [a c e] [b d f] [0 0 1] |
| [SVGNumber](./svgnumber/) | Wird für Attribute des Basistyps number verwendet. |
| [SVGNumberList](./svgnumberlist/) | Dieses Interface definiert eine Liste von SVGNumber-Objekten. |
| [SVGPoint](./svgpoint/) | Viele der SVG-DOM-Interfaces beziehen sich auf Objekte der Klasse SVGPoint. Ein SVGPoint ist ein (x, y)-Koordinatenpaar. Bei Matrixoperationen wird ein SVGPoint als Vektor der Form behandelt: [x] [y] [1]. Wenn ein SVGRect-Objekt als schreibgeschützt festgelegt ist, führt der Versuch, einem seiner Attribute einen Wert zuzuweisen, zu einer ausgelösten Ausnahme. |
| [SVGPointList](./svgpointlist/) | Dieses Interface definiert eine Liste von SVGPoint-Objekten. |
| [SVGPreserveAspectRatio](./svgpreserveaspectratio/) | Das SVGPreserveAspectRatio-Interface entspricht dem ‘preserveAspectRatio’-Attribut, das für einige SVG-Elemente verfügbar ist. |
| [SVGRect](./svgrect/) | Stellt rechteckige Geometrie dar. Rechtecke werden definiert als ein (x,y)-Koordinatenpaar, das einen minimalen X-Wert, einen minimalen Y-Wert sowie Breite und Höhe angibt, die in der Regel nicht negativ sein dürfen. |
| [SVGStringList](./svgStringlist/) | SVGStringList hat dieselben Attribute und Methoden wie andere SVGxxxList-Interfaces. Implementierer könnten in Betracht ziehen, eine einzige Basisklasse zu verwenden, um die verschiedenen SVGxxxList-Interfaces zu implementieren. |
| [SVGTransform](./svgtransform/) | SVGTransform ist das Interface für eine der Komponenten-Transformationen innerhalb einer SVGTransformList; ein SVGTransform-Objekt entspricht also einer einzelnen Komponente (z. B. 'scale(…)' oder 'matrix(…)') innerhalb einer ‘transform’-Attributspezifikation. |
| [SVGTransformList](./svgtransformlist/) | Dieses Interface definiert eine Liste von SVGTransform-Objekten. |
| [SVGValueType](./svgvaluetype/) | Der Typ SVGValueType wird verwendet, um einen Basis‑SVG‑Werttyp darzustellen. |
