## SVGLength.Value property

Der Wert als Gleitkommazahl in Benutzereinheiten. Das Setzen dieses Attributs führt dazu, dass valueInSpecifiedUnits und valueAsString automatisch aktualisiert werden, um diese Einstellung widerzuspiegeln.

```java
public float Value { get; set; }
```

### Property Value

Der Wert.
