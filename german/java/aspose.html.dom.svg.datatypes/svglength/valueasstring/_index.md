## SVGLength.ValueAsString property

Der Wert als String, in den durch unitType ausgedrückten Einheiten. Das Setzen dieses Attributs führt dazu, dass value, valueInSpecifiedUnits und unitType automatisch aktualisiert werden, um diese Einstellung widerzuspiegeln.

```java
public String ValueAsString { get; set; }
```

### Property Value

Der Wert als String.

### Ausnahmen

| Ausnahme | Bedingung |
| --- | --- |
| [dOMException](../../../com.aspose.html.dom/domexception/) | Code [`SYNTAX_ERR`](../../../com.aspose.html.dom/domexception/syntax_err/) Wird ausgelöst, wenn der zugewiesene String nicht als gültige Länge geparst werden kann. |
| [dOMException](../../../com.aspose.html.dom/domexception/) | Code [`NO_MODIFICATION_ALLOWED_ERR`](../../../com.aspose.html.dom/domexception/no_modification_allowed_err/) ausgelöst, wenn die Länge einem schreibgeschützten Attribut entspricht oder das Objekt selbst schreibgeschützt ist. |
