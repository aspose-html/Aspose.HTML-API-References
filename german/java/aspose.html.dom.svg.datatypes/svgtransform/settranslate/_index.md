## SVGTransform.SetTranslate method

Setzt den Transformationstyp auf SVG_TRANSFORM_TRANSLATE, wobei die Parameter tx und ty die Translationsbeträge festlegen.

```java
public void SetTranslate(float tx, float ty)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| tx | Single | Der Übersetzungsbetrag in X. |
| ty | Single | Der Translationsbetrag in Y. |
