## SVGAngle.ValueAsString property

Der Winkelwert als String‑Wert, in den durch unitType ausgedrückten Einheiten. Das Setzen dieses Attributs führt dazu, dass value, valueInSpecifiedUnits und unitType automatisch aktualisiert werden, um diese Einstellung widerzuspiegeln.

```java
public String ValueAsString { get; set; }
```

### Property Value

Der Wert als String.
