## SVGAngle.ValueInSpecifiedUnits property

Der Winkelwert als Gleitkommawert, in den durch unitType ausgedrückten Einheiten. Das Setzen dieses Attributs führt dazu, dass value und valueAsString automatisch aktualisiert werden, um diese Einstellung widerzuspiegeln.

```java
public float ValueInSpecifiedUnits { get; set; }
```

### Property Value

Der Wert in angegebenen Einheiten.
