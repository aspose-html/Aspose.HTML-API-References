## SVGAnimatedValue&lt;T&gt;.AnimVal property

Wenn das angegebene Attribut oder die Eigenschaft animiert wird, enthält sie den aktuellen animierten Wert des Attributs oder der Eigenschaft. Wenn das angegebene Attribut oder die Eigenschaft derzeit nicht animiert wird, enthält sie denselben Wert wie baseVal.

```java
public T AnimVal { get; }
```

### Property Value

`true` wenn [anim value]; sonst `false`.
