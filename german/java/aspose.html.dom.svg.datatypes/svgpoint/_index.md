## SVGPoint class

Viele der SVG DOM-Interfaces beziehen sich auf Objekte der Klasse SVGPoint. Ein SVGPoint ist ein (x, y)-Koordinatenpaar. Bei Matrixoperationen wird ein SVGPoint als Vektor der Form behandelt: [x] [y] [1]. Wenn ein SVGRect-Objekt als schreibgeschützt deklariert ist, führt der Versuch, einem seiner Attribute einen Wert zuzuweisen, zu einer ausgelösten Ausnahme.

```java
public class SVGPoint : SVGValueType
```
