## IUrlSearchParams.Set method

Setzt den Wert des zuerst gefundenen Namens‑Wert‑Paares auf den angegebenen Wert und entfernt die übrigen. Wenn keine Namens‑Wert‑Paare mit dem angegebenen Namen gefunden werden, wird ein neues an die Liste angehängt.

```java
public void Set(String name, String value)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| name | String | Schlüssel, der zum Finden von Namens‑Wert‑Paaren verwendet wird. |
| Wert | String | Wert, der gesetzt wird. |
