## Configuration.Security property

Liest oder setzt das Sandbox-Flag der Konfiguration. Siehe den Artikel über [sandboxing](https://docs.aspose.com/html/net/working-with-documents/environment-configuration/#sandboxing).

```java
public Sandbox Security { get; set; }
```

### Property Value

Die Sicherheit. Ein [`sandboxing flag`](../../sandbox/) Satz ist eine Menge von null oder mehr Flags, die verwendet werden, um die Fähigkeiten potenziell nicht vertrauenswürdiger Ressourcen einzuschränken. Das Sandbox-Attribut ermöglicht es Ihnen, eine Reihe von Einschränkungen für den im Frame geladenen Inhalt festzulegen, zum Beispiel Formulare und Skripte zu blockieren.
