## HTMLInputElement.DefaultValue property

Wenn das `type`-Attribut des Elements den Wert "text", "file" oder "password" hat, stellt dies das HTML value-Attribut des Elements dar. Der Wert dieses Attributs ändert sich nicht, wenn sich der Inhalt der entsprechenden Formularsteuerung in einem interaktiven User-Agent ändert. Siehe die Definition des value-Attributs in HTML 4.01.

```java
public String DefaultValue { get; set; }
```
