## HTMLInputElement.Checked property

Wenn das `type`‑Attribut des Elements den Wert "radio" oder "checkbox" hat, stellt dies den aktuellen Zustand der Formsteuerung in einem interaktiven User‑Agenten dar. Änderungen dieses Attributs ändern den Zustand der Formsteuerung, ändern jedoch nicht den Wert des HTML‑checked‑Attributs des INPUT‑Elements. Während der Behandlung eines Klick‑Ereignisses auf ein Input‑Element mit einem type‑Attribut, das den Wert "radio" oder "checkbox" hat, können einige Implementierungen den Wert dieser Eigenschaft ändern, bevor das Ereignis im Dokument ausgelöst wird. Wenn die Standardaktion des Ereignisses abgebrochen wird, kann der Wert der Eigenschaft wieder auf den ursprünglichen Wert zurückgesetzt werden. Das bedeutet, dass der Wert dieser Eigenschaft während der Behandlung von Klick‑Ereignissen implementationsabhängig ist.

```java
public bool Checked { get; set; }
```
