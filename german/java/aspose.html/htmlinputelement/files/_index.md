## HTMLInputElement.Files property

Das files IDL‑Attribut ermöglicht Skripten den Zugriff auf die vom Element ausgewählten Dateien. Beim Abrufen, falls das IDL‑Attribut zutrifft, muss ein FileList‑Objekt zurückgegeben werden, das die aktuell ausgewählten Dateien repräsentiert. Dasselbe Objekt muss zurückgegeben werden, bis sich die Liste der ausgewählten Dateien ändert. Wenn das IDL‑Attribut nicht zutrifft, muss stattdessen null zurückgegeben werden. [FILEAPI]

```java
public IFileList Files { get; }
```
