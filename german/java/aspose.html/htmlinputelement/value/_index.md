## HTMLInputElement.Value property

Wenn das `type`-Attribut des Elements den Wert "text", "file" oder "password" hat, stellt dies den aktuellen Inhalt der entsprechenden Form-Steuerung in einem interaktiven User-Agent dar. Das Ändern dieses Attributs ändert den Inhalt der Form-Steuerung, ändert jedoch nicht den Wert des HTML‑value‑Attributs des Elements. Wenn das `type`-Attribut des Elements den Wert "button", "hidden", "submit", "reset", "image", "checkbox" oder "radio" hat, stellt dies das HTML‑value‑Attribut des Elements dar. Siehe die Definition des value-Attributs in HTML 4.01.

```java
public String Value { get; set; }
```
