## HTMLInputElement.DefaultChecked property

Wenn `type` den Wert "radio" oder "checkbox" hat, stellt dies das HTML‑checked‑Attribut des Elements dar. Der Wert dieses Attributs ändert sich nicht, wenn sich der Zustand der entsprechenden Form-Steuerung in einem interaktiven User-Agent ändert. Siehe die Definition des checked-Attributs in HTML 4.01.

```java
public bool DefaultChecked { get; set; }
```
