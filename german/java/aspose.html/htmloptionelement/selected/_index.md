## HTMLOptionElement.Selected property

Stellt den aktuellen Zustand des entsprechenden Formularelements in einem interaktiven User-Agent dar. Das Ändern dieses Attributs ändert den Zustand des Formularelements, ändert jedoch nicht den Wert des HTML selected-Attributs des Elements.

```java
public bool Selected { get; set; }
```
