## HTMLTextAreaElement.Value property

Stellt den aktuellen Inhalt des entsprechenden Formularelements in einem interaktiven User‑Agent dar. Das Ändern dieses Attributs ändert den Inhalt des Formularelements, jedoch nicht den Inhalt des Elements. Wenn die gesamten Daten nicht in einen einzelnen `DOMString` passen, kann die Implementierung die Daten abschneiden.

```java
public String Value { get; set; }
```
