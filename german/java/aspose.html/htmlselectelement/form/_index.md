## HTMLSelectElement.Form property

Die Anzahl der Optionen in diesem `SELECT`.

Gibt das `FORM`-Element zurück, das diese Steuerung enthält. Gibt `null` zurück, wenn diese Steuerung nicht im Kontext eines Formulars ist.
