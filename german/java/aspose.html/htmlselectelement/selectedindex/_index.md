## HTMLSelectElement.SelectedIndex property

Der ordinale Index der ausgewählten Option, beginnend bei 0. Der Wert -1 wird zurückgegeben, wenn kein Element ausgewählt ist. Wenn mehrere Optionen ausgewählt sind, wird der Index der zuerst ausgewählten Option zurückgegeben.

```java
public int SelectedIndex { get; set; }
```
