## HTMLSelectElement class

Das select-Element ermöglicht die Auswahl einer Option. Die enthaltenen Optionen können direkt über das select-Element als Sammlung zugegriffen werden. Siehe die SELECT-Elementdefinition in HTML 4.01.

Siehe auch die [Document object Model (DOM) Level 2 HTML Specification](http://www.w3.org/TR/2003/REC-DOM-Level-2-HTML-20030109).

```java
public class HTMLSelectElement : HTMLElement
```
