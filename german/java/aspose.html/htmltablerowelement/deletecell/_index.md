## HTMLTableRowElement.DeleteCell method

Lösche eine Zelle aus der aktuellen Zeile.

```java
public void DeleteCell(int index)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| index | Int32 | Der Index der zu löschenden Zelle, beginnend bei 0. Wenn der Index -1 ist, wird die letzte Zelle in der Zeile gelöscht. |

### Ausnahmen

| Ausnahme | Bedingung |
| --- | --- |
| [dOMException](../../../com.aspose.html.dom/domexception/) | INDEX_SIZE_ERR: Wird ausgelöst, wenn der angegebene `index` größer als oder gleich der Anzahl der Zellen ist oder wenn der Index eine negative Zahl außer -1 ist. @version DOM Level 2 |
