## Uint8ClampedArray class

Stellt ein Array von 8‑Bit‑vorzeichenlosen Ganzzahlen dar, die auf 0‑255 begrenzt sind; wenn Sie einen Wert außerhalb des Bereichs [0,255] angeben, wird stattdessen 0 oder 255 gesetzt;

```java
public class Uint8ClampedArray : TypedArray<byte>
```
