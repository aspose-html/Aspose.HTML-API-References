## HTMLFormElement.Enctype property

Der Inhaltstyp des übermittelten Formulars ist in der Regel "application/x-www-form-urlencoded". Siehe die Definition des enctype-Attributs in HTML 4.01. Der onsubmit‑Ereignishandler wird beim Aufrufen dieser Methode nicht garantiert ausgelöst. Das Verhalten ist aus historischen Gründen inkonsistent und Autoren sollten sich nicht auf ein bestimmtes verlassen.

```java
public String Enctype { get; set; }
```
