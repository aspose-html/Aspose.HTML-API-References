## HTMLDocument.Anchors property

Eine Sammlung aller Anker (`A`)-Elemente in einem Dokument, die einen Wert für das `name`‑Attribut besitzen. Aus Gründen der Abwärtskompatibilität enthält die zurückgegebene Menge von Ankern nur solche, die mit dem `name`‑Attribut erstellt wurden, nicht solche, die mit dem `id`‑Attribut erstellt wurden. Beachten Sie, dass in [[XHTML 1.0](http://www.w3.org/TR/2002/REC-xhtml1-20020801)] das `name`‑Attribut (siehe Abschnitt 4.10) keine Semantik hat und nur für ältere Benutzeragenten vorhanden ist: das `id`‑Attribut wird stattdessen verwendet. Benutzer sollten stattdessen die von [[DOM Level 2 Traversal](http://www.w3.org/TR/2000/REC-DOM-Level-2-Traversal-Range-20001113)] bereitgestellten Iterator‑Mechanismen bevorzugen.

public HTMLCollection Anchors { get; }
