## HTMLDocument.Referrer property

Gibt die URI [[IETF RFC 2396](http://www.ietf.org/rfc/rfc2396.txt)] der Seite zurück, die auf diese Seite verlinkt hat. Der Wert ist ein leerer String, wenn der Benutzer direkt zur Seite navigierte (nicht über einen Link, sondern zum Beispiel über ein Lesezeichen).

```java
public String Referrer { get; }
```
