## HTMLDocument.Images property

Eine Sammlung aller `IMG`-Elemente in einem Dokument. Das Verhalten ist aus Gründen der Abwärtskompatibilität auf `IMG`-Elemente beschränkt. Wie in [[HTML 4.01](http://www.w3.org/TR/1999/REC-html401-19991224)] vorgeschlagen, können Autoren zum Einbinden von Bildern das `OBJECT`-Element oder das `IMG`-Element verwenden. Daher wird empfohlen, dieses Attribut nicht zu benutzen, um Bilder im Dokument zu finden, sondern `getElementsByTagName` mit HTML 4.01 oder `getElementsByTagNameNS` mit XHTML 1.0 zu verwenden.

```java
public HTMLCollection Images { get; }
```
