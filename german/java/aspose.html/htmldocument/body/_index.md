## HTMLDocument.Body property

Das Element, das den Inhalt des Dokuments enthält. In Dokumenten mit `BODY`-Inhalten wird das `BODY`-Element zurückgegeben. In Frameset-Dokumenten wird das äußerste `FRAMESET`-Element zurückgegeben.

```java
public HTMLElement Body { get; set; }
```
