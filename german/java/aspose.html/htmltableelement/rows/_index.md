## HTMLTableElement.Rows property

Gibt das `TFOOT` der Tabelle zurück oder `null`, falls keines existiert.

Gibt eine Sammlung aller Zeilen der Tabelle zurück, einschließlich aller in `THEAD`, `TFOOT` und aller `TBODY`‑Elemente.

```java
public HTMLCollection Rows { get; }
```
