## ToDataURL() {#todataurl}

gibt eine Daten-URI zurück, die eine Darstellung des Bildes im durch den Typ-Parameter angegebenen Format enthält (Standard ist PNG). Das zurückgegebene Bild hat eine Auflösung von 96 dpi.

```java
public String ToDataURL()
```

### Rückgabewert

Ein DOMString, der die angeforderte data-URI enthält.

## ToDataURL(String, double) {#todataurl_2}

gibt eine Daten-URI zurück, die eine Darstellung des Bildes im durch den Typ-Parameter angegebenen Format enthält (Standard ist PNG). Das zurückgegebene Bild hat eine Auflösung von 96 dpi.

```java
public String ToDataURL(String type, double encoderOptions)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| Typ | String | Ein String, der das Bildformat angibt. Der Standardformattyp ist image/png. |
| encoderOptions | Double | Eine Zahl zwischen 0 und 1, die die Bildqualität angibt, wenn der angeforderte Typ image/jpeg oder image/webp ist. |

### Rückgabewert

Ein DOMString, der die angeforderte data-URI enthält.
