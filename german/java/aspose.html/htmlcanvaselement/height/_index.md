## HTMLCanvasElement.Height property

Ist eine positive ganze Zahl, die das height-HTML-Attribut des Canvas-Elements in CSS-Pixeln widerspiegelt. Wenn das Attribut nicht angegeben ist oder einen ungültigen Wert, wie einen negativen, hat, wird der Standardwert 150 verwendet.

```java
public ulong Height { get; set; }
```
