## HTMLCanvasElement.Width property

Ist eine positive ganze Zahl, die das width-HTML-Attribut des Canvas-Elements in CSS-Pixeln widerspiegelt. Wenn das Attribut nicht angegeben ist oder einen ungültigen Wert, wie einen negativen, hat, wird der Standardwert 300 verwendet.

```java
public ulong Width { get; set; }
```
