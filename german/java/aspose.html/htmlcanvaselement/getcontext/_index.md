## HTMLCanvasElement.GetContext method

Gibt einen Zeichenkontext für das Canvas zurück, oder null, wenn die Kontext-ID nicht unterstützt wird. Ein Zeichenkontext ermöglicht das Zeichnen auf dem Canvas.

```java
public object GetContext(String contextId)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| contextId | String | Ist ein String, der den Kontextbezeichner enthält, der den dem Canvas zugeordneten Zeichenkontext definiert. |

### Rückgabewert

Ein RenderingContext
