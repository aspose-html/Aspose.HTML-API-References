Das **com.aspose.html.saving.ResourceHandlers** Paket enthält Klassen, die für die Handhabung von Ressourcen verantwortlich sind.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [FileSystemResourceHandler](./filesystemresourcehandler/) | Diese Klasse ist eine Implementierung der Klasse [`ResourceHandler`](../com.aspose.html.saving.resourcehandlers/resourcehandler/), die dazu dient, Ressourcen im lokalen Dateisystem zu speichern. |
| [ResourceHandler](./resourcehandler/) | Diese Klasse ist für die Handhabung von Ressourcen verantwortlich. Sie stellt Methoden bereit, mit denen Sie steuern können, was mit dem [`Resource`](../com.aspose.html.saving/resource/) geschehen soll, sowie welchen Verweis das übergeordnete [`Resource`](../com.aspose.html.saving/resource/) erhalten wird. |
