## ResourceHandler class

Diese Klasse ist für die Verarbeitung von Ressourcen verantwortlich. Sie stellt Methoden bereit, die es Ihnen ermöglichen zu steuern, was mit dem [`Resource`](../../com.aspose.html.saving/resource/) geschehen soll, sowie welche Referenz in die übergeordnete [`Resource`](../../com.aspose.html.saving/resource/) geschrieben wird.
