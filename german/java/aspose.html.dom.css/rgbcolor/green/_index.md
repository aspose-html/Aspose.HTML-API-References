## RGBColor.Green property

Gibt den Grün‑Komponentenwert dieser Color-Struktur zurück.

```java
public CSSPrimitiveValue Green { get; }
```

### Property Value

Der Grünkomponentenwert dieses Color.

## Hinweise

Die Farbe jedes Pixels wird als 32‑Bit‑Zahl dargestellt: jeweils 8 Bit für Alpha, Rot, Grün und Blau (ARGB). Die Alpha‑Komponente gibt die Transparenz der Farbe an: 0 ist vollständig transparent und 255 ist vollständig undurchsichtig. Ebenso stellt ein A‑Wert von 255 eine undurchsichtige Farbe dar. Ein A‑Wert von 1 bis 254 stellt eine halbtransparente Farbe dar. Die Farbe wird undurchsichtiger, je näher A an 255 kommt.
