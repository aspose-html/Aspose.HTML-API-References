## SetProperty(String, String) {#setproperty}

Die CSSStyleDeclaration.setProperty()‑Methodenschnittstelle wird verwendet, um einen Eigenschaftswert mit Standardpriorität innerhalb dieses Deklarationsblocks zu setzen. Die Standardpriorität ist nicht "important", d. h. String.Empty.

```java
public void SetProperty(String propertyName, String value)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| propertyName | String | Ein String, der den zu ändernden CSS-Eigenschaftsnamen (mit Bindestrichen) darstellt. |
| Wert | String | Ein String, der den neuen Eigenschaftswert enthält. Wenn nicht angegeben, wird er als leerer String behandelt. |

## SetProperty(String, String, String) {#setproperty_1}

Die CSSStyleDeclaration.setProperty()‑Methodenschnittstelle wird verwendet, um einen Eigenschaftswert mit Standardpriorität innerhalb dieses Deklarationsblocks zu setzen. Die Standardpriorität ist nicht "important", d. h. String.Empty.

```java
public void SetProperty(String propertyName, String value, String priority)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| propertyName | String | Ein String, der den zu ändernden CSS-Eigenschaftsnamen (mit Bindestrichen) darstellt. |
| Wert | String | Ein String, der den neuen Eigenschaftswert enthält. Wenn nicht angegeben, wird er als leerer String behandelt. |
| Priorität | String | Ein String, der das Setzen der CSS-Priorität "important" ermöglicht. Wenn nicht angegeben, wird er als leerer String behandelt. Die folgenden Werte werden akzeptiert: String-Wert "important", Schlüsselwort undefined oder leerer String "". |
