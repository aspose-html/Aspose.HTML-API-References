## ICSSStyleDeclaration.Length property

Die schreibgeschützte Eigenschaft gibt eine ganze Zahl der Eigenschaften zurück, die in diesem CSS-Deklarationsblock explizit gesetzt wurden. Der Bereich gültiger Indizes ist 0 bis length-1 inklusive.

```java
public int Length { get; }
```

### Property Value

Eine ganze Zahl, die die Anzahl der Stile angibt, die explizit am übergeordneten Element der Instanz gesetzt wurden.
