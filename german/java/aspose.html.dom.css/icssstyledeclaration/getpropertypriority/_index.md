## ICSSStyleDeclaration.GetPropertyPriority method

Wird verwendet, um die Priorität einer CSS‑Eigenschaft (z. B. das \"important\"‑Qualifizierer) abzurufen, wenn die Eigenschaft in diesem Deklarationsblock explizit gesetzt wurde.

```java
public String GetPropertyPriority(String propertyName)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| propertyName | String | property ist ein DOMString, der den zu prüfenden Eigenschaftsnamen darstellt. |

### Rückgabewert

priority ist ein DOMString, der die Priorität (z. B. "important") darstellt, falls vorhanden. Wenn keine vorhanden ist, wird ein leerer String zurückgegeben.
