## ICSSStyleDeclaration.GetPropertyValue method

Die CSSStyleDeclaration.getPropertyValue()‑Methodenschnittstelle gibt einen String zurück, der den Wert einer angegebenen CSS‑Eigenschaft enthält.

```java
public String GetPropertyValue(String propertyName)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| propertyName | String | propertyName ist ein String, der den Eigenschaftsnamen (mit Bindestrichen) darstellt, der geprüft werden soll. |

### Rückgabewert

value ist ein String, der den Wert der Eigenschaft enthält. Wenn nicht gesetzt, wird ein leerer String zurückgegeben.
