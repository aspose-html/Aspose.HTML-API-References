## ICSSStyleSheet.CSSRules property

Die schreibgeschützte CSSStyleSheet-Eigenschaft cssRules gibt eine Live‑[`CSSRuleList`](../../icssrulelist/) zurück, die eine Echtzeit‑Liste aller CSS‑Regeln, aus denen das Stylesheet besteht, bereitstellt. Jeder Eintrag in der Liste ist ein [`CSSRule`](../../icssrule/), das eine einzelne Regel definiert.

```java
public ICSSRuleList CSSRules { get; }
```

### Property Value

Eine live‑aktualisierende [`CSSRuleList`](../../icssrulelist/), die alle CSS‑Regeln des Stylesheets enthält. Jeder Eintrag in der Regel‑Liste ist ein [`CSSRule`](../../icssrule/)-Objekt, das eine Regel des Stylesheets beschreibt.
