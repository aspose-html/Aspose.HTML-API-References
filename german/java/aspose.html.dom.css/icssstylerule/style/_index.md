## ICSSStyleRule.Style property

Die schreibgeschützte style-Eigenschaft ist die [`CSSStyleDeclaration`](../../icssstyledeclaration/) Schnittstelle für den Deklarationsblock der [`CSSStyleRule`](../).

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

Das style-Attribut muss ein CSSStyleDeclaration-Objekt für die Stilregel zurückgeben, mit den folgenden Eigenschaften:

computed flag - Unset.declarations - Die deklarierten Deklarationen in der Regel, in angegebener Reihenfolge.parent CSS rule - Das Kontextobjekt.owner node - Null.
