## ICSSStyleRule interface

Das CSSStyleRule-Interface stellt eine einzelne CSS-Stilregel dar. Das Attribut selectorText muss beim Auslesen das Ergebnis der Serialisierung der zugehörigen Selektorgruppe zurückgeben.

```java
public interface ICSSStyleRule : ICSSRule
```

| Name | Beschreibung |
| --- | --- |
| [getSelectorText](../../com.aspose.html.dom.css/icssstylerule/selectortext/) Die textuelle Darstellung des Selektors für das Regelset. Die Implementierung könnte beim Parsen des Selektors unbedeutende Leerzeichen entfernt haben. |
