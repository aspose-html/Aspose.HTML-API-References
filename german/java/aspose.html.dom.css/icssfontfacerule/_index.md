## ICSSFontFaceRule interface

Das CSSFontFaceRule‑Interface repräsentiert eine @font-face‑Regel in einem CSS‑Stylesheet. Die @font-face‑Regel wird verwendet, um eine Menge von Schriftbeschreibungen zu enthalten.

```java
public interface ICSSFontFaceRule : ICSSRule
```
