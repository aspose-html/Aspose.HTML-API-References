## ICSSPageRule.Style property

Dieses stellt ein Objekt dar, das einen CSS‑Deklarationsblock bildet und Stilinformationen sowie verschiedene stilbezogene Methoden und Eigenschaften bereitstellt.

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

Ein [`CSSStyleDeclaration`](../../icssstyledeclaration/)‑Objekt, das einen CSS‑Deklarationsblock darstellt.
