## ICSSPageRule interface

Das CSSPageRule‑Interface repräsentiert eine @page‑Regel innerhalb eines CSS‑Stylesheets. Die @page‑Regel wird verwendet, um die Abmessungen, Ausrichtung, Ränder usw. eines Seitenkastens für paginiertes Medium festzulegen.

public interface ICSSPageRule : ICSSRule
