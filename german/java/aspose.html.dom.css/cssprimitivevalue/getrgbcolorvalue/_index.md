## CSSPrimitiveValue.GetRGBColorValue method

Diese Methode wird verwendet, um die RGB‑Farbe zu erhalten. Wenn dieser CSS-Wert keinen RGB‑Farbwert enthält, wird eine DOMException ausgelöst. Änderungen an der entsprechenden Style-Eigenschaft können über das RGBColor-Interface vorgenommen werden.

```java
public abstract RGBColor GetRGBColorValue()
```

### Rückgabewert

Gibt RGB-Farbwert zurück
