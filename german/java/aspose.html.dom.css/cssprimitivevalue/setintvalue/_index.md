## CSSPrimitiveValue.SetIntValue method

Eine Methode, um den Ganzzahlwert mit einer angegebenen Einheit zu setzen. Wenn die mit diesem Wert verbundene Eigenschaft die angegebene Einheit oder den Ganzzahlwert nicht akzeptieren kann, bleibt der Wert unverändert und es wird eine DOMException ausgelöst.

```java
public abstract void SetIntValue(ushort unitType, int intValue)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| unitType | UInt16 | Typ der Einheit. |
| intValue | Int32 | Der int-Wert. |
