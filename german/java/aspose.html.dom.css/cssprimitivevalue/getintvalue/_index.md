## CSSPrimitiveValue.GetIntValue method

Diese Methode wird verwendet, um einen Ganzzahlwert in einer angegebenen Einheit zu erhalten. Wenn dieser CSS-Wert keinen Ganzzahlwert enthält oder nicht in die angegebene Einheit konvertiert werden kann, wird eine DOMException ausgelöst.

```java
public abstract int GetIntValue(ushort unitType)
```
