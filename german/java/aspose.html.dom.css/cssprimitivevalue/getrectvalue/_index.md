## CSSPrimitiveValue.GetRectValue method

Diese Methode wird verwendet, um den Rect-Wert zu erhalten. Wenn dieser CSS-Wert keinen Rect-Wert enthält, wird eine DOMException ausgelöst. Änderungen an der entsprechenden Stil-Eigenschaft können über das Rect-Interface vorgenommen werden.

```java
public abstract Rect GetRectValue()
```

### Rückgabewert

Gibt Rect‑Wert zurück
