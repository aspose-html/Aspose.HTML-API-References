## ICSSRule.Type property

Der Typ der Regel, wie in [CSSOM # dom-cssrule-type](https://drafts.csswg.org/cssom/#dom-cssrule-type) definiert. Es wird erwartet, dass bindungsspezifische Cast‑Methoden verwendet werden können, um von einer Instanz des CSSRule‑Interfaces auf das spezifische abgeleitete Interface zu casten, das durch den Typ impliziert wird.

```java
public short Type { get; }
```

### Property Value

Eine nicht‑negative Ganzzahl, die einem bestimmten Regeltyp zugeordnet ist. Dieses Element wird beim Erstellen einer Regel initialisiert und kann nicht geändert werden.
