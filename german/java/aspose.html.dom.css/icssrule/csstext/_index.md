## ICSSRule.CSSText property

Die cssText-Eigenschaft des [`CSSRule`](../)-Interfaces gibt den tatsächlichen Text einer [`CSSStyleSheet`](../../icssstylesheet/)-Style-Regel zurück.

Hinweis: Verwechseln Sie diese Eigenschaft nicht mit dem elementbezogenen CSSStyleDeclaration.cssText.

```java
public String CSSText { get; set; }
```

### Property Value

Gibt eine Serialisierung der CSS-Regel zurück. Beim Setzen des cssText-Attributs darf nichts geschehen.
