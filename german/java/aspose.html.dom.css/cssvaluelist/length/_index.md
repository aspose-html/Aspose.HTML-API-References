## CSSValueList.Length property

Die schreibgeschützte Eigenschaft length des CSSValueList‑Interfaces gibt die Anzahl der CSSValues in der Liste an. Der gültige Wertebereich der Indizes ist von 0 bis length‑1 inklusive.

```java
public int Length { get; }
```

### Property Value

Ein unsigned long, das die Anzahl der CSSValues in der aktuellen Instanz darstellt.
