## CSSValueList.CSSText property

Die cssText‑Eigenschaft des [`CSSValue`](../../cssvalue/)‑Interfaces stellt den aktuell berechneten CSS‑Eigenschaftswert dar.

Hinweis: Diese Eigenschaft war Teil eines Versuchs, ein typisiertes CSS-Objektmodell zu erstellen. Dieser Versuch wurde aufgegeben, und die meisten Browser implementieren es nicht.

```java
public String CSSText { get; set; }
```

### Property Value

Ein DOMString, der den aktuellen CSS‑Eigenschaftswert darstellt.
