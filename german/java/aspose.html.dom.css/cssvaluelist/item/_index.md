## CSSValueList indexer

Die item()-Methode des CSSValueList‑Interfaces wird verwendet, um einen CSSValue anhand eines ordinalen Index abzurufen.

Die Reihenfolge in dieser Sammlung entspricht der Reihenfolge der Werte in der CSS‑Stil‑Eigenschaft. Ist der Index größer oder gleich der Anzahl der Werte in der Liste, gibt diese Methode null zurück.

```java
public CSSValue this[int index] { get; }
```

### Rückgabewert

Ein CSSValue‑Objekt an der Indexposition in der CSSValueList oder null, falls dies kein gültiger Index ist.

### Property Value

Ein unsigned long, das den Index des CSS‑Werts innerhalb der Sammlung darstellt.
