## ICSSRuleList indexer

Wird verwendet, um eine CSS-Regel mittels der Methode item() (http://www.w3.org/TR/DOM-Level-2-Style/css.html#CSS-CSSRuleList) abzurufen. Die Reihenfolge in dieser Sammlung entspricht der Reihenfolge der Regeln im CSS-Stylesheet. Wenn der Index größer oder gleich der Anzahl der Regeln in der Liste ist, wird null zurückgegeben.

```java
public ICSSRule this[int index] { get; }
```

### Rückgabewert

Die item(index)-Methode muss das CSSRule-Objekt an der angegebenen Indexposition in der Sammlung zurückgeben. Wenn kein Objekt an dieser Indexposition existiert, muss die Methode null zurückgeben.

### Property Value

Der Index in der Sammlung von CSS-Regeln.
