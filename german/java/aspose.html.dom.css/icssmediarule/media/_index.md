## ICSSMediaRule.Media property

Die schreibgeschützte media-Eigenschaft des [`CSSMediaRule`](../)-Interfaces MediaList stellt das beabsichtigte Zielmedium für Stilinformationen dar.

```java
public IMediaList Media { get; }
```

### Property Value

Das media-Attribut muss ein MediaList-Objekt für die Liste der mit der @media-Anweisung angegebenen Medienabfragen zurückgeben.
