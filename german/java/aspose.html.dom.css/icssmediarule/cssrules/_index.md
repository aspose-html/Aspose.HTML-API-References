## ICSSMediaRule.CSSRules property

Die cssRules-Eigenschaft des CSSGroupingRule-Interfaces gibt eine [`CSSRuleList`](../../icssrulelist/) zurück, die eine Sammlung von [`CSSRule`](../../icssrule/)‑Objekten enthält.

```java
public ICSSRuleList CSSRules { get; }
```

### Property Value

Das cssRules-Attribut muss ein [`CSSRuleList`](../../icssrulelist/)-Objekt für die untergeordneten CSS-Regeln zurückgeben.
