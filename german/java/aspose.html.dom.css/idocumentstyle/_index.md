## IDocumentStyle interface

Das DocumentStyle-Interface bietet einen Mechanismus, über den die in ein Dokument eingebetteten Stylesheets abgerufen werden können. Es wird erwartet, dass eine Instanz des DocumentStyle-Interfaces mittels bindungsspezifischer Cast-Methoden auf einer Instanz des Document-Interfaces erhalten werden kann.

Siehe auch die [Document Object Model (DOM) Level 2 Style Specification](http://www.w3.org/TR/2000/REC-DOM-Level-2-Style-20001113).
