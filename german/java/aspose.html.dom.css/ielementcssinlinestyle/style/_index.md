## IElementCSSInlineStyle.Style property

Das style-Attribut muss ein CSS-Deklarationsblock-Objekt zurückgeben, dessen berechnete Flagge nicht gesetzt ist, dessen übergeordnete CSS-Regel null ist und dessen Eigentums‑Knoten das Kontextobjekt ist.

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

Der zugehörige CSS-Deklarationsblock für den Knoten oder null, wenn kein zugehöriger CSS-Deklarationsblock vorhanden ist.
