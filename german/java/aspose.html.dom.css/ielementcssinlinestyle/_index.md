## IElementCSSInlineStyle interface

Inline-Stilinformationen, die an Elementen angehängt sind, werden über das style-Attribut bereitgestellt. Dies stellt den Inhalt des STYLE-Attributs für HTML-Elemente dar (oder für Elemente in anderen Schemata oder DTDs, die das STYLE-Attribut auf dieselbe Weise verwenden). Es wird erwartet, dass eine Instanz des ElementCSSInlineStyle-Interfaces mittels bindungsspezifischer Cast-Methoden auf einer Instanz des Element-Interfaces erhalten werden kann, wenn das Element Inline-CSS-Stilinformationen unterstützt.

Siehe auch das [CSS Object Model (CSSOM) # IElementCSSInlineStyle](https://www.w3.org/TR/cssom-1/#the-elementcssinlinestyle-mixin)
