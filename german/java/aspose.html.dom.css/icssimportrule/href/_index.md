## ICSSImportRule.Href property

Die schreibgeschützte href‑Eigenschaft des CSSImportRule‑Interfaces gibt die durch die @import‑At‑Rule angegebene URL zurück.

Die aufgelöste URL wird das href‑Attribut des zugehörigen Stylesheets sein.

```java
public String Href { get; }
```

### Property Value

Gibt die URL des durch die @import‑At‑Rule angegebenen zugehörigen Stylesheets zurück.
