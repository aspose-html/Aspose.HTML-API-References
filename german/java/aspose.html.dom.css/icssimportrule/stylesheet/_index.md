## ICSSImportRule.StyleSheet property

Das Stylesheet, auf das sich diese Regel bezieht, wenn es geladen wurde. Der Wert dieses Attributs ist null, wenn das Stylesheet noch nicht geladen wurde oder nicht geladen wird (z. B. wenn das Stylesheet für einen Medientyp bestimmt ist, der vom User-Agent nicht unterstützt wird).

```java
public ICSSStyleSheet StyleSheet { get; }
```

### Property Value

Gibt das durch die @import‑At‑Rule angegebene CSS‑Stylesheet zurück. Es wird in Form eines [`CSSStyleSheet`](../../icssstylesheet/)-Objekts vorliegen.
