## ICSSKeyframesRule.DeleteRule method

Die deleteRule‑Methode löscht das [`CSSKeyframeRule`](../../icsskeyframerule/) mit dem übergebenen Schlüssel. Existiert keine Regel mit diesem Schlüssel, tut die Methode nichts.

```java
public void DeleteRule(String key)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| Key | String | Der Schlüssel, der die zu löschende Regel beschreibt. Der Schlüssel muss eine Zahl zwischen 0 und 1 ergeben, andernfalls wird die Regel ignoriert. |
