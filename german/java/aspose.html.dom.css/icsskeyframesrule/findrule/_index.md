## ICSSKeyframesRule.FindRule method

Die Methode findRule gibt die Regel zurück, deren Schlüssel dem übergebenen Schlüssel entspricht. Gibt es keine solche Regel, wird ein Nullwert zurückgegeben.

```java
public ICSSKeyframeRule FindRule(String key)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| key | String | Der Schlüssel, der die zu findende Regel beschreibt. Der Schlüssel muss sich in eine Zahl zwischen 0 und 1 auflösen, andernfalls wird die Regel ignoriert. |

### Rückgabewert

Gibt das zuletzt deklarierte [`CSSKeyframeRule`](../../icsskeyframerule/) zurück, das dem angegebenen Keyframe‑Selektor entspricht. Wenn keine passende Regel existiert, tut die Methode nichts.
