## IMediaList.AppendMedium method

Fügt das Medium newMedium am Ende der Liste hinzu. Wenn das newMedium bereits verwendet wird, wird es zuerst entfernt.

```java
public void AppendMedium(String newMedium)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| newMedium | String | Das neue Medium, das hinzugefügt werden soll. |

### Ausnahmen

| Ausnahme | Bedingung |
| --- | --- |
| DOMException | INVALID_CHARACTER_ERR: Wenn das Medium Zeichen enthält, die in der zugrunde liegenden Stylesprache ungültig sind. NO_MODIFICATION_ALLOWED_ERR: Wird ausgelöst, wenn diese Liste schreibgeschützt ist. |
