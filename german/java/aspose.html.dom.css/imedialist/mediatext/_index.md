## IMediaList.MediaText property

Ein Stringifier, der einen DOMString zurückgibt, der die MediaList als Text darstellt, und außerdem das Setzen einer neuen MediaList ermöglicht.

```java
public String MediaText { get; }
```

### Property Value

Die parsbare textuelle Darstellung der Medienliste. Dies ist eine kommagetrennte Liste von Medien.

### Ausnahmen

| Ausnahme | Bedingung |
| --- | --- |
| DOMException | SYNTAX_ERR: Wird ausgelöst, wenn der angegebene String-Wert einen Syntaxfehler enthält und nicht geparst werden kann. NO_MODIFICATION_ALLOWED_ERR: Wird ausgelöst, wenn diese Medienliste schreibgeschützt ist. |
