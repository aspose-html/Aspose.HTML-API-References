## IMediaList.Length property

Das Attribut length muss die Anzahl der Media Queries in der Sammlung von Media Queries zurückgeben. Der gültige Bereich für Media ist 0 bis length‑1 inklusive.

```java
public long Length { get; }
```

### Property Value

Gibt die Anzahl der Media Queries in der [`MediaList`](../) zurück.
