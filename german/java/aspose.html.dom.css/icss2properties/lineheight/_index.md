## ICSS2Properties.LineHeight property

Wenn die Eigenschaft auf ein [block-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#block-level) Element angewendet wird, dessen Inhalt aus [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) Elementen besteht, gibt sie die minimale Höhe jeder erzeugten Inline‑Box an.

Wenn die Eigenschaft auf ein [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) Element angewendet wird, gibt sie die exakte Höhe jeder vom Element erzeugten Box an. (Ausgenommen Inline‑[replaced](https://www.w3.org/TR/1998/REC-CSS2-19980512/conform.html#replaced-element) Elemente, bei denen die Höhe der Box durch die ['height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-height)-Eigenschaft bestimmt wird.)

```java
public String LineHeight { get; set; }
```
