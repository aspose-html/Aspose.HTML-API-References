## ICSS2Properties.BackgroundImage property

Diese Eigenschaft legt das Hintergrundbild eines Elements fest. Beim Festlegen eines Hintergrundbildes sollten Autoren auch eine Hintergrundfarbe angeben, die verwendet wird, wenn das Bild nicht verfügbar ist. Ist das Bild verfügbar, wird es über der Hintergrundfarbe gerendert. (Damit ist die Farbe in den transparenten Bereichen des Bildes sichtbar).

```java
public String BackgroundImage { get; set; }
```

### Rückgabewert

background-image-Eigenschaft

### Property Value

Werte für diese Eigenschaft sind entweder , um das Bild anzugeben, oder 'none', wenn kein Bild verwendet wird.
