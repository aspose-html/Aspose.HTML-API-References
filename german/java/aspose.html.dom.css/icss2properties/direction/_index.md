## ICSS2Properties.Direction property

Diese Eigenschaft legt die Grundschreibrichtung von Blöcken sowie die Richtung von Einbettungen und Overrides fest (siehe ['unicode-bidi'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-unicode-bidi)) für den Unicode‑Bidirektional‑Algorithmus. Zusätzlich gibt sie die Richtung des [table](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html) Spalten‑Layouts, die Richtung des horizontalen [overflow](https://www.w3.org/TR/1998/REC-CSS2-19980512/visufx.html#overflow) und die Position einer unvollständigen letzten Zeile in einem Block im Falle von 'text-align: justify' an.

```java
public String Direction { get; set; }
```
