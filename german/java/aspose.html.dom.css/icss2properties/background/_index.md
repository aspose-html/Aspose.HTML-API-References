## ICSS2Properties.Background property

Die 'background'-Eigenschaft ist eine Kurzschreibweise zum Festlegen der einzelnen background-Eigenschaften (z. B. 'background-color', 'background-image', 'background-repeat', 'background-attachment' und 'background-position') an derselben Stelle im Stylesheet.

```java
public String Background { get; set; }
```

### Rückgabewert

die background-Eigenschaft

### Property Value

Ruft eine Kurzschreibweise ab oder legt sie fest, um die einzelnen background-Eigenschaften an derselben Stelle im Stylesheet zu setzen.
