## ICSS2Properties.TextDecoration property

Diese Eigenschaft beschreibt Dekorationen, die dem Text eines Elements hinzugefügt werden. Wenn die Eigenschaft für ein [block-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#block-level)-Element angegeben wird, wirkt sie sich auf alle Inline‑Nachfahren des Elements aus. Wenn sie für ein [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level)-Element angegeben wird (oder dieses beeinflusst), wirkt sie sich auf alle vom Element erzeugten Boxen aus. Hat das Element keinen Inhalt oder keinen Textinhalt (z. B. das IMG‑Element in HTML), müssen Benutzeragenten diese Eigenschaft [ignorieren](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#ignore).

Die Werte haben die folgende Bedeutung:

none - Erzeugt keine Textdekoration. underline - Jede Textzeile wird unterstrichen. overline - Jede Textzeile hat eine Linie darüber. line-through - Jede Textzeile hat eine Linie durch die Mitte. blink - Text blinkt (wechselt zwischen sichtbar und unsichtbar).
