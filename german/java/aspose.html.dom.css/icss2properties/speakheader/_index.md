## ICSS2Properties.SpeakHeader property

Diese Eigenschaft gibt an, ob Tabellenüberschriften vor jeder Zelle gesprochen werden oder nur vor einer Zelle, wenn diese Zelle mit einer anderen Überschrift als der vorherigen Zelle verknüpft ist. Werte haben die folgende Bedeutung:

once - Die Überschrift wird einmal gesprochen, bevor eine Reihe von Zellen folgt.always - Die Überschrift wird vor jeder relevanten Zelle gesprochen.

```java
public String SpeakHeader { get; set; }
```
