## ICSS2Properties.SpeakNumeral property

Diese Eigenschaft steuert, wie Ziffern ausgesprochen werden. Werte haben die folgende Bedeutung:

digits – Spricht die Ziffern als einzelne Ziffern aus. So wird \"237\" als \"Zwei Drei Sieben\" ausgesprochen. continuous – Spricht die Ziffer als ganze Zahl aus. So wird \"237\" als \"Zweihundertsiebenunddreißig\" ausgesprochen. Wortdarstellungen sind sprachabhängig.

```java
public String SpeakNumeral { get; set; }
```
