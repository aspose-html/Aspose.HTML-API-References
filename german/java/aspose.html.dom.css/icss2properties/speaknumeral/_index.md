## ICSS2Properties.SpeakNumeral property

Diese Eigenschaft steuert, wie Zahlen ausgesprochen werden. Werte haben die folgende Bedeutung:

digits – Die Zahl wird als einzelne Ziffern ausgesprochen. So wird "237" als "Zwei Drei Sieben" gesprochen. continuous – Die Zahl wird als ganze Zahl ausgesprochen. So wird "237" als "Zweihundertsiebenunddreißig" gesprochen. Wortdarstellungen sind sprachabhängig.

```java
public String SpeakNumeral { get; set; }
```
