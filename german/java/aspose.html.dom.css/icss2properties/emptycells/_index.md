## ICSS2Properties.EmptyCells property

Im Modell der getrennten Rahmen steuert diese Eigenschaft die Darstellung von Rahmen um Zellen, die keinen sichtbaren Inhalt haben. Leere Zellen und Zellen, bei denen die 'visibility'-Eigenschaft auf 'hidden' gesetzt ist, werden als ohne sichtbaren Inhalt betrachtet.

public String EmptyCells { get; set; }
