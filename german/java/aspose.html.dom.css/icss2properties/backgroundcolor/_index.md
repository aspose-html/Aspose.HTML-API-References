## ICSS2Properties.BackgroundColor property

Diese Eigenschaft legt die Hintergrundfarbe eines Elements fest, entweder als Wert oder mit dem Schlüsselwort "transparent", um die darunter liegenden Farben durchscheinen zu lassen.

```java
public String BackgroundColor { get; set; }
```

### Rückgabewert

background-color Eigenschaft

### Property Value

Eine Farbe ist entweder ein Schlüsselwort oder eine numerische RGB‑Spezifikation.
