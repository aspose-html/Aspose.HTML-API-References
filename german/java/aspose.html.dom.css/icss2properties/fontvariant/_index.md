## ICSS2Properties.FontVariant property

In einer Small-Caps-Schrift sehen die Glyphen für Kleinbuchstaben den Großbuchstaben ähnlich, jedoch in kleinerer Größe und mit leicht anderen Proportionen. Die 'font-variant'-Eigenschaft fordert eine solche Schrift für bikamerale Schriften (mit zwei Schriftsystemen, wie die lateinische Schrift) an. Diese Eigenschaft hat keine sichtbare Wirkung bei Skripten, die unikamer sind (mit nur einem Schriftsystem, wie bei den meisten Schriftsystemen der Welt).

```java
public String FontVariant { get; set; }
```
