## ICSS2Properties.Font property

Die 'font'-Eigenschaft ist, außer wie unten beschrieben, eine Kurzschreibweise zum Festlegen von 'font-style', 'font-variant', 'font-weight', 'font-size', 'line-height' und 'font-family' an derselben Stelle im Stylesheet. Die Syntax dieser Eigenschaft basiert auf einer traditionellen typografischen Kurzschreibweise, um mehrere eigenschaftenbezogene Einstellungen für Schriften zu setzen.

```java
public String Font { get; set; }
```
