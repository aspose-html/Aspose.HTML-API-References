## ICSS2Properties.MinHeight property

Diese beiden Eigenschaften ermöglichen es Autoren, die Höhe von Boxen auf einen bestimmten Bereich zu beschränken. Werte haben die folgende Bedeutung:

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - Gibt eine feste minimale oder maximale berechnete Höhe an.'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - Gibt einen Prozentsatz zur Bestimmung des berechneten Wertes an. Der Prozentsatz wird in Bezug auf die Höhe des erzeugten Box-[containing block](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#containing-block) berechnet. Wenn die Höhe des enthaltenden Blocks nicht explizit angegeben ist (d. h. sie hängt von der Inhalts­höhe ab), wird der Prozentwert wie 'auto' interpretiert.none - (Nur bei ['max-height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-max-height)) Keine Begrenzung der Boxhöhe.
