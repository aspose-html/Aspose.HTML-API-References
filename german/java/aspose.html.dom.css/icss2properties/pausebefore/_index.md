## ICSS2Properties.PauseBefore property

Diese Eigenschaften geben eine Pause an, die vor (oder nach) dem Vorlesen des Inhalts eines Elements eingehalten werden soll. Die Werte haben die folgende Bedeutung:

'[time](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-time)' - Gibt die Pause in absoluten Zeiteinheiten (Sekunden und Millisekunden) an.'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - Bezieht sich auf das Inverse des Wertes der ['speech-rate'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-speech-rate)-Eigenschaft. Zum Beispiel, wenn die Sprachrate 120 Wörter pro Minute beträgt (d.h. ein Wort dauert eine halbe Sekunde, oder 500 ms), dann bedeutet ein ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) von 100 % eine Pause von 500 ms und ein ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) von 20 % bedeutet 100 ms.
