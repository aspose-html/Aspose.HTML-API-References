## ICSS2Properties.Speak property

Diese Eigenschaft gibt an, ob Text auditiv wiedergegeben wird und, falls ja, in welcher Weise (etwa analog zur ['display'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-display) Eigenschaft). Die möglichen Werte sind:

none - Unterdrückt die auditive Wiedergabe, sodass das Element keine Zeit zum Rendern benötigt. Beachten Sie jedoch, dass Nachfahren diesen Wert überschreiben können und gesprochen werden. (Um sicherzustellen, dass die Wiedergabe eines Elements und seiner Nachfahren unterdrückt wird, verwenden Sie die ['display'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-display) Eigenschaft).normal - Verwendet sprachabhängige Ausspracheregeln für die Wiedergabe eines Elements und seiner Kinder.spell-out - Buchstabiert den Text Buchstabe für Buchstabe (nützlich für Akronyme und Abkürzungen).

public String Speak { get; set; }
