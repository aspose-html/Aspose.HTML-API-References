## ICSS2Properties.SpeakPunctuation property

Diese Eigenschaft gibt an, wie Satzzeichen ausgesprochen werden. Werte haben die folgende Bedeutung:

code - Satzzeichen wie Semikolons, geschweifte Klammern usw. sollen wörtlich ausgesprochen werden. none - Satzzeichen werden nicht ausgesprochen, sondern natürlich als verschiedene Pausen wiedergegeben.

```java
public String SpeakPunctuation { get; set; }
```
