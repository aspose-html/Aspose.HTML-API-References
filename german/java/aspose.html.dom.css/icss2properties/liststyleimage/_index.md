## ICSS2Properties.ListStyleImage property

Diese Eigenschaft legt das Bild fest, das als Listenelement-Marker verwendet wird. Wenn das Bild verfügbar ist, ersetzt es den mit ['list-style-type'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-list-style-type) festgelegten Marker.

```java
public String ListStyleImage { get; set; }
```
