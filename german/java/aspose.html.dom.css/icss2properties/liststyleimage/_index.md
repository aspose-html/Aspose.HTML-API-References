## ICSS2Properties.ListStyleImage property

Diese Eigenschaft legt das Bild fest, das als Aufzählungszeichen verwendet wird. Wenn das Bild verfügbar ist, ersetzt es das mit dem ['list-style-type'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-list-style-type) Zeichen.

```java
public String ListStyleImage { get; set; }
```
