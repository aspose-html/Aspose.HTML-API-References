## ICSS2Properties.BorderRightWidth property

Diese Eigenschaft ist eine Kurzschreibweise zum Festlegen von 'border-top-width', 'border-right-width', 'border-bottom-width' und 'border-left-width' an derselben Stelle im Stylesheet.

Wenn nur ein Wert angegeben ist, gilt er für alle Seiten. Wenn zwei Werte angegeben sind, werden die oberen und unteren Ränder auf den ersten Wert gesetzt und die rechten und linken auf den zweiten. Wenn drei Werte angegeben sind, wird der obere Rand auf den ersten Wert gesetzt, die linken und rechten Ränder auf den zweiten und der untere Rand auf den dritten. Wenn vier Werte angegeben sind, gelten sie für oben, rechts, unten und links in dieser Reihenfolge.

```java
public String BorderRightWidth { get; set; }
```
