## ICSS2Properties.CounterIncrement property

Die ['counter-increment'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-counter-increment)-Eigenschaft akzeptiert einen oder mehrere Namen von Zählern (Identifikatoren), von denen jeder optional von einer Ganzzahl gefolgt werden kann. Die Ganzzahl gibt an, um wie viel der Zähler bei jedem Auftreten des Elements erhöht wird. Der Standardinkrementwert ist 1. Null und negative Ganzzahlen sind zulässig.

```java
public String CounterIncrement { get; set; }
```
