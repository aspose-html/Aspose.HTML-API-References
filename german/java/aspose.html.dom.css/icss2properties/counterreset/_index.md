## ICSS2Properties.CounterReset property

Die ['counter-reset'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-counter-reset) Eigenschaft enthält außerdem eine Liste von einem oder mehreren Namen von Zählern, von denen jeder optional von einer Ganzzahl gefolgt wird. Die Ganzzahl gibt den Wert an, auf den der Zähler bei jedem Auftreten des Elements gesetzt wird. Der Standardwert ist 0.

```java
public String CounterReset { get; set; }
```
