## ICSS2Properties.FontFamily property

Diese Eigenschaft gibt eine priorisierte Liste von Schriftfamiliennamen und/oder generischen Familiennamen an. Um das Problem zu lösen, dass eine einzelne Schriftart möglicherweise nicht alle Glyphen zur Darstellung aller Zeichen in einem Dokument enthält, oder dass nicht alle Schriftarten auf allen Systemen verfügbar sind, ermöglicht diese Eigenschaft Autoren, eine Liste von Schriftarten desselben Stils und derselben Größe anzugeben, die nacheinander ausprobiert werden, um zu prüfen, ob sie ein Glyph für ein bestimmtes Zeichen enthalten. Diese Liste wird als Font-Set bezeichnet.

```java
public String FontFamily { get; set; }
```
