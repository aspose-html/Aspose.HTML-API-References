## ICSS2Properties.PitchRange property

Gibt die Variation der durchschnittlichen Tonhöhe an. Die wahrgenommene Tonhöhe einer menschlichen Stimme wird durch die Grundfrequenz bestimmt und liegt typischerweise bei 120 Hz für eine männliche Stimme und 210 Hz für eine weibliche Stimme. Menschliche Sprachen werden mit unterschiedlicher Intonation und Tonhöhe gesprochen; diese Variationen vermitteln zusätzliche Bedeutung und Betonung. Daher weist eine stark ausdrucksvolle Stimme, d. h. eine stark modulierte Stimme, einen großen Tonhöhenbereich auf. Diese Eigenschaft gibt den Bereich an, in dem diese Variationen auftreten, d. h. wie stark die Grundfrequenz von der durchschnittlichen Tonhöhe abweichen kann.

```java
public String PitchRange { get; set; }
```
