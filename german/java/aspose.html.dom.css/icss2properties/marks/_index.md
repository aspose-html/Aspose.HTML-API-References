## ICSS2Properties.Marks property

Beim hochwertigen Druck werden Markierungen häufig außerhalb der Seitenbox hinzugefügt. Diese Eigenschaft gibt an, ob Kreuzmarken, Schnittmarken oder beide direkt außerhalb der Kante der [Seitenbox](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#page-box) gerendert werden sollen.

Schnittmarken zeigen an, wo die Seite geschnitten werden soll. Kreuzmarken (auch als Registermarken oder Registrierungsmarken bekannt) werden zum Ausrichten von Bögen verwendet.

Markierungen sind nur auf absoluten Seitenboxen sichtbar (siehe die ['size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-size)-Eigenschaft). In relativen Seitenboxen wird die Seitenbox am Ziel ausgerichtet und die Markierungen befinden sich außerhalb des druckbaren Bereichs.

Die Größe, der Stil und die Position von Kreuzmarkierungen hängen vom User-Agent ab.
