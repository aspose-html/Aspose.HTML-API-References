## ICSS2Properties.TextIndent property

Diese Eigenschaft gibt die Einrückung der ersten Textzeile in einem Block an. Genauer gesagt legt sie die Einrückung der ersten Box fest, die in die erste [Zeilenbox](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#line-box) des Blocks fließt. Die Box wird relativ zur linken (oder rechten, bei Rechts‑nach‑Links‑Layout) Kante der Zeilenbox eingerückt. Benutzeragenten sollten diese Einrückung als Leerraum darstellen.

Die Werte haben die folgende Bedeutung:

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - Die Einrückung ist eine feste Länge.'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - Die Einrückung ist ein Prozentsatz der Breite des enthaltenden Blocks.
