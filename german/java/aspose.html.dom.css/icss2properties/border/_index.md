## ICSS2Properties.Border property

Die 'border'-Eigenschaft ist eine Kurzschreibweise, um dieselbe Breite, Farbe und Stil für alle vier Ränder einer Box festzulegen. Im Gegensatz zu den Kurzschreibweisen 'margin' und 'padding' kann die 'border'-Eigenschaft nicht unterschiedliche Werte für die vier Ränder setzen. Dafür muss eine oder mehrere der anderen border-Eigenschaften verwendet werden.

```java
public String Border { get; set; }
```
