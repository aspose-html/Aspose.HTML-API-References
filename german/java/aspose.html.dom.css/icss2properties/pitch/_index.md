## ICSS2Properties.Pitch property

Gibt die durchschnittliche Tonhöhe (eine Frequenz) der sprechenden Stimme an. Die durchschnittliche Tonhöhe einer Stimme hängt von der Stimmfamilie ab. Zum Beispiel liegt die durchschnittliche Tonhöhe einer normalen männlichen Stimme bei etwa 120 Hz, bei einer weiblichen Stimme bei etwa 210 Hz.

public String Pitch { get; set; }
