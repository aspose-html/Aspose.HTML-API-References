## ICSS2Properties.Elevation property

Werte dieser Eigenschaft haben die folgenden Bedeutungen:

'angle' - Gibt die Elevation als Winkel an, zwischen '-90deg' und '90deg'. '0deg' bedeutet am vorderen Horizont, was grob bedeutet, dass es auf gleicher Höhe mit dem Hörer liegt. '90deg' bedeutet direkt über dem Kopf und '-90deg' bedeutet direkt darunter. below - Gleich wie '-90deg'. level - Gleich wie '0deg'. above - Gleich wie '90deg'. higher - Fügt der aktuellen Elevation 10 Grad hinzu. lower - Subtrahiert 10 Grad von der aktuellen Elevation.

public String Elevation { get; set; }
