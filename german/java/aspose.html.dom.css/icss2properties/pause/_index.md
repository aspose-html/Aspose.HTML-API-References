## ICSS2Properties.Pause property

Die ['pause'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause)-Eigenschaft ist eine Kurzschreibweise zum Festlegen von ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) und ['pause-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-after). Werden zwei Werte angegeben, ist der erste Wert ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) und der zweite ['pause-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-after). Wird nur ein Wert angegeben, gilt er für beide Eigenschaften.

```java
public String Pause { get; set; }
```
