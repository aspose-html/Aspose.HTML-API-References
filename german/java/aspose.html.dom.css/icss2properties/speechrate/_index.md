## ICSS2Properties.SpeechRate property

Diese Eigenschaft gibt die Sprechgeschwindigkeit an. Beachten Sie, dass sowohl absolute als auch relative Schlüsselwortwerte erlaubt sind (vergleichbar mit ['font-size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html#propdef-font-size)). Die Werte haben die folgende Bedeutung:

'[number](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-number)' – Gibt die Sprechgeschwindigkeit in Wörtern pro Minute an, eine Größe, die je nach Sprache leicht variiert, aber dennoch von Sprachsynthesizern breit unterstützt wird.

x-slow – Entspricht 80 Wörtern pro Minute.

slow – Entspricht 120 Wörtern pro Minute.

mittel - Gleich wie 180 - 200 Wörter pro Minute.

schnell - Gleich wie 300 Wörter pro Minute.

x-schnell - Gleich wie 500 Wörter pro Minute.

schneller - Fügt der aktuellen Sprechgeschwindigkeit 40 Wörter pro Minute hinzu.

langsamer - Subtrahiert 40 Wörter pro Minute von der aktuellen Sprechgeschwindigkeit.

```java
public String SpeechRate { get; set; }
```
