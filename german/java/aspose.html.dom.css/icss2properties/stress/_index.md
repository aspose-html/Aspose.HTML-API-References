## ICSS2Properties.Stress property

Gibt die Höhe von "lokalen Spitzen" im Intonationsverlauf einer Stimme an. Zum Beispiel ist Englisch eine betonte Sprache, und verschiedene Teile eines Satzes erhalten primären, sekundären oder tertiären Akzent. Der Wert von ['stress'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-stress) steuert die Menge der Intonation, die durch diese Akzentmarker entsteht. Diese Eigenschaft ist ein Begleiter der ['pitch-range'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pitch-range) Eigenschaft und wird bereitgestellt, um Entwicklern die Nutzung hochwertiger auditiver Anzeigen zu ermöglichen.

```java
public String Stress { get; set; }
```
