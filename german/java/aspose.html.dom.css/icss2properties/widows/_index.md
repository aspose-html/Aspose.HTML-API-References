## ICSS2Properties.Widows property

Die ['orphans'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-orphans) Eigenschaft gibt die minimale Anzahl von Zeilen eines Absatzes an, die am unteren Seitenrand verbleiben müssen. Die ['widows'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-widows) Eigenschaft gibt die minimale Anzahl von Zeilen eines Absatzes an, die am oberen Seitenrand verbleiben müssen. Beispiele dafür, wie sie zur Steuerung von Seitenumbrüchen verwendet werden, sind unten angegeben.

```java
public String Widows { get; set; }
```
