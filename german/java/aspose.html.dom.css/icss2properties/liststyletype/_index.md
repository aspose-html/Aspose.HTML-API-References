## ICSS2Properties.ListStyleType property

Diese Eigenschaft legt das Aussehen des Listenelement-Markierers fest, wenn ['list-style-image'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-list-style-image) den Wert 'none' hat oder wenn das durch die URI referenzierte Bild nicht angezeigt werden kann. Der Wert 'none' bedeutet keinen Marker, andernfalls gibt es drei Arten von Markern: Glyphen, Nummerierungssysteme und alphabetische Systeme. Hinweis: Nummerierte Listen verbessern die Barrierefreiheit von Dokumenten, indem sie das Navigieren durch Listen erleichtern.

Glyphen werden mit disc, circle und square angegeben. Ihre genaue Darstellung hängt vom User-Agent ab.

Nummerierungssysteme werden angegeben mit:

decimal - Dezimale Zahlen, beginnend mit 1. decimal-leading-zero - Dezimale Zahlen mit führenden Nullen (z.B. 01, 02, 03, ..., 98, 99). lower-roman - Römische Ziffern in Kleinbuchstaben (i, ii, iii, iv, v, usw.). upper-roman - Römische Ziffern in Großbuchstaben (I, II, III, IV, V, usw.). hebrew - Traditionelle hebräische Nummerierung. georgian - Traditionelle georgische Nummerierung (an, ban, gan, ..., he, tan, in, in-an, ...). armenian - Traditionelle armenische Nummerierung. cjk-ideographic - Einfache ideographische Zahlen. hiragana - a, i, u, e, o, ka, ki, ... katakana - A, I, U, E, O, KA, KI, ... hiragana-iroha - i, ro, ha, ni, ho, he, to, ... katakana-iroha - I, RO, HA, NI, HO, HE, TO, ...
