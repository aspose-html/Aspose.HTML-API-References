## ICSS2Properties.TextAlign property

Diese Eigenschaft beschreibt, wie Inline-Inhalt eines Blocks ausgerichtet wird. Werte haben die folgende Bedeutung:

left, right, center, and justify - Links, rechts, zentriert und im Blocksatz - Text, jeweils.'[String](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-String)' - Gibt einen String an, an dem Zellen in einer Tabellenspalte ausgerichtet werden (siehe den Abschnitt über [horizontal alignment in a column](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#column-alignment) für Details und ein Beispiel). Dieser Wert gilt nur für [table](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html)-Zellen. Wenn er auf anderen Elementen gesetzt wird, wird er als 'left' oder 'right' behandelt, abhängig davon, ob ['direction'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-direction) 'ltr' bzw. 'rtl' ist.
