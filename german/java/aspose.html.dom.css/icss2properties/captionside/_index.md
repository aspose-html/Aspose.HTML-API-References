## ICSS2Properties.CaptionSide property

Diese Eigenschaft gibt die Position der Caption‑Box relativ zur Tabellen‑Box an. Werte haben die folgenden Bedeutungen:

top - Positioniert die Caption‑Box über der Tabellen‑Box. bottom - Positioniert die Caption‑Box unter der Tabellen‑Box. left - Positioniert die Caption‑Box links von der Tabellen‑Box. right - Positioniert die Caption‑Box rechts von der Tabellen‑Box.

```java
public String CaptionSide { get; set; }
```
