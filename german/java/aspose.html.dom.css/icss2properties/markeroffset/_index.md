## ICSS2Properties.MarkerOffset property

Diese Eigenschaft gibt den Abstand zwischen den nächstgelegenen [border edges](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#border-edge) einer Markierungsbox und ihrer zugehörigen [principal box](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#principal-box) an. Der Versatz kann entweder eine benutzerdefinierte ([length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)) sein oder vom UA ('auto') gewählt werden. Längen können negativ sein, jedoch können implementierungsspezifische Grenzen bestehen.

```java
public String MarkerOffset { get; set; }
```
