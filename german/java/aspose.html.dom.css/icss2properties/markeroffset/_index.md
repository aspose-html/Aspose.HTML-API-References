## ICSS2Properties.MarkerOffset property

Diese Eigenschaft gibt den Abstand zwischen den nächsten [Randkanten](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#border-edge) einer Markierungsbox und ihrer zugehörigen [Hauptbox](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#principal-box) an. Der Versatz kann entweder eine benutzerdefinierte ([Länge](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)) sein oder vom UA ('auto') gewählt werden. Längen können negativ sein, es können jedoch implementierungsspezifische Grenzen existieren.

```java
public String MarkerOffset { get; set; }
```
