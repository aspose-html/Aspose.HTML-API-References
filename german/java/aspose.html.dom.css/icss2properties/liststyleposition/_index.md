## ICSS2Properties.ListStylePosition property

Diese Eigenschaft gibt die Position des Markierungsfeldes im Hauptblockfeld an. Werte haben die folgende Bedeutung:

outside - Das Markierungsfeld ist außerhalb des Hauptblockfeldes. Hinweis: CSS1 spezifizierte den genauen Ort des Markierungsfeldes nicht und aus Kompatibilitätsgründen bleibt CSS2 ebenso mehrdeutig. Für eine genauere Steuerung der Markierungsfelder verwenden Sie bitte markers. inside - Das Markierungsfeld ist das erste Inline-Feld im Hauptblockfeld, nach dem der Inhalt des Elements fließt.

```java
public String ListStylePosition { get; set; }
```
