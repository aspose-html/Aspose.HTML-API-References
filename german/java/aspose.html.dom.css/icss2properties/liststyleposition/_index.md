## ICSS2Properties.ListStylePosition property

Diese Eigenschaft gibt die Position des Marker‑Kastens im Hauptblockkasten an. Die Werte haben die folgende Bedeutung:

outside - Der Marker‑Kasten ist außerhalb des Hauptblockkastens. Hinweis: CSS1 spezifizierte den genauen Ort des Marker‑Kastens nicht und aus Kompatibilitätsgründen bleibt CSS2 ebenso mehrdeutig. Für eine genauere Steuerung von Marker‑Kästen verwenden Sie bitte markers.inside - Der Marker‑Kasten ist die erste Inline‑Box im Hauptblockkasten, nach der der Inhalt des Elements fließt.

public String ListStylePosition { get; set; }
