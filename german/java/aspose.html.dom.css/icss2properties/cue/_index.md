## ICSS2Properties.Cue property

Die ['cue'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue) Eigenschaft ist eine Kurzschreibweise zum Festlegen von ['cue-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-before) und ['cue-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-after). Wenn zwei Werte angegeben werden, ist der erste Wert ['cue-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-before) und der zweite ['cue-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-after). Wenn nur ein Wert angegeben wird, gilt er für beide Eigenschaften.

```java
public String Cue { get; set; }
```
