## ICSS2Properties.BackgroundRepeat property

Wenn ein Hintergrundbild angegeben ist, legt diese Eigenschaft fest, ob das Bild wiederholt (gekachelt) wird und wie. Das gesamte Kacheln deckt die Inhalts‑ und Innenabstand‑Bereiche einer Box ab. Die Werte haben die folgende Bedeutung:

repeat - Das Bild wird sowohl horizontal als auch vertikal wiederholt. repeat-x - Das Bild wird nur horizontal wiederholt. repeat-y - Das Bild wird nur vertikal wiederholt. no-repeat - Das Bild wird nicht wiederholt: Es wird nur eine Kopie des Bildes gezeichnet.

```java
public String BackgroundRepeat { get; set; }
```

### Rückgabewert

background-repeat Eigenschaft

Der background‑repeat‑Wert aus der Liste, wie oben definiert.
