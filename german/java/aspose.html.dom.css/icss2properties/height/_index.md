## ICSS2Properties.Height property

Diese Eigenschaft gibt die [Inhaltshöhe](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#content-height) von Boxen an, die von Block‑Elementen und [ersetzten](https://www.w3.org/TR/1998/REC-CSS2-19980512/conform.html#replaced-element) Elementen erzeugt werden.

Diese Eigenschaft gilt nicht für nicht‑ersetzte [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) Elemente. Die Höhe der Boxen eines nicht‑ersetzten Inline‑Elements wird durch den (möglicherweise geerbten) ['line-height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-line-height) Wert des Elements bestimmt.

```java
public String Height { get; set; }
```
