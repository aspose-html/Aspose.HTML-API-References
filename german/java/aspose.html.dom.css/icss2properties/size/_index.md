## ICSS2Properties.Size property

Diese Eigenschaft legt die Größe und Ausrichtung einer Seitenbox fest.

Die Größe einer Seitenbox kann entweder "absolute" (feste Größe) oder "relative" (skalierbar, d. h. an verfügbare Blattgrößen anpassend) sein. Relative Seitenboxen ermöglichen es Benutzeragenten, ein Dokument zu skalieren und die Zielgröße optimal zu nutzen.

Drei Werte für die ['size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-size)-Eigenschaft erzeugen eine relative Seitenbox:

auto - Die Seitenbox wird auf die Größe und Ausrichtung des Zielblatts gesetzt.landscape - Überschreibt die Ausrichtung des Ziels. Die Seitenbox hat dieselbe Größe wie das Ziel, und die längeren Seiten sind horizontal.portrait - Überschreibt die Ausrichtung des Ziels. Die Seitenbox hat dieselbe Größe wie das Ziel, und die kürzeren Seiten sind horizontal.
