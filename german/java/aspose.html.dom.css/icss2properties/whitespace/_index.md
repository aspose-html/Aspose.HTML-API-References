## ICSS2Properties.WhiteSpace property

Diese Eigenschaft legt fest, wie [Leerzeichen](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#whitespace) innerhalb des Elements behandelt werden. Werte haben die folgende Bedeutung:

normal – Dieser Wert veranlasst Benutzeragenten, Sequenzen von Leerzeichen zusammenzuziehen und Zeilen nach Bedarf zu umbrechen, um Zeilenboxen zu füllen. Zusätzliche Zeilenumbrüche können durch Vorkommen von "\A" im generierten Inhalt erzeugt werden (z. B. für das BR-Element in HTML). pre – Dieser Wert verhindert, dass Benutzeragenten Sequenzen von Leerzeichen zusammenziehen. Zeilen werden nur bei Zeilenumbrüchen im Quelltext oder bei Vorkommen von "\A" im generierten Inhalt umgebrochen. nowrap – Dieser Wert zieht Leerzeichen wie bei 'normal' zusammen, unterdrückt jedoch Zeilenumbrüche im Text, außer denen, die durch "\A" im generierten Inhalt erzeugt werden (z. B. für das BR-Element in HTML).

public String WhiteSpace { get; set; }
