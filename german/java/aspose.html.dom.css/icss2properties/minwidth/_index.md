## ICSS2Properties.MinWidth property

Diese beiden Eigenschaften ermöglichen es Autoren, die Breite von Boxen auf einen bestimmten Bereich zu beschränken. Werte haben die folgende Bedeutung:

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - Gibt eine feste minimale oder maximale berechnete Breite an. '[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - Gibt einen Prozentsatz zur Bestimmung des berechneten Werts an. Der Prozentsatz wird relativ zur Breite des erzeugten Box-[containing block](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#containing-block) berechnet. none - (Nur bei ['max-width'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-max-width)) Keine Begrenzung der Breite der Box.

public String MinWidth { get; set; }
