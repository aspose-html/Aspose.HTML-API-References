## ICSS2Properties.VoiceFamily property

Der Wert ist eine kommagetrennte, priorisierte Liste von Stimmfamiliennamen (vergleiche mit ['font-family'](https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html#propdef-font-family)). Werte haben die folgenden Bedeutungen:

'generic-voice' - Werte sind Stimmfamilien. Mögliche Werte sind 'male', 'female' und 'child'.'specific-voice' - Werte sind spezifische Instanzen (z. B. comedian, trinoids, carlos, lani).

```java
public String VoiceFamily { get; set; }
```
