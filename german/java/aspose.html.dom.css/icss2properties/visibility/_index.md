## ICSS2Properties.Visibility property

Die ['visibility'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visufx.html#propdef-visibility)-Eigenschaft gibt an, ob die von einem Element erzeugten Boxen gerendert werden. Unsichtbare Boxen beeinflussen das Layout weiterhin (setze die ['display'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-display)-Eigenschaft auf 'none', um die Boxenerzeugung vollständig zu unterdrücken). Werte haben die folgende Bedeutung:

visible - Die erzeugte Box ist sichtbar. hidden - Die erzeugte Box ist unsichtbar (vollständig transparent), beeinflusst jedoch weiterhin das Layout. collapse - Bitte konsultiere den Abschnitt über [dynamic row and column effects](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#dynamic-effects) in Tabellen. Wenn es auf Elemente angewendet wird, die keine Zeilen oder Spalten sind, hat 'collapse' die gleiche Bedeutung wie 'hidden'.

```java
public String Visibility { get; set; }
```
