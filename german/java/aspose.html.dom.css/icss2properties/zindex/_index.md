## ICSS2Properties.ZIndex property

Für ein positioniertes Element gibt die ['z-index'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-z-index)-Eigenschaft an:

Die Stapelstufe des Elements im aktuellen Stapelkontext. Ob das Element einen lokalen Stapelkontext erstellt.

public String ZIndex { get; set; }
