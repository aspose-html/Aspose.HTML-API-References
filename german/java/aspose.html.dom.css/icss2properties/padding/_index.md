## ICSS2Properties.Padding property

Die ['padding'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-padding) Eigenschaft ist eine Kurzschreibweise zum Festlegen von ['padding-top'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-padding-top), ['padding-right'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-padding-right), ['padding-bottom'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-padding-bottom) und ['padding-left'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-padding-left) an derselben Stelle im Stylesheet.

Wenn nur ein Wert angegeben ist, gilt er für alle Seiten. Wenn zwei Werte angegeben sind, werden die oberen und unteren Innenabstände auf den ersten Wert gesetzt und die rechten und linken Innenabstände auf den zweiten Wert. Wenn drei Werte angegeben sind, wird der obere Innenabstand auf den ersten Wert gesetzt, die linken und rechten auf den zweiten und der untere auf den dritten Wert. Wenn vier Werte angegeben sind, gelten sie für oben, rechts, unten und links in dieser Reihenfolge.
