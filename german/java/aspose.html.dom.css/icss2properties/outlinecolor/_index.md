## ICSS2Properties.OutlineColor property

Die mit den Outline-Eigenschaften erstellte Kontur wird "über" einer Box gezeichnet, d.h. die Kontur liegt immer oben und beeinflusst weder die Position noch die Größe der Box oder anderer Boxen. Daher führt das Anzeigen oder Unterdrücken von Konturen nicht zu einem Reflow.

```java
public String OutlineColor { get; set; }
```
