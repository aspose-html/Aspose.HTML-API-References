## ICSS2Properties.PageBreakBefore property

Werte für diese Eigenschaften haben die folgende Bedeutung:

auto - Weder einen Seitenumbruch vor (nach, innerhalb) der erzeugten Box erzwingen noch verbieten. always - Immer einen Seitenumbruch vor (nach) der erzeugten Box erzwingen. avoid - Einen Seitenumbruch vor (nach, innerhalb) der erzeugten Box vermeiden. left - Einen oder zwei Seitenumbrüche vor (nach) der erzeugten Box erzwingen, sodass die nächste Seite als linke Seite formatiert wird. right - Einen oder zwei Seitenumbrüche vor (nach) der erzeugten Box erzwingen, sodass die nächste Seite als rechte Seite formatiert wird.

public String PageBreakBefore { get; set; }
