## ICSS2Properties.TableLayout property

Die ['table-layout'](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#propdef-table-layout) Eigenschaft steuert den Algorithmus, der zum Anordnen der Tabellenzellen, -reihen und -spalten verwendet wird. Werte haben die folgende Bedeutung:

fixed - Verwenden Sie den festen Tabellenlayout-Algorithmus auto - Verwenden Sie einen beliebigen automatischen Tabellenlayout-Algorithmus

public String TableLayout { get; set; }
