## ICSS2Properties.Margin property

Die ['margin'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin) Eigenschaft ist eine Kurzschreibweise zum Festlegen von ['margin-top'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-top), ['margin-right'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-right), ['margin-bottom'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-bottom) und ['margin-left'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-left) an derselben Stelle im Stylesheet.

Wenn nur ein Wert angegeben ist, gilt er für alle Seiten. Wenn zwei Werte angegeben sind, werden die oberen und unteren Abstände auf den ersten Wert gesetzt und die rechten und linken Abstände auf den zweiten Wert. Wenn drei Werte angegeben sind, wird der obere auf den ersten Wert gesetzt, die linken und rechten auf den zweiten und der untere auf den dritten. Wenn vier Werte angegeben sind, gelten sie für oben, rechts, unten und links in dieser Reihenfolge.
