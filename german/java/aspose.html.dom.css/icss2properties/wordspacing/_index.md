## ICSS2Properties.WordSpacing property

Diese Eigenschaft gibt das Abstandverhalten zwischen Wörtern an. Werte haben die folgende Bedeutung:

normal - Der normale Zwischenwortabstand, wie durch die aktuelle Schriftart und/oder den UA definiert.'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - Dieser Wert gibt den Zwischenwortabstand zusätzlich zum Standardabstand zwischen Wörtern an. Werte können negativ sein, es können jedoch implementierungsspezifische Grenzen existieren.

```java
public String WordSpacing { get; set; }
```
