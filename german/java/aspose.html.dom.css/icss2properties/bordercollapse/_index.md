## ICSS2Properties.BorderCollapse property

Diese Eigenschaft wählt das Rahmenmodell einer Tabelle aus. Der Wert 'separate' wählt das Modell der getrennten Rahmen. Der Wert 'collapse' wählt das Modell der zusammenfallenden Rahmen. Die Modelle werden unten beschrieben.

public String BorderCollapse { get; set; }
