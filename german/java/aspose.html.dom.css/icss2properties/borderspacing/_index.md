## ICSS2Properties.BorderSpacing property

Die Längen geben den Abstand an, der benachbarte Zellenränder trennt. Wird eine Länge angegeben, gilt sie sowohl für den horizontalen als auch für den vertikalen Abstand. Werden zwei Längen angegeben, gibt die erste den horizontalen Abstand und die zweite den vertikalen Abstand an. Längen dürfen nicht negativ sein.

public String BorderSpacing { get; set; }
