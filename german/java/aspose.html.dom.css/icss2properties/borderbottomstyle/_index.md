## ICSS2Properties.BorderBottomStyle property

Die 'border-style'-Eigenschaft legt den Stil der vier Rahmen fest. Sie kann ein bis vier Werte haben, und die Werte werden wie bei 'border-width' oben auf die verschiedenen Seiten angewendet.
