## ICSS2Properties.TextTransform property

Diese Eigenschaft steuert die Großschreibungseffekte des Textes eines Elements. Werte haben die folgende Bedeutung:

capitalize - Setzt das erste Zeichen jedes Wortes in Großbuchstaben. uppercase - Setzt alle Zeichen jedes Wortes in Großbuchstaben. lowercase - Setzt alle Zeichen jedes Wortes in Kleinbuchstaben. none - Keine Großschreibungseffekte.

public String TextTransform { get; set; }
