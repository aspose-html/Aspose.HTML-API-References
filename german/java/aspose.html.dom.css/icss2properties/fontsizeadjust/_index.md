## ICSS2Properties.FontSizeAdjust property

In bikameralen Schriften ist die subjektive scheinbare Größe und Lesbarkeit einer Schrift weniger von ihrem 'font-size'-Wert abhängig als vom Wert ihrer 'x-height', oder, sinnvoller, vom Verhältnis dieser beiden Werte, dem sogenannten Aspektwert (Schriftgröße geteilt durch x-height). Je höher der Aspektwert, desto wahrscheinlicher ist, dass eine Schrift in kleineren Größen lesbar bleibt. Umgekehrt werden Schriften mit einem niedrigeren Aspektwert unterhalb einer bestimmten Schwelle schneller unlesbar als solche mit einem höheren Aspektwert. Eine einfache Schriftart‑Ersetzung, die ausschließlich auf der Schriftgröße basiert, kann zu unlesbaren Zeichen führen.

public String FontSizeAdjust { get; set; }
