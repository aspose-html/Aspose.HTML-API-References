## ICSS2Properties.Richness property

Gibt die Reichhaltigkeit bzw. Helligkeit der sprechenden Stimme an. Eine reiche Stimme wird in einem großen Raum "tragen", eine sanfte Stimme nicht. (Der Begriff "sanft" bezieht sich darauf, wie die Wellenform beim Zeichnen aussieht.)

```java
public String Richness { get; set; }
```
