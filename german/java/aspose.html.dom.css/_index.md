Bietet Schnittstellen für die DOM Level 2 Style Specification. Cascading Style Sheets (CSS) ist eine Stylesheet‑Sprache, die es Autoren und Benutzern ermöglicht, Stil (z. B. Schriftarten und Abstände) an strukturierte Dokumente (z. B. HTML‑Dokumente und XML‑Anwendungen) anzuhängen. Sie unterstützt medienspezifische Stylesheets, sodass Autoren die Darstellung ihrer Dokumente für visuelle Browser, akustische Geräte, Drucker, Braille‑Geräte, Handgeräte usw. anpassen können. Außerdem unterstützt sie die Positionierung von Inhalten, Tabellenlayout, Internationalisierungs‑Features und einige Eigenschaften der Benutzeroberfläche. Durch die Trennung von Präsentationsstil und Dokumentinhalt vereinfacht CSS das Web‑Authoring und die Wartung von Websites.
