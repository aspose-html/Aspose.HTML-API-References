## ICSSKeyframeRule interface

Die `CSSKeyframeRule`‑Schnittstelle beschreibt ein Objekt, das einen Satz von Stilen für einen bestimmten Keyframe darstellt. Es entspricht dem Inhalt eines einzelnen Keyframes einer @keyframes‑At‑Rule.

```java
public interface ICSSKeyframeRule : ICSSRule
```
