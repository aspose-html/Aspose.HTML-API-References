## IStyleSheet.Type property

Dies gibt die Stylesheet-Sprache für dieses Stylesheet an. Die Stylesheet-Sprache wird als Content-Type angegeben (z. B. "text/css").

```java
public String Type { get; }
```

### Property Value

Das type-Attribut muss den Typ zurückgeben.
