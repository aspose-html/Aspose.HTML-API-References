## IStyleSheet.Title property

Die title‑Eigenschaft des [`StyleSheet`](../) Interfaces gibt den Hinweis‑Titel des aktuellen Stylesheets zurück.

Der title wird häufig im [`ownerNode`](../ownernode/) angegeben.

```java
public String Title { get; }
```

### Property Value

Das Attribut parentStyleSheet muss das übergeordnete [`CSS style sheet`](../../icssstylesheet/) zurückgeben.
