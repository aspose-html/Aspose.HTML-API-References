## IStyleSheet.Media property

Die media-Eigenschaft des [`StyleSheet`](../)-Interfaces gibt das beabsichtigte Zielmedium für Stilinformationen an. Es ist ein schreibgeschütztes, array‑ähnliches [`MediaList`](../../imedialist/)-Objekt und kann mit deleteMedium() entfernt und mit appendMedium() hinzugefügt werden.

```java
public IMediaList Media { get; }
```

### Property Value

Das media-Attribut muss das [`MediaList`](../../imedialist/)-Objekt zurückgeben, das dem CSS-Stylesheet zugeordnet ist.
