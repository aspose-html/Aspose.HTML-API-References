## IStyleSheet.Href property

Die href‑Eigenschaft des [`StyleSheet`](../) Interfaces gibt den Speicherort des Stylesheets zurück.

```java
public String Href { get; }
```

### Property Value

uri ist ein String, der die URI des Stylesheets enthält.

## Hinweise

Wenn das Stylesheet ein verknüpftes Stylesheet ist, ist der Wert dieses Attributs sein Speicherort. Für Inline‑Stylesheets ist der Wert dieses Attributs NULL.

Diese Eigenschaft ist in Firefox, Opera, Google Chrome und Safari schreibgeschützt und in Internet Explorer lesbar/schreibbar.
