## CSSEngineMode enumeration

Gibt den CSSEngine‑Modus an. Die Werte haben folgende Bedeutung:

default – Der CSS‑Parser arbeitet gemäß der W3C‑Empfehlung und unterstützt keine benutzerdefinierten Erweiterungen. not‑strict – Alle nicht dokumentierten Eigenschaften werden geparst und können darüber zugegriffen werden.

```java
[Flags]
public enum CSSEngineMode
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Default | `0` | Der CSS‑Parser arbeitet gemäß der W3C‑Empfehlung und unterstützt die benutzerdefinierten Erweiterungen nicht. |
| NotStrict | `1` | Der CSS‑Parser arbeitet im nicht‑strikten Modus. Alle nicht dokumentierten Eigenschaften werden geparst und können darüber zugegriffen werden. |
