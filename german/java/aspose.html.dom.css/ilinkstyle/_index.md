## ILinkStyle interface

Das LinkStyle-Interface bietet einen Mechanismus, über den ein Stylesheet von dem Knoten abgerufen werden kann, der für das Verlinken in ein Dokument verantwortlich ist. Eine Instanz des LinkStyle-Interfaces kann mittels bindungsspezifischer Cast-Methoden auf einer Instanz eines verlinkenden Knotens (HTMLLinkElement,

HTMLStyleElement oder ProcessingInstruction in DOM Level 2).

Siehe auch das [CSS Object Model (CSSOM) # ](https://www.w3.org/TR/cssom-1/#the-linkstyle-interface)[LinkStyle](https://www.w3.org/TR/cssom-1/#the-linkstyle-interface).
