## Rect class

Das Rect-Interface wird verwendet, um einen beliebigen Rechteckwert darzustellen. Dieses Interface spiegelt die Werte in der zugrunde liegenden Style-Eigenschaft wider. Daher ändern Änderungen an den [`CSSPrimitiveValue`](../cssprimitivevalue/) Objekten die Style-Eigenschaft.

```java
public class Rect : DOMObject
```

| [getLeft](../../com.aspose.html.dom.css/rect/left/) Dieses Attribut wird für die linke Seite des Rechtecks verwendet. |
