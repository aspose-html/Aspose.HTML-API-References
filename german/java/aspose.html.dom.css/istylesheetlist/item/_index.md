## IStyleSheetList indexer

Die item(index)‑Methode muss das [`CSS style sheet`](../../icssstylesheet/) am angegebenen Index in der Sammlung zurückgeben. Wenn kein Objekt an diesem Index existiert, muss die Methode null zurückgeben.

```java
public ICSSStyleSheet this[int index] { get; }
```

### Rückgabewert

Ein [`CSSStyleSheet`](../../icssstylesheet/)-Objekt oder null, falls für diesen Index kein Objekt existiert.

### Property Value

Ein ganzzahliger Wert, der den Index des zurückzugebenden Elements in der Sammlung angibt.
