## ResourceHandlingOptions.MaxHandlingDepth property

Liest oder setzt die maximale Tiefe von Seiten, die verarbeitet werden sollen. Eine Tiefe von 1 bedeutet, dass nur Seiten, die direkt aus dem gespeicherten Dokument referenziert werden, verarbeitet werden. Das Setzen dieser Eigenschaft auf -1 führt zur Verarbeitung aller Seiten. Der Standardwert ist 0.

```java
public int MaxHandlingDepth { get; set; }
```
