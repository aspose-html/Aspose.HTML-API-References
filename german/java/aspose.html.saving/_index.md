Das **com.aspose.html.saving** Paket wird durch Datenklassen zur Beschreibung spezifischer Speicheroptionen im Konvertierungs-/Speicherprozess präsentiert.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [DocSaveOptions](./docsaveoptions/) | Spezifische Optionsdatenklasse. Durch Zuweisen von Eigenschaften können Sie Rendering‑Charakteristiken wie Auflösung, Seitengröße, Hintergrundfarbe sowie dokumentspezifische Optionen wie Schriftart‑Einbettung verwalten. Weitere Informationen siehe in der Dokumentation [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-docx/#save-options). |
| [HTMLSaveOptions](./htmlsaveoptions/) | Stellt HTML-Speicheroptionen dar. Durch Zuweisen spezifischer Eigenschaften können Sie die Ressourcenverarbeitung wie maximale Verarbeitungstiefe usw. verwalten. Weitere Informationen siehe in der Dokumentation [article](https://docs.aspose.com/html/net/working-with-documents/saving-a-document/). |
| [ImageSaveOptions](./imagesaveoptions/) | Spezifische Optionsdatenklasse. Sie bietet Eigenschaften zur Verwaltung der Bildauflösung, Glättungsqualität, des Formats sowie der Seiteneinstellungen usw. Weitere Informationen erhalten Sie in der Dokumentation [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-jpg/#save-options). |
| [MarkdownSaveOptions](./markdownsaveoptions/) | Stellt Markdown-Speicheroptionen dar. Zum Beispiel können Sie den Markdown-Formatierungsstil festlegen, vordefinierte, mit GitLab Flavored Markdown kompatible Optionen verwenden und die Ressourcenverarbeitung konfigurieren. Weitere Informationen finden Sie im [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-markdown/#save-options). |
| [MHTMLSaveOptions](./mhtmlsaveoptions/) | Stellt MHTML-Speicheroptionen dar. Durch Zuweisen spezifischer Eigenschaften können Sie die Ressourcenverarbeitung wie maximale Verarbeitungstiefe usw. verwalten. Weitere Informationen siehe in der Dokumentation [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-mhtml/#save-options). |
| [PdfSaveOptions](./pdfsaveoptions/) | Spezifische Datenklasse bietet einige Eigenschaften zur Verwaltung des Konversionsergebnisses. Zum Beispiel spezifiziert [`PageSetup`](../com.aspose.html.rendering/pagesetup/) die Seiteneigenschaften. Siehe die Dokumentation [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-pdf/#convert-html-to-pdf-using-pdfsaveoptions). |
| [Resource](./resource/) | Diese Klasse beschreibt eine Ressource und stellt Methoden zur Verarbeitung bereit. |
| [ResourceHandlingContext](./resourcehandlingcontext/) | Diese Klasse enthält Informationen, die bei der Verarbeitung von Ressourcen verwendet werden. |
| [ResourceHandlingOptions](./resourcehandlingoptions/) | Stellt Optionen zur Ressourcenverarbeitung dar. |
| [SaveOptions](./saveoptions/) | Dies ist eine abstrakte Basisklasse für Klassen, die dem Benutzer ermöglichen, zusätzliche Optionen beim Speichern eines Dokuments in ein bestimmtes Format anzugeben. |
| [TextSaveOptions](./textsaveoptions/) | Stellt Text‑Speicheroptionen dar |
| [XpsSaveOptions](./xpssaveoptions/) | Spezifische Optionsdatenklasse bietet einige Eigenschaften zur Verwaltung des Konversionsergebnisses. Zum Beispiel spezifiziert [`PageSetup`](../com.aspose.html.rendering/pagesetup/) die Seiteneigenschaften. Siehe die Dokumentation [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-xps/#save-options). |
## Aufzählung

| Aufzählung | Beschreibung |

| [HTMLSaveFormat](./htmlsaveformat/) | Gibt das Format an, in dem das Dokument gespeichert wird. Weitere Informationen zum Speichern von [`HTMLDocument`](../com.aspose.html/htmldocument/) finden Sie im [article](https://docs.aspose.com/html/net/working-with-documents/saving-a-document/). |
| [MarkdownFeatures](./markdownfeatures/) | Ein [`MarkdownFeatures`](../com.aspose.html.saving/markdownfeatures/) Flag-Set ist eine Menge von null oder mehr der folgenden Flags, die verwendet werden, um Elemente auszuwählen, die in Markdown konvertiert werden. |
| [MarkdownFormatter](./markdownformatter/) | Gibt an, wie die Ausgabe formatiert wird. |
| [ResourceHandling](./resourcehandling/) | Dieses Enum stellt Optionen zur Ressourcenverwaltung dar. |
| [ResourceStatus](./resourcestatus/) | Zeigt den Status der Ressource an. |
| [UrlRestriction](./urlrestriction/) | Dieses Enum stellt Einschränkungen dar, die auf URLs von verarbeiteten Ressourcen angewendet werden. |
