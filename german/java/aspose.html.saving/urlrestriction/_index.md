## UrlRestriction enumeration

Dieses Enum stellt Beschränkungen dar, die auf URLs von verarbeiteten Ressourcen angewendet werden.

```java
public enum UrlRestriction
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| RootAndSubFolders | `0` | Nur Ressourcen, die im Stammverzeichnis und in Unterordnern liegen, werden verarbeitet. |
| SameHost | `1` | Nur Ressourcen, die sich im selben Host befinden, werden verarbeitet. |
| None | `2` | Alle Ressourcen werden verarbeitet. |
