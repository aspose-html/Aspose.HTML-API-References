## TextSaveOptions.EnableListItemMarkers property

Option, die auf OL- und UL-Elemente bei der HTML-zu-Text-Konvertierung angewendet wird. Sie definiert, wie die äußeren Listensymbole von OL- und UL-Elementen verarbeitet werden. Wenn true, werden vor OL-Elementen Nummern und vor UL-Elementen Punkte hinzugefügt. Wenn false, werden sie nicht hinzugefügt (Standardverhalten gemäß der Spezifikation).

```java
public bool EnableListItemMarkers { get; set; }
```
