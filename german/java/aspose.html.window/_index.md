Das **com.aspose.html.window**-Paket bezieht sich auf das Fensterobjekt, das ein Fenster darstellt, das ein DOM-Dokument enthält. Es umfasst Klassen und Schnittstellen, die mit der aktiven Dokumentadresse und dem Browserverlauf zusammenhängen.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [Location](./location/) | Location-Objekte bieten eine Darstellung der Adresse des aktiven Dokuments ihres Dokument‑Browsing‑Kontexts und ermöglichen es, den aktuellen Eintrag der Sitzungsverlauf‑History des Browsing‑Kontexts zu ändern, indem Einträge im History‑Objekt hinzugefügt oder ersetzt werden. |
| [MediaQueryList](./mediaquerylist/) | Ein MediaQueryList‑Objekt speichert Informationen zu einer auf ein Dokument angewendeten Media‑Query und unterstützt sowohl sofortiges als auch ereignisgesteuertes Abgleichen des Dokumentzustands. Siehe die CSSOM‑View‑Modul‑Spezifikation: [https://www.w3.org/TR/cssom-view/#the-mediaquerylist-interface](https://www.w3.org/TR/cssom-view/#the-mediaquerylist-interface) |
## Schnittstellen

| Schnittstelle | Beschreibung |
| --- | --- |
| [IWindow](./iwindow/) | Das window‑Objekt stellt ein Fenster dar, das ein DOM‑Dokument enthält. |
| [IWindowEventHandlers](./iwindoweventhandlers/) | Stellt eine Schnittstelle dar, die vom window‑Objekt geerbt werden muss. |
| [IWindowTimers](./iwindowtimers/) | Ermöglicht Autoren, timerbasierte Rückrufe zu planen. |
