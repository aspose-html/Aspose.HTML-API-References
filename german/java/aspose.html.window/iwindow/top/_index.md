## IWindow.Top property

Das top IDL‑Attribut im Window‑Objekt eines Dokuments in einem Browsing‑Kontext b muss das WindowProxy‑Objekt seines Top‑Level‑Browsing‑Kontexts zurückgeben (das sein eigenes WindowProxy‑Objekt wäre, wenn es selbst ein Top‑Level‑Browsing‑Kontext wäre), falls es eines gibt, oder sonst sein eigenes WindowProxy‑Objekt (z. B. wenn es ein losgelöster verschachtelter Browsing‑Kontext war).

```java
public IWindow Top { get; }
```
