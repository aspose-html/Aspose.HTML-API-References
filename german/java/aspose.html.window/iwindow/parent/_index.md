## IWindow.Parent property

Das übergeordnete IDL-Attribut des Window-Objekts eines Dokuments in einem Browsing‑Kontext b muss das WindowProxy‑Objekt des übergeordneten Browsing‑Kontexts zurückgeben, falls ein solcher existiert (d. h. wenn b ein untergeordneter Browsing‑Kontext ist), oder das WindowProxy‑Objekt des Browsing‑Kontexts b selbst, andernfalls (d. h. wenn es ein Top‑Level‑Browsing‑Kontext oder ein abgetrennter verschachtelter Browsing‑Kontext ist).

```java
public IWindow Parent { get; }
```

### Property Value

Der Elternteil.
