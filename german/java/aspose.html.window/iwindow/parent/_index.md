## IWindow.Parent property

Das übergeordnete IDL-Attribut am Window-Objekt eines Dokuments in einem Browsing-Kontext b muss das WindowProxy-Objekt des übergeordneten Browsing-Kontexts zurückgeben, falls eines existiert (d. h. wenn b ein untergeordneter Browsing-Kontext ist), oder das WindowProxy-Objekt des Browsing-Kontexts b selbst, andernfalls (d. h. wenn es ein Top-Level-Browsing-Kontext ist).

```java
public IWindow Parent { get; }
```

### Property Value

Der Elternteil.
