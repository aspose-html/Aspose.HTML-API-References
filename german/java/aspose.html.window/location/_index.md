## Location class

Location-Objekte bieten eine Darstellung der Adresse des aktiven Dokuments ihres Dokumenten-Browsing-Kontexts und ermöglichen es, den aktuellen Eintrag des Sitzungsverlaufs des Browsing-Kontexts zu ändern, indem Einträge im Verlauf-Objekt hinzugefügt oder ersetzt werden.

```java
public sealed class Location : DOMObject
```
