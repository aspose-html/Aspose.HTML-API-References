## TemplateLoadOptions.NamesAreCaseSensitive property

Eigenschaft, die angibt, ob die Namen von Vorlagen- und Datenelementen unabhängig von der Groß‑ und Kleinschreibung abgeglichen werden sollen oder nicht. Wenn true, ist der Abgleich groß‑ und kleinschreibungssensitiv; wenn false, wird die Groß‑ und Kleinschreibung ignoriert. Standardwert ist true.

```java
public bool NamesAreCaseSensitive { get; set; }
```
