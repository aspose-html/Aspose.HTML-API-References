## IBlob.Type property

Die ASCII‑kodierte Zeichenkette in Kleinbuchstaben, die den Medientyp des Blob darstellt. Beim Abrufen müssen Benutzeragenten den Typ eines Blob als ASCII‑kodierte Zeichenkette in Kleinbuchstaben zurückgeben, sodass sie nach Umwandlung in eine Byte‑Sequenz ein parsebarer MIME‑Typ ist, oder die leere Zeichenkette – 0 Bytes – falls der Typ nicht ermittelt werden kann.

public String Type { get; }
