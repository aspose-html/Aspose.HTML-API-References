## IBlob.Type property

Der ASCII‑kodierte String in Kleinbuchstaben, der den Medientyp des Blob darstellt. Beim Abrufen müssen Benutzeragenten den Typ eines Blob als ASCII‑kodierten String in Kleinbuchstaben zurückgeben, sodass er nach der Umwandlung in eine Byte‑Sequenz ein parsbarer MIME‑Typ ist, oder der leere String – 0 Bytes – falls der Typ nicht ermittelt werden kann.

public String Type { get; }
