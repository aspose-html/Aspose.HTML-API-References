## IBlob.Size property

Gibt die Größe der Byte‑Sequenz in Byte an. Beim Abrufen müssen konforme Benutzeragenten die Gesamtzahl der Bytes zurückgeben, die von einem FileReader‑ oder FileReaderSync‑Objekt gelesen werden können, oder 0, wenn das Blob keine lesbaren Bytes enthält.

```java
public ulong Size { get; }
```
