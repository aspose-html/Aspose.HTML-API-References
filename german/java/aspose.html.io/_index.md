Zusätzlich zu den standardmäßigen IO (Ein-/Ausgabe)-Werkzeugen enthält das **com.aspose.html.io** Paket Hilfsklassen und Schnittstellen.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [FileCreateStreamProvider](./filecreatestreamprovider/) | Stellt die FileStream-Implementierung zur Bereitstellung von Streams für die Rendering‑Geräte dar. |
## Schnittstellen

| Schnittstelle | Beschreibung |
| --- | --- |
| [IBlob](./iblob/) | Ein Blob‑Objekt bezieht sich auf eine Byte‑Sequenz und besitzt ein Attribut size, das die Gesamtzahl der Bytes in der Sequenz angibt, sowie ein Attribut type, das ein ASCII‑kodierter String in Kleinbuchstaben ist und den Medientyp der Byte‑Sequenz darstellt. |
| [ICreateStreamProvider](./icreatestreamprovider/) | Stellt eine Schnittstelle dar, die von Klassen implementiert werden kann, die Streams für die Rendering‑Geräte bereitstellen. |
| [IFile](./ifile/) | Ein File‑Objekt ist ein Blob‑Objekt mit einem Attribut name, das ein String ist; es kann innerhalb der Webanwendung über einen Konstruktor erstellt werden oder ist ein Verweis auf eine Byte‑Sequenz aus einer Datei des zugrunde liegenden (OS‑)Dateisystems. |
| [IFileList](./ifilelist/) | Stellt die Schnittstelle für eine Liste von Dateien dar. |
