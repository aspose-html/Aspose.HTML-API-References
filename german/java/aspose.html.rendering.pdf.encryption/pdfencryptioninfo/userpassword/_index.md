## PdfEncryptionInfo.UserPassword property

Liest oder setzt das Benutzerkennwort.

```java
public String UserPassword { get; set; }
```

### Property Value

Das Benutzerkennwort.

## Hinweise

Das Öffnen des Dokuments mit dem korrekten Benutzerkennwort (oder das Öffnen eines Dokuments, das kein Benutzerkennwort hat) ermöglicht zusätzliche Vorgänge, die gemäß den im Verschlüsselungswörterbuch des Dokuments angegebenen Benutzerzugriffsberechtigungen ausgeführt werden können.
