## PdfEncryptionInfo.UserPassword property

Liest oder setzt das Benutzerpasswort.

```java
public String UserPassword { get; set; }
```

### Property Value

Das Benutzerpasswort.

## Hinweise

Das Öffnen des Dokuments mit dem korrekten Benutzerpasswort (oder das Öffnen eines Dokuments, das kein Benutzerpasswort hat) ermöglicht zusätzliche Vorgänge, die gemäß den im Verschlüsselungswörterbuch des Dokuments angegebenen Benutzerzugriffsberechtigungen durchgeführt werden können.
