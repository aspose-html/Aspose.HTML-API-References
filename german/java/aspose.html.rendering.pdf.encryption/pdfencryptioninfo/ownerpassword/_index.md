## PdfEncryptionInfo.OwnerPassword property

Gibt das Owner-Passwort zurück oder setzt es.

```java
public String OwnerPassword { get; set; }
```

### Property Value

Das Owner-Passwort.

## Hinweise

Das Öffnen des Dokuments mit dem korrekten Owner-Passwort (unter der Annahme, dass es nicht dasselbe wie das Benutzerpasswort ist) ermöglicht vollen (Owner-)Zugriff auf das Dokument. Dieser uneingeschränkte Zugriff beinhaltet die Möglichkeit, die Passwörter des Dokuments und die Zugriffsberechtigungen zu ändern.
