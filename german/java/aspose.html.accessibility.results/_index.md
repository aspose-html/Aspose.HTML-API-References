Das **com.aspose.html.accessibility.results**-Paket enthält Klassen, die die Ergebnisse der Regelvalidierung beschreiben.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [RuleValidationResult](./rulevalidationresult/) | Klasse – Ergebnis der Regelprüfung, enthält eine Liste von [`ITechniqueResult`](../com.aspose.html.accessibility/itechniqueresult/), die Wege zur Erfüllung der Erfolgskriterien darstellen. |
| [ValidationResult](./validationresult/) | Die Haupt‑Ergebnis‑Klasse, die Ergebnisse für alle Kriterien aus dem AccessibilityRules‑Objekt enthält. |
