## ImageRenderingOptions.VerticalResolution property

Legt die vertikale Auflösung für Ausgabe‑ und interne (bei der Filterverarbeitung verwendete) Bilder fest oder gibt sie zurück, in Pixel pro Zoll. Standardmäßig ist diese Eigenschaft 300 dpi.

```java
public Resolution VerticalResolution { get; set; }
```
