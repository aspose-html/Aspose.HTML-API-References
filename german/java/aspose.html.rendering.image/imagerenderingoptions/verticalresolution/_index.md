## ImageRenderingOptions.VerticalResolution property

Setzt oder liest die vertikale Auflösung für Ausgabe- und interne (die bei der Filterverarbeitung verwendet werden) Bilder, in Pixel pro Zoll. Standardmäßig ist diese Eigenschaft 300 dpi.

```java
public Resolution VerticalResolution { get; set; }
```
