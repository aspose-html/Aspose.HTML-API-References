## NodeFilter.SHOW_NOTATION field

Notation-Knoten anzeigen. Dies ist nur sinnvoll, wenn ein Iterator oder Tree-Walker mit einem Notation-Knoten als Wurzel erstellt wird; in diesem Fall bedeutet dies, dass der Notation-Knoten an der ersten Position der Traversierung erscheint. Da Notationen kein Teil des Dokumentbaums sind, erscheinen sie nicht beim Durchlaufen des Dokumentbaums.

```java
public const long SHOW_NOTATION;
```
