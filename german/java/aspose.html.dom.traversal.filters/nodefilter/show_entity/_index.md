## NodeFilter.SHOW_ENTITY field

Entity-Knoten anzeigen. Dies ist nur sinnvoll, wenn ein Iterator oder Tree-Walker mit einem Entity-Knoten als Wurzel erstellt wird; in diesem Fall bedeutet dies, dass der Entity-Knoten an der ersten Position der Traversierung erscheint. Da Entitäten nicht Teil des Dokumentbaums sind, erscheinen sie nicht beim Durchlaufen des Dokumentbaums.

```java
public const long SHOW_ENTITY;
```
