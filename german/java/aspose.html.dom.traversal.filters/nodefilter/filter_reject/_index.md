## NodeFilter.FILTER_REJECT field

Verwerfe den Knoten. Navigationsmethoden, die für NodeIterator oder TreeWalker definiert sind, geben diesen Knoten nicht zurück. Für TreeWalker werden auch die Kinder dieses Knotens verworfen. NodeIterators behandeln dies als Synonym für FILTER_SKIP.

```java
public const short FILTER_REJECT;
```
