Das Paket stellt die Knotenfilterfunktionalität bereit. Filter sind Objekte, die wissen, wie man Knoten "herausfiltert". Wenn einem Knoteniterator oder Baumwanderer ein Knotenfilter übergeben wird, wendet er den Filter an, bevor er den nächsten Knoten zurückgibt. Wenn der Filter sagt, den Knoten zu akzeptieren, gibt die Traversallogik ihn zurück; andernfalls sucht die Traversal nach dem nächsten Knoten und tut so, als wäre der abgelehnte Knoten nicht vorhanden.
