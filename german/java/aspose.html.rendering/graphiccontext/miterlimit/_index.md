## GraphicContext.MiterLimit property

Setzt oder liest die maximale Länge von Gehrungs‑Verbindungen für gezeichnete Pfade. Dieser Parameter begrenzt die Länge der "Spitzen", die entstehen, wenn Liniensegmente an scharfen Winkeln zusammenlaufen.

```java
public float MiterLimit { get; set; }
```
