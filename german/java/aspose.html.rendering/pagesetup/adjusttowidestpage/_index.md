## PageSetup.AdjustToWidestPage property

Liest oder setzt ein Flag, das den Fall bestimmt, in dem die Seitengröße an die breiteste Seite im Dokument angepasst wird. Diese Option ist zeitaufwendig, sodass die Verarbeitungszeit des Dokuments bis zu doppelt so lang werden kann. Die Anpassung erfolgt nur, wenn die breiteste Seite im Dokument breiter ist als die in [`PageSetup`](../) festgelegte Seitengröße. Die angepasste Seitengröße wird für alle Seiten im Dokument verwendet.

```java
public bool AdjustToWidestPage { get; set; }
```
