## PageSetup.PageLayoutOptions property

Ruft die [`PageLayoutOptions`](../../pagelayoutoptions/) ab oder legt sie fest. Standardwert ist None, jeder andere Wert überschreibt das Verhalten von [`AdjustToWidestPage`](../adjusttowidestpage/). Funktioniert nur mit HTML-Dokumenten.

```java
public PageLayoutOptions PageLayoutOptions { get; set; }
```
