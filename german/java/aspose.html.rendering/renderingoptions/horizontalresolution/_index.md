## RenderingOptions.HorizontalResolution property

Legt die horizontale Auflösung für interne (bei der Filterverarbeitung verwendete) Bilder fest oder gibt sie zurück, in Pixel pro Zoll. Standardmäßig beträgt diese Eigenschaft 300 dpi.

```java
public Resolution HorizontalResolution { get; set; }
```
