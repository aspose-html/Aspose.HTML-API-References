## RenderingOptions.VerticalResolution property

Legt die vertikale Auflösung für interne (bei der Filterverarbeitung verwendete) Bilder fest oder gibt sie zurück, gemessen in Pixel pro Zoll. Standardmäßig beträgt diese Eigenschaft 300 dpi.

```java
public Resolution VerticalResolution { get; set; }
```
