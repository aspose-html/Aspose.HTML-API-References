Das **com.aspose.html.drawing** Paket enthält Objekte und Schnittstellen zur Angabe von Messungen und Einheiten sowie Zeichenattributobjekte wie Pinsel, Farben und Schriftarten.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [Angle](./angle/) | Der Winkeldatentyp |
| [Color](./color/) | Die Klasse Color ermöglicht es, Farben als Rot-Grün-Blau (RGB)-Werte, Farbton‑Sättigung‑Luminanz (HSL)-Werte, Farbton‑Sättigung‑Wert (HSV)-Werte, Farbton‑Weiß‑Schwarz (HWB)-Werte, Lichtheit‑A‑B (LAB)-Werte, Luminanz‑Chroma‑Farbton (LCH)-Werte, Cyan‑Magenta‑Gelb‑Schlüssel (CMYK)-Werte, Natürliche Farben (NCOL)-Werte oder mit einem Farbnamen anzugeben. Ein Alpha‑Kanal ist ebenfalls verfügbar, um Transparenz anzugeben. |
| [Dimension](./dimension/) | Stellt die Basisklasse für Dimensionen bereit. Der allgemeine Begriff 'Dimension' bezeichnet eine Zahl mit einer angehängten Einheit und wird durch [`UnitType`](../com.aspose.html.drawing/unittype/) dargestellt. |
| [Frequency](./frequency/) | Die Einheit 'frequency'. |
| [Length](./length/) | Stellt eine Längeneinheit dar. |
| [LengthOrAuto](./lengthorauto/) | Stellt einen Container für die Speicherung von Längen- oder 'auto'-Einheiten dar. |
| [Margin](./margin/) | Stellt Seitenrand dar. |
| [Numeric](./numeric/) | Stellt die Basisklasse für numerische Typen bereit. |
| [Page](./page/) | Stellt ein Seitenobjekt dar, das für die Konfiguration der Ausgabeseite verwendet wird. Der Standardwert für die Seitengröße ist A4 (210 × 297 mm). |
| [Resolution](./resolution/) | Stellt eine Auflösungseinheit dar. |
| [Size](./size/) | Speichert Werte, die Höhe und Breite angeben. |
| [Time](./time/) | Stellt eine Zeiteinheit dar. |
| [Unit](./unit/) | Stellt die Basisklasse für Maßeinheiten bereit. |
| [UnitType](./unittype/) | Gibt die Maßeinheit an. |
## Schnittstellen

| Schnittstelle | Beschreibung |
| --- | --- |
| [IBrush](./ibrush/) | Deklariert eine Methode zum Abrufen des Pinseltyps. |
| [IColorComponents](./icolorcomponents/) | Deklariert Methoden und Eigenschaften zur Verarbeitung von Farbbestandteilen. |
| [IDrawingFactory](./idrawingfactory/) | Stellt eine Fabrik zum Erzeugen von zeichnungsbezogenen Objekten dar. |
| [IGradientBrush](./igradientbrush/) | Deklariert Methoden zum Abrufen gemeinsamer Eigenschaften von Farbverlaufspinseln. |
| [IInterpolationColor](./iinterpolationcolor/) | Deklariert Methoden zum Abrufen der Interpolationsfarbe. |
| [ILinearGradientBrush](./ilineargradientbrush/) | Definiert die Pinsel‑Schnittstelle mit einem linearen Farbverlauf. |
| [IMatrix](./imatrix/) | Stellt eine Matrix dar, die für Transformationen verwendet wird. |
| [ISolidBrush](./isolidbrush/) | Definiert die Pinsel‑Schnittstelle einer einzelnen Farbe. |
| [ITextureBrush](./itexturebrush/) | Definiert die Pinsel‑Schnittstelle, die ein Bild verwendet, um das Innere einer Form zu füllen. |
| [ITransformableBrush](./itransformablebrush/) | Deklariert Methoden zum Abrufen der Transformationsmatrix und des Wrap‑Modus. |
| [ITrueTypeFont](./itruetypefont/) | Deklariert Methoden zur Arbeit mit TrueType-Schriftarten. |
