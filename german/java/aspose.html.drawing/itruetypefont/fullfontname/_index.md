## ITrueTypeFont.FullFontName property

Dies sollte eine Kombination aus "FamilyName" und "SubFamilyName" sein. Ausnahme: Wenn die Schriftart "Regular" ist, wie in "SubFamilyName" angegeben, dann nur den im "FamilyName" enthaltenen Familiennamen verwenden. Eine Ausnahme von der obigen Definition des vollständigen Fontnamens gilt für Microsoft‑Plattform‑Strings für CFF‑OpenType‑Schriften: In diesem Fall muss der String des vollständigen Fontnamens identisch sein mit dem PostScript‑FontName im CFF‑Name‑INDEX.

```java
public String FullFontName { get; }
```

### Rückgabewert

Vollständiger Name der Schrift
