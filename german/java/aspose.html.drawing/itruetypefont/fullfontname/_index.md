## ITrueTypeFont.FullFontName property

Dies sollte eine Kombination aus "FamilyName" und "SubFamilyName" sein. Ausnahme: Wenn die Schriftart "Regular" ist, wie in "SubFamilyName" angegeben, dann verwende nur den Familiennamen aus "FamilyName". Eine Ausnahme von der obigen Definition des vollständigen Schriftartnamens gilt für Microsoft‑Plattform‑Strings für CFF‑OpenType‑Schriften: In diesem Fall muss der vollständige Schriftartname-String identisch sein mit dem PostScript‑FontName im CFF‑Name‑INDEX.

```java
public String FullFontName { get; }
```

### Rückgabewert

Vollständiger Name der Schriftart
