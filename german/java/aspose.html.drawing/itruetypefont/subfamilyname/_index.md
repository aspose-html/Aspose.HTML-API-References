## ITrueTypeFont.SubFamilyName property

Der Font-Subfamily-Name unterscheidet die Schrift in einer Gruppe mit demselben Font-Familiennamen. Dies soll Stil (italic, oblique) und Gewicht (light, bold, black usw.) adressieren. Eine Schrift ohne besondere Unterschiede in Gewicht oder Stil (z. B. mittleres Gewicht, nicht kursiv und mit gesetztem fsSelection‑Bit 6) sollte den String "Regular" an dieser Position speichern.

```java
public String SubFamilyName { get; }
```

### Rückgabewert

Subfamilienname der Schrift
