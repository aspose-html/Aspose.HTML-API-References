## ITrueTypeFont.SubFamilyName property

Der Font Subfamily name unterscheidet die Schrift in einer Gruppe mit demselben Font Family name. Dies soll Stil (italic, oblique) und Gewicht (light, bold, black usw.) adressieren. Eine Schrift ohne besondere Unterschiede in Gewicht oder Stil (z.B. mittleres Gewicht, nicht italic und mit gesetztem fsSelection-Bit 6) sollte den String "Regular" an dieser Position speichern.

```java
public String SubFamilyName { get; }
```

### Rückgabewert

Subfamily name der Schrift
