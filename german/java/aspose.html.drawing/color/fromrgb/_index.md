## FromRgb(byte, byte, byte) {#fromrgb}

Gibt ein neues Color mit den angeforderten ged-, Grün- und Blauwerten zurück. Alle Farbkomponenten müssen im Bereich 0‑255 liegen.

```java

```

| grün | Byte | Ein Byte, das die grüne Komponente der Farbe darstellt. |
