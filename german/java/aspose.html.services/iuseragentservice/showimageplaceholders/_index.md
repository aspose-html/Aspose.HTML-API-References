## IUserAgentService.ShowImagePlaceholders property

Bilder können Fallback‑Inhalte haben: Inhalte, die verwendet werden sollten, wenn eine externe Ressource nicht genutzt werden kann (zum Beispiel, weil sie in einem nicht unterstützten Format vorliegt). Die Eigenschaft `ShowImagePlaceholders` gibt an, ob das Ersatzbild angezeigt werden soll (standardmäßig ist true).

```java
public bool ShowImagePlaceholders { get; set; }
```
