Das **com.aspose.html.services** Paket enthält Schnittstellen als Protokolle für Service-Implementierungen.

## Schnittstellen

| Schnittstelle | Beschreibung |
| --- | --- |
| [IDeviceInformationService](./ideviceinformationservice/) | Eine Schnittstelle, die eine Umgebung beschreibt, in der [`Document`](../com.aspose.html.dom/document/) dem Benutzer präsentiert wird. |
| [INetworkService](./inetworkservice/) | Stellt eine Schnittstelle für Netzwerkoperationen bereit. |
| [IRuntimeService](./iruntimeservice/) | Dieser Service wird verwendet, um zur Laufzeit bezogene Eigenschaften zu konfigurieren. |
| [IUserAgentService](./iuseragentservice/) | Eine Schnittstelle, die eine Benutzer‑Agent‑Umgebung beschreibt. |
