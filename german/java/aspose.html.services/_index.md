Das **com.aspose.html.services** Paket enthält Schnittstellen als Protokolle für Service-Implementierungen.

## Schnittstellen

| Schnittstelle | Beschreibung |
| --- | --- |
| [IDeviceInformationService](./ideviceinformationservice/) | Eine Schnittstelle, die eine Umgebung beschreibt, in der [`Document`](../com.aspose.html.dom/document/) dem Benutzer präsentiert wird. |
| [INetworkService](./inetworkservice/) | Bietet eine Schnittstelle für Netzwerkoperationen. |
| [IRuntimeService](./iruntimeservice/) | Dieser Dienst wird verwendet, um zur Laufzeit bezogene Eigenschaften zu konfigurieren. |
| [IUserAgentService](./iuseragentservice/) | Eine Schnittstelle, die eine Benutzeragenten-Umgebung beschreibt. |
