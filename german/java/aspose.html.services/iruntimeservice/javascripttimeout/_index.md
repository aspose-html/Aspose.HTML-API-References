## IRuntimeService.JavaScriptTimeout property

Gibt oder setzt TimeSpan, das die Ausführungszeit von JavaScript begrenzt. Wenn das Skript länger als das angegebene TimeSpan ausgeführt wird, wird es abgebrochen. Sie können einen unbegrenzten Timeout festlegen, indem Sie TimeSpan auf -1 Millisekunde setzen. Der Standardwert ist 1 Minute.

```java
public TimeSpan JavaScriptTimeout { get; set; }
```
