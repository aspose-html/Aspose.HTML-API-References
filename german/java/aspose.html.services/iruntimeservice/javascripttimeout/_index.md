## IRuntimeService.JavaScriptTimeout property

Gibt den TimeSpan zurück oder legt ihn fest, der die Ausführungszeit von JavaScript begrenzt. Wird das Skript länger als der angegebene TimeSpan ausgeführt, wird es abgebrochen. Sie können einen unbegrenzten Timeout festlegen, indem Sie den TimeSpan auf -1 Millisekunde setzen. Der Standardwert ist 1 Minute.

```java
public TimeSpan JavaScriptTimeout { get; set; }
```
