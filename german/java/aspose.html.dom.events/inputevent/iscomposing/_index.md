## InputEvent.IsComposing property

true, wenn das Eingabeereignis als Teil einer Kompositionssitzung auftritt, d. h. nach einem compositionstart‑Ereignis und vor dem entsprechenden compositionend‑Ereignis. Der nicht initialisierte Wert dieses Attributs MUSS false sein.

```java
public bool IsComposing { get; }
```

### Property Value

`true` wenn diese Instanz komponiert; andernfalls `false`.
