## InputEvent.Data property

Die Daten enthalten den Wert der durch eine Eingabemethode erzeugten Zeichen. Dies KANN ein einzeltes Unicode‑Zeichen oder eine nicht leere Sequenz von Unicode‑Zeichen [Unicode] sein. Zeichen SOLLTEN gemäß der Unicode‑Normalisierungsform NFC, definiert in [UAX15], normalisiert werden. Dieses Attribut KANN die leere Zeichenkette enthalten.

```java
public String Data { get; }
```

### Property Value

Die Ereignisdaten.
