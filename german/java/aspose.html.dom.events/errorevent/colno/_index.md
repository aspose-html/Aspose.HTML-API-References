## ErrorEvent.ColNo property

Das colno-Attribut muss den Wert zurückgeben, auf den es initialisiert wurde. Wenn das Objekt erstellt wird, muss dieses Attribut auf Null (0) initialisiert werden. Es stellt die Spaltennummer dar, in der der Fehler im Skript aufgetreten ist.

```java
public uint ColNo { get; }
```
