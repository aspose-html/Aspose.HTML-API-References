## ErrorEvent.FileName property

Das filename-Attribut muss den Wert zurückgeben, mit dem es initialisiert wurde. Wenn das Objekt erstellt wird, muss dieses Attribut auf die leere Zeichenkette initialisiert werden. Es stellt die absolute URL des Skripts dar, in dem der Fehler ursprünglich aufgetreten ist.

```java
public String FileName { get; }
```

### Property Value

Der Dateiname.
