## Event.StopPropagation method

Die `StopPropagation`‑Methode wird verwendet, um die weitere Ausbreitung eines Ereignisses während des Ereignisflusses zu verhindern.

```java
public void StopPropagation()
```

## Hinweise

Wenn diese Methode von irgendeinem [`IEventListener`](../../ieventlistener/) aufgerufen wird, hört das Ereignis auf, durch den Baum zu propagieren. Das Ereignis wird die Auslösung an alle Listener des aktuellen [`IEventTarget`](../../ieventtarget/) abschließen, bevor der Ereignisfluss stoppt. Diese Methode kann in jeder Phase des Ereignisflusses verwendet werden.
