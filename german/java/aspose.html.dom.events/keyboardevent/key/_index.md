## KeyboardEvent.Key property

Die Eigenschaft key enthält den Tastwert der gedrückten Taste. Hat der Wert eine druckbare Darstellung, MUSS er ein nicht‑leerer Unicode‑Zeichen‑String sein, der dem in dieser Spezifikation definierten Algorithmus zur Bestimmung des Tastwerts entspricht. Hat der Wert eine Steuerungstaste ohne druckbare Darstellung, MUSS er einer der im Schlüsselwert‑Set definierten Tastwerte sein, wie durch den Algorithmus zur Bestimmung des Tastwerts festgelegt. Implementierungen, die eine Taste nicht identifizieren können, MUSS den Tastwert „Unidentified“ verwenden.

```java
public String Key { get; }
```

### Property Value

Der Tastwert.
