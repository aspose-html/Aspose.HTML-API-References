## KeyboardEvent.Code property

Der Code enthält einen String, der die physische gedrückte Taste identifiziert. Der Wert wird nicht vom aktuellen Tastaturlayout oder Modifier‑Zustand beeinflusst, sodass eine bestimmte Taste immer denselben Wert zurückgibt.

```java
public String Code { get; }
```

### Property Value

Der Tastencode.
