## WheelEvent.DeltaZ property

In User Agents, bei denen die Standardaktion des Wheel-Events das Scrollen ist, MUSS der Wert die Messung entlang der Z-Achse (in Pixeln, Zeilen oder Seiten) sein, die gescrollt werden soll, falls das Event nicht abgebrochen wird. Andernfalls ist dies eine implementierungsspezifische Messung (in Pixeln, Zeilen oder Seiten) der Bewegung eines Wheel-Geräts um die Z-Achse.

```java
public double DeltaZ { get; }
```
