## WheelEvent.DeltaX property

In User‑Agents, bei denen die Standardaktion des Wheel‑Events das Scrollen ist, MÜSSEN die Werte die Messung entlang der X‑Achse (in Pixeln, Zeilen oder Seiten) sein, die gescrollt wird, wenn das Ereignis nicht abgebrochen wird. Andernfalls handelt es sich um eine implementierungsspezifische Messung (in Pixeln, Zeilen oder Seiten) der Bewegung eines Rad‑Geräts um die X‑Achse.

```java
public double DeltaX { get; }
```

### Property Value

Das Attribut deltaX.
