## WheelEvent.DeltaX property

In Benutzeragenten, bei denen die Standardaktion des Wheel-Events das Scrollen ist, MUSS der Wert die Messung entlang der x-Achse (in Pixeln, Zeilen oder Seiten) sein, die gescrollt wird, wenn das Ereignis nicht abgebrochen wird. Andernfalls ist dies eine implementierungsspezifische Messung (in Pixeln, Zeilen oder Seiten) der Bewegung eines Wheel-Geräts um die x-Achse.

```java
public double DeltaX { get; }
```

Das deltaX-Attribut.
