Das **com.aspose.html.dom.attributes**-Paket enthält einheitliche Attributklassen, die Merkmale oder Verhaltensweisen jedes Objekts (Knoten, Element, …) spezifizieren oder qualifizieren.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [DOMConstructorAttribute](./domconstructorattribute/) | Gibt einen Konstruktor an, der vom W3C definiert ist. |
| [DOMNameAttribute](./domnameattribute/) | Gibt den offiziellen DOM-Objektnamen an, wie er vom W3C definiert wurde. |
| [DOMNamedPropertyGetterAttribute](./domnamedpropertygetterattribute/) | Gibt an, dass die Methode als benannter Property-Getter verwendet wird. |
| [DOMNoInterfaceObjectAttribute](./domnointerfaceobjectattribute/) | Wenn das erweiterte Attribut [NoInterfaceObject] auf einem Interface erscheint, bedeutet dies, dass für das Interface im ECMAScript-Binding kein Interface-Objekt existiert. |
| [DOMNullableAttribute](./domnullableattribute/) | Gibt an, dass einem DOM-Objekt ein Nullwert zugewiesen werden kann. |
| [DOMObjectAttribute](./domobjectattribute/) | Gibt an, dass das Objekt, das mit diesem Attribut markiert ist, vom W3C definiert wurde. |
| [DOMTreatNullAsAttribute](./domtreatnullasattribute/) | Zeigt an, dass ein Nullwert des Mitgliederwerts als der angegebene Wert behandelt wird. |
