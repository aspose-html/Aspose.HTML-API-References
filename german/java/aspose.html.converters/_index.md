Das Ziel des **com.aspose.html.converters**-Pakets ist ein einfacher Zugriff auf Konvertierungsmethoden. Es bietet ein breites Spektrum an Konvertierungen in gängige Formate wie PDF, XPS, Bildformate usw. Spezifischere Konvertierungs‑ (Rendering‑, Speicher‑) Anwendungsfälle werden durch gut bekannte und dokumentierte Low‑Level‑API‑Funktionen in fachorientierten Paketen bereitgestellt.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [Converter](./converter/) | Gemeinsame Fassade ausschließlich für die am häufigsten vorkommenden Konvertierungsszenarien. Sie bietet eine breite Palette von Konvertierungen in gängige Formate wie PDF, XPS, Bildformate usw. Spezifischere Anwendungsfälle für Konvertierung (Rendering, Speicherung) werden durch bekannte und dokumentierte Low-Level-API-Funktionen bereitgestellt. |
| [TemplateContentOptions](./templatecontentoptions/) | Inline-Inhaltsobjekt für die Zusammenführungsbearbeitung. |
| [TemplateData](./templatedata/) | Zusammenführungs-(Benutzer-)Datenobjekt. |
