## Converter class

Gemeinsame Fassade ausschließlich für die am häufigsten vorkommenden Konvertierungsszenarien. Sie bietet eine breite Palette von Konvertierungen in gängige Formate wie PDF, XPS, Bildformate usw. Spezifischere Anwendungsfälle für Konvertierung (Rendering, Speicherung) werden durch bekannte und dokumentierte Low-Level-API-Funktionen bereitgestellt.

Weitere detaillierte, konversionsspezifische Informationen erhalten Sie in der [Aspose Documentation](https://docs.aspose.com/html/net/converting-between-formats/)

```java
public static class Converter
```
