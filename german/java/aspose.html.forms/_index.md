Das Paket bietet Zugriff auf zahlreiche Objekte (Elemente), die für die Benutzerinteraktivität innerhalb von Formularen als Webseitenelement verantwortlich sind.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [ButtonElement](./buttonelement/) | Das ButtonElement stellt einen Wrapper dar, der mit dem HTMLButtonElement verknüpft ist. |
| [DataListElement](./datalistelement/) | Das DataListElement stellt einen Wrapper dar, der mit dem HTMLDataListElement verknüpft ist. |
| [FormEditor](./formeditor/) | Diese Klasse stellt den Editor für das [`HTMLFormElement`](../com.aspose.html/htmlformelement/) dar, der .net‑Entwicklern einen einfacheren Weg zum Bearbeiten von HTML‑Formularen bietet. |
| [FormElement](./formelement/) | Stellt die Basisklasse für Formularelemente dar. |
| [FormElement&lt;T&gt;](./formelement-1/) | Das [`FormElement`](../com.aspose.html.forms/formelement/) repräsentiert das generische Feld. |
| [FormSubmitter](./formsubmitter/) | Diese Klasse ermöglicht das Vorbereiten eines angegebenen [`HTMLFormElement`](../com.aspose.html/htmlformelement/), sammelt Werte aus dem Formularelement, sendet sie an den entfernten Server und empfängt eine Antwort. |
| [InputElement](./inputelement/) | Das InputElement stellt einen Wrapper dar, der mit dem HTMLInputElement verknüpft ist. |
| [OptionCollection](./optioncollection/) | Das OptionElements stellt einen Wrapper dar, der mit der IHTMLOptionsCollection verknüpft ist. |
| [OptionElement](./optionelement/) | Das OptionElement stellt einen Wrapper dar, der mit dem HTMLOptionElement verknüpft ist. |
| [SelectElement](./selectelement/) | Das SelectElement stellt einen Wrapper dar, der mit dem HTMLSelectElement verknüpft ist. |
| [SubmissionResult](./submissionresult/) | Diese Klasse stellt das Ergebnis des Sendens von Formulardaten an den Server dar. |
| [TextAreaElement](./textareaelement/) | Das TextAreaElement stellt einen Wrapper dar, der mit dem HTMLTextAreaElement verknüpft ist. |
