## Observe(Node) {#observe}

Weist den User‑Agent an, ein angegebenes Ziel (einen Knoten) zu beobachten und Mutationen basierend auf den durch die Optionen (ein Objekt) festgelegten Kriterien zu melden. Das Optionsargument ermöglicht das Festlegen von Beobachtungsoptionen für Mutationen über Objektmitglieder.

```java
public void Observe(Node target)
```
