## Observe(Node) {#observe}

Weist den User-Agent an, ein angegebenes Ziel (einen Knoten) zu beobachten und alle Mutationen basierend auf den durch Optionen (ein Objekt) vorgegebenen Kriterien zu melden. Das Optionsargument ermöglicht das Festlegen von Beobachtungsoptionen für Mutationen über Objektmitglieder.

```java
public void Observe(Node target)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| Ziel | Node | Das Ziel für observe. |
