## MutationObserver constructor

Erstellt ein MutationObserver-Objekt und setzt dessen [`MutationCallback`](../../mutationcallback/) auf callback. Der Callback wird mit einer Liste von MutationRecord-Objekten als erstem Argument und dem erstellten MutationObserver-Objekt als zweitem Argument aufgerufen. Er wird aufgerufen, nachdem Knoten, die mit der !:Observe(Node, IMutationObserverInit)-Methode registriert wurden, mutiert wurden.

```java
public MutationObserver(MutationCallback callback)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| callback | MutationCallback | Der Callback. |
