Das **com.aspose.html.dom.mutations**-Paket bietet die Möglichkeit, DOM‑Mutationen zu beobachten und spezifische Callback‑Informationen zu erhalten.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [MutationCallback](./mutationcallback/) | Stellt die Methode dar, die Mutationsereignisse verarbeitet. |
| [MutationObserver](./mutationobserver/) | Ein Objekt kann verwendet werden, um Mutationen am Baum von [`.`](../com.aspose.html.dom/node/) zu beobachten. |
| [MutationObserverInit](./mutationobserverinit/) | Diese Klasse stellt eine Optionssammlung dar, die verwendet wird, um [`MutationObserver`](../com.aspose.html.dom.mutations/mutationobserver/) zu konfigurieren. |
| [MutationRecord](./mutationrecord/) | Ein MutationRecord stellt eine einzelne DOM-Mutation dar. Es ist das Objekt, das an die [`MutationObserver`](../com.aspose.html.dom.mutations/mutationobserver/)-[`MutationCallback`](../com.aspose.html.dom.mutations/mutationcallback/) übergeben wird. |
