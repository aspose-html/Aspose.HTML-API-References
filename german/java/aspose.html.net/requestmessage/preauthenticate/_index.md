## RequestMessage.PreAuthenticate property

Liest oder legt einen Wert fest, der angibt, ob ein Authorization-Header mit der Anforderung gesendet werden soll.

```java
public bool PreAuthenticate { get; set; }
```

### Property Value

`true`, um einen HTTP-Authorization-Header mit Anfragen zu senden, nachdem die Authentifizierung stattgefunden hat; andernfalls `false`. Der Standardwert ist `false`.
