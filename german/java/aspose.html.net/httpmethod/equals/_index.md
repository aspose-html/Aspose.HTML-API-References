## Equals(HttpMethod) {#equals}

Gibt an, ob das aktuelle Objekt einem anderen Objekt desselben Typs gleich ist.


| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| andere | HttpMethod | Ein Objekt zum Vergleich mit diesem Objekt. |

### Rückgabewert
