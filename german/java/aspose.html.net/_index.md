Das **com.aspose.html.net** Paket wird durch Klassen und Schnittstellen bereitgestellt, die für die einfache Netzwerkverarbeitung verantwortlich sind.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [ByteArrayContent](./bytearraycontent/) | Stellt Inhalt basierend auf einem Byte‑Array dar. |
| [Content](./content/) | Stellt eine Basisklasse für einen HTTP-Entitätskörper und Inhalts‑Header dar. |
| [ContentHeaders](./contentheaders/) | Enthält die Header, die mit einem Inhalt verbunden sind. |
| [FormUrlEncodedContent](./formurlencodedcontent/) | Ein Container für Name‑Wert‑Tupel, die mit dem MIME‑Typ application/x-www-form-urlencoded kodiert sind. |
| [HttpMethod](./httpmethod/) | Stellt eine Hilfsklasse zum Abrufen und Vergleichen von Standard‑HTTP‑Methoden dar. |
| [MessageFilter](./messagefilter/) | Stellt eine abstrakte Basisklasse für verschiedene Filterklassen dar, die zum Abfragen von Nachrichten verwendet werden |
| [MessageHandler](./messagehandler/) | Stellt einen Basistyp für Nachrichten-Handler dar. |
| [MessageHandlerCollection](./messagehandlercollection/) | Stellt eine Sammlung des [`MessageHandler`](../com.aspose.html.net/messagehandler/) dar. |
| [MultipartContent](./multipartcontent/) | Stellt einen multipart/*-Inhalt dar. |
| [MultipartFormDataContent](./multipartformdatacontent/) | Stellt Inhalt für den multipart/form-data-Kodierungsalgorithmus dar |
| [RequestHeaders](./requestheaders/) | Enthält Protokoll-Header, die mit einer Anforderung verbunden sind. |
| [RequestMessage](./requestmessage/) | Stellt eine Anforderungsnachricht dar. |
| [ResponseHeaders](./responseheaders/) | Enthält Protokoll-Header, die mit einer Antwort verbunden sind. |
| [ResponseMessage](./responsemessage/) | Stellt eine Antwortnachricht dar. |
| [StreamContent](./streamcontent/) | Stellt Inhalt basierend auf einem Stream dar. |
| [StringContent](./Stringcontent/) | Stellt Inhalt basierend auf einem String dar. |
| [UrlResolver](./urlresolver/) | Stellt eine Hilfsklasse zum Auflösen einer absoluten URL anhand eines Uniform Resource Identifier (URI) bereit. |
## Schnittstellen
