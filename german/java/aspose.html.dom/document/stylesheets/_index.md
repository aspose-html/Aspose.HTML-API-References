## Document.StyleSheets property

Eine Liste, die alle Stylesheets enthält, die explizit in ein Dokument verlinkt oder darin eingebettet sind. Für HTML‑Dokumente umfasst dies externe Stylesheets, die über das HTML‑LINK‑Element eingebunden werden, sowie Inline‑STYLE‑Elemente.

public IStyleSheetList StyleSheets { get; }
