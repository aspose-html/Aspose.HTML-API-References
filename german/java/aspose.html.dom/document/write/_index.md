## Document.Write method

Schreibt eine Zeichenkette in einen Dokumenten-Stream, der mit open() geöffnet wurde. Beachten Sie, dass die Funktion ein Dokument erzeugt, das nicht unbedingt von einer DTD gesteuert wird und daher im Kontext des Dokuments ein ungültiges Ergebnis erzeugen kann.

```java
public void Write(params String[] texts)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| Texte | String[] | Der String, der in eine Struktur im Dokumentenstrukturmodell geparst werden soll. |
