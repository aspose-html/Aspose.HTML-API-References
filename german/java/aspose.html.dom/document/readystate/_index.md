## Document.ReadyState property

Gibt den Dokumentbereitschaftszustand zurück. Das "loading", während das Document lädt, "interactive", sobald es das Parsen abgeschlossen hat, aber noch Unterressourcen lädt, und "complete", sobald es geladen ist.

```java
public String ReadyState { get; }
```
