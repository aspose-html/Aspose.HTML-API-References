## Document.ReadyState property

Gibt den Dokumentstatus zurück. "loading" während das Document lädt, "interactive" sobald das Parsen abgeschlossen ist, aber noch Unterressourcen lädt, und "complete" sobald es vollständig geladen ist.

```java
public String ReadyState { get; }
```
