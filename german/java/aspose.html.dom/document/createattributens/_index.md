## Document.CreateAttributeNS method

Die Methode Document.createAttribute() erstellt einen neuen Attributknoten und gibt ihn zurück. Das erstellte Objekt ist ein Knoten, der das [Attr](T:com.aspose.html.dom.Attr)‑Interface implementiert. Das DOM erzwingt nicht, welche Art von Attributen auf diese Weise zu einem bestimmten Element hinzugefügt werden können.

```java
public Attr CreateAttributeNS(String packageURI, String qualifiedName)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| packageURI | String | Der Paket-URI des Attributs. |
| qualifiedName | String | name ist ein String, der den Namen des Attributs enthält. |
