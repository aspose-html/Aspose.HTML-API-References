## Document.XmlVersion property

Ein Attribut, das als Teil der XML-Deklaration die Versionsnummer dieses Dokuments angibt. Wenn keine Deklaration vorhanden ist und dieses Dokument das "XML"-Feature unterstützt, ist der Wert "1.0". Unterstützt das Dokument das "XML"-Feature nicht, ist der Wert immer null.

```java
public String XmlVersion { get; set; }
```

### Property Value

Die XML-Version.
