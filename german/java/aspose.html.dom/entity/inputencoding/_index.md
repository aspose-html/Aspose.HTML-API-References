## Entity.InputEncoding property

Ein Attribut, das die beim Parsen verwendete Kodierung für diese Entität angibt, wenn es sich um eine externe geparste Entität handelt. Dies ist null, wenn es eine Entität aus dem internen Teilbereich ist oder wenn sie nicht bekannt ist.

```java
public String InputEncoding { get; }
```

### Property Value

Die Eingabekodierung.
