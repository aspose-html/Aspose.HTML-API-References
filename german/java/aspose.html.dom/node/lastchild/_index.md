## Node.LastChild property

Die schreibgeschützte lastChild‑Eigenschaft des [`Node`](../)‑Interfaces gibt das letzte Kind des Knotens zurück. Wenn dessen übergeordnetes Element ein Element ist, ist das Kind in der Regel ein Elementknoten, ein Textknoten oder ein Kommentar‑Knoten. Sie gibt null zurück, wenn keine Kind‑Elemente vorhanden sind.

```java
public Node LastChild { get; }
```

### Property Value

Ein [`Node`](../), das das letzte Kind des Knotens ist, oder null, wenn keine Kind‑Elemente vorhanden sind.
