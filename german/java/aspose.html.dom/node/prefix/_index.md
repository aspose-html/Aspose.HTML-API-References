## Node.Prefix property

Die schreibgeschützte Eigenschaft prefix gibt das Paket‑Präfix des angegebenen Elements zurück, oder null, falls kein Präfix angegeben ist.

```java
public String Prefix { get; set; }
```

### Property Value

Die Eigenschaft gibt das zugehörige Paket‑Prefix zurück.
