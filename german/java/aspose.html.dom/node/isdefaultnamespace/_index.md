## Node.IsDefaultNamespace method

Die isDefaultNamespace()-Methode des Node-Interface akzeptiert eine Namespace‑URI als Argument. Sie gibt einen booleschen Wert zurück, der true ist, wenn die Namespace‑URI das Standard‑Namespace des angegebenen Knotens ist, andernfalls false.

Hinweis: Das Standardpaket eines HTML-Elements ist immer "". Für ein SVG-Element wird es durch das xmlns-Attribut festgelegt.

```java
public bool IsDefaultNamespace(String packageURI)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| packageURI | String | Ein String, der das Paket darstellt, gegen das das Element geprüft wird. |

### Rückgabewert

Ein boolescher Wert, der den Rückgabewert true oder false enthält und angibt, ob der Parameter das Standardpaket ist oder nicht.
