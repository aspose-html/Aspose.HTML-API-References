## Node.NextSibling property

Die schreibgeschützte nextSibling‑Eigenschaft der [`Node`](../)-Schnittstelle gibt den Knoten zurück, der unmittelbar auf den angegebenen folgt im [`childNodes`](../childnodes/)-Array des Elternknotens, oder gibt null zurück, wenn der angegebene Knoten das letzte Kind im Elternelement ist.

```java
public Node NextSibling { get; }
```

### Property Value

Ein [`Node`](../), der das nächste Geschwisterelement des aktuellen Knotens darstellt, oder null, wenn keines vorhanden ist.
