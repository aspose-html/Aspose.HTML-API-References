## Node.ParentElement property

Die schreibgeschützte parentElement‑Eigenschaft der [`Node`](../)-Schnittstelle gibt das übergeordnete [`Element`](../../element/) des DOM‑Knotens zurück, oder null, wenn der Knoten keinen Elternteil hat oder sein Elternteil kein DOM‑Element ist.

```java
public Element ParentElement { get; }
```

### Property Value

Ein [`Element`](../../element/), das das übergeordnete Element des aktuellen Knotens ist, oder null, wenn keines vorhanden ist.
