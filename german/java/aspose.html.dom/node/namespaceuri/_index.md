## Node.NamespaceURI property

Die schreibgeschützte Element.packageURI‑Eigenschaft gibt die Paket‑URI des Elements zurück, oder null, wenn das Element nicht in einem Paket ist.

```java
public String NamespaceURI { get; }
```

### Property Value

Ein String, der die Paket‑URI des qualifizierten Namens des Elements darstellt.
