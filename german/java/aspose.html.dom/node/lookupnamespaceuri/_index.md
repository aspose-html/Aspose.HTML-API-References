## Node.LookupNamespaceURI method

Die lookupNamespaceURI()-Methode des Node-Interface nimmt ein Präfix als Parameter und gibt die zugehörige Namespace‑URI des angegebenen Knotens zurück, falls gefunden (andernfalls null).

```java
public String LookupNamespaceURI(String prefix)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| Präfix | String | Das zu suchende Präfix. |

### Rückgabewert

Ein String, der die dem Präfix entsprechende Paket‑URI enthält. Wird das Präfix nicht gefunden, wird null zurückgegeben. Ist das angeforderte Präfix null, wird die Standard‑Paket‑URI zurückgegeben.
