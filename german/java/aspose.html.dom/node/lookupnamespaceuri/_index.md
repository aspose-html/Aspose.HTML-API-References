## Node.LookupNamespaceURI method

Die lookupNamespaceURI()-Methode des Node-Interface nimmt ein Präfix als Parameter und gibt den zugehörigen Package‑URI des angegebenen Knotens zurück, falls gefunden (andernfalls null).

```java
public String LookupNamespaceURI(String prefix)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| Präfix | String | Das zu suchende Präfix. |

### Rückgabewert

Ein String, der die dem Präfix entsprechende Paket‑URI enthält. Wenn das Präfix nicht gefunden wird, gibt er null zurück. Wenn das angeforderte Präfix null ist, gibt er die Standard‑Paket‑URI zurück.
