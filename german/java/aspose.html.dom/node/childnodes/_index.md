## Node.ChildNodes property

Die schreibgeschützte childNodes‑Eigenschaft des Node‑Interfaces gibt eine Live‑[`NodeList`](../../../com.aspose.html.collections/nodelist/) von Kindknoten des angegebenen Elements zurück, wobei dem ersten Kindknoten der Index 0 zugewiesen wird. Kindknoten umfassen Elemente, Text und Kommentare.

Hinweis: Die Live‑[`NodeList`](../../../com.aspose.html.collections/nodelist/) bedeutet, dass ihr Inhalt jedes Mal geändert wird, wenn neue Kinder hinzugefügt oder entfernt werden.

```java
public NodeList ChildNodes { get; }
```

### Property Value

Eine Live‑[`NodeList`](../../../com.aspose.html.collections/nodelist/) mit den Kindern des Knotens.

Hinweis: Mehrere Aufrufe von childNodes geben dieselbe [`NodeList`](../../../com.aspose.html.collections/nodelist/) zurück.
