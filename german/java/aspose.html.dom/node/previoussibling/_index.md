## Node.PreviousSibling property

Die schreibgeschützte previousSibling‑Eigenschaft des [`Node`](../)‑Interfaces gibt den Knoten zurück, der dem angegebenen Knoten im [`childNodes`](../firstchild/)‑Verzeichnis seines Elternteils unmittelbar vorausgeht, oder null, wenn der angegebene Knoten der erste in dieser Liste ist.

```java
public Node PreviousSibling { get; }
```

### Property Value

Ein [`Node`](../), das das vorherige Geschwister des aktuellen Knotens repräsentiert, oder null, wenn keines vorhanden ist.
