## Node.ReplaceChild method

Ersetzt den Kindknoten oldChild durch newChild in der Kindliste und gibt den oldChild‑Knoten zurück. Ist newChild ein [`DocumentFragment`](../../documentfragment/)-Objekt, wird oldChild durch alle [`DocumentFragment`](../../documentfragment/)-Kinder ersetzt, die in derselben Reihenfolge eingefügt werden. Befindet sich newChild bereits im Baum, wird es zuerst entfernt.

```java
public Node ReplaceChild(Node node, Node child)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| Knoten | Node | Der neue Knoten, der oldChild ersetzen soll. |
| Kind | Node | Das zu ersetzende Kind. |

### Rückgabewert

Der ersetzte Node. Dies ist derselbe Knoten wie oldChild.
