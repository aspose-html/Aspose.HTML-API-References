## Node.IsEqualNode method

Die isEqualNode()-Methode der [`Node`](../)-Schnittstelle prüft, ob zwei Knoten gleich sind. Zwei Knoten sind gleich, wenn sie denselben Typ und definierende Merkmale haben (bei Elementen wären das ihre ID, die Anzahl der Kinder usw.), ihre Attribute übereinstimmen und so weiter. Der genaue Satz von Datenpunkten, die übereinstimmen müssen, variiert je nach Knotentyp.

```java
public bool IsEqualNode(Node otherNode)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| otherNode | Node | Der [`Node`](../), mit dem die Gleichheit verglichen werden soll. |

### Rückgabewert

Ein boolescher Wert, der true ist, wenn die beiden Knoten gleich sind, oder false, wenn nicht. Ist otherNode null, gibt isEqualNode() immer false zurück.
