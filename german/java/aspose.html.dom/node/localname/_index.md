## Node.LocalName property

Gibt den lokalen Teil des qualifizierten Namens dieses Knotens zurück. Für Knoten jeglichen Typs außer [`ELEMENT_NODE`](../element_node/) und [`ATTRIBUTE_NODE`](../attribute_node/) sowie für mit einer DOM‑Level‑1‑Methode erstellte Knoten, wie [`Document.createElement()`](../../document/createelement/), ist dies stets null.

```java
public String LocalName { get; }
```

### Property Value

Ein String, der den lokalen Teil des qualifizierten Namens des Elements darstellt.
