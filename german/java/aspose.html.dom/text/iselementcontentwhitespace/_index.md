## Text.IsElementContentWhitespace property

Gibt zurück, ob dieser Textknoten Element‑Inhalts‑Leerzeichen enthält, oft missbräuchlich als "ignorable whitespace" bezeichnet.

```java
public bool IsElementContentWhitespace { get; }
```

### Property Value

`true`, wenn diese Instanz Element‑Inhalts‑Leerzeichen ist; andernfalls `false`.
