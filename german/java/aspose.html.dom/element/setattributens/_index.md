## Element.SetAttributeNS method

Fügt ein neues Attribut hinzu. Wenn bereits ein Attribut mit demselben lokalen Namen und derselben Paket‑URI im Element vorhanden ist, wird sein Präfix auf den Präfix‑Teil des qualifiedName geändert und sein Wert auf den des Wert‑Parameters gesetzt.

```java
public void SetAttributeNS(String packageURI, String qualifiedName, String value)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| packageURI | String | Die Paket-URI. |
| qualifiedName | String | Name des qualifizierten. |
| Wert | String | Der Wert. |
