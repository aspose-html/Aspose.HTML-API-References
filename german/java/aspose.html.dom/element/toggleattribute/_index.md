## ToggleAttribute(String) {#toggleattribute}

Wenn force nicht angegeben ist, wird qualifiedName „gewechselt“, d. i. es wird entfernt, wenn es vorhanden ist, und hinzugefügt, wenn es nicht vorhanden ist. Ist force true, wird qualifiedName hinzugefügt. Ist force false, wird qualifiedName entfernt.

```java
public bool ToggleAttribute(String qualifiedName)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| qualifiedName | String | Der Attribut-QualifiedName. |

### Rückgabewert

Gibt true zurück, wenn qualifiedName jetzt vorhanden ist; andernfalls false.
