## IDOMImplementation interface

Das DOMImplementation‑Interface bietet eine Reihe von Methoden zur Durchführung von Operationen, die von keiner bestimmten Instanz des Document Object Model abhängig sind.

```java
public interface IDOMImplementation
```

## Methoden

| Name | Beschreibung |
| --- | --- |
| [createDocument](../../com.aspose.html.dom/idomimplementation/createdocument/)(String, String, DocumentType) | Erstellt ein DOM Document-Objekt des angegebenen Typs mit seinem Dokument-Element. |
| [createDocumentType](../../com.aspose.html.dom/idomimplementation/createdocumenttype/)(String, String, String) | Erstellt einen leeren DocumentType‑Knoten. Entity‑Deklarationen und Notationen stehen nicht zur Verfügung. Entity‑Referenzerweiterungen und das Hinzufügen von Standardattributen erfolgen nicht. |
| [createHTMLDocument](../../com.aspose.html.dom/idomimplementation/createhtmldocument/)(String) | Gibt ein Dokument zurück, bei dem bereits ein einfacher Baum mit einem Titel‑Element erstellt wurde, sofern das Titel‑Argument nicht weggelassen wird. |
| [hasFeature](../../com.aspose.html.dom/idomimplementation/hasfeature/)() | Prüft, ob die DOM‑Implementierung ein bestimmtes Feature und eine bestimmte Version unterstützt, wie in DOM Features angegeben. |
