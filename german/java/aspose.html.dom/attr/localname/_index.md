## Attr.LocalName property

Gibt den lokalen Teil des qualifizierten Namens dieses Knotens zurück. Für Knoten jeglichen Typs außer ELEMENT_NODE und ATTRIBUTE_NODE sowie für mit einer DOM Level 1-Methode erstellte Knoten, wie Document.createElement(), ist dies immer null.

```java
public String LocalName { get; }
```

### Property Value

Der Name des Lokalen.
