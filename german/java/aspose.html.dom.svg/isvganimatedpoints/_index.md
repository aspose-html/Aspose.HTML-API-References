## ISVGAnimatedPoints interface

Das SVGAnimatedPoints-Interface unterstützt Elemente, die ein ‘points’-Attribut besitzen, das eine Liste von Koordinatenwerten enthält und die die Möglichkeit unterstützt, dieses Attribut zu animieren. Zusätzlich wird das ‘points’-Attribut des ursprünglichen Elements, das über das XML DOM(e.g., using the getAttribute() method call) abgerufen wird, alle Änderungen an den Punkten widerspiegeln.

```java
public interface ISVGAnimatedPoints
```

## Eigenschaften

| Name | Beschreibung |
| --- | --- |
| [getAnimatedPoints](../../com.aspose.html.dom.svg/isvganimatedpoints/animatedpoints/) Bietet Zugriff auf den aktuellen animierten Inhalt des ‘points’-Attributs. Wenn das angegebene Attribut oder die Eigenschaft animiert wird, enthält es den aktuellen animierten Wert des Attributs oder der Eigenschaft. Wenn das angegebene Attribut oder die Eigenschaft derzeit nicht animiert wird, enthält es denselben Wert wie points. |
| [getPoints](../../com.aspose.html.dom.svg/isvganimatedpoints/points/) Bietet Zugriff auf die Basis (d. h. statischen) Inhalte des ‘points’-Attributs. |
