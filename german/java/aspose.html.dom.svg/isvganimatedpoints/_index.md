## ISVGAnimatedPoints interface

The SVGAnimatedPoints interface supports elements which have a ‘points’ attribute which holds a list of coordinate values and which support the ability to animate that attribute. Additionally, the ‘points’ attribute on the original element accessed via the XML DOM(e.g., using the getAttribute() method call) will reflect any changes made to points.

public interface ISVGAnimatedPoints

| --- | --- |
| [getAnimatedPoints](../../com.aspose.html.dom.svg/isvganimatedpoints/animatedpoints/) Bietet Zugriff auf den aktuellen animierten Inhalt des ‘points’-Attributs. Wenn das angegebene Attribut oder die Eigenschaft animiert wird, enthält es den aktuellen animierten Wert des Attributs oder der Eigenschaft. Wenn das angegebene Attribut oder die Eigenschaft derzeit nicht animiert wird, enthält es denselben Wert wie points. |
| [getPoints](../../com.aspose.html.dom.svg/isvganimatedpoints/points/) Bietet Zugriff auf den Basis‑ (d. h. statischen) Inhalt des ‘points’-Attributs. |
