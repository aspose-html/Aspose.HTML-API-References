## SVGPolygonElement.AnimatedPoints property

Bietet Zugriff auf die aktuell animierten Inhalte des ‘points’-Attributs. Wenn das angegebene Attribut oder die Eigenschaft animiert wird, enthält es den aktuellen animierten Wert des Attributs oder der Eigenschaft. Wenn das angegebene Attribut oder die Eigenschaft nicht animiert wird, enthält es denselben Wert wie points.

```java
public SVGPointList AnimatedPoints { get; }
```

### Property Value

Die animierten Punkte.
