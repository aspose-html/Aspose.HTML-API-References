## SVGMarkerElement.SVG_MARKERUNITS_UNKNOWN field

Der Markierungseinheitstyp ist keiner der vordefinierten Typen. Es ist ungültig, zu versuchen, einen neuen Wert dieses Typs zu definieren oder einen bestehenden Wert zu diesem Typ zu wechseln.

```java
public const ushort SVG_MARKERUNITS_UNKNOWN;
```
