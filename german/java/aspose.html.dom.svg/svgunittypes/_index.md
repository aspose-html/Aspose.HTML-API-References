## SVGUnitTypes enumeration

The SVGUnitTypes enumeration defines a commonly used set of constants and is a base interface used by SVGGradientElement, SVGPatternElement, SVGClipPathElement, SVGMaskElement and SVGFilterElement.

```java
public enum SVGUnitTypes
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| SVG_UNIT_TYPE_UNKNOWN | `0` | Der Typ ist keiner der vordefinierten Typen. Es ist ungültig, einen neuen Wert dieses Typs zu definieren oder zu versuchen, einen bestehenden Wert zu diesem Typ zu wechseln. |
| SVG_UNIT_TYPE_USERSPACEONUSE | `1` | Entspricht dem Wert 'userSpaceOnUse'. |
| SVG_UNIT_TYPE_OBJECTBOUNDINGBOX | `2` | Entspricht dem Wert 'objectBoundingBox'. |
