## SVGTextContentElement.GetNumberOfChars method

Gibt die Gesamtzahl der für das Rendern im aktuellen Element verfügbaren Zeichen zurück, einschließlich der referenzierten Zeichen aus der ‘tref’-Referenz, unabhängig davon, ob sie gerendert werden. Im Wesentlichen entspricht dies der Länge des Node::textContent-Attributs aus DOM Level 3 Core ([DOM3], Abschnitt 1.4), sofern dieses Attribut auch ‘tref’-Elemente expandiert.

```java
public long GetNumberOfChars()
```

### Rückgabewert

Gesamtzahl der Zeichen.
