## SVGElement.Style property

Entspricht dem Attribut ‘style’ des angegebenen Elements. Wenn der User-Agent keine CSS-Stilunterstützung bietet, muss dieses Attribut stets den Wert null haben.

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value
