## SVGDocument class

Ein `SVGDocument` ist die Wurzel der SVG-Hierarchie und enthält den gesamten Inhalt. Neben dem Zugriff auf die Hierarchie bietet es auch einige Komfortmethoden zum Zugriff auf bestimmte Informationssätze aus dem Dokument. Wenn ein ‘svg’-Element inline als Komponente eines Dokuments aus einem anderen Paket eingebettet ist, beispielsweise wenn ein ‘svg’-Element inline in ein XHTML-Dokument [XHTML] eingebettet wird, dann existiert kein SVGDocument-Objekt; stattdessen ist das Wurzelobjekt in der Dokumentobjekt-Hierarchie ein Document-Objekt eines anderen Typs, wie ein HTMLDocument-Objekt. Ein SVGDocument-Objekt existiert jedoch, wenn das Wurzelelement der XML-Dokumenthierarchie ein ‘svg’-Element ist, beispielsweise beim Betrachten einer eigenständigen SVG-Datei (d. h. einer Datei mit dem MIME-Typ "image/svg+xml"). In diesem Fall ist das SVGDocument-Objekt das Wurzelobjekt der Dokumentobjektmodell-Hierarchie.

public class SVGDocument : Document, IDocumentCSS
