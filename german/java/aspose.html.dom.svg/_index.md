Alle Klassen im **com.aspose.html.dom.svg**-Paket basieren auf den w3c SVG2‑Empfehlungen. Mit diesem Paket können Sie SVG‑Dateien nach Ihren Anforderungen laden, navigieren oder rendern.

| [SVGDocument](./svgdocument/) | Ein `SVGDocument` ist die Wurzel der SVG-Hierarchie und enthält den gesamten Inhalt. Neben dem Zugriff auf die Hierarchie bietet es auch einige Komfortmethoden zum Zugriff auf bestimmte Informationssätze aus dem Dokument. Wenn ein ‘svg’-Element inline als Komponente eines Dokuments aus einem anderen Paket eingebettet ist, beispielsweise wenn ein ‘svg’-Element inline in ein XHTML-Dokument [XHTML] eingebettet wird, dann existiert kein SVGDocument-Objekt; stattdessen ist das Wurzelobjekt in der Dokumentobjekt-Hierarchie ein Document-Objekt eines anderen Typs, wie ein HTMLDocument-Objekt. Ein SVGDocument-Objekt existiert jedoch, wenn das Wurzelelement der XML-Dokumenthierarchie ein ‘svg’-Element ist, beispielsweise beim Betrachten einer eigenständigen SVG-Datei (d. h. einer Datei mit dem MIME-Typ "image/svg+xml"). Für die Methoden dieser Schnittstelle, die sich auf einen Index zu einem Zeichen oder eine Anzahl von Zeichen beziehen, sind diese Referenzen als ein Index zu einer UTF-16-Codeeinheit bzw. eine Anzahl von UTF-16-Codeeinheiten zu interpretieren.
