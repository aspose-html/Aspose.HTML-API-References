Alle Klassen im **com.aspose.html.dom.svg**-Paket basieren auf den w3c SVG2‑Empfehlungen. Mit diesem Paket können Sie SVG‑Dateien nach Ihren Anforderungen laden, navigieren oder rendern.

Wenn ein ‘svg’-Element inline als Komponente eines Dokuments aus einem anderen Paket eingebettet wird, beispielsweise wenn ein ‘svg’-Element inline innerhalb eines XHTML-Dokuments [XHTML] eingebettet ist, existiert kein SVGDocument-Objekt; stattdessen ist das Wurzelobjekt in der Dokumentobjekt-Hierarchie ein Document-Objekt eines anderen Typs, wie ein HTMLDocument-Objekt.
