## SVGGraphicsElement.GetBBox method

Gibt das enge Begrenzungsrechteck im aktuellen Benutzerraum zurück (d. i. nach Anwendung des Attributs ‘transform’, falls vorhanden) für die Geometrie aller enthaltenen Grafikelemente, ohne Strichführung, Clipping, Maskierung und Filtereffekte. Hinweis: getBBox muss das tatsächliche Begrenzungsrechteck zum Zeitpunkt des Aufrufs zurückgeben, selbst wenn das Element noch nicht gerendert wurde.

```java
public SVGRect GetBBox()
```

### Rückgabewert

Ein SVGRect-Objekt, das die Begrenzungsbox definiert.
