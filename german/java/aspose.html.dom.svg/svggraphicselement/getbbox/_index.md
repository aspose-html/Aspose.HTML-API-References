## SVGGraphicsElement.GetBBox method

Gibt die enge Begrenzungsbox im aktuellen Benutzerraum zurück (d. h. nach Anwendung des Attributs ‘transform’, falls vorhanden) für die Geometrie aller enthaltenen Grafikelemente, ohne Strichführung, Clipping, Maskierung und Filtereffekte. Hinweis: getBBox muss zum Zeitpunkt des Aufrufs die tatsächliche Begrenzungsbox zurückgeben, selbst wenn das Element noch nicht gerendert wurde.

```java
public SVGRect GetBBox()
```

### Rückgabewert

Ein SVGRect-Objekt, das das Begrenzungsrechteck definiert.
