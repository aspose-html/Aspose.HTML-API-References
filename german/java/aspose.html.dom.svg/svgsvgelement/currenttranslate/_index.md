## SVGSVGElement.CurrentTranslate property

Bei einem äußersten SVG‑Element der entsprechende Translationsfaktor, der die Benutzermagnifikation berücksichtigt. Wenn er bei einem ‘svg’-Element, das nicht das äußerste SVG‑Element ist, abgerufen wird, ist das Verhalten dieses Attributs nicht definiert.

```java
public SVGPoint CurrentTranslate { get; }
```

### Property Value

Die aktuelle Translation.
