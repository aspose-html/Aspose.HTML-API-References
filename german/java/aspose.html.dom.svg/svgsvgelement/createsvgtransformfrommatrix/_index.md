## SVGSVGElement.CreateSVGTransformFromMatrix method

Erstellt ein SVGTransform‑Objekt außerhalb von Dokumentbäumen. Das Objekt wird mit der angegebenen Matrix‑Transformation (d.h. SVG_TRANSFORM_MATRIX) initialisiert. Die Werte der Parameter‑Matrix werden kopiert, der Matrix‑Parameter wird nicht als SVGTransform::matrix übernommen.

```java
public SVGTransform CreateSVGTransformFromMatrix(SVGMatrix matrix)
```

| Matrix | SVGMatrix | Die Transformationsmatrix. |
