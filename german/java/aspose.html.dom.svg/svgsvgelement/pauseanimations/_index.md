## SVGSVGElement.PauseAnimations method

Setzt (d. h. pausiert) alle derzeit laufenden Animationen, die innerhalb des SVG-Dokumentfragments definiert sind, das diesem ‘svg’-Element entspricht, und lässt die Animationsuhr dieses Dokumentfragments stillstehen, bis sie wieder fortgesetzt wird.
