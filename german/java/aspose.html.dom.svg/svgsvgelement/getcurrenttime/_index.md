## SVGSVGElement.GetCurrentTime method

Gibt die aktuelle Zeit in Sekunden relativ zur Startzeit des aktuellen SVG-Dokumentfragments zurück. Wird getCurrentTime aufgerufen, bevor die Dokumentzeitlinie begonnen hat (z. B. durch ein Skript, das in einem ‘script’-Element läuft, bevor das SVGLoad-Ereignis des Dokuments ausgelöst wird), wird 0 zurückgegeben.

```java
public float GetCurrentTime()
```

### Rückgabewert

Die aktuelle Zeit in Sekunden, oder 0, wenn die Dokument‑Zeitlinie noch nicht begonnen hat.
