## SVGViewElement.ViewTarget property

Entspricht dem Attribut ‘viewTarget’ des angegebenen ‘view’-Elements. Eine Liste von DOMString-Werten, die die im ‘viewTarget’-Attribut aufgeführten Namen enthalten. Jeder der DOMString-Werte kann mit dem entsprechenden Element mittels des Aufrufs der getElementById()-Methode verknüpft werden.

```java
public SVGStringList ViewTarget { get; }
```

### Property Value

Das Attribut ‘viewTarget’ des angegebenen ‘view’-Elements.
