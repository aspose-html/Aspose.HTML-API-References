## SVGOptimizationOptions.RemoveUnusedNamespaces property

Liest oder setzt die Option, die Deklaration ungenutzter Pakete aus dem SVG‑Element zu entfernen, die in Elementen oder Attributen nicht verwendet werden. Sie ist standardmäßig 'true'.
