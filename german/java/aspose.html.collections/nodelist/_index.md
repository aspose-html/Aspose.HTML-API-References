## NodeList class

Die NodeList bietet die Abstraktion einer geordneten Sammlung von Knoten, ohne festzulegen oder einzuschränken, wie diese Sammlung implementiert wird.

```java
public abstract class NodeList : DOMObject, IEnumerable<Node>
```
