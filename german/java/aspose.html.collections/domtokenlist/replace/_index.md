## DOMTokenList.Replace method

Ersetzt ein vorhandenes Token durch ein neues Token. Tut nichts, wenn das erste Token nicht existiert.

```java
public bool Replace(String token, String newToken)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| Token | String | Das Token, das Sie ersetzen möchten. |
| newToken | String | Das Token, mit dem Sie das alte Token ersetzen möchten. |

### Rückgabewert

Boolean `true`, wenn das Token gefunden und ersetzt wurde, andernfalls `false`.
