## NamedNodeMap.SetNamedItem method

Fügt einen Knoten über sein nodeName-Attribut hinzu. Wenn bereits ein Knoten mit diesem Namen in dieser Map vorhanden ist, wird er durch den neuen ersetzt. Das Ersetzen eines Knotens durch sich selbst hat keine Wirkung.

```java
public Attr SetNamedItem(Attr attr)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| attr | Attr | Das Attribut. |

### Rückgabewert

Gibt Knoten zurück.
