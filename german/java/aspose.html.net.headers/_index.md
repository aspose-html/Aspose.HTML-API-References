Das **com.aspose.html.net.headers** bietet einige Datenklassen zur Beschreibung von Header-Inhalten im Netzwerkverkehr.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [ContentDispositionHeaderValue](./contentdispositionheadervalue/) | Stellt den Wert des Content‑Disposition‑Headers dar. |
| [ContentTypeHeaderValue](./contenttypeheadervalue/) | Stellt einen Content‑Type‑Headerwert dar. |
| [NameValueHeaderValue](./namevalueheadervalue/) | Stellt ein Namens-/Wert-Paar dar, das einen Header-Wert beschreibt. |
