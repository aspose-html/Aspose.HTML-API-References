Das **com.aspose.html.net.headers** Paket stellt einige Datenklassen zur Beschreibung von Header-Inhalten im Netzwerk bereit.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [ContentDispositionHeaderValue](./contentdispositionheadervalue/) | Stellt den Wert des Content‑Disposition‑Headers dar. |
| [ContentTypeHeaderValue](./contenttypeheadervalue/) | Stellt den Wert des Content‑Type‑Headers dar. |
| [NameValueHeaderValue](./namevalueheadervalue/) | Stellt ein Namens-/Wert-Paar dar, das einen Header-Wert beschreibt. |
