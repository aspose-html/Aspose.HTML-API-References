Das **com.aspose.html.dom.svg.paths**-Paket beschreibt Klassen zur Darstellung der Kontur einer Form, die gefüllt oder gestrichen werden kann. Ein Pfad kann auch als Clipping‑Pfad verwendet werden, um Animationen zu beschreiben oder Text zu positionieren.
