## ISVGAnimatedPathData.PathSegList property

Bietet Zugriff auf die Basis‑ (d.h. statischen) Inhalte des ‘d’-Attributs in einer Form, die eins‑zu‑eins der SVG‑Syntax entspricht. So hat das ‘d’-Attribut, wenn es einen "absoluten moveto (M)" und einen "absoluten arcto (A)" Befehl enthält, dann wird pathSegList zwei Einträge haben: ein SVG_PATHSEG_MOVETO_ABS und ein SVG_PATHSEG_ARC_ABS.

```java
public SVGPathSegList PathSegList { get; }
```

### Property Value

Die Pfadsegmentliste.
