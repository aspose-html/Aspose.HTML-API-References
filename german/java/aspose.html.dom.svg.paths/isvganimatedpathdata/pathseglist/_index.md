## ISVGAnimatedPathData.PathSegList property

Bietet Zugriff auf die Basis‑ (d. h. statischen) Inhalte des ‘d’-Attributs in einer Form, die eins‑zu‑eins mit der SVG‑Syntax übereinstimmt. Somit hat pathSegList zwei Einträge, wenn das ‘d’-Attribut einen "absoluten moveto (M)" und einen "absoluten arcto (A)" Befehl enthält: ein SVG_PATHSEG_MOVETO_ABS und ein SVG_PATHSEG_ARC_ABS.

```java
public SVGPathSegList PathSegList { get; }
```

### Property Value

Die Pfadsegmentliste.
