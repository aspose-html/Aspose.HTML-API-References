## ISVGAnimatedPathData.AnimatedPathSegList property

Bietet Zugriff auf die aktuellen animierten Inhalte des ‘d’-Attributs in einer Form, die eins‑zu‑eins mit der SVG‑Syntax übereinstimmt. Wenn das angegebene Attribut oder die Eigenschaft animiert wird, enthält es den aktuellen animierten Wert des Attributs oder der Eigenschaft, und sowohl das Objekt selbst als auch dessen Inhalte sind schreibgeschützt. Wenn das angegebene Attribut oder die Eigenschaft derzeit nicht animiert wird, enthält es denselben Wert wie pathSegList.

```java
public SVGPathSegList AnimatedPathSegList { get; }
```

### Property Value

Die animierte Pfadsegmentliste.
