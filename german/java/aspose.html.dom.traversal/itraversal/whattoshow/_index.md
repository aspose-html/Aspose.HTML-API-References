## ITraversal.WhatToShow property

Dieses Attribut bestimmt, welche Knotentypen über den Iterator präsentiert werden. Der verfügbare Satz von Konstanten ist im NodeFilter-Interface definiert. Knoten, die von whatToShow nicht akzeptiert werden, werden übersprungen, aber ihre Kinder können weiterhin berücksichtigt werden. Hinweis: Dieses Überspringen hat Vorrang vor dem Filter, falls vorhanden.

```java
public long WhatToShow { get; }
```

### Property Value

Das what to show.
