## ITreeWalker.FirstChild method

Verschiebt den TreeWalker zum ersten sichtbaren Kind des aktuellen Knotens und gibt den neuen Knoten zurück. Wenn der aktuelle Knoten keine sichtbaren Kinder hat, wird null zurückgegeben und der aktuelle Knoten bleibt erhalten.

```java
public Node FirstChild()
```

### Rückgabewert

Der neue Knoten oder null, wenn der aktuelle Knoten keine sichtbaren Kinder in der logischen Ansicht des TreeWalkers hat.
