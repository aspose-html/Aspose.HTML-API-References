## ITreeWalker.ParentNode method

Bewegt sich zum nächsten sichtbaren Vorfahrenknoten des aktuellen Knotens und gibt ihn zurück. Wenn die Suche nach parentNode versucht, vom Wurzelknoten des TreeWalkers nach oben zu gehen, oder wenn kein sichtbarer Vorfahr gefunden wird, behält die Methode die aktuelle Position bei und gibt null zurück.

```java
public Node ParentNode()
```

### Rückgabewert

Der neue übergeordnete Knoten oder null, wenn der aktuelle Knoten keinen Elternknoten in der logischen Ansicht des TreeWalkers hat.
