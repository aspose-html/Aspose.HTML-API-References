## ITreeWalker.LastChild method

Verschiebt den TreeWalker zum letzten sichtbaren Kind des aktuellen Knotens und gibt den neuen Knoten zurück. Wenn der aktuelle Knoten keine sichtbaren Kinder hat, wird null zurückgegeben und der aktuelle Knoten bleibt erhalten.

```java
public Node LastChild()
```

### Rückgabewert

Der neue Knoten oder null, wenn der aktuelle Knoten keine Kinder in der logischen Ansicht des TreeWalkers hat.
