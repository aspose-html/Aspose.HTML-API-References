## INodeIterator.Detach method

Löst den NodeIterator von der Menge, über die er iteriert hat, gibt alle Rechenressourcen frei und versetzt den Iterator in den INVALID‑Zustand. Nachdem detach aufgerufen wurde, führen Aufrufe von nextNode oder previousNode zu der Ausnahme INVALID_STATE_ERR.
