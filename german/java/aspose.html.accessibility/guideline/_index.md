## Guideline class

Richtlinien – die nächste Ebene nach den Prinzipien. Sie sind nicht testbar, sondern skizzieren Rahmenwerke und allgemeine Ziele, die Autoren helfen, Erfolgskriterien zu verstehen und die Techniken besser anzuwenden. Richtlinien sind eine Liste von Akzeptanzkriterien vom Typ RuleDirectory{Criterion}.
