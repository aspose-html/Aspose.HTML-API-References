## Converter class

共享外观仅用于最常见的转换场景。它提供了广泛的转换，支持 PDF、XPS、图像等流行格式。更具体的转换（渲染、保存）使用案例由知名且有文档的底层 API 函数提供。

您可以在 [Aspose Documentation](https://docs.aspose.com/html/net/converting-between-formats/) 上获取更详细的特定转换信息。

```java
public static class Converter
```
