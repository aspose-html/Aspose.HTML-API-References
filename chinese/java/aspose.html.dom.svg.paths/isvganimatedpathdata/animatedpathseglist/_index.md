## ISVGAnimatedPathData.AnimatedPathSegList property

提供对 ‘d’ 属性当前动画内容的访问，形式与 SVG 的语法一一对应。如果给定的属性或属性正在动画，则包含该属性的当前动画值，且对象本身及其内容均为只读。如果给定的属性或属性当前未动画，则包含与 pathSegList 相同的值。

```java
public SVGPathSegList AnimatedPathSegList { get; }
```

### Property Value

动画路径段列表。
