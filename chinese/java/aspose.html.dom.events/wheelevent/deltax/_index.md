## WheelEvent.DeltaX property

在默认行为为滚动的用户代理中，如果事件未被取消，则该值必须是沿 x 轴的计量（以像素、行或页为单位），用于滚动。否则，这是一种实现特定的计量（以像素、行或页为单位），表示轮设备围绕 x 轴的移动。

public double DeltaX { get; }
