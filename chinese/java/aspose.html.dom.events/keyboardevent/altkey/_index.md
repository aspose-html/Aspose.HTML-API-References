## KeyboardEvent.AltKey property

若 Alt（alternative）（或 \"Option\")键修饰符处于激活状态则为 true。此属性的未初始化值必须为 false。

```java
public bool AltKey { get; }
```

### Property Value

`true` 表示 Alt；否则为 `false`。
