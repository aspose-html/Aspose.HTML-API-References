## KeyboardEvent.DOM_KEY_LOCATION_NUMPAD field

键激活源于数字键盘或对应数字键盘的虚拟键（当此键有多个可能位置时）。请注意，NumLock 键应始终使用 DOM_KEY_LOCATION_STANDARD 位置进行编码。

```java
public const ulong DOM_KEY_LOCATION_NUMPAD;
```
