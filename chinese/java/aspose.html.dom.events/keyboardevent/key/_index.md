## KeyboardEvent.Key property

key 保存被按下键的键值。如果该值有可打印的表示，则必须是符合本规范中键值确定算法的非空 Unicode 字符串。如果该值是没有可打印表示的控制键，则必须是键值集合中由键值确定算法定义的键值之一。无法识别键的实现必须使用键值 “Unidentified”。

```java
public String Key { get; }
```

### Property Value

键值。
