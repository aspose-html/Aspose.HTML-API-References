## KeyboardEvent.CtrlKey property

若 Control（control）键修饰符处于激活状态则为 true。此属性的未初始化值必须为 false。

```java
public bool CtrlKey { get; }
```

### Property Value

`true` 表示 Control；否则为 `false`。
