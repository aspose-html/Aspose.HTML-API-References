## KeyboardEvent.IsComposing property

如果键事件作为组合会话的一部分发生，即在 compositionstart 事件之后、对应的 compositionend 事件之前，则为 true。此属性的未初始化值必须为 false。

```java
public bool IsComposing { get; }
```

### Property Value

`true` 如果此实例正在组合；否则，`false`。
