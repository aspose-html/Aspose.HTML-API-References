## InputEvent.Data property

data 保存由输入法生成的字符值。它可以是单个 Unicode 字符或非空的 Unicode 字符序列 [Unicode]。字符应按照 [UAX15] 中定义的 Unicode 正规化形式 NFC 进行规范化。此属性可以包含空字符串。

```java
public String Data { get; }
```

### Property Value

事件数据。
