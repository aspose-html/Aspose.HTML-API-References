## ErrorEvent.Error property

error 属性必须返回其初始化时的值。创建对象时，此属性必须初始化为 null。适当情况下，它会被设置为表示错误的对象（例如在未捕获的 DOM 异常情况下的异常对象）。

```java
public object Error { get; }
```

### Property Value

错误。
