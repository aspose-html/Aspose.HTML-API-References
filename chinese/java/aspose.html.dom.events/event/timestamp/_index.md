## Event.TimeStamp property

用于指定事件创建时相对于纪元的毫秒时间。由于某些系统可能不提供此信息，timeStamp 的值可能并非对所有事件都可用。如果不可用，将返回 0。纪元时间的示例包括系统启动时间或 1970 年 1 月 1 日 00:00:00 UTC。

```java
public ulong TimeStamp { get; }
```
