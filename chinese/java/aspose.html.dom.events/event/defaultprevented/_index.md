## Event.DefaultPrevented property

如果在 cancelable 属性为 true 时调用了 preventDefault()，则返回 true；否则返回 false。

```java
public bool DefaultPrevented { get; }
```

### Property Value

`true` 表示已阻止默认操作；否则为 `false`。
