## Event.StopPropagation method

`StopPropagation` 方法用于在事件流期间阻止事件的进一步传播。

```java
public void StopPropagation()
```

## 备注

如果任何 [`IEventListener`](../../ieventlistener/) 调用此方法，事件将在树中停止传播。事件将在当前 [`IEventTarget`](../../ieventtarget/) 上的所有监听器完成分发后才停止事件流。此方法可在事件流的任何阶段使用。
