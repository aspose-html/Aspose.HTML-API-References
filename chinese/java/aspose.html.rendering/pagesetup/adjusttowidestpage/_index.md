## PageSetup.AdjustToWidestPage property

获取或设置标志，以确定何时将页面大小调整为文档中最宽的页面。此选项耗时较长，可能使文档处理时间增加两倍。仅当文档中最宽的页面宽于在[`PageSetup`](../) 中确定的页面大小时才会进行调整。调整后的页面大小将用于文档中的所有页面。

```java
public bool AdjustToWidestPage { get; set; }
```
