## IDevice.Fill method

填充当前路径所围成的整个区域。如果路径由多个不相连的子路径组成，则会一起填充所有子路径的内部。此方法终止当前路径。

```java
public void Fill(FillRule rule)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| 规则 | FillRule | 填充规则指定封闭路径的内部如何被填充 |
