## Device&lt;TGraphicContext,TRenderingOptions&gt;.ClosePath method

通过从当前点到子路径起始点追加直线段来关闭当前子路径。如果当前子路径已关闭，\"ClosePath\" 不执行任何操作。此操作符会终止当前子路径。向当前路径追加另一个段会开始一个新子路径，即使该段起始于由 \"ClosePath\" 方法到达的端点。
