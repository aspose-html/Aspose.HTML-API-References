## SVGGeometryElement.GetPointAtLength method

返回用户空间中的 (x,y) 坐标，该坐标是沿路径的距离单位，使用用户代理的沿路径距离算法。

```java
public SVGPoint GetPointAtLength(float distance)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| 距离 | 单精度浮点数 | 相对于路径起点的路径距离，以当前用户坐标系中的距离表示。 |

### 返回值

返回的用户空间中的点。
