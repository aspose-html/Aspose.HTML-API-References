## SVGViewElement.ViewTarget property

对应给定 ‘view’ 元素上的属性 ‘viewTarget’。一个包含 ‘viewTarget’ 属性中列出的名称的 DOMString 值列表。每个 DOMString 值可通过调用 getElementById() 方法与相应的元素关联。

```java
public SVGStringList ViewTarget { get; }
```

### Property Value

给定 ‘view’ 元素的属性 ‘viewTarget’。
