## SVGSVGElement.GetCurrentTime method

返回相对于当前 SVG 文档片段开始时间的当前时间（秒）。如果在文档时间线开始之前调用 getCurrentTime（例如，在 ‘script’ 元素中的脚本在文档的 SVGLoad 事件分发之前运行），则返回 0。

```java
public float GetCurrentTime()
```

### 返回值

当前时间（单位为秒），如果文档时间线尚未开始则为 0。
