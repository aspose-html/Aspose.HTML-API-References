## SVGSVGElement.GetElementById method

在此 SVG 文档片段中（即搜索限制在文档树的子集内）搜索 id 为 elementId 的 Element。如果找到该 Element，则返回该 Element。如果不存在此类元素，则返回 null。如果多个元素具有相同 id，则行为未定义。

```java
public Element GetElementById(String elementId)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| elementId | String | 元素的唯一 id 值。 |

### 返回值

匹配的元素。
