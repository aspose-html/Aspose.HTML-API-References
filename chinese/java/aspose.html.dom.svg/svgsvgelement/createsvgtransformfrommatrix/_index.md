## SVGSVGElement.CreateSVGTransformFromMatrix method

在任何文档树之外创建 SVGTransform 对象。该对象初始化为给定的矩阵变换（即 SVG_TRANSFORM_MATRIX）。参数矩阵的数值被复制，矩阵参数并未被采用为 SVGTransform::matrix。

```java
public SVGTransform CreateSVGTransformFromMatrix(SVGMatrix matrix)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| 矩阵 | SVGMatrix | 变换矩阵。 |

### 返回值

一个 SVGTransform 对象。
