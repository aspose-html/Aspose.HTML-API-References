## SVGSVGElement.CurrentTranslate property

在最外层的 svg 元素上，它是考虑用户“放大”的相应平移因子。当在非最外层的 ‘svg’ 元素上访问时，该属性的行为未定义。

```java
public SVGPoint CurrentTranslate { get; }
```

### Property Value

当前平移。
