## SVGGraphicsElement.GetBBox method

返回当前用户空间中所有包含的图形元素的几何形状的紧密边界框（即在应用了 ‘transform’ 属性（如果有）之后），不包括描边、裁剪、遮罩和滤镜效果）。请注意，getBBox 必须在调用方法时返回实际的边界框，即使该元素尚未渲染。

```java
public SVGRect GetBBox()
```

### 返回值

一个定义边界框的 SVGRect 对象。
