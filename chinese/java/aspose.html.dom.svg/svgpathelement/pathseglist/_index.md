## SVGPathElement.PathSegList property

提供对 ‘d’ 属性基础（即静态）内容的访问，形式与 SVG 的语法一一对应。因此，如果 ‘d’ 属性具有 "absolute moveto (M)" 和 "absolute arcto (A)" 命令，则 pathSegList 将包含两个条目：SVG_PATHSEG_MOVETO_ABS 和 SVG_PATHSEG_ARC_ABS。

```java
public SVGPathSegList PathSegList { get; set; }
```

### Property Value

路径段列表。
