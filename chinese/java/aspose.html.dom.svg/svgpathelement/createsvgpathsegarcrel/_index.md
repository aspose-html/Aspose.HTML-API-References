## SVGPathElement.CreateSVGPathSegArcRel method

返回一个独立的、无父级的 SVGPathSegArcRel 对象。

```java
public SVGPathSegArcRel CreateSVGPathSegArcRel(float x, float y, float r1, float r2, float angle, 
    bool largeArcFlag, bool sweepFlag)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| x | 单精度浮点数 | 此路径段终点的相对 X 坐标。 |
| y | 单精度浮点数 | 此路径段终点的相对 Y 坐标。 |
| r1 | 单精度浮点数 | 椭圆的 x 轴半径（即 r1）。 |
| r2 | 单精度浮点数 | 椭圆的 y 轴半径（即 r2）。 |
| angle | 单精度浮点数 | 椭圆的 x 轴相对于用户坐标系 x 轴的旋转角度（单位为度）。 |
| largeArcFlag | Boolean | large-arc-flag 参数的值。 |
| sweepFlag | Boolean | large-arc-flag 参数的值。 |

### 返回值

一个独立的、没有父级的 SVGPathSegArcRel 对象。
