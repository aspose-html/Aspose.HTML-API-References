## SVGMarkerElement.OrientAngle property

对应于给定 ‘marker’ 元素上的 ‘orient’ 属性。如果 markerUnits 为 SVG_MARKER_ORIENT_ANGLE，则 ‘orient’ 属性的角度值；否则将被设为零。

```java
public SVGAnimatedAngle OrientAngle { get; }
```

### Property Value

给定 ‘marker’ 元素的 ‘orient’ 属性。
