## SVGTextContentElement.GetNumberOfChars method

返回当前元素中可用于渲染的字符总数，包括来自 ‘tref’ 引用的字符，无论它们是否会被渲染。实际上，这相当于 DOM Level 3 Core（[DOM3]，第 1.4 节）中 Node::textContent 属性的长度，如果该属性同样展开了 ‘tref’ 元素的话。

```java
public long GetNumberOfChars()
```

### 返回值

字符总数。
