## SVGTextContentElement.GetComputedTextLength method

此元素中渲染的所有字符的所有前进值的总和，包括字形（水平或垂直）的前进值、属性 ‘kerning’、‘letter-spacing’ 和 ‘word-spacing’ 的影响以及 ‘tspan’ 元素上属性 ‘dx’ 和 ‘dy’ 的调整。对于非渲染环境，用户代理应对字形度量做出合理假设。

```java
public float GetComputedTextLength()
```

### 返回值

文本的前进距离。
