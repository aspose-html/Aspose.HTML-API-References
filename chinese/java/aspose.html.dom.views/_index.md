**com.aspose.html.dom.views** package describes AbstractView and DocumentView interfaces according Document Object Model Views specification.

## 接口

| 接口 | 描述 |
| --- | --- |
| [IAbstractView](./iabstractview/) | 所有视图都应从此基础接口派生。 |
| [IDocumentView](./idocumentview/) | 该 DocumentView 接口由支持 DOM 视图的 DOM 实现中的 Document 对象实现。它提供了一个属性，用于检索文档的默认视图。 |
