## ITrueTypeFont.SubFamilyName property

字体子族名称用于区分在同一字体族名称下的字体组。它用于表示样式（斜体、倾斜）和粗细（细体、粗体、黑体等）。对于没有特定粗细或样式差异的字体（例如中等粗细、非斜体且 fsSelection 位 6 为 1），应在此位置存储字符串 “Regular”。

```java
public String SubFamilyName { get; }
```

### 返回值

字体的子族名称
