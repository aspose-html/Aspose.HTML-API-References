该 **com.aspose.html.drawing** 包包含用于指定测量和单位以及绘图属性对象（如画刷、颜色和字体）的对象和接口。

## 类

| 类 | 描述 |
| --- | --- |
| [Angle](./angle/) | 角度数据类型 |
| [Color](./color/) | Color 类允许您使用红绿蓝 (RGB) 值、色相-饱和度-亮度 (HSL) 值、色相-饱和度-数值 (HSV) 值、色相-白度-黑度 (HWB) 值、亮度-A-B (LAB) 值、亮度-色度-色相 (LCH) 值、青品红-黄-键 (CMYK) 值、自然颜色 (NCOL) 值，或使用颜色名称来指定颜色。Alpha 通道也可用于指示透明度。 |
| [Dimension](./dimension/) | 提供维度的基类。通用术语“dimension”指带有单位的数值，并通过 [`UnitType`](../com.aspose.html.drawing/unittype/) 表示。 |
| [Frequency](./frequency/) | “frequency” 单位。 |
| [Length](./length/) | 表示长度测量单位。 |
| [LengthOrAuto](./lengthorauto/) | 表示用于存储长度或 “auto” 单位的容器。 |
| [Margin](./margin/) | 表示页面边距。 |
| [Numeric](./numeric/) | 提供数值类型的基类。 |
| [Page](./page/) | 表示用于配置输出页面的页面对象。页面尺寸的默认值为 A4（210×297mm）。 |
| [Resolution](./resolution/) | 表示分辨率单位。 |
| [Size](./size/) | 存储指定高度和宽度的值。 |
| [Time](./time/) | 表示时间单位。 |
| [Unit](./unit/) | 提供计量单位的基类。 |
| [UnitType](./unittype/) | 指定计量单位。 |
