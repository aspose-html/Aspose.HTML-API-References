**com.aspose.html.rendering.image** 包提供特定的设备类以及负责渲染为光栅格式（jpeg、png、bmp、gif、tiff）的少量渲染选项类。

## 类

| 类 | 描述 |
| --- | --- |
| [ImageDevice](./imagedevice/) | 表示渲染为光栅格式：jpeg、png、bmp、gif、tiff。 |
| [ImageRenderingOptions](./imagerenderingoptions/) | 表示针对 [`ImageDevice`](../com.aspose.html.rendering.image/imagedevice/) 的渲染选项。此选项用于指定输出图像格式、压缩、分辨率等。 |
| [TextOptions](./textoptions/) | 表示针对 [`ImageDevice`](../com.aspose.html.rendering.image/imagedevice/) 的文本渲染选项。 |
## 枚举

| 枚举 | 描述 |
| --- | --- |
| [Compression](./compression/) | 指定 Tagged Image File Format（TIFF）位图图像的可能压缩方案。 |
| [ImageFormat](./imageformat/) | 指定图像的文件格式。 |
