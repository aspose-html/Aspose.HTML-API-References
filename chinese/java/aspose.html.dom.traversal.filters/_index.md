该包提供节点过滤功能。过滤器是能够“过滤”节点的对象。如果为节点迭代器或树遍历器提供了节点过滤器，它会在返回下一个节点之前应用该过滤器。如果过滤器接受该节点，遍历逻辑会返回它；否则，遍历会寻找下一个节点，并假装被拒绝的节点不存在。
