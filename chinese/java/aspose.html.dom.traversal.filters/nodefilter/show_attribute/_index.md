## NodeFilter.SHOW_ATTRIBUTE field

显示 Attr 节点。仅在使用属性节点作为根创建迭代器或树遍历器时才有意义；在这种情况下，这意味着属性节点将在迭代或遍历的第一个位置出现。由于属性永远不是其他节点的子节点，它们在遍历文档树时不会出现。

```java
public const long SHOW_ATTRIBUTE;
```
