**com.aspose.html.rendering.pdf.encryption** 包包含描述 PDF 加密细节（如密码、加密算法等）的数据类。

## 类

| 类 | 描述 |
| --- | --- |
| [PdfEncryptionInfo](./pdfencryptioninfo/) | 包含 PDF 加密的详细信息。 |
## 枚举

| 枚举 | 描述 |
| --- | --- |
| [PdfEncryptionAlgorithm](./pdfencryptionalgorithm/) | 加密模式枚举。描述使用的算法和密钥长度。此枚举被扩展以进一步增强功能。此枚举实现了\"Base-to-Core\"模式。 |
| [PdfPermissions](./pdfpermissions/) | 此枚举表示用户对 PDF 的权限。 |
