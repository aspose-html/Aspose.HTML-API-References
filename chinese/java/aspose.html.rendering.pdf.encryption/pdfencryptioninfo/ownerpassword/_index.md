## PdfEncryptionInfo.OwnerPassword property

获取或设置所有者密码。

```java
public String OwnerPassword { get; set; }
```

### Property Value

所有者密码。

## 备注

使用正确的所有者密码打开文档（假设它与用户密码不同）可获得对文档的完整（所有者）访问权限。此无限制的访问包括更改文档密码和访问权限的能力。
