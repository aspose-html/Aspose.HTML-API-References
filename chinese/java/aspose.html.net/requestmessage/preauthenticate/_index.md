## RequestMessage.PreAuthenticate property

获取或设置一个值，指示是否在请求中发送 Authorization 头部。

```java
public bool PreAuthenticate { get; set; }
```

### Property Value

`true` 表示在身份验证完成后随请求发送 HTTP Authorization 头部；否则为 `false`。默认值为 `false`。
