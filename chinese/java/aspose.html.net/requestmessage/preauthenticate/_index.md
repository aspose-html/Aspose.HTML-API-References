## RequestMessage.PreAuthenticate property

获取或设置指示是否在请求中发送 Authorization 头的值。

```java
public bool PreAuthenticate { get; set; }
```

### Property Value

`true` 表示在完成身份验证后随请求发送 HTTP Authorization 头；否则为 `false`。默认值为 `false`。
