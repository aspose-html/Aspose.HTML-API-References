## HTMLTableElement.Rows property

返回表格的 `TFOOT`，若不存在则返回 `null`。

返回表格中所有行的集合，包括 `THEAD`、`TFOOT` 中的行以及所有 `TBODY` 元素中的行。

```java
public HTMLCollection Rows { get; }
```
