## Configuration.Security property

获取或设置配置的沙箱标志。请参阅关于 [sandboxing](https://docs.aspose.com/html/net/working-with-documents/environment-configuration/#sandboxing) 的文章。

```java
public Sandbox Security { get; set; }
```

### Property Value

安全性。一个 [`sandboxing flag`](../../sandbox/) 集合是零个或多个标志的集合，用于限制潜在不受信任资源的能力。sandbox 属性允许您对加载到框架中的内容设置多项限制，例如，阻止表单和脚本。
