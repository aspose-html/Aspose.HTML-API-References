## HTMLInputElement.DefaultChecked property

当 `type` 的值为 "radio" 或 "checkbox" 时，此属性表示元素的 HTML checked 属性。如果交互式用户代理中相应表单控件的状态发生变化，此属性的值不会改变。请参阅 HTML 4.01 中的 checked 属性定义。

```java
public bool DefaultChecked { get; set; }
```
