## HTMLInputElement.DefaultValue property

当元素的 `type` 属性值为 "text"、"file" 或 "password" 时，这代表元素的 HTML value 属性。如果在交互式用户代理中相应的表单控件内容改变，此属性的值不会改变。参见 HTML 4.01 中的 value 属性定义。

```java
public String DefaultValue { get; set; }
```
