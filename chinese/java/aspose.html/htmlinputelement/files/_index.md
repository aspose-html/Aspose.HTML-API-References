## HTMLInputElement.Files property

files IDL 属性允许脚本访问元素的选中文件。获取时，如果 IDL 属性适用，则必须返回表示当前选中文件的 FileList 对象。该对象应保持不变，直至选中文件列表发生变化。如果 IDL 属性不适用，则必须返回 null。[FILEAPI]

public IFileList Files { get; }
