## HTMLInputElement.Value property

当元素的 `type` 属性值为 "text"、"file" 或 "password" 时，表示相应表单控件在交互式用户代理中的当前内容。更改此属性会更改表单控件的内容，但不会更改元素的 HTML value 属性的值。当元素的 `type` 属性值为 "button"、"hidden"、"submit"、"reset"、"image"、"checkbox" 或 "radio" 时，表示元素的 HTML value 属性。请参阅 HTML 4.01 中的 value 属性定义。

```java
public String Value { get; set; }
```
