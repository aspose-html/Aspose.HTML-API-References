## HTMLDocument.Images property

文档中所有 `IMG` 元素的集合。出于向后兼容性，行为仅限于 `IMG` 元素。正如 [[HTML 4.01](http://www.w3.org/TR/1999/REC-html401-19991224)] 所建议的，为了包含图像，作者可以使用 `OBJECT` 元素或 `IMG` 元素。因此建议不要使用此属性来查找文档中的图像，而是使用 HTML 4.01 的 `getElementsByTagName` 或 XHTML 1.0 的 `getElementsByTagNameNS`。

```java
public HTMLCollection Images { get; }
```
