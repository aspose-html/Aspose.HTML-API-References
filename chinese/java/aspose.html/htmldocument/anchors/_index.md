## HTMLDocument.Anchors property

文档中所有具有 `name` 属性值的锚点 (`A`) 元素的集合。出于向后兼容性的原因，返回的锚点集合仅包含使用 `name` 属性创建的锚点，而不包括使用 `id` 属性创建的锚点。请注意，在 [[XHTML 1.0](http://www.w3.org/TR/2002/REC-xhtml1-20020801)] 中，`name` 属性（参见第 4.10 节）没有语义，仅为旧版用户代理保留，实际使用 `id` 属性。用户应优先使用 [[DOM Level 2 Traversal](http://www.w3.org/TR/2000/REC-DOM-Level-2-Traversal-Range-20001113)] 提供的迭代器机制。

```java
public HTMLCollection Anchors { get; }
```
