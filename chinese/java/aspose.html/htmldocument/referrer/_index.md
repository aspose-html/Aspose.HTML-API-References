## HTMLDocument.Referrer property

返回链接到此页面的页面的 URI [[IETF RFC 2396](http://www.ietf.org/rfc/rfc2396.txt)]。如果用户直接导航到该页面（未通过链接，例如通过书签），则该值为空字符串。

```java
public String Referrer { get; }
```
