Aspose.Html 包含用于操作[`HTML 文档`](aspose.html/htmldocument/)的类和方法，无论是简单还是复杂，且可即时完成。Aspose.HTML for Java 允许开发者插入、删除、替换 HTML 节点，提取 CSS 样式信息，通过[`HTML 文档`](aspose.html/htmldocument/)进行导航，可使用由遍历规范提供的[`NodeIterator`](aspose.html.dom.traversal/inodeiterator/)、[`TreeWalker`](aspose.html.dom.traversal/itreewalker/)，或 XPath、CSS 选择器查询。它还提供脚本功能，允许通过 JavaScript 操作 HTML DOM。除了 HTML 外，此 API 还具备加载 EPUB 和 MHTML 的能力。Aspose API 以其跨文件格式转换功能著称，此 API 也提供加载 HTML 文件并将输出渲染为 PDF、XPS 以及包括 JPEG、PNG、BMP 和 TIFF 在内的光栅图像格式的能力。
