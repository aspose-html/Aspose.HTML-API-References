## IUrlSearchParams.Set method

将找到的第一个名称为指定名称的键值对的值设为指定值，并删除其他键值对。如果未找到具有指定名称的键值对，则会在列表中追加一个新的键值对。

```java
public void Set(String name, String value)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| name | String | 用于查找名称-值对的键。 |
| 值 | String | 将被设置的值。 |
