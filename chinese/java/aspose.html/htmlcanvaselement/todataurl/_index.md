## ToDataURL(String, double) {#todataurl_2}

返回一个数据 URI，包含按 type 参数指定的格式（默认 PNG）的图像表示。返回的图像分辨率为 96 dpi。

```java
public String ToDataURL(String type, double encoderOptions)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| 类型 | String | 一个指示图像格式的字符串。默认的格式类型是 image/png。 |
| encoderOptions | Double | 一个介于 0 到 1 之间的数字，指示图像质量（当请求的类型为 image/jpeg 或 image/webp 时）。 |

### 返回值

一个包含请求的数据 URI 的 DOMString。
