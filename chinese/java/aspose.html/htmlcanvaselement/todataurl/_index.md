```java
public String ToDataURL()
```

一个包含请求的 data URI 的 DOMString。

## ToDataURL(String, double) {#todataurl_2}

返回一个数据 URI，其中包含按 type 参数指定的格式（默认为 PNG）的图像表示。返回的图像分辨率为 96 dpi。

```java
public String ToDataURL(String type, double encoderOptions)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| type | String | 一个字符串，指示图像格式。默认的格式类型是 image/png。 |
| encoderOptions | Double | 一个介于 0 和 1 之间的数字，指示图像质量（当请求的类型为 image/jpeg 或 image/webp 时）。 |

一个包含请求的 data URI 的 DOMString。
