## HTMLCanvasElement.GetContext method

返回 canvas 上的绘图上下文，如果不支持该上下文 ID，则返回 null。绘图上下文允许您在 canvas 上绘制。

```java
public object GetContext(String contextId)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| contextId | String | 是一个字符串，包含定义与画布关联的绘图上下文的上下文标识符。 |

### 返回值

一个 RenderingContext
