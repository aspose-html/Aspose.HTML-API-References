## HTMLTextAreaElement.Value property

表示对应表单控件在交互式用户代理中的当前内容。更改此属性会更改表单控件的内容，但不会更改元素的内容。如果全部数据无法容纳在单个 `DOMString` 中，实现可能会截断数据。

```java
public String Value { get; set; }
```
