## HTMLTableRowElement.RowIndex property

这是按逻辑顺序而非文档顺序。`rowIndex` 会考虑表格中的 (`THEAD`、`TFOOT` 或 `TBODY`) 部分，将 `THEAD` 行首先放入索引，其次是 `TBODY` 行，最后是 `TFOOT` 行。@version DOM Level 2

public int RowIndex { get; }
