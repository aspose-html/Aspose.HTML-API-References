## HTMLFormElement.Enctype property

提交表单的内容类型，通常为 "application/x-www-form-urlencoded"。请参阅 HTML 4.01 中的 enctype 属性定义。调用此方法时，onsubmit 事件处理程序不一定会被触发。由于历史原因行为不一致，作者不应依赖特定的实现。

```java
public String Enctype { get; set; }
```
