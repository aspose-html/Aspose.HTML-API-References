## IXPathNamespace.OwnerElement property

请求时包所在范围的 [`Element`](../../../com.aspose.html.dom/element/)。即使文档更改导致该元素上的包超出范围并且此节点不再通过 XPath 在该处找到，此返回的包节点也不会改变。

```java
public Element OwnerElement { get; }
```
