## IXPathNamespace.OwnerElement property

当请求时，包所在范围内的 [`Element`](../../../com.aspose.html.dom/element/)。即使文档更改导致该元素的范围失效且该节点不再通过 XPath 在该元素中找到，此返回的包节点也不会改变。

```java
public Element OwnerElement { get; }
```
