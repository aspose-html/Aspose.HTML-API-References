## 命名空间

| 命名空间 | 描述 |

| [com.aspose.html](./aspose.html/) | Aspose.Html 包包含用于操作[`HTML documents`](aspose.html/htmldocument/)的类和方法，无论是简单还是复杂，且可即时完成。Aspose.HTML for Java 允许开发者 Insert、Remove、Replace HTML 节点，提取 CSS 样式信息，使用 [`HTML document`](aspose.html/htmldocument/) 通过 [`NodeIterator`](aspose.html.dom.traversal/inodeiterator/)、[`TreeWalker`](aspose.html.dom.traversal/itreewalker/)（由遍历规范提供），或 XPath、CSS 选择器查询进行导航。它还提供脚本功能，允许通过 JavaScript 操作 HTML DOM。除了 HTML 外，此 API 还具备加载 EPUB 和 MHTML 的能力。Aspose API 以其跨文件格式转换功能著称，此 API 同样能够加载 HTML 文件并将输出渲染为 PDF、XPS 以及包括 JPEG、PNG、BMP 和 TIFF 在内的光栅图像格式。 |
