## NamedNodeMap.SetNamedItemNS method

使用其 packageURI 和 localName 添加节点。如果映射中已存在具有相同包 URI 和本地名称的节点，则被新节点替换。用自身替换节点不会产生任何影响。

```java
public Attr SetNamedItemNS(Attr attr)
```
