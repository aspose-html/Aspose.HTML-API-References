## Toggle(String, bool) {#toggle_1}

如果标记已存在于列表中则将其移除，否则将其添加到列表中。

```java
public bool Toggle(String token, bool force)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| 标记 | String | 您想要切换的标记。 |
| force | Boolean | 一个布尔值（如果提供），将切换操作转换为单向操作。设为 false 时，仅移除标记而不添加；设为 true 时，仅添加标记而不移除。 |

### 返回值

一个布尔值，指示调用后标记是否在列表中。
