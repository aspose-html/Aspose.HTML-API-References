## ICSSStyleSheet.CSSRules property

只读的 CSSStyleSheet 属性 cssRules 返回一个实时的 [`CSSRuleList`](../../icssrulelist/)，提供包含样式表中每个 CSS 规则的实时、最新列表。列表中的每个项都是一个定义单个规则的 [`CSSRule`](../../icssrule/)。

```java
public ICSSRuleList CSSRules { get; }
```

### Property Value

一个实时更新的 [`CSSRuleList`](../../icssrulelist/)，包含构成样式表的每个 CSS 规则。规则列表中的每个条目都是一个描述构成样式表的单个规则的 [`CSSRule`](../../icssrule/) 对象。

## 备注

[CSSOM](https://drafts.csswg.org/cssom/) defines APIs (including generic parsing and serialization rules) for Media Queries, Selectors, and of course CSS itself.
