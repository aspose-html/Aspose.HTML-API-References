## ICSSStyleSheet.OwnerRule property

只读的 CSSStyleSheet 属性 ownerRule 返回对应于将样式表导入文档的 @import 规则的 [`CSSImportRule`](../../icssimportrule/)。如果样式表未通过 @import 导入到文档中，返回值为 null。

```java
public ICSSRule OwnerRule { get; }
```

### Property Value

对应于将样式表导入文档的 @import 规则的 CSSImportRule。如果样式表未通过 @import 导入到文档中，返回值为 null。
