## ICSSRule.CSSText property

[`CSSRule`](../) 接口的 cssText 属性返回 [`CSSStyleSheet`](../../icssstylesheet/) 样式规则的实际文本。

注意：不要将此属性与元素样式 CSSStyleDeclaration.cssText 混淆。

```java
public String CSSText { get; set; }
```

### Property Value

返回 CSS 规则的序列化字符串。设置 cssText 属性时必须不执行任何操作。
