## ICSSRule.Type property

规则的类型，按照 [CSSOM # dom-cssrule-type](https://drafts.csswg.org/cssom/#dom-cssrule-type) 定义。期望可以使用特定绑定的强制转换方法，将 CSSRule 接口的实例向下转换为该类型所暗示的具体派生接口。

```java
public short Type { get; }
```

### Property Value

与特定规则类型关联的非负整数。该值在创建规则时初始化，之后不可更改。
