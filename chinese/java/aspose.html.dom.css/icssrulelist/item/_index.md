## ICSSRuleList indexer

用于通过 item() 方法检索 CSS 规则 (http://www.w3.org/TR/DOM-Level-2-Style/css.html#CSS-CSSRuleList)。此集合中的顺序对应 CSS 样式表中规则的顺序。如果索引大于或等于列表中的规则数量，则返回 null。

```java
public ICSSRule this[int index] { get; }
```

### 返回值

item(index) 方法必须返回集合中第 index 个 CSSRule 对象。如果集合中不存在第 index 个对象，则该方法必须返回 null。

### Property Value

CSS 规则集合中的索引。
