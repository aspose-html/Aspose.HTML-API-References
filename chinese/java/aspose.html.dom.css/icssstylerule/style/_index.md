## ICSSStyleRule.Style property

只读的 style 属性是用于 [`CSSStyleRule`](../) 声明块的 [`CSSStyleDeclaration`](../../icssstyledeclaration/) 接口。

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

style 属性必须返回一个 CSSStyleDeclaration 对象用于样式规则，并具有以下属性：

computed flag - Unset.声明 - 规则中声明的声明，按指定顺序。parent CSS rule - 上下文对象。owner node - Null。
