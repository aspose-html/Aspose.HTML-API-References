## ICSSStyleRule.Style property

只读的 style 属性是 [`CSSStyleDeclaration`](../../icssstyledeclaration/) 接口，用于 [`CSSStyleRule`](../) 的声明块。

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

style 属性必须返回一个 CSSStyleDeclaration 对象用于样式规则，具有以下属性：

computed 标志 - Unset.declarations - 规则中声明的声明，按指定顺序。parent CSS rule - 上下文对象。owner node - Null。
