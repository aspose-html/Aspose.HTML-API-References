## IElementCSSInlineStyle.Style property

style 属性必须返回一个 CSS 声明块对象，该对象的 computed 标志未设置，父 CSS 规则为 null，且所有者节点是上下文对象。

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

节点关联的 CSS 声明块，若不存在关联的 CSS 声明块则为 null。
