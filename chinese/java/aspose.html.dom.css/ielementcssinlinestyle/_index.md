## IElementCSSInlineStyle interface

内联样式信息附加到元素上，通过 style 属性公开。这表示 HTML 元素的 STYLE 属性内容（或其他模式或 DTD 中以相同方式使用 STYLE 属性的元素）。预期当元素支持内联 CSS 样式信息时，可以通过在 Element 接口的实例上使用特定绑定的强制转换方法来获取 ElementCSSInlineStyle 接口的实例。
