## Rect class

Rect 接口用于表示任何 rect 值。该接口反映底层 style 属性中的值。因此，对 [`CSSPrimitiveValue`](../cssprimitivevalue/) 对象所做的修改会修改 style 属性。

public class Rect : DOMObject
