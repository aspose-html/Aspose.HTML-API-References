## CSSValue.CSSText property

[`CSSValue`](../) 接口的 cssText 属性表示当前计算的 CSS 属性值。

注意：此属性曾是创建类型化 CSS 对象模型的尝试的一部分。该尝试已被放弃，大多数浏览器并未实现它。

```java
public abstract String CSSText { get; set; }
```

### Property Value

表示当前 CSS 属性值的 DOMString。
