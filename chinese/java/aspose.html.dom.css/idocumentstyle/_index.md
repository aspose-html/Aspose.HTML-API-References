## IDocumentStyle interface

DocumentStyle 接口提供一种机制，可检索嵌入文档中的样式表。预期可以通过在 Document 接口的实例上使用特定绑定的强制转换方法来获取 DocumentStyle 接口的实例。

另请参阅 [Document Object Model (DOM) Level 2 Style Specification](http://www.w3.org/TR/2000/REC-DOM-Level-2-Style-20001113)。

```java
public interface IDocumentStyle
```

## 属性

| 名称 | 描述 |
| --- | --- |
| [getStyleSheets](../../com.aspose.html.dom.css/idocumentstyle/stylesheets/) 包含文档中所有显式链接或嵌入的样式表的列表。对于 HTML 文档，这包括通过 HTML LINK 元素包含的外部样式表以及内联 STYLE 元素。 |
