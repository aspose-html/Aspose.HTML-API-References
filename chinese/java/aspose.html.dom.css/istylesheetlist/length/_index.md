## IStyleSheetList.Length property

length 属性必须返回集合中表示的 CSS 样式表数量。有效子样式表索引的范围为 0 到 length-1（含）。

```java
public int Length { get; }
```

### Property Value

一个整数，指示集合中的项目数量。
