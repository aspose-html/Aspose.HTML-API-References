## RGBColor.Blue property

获取此 Color 结构的蓝色分量值。

```java
public CSSPrimitiveValue Blue { get; }
```

### Property Value

此 Color 的蓝色分量值。

## 备注

每个像素的颜色表示为 32 位数字：每个通道 8 位，分别为 alpha、red、green 和 blue（ARGB）。alpha 通道指定颜色的透明度：0 表示完全透明，255 表示完全不透明。同样，alpha 值为 255 表示不透明颜色，alpha 值在 1 到 254 之间表示半透明颜色。随着 alpha 接近 255，颜色变得更不透明。
