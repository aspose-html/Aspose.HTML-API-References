## ICSS2Properties.MaxWidth property

这两个属性允许作者将盒子宽度限制在一定范围内。值具有以下含义：

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - 指定固定的最小或最大计算宽度。'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - 指定用于确定计算值的百分比。该百分比是相对于生成盒子的 [containing block](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#containing-block) 的宽度计算的。none - （仅适用于['max-width'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-max-width)）盒子的宽度没有限制。

```java
public String MaxWidth { get; set; }
```

### 返回值

max-width 属性
