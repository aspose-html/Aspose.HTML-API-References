## ICSS2Properties.Size property

此属性指定页面盒子的大小和方向。

页面盒子的大小可以是 "absolute"（固定尺寸）或 "relative"（可伸缩的，即适配可用纸张尺寸）。相对页面盒子允许用户代理缩放文档并充分利用目标尺寸。

['size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-size) 属性的三个值会创建相对页面盒子：

auto - 页面盒子将设置为目标纸张的大小和方向。landscape - 覆盖目标的方向。页面盒子与目标大小相同，较长的一侧为水平。portrait - 覆盖目标的方向。页面盒子与目标大小相同，较短的一侧为水平。

public String Size { get; set; }
