## ICSS2Properties.Border property

‘border’ 属性是一个简写属性，用于为盒子的四条边设置相同的宽度、颜色和样式。与简写的 ‘margin’ 和 ‘padding’ 属性不同，‘border’ 属性不能为四条边设置不同的值。若要实现此目的，需要使用一个或多个其他 border 属性。

```java
public String Border { get; set; }
```

### 返回值

border 属性
