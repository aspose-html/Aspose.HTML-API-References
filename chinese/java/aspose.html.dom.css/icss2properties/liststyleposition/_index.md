## ICSS2Properties.ListStylePosition property

此属性指定标记框在主块盒中的位置。取值含义如下：

outside - 标记框位于主块盒之外。注意：CSS1 未明确标记框的精确位置，出于兼容性考虑，CSS2 仍然同样模糊。若需更精确地控制标记框，请使用 markers。inside - 标记框是主块盒中的第一个内联盒，随后元素内容在其后流动。

```java
public String ListStylePosition { get; set; }
```

### 返回值

list-style-position 属性
