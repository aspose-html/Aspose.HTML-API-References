## ICSS2Properties.TextAlign property

此属性描述块的内联内容如何对齐。取值含义如下：

left、right、center 和 justify - 分别表示左对齐、右对齐、居中对齐和两端对齐文本。'[String](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-String)' - 指定一个字符串，用于对齐表格列中的单元格（详见 [horizontal alignment in a column](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#column-alignment) 部分及示例）。此取值仅适用于 [table](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html) 单元格。如果在其他元素上设置，则会根据 ['direction'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-direction) 是 'ltr' 还是 'rtl'，分别视为 'left' 或 'right'。

```java
public String TextAlign { get; set; }
```
