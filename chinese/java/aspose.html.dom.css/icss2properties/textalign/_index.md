## ICSS2Properties.TextAlign property

此属性描述块的内联内容如何对齐。取值含义如下：

left, right, center, and justify - 左、右、居中和两端对齐文本，分别对应 left、right、center 和 justify。'[String](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-String)' - 指定一个字符串，用于对齐表格列中的单元格（详见关于 [horizontal alignment in a column](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#column-alignment) 的章节以及示例）。此取值仅适用于 [table](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html) 单元格。如果在其他元素上设置，它将被视为 'left' 或 'right'，取决于 ['direction'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-direction) 是 'ltr' 还是 'rtl'。

```java
public String TextAlign { get; set; }
```
