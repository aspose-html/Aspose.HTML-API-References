## ICSS2Properties.BorderRightWidth property

此属性是一个简写属性，用于在样式表的同一位置设置 'border-top-width'、'border-right-width'、'border-bottom-width' 和 'border-left-width'。

如果只有一个值，则它适用于所有边。如果有两个值，则上边框和下边框使用第一个值，右边框和左边框使用第二个值。如果有三个值，则上边框使用第一个值，左边框和右边框使用第二个值，下边框使用第三个值。如果有四个值，则它们分别适用于上、右、下、左。

```java
public String BorderRightWidth { get; set; }
```

### 返回值

border-right-width 属性
