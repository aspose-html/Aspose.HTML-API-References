## ICSS2Properties.BorderRightWidth property

此属性是一个简写属性，用于在样式表中一次性设置 'border-top-width'、'border-right-width'、'border-bottom-width' 和 'border-left-width'。

如果只有一个值，则它适用于所有边。若有两个值，顶部和底部边框使用第一个值，右侧和左侧使用第二个值。若有三个值，顶部使用第一个值，左侧和右侧使用第二个值，底部使用第三个值。若有四个值，则分别对应顶部、右侧、底部和左侧。

```java
public String BorderRightWidth { get; set; }
```

### 返回值

border-right-width 属性
