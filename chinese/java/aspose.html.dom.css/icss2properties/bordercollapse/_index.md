## ICSS2Properties.BorderCollapse property

此属性选择表格的边框模型。值 'separate' 选择分离边框模型。值 'collapse' 选择合并边框模型。模型描述如下。

```java
public String BorderCollapse { get; set; }
```

### 返回值

border-collapse 属性
