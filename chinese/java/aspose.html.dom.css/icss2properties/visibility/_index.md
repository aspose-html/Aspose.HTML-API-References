## ICSS2Properties.Visibility property

['visibility'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visufx.html#propdef-visibility) 属性指定元素生成的盒子是否渲染。不可见的盒子仍会影响布局（将 ['display'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-display) 属性设为 'none' 可完全抑制盒子生成）。值具有以下含义：

visible - 生成的盒子可见。hidden - 生成的盒子不可见（完全透明），但仍会影响布局。collapse - 请参阅表格中关于 [dynamic row and column effects](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#dynamic-effects) 的章节。如果在行或列之外的元素上使用，‘collapse’ 与 ‘hidden’ 含义相同。

```java
public String Visibility { get; set; }
```

visibility 属性
