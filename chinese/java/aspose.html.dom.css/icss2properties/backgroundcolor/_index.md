## ICSS2Properties.BackgroundColor property

此属性将元素的背景颜色设置为一个值或关键字 'transparent'，以使底层颜色透显。

```java
public String BackgroundColor { get; set; }
```

### 返回值

background-color 属性

### Property Value

颜色可以是关键字或数值 RGB 规范。
