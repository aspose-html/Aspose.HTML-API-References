## ICSS2Properties.BackgroundColor property

此属性设置元素的背景颜色，可以是具体值或关键字 “transparent”，以使底层颜色透显。

```java
public String BackgroundColor { get; set; }
```

### 返回值

background-color 属性

### Property Value

颜色要么是关键字，要么是数值 RGB 规范。
