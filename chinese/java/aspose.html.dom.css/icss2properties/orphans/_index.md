## ICSS2Properties.Orphans property

['orphans'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-orphans)属性指定段落在页面底部必须保留的最少行数。['widows'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-widows)属性指定段落在页面顶部必须保留的最少行数。下面给出了它们用于控制分页的示例。

```java
public String Orphans { get; set; }
```
