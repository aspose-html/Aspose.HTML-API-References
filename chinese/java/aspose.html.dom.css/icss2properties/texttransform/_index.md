## ICSS2Properties.TextTransform property

此属性控制元素文本的大小写效果。取值含义如下：

capitalize - 将每个单词的首字符转为大写。uppercase - 将每个单词的所有字符转为大写。lowercase - 将每个单词的所有字符转为小写。none - 不进行大小写转换。

```java
public String TextTransform { get; set; }
```

text-transform 属性
