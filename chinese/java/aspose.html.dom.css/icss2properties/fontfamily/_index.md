## ICSS2Properties.FontFamily property

此属性指定字体族名称和/或通用族名称的优先列表。为了解决单个字体可能不包含显示文档中所有字符的字形，或并非所有系统都提供所有字体的问题，此属性允许作者指定一系列具有相同样式和大小的字体，按顺序尝试以查看是否包含某个字符的字形。此列表称为字体集。

```java
public String FontFamily { get; set; }
```

font-family 属性
