## ICSS2Properties.CaptionSide property

此属性指定标题框相对于表格框的位置。取值含义如下：

top - 将标题框置于表格框上方。bottom - 将标题框置于表格框下方。left - 将标题框置于表格框左侧。right - 将标题框置于表格框右侧。

```java
public String CaptionSide { get; set; }
```

caption-side 属性
