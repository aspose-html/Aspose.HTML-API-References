## ICSS2Properties.CaptionSide property

此属性指定标题框相对于表格盒子的位置。取值含义如下：

top - 将标题框定位在表格盒子上方。bottom - 将标题框定位在表格盒子下方。left - 将标题框定位在表格盒子左侧。right - 将标题框定位在表格盒子右侧。

```java
public String CaptionSide { get; set; }
```
