## ICSS2Properties.BackgroundAttachment property

如果指定了背景图像，此属性指定它是相对于视口固定（'fixed'）还是随文档滚动（'scroll'）。

即使图像是固定的，也只有在元素的背景或内边距区域时才可见。因此，除非图像被平铺（'background-repeat: repeat'），否则可能不可见。

```java
public String BackgroundAttachment { get; set; }
```

### 返回值

background-attachment 属性
