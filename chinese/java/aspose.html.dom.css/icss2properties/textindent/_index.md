## ICSS2Properties.TextIndent property

此属性指定块中首行文本的缩进。更确切地说，它指定流入块的首个[line box](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#line-box)的第一个盒子的缩进。该盒子相对于行盒子的左边缘（或在从右到左布局时的右边缘）进行缩进。用户代理应将此缩进渲染为空白空间。

取值具有以下含义：

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - 缩进是固定长度。'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - 缩进是包含块宽度的百分比。

```java
public String TextIndent { get; set; }
```
