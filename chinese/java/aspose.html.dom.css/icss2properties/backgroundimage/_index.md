## ICSS2Properties.BackgroundImage property

此属性设置元素的背景图像。设置背景图像时，作者应同时指定在图像不可用时使用的背景颜色。图像可用时，它会渲染在背景颜色之上。（因此，颜色在图像的透明部分可见。）

```java
public String BackgroundImage { get; set; }
```

### 返回值

background-image 属性

### Property Value

此属性的取值要么是 , 用于指定图像，要么是 'none'，表示不使用图像。
