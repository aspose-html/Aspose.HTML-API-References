## ICSS2Properties.Pause property

['pause'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause) 属性是设置 ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) 和 ['pause-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-after) 的简写。如果提供两个值，第一个值是 ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before)，第二个值是 ['pause-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-after)。如果只提供一个值，则同时应用于两个属性。

```java
public String Pause { get; set; }
```

### 返回值

pause 属性
