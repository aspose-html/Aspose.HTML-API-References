## ICSS2Properties.Font property

‘font’ 属性除以下所述外，是一种简写属性，用于在样式表的同一位置设置 ‘font-style’、‘font-variant’、‘font-weight’、‘font-size’、‘line-height’ 和 ‘font-family’。此属性的语法基于传统的排版简写表示法，用于设置多个与字体相关的属性。

```java
public String Font { get; set; }
```

font 属性
