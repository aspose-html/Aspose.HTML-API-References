## ICSS2Properties.BorderSpacing property

长度指定相邻单元格边框之间的距离。如果只指定一个长度，则同时作为水平和垂直间距。如果指定两个长度，第一个表示水平间距，第二个表示垂直间距。长度不得为负值。

```java
public String BorderSpacing { get; set; }
```

border-spacing 属性
