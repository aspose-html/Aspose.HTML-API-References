## ICSS2Properties.Direction property

此属性指定块的基础书写方向以及嵌入和覆盖的方向（参见 ['unicode-bidi'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-unicode-bidi)）以用于 Unicode 双向算法。此外，它还指定 [table](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html) 列布局的方向、水平 [overflow](https://www.w3.org/TR/1998/REC-CSS2-19980512/visufx.html#overflow) 的方向，以及在 'text-align: justify' 情况下块中不完整的最后一行的位置。

```java
public String Direction { get; set; }
```

### 返回值

direction 属性
