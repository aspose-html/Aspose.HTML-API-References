## ICSS2Properties.PitchRange property

指定平均音高的变化。人声的感知音高由基频决定，男性声音通常约为 120Hz，女性声音约为 210Hz。人类语言的发音具有不同的语调和音高，这些变化传递额外的意义和强调。因此，语调丰富的声音（即高度变化的声音）表现出较大的音高范围。此属性指定这些变化发生的范围，即基频相对于平均音高的偏离程度。

```java
public String PitchRange { get; set; }
```
