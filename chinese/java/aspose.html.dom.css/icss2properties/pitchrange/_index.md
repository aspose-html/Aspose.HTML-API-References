## ICSS2Properties.PitchRange property

指定平均音高的变化。人声的感知音高由基频决定，男性声音通常约为120Hz，女性声音约为210Hz。人类语言的语调和音高会变化；这些变化传达额外的意义和强调。因此，语调丰富的声音，即高度起伏的声音，显示出较大的音高范围。此属性指定这些变化发生的范围，即基频相对于平均音高的偏差幅度。

```java
public String PitchRange { get; set; }
```
