## ICSS2Properties.CounterIncrement property

['counter-increment'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-counter-increment) 属性接受一个或多个计数器（标识符）的名称，每个名称后可选跟随一个整数。该整数表示每次出现该元素时计数器递增的量。默认递增值为 1。允许使用零和负整数。

```java
public String CounterIncrement { get; set; }
```
