## ICSS2Properties.FontVariant property

在 small-caps 字体中，小写字母的字形看起来类似于大写字母，但尺寸更小且比例略有不同。'font-variant' 属性请求此类双大小写（具有两个字形，如拉丁文字）的字体。对于单一大小写（仅有一种字形，如大多数世界书写系统）的文字，此属性没有可见效果。

```java
public String FontVariant { get; set; }
```

### 返回值

font-variant 属性
