## ICSS2Properties.FontVariant property

在小型大写字母（small-caps）字体中，小写字母的字形看起来类似于大写字母，但尺寸更小且比例略有不同。'font-variant' 属性请求这种双大小写（bicameral）的字体（如拉丁文字）。对于单一大小写（unicameral）的文字系统（如世界上大多数书写系统），此属性没有可见效果。

```java
public String FontVariant { get; set; }
```

### 返回值

font-variant 属性
