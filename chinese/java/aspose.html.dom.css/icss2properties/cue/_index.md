## ICSS2Properties.Cue property

['cue'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue) 属性是设置 ['cue-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-before) 和 ['cue-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-after) 的简写。如果提供两个值，第一个值是 ['cue-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-before)，第二个值是 ['cue-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-after)。如果只提供一个值，则同时应用于两个属性。

```java
public String Cue { get; set; }
```

cue 属性
