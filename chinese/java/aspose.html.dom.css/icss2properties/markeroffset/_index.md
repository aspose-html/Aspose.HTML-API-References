## ICSS2Properties.MarkerOffset property

此属性指定标记框最近的 [border edges](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#border-edge) 与其关联的 [principal box](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#principal-box) 之间的距离。偏移量可以是用户指定的（[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)）或由 UA 选择（'auto'）。长度可以为负，但可能存在实现特定的限制。

```java
public String MarkerOffset { get; set; }
```

marker-offset 属性
