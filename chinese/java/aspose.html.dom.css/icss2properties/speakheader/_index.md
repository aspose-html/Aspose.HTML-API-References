## ICSS2Properties.SpeakHeader property

此属性指定是对每个单元格在其前朗读表头，还是仅在该单元格与前一个单元格的表头不同的情况下朗读表头。取值含义如下：

once - 表头朗读一次，在一系列单元格之前。always - 表头在每个相关单元格之前朗读。

```java
public String SpeakHeader { get; set; }
```

speak-header 属性
