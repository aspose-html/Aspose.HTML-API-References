## ICSS2Properties.Height property

此属性指定由块级和[替换](https://www.w3.org/TR/1998/REC-CSS2-19980512/conform.html#replaced-element)元素生成的盒子的[内容高度](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#content-height)。

此属性不适用于非替换的[行内级别](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level)元素。非替换行内元素的盒子的高度由元素的（可能继承的）['行高'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-line-height)值决定。

```java
public String Height { get; set; }
```
