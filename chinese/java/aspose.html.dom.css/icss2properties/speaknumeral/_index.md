## ICSS2Properties.SpeakNumeral property

此属性控制数字的朗读方式。值具有以下含义：

digits - 将数字逐位朗读。例如，"237"朗读为 "Two Three Seven"。continuous - 将数字整体朗读。例如，"237"朗读为 "Two hundred thirty seven"。单词表示取决于语言。

```java
public String SpeakNumeral { get; set; }
```
