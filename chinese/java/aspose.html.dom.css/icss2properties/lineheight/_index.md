## ICSS2Properties.LineHeight property

如果该属性设置在一个 [block-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#block-level) 元素，其内容由 [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) 元素组成，则它指定每个生成的 inline 框的最小高度。

如果该属性设置在一个 [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) 元素上，它指定该元素生成的每个盒子的精确高度。（对于 inline [replaced](https://www.w3.org/TR/1998/REC-CSS2-19980512/conform.html#replaced-element) 元素，盒子的高度由 ['height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-height) 属性决定。）

```java
public String LineHeight { get; set; }
```

### 返回值

line-height 属性
