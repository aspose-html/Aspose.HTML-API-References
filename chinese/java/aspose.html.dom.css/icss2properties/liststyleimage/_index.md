## ICSS2Properties.ListStyleImage property

此属性设置将用作列表项标记的图像。当图像可用时，它将替换使用 ['list-style-type'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-list-style-type) 标记的默认标记。

```java
public String ListStyleImage { get; set; }
```

### 返回值

list-style-image 属性
