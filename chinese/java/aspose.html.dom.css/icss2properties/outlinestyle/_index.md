## ICSS2Properties.OutlineStyle property

使用 outline 属性创建的轮廓绘制在“盒子之上”，即轮廓始终位于顶部，并且不影响盒子或其他任何盒子的定位或尺寸。因此，显示或隐藏轮廓不会导致重排。

```java
public String OutlineStyle { get; set; }
```

outline-style 属性
