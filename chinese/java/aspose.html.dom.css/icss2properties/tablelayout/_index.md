## ICSS2Properties.TableLayout property

此 ['table-layout'](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#propdef-table-layout) 属性控制用于布局表格单元格、行和列的算法。取值含义如下：

fixed - 使用固定表格布局算法；auto - 使用任意自动表格布局算法

```java
public String TableLayout { get; set; }
```

table-layout 属性
