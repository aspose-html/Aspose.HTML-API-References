## ICSS2Properties.Stress property

指定声音语调轮廓中“局部峰值”的高度。例如，英语是一种重音语言，句子的不同部分被分配为主要、次要或三级重音。['stress'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-stress) 的取值控制这些重音标记导致的音调变化量。此属性是 ['pitch-range'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pitch-range) 属性的配套属性，提供给开发者用于利用更高级的听觉显示。

```java
public String Stress { get; set; }
```

### 返回值

stress 属性
