## ICSS2Properties.FontSizeAdjust property

在双字母脚本中，字体的主观感知大小和可读性不太依赖于其 'font-size' 值，而更依赖于其 'x-height' 的值，或者更实用地说，依赖于这两个值的比率，称为 aspect value（字体大小除以 x-height）。 aspect value 越高，字体在较小尺寸下保持可读性的可能性越大。 相反，aspect value 较低的字体在低于某一阈值尺寸时会更快变得不可读，而 aspect value 较高的字体则不易出现此情况。 单纯依赖 font size 的直接字体替换可能导致字符不可读。

```java
public String FontSizeAdjust { get; set; }
```
