## ICSS2Properties.WordSpacing property

此属性指定单词之间的间距行为。取值含义如下：

normal - 正常的单词间距，由当前字体和/或用户代理定义。'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - 此取值表示在默认单词间距之外的额外间距。取值可以为负，但可能受到实现特定的限制。

```java
public String WordSpacing { get; set; }
```

### 返回值

word-spacing 属性
