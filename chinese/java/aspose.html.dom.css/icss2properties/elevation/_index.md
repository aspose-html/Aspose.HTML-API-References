## ICSS2Properties.Elevation property

此属性的值具有以下含义：

‘angle’ - 将仰角指定为角度，范围在 ‘-90deg’ 到 ‘90deg’ 之间。‘0deg’ 表示前方水平线，大致等同于与听者同高。‘90deg’ 表示正上方，‘-90deg’ 表示正下方。below - 等同于 ‘-90deg’。level - 等同于 ‘0deg’。above - 等同于 ‘90deg’。higher - 在当前仰角上增加 10 度。lower - 在当前仰角上减少 10 度。

public String Elevation { get; set; }
