## ICSS2Properties.PageBreakAfter property

这些属性的取值含义如下：

auto - 既不强制也不禁止在生成的盒子之前（之后、内部）分页。always - 始终在生成的盒子之前（之后）强制分页。avoid - 避免在生成的盒子之前（之后、内部）分页。left - 在生成的盒子之前（之后）强制一次或两次分页，使下一页排版为左页。right - 在生成的盒子之前（之后）强制一次或两次分页，使下一页排版为右页。

```java
public String PageBreakAfter { get; set; }
```
