## ICSS2Properties.TextDecoration property

此属性描述添加到元素文本的装饰。如果该属性针对 [block-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#block-level) 元素指定，则影响该元素的所有内联级后代。如果针对（或影响）[inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) 元素指定，则影响该元素生成的所有框。如果元素没有内容或没有文本内容（例如 HTML 中的 IMG 元素），用户代理必须[ignore](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#ignore)此属性。

以下值的含义如下：

none - 不产生文本装饰。underline - 每行文本都有下划线。overline - 每行文本上方有一条线。line-through - 每行文本中间有一条线。blink - 文本闪烁（在可见和不可见之间交替）。

public String TextDecoration { get; set; }
