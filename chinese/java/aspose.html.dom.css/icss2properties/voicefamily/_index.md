## ICSS2Properties.VoiceFamily property

该值是以逗号分隔的、按优先级排序的语音族名称列表（可与 ['font-family'](https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html#propdef-font-family) 进行比较）。值具有以下含义：

‘generic-voice’ - 值为语音族。可能的取值有 ‘male’、‘female’ 和 ‘child’。‘specific-voice’ - 值为具体实例（例如 comedian、trinoids、carlos、lani）。

```java
public String VoiceFamily { get; set; }
```

voice-family 属性
