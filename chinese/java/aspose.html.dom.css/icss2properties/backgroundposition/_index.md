## ICSS2Properties.BackgroundPosition property

如果已指定背景图像，此属性指定其初始位置。取值含义如下：

当值对为 '0% 0%' 时，图像的左上角与盒子填充边缘的左上角对齐。值对为 '100% 100%' 时，图像的右下角位于填充区域的右下角。值对为 '14% 84%' 时，图像中横跨 14%、纵向下移 84% 的点放置在填充区域中横跨 14%、纵向下移 84% 的点上。值对为 '2cm 2cm' 时，图像的左上角相对于填充区域的左上角向右移动 2cm、向下移动 2cm。top left 和 left top - 等同于 '0% 0%'。top、top center 和 center top - 等同于 '50% 0%'。right top 和 top right - 等同于 '100% 0%'。left、left center 和 center left - 等同于 '0% 50%'。center 和 center center - 等同于 '50% 50%'。right、right center 和 center right - 等同于 '100% 50%'。bottom left 和 left bottom - 等同于 '0% 100%'。bottom、bottom center 和 center bottom - 等同于 '50% 100%'。bottom right 和 right bottom - 等同于 '100% 100%'。

```java
public String BackgroundPosition { get; set; }
```

### 返回值

background-position 属性

### Property Value

上述列表中定义的 background position 值。
