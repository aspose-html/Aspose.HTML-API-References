## ICSS2Properties.BackgroundRepeat property

如果指定了背景图像，此属性指定图像是否重复（平铺），以及如何平铺。所有平铺覆盖盒子的内容区和内边距区。取值含义如下：

repeat - 图像在水平和垂直方向上都重复。repeat-x - 图像仅在水平方向重复。repeat-y - 图像仅在垂直方向重复。no-repeat - 图像不重复：仅绘制一份图像。

```java
public String BackgroundRepeat { get; set; }
```

### 返回值

background-repeat 属性

### Property Value

如上所定义的列表中的 background repeat 值。
