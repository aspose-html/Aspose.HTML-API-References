## ICSS2Properties.EmptyCells property

在分离边框模型中，此属性控制对没有可见内容的单元格周围边框的渲染。空单元格以及 'visibility' 属性设置为 'hidden' 的单元格被视为没有可见内容。

```java
public String EmptyCells { get; set; }
```

### 返回值

empty-cells 属性
