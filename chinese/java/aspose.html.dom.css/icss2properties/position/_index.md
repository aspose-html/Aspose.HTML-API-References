## ICSS2Properties.Position property

此属性的值具有以下含义：

static - 该盒子是普通盒子，按照[正常流](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#normal-flow)布局。['left'] 和 ['top'] 属性不适用。

```java
public String Position { get; set; }
```

### 返回值

relative - 盒子的位置是根据[正常流](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#normal-flow)计算的（这称为正常流中的位置）。然后盒子相对于其正常位置进行[相对](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#relative-positioning)偏移。当盒子 B 采用相对定位时，后续盒子的位置计算好像 B 没有偏移一样。
