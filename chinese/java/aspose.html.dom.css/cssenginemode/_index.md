## CSSEngineMode enumeration

指定 CSSEngine 模式。各值含义如下：

default - CSS 解析器将遵循 W3C 推荐工作，不支持自定义扩展。not-strict - 所有未记录的属性将被解析，并可通过访问获取。

```java
[Flags]
public enum CSSEngineMode
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Default | `0` | CSS 解析器将遵循 W3C 推荐工作，不支持自定义扩展。 |
| NotStrict | `1` | CSS 解析器将在非严格模式下工作。所有未记录的属性将被解析，并可通过访问获取。 |
