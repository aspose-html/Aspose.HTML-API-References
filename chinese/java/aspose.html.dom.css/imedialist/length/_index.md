## IMediaList.Length property

length 属性必须返回媒体查询集合中的媒体查询数量。有效媒体的范围为 0 到 length-1（含）。

```java
public long Length { get; }
```

### Property Value

返回 [`MediaList`](../) 中的媒体查询数量。
