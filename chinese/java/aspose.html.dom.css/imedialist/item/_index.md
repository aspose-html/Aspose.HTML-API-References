## IMediaList indexer

item(index) 方法必须返回由索引给出的媒体查询集合中的媒体查询的序列化字符串；如果索引大于或等于媒体查询集合的数量，则返回 null。

```java
public String this[int index] { get; }
```

### 返回值

返回一个字符串，表示位于 [`MediaList`](../) 中的媒体查询的文本形式，依据媒体查询的索引值。

### Property Value

一个整数，表示要返回的集合中项目的索引。
