## IStyleSheet.Title property

[`StyleSheet`](../) 接口的 title 属性返回当前样式表的建议标题。

title 通常在 [`ownerNode`](../ownernode/) 中指定。

```java
public String Title { get; }
```

### Property Value

parentStyleSheet 属性必须返回父级 [`CSS style sheet`](../../icssstylesheet/)。
