## SetProperty(String, String) {#setproperty}

CSSStyleDeclaration.setProperty() 方法接口用于在此声明块中以默认优先级设置属性值。默认优先级不是 \"important\"，即 String.Empty。

```java
public void SetProperty(String propertyName, String value)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| propertyName | String | 一个字符串，表示要修改的 CSS 属性名称（连字符形式）。 |
| 值 | String | 一个字符串，包含新的属性值。如果未指定，则视为空字符串。 |

## SetProperty(String, String, String) {#setproperty_1}

CSSStyleDeclaration.setProperty() 方法接口用于在此声明块中以默认优先级设置属性值。默认优先级不是 \"important\"，即 String.Empty。

```java
public void SetProperty(String propertyName, String value, String priority)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| propertyName | String | 一个字符串，表示要修改的 CSS 属性名称（连字符形式）。 |
| 值 | String | 一个字符串，包含新的属性值。如果未指定，则视为空字符串。 |
| priority | String | 一个字符串，用于设置 "important" CSS 优先级。如果未指定，则视为空字符串。接受以下值：字符串值 "important"、关键字 undefined 或空字符串 ""。 |
