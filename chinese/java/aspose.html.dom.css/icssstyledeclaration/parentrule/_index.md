## ICSSStyleDeclaration.ParentRule property

CSSStyleDeclaration.parentRule 只读属性返回一个 CSSRule，它是此样式块的父级，例如一个 [`CSSStyleRule`](../../icssstylerule/)，表示 CSS 选择器的样式。

```java
public ICSSRule ParentRule { get; }
```

### Property Value

包含此声明块的 CSS 规则，如果此 [`CSSStyleDeclaration`](../) 未附加到 [`CSSRule`](../../icssrule/) 则为 null。
