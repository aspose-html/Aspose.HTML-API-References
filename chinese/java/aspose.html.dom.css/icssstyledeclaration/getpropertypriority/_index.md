## ICSSStyleDeclaration.GetPropertyPriority method

用于检索在此声明块中显式设置的 CSS 属性的优先级（例如 \"important\" 修饰符）。

```java
public String GetPropertyPriority(String propertyName)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| propertyName | String | property 是一个 DOMString，表示要检查的属性名称。 |

### 返回值

priority 是一个 DOMString，表示优先级（例如 "important"），如果存在的话。如果不存在，则返回空字符串。
