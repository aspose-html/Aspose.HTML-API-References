## ICSSStyleDeclaration indexer

用于检索此声明块中已显式设置的属性。使用此方法检索的属性顺序不必与设置时的顺序相同。此方法可用于遍历此声明块中的所有属性。

```java
public String this[int index] { get; }
```

### 返回值

propertyName 是一个字符串，表示指定索引处的 CSS 属性名称。

### Property Value

index 是要获取的节点的索引。索引从零开始。
