## ICSSStyleDeclaration.GetPropertyValue method

CSSStyleDeclaration.getPropertyValue() 方法接口返回包含指定 CSS 属性值的字符串。

```java
public String GetPropertyValue(String propertyName)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| propertyName | String | propertyName 是表示要检查的属性名称（连字符形式）的字符串。 |

### 返回值

value 是包含属性值的字符串。如果未设置，则返回空字符串。
