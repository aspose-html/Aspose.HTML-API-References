## ICSSStyleDeclaration.CSSText property

声明块的可解析文本表示（不包括外部的大括号）。设置此属性将导致解析新值并重置声明块中的所有属性，包括属性的删除或添加。

```java
public String CSSText { get; set; }
```

### Property Value

设置此属性会更改内联样式。如果需要计算后的声明块的文本表示，可以使用 JSON.Stringify() 获取。
