## ICSSMediaRule.InsertRule method

CSSGroupingRule 接口的 insertRule() 方法向 CSS 规则列表中添加一个新 CSS 规则。

```java
public long InsertRule(String rule, long index)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| 规则 | String | 媒体规则，以 CSSOMString 表示。 |
| index | Int64 | 可选的插入规则的索引；默认值为 0。 |

### 返回值

insertRule(rule, index) 方法返回在指定索引处将 CSS 规则插入子 CSS 规则列表的结果。
