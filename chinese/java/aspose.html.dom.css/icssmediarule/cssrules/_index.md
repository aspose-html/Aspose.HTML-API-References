## ICSSMediaRule.CSSRules property

CSSGroupingRule 接口的 cssRules 属性返回一个 [`CSSRuleList`](../../icssrulelist/)，其中包含一组 [`CSSRule`](../../icssrule/) 对象。

```java
public ICSSRuleList CSSRules { get; }
```

### Property Value

cssRules 属性必须返回一个用于子 CSS 规则的 [`CSSRuleList`](../../icssrulelist/) 对象。
