## ICSSKeyframesRule.FindRule method

findRule 方法返回键与传入键匹配的规则。如果不存在此类规则，则返回 null 值。

```java
public ICSSKeyframeRule FindRule(String key)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| 键 | String | 描述要查找规则的键。该键必须解析为 0 到 1 之间的数值，否则该规则将被忽略。 |

### 返回值

返回最后声明的匹配指定关键帧选择器的 [`CSSKeyframeRule`](../../icsskeyframerule/)。如果不存在匹配的规则，方法不执行任何操作。
