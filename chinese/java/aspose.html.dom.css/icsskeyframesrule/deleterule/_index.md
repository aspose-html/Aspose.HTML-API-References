## ICSSKeyframesRule.DeleteRule method

deleteRule 方法删除具有给定键的 [`CSSKeyframeRule`](../../icsskeyframerule/)。如果不存在具有该键的规则，方法不执行任何操作。

```java
public void DeleteRule(String key)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| 键色 | String | 描述要删除规则的键。该键必须解析为 0 到 1 之间的数字，否则该规则将被忽略。 |
