## ICSSImportRule.StyleSheet property

此规则引用的样式表（如果已加载）。如果样式表尚未加载或不会被加载（例如样式表针对用户代理不支持的媒体类型），则此属性的值为 null。

```java
public ICSSStyleSheet StyleSheet { get; }
```

### Property Value

返回由 @import 规则指定的 CSS 样式表。它将以 [`CSSStyleSheet`](../../icssstylesheet/) 对象的形式返回。
