## ICSSImportRule.Href property

CSSImportRule 接口的只读 href 属性返回 @import 规则指定的 URL。

解析后的 URL 将是关联样式表的 href 属性。

```java
public String Href { get; }
```

### Property Value

返回由 @import 规则指定的关联样式表的 URL。
