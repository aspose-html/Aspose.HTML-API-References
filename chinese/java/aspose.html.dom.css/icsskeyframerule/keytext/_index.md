## ICSSKeyframeRule.KeyText property

CSSKeyframeRule 接口的 keyText 属性将关键帧选择器表示为以逗号分隔的百分比值列表。from 和 to 关键字分别映射到 0% 和 100%。

```java
public String KeyText { get; }
```

### Property Value

返回关键帧选择器，以逗号分隔的百分比值列表形式。
