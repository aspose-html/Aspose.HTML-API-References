## ICSSKeyframeRule interface

`CSSKeyframeRule` 接口描述了一个表示给定关键帧样式集合的对象。它对应于 @keyframes at-rule 中单个关键帧的内容。

```java
public interface ICSSKeyframeRule : ICSSRule
```

| 名称 | 描述 |

| [getKeyText](../../com.aspose.html.dom.css/icsskeyframerule/keytext/) CSSKeyframeRule 接口的 keyText 属性将关键帧选择器表示为逗号分隔的百分比值列表。关键字 from 和 to 分别映射到 0% 和 100%。 |
| [getStyle](../../com.aspose.html.dom.css/icsskeyframerule/style/) 只读的 CSSKeyframeRule.style 属性是用于 `CSSKeyframeRule` 声明块的 [`CSSStyleDeclaration`](../icssstyledeclaration/) 接口。 |
