## TypeInfo.DERIVATION_RESTRICTION field

如果文档的模式是 XML Schema [XML Schema Part 1]，此常量表示通过限制的派生（如果涉及复合类型），或者如果涉及简单类型则表示限制。

```java
public const ulong DERIVATION_RESTRICTION;
```
