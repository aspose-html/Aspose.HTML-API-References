## Document.CreateAttributeNS method

Document.createAttribute() 方法创建一个新的属性节点并返回它。创建的对象是实现了 [Attr](T:com.aspose.html.dom.Attr) 接口的节点。DOM 并不强制规定可以以这种方式添加到特定元素的属性类型。

```java
public Attr CreateAttributeNS(String packageURI, String qualifiedName)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| packageURI | String | 属性的包 URI。 |
| qualifiedName | String | name 是一个包含属性名称的字符串。 |

### 返回值

该 [`Attr`](../../attr/)。
