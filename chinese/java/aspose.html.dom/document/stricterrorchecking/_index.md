## Document.StrictErrorChecking property

一个指定是否强制进行错误检查的属性。设置为 false 时，实现可以不检测 DOM 操作中通常定义的每一种可能错误情况，也不在 DOM 操作中抛出任何 DOMException，或在使用 Document.normalizeDocument() 时不报告错误。出现错误时行为未定义。此属性默认值为 true。

```java
public bool StrictErrorChecking { get; set; }
```

### Property Value

`true` 表示严格错误检查；否则为 `false`。
