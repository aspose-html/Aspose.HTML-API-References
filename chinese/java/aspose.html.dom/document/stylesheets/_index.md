## Document.StyleSheets property

一个列表，包含文档中显式链接或嵌入的所有样式表。对于 HTML 文档，这包括通过 HTML LINK 元素包含的外部样式表以及内联 STYLE 元素。

```java
public IStyleSheetList StyleSheets { get; }
```
