## Document.StyleSheets property

包含文档中所有显式链接或嵌入的样式表的列表。对于 HTML 文档，这包括通过 HTML LINK 元素包含的外部样式表以及内联 STYLE 元素。

```java
public IStyleSheetList StyleSheets { get; }
```
