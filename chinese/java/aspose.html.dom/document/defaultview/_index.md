## Document.DefaultView property

Document 接口的 defaultView IDL 属性在获取时，必须返回该文档的浏览上下文的 WindowProxy 对象（如果该文档具有关联的浏览上下文），否则返回 null。

```java
public IWindow DefaultView { get; }
```
