## Document.XmlStandalone property

作为 XML 声明的一部分，指定此文档是否为独立文档的属性。如果未指定，则为 false。

```java
public bool XmlStandalone { get; set; }
```

### Property Value

`true` 表示 XML 为独立文档；否则为 `false`。
