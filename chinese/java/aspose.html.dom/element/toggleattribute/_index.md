## ToggleAttribute(String) {#toggleattribute}

如果未提供 force，则"切换"qualifiedName：如果已存在则移除，未存在则添加。如果 force 为 true，则添加 qualifiedName；如果 force 为 false，则移除 qualifiedName。

```java
public bool ToggleAttribute(String qualifiedName)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| qualifiedName | String | 属性 QualifiedName。 |

### 返回值

如果 qualifiedName 现在存在则返回 true；否则返回 false。
