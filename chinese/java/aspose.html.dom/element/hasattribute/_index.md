## Element.HasAttribute method

当此元素上指定了具有给定名称的属性或该属性具有默认值时返回 true，否则返回 false。

```java
public bool HasAttribute(String qualifiedName)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| name | String | 属性名称。 |

### 返回值

`true` 如果指定的名称具有属性；否则为 `false`。
