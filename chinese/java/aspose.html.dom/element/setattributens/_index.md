## Element.SetAttributeNS method

添加一个新属性。如果元素上已存在具有相同本地名称和包 URI 的属性，则其前缀会更改为 qualifiedName 的前缀部分，且其值会更改为 value 参数的值。

```java
public void SetAttributeNS(String packageURI, String qualifiedName, String value)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| packageURI | String | 包 URI。 |
| qualifiedName | String | 限定名称。 |
| 值 | String | 该值。 |
