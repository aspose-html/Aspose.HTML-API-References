## Element.HasAttributeNS method

当此元素上指定了具有给定本地名称和包 URI 的属性或该属性具有默认值时返回 true，否则返回 false。

```java
public bool HasAttributeNS(String packageURI, String localName)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| packageURI | String | 该 package URI。 |
| localName | String | 本地的名称。 |

### 返回值

`true` 如果 [has attribute NS] [指定的包 URI]；否则 `false`。
