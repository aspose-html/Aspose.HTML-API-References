## Node.FirstChild property

只读的 firstChild 属性（[`Node`](../) 接口）返回树中节点的第一个子节点，如果节点没有子节点则返回 null。

如果节点是 Document，则此属性返回其直接子节点列表中的第一个节点。

```java
public Node FirstChild { get; }
```

### Property Value

一个 [`Node`](../)，如果不存在则为 null。
