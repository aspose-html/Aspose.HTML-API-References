## Node.LocalName property

返回此节点的限定名称的本地部分。对于除 [`ELEMENT_NODE`](../element_node/) 和 [`ATTRIBUTE_NODE`](../attribute_node/) 之外的任何类型节点，以及使用 DOM Level 1 方法创建的节点，例如 [`Document.createElement()`](../../document/createelement/)，此值始终为 null。

```java
public String LocalName { get; }
```

### Property Value

一个表示元素限定名称本地部分的字符串。
