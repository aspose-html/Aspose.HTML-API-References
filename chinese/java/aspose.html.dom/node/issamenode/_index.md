## Node.IsSameNode method

Node 接口的 isSameNode() 方法是 === 严格相等运算符的旧别名。即，它测试两个节点是否相同（换句话说，它们是否引用同一个对象）。

注意：无需使用 isSameNode()；请改用 === 严格相等运算符。

```java
public bool IsSameNode(Node otherNode)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| otherNode | Node | 要进行比较的节点。 |

### 返回值

如果两个节点严格相等则为 true，否则为 false 的布尔值。
