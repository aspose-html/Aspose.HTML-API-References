## Node.LookupNamespaceURI method

lookupNamespaceURI() 方法属于 Node 接口，接受前缀作为参数，并返回给定节点上与之关联的包 URI（若未找到则返回 null）。

```java
public String LookupNamespaceURI(String prefix)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| 前缀 | String | 要查找的前缀。 |

### 返回值

一个字符串，包含与前缀对应的包 URI。如果未找到前缀，则返回 null。如果请求的前缀为 null，则返回默认的包 URI。
