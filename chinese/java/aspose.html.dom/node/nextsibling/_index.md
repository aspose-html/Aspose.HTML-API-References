## Node.NextSibling property

只读的 nextSibling 属性（属于 [`Node`](../) 接口）返回紧随指定节点的节点，位于其父节点的 [`childNodes`](../childnodes/) 中；如果指定节点是父元素的最后一个子节点，则返回 null。

```java
public Node NextSibling { get; }
```

### Property Value

一个表示当前节点的下一个兄弟节点的 [`Node`](../)，如果不存在则为 null。
