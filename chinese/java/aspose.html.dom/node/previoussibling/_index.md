## Node.PreviousSibling property

只读的 previousSibling 属性（[`Node`](../) 接口）返回其父节点的 [`childNodes`](../firstchild/) 列表中紧邻指定节点之前的节点，如果指定节点是列表中的第一个则返回 null。

```java
public Node PreviousSibling { get; }
```

### Property Value

一个表示当前节点的前一个兄弟节点的 [`Node`](../)，如果不存在则为 null。
