## SVGAngle.ValueInSpecifiedUnits property

角度值以浮点数形式表示，单位由 unitType 指定。设置此属性将导致 value 和 valueAsString 自动更新以反映此设置。

```java
public float ValueInSpecifiedUnits { get; set; }
```

### Property Value

指定单位中的值。
