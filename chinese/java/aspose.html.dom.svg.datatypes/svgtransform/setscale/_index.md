## SVGTransform.SetScale method

将变换类型设置为 SVG_TRANSFORM_SCALE，参数 sx 和 sy 定义缩放量。

```java
public void SetScale(float sx, float sy)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| sx | 单精度浮点数 | X 方向的缩放量。 |
| sy | 单精度浮点数 | Y 方向的缩放量。 |
