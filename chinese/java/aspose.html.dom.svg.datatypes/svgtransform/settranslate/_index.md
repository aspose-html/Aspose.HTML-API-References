## SVGTransform.SetTranslate method

将变换类型设置为 SVG_TRANSFORM_TRANSLATE，参数 tx 和 ty 定义平移量。

```java
public void SetTranslate(float tx, float ty)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| tx | 单精度浮点数 | X 方向的平移量。 |
| ty | 单精度浮点数 | Y 方向的平移量。 |
