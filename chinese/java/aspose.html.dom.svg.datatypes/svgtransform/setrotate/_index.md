## SVGTransform.SetRotate method

将变换类型设置为 SVG_TRANSFORM_ROTATE，参数 angle 定义旋转角度，参数 cx 和 cy 定义可选的旋转中心。

```java
public void SetRotate(float angle, float cx, float cy)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| angle | 单精度浮点数 | 旋转角度。 |
| cx | 单精度浮点数 | 旋转中心的 x 坐标。 |
| cy | 单精度浮点数 | 旋转中心的 y 坐标。 |

### 异常

| 异常 | 条件 |
| --- | --- |
| [dOMException](../../../com.aspose.html.dom/domexception/) | 代码 [`NO_MODIFICATION_ALLOWED_ERR`](../../../com.aspose.html.dom/domexception/no_modification_allowed_err/)。在尝试更改只读属性的值时抛出。 |
