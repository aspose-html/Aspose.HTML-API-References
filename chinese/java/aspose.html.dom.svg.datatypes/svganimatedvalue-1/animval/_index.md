## SVGAnimatedValue&lt;T&gt;.AnimVal property

如果给定的属性或属性正在动画，包含该属性或属性的当前动画值。如果给定的属性或属性当前未动画，包含与 baseVal 相同的值。

```java
public T AnimVal { get; }
```

### Property Value

`true` 如果是 [anim value]；否则为 `false`。
