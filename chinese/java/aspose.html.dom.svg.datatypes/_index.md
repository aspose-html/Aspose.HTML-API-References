该包提供对所有 SVG 特定数据类型的访问。

## 类

| 类 | 描述 |
| --- | --- |
| [SVGAngle](./svgangle/) | SVGAngle 接口对应于 angle 基本数据类型。 |
| [SVGAnimatedAngle](./svganimatedangle/) | 用于可以动画化的 angle 基本数据类型属性。 |
| [SVGAnimatedBoolean](./svganimatedboolean/) | 用于可以动画化的 boolean 类型属性。 |
| [SVGAnimatedEnumeration](./svganimatedenumeration/) | 用于其值必须来自特定枚举常量且可以动画化的属性。 |
| [SVGAnimatedInteger](./svganimatedinteger/) | 用于可以动画化的 integer 基本类型属性。 |
| [SVGAnimatedLength](./svganimatedlength/) | 用于可以动画化的 length 基本类型属性。 |
| [SVGAnimatedLengthList](./svganimatedlengthlist/) | 用于可以动画化的 SVGLengthList 类型属性。 |
| [SVGAnimatedNumber](./svganimatednumber/) | 用于可以动画化的 number 基本类型属性。 |
| [SVGAnimatedNumberList](./svganimatednumberlist/) | 用于接受数字列表且可以动画化的属性。 |
| [SVGAnimatedPreserveAspectRatio](./svganimatedpreserveaspectratio/) | 用于可以动画化的 SVGPreserveAspectRatio 类型属性。 |
| [SVGAnimatedRect](./svganimatedrect/) | 用于可以动画化的 SVGRect 类型属性。 |
| [SVGAnimatedString](./svganimatedString/) | 用于可以动画化的 DOMString 类型属性。 |
| [SVGAnimatedTransformList](./svganimatedtransformlist/) | 用于指定一组变换的各种属性，例如在许多 SVG 元素中可用且可动画的 ‘transform’ 属性。 |
| [SVGAnimatedValue&lt;T&gt;](./svganimatedvalue-1/) | 用于可以动画化的类型属性。 |
| [SVGLength](./svglength/) | SVGLength 接口对应长度基本数据类型。SVGLength 对象可以被指定为只读，这意味着尝试修改该对象将抛出异常，如下所述。 |
| [SVGLengthList](./svglengthlist/) | 此接口定义了 SVGLength 对象的列表。 |
| [SVGMatrix](./svgmatrix/) | 许多 SVG 的图形操作使用形式为 [a c e] [b d f] 的 2x3 矩阵，在进行矩阵运算时会展开为 3x3 矩阵，即 [a c e] [b d f] [0 0 1]。 |
| [SVGNumber](./svgnumber/) | 用于基本类型 number 的属性。 |
| [SVGNumberList](./svgnumberlist/) | 此接口定义了 SVGNumber 对象的列表。 |
| [SVGPoint](./svgpoint/) | 许多 SVG DOM 接口引用类 SVGPoint 的对象。SVGPoint 是一个 (x, y) 坐标对。在矩阵运算中，SVGPoint 被视为形式为 [x] [y] [1] 的向量。如果 SVGRect 对象被指定为只读，则尝试为其属性赋值将抛出异常。 |
| [SVGPointList](./svgpointlist/) | 此接口定义了 SVGPoint 对象的列表。 |
| [SVGPreserveAspectRatio](./svgpreserveaspectratio/) | SVGPreserveAspectRatio 接口对应 ‘preserveAspectRatio’ 属性，该属性在某些 SVG 元素中可用。 |
| [SVGRect](./svgrect/) | 表示矩形几何形状。矩形定义为包含一个 (x,y) 坐标对，用于标识最小 X 值、最小 Y 值以及宽度和高度，通常约束为非负。 |
| [SVGStringList](./svgStringlist/) | SVGStringList 具有与其他 SVGxxxList 接口相同的属性和方法。实现者可以考虑使用单一基类来实现各种 SVGxxxList 接口。 |
| [SVGTransform](./svgtransform/) | SVGTransform 是 SVGTransformList 中某个组件变换的接口；因此，SVGTransform 对象对应于 ‘transform’ 属性规范中的单个组件（例如 'scale(…)' 或 'matrix(…)')。 |
| [SVGTransformList](./svgtransformlist/) | 此接口定义了 SVGTransform 对象的列表。 |
| [SVGValueType](./svgvaluetype/) | SVGValueType 类型用于表示基础 SVG 值类型。 |
