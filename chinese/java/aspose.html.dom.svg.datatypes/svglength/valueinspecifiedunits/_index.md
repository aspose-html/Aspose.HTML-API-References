## SVGLength.ValueInSpecifiedUnits property

该值以 unitType 表示的单位的浮点数形式表示。设置此属性将导致 value 和 valueAsString 自动更新以反映此设置。

```java
public float ValueInSpecifiedUnits { get; set; }
```

### Property Value

指定单位中的值。
