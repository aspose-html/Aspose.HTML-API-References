## SVGLength.ValueAsString property

该值以 unitType 表示的单位中的字符串形式表示。设置此属性将导致 value、valueInSpecifiedUnits 和 unitType 自动更新以反映此设置。

```java
public String ValueAsString { get; set; }
```

### Property Value

值为 String。
