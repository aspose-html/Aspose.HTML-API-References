## FontEmbeddingRule enumeration

表示字体嵌入规则。

```java
public enum FontEmbeddingRule
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Full | `1` | 所有使用的字体将原样嵌入。请注意，某些字体可能受许可限制，这会导致生成的文档不可编辑。此外，嵌入的字体文件可能会显著增加生成文档的大小。 |
| None | `2` | 字体不会被嵌入。 |
