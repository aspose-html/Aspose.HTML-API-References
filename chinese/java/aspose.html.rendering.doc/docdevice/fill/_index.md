## DocDevice.Fill method

填充当前路径所围成的整个区域。如果路径由多个不相连的子路径组成，则会一起填充所有子路径的内部。此方法终止当前路径。

```java
public void Fill(FillRule mode)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| mode | FillRule | 填充模式指定封闭路径内部的填充方式 |
