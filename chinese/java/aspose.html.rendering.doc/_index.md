**com.aspose.html.rendering.doc** 包提供特定的设备类以及负责渲染为 DOCX 文档的少量渲染选项类。

## 类

| 类 | 描述 |
| --- | --- |
| [DocDevice](./docdevice/) | 表示渲染到 DOCX 文档。 |
| [DocRenderingOptions](./docrenderingoptions/) | 表示 [`DocDevice`](../com.aspose.html.rendering.doc/docdevice/) 的渲染选项。 |
## 枚举

| 枚举 | 描述 |
| --- | --- |
| [DocumentFormat](./documentformat/) | 表示输出文档的文件格式。 |
| [FontEmbeddingRule](./fontembeddingrule/) | 表示字体嵌入规则。 |
