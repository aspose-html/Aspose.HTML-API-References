## IImageData interface

从给定的 Uint8ClampedArray 及其包含的图像尺寸创建 ImageData 对象。如果未提供数组，则创建一个黑色矩形的图像。

```java
public interface IImageData
```

## 属性

| 名称 | 描述 |
| --- | --- |
| [getData](../../com.aspose.html.dom.canvas/iimagedata/data/) 是一个 Uint8ClampedArray，表示一个一维数组，包含按 RGBA 顺序的数据，整数值在 0 到 255（含）之间。 |
| [getHeight](../../com.aspose.html.dom.canvas/iimagedata/height/) 是一个无符号长整数，表示 ImageData 的实际高度（像素）。 |
| [getWidth](../../com.aspose.html.dom.canvas/iimagedata/width/) 是一个无符号长整数，表示 ImageData 的实际宽度（像素）。 |
