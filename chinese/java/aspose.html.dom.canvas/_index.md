## 类

| 类 | 描述 |
| --- | --- |
| [Path2D](./path2d/) | Canvas 2D API 的 Path2D 接口用于声明路径，这些路径随后在 CanvasRenderingContext2D 对象上使用。CanvasRenderingContext2D 接口的路径方法也在此接口中提供，允许您创建可以在画布上根据需要保留和重放的路径。 |
## 接口

| 接口 | 描述 |
| --- | --- |
| [ICanvasDrawingStyles](./icanvasdrawingstyles/) | ICanvasDrawingStyles 接口提供用于控制线条绘制方式和文本布局方式的方法和属性。 |
| [ICanvasGradient](./icanvasgradient/) | 表示描述渐变的不透明对象。 |
| [ICanvasPathMethods](./icanvaspathmethods/) | ICanvasPathMethods 接口用于操作对象的路径。 |
| [ICanvasPattern](./icanvaspattern/) | 表示基于图像、画布或视频的图案描述的不透明对象。 |
| [ICanvasRenderingContext2D](./icanvasrenderingcontext2d/) | ICanvasRenderingContext2D 接口用于在 canvas 元素上绘制矩形、文本、图像和其他对象。它为 canvas 元素的绘图表面提供 2D 渲染上下文。 |
| [IImageData](./iimagedata/) | 从给定的 Uint8ClampedArray 及其包含的图像尺寸创建 ImageData 对象。如果未提供数组，则创建一个黑色矩形的图像。 |
| [ITextMetrics](./itextmetrics/) | 表示 canvas 中文本的尺寸。 |
