## IsPointInPath(double, double) {#ispointinpath_2}

报告指定点是否位于当前路径中。

```java
public bool IsPointInPath(double x, double y)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| x | Double | 要检查的点的 X 坐标。 |
| y | Double | 要检查的点的 Y 坐标。 |

### 返回值

如果点位于路径填充所包含的区域内则返回 true，否则返回 false。
