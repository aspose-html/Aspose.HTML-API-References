## CreateImageData(double, double) {#createimagedata_1}

创建一个具有指定尺寸的新空白 ImageData 对象。新对象中的所有像素都是透明黑色。

```java
public IImageData CreateImageData(double sw, double sh)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| sw | Double | 新 ImageData 对象的宽度。 |
| sh | Double | 新 ImageData 对象的高度。 |

### 返回值

一个具有指定宽度和高度的新 ImageData 对象。该新对象填充了透明的黑色像素。

```java
public IImageData CreateImageData(IImageData imagedata)
```

| 参数 | 类型 | 描述 |
