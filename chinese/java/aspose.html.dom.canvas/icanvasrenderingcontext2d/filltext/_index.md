```java
public void FillText(String text, double x, double y, double maxWidth)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| text | String | 使用当前字体、textAlign、textBaseline 和 direction 值绘制的文本。 |
| x | Double | 文本起始点的坐标 x 轴。 |
| y | Double | 文本起始点的坐标 y 轴。 |
| maxWidth | Double | 绘制的最大宽度。如果指定且字符串计算后宽度超过此值，字体将被调整为使用更水平压缩的字体（如果有可用的，或通过水平缩放当前字体合成出可读的字体），或者使用更小的字体。 |
