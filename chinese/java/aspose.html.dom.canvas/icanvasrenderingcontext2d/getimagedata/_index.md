## ICanvasRenderingContext2D.GetImageData method

返回一个 ImageData 对象，表示由矩形指定的画布区域的底层像素数据，该矩形起始于 (sx, sy)，宽度为 sw，高度为 sh。此方法不受画布变换矩阵的影响。

```java
public IImageData GetImageData(double sx, double sy, double sw, double sh)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| sx | Double | 要提取 ImageData 的矩形左上角的 x 坐标。 |
| sy | Double | 要提取 ImageData 的矩形左上角的 y 坐标。 |
| sw | Double | 要提取 ImageData 的矩形的宽度。 |
| sh | Double | 要提取 ImageData 的矩形的高度。 |

### 返回值

一个 ImageData 对象，包含画布给定矩形的图像数据。
