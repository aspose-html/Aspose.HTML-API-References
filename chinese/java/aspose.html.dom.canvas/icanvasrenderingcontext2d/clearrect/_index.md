## ICanvasRenderingContext2D.ClearRect method

将由起始点 (x, y) 和尺寸 (width, height) 定义的矩形中的所有像素设置为透明黑色，擦除任何先前绘制的内容。

```java
public void ClearRect(double x, double y, double w, double h)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| x | Double | 矩形起始点的 x 坐标。 |
| y | Double | 矩形起始点的 y 坐标。 |
| w | Double | 矩形的宽度。 |
| h | Double | 矩形的高度。 |
