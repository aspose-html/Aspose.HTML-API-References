## ICanvasPathMethods.BezierCurveTo method

向路径添加三次 Bézier 曲线。它需要三个点。前两个点是控制点，第三个点是终点。起始点是当前路径中的最后一点，可在创建 Bézier 曲线之前使用 moveTo() 更改。

```java
public void BezierCurveTo(double cp1x, double cp1y, double cp2x, double cp2y, double x, double y)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| cp1x | Double | 第一个控制点的坐标的 x 轴。 |
| cp1y | Double | 第一个控制点的坐标的 y 轴。 |
| cp2x | Double | 第二个控制点的坐标的 x 轴。 |
| cp2y | Double | 第二个控制点的坐标的 y 轴。 |
| x | Double | 终点坐标的 x 轴。 |
| y | Double | 终点坐标的 y 轴。 |
