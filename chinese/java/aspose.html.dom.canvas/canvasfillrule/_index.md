## CanvasFillRule enumeration

此枚举用于选择填充规则算法，以确定点是位于路径内部还是外部。

```java
public enum CanvasFillRule
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| NonZero | `0` | 值 "nonzero" 表示非零环绕规则，即如果从该点绘制的半无限直线在一个方向上穿过形状路径的次数等于在相反方向上穿过的次数，则该点被视为在形状外部。 |
| EvenOdd | `1` | 值 "evenodd" 表示奇偶规则，即如果从该点绘制的半无限直线穿过形状路径的次数为偶数，则该点被视为在形状外部。 |
