除了标准的 IO（输入输出）工具外，**com.aspose.html.io** 包包含辅助类和接口。

## 类

| 类 | 描述 |
| --- | --- |
| [FileCreateStreamProvider](./filecreatestreamprovider/) | 表示用于向渲染设备提供流的 FileStream 实现。 |
## 接口

| 接口 | 描述 |
| --- | --- |
| [IBlob](./iblob/) | Blob 对象指代一个字节序列，并具有 size 属性，表示该字节序列的总字节数，以及 type 属性，这是一个小写的 ASCII 编码字符串，表示该字节序列的媒体类型。 |
| [ICreateStreamProvider](./icreatestreamprovider/) | 表示一个接口，可由提供流给渲染设备的类实现。 |
| [IFile](./ifile/) | File 对象是具有 name 属性（字符串）的 Blob 对象；它可以通过构造函数在 Web 应用中创建，或是对底层（操作系统）文件系统中文件的字节序列的引用。 |
| [IFileList](./ifilelist/) | 表示文件列表的接口。 |
