## IBlob.Size property

返回字节序列的大小（字节数）。获取时，符合规范的用户代理必须返回可以被 FileReader 或 FileReaderSync 对象读取的总字节数，如果 Blob 没有可读取的字节则返回 0。

```java
public ulong Size { get; }
```
