## IBlob.Type property

表示 Blob 媒体类型的 ASCII 编码小写字符串。获取时，用户代理必须返回 Blob 的类型，作为小写的 ASCII 编码字符串，使其转换为字节序列后是可解析的 MIME 类型；如果无法确定类型，则返回空字符串（0 字节）。

```java
public String Type { get; }
```
