该 **com.aspose.html.dom.mutations** 提供观察 DOM 变异并获取特定回调信息的机会。

## 类

| 类 | 描述 |
| --- | --- |
| [MutationCallback](./mutationcallback/) | 表示将处理变更事件的方法。 |
| [MutationObserver](./mutationobserver/) | 对象可用于观察对 [`.`](../com.aspose.html.dom/node/) 树的变更。 |
| [MutationObserverInit](./mutationobserverinit/) | 此类表示一个选项集合，用于配置 [`MutationObserver`](../com.aspose.html.dom.mutations/mutationobserver/)。 |
| [MutationRecord](./mutationrecord/) | MutationRecord 表示一次单独的 DOM 变更。它是传递给 [`MutationObserver`](../com.aspose.html.dom.mutations/mutationobserver/) 的 [`MutationCallback`](../com.aspose.html.dom.mutations/mutationcallback/) 的对象。 |
