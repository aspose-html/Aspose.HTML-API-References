## ITraversal.WhatToShow property

此属性决定通过迭代器呈现的节点类型。可用的常量集合在 NodeFilter 接口中定义。未被 whatToShow 接受的节点将被跳过，但其子节点仍可能被考虑。请注意，此跳过在有过滤器时优先于过滤器。

```java
public long WhatToShow { get; }
```

### Property Value

要显示的内容。
