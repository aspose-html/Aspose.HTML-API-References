## ITreeWalker.ParentNode method

移动到并返回当前节点最近的可见祖先节点。如果在搜索 parentNode 时尝试从 TreeWalker 的根节点向上移动，或未能找到可见的祖先节点，则此方法保持当前位置并返回 null。

```java
public Node ParentNode()
```

### 返回值

新的父节点，如果在 TreeWalker 的逻辑视图中当前节点没有父节点，则为 null。
