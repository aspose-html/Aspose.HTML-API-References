## ITreeWalker.FirstChild method

将 TreeWalker 移动到当前节点的第一个可见子节点，并返回该新节点。如果当前节点没有可见子节点，则返回 null，并保持当前节点不变。

```java
public Node FirstChild()
```

### 返回值

新节点；如果当前节点在 TreeWalker 的逻辑视图中没有可见子节点，则返回 null。
