## INodeIterator.Detach method

将 NodeIterator 与其遍历的集合分离，释放任何计算资源并将迭代器置于 INVALID 状态。调用 detach 后，调用 nextNode 或 previousNode 将抛出异常 INVALID_STATE_ERR。
