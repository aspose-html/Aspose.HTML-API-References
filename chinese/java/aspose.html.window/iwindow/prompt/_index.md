## IWindow.Prompt method

显示带有给定消息的模态文本字段提示框，等待用户关闭，并返回用户输入的值。如果用户取消提示，则返回 null。如果提供了第二个参数，则使用给定的值作为默认值。

```java
public String Prompt(String message, String @default)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| message | String | 信息。 |
| 默认 | String | 默认值。 |

### 返回值

返回用户输入的值
