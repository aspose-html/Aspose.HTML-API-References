## IWindow.Top property

在浏览上下文 b 中的文档的 Window 对象上的 top IDL 属性必须返回其顶层浏览上下文的 WindowProxy 对象（如果它本身是顶层浏览上下文，则为它自己的 WindowProxy 对象），如果有的话，否则返回它自己的 WindowProxy 对象（例如如果它是一个已分离的嵌套浏览上下文）。

```java
public IWindow Top { get; }
```
