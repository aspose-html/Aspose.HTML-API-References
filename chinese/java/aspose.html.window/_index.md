该 **com.aspose.html.window** 包与表示包含 DOM 文档的窗口的 window 对象相关。它包括与活动文档地址和浏览历史相关的类和接口。

## 类

| 类 | 描述 |
| --- | --- |
| [Location](./location/) | Location 对象提供其 Document 浏览上下文中活动文档地址的表示，并通过在历史对象中添加或替换条目来更改浏览上下文会话历史的当前条目。 |
| [MediaQueryList](./mediaquerylist/) | MediaQueryList 对象存储有关应用于文档的媒体查询的信息，支持对文档状态的即时匹配和事件驱动匹配。参见 CSSOM View Module 规范: [https://www.w3.org/TR/cssom-view/#the-mediaquerylist-interface](https://www.w3.org/TR/cssom-view/#the-mediaquerylist-interface) |
## 接口

| 接口 | 描述 |
| --- | --- |
| [IWindow](./iwindow/) | window 对象表示包含 DOM 文档的窗口。 |
| [IWindowEventHandlers](./iwindoweventhandlers/) | 表示必须被 window 对象继承的接口。 |
| [IWindowTimers](./iwindowtimers/) | 允许作者安排基于计时器的回调。 |
