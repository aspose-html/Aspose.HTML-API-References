该 **com.aspose.html.dom.attributes** 包包含统一的属性类，用于指定或限定任何对象（节点、元素等）的特性或行为。

## 类

| 类 | 描述 |
| --- | --- |
| [DOMConstructorAttribute](./domconstructorattribute/) | 指定由 W3C 定义的构造函数。 |
| [DOMNameAttribute](./domnameattribute/) | 指定由 W3C 定义的官方 DOM 对象名称。 |
| [DOMNamedPropertyGetterAttribute](./domnamedpropertygetterattribute/) | 指定该方法将用作具名属性的 getter。 |
| [DOMNoInterfaceObjectAttribute](./domnointerfaceobjectattribute/) | 如果在接口上出现 [NoInterfaceObject] 扩展属性，则表示在 ECMAScript 绑定中该接口不会有接口对象。 |
| [DOMNullableAttribute](./domnullableattribute/) | 指定可以为 DOM 对象分配 null 值。 |
| [DOMObjectAttribute](./domobjectattribute/) | 指定对象被此属性标记是由 W3C 定义的。 |
| [DOMTreatNullAsAttribute](./domtreatnullasattribute/) | 指示成员值的 null 将被视为指定的值。 |
## 枚举

| 枚举 | 描述 |
| --- | --- |
| [Accessors](./accessors/) | 表示由 W3C 定义的成员访问器的枚举。 |
