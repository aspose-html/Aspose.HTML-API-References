**com.aspose.html.rendering.pdf** 包提供特定的设备类以及负责渲染为 PDF 文档的少量渲染选项类。

## 类

| 类 | 描述 |
| --- | --- |
| [PdfDevice](./pdfdevice/) | 表示渲染为 PDF 文档。 |
| [PdfDocumentInfo](./pdfdocumentinfo/) | 表示 PDF 文档的信息。 |
| [PdfRenderingOptions](./pdfrenderingoptions/) | 表示 [`PdfDevice`](../com.aspose.html.rendering.pdf/pdfdevice/) 的渲染选项。 |
## 枚举

| 枚举 | 描述 |
| --- | --- |
| [FormFieldBehaviour](./formfieldbehaviour/) | 此枚举用于指定输出 PDF 文档中表单字段的行为。 |
