## TextSaveOptions.EnableListItemMarkers property

此选项在 HTML 转换为文本时应用于 OL、UL 元素。实际上它定义了如何处理 OL 和 UL 元素的外部列表标记。如果为 true，则在 OL 项目前添加项目编号，或在 UL 项目前添加点。如果为 false，则不添加（遵循规范的默认行为）。

```java
public bool EnableListItemMarkers { get; set; }
```
