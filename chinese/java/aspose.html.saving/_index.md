**com.aspose.html.saving** 包由用于描述转换/保存过程中特定保存选项的数据类组成。

## 类

| 类 | 描述 |
| --- | --- |
| [DocSaveOptions](./docsaveoptions/) | 特定选项数据类。通过分配属性，您可以管理渲染特性，例如分辨率、页面大小、背景颜色，以及文档特定选项，例如字体嵌入。更多信息请参阅文档 [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-docx/#save-options)。 |
| [HTMLSaveOptions](./htmlsaveoptions/) | 表示 HTML 保存选项。通过分配特定属性，您可以管理资源处理，例如最大处理深度等。更多信息请参阅文档 [article](https://docs.aspose.com/html/net/working-with-documents/saving-a-document/)。 |
| [ImageSaveOptions](./imagesaveoptions/) | 特定选项数据类。它提供属性以管理图像结果分辨率、平滑质量、格式以及页面设置等。更多信息请参阅文档 [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-jpg/#save-options)。 |
| [MarkdownSaveOptions](./markdownsaveoptions/) | 表示 Markdown 保存选项。例如，您可以设置 Markdown 格式样式，使用预定义的兼容 GitLab Flavored Markdown 的选项，并配置资源处理。更多信息请参阅 [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-markdown/#save-options)。 |
| [MHTMLSaveOptions](./mhtmlsaveoptions/) | 表示 MHTML 保存选项。通过分配特定属性，您可以管理资源处理，例如最大处理深度等。更多信息请参阅文档 [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-mhtml/#save-options)。 |
| [PdfSaveOptions](./pdfsaveoptions/) | 特定数据类提供少量属性以管理转换结果。例如 [`PageSetup`](../com.aspose.html.rendering/pagesetup/) 指定页面特性。请参阅文档 [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-pdf/#convert-html-to-pdf-using-pdfsaveoptions)。 |
| [Resource](./resource/) | 此类描述资源并提供处理该资源的方法。 |
| [ResourceHandlingContext](./resourcehandlingcontext/) | 此类包含在处理资源时使用的信息。 |
| [ResourceHandlingOptions](./resourcehandlingoptions/) | 表示资源处理选项。 |
| [SaveOptions](./saveoptions/) | 这是一个抽象基类，供允许用户在将文档保存为特定格式时指定附加选项的类使用。 |
| [TextSaveOptions](./textsaveoptions/) | 表示 Text 保存选项 |
| [XpsSaveOptions](./xpssaveoptions/) | 特定选项数据类提供少量属性以管理转换结果。例如 [`PageSetup`](../com.aspose.html.rendering/pagesetup/) 指定页面特性。请参阅文档 [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-xps/#save-options)。 |
## 枚举

| 枚举 | 描述 |
| --- | --- |
| [HTMLSaveFormat](./htmlsaveformat/) | 指定文档保存的格式。您可以在 [article](https://docs.aspose.com/html/net/working-with-documents/saving-a-document/) 中找到有关保存 [`HTMLDocument`](../com.aspose.html/htmldocument/) 的更多信息。 |
| [MarkdownFeatures](./markdownfeatures/) | 一个 [`MarkdownFeatures`](../com.aspose.html.saving/markdownfeatures/) 标志集合是零个或多个以下标志的集合，这些标志用于选择要转换为 markdown 的元素。 |
| [MarkdownFormatter](./markdownformatter/) | 指定输出的格式方式。 |
| [ResourceHandling](./resourcehandling/) | 此枚举表示资源处理选项。 |
| [ResourceStatus](./resourcestatus/) | 指示资源状态。 |
| [UrlRestriction](./urlrestriction/) | 此枚举表示对已处理资源的 URL 所施加的限制。 |
