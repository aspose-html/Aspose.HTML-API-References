El paquete **com.aspose.html.collections** está compuesto por clases para representar, almacenar y manipular nodos y elementos.

## Clases

| Clase | Descripción |
| --- | --- |
| [DOMTokenList](./domtokenlist/) | La clase DOMTokenList representa un conjunto de tokens separados por espacios. Está indexada comenzando en 0 al igual que los objetos Array de JavaScript. DOMTokenList siempre distingue entre mayúsculas y minúsculas. |
| [HTMLCollection](./htmlcollection/) | El [`HTMLCollection`](../com.aspose.html.collections/htmlcollection/) representa una colección genérica de [`Element`](../com.aspose.html.dom/element/). |
| [NamedNodeMap](./namednodemap/) | Representa colecciones de atributos que pueden accederse por nombre. |
| [NodeList](./nodelist/) | NodeList proporciona la abstracción de una colección ordenada de nodos, sin definir ni restringir cómo se implementa esta colección. |
