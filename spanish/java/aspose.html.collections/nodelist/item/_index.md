## NodeList indexer

El método devuelve el elemento en la posición índice de la colección. Si el índice es mayor o igual que el número de nodos en la lista, devuelve null.

```java
public abstract Node this[int index] { get; }
```

| Parámetro | Descripción |
| --- | --- |
| index | El índice. |

### Valor de retorno

Devuelve el nodo.
