## NodeList class

NodeList proporciona la abstracción de una colección ordenada de nodos, sin definir ni restringir cómo se implementa esta colección.

```java
public abstract class NodeList : DOMObject, IEnumerable<Node>
```

## Propiedades

| Nombre | Descripción |
| --- | --- |
| abstracto [getItem](../../com.aspose.html.collections/nodelist/item/) Método devuelve el elemento en la posición índice de la colección. Si el índice es mayor o igual que el número de nodos en la lista, esto devuelve null. |
| abstracto [getLength](../../com.aspose.html.collections/nodelist/length/) El número de nodos en la lista. |
