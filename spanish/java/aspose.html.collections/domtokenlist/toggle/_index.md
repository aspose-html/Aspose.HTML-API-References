## Toggle(String) {#toggle}

Elimina el token de la lista si existe, o agrega el token a la lista si no existe.

```java
public bool Toggle(String token)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| token | Cadena | El token que deseas alternar. |

### Valor devuelto

Un Booleano que indica si el token está en la lista después de la llamada.

## Toggle(String, bool) {#toggle_1}

Elimina el token de la lista si existe, o agrega el token a la lista si no existe.

```java
public bool Toggle(String token, bool force)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| token | Cadena | El token que deseas alternar. |
| force | Boolean | Un Booleano que, si se incluye, convierte la alternancia en una operación unidireccional. Si se establece en false, el token solo se eliminará, pero no se añadirá. Si se establece en true, el token solo se añadirá, pero no se eliminará. |

### Valor devuelto

Un Booleano que indica si el token está en la lista después de la llamada.
