## DOMTokenList indexer

Devuelve el elemento de la lista por su índice, o null si el índice es mayor o igual a la longitud de la lista.

```java
public String this[uint index] { get; }
```

| Parámetro | Descripción |
| --- | --- |
| index | El índice. |

### Valor de retorno

Una cadena que representa un token en la lista.
