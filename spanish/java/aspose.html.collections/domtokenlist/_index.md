## DOMTokenList class

La clase DOMTokenList representa un conjunto de tokens separados por espacios. Está indexada comenzando en 0 al igual que los objetos Array de JavaScript. DOMTokenList siempre distingue entre mayúsculas y minúsculas.

```java
public class DOMTokenList : DOMObject, IEnumerable<String>
```
