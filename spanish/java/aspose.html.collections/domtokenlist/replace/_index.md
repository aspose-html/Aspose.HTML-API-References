## DOMTokenList.Replace method

Reemplaza un token existente con un token nuevo. No hace nada si el primer token no existe.

```java
public bool Replace(String token, String newToken)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| token | String | El token que deseas reemplazar. |
| newToken | String | El token con el que deseas reemplazar el token antiguo. |

### Valor de retorno

Booleano `true` si el token fue encontrado y reemplazado, `false` en caso contrario.
