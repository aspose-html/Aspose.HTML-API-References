## NamedNodeMap.SetNamedItemNS method

Agrega un nodo usando su packageURI y localName. Si ya existe un nodo con ese URI de paquete y ese nombre local en este mapa, se reemplaza por el nuevo. Reemplazar un nodo por sí mismo no tiene efecto.

```java
public Attr SetNamedItemNS(Attr attr)
```

| Parámetro | Tipo | Descripción |

| attr | Attr | El atributo. |

### Valor de retorno
