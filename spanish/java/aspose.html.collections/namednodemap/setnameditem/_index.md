## NamedNodeMap.SetNamedItem method

Agrega un nodo usando su atributo nodeName. Si ya existe un nodo con ese nombre en este mapa, se reemplaza por el nuevo. Reemplazar un nodo por sí mismo no tiene efecto.

```java
public Attr SetNamedItem(Attr attr)
```

| attr | Attr | El atributo. |
