## NamedNodeMap class

Representa colecciones de atributos que pueden accederse por nombre.

```java
public class NamedNodeMap : DOMObject
```

## Propiedades

| Nombre | Descripción |
| --- | --- |
| [getItem](../../com.aspose.html.collections/namednodemap/item/) Devuelve el elemento en la posición índice del mapa. Si el índice es mayor o igual que el número de nodos en este mapa, devuelve null. (2 indexadores) |
| [getLength](../../com.aspose.html.collections/namednodemap/length/) El número de nodos en este mapa. |

## Métodos
