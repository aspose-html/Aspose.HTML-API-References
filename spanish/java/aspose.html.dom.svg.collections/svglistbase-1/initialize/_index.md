## SVGListBase&lt;T&gt;.Initialize method

Elimina todos los elementos actuales existentes de la lista y vuelve a inicializar la lista para contener el único elemento especificado por el parámetro.

```java
public T Initialize(T newItem)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| newItem | T | El elemento que debe convertirse en el único miembro de la lista. |

### Valor devuelto

El elemento que se está insertando en la lista.
