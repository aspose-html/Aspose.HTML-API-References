## ITextureBrush interface

Define la interfaz de pincel que utiliza una imagen para rellenar el interior de una forma.

```java
public interface ITextureBrush : ITransformableBrush
```

## Propiedades

| Nombre | Descripción |
| --- | --- |
| [getColorMap](../../com.aspose.html.drawing/itexturebrush/colormap/) El número de elementos debe ser par. Cada elemento par es el color antiguo. Cada elemento impar es el color nuevo. |
| [getImage](../../com.aspose.html.drawing/itexturebrush/image/) Obtiene o establece la imagen utilizada por el pincel. |
| [getImageArea](../../com.aspose.html.drawing/itexturebrush/imagearea/) Especifica la porción de la imagen utilizada por el pincel. Si es igual a RectangleF.Empty, entonces se usará la imagen completa. Las coordenadas están en píxeles. |

[setOpacity] Get opacity value in a color transform matrix. |
