## ITextureBrush.ImageArea property

Especifica la porción de la imagen utilizada por el pincel. Si es igual a RectangleF.Empty entonces se utilizará la imagen completa. Las coordenadas están en píxeles.

```java
public RectangleF ImageArea { get; }
```

### Valor de retorno

Área de imagen
