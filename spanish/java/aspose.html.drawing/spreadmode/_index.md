## SpreadMode enumeration

Especifica cómo se repite una textura o degradado cuando es más pequeña que el área a rellenar.

```java
public enum SpreadMode
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Tile | `0` | La textura o degradado se repite. |
| TileFlipX | `1` | La textura o degradado se repite y se voltea horizontalmente. |
| TileFlipY | `2` | La textura o degradado se repite y se voltea verticalmente. |
| TileFlipXY | `3` | La textura o degradado se repite y se voltea tanto horizontalmente como verticalmente. |
| Clamp | `4` | La textura o degradado está limitada al borde. |
