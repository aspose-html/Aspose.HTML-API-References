## ITrueTypeFont.FullFontName property

Esto debe ser una combinación de "FamilyName" y "SubFamilyName". Excepción: si la fuente es "Regular" según lo indicado en "SubFamilyName", entonces use solo el nombre de familia contenido en "FamilyName". Una excepción a la definición anterior de Full font name es para las cadenas de la plataforma Microsoft de fuentes CFF OpenType: en este caso, la cadena Full font name debe ser idéntica al PostScript FontName en el CFF Name INDEX.

```java
public String FullFontName { get; }
```
