## ITrueTypeFont.FullFontName property

Esto debe ser una combinación de "FamilyName" y "SubFamilyName". Excepción: si la fuente es "Regular" según lo indicado en "SubFamilyName", entonces use solo el nombre de familia contenido en "FamilyName". Una excepción a la definición anterior del nombre completo de la fuente es para las cadenas de la plataforma Microsoft de fuentes OpenType CFF: en este caso, la cadena del nombre completo de la fuente debe ser idéntica al FontName PostScript en el CFF Name INDEX.

```java
public String FullFontName { get; }
```

### Valor de retorno

Nombre completo de la fuente
