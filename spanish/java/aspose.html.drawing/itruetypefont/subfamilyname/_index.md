## ITrueTypeFont.SubFamilyName property

El nombre de subfamilia de fuente distingue la fuente en un grupo con el mismo nombre de familia de fuente. Se supone que esto aborda el estilo (cursiva, oblicua) y el peso (ligero, negrita, negro, etc.). Una fuente sin diferencias particulares en peso o estilo (p. ej., peso medio, no cursiva y con el bit 6 de fsSelection activado) debería tener la cadena "Regular" almacenada en esta posición.

```java
public String SubFamilyName { get; }
```

### Valor de retorno

Nombre de subfamilia de fuente
