El paquete **com.aspose.html.drawing** contiene objetos e interfaces para especificar medidas y unidades, así como objetos de atributos de dibujo como pinceles, colores y fuentes.

## Clases

| Clase | Descripción |
| --- | --- |
| [Angle](./angle/) | El tipo de dato ángulo |
| [Color](./color/) | La clase Color le permite especificar colores como valores Rojo-Verde-Azul (RGB), valores de Matiz-Saturación-Luminancia (HSL), valores de Matiz-Saturación-Valor (HSV), valores de Matiz-Blancura-Negrura (HWB), valores de luminosidad-A-B (LAB), valores de Luminancia-Croma-Matiz (LCH), valores de Cian-Magenta-Amarillo-Clave (CMYK), valores de colores naturales (NCOL), o con un nombre de color. También está disponible un canal Alfa para indicar transparencia. |
| [Dimension](./dimension/) | Proporciona la clase base para dimensiones. El término general 'dimensión' se refiere a un número con una unidad adjunta, y se denota mediante [`UnitType`](../com.aspose.html.drawing/unittype/). |
| [Frequency](./frequency/) | La unidad 'frequency'. |
| [Length](./length/) | Representa una unidad de medida de longitud. |
| [LengthOrAuto](./lengthorauto/) | Representa un contenedor para almacenar longitudes o unidades 'auto'.. |
| [Margin](./margin/) | Representa el margen de página. |
| [Numeric](./numeric/) | Proporciona la clase base para tipos numéricos. |
| [Page](./page/) | Representa un objeto de página que se utiliza para la configuración de la página de salida. El valor lacuna para el tamaño de página es A4(210x297mm) |
| [Resolution](./resolution/) | Representa una unidad de resolución. |
| [Size](./size/) | Almacena valores que especifican una altura y anchura. |
| [Time](./time/) | Representa una unidad de tiempo. |
| [Unit](./unit/) | Proporciona la clase base para unidades de medida. |
| [UnitType](./unittype/) | Especifica la unidad de medida. |
## Interfaces

| Interfaz | Descripción |
| --- | --- |
| [IBrush](./ibrush/) | Declara el método para obtener el tipo de pincel. |
| [IColorComponents](./icolorcomponents/) | Declara el método y las propiedades para procesar componentes de color. |
| [IDrawingFactory](./idrawingfactory/) | Representa una fábrica para crear objetos relacionados con el dibujo. |
| [IGradientBrush](./igradientbrush/) | Declare métodos para obtener propiedades comunes de los pinceles degradados. |
| [IInterpolationColor](./iinterpolationcolor/) | Declara métodos para obtener el color de interpolación. |
| [ILinearGradientBrush](./ilineargradientbrush/) | Define la interfaz de pincel con un degradado lineal. |
| [IMatrix](./imatrix/) | Representa una matriz utilizada para transformaciones. |
| [ISolidBrush](./isolidbrush/) | Define la interfaz de pincel de un solo color. |
| [ITextureBrush](./itexturebrush/) | Define la interfaz de pincel que utiliza una imagen para rellenar el interior de una forma. |
| [ITransformableBrush](./itransformablebrush/) | Declara métodos para obtener la matriz de transformación y el modo de ajuste. |
| [ITrueTypeFont](./itruetypefont/) | Declara métodos para trabajar con fuentes TrueType. |
