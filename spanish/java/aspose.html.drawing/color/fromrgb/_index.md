## FromRgb(byte, byte, byte) {#fromrgb}

Devuelve un nuevo Color con los valores solicitados de ged, verde, azul. Todos los componentes de color deben estar en el rango 0-255.

```java
public static Color FromRgb(byte red, byte green, byte blue)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| rojo | Byte | Un byte que representa el componente rojo del color. |
| verde | Byte | Un byte que representa el componente verde del color. |
| azul | Byte | Un byte que representa el componente azul del color. |
