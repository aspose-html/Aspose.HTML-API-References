## Color.ToNaturalColorString method

Devuelve un color Natural (NCol) especificado usando una letra de color con un número para indicar la distancia (en porcentaje) del color.

```java
public String ToNaturalColorString(int digits)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| digits | Int32 | Establece la precisión de redondeo para los componentes de color. |

### Valor devuelto

Una cadena de colores naturales (NCol) String
