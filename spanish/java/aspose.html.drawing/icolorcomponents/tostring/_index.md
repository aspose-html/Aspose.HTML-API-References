## IColorComponents.ToString method

Convierte los componentes de color a una representación de cadena.

```java
public String ToString(bool includeAlpha, bool asDecimal, int digits)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| includeAlpha | Boolean | Especifica si se debe agregar el componente Alpha. |
| asDecimal | Boolean | Especifica si los componentes de color se conservan como número decimal o como porcentaje. |
| digits | Int32 | Establece la precisión de redondeo para los componentes de color. |

### Valor de retorno

Representación en cadena de los componentes de color.
