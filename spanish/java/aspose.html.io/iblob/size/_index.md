## IBlob.Size property

Devuelve el tamaño de la secuencia de bytes en número de bytes. Al obtenerla, los agentes de usuario conformes deben devolver el número total de bytes que pueden ser leídos por un objeto FileReader o FileReaderSync, o 0 si el Blob no tiene bytes para leer.

```java
public ulong Size { get; }
```
