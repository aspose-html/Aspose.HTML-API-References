## IFile.LastModified property

La fecha de última modificación del archivo. Al obtenerla, si los agentes de usuario pueden proporcionar esta información, debe devolver un long long establecido al momento en que el archivo fue modificado por última vez, como el número de milisegundos transcurridos desde la época Unix.

```java
public long LastModified { get; }
```
