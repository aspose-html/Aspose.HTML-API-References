## IUserAgentService.ShowImagePlaceholders property

Las imágenes pueden tener contenido de respaldo: contenido que debe usarse cuando un recurso externo no puede ser utilizado (por ejemplo, porque está en un formato no compatible). La propiedad `ShowImagePlaceholders` especifica si se debe mostrar la imagen de respaldo (el valor predeterminado es true).

```java
public bool ShowImagePlaceholders { get; set; }
```
