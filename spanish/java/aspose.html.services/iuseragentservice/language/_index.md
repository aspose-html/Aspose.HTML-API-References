## IUserAgentService.Language property

El `Language` especifica el idioma principal para el contenido del elemento y para cualquiera de los atributos del elemento que contengan texto. Su valor debe ser una etiqueta de idioma BCP 47 válida, o la cadena vacía. Establecer el atributo a la cadena vacía indica que el idioma principal es desconocido.

```java
public String Language { get; set; }
```

### Property Value

El idioma del agente de usuario.
