El paquete **com.aspose.html.services** contiene interfaces como protocolos para implementaciones de servicios.

## Interfaces

| Interfaz | Descripción |
| --- | --- |
| [IDeviceInformationService](./ideviceinformationservice/) | Una interfaz que describe un entorno en el que [`Document`](../com.aspose.html.dom/document/) se presenta al usuario. |
| [INetworkService](./inetworkservice/) | Proporciona una interfaz para las operaciones de red. |
| [IRuntimeService](./iruntimeservice/) | Este servicio se utiliza para configurar propiedades relacionadas con el tiempo de ejecución. |
| [IUserAgentService](./iuseragentservice/) | Una interfaz que describe un entorno de agente de usuario. |
