## IRuntimeService.JavaScriptTimeout property

Obtiene o establece TimeSpan que limita el tiempo de ejecución de JavaScript. Si el script se ejecuta más tiempo que el TimeSpan proporcionado, será cancelado. Puede especificar un tiempo de espera infinito estableciendo TimeSpan en -1 milisegundo. El valor predeterminado es 1 minuto.

```java
public TimeSpan JavaScriptTimeout { get; set; }
```
