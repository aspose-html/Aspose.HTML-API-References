## IDocumentEvent interface

La interfaz DocumentEvent proporciona un mecanismo mediante el cual el usuario puede crear un Event de un tipo soportado por la implementación. Se espera que la interfaz DocumentEvent se implemente en el mismo objeto que implementa la interfaz Document en una implementación que soporta el modelo de eventos.

```java
public interface IDocumentEvent
```

## Observaciones

Se espera que la interfaz se implemente en el mismo objeto que implementa la interfaz en una implementación que soporta el modelo de eventos.
