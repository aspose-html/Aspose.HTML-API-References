## InputEvent.Data property

Los datos contienen el valor de los caracteres generados por un método de entrada. Esto PUEDE ser un solo carácter Unicode o una secuencia no vacía de caracteres Unicode [Unicode]. Los caracteres DEBERÍAN ser normalizados según la forma de normalización Unicode NFC, definida en [UAX15]. Este atributo PUEDE contener la cadena vacía.

```java
public String Data { get; }
```

### Property Value

Los datos del evento.
