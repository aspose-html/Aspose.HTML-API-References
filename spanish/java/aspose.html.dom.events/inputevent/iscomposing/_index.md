## InputEvent.IsComposing property

true si el evento de entrada ocurre como parte de una sesión de composición, es decir, después de un evento compositionstart y antes del evento compositionend correspondiente. El valor no inicializado de este atributo DEBE ser false.

```java
public bool IsComposing { get; }
```

### Property Value

`true` si esta instancia está componiendo; de lo contrario, `false`.
