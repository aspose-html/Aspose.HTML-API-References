## ErrorEvent.FileName property

El atributo filename debe devolver el valor con el que se inicializó. Cuando se crea el objeto, este atributo debe inicializarse a la cadena vacía. Representa la URL absoluta del script en el que el error se produjo originalmente.

```java
public String FileName { get; }
```

### Property Value

El nombre de archivo.
