## ErrorEvent.Error property

El atributo error debe devolver el valor con el que se inicializó. Cuando se crea el objeto, este atributo debe inicializarse a null. Cuando corresponda, se establece al objeto que representa el error (p. ej., el objeto de excepción en el caso de una excepción DOM no capturada).

```java
public object Error { get; }
```

### Property Value

El error.
