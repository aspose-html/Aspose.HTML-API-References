## ErrorEvent.LineNo property

El atributo lineno debe devolver el valor con el que se inicializó. Cuando se crea el objeto, este atributo debe inicializarse a cero. Representa el número de línea donde ocurrió el error en el script.

```java
public uint LineNo { get; }
```
