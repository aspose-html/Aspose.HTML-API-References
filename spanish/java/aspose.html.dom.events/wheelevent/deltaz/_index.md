## WheelEvent.DeltaZ property

En agentes de usuario donde la acción predeterminada del evento de rueda es desplazar, el valor DEBE ser la medida a lo largo del eje z (en píxeles, líneas o páginas) que se desplazará en caso de que el evento no sea cancelado. De lo contrario, esta es una medida específica de la implementación (en píxeles, líneas o páginas) del movimiento de un dispositivo de rueda alrededor del eje z.

```java
public double DeltaZ { get; }
```

El atributo deltaZ.
