## WheelEvent.DeltaY property

En los agentes de usuario donde la acción predeterminada del evento wheel es desplazar, el valor DEBE ser la medida a lo largo del eje y (en píxeles, líneas o páginas) que se desplazará en caso de que el evento no sea cancelado. De lo contrario, esta es una medida específica de la implementación (en píxeles, líneas o páginas) del movimiento de un dispositivo de rueda alrededor del eje y.

```java
public double DeltaY { get; }
```

### Property Value

El atributo deltaY.
