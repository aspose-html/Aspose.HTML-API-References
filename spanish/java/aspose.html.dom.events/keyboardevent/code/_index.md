## KeyboardEvent.Code property

El código contiene una String que identifica la tecla física que se está presionando. El valor no se ve afectado por la distribución de teclado actual o el estado de los modificadores, por lo que una tecla particular siempre devolverá el mismo valor.

```java
public String Code { get; }
```

### Property Value

El código de tecla.
