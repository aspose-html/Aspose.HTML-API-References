## KeyboardEvent.DOM_KEY_LOCATION_NUMPAD field

La activación de la tecla se originó en el teclado numérico o con una tecla virtual correspondiente al teclado numérico (cuando hay más de una ubicación posible para esta tecla). Tenga en cuenta que la tecla NumLock siempre debe codificarse con una ubicación de DOM_KEY_LOCATION_STANDARD.

```java
public const ulong DOM_KEY_LOCATION_NUMPAD;
```
