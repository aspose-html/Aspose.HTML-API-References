## KeyboardEvent.DOM_KEY_LOCATION_STANDARD field

La activación de la tecla NO DEBE distinguirse como la versión izquierda o derecha de la tecla, y (excepto la tecla NumLock) no se originó en el teclado numérico (o no se originó con una tecla virtual correspondiente al teclado numérico).

```java
public const ulong DOM_KEY_LOCATION_STANDARD;
```
