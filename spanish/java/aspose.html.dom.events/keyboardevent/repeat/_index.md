## KeyboardEvent.Repeat property

true si la tecla ha sido presionada de manera sostenida. Mantener una tecla presionada DEBE resultar en la repetición de los eventos keydown, beforeinput, input en este orden, a una velocidad determinada por la configuración del sistema. Para dispositivos móviles que tienen comportamiento de pulsación larga, el primer evento de tecla con un valor de atributo repeat de true DEBE servir como indicación de una pulsación larga. El tiempo que la tecla DEBE estar presionada para comenzar a repetirse depende de la configuración.

```java
public bool Repeat { get; }
```

### Property Value

`true` si repeat; de lo contrario, `false`.
