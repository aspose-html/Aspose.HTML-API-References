## KeyboardEvent.Repeat property

true si la tecla ha sido presionada de forma sostenida. Mantener una tecla pulsada DEBE resultar en la repetición de los eventos keydown, beforeinput e input en este orden, a una velocidad determinada por la configuración del sistema. En dispositivos móviles con comportamiento de pulsación larga, el primer evento de tecla con el atributo repeat con valor true DEBE servir como indicación de una pulsación larga. El tiempo que la tecla DEBE estar presionada para comenzar a repetirse depende de la configuración.

```java
public bool Repeat { get; }
```

### Property Value

`true` si repeat; de lo contrario, `false`.
