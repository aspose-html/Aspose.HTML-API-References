## KeyboardEvent.Key property

La tecla contiene el valor de la tecla presionada. Si el valor tiene una representación impresa, DEBE ser una cadena de caracteres Unicode no vacía, cumpliendo con el algoritmo para determinar el valor de la tecla definido en esta especificación. Si el valor es una tecla de control que no tiene representación impresa, DEBE ser uno de los valores de tecla definidos en el conjunto de valores de tecla, según el algoritmo para determinar el valor de la tecla. Las implementaciones que no puedan identificar una tecla DEBEN usar el valor de tecla Unidentified.

```java
public String Key { get; }
```

### Property Value

El valor de la tecla.
