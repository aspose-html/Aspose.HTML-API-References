## Event.IsTrusted property

El atributo isTrusted debe devolver el valor con el que se inicializó. Cuando se crea un evento, el atributo debe inicializarse en false.

```java
public bool IsTrusted { get; }
```

### Property Value

`true` si esta instancia es confiable; de lo contrario, `false`.
