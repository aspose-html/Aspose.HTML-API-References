## Event.TimeStamp property

Se usa para especificar el tiempo (en milisegundos relativo a la época) en que se creó el evento. Debido a que algunos sistemas pueden no proporcionar esta información, el valor de timeStamp puede no estar disponible para todos los eventos. Cuando no esté disponible, se devolverá un valor de 0. Ejemplos de tiempo de época son el momento del inicio del sistema o 0:0:0 UTC 1 de enero de 1970.

```java
public ulong TimeStamp { get; }
```
