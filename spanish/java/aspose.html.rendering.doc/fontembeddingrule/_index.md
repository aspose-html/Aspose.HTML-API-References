## FontEmbeddingRule enumeration

Representa las reglas de incrustación de fuentes.

```java
public enum FontEmbeddingRule
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Full | `1` | Todas las fuentes utilizadas se incrustarán tal cual. Tenga en cuenta que alguna fuente podría estar licenciada, lo que hará que el documento resultante no sea editable. Además, los archivos de fuentes incrustados podrían aumentar significativamente el tamaño del documento resultante. |
| None | `2` | Las fuentes no se incrustarán. |
