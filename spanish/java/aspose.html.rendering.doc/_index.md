El paquete **com.aspose.html.rendering.doc** proporciona una clase de dispositivo específica, así como algunas clases de opciones de renderizado responsables de renderizar a un documento DOCX.

## Clases

| Clase | Descripción |
| --- | --- |
| [DocDevice](./docdevice/) | Representa el renderizado a un documento DOCX. |
| [DocRenderingOptions](./docrenderingoptions/) | Representa las opciones de renderizado para [`DocDevice`](../com.aspose.html.rendering.doc/docdevice/). |
## Enumeración

| Enumeración | Descripción |
| --- | --- |
| [DocumentFormat](./documentformat/) | Representa el formato de archivo del documento de salida. |
| [FontEmbeddingRule](./fontembeddingrule/) | Representa las reglas de incrustación de fuentes. |
