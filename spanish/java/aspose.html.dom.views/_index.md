**com.aspose.html.dom.views** package describes AbstractView and DocumentView interfaces according Document Object Model Views specification.

## Interfaces

| Interfaz | Descripción |
| --- | --- |
| [IAbstractView](./iabstractview/) | Una interfaz base de la que todas las vistas deben derivar. |
| [IDocumentView](./idocumentview/) | La interfaz DocumentView es implementada por objetos Document en implementaciones DOM que soportan DOM Views. Proporciona un atributo para obtener la vista predeterminada de un documento. |
