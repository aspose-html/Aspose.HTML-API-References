El paquete **com.aspose.html.dom.attributes** contiene clases de atributos unificados que especifican o califican cualquier característica o comportamiento de un objeto (nodo, elemento, ...).

## Clases

| Clase | Descripción |
| --- | --- |
| [DOMConstructorAttribute](./domconstructorattribute/) | Especifica un constructor que está definido por el W3C. |
| [DOMNameAttribute](./domnameattribute/) | Especifica el nombre oficial del objeto DOM tal como lo define el W3C. |
| [DOMNamedPropertyGetterAttribute](./domnamedpropertygetterattribute/) | Especifica que el método se usará como getter de propiedad nombrada. |
| [DOMNoInterfaceObjectAttribute](./domnointerfaceobjectattribute/) | Si el atributo extendido [NoInterfaceObject] aparece en una interfaz, indica que no existirá un objeto de interfaz para la interfaz en el enlace ECMAScript. |
| [DOMNullableAttribute](./domnullableattribute/) | Especifica que a un objeto DOM se le puede asignar un valor nulo. |
| [DOMObjectAttribute](./domobjectattribute/) | Especifica que el objeto marcado con este atributo está definido por el W3C. |
| [DOMTreatNullAsAttribute](./domtreatnullasattribute/) | Indica que el valor nulo del miembro se tratará como el valor especificado. |
## Enumeración

| Enumeración | Descripción |
| --- | --- |
| [Accessors](./accessors/) | Representa la enumeración de accesores de miembros que está definida por el W3C. |
