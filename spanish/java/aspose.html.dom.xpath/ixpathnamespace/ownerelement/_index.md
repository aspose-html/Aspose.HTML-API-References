## IXPathNamespace.OwnerElement property

El [`Element`](../../../com.aspose.html.dom/element/) en el que el paquete estaba en alcance cuando se solicitó. Esto no cambia en un nodo de paquete devuelto incluso si el documento cambia de manera que el paquete quede fuera de alcance en ese elemento y este nodo ya no se encuentre allí mediante XPath.
