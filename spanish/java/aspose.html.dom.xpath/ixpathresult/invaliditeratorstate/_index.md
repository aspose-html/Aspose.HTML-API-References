## IXPathResult.InvalidIteratorState property

Indica que el iterador se ha vuelto inválido. Verdadero si `resultType` es de tipo `UnorderedNodeIterator` o `OrderedNodeIterator` y el documento ha sido modificado desde que se devolvió este resultado.

```java
public bool InvalidIteratorState { get; }
```
