El paquete representa la funcionalidad de filtrado de nodos. Los filtros son objetos que saben cómo "filtrar" nodos. Si a un iterador de nodos o caminante de árbol se le proporciona un filtro de nodos, aplica el filtro antes de devolver el siguiente nodo. Si el filtro indica aceptar el nodo, la lógica de recorrido lo devuelve; de lo contrario, el recorrido busca el siguiente nodo y finge que el nodo rechazado no estaba.
