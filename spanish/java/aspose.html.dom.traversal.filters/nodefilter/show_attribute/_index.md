## NodeFilter.SHOW_ATTRIBUTE field

Mostrar nodos Attr. Esto solo tiene sentido al crear un iterador o tree-walker con un nodo de atributo como raíz; en este caso, significa que el nodo de atributo aparecerá en la primera posición de la iteración o recorrido. Dado que los atributos nunca son hijos de otros nodos, no aparecen al recorrer el árbol del documento.

```java
public const long SHOW_ATTRIBUTE;
```
