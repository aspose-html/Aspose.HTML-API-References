## NodeFilter.SHOW_ENTITY field

Mostrar nodos Entity. Esto solo tiene sentido al crear un iterador o tree-walker con un nodo Entity como raíz; en este caso, significa que el nodo Entity aparecerá en la primera posición del recorrido. Dado que las entidades no forman parte del árbol del documento, no aparecen al recorrer el árbol del documento.

```java
public const long SHOW_ENTITY;
```
