## NodeFilter.FILTER_SKIP field

Omitir este nodo único. Los métodos de navegación definidos para NodeIterator o TreeWalker no devolverán este nodo. Tanto para NodeIterator como para TreeWalker, los hijos de este nodo seguirán siendo considerados.

```java
public const short FILTER_SKIP;
```
