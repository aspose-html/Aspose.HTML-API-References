## FillRule enumeration

Especifica la regla de relleno utilizada en el renderizado de SVG y HTML.

```java
public enum FillRule
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| EvenOdd | `0` | Determina el área de relleno usando la regla de par-impar. El comportamiento corresponde a System.Drawing.Drawing2D.FillMode.Alternate. |
| Nonzero | `1` | Determina el área de relleno usando la regla de no-cero. El comportamiento corresponde a System.Drawing.Drawing2D.FillMode.Winding. |
