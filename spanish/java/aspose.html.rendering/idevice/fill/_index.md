## IDevice.Fill method

Rellena toda la región delimitada por la ruta actual. Si la ruta consta de varios subtrazos desconectados, rellena el interior de todos los subtrazos, considerados en conjunto. Este método finaliza la ruta actual.

```java
public void Fill(FillRule rule)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| regla | FillRule | La regla de relleno especifica cómo se rellena el interior de una ruta cerrada |
