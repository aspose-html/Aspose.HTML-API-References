## Device&lt;TGraphicContext,TRenderingOptions&gt;.Fill method

Rellena toda la región delimitada por la ruta actual. Si la ruta consta de varios subtrazados desconectados, rellena el interior de todos los subtrazados, considerados en conjunto. Este método finaliza la ruta actual.

```java
public void Fill(FillRule rule)
```

| Parámetro | Tipo | Descripción |

| regla | FillRule | La regla de relleno especifica cómo se rellena el interior de una ruta cerrada |
