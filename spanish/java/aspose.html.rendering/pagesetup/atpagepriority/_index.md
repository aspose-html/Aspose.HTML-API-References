## PageSetup.AtPagePriority property

Obtiene o establece [`AtPagePriority`](../../atpagepriority/) que determinará el orden de aplicación de las declaraciones de tamaño de página. Por defecto, las opciones sobrescribirán las reglas css `@page`.

```java
public AtPagePriority AtPagePriority { get; set; }
```
