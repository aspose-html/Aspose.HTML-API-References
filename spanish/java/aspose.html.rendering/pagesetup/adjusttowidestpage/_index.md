## PageSetup.AdjustToWidestPage property

Obtiene o establece una bandera que determina el caso en que el tamaño de página se ajustará a la página más ancha del documento. Esta opción consume mucho tiempo, por lo que el tiempo de procesamiento del documento puede duplicarse. El ajuste se realizará solo si la página más ancha del documento es más ancha que el tamaño de página determinado en [`PageSetup`](../). El tamaño de página ajustado se usará para todas las páginas del documento.

```java
public bool AdjustToWidestPage { get; set; }
```
