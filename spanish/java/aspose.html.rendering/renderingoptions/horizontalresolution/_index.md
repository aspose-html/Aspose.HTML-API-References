## RenderingOptions.HorizontalResolution property

Establece o obtiene la resolución horizontal para imágenes internas (que se usan durante el procesamiento de filtros), en píxeles por pulgada. Por defecto, esta propiedad es 300 dpi.

```java
public Resolution HorizontalResolution { get; set; }
```
