El paquete **com.aspose.html.rendering** consta de numerosos objetos renderizadores, así como de clases de opciones de bajo nivel apropiadas que son responsables de renderizar documentos/archivos en una implementación de IDevice.

## Clases

| Clase | Descripción |
| --- | --- |
| [CssOptions](./cssoptions/) | Representa opciones de renderizado CSS. |
| [Device](./device/) | Representa una clase base para implementar dispositivos de renderizado que se utilizan para dibujar gráficos en varios formatos y entornos. |
| [Device&lt;TGraphicContext,TRenderingOptions&gt;](./device-2/) | Representa la clase base para la implementación de dispositivos de renderizado particulares. |
| [EpubRenderer](./epubrenderer/) | Representa un renderizador de documentos EPub. |
| [GraphicContext](./graphiccontext/) | Mantiene los parámetros de control gráfico actuales. Estos parámetros definen el marco global dentro del cual se ejecutan los operadores gráficos. |
| [HtmlRenderer](./htmlrenderer/) | Representa un renderizador de documentos HTML. |
| [MhtmlRenderer](./mhtmlrenderer/) | Representa un renderizador de documentos MHTML. |
| [PageSetup](./pagesetup/) | Representa un objeto de configuración de página que se utiliza para la configuración de la salida del conjunto de páginas. |
| [Renderer](./renderer/) | Representa una clase base para todos los renderizadores e implementa la interfaz IDisposable. |
| [Renderer&lt;TSource&gt;](./renderer-1/) | Representa una clase abstracta para todos los renderizadores. |
| [RenderingOptions](./renderingoptions/) | Representa opciones de renderizado. |
| [SvgRenderer](./svgrenderer/) | Representa un renderizador de documentos SVG. |
| [TextInfo](./textinfo/) | Contiene información sobre el texto renderizado. |
## Structures

| Estructura | Descripción |
| --- | --- |
| [GlyphInfo](./glyphinfo/) | Contiene información relacionada con glifos. |
## Interfaces

| Interfaz | Descripción |
| --- | --- |
| [IDevice](./idevice/) | Define métodos y propiedades que soportan el renderizado personalizado de los elementos gráficos como rutas, texto e imágenes. |
## Enumeración

| Enumeración | Descripción |
| --- | --- |
| [AtPagePriority](./atpagepriority/) | Especifica los posibles órdenes de aplicación de declaraciones de tamaño de página. |
| [FillRule](./fillrule/) | Especifica la regla de relleno utilizada en el renderizado de SVG y HTML. |
| [MediaType](./mediatype/) | Especifica los tipos de medios posibles utilizados durante el renderizado. |
| [PageLayoutOptions](./pagelayoutoptions/) | Especifica banderas que, junto con otras opciones de PageSetup, determinan los tamaños y disposiciones de las páginas. Estas banderas pueden combinarse según sus descripciones. |
| [StrokeLineCap](./strokelinecap/) | Especifica el extremo de línea utilizado en el renderizado de SVG y HTML. |
| [StrokeLineJoin](./strokelinejoin/) | Especifica el estilo de unión de línea utilizado en el renderizado de SVG y HTML. |
