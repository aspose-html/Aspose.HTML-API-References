## AtPagePriority enumeration

Especifica los posibles órdenes de aplicación de declaraciones de tamaño de página.

```java
public enum AtPagePriority
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| OptionsPriority | `0` | Especifica que los valores de [`PageSetup`](../pagesetup/) declarados en [`RenderingOptions`](../renderingoptions/) sobrescribirán los valores definidos en CSS mediante reglas `@page`. |
| CssPriority | `1` | Especifica que las reglas `@page` definidas en CSS sobrescribirán los valores definidos en [`PageSetup`](../pagesetup/). |
