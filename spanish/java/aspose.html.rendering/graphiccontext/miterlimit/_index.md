## GraphicContext.MiterLimit property

Establece o obtiene la longitud máxima de las uniones en inglete de líneas para rutas trazadas. Este parámetro limita la longitud de los \"picos\" que se producen cuando los segmentos de línea se unen en ángulos agudos.

```java
public float MiterLimit { get; set; }
```
