## SVGMarkerElement.OrientAngle property

Corresponde al atributo ‘orient’ en el elemento ‘marker’ dado. Si markerUnits es SVG_MARKER_ORIENT_ANGLE, el valor del ángulo para el atributo ‘orient’; de lo contrario, se establecerá a cero.

```java
public SVGAnimatedAngle OrientAngle { get; }
```

### Property Value

El atributo ‘orient’ del elemento ‘marker’ dado.
