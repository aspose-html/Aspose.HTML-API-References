## ISVGAnimatedPoints interface

La interfaz SVGAnimatedPoints admite elementos que tienen un atributo ‘points’ que contiene una lista de valores de coordenadas y que soportan la capacidad de animar ese atributo. Además, el atributo ‘points’ en el elemento original accedido a través del XML DOM (p. ej., usando la llamada al método getAttribute()) reflejará cualquier cambio realizado en los puntos.

```java
public interface ISVGAnimatedPoints
```

## Propiedades

| Nombre | Descripción |
| --- | --- |
| [getAnimatedPoints](../../com.aspose.html.dom.svg/isvganimatedpoints/animatedpoints/) Proporciona acceso al contenido animado actual del atributo ‘points’. Si el atributo o propiedad dado está siendo animado, contiene el valor animado actual del atributo o propiedad. Si el atributo o propiedad dado no está siendo animado, contiene el mismo valor que points. |
| [getPoints](../../com.aspose.html.dom.svg/isvganimatedpoints/points/) Proporciona acceso al contenido base (es decir, estático) del atributo ‘points’. |
