## SVGViewElement.ViewTarget property

Corresponde al atributo ‘viewTarget’ en el elemento ‘view’ dado. Una lista de valores DOMString que contienen los nombres listados en el atributo ‘viewTarget’. Cada uno de los valores DOMString puede asociarse con el elemento correspondiente usando la llamada al método getElementById().

```java
public SVGStringList ViewTarget { get; }
```

### Property Value

El atributo ‘viewTarget’ del elemento ‘view’ dado.
