## SVGPolygonElement.AnimatedPoints property

Proporciona acceso al contenido animado actual del atributo ‘points’. Si el atributo o propiedad dado está siendo animado, contiene el valor animado actual del atributo o propiedad. Si el atributo o propiedad dado no está siendo animado, contiene el mismo valor que points.

```java
public SVGPointList AnimatedPoints { get; }
```

### Property Value

Los puntos animados.
