## SVGSVGElement.SetCurrentTime method

Ajusta el reloj para este fragmento de documento SVG, estableciendo una nueva hora actual. Si setCurrentTime se llama antes de que la línea de tiempo del documento haya comenzado (por ejemplo, mediante un script que se ejecuta en un elemento ‘script’ antes de que se despache el evento SVGLoad del documento), entonces el valor de segundos en la última invocación del método indica el tiempo al que el documento buscará una vez que la línea de tiempo del documento haya comenzado.

```java
public void SetCurrentTime(float seconds)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| segundos | Single | El nuevo tiempo actual en segundos relativo al tiempo de inicio del fragmento de documento SVG actual. |
