## SVGSVGElement.CurrentTranslate property

En un elemento svg externo, el factor de traducción correspondiente que tiene en cuenta la "magnificación" del usuario. Cuando se accede a él en un elemento ‘svg’ que no es el svg externo, es indefinido qué comportamiento tiene este atributo.

```java
public SVGPoint CurrentTranslate { get; }
```

### Property Value

La traducción actual.
