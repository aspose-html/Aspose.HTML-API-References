## SVGSVGElement class

Una definición clave de interfaz es la interfaz SVGSVGElement, que es la interfaz que corresponde al elemento ‘svg’. Esta interfaz contiene varios métodos utilitarios diversos y de uso frecuente, como operaciones de matrices y la capacidad de controlar el tiempo de redibujado en dispositivos de renderizado visual.

```java
public class SVGSVGElement : SVGGraphicsElement, IDocumentEvent, ISVGFitToViewBox, ISVGZoomAndPan
```
