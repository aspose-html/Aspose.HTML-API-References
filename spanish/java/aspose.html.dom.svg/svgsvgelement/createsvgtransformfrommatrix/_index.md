## SVGSVGElement.CreateSVGTransformFromMatrix method

Crea un objeto SVGTransform fuera de cualquier árbol de documentos. El objeto se inicializa con la transformación de matriz proporcionada (es decir, SVG_TRANSFORM_MATRIX). Los valores de la matriz de parámetro se copian; el parámetro matrix no se adopta como SVGTransform::matrix.

```java
public SVGTransform CreateSVGTransformFromMatrix(SVGMatrix matrix)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| matriz | SVGMatrix | La matriz de transformación. |

### Valor devuelto

Un objeto SVGTransform.
