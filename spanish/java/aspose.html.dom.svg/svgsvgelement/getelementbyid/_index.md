## SVGSVGElement.GetElementById method

Busca en este fragmento de documento SVG (es decir, la búsqueda se restringe a un subconjunto del árbol del documento) un Element cuyo id está dado por elementId. Si se encuentra un Element, se devuelve ese Element. Si no existe tal elemento, se devuelve null. El comportamiento no está definido si más de un elemento tiene este id.

```java
public Element GetElementById(String elementId)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| elementId | String | El valor de id único para un elemento. |

### Valor de retorno

El elemento coincidente.
