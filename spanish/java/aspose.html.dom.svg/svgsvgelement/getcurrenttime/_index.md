## SVGSVGElement.GetCurrentTime method

Devuelve el tiempo actual en segundos relativo al tiempo de inicio del fragmento de documento SVG actual. Si getCurrentTime se llama antes de que la línea de tiempo del documento haya comenzado (por ejemplo, mediante un script que se ejecuta en un elemento ‘script’ antes de que se despache el evento SVGLoad del documento), se devuelve 0.

```java
public float GetCurrentTime()
```

### Valor de retorno

El tiempo actual en segundos, o 0 si la línea de tiempo del documento aún no ha comenzado.
