## SVGPathElement.AnimatedPathSegList property

Proporciona acceso al contenido animado actual del atributo ‘d’ en una forma que coincide uno a uno con la sintaxis de SVG. Si el atributo o propiedad dado está siendo animado, contiene el valor animado actual del atributo o propiedad, y tanto el propio objeto como su contenido son de solo lectura. Si el atributo o propiedad dado no está siendo animado, contiene el mismo valor que pathSegList.

```java
public SVGPathSegList AnimatedPathSegList { get; }
```

### Property Value

La lista de segmentos de ruta animada.
