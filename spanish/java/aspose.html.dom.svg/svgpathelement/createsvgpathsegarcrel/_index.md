## SVGPathElement.CreateSVGPathSegArcRel method

Devuelve un objeto SVGPathSegArcRel independiente y sin padre.

```java
public SVGPathSegArcRel CreateSVGPathSegArcRel(float x, float y, float r1, float r2, float angle, 
    bool largeArcFlag, bool sweepFlag)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| x | Single | La coordenada X relativa del punto final de este segmento de ruta. |
| y | Single | La coordenada Y relativa del punto final de este segmento de ruta. |
| r1 | Single | El radio del eje x de la elipse (es decir, r1). |
| r2 | Single | El radio del eje y para la elipse (es decir, r2). |
| angle | Single | El ángulo de rotación en grados para el eje x de la elipse relativo al eje x del sistema de coordenadas del usuario. |
| largeArcFlag | Boolean | El valor del parámetro large-arc-flag. |
| sweepFlag | Boolean | El valor del parámetro large-arc-flag. |

### Valor devuelto

Un objeto SVGPathSegArcRel independiente y sin padre.
