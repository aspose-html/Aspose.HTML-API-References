## SVGTextContentElement.GetNumberOfChars method

Devuelve el número total de caracteres disponibles para renderizar dentro del elemento actual, que incluye los caracteres referenciados desde la referencia ‘tref’, independientemente de si se renderizarán o no. En efecto, esto equivale a la longitud del atributo Node::textContent del DOM Level 3 Core ([DOM3], sección 1.4), si ese atributo también expandió los elementos ‘tref’.

```java
public long GetNumberOfChars()
```

### Valor de retorno

Número total de caracteres.
