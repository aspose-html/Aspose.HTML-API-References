## SVGGraphicsElement.GetBBox method

Devuelve el cuadro delimitador ajustado en el espacio de usuario actual (es decir, después de aplicar el atributo ‘transform’, si lo hay) sobre la geometría de todos los elementos gráficos contenidos, excluyendo trazos, recortes, máscaras y efectos de filtro). Tenga en cuenta que getBBox debe devolver el cuadro delimitador real en el momento en que se llamó al método, incluso en caso de que el elemento aún no se haya renderizado.

```java
public SVGRect GetBBox()
```

### Valor devuelto

Un objeto SVGRect que define el cuadro delimitador.
