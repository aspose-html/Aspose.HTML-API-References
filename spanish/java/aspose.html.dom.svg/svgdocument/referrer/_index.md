## SVGDocument.Referrer property

Devuelve el URI de la página que enlazó a esta página. El valor es una cadena vacía si el usuario navegó a la página directamente (no a través de un enlace, sino, por ejemplo, mediante un marcador).

```java
public String Referrer { get; }
```

### Property Value

El referente.
