## SVGUnitTypes enumeration

La enumeración SVGUnitTypes define un conjunto de constantes de uso común y es una interfaz base utilizada por SVGGradientElement, SVGPatternElement, SVGClipPathElement, SVGMaskElement y SVGFilterElement.

```java
public enum SVGUnitTypes
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| SVG_UNIT_TYPE_UNKNOWN | `0` | El tipo no es uno de los tipos predefinidos. Es inválido intentar definir un nuevo valor de este tipo o intentar cambiar un valor existente a este tipo. |
| SVG_UNIT_TYPE_USERSPACEONUSE | `1` | Corresponde al valor 'userSpaceOnUse'. |
| SVG_UNIT_TYPE_OBJECTBOUNDINGBOX | `2` | Corresponde al valor 'objectBoundingBox'. |
