## MutationObserverInit.TryGetValue method

Obtiene el valor asociado a la clave especificada.

```java
public bool TryGetValue(String key, out object value)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| key | Cadena | La clave del valor a obtener. |
| valor | Object& | Cuando este método devuelve, contiene el valor asociado con la clave especificada, si la clave se encuentra; de lo contrario, null. |

### Valor devuelto
