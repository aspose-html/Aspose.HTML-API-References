## Observe(Node) {#observe}

Indica al agente de usuario que observe un objetivo dado (un nodo) e informe cualquier mutación según los criterios proporcionados por options (un objeto). El argumento options permite establecer opciones de observación de mutaciones mediante los miembros del objeto.

```java
public void Observe(Node target)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| objetivo | Node | El objetivo para observar. |
