## MutationObserver constructor

Construye un objeto MutationObserver y establece su [`MutationCallback`](../../mutationcallback/) a callback. El callback se invoca con una lista de objetos MutationRecord como primer argumento y el objeto MutationObserver construido como segundo argumento. Se invoca después de que los nodos registrados con el método !:Observe(Node, IMutationObserverInit) son mutados.

```java
public MutationObserver(MutationCallback callback)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| callback | MutationCallback | El callback. |
