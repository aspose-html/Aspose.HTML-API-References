El paquete **com.aspose.html.dom.mutations** brinda la oportunidad de observar mutaciones del DOM y obtener información de devolución de llamada específica.

## Clases

| Clase | Descripción |
| --- | --- |
| [MutationCallback](./mutationcallback/) | Representa el método que manejará eventos de mutación. |
| [MutationObserver](./mutationobserver/) | Un objeto puede usarse para observar mutaciones en el árbol de [`.`](../com.aspose.html.dom/node/) |
| [MutationObserverInit](./mutationobserverinit/) | Esta clase representa una colección de opciones que se utiliza para configurar [`MutationObserver`](../com.aspose.html.dom.mutations/mutationobserver/). |
| [MutationRecord](./mutationrecord/) | Un MutationRecord representa una mutación individual del DOM. Es el objeto que se pasa al [`MutationObserver`](../com.aspose.html.dom.mutations/mutationobserver/)'s [`MutationCallback`](../com.aspose.html.dom.mutations/mutationcallback/). |
