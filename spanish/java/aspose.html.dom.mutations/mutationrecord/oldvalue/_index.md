## MutationRecord.OldValue property

El valor devuelto depende del tipo. Para "attributes", es el valor del atributo modificado antes del cambio. Para "characterData", son los datos del nodo modificado antes del cambio. Para "childList", es null.

```java
public String OldValue { get; }
```

### Property Value

El valor anterior.
