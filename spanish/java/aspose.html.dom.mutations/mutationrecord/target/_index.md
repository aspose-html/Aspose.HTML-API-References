## MutationRecord.Target property

Devuelve el nodo afectado por la mutación, según el tipo. Para "attributes", es el elemento cuyo atributo cambió. Para "characterData", es el nodo CharacterData. Para "childList", es el nodo cuyos hijos cambiaron.

public Node Target { get; }

El objetivo.
