## RequestMessage.PreAuthenticate property

Obtiene o establece un valor que indica si se debe enviar un encabezado de autorización con la solicitud.

```java
public bool PreAuthenticate { get; set; }
```

### Property Value

`true` para enviar un encabezado de autorización HTTP con las solicitudes después de que se haya realizado la autenticación; de lo contrario, `false`. El valor predeterminado es `false`.
