El paquete **com.aspose.html.net** está formado por clases e interfaces que son responsables de facilitar el procesamiento de red.

## Clases

| Clase | Descripción |
| --- | --- |
| [ByteArrayContent](./bytearraycontent/) | Representa contenido basado en una matriz de bytes. |
| [Content](./content/) | Representa una clase base para un cuerpo de entidad HTTP y encabezados de contenido. |
| [ContentHeaders](./contentheaders/) | Contiene los encabezados asociados a un contenido. |
| [FormUrlEncodedContent](./formurlencodedcontent/) | Un contenedor para tuplas nombre/valor codificadas usando el tipo MIME application/x-www-form-urlencoded. |
| [HttpMethod](./httpmethod/) | Representa una clase de utilidad para obtener y comparar los métodos HTTP estándar. |
| [MessageFilter](./messagefilter/) | Representa una clase base abstracta para diferentes clases de filtros utilizadas para consultar mensajes |
| [MessageHandler](./messagehandler/) | Representa un tipo base para los manejadores de mensajes. |
| [MessageHandlerCollection](./messagehandlercollection/) | Representa una colección del [`MessageHandler`](../com.aspose.html.net/messagehandler/). |
| [MultipartContent](./multipartcontent/) | Representa un contenido multipart/*. |
| [MultipartFormDataContent](./multipartformdatacontent/) | Representa contenido para el algoritmo de codificación multipart/form-data |
| [RequestHeaders](./requestheaders/) | Contiene encabezados de protocolo asociados a una solicitud. |
| [RequestMessage](./requestmessage/) | Representa un mensaje de solicitud. |
| [ResponseHeaders](./responseheaders/) | Contiene encabezados de protocolo asociados a una respuesta. |
| [ResponseMessage](./responsemessage/) | Representa un mensaje de respuesta. |
| [StreamContent](./streamcontent/) | Representa contenido basado en un flujo. |
| [StringContent](./Stringcontent/) | Representa contenido basado en una cadena. |
| [UrlResolver](./urlresolver/) | Representa una clase de utilidad para resolver URL absolutas mediante un Identificador Uniforme de Recursos (URI). |
## Interfaces

| Interfaz | Descripción |
| --- | --- |
| [INetwork](./inetwork/) | Proporciona una interfaz para servicios de red. |
| [INetworkOperationContext](./inetworkoperationcontext/) | Proporciona información contextual para los servicios de red. |
