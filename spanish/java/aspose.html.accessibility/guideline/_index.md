## Guideline class

Directrices - el siguiente nivel después de los principios. No son evaluables, pero describen marcos y objetivos generales que ayudan a los autores a comprender los criterios de éxito y aplicar mejor las técnicas. Las directrices son una lista de criterios de aceptación con tipo RuleDirectory{Criterion}.
