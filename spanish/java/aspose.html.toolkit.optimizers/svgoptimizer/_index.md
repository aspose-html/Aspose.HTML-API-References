## SVGOptimizer class

SVGOptimizer es una clase estática diseñada para optimizar documentos SVG. Por optimización, entendemos la eliminación de elementos no utilizados o invisibles y sus atributos, la fusión de grupos y la reducción del tamaño de los segmentos de ruta.
