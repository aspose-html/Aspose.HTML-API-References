El paquete **com.aspose.html.toolkit.optimizers** contiene clases para optimizar documentos SVG. El proceso de optimización implica eliminar elementos no utilizados o invisibles y sus atributos, combinar grupos y reducir el tamaño de los segmentos de ruta.

## Clases

| Clase | Descripción |
| --- | --- |
| [SVGOptimizationOptions](./svgoptimizationoptions/) | SVGOptimizationOptions es una clase para almacenar opciones de optimización de documentos SVG. |
| [SVGOptimizer](./svgoptimizer/) | SVGOptimizer es una clase estática diseñada para optimizar documentos SVG. Por optimización, entendemos la eliminación de elementos no utilizados o invisibles y sus atributos, la fusión de grupos y la reducción del tamaño de los segmentos de ruta. |
| [SVGPathOptimizationOptions](./svgpathoptimizationoptions/) | SVGPathOptimizationOptions es una clase para almacenar opciones de optimización de segmentos de elementos de ruta SVG. |
