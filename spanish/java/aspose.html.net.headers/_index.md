El paquete **com.aspose.html.net.headers** proporciona algunas clases de datos para describir el contenido de los encabezados en la red.

## Clases

| Clase | Descripción |
| --- | --- |
| [ContentDispositionHeaderValue](./contentdispositionheadervalue/) | Representa el valor del encabezado Content-Disposition. |
| [ContentTypeHeaderValue](./contenttypeheadervalue/) | Representa un valor de encabezado Content-Type. |
| [NameValueHeaderValue](./namevalueheadervalue/) | Representa un par nombre/valor que describe un valor de encabezado. |
