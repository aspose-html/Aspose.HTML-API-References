## ISVGAnimatedPathData.PathSegList property

Proporciona acceso al contenido base (es decir, estático) del atributo ‘d’ en una forma que coincide uno a uno con la sintaxis de SVG. Así, si el atributo ‘d’ tiene un \"moveto absoluto (M)\" y un \"arcto absoluto (A)\", entonces pathSegList tendrá dos entradas: un SVG_PATHSEG_MOVETO_ABS y un SVG_PATHSEG_ARC_ABS.

```java
public SVGPathSegList PathSegList { get; }
```

### Property Value

La lista de segmentos de ruta.
