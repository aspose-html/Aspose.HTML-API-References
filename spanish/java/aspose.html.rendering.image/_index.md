El paquete **com.aspose.html.rendering.image** proporciona una clase de dispositivo específica, así como algunas clases de opciones de renderizado responsables de renderizar a formatos rasterizados: jpeg, png, bmp, gif, tiff.

## Clases

| Clase | Descripción |
| --- | --- |
| [ImageDevice](./imagedevice/) | Representa el renderizado a formatos raster: jpeg, png, bmp, gif, tiff. |
| [ImageRenderingOptions](./imagerenderingoptions/) | Representa opciones de renderizado para [`ImageDevice`](../com.aspose.html.rendering.image/imagedevice/). Estas opciones se utilizan para especificar el formato de imagen de salida, compresión, resolución, etc. |
| [TextOptions](./textoptions/) | Representa opciones de renderizado de texto para [`ImageDevice`](../com.aspose.html.rendering.image/imagedevice/). |
## Enumeración

| Enumeración | Descripción |
| --- | --- |
| [Compression](./compression/) | Especifica los posibles esquemas de compresión para imágenes bitmap en formato Tagged Image File Format (TIFF). |
| [ImageFormat](./imageformat/) | Especifica el formato de archivo de la imagen. |
