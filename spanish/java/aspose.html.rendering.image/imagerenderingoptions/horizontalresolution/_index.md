## ImageRenderingOptions.HorizontalResolution property

Establece o obtiene la resolución horizontal para imágenes de salida e internas (que se usan durante el procesamiento de filtros), en píxeles por pulgada. Por defecto, esta propiedad es 300 ppp.

public Resolution HorizontalResolution { get; set; }
