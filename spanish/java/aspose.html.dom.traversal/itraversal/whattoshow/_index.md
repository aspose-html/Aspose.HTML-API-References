## ITraversal.WhatToShow property

Este atributo determina qué tipos de nodo se presentan a través del iterador. El conjunto disponible de constantes está definido en la interfaz NodeFilter. Los nodos no aceptados por whatToShow serán omitidos, pero sus hijos aún pueden ser considerados. Tenga en cuenta que este salto tiene precedencia sobre el filtro, si lo hay.

```java
public long WhatToShow { get; }
```

### Property Value

El what to show.
