## ITreeWalker.FirstChild method

Mueve el TreeWalker al primer hijo visible del nodo actual y devuelve el nuevo nodo. Si el nodo actual no tiene hijos visibles, devuelve null y conserva el nodo actual.

```java
public Node FirstChild()
```

### Valor de retorno

El nuevo nodo, o null si el nodo actual no tiene hijos visibles en la vista lógica del TreeWalker.
