## ITreeWalker.LastChild method

Mueve el TreeWalker al último hijo visible del nodo actual y devuelve el nuevo nodo. Si el nodo actual no tiene hijos visibles, devuelve null y conserva el nodo actual.

```java
public Node LastChild()
```

### Valor de retorno

El nuevo nodo, o null si el nodo actual no tiene hijos en la vista lógica del TreeWalker.
