## ITreeWalker.PreviousNode method

Mueve el TreeWalker al nodo visible anterior en orden de documento relativo al nodo actual, y devuelve el nuevo nodo. Si el nodo actual no tiene nodo anterior, o si la búsqueda de previousNode intenta subir desde el nodo raíz del TreeWalker, devuelve null y conserva el nodo actual.

```java
public Node PreviousNode()
```

### Valor de retorno

El nuevo nodo, o null si el nodo actual no tiene nodo anterior en la vista lógica del TreeWalker.
