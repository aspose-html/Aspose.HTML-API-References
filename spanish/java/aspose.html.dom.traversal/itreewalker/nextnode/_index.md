## ITreeWalker.NextNode method

Mueve el TreeWalker al siguiente nodo visible en orden de documento relativo al nodo actual y devuelve el nuevo nodo. Si el nodo actual no tiene nodo siguiente, o si la búsqueda de nextNode intenta avanzar hacia arriba desde el nodo raíz del TreeWalker, devuelve null y conserva el nodo actual.

```java
public Node NextNode()
```

### Valor de retorno

El nuevo nodo, o null si el nodo actual no tiene nodo siguiente en la vista lógica del TreeWalker.
