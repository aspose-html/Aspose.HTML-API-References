## ITreeWalker.NextSibling method

Mueve el TreeWalker al siguiente hermano visible del nodo actual y devuelve el nuevo nodo. Si el nodo actual no tiene siguiente hermano visible, devuelve null y conserva el nodo actual.

```java
public Node NextSibling()
```

### Valor devuelto

El nuevo nodo, o null si el nodo actual no tiene hermano siguiente en la vista lógica del TreeWalker.
