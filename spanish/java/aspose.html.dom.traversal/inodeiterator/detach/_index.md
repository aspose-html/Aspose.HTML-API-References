## INodeIterator.Detach method

Desacopla el NodeIterator del conjunto que iteró, liberando cualquier recurso computacional y colocando el iterador en el estado INVALID. Después de que se haya invocado detach, las llamadas a nextNode o previousNode lanzarán la excepción INVALID_STATE_ERR.
