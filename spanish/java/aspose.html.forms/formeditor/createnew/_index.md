## FormEditor.CreateNew method

Crea un nuevo [`HTMLFormElement`](../../../com.aspose.html/htmlformelement/) y lo asocia con [`FormEditor`](../). [`HTMLFormElement`](../../../com.aspose.html/htmlformelement/) se crea en estado separado del documento; para adjuntarlo al documento, seleccione la ubicación adecuada y use el método [`AppendChild`](../../../com.aspose.html.dom/node/appendchild/).

```java
public static FormEditor CreateNew(HTMLDocument document)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| document | HTMLDocument | El [`HTMLDocument`](../../../com.aspose.html/htmldocument/). |

### Valor de retorno

Devuelve una nueva instancia de la clase [`FormEditor`](../)
