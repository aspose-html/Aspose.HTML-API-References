El paquete proporciona acceso a numerosos objetos (elementos) que son responsables de la interactividad del usuario dentro del formulario como componente de página web.

## Clases

| Clase | Descripción |
| --- | --- |
| [ButtonElement](./buttonelement/) | El ButtonElement representa un contenedor que está asociado con el HTMLButtonElement. |
| [DataListElement](./datalistelement/) | El DataListElement representa un contenedor que está asociado con el HTMLDataListElement |
| [FormEditor](./formeditor/) | Esta clase representa el editor sobre el [`HTMLFormElement`](../com.aspose.html/htmlformelement/) que crea una forma más fácil para los desarrolladores .net de editar los formularios HTML. |
| [FormElement](./formelement/) | Representa la clase base para los elementos de formulario. |
| [FormElement&lt;T&gt;](./formelement-1/) | El [`FormElement`](../com.aspose.html.forms/formelement/) representa el campo genérico. |
| [FormSubmitter](./formsubmitter/) | Esta clase permite preparar el [`HTMLFormElement`](../com.aspose.html/htmlformelement/) especificado, recopila valores del elemento del formulario, los envía al servidor remoto y recibe una respuesta. |
| [InputElement](./inputelement/) | El InputElement representa un contenedor que está asociado con el HTMLInputElement. |
| [OptionCollection](./optioncollection/) | El OptionElements representa un contenedor que está asociado con el IHTMLOptionsCollection |
| [OptionElement](./optionelement/) | El OptionElement representa un contenedor que está asociado con el HTMLOptionElement |
| [SelectElement](./selectelement/) | El SelectElement representa un contenedor que está asociado con el HTMLSelectElement |
| [SubmissionResult](./submissionresult/) | Esta clase representa el resultado del envío de datos del formulario al servidor. |
| [TextAreaElement](./textareaelement/) | El TextAreaElement representa un contenedor que está asociado con el HTMLTextAreaElement |
## Enumeración

| Enumeración | Descripción |
| --- | --- |
| [ButtonType](./buttontype/) | Esta enumeración representa los estados del botón. |
| [FormElementType](./formelementtype/) | Representa una enumeración de los tipos de Elementos de Formulario y su correspondencia con los Elementos HTML. |
| [InputElementType](./inputelementtype/) | Representa los estados del campo de entrada. |
