## Text.IsElementContentWhitespace property

Devuelve si este nodo de texto contiene espacio en blanco de contenido de elemento, a menudo llamado abusivamente "espacio en blanco ignorado".

```java
public bool IsElementContentWhitespace { get; }
```

### Property Value

`true` si esta instancia es espacio en blanco de contenido de elemento; de lo contrario, `false`.
