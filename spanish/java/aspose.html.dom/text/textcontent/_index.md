## Text.TextContent property

Este atributo devuelve el contenido de texto de este nodo y sus descendientes. Cuando se define como null, establecerlo no tiene efecto. Al establecerlo, cualquier hijo posible que pueda tener este nodo se elimina y, si la nueva cadena no está vacía ni es null, se reemplaza por un único nodo Text que contiene la cadena a la que se establece este atributo.

```java
public String TextContent { get; set; }
```

### Property Value

El contenido del texto.
