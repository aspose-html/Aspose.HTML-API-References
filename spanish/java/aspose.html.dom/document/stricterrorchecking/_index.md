## Document.StrictErrorChecking property

Un atributo que especifica si la verificación de errores está habilitada o no. Cuando se establece en false, la implementación es libre de no probar cada posible caso de error definido normalmente en las operaciones DOM y no lanzar ninguna DOMException en las operaciones DOM ni reportar errores al usar Document.normalizeDocument(). En caso de error, el comportamiento es indefinido. Este atributo es true por defecto.

```java
public bool StrictErrorChecking { get; set; }
```

### Property Value

`true` si la verificación estricta de errores; de lo contrario, `false`.
