## Document.ReadyState property

Devuelve la disponibilidad del documento. "loading" mientras el Document se está cargando, "interactive" una vez que ha terminado de analizar pero sigue cargando subrecursos, y "complete" una vez que se ha cargado.

```java
public String ReadyState { get; }
```
