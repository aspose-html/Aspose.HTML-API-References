## Document.StyleSheets property

Una lista que contiene todas las hojas de estilo vinculadas explícitamente o incrustadas en un documento. Para documentos HTML, esto incluye hojas de estilo externas, incluidas mediante el elemento HTML LINK, y elementos STYLE en línea.

```java
public IStyleSheetList StyleSheets { get; }
```
