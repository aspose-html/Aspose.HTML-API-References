## Document.XmlVersion property

Un atributo que especifica, como parte de la declaración XML, el número de versión de este documento. Si no hay declaración y si este documento soporta la característica "XML", el valor es "1.0". Si este documento no soporta la característica "XML", el valor es siempre null.

```java
public String XmlVersion { get; set; }
```

### Property Value

La versión XML.
