## Document.DefaultView property

El atributo IDL defaultView de la interfaz Document, al obtenerse, debe devolver el objeto WindowProxy del contexto de navegación de este Document, si este Document tiene un contexto de navegación asociado, o null en caso contrario.

```java
public IWindow DefaultView { get; }
```
