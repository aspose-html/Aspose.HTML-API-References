## Document.XmlStandalone property

Un atributo que especifica, como parte de la declaración XML, si este documento es independiente. Es falso cuando no se especifica.

```java
public bool XmlStandalone { get; set; }
```

### Property Value

`true` si XML independiente; de lo contrario, `false`.
