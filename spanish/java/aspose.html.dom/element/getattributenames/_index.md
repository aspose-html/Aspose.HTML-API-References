## Element.GetAttributeNames method

Devuelve los nombres de los atributos del elemento como una matriz de cadenas. Si el elemento no tiene atributos, devuelve una matriz vacía.

```java
public String[] GetAttributeNames()
```

### Valor devuelto

Matriz de Cadenas representa los nombres de los atributos.
