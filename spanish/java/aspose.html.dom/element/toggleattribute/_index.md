## ToggleAttribute(String) {#toggleattribute}

Si no se proporciona force, \"alternar\" qualifiedName, eliminándolo si está presente y añadiéndolo si no lo está. Si force es true, se añade qualifiedName. Si force es false, se elimina qualifiedName.

```java
public bool ToggleAttribute(String qualifiedName)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| qualifiedName | String | El atributo QualifiedName. |

### Valor de retorno

Devuelve true si qualifiedName está ahora presente; de lo contrario, false.
