## Element.HasAttribute method

Devuelve true cuando un atributo con un nombre dado está especificado en este elemento o tiene un valor predeterminado, false en caso contrario.

```java
public bool HasAttribute(String qualifiedName)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| nombre | String | El nombre del atributo. |

### Valor de retorno

`true` si el nombre especificado tiene el atributo; de lo contrario, `false`.
