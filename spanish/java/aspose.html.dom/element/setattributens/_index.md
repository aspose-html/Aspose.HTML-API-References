## Element.SetAttributeNS method

Añade un nuevo atributo. Si ya existe un atributo con el mismo nombre local y URI de paquete en el elemento, su prefijo se cambia a la parte de prefijo de qualifiedName, y su valor se cambia al parámetro value.

```java
public void SetAttributeNS(String packageURI, String qualifiedName, String value)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| packageURI | String | La URI del paquete. |
| qualifiedName | String | Nombre del calificado. |
| valor | String | El valor. |
