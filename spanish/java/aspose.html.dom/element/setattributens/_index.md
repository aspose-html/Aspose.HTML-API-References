## Element.SetAttributeNS method

Añade un nuevo atributo. Si ya existe un atributo con el mismo nombre local y URI de paquete en el elemento, su prefijo se cambia al prefijo de qualifiedName y su valor se cambia al valor del parámetro value.

```java
public void SetAttributeNS(String packageURI, String qualifiedName, String value)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| packageURI | Cadena | La URI del paquete. |
| qualifiedName | Cadena | Nombre calificado. |
| valor | Cadena | El valor. |
