## Element.AttachShadow method

Crea una raíz sombra y la adjunta al elemento actual.

```java
public ShadowRoot AttachShadow(ShadowRootMode mode)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| modo | ShadowRootMode | Modo en el que se creará el shadow root. |

### Valor devuelto

Creado [`ShadowRoot`](../../shadowroot/).

### Excepciones

| excepción | condición |
| --- | --- |
| Error | NotSupportedError: Element no admite árbol shadow. |
| Error | InvalidStateError: Element ya tiene un árbol shadow. |
