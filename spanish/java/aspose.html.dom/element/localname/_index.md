## Element.LocalName property

Devuelve la parte local del nombre calificado de este nodo. Para nodos de cualquier tipo que no sean ELEMENT_NODE y ATTRIBUTE_NODE y nodos creados con un método de DOM Level 1, como Document.createElement(), esto siempre es null.

```java
public String LocalName { get; }
```

### Property Value

El nombre del local.
