## Element.HasAttributeNS method

Devuelve true cuando un atributo con un nombre local y URI del paquete dados está especificado en este elemento o tiene un valor predeterminado, false en caso contrario.

```java
public bool HasAttributeNS(String packageURI, String localName)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| packageURI | Cadena | La URI del paquete. |
| localName | Cadena | Nombre del local. |

### Valor devuelto

`true` si [has attribute NS] [the specified package URI]; de lo contrario, `false`.
