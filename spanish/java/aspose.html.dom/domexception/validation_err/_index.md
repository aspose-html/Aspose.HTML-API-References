## DOMException.VALIDATION_ERR field

Si una llamada a un método como insertBefore o removeChild hiciera que el Node sea inválido respecto a la "validez parcial", se lanzaría esta excepción y la operación no se realizaría. Este código se usa en [DOM Level 3 Validation]. Consulte esta especificación para obtener más información.

```java
public const ushort VALIDATION_ERR;
```
