## Node.LocalName property

Devuelve la parte local del nombre calificado de este nodo. Para nodos de cualquier tipo que no sean [`ELEMENT_NODE`](../element_node/) ni [`ATTRIBUTE_NODE`](../attribute_node/) y nodos creados con un método DOM Level 1, como [`Document.createElement()`](../../document/createelement/), esto siempre es null.

```java
public String LocalName { get; }
```

### Property Value

Una cadena que representa la parte local del nombre calificado del elemento.
