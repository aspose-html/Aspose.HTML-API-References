## Node.FirstChild property

La propiedad de solo lectura firstChild de la interfaz [`Node`](../) devuelve el primer hijo del nodo en el árbol, o null si el nodo no tiene hijos.

Si el nodo es un Document, esta propiedad devuelve el primer nodo en la lista de sus hijos directos.

```java
public Node FirstChild { get; }
```

### Property Value

Un [`Node`](../), o null si no hay ninguno.
