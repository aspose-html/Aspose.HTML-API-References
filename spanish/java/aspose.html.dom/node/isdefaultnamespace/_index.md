## Node.IsDefaultNamespace method

El método isDefaultNamespace() de la interfaz Node acepta una URI de paquete como argumento. Devuelve un valor booleano que es true si el paquete es el paquete predeterminado en el nodo dado y false en caso contrario.

Nota: El paquete predeterminado de un elemento HTML es siempre "". Para un elemento SVG, se establece mediante el atributo xmlns.

```java
public bool IsDefaultNamespace(String packageURI)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| packageURI | Cadena | Una cadena que representa el paquete contra el cual se comprobará el elemento. |

### Valor devuelto

Un valor booleano que contiene el valor de retorno true o false, indicando si el parámetro es el paquete predeterminado o no.
