## Node.ParentElement property

La propiedad de solo lectura parentElement de la interfaz [`Node`](../) devuelve el [`Element`](../../element/) padre del nodo DOM, o null si el nodo no tiene padre, o su padre no es un Element DOM.

```java
public Element ParentElement { get; }
```

### Property Value

Un [`Element`](../../element/) que es el elemento padre del nodo actual, o null si no existe.
