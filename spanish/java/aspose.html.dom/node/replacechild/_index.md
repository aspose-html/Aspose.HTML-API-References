## Node.ReplaceChild method

Reemplaza el nodo hijo oldChild con newChild en la lista de hijos y devuelve el nodo oldChild. Si newChild es un objeto [`DocumentFragment`](../../documentfragment/), oldChild es reemplazado por todos los hijos del [`DocumentFragment`](../../documentfragment/) que se insertan en el mismo orden. Si newChild ya está en el árbol, se elimina primero.

```java
public Node ReplaceChild(Node node, Node child)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| nodo | Node | El nuevo nodo que reemplazará a oldChild. |
| hijo | Node | El hijo que será reemplazado. |

### Valor devuelto

El Node reemplazado. Este es el mismo nodo que oldChild.
