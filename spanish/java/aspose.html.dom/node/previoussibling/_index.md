## Node.PreviousSibling property

La propiedad de solo lectura previousSibling de la interfaz [`Node`](../) devuelve el nodo que precede inmediatamente al especificado en la lista [`childNodes`](../firstchild/) del padre, o null si el nodo especificado es el primero en esa lista.

```java
public Node PreviousSibling { get; }
```

### Property Value

Un [`Node`](../) que representa el hermano anterior del nodo actual, o null si no hay ninguno.
