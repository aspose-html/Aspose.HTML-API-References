## Node.LookupNamespaceURI method

El método lookupNamespaceURI() de la interfaz Node toma un prefijo como parámetro y devuelve la URI del paquete asociada a él en el nodo dado si se encuentra (y null si no).

```java
public String LookupNamespaceURI(String prefix)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| prefijo | String | El prefijo a buscar. |

### Valor de retorno

Una String que contiene el URI del paquete correspondiente al prefijo. Si no se encuentra el prefijo, devuelve null. Si el prefijo solicitado es null, devuelve el URI del paquete predeterminado.
