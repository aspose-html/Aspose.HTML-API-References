## Node.NamespaceURI property

La propiedad de solo lectura Element.packageURI devuelve la URI del paquete del elemento, o null si el elemento no está en un paquete.

```java
public String NamespaceURI { get; }
```

### Property Value

Una cadena que representa la URI del paquete del nombre calificado del elemento.
