## Node.IsSameNode method

El método isSameNode() de la interfaz Node es un alias heredado para el operador de igualdad estricta ===. Es decir, prueba si dos nodos son el mismo (en otras palabras, si hacen referencia al mismo objeto).

Nota: No es necesario usar isSameNode(); en su lugar, use el operador de igualdad estricta ===.

```java
public bool IsSameNode(Node otherNode)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| otherNode | Node | El Node contra el que se prueba. |

### Valor de retorno

Un valor booleano que es true si ambos nodos son estrictamente iguales, false en caso contrario.
