## Node.Prefix property

La propiedad de solo lectura prefix devuelve el prefijo del paquete del elemento especificado, o null si no se especifica ningún prefijo.

```java
public String Prefix { get; set; }
```

### Property Value

La propiedad devuelve el prefijo de paquete asociado.
