## Node.IsEqualNode method

El método isEqualNode() de la interfaz [`Node`](../) prueba si dos nodos son iguales. Dos nodos son iguales cuando tienen el mismo tipo, características definitorias (para elementos, esto sería su ID, número de hijos, etc.), sus atributos coinciden, y demás. El conjunto específico de datos que deben coincidir varía según los tipos de los nodos.

```java
public bool IsEqualNode(Node otherNode)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| otherNode | Node | El [`Node`](../) con el que comparar la igualdad. |

### Valor de retorno

Un valor booleano que es true si los dos nodos son iguales, o false si no lo son. Si otherNode es null, isEqualNode() siempre devuelve false.
