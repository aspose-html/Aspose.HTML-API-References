## Node.IsEqualNode method

El método isEqualNode() de la interfaz [`Node`](../) verifica si dos nodos son iguales. Dos nodos son iguales cuando tienen el mismo tipo, características definitorias (para los elementos, esto sería su ID, número de hijos, etc.), sus atributos coinciden, y demás. El conjunto específico de datos que debe coincidir varía según los tipos de los nodos.

```java
public bool IsEqualNode(Node otherNode)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| otherNode | Node | El [`Node`](../) con el que comparar la igualdad. |

### Valor devuelto

Un valor booleano que es true si los dos nodos son iguales, o false si no lo son. Si otherNode es null, isEqualNode() siempre devuelve false.
