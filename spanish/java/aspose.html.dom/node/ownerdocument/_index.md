## Node.OwnerDocument property

La propiedad de solo lectura ownerDocument de la interfaz Node devuelve el objeto de documento de nivel superior del nodo.

```java
public Document OwnerDocument { get; }
```

### Property Value

Un [`Document`](../../document/) que es el objeto de nivel superior en el que se crean todos los nodos hijos.

Si esta propiedad se usa en un nodo que es a su vez un documento, el valor es null.
