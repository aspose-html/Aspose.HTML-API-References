## Node.NodeValue property

La propiedad nodeValue de la interfaz [`Node `](../) devuelve o establece el valor del nodo actual.

```java
public String NodeValue { get; set; }
```

### Property Value

Una String que contiene el valor del nodo actual, si lo hay. Para el propio documento, nodeValue devuelve null. Para nodos de texto, comentario y CDATA, nodeValue devuelve el contenido del nodo. Para nodos de atributo, se devuelve el valor del atributo.
