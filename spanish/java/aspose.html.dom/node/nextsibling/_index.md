## Node.NextSibling property

La propiedad de solo lectura nextSibling de la interfaz [`Node`](../) devuelve el nodo que sigue inmediatamente al especificado en el [`childNodes`](../childnodes/) del padre, o devuelve null si el nodo especificado es el último hijo del elemento padre.

```java
public Node NextSibling { get; }
```

### Property Value

Un [`Node`](../) que representa el siguiente hermano del nodo actual, o null si no hay ninguno.
