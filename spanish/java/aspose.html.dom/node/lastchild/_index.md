## Node.LastChild property

La propiedad de solo lectura lastChild de la interfaz [`Node`](../) devuelve el último hijo del nodo. Si su padre es un elemento, entonces el hijo suele ser un nodo de elemento, un nodo de texto o un nodo de comentario. Devuelve null si no hay elementos hijos.

```java
public Node LastChild { get; }
```

### Property Value

Un [`Node`](../) que es el último hijo del nodo, o null si no hay elementos hijos.
