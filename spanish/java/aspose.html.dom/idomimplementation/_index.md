## IDOMImplementation interface

La interfaz DOMImplementation proporciona una serie de métodos para realizar operaciones que son independientes de cualquier instancia particular del modelo de objetos del documento.

```java
public interface IDOMImplementation
```

## Métodos

| Nombre | Descripción |
| --- | --- |
| [createDocument](../../com.aspose.html.dom/idomimplementation/createdocument/)(String, String, DocumentType) | Crea un objeto DOM Document del tipo especificado con su elemento de documento. |
| [createDocumentType](../../com.aspose.html.dom/idomimplementation/createdocumenttype/)(String, String, String) | Crea un nodo DocumentType vacío. No se ponen a disposición las declaraciones de entidades y notaciones. No se realizan expansiones de referencias de entidad ni adiciones de atributos predeterminados. |

| [hasFeature](../../com.aspose.html.dom/idomimplementation/hasfeature/)() | Comprueba si la implementación DOM implementa una característica y versión específicas, según lo especificado en DOM Features. |
