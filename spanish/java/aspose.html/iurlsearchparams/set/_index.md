## IUrlSearchParams.Set method

Establece el valor del primer par nombre-valor encontrado al valor especificado y elimina los demás. Si no se encuentran pares nombre-valor con el nombre especificado, se agregará uno nuevo a la lista.

public void Set(String name, String value)

| valor | String | Valor que se establecerá. |
