## HTMLOptionElement.Selected property

Representa el estado actual del control de formulario correspondiente, en un agente de usuario interactivo. Cambiar este atributo cambia el estado del control de formulario, pero no cambia el valor del atributo selected de HTML del elemento.

```java
public bool Selected { get; set; }
```
