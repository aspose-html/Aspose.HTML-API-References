## HTMLDocument.Anchors property

Una colección de todos los elementos de ancla (`A`) en un documento con un valor para el atributo `name`. Por razones de compatibilidad retroactiva, el conjunto devuelto de anclas solo contiene aquellas creadas con el atributo `name`, no las creadas con el atributo `id`. Tenga en cuenta que en [[XHTML 1.0](http://www.w3.org/TR/2002/REC-xhtml1-20020801)], el atributo `name` (ver sección 4.10) no tiene semántica y solo está presente para agentes de usuario heredados: se usa el atributo `id` en su lugar. Los usuarios deberían preferir los mecanismos de iteración proporcionados por [[DOM Level 2 Traversal](http://www.w3.org/TR/2000/REC-DOM-Level-2-Traversal-Range-20001113)] en su lugar.

public HTMLCollection Anchors { get; }
