## HTMLDocument.Images property

Una colección de todos los elementos `IMG` en un documento. El comportamiento está limitado a los elementos `IMG` por compatibilidad retroactiva. Según lo sugerido por [[HTML 4.01](http://www.w3.org/TR/1999/REC-html401-19991224)], para incluir imágenes, los autores pueden usar el elemento `OBJECT` o el elemento `IMG`. Por lo tanto, se recomienda no usar este atributo para buscar imágenes en el documento, sino `getElementsByTagName` con HTML 4.01 o `getElementsByTagNameNS` con XHTML 1.0.

```java
public HTMLCollection Images { get; }
```
