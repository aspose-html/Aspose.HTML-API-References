## HTMLDocument.Referrer property

Devuelve el URI [[IETF RFC 2396](http://www.ietf.org/rfc/rfc2396.txt)] de la página que enlazó a esta página. El valor es una String vacía si el usuario navegó a la página directamente (no a través de un enlace, sino, por ejemplo, mediante un marcador).

```java
public String Referrer { get; }
```
