## HTMLTableElement.Rows property

Devuelve el `TFOOT` de la tabla, o `null` si no existe.

Devuelve una colección de todas las filas de la tabla, incluyendo todas en `THEAD`, `TFOOT` y todos los elementos `TBODY`.

```java
public HTMLCollection Rows { get; }
```
