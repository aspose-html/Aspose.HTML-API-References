## TypedArray&lt;T&gt; class

Los objetos TypedArray presentan una vista similar a una matriz de un búfer de datos binarios subyacente.

```java
public abstract class TypedArray<T> : TypedArray
    where T : struct
```

| Parámetro | Descripción |
| --- | --- |
| T | El tipo de datos. |
