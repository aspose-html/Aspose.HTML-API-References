El paquete Aspose.Html contiene clases y métodos para manipular [`HTML documents`](aspose.html/htmldocument/), ya sean simples o complejos y en tiempo real. Aspose.HTML para Java permite a los desarrolladores Insertar, Eliminar, Reemplazar nodos HTML, extraer información de estilo CSS, Navegar a través de [`HTML document`](aspose.html/htmldocument/) ya sea mediante [`NodeIterator`](aspose.html.dom.traversal/inodeiterator/), [`TreeWalker`](aspose.html.dom.traversal/itreewalker/) que se proporcionan mediante Especificaciones de Traversal, consultas XPath o selectores CSS. También ofrece scripting que permite manipular el DOM HTML mediante JavaScript. Además de HTML, esta API también proporciona la capacidad de cargar EPUB y MHTML. Las APIs de Aspose son famosas por sus funciones de conversión entre formatos de archivo y esta API también brinda la capacidad de cargar archivos HTML y renderizar la salida en PDF, XPS y formatos de imagen rasterizados, incluidos JPEG, PNG, BMP y TIFF.
