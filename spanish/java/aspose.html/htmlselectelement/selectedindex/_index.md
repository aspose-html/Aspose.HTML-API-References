## HTMLSelectElement.SelectedIndex property

El índice ordinal de la opción seleccionada, comenzando desde 0. Se devuelve el valor -1 si no se selecciona ningún elemento. Si se seleccionan múltiples opciones, se devuelve el índice de la primera opción seleccionada.

```java
public int SelectedIndex { get; set; }
```
