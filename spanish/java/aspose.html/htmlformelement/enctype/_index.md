## HTMLFormElement.Enctype property

El tipo de contenido del formulario enviado, generalmente "application/x-www-form-urlencoded". Consulte la definición del atributo enctype en HTML 4.01. No se garantiza que el controlador de evento onsubmit se active al invocar este método. El comportamiento es inconsistente por razones históricas y los autores no deben confiar en uno en particular.

public String Enctype { get; set; }
