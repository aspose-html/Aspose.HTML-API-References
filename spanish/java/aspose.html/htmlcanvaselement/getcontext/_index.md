## HTMLCanvasElement.GetContext method

Devuelve un contexto de dibujo en el canvas, o null si el ID de contexto no es compatible. Un contexto de dibujo le permite dibujar en el canvas.

```java
public object GetContext(String contextId)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| contextId | String | Es una cadena que contiene el identificador de contexto que define el contexto de dibujo asociado al lienzo |

### Valor de retorno

Un RenderingContext
