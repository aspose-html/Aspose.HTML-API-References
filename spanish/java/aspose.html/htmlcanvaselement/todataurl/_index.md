## ToDataURL() {#todataurl}

devuelve un URI de datos que contiene una representación de la imagen en el formato especificado por el parámetro type (por defecto PNG). La imagen devuelta tiene una resolución de 96 ppp.

```java
public String ToDataURL()
```

### Valor devuelto

Una DOMString que contiene la URI de datos solicitada.

## ToDataURL(String, double) {#todataurl_2}

devuelve un URI de datos que contiene una representación de la imagen en el formato especificado por el parámetro type (por defecto PNG). La imagen devuelta tiene una resolución de 96 ppp.

```java
public String ToDataURL(String type, double encoderOptions)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| type | Cadena | Una String que indica el formato de la imagen. El tipo de formato predeterminado es image/png. |
| encoderOptions | Double | Un Number entre 0 y 1 que indica la calidad de la imagen si el tipo solicitado es image/jpeg o image/webp. |

### Valor devuelto

Una DOMString que contiene la URI de datos solicitada.
