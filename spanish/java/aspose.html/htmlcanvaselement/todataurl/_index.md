## ToDataURL() {#todataurl}

devuelve una URI de datos que contiene una representación de la imagen en el formato especificado por el parámetro type (por defecto PNG). La imagen devuelta tiene una resolución de 96 dpi.

```java
public String ToDataURL()
```

### Valor de retorno

Una DOMString que contiene la URI de datos solicitada.

## ToDataURL(String, double) {#todataurl_2}

devuelve una URI de datos que contiene una representación de la imagen en el formato especificado por el parámetro type (por defecto PNG). La imagen devuelta tiene una resolución de 96 dpi.

```java
public String ToDataURL(String type, double encoderOptions)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| tipo | String | Una cadena que indica el formato de la imagen. El tipo de formato predeterminado es image/png. |
| encoderOptions | Doble | Un número entre 0 y 1 que indica la calidad de la imagen si el tipo solicitado es image/jpeg o image/webp. |

### Valor de retorno

Una DOMString que contiene la URI de datos solicitada.
