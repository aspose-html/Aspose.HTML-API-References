## HTMLCanvasElement.Width property

Es un entero positivo que refleja el atributo width de HTML del elemento canvas interpretado en píxeles CSS. Cuando el atributo no se especifica, o se establece en un valor no válido, como un número negativo, se usa el valor predeterminado de 300.

```java
public ulong Width { get; set; }
```
