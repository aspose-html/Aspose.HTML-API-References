## HTMLInputElement.DefaultValue property

Cuando el atributo `type` del elemento tiene el valor "text", "file" o "password", esto representa el atributo value de HTML del elemento. El valor de este atributo no cambia si el contenido del control de formulario correspondiente, en un agente de usuario interactivo, cambia. Consulte la definición del atributo value en HTML 4.01.

```java
public String DefaultValue { get; set; }
```
