## HTMLInputElement.Src property

Cuando el atributo `type` tiene el valor "image", este atributo especifica la ubicación de la imagen que se usará para decorar el botón de envío gráfico. Consulte la definición del atributo src en HTML 4.01.

```java
public String Src { get; set; }
```
