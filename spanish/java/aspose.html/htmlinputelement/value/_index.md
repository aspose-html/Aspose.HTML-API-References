## HTMLInputElement.Value property

Cuando el atributo `type` del elemento tiene el valor \"text\", \"file\" o \"password\", esto representa el contenido actual del control de formulario correspondiente, en un agente de usuario interactivo. Cambiar este atributo modifica el contenido del control de formulario, pero no cambia el valor del atributo HTML value del elemento. Cuando el atributo `type` del elemento tiene el valor \"button\", \"hidden\", \"submit\", \"reset\", \"image\", \"checkbox\" o \"radio\", esto representa el atributo HTML value del elemento. Consulte la definición del atributo value en HTML 4.01.

```java
public String Value { get; set; }
```
