## HTMLInputElement.DefaultChecked property

Cuando `type` tiene el valor "radio" o "checkbox", esto representa el atributo HTML checked del elemento. El valor de este atributo no cambia si el estado del control de formulario correspondiente, en un agente de usuario interactivo, cambia. Consulte la definición del atributo checked en HTML 4.01.

```java
public bool DefaultChecked { get; set; }
```
