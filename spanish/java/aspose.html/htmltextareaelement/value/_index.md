## HTMLTextAreaElement.Value property

Representa el contenido actual del control de formulario correspondiente, en un agente de usuario interactivo. Cambiar este atributo modifica el contenido del control de formulario, pero no cambia el contenido del elemento. Si la totalidad de los datos no puede caber en una sola `DOMString`, la implementación puede truncar los datos.

```java
public String Value { get; set; }
```
