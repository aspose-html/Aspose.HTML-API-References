## IHTMLOptionsCollection interface

Un `HTMLOptionsCollection` es una lista de nodos que representan el elemento option de HTML. Un nodo individual puede accederse mediante un índice ordinal o los atributos `name` o `id` del nodo. Se asume que las colecciones en el DOM HTML son dinámicas, lo que significa que se actualizan automáticamente cuando el documento subyacente cambia.

Consulte también la [Document object Model (DOM) Level 2 HTML Specification](http://www.w3.org/TR/2003/REC-DOM-Level-2-HTML-20030109). @since DOM Level 2

```java
public interface IHTMLOptionsCollection : IEnumerable<Element>
```
