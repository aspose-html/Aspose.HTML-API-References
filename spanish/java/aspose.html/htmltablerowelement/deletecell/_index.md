## HTMLTableRowElement.DeleteCell method

Eliminar una celda de la fila actual.

```java
public void DeleteCell(int index)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| index | Int32 | El índice de la celda a eliminar, comenzando desde 0. Si el índice es -1 se elimina la última celda de la fila. |

### Excepciones

| excepción | condición |
| --- | --- |
| [dOMException](../../../com.aspose.html.dom/domexception/) | INDEX_SIZE_ERR: Se produce si el `index` especificado es mayor o igual que el número de celdas o si el índice es un número negativo distinto de -1. @versión DOM Level 2 |
