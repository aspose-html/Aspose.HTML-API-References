## PdfEncryptionInfo.UserPassword property

Obtiene o establece la contraseña de usuario.

```java
public String UserPassword { get; set; }
```

### Property Value

La contraseña de usuario.

## Observaciones

Abrir el documento con la contraseña de usuario correcta (o abrir un documento que no tiene contraseña de usuario) permite realizar operaciones adicionales según los permisos de acceso de usuario especificados en el diccionario de cifrado del documento.
