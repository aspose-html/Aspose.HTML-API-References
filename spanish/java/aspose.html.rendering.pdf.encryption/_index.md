El paquete **com.aspose.html.rendering.pdf.encryption** contiene clases de datos que describen los detalles del cifrado PDF, como la contraseña, el algoritmo de cifrado, etc.

## Clases

| Clase | Descripción |
| --- | --- |
| [PdfEncryptionInfo](./pdfencryptioninfo/) | Contiene detalles para un cifrado PDF. |
## Enumeración

| Enumeración | Descripción |
| --- | --- |
| [PdfEncryptionAlgorithm](./pdfencryptionalgorithm/) | Enumeración de modo de cifrado. Describe el uso de algoritmo y longitud de clave. Esta enumeración se extiende para poder aumentar aún más la funcionalidad. Esta enumeración implementa el patrón "Base-to-Core". |
| [PdfPermissions](./pdfpermissions/) | Esta enumeración representa los permisos del usuario para un PDF. |
