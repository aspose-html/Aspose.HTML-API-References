## PdfEncryptionAlgorithm enumeration

Enumeración de modo de cifrado. Describe el uso de algoritmo y longitud de clave. Esta enumeración se extiende para poder aumentar aún más la funcionalidad. Esta enumeración implementa el patrón "Base-to-Core".

```java
public enum PdfEncryptionAlgorithm
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |

| RC4_128 | `1` | Algoritmo, con una longitud de clave de cifrado RC4 de 128 bits y conjunto de permisos avanzado; |
