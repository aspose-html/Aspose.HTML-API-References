## ICSSImportRule.StyleSheet property

La hoja de estilo referida por esta regla, si ha sido cargada. El valor de este atributo es null si la hoja de estilo aún no ha sido cargada o si no será cargada (p.ej. si la hoja de estilo es para un tipo de medio no soportado por el agente de usuario).

```java
public ICSSStyleSheet StyleSheet { get; }
```

### Property Value

Devuelve la hoja de estilo CSS especificada por la regla @import. Esto será en forma de un objeto [`CSSStyleSheet`](../../icssstylesheet/).
