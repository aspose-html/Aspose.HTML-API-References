## ICSSImportRule interface

La interfaz CSSImportRule representa una regla @import dentro de una hoja de estilo CSS. La regla @import se utiliza para importar reglas de estilo de otras hojas de estilo.

```java
public interface ICSSImportRule : ICSSRule
```

## Propiedades

| Nombre | Descripción |
| --- | --- |
| [getHref](../../com.aspose.html.dom.css/icssimportrule/href/) La propiedad de solo lectura href de la interfaz CSSImportRule devuelve la URL especificada por la regla @import. |
| [getMedia](../../com.aspose.html.dom.css/icssimportrule/media/) La propiedad de solo lectura media de la interfaz CSSImportRule devuelve un objeto MediaList, que contiene el valor del atributo media de la hoja de estilo asociada. |
| [getStyleSheet](../../com.aspose.html.dom.css/icssimportrule/stylesheet/) La hoja de estilo a la que se refiere esta regla, si ha sido cargada. El valor de este atributo es null si la hoja de estilo aún no se ha cargado o si no se cargará (p. ej., si la hoja de estilo es para un tipo de medio no soportado por el agente de usuario). |
