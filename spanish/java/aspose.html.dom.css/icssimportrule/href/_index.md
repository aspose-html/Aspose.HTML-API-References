## ICSSImportRule.Href property

La propiedad href de solo lectura de la interfaz CSSImportRule devuelve la URL especificada por la regla @import.

La URL resuelta será el atributo href de la hoja de estilo asociada.

```java
public String Href { get; }
```

### Property Value

Devuelve la URL de la hoja de estilo asociada especificada por la regla @import.
