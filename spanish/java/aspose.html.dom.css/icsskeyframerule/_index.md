## ICSSKeyframeRule interface

La interfaz `CSSKeyframeRule` describe un objeto que representa un conjunto de estilos para un keyframe dado. Corresponde al contenido de un único keyframe de una regla @keyframes.

```java
public interface ICSSKeyframeRule : ICSSRule
```

## Propiedades

| Nombre | Descripción |
| --- | --- |
| [getKeyText](../../com.aspose.html.dom.css/icsskeyframerule/keytext/) La propiedad keyText de la interfaz CSSKeyframeRule representa el selector de keyframe como una lista separada por comas de valores de porcentaje. Las palabras clave from y to se asignan a 0% y 100%, respectivamente. |
| [getStyle](../../com.aspose.html.dom.css/icsskeyframerule/style/) La propiedad de solo lectura CSSKeyframeRule.style es la interfaz [`CSSStyleDeclaration`](../icssstyledeclaration/) para el bloque de declaración del `CSSKeyframeRule`. |
