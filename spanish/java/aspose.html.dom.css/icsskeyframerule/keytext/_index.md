## ICSSKeyframeRule.KeyText property

La propiedad keyText de la interfaz CSSKeyframeRule representa el selector de fotograma clave como una lista separada por comas de valores de porcentaje. Las palabras clave from y to se asignan a 0% y 100%, respectivamente.

```java
public String KeyText { get; }
```

### Property Value

Devuelve el selector de fotograma clave como una lista separada por comas de valores de porcentaje.
