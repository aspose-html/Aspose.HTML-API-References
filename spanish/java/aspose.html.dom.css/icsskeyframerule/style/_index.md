## ICSSKeyframeRule.Style property

The read-only CSSKeyframeRule.style property es la interfaz [`CSSStyleDeclaration`](../../icssstyledeclaration/) para el bloque de declaraciones del [`CSSKeyframeRule`](../).

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

Un objeto [`CSSStyleDeclaration`](../../icssstyledeclaration/), con las siguientes propiedades:

bandera computed - Unset.declarations - Las declaraciones declaradas en la regla, en el orden en que fueron especificadas, propiedades abreviadas expandidas a sus formas largas.parent CSS rule - El objeto de contexto, que es un alias de this.owner node - Null.
