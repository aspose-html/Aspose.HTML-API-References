## IStyleSheetList indexer

El método item(index) debe devolver el [`CSS style sheet`](../../icssstylesheet/) en la posición indexth de la colección. Si no hay un objeto indexth en la colección, el método debe devolver null.

```java
public ICSSStyleSheet this[int index] { get; }
```

### Valor devuelto

Un objeto [`CSSStyleSheet`](../../icssstylesheet/), o null si no existe uno para este índice.

### Property Value

Un entero que es el índice del elemento en la colección que se debe devolver.
