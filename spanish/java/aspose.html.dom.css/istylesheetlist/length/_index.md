## IStyleSheetList.Length property

El atributo length debe devolver el número de hojas de estilo CSS representadas por la colección. El rango de índices válidos de hojas de estilo secundarias es de 0 a length-1 inclusive.

```java
public int Length { get; }
```

### Property Value

Un entero que indica el número de elementos en la colección.
