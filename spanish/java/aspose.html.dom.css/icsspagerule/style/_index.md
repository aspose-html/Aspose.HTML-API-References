## ICSSPageRule.Style property

La propiedad de solo lectura style de la interfaz [`CSSPageRule`](../) devuelve un objeto [`CSSStyleDeclaration`](../../icssstyledeclaration/). Esto representa un objeto que es un bloque de declaraciones CSS y expone información de estilo y varios métodos y propiedades relacionados con el estilo.

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

Un objeto [`CSSStyleDeclaration`](../../icssstyledeclaration/) que representa un bloque de declaraciones CSS.
