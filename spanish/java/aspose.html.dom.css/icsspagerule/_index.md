## ICSSPageRule interface

La interfaz CSSPageRule representa una regla @page dentro de una hoja de estilo CSS. La regla @page se utiliza para especificar las dimensiones, orientación, márgenes, etc., de una caja de página para medios paginados.

```java
public interface ICSSPageRule : ICSSRule
```
