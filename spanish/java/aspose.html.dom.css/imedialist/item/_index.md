## IMediaList indexer

El método item(index) debe devolver una serialización de la consulta de medios en la colección de consultas de medios dada por el índice, o null si el índice es mayor o igual que el número de consultas de medios en la colección.

```java
public String this[int index] { get; }
```

### Valor de retorno

Devuelve un String que representa una consulta de medios como texto, dado el valor de índice de la consulta de medios dentro del [`MediaList`](../).

### Property Value

Un entero que es el índice del elemento en la colección que se debe devolver.
