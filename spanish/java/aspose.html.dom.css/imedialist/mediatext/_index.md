## IMediaList.MediaText property

Un Stringifier que devuelve un DOMString que representa el MediaList como texto y también permite establecer un nuevo MediaList.

```java
public String MediaText { get; }
```

### Property Value

La representación textual que se puede analizar de la lista de medios. Es una lista de medios separada por comas.

### Excepciones

| excepción | condición |
| --- | --- |
| DOMException | SYNTAX_ERR: Generado si el valor String especificado tiene un error de sintaxis y no se puede analizar. NO_MODIFICATION_ALLOWED_ERR: Generado si esta lista de medios es de solo lectura. |
