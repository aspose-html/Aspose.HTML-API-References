## IMediaList.AppendMedium method

Agrega el medio newMedium al final de la lista. Si newMedium ya está en uso, se elimina primero.

```java
public void AppendMedium(String newMedium)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| newMedium | String | El nuevo medio a añadir. |

### Excepciones

| excepción | condición |
| --- | --- |
| DOMException | INVALID_CHARACTER_ERR: Si el medio contiene caracteres que no son válidos en el lenguaje de estilo subyacente. NO_MODIFICATION_ALLOWED_ERR: Generado si esta lista es de solo lectura. |
