## ICSSKeyframesRule.FindRule method

El método findRule devuelve la regla cuya clave coincide con la clave proporcionada. Si no existe tal regla, se devuelve un valor nulo.

```java
public ICSSKeyframeRule FindRule(String key)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| key | Cadena | La clave que describe la regla a buscar. La clave debe resolverse a un número entre 0 y 1, o la regla se ignora. |

### Valor devuelto

Devuelve el último [`CSSKeyframeRule`](../../icsskeyframerule/) declarado que coincida con el selector de fotograma clave especificado. Si no existe una regla coincidente, el método no hace nada.
