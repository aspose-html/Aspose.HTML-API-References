## ICSSKeyframesRule.DeleteRule method

El método deleteRule elimina el [`CSSKeyframeRule`](../../icsskeyframerule/) con la clave proporcionada. Si no existe una regla con esa clave, el método no hace nada.

```java
public void DeleteRule(String key)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| key | Cadena | La clave que describe la regla a eliminar. La clave debe resolverse a un número entre 0 y 1, o la regla se ignora. |
