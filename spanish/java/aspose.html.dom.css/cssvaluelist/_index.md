## CSSValueList class

La interfaz CSSValueList proporciona la abstracción de una colección ordenada de valores CSS.

Nota: Esta interfaz formó parte de un intento de crear un Modelo de Objetos CSS tipado. Este intento ha sido abandonado, y la mayoría de los navegadores no lo implementan.

```java
public class CSSValueList : CSSValue, ICSSValueList, IEnumerable<CSSValue>
```
