## CSSValueList indexer

El método item() de la interfaz CSSValueList se usa para obtener un CSSValue por índice ordinal.

El orden en esta colección representa el orden de los valores en la propiedad de estilo CSS. Si el índice es mayor o igual que el número de valores en la lista, este método devuelve null.

```java
public CSSValue this[int index] { get; }
```

### Valor devuelto

Un objeto CSSValue en la posición de índice en el CSSValueList, o null si no es un índice válido.

### Property Value

Un unsigned long que representa el índice del valor CSS dentro de la colección.
