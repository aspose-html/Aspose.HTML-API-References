## CSSValue.CSSText property

La propiedad cssText de la interfaz [`CSSValue`](../) representa el valor actual calculado de la propiedad CSS.

Nota: Esta propiedad formaba parte de un intento de crear un Modelo de Objetos CSS tipado. Este intento ha sido abandonado, y la mayoría de los navegadores no lo implementan.

```java
public abstract String CSSText { get; set; }
```

### Property Value

Una DOMString que representa el valor actual de la propiedad CSS.
