## ICSSRule.CSSText property

La propiedad cssText de la interfaz [`CSSRule`](../) devuelve el texto real de una regla de estilo [`CSSStyleSheet`](../../icssstylesheet/).

Nota: No confunda esta propiedad con CSSStyleDeclaration.cssText de estilo de elemento.

```java
public String CSSText { get; set; }
```

### Property Value

Devuelve una serialización de la regla CSS. Al establecer el atributo cssText no debe hacer nada.
