## ICSSRule.Type property

El tipo de la regla, según lo definido en [CSSOM # dom-cssrule-type](https://drafts.csswg.org/cssom/#dom-cssrule-type). Se espera que los métodos de casting específicos del binding puedan usarse para convertir una instancia de la interfaz CSSRule al interfaz derivada específica implícita por el tipo.

```java
public short Type { get; }
```

### Property Value

Un entero no negativo asociado a un tipo particular de regla. Este elemento se inicializa cuando se crea una regla y no puede cambiar.
