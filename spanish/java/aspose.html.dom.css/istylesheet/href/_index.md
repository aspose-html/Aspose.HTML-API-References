## IStyleSheet.Href property

La propiedad href de la interfaz [`StyleSheet`](../) devuelve la ubicación de la hoja de estilo.

```java
public String Href { get; }
```

### Property Value

uri es una cadena que contiene el URI de la hoja de estilo.

## Observaciones

Si la hoja de estilo es una hoja de estilo vinculada, el valor de su atributo es su ubicación. Para hojas de estilo en línea, el valor de este atributo es NULL.

Esta propiedad es de solo lectura en Firefox, Opera, Google Chrome y Safari, y es de lectura/escritura en Internet Explorer.
