## IStyleSheet.Type property

Esto especifica el lenguaje de hoja de estilo para esta hoja de estilo. El lenguaje de hoja de estilo se especifica como un tipo de contenido (p. ej. "text/css").

```java
public String Type { get; }
```

### Property Value

El atributo type debe devolver el tipo.
