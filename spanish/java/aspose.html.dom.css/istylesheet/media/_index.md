## IStyleSheet.Media property

La propiedad media de la interfaz [`StyleSheet`](../) especifica el medio de destino previsto para la información de estilo. Es un objeto [`MediaList`](../../imedialist/) similar a un arreglo, de solo lectura, y puede eliminarse con deleteMedium() y añadirse con appendMedium().

```java
public IMediaList Media { get; }
```

### Property Value

El atributo media debe devolver el objeto [`MediaList`](../../imedialist/) asociado con la hoja de estilo CSS.

## Observaciones

[CSSOM](https://drafts.csswg.org/cssom/) defines APIs (including generic parsing and serialization rules) for Media Queries, Selectors, and of course CSS itself.
