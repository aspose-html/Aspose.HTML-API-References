## IElementCSSInlineStyle.Style property

El atributo style debe devolver un objeto bloque de declaración CSS cuya bandera computed está sin establecer, cuya regla CSS padre es nula y cuyo nodo propietario es el objeto de contexto.

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

El bloque de declaración CSS asociado al nodo o null si no hay un bloque de declaración CSS asociado.
