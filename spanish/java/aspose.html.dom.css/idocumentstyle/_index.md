## IDocumentStyle interface

La interfaz DocumentStyle proporciona un mecanismo mediante el cual se pueden obtener las hojas de estilo incrustadas en un documento. Se espera que una instancia de la interfaz DocumentStyle pueda obtenerse usando métodos de casting específicos del enlace en una instancia de la interfaz Document.

Vea también la [Document Object Model (DOM) Level 2 Style Specification](http://www.w3.org/TR/2000/REC-DOM-Level-2-Style-20001113).

```java
public interface IDocumentStyle
```

| Nombre | Descripción |
| --- | --- |
| [getStyleSheets](../../com.aspose.html.dom.css/idocumentstyle/stylesheets/) Una lista que contiene todas las hojas de estilo vinculadas explícitamente o incrustadas en un documento. Para documentos HTML, esto incluye hojas de estilo externas, incluidas mediante el elemento HTML LINK, y elementos STYLE en línea. |
