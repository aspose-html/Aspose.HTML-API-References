```java
public CSSPrimitiveValue Red { get; }
```

### Property Value

El valor del componente rojo de este Color.

## Observaciones

El color de cada píxel se representa como un número de 32 bits: 8 bits para alfa, rojo, verde y azul (ARGB). El componente alfa especifica la transparencia del color: 0 es totalmente transparente y 255 es totalmente opaco. De manera similar, un valor A de 255 representa un color opaco. Un valor A entre 1 y 254 representa un color semitransparente. El color se vuelve más opaco a medida que A se acerca a 255.
