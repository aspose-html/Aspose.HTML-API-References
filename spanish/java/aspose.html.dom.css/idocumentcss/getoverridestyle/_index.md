## IDocumentCSS.GetOverrideStyle method

Este método se usa para obtener la declaración de estilo de sobrescritura para un elemento especificado y un pseudo‑elemento especificado.

```java
public ICSSStyleDeclaration GetOverrideStyle(Element elt, String pseudoElt)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| elt | Elemento | El elemento cuyo estilo será modificado. Este parámetro no puede ser nulo. |
| pseudoElt | Cadena | El pseudo‑elemento o nulo si no hay ninguno. |

### Valor devuelto

La declaración de estilo de anulación.
