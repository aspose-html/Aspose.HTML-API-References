## CSSEngineMode enumeration

Especifica el modo CSSEngine. Los valores tienen el siguiente significado:

default - El analizador CSS funcionará de acuerdo con la recomendación w3c y no admite extensiones personalizadas.not-strict - Todas las propiedades no documentadas serán analizadas y podrán accederse a través de.

```java
[Flags]
public enum CSSEngineMode
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Default | `0` | El analizador CSS funcionará de acuerdo con la recomendación w3c y no admite las extensiones personalizadas. |
| NotStrict | `1` | El analizador CSS funcionará en modo no estricto. Todas las propiedades no documentadas serán analizadas y podrán accederse a través de. |
