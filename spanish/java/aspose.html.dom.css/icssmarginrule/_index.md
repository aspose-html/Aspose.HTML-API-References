## ICSSMarginRule interface

La interfaz CSSMarginRule representa una regla at-rule de margen (p. ej., @top-left) en una regla at-rule @page.

```java
public interface ICSSMarginRule : ICSSRule
```

## Propiedades

| Nombre | Descripción |
| --- | --- |
| [getName](../../com.aspose.html.dom.css/icssmarginrule/name/) El atributo name debe devolver el nombre de la regla de margen. El carácter @ no está incluido en el nombre. |
| [getStyle](../../com.aspose.html.dom.css/icssmarginrule/style/) El atributo style debe devolver un objeto [`CSSStyleDeclaration`](../icssstyledeclaration/) para la regla de margen. |
