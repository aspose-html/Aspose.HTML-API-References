## ICSSStyleRule interface

La interfaz CSSStyleRule representa una única regla de estilo CSS. El atributo selectorText, al obtenerse, debe devolver el resultado de serializar el grupo de selectores asociado.

```java
public interface ICSSStyleRule : ICSSRule
```

## Propiedades

| Nombre | Descripción |
| --- | --- |
| [getSelectorText](../../com.aspose.html.dom.css/icssstylerule/selectortext/) La representación textual del selector para el conjunto de reglas. La implementación puede haber eliminado espacios en blanco insignificantes al analizar el selector. |
| [getStyle](../../com.aspose.html.dom.css/icssstylerule/style/) La propiedad de estilo de solo lectura es la interfaz [`CSSStyleDeclaration`](../icssstyledeclaration/) para el bloque de declaración del `CSSStyleRule`. |
