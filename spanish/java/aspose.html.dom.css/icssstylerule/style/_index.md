## ICSSStyleRule.Style property

La propiedad de estilo de solo lectura es la interfaz [`CSSStyleDeclaration`](../../icssstyledeclaration/) para el bloque de declaración del [`CSSStyleRule`](../).

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

El atributo style debe devolver un objeto CSSStyleDeclaration para la regla de estilo, con las siguientes propiedades:

bandera computed - Unset.declarations - Las declaraciones declaradas en la regla, en el orden especificado. parent CSS rule - El objeto de contexto. owner node - Null.
