## ICSSStyleSheet.DeleteRule method

El método deleteRule() de [`CSSStyleSheet`](../) elimina una regla del objeto hoja de estilos.

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| index | Int32 | El índice en la [`CSSRuleList`](../../icssrulelist/) de la hoja de estilos que indica la regla a eliminar. |
