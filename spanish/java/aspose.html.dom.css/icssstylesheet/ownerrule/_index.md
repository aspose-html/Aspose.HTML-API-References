## ICSSStyleSheet.OwnerRule property

La propiedad de solo lectura ownerRule de CSSStyleSheet devuelve el [`CSSImportRule`](../../icssimportrule/) correspondiente a la regla @import que importó la hoja de estilo al documento. Si la hoja de estilo no fue importada al documento mediante @import, el valor devuelto es null.

```java
public ICSSRule OwnerRule { get; }
```

### Property Value

Un CSSImportRule correspondiente a la regla @import que importó la hoja de estilo al documento. Si la hoja de estilo no fue importada al documento mediante @import, el valor devuelto es null.
