## CSSPrimitiveValue.SetFloatValue method

Un método para establecer el valor flotante con una unidad especificada. Si la propiedad asociada a este valor no puede aceptar la unidad especificada o el valor flotante, el valor permanecerá sin cambios y se lanzará una DOMException.

```java
public abstract void SetFloatValue(ushort unitType, float floatValue)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| unitType | UInt16 | Tipo de la unidad. |
| floatValue | Single | El valor flotante. |
