## CSSPrimitiveValue.GetRectValue method

Este método se usa para obtener el valor Rect. Si este valor CSS no contiene un valor rect, se lanza una DOMException. La modificación de la propiedad de estilo correspondiente se puede lograr usando la interfaz Rect.

```java
public abstract Rect GetRectValue()
```

### Valor de retorno

Devuelve el valor Rect
