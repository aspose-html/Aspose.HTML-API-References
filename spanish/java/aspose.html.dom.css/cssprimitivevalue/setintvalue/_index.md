## CSSPrimitiveValue.SetIntValue method

Un método para establecer el valor entero con una unidad especificada. Si la propiedad asociada a este valor no puede aceptar la unidad especificada o el valor entero, el valor permanecerá sin cambios y se lanzará una DOMException.

```java
public abstract void SetIntValue(ushort unitType, int intValue)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| unitType | UInt16 | Tipo de la unidad. |
| intValue | Int32 | El valor entero. |
