## CSSPrimitiveValue.GetRGBColorValue method

Este método se usa para obtener el color RGB. Si este valor CSS no contiene un valor de color RGB, se lanza una DOMException. La modificación de la propiedad de estilo correspondiente se puede lograr usando la interfaz RGBColor.

```java
public abstract RGBColor GetRGBColorValue()
```

### Valor de retorno

Devuelve el valor de color RGB
