## CSSPrimitiveValue.SetStringValue method

Un método para establecer el valor String con la unidad especificada. Si la propiedad asociada a este valor no puede aceptar la unidad especificada o el valor String, el valor permanecerá sin cambios y se lanzará una DOMException.

```java
public abstract void SetStringValue(ushort StringType, String StringValue)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| StringType | UInt16 | Tipo de la cadena. |
| StringValue | String | El valor de la cadena. |
