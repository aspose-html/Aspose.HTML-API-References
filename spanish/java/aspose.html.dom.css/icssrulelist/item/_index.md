## ICSSRuleList indexer

Se usa para recuperar una regla CSS mediante el método item() (http://www.w3.org/TR/DOM-Level-2-Style/css.html#CSS-CSSRuleList). El orden en esta colección representa el orden de las reglas en la hoja de estilo CSS. Si el índice es mayor o igual que el número de reglas en la lista, esto devuelve null.

```java
public ICSSRule this[int index] { get; }
```

### Valor devuelto

El método item(index) debe devolver el objeto CSSRule en la posición índice de la colección. Si no hay un objeto en esa posición en la colección, el método debe devolver null.

### Property Value

El índice en la colección de reglas CSS.
