## ICSSFontFaceRule interface

La interfaz CSSFontFaceRule representa una regla @font-face en una hoja de estilo CSS. La regla @font-face se utiliza para contener un conjunto de descripciones de fuentes.

```java
public interface ICSSFontFaceRule : ICSSRule
```
