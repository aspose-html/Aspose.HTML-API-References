## Rect.Bottom property

Este atributo se usa para la parte inferior del rect.

```java
public CSSPrimitiveValue Bottom { get; }
```

### Property Value

El valor del eje y de la parte inferior del rectángulo. Si el rectángulo está vacío, el valor es NegativeInfinity.
