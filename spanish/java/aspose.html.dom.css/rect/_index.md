## Rect class

La interfaz Rect se usa para representar cualquier valor rect. Esta interfaz refleja los valores en la propiedad de estilo subyacente. Por lo tanto, las modificaciones realizadas a los objetos [`CSSPrimitiveValue`](../cssprimitivevalue/) modifican la propiedad de estilo.

```java
public class Rect : DOMObject
```
