## ICSSMediaRule.CSSRules property

La propiedad cssRules de la interfaz CSSGroupingRule devuelve una [`CSSRuleList`](../../icssrulelist/) que contiene una colección de objetos [`CSSRule`](../../icssrule/).

```java
public ICSSRuleList CSSRules { get; }
```

### Property Value

El atributo cssRules debe devolver un objeto [`CSSRuleList`](../../icssrulelist/) para las reglas CSS hijas.
