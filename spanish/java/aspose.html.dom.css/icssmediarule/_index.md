## ICSSMediaRule interface

La interfaz CSSMediaRule representa una regla @media en una hoja de estilo CSS. Una regla @media puede usarse para delimitar reglas de estilo para tipos de medios específicos.

```java
public interface ICSSMediaRule : ICSSRule
```

| Nombre | Descripción |
| --- | --- |
| [getCSSRules](../../com.aspose.html.dom.css/icssmediarule/cssrules/) La propiedad cssRules de la interfaz CSSGroupingRule devuelve una [`CSSRuleList`](../icssrulelist/) que contiene una colección de objetos [`CSSRule`](../icssrule/). |
| [getMedia](../../com.aspose.html.dom.css/icssmediarule/media/) La propiedad de solo lectura media de la interfaz `CSSMediaRule` MediaList representa el medio de destino previsto para la información de estilo. |
