## ICSSMediaRule.Media property

La propiedad de solo lectura media de la interfaz [`CSSMediaRule`](../) MediaList representa el medio de destino previsto para la información de estilo.

```java
public IMediaList Media { get; }
```

### Property Value

El atributo media debe devolver un objeto MediaList para la lista de consultas de medios especificadas con la regla @media.
