## ICSSMediaRule.InsertRule method

El método insertRule() de la interfaz CSSGroupingRule agrega una nueva regla CSS a una lista de reglas CSS.

```java
public long InsertRule(String rule, long index)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| regla | Cadena | La regla de medios como CSSOMString. |
| index | Int64 | Un índice opcional en el que insertar la regla; por defecto es 0. |

### Valor devuelto

El método insertRule(regla, índice) devuelve el resultado de invocar la inserción de una regla CSS en las reglas CSS hijas en el índice.
