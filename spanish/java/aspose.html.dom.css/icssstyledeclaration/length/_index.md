## ICSSStyleDeclaration.Length property

La propiedad de solo lectura devuelve un número entero de propiedades que se han establecido explícitamente en este bloque de declaración CSS. El rango de índices válidos es de 0 a length-1 inclusive.

```java
public int Length { get; }
```

### Property Value

Un entero que indica el número de estilos establecidos explícitamente en el padre de la instancia.
