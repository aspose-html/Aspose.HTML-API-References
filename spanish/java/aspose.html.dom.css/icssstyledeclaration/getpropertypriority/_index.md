## ICSSStyleDeclaration.GetPropertyPriority method

Se usa para recuperar la prioridad de una propiedad CSS (p. ej., el calificador "important") si la propiedad ha sido establecida explícitamente en este bloque de declaración.

```java
public String GetPropertyPriority(String propertyName)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| propertyName | String | property es una DOMString que representa el nombre de la propiedad a comprobar. |

### Valor de retorno

priority es una DOMString que representa la prioridad (p. ej., "important") si existe. Si no existe, devuelve la cadena vacía.
