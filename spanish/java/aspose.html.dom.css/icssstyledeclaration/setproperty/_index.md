## SetProperty(String, String) {#setproperty}

La interfaz del método CSSStyleDeclaration.setProperty() se usa para establecer el valor de una propiedad con prioridad predeterminada dentro de este bloque de declaración. La prioridad predeterminada no es "important", es decir, String.Empty.

```java
public void SetProperty(String propertyName, String value)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| propertyName | Cadena | Una cadena que representa el nombre de la propiedad CSS (con guiones) a modificar. |
| valor | Cadena | Una cadena que contiene el nuevo valor de la propiedad. Si no se especifica, se trata como una cadena vacía. |

## SetProperty(String, String, String) {#setproperty_1}

La interfaz del método CSSStyleDeclaration.setProperty() se usa para establecer el valor de una propiedad con prioridad predeterminada dentro de este bloque de declaración. La prioridad predeterminada no es "important", es decir, String.Empty.

```java
public void SetProperty(String propertyName, String value, String priority)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| propertyName | Cadena | Una cadena que representa el nombre de la propiedad CSS (con guiones) a modificar. |
| valor | Cadena | Una cadena que contiene el nuevo valor de la propiedad. Si no se especifica, se trata como una cadena vacía. |
| prioridad | Cadena | Una cadena que permite establecer la prioridad CSS "important". Si no se especifica, se trata como una cadena vacía. Los valores aceptados son: valor de cadena "important", palabra clave undefined o cadena vacía "". |
