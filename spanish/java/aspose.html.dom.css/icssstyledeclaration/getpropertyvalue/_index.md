## ICSSStyleDeclaration.GetPropertyValue method

La interfaz del método CSSStyleDeclaration.getPropertyValue() devuelve una cadena que contiene el valor de una propiedad CSS especificada.

```java
public String GetPropertyValue(String propertyName)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| propertyName | Cadena | propertyName es una String que representa el nombre de la propiedad (en formato con guiones) a comprobar. |

### Valor devuelto

value es una String que contiene el valor de la propiedad. Si no está establecida, devuelve la String vacía.
