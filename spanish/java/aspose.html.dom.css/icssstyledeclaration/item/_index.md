## ICSSStyleDeclaration indexer

Se usa para obtener las propiedades que se han establecido explícitamente en este bloque de declaración. El orden de las propiedades recuperadas mediante este método no tiene que coincidir con el orden en que fueron establecidas. Este método puede usarse para iterar sobre todas las propiedades en este bloque de declaración.

```java
public String this[int index] { get; }
```

### Valor de retorno

propertyName es una cadena que representa el nombre de la propiedad CSS en el índice especificado.

### Property Value

index es el índice del nodo a obtener. El índice comienza en cero.
