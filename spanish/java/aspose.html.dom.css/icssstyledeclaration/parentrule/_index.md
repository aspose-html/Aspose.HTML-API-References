## ICSSStyleDeclaration.ParentRule property

La propiedad de solo lectura CSSStyleDeclaration.parentRule devuelve un CSSRule que es el padre de este bloque de estilo, por ejemplo, un [`CSSStyleRule`](../../icssstylerule/) que representa el estilo para un selector CSS.

```java
public ICSSRule ParentRule { get; }
```

### Property Value

La regla CSS que contiene este bloque de declaración o null si este [`CSSStyleDeclaration`](../) no está adjunto a un [`CSSRule`](../../icssrule/).
