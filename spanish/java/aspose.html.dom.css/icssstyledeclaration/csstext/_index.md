## ICSSStyleDeclaration.CSSText property

La representación textual analizables del bloque de declaración (excluyendo las llaves circundantes). Establecer este atributo provocará el análisis del nuevo valor y el restablecimiento de todas las propiedades en el bloque de declaración, incluida la eliminación o adición de propiedades.

```java
public String CSSText { get; set; }
```

### Property Value

Establecer este atributo cambia el estilo inline. Si deseas una representación textual de un bloque de declaración calculado, puedes obtenerla con JSON.Stringify().
