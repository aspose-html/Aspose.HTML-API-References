## ICSS2Properties.ListStyleType property

Esta propiedad especifica la apariencia del marcador de elemento de lista si ['list-style-image'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-list-style-image) tiene el valor 'none' o si la imagen a la que apunta el URI no puede mostrarse. El valor 'none' indica que no hay marcador; de lo contrario existen tres tipos de marcador: glifos, sistemas de numeración y sistemas alfabéticos. Nota. Las listas numeradas mejoran la accesibilidad del documento al facilitar la navegación por las listas.

Los glifos se especifican con disc, circle y square. Su renderizado exacto depende del agente de usuario.

Los sistemas de numeración se especifican con:

decimal - Números decimales, comenzando con 1.decimal-leading-zero - Números decimales con ceros iniciales (p.ej., 01, 02, 03, ..., 98, 99).lower-roman - Numerales romanos en minúscula (i, ii, iii, iv, v, etc.).upper-roman - Numerales romanos en mayúscula (I, II, III, IV, V, etc.).hebrew - Numeración hebrea tradicional.georgian - Numeración georgiana tradicional (an, ban, gan, ..., he, tan, in, in-an, ...).armenian - Numeración armenia tradicional.cjk-ideographic - Números ideográficos simpleshiragana - a, i, u, e, o, ka, ki, ...katakana - A, I, U, E, O, KA, KI, ...hiragana-iroha - i, ro, ha, ni, ho, he, to, ...katakana-iroha - I, RO, HA, NI, HO, HE, TO, ...

public String ListStyleType { get; set; }
