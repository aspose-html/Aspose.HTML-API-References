## ICSS2Properties.Height property

Esta propiedad especifica la [altura del contenido](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#content-height) de los cuadros generados por elementos de nivel de bloque y [reemplazados](https://www.w3.org/TR/1998/REC-CSS2-19980512/conform.html#replaced-element) elementos.

Esta propiedad no se aplica a los elementos [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) no reemplazados. La altura de los cuadros de un elemento inline no reemplazado se determina por el valor (posiblemente heredado) de ['line-height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-line-height) del elemento.

```java
public String Height { get; set; }
```
