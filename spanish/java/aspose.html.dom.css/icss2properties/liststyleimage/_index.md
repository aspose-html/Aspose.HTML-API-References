## ICSS2Properties.ListStyleImage property

Esta propiedad establece la imagen que se usará como marcador de elemento de lista. Cuando la imagen está disponible, reemplazará el conjunto de marcadores con el marcador ['list-style-type'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-list-style-type).

```java
public String ListStyleImage { get; set; }
```

### Valor devuelto

propiedad list-style-image
