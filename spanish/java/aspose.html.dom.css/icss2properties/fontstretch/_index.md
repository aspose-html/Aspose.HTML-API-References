## ICSS2Properties.FontStretch property

La propiedad ['font-stretch'](https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html#propdef-font-stretch) selecciona una fuente normal, condensada o extendida de una familia tipográfica. Los valores de palabra clave absolutos tienen el siguiente orden, de la más estrecha a la más ancha:

ultra-condensedextra-condensedcondensedsemi-condensednormalsemi-expandedexpandedextra-expandedultra-expanded
