## ICSS2Properties.EmptyCells property

En el modelo de bordes separados, esta propiedad controla la representación de los bordes alrededor de las celdas que no tienen contenido visible. Las celdas vacías y las celdas con la propiedad 'visibility' establecida en 'hidden' se consideran sin contenido visible.

```java
public String EmptyCells { get; set; }
```

### Valor de retorno

propiedad empty-cells
