## ICSS2Properties.VoiceFamily property

El valor es una lista priorizada, separada por comas, de nombres de familia de voz (compare con ['font-family'](https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html#propdef-font-family)). Los valores tienen los siguientes significados:

'generic-voice' - Los valores son familias de voz. Los valores posibles son 'male', 'female' y 'child'.'specific-voice' - Los valores son instancias específicas (p.ej., comedian, trinoids, carlos, lani).

public String VoiceFamily { get; set; }
