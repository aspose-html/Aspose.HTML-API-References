## ICSS2Properties.Margin property

La propiedad ['margin'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin) es una propiedad abreviada para establecer ['margin-top'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-top), ['margin-right'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-right), ['margin-bottom'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-bottom) y ['margin-left'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-left) en el mismo lugar de la hoja de estilo.

Si solo hay un valor, se aplica a todos los lados. Si hay dos valores, los márgenes superior e inferior se establecen al primer valor y los márgenes derecho e izquierdo al segundo. Si hay tres valores, el superior se establece al primer valor, los izquierdo y derecho al segundo, y el inferior al tercer valor. Si hay cuatro valores, se aplican al superior, derecho, inferior e izquierdo, respectivamente.

```java
public String Margin { get; set; }
```
