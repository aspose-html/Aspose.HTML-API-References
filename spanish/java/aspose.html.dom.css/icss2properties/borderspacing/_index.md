## ICSS2Properties.BorderSpacing property

Las longitudes especifican la distancia que separa los bordes de celdas adyacentes. Si se especifica una longitud, proporciona tanto el espaciado horizontal como el vertical. Si se especifican dos, la primera da el espaciado horizontal y la segunda el espaciado vertical. Las longitudes no pueden ser negativas.

```java
public String BorderSpacing { get; set; }
```

propiedad border-spacing
