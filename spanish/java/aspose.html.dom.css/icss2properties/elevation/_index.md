## ICSS2Properties.Elevation property

Los valores de esta propiedad tienen los siguientes significados:

'angle' - Especifica la elevación como un ángulo, entre '-90deg' y '90deg'. '0deg' significa en el horizonte delantero, lo que en términos generales significa nivel con el oyente. '90deg' significa directamente sobre la cabeza y '-90deg' significa directamente debajo. below - Lo mismo que '-90deg'. level - Lo mismo que '0deg'. above - Lo mismo que '90deg'. higher - Añade 10 grados a la elevación actual. lower - Resta 10 grados a la elevación actual.

public String Elevation { get; set; }
