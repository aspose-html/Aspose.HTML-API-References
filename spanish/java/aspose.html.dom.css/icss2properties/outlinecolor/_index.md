## ICSS2Properties.OutlineColor property

El contorno creado con las propiedades de contorno se dibuja \"sobre\" una caja, es decir, el contorno está siempre encima y no influye en la posición o el tamaño de la caja, o de cualquier otra caja. Por lo tanto, mostrar u ocultar contornos no provoca reflujo.

```java
public String OutlineColor { get; set; }
```

### Valor de retorno

normal - El elemento no abre un nivel adicional de incrustación respecto al algoritmo bidireccional. Para los elementos en línea, el reordenamiento implícito funciona a través de los límites de los elementos.
