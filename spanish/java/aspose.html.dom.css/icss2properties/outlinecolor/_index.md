## ICSS2Properties.OutlineColor property

El contorno creado con las propiedades de outline se dibuja "sobre" una caja, es decir, el contorno está siempre encima y no influye en la posición o el tamaño de la caja, ni de ninguna otra caja. Por lo tanto, mostrar u ocultar contornos no provoca reflujo.

```java
public String OutlineColor { get; set; }
```
