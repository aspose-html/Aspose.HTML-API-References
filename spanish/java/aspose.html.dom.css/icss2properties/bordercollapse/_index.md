## ICSS2Properties.BorderCollapse property

Esta propiedad selecciona el modelo de bordes de una tabla. El valor 'separate' selecciona el modelo de bordes separados. El valor 'collapse' selecciona el modelo de bordes colapsados. Los modelos se describen a continuación.
