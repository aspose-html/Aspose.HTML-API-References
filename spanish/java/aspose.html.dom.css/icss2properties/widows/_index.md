## ICSS2Properties.Widows property

La propiedad ['orphans'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-orphans) especifica el número mínimo de líneas de un párrafo que deben quedar al final de una página. La propiedad ['widows'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-widows) especifica el número mínimo de líneas de un párrafo que deben quedar al inicio de una página. A continuación se presentan ejemplos de cómo se utilizan para controlar los saltos de página.

```java
public String Widows { get; set; }
```
