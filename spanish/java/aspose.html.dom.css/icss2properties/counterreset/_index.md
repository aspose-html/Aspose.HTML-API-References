## ICSS2Properties.CounterReset property

La propiedad ['counter-reset'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-counter-reset) también contiene una lista de uno o más nombres de contadores, cada uno opcionalmente seguido por un entero. El entero indica el valor al que se establece el contador en cada aparición del elemento. El valor predeterminado es 0.

```java
public String CounterReset { get; set; }
```

propiedad counter-reset
