## ICSS2Properties.MarkerOffset property

Esta propiedad especifica la distancia entre los [bordes más cercanos](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#border-edge) de una caja de marcador y su [caja principal](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#principal-box) asociada. El desplazamiento puede ser una ([longitud](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)) especificada por el usuario o elegida por el UA ('auto'). Las longitudes pueden ser negativas, pero pueden existir límites específicos de la implementación.

```java
public String MarkerOffset { get; set; }
```
