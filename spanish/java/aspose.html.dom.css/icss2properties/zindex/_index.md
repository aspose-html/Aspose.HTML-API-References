## ICSS2Properties.ZIndex property

Para una caja posicionada, la propiedad ['z-index'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-z-index) especifica:

El nivel de apilamiento de la caja en el contexto de apilamiento actual. Si la caja establece un contexto de apilamiento local.

public String ZIndex { get; set; }
