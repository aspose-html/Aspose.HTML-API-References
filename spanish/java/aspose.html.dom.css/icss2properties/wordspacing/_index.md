## ICSS2Properties.WordSpacing property

Esta propiedad especifica el comportamiento del espaciado entre palabras. Los valores tienen los siguientes significados:

normal - El espacio interpalabras normal, según lo definido por la fuente actual y/o el UA. '[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - Este valor indica un espacio interpalabras adicional al espacio predeterminado entre palabras. Los valores pueden ser negativos, pero pueden existir límites específicos de la implementación.

```java
public String WordSpacing { get; set; }
```
