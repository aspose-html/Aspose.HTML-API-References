## ICSS2Properties.FontVariant property

En una fuente small-caps, los glifos de las letras minúsculas se parecen a los de mayúsculas, pero en un tamaño más pequeño y con proporciones ligeramente diferentes. La propiedad 'font-variant' solicita una fuente de este tipo para sistemas bicamerales (que tienen dos casos, como el alfabeto latino). Esta propiedad no tiene efecto visible para los sistemas de escritura unicamerales (que tienen un solo caso, como la mayoría de los sistemas de escritura del mundo).

```java
public String FontVariant { get; set; }
```

### Valor de retorno

propiedad font-variant
