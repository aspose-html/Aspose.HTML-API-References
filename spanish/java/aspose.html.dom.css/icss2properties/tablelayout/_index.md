## ICSS2Properties.TableLayout property

La propiedad ['table-layout'](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#propdef-table-layout) controla el algoritmo utilizado para organizar las celdas, filas y columnas de la tabla. Los valores tienen el siguiente significado:

fixed - Usa el algoritmo de diseño de tabla fijo. auto - Usa cualquier algoritmo de diseño de tabla automático

public String TableLayout { get; set; }
