## ICSS2Properties.Richness property

Especifica la riqueza, o brillantez, de la voz hablada. Una voz rica "se propagará" en una sala grande, una voz suave no lo hará. (El término "suave" se refiere a cómo se ve la forma de onda cuando se dibuja.)

```java
public String Richness { get; set; }
```
