## ICSS2Properties.BorderTopColor property

La propiedad 'border-color' establece el color de los cuatro bordes. Los valores tienen los siguientes significados:

color - Especifica un valor de color.
transparent - El borde es transparente (aunque puede tener ancho).

public String BorderTopColor { get; set; }
