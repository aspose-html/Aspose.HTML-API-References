## ICSS2Properties.Background property

La propiedad 'background' es una propiedad abreviada para establecer las propiedades de fondo individuales (es decir, 'background-color', 'background-image', 'background-repeat', 'background-attachment' y 'background-position') en el mismo lugar de la hoja de estilo.

```java
public String Background { get; set; }
```

### Valor de retorno

la propiedad background

### Property Value

Obtiene o establece una propiedad abreviada para establecer las propiedades de fondo individuales en el mismo lugar de la hoja de estilo.
