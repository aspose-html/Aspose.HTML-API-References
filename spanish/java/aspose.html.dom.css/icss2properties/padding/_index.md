## ICSS2Properties.Padding property

La propiedad ['padding'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-padding) es una propiedad abreviada para establecer ['padding-top'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-padding-top), ['padding-right'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-padding-right), ['padding-bottom'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-padding-bottom), y ['padding-left'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-padding-left) en el mismo lugar de la hoja de estilo.

Si solo hay un valor, se aplica a todos los lados. Si hay dos valores, los rellenos superior e inferior se establecen al primer valor y los rellenos derecho e izquierdo al segundo. Si hay tres valores, el superior se establece al primer valor, los laterales izquierdo y derecho al segundo, y el inferior al tercer valor. Si hay cuatro valores, se aplican respectivamente al superior, derecho, inferior y izquierdo.

```java
public String Padding { get; set; }
```
