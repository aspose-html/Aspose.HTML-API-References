## ICSS2Properties.SpeakPunctuation property

Esta propiedad especifica cómo se pronuncia la puntuación. Los valores tienen los siguientes significados:

code - Puntuación como puntos y comas, llaves, etc., debe pronunciarse literalmente.none - La puntuación no debe pronunciarse, sino que se representa naturalmente como varias pausas.

public String SpeakPunctuation { get; set; }
