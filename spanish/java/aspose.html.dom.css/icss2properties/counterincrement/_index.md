## ICSS2Properties.CounterIncrement property

La propiedad ['counter-increment'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-counter-increment) acepta uno o más nombres de contadores (identificadores), cada uno opcionalmente seguido por un entero. El entero indica en cuánto se incrementa el contador por cada aparición del elemento. El incremento predeterminado es 1. Se permiten enteros cero y negativos.

```java
public String CounterIncrement { get; set; }
```
