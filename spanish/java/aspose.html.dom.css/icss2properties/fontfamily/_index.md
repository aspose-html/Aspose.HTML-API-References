## ICSS2Properties.FontFamily property

Esta propiedad especifica una lista priorizada de nombres de familias tipográficas y/o nombres de familias genéricas. Para abordar el problema de que una sola fuente puede no contener glifos para mostrar todos los caracteres de un documento, o que no todas las fuentes están disponibles en todos los sistemas, esta propiedad permite a los autores especificar una lista de fuentes, todas del mismo estilo y tamaño, que se prueban en secuencia para ver si contienen un glifo para un carácter determinado. Esta lista se llama conjunto de fuentes.

```java
public String FontFamily { get; set; }
```
