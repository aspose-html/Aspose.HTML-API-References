## ICSS2Properties.Visibility property

La propiedad ['visibility'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visufx.html#propdef-visibility) especifica si los cuadros generados por un elemento se renderizan. Los cuadros invisibles siguen afectando el diseño (establezca la propiedad ['display'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-display) a 'none' para suprimir la generación de cuadros por completo). Los valores tienen los siguientes significados:

visible - El cuadro generado es visible. hidden - El cuadro generado es invisible (totalmente transparente), pero sigue afectando el diseño. collapse - Consulte la sección sobre [dynamic row and column effects](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#dynamic-effects) en tablas. Si se usa en elementos que no sean filas o columnas, 'collapse' tiene el mismo significado que 'hidden'.

```java
public String Visibility { get; set; }
```

propiedad visibility
