## ICSS2Properties.ListStylePosition property

Esta propiedad especifica la posición del cuadro del marcador en el bloque principal. Los valores tienen los siguientes significados:

outside - El cuadro del marcador está fuera del bloque principal. Nota. CSS1 no especificó la ubicación precisa del cuadro del marcador y, por razones de compatibilidad, CSS2 sigue siendo igualmente ambiguo. Para un control más preciso de los cuadros del marcador, por favor use markers.inside - El cuadro del marcador es el primer cuadro en línea en el bloque principal, después del cual fluye el contenido del elemento.

public String ListStylePosition { get; set; }
