## ICSS2Properties.BackgroundRepeat property

Si se especifica una imagen de fondo, esta propiedad indica si la imagen se repite (en mosaico) y cómo. Todo el mosaico cubre las áreas de contenido y relleno de una caja. Los valores tienen los siguientes significados:

repeat - La imagen se repite tanto horizontal como verticalmente. repeat-x - La imagen se repite solo horizontalmente. repeat-y - La imagen se repite solo verticalmente. no-repeat - La imagen no se repite: solo se dibuja una copia de la imagen.

```java
public String BackgroundRepeat { get; set; }
```

### Valor de retorno

propiedad background-repeat

### Property Value

El valor de background-repeat de la lista tal como se definió arriba.
