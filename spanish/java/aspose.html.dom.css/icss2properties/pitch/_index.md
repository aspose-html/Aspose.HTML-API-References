## ICSS2Properties.Pitch property

Especifica el tono medio (una frecuencia) de la voz hablada. El tono medio de una voz depende de la familia vocal. Por ejemplo, el tono medio de una voz masculina estándar es alrededor de 120 Hz, pero el de una voz femenina es alrededor de 210 Hz.

public String Pitch { get; set; }
