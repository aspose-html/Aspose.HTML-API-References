## ICSS2Properties.PageBreakBefore property

Los valores para estas propiedades tienen los siguientes significados:

auto - No fuerza ni prohíbe un salto de página antes (después, dentro) del cuadro generado. always - Siempre fuerza un salto de página antes (después) del cuadro generado. avoid - Evita un salto de página antes (después, dentro) del cuadro generado. left - Fuerza uno o dos saltos de página antes (después) del cuadro generado para que la página siguiente se formatee como una página izquierda. right - Fuerza uno o dos saltos de página antes (después) del cuadro generado para que la página siguiente se formatee como una página derecha.

public String PageBreakBefore { get; set; }
