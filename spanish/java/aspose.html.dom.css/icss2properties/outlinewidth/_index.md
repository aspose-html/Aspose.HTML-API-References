## ICSS2Properties.OutlineWidth property

El contorno creado con las propiedades de contorno se dibuja \"sobre\" una caja, es decir, el contorno está siempre encima y no influye en la posición o el tamaño de la caja, o de cualquier otra caja. Por lo tanto, mostrar u ocultar contornos no provoca reflujo.

```java
public String OutlineWidth { get; set; }
```

propiedad outline-width
