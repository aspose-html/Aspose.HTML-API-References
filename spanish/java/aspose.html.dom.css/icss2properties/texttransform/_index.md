## ICSS2Properties.TextTransform property

Esta propiedad controla los efectos de capitalización del texto de un elemento. Los valores tienen los siguientes significados:

capitalize - Coloca el primer carácter de cada palabra en mayúscula.uppercase - Coloca todos los caracteres de cada palabra en mayúscula.lowercase - Coloca todos los caracteres de cada palabra en minúscula.none - No hay efectos de capitalización.

```java
public String TextTransform { get; set; }
```
