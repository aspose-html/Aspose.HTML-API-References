## ICSS2Properties.Border property

La propiedad 'border' es una propiedad abreviada para establecer el mismo ancho, color y estilo en los cuatro bordes de una caja. A diferencia de las propiedades abreviadas 'margin' y 'padding', la propiedad 'border' no puede establecer valores diferentes en los cuatro bordes. Para hacerlo, se debe usar una o más de las otras propiedades de borde.

```java
public String Border { get; set; }
```
