## ICSS2Properties.SpeakNumeral property

Esta propiedad controla cómo se pronuncian los numerales. Los valores tienen los siguientes significados:

digits - Pronunciar el numeral como dígitos individuales. Así, "237" se pronuncia "Two Three Seven". continuous - Pronunciar el numeral como un número completo. Así, "237" se pronuncia "Two hundred thirty seven". Las representaciones en palabras dependen del idioma.

```java
public String SpeakNumeral { get; set; }
```
