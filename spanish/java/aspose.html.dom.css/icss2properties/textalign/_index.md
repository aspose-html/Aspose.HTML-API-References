## ICSS2Properties.TextAlign property

Esta propiedad describe cómo se alinea el contenido en línea de un bloque. Los valores tienen los siguientes significados:

left, right, center, and justify - Izquierda, derecha, centrado y justificado doble, respectivamente.'[String](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-String)' - Especifica una cadena en la que se alinearán las celdas de una columna de tabla (ver la sección sobre [alineación horizontal en una columna](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#column-alignment) para obtener detalles y un ejemplo). Este valor se aplica solo a celdas de [tabla](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html). Si se establece en otros elementos, se tratará como 'left' o 'right', dependiendo de si ['direction'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-direction) es 'ltr' o 'rtl', respectivamente.
