## ICSS2Properties.PageBreakAfter property

Los valores para estas propiedades tienen los siguientes significados:

auto - No forzar ni prohibir un salto de página antes (después, dentro) del cuadro generado. always - Siempre forzar un salto de página antes (después) del cuadro generado. avoid - Evitar un salto de página antes (después, dentro) del cuadro generado. left - Forzar uno o dos saltos de página antes (después) del cuadro generado de modo que la página siguiente se formatee como una página izquierda. right - Forzar uno o dos saltos de página antes (después) del cuadro generado de modo que la página siguiente se formatee como una página derecha.
