## ICSS2Properties.Stress property

Especifica la altura de los "picos locales" en el contorno de entonación de una voz. Por ejemplo, el inglés es un idioma con acento, y diferentes partes de una oración se asignan con acento primario, secundario o terciario. El valor de ['stress'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-stress) controla la cantidad de inflexión que resulta de estos marcadores de acento. Esta propiedad es complementaria a la propiedad ['pitch-range'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pitch-range) y se proporciona para permitir a los desarrolladores aprovechar pantallas auditivas de alta gama.

public String Stress { get; set; }
