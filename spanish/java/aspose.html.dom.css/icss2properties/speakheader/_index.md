## ICSS2Properties.SpeakHeader property

Esta propiedad especifica si los encabezados de tabla se pronuncian antes de cada celda, o solo antes de una celda cuando esa celda está asociada a un encabezado diferente al de la celda anterior. Los valores tienen los siguientes significados:

once - El encabezado se pronuncia una vez, antes de una serie de celdas. always - El encabezado se pronuncia antes de cada celda pertinente.

public String SpeakHeader { get; set; }
