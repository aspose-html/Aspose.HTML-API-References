## ICSS2Properties.BorderTopStyle property

La propiedad 'border-style' establece el estilo de los cuatro bordes. Puede tener de uno a cuatro valores, y los valores se establecen en los diferentes lados como en 'border-width' arriba.

```java
public String BorderTopStyle { get; set; }
```

propiedad border-top-style
