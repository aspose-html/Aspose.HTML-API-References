## ICSS2Properties.LineHeight property

Si la propiedad se establece en un elemento [block-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#block-level) cuyo contenido está compuesto por elementos [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level), especifica la altura mínima de cada cuadro en línea generado.

Si la propiedad se establece en un elemento [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level), especifica la altura exacta de cada cuadro generado por el elemento. (Excepto para los elementos en línea [replaced](https://www.w3.org/TR/1998/REC-CSS2-19980512/conform.html#replaced-element), donde la altura del cuadro se determina mediante la propiedad ['height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-height).)

```java
public String LineHeight { get; set; }
```
