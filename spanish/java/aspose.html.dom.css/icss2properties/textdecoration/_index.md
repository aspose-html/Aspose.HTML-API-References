## ICSS2Properties.TextDecoration property

Esta propiedad describe las decoraciones que se añaden al texto de un elemento. Si la propiedad se especifica para un elemento [block-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#block-level), afecta a todos los descendientes de nivel en línea del elemento. Si se especifica para (o afecta a) un elemento [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level), afecta a todas las cajas generadas por el elemento. Si el elemento no tiene contenido o contenido de texto (p. ej., el elemento IMG en HTML), los agentes de usuario deben [ignore](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#ignore) esta propiedad.

Los valores tienen los siguientes significados:

none - No produce decoración de texto.underline - Cada línea de texto está subrayada.overline - Cada línea de texto tiene una línea encima.line-through - Cada línea de texto tiene una línea atravesada en el medioblink - El texto parpadea (alternando entre visible e invisible).
