## ICSS2Properties.BackgroundAttachment property

Si se especifica una imagen de fondo, esta propiedad indica si está fija respecto al viewport ('fixed') o se desplaza junto con el documento ('scroll').

Aunque la imagen esté fija, solo será visible cuando se encuentre en el fondo o en el área de padding del elemento. Por lo tanto, a menos que la imagen esté en mosaico ('background-repeat: repeat'), puede ser invisible.
