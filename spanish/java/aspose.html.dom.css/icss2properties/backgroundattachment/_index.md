## ICSS2Properties.BackgroundAttachment property

Si se especifica una imagen de fondo, esta propiedad especifica si está fija con respecto a la ventana gráfica ('fixed') o se desplaza junto con el documento ('scroll').

Incluso si la imagen está fija, solo será visible cuando se encuentre en el fondo o en el área de relleno del elemento. Por lo tanto, a menos que la imagen esté en mosaico ('background-repeat: repeat'), puede ser invisible.

```java
public String BackgroundAttachment { get; set; }
```
