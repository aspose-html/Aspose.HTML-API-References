## ICSS2Properties.PitchRange property

Especifica la variación en el tono medio. El tono percibido de una voz humana está determinado por la frecuencia fundamental y típicamente tiene un valor de 120 Hz para una voz masculina y 210 Hz para una voz femenina. Los lenguajes humanos se hablan con variaciones de inflexión y tono; estas variaciones transmiten significado adicional y énfasis. Así, una voz muy animada, es decir, una que está fuertemente inflexionada, muestra un amplio rango de tono. Esta propiedad especifica el rango en el que ocurren estas variaciones, es decir, cuánto puede desviarse la frecuencia fundamental del tono medio.

```java
public String PitchRange { get; set; }
```
