## ICSS2Properties.BorderRightWidth property

Esta propiedad es una propiedad abreviada para establecer 'border-top-width', 'border-right-width', 'border-bottom-width' y 'border-left-width' en el mismo lugar de la hoja de estilo.

Si hay un solo valor, se aplica a todos los lados. Si hay dos valores, los bordes superior e inferior se establecen con el primer valor y los bordes derecho e izquierdo con el segundo. Si hay tres valores, el superior se establece con el primer valor, los bordes izquierdo y derecho con el segundo, y el inferior con el tercer valor. Si hay cuatro valores, se aplican respectivamente al superior, derecho, inferior y izquierdo.

```java
public String BorderRightWidth { get; set; }
```

### Valor de retorno

propiedad border-right-width
