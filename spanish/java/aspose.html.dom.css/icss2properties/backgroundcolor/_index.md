## ICSS2Properties.BackgroundColor property

Esta propiedad establece el color de fondo de un elemento, ya sea un valor o la palabra clave 'transparent', para que los colores subyacentes se vean a través de él.

```java
public String BackgroundColor { get; set; }
```

### Valor devuelto

propiedad background-color

### Property Value

Un color es una palabra clave o una especificación numérica RGB.
