## ICSS2Properties.Marks property

En la impresión de alta calidad, a menudo se añaden marcas fuera de la caja de página. Esta propiedad especifica si se deben renderizar marcas de cruz, marcas de recorte o ambas justo fuera del borde de la [caja de página](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#page-box).

Las marcas de recorte indican dónde debe cortarse la página. Las marcas de cruz (también conocidas como marcas de registro) se utilizan para alinear las hojas.

Las marcas son visibles solo en cajas de página absolutas (ver la propiedad ['size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-size)). En cajas de página relativas, la caja de página se alineará con el objetivo y las marcas estarán fuera del área imprimible.

El tamaño, estilo y posición de las marcas de cruz dependen del agente de usuario.
