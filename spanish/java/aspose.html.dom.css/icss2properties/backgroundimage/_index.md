## ICSS2Properties.BackgroundImage property

Esta propiedad establece la imagen de fondo de un elemento. Al establecer una imagen de fondo, los autores también deben especificar un color de fondo que se usará cuando la imagen no esté disponible. Cuando la imagen está disponible, se renderiza sobre el color de fondo. (Así, el color es visible en las partes transparentes de la imagen).

```java
public String BackgroundImage { get; set; }
```

### Valor devuelto

propiedad background-image

### Property Value

Los valores para esta propiedad son o , para especificar la imagen, o 'none', cuando no se usa ninguna imagen.
