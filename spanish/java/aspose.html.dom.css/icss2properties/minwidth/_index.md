## ICSS2Properties.MinWidth property

Estas dos propiedades permiten a los autores limitar el ancho de las cajas a un rango determinado. Los valores tienen los siguientes significados:

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - Especifica un ancho calculado fijo mínimo o máximo.'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - Especifica un porcentaje para determinar el valor calculado. El porcentaje se calcula con respecto al ancho del [bloque contenedor](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#containing-block) de la caja generada. none - (Solo en ['max-width'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-max-width)) No hay límite en el ancho de la caja.

```java
public String MinWidth { get; set; }
```
