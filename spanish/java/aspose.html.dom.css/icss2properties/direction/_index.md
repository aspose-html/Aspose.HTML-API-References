## ICSS2Properties.Direction property

Esta propiedad especifica la dirección base de escritura de los bloques y la dirección de incrustaciones y anulaciones (ver ['unicode-bidi'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-unicode-bidi)) para el algoritmo bidireccional Unicode. Además, especifica la dirección del diseño de columnas de [table](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html), la dirección del [overflow](https://www.w3.org/TR/1998/REC-CSS2-19980512/visufx.html#overflow) horizontal, y la posición de una última línea incompleta en un bloque en caso de 'text-align: justify'.

```java
public String Direction { get; set; }
```
