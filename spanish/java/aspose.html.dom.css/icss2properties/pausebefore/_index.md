## ICSS2Properties.PauseBefore property

Estas propiedades especifican una pausa que se debe observar antes (o después) de pronunciar el contenido de un elemento. Los valores tienen los siguientes significados:

'[time](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-time)' - Expresa la pausa en unidades de tiempo absolutas (segundos y milisegundos). '[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - Se refiere al inverso del valor de la propiedad ['speech-rate'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-speech-rate). Por ejemplo, si la speech-rate es 120 palabras por minuto (es decir, una palabra tarda medio segundo, o 500 ms), entonces un ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) del 100 % significa una pausa de 500 ms y un ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) del 20 % significa 100 ms.
