## TemplateLoadOptions.NamesAreCaseSensitive property

Propiedad que especifica si los nombres de los elementos de plantilla y de datos se compararán sin importar mayúsculas o minúsculas. Si es true, la coincidencia distingue entre mayúsculas; si es false, se ignorará la distinción de mayúsculas. El valor predeterminado es true.

```java
public bool NamesAreCaseSensitive { get; set; }
```
