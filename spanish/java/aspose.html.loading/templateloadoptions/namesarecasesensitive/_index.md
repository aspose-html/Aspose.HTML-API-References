## TemplateLoadOptions.NamesAreCaseSensitive property

Propiedad que especifica si los nombres de los elementos de plantilla y datos se coincidirán sin importar mayúsculas o minúsculas. Si es verdadero, la coincidencia distingue entre mayúsculas y minúsculas; si es falso, se ignorará la distinción de mayúsculas. El valor predeterminado es verdadero.

```java
public bool NamesAreCaseSensitive { get; set; }
```
