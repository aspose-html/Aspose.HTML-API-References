## SVGAngle.SVG_ANGLETYPE_UNSPECIFIED field

No se proporcionó un tipo de unidad (es decir, se especificó un valor sin unidad). Para ángulos, un valor sin unidad se trata de la misma manera que si se especificaran grados.

```java
public const ushort SVG_ANGLETYPE_UNSPECIFIED;
```
