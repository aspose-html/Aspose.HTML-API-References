## SVGAngle.ValueInSpecifiedUnits property

El valor del ángulo como un número de punto flotante, en las unidades expresadas por unitType. Establecer este atributo hará que value y valueAsString se actualicen automáticamente para reflejar esta configuración.

```java
public float ValueInSpecifiedUnits { get; set; }
```

### Property Value

El valor en unidades especificadas.
