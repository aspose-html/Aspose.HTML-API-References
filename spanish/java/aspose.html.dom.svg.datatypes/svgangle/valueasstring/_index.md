## SVGAngle.ValueAsString property

El valor del ángulo como una cadena, en las unidades expresadas por unitType. Establecer este atributo hará que value, valueInSpecifiedUnits y unitType se actualicen automáticamente para reflejar esta configuración.

```java
public String ValueAsString { get; set; }
```

### Property Value

El valor como cadena.
