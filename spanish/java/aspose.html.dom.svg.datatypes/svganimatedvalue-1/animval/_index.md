## SVGAnimatedValue&lt;T&gt;.AnimVal property

Si el atributo o propiedad dado está siendo animado, contiene el valor animado actual del atributo o propiedad. Si el atributo o propiedad dado no está siendo animado, contiene el mismo valor que baseVal.

```java
public T AnimVal { get; }
```

### Property Value

`true` si [valor anim]; de lo contrario, `false`.
