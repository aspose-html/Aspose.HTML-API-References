El paquete brinda acceso a todos los tipos de datos específicos de SVG.

## Clases

| Clase | Descripción |
| --- | --- |
| [SVGAngle](./svgangle/) | La interfaz SVGAngle corresponde al tipo de dato básico ángulo. |
| [SVGAnimatedAngle](./svganimatedangle/) | Se usa para atributos del tipo de dato básico ángulo que pueden animarse. |
| [SVGAnimatedBoolean](./svganimatedboolean/) | Se usa para atributos de tipo booleano que pueden animarse. |
| [SVGAnimatedEnumeration](./svganimatedenumeration/) | Se usa para atributos cuyo valor debe ser una constante de una enumeración particular y que pueden animarse. |
| [SVGAnimatedInteger](./svganimatedinteger/) | Se usa para atributos del tipo básico entero que pueden animarse. |
| [SVGAnimatedLength](./svganimatedlength/) | Se usa para atributos del tipo básico longitud que pueden animarse. |
| [SVGAnimatedLengthList](./svganimatedlengthlist/) | Se usa para atributos de tipo SVGLengthList que pueden animarse. |
| [SVGAnimatedNumber](./svganimatednumber/) | Se usa para atributos del tipo básico número que pueden animarse. |
| [SVGAnimatedNumberList](./svganimatednumberlist/) | Se usa para atributos que aceptan una lista de números y que pueden animarse. |
| [SVGAnimatedPreserveAspectRatio](./svganimatedpreserveaspectratio/) | Se usa para atributos de tipo SVGPreserveAspectRatio que pueden animarse. |
| [SVGAnimatedRect](./svganimatedrect/) | Se usa para atributos de tipo SVGRect que pueden animarse. |
| [SVGAnimatedString](./svganimatedString/) | Se usa para atributos de tipo DOMString que pueden animarse. |
| [SVGAnimatedTransformList](./svganimatedtransformlist/) | Se utiliza para los diversos atributos que especifican un conjunto de transformaciones, como el atributo ‘transform’ que está disponible en muchos de los elementos de SVG y que puede ser animado. |
| [SVGAnimatedValue&lt;T&gt;](./svganimatedvalue-1/) | Se utiliza para atributos de tipos que pueden ser animados. |
| [SVGLength](./svglength/) | La interfaz SVGLength corresponde al tipo de dato básico de longitud. Un objeto SVGLength puede designarse como solo lectura, lo que significa que los intentos de modificar el objeto provocarán que se lance una excepción, como se describe a continuación. |
| [SVGLengthList](./svglengthlist/) | Esta interfaz define una lista de objetos SVGLength. |
| [SVGMatrix](./svgmatrix/) | Muchas de las operaciones gráficas de SVG utilizan matrices 2x3 de la forma: [a c e] [b d f] que, al expandirse a una matriz 3x3 para fines de aritmética de matrices, se convierten en: [a c e] [b d f] [0 0 1] |
| [SVGNumber](./svgnumber/) | Se utiliza para atributos de tipo básico número. |
| [SVGNumberList](./svgnumberlist/) | Esta interfaz define una lista de objetos SVGNumber. |
| [SVGPoint](./svgpoint/) | Muchas de las interfaces SVG DOM hacen referencia a objetos de la clase SVGPoint. Un SVGPoint es un par de coordenadas (x, y). Cuando se usa en operaciones de matrices, un SVGPoint se trata como un vector de la forma: [x] [y] [1] Si un objeto SVGRect se designa como solo lectura, entonces intentar asignar a uno de sus atributos provocará que se lance una excepción. |
| [SVGPointList](./svgpointlist/) | Esta interfaz define una lista de objetos SVGPoint. |
| [SVGPreserveAspectRatio](./svgpreserveaspectratio/) | La interfaz SVGPreserveAspectRatio corresponde al atributo ‘preserveAspectRatio’, que está disponible en algunos de los elementos de SVG. |
| [SVGRect](./svgrect/) | Representa geometría rectangular. Los rectángulos se definen como un par de coordenadas (x,y) que identifican un valor mínimo X, un valor mínimo Y, y un ancho y alto, que normalmente están restringidos a ser no negativos. |
| [SVGStringList](./svgStringlist/) | SVGStringList tiene los mismos atributos y métodos que otras interfaces SVGxxxList. Los implementadores pueden considerar usar una única clase base para implementar las diversas interfaces SVGxxxList. |
| [SVGTransform](./svgtransform/) | SVGTransform es la interfaz para una de las transformaciones componentes dentro de una SVGTransformList; por lo tanto, un objeto SVGTransform corresponde a un único componente (p. ej., 'scale(…)' o 'matrix(…)') dentro de una especificación del atributo ‘transform’. |
| [SVGTransformList](./svgtransformlist/) | Esta interfaz define una lista de objetos SVGTransform. |
| [SVGValueType](./svgvaluetype/) | El tipo SVGValueType se utiliza para representar un tipo de valor base de SVG. |
