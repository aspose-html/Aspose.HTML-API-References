## SVGTransform.SetTranslate method

Establece el tipo de transformación a SVG_TRANSFORM_TRANSLATE, con los parámetros tx y ty que definen las cantidades de traslación.

```java
public void SetTranslate(float tx, float ty)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| tx | Single | La cantidad de traslación en X. |
| ty | Single | La cantidad de traslación en Y. |
