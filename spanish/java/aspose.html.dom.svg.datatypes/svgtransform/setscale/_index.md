## SVGTransform.SetScale method

Establece el tipo de transformación a SVG_TRANSFORM_SCALE, con los parámetros sx y sy que definen las cantidades de escala.

```java
public void SetScale(float sx, float sy)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| sx | Single | La cantidad de escala en X. |
| sy | Single | La cantidad de escala en Y. |
