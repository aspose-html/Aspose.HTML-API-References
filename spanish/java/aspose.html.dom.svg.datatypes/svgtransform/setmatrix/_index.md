## SVGTransform.SetMatrix method

Establece el tipo de transformación a SVG_TRANSFORM_MATRIX, con el parámetro matrix que define la nueva transformación. Los valores del parámetro matrix se copian; el parámetro matrix no reemplaza a SVGTransform::matrix.

```java
public void SetMatrix(SVGMatrix matrix)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| matriz | SVGMatrix | La nueva matriz para la transformación. |
