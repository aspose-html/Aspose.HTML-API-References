## SVGRect class

Representa geometría rectangular. Los rectángulos se definen como un par de coordenadas (x,y) que identifican un valor mínimo X, un valor mínimo Y, y un ancho y alto, que normalmente están restringidos a ser no negativos.

public class SVGRect : SVGValueType
