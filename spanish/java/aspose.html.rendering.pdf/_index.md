El paquete **com.aspose.html.rendering.pdf** proporciona una clase de dispositivo específica, así como algunas clases de opciones de renderizado responsables de renderizar a un documento PDF.

## Clases

| Clase | Descripción |
| --- | --- |
| [PdfDevice](./pdfdevice/) | Representa el renderizado a un documento PDF. |
| [PdfDocumentInfo](./pdfdocumentinfo/) | Representa la información del documento PDF. |
| [PdfRenderingOptions](./pdfrenderingoptions/) | Representa las opciones de renderizado para [`PdfDevice`](../com.aspose.html.rendering.pdf/pdfdevice/). |
## Enumeración

| Enumeración | Descripción |
| --- | --- |
| [FormFieldBehaviour](./formfieldbehaviour/) | Esta enumeración se usa para especificar el comportamiento de los campos de formulario en el documento PDF de salida. |
