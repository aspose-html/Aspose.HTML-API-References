## Path2D.ArcTo method

Agrega un arco a la ruta con los puntos de control y radio dados, conectado al punto anterior mediante una línea recta.

```java
public void ArcTo(double x1, double y1, double x2, double y2, double radius)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| x1 | Double | Coordenadas del eje x para el primer punto de control. |
| y1 | Double | Coordenadas del eje y del primer punto de control. |
| x2 | Double | Coordenadas del eje x del segundo punto de control. |
| y2 | Double | Coordenadas del eje y del segundo punto de control. |
| radio | Double | El radio del arco. |
