## CanvasFillRule enumeration

Esta enumeración se usa para seleccionar el algoritmo de regla de relleno que determina si un punto está dentro o fuera de una ruta.

```java
public enum CanvasFillRule
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| NonZero | `0` | El valor "nonzero" indica la regla de enrollamiento no nulo, en la cual un punto se considera fuera de una forma si el número de veces que una línea recta semilimitada trazada desde ese punto cruza la trayectoria de la forma en una dirección es igual al número de veces que la cruza en la dirección opuesta. |
| EvenOdd | `1` | El valor "evenodd" indica la regla par-impar, en la cual un punto se considera fuera de una forma si el número de veces que una línea recta semilimitada trazada desde ese punto cruza la trayectoria de la forma es par. |
