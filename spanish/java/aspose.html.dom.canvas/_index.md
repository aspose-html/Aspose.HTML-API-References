## Clases

| Clase | Descripción |
| --- | --- |
| [Path2D](./path2d/) | La interfaz Path2D de la API Canvas 2D se utiliza para declarar rutas que luego se usan en objetos CanvasRenderingContext2D. Los métodos de ruta de la interfaz CanvasRenderingContext2D también están presentes en esta interfaz y le permiten crear rutas que puede retener y reproducir según sea necesario en un canvas. |
## Interfaces

| Interfaz | Descripción |
| --- | --- |
| [ICanvasDrawingStyles](./icanvasdrawingstyles/) | La interfaz ICanvasDrawingStyles proporciona métodos y propiedades que controlan cómo se dibujan las líneas y cómo se dispone el texto. |
| [ICanvasGradient](./icanvasgradient/) | Representa un objeto opaco que describe un degradado. |
| [ICanvasPathMethods](./icanvaspathmethods/) | La interfaz ICanvasPathMethods se utiliza para manipular rutas de objetos. |
| [ICanvasPattern](./icanvaspattern/) | Representa un objeto opaco que describe un patrón, basado en una imagen, un canvas o un video. |
| [ICanvasRenderingContext2D](./icanvasrenderingcontext2d/) | La interfaz ICanvasRenderingContext2D se utiliza para dibujar rectángulos, texto, imágenes y otros objetos sobre el elemento canvas. Proporciona el contexto de renderizado 2D para la superficie de dibujo de un elemento canvas. |
| [IImageData](./iimagedata/) | Crea un objeto ImageData a partir de un Uint8ClampedArray dado y del tamaño de la imagen que contiene. Si no se proporciona un arreglo, crea una imagen de un rectángulo negro. |
| [ITextMetrics](./itextmetrics/) | Representa la dimensión de un texto en el canvas. |
## Enumeración
