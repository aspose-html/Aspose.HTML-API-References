## ICanvasRenderingContext2D.ClearRect method

Establece todos los píxeles del rectángulo definido por el punto de inicio (x, y) y el tamaño (ancho, alto) a negro transparente, borrando cualquier contenido dibujado previamente.

```java
public void ClearRect(double x, double y, double w, double h)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| x | Double | El eje x de la coordenada del punto de inicio del rectángulo. |
| y | Double | El eje y de la coordenada del punto de inicio del rectángulo. |
| w | Double | El ancho del rectángulo. |
| h | Double | La altura del rectángulo. |
