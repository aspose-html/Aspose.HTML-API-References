## CreateImageData(double, double) {#createimagedata_1}

Crea un nuevo objeto ImageData vacío con las dimensiones especificadas. Todos los píxeles del nuevo objeto son negro transparente.

```java
public IImageData CreateImageData(double sw, double sh)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| sw | Doble | El ancho que se asignará al nuevo objeto ImageData. |
| sh | Doble | La altura que se asignará al nuevo objeto ImageData. |

### Valor de retorno

Un nuevo objeto ImageData con el ancho y alto especificados. El nuevo objeto está lleno de píxeles negros transparentes.

## CreateImageData(IImageData) {#createimagedata}

```java
public IImageData CreateImageData(IImageData imagedata)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
