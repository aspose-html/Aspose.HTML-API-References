## FillText(String, double, double, double) {#filltext_1}

Dibuja (rellena) un texto dado en la posición (x,y) especificada.

```java
public void FillText(String text, double x, double y, double maxWidth)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| texto | Cadena | El texto a dibujar usando la fuente actual, textAlign, textBaseline y los valores de dirección. |
| x | Double | El eje x de la coordenada del punto de inicio del texto. |
| y | Double | El eje y de la coordenada del punto de inicio del texto. |
| maxWidth | Double | El ancho máximo para dibujar. Si se especifica, y la cadena se calcula que es más ancha que este ancho, la fuente se ajusta para usar una fuente más condensada horizontalmente (si está disponible o si se puede sintetizar una razonablemente legible escalando la fuente actual horizontalmente) o una fuente más pequeña. |
