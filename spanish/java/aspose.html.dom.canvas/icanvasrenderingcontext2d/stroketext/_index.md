## StrokeText(String, double, double, double?) {#stroketext_1}

Dibuja (traza) un texto dado en la posición (x, y) proporcionada.

```java
public void StrokeText(String text, double x, double y, double? maxWidth)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| texto | String | El texto a dibujar usando la fuente actual, textAlign, textBaseline y los valores de dirección. |
| x | Doble | El eje x de la coordenada para el punto de inicio del texto. |
| y | Doble | El eje y de la coordenada para el punto de inicio del texto. |
| maxWidth | Nullable`1 | El ancho máximo para dibujar. Si se especifica y la cadena se calcula más ancha que este ancho, la fuente se ajusta para usar una fuente más condensada horizontalmente (si está disponible o si se puede sintetizar una razonablemente legible escalando la fuente actual horizontalmente) o una fuente más pequeña. |
