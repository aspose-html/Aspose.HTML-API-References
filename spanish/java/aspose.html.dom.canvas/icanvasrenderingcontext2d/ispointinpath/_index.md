## IsPointInPath(double, double) {#ispointinpath_2}

Informa si el punto especificado está contenido en la ruta actual o no.

```java
public bool IsPointInPath(double x, double y)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| x | Double | La coordenada X del punto a comprobar. |
| y | Double | La coordenada Y del punto a comprobar. |

### Valor devuelto

Devuelve true si el punto está dentro del área contenida por el relleno de una ruta, de lo contrario false.
