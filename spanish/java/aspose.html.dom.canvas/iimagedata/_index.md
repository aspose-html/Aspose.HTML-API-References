## IImageData interface

Crea un objeto ImageData a partir de un Uint8ClampedArray dado y del tamaño de la imagen que contiene. Si no se proporciona un arreglo, crea una imagen de un rectángulo negro.

```java
public interface IImageData
```

## Propiedades

| Nombre | Descripción |
| --- | --- |
| [getData](../../com.aspose.html.dom.canvas/iimagedata/data/) es un Uint8ClampedArray que representa una matriz unidimensional que contiene los datos en orden RGBA, con valores enteros entre 0 y 255 (incluidos). |
| [getHeight](../../com.aspose.html.dom.canvas/iimagedata/height/) es un unsigned long que representa la altura real, en píxeles, de ImageData. |
| [getWidth](../../com.aspose.html.dom.canvas/iimagedata/width/) es un unsigned long que representa el ancho real, en píxeles, de ImageData. |
