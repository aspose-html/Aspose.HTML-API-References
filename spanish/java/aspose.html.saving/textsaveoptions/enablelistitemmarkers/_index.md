## TextSaveOptions.EnableListItemMarkers property

Opción que se aplica a los elementos OL y UL en la conversión de HTML a texto. De hecho, define cómo procesar los marcadores de lista externos de los elementos OL y UL. Si es true, se añaden números de ítem antes de los elementos OL, o puntos antes de los elementos UL. Si es false, no se añaden (comportamiento por defecto según la especificación).

```java
public bool EnableListItemMarkers { get; set; }
```
