## TextSaveOptions.EnableListItemMarkers property

Opción que se aplica a los elementos OL, UL en la conversión de HTML a texto. De hecho, define cómo procesar los marcadores de lista externos de los elementos OL y UL. Si es verdadero, se añaden números de ítem antes de los ítems OL, o puntos antes de los ítems UL. Si es falso, no se añaden (comportamiento predeterminado siguiendo la especificación).

```java
public bool EnableListItemMarkers { get; set; }
```
