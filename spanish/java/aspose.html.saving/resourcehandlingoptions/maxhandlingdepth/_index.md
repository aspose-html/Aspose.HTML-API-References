## ResourceHandlingOptions.MaxHandlingDepth property

Obtiene o establece la profundidad máxima de páginas que se manejarán. Una profundidad de 1 significa que solo se manejarán las páginas referenciadas directamente desde el documento guardado. Establecer esta propiedad en -1 provocará el manejo de todas las páginas. El valor predeterminado es 0.

```java
public int MaxHandlingDepth { get; set; }
```
