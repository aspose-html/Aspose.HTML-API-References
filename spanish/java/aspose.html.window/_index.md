El paquete **com.aspose.html.window** está relacionado con el objeto ventana que representa una ventana que contiene un documento DOM. Incluye clases e interfaces relacionadas con la dirección del documento activo y el historial de navegación.

## Clases

| Clase | Descripción |
| --- | --- |
| [Location](./location/) | Los objetos Location proporcionan una representación de la dirección del documento activo de su contexto de navegación del Document, y permiten que la entrada actual del historial de sesión del contexto de navegación se cambie, añadiendo o reemplazando entradas en el objeto de historial. |
| [MediaQueryList](./mediaquerylist/) | Un objeto MediaQueryList almacena información sobre una consulta de medios aplicada a un documento, con soporte tanto para coincidencias inmediatas como basadas en eventos contra el estado del documento. Consulte la especificación del módulo de vista CSSOM: [https://www.w3.org/TR/cssom-view/#the-mediaquerylist-interface](https://www.w3.org/TR/cssom-view/#the-mediaquerylist-interface) |
## Interfaces

| Interfaz | Descripción |
| --- | --- |
| [IWindow](./iwindow/) | El objeto window representa una ventana que contiene un documento DOM. |
| [IWindowEventHandlers](./iwindoweventhandlers/) | Representa una interfaz que debe ser heredada por el objeto window. |
| [IWindowTimers](./iwindowtimers/) | Permite a los autores programar devoluciones de llamada basadas en temporizadores. |
