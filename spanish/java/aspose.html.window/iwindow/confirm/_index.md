## IWindow.Confirm method

Muestra un cuadro de diálogo modal de OK/Cancelar con el mensaje proporcionado, espera a que el usuario lo cierre y devuelve true si el usuario pulsa OK y false si pulsa Cancelar.

```java
public bool Confirm(String message)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| mensaje | String | El mensaje. |

### Valor de retorno

Devuelve true si el usuario hace clic en OK y false si hace clic en Cancel.
