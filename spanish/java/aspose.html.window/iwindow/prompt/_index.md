## IWindow.Prompt method

Muestra un cuadro de diálogo modal con un campo de texto y el mensaje proporcionado, espera a que el usuario lo cierre y devuelve el valor introducido por el usuario. Si el usuario cancela el cuadro de diálogo, devuelve null. Si se proporciona el segundo argumento, el valor dado se utiliza como predeterminado.

```java
public String Prompt(String message, String @default)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| mensaje | String | El mensaje. |
| predeterminado | String | El predeterminado. |

### Valor de retorno

Devuelve el valor que el usuario ingresó
