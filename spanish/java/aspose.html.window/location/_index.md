## Location class

Los objetos Location proporcionan una representación de la dirección del documento activo de su contexto de navegación del Document, y permiten que la entrada actual del historial de sesión del contexto de navegación sea modificada, añadiendo o reemplazando entradas en el objeto de historial.

```java
public sealed class Location : DOMObject
```
