## OptionElement.Selected property

Представляет текущее состояние соответствующего элемента управления формой в интерактивном пользовательском агенте. Изменение этого атрибута изменяет состояние элемента управления формой, но не меняет значение атрибута selected HTML элемента.

```java
public bool Selected { get; set; }
```
