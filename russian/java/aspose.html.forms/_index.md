Пакет предоставляет доступ к множеству объектов (элементов), отвечающих за взаимодействие пользователя с формой как компонентом веб‑страницы.

## Классы

| Класс | Описание |
| --- | --- |
| [ButtonElement](./buttonelement/) | ButtonElement представляет обёртку, связанную с HTMLButtonElement. |
| [DataListElement](./datalistelement/) | DataListElement представляет обёртку, связанную с HTMLDataListElement |
| [FormEditor](./formeditor/) | Этот класс представляет редактор над [`HTMLFormElement`](../com.aspose.html/htmlformelement/), который упрощает .net‑разработчикам редактирование HTML‑форм. |
| [FormElement](./formelement/) | Представляет базовый класс для элементов формы. |
| [FormElement&lt;T&gt;](./formelement-1/) | [`FormElement`](../com.aspose.html.forms/formelement/) представляет обобщённое поле |
| [FormSubmitter](./formsubmitter/) | Этот класс позволяет подготовить указанный [`HTMLFormElement`](../com.aspose.html/htmlformelement/), собрать значения из элемента формы, отправить их на удалённый сервер и получить ответ. |
| [InputElement](./inputelement/) | InputElement представляет обёртку, связанную с HTMLInputElement. |
| [OptionCollection](./optioncollection/) | OptionElements представляет обёртку, связанную с IHTMLOptionsCollection |
| [OptionElement](./optionelement/) | OptionElement представляет обёртку, связанную с HTMLOptionElement |
| [SelectElement](./selectelement/) | SelectElement представляет обёртку, связанную с HTMLSelectElement |
| [SubmissionResult](./submissionresult/) | Этот класс представляет результат отправки данных формы на сервер. |
| [TextAreaElement](./textareaelement/) | TextAreaElement представляет обёртку, связанную с HTMLTextAreaElement |
## Перечисление

| Перечисление | Описание |

| [InputElementType](./inputelementtype/) | Представляет состояния поля ввода. |
