## Event.PreventDefault method

Если событие отменяемо, метод `PreventDefault` используется, чтобы указать, что событие должно быть отменено, что означает, что любое действие по умолчанию, обычно выполняемое реализацией в результате события, не произойдёт.

```java
public void PreventDefault()
```

## Примечания

Если на любой стадии потока событий вызывается метод `PreventDefault`, событие отменяется. Любое действие по умолчанию, связанное с событием, не произойдёт. Вызов этого метода для неотменяемого события не оказывает эффекта. После вызова `PreventDefault` он остаётся в силе до завершения распространения события. Этот метод может использоваться на любой стадии потока событий.
