## Event.IsTrusted property

Атрибут isTrusted должен возвращать значение, с которым он был инициализирован. При создании события атрибут должен быть инициализирован значением false.

```java
public bool IsTrusted { get; }
```

### Property Value

`true`, если этот экземпляр доверенный; иначе `false`.
