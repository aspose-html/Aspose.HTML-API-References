## Event.DefaultPrevented property

Возвращает true, если вызвано preventDefault(), когда значение атрибута cancelable равно true, и false в противном случае.

```java
public bool DefaultPrevented { get; }
```

### Property Value

`true`, если [default prevented]; иначе `false`.
