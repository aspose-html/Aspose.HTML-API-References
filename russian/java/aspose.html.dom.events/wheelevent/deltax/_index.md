## WheelEvent.DeltaX property

В пользовательских агентах, где действие по умолчанию события колеса — прокрутка, значение ДОЛЖНО быть измерением вдоль оси x (в пикселях, строках или страницах), которое будет прокручено, если событие не отменено. В противном случае это измерение, специфичное для реализации (в пикселях, строках или страницах) движения устройства колеса вокруг оси x.

```java
public double DeltaX { get; }
```

### Property Value

Атрибут deltaX.
