## WheelEvent.DeltaZ property

В пользовательских агентах, где действие по умолчанию события колеса — прокрутка, значение ДОЛЖНО представлять измерение вдоль оси Z (в пикселях, строках или страницах), которое будет прокручено, если событие не отменено. В противном случае это измерение, специфичное для реализации (в пикселях, строках или страницах) движения устройства колеса вокруг оси Z.

```java
public double DeltaZ { get; }
```

### Property Value

Атрибут deltaZ.
