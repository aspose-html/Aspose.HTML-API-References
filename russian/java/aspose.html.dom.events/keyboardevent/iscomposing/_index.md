## KeyboardEvent.IsComposing property

true, если событие клавиши происходит в рамках сеанса композиции, т.е. после события compositionstart и до соответствующего события compositionend. Неинициализированное значение этого атрибута ДОЛЖНО быть false.

```java
public bool IsComposing { get; }
```

### Property Value

`true` если этот экземпляр находится в состоянии композиции; в противном случае, `false`.
