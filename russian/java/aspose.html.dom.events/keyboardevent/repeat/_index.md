## KeyboardEvent.Repeat property

true, если клавиша удерживается длительное время. Удерживание клавиши ДОЛЖНО приводить к повторению событий keydown, beforeinput, input в этом порядке с частотой, определяемой конфигурацией системы. Для мобильных устройств с поведением длительного нажатия первое событие клавиши с атрибутом repeat, значение которого true, ДОЛЖНО служить индикатором длительного нажатия. Длительность, в течение которой клавиша ДОЛЖНА быть удержана, чтобы начать повторение, зависит от конфигурации.

```java
public bool Repeat { get; }
```

### Property Value

`true` если повтор; иначе `false`.
