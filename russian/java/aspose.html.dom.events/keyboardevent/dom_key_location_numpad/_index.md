## KeyboardEvent.DOM_KEY_LOCATION_NUMPAD field

Активация клавиши произошла на цифровой клавиатуре или с виртуальной клавишей, соответствующей цифровой клавиатуре (когда существует более одного возможного расположения этой клавиши). Обратите внимание, что клавиша NumLock всегда должна кодироваться с расположением DOM_KEY_LOCATION_STANDARD.

```java
public const ulong DOM_KEY_LOCATION_NUMPAD;
```
