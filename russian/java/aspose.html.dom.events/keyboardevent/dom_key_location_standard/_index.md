## KeyboardEvent.DOM_KEY_LOCATION_STANDARD field

Активация клавиши НЕ ДОЛЖНА отличаться как левая или правая версия клавиши, и (за исключением клавиши NumLock) не произошла с цифровой клавиатуры (или не произошла с виртуальной клавишей, соответствующей цифровой клавиатуре).

```java
public const ulong DOM_KEY_LOCATION_STANDARD;
```
