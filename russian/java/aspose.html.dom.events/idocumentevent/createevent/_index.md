## IDocumentEvent.CreateEvent method

Метод createEvent используется для создания событий, когда пользователю неудобно или не требуется создавать Event самостоятельно.

```java
public Event CreateEvent(String eventType)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| eventType | String | Параметр eventType указывает тип интерфейса, который необходимо создать. Если указанный интерфейс поддерживается реализацией, этот метод вернёт новый объект запрошенного типа интерфейса. Если  должен быть отправлен через метод, соответствующий метод должен быть вызван после создания для инициализации значений. Метод используется для создания  , когда пользователю неудобно или не требуется создавать их самостоятельно. В случаях, когда предоставленная реализацией реализация недостаточна, пользователи могут предоставить свои собственные реализации для использования с методом. |

### Возвращаемое значение

Возвращает только что созданное событие указанного типа события.
