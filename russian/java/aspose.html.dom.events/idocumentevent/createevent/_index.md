## IDocumentEvent.CreateEvent method

Метод createEvent используется для создания событий (Event), когда пользователю неудобно или не требуется создавать событие самостоятельно.

```java
public Event CreateEvent(String eventType)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| eventType | String | Параметр eventType указывает тип интерфейса, который необходимо создать. Если указанный интерфейс поддерживается реализацией, этот метод вернёт новый объект запрошенного типа интерфейса. Если объект должен быть отправлен с помощью метода, после создания необходимо вызвать соответствующий метод для инициализации значений. Метод используется для создания s, когда пользователю неудобно или не требуется создавать их самостоятельно. В случаях, когда предоставленная реализацией функциональность недостаточна, пользователи могут предоставить свои собственные реализации для использования с этим методом. |

### Возвращаемое значение

Возвращает только что созданное событие указанного типа.
