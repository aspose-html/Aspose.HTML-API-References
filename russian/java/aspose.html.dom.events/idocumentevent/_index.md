## IDocumentEvent interface

Интерфейс DocumentEvent предоставляет механизм, с помощью которого пользователь может создать событие типа, поддерживаемого реализацией. Ожидается, что интерфейс DocumentEvent будет реализован в том же объекте, который реализует интерфейс Document в реализации, поддерживающей модель событий.

```java
public interface IDocumentEvent
```

## Примечания

Ожидается, что интерфейс будет реализован в том же объекте, который реализует интерфейс, в реализации, поддерживающей модель событий.
