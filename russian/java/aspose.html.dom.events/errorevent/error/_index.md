## ErrorEvent.Error property

Атрибут error должен возвращать значение, с которым он был инициализирован. При создании объекта этот атрибут должен быть инициализирован null. При необходимости он устанавливается в объект, представляющий ошибку (например, объект исключения в случае необработанного исключения DOM).

```java
public object Error { get; }
```

### Property Value

Ошибка.
