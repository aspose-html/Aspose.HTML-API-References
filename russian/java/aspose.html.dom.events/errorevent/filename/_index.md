## ErrorEvent.FileName property

Атрибут filename должен возвращать значение, с которым он был инициализирован. При создании объекта этот атрибут должен быть инициализирован пустой строкой. Он представляет абсолютный URL скрипта, в котором изначально произошла ошибка.

```java
public String FileName { get; }
```

### Property Value

Имя файла.
