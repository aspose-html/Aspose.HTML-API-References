## ErrorEvent.LineNo property

Атрибут lineno должен возвращать значение, с которым он был инициализирован. При создании объекта этот атрибут должен быть инициализирован нулём. Он представляет номер строки, в которой произошла ошибка в скрипте.

```java
public uint LineNo { get; }
```
