## ErrorEvent.ColNo property

Атрибут colno должен возвращать значение, с которым он был инициализирован. При создании объекта этот атрибут должен быть инициализирован нулём. Он представляет номер столбца, в котором произошла ошибка в скрипте.

```java
public uint ColNo { get; }
```
