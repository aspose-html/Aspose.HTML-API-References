## IEventListener interface

Интерфейс является основным способом обработки событий. Пользователи реализуют интерфейс и регистрируют свой слушатель с помощью метода. Пользователи также должны удалить свой слушатель после завершения его использования.

```java
public interface IEventListener
```

## Методы

| Имя | Описание |
| --- | --- |
| [handleEvent](../../com.aspose.html.dom.events/ieventlistener/handleevent/)(Event) | Этот метод вызывается каждый раз, когда происходит событие типа, для которого был зарегистрирован интерфейс. |

## Примечания

При копировании узла с помощью метода cloneNode обработчики событий, прикреплённые к исходному узлу, не копируются в новый узел. Если пользователь хочет добавить те же обработчики событий к только что созданной копии, он должен сделать это вручную.
