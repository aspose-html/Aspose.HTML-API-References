## IEventListener interface

Интерфейс является основным способом обработки событий. Пользователи реализуют интерфейс и регистрируют свой слушатель, используя метод. Пользователи также должны удалить свой слушатель после завершения его использования.

```java
public interface IEventListener
```

## Методы

| Имя | Описание |
| --- | --- |
| [handleEvent](../../com.aspose.html.dom.events/ieventlistener/handleevent/)(Event) | Этот метод вызывается каждый раз, когда происходит событие типа, для которого был зарегистрирован интерфейс. |

## Примечания

Когда узел (Node) копируется с помощью метода cloneNode, привязанные к исходному узлу обработчики событий (Event Listeners) не прикрепляются к скопированному узлу. Если пользователь хочет, чтобы те же обработчики событий были добавлены к вновь созданной копии, пользователь должен добавить их вручную.
