## InputEvent.Data property

Данные содержат значение символов, сгенерированных методом ввода. Это МОЖЕТ быть один Unicode‑символ или непустая последовательность Unicode‑символов [Unicode]. Символы ДОЛЖНЫ быть нормализованы в соответствии с формой нормализации Unicode NFC, определённой в [UAX15]. Этот атрибут МОЖЕТ содержать пустую строку.

```java
public String Data { get; }
```
