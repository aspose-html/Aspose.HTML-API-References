## Element.HasAttributeNS method

Возвращает true, если атрибут с заданным локальным именем и URI пакета указан у этого элемента или имеет значение по умолчанию, иначе возвращает false.

```java
public bool HasAttributeNS(String packageURI, String localName)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| packageURI | String | URI пакета. |
| localName | String | Имя локального. |

### Возвращаемое значение

`true` если [has attribute NS] [the specified package URI]; иначе, `false`.
