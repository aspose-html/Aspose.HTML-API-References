## Element.HasAttribute method

Возвращает true, если атрибут с заданным именем указан у этого элемента или имеет значение по умолчанию, в противном случае — false.

```java
public bool HasAttribute(String qualifiedName)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| имя | String | Имя атрибута. |

### Возвращаемое значение

`true`, если указанный имя имеет атрибут; иначе `false`.
