## Element.ChildElementCount property

Возвращает текущее количество элементных узлов, являющихся дочерними элементами данного элемента. 0, если у этого элемента нет дочерних узлов типа nodeType 1.

```java
public int ChildElementCount { get; }
```

### Property Value

Количество дочерних элементов.
