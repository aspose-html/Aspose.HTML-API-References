## ToggleAttribute(String) {#toggleattribute}

Если параметр force не указан, происходит «переключение» qualifiedName: он удаляется, если присутствует, и добавляется, если отсутствует. Если force равно true, qualifiedName добавляется. Если force равно false, qualifiedName удаляется.

```java
public bool ToggleAttribute(String qualifiedName)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| qualifiedName | String | Атрибут QualifiedName. |

### Возвращаемое значение

Возвращает true, если qualifiedName теперь присутствует; иначе false.

## ToggleAttribute(String, bool) {#toggleattribute_1}

```java
public bool ToggleAttribute(String qualifiedName, bool force)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| qualifiedName | String | Атрибут QualifiedName. |
| force | Boolean | Опция force для переключения атрибута. |

### Возвращаемое значение

Возвращает true, если qualifiedName теперь присутствует; иначе false.
