## TypeInfo.DERIVATION_RESTRICTION field

Если схема документа является XML Schema [XML Schema Part 1], эта константа представляет производное отношение по ограничению, если задействованы сложные типы, или ограничение, если задействованы простые типы.

```java
public const ulong DERIVATION_RESTRICTION;
```
