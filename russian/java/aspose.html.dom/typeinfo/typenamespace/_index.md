## TypeInfo.TypeNamespace property

Возвращает пакет типа. Пакет типа, объявленного для связанного элемента или атрибута, или null, если элемент не имеет объявления или информация о пакете недоступна.

```java
public String TypeNamespace { get; }
```

### Property Value

Пакет типа.
