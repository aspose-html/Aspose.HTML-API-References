## Attr.LocalName property

Возвращает локальную часть квалифицированного имени этого узла. Для узлов любого типа, кроме ELEMENT_NODE и ATTRIBUTE_NODE, и узлов, созданных методом уровня DOM 1, таким как Document.createElement(), всегда возвращается null.

```java
public String LocalName { get; }
```

### Property Value

Имя локального.
