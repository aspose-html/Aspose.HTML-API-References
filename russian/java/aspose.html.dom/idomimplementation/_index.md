## IDOMImplementation interface

Интерфейс DOMImplementation предоставляет ряд методов для выполнения операций, независимых от конкретного экземпляра модели объектного документа.

```java
public interface IDOMImplementation
```

## Методы

| Имя | Описание |
| --- | --- |
| [createDocument](../../com.aspose.html.dom/idomimplementation/createdocument/)(String, String, DocumentType) | Создает объект DOM Document указанного типа с его корневым элементом. |
| [createDocumentType](../../com.aspose.html.dom/idomimplementation/createdocumenttype/)(String, String, String) | Создает пустой узел DocumentType. Объявления сущностей и обозначений не доступны. Расширения ссылок на сущности и добавление атрибутов по умолчанию не происходят. |
| [createHTMLDocument](../../com.aspose.html.dom/idomimplementation/createhtmldocument/)(String) | Возвращает документ с уже построенным базовым деревом, включающим элемент title, если аргумент title не опущен. |
| [hasFeature](../../com.aspose.html.dom/idomimplementation/hasfeature/)() | Проверяет, реализует ли DOM‑реализация определенную функцию и версию, как указано в DOM Features. |
