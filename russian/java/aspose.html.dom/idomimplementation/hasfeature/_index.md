## IDOMImplementation.HasFeature method

Проверяет, реализует ли реализация DOM определенную функцию и версию, как указано в DOM Features.

```java
public bool HasFeature()
```

### Возвращаемое значение

`true` если указанная функция имеет возможность; иначе `false`.
