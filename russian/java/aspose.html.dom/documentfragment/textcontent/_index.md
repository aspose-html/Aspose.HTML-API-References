## DocumentFragment.TextContent property

Этот атрибут возвращает текстовое содержимое этого узла и его потомков. Если он задан как null, попытка установить его не оказывает эффекта. При установке все возможные дочерние узлы удаляются, и если новая строка не пуста и не null, она заменяется одним текстовым узлом, содержащим эту строку.

```java
public String TextContent { get; set; }
```

### Property Value

Содержимое текста.
