## DocumentFragment.InnerHTML property

Возвращает фрагмент HTML или XML, представляющий содержимое элемента. Можно установить, чтобы заменить содержимое элемента узлами, разобранными из указанной строки.

```java
public String InnerHTML { get; set; }
```

### Property Value

Внутренний HTML.
