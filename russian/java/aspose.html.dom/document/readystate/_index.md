## Document.ReadyState property

Возвращает готовность документа. \"loading\" — пока Document загружается, \"interactive\" — после завершения парсинга, но продолжается загрузка подресурсов, и \"complete\" — после полной загрузки.

```java
public String ReadyState { get; }
```
