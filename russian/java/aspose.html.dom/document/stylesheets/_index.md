## Document.StyleSheets property

Список, содержащий все таблицы стилей, явно связанные или встроенные в документ. Для HTML‑документов это включает внешние таблицы стилей, подключённые через элемент HTML LINK, и встроенные элементы STYLE.

public IStyleSheetList StyleSheets { get; }
