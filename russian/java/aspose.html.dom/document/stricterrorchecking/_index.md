## Document.StrictErrorChecking property

Атрибут, указывающий, применяется ли проверка ошибок. При значении false реализация может не проверять каждый возможный случай ошибки, обычно определяемый в операциях DOM, и не генерировать DOMException при операциях DOM или не сообщать об ошибках при использовании Document.normalizeDocument(). В случае ошибки поведение не определено. По умолчанию этот атрибут имеет значение true.

```java
public bool StrictErrorChecking { get; set; }
```

### Property Value

`true` если включена строгая проверка ошибок; иначе `false`.
