## Document.ImportNode method

Импортирует узел из другого документа в текущий, не изменяя и не удаляя исходный узел из оригинального документа; этот метод создаёт новую копию исходного узла.

```java
public Node ImportNode(Node importedNode, bool deep)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| importedNode | Узел | Импортированный узел. |
| глубокий | Boolean | если установлено `true` [deep]. |
