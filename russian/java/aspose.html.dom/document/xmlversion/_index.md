## Document.XmlVersion property

Атрибут, указывающий, в составе декларации XML, номер версии этого документа. Если декларации нет и если этот документ поддерживает функцию \"XML\", значение равно \"1.0\". Если этот документ не поддерживает функцию \"XML\", значение всегда равно null.

```java
public String XmlVersion { get; set; }
```

### Property Value

Версия XML.
