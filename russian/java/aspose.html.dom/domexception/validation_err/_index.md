## DOMException.VALIDATION_ERR field

Если вызов метода, такого как insertBefore или removeChild, сделает узел (Node) недействительным с точки зрения «частичной валидности», будет выброшено исключение, и операция не будет выполнена. Этот код используется в [DOM Level 3 Validation]. Обратитесь к этой спецификации для получения дополнительной информации.

```java
public const ushort VALIDATION_ERR;
```
