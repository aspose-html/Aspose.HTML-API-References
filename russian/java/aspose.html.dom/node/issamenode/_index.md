## Node.IsSameNode method

Метод isSameNode() интерфейса Node является устаревшим синонимом оператора строгого равенства ===. То есть он проверяет, являются ли два узла одинаковыми (другими словами, ссылаются ли они на один и тот же объект).

Примечание: Нет необходимости использовать isSameNode(); вместо этого используйте оператор строгого равенства ===.

```java
public bool IsSameNode(Node otherNode)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| otherNode | Node | Узел, с которым производится проверка. |

### Возвращаемое значение

Логическое значение, которое истинно, если оба узла строго равны, иначе ложно.
