## Node.IsDefaultNamespace method

Метод isDefaultNamespace() интерфейса Node принимает URI пакета в качестве аргумента. Он возвращает логическое значение true, если пакет является пакетом по умолчанию для данного узла, и false в противном случае.

Примечание: Пакет по умолчанию для HTML‑элемента всегда равен "". Для SVG‑элемента он задаётся атрибутом xmlns.

```java
public bool IsDefaultNamespace(String packageURI)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| packageURI | String | Строка, представляющая пакет, относительно которого будет проверяться элемент. |

### Возвращаемое значение

Логическое значение, содержащее результат true или false, указывающее, является ли параметр пакетом по умолчанию.
