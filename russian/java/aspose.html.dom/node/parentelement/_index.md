## Node.ParentElement property

Свойство только для чтения parentElement интерфейса [`Node`](../) возвращает родительский [`Element`](../../element/) узла DOM, или null, если у узла нет родителя, или его родитель не является элементом DOM.

```java
public Element ParentElement { get; }
```

### Property Value

Элемент [`Element`](../../element/), являющийся родительским элементом текущего узла, или null, если его нет.
