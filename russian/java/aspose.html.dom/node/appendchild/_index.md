## Node.AppendChild method

Метод appendChild() интерфейса Node добавляет узел в конец списка дочерних элементов указанного родительского узла. Если переданный дочерний элемент является ссылкой на уже существующий узел в документе, appendChild() перемещает его из текущего положения в новое (не требуется удалять узел из его родительского узла перед добавлением его к другому узлу).

Это означает, что узел не может находиться в двух точках документа одновременно. Поэтому, если у узла уже есть родитель, он сначала удаляется, а затем вставляется в новое положение. Метод [`Node.cloneNode()`](../clonenode/) можно использовать для создания копии узла перед его добавлением к новому родителю. Копии, созданные с помощью [`cloneNode`](../clonenode/), не синхронизируются автоматически.

```java
public Node AppendChild(Node node)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| узел | Node | Узел, который будет добавлен к указанному родительскому узлу (обычно элементу). |

### Возвращаемое значение

Узел, являющийся добавленным дочерним элементом (aChild), за исключением случая, когда aChild является [`DocumentFragment`](../../documentfragment/); тогда возвращается пустой [`DocumentFragment`](../../documentfragment/).
