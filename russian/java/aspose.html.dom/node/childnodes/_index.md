## Node.ChildNodes property

Только для чтения свойство childNodes интерфейса Node возвращает живой [`NodeList`](../../../com.aspose.html.collections/nodelist/) дочерних узлов заданного элемента, где первый дочерний узел имеет индекс 0. Дочерние узлы включают элементы, текст и комментарии.

Примечание: То, что [`NodeList`](../../../com.aspose.html.collections/nodelist/) является живым, означает, что его содержимое меняется каждый раз, когда добавляются или удаляются новые дочерние узлы.

```java
public NodeList ChildNodes { get; }
```

### Property Value

Живой [`NodeList`](../../../com.aspose.html.collections/nodelist/), содержащий дочерние узлы узла.

Примечание: Несколько вызовов childNodes возвращают один и тот же [`NodeList`](../../../com.aspose.html.collections/nodelist/).
