## Node.LocalName property

Возвращает локальную часть квалифицированного имени этого узла. Для узлов любого типа, кроме [`ELEMENT_NODE`](../element_node/) и [`ATTRIBUTE_NODE`](../attribute_node/), а также узлов, созданных методом уровня DOM 1, таким как [`Document.createElement()`](../../document/createelement/), всегда возвращается null.

```java
public String LocalName { get; }
```

### Property Value

Строка, представляющая локальную часть квалифицированного имени элемента.
