## Node.NextSibling property

Только для чтения свойство nextSibling интерфейса [`Node`](../) возвращает узел, непосредственно следующий за указанным в родительском [`childNodes`](../childnodes/), или возвращает null, если указанный узел является последним дочерним элементом в родительском элементе.

```java
public Node NextSibling { get; }
```

### Property Value

[`Node`](../) представляющий следующий соседний узел текущего узла, или null, если их нет.
