## Node.OwnerDocument property

Только для чтения свойство ownerDocument интерфейса Node возвращает объект верхнего уровня документа узла.

```java
public Document OwnerDocument { get; }
```

### Property Value

Объект [`Document`](../../document/), который является объектом верхнего уровня, в котором создаются все дочерние узлы.

Если это свойство используется на узле, который сам является документом, значение равно null.
