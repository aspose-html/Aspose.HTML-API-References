## Node.NamespaceURI property

Свойство только для чтения Element.packageURI возвращает URI пакета элемента, или null, если элемент не находится в пакете.

```java
public String NamespaceURI { get; }
```

### Property Value

Строка, представляющая URI пакета квалифицированного имени элемента.
