## Node.HasChildNodes method

Метод hasChildNodes() интерфейса Node возвращает логическое значение, указывающее, имеет ли данный [`Node`](../) дочерние узлы.

```java
public bool HasChildNodes()
```

### Возвращаемое значение

Логическое значение, которое истинно, если у узла есть дочерние узлы, и ложно в противном случае.
