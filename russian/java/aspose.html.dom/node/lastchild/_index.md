## Node.LastChild property

Свойство только для чтения lastChild интерфейса [`Node`](../) возвращает последнего потомка узла. Если его родитель — элемент, то потомок обычно является элементным узлом, текстовым узлом или узлом комментария. Возвращает null, если дочерних элементов нет.

```java
public Node LastChild { get; }
```

### Property Value

Объект [`Node`](../), являющийся последним потомком узла, или null, если дочерних элементов нет.
