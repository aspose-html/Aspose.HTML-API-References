## Node.IsEqualNode method

Метод isEqualNode() интерфейса [`Node`](../) проверяет, равны ли два узла. Два узла считаются равными, когда они имеют одинаковый тип, определяющие характеристики (для элементов это их ID, количество дочерних узлов и т.д.), их атрибуты совпадают и т.п. Конкретный набор данных, которые должны совпадать, варьируется в зависимости от типов узлов.

```java
public bool IsEqualNode(Node otherNode)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| otherNode | Node | Узел [`Node`](../), с которым сравнивать равенство. |

### Возвращаемое значение

Булево значение, которое истинно, если два узла равны, и ложно в противном случае. Если otherNode равно null, isEqualNode() всегда возвращает false.
