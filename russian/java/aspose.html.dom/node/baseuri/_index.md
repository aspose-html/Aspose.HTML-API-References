## Node.BaseURI property

Только для чтения свойство baseURI интерфейса Node возвращает абсолютный базовый URL документа, содержащего узел.

Базовый URL используется для разрешения относительных URL, когда браузеру необходимо получить абсолютный URL, например при обработке атрибута src элемента img HTML или атрибутов xlink:href или href в SVG.

```java
public String BaseURI { get; }
```

### Property Value

Геттер baseURI возвращает базовый URL документа узла, сериализованный.
