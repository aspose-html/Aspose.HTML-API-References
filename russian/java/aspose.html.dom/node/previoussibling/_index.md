## Node.PreviousSibling property

Только для чтения свойство previousSibling интерфейса [`Node`](../) возвращает узел, непосредственно предшествующий указанному, в списке [`childNodes`](../firstchild/) его родителя, или null, если указанный узел является первым в этом списке.

```java
public Node PreviousSibling { get; }
```

### Property Value

Объект [`Node`](../) представляет предыдущего брата текущего узла, или null, если их нет.
