## Node.LookupNamespaceURI method

Метод lookupNamespaceURI() интерфейса Node принимает префикс в качестве параметра и возвращает URI пакета, связанный с ним у данного узла, если найден (и null, если нет).

```java
public String LookupNamespaceURI(String prefix)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| префикс | String | Префикс для поиска. |

### Возвращаемое значение

Строка, содержащая URI пакета, соответствующего префиксу. Если префикс не найден, возвращается null. Если запрошенный префикс равен null, возвращается URI пакета по умолчанию.
