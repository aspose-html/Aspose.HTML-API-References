## ITreeWalker.NextNode method

Перемещает TreeWalker к следующему видимому узлу в порядке документа относительно текущего узла и возвращает новый узел. Если у текущего узла нет следующего узла или поиск nextNode пытается подняться выше корневого узла TreeWalker, возвращает null и сохраняет текущий узел.

```java
public Node NextNode()
```

### Возвращаемое значение

Новый узел, или null, если у текущего узла нет следующего узла в логическом представлении TreeWalker.
