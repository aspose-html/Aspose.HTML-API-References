## ITreeWalker.ParentNode method

Перемещает к ближайшему видимому предку текущего узла и возвращает его. Если поиск parentNode пытается подняться выше корневого узла TreeWalker или не находит видимого предка, метод сохраняет текущую позицию и возвращает null.

```java
public Node ParentNode()
```

### Возвращаемое значение

Новый родительский узел или null, если у текущего узла нет родителя в логическом представлении TreeWalker.
