## IElementTraversal.PreviousElementSibling property

Возвращает предыдущий соседний элемент этого элемента. null, если у этого элемента нет соседних элементов, идущих перед ним в дереве документа.

```java
public Element PreviousElementSibling { get; }
```

### Property Value

Предыдущий соседний элемент.
