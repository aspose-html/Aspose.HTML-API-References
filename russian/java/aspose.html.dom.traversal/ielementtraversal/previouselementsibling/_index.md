## IElementTraversal.PreviousElementSibling property

Возвращает узел предыдущего соседнего элемента данного элемента. null, если у этого элемента нет соседних элементных узлов, которые идут перед ним в дереве документа.

```java
public Element PreviousElementSibling { get; }
```

### Property Value

Предыдущий соседний элемент.
