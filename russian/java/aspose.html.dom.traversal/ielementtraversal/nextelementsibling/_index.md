## IElementTraversal.NextElementSibling property

Возвращает узел следующего соседнего элемента данного элемента. null, если у этого элемента нет соседних элементных узлов, которые идут после него в дереве документа.

```java
public Element NextElementSibling { get; }
```

### Property Value

Следующий соседний элемент.
