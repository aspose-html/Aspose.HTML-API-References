## IElementTraversal.NextElementSibling property

Возвращает следующий соседний элемент этого элемента. null, если у этого элемента нет соседних элементов, идущих после него в дереве документа.

```java
public Element NextElementSibling { get; }
```

### Property Value

Следующий соседний элемент.
