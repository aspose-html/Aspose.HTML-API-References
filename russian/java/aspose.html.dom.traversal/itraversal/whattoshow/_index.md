## ITraversal.WhatToShow property

Этот атрибут определяет, какие типы узлов представлены через итератор. Доступный набор констант определён в интерфейсе NodeFilter. Узлы, не принятые whatToShow, будут пропущены, но их дочерние элементы могут быть учтены. Обратите внимание, что это пропускание имеет приоритет над фильтром, если он существует.

public long WhatToShow { get; }
