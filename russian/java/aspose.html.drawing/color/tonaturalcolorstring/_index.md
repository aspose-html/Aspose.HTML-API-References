## Color.ToNaturalColorString method

Возвращает указанный цвет Natural colors (NCol), используя буквенный обозначитель цвета и число, указывающее расстояние (в процентах) от цвета.

```java
public String ToNaturalColorString(int digits)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| digits | Int32 | Устанавливает точность округления для компонентов цвета. |

### Возвращаемое значение

Строка Natural colors (NCol)
