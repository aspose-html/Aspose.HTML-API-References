## ITrueTypeFont.SubFamilyName property

Имя подсемейства шрифта различает шрифт в группе с тем же именем семейства шрифта. Предполагается, что это учитывает стиль (italic, oblique) и вес (light, bold, black и т.д.). Шрифт без особых различий в весе или стиле (например средний вес, не italic и установленный бит fsSelection 6) должен иметь строку \"Regular\" в этой позиции

```java
public String SubFamilyName { get; }
```

### Возвращаемое значение

Имя подсемейства шрифта
