## ITrueTypeFont.SubFamilyName property

Имя подсемейства шрифта различает шрифт в группе с тем же именем семейства шрифта. Предполагается, что это учитывает стиль (italic, oblique) и вес (light, bold, black, etc.). Шрифт без особых различий в весе или стиле (e.g. medium weight, not italic and fsSelection bit 6 set) должен иметь строку "Regular" в этом положении.

```java
public String SubFamilyName { get; }
```

### Возвращаемое значение

Имя подсемейства шрифта
