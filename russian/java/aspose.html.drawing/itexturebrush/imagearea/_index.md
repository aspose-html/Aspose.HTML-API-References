## ITextureBrush.ImageArea property

Указывает часть изображения, используемую кистью. Если равно RectangleF.Empty, будет использовано всё изображение. Координаты задаются в пикселях.

```java
public RectangleF ImageArea { get; }
```

### Возвращаемое значение

Область изображения
