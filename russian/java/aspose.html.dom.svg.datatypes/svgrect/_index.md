## SVGRect class

Представляет прямоугольную геометрию. Прямоугольники определяются как пара координат (x,y), указывающая минимальное значение X, минимальное значение Y, а также ширину и высоту, которые обычно ограничены неотрицательными значениями.

```java
public class SVGRect : SVGValueType
```
