## SVGAngle.ValueInSpecifiedUnits property

Значение угла как число с плавающей точкой, в единицах, указанных unitType. Установка этого атрибута приведёт к автоматическому обновлению value и valueAsString, чтобы отразить эту настройку.

```java
public float ValueInSpecifiedUnits { get; set; }
```

### Property Value

Значение в указанных единицах.
