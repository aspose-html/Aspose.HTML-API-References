## SVGAngle.SVG_ANGLETYPE_UNSPECIFIED field

Тип единицы измерения не был указан (т.е. было задано безразмерное значение). Для углов безразмерное значение рассматривается так же, как если бы были указаны градусы.

```java
public const ushort SVG_ANGLETYPE_UNSPECIFIED;
```
