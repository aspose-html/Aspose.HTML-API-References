## SVGTransform.SetTranslate method

Устанавливает тип трансформации в SVG_TRANSFORM_TRANSLATE, с параметрами tx и ty, определяющими величины трансляции.

```java
public void SetTranslate(float tx, float ty)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| tx | Single | Величина перемещения по X. |
| ты | Single | Величина трансляции по оси Y. |

| исключение | условие |
