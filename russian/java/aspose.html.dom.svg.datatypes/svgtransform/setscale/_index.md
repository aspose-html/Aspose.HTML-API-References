## SVGTransform.SetScale method

Устанавливает тип трансформации в SVG_TRANSFORM_SCALE, с параметрами sx и sy, определяющими коэффициенты масштабирования.

```java
public void SetScale(float sx, float sy)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| sx | Single | Величина масштабирования по оси X. |
| sy | Single | Величина масштабирования по оси Y. |

### Исключения

| исключение | условие |
| --- | --- |
| [dOMException](../../../com.aspose.html.dom/domexception/) | Код [`NO_MODIFICATION_ALLOWED_ERR`](../../../com.aspose.html.dom/domexception/no_modification_allowed_err/). Возникает при попытке изменить значение только для чтения атрибута. |
