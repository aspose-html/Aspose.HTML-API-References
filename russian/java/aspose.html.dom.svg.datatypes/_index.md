Пакет предоставляет доступ ко всем типам данных, специфичным для SVG.

## Классы

| Класс | Описание |
| --- | --- |
| [SVGAngle](./svgangle/) | Интерфейс SVGAngle соответствует базовому типу данных angle. |
| [SVGAnimatedAngle](./svganimatedangle/) | Используется для атрибутов базового типа angle, которые могут анимироваться. |
| [SVGAnimatedBoolean](./svganimatedboolean/) | Используется для атрибутов типа boolean, которые могут анимироваться. |
| [SVGAnimatedEnumeration](./svganimatedenumeration/) | Используется для атрибутов, значение которых должно быть константой из определённого перечисления и которые могут анимироваться. |
| [SVGAnimatedInteger](./svganimatedinteger/) | Используется для атрибутов базового типа integer, которые могут анимироваться. |
| [SVGAnimatedLength](./svganimatedlength/) | Используется для атрибутов базового типа length, которые могут анимироваться. |
| [SVGAnimatedLengthList](./svganimatedlengthlist/) | Используется для атрибутов типа SVGLengthList, которые могут анимироваться. |
| [SVGAnimatedNumber](./svganimatednumber/) | Используется для атрибутов базового типа number, которые могут анимироваться. |
| [SVGAnimatedNumberList](./svganimatednumberlist/) | Используется для атрибутов, принимающих список чисел и которые могут анимироваться. |
| [SVGAnimatedPreserveAspectRatio](./svganimatedpreserveaspectratio/) | Используется для атрибутов типа SVGPreserveAspectRatio, которые могут анимироваться. |
| [SVGAnimatedRect](./svganimatedrect/) | Используется для атрибутов типа SVGRect, которые могут анимироваться. |
| [SVGAnimatedString](./svganimatedString/) | Используется для атрибутов типа DOMString, которые могут анимироваться. |
| [SVGAnimatedTransformList](./svganimatedtransformlist/) | Используется для различных атрибутов, которые задают набор преобразований, таких как атрибут ‘transform’, доступный для многих элементов SVG, и который может анимироваться. |
| [SVGAnimatedValue&lt;T&gt;](./svganimatedvalue-1/) | Используется для атрибутов типов, которые могут анимироваться. |
| [SVGLength](./svglength/) | Интерфейс SVGLength соответствует базовому типу данных длина. Объект SVGLength может быть объявлен только для чтения, что означает, что попытки изменить объект приведут к выбросу исключения, как описано ниже. |
| [SVGLengthList](./svglengthlist/) | Этот интерфейс определяет список объектов SVGLength. |
| [SVGMatrix](./svgmatrix/) | Во многих графических операциях SVG используются 2×3 матрицы вида: [a c e] [b d f], которые при расширении до 3×3 матрицы для целей матричной арифметики становятся: [a c e] [b d f] [0 0 1] |
| [SVGNumber](./svgnumber/) | Используется для атрибутов базового типа number. |
| [SVGNumberList](./svgnumberlist/) | Этот интерфейс определяет список объектов SVGNumber. |
| [SVGPoint](./svgpoint/) | Во многих интерфейсах SVG DOM имеются ссылки на объекты класса SVGPoint. SVGPoint представляет собой пару координат (x, y). При использовании в матричных операциях SVGPoint рассматривается как вектор формы: [x] [y] [1]. Если объект SVGRect объявлен только для чтения, попытка присвоить значение одному из его атрибутов приведёт к выбросу исключения. |
| [SVGPointList](./svgpointlist/) | Этот интерфейс определяет список объектов SVGPoint. |
| [SVGPreserveAspectRatio](./svgpreserveaspectratio/) | Интерфейс SVGPreserveAspectRatio соответствует атрибуту ‘preserveAspectRatio’, доступному для некоторых элементов SVG. |
| [SVGRect](./svgrect/) | Представляет прямоугольную геометрию. Прямоугольники определяются как пара координат (x, y), указывающая минимальное значение X, минимальное значение Y, а также ширину и высоту, которые обычно ограничены неотрицательными значениями. |
| [SVGStringList](./svgStringlist/) | SVGStringList имеет те же атрибуты и методы, что и другие интерфейсы SVGxxxList. Реализаторы могут рассмотреть возможность использования единого базового класса для реализации различных интерфейсов SVGxxxList. |
| [SVGTransform](./svgtransform/) | SVGTransform — это интерфейс одной из компонентных трансформаций внутри SVGTransformList; таким образом, объект SVGTransform соответствует отдельной компоненте (например, 'scale(…)' или 'matrix(…)') в спецификации атрибута ‘transform’. |
| [SVGTransformList](./svgtransformlist/) | Этот интерфейс определяет список объектов SVGTransform. |
| [SVGValueType](./svgvaluetype/) | Тип SVGValueType используется для представления базового типа значения SVG. |
