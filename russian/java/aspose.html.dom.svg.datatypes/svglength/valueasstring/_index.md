## SVGLength.ValueAsString property

Значение в виде строки, в единицах, указанных unitType. Установка этого атрибута приведёт к автоматическому обновлению value, valueInSpecifiedUnits и unitType, чтобы отразить данную настройку.

```java
public String ValueAsString { get; set; }
```

### Property Value

Значение как String.

### Исключения

| исключение | условие |
| --- | --- |
| [dOMException](../../../com.aspose.html.dom/domexception/) | Код [`SYNTAX_ERR`](../../../com.aspose.html.dom/domexception/syntax_err/) возникает, если назначенная строка не может быть разобрана как допустимая длина. |
| [dOMException](../../../com.aspose.html.dom/domexception/) | Код [`NO_MODIFICATION_ALLOWED_ERR`](../../../com.aspose.html.dom/domexception/no_modification_allowed_err/) вызывается, когда длина соответствует атрибуту только для чтения или когда сам объект только для чтения. |
