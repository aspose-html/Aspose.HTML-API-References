## SVGLength.ValueInSpecifiedUnits property

Значение в виде числа с плавающей точкой, в единицах, указанных unitType. Установка этого атрибута приведёт к автоматическому обновлению value и valueAsString, чтобы отразить данную настройку.

```java
public float ValueInSpecifiedUnits { get; set; }
```

### Property Value

Значение в указанных единицах.

| исключение | условие |
