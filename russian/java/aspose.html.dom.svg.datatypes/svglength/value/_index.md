## SVGLength.Value property

Значение как число с плавающей точкой в пользовательских единицах. Установка этого атрибута приведёт к автоматическому обновлению valueInSpecifiedUnits и valueAsString, чтобы отразить эту настройку.

```java
public float Value { get; set; }
```
