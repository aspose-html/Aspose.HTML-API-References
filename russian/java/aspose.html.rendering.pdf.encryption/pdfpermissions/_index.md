## PdfPermissions enumeration

Это перечисление представляет разрешения пользователя для PDF.

```java
[Flags]
public enum PdfPermissions
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| PrintDocument | `4` | (Обработчики безопасности версии 2) Печать документа. (Обработчики безопасности версии 3 и выше) Печать документа (возможно не в самом высоком качестве, в зависимости от того, установлен ли параметр PrintingQuality). |
| ModifyContent | `8` | Изменять содержимое документа операциями, отличными от тех, которые контролируются ModifyTextAnnotations, FillForm и 11. |
| ExtractContent | `10` | (Обработчики безопасности версии 2) Копировать или иным способом извлекать текст и графику из документа, включая извлечение текста и графики (в поддержку доступности для пользователей с ограниченными возможностями или в иных целях). (Обработчики безопасности версии 3 и выше) Копировать или иным способом извлекать текст и графику из документа операциями, отличными от тех, которые контролируются ExtractContentWithDisabilities. |
| ModifyTextAnnotations | `20` | Добавлять или изменять текстовые аннотации, заполнять интерактивные поля форм и, если также установлен ModifyContent, создавать или изменять интерактивные поля форм (включая поля подписи). |
| FillForm | `100` | (Обработчики безопасности версии 3 и выше) Заполнять существующие интерактивные поля форм (включая поля подписи), даже если флаг ModifyTextAnnotations снят. |
| ExtractContentWithDisabilities | `200` | (Обработчики безопасности версии 3 и выше) Извлекать текст и графику (в поддержку доступности для пользователей с ограниченными возможностями или в иных целях). |
| AssembleDocument | `400` | (Обработчики безопасности версии 3 и выше) Собирать документ (вставлять, вращать или удалять страницы и создавать закладки или миниатюры), даже если флаг ModifyContent снят. |
| PrintingQuality | `800` | (Обработчики безопасности версии 3 и выше) Печатать документ в представление, из которого может быть создана точная цифровая копия содержимого PDF. Когда этот бит снят (и бит 3 установлен), печать ограничивается низкоуровневым представлением внешнего вида, возможно с пониженным качеством. |
