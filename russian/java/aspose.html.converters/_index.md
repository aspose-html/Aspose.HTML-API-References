Цель пакета **com.aspose.html.converters** — обеспечить простой доступ к методам конвертации. Он предоставляет широкий спектр конвертаций в популярные форматы, такие как PDF, XPS, форматы изображений и т.д. Более специфические сценарии конвертации (рендеринг, сохранение) представлены хорошо известными и документированными низкоуровневыми функциями API в предметно‑ориентированных пакетах.

## Классы

| Класс | Описание |
| --- | --- |
| [Converter](./converter/) | Общая фасадная оболочка только для наиболее часто встречающихся сценариев конвертации. Она предоставляет широкий спектр конвертаций в популярные форматы, такие как PDF, XPS, форматы изображений и т.д. Более специфические сценарии конвертации (рендеринг, сохранение) представлены хорошо известными и документированными низкоуровневыми API‑функциями. |
| [TemplateContentOptions](./templatecontentoptions/) | Встроенный объект контента для обработки слияния. |
| [TemplateData](./templatedata/) | Объект данных слияния (пользовательских). |
