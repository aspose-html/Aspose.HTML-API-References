Цель пакета **com.aspose.html.converters** — обеспечить простой доступ к методам конвертации. Он предоставляет широкий спектр конвертаций в популярные форматы, такие как PDF, XPS, форматы изображений и т.д. Более специфические сценарии конвертации (рендеринг, сохранение) представлены известными и документированными функциями низкоуровневого API в специализированных пакетах.

## Классы

| Класс | Описание |
| --- | --- |
| [Converter](./converter/) | Общая фасада только для наиболее часто встречающихся сценариев конвертации. Она предоставляет широкий спектр конвертаций в популярные форматы, такие как PDF, XPS, форматы изображений и т.д. Более специфические сценарии конвертации (рендеринг, сохранение) представлены известными и документированными низкоуровневыми функциями API. |
| [TemplateContentOptions](./templatecontentoptions/) | Встроенный объект контента для обработки слияния. |
| [TemplateData](./templatedata/) | Объект данных слияния (User). |
