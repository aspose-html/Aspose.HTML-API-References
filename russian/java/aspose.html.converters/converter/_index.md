## Converter class

Общая фасадная оболочка только для наиболее часто встречающихся сценариев конвертации. Она предоставляет широкий спектр конвертаций в популярные форматы, такие как PDF, XPS, форматы изображений и т.д. Более специфические сценарии конвертации (рендеринг, сохранение) представлены хорошо известными и документированными низкоуровневыми API‑функциями.

Более подробную информацию о конкретных конверсиях можно получить в [Aspose Documentation](https://docs.aspose.com/html/net/converting-between-formats/)

public static class Converter
