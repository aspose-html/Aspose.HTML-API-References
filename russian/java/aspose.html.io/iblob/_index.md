## IBlob interface

Объект Blob представляет собой последовательность байтов и имеет атрибут size, который является общим числом байтов в последовательности, а также атрибут type, который представляет собой строку в нижнем регистре, закодированную в ASCII, обозначающую тип медиа последовательности байтов.

```java
public interface IBlob
```

## Свойства

| Имя | Описание |
| --- | --- |
| [getSize](../../com.aspose.html.io/iblob/size/) Возвращает размер последовательности байтов в количестве байтов. При получении совместимые пользовательские агенты должны вернуть общее количество байтов, которые могут быть прочитаны объектом FileReader или FileReaderSync, или 0, если у Blob нет байтов для чтения. |
| [getType](../../com.aspose.html.io/iblob/type/) Строка в нижнем регистре, закодированная в ASCII, представляющая тип медиа Blob. При получении пользовательские агенты должны вернуть тип Blob как строку, закодированную в ASCII в нижнем регистре, так чтобы при преобразовании в последовательность байтов это был корректный MIME‑тип, или пустую строку – 0 байт – если тип определить невозможно. |
