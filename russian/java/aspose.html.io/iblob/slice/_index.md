## IBlob.Slice method

Возвращает новый объект Blob с байтами, начиная с необязательного параметра start и заканчивая, но не включая, необязательный параметр end, а также с атрибутом type, значение которого равно необязательному параметру contentType.

```java
public IBlob Slice(ulong start, ulong end, String contentType)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| начало | UInt64 | Параметр представляет значение начальной точки среза. |
| конец | UInt64 | Параметр представляет значение начальной точки среза. |
| contentType | String | Параметр представляет тип медиа-данных Blob. |

### Возвращаемое значение

Возвращает новый объект Blob с байтами, начиная с необязательного параметра start и заканчивая, но не включая, необязательный параметр end, а также с атрибутом type, значение которого равно необязательному параметру contentType.
