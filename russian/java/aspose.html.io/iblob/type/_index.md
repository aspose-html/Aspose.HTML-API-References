## IBlob.Type property

Строка в нижнем регистре, закодированная в ASCII, представляющая тип медиа-данных Blob. При получении пользовательские агенты должны возвращать тип Blob как строку, закодированную в ASCII в нижнем регистре, так чтобы при преобразовании в последовательность байтов это был корректный MIME‑тип, или пустую строку — 0 байт — если тип определить невозможно.

```java
public String Type { get; }
```
