Помимо стандартных средств ввода‑вывода (IO) пакет **com.aspose.html.io** содержит вспомогательные классы и интерфейсы.

## Классы

| Класс | Описание |
| --- | --- |
| [FileCreateStreamProvider](./filecreatestreamprovider/) | Представляет реализацию FileStream для предоставления потоков устройствам рендеринга. |
## Интерфейсы

| Интерфейс | Описание |
| --- | --- |
| [IBlob](./iblob/) | Объект Blob представляет собой последовательность байтов и имеет атрибут size, который является общим числом байтов в последовательности, а также атрибут type, который представляет собой строку в нижнем регистре, закодированную в ASCII, обозначающую тип медиа последовательности байтов. |
| [ICreateStreamProvider](./icreatestreamprovider/) | Представляет интерфейс, который может быть реализован классами, предоставляющими потоки устройствам рендеринга. |
| [IFile](./ifile/) | Объект File — это объект Blob с атрибутом name, который является строкой; он может быть создан в веб‑приложении через конструктор или является ссылкой на последовательность байтов из файла файловой системы (OS). |
| [IFileList](./ifilelist/) | Представляет интерфейс для списка файлов. |
