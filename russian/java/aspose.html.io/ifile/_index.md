## IFile interface

Объект File — это объект Blob с атрибутом name, который является строкой; он может быть создан в веб‑приложении через конструктор или представляет собой ссылку на последовательность байтов из файла файловой системы (ОС).

```java
public interface IFile : IBlob
```

## Свойства

| Имя | Описание |
| --- | --- |
| [getLastModified](../../com.aspose.html.io/ifile/lastmodified/) Дата последнего изменения файла. При получении, если пользовательские агенты могут предоставить эту информацию, метод должен вернуть значение типа long long, установленное во время последнего изменения файла в миллисекундах, прошедших с эпохи Unix. |
| [getName](../../com.aspose.html.io/ifile/name/) Имя файла. При получении метод должен вернуть имя файла как строку. |
