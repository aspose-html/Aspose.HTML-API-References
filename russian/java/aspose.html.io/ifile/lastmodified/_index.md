## IFile.LastModified property

Дата последнего изменения файла. При получении, если пользовательские агенты могут предоставить эту информацию, должно возвращать значение типа long long, установленное во время последнего изменения файла в виде количества миллисекунд с эпохи Unix.

```java
public long LastModified { get; }
```
