## ISVGAnimatedPathData.PathSegList property

Предоставляет доступ к базовым (т.е. статическим) содержимым атрибута ‘d’ в форме, полностью соответствующей синтаксису SVG. Таким образом, если атрибут ‘d’ содержит «абсолютную команду перемещения (M)» и «абсолютную команду дуги (A)», то pathSegList будет иметь две записи: SVG_PATHSEG_MOVETO_ABS и SVG_PATHSEG_ARC_ABS.

public SVGPathSegList PathSegList { get; }
