## Guideline class

Руководства — следующий уровень после принципов. Они не подлежат тестированию, но описывают рамки и общие цели, помогающие авторам понять критерии успеха и лучше применять техники. Руководства представляют собой список критериев приемки с типом RuleDirectory{Criterion}.
