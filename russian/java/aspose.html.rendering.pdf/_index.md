Пакет **com.aspose.html.rendering.pdf** предоставляет конкретный класс устройства, а также несколько классов параметров рендеринга, отвечающих за вывод в PDF‑документ.

## Классы

| Класс | Описание |
| --- | --- |
| [PdfDevice](./pdfdevice/) | Представляет рендеринг в PDF‑документ. |
| [PdfDocumentInfo](./pdfdocumentinfo/) | Представляет информацию о PDF‑документе. |
| [PdfRenderingOptions](./pdfrenderingoptions/) | Представляет параметры рендеринга для [`PdfDevice`](../com.aspose.html.rendering.pdf/pdfdevice/). |
