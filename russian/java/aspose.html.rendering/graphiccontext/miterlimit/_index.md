## GraphicContext.MiterLimit property

Устанавливает или получает максимальную длину срезов соединений линий для обводимых контуров. Этот параметр ограничивает длину «зубцов», образующихся при соединении сегментов линий под острыми углами.

```java
public float MiterLimit { get; set; }
```
