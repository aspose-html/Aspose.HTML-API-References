## StrokeLineJoin enumeration

Указывает стиль соединения линий, используемый при рендеринге SVG и HTML.

```java
public enum StrokeLineJoin
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Miter | `0` | Линии соединяются острым углом, выходящим за пределы конечных точек. |
| Round | `1` | Линии соединяются с закруглённым углом. |
| Bevel | `2` | Линии соединяются с фаской. |
