## IDevice.ClosePath method

Замыкает текущий подпуть, добавляя прямой отрезок от текущей точки к начальной точке подпути. Если текущий подпуть уже закрыт, \"ClosePath\" ничего не делает. Этот оператор завершает текущий подпуть. Добавление другого отрезка к текущему пути начинает новый подпуть, даже если новый отрезок начинается в конечной точке, достигнутой методом \"ClosePath\".
