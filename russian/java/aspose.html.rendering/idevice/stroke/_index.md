## IDevice.Stroke method

Обводит линию вдоль текущего контура. Обводимая линия следует каждому прямому или изогнутому сегменту контура, центрируясь на сегменте со сторонами, параллельными ему. Каждая подпуть контура обрабатывается отдельно. Этот метод завершает текущий контур.
