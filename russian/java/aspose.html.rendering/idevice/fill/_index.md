## IDevice.Fill method

Заполняет всю область, ограниченную текущим контуром. Если контур состоит из нескольких несвязанных подпутей, он заполняет внутренние части всех подпутей вместе. Этот метод завершает текущий контур.

```java
public void Fill(FillRule rule)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| правило | FillRule | Правило заполнения определяет, как внутренность замкнутого пути заполняется |
