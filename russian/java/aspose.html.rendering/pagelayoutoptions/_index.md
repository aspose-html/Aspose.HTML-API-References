## PageLayoutOptions enumeration

Указывает флаги, которые вместе с другими параметрами PageSetup определяют размеры и макеты страниц. Эти флаги могут комбинироваться согласно их описаниям.

```java
[Flags]
public enum PageLayoutOptions
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| None | `0` | Значение по умолчанию, указывающее, что PageLayoutOptions не будет влиять на размеры и макеты страниц. |
| FitToContentWidth | `1` | Этот флаг указывает, что ширина страниц определяется размером содержимого, а не указанной шириной страницы. Ширина содержимого рассчитывается индивидуально для каждой страницы. |
| UseWidestPage | `2` | В сочетании с FitToContentWidth указывает, что ширина каждой страницы будет одинаковой и равной самой широкой размеру содержимого среди всех страниц. |
| FitToWidestContentWidth | `3` | Этот флаг указывает, что ширина страницы определяется размером содержимого, а не указанной шириной страницы. Ширина каждой страницы будет одинаковой и равной самой широкой размеру содержимого среди всех страниц. |
| FitToContentHeight | `10` | Этот флаг указывает, что высота страницы определяется размером содержимого, а не указанной высотой страницы. Если этот флаг указан, всё содержимое документа будет размещено на одной странице. |
| ScaleToPageWidth | `100` | Этот флаг указывает, что содержимое документа будет масштабировано, чтобы соответствовать странице, где разница между доступной шириной страницы и перекрывающимся содержимым наибольшая. Он конфликтует с флагом FitToContentWidth, и если оба флага указаны, будет применён только ScaleToPageWidth. |
| ScaleToPageHeight | `1000` | Этот флаг указывает, что содержимое документа будет масштабировано, чтобы соответствовать высоте первой страницы. Он конфликтует с флагом FitToContentHeight, и если оба флага указаны, будет применён только ScaleToPageHeight. Всё содержимое документа будет размещено только на одной странице. |
