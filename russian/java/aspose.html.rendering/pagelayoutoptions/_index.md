## PageLayoutOptions enumeration

Указывает флаги, которые вместе с другими параметрами PageSetup определяют размеры и макеты страниц. Эти флаги могут комбинироваться в соответствии с их описаниями.

```java
[Flags]
public enum PageLayoutOptions
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| None | `0` | Значение по умолчанию, которое указывает, что PageLayoutOptions не будет влиять на размеры и макеты страниц. |
| FitToContentWidth | `1` | Этот флаг указывает, что ширина страниц определяется размером содержимого, а не указанной шириной страницы. Ширина содержимого рассчитывается индивидуально для каждой страницы. |
| UseWidestPage | `2` | При комбинировании с FitToContentWidth указывает, что ширина каждой страницы будет одинаковой и равной самой широкой величине содержимого среди всех страниц. |
| FitToWidestContentWidth | `3` | Этот флаг указывает, что ширина страницы определяется размером содержимого, а не указанной шириной страницы. Ширина каждой страницы будет одинаковой и равной самой широкой величине содержимого среди всех страниц. |
| FitToContentHeight | `10` | Этот флаг указывает, что высота страницы определяется размером содержимого, а не указанной высотой страницы. Всё содержимое документа будет размещено на одной странице, если этот флаг указан. |
| ScaleToPageWidth | `100` | Этот флаг указывает, что содержимое документа будет масштабировано так, чтобы вписаться в страницу, где разница между доступной шириной страницы и перекрывающимся содержимым максимальна. Он конфликтует с флагом FitToContentWidth, и если оба флага указаны, только ScaleToPageWidth будет применён. |
| ScaleToPageHeight | `1000` | Этот флаг указывает, что содержимое документа будет масштабировано так, чтобы вписаться в высоту первой страницы. Он конфликтует с флагом FitToContentHeight, и если оба флага указаны, только ScaleToPageHeight будет применён. Всё содержимое документа будет размещено только на одной странице. |
