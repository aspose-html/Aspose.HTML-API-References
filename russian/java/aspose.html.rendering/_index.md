Пакет **com.aspose.html.rendering** состоит из множества объектов рендерера, а также соответствующих классов параметров низкого уровня, отвечающих за рендеринг документов/файлов в реализацию IDevice.

## Классы

| Класс | Описание |
| --- | --- |
| [CssOptions](./cssoptions/) | Представляет параметры рендеринга CSS. |
| [Device](./device/) | Представляет базовый класс для реализации устройств рендеринга, которые используются для отрисовки графики в различных форматах и средах. |
| [Device&lt;TGraphicContext,TRenderingOptions&gt;](./device-2/) | Представляет базовый класс для реализации конкретных устройств рендеринга. |
| [EpubRenderer](./epubrenderer/) | Представляет рендерер EPub-документов. |
| [GraphicContext](./graphiccontext/) | Содержит текущие параметры управления графикой. Эти параметры определяют глобальную структуру, в которой выполняются графические операторы. |
| [HtmlRenderer](./htmlrenderer/) | Представляет рендерер HTML-документов. |
| [MhtmlRenderer](./mhtmlrenderer/) | Представляет рендерер MHTML-документов. |
| [PageSetup](./pagesetup/) | Представляет объект настройки страницы, используемый для конфигурации набора выводимых страниц. |
| [Renderer](./renderer/) | Представляет базовый класс для всех рендереров и реализует интерфейс IDisposable. |
| [Renderer&lt;TSource&gt;](./renderer-1/) | Представляет абстрактный класс для всех рендереров. |
| [RenderingOptions](./renderingoptions/) | Представляет параметры рендеринга. |
| [SvgRenderer](./svgrenderer/) | Представляет рендерер SVG-документов. |
| [TextInfo](./textinfo/) | Содержит информацию о отрендеренном тексте. |

| Интерфейс | Описание |

## Перечисление

| Перечисление | Описание |

| [AtPagePriority](./atpagepriority/) | Указывает возможные порядки применения объявлений размеров страниц. |
| [FillRule](./fillrule/) | Указывает правило заполнения, используемое при рендеринге SVG и HTML. |
| [MediaType](./mediatype/) | Указывает возможные типы медиа, используемые во время рендеринга. |
| [PageLayoutOptions](./pagelayoutoptions/) | Указывает флаги, которые вместе с другими параметрами PageSetup определяют размеры и макеты страниц. Эти флаги могут комбинироваться в соответствии с их описаниями. |
| [StrokeLineCap](./strokelinecap/) | Указывает тип окончания линии, используемый при рендеринге SVG и HTML. |
