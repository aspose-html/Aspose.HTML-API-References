## PageSetup.PageLayoutOptions property

Получает или задает [`PageLayoutOptions`](../../pagelayoutoptions/). Значение по умолчанию — None, любое другое значение переопределит [`AdjustToWidestPage`](../adjusttowidestpage/) поведение. Работает только с HTML‑документами.

```java
public PageLayoutOptions PageLayoutOptions { get; set; }
```
