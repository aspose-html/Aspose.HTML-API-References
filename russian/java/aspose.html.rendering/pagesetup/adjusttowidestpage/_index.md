## PageSetup.AdjustToWidestPage property

Получает или задает флаг, определяющий случай, когда размер страницы будет скорректирован до самой широкой страницы в документе. Эта опция требует много времени, поэтому время обработки документа может увеличиться вдвое. Корректировка произойдёт только если самая широкая страница в документе шире размера страницы, определённого в [`PageSetup`](../). Скорректированный размер страницы будет использоваться для всех страниц в документе.

```java
public bool AdjustToWidestPage { get; set; }
```
