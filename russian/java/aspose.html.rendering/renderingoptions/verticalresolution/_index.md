## RenderingOptions.VerticalResolution property

Устанавливает или получает вертикальное разрешение для внутренних (используемых при обработке фильтров) изображений в пикселях на дюйм. По умолчанию это свойство равно 300 dpi.

public Resolution VerticalResolution { get; set; }
