## RenderingOptions.HorizontalResolution property

Устанавливает или получает горизонтальное разрешение для внутренних (используемых при обработке фильтров) изображений, в пикселях на дюйм. По умолчанию это свойство равно 300 dpi.

public Resolution HorizontalResolution { get; set; }
