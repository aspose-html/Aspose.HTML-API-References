## FillRule enumeration

Указывает правило заполнения, используемое при рендеринге SVG и HTML.

```java
public enum FillRule
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| EvenOdd | `0` | Определяет область заполнения с использованием правила «чётно‑нечётное». Поведение соответствует System.Drawing.Drawing2D.FillMode.Alternate. |
| Nonzero | `1` | Определяет область заполнения с использованием правила «не‑ноль». Поведение соответствует System.Drawing.Drawing2D.FillMode.Winding. |
