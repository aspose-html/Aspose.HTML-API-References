## ICSSPageRule.Style property

Свойство только для чтения style интерфейса [`CSSPageRule`](../) возвращает объект [`CSSStyleDeclaration`](../../icssstyledeclaration/). Это представляет объект, являющийся блоком CSS‑деклараций, и предоставляет информацию о стиле и различные методы и свойства, связанные со стилем.

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

Объект [`CSSStyleDeclaration`](../../icssstyledeclaration/), представляющий блок CSS‑деклараций.
