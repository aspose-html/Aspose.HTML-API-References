## ICSSPageRule interface

Интерфейс CSSPageRule представляет правило @page в таблице стилей CSS. Правило @page используется для указания размеров, ориентации, полей и т.д. области страницы для печатных носителей.

```java
public interface ICSSPageRule : ICSSRule
```
