## CSSPrimitiveValue.GetRGBColorValue method

Этот метод используется для получения цвета RGB. Если это CSS‑значение не содержит значение цвета RGB, генерируется DOMException. Изменение соответствующего свойства стиля можно выполнить с помощью интерфейса RGBColor.

```java
public abstract RGBColor GetRGBColorValue()
```

### Возвращаемое значение

Возвращает значение RGB‑цвета
