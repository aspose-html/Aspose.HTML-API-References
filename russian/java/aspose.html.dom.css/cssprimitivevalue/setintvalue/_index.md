## CSSPrimitiveValue.SetIntValue method

Метод для установки целочисленного значения в указанной единице измерения. Если свойство, к которому привязано это значение, не может принимать указанную единицу или целочисленное значение, значение останется неизменным, и будет сгенерирован DOMException.

```java
public abstract void SetIntValue(ushort unitType, int intValue)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| unitType | UInt16 | Тип единицы. |
| intValue | Int32 | Целочисленное значение. |
