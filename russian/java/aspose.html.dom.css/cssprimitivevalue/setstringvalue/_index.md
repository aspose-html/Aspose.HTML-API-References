## CSSPrimitiveValue.SetStringValue method

Метод для установки строкового значения в указанной единице измерения. Если свойство, к которому привязано это значение, не может принимать указанную единицу или строковое значение, значение останется неизменным, и будет сгенерирован DOMException.
