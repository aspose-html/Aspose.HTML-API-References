## IDocumentCSS.GetOverrideStyle method

Этот метод используется для получения объявления переопределяющего стиля для указанного элемента и указанного псевдо‑элемента.

```java
public ICSSStyleDeclaration GetOverrideStyle(Element elt, String pseudoElt)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| elt | Элемент | Элемент, стиль которого будет изменён. Этот параметр не может быть null. |
| pseudoElt | String | Псевдо‑элемент или null, если его нет. |

### Возвращаемое значение

Объявление переопределённого стиля.
