## IStyleSheet.Media property

Свойство media интерфейса [`StyleSheet`](../) указывает целевую среду назначения для информации о стиле. Это объект [`MediaList`](../../imedialist/), похожий на массив, только для чтения, и его можно удалить с помощью deleteMedium() и добавить с помощью appendMedium().

```java
public IMediaList Media { get; }
```

### Property Value

Атрибут media должен возвращать объект [`MediaList`](../../imedialist/), связанный с таблицей стилей CSS.

## Примечания

[CSSOM](https://drafts.csswg.org/cssom/) defines APIs (including generic parsing and serialization rules) for Media Queries, Selectors, and of course CSS itself.
