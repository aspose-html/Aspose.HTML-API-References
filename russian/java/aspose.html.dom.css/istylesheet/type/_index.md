## IStyleSheet.Type property

Указывает язык таблицы стилей для этой таблицы стилей. Язык таблицы стилей задаётся как тип содержимого (например, "text/css").

```java
public String Type { get; }
```

### Property Value

Атрибут type должен возвращать тип.
