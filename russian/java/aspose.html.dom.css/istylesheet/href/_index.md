## IStyleSheet.Href property

Свойство href интерфейса [`StyleSheet`](../) возвращает расположение таблицы стилей.

```java
public String Href { get; }
```

### Property Value

uri — это строка, содержащая URI таблицы стилей.

## Примечания

Если таблица стилей является связанной, значение её атрибута — это её расположение. Для встроенных таблиц стилей значение этого атрибута равно NULL.

Это свойство только для чтения в Firefox, Opera, Google Chrome и Safari, и доступно для чтения/записи в Internet Explorer.
