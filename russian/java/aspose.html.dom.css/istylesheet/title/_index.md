## IStyleSheet.Title property

Свойство title интерфейса [`StyleSheet`](../) возвращает рекомендованное название текущей таблицы стилей.

Название часто указывается в [`ownerNode`](../ownernode/).

```java
public String Title { get; }
```

### Property Value

Атрибут parentStyleSheet должен возвращать родительскую [`CSS style sheet`](../../icssstylesheet/).
