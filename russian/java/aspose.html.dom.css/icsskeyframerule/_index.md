## ICSSKeyframeRule interface

Интерфейс `CSSKeyframeRule` описывает объект, представляющий набор стилей для заданного ключевого кадра. Он соответствует содержимому одного ключевого кадра правила @keyframes.

```java
public interface ICSSKeyframeRule : ICSSRule
```

| Имя | Описание |
| --- | --- |
| [getKeyText](../../com.aspose.html.dom.css/icsskeyframerule/keytext/) Свойство keyText интерфейса CSSKeyframeRule представляет селектор ключевого кадра как список процентных значений, разделённых запятыми. Ключевые слова from и to соответствуют 0% и 100% соответственно. |
