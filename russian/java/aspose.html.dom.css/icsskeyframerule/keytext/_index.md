## ICSSKeyframeRule.KeyText property

Свойство keyText интерфейса CSSKeyframeRule представляет селектор keyframe в виде списка процентных значений, разделённых запятыми. Ключевые слова from и to соответствуют 0% и 100% соответственно.

```java
public String KeyText { get; }
```

### Property Value

Возвращает селектор keyframe в виде списка процентных значений, разделённых запятыми.
