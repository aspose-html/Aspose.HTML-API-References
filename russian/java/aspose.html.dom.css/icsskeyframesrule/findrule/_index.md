## ICSSKeyframesRule.FindRule method

Метод findRule возвращает правило с ключом, совпадающим с переданным ключом. Если такого правила нет, возвращается значение null.

```java
public ICSSKeyframeRule FindRule(String key)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| ключ | String | Ключ, описывающий правило для поиска. Ключ должен быть числом от 0 до 1, иначе правило игнорируется. |

### Возвращаемое значение

Возвращает последнее объявленное [`CSSKeyframeRule`](../../icsskeyframerule/), соответствующее указанному селектору keyframe. Если подходящее правило отсутствует, метод ничего не делает.
