## ICSSKeyframesRule.DeleteRule method

Метод deleteRule удаляет [`CSSKeyframeRule`](../../icsskeyframerule/) с переданным ключом. Если правило с этим ключом не существует, метод ничего не делает.

```java
public void DeleteRule(String key)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| ключ | String | Ключ, описывающий правило для удаления. Ключ должен быть числом от 0 до 1, иначе правило игнорируется. |
