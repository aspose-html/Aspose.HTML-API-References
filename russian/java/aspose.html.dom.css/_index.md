Предоставляет интерфейсы для спецификации стилей DOM Level 2. Каскадные таблицы стилей (CSS) — язык таблиц стилей, позволяющий авторам и пользователям применять стили (например, шрифты и отступы) к структурированным документам (например, HTML‑документам и XML‑приложениям). Он поддерживает медиа‑специфические таблицы стилей, чтобы авторы могли адаптировать представление своих документов под визуальные браузеры, аудиоустройства, принтеры, брайлевские устройства, портативные устройства и т.д. Также поддерживается позиционирование контента, разметка таблиц, функции интернационализации и некоторые свойства, связанные с пользовательским интерфейсом. Отделяя стиль представления документов от их содержимого, CSS упрощает веб‑авторинг и обслуживание сайтов.
