## ICSSStyleDeclaration.GetPropertyValue method

Метод интерфейса CSSStyleDeclaration.getPropertyValue() возвращает строку, содержащую значение указанного CSS‑свойства.

```java
public String GetPropertyValue(String propertyName)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| propertyName | String | propertyName — строка, представляющая имя свойства (в виде с дефисом), которое нужно проверить. |

### Возвращаемое значение

value — строка, содержащая значение свойства. Если не задано, возвращает пустую строку.
