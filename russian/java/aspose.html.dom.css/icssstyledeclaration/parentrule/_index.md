## ICSSStyleDeclaration.ParentRule property

Свойство только для чтения CSSStyleDeclaration.parentRule возвращает CSSRule, который является родителем этого блока стилей, например [`CSSStyleRule`](../../icssstylerule/), представляющий стиль для CSS‑селектора.

```java
public ICSSRule ParentRule { get; }
```

### Property Value

CSS‑правило, которое содержит этот блок объявлений, или null, если этот [`CSSStyleDeclaration`](../) не привязан к [`CSSRule`](../../icssrule/).
