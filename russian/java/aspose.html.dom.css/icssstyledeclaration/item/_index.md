## ICSSStyleDeclaration indexer

Используется для получения свойств, явно заданных в этом блоке объявлений. Порядок получаемых с помощью этого метода свойств не обязан соответствовать порядку их установки. Этот метод можно использовать для перебора всех свойств в этом блоке объявлений.

```java
public String this[int index] { get; }
```

### Возвращаемое значение

propertyName — это String, который является именем CSS‑свойства по указанному индексу.

### Property Value

index — это индекс узла, который нужно получить. Индекс начинается с нуля.
