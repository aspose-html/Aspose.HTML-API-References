## ICSSStyleDeclaration.Length property

Только для чтения свойство возвращает целое число свойств, явно заданных в этом блоке CSS‑объявления. Диапазон допустимых индексов — от 0 до length‑1 включительно.

```java
public int Length { get; }
```

### Property Value

Целое число, предоставляющее количество стилей, явно заданных у родителя экземпляра.
