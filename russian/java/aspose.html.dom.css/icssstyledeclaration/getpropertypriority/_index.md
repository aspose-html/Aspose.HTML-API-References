## ICSSStyleDeclaration.GetPropertyPriority method

Используется для получения приоритета CSS‑свойства (например, квалификатора "important"), если свойство было явно задано в этом блоке объявлений.

```java
public String GetPropertyPriority(String propertyName)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| propertyName | String | property — DOMString, представляющий имя свойства, которое необходимо проверить. |

### Возвращаемое значение

priority — DOMString, представляющий приоритет (например, "important"), если он существует. Если приоритета нет, возвращает пустую строку.
