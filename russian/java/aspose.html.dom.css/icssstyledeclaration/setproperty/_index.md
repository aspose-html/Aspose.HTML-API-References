## SetProperty(String, String) {#setproperty}

Метод интерфейса CSSStyleDeclaration.setProperty() используется для установки значения свойства с приоритетом по умолчанию в этом блоке объявлений. Приоритет по умолчанию не является "important", т.д. String.Empty.

```java
public void SetProperty(String propertyName, String value)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| propertyName | String | `String` представляющий имя CSS‑свойства (в виде дефисного написания), которое нужно изменить. |
| значение | String | `String`, содержащий новое значение свойства. Если не указано, считается пустой строкой. |

## SetProperty(String, String, String) {#setproperty_1}

Метод интерфейса CSSStyleDeclaration.setProperty() используется для установки значения свойства с приоритетом по умолчанию в этом блоке объявлений. Приоритет по умолчанию не является "important", т.д. String.Empty.

```java
public void SetProperty(String propertyName, String value, String priority)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| propertyName | String | `String` представляющий имя CSS‑свойства (в виде дефисного написания), которое нужно изменить. |
| значение | String | `String`, содержащий новое значение свойства. Если не указано, считается пустой строкой. |
| priority | String | `String`, позволяющий установить CSS‑приоритет "important". Если не указано, считается пустой строкой. Допустимы следующие значения: строковое значение "important", ключевое слово undefined или пустая строка "". |
