## ICSSStyleSheet.OwnerRule property

Только для чтения свойство CSSStyleSheet ownerRule возвращает [`CSSImportRule`](../../icssimportrule/), соответствующее правилу @import, которое импортировало таблицу стилей в документ. Если таблица стилей не была импортирована в документ с помощью @import, возвращаемое значение равно null.

```java
public ICSSRule OwnerRule { get; }
```

### Property Value

CSSImportRule, соответствующее правилу @import, которое импортировало таблицу стилей в документ. Если таблица стилей не была импортирована в документ с помощью @import, возвращаемое значение равно null.
