## ICSSStyleSheet.CSSRules property

Свойство только для чтения cssRules объекта CSSStyleSheet возвращает живой [`CSSRuleList`](../../icssrulelist/), который предоставляет актуальный в реальном времени список всех CSS‑правил, составляющих таблицу стилей. Каждый элемент списка — это [`CSSRule`](../../icssrule/), определяющий отдельное правило.

```java
public ICSSRuleList CSSRules { get; }
```

### Property Value

Живой обновляемый [`CSSRuleList`](../../icssrulelist/), содержащий все CSS‑правила, составляющие таблицу стилей. Каждый элемент списка правил — объект [`CSSRule`](../../icssrule/), описывающий одно правило, входящее в таблицу стилей.
