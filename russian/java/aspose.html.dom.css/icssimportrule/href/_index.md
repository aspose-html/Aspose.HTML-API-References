## ICSSImportRule.Href property

Только для чтения свойство href интерфейса CSSImportRule возвращает URL, указанный правилом @import.

Разрешённый URL будет атрибутом href связанной таблицы стилей.

```java
public String Href { get; }
```

### Property Value

Возвращает URL связанной таблицы стилей, указанной правилом @import.
