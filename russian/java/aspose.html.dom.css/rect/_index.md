## Rect class

Интерфейс Rect используется для представления любого значения rect. Этот интерфейс отражает значения в базовом свойстве style. Поэтому изменения, внесённые в объекты [`CSSPrimitiveValue`](../cssprimitivevalue/), изменяют свойство style.

```java
public class Rect : DOMObject
```
