## IElementCSSInlineStyle.Style property

Атрибут style должен возвращать объект блока CSS‑объявления, у которого флаг computed не установлен, родительское CSS‑правило равно null и владелец узла является контекстным объектом.

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

Связанный блок CSS‑объявления для узла или null, если связанный блок CSS‑объявления отсутствует.
