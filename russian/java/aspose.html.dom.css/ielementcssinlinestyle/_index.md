## IElementCSSInlineStyle interface

Инлайн‑информация о стиле, прикреплённая к элементам, доступна через атрибут style. Это представляет содержимое атрибута STYLE для HTML‑элементов (или элементов в других схемах или DTD, которые используют атрибут STYLE аналогичным образом). Ожидается, что экземпляр интерфейса ElementCSSInlineStyle можно получить, используя специфичные для привязки методы приведения типа к экземпляру интерфейса Element, когда элемент поддерживает инлайн‑информацию о стиле CSS.

Смотрите также [CSS Object Model (CSSOM) # IElementCSSInlineStyle](https://www.w3.org/TR/cssom-1/#the-elementcssinlinestyle-mixin)
