## RGBColor.Alpha property

Получает значение альфа‑компонента этой структуры Color.

```java
public CSSPrimitiveValue Alpha { get; }
```

### Property Value

Значение альфа‑компонента этой Color.

## Примечания

Цвет каждого пикселя представляется 32‑битным числом: по 8 бит на альфа‑канал, красный, зелёный и синий (ARGB). Альфа‑компонент определяет прозрачность цвета: 0 — полностью прозрачный, 255 — полностью непрозрачный. Аналогично, значение A = 255 представляет непрозрачный цвет. Значения A от 1 до 254 представляют полупрозрачный цвет. Цвет становится более непрозрачным по мере приближения A к 255.
