## RGBColor.Red property

Возвращает значение красного компонента этой структуры Color.

```java
public CSSPrimitiveValue Red { get; }
```

### Property Value

Значение красного компонента этого цвета.

## Примечания

Цвет каждого пикселя представлен 32‑битным числом: по 8 бит на альфа‑канал, красный, зелёный и синий (ARGB). Альфа‑канал определяет прозрачность цвета: 0 — полностью прозрачный, 255 — полностью непрозрачный. Аналогично, значение A = 255 представляет непрозрачный цвет. Значения A от 1 до 254 обозначают полупрозрачный цвет. Чем ближе значение A к 255, тем более непрозрачным становится цвет.
