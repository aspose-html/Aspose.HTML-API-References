## IStyleSheetList.Length property

Атрибут length должен возвращать количество CSS‑таблиц стилей, представленных в коллекции. Диапазон допустимых индексов дочерних таблиц стилей — от 0 до length‑1 включительно.

```java
public int Length { get; }
```

### Property Value

Целое число, указывающее количество элементов в коллекции.
