## ICSSStyleRule.Style property

Свойство стиля только для чтения представляет собой интерфейс [`CSSStyleDeclaration`](../../icssstyledeclaration/) для блока объявлений [`CSSStyleRule`](../).

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

Атрибут style должен возвращать объект CSSStyleDeclaration для правила стиля, со следующими свойствами:

computed flag - Unset.declarations - Объявленные декларации в правиле, в указанном порядке. parent CSS rule - Объект контекста. owner node - Null.
