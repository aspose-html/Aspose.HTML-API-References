## ICSSStyleRule interface

Интерфейс CSSStyleRule представляет отдельное правило CSS‑стиля. Атрибут selectorText при чтении должен возвращать результат сериализации связанной группы селекторов.

```java
public interface ICSSStyleRule : ICSSRule
```
