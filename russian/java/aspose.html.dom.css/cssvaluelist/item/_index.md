## CSSValueList indexer

Метод item() интерфейса CSSValueList используется для получения CSSValue по порядковому индексу.

Порядок в этой коллекции соответствует порядку значений свойства CSS‑стиля. Если индекс больше или равен количеству значений в списке, этот метод возвращает null.

```java
public CSSValue this[int index] { get; }
```

### Возвращаемое значение

Объект CSSValue в позиции индекса в CSSValueList, или null, если индекс недействителен.

### Property Value

Беззнаковое целое типа unsigned long, представляющее индекс значения CSS в коллекции.
