## CSSValueList.CSSText property

Свойство cssText интерфейса [`CSSValue`](../../cssvalue/) представляет текущее вычисленное значение CSS‑свойства.

Примечание: Это свойство было частью попытки создать типизированную объектную модель CSS. Эта попытка была отменена, и большинство браузеров её не реализуют.

```java
public String CSSText { get; set; }
```

### Property Value

DOMString, представляющая текущее значение свойства CSS.
