## CSSValueList.Length property

Только для чтения свойство length интерфейса CSSValueList представляет количество CSSValue в списке. Диапазон допустимых значений индексов — от 0 до length‑1 включительно.

```java
public int Length { get; }
```

### Property Value

Беззнаковое целое, представляющее количество CSSValue в текущем экземпляре.
