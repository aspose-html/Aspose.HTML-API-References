## IMediaList.AppendMedium method

Добавляет носитель newMedium в конец списка. Если newMedium уже используется, он сначала удаляется.

```java
public void AppendMedium(String newMedium)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| newMedium | String | Новая среда для добавления. |

### Исключения

| исключение | условие |
| --- | --- |
| DOMException | INVALID_CHARACTER_ERR: Если среда содержит символы, недопустимые в базовом языке стилей. NO_MODIFICATION_ALLOWED_ERR: Возникает, если этот список только для чтения. |
