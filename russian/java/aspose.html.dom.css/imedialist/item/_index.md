## IMediaList indexer

Метод item(index) должен возвращать сериализацию медиа‑запроса из коллекции медиа‑запросов по индексу, или null, если индекс больше или равен количеству медиа‑запросов в коллекции.

```java
public String this[int index] { get; }
```

### Возвращаемое значение

Возвращает строку, представляющую медиа‑запрос в виде текста, по индексу медиа‑запроса внутри [`MediaList`](../).

### Property Value

Целое число, представляющее индекс элемента в коллекции, который должен быть возвращён.
