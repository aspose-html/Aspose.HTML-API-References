## IMediaList indexer

Метод item(index) должен возвращать сериализацию медиазапроса из коллекции медиазапросов по указанному индексу, или null, если индекс больше или равен количеству медиазапросов в коллекции.

```java
public String this[int index] { get; }
```

### Возвращаемое значение

Возвращает строку, представляющую медиазапрос в виде текста, по индексу медиазапроса внутри [`MediaList`](../).

### Property Value

Целое число, являющееся индексом элемента в коллекции, который необходимо вернуть.
