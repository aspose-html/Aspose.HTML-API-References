## IMediaList.Length property

Атрибут length должен возвращать количество медиазапросов в коллекции медиазапросов. Диапазон допустимых медиазапросов от 0 до length-1 включительно.

```java
public long Length { get; }
```

### Property Value

Возвращает количество медиазапросов в [`MediaList`](../).
