## IMediaList.MediaText property

Stringifier, который возвращает DOMString, представляющий MediaList в виде текста, и также позволяет установить новый MediaList.

```java
public String MediaText { get; }
```

### Property Value

Разбираемое текстовое представление списка медиа. Это список медиа, разделённый запятыми.

### Исключения

| исключение | условие |
| --- | --- |
| DOMException | SYNTAX_ERR: Возникает, если указанное строковое значение содержит синтаксическую ошибку и не может быть разобрано. NO_MODIFICATION_ALLOWED_ERR: Возникает, если этот список медиа только для чтения. |
