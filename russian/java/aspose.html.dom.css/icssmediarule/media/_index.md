## ICSSMediaRule.Media property

Только для чтения свойство media интерфейса [`CSSMediaRule`](../) MediaList представляет целевую среду назначения для информации о стиле.

```java
public IMediaList Media { get; }
```

### Property Value

Атрибут media должен возвращать объект MediaList для списка медиазапросов, указанных с помощью директивы @media.
