## ICSSMediaRule.InsertRule method

Метод insertRule() интерфейса CSSGroupingRule добавляет новое правило CSS в список правил CSS.

```java
public long InsertRule(String rule, long index)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| правило | String | Правило media в виде CSSOMString. |
| index | Int64 | Необязательный индекс, по которому вставлять правило; по умолчанию 0. |

### Возвращаемое значение

Метод insertRule(rule, index) возвращает результат вызова вставки правила CSS в дочерние правила CSS по индексу.
