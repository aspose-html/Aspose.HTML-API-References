## ICSS2Properties.ListStyleImage property

Это свойство задает изображение, которое будет использоваться в качестве маркера элемента списка. Когда изображение доступно, оно заменит набор маркеров маркером ['list-style-type'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-list-style-type).

```java
public String ListStyleImage { get; set; }
```

### Возвращаемое значение

свойство list-style-image
