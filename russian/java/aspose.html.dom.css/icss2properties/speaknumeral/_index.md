## ICSS2Properties.SpeakNumeral property

Это свойство управляет тем, как произносятся цифры. Значения имеют следующие значения:

digits — произносить цифру как отдельные цифры. Таким образом, "237" произносится как "Два Три Семь". continuous — произносить цифру как целое число. Таким образом, "237" произносится как "Двести тридцать семь". Словесные представления зависят от языка.

```java
public String SpeakNumeral { get; set; }
```

### Возвращаемое значение

свойство speak-numeral
