## ICSS2Properties.FontVariant property

В шрифте small-caps глифы строчных букв выглядят похожими на заглавные, но в меньшем размере и с немного другими пропорциями. Свойство 'font-variant' запрашивает такой шрифт для двуязычных (имеющих два регистра, как в латинском письме). Это свойство не оказывает видимого эффекта для скриптов, имеющих один регистр (unicameral), как большинство систем письма мира.

```java
public String FontVariant { get; set; }
```

### Возвращаемое значение

свойство font-variant
