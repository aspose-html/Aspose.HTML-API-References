## ICSS2Properties.TableLayout property

Свойство ['table-layout'](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#propdef-table-layout) управляет алгоритмом, используемым для размещения ячеек, строк и столбцов таблицы. Значения имеют следующее значение:

fixed - Использовать фиксированный алгоритм разметки таблицыauto - Использовать любой автоматический алгоритм разметки таблицы

```java
public String TableLayout { get; set; }
```

свойство table-layout
