## ICSS2Properties.TextIndent property

Это свойство задает отступ первой строки текста в блоке. Точнее, оно задает отступ первой коробки, которая заполняет первую [line box](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#line-box) блока. Эта коробка отступает относительно левого (или правого, для right-to-left layout) края строковой коробки. Пользовательские агенты должны отображать этот отступ как пустое пространство.

Значения имеют следующее значение:

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - Отступ имеет фиксированную длину.'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - Отступ задаётся в процентах от ширины содержащего блока.

```java
public String TextIndent { get; set; }
```

### Возвращаемое значение

свойство text-indent
