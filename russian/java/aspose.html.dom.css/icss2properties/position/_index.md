## ICSS2Properties.Position property

Значения этого свойства имеют следующее значение:

static - Бокс является обычным боксом, размещённым согласно [normal flow](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#normal-flow). Свойства ['left'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-left) и ['top'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-top) не применяются.
