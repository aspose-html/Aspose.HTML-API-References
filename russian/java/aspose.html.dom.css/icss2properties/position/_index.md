## ICSS2Properties.Position property

Значения этого свойства имеют следующее значение:

static — Ящик является обычным ящиком, размещённым согласно [normal flow](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#normal-flow). Свойства ['left'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-left) и ['top'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-top) не применяются.

```java
public String Position { get; set; }
```

### Возвращаемое значение

relative — Позиция ящика вычисляется согласно [normal flow](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#normal-flow) (это называется позиция в нормальном потоке). Затем ящик смещается [relative](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#relative-positioning) от своей обычной позиции. Когда ящик B позиционируется относительно, позиция следующего ящика вычисляется так, как будто B не был смещён.
