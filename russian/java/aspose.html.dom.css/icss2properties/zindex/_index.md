## ICSS2Properties.ZIndex property

Для позиционированного блока свойство ['z-index'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-z-index) указывает:

Уровень стека блока в текущем контексте наложения. Устанавливает ли блок локальный контекст наложения.

```java
public String ZIndex { get; set; }
```

### Возвращаемое значение

свойство z-index
