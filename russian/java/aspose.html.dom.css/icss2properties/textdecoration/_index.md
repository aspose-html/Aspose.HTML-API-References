## ICSS2Properties.TextDecoration property

Это свойство описывает декорации, добавляемые к тексту элемента. Если свойство указано для [блочного](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#block-level) элемента, оно влияет на всех вложенных строчных потомков элемента. Если оно указано для (или влияет на) [строчного](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) элемента, оно влияет на все коробки, генерируемые элементом. Если у элемента нет содержимого или текстового содержимого (например, элемент IMG в HTML), пользовательские агенты должны [игнорировать](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#ignore) это свойство.

Значения имеют следующее значение:

none — Не создает текстовых декораций. underline — Каждая строка текста подчёркнута. overline — Каждая строка текста имеет линию над ней. line-through — Каждая строка текста имеет линию, проходящую посередине. blink — Текст мигает (чередуется между видимым и невидимым).

```java
public String TextDecoration { get; set; }
```

### Возвращаемое значение

свойство text-decoration
