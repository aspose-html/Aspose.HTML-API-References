## ICSS2Properties.WordSpacing property

Это свойство определяет поведение интервалов между словами. Значения имеют следующее значение:

normal - Обычный межсловный интервал, определяемый текущим шрифтом и/или пользовательским агентом. '[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - Это значение указывает межсловный интервал в дополнение к стандартному пространству между словами. Значения могут быть отрицательными, но могут существовать ограничения, зависящие от реализации.

```java
public String WordSpacing { get; set; }
```

свойство word-spacing
