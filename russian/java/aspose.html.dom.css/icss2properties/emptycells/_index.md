## ICSS2Properties.EmptyCells property

В модели раздельных границ это свойство управляет отрисовкой границ вокруг ячеек, не имеющих видимого содержимого. Пустые ячейки и ячейки со свойством 'visibility', установленным в 'hidden', считаются не имеющими видимого содержимого.

```java
public String EmptyCells { get; set; }
```

### Возвращаемое значение

свойство empty-cells
