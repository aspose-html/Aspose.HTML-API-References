## ICSS2Properties.PitchRange property

Указывает вариацию среднего тона. Воспринимаемый тон человеческого голоса определяется основной частотой и обычно составляет 120 Гц для мужского голоса и 210 Гц для женского голоса. Человеческие языки произносятся с различной интонацией и высотой тона; эти вариации передают дополнительный смысл и акцент. Таким образом, очень выразительный голос, т.е. сильно интонированный, демонстрирует широкий диапазон тона. Это свойство указывает диапазон, в котором происходят эти вариации, т.е. насколько основная частота может отклоняться от среднего тона.

```java
public String PitchRange { get; set; }
```

### Возвращаемое значение

свойство pitch-range
