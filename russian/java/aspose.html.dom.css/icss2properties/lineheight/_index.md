## ICSS2Properties.LineHeight property

Если свойство установлено для [block-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#block-level) элемента, содержимое которого состоит из [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) элементов, оно задаёт минимальную высоту каждого генерируемого встроенного блока.

Если свойство установлено для [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) элемента, оно задаёт точную высоту каждого блока, генерируемого элементом. (За исключением встроенных [replaced](https://www.w3.org/TR/1998/REC-CSS2-19980512/conform.html#replaced-element) элементов, где высота блока задаётся свойством ['height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-height).)

```java
public String LineHeight { get; set; }
```

### Возвращаемое значение

свойство line-height
