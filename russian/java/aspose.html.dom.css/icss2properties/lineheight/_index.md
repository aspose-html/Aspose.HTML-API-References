## ICSS2Properties.LineHeight property

Если свойство установлено на элементе [block-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#block-level), содержимое которого состоит из элементов [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level), оно задаёт минимальную высоту каждого сгенерированного inline-бокса.

Если свойство установлено на элементе [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level), оно задаёт точную высоту каждого бокса, генерируемого элементом. (За исключением встроенных элементов [replaced](https://www.w3.org/TR/1998/REC-CSS2-19980512/conform.html#replaced-element), где высота бокса задаётся свойством ['height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-height).)

```java
public String LineHeight { get; set; }
```

### Возвращаемое значение

свойство line-height
