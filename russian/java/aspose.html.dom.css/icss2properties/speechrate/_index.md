## ICSS2Properties.SpeechRate property

Это свойство указывает скорость речи. Обратите внимание, что допускаются как абсолютные, так и относительные ключевые слова (сравните с ['font-size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html#propdef-font-size)). Значения имеют следующее значение:

'[number](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-number)' — указывает скорость речи в словах в минуту, величину, которая несколько варьируется в зависимости от языка, но тем не менее широко поддерживается синтезаторами речи.

x-slow — то же, что 80 слов в минуту.

slow — то же, что 120 слов в минуту.

medium - То же, что 180 - 200 слов в минуту.

fast - То же, что 300 слов в минуту.

x-fast - То же, что 500 слов в минуту.

faster - Добавляет 40 слов в минуту к текущей скорости речи.

slower - Вычитает 40 слов в минуту из текущей скорости речи.

```java
public String SpeechRate { get; set; }
```

### Возвращаемое значение

свойство speech-rate
