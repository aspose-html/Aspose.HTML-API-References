## ICSS2Properties.BackgroundRepeat property

Если указано фоновое изображение, это свойство определяет, будет ли изображение повторяться (тайлиться) и как. Всё тайлирование покрывает области содержимого и отступов коробки. Значения имеют следующее значение:

repeat - Изображение повторяется как по горизонтали, так и по вертикали. repeat-x - Изображение повторяется только по горизонтали. repeat-y - Изображение повторяется только по вертикали. no-repeat - Изображение не повторяется: рисуется только один экземпляр изображения.

```java
public String BackgroundRepeat { get; set; }
```

### Возвращаемое значение

свойство background-repeat

### Property Value

Значение background-repeat из списка, как определено выше.
