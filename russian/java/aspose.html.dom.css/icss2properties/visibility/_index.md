## ICSS2Properties.Visibility property

Свойство ['visibility'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visufx.html#propdef-visibility) определяет, отображаются ли блоки, созданные элементом. Невидимые блоки всё равно влияют на раскладку (установите свойство ['display'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-display) в 'none', чтобы полностью подавить создание блоков). Значения имеют следующее значение:

visible - Сгенерированный блок видим. hidden - Сгенерированный блок невидим (полностью прозрачный), но всё равно влияет на раскладку. collapse - См. раздел о [dynamic row and column effects](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#dynamic-effects) в таблицах. При использовании на элементах, отличных от строк или столбцов, 'collapse' имеет то же значение, что и 'hidden'.

```java
public String Visibility { get; set; }
```

### Возвращаемое значение

свойство visibility
