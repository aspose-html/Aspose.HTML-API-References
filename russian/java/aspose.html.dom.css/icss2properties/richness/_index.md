## ICSS2Properties.Richness property

Указывает насыщенность или яркость голоса. Насыщенный голос будет «заполнять» большой зал, а гладкий — нет. (Термин «гладкий» относится к тому, как выглядит форма волны при рисовании.)

```java
public String Richness { get; set; }
```

### Возвращаемое значение

свойство richness
