## ICSS2Properties.Pause property

Свойство ['pause'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause) является сокращением для установки ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) и ['pause-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-after). Если указаны два значения, первое значение — ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before), а второе — ['pause-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-after). Если указано только одно значение, оно применяется к обоим свойствам.

```java
public String Pause { get; set; }
```

### Возвращаемое значение

свойство pause
