## ICSS2Properties.TextAlign property

Это свойство описывает, как выравнивается встроенное содержимое блока. Значения имеют следующее значение:

left, right, center, and justify - левый, правый, центрированный и двойное выравнивание текста соответственно.'[String](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-String)' - Указывает строку, по которой будут выравниваться ячейки в столбце таблицы (см. раздел о [horizontal alignment in a column](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#column-alignment) для деталей и примера). Это значение применяется только к ячейкам [table](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html). Если установить его для других элементов, оно будет рассматриваться как 'left' или 'right' в зависимости от того, является ли ['direction'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-direction) 'ltr' или 'rtl' соответственно.

```java
public String TextAlign { get; set; }
```
