## ICSS2Properties.SpeakPunctuation property

Это свойство определяет, как произносится пунктуация. Значения имеют следующее значение:

code - Пунктуация, такая как точки с запятой, фигурные скобки и т.д., должна произноситься буквально.none - Пунктуация не произносится, а отображается естественно в виде различных пауз.

```java
public String SpeakPunctuation { get; set; }
```

### Возвращаемое значение

свойство speak-punctuation
