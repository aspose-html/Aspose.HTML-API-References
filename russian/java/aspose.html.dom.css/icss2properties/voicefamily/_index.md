## ICSS2Properties.VoiceFamily property

Значение представляет собой приоритетный список названий голосовых семейств, разделённых запятыми (сравните с ['font-family'](https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html#propdef-font-family)). Значения имеют следующие значения:

'generic-voice' - Значения представляют голосовые семьи. Возможные значения: 'male', 'female' и 'child'.'specific-voice' - Значения представляют конкретные экземпляры (например, comedian, trinoids, carlos, lani).

```java
public String VoiceFamily { get; set; }
```

### Возвращаемое значение

свойство voice-family
