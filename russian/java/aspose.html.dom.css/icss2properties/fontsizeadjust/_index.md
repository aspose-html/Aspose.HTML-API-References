## ICSS2Properties.FontSizeAdjust property

В двубуквенных шрифтах субъективный визуальный размер и читаемость шрифта менее зависят от их значения 'font-size', чем от значения их 'x-height', или, что более полезно, от отношения этих двух величин, называемого коэффициентом соотношения (font size divided by x-height). Чем выше коэффициент, тем более вероятно, что шрифт небольших размеров будет читаемым. Обратно, шрифты с более низким коэффициентом станут нечитаемыми быстрее при уменьшении ниже определённого порогового размера, чем шрифты с более высоким коэффициентом. Прямой подбор шрифтов, основанный только на размере шрифта, может привести к нечитаемым символам.

```java
public String FontSizeAdjust { get; set; }
```

### Возвращаемое значение

свойство font-size-adjust
