## ICSS2Properties.CounterIncrement property

Свойство ['counter-increment'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-counter-increment) принимает одно или несколько имён счётчиков (идентификаторов), каждое из которых может быть дополнено целым числом. Целое число указывает, на сколько увеличивается счётчик при каждом появлении элемента. Значение по умолчанию — 1. Допускаются нулевые и отрицательные целые.

```java
public String CounterIncrement { get; set; }
```

### Возвращаемое значение

свойство counter-increment
