## ICSS2Properties.Stress property

Указывает высоту «локальных пиков» в интонационном контуре голоса. Например, английский — язык со стрессом, и разные части предложения получают первичный, вторичный или третичный стресс. Значение ['stress'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-stress) контролирует степень интонации, возникающей из этих маркеров стресса. Это свойство является дополнением к свойству ['pitch-range'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pitch-range) и предоставляется для того, чтобы разработчики могли использовать более продвинутые аудиовизуальные отображения.

```java
public String Stress { get; set; }
```

свойство stress
