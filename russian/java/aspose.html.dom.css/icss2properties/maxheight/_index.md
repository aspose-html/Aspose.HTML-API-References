## ICSS2Properties.MaxHeight property

Эти два свойства позволяют авторам ограничивать высоту блоков в определённом диапазоне. Значения имеют следующие значения:

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - Указывает фиксированную минимальную или максимальную вычисленную высоту.'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - Указывает процент для определения вычисленного значения. Процент рассчитывается относительно высоты сгенерированного блока [containing block](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#containing-block). Если высота содержащего блока не указана явно (т.е. зависит от высоты содержимого), процентное значение интерпретируется как 'auto'.none - (Только для ['max-height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-max-height)) Нет ограничения высоты блока.

```java
public String MaxHeight { get; set; }
```

### Возвращаемое значение

свойство max-height
