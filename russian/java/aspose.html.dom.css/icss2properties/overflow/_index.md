## ICSS2Properties.Overflow property

Это свойство указывает, будет ли содержимое блочного элемента обрезано, когда оно выходит за пределы коробки элемента (которая выступает в роли блока‑контейнера для содержимого). Значения имеют следующее значение:

visible - Это значение указывает, что содержимое не обрезается, то есть может быть отрисовано за пределами блочной коробки. hidden - Это значение указывает, что содержимое обрезается и не должно предоставляться механизм прокрутки для просмотра содержимого за пределами области обрезки; пользователи не получат доступ к обрезанному содержимому. Размер и форма области обрезки задаются свойством ['clip'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visufx.html#propdef-clip). scroll - Это значение указывает, что содержимое обрезается и что если пользовательский агент использует механизм прокрутки, видимый на экране (например, полоса прокрутки или панель), этот механизм должен отображаться для блока независимо от того, обрезано ли какое‑либо его содержимое. Это предотвращает проблемы с появлением и исчезновением полос прокрутки в динамической среде. Когда это значение указано и целевая среда — «print» или «projection», переполняющееся содержимое должно быть напечатано. auto - Поведение значения «auto» зависит от пользовательского агента, но должно приводить к предоставлению механизма прокрутки для переполняющихся блоков.

```java
public String Overflow { get; set; }
```
