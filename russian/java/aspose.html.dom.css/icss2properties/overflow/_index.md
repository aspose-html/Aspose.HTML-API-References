## ICSS2Properties.Overflow property

Это свойство указывает, обрезается ли содержимое блочного элемента, когда оно выходит за пределы коробки элемента (которая выступает в качестве содержащего блока для содержимого). Значения имеют следующее значение:

visible - Это значение указывает, что содержимое не обрезается, т.е. может отображаться за пределами блочной коробки. hidden - Это значение указывает, что содержимое обрезается и не должно предоставляться механизм прокрутки для просмотра содержимого за пределами области обрезки; пользователи не будут иметь доступа к обрезанному содержимому. Размер и форма области обрезки задаются свойством ['clip'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visufx.html#propdef-clip). scroll - Это значение указывает, что содержимое обрезается и если пользовательский агент использует механизм прокрутки, видимый на экране (например, полоса прокрутки или панель), этот механизм должен отображаться для коробки независимо от того, обрезано ли её содержимое. Это устраняет проблемы с появлением и исчезновением полос прокрутки в динамической среде. Когда это значение указано и целевая среда — 'print' или 'projection', переполняющее содержимое должно быть напечатано. auto - Поведение значения 'auto' зависит от пользовательского агента, но должно вызывать предоставление механизма прокрутки для переполняющих коробок.

```java
public String Overflow { get; set; }
```
