## ICSS2Properties.Border property

Свойство 'border' является сокращённым свойством для установки одинаковой ширины, цвета и стиля для всех четырёх границ блока. В отличие от сокращённых свойств 'margin' и 'padding', свойство 'border' не может задавать разные значения для каждой границы. Для этого необходимо использовать одно или несколько других свойств границы.

```java
public String Border { get; set; }
```

### Возвращаемое значение

свойство border
