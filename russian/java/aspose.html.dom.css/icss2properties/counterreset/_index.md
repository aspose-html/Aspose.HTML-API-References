## ICSS2Properties.CounterReset property

Свойство ['counter-reset'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-counter-reset) также содержит список из одного или более имён счётчиков, каждое из которых может быть дополнено целым числом. Целое число задаёт значение, которое будет присвоено счётчику при каждом появлении элемента. Значение по умолчанию — 0.

```java
public String CounterReset { get; set; }
```

### Возвращаемое значение

свойство counter-reset
