## ICSS2Properties.BackgroundImage property

Это свойство задаёт фонового изображения элемента. При установке фонового изображения авторы также должны указывать фоновой цвет, который будет использоваться, когда изображение недоступно. Когда изображение доступно, оно отрисовывается поверх фонового цвета. (Таким образом, цвет виден в прозрачных частях изображения).

```java
public String BackgroundImage { get; set; }
```

### Возвращаемое значение

свойство background-image

### Property Value

Значения для этого свойства могут быть либо , чтобы указать изображение, либо 'none', когда изображение не используется.
