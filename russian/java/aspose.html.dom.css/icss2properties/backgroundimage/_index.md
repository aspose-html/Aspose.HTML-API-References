## ICSS2Properties.BackgroundImage property

Это свойство задает фоновое изображение элемента. При установке фонового изображения авторы также должны указать фоновый цвет, который будет использоваться, когда изображение недоступно. Когда изображение доступно, оно отображается поверх фонового цвета. (Таким образом, цвет виден в прозрачных частях изображения).

```java
public String BackgroundImage { get; set; }
```

### Возвращаемое значение

background-image свойство

### Property Value

Значения для этого свойства либо , чтобы указать изображение, либо 'none', когда изображение не используется.
