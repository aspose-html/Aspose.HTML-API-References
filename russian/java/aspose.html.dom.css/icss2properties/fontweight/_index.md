## ICSS2Properties.FontWeight property

Свойство 'font-weight' определяет толщину шрифта. Значения имеют следующее значение:

100 до 900 - Эти значения образуют упорядоченную последовательность, где каждое число указывает на толщину, не менее темной, чем у предшествующего. normal - То же, что '400'. bold - То же, что '700'. bolder - Указывает следующую толщину, которая назначается шрифту более темной, чем унаследованная. Если такой толщины нет, результатом будет следующее более темное числовое значение (и шрифт останется неизменным), если только унаследованное значение не было '900', в этом случае результирующая толщина также будет '900'. lighter - Указывает следующую толщину, которая назначается шрифту более светлой, чем унаследованная. Если такой толщины нет, результатом будет следующее более светлое числовое значение (и шрифт останется неизменным), если только унаследованное значение не было '100', в этом случае результирующая толщина также будет '100'.

```java
public String FontWeight { get; set; }
```

### Возвращаемое значение

свойство font-weight
