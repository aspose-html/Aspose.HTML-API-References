## ICSS2Properties.BorderTopColor property

Свойство 'border-color' задаёт цвет четырёх границ. Значения имеют следующие значения:

color - Указывает значение цвета. transparent - Граница прозрачна (хотя может иметь ширину).

```java
public String BorderTopColor { get; set; }
```

### Возвращаемое значение

свойство border-top-color
