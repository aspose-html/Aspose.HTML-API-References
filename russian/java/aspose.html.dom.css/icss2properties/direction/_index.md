## ICSS2Properties.Direction property

Это свойство указывает базовое направление письма блоков и направление вложений и переопределений (см. ['unicode-bidi'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-unicode-bidi)) для алгоритма Unicode bidirectional. Кроме того, оно указывает направление расположения столбцов [table](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html), направление горизонтального [overflow](https://www.w3.org/TR/1998/REC-CSS2-19980512/visufx.html#overflow) и позицию неполной последней строки в блоке в случае 'text-align: justify'.

```java
public String Direction { get; set; }
```

### Возвращаемое значение

свойство direction
