## ICSS2Properties.Background property

'background' свойство является сокращённым свойством для установки отдельных свойств фона (например, 'background-color', 'background-image', 'background-repeat', 'background-attachment' и 'background-position') в одном месте таблицы стилей.

```java
public String Background { get; set; }
```

### Возвращаемое значение

background свойство

### Property Value

Получает или задаёт сокращённое свойство для установки отдельных свойств фона в одном месте таблицы стилей.
