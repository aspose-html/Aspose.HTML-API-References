## ICSS2Properties.Background property

Свойство 'background' является сокращённым свойством для задания отдельных фоновых свойств (например, 'background-color', 'background-image', 'background-repeat', 'background-attachment' и 'background-position') в одном месте таблицы стилей.

```java
public String Background { get; set; }
```

### Возвращаемое значение

свойство background

### Property Value

Получает или задаёт сокращённое свойство для задания отдельных фоновых свойств в одном месте таблицы стилей.
