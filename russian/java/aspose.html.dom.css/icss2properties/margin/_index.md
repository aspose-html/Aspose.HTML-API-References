## ICSS2Properties.Margin property

Свойство ['margin'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin) является сокращённым свойством для установки ['margin-top'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-top), ['margin-right'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-right), ['margin-bottom'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-bottom) и ['margin-left'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-left) в одном месте таблицы стилей.

Если указано только одно значение, оно применяется ко всем сторонам. Если указано два значения, верхний и нижний отступы устанавливаются в первое значение, а правый и левый — во второе. Если указано три значения, верхний устанавливается в первое значение, левый и правый — во второе, а нижний — в третье. Если указано четыре значения, они применяются соответственно к верхнему, правому, нижнему и левому.

```java
public String Margin { get; set; }
```
