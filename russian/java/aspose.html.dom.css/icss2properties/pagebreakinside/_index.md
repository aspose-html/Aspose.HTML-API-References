## ICSS2Properties.PageBreakInside property

Значения этих свойств имеют следующие значения:

auto - Не принуждать и не запрещать разрыв страницы перед (после, внутри) сгенерированного блока. always - Всегда принуждать разрыв страницы перед (после) сгенерированного блока. avoid - Избегать разрыва страницы перед (после, внутри) сгенерированного блока. left - Принудительно вставлять один или два разрыва страницы перед (после) сгенерированного блока, чтобы следующая страница была оформлена как левая. right - Принудительно вставлять один или два разрыва страницы перед (после) сгенерированного блока, чтобы следующая страница была оформлена как правая.

```java
public String PageBreakInside { get; set; }
```

свойство page-break-inside
