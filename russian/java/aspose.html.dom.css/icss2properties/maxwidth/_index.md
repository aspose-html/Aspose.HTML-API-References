## ICSS2Properties.MaxWidth property

Эти два свойства позволяют авторам ограничивать ширину блоков в определённом диапазоне. Значения имеют следующие значения:

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - Указывает фиксированную минимальную или максимальную вычисленную ширину. '[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - Указывает процент для определения вычисленного значения. Процент рассчитывается относительно ширины [containing block](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#containing-block). none - (Только для ['max-width'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-max-width)) Нет ограничения ширины блока.

```java
public String MaxWidth { get; set; }
```

### Возвращаемое значение

max-width свойство
