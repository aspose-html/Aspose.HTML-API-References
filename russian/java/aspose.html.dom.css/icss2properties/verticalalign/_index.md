## ICSS2Properties.VerticalAlign property

Это свойство влияет на вертикальное позиционирование внутри строкового блока коробок, генерируемых встроенным (inline-level) элементом. Следующие значения имеют смысл только относительно родительского встроенного элемента или родительского блочного элемента, если этот элемент генерирует [анонимные встроенные блоки](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#anonymous); они не оказывают влияния, если такой родитель не существует.

Примечание. Значения этого свойства имеют несколько иной смысл в контексте таблиц. Пожалуйста, обратитесь к разделу о [алгоритмах высоты таблиц](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#height-layout) для получения подробностей. baseline — выравнивает базовую линию коробки с базовой линией родительской коробки. Если у коробки нет базовой линии, выравнивает нижний край коробки с базовой линией родителя. middle — выравнивает вертикальную середину коробки с базовой линией родительской коробки плюс половина x‑height родителя. sub — опускает базовую линию коробки до правильного положения для нижних индексов родительской коробки. (Это значение не влияет на размер шрифта текста элемента.) super — поднимает базовую линию коробки до правильного положения для верхних индексов родительской коробки. (Это значение не влияет на размер шрифта текста элемента.) text-top — выравнивает верх коробки с верхом шрифта родительского элемента. text-bottom — выравнивает низ коробки с низом шрифта родительского элемента. '[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' — поднимает (положительное значение) или опускает (отрицательное значение) коробку на указанное расстояние (процент от значения ['line-height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-line-height)). Значение '0%' эквивалентно 'baseline'. '[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' — поднимает (положительное значение) или опускает (отрицательное значение) коробку на указанное расстояние. Значение '0cm' эквивалентно 'baseline'. top — выравнивает верх коробки с верхом строкового блока. bottom — выравнивает низ коробки с низом строкового блока.
