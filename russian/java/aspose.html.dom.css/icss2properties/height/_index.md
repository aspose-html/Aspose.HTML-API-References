## ICSS2Properties.Height property

Это свойство определяет [высоту содержимого](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#content-height) блоков, создаваемых блочными и [заменяемыми](https://www.w3.org/TR/1998/REC-CSS2-19980512/conform.html#replaced-element) элементами.

Это свойство не применяется к не заменяемым [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) элементам. Высота блоков не заменяемого встроенного элемента задаётся значением (возможно унаследованным) ['line-height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-line-height) элемента.

```java
public String Height { get; set; }
```

### Возвращаемое значение

свойство height
