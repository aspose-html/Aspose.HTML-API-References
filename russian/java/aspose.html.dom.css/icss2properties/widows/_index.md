## ICSS2Properties.Widows property

Свойство ['orphans'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-orphans) указывает минимальное количество строк абзаца, которое должно оставаться в нижней части страницы. Свойство ['widows'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-widows) указывает минимальное количество строк абзаца, которое должно оставаться в верхней части страницы. Ниже приведены примеры того, как они используются для управления разрывами страниц.

```java
public String Widows { get; set; }
```

### Возвращаемое значение

свойство widows
