## ICSS2Properties.Clear property

Это свойство указывает, какие стороны коробки(ок) элемента не могут соприкасаться с ранее плавающим блоком. (Возможно, что сам элемент имеет плавающие потомки; свойство 'clear' не оказывает влияния на них.)

Это свойство может быть указано только для блочных элементов (включая плавающие). Для компактных и run-in коробок это свойство применяется к конечной блочной коробке, к которой принадлежит компактная или run-in коробка.

Значения имеют следующее значение при применении к неплавающим блочным коробкам:

left - Верхний отступ генерируемой коробки увеличивается настолько, что верхняя граница оказывается ниже нижней внешней границы всех левоплавающих коробок, полученных из элементов, предшествующих в исходном документе. right - Верхний отступ генерируемой коробки увеличивается настолько, что верхняя граница оказывается ниже нижней внешней границы всех правоплавающих коробок, полученных из элементов, предшествующих в исходном документе. both - Генерируемая коробка перемещается ниже всех плавающих коробок более ранних элементов в исходном документе. none - Нет ограничений положения коробки относительно плавающих элементов.

```java
public String Clear { get; set; }
```

### Возвращаемое значение

clear свойство
