## ICSS2Properties.Clear property

Это свойство указывает, какие стороны коробки(ок) элемента не могут соприкасаться с ранее плавающим блоком. (Возможно, что у самого элемента есть плавающие потомки; свойство 'clear' не влияет на них.)

Это свойство может быть указано только для блочных элементов (включая плавающие). Для компактных и внедряемых блоков это свойство применяется к конечному блочному блоку, к которому принадлежит компактный или внедряемый блок.

Значения имеют следующее значение при применении к не плавающим блочным коробкам:

left - Верхний отступ генерируемого блока увеличивается настолько, что верхняя граница находится ниже нижней внешней границы всех левосторонних плавающих блоков, полученных из элементов, предшествующих в исходном документе. right - Верхний отступ генерируемого блока увеличивается настолько, что верхняя граница находится ниже нижней внешней границы всех правосторонних плавающих блоков, полученных из элементов, предшествующих в исходном документе. both - Генерируемый блок перемещается ниже всех плавающих блоков более ранних элементов в исходном документе. none - Нет ограничений положения блока относительно плавающих элементов.

```java
public String Clear { get; set; }
```

### Возвращаемое значение

свойство clear
