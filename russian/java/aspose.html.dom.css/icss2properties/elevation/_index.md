## ICSS2Properties.Elevation property

Значения этого свойства имеют следующие значения:

'angle' - Задает высоту как угол, от '-90deg' до '90deg'. '0deg' означает горизонт впереди, что приблизительно соответствует уровню слушателя. '90deg' означает прямо над головой, а '-90deg' — прямо внизу. below - То же, что '-90deg'. level - То же, что '0deg'. above - То же, что '90deg'. higher - Добавляет 10 градусов к текущей высоте. lower - Вычитает 10 градусов из текущей высоты.

```java
public String Elevation { get; set; }
```
