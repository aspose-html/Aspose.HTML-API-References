## ICSS2Properties.Orphans property

Свойство ['orphans'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-orphans) указывает минимальное количество строк абзаца, которое должно оставаться внизу страницы. Свойство ['widows'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-widows) указывает минимальное количество строк абзаца, которое должно оставаться вверху страницы. Примеры того, как они используются для управления разрывами страниц, приведены ниже.

```java
public String Orphans { get; set; }
```

### Возвращаемое значение

свойство orphans
