## ICSS2Properties.Cue property

Свойство ['cue'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue) является сокращением для установки ['cue-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-before) и ['cue-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-after). Если указаны два значения, первое значение — ['cue-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-before), а второе — ['cue-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-after). Если указано только одно значение, оно применяется к обоим свойствам.

```java
public String Cue { get; set; }
```

### Возвращаемое значение

свойство cue
