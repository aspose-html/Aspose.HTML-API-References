## ICSS2Properties.BorderRightWidth property

Это свойство является сокращением для установки 'border-top-width', 'border-right-width', 'border-bottom-width' и 'border-left-width' в одном месте таблицы стилей.

Если указано только одно значение, оно применяется ко всем сторонам. Если указано два значения, верхняя и нижняя границы устанавливаются в первое значение, а правая и левая — во второе. Если указано три значения, верхняя граница устанавливается в первое значение, левая и правая — во второе, а нижняя — в третье. Если указано четыре значения, они применяются соответственно к верхней, правой, нижней и левой границе.

```java
public String BorderRightWidth { get; set; }
```

### Возвращаемое значение

border-right-width свойство
