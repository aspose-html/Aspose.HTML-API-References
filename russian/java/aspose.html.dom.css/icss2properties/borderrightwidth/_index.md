## ICSS2Properties.BorderRightWidth property

Это свойство является сокращённым свойством для установки 'border-top-width', 'border-right-width', 'border-bottom-width' и 'border-left-width' в одном месте таблицы стилей.

Если указано только одно значение, оно применяется ко всем сторонам. Если указано два значения, верхняя и нижняя границы получают первое значение, а правая и левая — второе. Если указано три значения, верх получает первое значение, левая и правая — второе, а нижняя — третье. Если указано четыре значения, они применяются соответственно к верхней, правой, нижней и левой границе.

```java
public String BorderRightWidth { get; set; }
```

### Возвращаемое значение

свойство border-right-width
