## ICSS2Properties.WhiteSpace property

Это свойство определяет, как обрабатываются [whitespace](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#whitespace) внутри элемента. Значения имеют следующее значение:

normal - Это значение указывает пользовательским агентам сворачивать последовательности пробельных символов и разрывать строки по мере необходимости для заполнения строковых блоков. Дополнительные разрывы строк могут создаваться в результате появления "\A" в генерируемом содержимом (например, для элемента BR в HTML).pre - Это значение предотвращает сворачивание последовательностей пробельных символов пользовательскими агентами. Строки разрываются только при переходах на новую строку в исходном коде или при появлении "\A" в генерируемом содержимом.nowrap - Это значение сворачивает пробелы так же, как 'normal', но подавляет разрывы строк внутри текста, за исключением тех, которые создаются "\A" в генерируемом содержимом (например, для элемента BR в HTML).

```java
public String WhiteSpace { get; set; }
```
