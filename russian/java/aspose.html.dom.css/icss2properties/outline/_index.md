## ICSS2Properties.Outline property

Контур, созданный с помощью свойств outline, рисуется «поверх» коробки, т.е. контур всегда находится сверху и не влияет на позицию или размер коробки или любых других коробок. Поэтому отображение или скрытие контуров не вызывает перерасчёта макета.

```java
public String Outline { get; set; }
```

### Возвращаемое значение

свойство outline
