## ICSS2Properties.FontFamily property

Это свойство задает приоритетный список названий семейств шрифтов и/или общих названий семейств. Чтобы решить проблему, когда один шрифт может не содержать глифов для отображения всех символов в документе, или когда не все шрифты доступны на всех системах, это свойство позволяет авторам указывать список шрифтов одинакового стиля и размера, которые проверяются последовательно, чтобы увидеть, содержит ли шрифт глиф для определённого символа. Этот список называется набором шрифтов.

```java
public String FontFamily { get; set; }
```

### Возвращаемое значение

свойство font-family
