## ICSS2Properties.Marks property

При высококачественной печати метки часто добавляются за пределами коробки страницы. Это свойство указывает, должны ли отображаться крестовые метки, обрезные метки или оба типа сразу за краем [page box](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#page-box).

Обрезные метки указывают, где следует разрезать страницу. Крестовые метки (также известные как регистрационные метки или метки регистрации) используются для выравнивания листов.

Метки видимы только на абсолютных коробках страницы (см. свойство ['size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-size)). В относительных коробках страницы коробка будет выровнена с целью, а метки окажутся за пределами печатной области.

Размер, стиль и положение крестов зависят от пользовательского агента.

```java
public String Marks { get; set; }
```
