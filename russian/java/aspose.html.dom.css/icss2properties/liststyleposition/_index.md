## ICSS2Properties.ListStylePosition property

Это свойство указывает положение маркерного блока в основном блочном элементе. Значения имеют следующее значение:

outside - Маркерный блок находится вне основного блочного элемента. Примечание. CSS1 не указывал точное расположение маркерного блока, и по соображениям совместимости CSS2 остаётся столь же неоднозначным. Для более точного управления маркерными блоками, пожалуйста, используйте markers. inside - Маркерный блок является первым встроенным блоком в основном блочном элементе, после чего содержимое элемента продолжается.

```java
public String ListStylePosition { get; set; }
```

свойство list-style-position
