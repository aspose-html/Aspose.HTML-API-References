## ICSS2Properties.ListStylePosition property

Это свойство определяет позицию маркерного блока в основном блочном контейнере. Значения имеют следующие значения:

outside - Маркерный блок находится за пределами основного блочного контейнера. Примечание. CSS1 не указывал точное расположение маркерного блока, и по соображениям совместимости CSS2 остаётся столь же неоднозначным. Для более точного управления маркерными блоками, пожалуйста, используйте markers. inside - Маркерный блок является первым встроенным блоком в основном блочном контейнере, после чего содержимое элемента продолжается.

```java
public String ListStylePosition { get; set; }
```

свойство list-style-position
