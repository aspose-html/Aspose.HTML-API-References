## ICSS2Properties.MarkerOffset property

Это свойство указывает расстояние между ближайшими [границы краёв](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#border-edge) маркерного блока и его связанным [основным блоком](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#principal-box). Смещение может быть задано пользователем как ([длина](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)) или выбрано браузером ('auto'). Длины могут быть отрицательными, но могут существовать ограничения, зависящие от реализации.

```java
public String MarkerOffset { get; set; }
```

### Возвращаемое значение

свойство marker-offset
