## ICSS2Properties.BackgroundAttachment property

Если указано фоновое изображение, это свойство определяет, фиксировано ли оно относительно области просмотра ('fixed') или прокручивается вместе с документом ('scroll').

Даже если изображение фиксировано, оно будет видно только тогда, когда находится в фоновом или отступном (padding) участке элемента. Поэтому, если изображение не повторяется ('background-repeat: repeat'), оно может быть невидимым.

```java
public String BackgroundAttachment { get; set; }
```

### Возвращаемое значение

свойство background-attachment
