## ICSS2Properties.BorderStyle property

Свойство 'border-style' задаёт стиль четырёх границ. Оно может принимать от одного до четырёх значений, и значения задаются для разных сторон так же, как для 'border-width' выше.

```java
public String BorderStyle { get; set; }
```

### Возвращаемое значение

border-style свойство
