## ICSS2Properties.PageBreakAfter property

Значения этих свойств имеют следующее значение:

auto - Ни принуждать, ни запрещать разрыв страницы перед (после, внутри) сгенерированным блоком. always - Всегда принудительно разрывать страницу перед (после) сгенерированным блоком. avoid - Избегать разрыва страницы перед (после, внутри) сгенерированным блоком. left - Принудительно вставить один или два разрыва страницы перед (после) сгенерированным блоком, чтобы следующая страница была оформлена как левая. right - Принудительно вставить один или два разрыва страницы перед (после) сгенерированным блоком, чтобы следующая страница была оформлена как правая.

```java
public String PageBreakAfter { get; set; }
```
