## ICSS2Properties.SpeakHeader property

Это свойство определяет, произносятся ли заголовки таблицы перед каждой ячейкой, или только перед ячейкой, когда эта ячейка связана с другим заголовком, чем предыдущая ячейка. Значения имеют следующее значение:

once - Заголовок произносится один раз, перед серией ячеек.always - Заголовок произносится перед каждой соответствующей ячейкой.

```java
public String SpeakHeader { get; set; }
```

### Возвращаемое значение

свойство speak-header
