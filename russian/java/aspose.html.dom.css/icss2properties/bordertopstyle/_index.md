## ICSS2Properties.BorderTopStyle property

Свойство 'border-style' задаёт стиль четырёх границ. Оно может принимать от одного до четырёх значений, и значения задаются для разных сторон, как для 'border-width' выше.

```java
public String BorderTopStyle { get; set; }
```

### Возвращаемое значение

свойство border-top-style
