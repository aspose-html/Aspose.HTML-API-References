## ICSS2Properties.Pitch property

Указывает среднюю частоту (тон) говорящего голоса. Средний тон голоса зависит от голосовой группы. Например, средний тон стандартного мужского голоса составляет около 120 Гц, а у женского голоса — около 210 Гц.

```java
public String Pitch { get; set; }
```
