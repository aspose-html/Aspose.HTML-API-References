## ICSS2Properties.BorderSpacing property

Длины указывают расстояние, разделяющее соседние границы ячеек. Если указана одна длина, она задаёт как горизонтальное, так и вертикальное расстояние. Если указаны две, первая задаёт горизонтальное расстояние, а вторая — вертикальное. Длины не могут быть отрицательными.

```java
public String BorderSpacing { get; set; }
```

### Возвращаемое значение

Свойство border-spacing
