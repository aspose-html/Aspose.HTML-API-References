## ICSS2Properties.TextTransform property

Это свойство управляет эффектами капитализации текста элемента. Значения имеют следующие значения:

capitalize - Делает первую букву каждого слова заглавной. uppercase - Делает все символы каждого слова заглавными. lowercase - Делает все символы каждого слова строчными. none - Не применяет эффекты капитализации.

```java
public String TextTransform { get; set; }
```

### Возвращаемое значение

свойство text-transform
