## ICSS2Properties.CaptionSide property

Это свойство указывает позицию блока подписи относительно таблицы. Значения имеют следующее значение:

top - Размещает блок подписи над таблицей. bottom - Размещает блок подписи под таблицей. left - Размещает блок подписи слева от таблицы. right - Размещает блок подписи справа от таблицы.

```java
public String CaptionSide { get; set; }
```

свойство caption-side
