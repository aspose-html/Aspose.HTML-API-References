## ICSSRule.Type property

Тип правила, как определено в [CSSOM # dom-cssrule-type](https://drafts.csswg.org/cssom/#dom-cssrule-type). Ожидается, что методы приведения, специфичные для привязки, могут использоваться для приведения экземпляра интерфейса CSSRule к конкретному производному интерфейсу, подразумеваемому типом.

```java
public short Type { get; }
```

### Property Value

Неотрицательное целое число, связанное с определённым типом правила. Этот элемент инициализируется при создании правила и не может изменяться.
