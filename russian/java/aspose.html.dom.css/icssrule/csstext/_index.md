## ICSSRule.CSSText property

Свойство cssText интерфейса [`CSSRule`](../) возвращает фактический текст правила стиля [`CSSStyleSheet`](../../icssstylesheet/).

Примечание: Не путайте это свойство со свойством element-style CSSStyleDeclaration.cssText.

```java
public String CSSText { get; set; }
```

### Property Value

Возвращает сериализацию правила CSS. При установке атрибута cssText ничего не должно происходить.
