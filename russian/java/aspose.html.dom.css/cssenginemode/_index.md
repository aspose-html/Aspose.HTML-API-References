## CSSEngineMode enumeration

Указывает режим CSSEngine. Значения имеют следующее значение:

default - CSS‑парсер будет работать в соответствии с рекомендациями w3c и не поддерживает пользовательские расширения. not‑strict - Все недокументированные свойства будут разобраны и могут быть доступны через.

```java
[Flags]
public enum CSSEngineMode
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Default | `0` | CSS‑парсер будет работать в соответствии с рекомендациями w3c и не поддерживает пользовательские расширения. |
| NotStrict | `1` | CSS‑парсер будет работать в режиме без строгой проверки. Все недокументированные свойства будут разобраны и могут быть доступны через. |
