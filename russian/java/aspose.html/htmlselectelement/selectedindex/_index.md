## HTMLSelectElement.SelectedIndex property

Порядковый индекс выбранного варианта, начиная с 0. Значение -1 возвращается, если ни один элемент не выбран. Если выбрано несколько вариантов, возвращается индекс первого выбранного варианта.

```java
public int SelectedIndex { get; set; }
```
