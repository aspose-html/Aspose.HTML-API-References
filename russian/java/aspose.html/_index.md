Пакет Aspose.Html содержит классы и методы для работы с [`HTML‑документы`](aspose.html/htmldocument/), будь то простые или сложные, и в режиме реального времени. Aspose.HTML для Java позволяет разработчикам Вставлять, Удалять, Заменять узлы HTML, извлекать информацию о CSS‑стилях, Навигировать по [`HTML‑документ`](aspose.html/htmldocument/) с помощью [`NodeIterator`](aspose.html.dom.traversal/inodeiterator/), [`TreeWalker`](aspose.html.dom.traversal/itreewalker/), предоставляемых спецификациями Traversal, XPath или запросов CSS‑селекторов. Также предлагается скриптинг, позволяющий манипулировать DOM HTML через JavaScript. Помимо HTML, этот API также предоставляет возможности загрузки EPUB и MHTML. API Aspose известны своими возможностями конвертации между форматами файлов, и этот API также позволяет загружать HTML‑файлы и выводить результат в PDF, XPS и растровые форматы изображений, включая JPEG, PNG, BMP и TIFF.
