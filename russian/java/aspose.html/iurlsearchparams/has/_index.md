## IUrlSearchParams.Has method

Проверяет, существует ли в списке пара имя‑значение с именем `name`.

```java
public bool Has(String name)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| name | String | Ключ, который будет использоваться для поиска пары имя‑значение. |

### Возвращаемое значение

`True` если в списке существует пара имя‑значение, у которой имя равно `name`, и `false` в противном случае.
