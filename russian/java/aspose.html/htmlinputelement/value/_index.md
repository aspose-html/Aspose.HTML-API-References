## HTMLInputElement.Value property

Когда атрибут `type` элемента имеет значение "text", "file" или "password", это представляет текущие содержимое соответствующего элемента управления формой в интерактивном пользовательском агенте. Изменение этого атрибута меняет содержимое элемента управления, но не меняет значение HTML‑атрибута value элемента. Когда атрибут `type` элемента имеет значение "button", "hidden", "submit", "reset", "image", "checkbox" или "radio", это представляет HTML‑атрибут value элемента. См. определение атрибута value в HTML 4.01.

```java
public String Value { get; set; }
```
