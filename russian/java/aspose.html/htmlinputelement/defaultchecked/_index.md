## HTMLInputElement.DefaultChecked property

Когда `type` имеет значение "radio" или "checkbox", это представляет HTML‑атрибут checked элемента. Значение этого атрибута не меняется, если состояние соответствующего элемента управления формой в интерактивном пользовательском агенте изменяется. См. определение атрибута checked в HTML 4.01.

```java
public bool DefaultChecked { get; set; }
```
