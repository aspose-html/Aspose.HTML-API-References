## HTMLInputElement.Checked property

Когда атрибут `type` элемента имеет значение "radio" или "checkbox", это представляет текущее состояние элемента управления формой в интерактивном пользовательском агенте. Изменения этого атрибута меняют состояние элемента управления формой, но не изменяют значение HTML‑атрибута checked элемента INPUT. Во время обработки события click на элементе input с атрибутом type, имеющим значение "radio" или "checkbox", некоторые реализации могут изменить значение этого свойства до того, как событие будет распространено в документе. Если действие по умолчанию события отменяется, значение свойства может быть возвращено к исходному. Это означает, что значение этого свойства во время обработки событий click зависит от реализации.

```java
public bool Checked { get; set; }
```
