## HTMLInputElement.DefaultValue property

Когда атрибут `type` элемента имеет значение "text", "file" или "password", это представляет HTML-атрибут value элемента. Значение этого атрибута не меняется, если содержимое соответствующего элемента управления формой в интерактивном пользовательском агенте изменяется. См. определение атрибута value в HTML 4.01.

```java
public String DefaultValue { get; set; }
```
