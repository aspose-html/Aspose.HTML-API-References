## HTMLInputElement.Files property

Атрибут IDL files позволяет скриптам получать доступ к выбранным файлам элемента. При чтении, если атрибут IDL применим, он должен возвращать объект FileList, представляющий текущие выбранные файлы. Один и тот же объект должен возвращаться, пока список выбранных файлов не изменится. Если атрибут IDL не применим, он должен возвращать null. [FILEAPI]

```java
public IFileList Files { get; }
```
