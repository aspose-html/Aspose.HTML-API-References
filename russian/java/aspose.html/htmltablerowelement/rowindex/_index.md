## HTMLTableRowElement.RowIndex property

Это логический порядок, а не порядок в документе. `rowIndex` учитывает секции (`THEAD`, `TFOOT` или `TBODY`) внутри таблицы, размещая строки `THEAD` первыми в индексе, затем строки `TBODY`, затем строки `TFOOT`. @version DOM Level 2
