## HTMLTextAreaElement.Value property

Представляет текущие содержимое соответствующего элемента формы в интерактивном пользовательском агенте. Изменение этого атрибута меняет содержимое элемента формы, но не меняет содержимое самого элемента. Если весь объём данных не помещается в один `DOMString`, реализация может усечь данные.

```java
public String Value { get; set; }
```
