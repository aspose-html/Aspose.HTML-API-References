## Metered.SetMeteredKey method

Устанавливает публичный и приватный метерные ключи. Если вы приобрели метерную лицензию, при запуске приложения этот API должен быть вызван, обычно этого достаточно. Однако если постоянно не удаётся загрузить данные о потреблении и прошло более 24 часов, лицензия будет переключена в статус оценки; чтобы избежать этого, следует регулярно проверять статус лицензии, и если он находится в статусе оценки, вызвать этот API снова.

```java
public void SetMeteredKey(String publicKey, String privateKey)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| publicKey | String | публичный ключ |
| privateKey | String | приватный ключ |
