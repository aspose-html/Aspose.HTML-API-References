## Sandbox enumeration

Набор флагов песочницы — это набор из нуля или более следующих флагов, которые используются для ограничения возможностей потенциально недоверенных ресурсов.

```java
[Flags]
public enum Sandbox
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| None | `0` | Флаги не установлены, все функции песочницы приняты |
| Navigation | `1` | Этот флаг предотвращает навигацию содержимого в контексты просмотра, отличные от самого изолированного контекста просмотра (или вложенных в него контекстов), вспомогательные контексты просмотра (которые защищены флагом sandboxed auxiliary navigation browsing context, определённым далее), и контекст просмотра верхнего уровня (который защищён флагом sandboxed top-level navigation browsing context, определённым ниже). Если флаг sandboxed auxiliary navigation browsing context не установлен, то в некоторых случаях ограничения всё же позволяют открывать всплывающие окна (новые контексты просмотра верхнего уровня). Эти контексты просмотра всегда имеют один разрешённый изолированный навигатор, задаваемый при создании контекста просмотра, который позволяет создающему их контексту действительно навигировать их. (В противном случае флаг sandboxed navigation browsing context предотвратил бы их навигацию, даже если они были открыты. |
| AuxiliaryNavigation | `2` | Этот флаг предотвращает создание содержимым новых вспомогательных контекстов просмотра, например с помощью атрибута target или метода window.open(). |
| TopLevelNavigation | `4` | Этот флаг предотвращает навигацию содержимого в его контекст просмотра верхнего уровня и предотвращает закрытие этого контекста. Когда флаг sandboxed top-level navigation browsing context не установлен, содержимое может навигировать свой контекст просмотра верхнего уровня, но другие контексты просмотра всё ещё защищены флагом sandboxed navigation browsing context и, возможно, флагом sandboxed auxiliary navigation browsing context. |
| Plugins | `8` | Этот флаг предотвращает создание содержимым плагинов, будь то с помощью элемента embed, элемента object, элемента applet или через навигацию вложенного контекста просмотра, если только эти плагины не могут быть защищены. |
| Origin | `10` | Этот флаг принуждает содержимое к уникальному источнику, тем самым предотвращая доступ к другому содержимому того же источника. |
| Forms | `20` | Этот флаг блокирует отправку форм. |
| PointerLock | `40` | Этот флаг отключает API Pointer Lock. |
| Scripts | `80` | Этот флаг блокирует выполнение скриптов. |
| AutomaticFeatures | `100` | Этот флаг блокирует функции, которые срабатывают автоматически, такие как автоматическое воспроизведение видео или автоматический фокус на элементе формы. |
| Fullscreen | `200` | Этот флаг предотвращает использование содержимым метода requestFullscreen(). |
| DocumentDomain | `400` | Этот флаг предотвращает использование содержимым функции document.domain для изменения эффективного источника скрипта. |
| Images | `800` | Этот флаг отключает загрузку изображений. |
