## HTMLDocument.Referrer property

Возвращает URI [[IETF RFC 2396](http://www.ietf.org/rfc/rfc2396.txt)] страницы, которая ссылалась на эту страницу. Значение является пустой строкой, если пользователь перешёл на страницу напрямую (не через ссылку, а, например, через закладку).

```java
public String Referrer { get; }
```
