## HTMLDocument.Anchors property

Коллекция всех элементов‑якорей (`A`) в документе, у которых задан атрибут `name`. По причинам обратной совместимости возвращаемый набор якорей содержит только те, которые созданы с атрибутом `name`, а не с атрибутом `id`. Обратите внимание, что в [[XHTML 1.0](http://www.w3.org/TR/2002/REC-xhtml1-20020801)] атрибут `name` (см. раздел 4.10) не имеет семантики и присутствует только для устаревших пользовательских агентов: вместо него используется атрибут `id`. Пользователям рекомендуется использовать механизмы итерации, предоставляемые [[DOM Level 2 Traversal](http://www.w3.org/TR/2000/REC-DOM-Level-2-Traversal-Range-20001113)], вместо этого.

```java
public HTMLCollection Anchors { get; }
```
