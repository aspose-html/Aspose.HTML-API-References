## Uint8ClampedArray class

Представляет массив 8‑битных беззнаковых целых чисел, ограниченных диапазоном 0‑255; если указано значение вне диапазона [0,255], будет установлено 0 или 255.

```java
public class Uint8ClampedArray : TypedArray<byte>
```
