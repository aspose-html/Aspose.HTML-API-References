## Configuration.Security property

Получает или задает флаг sandboxing конфигурации. См. статью о [sandboxing](https://docs.aspose.com/html/net/working-with-documents/environment-configuration/#sandboxing).

```java
public Sandbox Security { get; set; }
```

### Property Value

Безопасность. Набор [`sandboxing flag`](../../sandbox/) представляет собой набор из нуля или более флагов, которые используются для ограничения возможностей потенциально ненадёжных ресурсов. Атрибут sandbox позволяет задать ряд ограничений для содержимого, загружаемого во фрейм, например, блокировать формы и скрипты.
