## ToDataURL() {#todataurl}

Возвращает URI данных, содержащий представление изображения в формате, указанном параметром type (по умолчанию PNG). Возвращаемое изображение имеет разрешение 96 dpi.

```java
public String ToDataURL()
```

### Возвращаемое значение

DOMString, содержащий запрошенный URI данных.

## ToDataURL(String, double) {#todataurl_2}

Возвращает URI данных, содержащий представление изображения в формате, указанном параметром type (по умолчанию PNG). Возвращаемое изображение имеет разрешение 96 dpi.

```java

```

| Параметр | Тип | Описание |
| --- | --- | --- |
| тип | String | Строка, указывающая формат изображения. Формат по умолчанию — image/png. |

DOMString, содержащий запрошенный URI данных.
