## HTMLCanvasElement.GetContext method

Возвращает контекст рисования на canvas, или null, если указанный ID контекста не поддерживается. Контекст рисования позволяет рисовать на canvas.

```java
public object GetContext(String contextId)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| contextId | String | Строка, содержащая идентификатор контекста, определяющего контекст рисования, связанный с холстом |

### Возвращаемое значение

Объект RenderingContext
