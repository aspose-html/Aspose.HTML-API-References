## HTMLCanvasElement.Height property

Положительное целое число, отражающее значение атрибута height элемента canvas, интерпретируемое в пикселях CSS. Если атрибут не указан или задан недопустимое значение, например отрицательное, используется значение по умолчанию 150.

```java
public ulong Height { get; set; }
```
