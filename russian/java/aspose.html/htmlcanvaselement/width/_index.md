## HTMLCanvasElement.Width property

Положительное целое число, отражающее значение атрибута width элемента canvas, интерпретируемое в пикселях CSS. Если атрибут не указан или задан недопустимое значение, например отрицательное, используется значение по умолчанию 300.

```java
public ulong Width { get; set; }
```
