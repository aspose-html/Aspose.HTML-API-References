## HTMLFormElement.Enctype property

Тип содержимого отправляемой формы, обычно "application/x-www-form-urlencoded". См. определение атрибута enctype в HTML 4.01. Обработчик события onsubmit не гарантирует вызов при вызове этого метода. Поведение неоднозначно по историческим причинам, и авторам не следует полагаться на конкретное поведение.

```java
public String Enctype { get; set; }
```
