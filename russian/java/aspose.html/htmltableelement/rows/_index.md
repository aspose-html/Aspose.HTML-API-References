## HTMLTableElement.Rows property

Возвращает `TFOOT` таблицы или `null`, если он отсутствует.

Возвращает коллекцию всех строк таблицы, включая все в `THEAD`, `TFOOT`, все элементы `TBODY`.

```java
public HTMLCollection Rows { get; }
```

| исключение | условие |
| --- | --- |
| [dOMException](../../../com.aspose.html.dom/domexception/) | HIERARCHY_REQUEST_ERR: если элемент не является `TFOOT`. @version DOM Level 2 |
