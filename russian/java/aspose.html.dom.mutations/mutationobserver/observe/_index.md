## Observe(Node) {#observe}

Инструктирует пользовательский агент наблюдать за указанной целью (узлом) и сообщать о любых мутациях в соответствии с критериями, заданными параметром options (объект). Параметр options позволяет задавать параметры наблюдения за мутациями через свойства объекта.

```java
public void Observe(Node target)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| цель | Node | Целевой объект для наблюдения. |
