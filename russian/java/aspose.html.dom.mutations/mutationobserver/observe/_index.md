## Observe(Node) {#observe}

Инструктирует пользовательский агент наблюдать за заданной целью (узлом) и сообщать о любых мутациях в соответствии с критериями, заданными параметрами (объектом). Аргумент options позволяет задавать параметры наблюдения за мутациями через члены объекта.

```java
public void Observe(Node target)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| цель | Узел | Цель для observe. |
