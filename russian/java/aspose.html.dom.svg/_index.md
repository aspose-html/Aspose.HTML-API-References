Все классы в пакете **com.aspose.html.dom.svg** основаны на рекомендациях w3c SVG2. С помощью этого пакета вы можете загружать, перемещаться по или рендерить SVG‑файл в соответствии с вашими требованиями.

Когда элемент ‘svg’ встроен непосредственно как компонент документа из другого пакета, например, когда элемент ‘svg’ встроен в документ XHTML [XHTML], объект SVGDocument не будет существовать; вместо этого корневым объектом в иерархии объектов документа будет объект Document другого типа, например объект HTMLDocument. Тем не менее объект SVGDocument действительно будет существовать, когда корневым элементом иерархии XML‑документа является элемент ‘svg’, например при просмотре отдельного SVG‑файла (т.е. файла с MIME‑типом \"image/svg+xml\"). Для методов этого интерфейса, которые ссылаются на индекс символа или количество символов, эти ссылки следует интерпретировать соответственно как индекс кода UTF‑16 или количество кодов UTF‑16. ## Интерфейсы
