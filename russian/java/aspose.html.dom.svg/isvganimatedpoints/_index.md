## ISVGAnimatedPoints interface

Интерфейс SVGAnimatedPoints поддерживает элементы, которые имеют атрибут ‘points’, содержащий список координатных значений и поддерживают возможность анимировать этот атрибут. Кроме того, атрибут ‘points’ оригинального элемента, доступный через XML DOM (например, с помощью вызова метода getAttribute()), будет отражать любые изменения, внесённые в точки.

```java
public interface ISVGAnimatedPoints
```
