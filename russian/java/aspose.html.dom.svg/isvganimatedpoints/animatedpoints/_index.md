## ISVGAnimatedPoints.AnimatedPoints property

Предоставляет доступ к текущему анимированному содержимому атрибута ‘points’. Если данный атрибут или свойство анимируется, содержит текущие анимированные значения атрибута или свойства. Если данный атрибут или свойство в данный момент не анимируется, содержит то же значение, что и points.

```java
public SVGPointList AnimatedPoints { get; }
```

### Property Value

Анимированные точки.
