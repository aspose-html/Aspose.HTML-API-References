## SVGViewElement.ViewTarget property

Соответствует атрибуту ‘viewTarget’ данного элемента ‘view’. Список значений DOMString, содержащих имена, указанные в атрибуте ‘viewTarget’. Каждое значение DOMString может быть связано с соответствующим элементом с помощью вызова метода getElementById().

```java
public SVGStringList ViewTarget { get; }
```

### Property Value

Атрибут ‘viewTarget’ данного элемента ‘view’.
