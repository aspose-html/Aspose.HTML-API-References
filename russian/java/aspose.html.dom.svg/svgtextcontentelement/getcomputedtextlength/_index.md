## SVGTextContentElement.GetComputedTextLength method

Общая сумма всех значений advance, полученных при рендеринге всех символов внутри этого элемента, включая значение advance глифов (горизонтальное или вертикальное), влияние свойств ‘kerning’, ‘letter-spacing’ и ‘word-spacing’ и корректировки, вызванные атрибутами ‘dx’ и ‘dy’ в элементах ‘tspan’. Для сред, не выполняющих рендеринг, пользовательский агент должен делать разумные предположения о метриках глифов.

```java
public float GetComputedTextLength()
```

### Возвращаемое значение

Расстояние продвижения текста.
