## SVGGraphicsElement.GetBBox method

Возвращает плотный ограничивающий прямоугольник в текущем пользовательском пространстве (т.е. после применения атрибута ‘transform’, если он присутствует) по геометрии всех вложенных графических элементов, исключая обводку, обрезку, маскирование и эффекты фильтров). Обратите внимание, что getBBox должен возвращать фактический ограничивающий прямоугольник в момент вызова метода, даже если элемент ещё не был отрисован.

```java
public SVGRect GetBBox()
```

### Возвращаемое значение

Объект SVGRect, определяющий ограничивающий прямоугольник.
