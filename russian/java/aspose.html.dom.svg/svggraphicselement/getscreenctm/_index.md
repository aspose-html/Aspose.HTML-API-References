## SVGGraphicsElement.GetScreenCTM method

Возвращает матрицу преобразования от текущих пользовательских единиц (т.е. после применения атрибута ‘transform’, если он присутствует) к «пикселю», определяемому родительским пользовательским агентом. Для дисплейных устройств это, как правило, физический пиксель экрана. Для других устройств или сред, где размеры физических пикселей неизвестны, может использоваться алгоритм, аналогичный определению «пикселя» в CSS2. Обратите внимание, что возвращается null, если этот элемент не включён в дерево документа. Этот метод мог бы быть более точно назван getClientCTM, но имя getScreenCTM сохраняется по историческим причинам.

```java
public SVGMatrix GetScreenCTM()
```

### Возвращаемое значение

Объект SVGMatrix, определяющий заданную матрицу преобразования.
