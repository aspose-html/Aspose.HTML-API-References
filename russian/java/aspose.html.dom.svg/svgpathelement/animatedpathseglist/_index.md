## SVGPathElement.AnimatedPathSegList property

Предоставляет доступ к текущим анимированным содержимым атрибута ‘d’ в форме, полностью соответствующей синтаксису SVG. Если данный атрибут или свойство анимируется, содержит текущее анимированное значение атрибута или свойства, и как сам объект, так и его содержимое доступны только для чтения. Если данный атрибут или свойство в данный момент не анимируется, содержит то же значение, что и pathSegList.

```java
public SVGPathSegList AnimatedPathSegList { get; }
```

### Property Value

Анимированный список сегментов пути.
