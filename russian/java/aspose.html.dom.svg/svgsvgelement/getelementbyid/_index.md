## SVGSVGElement.GetElementById method

Ищет в данном фрагменте SVG‑документа (т.е. поиск ограничен поддеревом документа) элемент Element, чей id задан параметром elementId. Если элемент найден, он возвращается. Если такого элемента нет, возвращается null. Поведение не определено, если более одного элемента имеет этот id.

```java
public Element GetElementById(String elementId)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| elementId | String | Уникальное значение id для элемента. |

### Возвращаемое значение

Соответствующий элемент.
