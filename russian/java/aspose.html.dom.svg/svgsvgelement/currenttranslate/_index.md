## SVGSVGElement.CurrentTranslate property

На внешнем элементе svg соответствующий коэффициент трансляции, учитывающий пользовательское \"масштабирование\". При доступе к элементу ‘svg’, который не является внешним, поведение этого атрибута не определено.

```java
public SVGPoint CurrentTranslate { get; }
```

### Property Value

Текущая трансляция.
