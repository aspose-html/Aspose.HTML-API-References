## SVGMarkerElement.OrientAngle property

Соответствует атрибуту ‘orient’ в данном элементе ‘marker’. Если markerUnits равно SVG_MARKER_ORIENT_ANGLE, используется угловое значение атрибута ‘orient’; в противном случае оно будет установлено в ноль.

```java
public SVGAnimatedAngle OrientAngle { get; }
```

### Property Value

Атрибут ‘orient’ данного элемента ‘marker’.
