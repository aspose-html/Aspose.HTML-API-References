## NamedNodeMap class

Представляет коллекции атрибутов, к которым можно обращаться по имени.

```java
public class NamedNodeMap : DOMObject
```

## Свойства

| Имя | Описание |
| --- | --- |
| [getItem](../../com.aspose.html.collections/namednodemap/item/) Возвращает элемент с указанным индексом в карте. Если индекс больше или равен количеству узлов в этой карте, возвращает null. (2 индексатора) |
| [getLength](../../com.aspose.html.collections/namednodemap/length/) Количество узлов в этой карте. |

## Методы

| Имя | Описание |
| --- | --- |
| [getNamedItem](../../com.aspose.html.collections/namednodemap/getnameditem/)(String) | Получает узел, указанный по имени. |
| [getNamedItemNS](../../com.aspose.html.collections/namednodemap/getnameditemns/)(String, String) | Получает узел, указанный по локальному имени и URI пакета. |
| [getPlatformType](../../com.aspose.html.dom/domobject/getplatformtype/)() | Этот метод используется для получения объекта ECMAScript. |
| [removeNamedItem](../../com.aspose.html.collections/namednodemap/removenameditem/)(String) | Удаляет узел, указанный по имени. |
| [removeNamedItemNS](../../com.aspose.html.collections/namednodemap/removenameditemns/)(String, String) | Удаляет узел, указанный по локальному имени и URI пакета. |
| [setNamedItem](../../com.aspose.html.collections/namednodemap/setnameditem/)(Attr) | Добавляет узел, используя его атрибут nodeName. Если узел с таким именем уже присутствует в этой карте, он заменяется новым. Замена узла самим собой не оказывает эффекта. |
| [setNamedItemNS](../../com.aspose.html.collections/namednodemap/setnameditemns/)(Attr) | Добавляет узел, используя его packageURI и localName. Если узел с таким URI пакета и локальным именем уже присутствует в этой карте, он заменяется новым. Замена узла самим собой не оказывает эффекта. |
