## NamedNodeMap.SetNamedItemNS method

Добавляет узел, используя его packageURI и localName. Если узел с таким URI пакета и локальным именем уже присутствует в этой карте, он заменяется новым. Замена узла самим собой не оказывает эффекта.

```java
public Attr SetNamedItemNS(Attr attr)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| attr | Attr | Атрибут. |

### Возвращаемое значение

Возвращает узел.
