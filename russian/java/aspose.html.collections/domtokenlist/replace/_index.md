## DOMTokenList.Replace method

Заменяет существующий токен новым токеном. Не делает ничего, если первый токен не существует.

```java
public bool Replace(String token, String newToken)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| token | String | Токен, который вы хотите заменить. |
| newToken | String | Токен, которым вы хотите заменить старый токен. |

### Возвращаемое значение

Логическое значение `true`, если токен был найден и заменён, `false` в противном случае.
