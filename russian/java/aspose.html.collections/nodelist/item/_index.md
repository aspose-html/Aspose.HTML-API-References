## NodeList indexer

Метод возвращает элемент с указанным индексом в коллекции. Если индекс больше или равен количеству узлов в списке, возвращается null.

```java
public abstract Node this[int index] { get; }
```

| Параметр | Описание |
| --- | --- |
| index | Индекс. |

### Возвращаемое значение

Возвращает узел.
