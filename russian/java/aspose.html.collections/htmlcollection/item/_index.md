## HTMLCollection indexer

Возвращает элемент с индексом index в коллекции. Если индекс больше или равен количеству узлов в списке, возвращается null.

```java
public abstract Element this[int index] { get; }
```

| Параметр | Описание |
| --- | --- |
| index | Индекс. |

### Возвращаемое значение

Возвращает элемент.
