## Compression enumeration

Указывает возможные схемы сжатия для растровых изображений в формате Tagged Image File Format (TIFF).

```java
public enum Compression
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| LZW | `2` | Используется схема сжатия LZW. |
| CCITT3 | `3` | Используется схема сжатия CCITT3. |
| CCITT4 | `4` | Используется схема сжатия CCITT4. |
| Rle | `5` | Используется схема сжатия RLE. |
