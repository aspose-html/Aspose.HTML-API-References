Пакет **com.aspose.html.accessibility.results** содержит классы, описывающие результаты проверки правил.

## Классы

| Класс | Описание |
| --- | --- |
| [RuleValidationResult](./rulevalidationresult/) | Класс — результат проверки правила, содержит список [`ITechniqueResult`](../com.aspose.html.accessibility/itechniqueresult/), которые представляют способы удовлетворения критериев успеха. |
| [ValidationResult](./validationresult/) | Основной класс результата, который содержит результаты для всех критериев из объекта AccessibilityRules. |
