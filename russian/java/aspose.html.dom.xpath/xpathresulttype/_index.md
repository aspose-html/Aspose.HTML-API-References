## XPathResultType enumeration

Беззнаковый short, указывающий тип этого результата. Если указано конкретное `type`, то результат будет возвращён как соответствующий тип с использованием преобразований типов XPath, где это требуется и возможно.

```java
public enum XPathResultType
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Any | `0` | Этот код не представляет конкретный тип. Оценка XPath‑выражения никогда не возвращает этот тип. Если запрашивается этот тип, оценка возвращает тот тип, который естественно получается в результате оценки выражения. Если естественный результат — набор узлов, когда запрошен тип `Any`, то всегда возвращается тип `UnorderedNodeIterator`. Любое другое представление набора узлов должно быть запрошено явно. |
| Number | `1` | Результат — число, как определено в [XPath 1.0]. Изменение документа не делает число недействительным, но может привести к тому, что повторная оценка даст другое число. |
| String | `2` | Результат — строка, как определено в [XPath 1.0]. Изменение документа не делает строку недействительной, но может привести к тому, что строка больше не соответствует текущему документу. |
| Boolean | `3` | Результат — логическое значение, как определено в [XPath 1.0]. Изменение документа не делает логическое значение недействительным, но может привести к тому, что повторная оценка даст другое значение. |
| UnorderedNodeIterator | `4` | Результат — набор узлов, как определено в [XPath 1.0], который будет доступен итеративно и может не выдавать узлы в определённом порядке. Изменение документа делает итерацию недействительной. Это тип по умолчанию, возвращаемый, если результат — набор узлов и запрошен тип `Any`. |
| OrderedNodeIterator | `5` | Результат — набор узлов, как определено в [XPath 1.0], который будет доступен итеративно и будет выдавать узлы в порядке документа. Изменение документа делает итерацию недействительной. |
| UnorderedNodeSnapshot | `6` | Результат — набор узлов, как определено в [XPath 1.0], который будет доступен как список снимка узлов, который может быть неупорядоченным. Изменение документа не делает снимок недействительным, но может привести к тому, что повторная оценка даст другой снимок, а узлы в снимке могут быть изменены, перемещены или удалены из документа. |
| OrderedNodeSnapshot | `7` | Результат — набор узлов, как определено в [XPath 1.0], который будет доступен как список снимка узлов в исходном порядке документа. Изменение документа не делает снимок недействительным, но может привести к тому, что повторная оценка даст другой снимок, а узлы в снимке могут быть изменены, перемещены или удалены из документа. |
| AnyUnorderedNode | `8` | Результат — набор узлов, как определено в [XPath 1.0], и будет доступен как отдельный узел, который может быть `null`, если набор узлов пуст. Изменение документа не делает узел недействительным, но может привести к тому, что узел результата больше не соответствует текущему документу. Это удобство, позволяющее оптимизировать работу, поскольку реализация может остановиться, как только найден любой узел в результирующем наборе. Если в фактическом результате более одного узла, возвращённый отдельный узел может не быть первым в порядке документа. |
| FirstOrderedNode | `9` | Результат — набор узлов, как определено в [XPath 1.0], и будет доступен как отдельный узел, который может быть `null`, если набор узлов пуст. Изменение документа не делает узел недействительным, но может привести к тому, что узел результата больше не соответствует текущему документу. Это удобство, позволяющее оптимизировать работу, поскольку реализация может остановиться, как только найден первый узел в порядке документа из результирующего набора. Если в фактическом результате более одного узла, возвращённый отдельный узел будет первым в порядке документа. |
