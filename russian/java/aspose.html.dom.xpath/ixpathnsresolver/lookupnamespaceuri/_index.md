## IXPathNSResolver.LookupNamespaceURI method

Ищет URI пакета, связанный с заданным префиксом пакета. Оценщик XPath никогда не должен вызывать эту функцию с аргументом `null` или пустым, так как результат будет неопределён.

```java
public String LookupNamespaceURI(String prefix)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| префикс | String | Префикс, который нужно найти. |

### Возвращаемое значение

Возвращает связанный URI пакета или `null`, если он не найден.
