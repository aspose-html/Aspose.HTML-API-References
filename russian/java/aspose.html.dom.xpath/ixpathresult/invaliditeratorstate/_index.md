## IXPathResult.InvalidIteratorState property

Указывает, что итератор стал недействительным. Истина, если `resultType` is `UnorderedNodeIterator` или `OrderedNodeIterator` и документ был изменён с момента возврата этого результата.

```java
public bool InvalidIteratorState { get; }
```
