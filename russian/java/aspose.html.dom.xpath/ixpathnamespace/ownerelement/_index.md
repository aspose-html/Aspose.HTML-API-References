## IXPathNamespace.OwnerElement property

Элемент [`Element`](../../../com.aspose.html.dom/element/), в контексте которого пакет был доступен при запросе. Это не меняется в возвращённом узле пакета, даже если документ изменяется так, что пакет выходит за пределы области видимости этого элемента, и этот узел больше не находится там с помощью XPath.

```java
public Element OwnerElement { get; }
```
