## IXPathNamespace.OwnerElement property

Элемент [`Element`](../../../com.aspose.html.dom/element/), в контексте которого пакет был в области видимости при запросе. Это не меняется у возвращённого узла пакета, даже если документ изменяется так, что пакет выходит из области видимости на этом элементе, и этот узел больше не находится там с помощью XPath.

```java
public Element OwnerElement { get; }
```
