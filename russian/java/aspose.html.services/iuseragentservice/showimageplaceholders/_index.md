## IUserAgentService.ShowImagePlaceholders property

Изображения могут иметь резервный контент: контент, который следует использовать, когда внешний ресурс недоступен (например, потому что он в неподдерживаемом формате). Свойство `ShowImagePlaceholders` указывает, следует ли отображать резервное изображение (по умолчанию true).

```java
public bool ShowImagePlaceholders { get; set; }
```
