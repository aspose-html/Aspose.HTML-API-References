## IUserAgentService.Language property

`Language` указывает основной язык содержимого элемента и любых атрибутов элемента, содержащих текст. Его значение должно быть действительным тегом языка BCP 47 или пустой строкой. Установка атрибута в пустую строку указывает, что основной язык неизвестен.

```java
public String Language { get; set; }
```

### Property Value

Язык пользовательского агента.
