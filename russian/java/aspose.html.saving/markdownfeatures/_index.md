## MarkdownFeatures enumeration

Набор флагов `MarkdownFeatures` представляет собой набор из нуля или более следующих флагов, которые используются для выбора элементов, преобразуемых в markdown.

```java
[Flags]
public enum MarkdownFeatures
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| InlineHTML | `1` | Этот флаг включает инлайн-элементы HTML. Если флаг установлен, то блочные элементы (например, `div`), у которых атрибут `markdown` имеет значение `inline`, будут вставлены в результирующий markdown. |
| AutomaticParagraph | `2` | Этот флаг включает конвертацию элементов `paragraph`. Содержимое таких элементов будет размещено на отдельных строках, поэтому обработчики markdown обернут их. |
| Header | `4` | Этот флаг включает конвертацию элементов `header`. |
| Blockquote | `8` | Этот флаг включает конвертацию элементов `blockquote`. |
| List | `10` | Этот флаг включает конвертацию элементов `list`. |
| CodeBlock | `20` | Этот флаг включает конвертацию блоков кода. Блок кода состоит из двух элементов `pre` и `code`, содержимое такой конструкции обрабатывается "as is". |
| HorizontalRule | `40` | Этот флаг включает конвертацию `horizontal rules`. |
| Link | `80` | Этот флаг включает конвертацию элементов `a`. |
| Emphasis | `100` | Этот флаг включает преобразование элементов `emphasis`. |
| InlineCode | `200` | Этот флаг включает преобразование элементов `code`. |
| Image | `400` | Этот флаг включает преобразование элементов `img`. |
| LineBreak | `800` | Этот флаг включает преобразование элементов `br`. |
| Video | `1000` | Этот флаг включает преобразование элементов `video`. |
| Table | `2000` | Этот флаг включает преобразование элементов `table`. |
| TaskList | `4000` | Этот флаг включает преобразование списков задач. Список задач состоит из элемента `input`, который должен быть первым дочерним элементом элемента `list` и значение атрибута `type` которого должно быть равно `checkbox`. |
| Strikethrough | `8000` | Этот флаг включает преобразование элементов `del`. |
| Strong | `10000` | Этот флаг включает преобразование элементов `strong`. |
