## ResourceHandlingOptions.MaxHandlingDepth property

Получает или задает максимальную глубину страниц, которые будут обрабатываться. Глубина 1 означает, что будут обрабатываться только страницы, непосредственно связанные с сохранённым документом. Установка этого свойства в -1 приведёт к обработке всех страниц. Значение по умолчанию — 0.

```java
public int MaxHandlingDepth { get; set; }
```
