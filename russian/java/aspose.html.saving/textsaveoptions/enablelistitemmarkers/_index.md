## TextSaveOptions.EnableListItemMarkers property

Опция, применяемая к элементам OL и UL при конвертации HTML в текст. Фактически она определяет, как обрабатывать внешние маркеры списков элементов OL и UL. Если true, перед элементами OL добавляются номера пунктов, а перед элементами UL — точки. Если false, они не добавляются (поведение по умолчанию согласно спецификации).

```java
public bool EnableListItemMarkers { get; set; }
```
