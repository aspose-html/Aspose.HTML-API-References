## ICanvasRenderingContext2D.ClearRect method

Устанавливает все пиксели в прямоугольнике, определённом начальной точкой (x, y) и размерами (width, height), в прозрачный чёрный цвет, стирая любой ранее нарисованный контент.

```java
public void ClearRect(double x, double y, double w, double h)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| x | Double | Ось x координаты начальной точки прямоугольника. |
| y | Double | Ось y координаты начальной точки прямоугольника. |
| w | Double | Ширина прямоугольника. |
| h | Double | Высота прямоугольника. |
