## DrawImage(HTMLImageElement, double, double, double, double) {#drawimage_4}

Рисует указанное изображение.

```java
public void DrawImage(HTMLImageElement image, double dx, double dy, double dw, double dh)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| изображение | HTMLImageElement | HTMLImageElement для рисования в контексте. |
| dx | Double | Координата X в целевом холсте, указывающая место размещения верхнего левого угла исходного изображения. |
| dy | Double | Координата Y в целевом холсте, указывающая место размещения верхнего левого угла исходного изображения. |
| dw | Double | Ширина, в которой изображение будет отрисовано в целевом холсте. Это позволяет масштабировать отрисованное изображение. Если не указано, ширина изображения при отрисовке не масштабируется. |
| dh | Double | Высота, в которой изображение будет отрисовано в целевом холсте. Это позволяет масштабировать отрисованное изображение. Если не указано, высота изображения при отрисовке не масштабируется. |

## DrawImage(HTMLImageElement, double, double, double, double, double, double, double, double) {#drawimage_5}

Рисует указанное изображение.

```java
public void DrawImage(HTMLImageElement image, double sx, double sy, double sw, double sh, 
    double dx, double dy, double dw, double dh)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| изображение | HTMLImageElement | HTMLImageElement для рисования в контексте. |
| sx | Double | Координата X верхнего левого угла подпрямоугольника исходного изображения, который будет отрисован в целевом контексте. |
| sy | Double | Координата Y верхнего левого угла подпрямоугольника исходного изображения, который будет отрисован в целевом контексте. |
| sw | Double | Ширина подпрямоугольника исходного изображения, который будет отрисован в целевом контексте. Если не указано, используется весь прямоугольник от координат, заданных sx и sy, до правого нижнего угла изображения. |
| sh | Double | Высота подпрямоугольника исходного изображения, который будет отрисован в целевом контексте. |
| dx | Double | Координата X в целевом холсте, указывающая место размещения верхнего левого угла исходного изображения. |
| dy | Double | Координата Y в целевом холсте, указывающая место размещения верхнего левого угла исходного изображения. |
| dw | Double | Ширина, в которой изображение будет отрисовано в целевом холсте. Это позволяет масштабировать отрисованное изображение. Если не указано, ширина изображения при отрисовке не масштабируется. |
| dh | Double | Высота, в которой изображение будет отрисовано в целевом холсте. Это позволяет масштабировать отрисованное изображение. Если не указано, высота изображения при отрисовке не масштабируется. |
