## ICanvasRenderingContext2D.CreateRadialGradient method

Создаёт радиальный градиент, заданный координатами двух кругов, представленных параметрами.

```java
public ICanvasGradient CreateRadialGradient(double x0, double y0, double r0, double x1, double y1, 
    double r1)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| x0 | Double | Ось x координаты начального круга. |
| y0 | Double | Ось y координаты начального круга |
| r0 | Double | Радиус начального круга. |
| x1 | Double | Ось x координаты конечного круга. |
| y1 | Double | Ось y координаты конечного круга. |
| r1 | Double | Радиус конечного круга. |

### Возвращаемое значение

Радиальный CanvasGradient, инициализированный двумя указанными кругами.
