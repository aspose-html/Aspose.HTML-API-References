## IsPointInStroke(double, double) {#ispointinstroke_1}

Сообщает, находится ли указанный пункт внутри области, образованной обводкой пути.

```java
public bool IsPointInStroke(double x, double y)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| x | Double | Координата X проверяемой точки. |
| y | Double | Координата Y проверяемой точки. |

### Возвращаемое значение

Возвращает true, если точка находится внутри области, образованной обводкой пути, иначе false.
