## CreateImageData(double, double) {#createimagedata_1}

Создаёт новый пустой объект ImageData с указанными размерами. Все пиксели нового объекта являются прозрачными чёрными.

```java
public IImageData CreateImageData(double sw, double sh)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| sw | Double | Ширина нового объекта ImageData. |
| sh | Double | Высота нового объекта ImageData. |

### Возвращаемое значение

Новый объект ImageData с указанной шириной и высотой. Новый объект заполнен прозрачными чёрными пикселями.

## CreateImageData(IImageData) {#createimagedata}

Создаёт новый пустой объект ImageData с указанными размерами. Все пиксели нового объекта являются прозрачными чёрными.

```java
public IImageData CreateImageData(IImageData imagedata)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| imagedata | IImageData | Существующий объект ImageData, из которого копируются ширина и высота. Само изображение не копируется. |

### Возвращаемое значение

Новый объект ImageData с указанной шириной и высотой. Новый объект заполнен прозрачными чёрными пикселями.
