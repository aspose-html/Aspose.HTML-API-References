## IsPointInPath(double, double) {#ispointinpath_2}

Сообщает, находится ли указанный пункт внутри текущего пути.

```java
public bool IsPointInPath(double x, double y)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| x | Double | Координата X проверяемой точки. |
| y | Double | Координата Y проверяемой точки. |

### Возвращаемое значение

Возвращает true, если точка находится внутри области, образованной заполнением пути, иначе false.
