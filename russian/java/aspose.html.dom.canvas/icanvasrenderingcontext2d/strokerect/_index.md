## ICanvasRenderingContext2D.StrokeRect method

Рисует прямоугольник, начинающийся в точке (x, y) и имеющий ширину w и высоту h, на холсте, используя текущий стиль обводки.

```java
public void StrokeRect(double x, double y, double w, double h)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| x | Double | Ось x координаты начальной точки прямоугольника. |
| y | Double | Ось y координаты начальной точки прямоугольника. |
| w | Double | Ширина прямоугольника. |
| h | Double | Высота прямоугольника. |
