## CanvasFillRule enumeration

Это перечисление используется для выбора алгоритма правила заполнения, определяющего, находится ли точка внутри или снаружи пути.

```java
public enum CanvasFillRule
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| NonZero | `0` | Значение "nonzero" указывает правило ненулевого winding, при котором точка считается находящейся за пределами фигуры, если количество пересечений полубесконечной прямой, проведённой из этой точки, с контуром фигуры в одном направлении равно количеству пересечений в противоположном направлении. |
| EvenOdd | `1` | Значение "evenodd" указывает правило чет-нечет, при котором точка считается находящейся за пределами фигуры, если количество пересечений полубесконечной прямой, проведённой из этой точки, с контуром фигуры, является чётным. |
