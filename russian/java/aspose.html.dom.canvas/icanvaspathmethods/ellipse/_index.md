## Ellipse(double, double, double, double, double, double, double) {#ellipse}

Добавляет эллипс к пути, центрированный в позиции (x, y) с радиусами radiusX и radiusY, начиная с угла startAngle и заканчивая углом endAngle, движущийся в указанном направлении против часовой стрелки (по умолчанию по часовой).

```java
public void Ellipse(double x, double y, double radiusX, double radiusY, double rotation, 
    double startAngle, double endAngle)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| x | Double | Ось x координаты центра эллипса. |
| y | Double | Ось y координаты центра эллипса. |
| radiusX | Double | Радиус большой оси эллипса. |
| radiusY | Double | Радиус малой оси эллипса. |
| rotation | Double | Вращение этого эллипса, выраженное в радианах. |
| startAngle | Double | Начальная точка, измеренная от оси x, от которой будет рисоваться, выраженная в радианах. |
| endAngle | Double | Конечный угол эллипса, до которого будет рисоваться, выраженный в радианах. |

## Ellipse(double, double, double, double, double, double, double, bool) {#ellipse_1}

Добавляет эллипс к пути, центрированный в позиции (x, y) с радиусами radiusX и radiusY, начиная с угла startAngle и заканчивая углом endAngle, движущийся в указанном направлении против часовой стрелки (по умолчанию по часовой).

```java
public void Ellipse(double x, double y, double radiusX, double radiusY, double rotation, 
    double startAngle, double endAngle, bool anticlockwise)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| x | Double | Ось x координаты центра эллипса. |
| y | Double | Ось y координаты центра эллипса. |
| radiusX | Double | Радиус большой оси эллипса. |
| radiusY | Double | Радиус малой оси эллипса. |
| rotation | Double | Вращение этого эллипса, выраженное в радианах. |
| startAngle | Double | Начальная точка, измеренная от оси x, от которой будет рисоваться, выраженная в радианах. |
| endAngle | Double | Конечный угол эллипса, до которого будет рисоваться, выраженный в радианах. |
| против часовой стрелки | Boolean | Опциональный булевый параметр, который, если true, рисует эллипс против часовой стрелки (counter-clockwise), иначе по часовой стрелке. |
