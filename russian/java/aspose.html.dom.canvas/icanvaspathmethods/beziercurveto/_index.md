## ICanvasPathMethods.BezierCurveTo method

Добавляет кубическую кривую Безье к пути. Требуются три точки. Первые две точки являются контрольными точками, а третья — конечной точкой. Начальная точка — это последняя точка текущего пути, которую можно изменить с помощью moveTo() перед созданием кривой Безье.

```java
public void BezierCurveTo(double cp1x, double cp1y, double cp2x, double cp2y, double x, double y)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| cp1x | Double | Ось x координаты первой контрольной точки. |
| cp1y | Double | Ось y координаты первой контрольной точки. |
| cp2x | Double | Ось x координаты второй контрольной точки. |
| cp2y | Double | Ось y координаты второй контрольной точки. |
| x | Double | Ось x координаты конечной точки. |
| y | Double | Ось y координаты конечной точки. |
