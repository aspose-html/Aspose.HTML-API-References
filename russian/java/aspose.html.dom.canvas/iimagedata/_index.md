## IImageData interface

Создаёт объект ImageData из заданного Uint8ClampedArray и размера содержащегося в нём изображения. Если массив не указан, создаётся изображение чёрного прямоугольника.

```java
public interface IImageData
```

## Свойства

| Имя | Описание |
| --- | --- |
| [getData](../../com.aspose.html.dom.canvas/iimagedata/data/) является Uint8ClampedArray, представляющим одномерный массив, содержащий данные в порядке RGBA, с целочисленными значениями от 0 до 255 (включительно). |
| [getHeight](../../com.aspose.html.dom.canvas/iimagedata/height/) является беззнаковым целым типом unsigned long, представляющим фактическую высоту ImageData в пикселях. |
| [getWidth](../../com.aspose.html.dom.canvas/iimagedata/width/) является беззнаковым целым типом unsigned long, представляющим фактическую ширину ImageData в пикселях. |
