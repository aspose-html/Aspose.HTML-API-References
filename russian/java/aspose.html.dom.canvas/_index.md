## Классы

| Класс | Описание |
| --- | --- |
| [Path2D](./path2d/) | Интерфейс Path2D API Canvas 2D используется для объявления путей, которые затем применяются к объектам CanvasRenderingContext2D. Методы работы с путями интерфейса CanvasRenderingContext2D также присутствуют в этом интерфейсе и позволяют создавать пути, которые можно сохранять и воспроизводить по мере необходимости на холсте. |
## Интерфейсы

| Интерфейс | Описание |
| --- | --- |
| [ICanvasDrawingStyles](./icanvasdrawingstyles/) | Интерфейс ICanvasDrawingStyles предоставляет методы и свойства, контролирующие, как рисуются линии и как размещается текст. |
| [ICanvasGradient](./icanvasgradient/) | Представляет непрозрачный объект, описывающий градиент. |
| [ICanvasPathMethods](./icanvaspathmethods/) | Интерфейс ICanvasPathMethods используется для манипулирования путями объектов. |
| [ICanvasPattern](./icanvaspattern/) | Представляет непрозрачный объект, описывающий узор, основанный на изображении, холсте или видео. |
| [ICanvasRenderingContext2D](./icanvasrenderingcontext2d/) | Интерфейс ICanvasRenderingContext2D используется для рисования прямоугольников, текста, изображений и других объектов на элементе canvas. Он предоставляет 2‑D контекст рендеринга для поверхности рисования элемента canvas. |
| [IImageData](./iimagedata/) | Создаёт объект ImageData из заданного Uint8ClampedArray и размера содержащегося в нём изображения. Если массив не указан, создаётся изображение чёрного прямоугольника. |
| [ITextMetrics](./itextmetrics/) | Представляет размеры текста на холсте. |
