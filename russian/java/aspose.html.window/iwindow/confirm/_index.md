## IWindow.Confirm method

Отображает модальное диалоговое окно OK/Cancel с заданным сообщением, ждёт, пока пользователь его закроет, и возвращает true, если пользователь нажал OK, и false, если нажал Cancel.

```java
public bool Confirm(String message)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| message | String | Сообщение. |

### Возвращаемое значение

Возвращает true, если пользователь нажал ОК, и false, если пользователь нажал Отмена.
