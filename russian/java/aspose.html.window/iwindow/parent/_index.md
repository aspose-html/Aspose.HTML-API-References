## IWindow.Parent property

Атрибут parent IDL объекта Window документа в контексте просмотра b должен возвращать объект WindowProxy родительского контекста просмотра, если он существует (т.е. если b является дочерним контекстом просмотра), или объект WindowProxy самого контекста b в противном случае (т.е. если это контекст верхнего уровня или отсоединённый вложенный контекст просмотра).
