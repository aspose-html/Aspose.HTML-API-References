## IWindow.Prompt method

Отображает модальное окно с полем ввода текста и заданным сообщением, ожидает, пока пользователь его закроет, и возвращает введённое пользователем значение. Если пользователь отменил запрос, возвращается null. Если присутствует второй аргумент, указанное значение используется как значение по умолчанию.

```java
public String Prompt(String message, String @default)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| message | String | Сообщение. |
| по умолчанию | String | Значение по умолчанию. |

### Возвращаемое значение

Возвращает значение, введённое пользователем.
