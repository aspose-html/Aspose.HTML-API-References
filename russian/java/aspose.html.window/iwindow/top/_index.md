## IWindow.Top property

Атрибут top IDL на объекте Window документа в контексте просмотра b должен возвращать объект WindowProxy его контекста верхнего уровня (который был бы его собственным объектом WindowProxy, если бы он был контекстом верхнего уровня сам по себе), если он имеет такой, или его собственный объект WindowProxy в противном случае (например, если это был отсоединённый вложенный контекст просмотра).

```java
public IWindow Top { get; }
```
