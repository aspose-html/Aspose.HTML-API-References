## Location class

Объекты Location предоставляют представление адреса активного документа их контекста просмотра Document и позволяют изменить текущую запись истории сеанса контекста просмотра, добавляя или заменяя записи в объекте истории.

```java
public sealed class Location : DOMObject
```
