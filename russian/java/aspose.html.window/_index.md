Пакет **com.aspose.html.window** связан с объектом окна, который представляет окно, содержащее DOM‑документ. Он включает классы и интерфейсы, связанные с адресом активного документа и историей навигации.

## Классы

| Класс | Описание |
| --- | --- |
| [Location](./location/) | Объекты Location предоставляют представление адреса активного документа их контекста просмотра Document и позволяют изменить текущую запись истории сеанса контекста просмотра, добавляя или заменяя записи в объекте истории. |
| [MediaQueryList](./mediaquerylist/) | Объект MediaQueryList хранит информацию о медиазапросе, применённом к документу, с поддержкой как немедленного, так и событийного сопоставления с состоянием документа. См. спецификацию CSSOM View Module: [https://www.w3.org/TR/cssom-view/#the-mediaquerylist-interface](https://www.w3.org/TR/cssom-view/#the-mediaquerylist-interface) |
## Интерфейсы

| Интерфейс | Описание |
| --- | --- |
| [IWindow](./iwindow/) | Объект window представляет окно, содержащее DOM‑документ. |
| [IWindowEventHandlers](./iwindoweventhandlers/) | Представляет интерфейс, который должен наследоваться объектом window |
| [IWindowTimers](./iwindowtimers/) | Позволяет авторам планировать обратные вызовы, основанные на таймерах. |
