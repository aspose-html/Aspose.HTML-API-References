## DocDevice.Fill method

Заполняет всю область, ограниченную текущим контуром. Если контур состоит из нескольких несвязанных подпутей, он заполняет внутренние части всех подпутей совместно. Этот метод завершает текущий контур.

```java
public void Fill(FillRule mode)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| режим | FillRule | Режим заполнения определяет, как внутренность замкнутого пути заполняется |
