## FontEmbeddingRule enumeration

Представляет правила встраивания шрифтов.

```java
public enum FontEmbeddingRule
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Full | `1` | Все используемые шрифты будут встроены без изменений. Учтите, что некоторые шрифты могут быть лицензированы, что сделает полученный документ недоступным для редактирования. Кроме того, встроенные файлы шрифтов могут значительно увеличить размер получаемого документа. |
| None | `2` | Шрифты не будут встроены. |
