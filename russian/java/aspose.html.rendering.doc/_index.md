Пакет **com.aspose.html.rendering.doc** предоставляет конкретный класс устройства, а также несколько классов параметров рендеринга, отвечающих за вывод в документ DOCX.

## Классы

| Класс | Описание |
| --- | --- |
| [DocDevice](./docdevice/) | Представляет рендеринг в документ DOCX. |
| [DocRenderingOptions](./docrenderingoptions/) | Представляет параметры рендеринга для [`DocDevice`](../com.aspose.html.rendering.doc/docdevice/). |
## Перечисление

| Перечисление | Описание |

| [DocumentFormat](./documentformat/) | Представляет формат файла выходного документа. |
