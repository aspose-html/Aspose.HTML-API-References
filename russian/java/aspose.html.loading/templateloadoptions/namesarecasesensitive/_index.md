## TemplateLoadOptions.NamesAreCaseSensitive property

Свойство, которое указывает, будет ли сопоставление имён шаблона и элементов данных происходить независимо от регистра символов. Если true, сопоставление чувствительно к регистру; если false, регистр будет игнорироваться. Значение по умолчанию — true.

```java
public bool NamesAreCaseSensitive { get; set; }
```
