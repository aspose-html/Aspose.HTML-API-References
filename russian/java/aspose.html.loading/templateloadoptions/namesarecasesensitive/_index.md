## TemplateLoadOptions.NamesAreCaseSensitive property

Свойство, которое указывает, будут ли имена шаблона и элементов данных сравниваться без учёта регистра символов или нет. Если true, сравнение чувствительно к регистру; если false, регистр будет игнорироваться. Значение по умолчанию — true.

```java
public bool NamesAreCaseSensitive { get; set; }
```
