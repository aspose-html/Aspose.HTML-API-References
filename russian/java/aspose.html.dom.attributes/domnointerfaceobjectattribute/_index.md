## DOMNoInterfaceObjectAttribute class

Если расширенный атрибут [NoInterfaceObject] присутствует в интерфейсе, это указывает, что объект интерфейса не будет существовать для данного интерфейса в привязке ECMAScript.

```java
[AttributeUsage(AttributeTargets.All)]
public sealed class DOMNoInterfaceObjectAttribute : Attribute
```
