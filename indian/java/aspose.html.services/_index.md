**com.aspose.html.services** पैकेज में सेवा इम्प्लीमेंटेशन के प्रोटोकॉल के रूप में इंटरफ़ेस शामिल हैं।

## इंटरफ़ेस

| इंटरफ़ेस | विवरण |
| --- | --- |
| [IDeviceInformationService](./ideviceinformationservice/) | एक इंटरफ़ेस जो उस वातावरण का वर्णन करता है जिसमें [`Document`](../com.aspose.html.dom/document/) उपयोगकर्ता को प्रस्तुत किया जाता है। |
| [INetworkService](./inetworkservice/) | नेटवर्क ऑपरेशन्स के लिए एक इंटरफ़ेस प्रदान करता है। |
| [IRuntimeService](./iruntimeservice/) | यह सर्विस रनटाइम से संबंधित प्रॉपर्टीज़ को कॉन्फ़िगर करने के लिए उपयोग की जाती है। |
| [IUserAgentService](./iuseragentservice/) | एक इंटरफ़ेस जो उपयोगकर्ता एजेंट वातावरण का वर्णन करता है। |
