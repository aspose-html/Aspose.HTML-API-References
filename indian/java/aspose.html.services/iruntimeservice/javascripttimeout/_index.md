## IRuntimeService.JavaScriptTimeout property

TimeSpan प्राप्त करता है या सेट करता है जो JavaScript निष्पादन समय को सीमित करता है। यदि स्क्रिप्ट प्रदान किए गए TimeSpan से अधिक समय तक चलती है, तो इसे रद्द कर दिया जाएगा। आप TimeSpan को -1 मिलिसेकंड सेट करके अनंत टाइमआउट निर्दिष्ट कर सकते हैं। डिफ़ॉल्ट मान 1 मिनट है।

```java
public TimeSpan JavaScriptTimeout { get; set; }
```
