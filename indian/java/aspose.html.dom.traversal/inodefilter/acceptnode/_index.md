## INodeFilter.AcceptNode method

जाँचें कि क्या निर्दिष्ट नोड TreeWalker या NodeIterator के तर्कसंगत दृश्य में दृश्यमान है। यह फ़ंक्शन TreeWalker और NodeIterator के कार्यान्वयन द्वारा बुलाया जाएगा; यह सामान्यतः उपयोगकर्ता कोड से सीधे नहीं बुलाया जाता। (हालाँकि यदि आप अपने स्वयं के एप्लिकेशन लॉजिक को मार्गदर्शन करने के लिए वही फ़िल्टर उपयोग करना चाहते हैं तो आप ऐसा कर सकते हैं।)

```java
public short AcceptNode(Node n)
```

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| n | Node | फ़िल्टर को पास करता है या नहीं, यह जांचने के लिए नोड। |

### रिटर्न वैल्यू

ऊपर परिभाषित अनुसार यह निर्धारित करने के लिए एक स्थिरांक कि नोड को स्वीकार किया गया, अस्वीकार किया गया, या छोड़ दिया गया है।
