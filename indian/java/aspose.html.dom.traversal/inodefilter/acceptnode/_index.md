## INodeFilter.AcceptNode method

जाँचें कि कोई निर्दिष्ट नोड TreeWalker या NodeIterator के तार्किक दृश्य में दृश्यमान है या नहीं। यह फ़ंक्शन TreeWalker और NodeIterator के कार्यान्वयन द्वारा बुलाया जाएगा; यह सामान्यतः उपयोगकर्ता कोड से सीधे नहीं बुलाया जाता। (हालाँकि आप इसे उसी फ़िल्टर का उपयोग करके अपने एप्लिकेशन लॉजिक को निर्देशित करने के लिए भी कर सकते हैं।)

```java
public short AcceptNode(Node n)
```

| Parameter | Type | विवरण |
| --- | --- | --- |
| n | Node | फ़िल्टर को पास करता है या नहीं, यह जांचने के लिए जाँचने वाला नोड। |

### रिटर्न वैल्यू

एक स्थिरांक जो निर्धारित करता है कि नोड को स्वीकार किया गया है, अस्वीकार किया गया है, या ऊपर परिभाषित अनुसार छोड़ दिया गया है।
