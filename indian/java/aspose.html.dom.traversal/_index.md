The **com.aspose.html.dom.traversal** पैकेज में मेथड्स होते हैं जो इटरेटर और ट्री‑वॉकर बनाते हैं ताकि एलिमेंट्स के बीच नेविगेट किया जा सके और दस्तावेज़ क्रम में नोड और उसके बच्चों को ट्रैवर्स किया जा सके।
