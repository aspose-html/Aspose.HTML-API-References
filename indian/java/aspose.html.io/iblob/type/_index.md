## IBlob.Type property

ASCII-एन्कोडेड स्ट्रिंग लोअर केस में जो Blob के मीडिया प्रकार को दर्शाती है। प्राप्त करने पर, उपयोगकर्ता एजेंट को Blob का प्रकार ASCII-एन्कोडेड लोअर केस स्ट्रिंग के रूप में लौटाना चाहिए, ताकि जब इसे बाइट अनुक्रम में बदला जाए तो यह पार्स करने योग्य MIME प्रकार हो, या यदि प्रकार निर्धारित नहीं किया जा सकता तो खाली स्ट्रिंग – 0 बाइट।

```java
public String Type { get; }
```
