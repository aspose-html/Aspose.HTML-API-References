## IBlob.Type property

ASCII-एन्कोडेड स्ट्रिंग लोअर केस में जो Blob के मीडिया टाइप को दर्शाती है। प्राप्त करते समय, उपयोगकर्ता एजेंट को Blob के टाइप को ASCII-एन्कोडेड लोअर केस स्ट्रिंग के रूप में लौटाना चाहिए, ताकि जब इसे बाइट अनुक्रम में बदला जाए तो यह एक पार्स करने योग्य MIME टाइप हो, या यदि टाइप निर्धारित नहीं किया जा सकता तो खाली स्ट्रिंग – 0 बाइट्स –।

```java
public String Type { get; }
```
