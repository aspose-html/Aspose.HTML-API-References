## IBlob interface

एक Blob ऑब्जेक्ट बाइट अनुक्रम को दर्शाता है, और इसमें size एट्रिब्यूट होता है जो बाइट अनुक्रम में कुल बाइट्स की संख्या दर्शाता है, तथा type एट्रिब्यूट, जो लोअर केस में ASCII-एन्कोडेड स्ट्रिंग के रूप में बाइट अनुक्रम के मीडिया टाइप को दर्शाता है।

```java
public interface IBlob
```

## गुण

| नाम | विवरण |
| --- | --- |
| [getSize](../../com.aspose.html.io/iblob/size/) बाइट अनुक्रम का आकार बाइट्स की संख्या में लौटाता है। प्राप्त करने पर, अनुरूप उपयोगकर्ता एजेंट को वह कुल बाइट्स की संख्या लौटानी चाहिए जो FileReader या FileReaderSync ऑब्जेक्ट द्वारा पढ़ी जा सकती है, या यदि Blob में पढ़ने के लिए कोई बाइट नहीं है तो 0। |
| [getType](../../com.aspose.html.io/iblob/type/) वह ASCII-एन्कोडेड String छोटे अक्षरों में जो Blob के मीडिया प्रकार को दर्शाती है। प्राप्त करने पर, उपयोगकर्ता एजेंट को Blob का type एक ASCII-एन्कोडेड String छोटे अक्षरों में लौटाना चाहिए, ताकि जब इसे बाइट अनुक्रम में परिवर्तित किया जाए, तो यह एक पार्स करने योग्य MIME प्रकार हो, या यदि type निर्धारित नहीं किया जा सकता तो खाली String – 0 बाइट्स –। |
