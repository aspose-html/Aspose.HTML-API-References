मानक IO (इनपुट-आउटपुट) टूल्स के अतिरिक्त, **com.aspose.html.io** पैकेज में हेल्पर क्लासेज़ और इंटरफ़ेस होते हैं।

## क्लासेज़

| क्लास | विवरण |
| --- | --- |
| [FileCreateStreamProvider](./filecreatestreamprovider/) | रेंडरिंग डिवाइसों को स्ट्रीम प्रदान करने के लिए FileStream कार्यान्वयन का प्रतिनिधित्व करता है। |
## इंटरफ़ेस

| इंटरफ़ेस | विवरण |
| --- | --- |
| [IBlob](./iblob/) | एक Blob ऑब्जेक्ट बाइट अनुक्रम को दर्शाता है, और इसमें size एट्रिब्यूट होता है जो बाइट अनुक्रम में कुल बाइट्स की संख्या दर्शाता है, तथा type एट्रिब्यूट होता है, जो लोअर केस में ASCII-एन्कोडेड स्ट्रिंग के रूप में बाइट अनुक्रम के मीडिया टाइप को दर्शाता है। |
| [ICreateStreamProvider](./icreatestreamprovider/) | रेंडरिंग डिवाइसों को स्ट्रीम प्रदान करने वाली क्लासेज़ द्वारा लागू की जा सकने वाली इंटरफ़ेस का प्रतिनिधित्व करता है। |
| [IFile](./ifile/) | एक File ऑब्जेक्ट एक Blob ऑब्जेक्ट है जिसमें name एट्रिब्यूट होता है, जो एक स्ट्रिंग है; इसे वेब एप्लिकेशन के भीतर एक कंस्ट्रक्टर के माध्यम से बनाया जा सकता है, या यह अंतर्निहित (OS) फ़ाइल सिस्टम से फ़ाइल के बाइट अनुक्रम का संदर्भ है। |
| [IFileList](./ifilelist/) | फ़ाइलों की सूची के लिए इंटरफ़ेस का प्रतिनिधित्व करता है। |
