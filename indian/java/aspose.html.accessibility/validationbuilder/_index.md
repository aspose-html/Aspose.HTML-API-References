ValidationBuilder क्लास कॉन्फ़िगरेशन चरणों की ठोस कार्यान्वयन प्रदान करती है। ValidationSettings क्लास के लिए विधियों और सेटिंग्स को परिभाषित करती है।

public class ValidationBuilder
