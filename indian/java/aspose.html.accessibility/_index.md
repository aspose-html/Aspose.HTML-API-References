यह **com.aspose.html.accessibility** पैकेज सभी वेब एक्सेसेबिलिटी संबंधित हेरफेरों के लिए है। यह अंतर्राष्ट्रीय मानकों W3C Web Accessibility Initiative के अनुरूप है।

## क्लासेज़

| क्लास | विवरण |
| --- | --- |
| [AccessibilityRules](./accessibilityrules/) | वेब कंटेंट एक्सेसिबिलिटी गाइडलाइन्स (WCAG) 2 आवश्यकताओं (सफलता मानदंड) और तकनीकों के लिए त्वरित संदर्भ। सिद्धांतों की सूची शामिल है। https://www.w3.org/WAI/WCAG21/quickref/ |
| [AccessibilityValidator](./accessibilityvalidator/) | वैलिडेटर क्लास त्वरित संदर्भ नियमों को संभालती है। एक्सेसिबिलिटी जांचने के लिए एक Validate मेथड शामिल है। |
| [Criterion](./criterion/) | प्रत्येक सिफारिश के लिए सत्यापन योग्य सफलता मानदंड प्रदान किए जाते हैं, ताकि WCAG 2.0 उन क्षेत्रों में लागू किया जा सके जहाँ अनुपालन परीक्षण आवश्यक है। https://www.w3.org/WAI/WCAG21/Understanding/understanding-techniques |
| [Guideline](./guideline/) | गाइडलाइन्स - सिद्धांतों के बाद का अगला स्तर। ये परीक्षण योग्य नहीं हैं, लेकिन रूपरेखा ढाँचे और सामान्य लक्ष्य प्रदान करती हैं जो लेखकों को सफलता मानदंड समझने और तकनीकों को बेहतर लागू करने में मदद करते हैं। गाइडलाइन्स RuleDirectory{Criterion} प्रकार के स्वीकृति मानदंडों की सूची हैं। |
| [Principle](./principle/) | एक्सेसिबिलिटी प्रिंसिपल - वे सबसे उच्च स्तर हैं जो वेब एक्सेसिबिलिटी की नींव प्रदान करते हैं, जिसमें RuleCollection{Guideline} प्रकार की गाइडलाइन्स की सूची शामिल है। इस ऑब्जेक्ट को असेंबली के बाहर बनाने की अनुमति नहीं है। https://www.w3.org/WAI/fundamentals/accessibility-principles/ |
| [Rule](./rule/) | एक एब्स्ट्रैक्ट क्लास जो Rule की विशेषताओं को परिभाषित करती है और IRule इंटरफ़ेस को लागू करती है। |
| [Target](./target/) | क्लास में उस html या css तत्व का आइटम शामिल है जहाँ त्रुटि मिली थी। |
| [ValidationBuilder](./validationbuilder/) | ValidationBuilder क्लास कॉन्फ़िगरेशन चरणों की ठोस कार्यान्वयन प्रदान करती है। ValidationSettings क्लास के लिए विधियों और सेटिंग्स को परिभाषित करती है। |
| [WebAccessibility](./webaccessibility/) | ऑब्जेक्ट वेब कंटेंट एक्सेसिबिलिटी गाइडलाइन्स (WCAG) 2 आवश्यकताओं (सफलता मानदंड) और तकनीकों के लिए है। https://www.w3.org/WAI/WCAG21/quickref/ |
