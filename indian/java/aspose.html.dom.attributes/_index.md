The **com.aspose.html.dom.attributes** पैकेज में एकीकृत एट्रिब्यूट क्लासेज़ होते हैं जो किसी भी ऑब्जेक्ट (नोड, एलिमेंट, ...) की विशेषता या व्यवहार को निर्दिष्ट या योग्य बनाते हैं।

## क्लासेस

| क्लास | विवरण |
| --- | --- |
| [DOMConstructorAttribute](./domconstructorattribute/) | W3C द्वारा परिभाषित एक कंस्ट्रक्टर को निर्दिष्ट करता है। |
| [DOMNameAttribute](./domnameattribute/) | W3C द्वारा परिभाषित आधिकारिक DOM ऑब्जेक्ट नाम को निर्दिष्ट करता है। |
| [DOMNamedPropertyGetterAttribute](./domnamedpropertygetterattribute/) | निर्दिष्ट करता है कि यह मेथड नामित प्रॉपर्टी गेटर के रूप में उपयोग किया जाएगा। |
| [DOMNoInterfaceObjectAttribute](./domnointerfaceobjectattribute/) | यदि इंटरफ़ेस पर [NoInterfaceObject] विस्तारित एट्रिब्यूट दिखाई देता है, तो यह संकेत देता है कि ECMAScript बाइंडिंग में उस इंटरफ़ेस के लिए कोई इंटरफ़ेस ऑब्जेक्ट मौजूद नहीं होगा। |
| [DOMNullableAttribute](./domnullableattribute/) | निर्दिष्ट करता है कि एक DOM ऑब्जेक्ट को null मान सौंपा जा सकता है। |
| [DOMObjectAttribute](./domobjectattribute/) | निर्दिष्ट करता है कि इस एट्रिब्यूट के साथ चिह्नित ऑब्जेक्ट को W3C द्वारा परिभाषित किया गया है। |
| [DOMTreatNullAsAttribute](./domtreatnullasattribute/) | संकेत देता है कि सदस्य मान का null निर्दिष्ट मान के रूप में माना जाएगा। |
