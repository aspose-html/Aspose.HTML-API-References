## SVGSVGElement.GetElementById method

इस SVG दस्तावेज़ अंश (अर्थात, खोज दस्तावेज़ वृक्ष के एक उपसमुच्चय तक सीमित है) में वह Element खोजता है जिसका id elementId द्वारा दिया गया है। यदि कोई Element मिलता है, तो वह Element लौटाया जाता है। यदि ऐसा कोई तत्व नहीं है, तो null लौटाया जाता है। यदि एक से अधिक तत्वों का यह id है तो व्यवहार अपरिभाषित है।

```java
public Element GetElementById(String elementId)
```

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| elementId | String | एक तत्व के लिए अद्वितीय आईडी मान। |
