## SVGSVGElement.SetCurrentTime method

इस SVG दस्तावेज़ फ्रैगमेंट के लिए घड़ी को समायोजित करता है, एक नया वर्तमान समय स्थापित करता है। यदि setCurrentTime को दस्तावेज़ टाइमलाइन शुरू होने से पहले बुलाया जाता है (उदाहरण के लिए, ‘script’ तत्व में चल रहे स्क्रिप्ट द्वारा, जब दस्तावेज़ का SVGLoad इवेंट भेजा जाना है), तो विधि के अंतिम कॉल में सेकंड का मान वह समय देता है जिसे दस्तावेज़ टाइमलाइन शुरू होने पर प्राप्त करने का प्रयास करेगा।

```java
public void SetCurrentTime(float seconds)
```

| Parameter | Type | विवरण |
| --- | --- | --- |
| सेकंड | Single | वर्तमान SVG दस्तावेज़ फ्रैगमेंट की प्रारंभिक समय के सापेक्ष सेकंड में नया वर्तमान समय। |
