## SVGSVGElement.GetCurrentTime method

वर्तमान SVG दस्तावेज़ अंश के प्रारंभ समय के सापेक्ष सेकंड में वर्तमान समय लौटाता है। यदि getCurrentTime को दस्तावेज़ टाइमलाइन शुरू होने से पहले बुलाया जाता है (उदाहरण के लिए, ‘script’ तत्व में चल रहे स्क्रिप्ट द्वारा दस्तावेज़ के SVGLoad इवेंट के डिस्पैच होने से पहले), तो 0 लौटाया जाता है।

```java
public float GetCurrentTime()
```

### रिटर्न वैल्यू

सेकंड में वर्तमान समय, या 0 यदि दस्तावेज़ टाइमलाइन अभी तक शुरू नहीं हुई है।
