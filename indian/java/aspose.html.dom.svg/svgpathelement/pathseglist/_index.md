## SVGPathElement.PathSegList property

‘d’ एट्रिब्यूट की बेस (अर्थात स्थिर) सामग्री तक पहुँच प्रदान करता है, जो SVG की सिंटैक्स के साथ एक‑से‑एक मेल खाती है। इसलिए, यदि ‘d’ एट्रिब्यूट में "निरपेक्ष मूवटू (M)" और "निरपेक्ष आर्कटो (A)" कमांड हैं, तो pathSegList में दो प्रविष्टियाँ होंगी: एक SVG_PATHSEG_MOVETO_ABS और एक SVG_PATHSEG_ARC_ABS।

```java
public SVGPathSegList PathSegList { get; set; }
```

पथ खंड सूची।
