## SVGPathElement.AnimatedPathSegList property

‘d’ विशेषता की वर्तमान एनिमेटेड सामग्री तक पहुँच प्रदान करता है, जो SVG की सिंटैक्स के साथ एक‑से‑एक मेल खाता है। यदि दिया गया विशेषता या प्रॉपर्टी एनिमेट हो रही है, तो यह विशेषता या प्रॉपर्टी का वर्तमान एनिमेटेड मान रखता है, और वस्तु तथा उसकी सामग्री दोनों केवल‑पढ़ने योग्य हैं। यदि दिया गया विशेषता या प्रॉपर्टी वर्तमान में एनिमेट नहीं हो रही है, तो यह pathSegList के समान मान रखता है।

```java
public SVGPathSegList AnimatedPathSegList { get; }
```

### Property Value

एनिमेटेड पथ खंड सूची।
