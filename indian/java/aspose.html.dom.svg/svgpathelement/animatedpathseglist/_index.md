## SVGPathElement.AnimatedPathSegList property

‘d’ एट्रिब्यूट की वर्तमान एनिमेटेड सामग्री तक पहुँच प्रदान करता है, जो SVG की सिंटैक्स के साथ एक‑से‑एक मेल खाती है। यदि दिया गया एट्रिब्यूट या प्रॉपर्टी एनिमेट हो रहा है, तो यह एट्रिब्यूट या प्रॉपर्टी का वर्तमान एनिमेटेड मान रखता है, और ऑब्जेक्ट स्वयं तथा उसकी सामग्री केवल‑पढ़ने योग्य होते हैं। यदि दिया गया एट्रिब्यूट या प्रॉपर्टी वर्तमान में एनिमेट नहीं हो रहा है, तो यह pathSegList के समान मान रखता है।

```java
public SVGPathSegList AnimatedPathSegList { get; }
```

### Property Value

एनिमेटेड पथ खंड सूची।
