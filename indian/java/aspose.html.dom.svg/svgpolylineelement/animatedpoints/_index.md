## SVGPolylineElement.AnimatedPoints property

‘points’ एट्रिब्यूट की वर्तमान एनिमेटेड सामग्री तक पहुँच प्रदान करता है। यदि दिया गया एट्रिब्यूट या प्रॉपर्टी एनिमेटेड है, तो एट्रिब्यूट या प्रॉपर्टी का वर्तमान एनिमेटेड मान शामिल करता है। यदि दिया गया एट्रिब्यूट या प्रॉपर्टी वर्तमान में एनिमेटेड नहीं है, तो points के समान मान शामिल करता है।

```java
public SVGPointList AnimatedPoints { get; }
```

### Property Value

एनिमेटेड पॉइंट्स।
