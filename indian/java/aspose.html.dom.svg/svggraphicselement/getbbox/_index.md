## SVGGraphicsElement.GetBBox method

वर्तमान उपयोगकर्ता स्पेस में सभी सम्मिलित ग्राफ़िक्स तत्वों की ज्यामिति पर (यदि लागू हो तो ‘transform’ विशेषता के लागू होने के बाद) सटीक बाउंडिंग बॉक्स लौटाता है, स्ट्रोकिंग, क्लिपिंग, मास्किंग और फ़िल्टर प्रभावों को छोड़कर। ध्यान दें कि getBBox को उस समय वास्तविक बाउंडिंग बॉक्स लौटाना चाहिए जब विधि को बुलाया गया था, भले ही तत्व अभी तक रेंडर न हुआ हो।

```java
public SVGRect GetBBox()
```

### रिटर्न वैल्यू

एक SVGRect ऑब्जेक्ट जो बाउंडिंग बॉक्स को परिभाषित करता है।
