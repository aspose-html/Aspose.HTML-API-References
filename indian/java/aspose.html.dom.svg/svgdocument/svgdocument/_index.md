## SVGDocument(String) {#constructor_10}

[`SVGDocument`](../) क्लास का नया इंस्टेंस इनिशियलाइज़ करता है। कन्स्ट्रक्टर सिंक्रोनस रूप से काम करता है, यह सभी बाहरी संसाधनों (इमेज, स्क्रिप्ट आदि) के लोड होने का इंतज़ार करता है। असिंक्रोनस रूप से दस्तावेज़ लोड करने के लिए मेथड [`Navigate`](../../../com.aspose.html.dom/document/navigate/) या उसके ओवरलोड का उपयोग करें। या आप कुछ बाहरी संसाधनों के लोड को निष्क्रिय कर सकते हैं, इसके लिए [`Security`](../../../com.aspose.html.dom/ibrowsingcontext/security/) में उपयुक्त फ़्लैग सेट करें।

```java
public SVGDocument(String address)
```

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| पता | String | दस्तावेज़ का पता। इसे वर्तमान डायरेक्टरी पाथ के साथ मिलाकर एक पूर्ण URL बनाया जाएगा। |
