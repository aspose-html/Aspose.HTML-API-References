## SVGDocument(String) {#constructor_10}

[`SVGDocument`](../) क्लास का नया इंस्टेंस इनिशियलाइज़ करता है। कंस्ट्रक्टर सिंक्रोनस रूप से काम करता है, यह सभी बाहरी संसाधनों (इमेज, स्क्रिप्ट आदि) के लोड होने का इंतजार करता है। दस्तावेज़ को असिंक्रोनस रूप से लोड करने के लिए मेथड [`Navigate`](../../../com.aspose.html.dom/document/navigate/) या उसके ओवरलोड का उपयोग करें। या आप कुछ बाहरी संसाधनों के लोड को [`Security`](../../../com.aspose.html.dom/ibrowsingcontext/security/) में उपयुक्त फ़्लैग सेट करके डिसेबल कर सकते हैं।

```java
public SVGDocument(String address)
```

| Parameter | Type | विवरण |
| --- | --- | --- |
| पता | String | दस्तावेज़ पता। इसे वर्तमान डायरेक्टरी पाथ के साथ मिलाकर एक पूर्ण URL बनाया जाएगा। |

## SVGDocument(String, Url, Configuration) {#constructor_13}

[`SVGDocument`](../) क्लास का नया इंस्टेंस इनिशियलाइज़ करता है। कंस्ट्रक्टर सिंक्रोनस रूप से काम करता है, यह सभी बाहरी संसाधनों (इमेज, स्क्रिप्ट आदि) के लोड होने का इंतजार करता है। दस्तावेज़ को असिंक्रोनस रूप से लोड करने के लिए मेथड [`Navigate`](../../../com.aspose.html.dom/document/navigate/) या उसके ओवरलोड का उपयोग करें। या आप कुछ बाहरी संसाधनों के लोड को [`Security`](../../../com.aspose.html.dom/ibrowsingcontext/security/) में उपयुक्त फ़्लैग सेट करके डिसेबल कर सकते हैं।

```java
public SVGDocument(String content, Url baseUri, Configuration configuration)
```

| कॉन्फ़िगरेशन | कॉन्फ़िगरेशन | कॉन्फ़िगरेशन। |
