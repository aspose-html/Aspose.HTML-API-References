## SVGDocument class

`SVGDocument` SVG पदानुक्रम का मूल है और पूरी सामग्री को रखता है। पदानुक्रम तक पहुँच प्रदान करने के अलावा, यह दस्तावेज़ से कुछ जानकारी के सेट तक पहुँचने के लिए कुछ सुविधाजनक विधियाँ भी प्रदान करता है। जब कोई ‘svg’ तत्व किसी अन्य पैकेज के दस्तावेज़ के घटक के रूप में इनलाइन एम्बेड किया जाता है, जैसे कि जब एक ‘svg’ तत्व XHTML दस्तावेज़ [XHTML] में इनलाइन एम्बेड किया जाता है, तो `SVGDocument` ऑब्जेक्ट मौजूद नहीं रहेगा; इसके बजाय, दस्तावेज़ ऑब्जेक्ट पदानुक्रम में मूल ऑब्जेक्ट एक अलग प्रकार के Document ऑब्जेक्ट, जैसे कि HTMLDocument ऑब्जेक्ट होगा। हालांकि, जब XML दस्तावेज़ पदानुक्रम का मूल तत्व ‘svg’ तत्व होता है, जैसे कि एक स्टैंड‑अलोन SVG फ़ाइल (अर्थात, MIME प्रकार "image/svg+xml" वाली फ़ाइल) को देखना, तब `SVGDocument` ऑब्जेक्ट वास्तव में मौजूद रहेगा; इस स्थिति में, `SVGDocument` ऑब्जेक्ट दस्तावेज़ ऑब्जेक्ट मॉडल पदानुक्रम का मूल ऑब्जेक्ट होगा।

```java
public class SVGDocument : Document, IDocumentCSS
```
