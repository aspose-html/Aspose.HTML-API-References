## ISVGAnimatedPoints interface

SVGAnimatedPoints इंटरफ़ेस उन तत्वों का समर्थन करता है जिनमें ‘points’ एट्रिब्यूट होता है जो निर्देशांक मानों की सूची रखता है और जो उस एट्रिब्यूट को एनीमेट करने की क्षमता प्रदान करता है। अतिरिक्त रूप से, मूल तत्व पर XML DOM के माध्यम से (उदाहरण के लिए, getAttribute() मेथड कॉल का उपयोग करके) पहुँचा गया ‘points’ एट्रिब्यूट किए गए किसी भी परिवर्तन को प्रतिबिंबित करेगा।
