पैकेज फ़ॉर्म के भीतर वेब पेज घटक के रूप में उपयोगकर्ता इंटरैक्टिविटी के लिए जिम्मेदार कई ऑब्जेक्ट्स (तत्वों) तक पहुँच प्रदान करता है।

## क्लासेज़

| क्लास | विवरण |
| --- | --- |
| [ButtonElement](./buttonelement/) | ButtonElement वह रैपर दर्शाता है जो HTMLButtonElement से जुड़ा हुआ है। |
| [DataListElement](./datalistelement/) | DataListElement वह रैपर दर्शाता है जो HTMLDataListElement से जुड़ा हुआ है। |
| [FormEditor](./formeditor/) | यह क्लास [`HTMLFormElement`](../com.aspose.html/htmlformelement/) के ऊपर एडिटर का प्रतिनिधित्व करती है जो .net डेवलपर्स के लिए HTML फ़ॉर्म को संपादित करने का आसान तरीका बनाती है। |
| [FormElement](./formelement/) | फ़ॉर्म तत्वों के लिए बेस क्लास का प्रतिनिधित्व करता है। |
| [FormElement&lt;T&gt;](./formelement-1/) | यह [`FormElement`](../com.aspose.html.forms/formelement/) सामान्य फ़ील्ड का प्रतिनिधित्व करता है। |
| [FormSubmitter](./formsubmitter/) | यह क्लास निर्दिष्ट [`HTMLFormElement`](../com.aspose.html/htmlformelement/) को तैयार करने, फ़ॉर्म तत्व से मान एकत्र करने, उन्हें रिमोट सर्वर पर सबमिट करने और प्रतिक्रिया प्राप्त करने की अनुमति देती है। |
| [InputElement](./inputelement/) | InputElement वह रैपर दर्शाता है जो HTMLInputElement से जुड़ा हुआ है। |
| [OptionCollection](./optioncollection/) | OptionElements वह रैपर दर्शाता है जो IHTMLOptionsCollection से जुड़ा हुआ है। |
| [OptionElement](./optionelement/) | OptionElement वह रैपर दर्शाता है जो HTMLOptionElement से जुड़ा हुआ है। |
| [SelectElement](./selectelement/) | SelectElement वह रैपर दर्शाता है जो HTMLSelectElement से जुड़ा हुआ है। |
| [SubmissionResult](./submissionresult/) | यह क्लास सर्वर को फ़ॉर्म डेटा सबमिट करने के परिणाम का प्रतिनिधित्व करती है। |
| [TextAreaElement](./textareaelement/) | TextAreaElement वह रैपर दर्शाता है जो HTMLTextAreaElement से जुड़ा हुआ है। |
