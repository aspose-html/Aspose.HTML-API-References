| [InputElement](./inputelement/) | InputElement एक रैपर को दर्शाता है जो HTMLInputElement से जुड़ा होता है। |

| [SubmissionResult](./submissionresult/) | यह क्लास सर्वर को फ़ॉर्म डेटा सबमिट करने के परिणाम को दर्शाता है। |
| [TextAreaElement](./textareaelement/) | TextAreaElement एक रैपर को दर्शाता है जो HTMLTextAreaElement से जुड़ा होता है। |
