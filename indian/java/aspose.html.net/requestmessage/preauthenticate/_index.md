## RequestMessage.PreAuthenticate property

एक मान को प्राप्त करता है या सेट करता है जो दर्शाता है कि अनुरोध के साथ Authorization हेडर भेजना है या नहीं।

```java
public bool PreAuthenticate { get; set; }
```

### Property Value

`true` का उपयोग करके प्रमाणीकरण के बाद अनुरोधों के साथ HTTP Authorization हेडर भेजा जाता है; अन्यथा, `false`। डिफ़ॉल्ट `false` है।
