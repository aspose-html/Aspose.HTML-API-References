## क्लासेज़

| क्लास | विवरण |
| --- | --- |
| [Path2D](./path2d/) | Canvas 2D API का Path2D इंटरफ़ेस पाथ घोषित करने के लिए उपयोग किया जाता है, जिन्हें बाद में CanvasRenderingContext2D वस्तुओं पर उपयोग किया जाता है। CanvasRenderingContext2D इंटरफ़ेस की पाथ मेथड्स भी इस इंटरफ़ेस पर मौजूद हैं और आपको पाथ बनाने की अनुमति देती हैं जिन्हें आप आवश्यकतानुसार कैनवास पर बनाए रख सकते हैं और पुनः चला सकते हैं। |
## इंटरफ़ेस

| इंटरफ़ेस | विवरण |
| --- | --- |
| [ICanvasDrawingStyles](./icanvasdrawingstyles/) | ICanvasDrawingStyles इंटरफ़ेस मेथड्स और प्रॉपर्टीज़ प्रदान करता है जो नियंत्रित करती हैं कि रेखाएँ कैसे खींची जाती हैं और पाठ कैसे व्यवस्थित होता है। |
| [ICanvasGradient](./icanvasgradient/) | एक ग्रेडिएंट का वर्णन करने वाली अपारदर्शी वस्तु को दर्शाता है। |
| [ICanvasPathMethods](./icanvaspathmethods/) | ICanvasPathMethods इंटरफ़ेस वस्तुओं के पाथ को संशोधित करने के लिए उपयोग किया जाता है। |
| [ICanvasPattern](./icanvaspattern/) | एक छवि, कैनवास या वीडियो पर आधारित पैटर्न का वर्णन करने वाली अपारदर्शी वस्तु को दर्शाता है। |
| [ICanvasRenderingContext2D](./icanvasrenderingcontext2d/) | ICanvasRenderingContext2D इंटरफ़ेस आयत, पाठ, छवियों और अन्य वस्तुओं को कैनवास तत्व पर ड्रॉ करने के लिए उपयोग किया जाता है। यह कैनवास तत्व की ड्रॉइंग सतह के लिए 2D रेंडरिंग कॉन्टेक्स्ट प्रदान करता है। |
| [IImageData](./iimagedata/) | दिए गए Uint8ClampedArray और उसकी छवि के आकार से एक ImageData वस्तु बनाता है। यदि कोई एरे नहीं दिया गया, तो यह काली आयत की छवि बनाता है। |
| [ITextMetrics](./itextmetrics/) | कैनवास में पाठ का आयाम दर्शाता है। |
