## FillText(String, double, double, double) {#filltext_1}

दिए गए (x,y) स्थिति पर दिया गया टेक्स्ट ड्रॉ (भरे) करता है।

```java
public void FillText(String text, double x, double y, double maxWidth)
```

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| पाठ | String | वर्तमान फ़ॉन्ट, textAlign, textBaseline, और direction मानों का उपयोग करके ड्रॉ किया जाने वाला पाठ। |
| x | Double | पाठ की प्रारंभ बिंदु के लिए x अक्ष का निर्देशांक। |
| y | Double | पाठ की प्रारंभ बिंदु के लिए y अक्ष का निर्देशांक। |
| maxWidth | Double | ड्रॉ करने की अधिकतम चौड़ाई। यदि निर्दिष्ट की गई है, और स्ट्रिंग की गणना इस चौड़ाई से अधिक होती है, तो फ़ॉन्ट को अधिक क्षैतिज रूप से संकुचित फ़ॉन्ट (यदि उपलब्ध हो) या वर्तमान फ़ॉन्ट को क्षैतिज रूप से स्केल करके एक अधिक पठनीय फ़ॉन्ट या छोटे फ़ॉन्ट में समायोजित किया जाता है। |
