## FillText(String, double, double, double) {#filltext_1}

दिए गए (x,y) स्थिति पर एक निर्दिष्ट पाठ को ड्रॉ (भर) करता है।

```java
public void FillText(String text, double x, double y, double maxWidth)
```

| Parameter | Type | विवरण |
| --- | --- | --- |
| पाठ | String | वर्तमान फ़ॉन्ट, textAlign, textBaseline, और direction मानों का उपयोग करके ड्रॉ करने के लिए पाठ। |
| x | Double | पाठ प्रारंभ बिंदु के निर्देशांक का x अक्ष। |
| y | Double | पाठ प्रारंभ बिंदु के निर्देशांक का y अक्ष। |
| maxWidth | Double | ड्रॉ करने की अधिकतम चौड़ाई। यदि निर्दिष्ट की गई है और स्ट्रिंग की गणना इस चौड़ाई से अधिक होती है, तो फ़ॉन्ट को अधिक क्षैतिज रूप से संकुचित फ़ॉन्ट (यदि उपलब्ध हो या यदि वर्तमान फ़ॉन्ट को क्षैतिज रूप से स्केल करके एक उचित पठनीय फ़ॉन्ट निर्मित किया जा सकता है) या छोटे फ़ॉन्ट का उपयोग करने के लिए समायोजित किया जाता है। |
