## ICanvasRenderingContext2D.ClearRect method

शुरुआती बिंदु (x, y) और आकार (width, height) द्वारा परिभाषित आयत में सभी पिक्सेल को पारदर्शी काले रंग में सेट करता है, जिससे पहले से ड्रॉ किया गया कोई भी कंटेंट मिट जाता है।

```java
public void ClearRect(double x, double y, double w, double h)
```

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| x | Double | आयत के प्रारंभिक बिंदु के लिए निर्देशांक का x अक्ष। |
| y | Double | आयत के प्रारंभिक बिंदु के लिए निर्देशांक का y अक्ष। |
| w | Double | आयत की चौड़ाई। |
| h | Double | आयत की ऊँचाई। |
