## Arc(double, double, double, double, double) {#arc}

पथ में एक चाप जोड़ता है जो (x, y) स्थित पर केंद्रित है, त्रिज्या r के साथ, startAngle से शुरू होकर endAngle पर समाप्त होता है, और दिए गए दिशा में प्रतिक्लॉकवाइज़ (डिफ़ॉल्ट रूप से क्लॉकवाइज़) चलता है।

```java
public void Arc(double x, double y, double radius, double startAngle, double endAngle)
```

| Parameter | Type | विवरण |
| --- | --- | --- |
| x | Double | वक्र के केंद्र का x‑निर्देशांक। |
| y | Double | वक्र के केंद्र का y‑निर्देशांक। |
| त्रिज्या | Double | वक्र की त्रिज्या। |
| startAngle | Double | वक्र के शुरू होने का कोण, सकारात्मक x‑अक्ष से घड़ी की दिशा में मापा गया और रेडियन में व्यक्त किया गया। |
| endAngle | Double | वक्र के समाप्त होने का कोण, सकारात्मक x‑अक्ष से घड़ी की दिशा में मापा गया और रेडियन में व्यक्त किया गया। |

## Arc(double, double, double, double, double, bool) {#arc_1}

पथ में एक चाप जोड़ता है जो (x, y) स्थित पर केंद्रित है, त्रिज्या r के साथ, startAngle से शुरू होकर endAngle पर समाप्त होता है, और दिए गए दिशा में प्रतिक्लॉकवाइज़ (डिफ़ॉल्ट रूप से क्लॉकवाइज़) चलता है।

```java
public void Arc(double x, double y, double radius, double startAngle, double endAngle, 
    bool counterclockwise)
```

| Parameter | Type | विवरण |
| --- | --- | --- |
| x | Double | वक्र के केंद्र का x‑निर्देशांक। |
| y | Double | वक्र के केंद्र का y‑निर्देशांक। |
| त्रिज्या | Double | वक्र की त्रिज्या। |
| startAngle | Double | वक्र के शुरू होने का कोण, सकारात्मक x‑अक्ष से घड़ी की दिशा में मापा गया और रेडियन में व्यक्त किया गया। |
| endAngle | Double | वक्र के समाप्त होने का कोण, सकारात्मक x‑अक्ष से घड़ी की दिशा में मापा गया और रेडियन में व्यक्त किया गया। |
