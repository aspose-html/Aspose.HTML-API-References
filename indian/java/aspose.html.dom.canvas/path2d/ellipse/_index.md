## Ellipse(double, double, double, double, double, double, double) {#ellipse}

पथ में एक दीर्घवृत्त जोड़ता है जो (x, y) स्थिति पर केंद्रित है, radiusX और radiusY त्रिज्याओं के साथ, startAngle से शुरू होकर endAngle पर समाप्त होता है, और निर्दिष्ट दिशा में anticlockwise (डिफ़ॉल्ट रूप से clockwise) चलता है।

```java
public void Ellipse(double x, double y, double radiusX, double radiusY, double rotation, 
    double startAngle, double endAngle)
```

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| x | Double | एलिप्स के केंद्र के निर्देशांक का x-अक्ष। |
| y | Double | एलिप्स के केंद्र के निर्देशांक का y-अक्ष। |
| radiusX | Double | एलिप्स की प्रमुख-अक्ष त्रिज्या। |
| radiusY | Double | एलिप्स की गौण-अक्ष त्रिज्या। |
| rotation | Double | इस एलिप्स का घूर्णन, रेडियन में व्यक्त। |
| startAngle | Double | शुरुआती बिंदु, x-अक्ष से मापा गया, जिससे यह बनाया जाएगा, रेडियन में व्यक्त। |
| endAngle | Double | अंतिम एलिप्स का कोण, जिससे यह बनाया जाएगा, रेडियन में व्यक्त। |

## Ellipse(double, double, double, double, double, double, double, bool) {#ellipse_1}

पथ में एक दीर्घवृत्त जोड़ता है जो (x, y) स्थिति पर केंद्रित है, radiusX और radiusY त्रिज्याओं के साथ, startAngle से शुरू होकर endAngle पर समाप्त होता है, और निर्दिष्ट दिशा में anticlockwise (डिफ़ॉल्ट रूप से clockwise) चलता है।

```java
public void Ellipse(double x, double y, double radiusX, double radiusY, double rotation, 
    double startAngle, double endAngle, bool anticlockwise)
```

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| x | Double | एलिप्स के केंद्र के निर्देशांक का x-अक्ष। |
| y | Double | एलिप्स के केंद्र के निर्देशांक का y-अक्ष। |
| radiusX | Double | एलिप्स की प्रमुख-अक्ष त्रिज्या। |
| radiusY | Double | एलिप्स की गौण-अक्ष त्रिज्या। |
| rotation | Double | इस एलिप्स का घूर्णन, रेडियन में व्यक्त। |
| startAngle | Double | शुरुआती बिंदु, x-अक्ष से मापा गया, जिससे यह बनाया जाएगा, रेडियन में व्यक्त। |
| endAngle | Double | अंतिम एलिप्स का कोण, जिससे यह बनाया जाएगा, रेडियन में व्यक्त। |
| anticlockwise | Boolean | एक वैकल्पिक बूलियन जो, यदि सत्य हो, तो एलिप्स को विपरीत घड़ी दिशा (काउंटर-क्लॉकवाइज़) में बनाता है, अन्यथा घड़ी दिशा में। |
