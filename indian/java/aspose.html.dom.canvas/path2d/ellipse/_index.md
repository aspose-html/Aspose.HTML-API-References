## Ellipse(double, double, double, double, double, double, double) {#ellipse}

पथ में एक दीर्घवृत्त जोड़ता है जो (x, y) स्थित पर केंद्रित है, radiusX और radiusY त्रिज्याओं के साथ, startAngle से शुरू होकर endAngle पर समाप्त होता है, और दिए गए दिशा में प्रतिक्लॉकवाइज़ (डिफ़ॉल्ट रूप से क्लॉकवाइज़) चलता है।

```java
public void Ellipse(double x, double y, double radiusX, double radiusY, double rotation, 
    double startAngle, double endAngle)
```

| Parameter | Type | विवरण |
| --- | --- | --- |
| x | Double | एलिप्स के केंद्र के लिए निर्देशांक का x अक्ष। |
| y | Double | एलिप्स के केंद्र के लिए निर्देशांक का y अक्ष। |
| radiusX | Double | एलिप्स की प्रमुख-अक्ष त्रिज्या। |
| radiusY | Double | एलिप्स की लघु-अक्ष त्रिज्या। |
| rotation | Double | इस एलिप्स का घूर्णन, रेडियन में व्यक्त किया गया। |
| startAngle | Double | शुरुआती बिंदु, x अक्ष से मापा गया, जिससे यह बनाया जाएगा, रेडियन में व्यक्त किया गया। |
| endAngle | Double | एलिप्स के अंत का कोण, जिससे यह बनाया जाएगा, रेडियन में व्यक्त किया गया। |

## Ellipse(double, double, double, double, double, double, double, bool) {#ellipse_1}

पथ में एक दीर्घवृत्त जोड़ता है जो (x, y) स्थित पर केंद्रित है, radiusX और radiusY त्रिज्याओं के साथ, startAngle से शुरू होकर endAngle पर समाप्त होता है, और दिए गए दिशा में प्रतिक्लॉकवाइज़ (डिफ़ॉल्ट रूप से क्लॉकवाइज़) चलता है।

```java
public void Ellipse(double x, double y, double radiusX, double radiusY, double rotation, 
    double startAngle, double endAngle, bool anticlockwise)
```

| Parameter | Type | विवरण |
| --- | --- | --- |
| x | Double | एलिप्स के केंद्र के लिए निर्देशांक का x अक्ष। |
| y | Double | एलिप्स के केंद्र के लिए निर्देशांक का y अक्ष। |
| radiusX | Double | एलिप्स की प्रमुख-अक्ष त्रिज्या। |
| radiusY | Double | एलिप्स की लघु-अक्ष त्रिज्या। |
| rotation | Double | इस एलिप्स का घूर्णन, रेडियन में व्यक्त किया गया। |
| startAngle | Double | शुरुआती बिंदु, x अक्ष से मापा गया, जिससे यह बनाया जाएगा, रेडियन में व्यक्त किया गया। |
| endAngle | Double | एलिप्स के अंत का कोण, जिससे यह बनाया जाएगा, रेडियन में व्यक्त किया गया। |
| anticlockwise | Boolean | एक वैकल्पिक बूलियन जो, यदि सत्य है, तो एलिप्स को एंटी‑क्लॉकवाइज़ (विपरीत दिशा) में बनाता है, अन्यथा क्लॉकवाइज़ दिशा में। |
