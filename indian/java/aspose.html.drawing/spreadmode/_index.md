## SpreadMode enumeration

जब टेक्सचर या ग्रेडिएंट भरे जाने वाले क्षेत्र से छोटा हो तो उसे कैसे टाइल किया जाता है, यह निर्दिष्ट करता है।

```java
public enum SpreadMode
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| Tile | `0` | टेक्सचर या ग्रेडिएंट टाइल किया गया है। |
| TileFlipX | `1` | टेक्सचर या ग्रेडिएंट टाइल किया गया है और क्षैतिज रूप से उलटा है। |
| TileFlipY | `2` | टेक्सचर या ग्रेडिएंट टाइल किया गया है और लंबवत रूप से उलटा है। |
| TileFlipXY | `3` | टेक्सचर या ग्रेडिएंट टाइल किया गया है और क्षैतिज तथा लंबवत दोनों रूप से उलटा है। |
| Clamp | `4` | टेक्सचर या ग्रेडिएंट को किनारे पर क्लैंप किया गया है। |
