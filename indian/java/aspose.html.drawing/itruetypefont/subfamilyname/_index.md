## ITrueTypeFont.SubFamilyName property

Font Subfamily name एक समूह में समान Font Family name वाले फ़ॉन्ट को अलग करता है। यह शैली (italic, oblique) और वजन (light, bold, black, आदि) को दर्शाने के लिए माना जाता है। एक फ़ॉन्ट जिसमें वजन या शैली में कोई विशेष अंतर नहीं है (उदा. medium weight, न italic और fsSelection बिट 6 सेट), उसे इस स्थिति में String "Regular" संग्रहीत होना चाहिए।

```java
public String SubFamilyName { get; }
```
