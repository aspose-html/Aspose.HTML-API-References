## ITrueTypeFont.SubFamilyName property

फ़ॉन्ट सबफ़ैमिली नाम समान फ़ॉन्ट फ़ैमिली नाम वाले समूह में फ़ॉन्ट को अलग करता है। इसे शैली (इटैलिक, ऑब्लिक) और वजन (लाइट, बोल्ड, ब्लैक, आदि) को संबोधित करने के रूप में माना जाता है। वजन या शैली में कोई विशेष अंतर न रखने वाला फ़ॉन्ट (उदाहरण के लिए मध्यम वजन, इटैलिक नहीं और fsSelection बिट 6 सेट) इस स्थिति में स्ट्रिंग "Regular" संग्रहीत होना चाहिए।

```java
public String SubFamilyName { get; }
```
