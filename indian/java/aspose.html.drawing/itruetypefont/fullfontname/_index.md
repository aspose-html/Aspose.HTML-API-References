## ITrueTypeFont.FullFontName property

यह "FamilyName" और "SubFamilyName" का संयोजन होना चाहिए। अपवाद: यदि फ़ॉन्ट "SubFamilyName" में दर्शाए अनुसार "Regular" है, तो केवल "FamilyName" में मौजूद फ़ैमिली नाम का उपयोग करें। ऊपर दी गई Full फ़ॉन्ट नाम की परिभाषा में एक अपवाद Microsoft प्लेटफ़ॉर्म स्ट्रिंग्स के लिए CFF OpenType फ़ॉन्ट्स में है: इस मामले में, Full फ़ॉन्ट नाम स्ट्रिंग को CFF Name INDEX में PostScript FontName के समान होना चाहिए।

```java
public String FullFontName { get; }
```
