## ICSSKeyframesRule.FindRule method

findRule मेथड पास किए गए कुंजी से मेल खाने वाला नियम लौटाता है। यदि ऐसा कोई नियम नहीं है, तो null मान लौटाया जाता है।

```java
public ICSSKeyframeRule FindRule(String key)
```

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| की | String | वह कुंजी जो खोजे जाने वाले नियम का वर्णन करती है। कुंजी को 0 और 1 के बीच के संख्या में परिवर्तित होना चाहिए, अन्यथा नियम को अनदेखा किया जाता है। |

### रिटर्न वैल्यू

निर्दिष्ट keyframe चयनकर्ता से मेल खाने वाला अंतिम घोषित [`CSSKeyframeRule`](../../icsskeyframerule/) लौटाता है। यदि कोई मेल खाने वाला नियम नहीं है, तो मेथड कुछ नहीं करता।
