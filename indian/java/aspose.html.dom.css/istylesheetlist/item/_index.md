## IStyleSheetList indexer

item(index) मेथड को संग्रह में indexवें [`CSS style sheet`](../../icssstylesheet/) को लौटाना चाहिए। यदि संग्रह में indexवाँ ऑब्जेक्ट नहीं है, तो मेथड को null लौटाना चाहिए।

```java
public ICSSStyleSheet this[int index] { get; }
```

### रिटर्न वैल्यू

एक [`CSSStyleSheet`](../../icssstylesheet/) ऑब्जेक्ट, या यदि इस इंडेक्स के लिए कोई नहीं है तो null।

### Property Value

एक पूर्णांक जो संग्रह में लौटाए जाने वाले आइटम का इंडेक्स दर्शाता है।
