## ICSSKeyframeRule.Style property

पढ़ने-केवल CSSKeyframeRule.style प्रॉपर्टी वह [`CSSStyleDeclaration`](../../icssstyledeclaration/) इंटरफ़ेस है जो [`CSSKeyframeRule`](../) के घोषणा ब्लॉक के लिए है।

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

एक [`CSSStyleDeclaration`](../../icssstyledeclaration/) ऑब्जेक्ट, जिसमें निम्नलिखित प्रॉपर्टीज़ हैं:

computed flag - Unset. declarations - नियम में घोषित घोषणाएँ, वे क्रम में जिनमें निर्दिष्ट की गई थीं, शॉर्टहैंड प्रॉपर्टीज़ को लॉन्गहैंड में विस्तारित किया गया। parent CSS rule - वह संदर्भ ऑब्जेक्ट, जो इस.owner का उपनाम है। node - Null.
