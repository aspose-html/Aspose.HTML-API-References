## IMediaList indexer

item(index) मेथड को निर्दिष्ट इंडेक्स द्वारा दी गई मीडिया क्वेरी का सीरियलाइज़ेशन लौटाना चाहिए, या यदि इंडेक्स मीडिया क्वेरी की कुल संख्या से बड़ा या बराबर है तो null लौटाना चाहिए।

```java
public String this[int index] { get; }
```

### रिटर्न वैल्यू

एक स्ट्रिंग लौटाता है जो मीडिया क्वेरी को टेक्स्ट के रूप में दर्शाता है, जब मीडिया क्वेरी का इंडेक्स मान [`MediaList`](../) के भीतर दिया गया हो।

### Property Value

एक पूर्णांक जो संग्रह में लौटाए जाने वाले आइटम का इंडेक्स दर्शाता है।
