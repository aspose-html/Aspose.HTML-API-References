## IMediaList indexer

item(index) मेथड को इंडेक्स द्वारा निर्दिष्ट मीडिया क्वेरी का सीरियलाइज़ेशन लौटाना चाहिए, या यदि इंडेक्स मीडिया क्वेरी की संख्या से बड़ा या बराबर है तो null लौटाना चाहिए।

```java
public String this[int index] { get; }
```

### रिटर्न वैल्यू

एक String लौटाता है जो मीडिया क्वेरी को टेक्स्ट के रूप में दर्शाता है, मीडिया क्वेरी के इंडेक्स मान को [`MediaList`](../) के भीतर दिया गया है।

### Property Value

एक पूर्णांक जो संग्रह में लौटाए जाने वाले आइटम का इंडेक्स दर्शाता है।
