## IMediaList.MediaText property

एक Stringifier जो MediaList को टेक्स्ट के रूप में दर्शाने वाला DOMString लौटाता है, और आपको नया MediaList सेट करने की भी अनुमति देता है।

```java
public String MediaText { get; }
```

### Property Value

मीडिया सूची का पार्स करने योग्य टेक्स्टुअल प्रतिनिधित्व। यह मीडिया की कॉमा-सेपरेटेड सूची है।

### अपवाद

| अपवाद | शर्त |
| --- | --- |
| DOMException | SYNTAX_ERR: यदि निर्दिष्ट स्ट्रिंग मान में सिंटैक्स त्रुटि है और वह पार्स नहीं हो सकता तो उत्पन्न होता है। NO_MODIFICATION_ALLOWED_ERR: यदि यह मीडिया सूची केवल-पढ़ने योग्य है तो उत्पन्न होता है। |
