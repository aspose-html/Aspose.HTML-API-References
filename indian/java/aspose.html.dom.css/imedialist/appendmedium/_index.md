## IMediaList.AppendMedium method

```java
public void AppendMedium(String newMedium)
```

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| newMedium | String | जोड़ने के लिए नया माध्यम। |

| अपवाद | शर्त |
| --- | --- |
