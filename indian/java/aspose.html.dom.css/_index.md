DOM Level 2 Style Specification के लिए इंटरफ़ेस प्रदान करता है। Cascading Style Sheets (CSS) एक स्टाइल शीट भाषा है जो लेखकों और उपयोगकर्ताओं को संरचित दस्तावेज़ों (जैसे HTML दस्तावेज़ और XML एप्लिकेशन) में शैली (जैसे फ़ॉन्ट और स्पेसिंग) जोड़ने की अनुमति देती है। यह मीडिया‑विशिष्ट स्टाइल शीट्स का समर्थन करता है ताकि लेखक अपने दस्तावेज़ों की प्रस्तुति को विज़ुअल ब्राउज़र, ऑरल डिवाइस, प्रिंटर, ब्रेल डिवाइस, हैंडहेल्ड डिवाइस आदि के अनुसार अनुकूलित कर सकें। यह कंटेंट पोजिशनिंग, टेबल लेआउट, अंतर्राष्ट्रीयकरण के लिए सुविधाएँ और यूज़र इंटरफ़ेस से संबंधित कुछ प्रॉपर्टीज़ का भी समर्थन करता है। दस्तावेज़ों की प्रस्तुति शैली को उनकी सामग्री से अलग करके, CSS वेब लेखन और साइट रखरखाव को सरल बनाता है।
