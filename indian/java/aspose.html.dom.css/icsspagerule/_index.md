## ICSSPageRule interface

CSSPageRule इंटरफ़ेस CSS स्टाइल शीट के भीतर @page नियम का प्रतिनिधित्व करता है। @page नियम पेज्ड मीडिया के लिए पेज बॉक्स के आयाम, अभिविन्यास, मार्जिन आदि को निर्दिष्ट करने के लिए उपयोग किया जाता है।

```java
public interface ICSSPageRule : ICSSRule
```
