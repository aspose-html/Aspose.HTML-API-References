## ICSSPageRule.Style property

[`CSSPageRule`](../) इंटरफ़ेस की style पढ़ने-केवल प्रॉपर्टी एक [`CSSStyleDeclaration`](../../icssstyledeclaration/) ऑब्जेक्ट लौटाती है। यह एक CSS घोषणा ब्लॉक का प्रतिनिधित्व करता है, और शैली जानकारी तथा विभिन्न शैली-संबंधी मेथड और प्रॉपर्टी उजागर करता है।

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

एक [`CSSStyleDeclaration`](../../icssstyledeclaration/) ऑब्जेक्ट जो एक CSS घोषणा ब्लॉक का प्रतिनिधित्व करता है।
