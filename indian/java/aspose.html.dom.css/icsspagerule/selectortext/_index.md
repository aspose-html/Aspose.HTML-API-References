## ICSSPageRule.SelectorText property

```java
public String SelectorText { get; set; }
```

### Property Value

selectorText एट्रिब्यूट, प्राप्त करने पर, संबंधित CSS पेज चयनकर्ताओं की सूची को क्रमबद्ध करने के परिणाम को लौटाना चाहिए।
