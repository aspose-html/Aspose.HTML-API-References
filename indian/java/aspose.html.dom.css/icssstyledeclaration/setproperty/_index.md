## SetProperty(String, String) {#setproperty}

CSSStyleDeclaration.setProperty() मेथड इंटरफ़ेस इस घोषणा ब्लॉक में डिफ़ॉल्ट प्राथमिकता के साथ प्रॉपर्टी वैल्यू सेट करने के लिए उपयोग किया जाता है। डिफ़ॉल्ट प्राथमिकता "important" नहीं है, अर्थात् String.Empty

```java
public void SetProperty(String propertyName, String value)
```

| Parameter | Type | विवरण |
| --- | --- | --- |
| propertyName | String | एक String जो संशोधित की जाने वाली CSS प्रॉपर्टी नाम (हाइफ़न केस) को दर्शाता है। |
| मान | String | एक String जिसमें नया प्रॉपर्टी मान होता है। यदि निर्दिष्ट नहीं किया गया तो इसे खाली String माना जाता है। |

## SetProperty(String, String, String) {#setproperty_1}

CSSStyleDeclaration.setProperty() मेथड इंटरफ़ेस इस घोषणा ब्लॉक में डिफ़ॉल्ट प्राथमिकता के साथ प्रॉपर्टी वैल्यू सेट करने के लिए उपयोग किया जाता है। डिफ़ॉल्ट प्राथमिकता "important" नहीं है, अर्थात् String.Empty

```java
public void SetProperty(String propertyName, String value, String priority)
```

| Parameter | Type | विवरण |
| --- | --- | --- |
| propertyName | String | एक String जो संशोधित की जाने वाली CSS प्रॉपर्टी नाम (हाइफ़न केस) को दर्शाता है। |
| मान | String | एक String जिसमें नया प्रॉपर्टी मान होता है। यदि निर्दिष्ट नहीं किया गया तो इसे खाली String माना जाता है। |
| priority | String | एक String जो "important" CSS प्राथमिकता सेट करने की अनुमति देता है। यदि निर्दिष्ट नहीं किया गया तो इसे खाली String माना जाता है। निम्नलिखित मान स्वीकार किए जाते हैं: String मान "important", कीवर्ड undefined या खाली String मान ""। |
