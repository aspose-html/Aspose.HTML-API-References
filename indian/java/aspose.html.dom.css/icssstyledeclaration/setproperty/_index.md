## SetProperty(String, String) {#setproperty}

CSSStyleDeclaration.setProperty() मेथड इंटरफ़ेस इस घोषणा ब्लॉक के भीतर डिफ़ॉल्ट प्राथमिकता के साथ प्रॉपर्टी मान सेट करने के लिए उपयोग किया जाता है। डिफ़ॉल्ट प्राथमिकता "important" नहीं है, अर्थात् String.Empty

```java
public void SetProperty(String propertyName, String value)
```

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| propertyName | String | एक स्ट्रिंग जो संशोधित किए जाने वाले CSS प्रॉपर्टी नाम (हाइफ़न केस) को दर्शाती है। |
| मान | String | एक स्ट्रिंग जिसमें नया प्रॉपर्टी मान हो। यदि निर्दिष्ट नहीं किया गया है, तो इसे खाली स्ट्रिंग माना जाता है। |

## SetProperty(String, String, String) {#setproperty_1}

CSSStyleDeclaration.setProperty() मेथड इंटरफ़ेस इस घोषणा ब्लॉक के भीतर डिफ़ॉल्ट प्राथमिकता के साथ प्रॉपर्टी मान सेट करने के लिए उपयोग किया जाता है। डिफ़ॉल्ट प्राथमिकता "important" नहीं है, अर्थात् String.Empty

```java
public void SetProperty(String propertyName, String value, String priority)
```

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| propertyName | String | एक स्ट्रिंग जो संशोधित किए जाने वाले CSS प्रॉपर्टी नाम (हाइफ़न केस) को दर्शाती है। |
| मान | String | एक स्ट्रिंग जिसमें नया प्रॉपर्टी मान हो। यदि निर्दिष्ट नहीं किया गया है, तो इसे खाली स्ट्रिंग माना जाता है। |
| प्राथमिकता | String | एक स्ट्रिंग जो "important" CSS प्राथमिकता को सेट करने की अनुमति देती है। यदि निर्दिष्ट नहीं किया गया है, तो इसे खाली स्ट्रिंग माना जाता है। निम्नलिखित मान स्वीकार किए जाते हैं: स्ट्रिंग मान "important", कीवर्ड undefined या खाली स्ट्रिंग मान ""। |
