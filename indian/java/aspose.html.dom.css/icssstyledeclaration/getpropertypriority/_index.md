## ICSSStyleDeclaration.GetPropertyPriority method

यदि इस घोषणा ब्लॉक में प्रॉपर्टी स्पष्ट रूप से सेट की गई हो, तो CSS प्रॉपर्टी की प्राथमिकता (जैसे "important" क्वालिफायर) को पुनः प्राप्त करने के लिए उपयोग किया जाता है।

```java
public String GetPropertyPriority(String propertyName)
```

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| propertyName | String | property एक DOMString है जो जांचे जाने वाले प्रॉपर्टी नाम को दर्शाता है। |

### रिटर्न वैल्यू

priority एक DOMString है जो प्राथमिकता (जैसे "important") को दर्शाता है यदि वह मौजूद है। यदि कोई प्राथमिकता नहीं है, तो खाली String लौटाता है।
