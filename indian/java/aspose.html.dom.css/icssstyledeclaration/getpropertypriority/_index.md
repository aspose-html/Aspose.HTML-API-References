## ICSSStyleDeclaration.GetPropertyPriority method

यदि इस घोषणा ब्लॉक में कोई CSS प्रॉपर्टी स्पष्ट रूप से सेट की गई है तो उसकी प्राथमिकता (जैसे "important" क्वालिफायर) को पुनः प्राप्त करने के लिए उपयोग किया जाता है।

```java
public String GetPropertyPriority(String propertyName)
```

| Parameter | Type | विवरण |
| --- | --- | --- |
| propertyName | String | property एक DOMString है जो जांचे जाने वाले प्रॉपर्टी नाम का प्रतिनिधित्व करता है। |

### रिटर्न वैल्यू

priority एक DOMString है जो प्रायोरिटी (उदाहरण के लिए "important") का प्रतिनिधित्व करता है यदि वह मौजूद है। यदि नहीं है, तो खाली String लौटाता है।
