## ICSSStyleDeclaration.ParentRule property

CSSStyleDeclaration.parentRule पढ़ने-के-लिए-केवल प्रॉपर्टी एक CSSRule लौटाती है जो इस शैली ब्लॉक का पैरेंट है, उदाहरण के लिए एक [`CSSStyleRule`](../../icssstylerule/) जो CSS चयनकर्ता के लिए शैली को दर्शाता है।

```java
public ICSSRule ParentRule { get; }
```

### Property Value

यह CSS नियम जो इस घोषणा ब्लॉक को सम्मिलित करता है या null यदि यह [`CSSStyleDeclaration`](../) किसी [`CSSRule`](../../icssrule/) से जुड़ा नहीं है।
