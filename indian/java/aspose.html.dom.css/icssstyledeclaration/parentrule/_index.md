## ICSSStyleDeclaration.ParentRule property

CSSStyleDeclaration.parentRule पढ़ने‑के‑लिए‑केवल प्रॉपर्टी एक CSSRule लौटाती है जो इस शैली ब्लॉक का पैरेंट है, उदाहरण के लिए एक [`CSSStyleRule`](../../icssstylerule/) जो CSS चयनकर्ता के लिए शैली का प्रतिनिधित्व करता है।

```java
public ICSSRule ParentRule { get; }
```

### Property Value

CSS नियम जो इस घोषणा ब्लॉक को शामिल करता है या null यदि यह [`CSSStyleDeclaration`](../) किसी [`CSSRule`](../../icssrule/) से जुड़ा नहीं है।
