## ICSSStyleDeclaration.GetPropertyValue method

CSSStyleDeclaration.getPropertyValue() मेथड इंटरफ़ेस एक स्ट्रिंग लौटाता है जिसमें निर्दिष्ट CSS प्रॉपर्टी का मान होता है।

```java
public String GetPropertyValue(String propertyName)
```

| Parameter | Type | विवरण |
| --- | --- | --- |
| propertyName | String | propertyName एक String है जो जांचे जाने वाले प्रॉपर्टी नाम (हाइफ़न केस) का प्रतिनिधित्व करता है। |

### रिटर्न वैल्यू

value एक String है जिसमें प्रॉपर्टी का वैल्यू शामिल है। यदि सेट नहीं है, तो खाली String लौटाता है।
