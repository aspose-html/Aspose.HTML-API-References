## ICSSStyleDeclaration indexer

इस घोषणा ब्लॉक में स्पष्ट रूप से सेट की गई प्रॉपर्टियों को प्राप्त करने के लिए उपयोग किया जाता है। इस विधि से प्राप्त प्रॉपर्टियों का क्रम आवश्यक नहीं है कि वह सेट किए जाने के क्रम के समान हो। इस विधि का उपयोग इस घोषणा ब्लॉक की सभी प्रॉपर्टियों पर पुनरावृति करने के लिए किया जा सकता है।

```java
public String this[int index] { get; }
```

### रिटर्न वैल्यू

propertyName एक स्ट्रिंग है जो निर्दिष्ट इंडेक्स पर CSS प्रॉपर्टी का नाम दर्शाती है।

### Property Value

index वह इंडेक्स है जिसे प्राप्त किया जाना है। यह इंडेक्स शून्य-आधारित है।
