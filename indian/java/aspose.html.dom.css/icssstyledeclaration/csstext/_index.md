## ICSSStyleDeclaration.CSSText property

घोषणा ब्लॉक का पार्सेबल टेक्स्टुअल प्रतिनिधित्व (आसपास के कर्ली ब्रेसेस को छोड़कर)। इस एट्रिब्यूट को सेट करने से नया वैल्यू पार्स होगा और घोषणा ब्लॉक में सभी प्रॉपर्टीज़ रीसेट हो जाएँगी, जिसमें प्रॉपर्टीज़ का हटाना या जोड़ना शामिल है।

```java
public String CSSText { get; set; }
```

### Property Value

इस एट्रिब्यूट को सेट करने से इनलाइन स्टाइल बदल जाता है। यदि आप एक कंप्यूटेड घोषणा ब्लॉक का टेक्स्ट प्रतिनिधित्व चाहते हैं, तो आप इसे JSON.Stringify() से प्राप्त कर सकते हैं।
