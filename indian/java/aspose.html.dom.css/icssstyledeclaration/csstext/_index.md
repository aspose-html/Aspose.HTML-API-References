## ICSSStyleDeclaration.CSSText property

घोषणा ब्लॉक का पार्सेबल टेक्स्टुअल प्रतिनिधित्व (आसपास के कर्ली ब्रेसेस को छोड़कर)। इस एट्रिब्यूट को सेट करने से नया मान पार्स होगा और घोषणा ब्लॉक में सभी प्रॉपर्टी रीसेट हो जाएँगी, जिसमें प्रॉपर्टी हटाना या जोड़ना शामिल है।

```java
public String CSSText { get; set; }
```

### Property Value

इस एट्रिब्यूट को सेट करने से इनलाइन स्टाइल बदलता है। यदि आप एक कंप्यूटेड घोषणा ब्लॉक का टेक्स्ट प्रतिनिधित्व चाहते हैं, तो आप इसे JSON.Stringify() के साथ प्राप्त कर सकते हैं।
