## ICSSStyleDeclaration.RemoveProperty method

CSSStyleDeclaration.removeProperty() मेथड इंटरफ़ेस एक CSS स्टाइल घोषणा ऑब्जेक्ट से प्रॉपर्टी को हटाता है।

```java
public String RemoveProperty(String propertyName)
```

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| propertyName | String | propertyName एक स्ट्रिंग है जो हटाए जाने वाले प्रॉपर्टी नाम को दर्शाती है। ध्यान दें कि बहु-शब्दीय प्रॉपर्टी नाम हाइफ़न के साथ होते हैं और कैमेल केस में नहीं होते। |

### रिटर्न वैल्यू

oldValue एक DOMString है जो CSS प्रॉपर्टी के हटाए जाने से पहले के मान के बराबर है।

### अपवाद

| अपवाद | शर्त |
| --- | --- |
| DOMException | NO_MODIFICATION_ALLOWED_ERR: यदि प्रॉपर्टी या घोषणा ब्लॉक केवल-पढ़ने योग्य है। |
