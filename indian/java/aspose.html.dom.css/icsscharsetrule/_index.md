## ICSSCharsetRule interface

CSSCharsetRule इंटरफ़ेस CSS स्टाइल शीट में एक @charset नियम का प्रतिनिधित्व करता है। एन्कोडिंग एट्रिब्यूट का मान DOM ऑब्जेक्ट्स में टेक्स्ट डेटा की एन्कोडिंग को प्रभावित नहीं करता; यह एन्कोडिंग हमेशा UTF-16 रहती है। स्टाइल शीट लोड होने के बाद, एन्कोडिंग एट्रिब्यूट का मान @charset नियम में पाए गए मान के बराबर होता है। यदि मूल दस्तावेज़ में कोई @charset नहीं था, तो कोई CSSCharsetRule नहीं बनाया जाता। एन्कोडिंग एट्रिब्यूट का मान स्टाइल शीट के सीरियलाइज़ेशन के दौरान उपयोग की जाने वाली एन्कोडिंग के संकेत के रूप में भी उपयोग किया जा सकता है।

```java
public interface ICSSCharsetRule : ICSSRule
```
