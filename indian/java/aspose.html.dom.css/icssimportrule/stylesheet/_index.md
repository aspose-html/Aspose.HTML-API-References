## ICSSImportRule.StyleSheet property

इस नियम द्वारा संदर्भित स्टाइल शीट, यदि यह लोड हो चुकी है। इस एट्रिब्यूट का मान null होगा यदि स्टाइल शीट अभी तक लोड नहीं हुई है या यदि इसे लोड नहीं किया जाएगा (उदाहरण के लिए यदि स्टाइल शीट किसी ऐसे मीडिया प्रकार के लिए है जो उपयोगकर्ता एजेंट द्वारा समर्थित नहीं है)।

```java
public ICSSStyleSheet StyleSheet { get; }
```

### Property Value

वापस करता है CSS Stylesheet जिसे @import एट-रूल द्वारा निर्दिष्ट किया गया है। यह एक [`CSSStyleSheet`](../../icssstylesheet/) ऑब्जेक्ट के रूप में होगा।
