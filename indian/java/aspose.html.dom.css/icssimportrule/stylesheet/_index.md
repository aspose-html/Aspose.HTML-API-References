## ICSSImportRule.StyleSheet property

इस नियम द्वारा संदर्भित स्टाइल शीट, यदि लोड हो चुकी है। इस एट्रिब्यूट का मान null होगा यदि स्टाइल शीट अभी तक लोड नहीं हुई है या लोड नहीं होगी (उदाहरण के लिए यदि स्टाइल शीट किसी ऐसे मीडिया प्रकार के लिए है जो उपयोगकर्ता एजेंट द्वारा समर्थित नहीं है)।

```java
public ICSSStyleSheet StyleSheet { get; }
```

### Property Value

यह @import एट-रूल द्वारा निर्दिष्ट CSS स्टाइलशीट को लौटाता है। यह एक [`CSSStyleSheet`](../../icssstylesheet/) ऑब्जेक्ट के रूप में होगा।
