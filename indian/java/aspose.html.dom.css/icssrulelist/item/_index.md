## ICSSRuleList indexer

method item() (http://www.w3.org/TR/DOM-Level-2-Style/css.html#CSS-CSSRuleList) द्वारा एक CSS नियम प्राप्त करने के लिए उपयोग किया जाता है। इस संग्रह में क्रम CSS शैली पत्रक में नियमों के क्रम को दर्शाता है। यदि index सूची में नियमों की संख्या के बराबर या अधिक है, तो यह null लौटाता है।

```java
public ICSSRule this[int index] { get; }
```

### रिटर्न वैल्यू

item(index) मेथड को संग्रह में indexवें CSSRule ऑब्जेक्ट को लौटाना चाहिए। यदि संग्रह में indexवाँ ऑब्जेक्ट मौजूद नहीं है, तो मेथड को null लौटाना चाहिए।

### Property Value

CSS नियमों के संग्रह में इंडेक्स।
