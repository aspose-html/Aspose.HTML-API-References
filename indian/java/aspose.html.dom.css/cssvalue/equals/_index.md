## CSSValue.Equals method

```java
public bool Equals(object obj)
```

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| obj | ऑब्जेक्ट | इस इंस्टेंस के साथ तुलना करने के लिए ऑब्जेक्ट। |
