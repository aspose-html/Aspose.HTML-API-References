## ICSSValueList indexer

यह मेथड एक CSSValue को क्रमिक इंडेक्स द्वारा प्राप्त करने के लिए उपयोग किया जाता है। इस संग्रह में क्रम CSS शैली गुण में मानों के क्रम का प्रतिनिधित्व करता है। यदि इंडेक्स सूची में मानों की संख्या से बड़ा या उसके बराबर है, तो यह null लौटाता है।

इसके अलावा देखें [CSSOM](https://www.w3.org/TR/2000/REC-DOM-Level-2-Style-20001113/css.html#CSS-CSSValueList)[#CSSValueList](https://www.w3.org/TR/2000/REC-DOM-Level-2-Style-20001113/css.html#CSS-CSSValueList).

```java
public CSSValue this[int index] { get; }
```

### रिटर्न वैल्यू

इंडेक्स स्थिति में [`CSSValue`](../../cssvalue/) [`CSSValueList`](../../cssvaluelist/) में, या यदि वह वैध इंडेक्स नहीं है तो null।

### Property Value

संग्रह में इंडेक्स।

## टिप्पणियाँ

यह फीचर मूल रूप से [DOM Style Level 2](https://www.w3.org/TR/DOM-Level-2-Style) स्पेसिफिकेशन में परिभाषित किया गया था, लेकिन तब से इसे किसी भी मानकीकरण प्रयास से हटा दिया गया है।

इसे अब एक आधुनिक, लेकिन असंगत, [CSS Typed Object Model API](https://developer.mozilla.org/en-US/docs/Web/API/CSS_Typed_OM_API) द्वारा प्रतिस्थापित किया गया है, जो वर्तमान में मानक ट्रैक पर है।
