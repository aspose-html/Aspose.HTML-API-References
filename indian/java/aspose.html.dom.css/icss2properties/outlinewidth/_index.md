## ICSS2Properties.OutlineWidth property

outline प्रॉपर्टीज़ से निर्मित आउटलाइन बॉक्स के "over" खींची जाती है, अर्थात् आउटलाइन हमेशा शीर्ष पर रहती है, और बॉक्स या अन्य बॉक्सों की स्थिति या आकार को प्रभावित नहीं करती। इसलिए आउटलाइन को दिखाना या छिपाना रिफ्लो का कारण नहीं बनता।

```java
public String OutlineWidth { get; set; }
```
