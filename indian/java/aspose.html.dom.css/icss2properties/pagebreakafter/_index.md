## ICSS2Properties.PageBreakAfter property

Values for these properties have the following meanings:

auto - न तो उत्पन्न बॉक्स के पहले (बाद, अंदर) पेज ब्रेक को बाध्य करता है और न ही उसे प्रतिबंधित करता है। always - हमेशा उत्पन्न बॉक्स के पहले (बाद) पेज ब्रेक को बाध्य करता है। avoid - उत्पन्न बॉक्स के पहले (बाद, अंदर) पेज ब्रेक से बचता है। left - अगले पेज को बाएँ पेज के रूप में स्वरूपित करने के लिए उत्पन्न बॉक्स के पहले (बाद) एक या दो पेज ब्रेक को बाध्य करता है। right - अगले पेज को दाएँ पेज के रूप में स्वरूपित करने के लिए उत्पन्न बॉक्स के पहले (बाद) एक या दो पेज ब्रेक को बाध्य करता है।

```java
public String PageBreakAfter { get; set; }
```
