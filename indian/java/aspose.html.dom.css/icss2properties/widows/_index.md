## ICSS2Properties.Widows property

यह ['orphans'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-orphans) प्रॉपर्टी यह निर्धारित करती है कि पैराग्राफ की न्यूनतम पंक्तियों की संख्या पृष्ठ के नीचे छोड़नी चाहिए। यह ['widows'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-widows) प्रॉपर्टी यह निर्धारित करती है कि पैराग्राफ की न्यूनतम पंक्तियों की संख्या पृष्ठ के शीर्ष पर छोड़नी चाहिए। नीचे पृष्ठ विभाजन को नियंत्रित करने के लिए इनका उपयोग कैसे किया जाता है, इसके उदाहरण दिए गए हैं।

```java
public String Widows { get; set; }
```
