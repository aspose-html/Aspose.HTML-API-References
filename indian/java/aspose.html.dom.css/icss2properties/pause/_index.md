## ICSS2Properties.Pause property

यह ['pause'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause) गुण ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) और ['pause-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-after) सेट करने का शॉर्टहैंड है। यदि दो मान दिए जाएँ, तो पहला मान ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) और दूसरा मान ['pause-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-after) होता है। यदि केवल एक मान दिया जाए, तो वह दोनों गुणों पर लागू होता है।

```java
public String Pause { get; set; }
```
