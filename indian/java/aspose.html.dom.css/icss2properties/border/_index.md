## ICSS2Properties.Border property

‘border’ प्रॉपर्टी एक शॉर्टहैंड प्रॉपर्टी है जो बॉक्स के चारों किनारों के लिए समान चौड़ाई, रंग और शैली सेट करती है। शॉर्टहैंड ‘margin’ और ‘padding’ प्रॉपर्टीज़ के विपरीत, ‘border’ प्रॉपर्टी चारों किनारों पर अलग-अलग मान सेट नहीं कर सकती। ऐसा करने के लिए एक या अधिक अन्य border प्रॉपर्टीज़ का उपयोग करना आवश्यक है।

```java
public String Border { get; set; }
```
