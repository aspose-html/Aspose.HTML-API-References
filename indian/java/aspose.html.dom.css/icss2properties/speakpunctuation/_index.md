## ICSS2Properties.SpeakPunctuation property

यह प्रॉपर्टी निर्धारित करती है कि विराम चिह्न कैसे बोला जाता है। मानों के निम्नलिखित अर्थ हैं:

code - सेमीकोलन, ब्रेसेस आदि जैसे विराम चिह्नों को शाब्दिक रूप से बोला जाना चाहिए.none - विराम चिह्न नहीं बोला जाता, बल्कि विभिन्न विरामों के रूप में स्वाभाविक रूप से प्रस्तुत किया जाता है।

```java
public String SpeakPunctuation { get; set; }
```
