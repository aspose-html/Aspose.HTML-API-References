## ICSS2Properties.MarkerOffset property

यह प्रॉपर्टी मार्कर बॉक्स के निकटतम [border edges](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#border-edge) और उसके संबंधित [principal box](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#principal-box) के बीच की दूरी निर्दिष्ट करती है। ऑफ़सेट या तो उपयोगकर्ता‑निर्धारित ([length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)) हो सकता है या UA द्वारा ('auto') चुना जाता है। लंबाइयाँ नकारात्मक हो सकती हैं, लेकिन कार्यान्वयन‑विशिष्ट सीमाएँ हो सकती हैं।

```java
public String MarkerOffset { get; set; }
```
