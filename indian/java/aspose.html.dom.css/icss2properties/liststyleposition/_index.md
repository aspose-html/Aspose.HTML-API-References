## ICSS2Properties.ListStylePosition property

यह प्रॉपर्टी मुख्य ब्लॉक बॉक्स में मार्कर बॉक्स की स्थिति निर्दिष्ट करती है। मानों के निम्नलिखित अर्थ हैं:

outside - मार्कर बॉक्स मुख्य ब्लॉक बॉक्स के बाहर है। नोट। CSS1 ने मार्कर बॉक्स के सटीक स्थान को निर्दिष्ट नहीं किया था और संगतता के कारण, CSS2 भी समान रूप से अस्पष्ट रहता है। मार्कर बॉक्सों पर अधिक सटीक नियंत्रण के लिए, कृपया markers का उपयोग करें।inside - मार्कर बॉक्स मुख्य ब्लॉक बॉक्स में पहला इनलाइन बॉक्स है, जिसके बाद तत्व की सामग्री प्रवाहित होती है।

```java
public String ListStylePosition { get; set; }
```
