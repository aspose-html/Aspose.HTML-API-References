## ICSS2Properties.Size property

यह प्रॉपर्टी पेज बॉक्स का आकार और अभिविन्यास निर्दिष्ट करती है।

पेज बॉक्स का आकार या तो \"absolute\" (स्थिर आकार) या \"relative\" (स्केलेबल, अर्थात उपलब्ध शीट आकारों में फिट होना) हो सकता है। रिलेटिव पेज बॉक्स उपयोगकर्ता एजेंटों को दस्तावेज़ को स्केल करने और लक्ष्य आकार का इष्टतम उपयोग करने की अनुमति देते हैं।

['size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-size) प्रॉपर्टी के तीन मान एक रिलेटिव पेज बॉक्स बनाते हैं:

auto - पेज बॉक्स लक्ष्य शीट के आकार और अभिविन्यास पर सेट किया जाएगा।landscape - लक्ष्य के अभिविन्यास को ओवरराइड करता है। पेज बॉक्स लक्ष्य के समान आकार का है, और लंबी पक्ष क्षैतिज होते हैं।portrait - लक्ष्य के अभिविन्यास को ओवरराइड करता है। पेज बॉक्स लक्ष्य के समान आकार का है, और छोटी पक्ष क्षैतिज होते हैं।

```java
public String Size { get; set; }
```
