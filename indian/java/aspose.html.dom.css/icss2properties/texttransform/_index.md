## ICSS2Properties.TextTransform property

यह प्रॉपर्टी तत्व के पाठ के बड़े अक्षर प्रभावों को नियंत्रित करती है। मानों के निम्नलिखित अर्थ हैं:

capitalize - प्रत्येक शब्द के पहले अक्षर को बड़े अक्षर में बदलता है।uppercase - प्रत्येक शब्द के सभी अक्षरों को बड़े अक्षर में बदलता है।lowercase - प्रत्येक शब्द के सभी अक्षरों को छोटे अक्षर में बदलता है।none - कोई बड़े अक्षर प्रभाव नहीं।

```java
public String TextTransform { get; set; }
```
