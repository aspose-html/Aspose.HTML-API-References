## ICSS2Properties.Marks property

उच्च-गुणवत्ता वाली प्रिंटिंग में, अक्सर पेज बॉक्स के बाहर मार्क्स जोड़े जाते हैं। यह गुण निर्धारित करता है कि क्रॉस मार्क्स, क्रॉप मार्क्स या दोनों को [page box](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#page-box) किनारे के ठीक बाहर रेंडर किया जाना चाहिए।

क्रॉप मार्क्स यह दर्शाते हैं कि पेज को कहाँ काटा जाना चाहिए। क्रॉस मार्क्स (जिसे रजिस्टर मार्क्स या रजिस्ट्रेशन मार्क्स भी कहा जाता है) शीट्स को संरेखित करने के लिए उपयोग किए जाते हैं।

मार्क्स केवल निरपेक्ष पेज बॉक्स पर ही दिखाई देते हैं (['size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-size) गुण देखें)। सापेक्ष पेज बॉक्स में, पेज बॉक्स लक्ष्य के साथ संरेखित होगा और मार्क्स प्रिंट करने योग्य क्षेत्र के बाहर होंगे।

क्रॉस चिह्नों का आकार, शैली, और स्थिति उपयोगकर्ता एजेंट पर निर्भर करती है।

```java
public String Marks { get; set; }
```
