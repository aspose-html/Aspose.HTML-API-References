## ICSS2Properties.Height property

यह प्रॉपर्टी ब्लॉक-लेवल और [प्रतिस्थापित](https://www.w3.org/TR/1998/REC-CSS2-19980512/conform.html#replaced-element) तत्वों द्वारा उत्पन्न बॉक्सों की [सामग्री ऊँचाई](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#content-height) निर्दिष्ट करती है।

यह प्रॉपर्टी गैर-प्रतिस्थापित [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) तत्वों पर लागू नहीं होती है। गैर-प्रतिस्थापित इनलाइन तत्व के बॉक्सों की ऊँचाई तत्व के (संभवतः विरासत में मिले) ['line-height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-line-height) मान द्वारा निर्धारित होती है।

```java
public String Height { get; set; }
```
