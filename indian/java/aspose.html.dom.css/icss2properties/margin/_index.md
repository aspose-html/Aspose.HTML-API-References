## ICSS2Properties.Margin property

यह ['margin'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin) प्रॉपर्टी एक शॉर्टहैंड प्रॉपर्टी है जो ['margin-top'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-top), ['margin-right'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-right), ['margin-bottom'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-bottom) और ['margin-left'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-left) को एक ही स्थान पर स्टाइल शीट में सेट करने के लिए उपयोग की जाती है।

यदि केवल एक मान है, तो यह सभी पक्षों पर लागू होता है। यदि दो मान हैं, तो ऊपर और नीचे के मार्जिन पहले मान पर सेट होते हैं और दाएँ और बाएँ के मार्जिन दूसरे मान पर सेट होते हैं। यदि तीन मान हैं, तो ऊपर का मार्जिन पहले मान पर, बाएँ और दाएँ का मार्जिन दूसरे मान पर, और नीचे का मार्जिन तीसरे मान पर सेट होता है। यदि चार मान हैं, तो वे क्रमशः ऊपर, दाएँ, नीचे और बाएँ पर लागू होते हैं।

```java
public String Margin { get; set; }
```
