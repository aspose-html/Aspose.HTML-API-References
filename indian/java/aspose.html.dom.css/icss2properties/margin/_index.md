## ICSS2Properties.Margin property

यह ['margin'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin) प्रॉपर्टी एक शॉर्टहैंड प्रॉपर्टी है जो स्टाइल शीट में समान स्थान पर ['margin-top'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-top), ['margin-right'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-right), ['margin-bottom'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-bottom), और ['margin-left'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-left) सेट करने के लिए उपयोग की जाती है।

यदि केवल एक मान है, तो वह सभी पक्षों पर लागू होता है। यदि दो मान हैं, तो ऊपर और नीचे की मार्जिन पहले मान पर सेट की जाती हैं और दाएँ और बाएँ की मार्जिन दूसरे मान पर सेट की जाती हैं। यदि तीन मान हैं, तो ऊपर पहला मान, बाएँ और दाएँ दूसरा मान, और नीचे तीसरा मान सेट किया जाता है। यदि चार मान हैं, तो वे क्रमशः ऊपर, दाएँ, नीचे और बाएँ पर लागू होते हैं।

```java
public String Margin { get; set; }
```
