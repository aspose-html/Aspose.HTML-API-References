## ICSS2Properties.BackgroundRepeat property

यदि कोई पृष्ठभूमि छवि निर्दिष्ट की गई है, तो यह गुण निर्धारित करता है कि छवि दोहराई (टाइल) जाएगी या नहीं, और कैसे। सभी टाइलिंग बॉक्स की सामग्री और पैडिंग क्षेत्रों को कवर करती है। मानों के निम्नलिखित अर्थ हैं:

repeat - छवि को क्षैतिज और लंबवत दोनों दिशा में दोहराया जाता है।repeat-x - छवि केवल क्षैतिज दिशा में दोहराई जाती है।repeat-y - छवि केवल लंबवत दिशा में दोहराई जाती है।no-repeat - छवि दोहराई नहीं जाती: केवल एक ही प्रतिलिपि खींची जाती है।

```java
public String BackgroundRepeat { get; set; }
```

### रिटर्न वैल्यू

background-repeat गुण

### Property Value

ऊपर परिभाषित सूची से पृष्ठभूमि दोहराव मान।
