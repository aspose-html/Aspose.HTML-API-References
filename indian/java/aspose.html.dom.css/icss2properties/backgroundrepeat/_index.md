## ICSS2Properties.BackgroundRepeat property

यदि कोई बैकग्राउंड इमेज निर्दिष्ट की गई है, तो यह प्रॉपर्टी निर्धारित करती है कि इमेज दोहराई (टाइल) जाएगी या नहीं, और कैसे। सभी टाइलिंग बॉक्स की सामग्री और पैडिंग क्षेत्रों को कवर करती है। मानों के निम्नलिखित अर्थ हैं:

repeat - इमेज क्षैतिज और लंबवत दोनों दिशा में दोहराई जाती है। repeat-x - इमेज केवल क्षैतिज दिशा में दोहराई जाती है। repeat-y - इमेज केवल लंबवत दिशा में दोहराई जाती है। no-repeat - इमेज दोहराई नहीं जाती: केवल एक ही कॉपी खींची जाती है।

```java
public String BackgroundRepeat { get; set; }
```

### रिटर्न वैल्यू

background-repeat प्रॉपर्टी

### Property Value

ऊपर परिभाषित सूची से बैकग्राउंड repeat मान।
