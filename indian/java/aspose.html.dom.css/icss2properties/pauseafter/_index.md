## ICSS2Properties.PauseAfter property

ये प्रॉपर्टीज़ किसी तत्व की सामग्री को बोलने से पहले (या बाद में) लागू होने वाले विराम को निर्दिष्ट करती हैं। मानों के निम्नलिखित अर्थ हैं:

'[time](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-time)' - निरपेक्ष समय इकाइयों (सेकंड और मिलीसेकंड) में विराम को दर्शाता है।'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - ['speech-rate'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-speech-rate) प्रॉपर्टी के मान के उल्टे को संदर्भित करता है। उदाहरण के लिए, यदि speech-rate 120 शब्द प्रति मिनट है (अर्थात् एक शब्द आधा सेकंड लेता है, या 500ms), तो 100% का ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) 500 ms का विराम दर्शाता है और 20% का ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) 100 ms का।

public String PauseAfter { get; set; }
