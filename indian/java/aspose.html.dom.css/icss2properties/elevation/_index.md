## ICSS2Properties.Elevation property

इस प्रॉपर्टी के मानों के निम्नलिखित अर्थ हैं:

'angle' - ऊँचाई को एक कोण के रूप में निर्दिष्ट करता है, '-90deg' से '90deg' के बीच। '0deg' का अर्थ है आगे की क्षितिज पर, जो सुनने वाले के स्तर के बराबर है। '90deg' का अर्थ है सीधे ऊपर और '-90deg' का अर्थ है सीधे नीचे।below - '-90deg' के समान।level - '0deg' के समान।above - '90deg' के समान।higher - वर्तमान ऊँचाई में 10 डिग्री जोड़ता है।lower - वर्तमान ऊँचाई से 10 डिग्री घटाता है।

```java
public String Elevation { get; set; }
```
