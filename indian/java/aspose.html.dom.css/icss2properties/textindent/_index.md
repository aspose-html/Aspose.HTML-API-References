## ICSS2Properties.TextIndent property

यह प्रॉपर्टी ब्लॉक में पहली पंक्ति के टेक्स्ट की इंडेंटेशन निर्धारित करती है। अधिक सटीक रूप से, यह ब्लॉक की पहली [line box](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#line-box) में प्रवाहित होने वाले पहले बॉक्स की इंडेंटेशन को निर्दिष्ट करती है। बॉक्स को बाएँ (या राइट-टू-लेफ्ट लेआउट के लिए दाएँ) लाइन बॉक्स के किनारे के सापेक्ष इंडेंट किया जाता है। यूज़र एजेंट्स को इस इंडेंटेशन को खाली स्थान के रूप में रेंडर करना चाहिए।

मानों के निम्नलिखित अर्थ हैं:

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - इंडेंटेशन एक निश्चित लंबाई है।'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - इंडेंटेशन कंटेनिंग ब्लॉक की चौड़ाई का प्रतिशत है।

```java
public String TextIndent { get; set; }
```
