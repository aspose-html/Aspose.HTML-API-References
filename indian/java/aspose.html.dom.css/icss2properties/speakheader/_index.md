## ICSS2Properties.SpeakHeader property

यह प्रॉपर्टी निर्धारित करती है कि तालिका हेडर प्रत्येक सेल से पहले बोले जाएँ, या केवल तब जब वह सेल पिछले सेल से अलग हेडर से जुड़ा हो। मानों का निम्नलिखित अर्थ है:

once - हेडर एक बार बोला जाता है, कई कोशिकाओं की श्रृंखला से पहले। always - हेडर प्रत्येक संबंधित कोशिका से पहले बोला जाता है।

```java
public String SpeakHeader { get; set; }
```
