## ICSS2Properties.SpeakHeader property

यह प्रॉपर्टी निर्धारित करती है कि तालिका शीर्षकों को हर कोशिका से पहले बोला जाए, या केवल तब जब वह कोशिका पिछले कोशिका से अलग शीर्षक से जुड़ी हो। मानों का निम्नलिखित अर्थ है:

once - शीर्षक एक बार बोला जाता है, कई कोशिकाओं की श्रृंखला से पहले। always - शीर्षक हर संबंधित कोशिका से पहले बोला जाता है।

```java
public String SpeakHeader { get; set; }
```
