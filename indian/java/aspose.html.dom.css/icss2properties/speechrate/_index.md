## ICSS2Properties.SpeechRate property

यह प्रॉपर्टी बोलने की दर को निर्दिष्ट करती है। ध्यान दें कि निरपेक्ष और सापेक्ष दोनों कीवर्ड मान अनुमति हैं (['font-size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html#propdef-font-size) से तुलना करें)। मानों के निम्नलिखित अर्थ हैं:

'[number](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-number)' - शब्दों प्रति मिनट में बोलने की दर को निर्दिष्ट करता है, एक मात्रा जो भाषा के अनुसार कुछ हद तक बदलती है लेकिन फिर भी स्पीच सिंथेसाइज़र द्वारा व्यापक रूप से समर्थित है।

x-slow - 80 शब्द प्रति मिनट के बराबर।

slow - 120 शब्द प्रति मिनट के बराबर।

मध्यम - 180‑200 शब्द प्रति मिनट के समान।

तेज़ - 300 शब्द प्रति मिनट के समान।

एक्स‑तेज़ - 500 शब्द प्रति मिनट के समान।

तेज़तर - वर्तमान भाषण गति में प्रति मिनट 40 शब्द जोड़ता है।

धीमा - वर्तमान भाषण गति से प्रति मिनट 40 शब्द घटाता है।

```java
public String SpeechRate { get; set; }
```
