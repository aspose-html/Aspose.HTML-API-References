## ICSS2Properties.TextDecoration property

यह प्रॉपर्टी उन सजावटों का वर्णन करती है जो किसी तत्व के पाठ में जोड़ी जाती हैं। यदि यह प्रॉपर्टी एक [block-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#block-level) तत्व के लिए निर्दिष्ट है, तो यह तत्व के सभी इनलाइन-लेवल वंशजों को प्रभावित करती है। यदि यह एक [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) तत्व के लिए (या उसे प्रभावित) निर्दिष्ट है, तो यह तत्व द्वारा उत्पन्न सभी बॉक्सों को प्रभावित करती है। यदि तत्व में कोई सामग्री या पाठ नहीं है (उदाहरण के लिए, HTML में IMG तत्व), तो उपयोगकर्ता एजेंट को इस प्रॉपर्टी को [ignore](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#ignore) करना चाहिए।

मानों के निम्नलिखित अर्थ हैं:

none - कोई पाठ सजावट नहीं बनाता। underline - प्रत्येक पाठ पंक्ति के नीचे रेखा होती है। overline - प्रत्येक पाठ पंक्ति के ऊपर रेखा होती है। line-through - प्रत्येक पाठ पंक्ति के मध्य में रेखा होती है। blink - पाठ झपकता है (दृश्यमान और अदृश्य के बीच बदलता है)।
