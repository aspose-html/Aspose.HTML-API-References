## ICSS2Properties.Speak property

यह प्रॉपर्टी निर्धारित करती है कि क्या पाठ को श्रव्य रूप से प्रस्तुत किया जाएगा और यदि हाँ, तो किस प्रकार (display प्रॉपर्टी के समान)। संभावित मान हैं:

none - श्रव्य रेंडरिंग को दबाता है ताकि तत्व को रेंडर करने में कोई समय न लगे। ध्यान दें, हालांकि, कि वंशज इस मान को ओवरराइड कर सकते हैं और बोला जाएगा। (किसी तत्व और उसके वंशजों की रेंडरिंग को सुनिश्चित रूप से दबाने के लिए, ['display'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-display) प्रॉपर्टी का उपयोग करें)।normal - तत्व और उसके बच्चों को रेंडर करने के लिए भाषा‑निर्भर उच्चारण नियमों का उपयोग करता है।spell-out - पाठ को एक‑एक अक्षर के रूप में वर्णित करता है (संक्षिप्ताक्षर और संक्षेपों के लिए उपयोगी)।

```java
public String Speak { get; set; }
```
