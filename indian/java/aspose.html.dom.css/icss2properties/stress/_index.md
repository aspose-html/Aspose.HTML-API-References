## ICSS2Properties.Stress property

आवाज़ के इंटोनेशन कंटूर में "स्थानीय शिखरों" की ऊँचाई को निर्दिष्ट करता है। उदाहरण के लिए, अंग्रेज़ी एक तनावपूर्ण भाषा है, और वाक्य के विभिन्न भागों को प्राथमिक, द्वितीयक, या तृतीयक तनाव दिया जाता है। ['stress'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-stress) का मान इन तनाव संकेतकों से उत्पन्न स्वर परिवर्तन की मात्रा को नियंत्रित करता है। यह प्रॉपर्टी ['pitch-range'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pitch-range) प्रॉपर्टी के साथ सहचर है और डेवलपर्स को उच्च-स्तरीय श्रवण डिस्प्ले का उपयोग करने की अनुमति देने के लिए प्रदान की गई है।

```java
public String Stress { get; set; }
```
