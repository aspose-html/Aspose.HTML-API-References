## ICSS2Properties.WordSpacing property

यह प्रॉपर्टी शब्दों के बीच अंतराल व्यवहार को निर्दिष्ट करती है। मानों के निम्नलिखित अर्थ हैं:

normal - वर्तमान फ़ॉन्ट और/या यूज़र एजेंट द्वारा परिभाषित सामान्य शब्द‑अंतराल। '[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - यह मान शब्दों के बीच डिफ़ॉल्ट अंतराल के अतिरिक्त शब्द‑अंतराल को दर्शाता है। मान नकारात्मक हो सकते हैं, लेकिन कार्यान्वयन‑विशिष्ट सीमाएँ हो सकती हैं।

public String WordSpacing { get; set; }
