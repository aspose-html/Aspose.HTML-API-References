## ICSS2Properties.BackgroundAttachment property

यदि कोई बैकग्राउंड इमेज निर्दिष्ट की गई है, तो यह प्रॉपर्टी निर्धारित करती है कि वह व्यूपोर्ट के संबंध में स्थिर ('fixed') है या दस्तावेज़ के साथ स्क्रॉल ('scroll') करता है।

भले ही इमेज स्थिर हो, यह केवल तब ही दिखाई देती है जब वह तत्व के बैकग्राउंड या पैडिंग क्षेत्र में हो। इसलिए, जब तक इमेज टाइल नहीं की गई है ('background-repeat: repeat'), यह अदृश्य हो सकती है।

```java
public String BackgroundAttachment { get; set; }
```
