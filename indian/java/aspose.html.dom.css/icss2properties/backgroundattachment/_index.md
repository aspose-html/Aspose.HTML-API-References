## ICSS2Properties.BackgroundAttachment property

यदि कोई बैकग्राउंड इमेज निर्दिष्ट की गई है, तो यह प्रॉपर्टी यह निर्धारित करती है कि वह viewport के संबंध में ('fixed') स्थिर है या दस्तावेज़ के साथ ('scroll') स्क्रॉल करता है।

भले ही इमेज fixed हो, यह केवल तब ही दिखाई देती है जब वह तत्व के बैकग्राउंड या पैडिंग क्षेत्र में हो। इसलिए, जब तक इमेज टाइल नहीं की गई है ('background-repeat: repeat'), यह अदृश्य हो सकती है।

```java
public String BackgroundAttachment { get; set; }
```
