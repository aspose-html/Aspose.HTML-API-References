## ICSS2Properties.VoiceFamily property

मान आवाज़ परिवार नामों की कॉमा-सेपरेटेड, प्राथमिकता सूची है (['font-family'](https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html#propdef-font-family) से तुलना करें)। मानों के निम्नलिखित अर्थ हैं:

'generic-voice' - मान आवाज़ परिवार होते हैं। संभावित मान 'male', 'female', और 'child' हैं।'specific-voice' - मान विशिष्ट उदाहरण होते हैं (जैसे, comedian, trinoids, carlos, lani)।

```java
public String VoiceFamily { get; set; }
```

voice-family गुण
