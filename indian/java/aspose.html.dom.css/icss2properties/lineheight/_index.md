## ICSS2Properties.LineHeight property

यदि यह प्रॉपर्टी एक [block-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#block-level) तत्व पर सेट की जाती है जिसका कंटेंट [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) तत्वों से बना है, तो यह प्रत्येक उत्पन्न इनलाइन बॉक्स की न्यूनतम ऊँचाई निर्दिष्ट करती है।

यदि यह प्रॉपर्टी एक [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) तत्व पर सेट की जाती है, तो यह तत्व द्वारा उत्पन्न प्रत्येक बॉक्स की सटीक ऊँचाई निर्दिष्ट करती है। (इनलाइन [replaced](https://www.w3.org/TR/1998/REC-CSS2-19980512/conform.html#replaced-element) तत्वों को छोड़कर, जहाँ बॉक्स की ऊँचाई ['height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-height) प्रॉपर्टी द्वारा दी जाती है।)

```java
public String LineHeight { get; set; }
```
