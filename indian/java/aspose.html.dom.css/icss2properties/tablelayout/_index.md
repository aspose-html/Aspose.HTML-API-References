## ICSS2Properties.TableLayout property

यह ['table-layout'](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#propdef-table-layout) प्रॉपर्टी तालिका की कोशिकाओं, पंक्तियों और स्तंभों को व्यवस्थित करने के लिए उपयोग किए जाने वाले एल्गोरिदम को नियंत्रित करती है। मानों का निम्नलिखित अर्थ है:

fixed - स्थिर तालिका लेआउट एल्गोरिदम का उपयोग करें auto - कोई भी स्वचालित तालिका लेआउट एल्गोरिदम उपयोग करें

```java
public String TableLayout { get; set; }
```
