## ICSS2Properties.ListStyleType property

यह प्रॉपर्टी सूची आइटम मार्कर की उपस्थिति निर्दिष्ट करती है यदि ['list-style-image'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-list-style-image) का मान 'none' है या यदि URI द्वारा निर्दिष्ट छवि प्रदर्शित नहीं की जा सकती। मान 'none' कोई मार्कर नहीं दर्शाता, अन्यथा तीन प्रकार के मार्कर होते हैं: glyphs, numbering systems, और alphabetic systems। नोट। क्रमांकित सूचियाँ दस्तावेज़ की पहुँचयोग्यता को सुधारती हैं क्योंकि वे सूचियों को नेविगेट करना आसान बनाती हैं।

Glyphs को disc, circle, और square के साथ निर्दिष्ट किया जाता है। उनका सटीक रेंडरिंग उपयोगकर्ता एजेंट पर निर्भर करता है।

Numbering systems के साथ निर्दिष्ट किए जाते हैं:

decimal - दशमलव संख्याएँ, 1 से शुरू।decimal-leading-zero - प्रारंभिक शून्य के साथ पैडेड दशमलव संख्याएँ (उदा., 01, 02, 03, ..., 98, 99)।lower-roman - लोअरकेस रोमन अंक (i, ii, iii, iv, v, आदि)।upper-roman - अपरकेस रोमन अंक (I, II, III, IV, V, आदि)।hebrew - पारंपरिक हिब्रू क्रमांकन।georgian - पारंपरिक जॉर्जियन क्रमांकन (an, ban, gan, ..., he, tan, in, in-an, ...)।armenian - पारंपरिक अर्मेनियन क्रमांकन।cjk-ideographic - साधारण आइडियोग्राफिक संख्याएँ।hiragana - a, i, u, e, o, ka, ki, ...।katakana - A, I, U, E, O, KA, KI, ...।hiragana-iroha - i, ro, ha, ni, ho, he, to, ...।katakana-iroha - I, RO, HA, NI, HO, HE, TO, ...
