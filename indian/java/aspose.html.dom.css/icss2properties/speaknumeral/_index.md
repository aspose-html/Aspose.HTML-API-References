## ICSS2Properties.SpeakNumeral property

यह प्रॉपर्टी नियंत्रित करती है कि संख्याएँ कैसे बोली जाती हैं। मानों के निम्नलिखित अर्थ हैं:

digits - संख्या को व्यक्तिगत अंकों के रूप में बोला जाता है। उदाहरण के लिए, "237" को "Two Three Seven" कहा जाता है।continuous - संख्या को पूर्ण संख्या के रूप में बोला जाता है। उदाहरण के लिए, "237" को "Two hundred thirty seven" कहा जाता है। शब्द प्रतिनिधित्व भाषा पर निर्भर होते हैं।

```java
public String SpeakNumeral { get; set; }
```
