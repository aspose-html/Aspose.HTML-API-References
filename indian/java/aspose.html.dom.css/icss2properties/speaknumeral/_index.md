## ICSS2Properties.SpeakNumeral property

यह गुण नियंत्रित करता है कि अंकों को कैसे बोला जाता है। मानों के निम्नलिखित अर्थ हैं:

digits - अंक को व्यक्तिगत अंकों के रूप में बोला जाता है। उदाहरण के लिए, "237" को "Two Three Seven" कहा जाता है।continuous - अंक को पूर्ण संख्या के रूप में बोला जाता है। उदाहरण के लिए, "237" को "Two hundred thirty seven" कहा जाता है। शब्द प्रतिनिधित्व भाषा-निर्भर होते हैं।

```java
public String SpeakNumeral { get; set; }
```
