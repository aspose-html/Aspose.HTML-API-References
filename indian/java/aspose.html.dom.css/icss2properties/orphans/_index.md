## ICSS2Properties.Orphans property

The ['orphans'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-orphans) प्रॉपर्टी पैराग्राफ की न्यूनतम पंक्तियों की संख्या निर्दिष्ट करती है जो पृष्ठ के नीचे छोड़ी जानी चाहिए। The ['widows'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-widows) प्रॉपर्टी पैराग्राफ की न्यूनतम पंक्तियों की संख्या निर्दिष्ट करती है जो पृष्ठ के शीर्ष पर छोड़ी जानी चाहिए। पृष्ठ ब्रेक को नियंत्रित करने के लिए उनका उपयोग कैसे किया जाता है, इसके उदाहरण नीचे दिए गए हैं।

```java
public String Orphans { get; set; }
```
