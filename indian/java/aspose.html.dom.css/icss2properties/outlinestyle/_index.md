## ICSS2Properties.OutlineStyle property

outline गुणों से निर्मित रूपरेखा बॉक्स के "ऊपर" खींची जाती है, अर्थात् रूपरेखा हमेशा शीर्ष पर रहती है, और बॉक्स या अन्य बॉक्सों की स्थिति या आकार को प्रभावित नहीं करती। इसलिए, रूपरेखा को प्रदर्शित या दबाने से पुनः प्रवाह नहीं होता।

```java
public String OutlineStyle { get; set; }
```
