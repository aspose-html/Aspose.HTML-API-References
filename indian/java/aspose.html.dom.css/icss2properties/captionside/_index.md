## ICSS2Properties.CaptionSide property

यह प्रॉपर्टी टेबल बॉक्स के सापेक्ष कैप्शन बॉक्स की स्थिति निर्दिष्ट करती है। मानों के निम्नलिखित अर्थ हैं:

top - कैप्शन बॉक्स को टेबल बॉक्स के ऊपर स्थित करता है। bottom - कैप्शन बॉक्स को टेबल बॉक्स के नीचे स्थित करता है। left - कैप्शन बॉक्स को टेबल बॉक्स के बाएँ स्थित करता है। right - कैप्शन बॉक्स को टेबल बॉक्स के दाएँ स्थित करता है।

```java
public String CaptionSide { get; set; }
```
