## ICSS2Properties.Pitch property

बोलने वाली आवाज़ की औसत पिच (आवृत्ति) को निर्दिष्ट करता है। आवाज़ की औसत पिच आवाज़ परिवार पर निर्भर करती है। उदाहरण के लिए, मानक पुरुष आवाज़ की औसत पिच लगभग 120Hz होती है, जबकि महिला आवाज़ की लगभग 210Hz होती है।

public String Pitch { get; set; }
