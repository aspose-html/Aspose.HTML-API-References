## ICSS2Properties.PitchRange property

औसत पिच में परिवर्तन को निर्दिष्ट करता है। मानव आवाज़ की अनुभूत पिच मूल आवृत्ति द्वारा निर्धारित होती है और आमतौर पर पुरुष आवाज़ के लिए 120Hz तथा महिला आवाज़ के लिए 210Hz होती है। मानव भाषाएँ विभिन्न स्वरभंग और पिच के साथ बोली जाती हैं; ये परिवर्तन अतिरिक्त अर्थ और ज़ोर प्रदान करते हैं। इसलिए, अत्यधिक जीवंत आवाज़, अर्थात् जो बहुत अधिक स्वरभंगित हो, उच्च पिच रेंज प्रदर्शित करती है। यह गुण उन रेंज को निर्दिष्ट करता है जहाँ ये परिवर्तन होते हैं, अर्थात् मूल आवृत्ति औसत पिच से कितनी विचलित हो सकती है।

```java
public String PitchRange { get; set; }
```
