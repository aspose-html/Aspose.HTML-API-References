## ICSS2Properties.TextAlign property

यह प्रॉपर्टी वर्णन करती है कि ब्लॉक की इनलाइन सामग्री कैसे संरेखित होती है। मानों के निम्नलिखित अर्थ हैं:

left, right, center, and justify - बाएँ, दाएँ, केंद्र, और दोहरी जस्टिफ़ाइ टेक्स्ट, क्रमशः।'[String](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-String)' - वह स्ट्रिंग निर्दिष्ट करता है जिस पर तालिका कॉलम की कोशिकाएँ संरेखित होंगी (विवरण और उदाहरण के लिए [horizontal alignment in a column](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#column-alignment) देखें)। यह मान केवल [table](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html) कोशिकाओं पर लागू होता है। यदि अन्य तत्वों पर सेट किया जाता है, तो इसे 'left' या 'right' माना जाएगा, यह इस पर निर्भर करता है कि ['direction'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-direction) 'ltr' है या 'rtl', क्रमशः।

```java
public String TextAlign { get; set; }
```
