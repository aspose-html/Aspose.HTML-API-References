## ICSS2Properties.BorderRightWidth property

यह प्रॉपर्टी शैली पत्रिका में 'border-top-width', 'border-right-width', 'border-bottom-width', और 'border-left-width' को एक ही स्थान पर सेट करने के लिए एक शॉर्टहैंड प्रॉपर्टी है।
