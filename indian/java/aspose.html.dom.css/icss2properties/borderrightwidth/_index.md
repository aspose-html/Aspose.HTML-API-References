## ICSS2Properties.BorderRightWidth property

यह प्रॉपर्टी एक शॉर्टहैंड प्रॉपर्टी है जो स्टाइल शीट में एक ही स्थान पर 'border-top-width', 'border-right-width', 'border-bottom-width', और 'border-left-width' सेट करने के लिए उपयोग होती है।

यदि केवल एक मान है, तो यह सभी पक्षों पर लागू होता है। यदि दो मान हैं, तो ऊपर और नीचे की सीमाएँ पहले मान पर सेट की जाती हैं और दाएँ और बाएँ दूसरी पर। यदि तीन मान हैं, तो ऊपर पहला मान, बाएँ और दाएँ दूसरा मान, और नीचे तीसरा मान सेट किया जाता है। यदि चार मान हैं, तो वे क्रमशः ऊपर, दाएँ, नीचे और बाएँ पर लागू होते हैं।

```java
public String BorderRightWidth { get; set; }
```
