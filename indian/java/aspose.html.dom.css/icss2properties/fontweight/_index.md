## ICSS2Properties.FontWeight property

'font-weight' प्रॉपर्टी फ़ॉन्ट के वजन को निर्दिष्ट करती है। मानों के निम्नलिखित अर्थ हैं:

100 से 900 - ये मान क्रमबद्ध अनुक्रम बनाते हैं, जहाँ प्रत्येक संख्या पूर्ववर्ती से कम से कम उतनी ही गहरी वजन दर्शाती है।normal - '400' के समान।bold - '700' के समान।bolder - वह अगला वजन निर्दिष्ट करता है जो विरासत में मिले फ़ॉन्ट से अधिक गहरा हो। यदि ऐसा कोई वजन नहीं है, तो यह केवल अगली अधिक गहरी संख्यात्मक मान बन जाता है (और फ़ॉन्ट अपरिवर्तित रहता है), जब तक कि विरासत में मिला मान '900' न हो, तब परिणामस्वरूप वजन भी '900' रहेगा।lighter - वह अगला वजन निर्दिष्ट करता है जो विरासत में मिले फ़ॉन्ट से हल्का हो। यदि ऐसा कोई वजन नहीं है, तो यह केवल अगली हल्की संख्यात्मक मान बन जाता है (और फ़ॉन्ट अपरिवर्तित रहता है), जब तक कि विरासत में मिला मान '100' न हो, तब परिणामस्वरूप वजन भी '100' रहेगा।

```java
public String FontWeight { get; set; }
```
