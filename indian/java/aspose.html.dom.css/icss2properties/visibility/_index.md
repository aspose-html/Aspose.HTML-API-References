## ICSS2Properties.Visibility property

['visibility'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visufx.html#propdef-visibility) प्रॉपर्टी यह निर्धारित करती है कि किसी तत्व द्वारा उत्पन्न बॉक्स रेंडर किए जाते हैं या नहीं। अदृश्य बॉक्स अभी भी लेआउट को प्रभावित करते हैं (बॉक्स निर्माण को पूरी तरह से रोकने के लिए ['display'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-display) प्रॉपर्टी को 'none' सेट करें)। मानों के निम्नलिखित अर्थ हैं:

visible - उत्पन्न बॉक्स दृश्यमान है।hidden - उत्पन्न बॉक्स अदृश्य (पूरी तरह पारदर्शी) है, लेकिन अभी भी लेआउट को प्रभावित करता है।collapse - कृपया तालिकाओं में [dynamic row and column effects](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#dynamic-effects) अनुभाग देखें। यदि यह पंक्तियों या स्तंभों के अलावा अन्य तत्वों पर उपयोग किया जाता है, तो 'collapse' का अर्थ 'hidden' के समान है।

```java
public String Visibility { get; set; }
```
