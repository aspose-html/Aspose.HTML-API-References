## ICSS2Properties.Background property

‘background’ प्रॉपर्टी एक शॉर्टहैंड प्रॉपर्टी है जो व्यक्तिगत बैकग्राउंड प्रॉपर्टी (जैसे कि 'background-color', 'background-image', 'background-repeat', 'background-attachment' और 'background-position') को स्टाइल शीट में एक ही स्थान पर सेट करती है।

```java
public String Background { get; set; }
```

### रिटर्न वैल्यू

यह background प्रॉपर्टी

### Property Value

व्यक्तिगत बैकग्राउंड प्रॉपर्टी को स्टाइल शीट में एक ही स्थान पर सेट करने के लिए शॉर्टहैंड प्रॉपर्टी को प्राप्त करता है या सेट करता है।
