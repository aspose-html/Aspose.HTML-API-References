## ICSS2Properties.Background property

‘background’ गुण व्यक्तिगत बैकग्राउंड गुणों को सेट करने के लिए एक शॉर्टहैंड गुण है (जैसे, 'background-color', 'background-image', 'background-repeat', 'background-attachment' और 'background-position') शैली पत्रक में एक ही स्थान पर।

```java
public String Background { get; set; }
```

### रिटर्न वैल्यू

यह background गुण

### Property Value

व्यक्तिगत बैकग्राउंड गुणों को शैली पत्रक में एक ही स्थान पर सेट करने के लिए एक शॉर्टहैंड गुण प्राप्त करता है या सेट करता है।
