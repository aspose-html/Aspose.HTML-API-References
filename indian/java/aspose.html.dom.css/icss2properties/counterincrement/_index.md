## ICSS2Properties.CounterIncrement property

The ['counter-increment'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-counter-increment) प्रॉपर्टी एक या अधिक काउंटर (पहचानकर्ता) के नाम स्वीकार करती है, प्रत्येक के बाद वैकल्पिक रूप से एक पूर्णांक हो सकता है। यह पूर्णांक दर्शाता है कि प्रत्येक एलिमेंट की उपस्थिति पर काउंटर कितना बढ़ाया जाता है। डिफ़ॉल्ट वृद्धि 1 है। शून्य और नकारात्मक पूर्णांक भी अनुमति हैं।

```java
public String CounterIncrement { get; set; }
```
