## ICSS2Properties.CounterIncrement property

['counter-increment'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-counter-increment) गुण एक या अधिक काउंटर (पहचानकर्ता) के नाम स्वीकार करता है, प्रत्येक के बाद वैकल्पिक रूप से एक पूर्णांक हो सकता है। पूर्णांक दर्शाता है कि तत्व के प्रत्येक प्रकट होने पर काउंटर कितना बढ़ेगा। डिफ़ॉल्ट वृद्धि 1 है। शून्य और नकारात्मक पूर्णांक की अनुमति है।

```java
public String CounterIncrement { get; set; }
```
