## ICSS2Properties.FontVariant property

एक छोटे‑कैप्स फ़ॉन्ट में, छोटे अक्षरों के ग्लिफ़ बड़े अक्षरों के समान दिखते हैं, लेकिन छोटे आकार में और थोड़ी अलग अनुपात के साथ। 'font-variant' प्रॉपर्टी ऐसे फ़ॉन्ट का अनुरोध करती है जो द्वि‑केस (बिकैमेरल) हो (जैसे लैटिन लिपि में दो केस होते हैं)। यह प्रॉपर्टी उन लिपियों पर कोई दृश्यमान प्रभाव नहीं डालती जो एक‑केस (यूनिकैमेरल) हैं (जिनमें केवल एक केस होता है, जैसा कि अधिकांश विश्व की लेखन प्रणालियों में है)।

```java
public String FontVariant { get; set; }
```
