## ICSS2Properties.FontVariant property

छोटे कैप्स फ़ॉन्ट में, लोअरकेस अक्षरों के ग्लिफ़ अपरकेस के समान दिखते हैं, लेकिन छोटे आकार में और थोड़ी अलग अनुपात के साथ। 'font-variant' प्रॉपर्टी ऐसे फ़ॉन्ट का अनुरोध करती है जो द्वि-केस (बाइकेमेरल) हो (जैसे लैटिन लिपि में दो केस होते हैं)। यह प्रॉपर्टी उन लिपियों पर कोई दृश्यमान प्रभाव नहीं डालती जो एक-केस (यूनिकेमरल) हैं (जैसे अधिकांश विश्व की लेखन प्रणालियों में केवल एक केस होता है)।

```java
public String FontVariant { get; set; }
```
