## ICSS2Properties.MinHeight property

ये दो प्रॉपर्टी लेखकों को बॉक्स की ऊँचाई को एक निश्चित सीमा में सीमित करने की अनुमति देती हैं। मानों के निम्नलिखित अर्थ हैं:

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - एक निश्चित न्यूनतम या अधिकतम गणना की गई ऊँचाई निर्दिष्ट करता है।'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - गणना मान निर्धारित करने के लिए प्रतिशत निर्दिष्ट करता है। प्रतिशत उत्पन्न बॉक्स के [containing block](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#containing-block) की ऊँचाई के सापेक्ष गणना किया जाता है। यदि कंटेनिंग ब्लॉक की ऊँचाई स्पष्ट रूप से निर्दिष्ट नहीं है (अर्थात यह सामग्री की ऊँचाई पर निर्भर करती है), तो प्रतिशत मान को 'auto' की तरह व्याख्या किया जाता है।none - (केवल ['max-height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-max-height)) बॉक्स की ऊँचाई पर कोई सीमा नहीं।

```java
public String MinHeight { get; set; }
```
