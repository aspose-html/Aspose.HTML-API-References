## ICSS2Properties.PageBreakInside property

इन प्रॉपर्टीज़ के मानों के निम्नलिखित अर्थ हैं:

auto - उत्पन्न बॉक्स से पहले (या बाद, अंदर) पेज ब्रेक को न तो लागू करें और न ही प्रतिबंधित करें। always - उत्पन्न बॉक्स से पहले (या बाद) हमेशा पेज ब्रेक लागू करें। avoid - उत्पन्न बॉक्स से पहले (या बाद, अंदर) पेज ब्रेक से बचें। left - उत्पन्न बॉक्स से पहले (या बाद) एक या दो पेज ब्रेक लागू करें ताकि अगला पृष्ठ बाएँ पृष्ठ के रूप में स्वरूपित हो। right - उत्पन्न बॉक्स से पहले (या बाद) एक या दो पेज ब्रेक लागू करें ताकि अगला पृष्ठ दाएँ पृष्ठ के रूप में स्वरूपित हो।

```java
public String PageBreakInside { get; set; }
```
