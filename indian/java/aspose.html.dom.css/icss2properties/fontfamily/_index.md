## ICSS2Properties.FontFamily property

यह प्रॉपर्टी फ़ॉन्ट परिवार नामों और/या सामान्य परिवार नामों की प्राथमिकता सूची निर्दिष्ट करती है। इस समस्या से निपटने के लिए कि एकल फ़ॉन्ट दस्तावेज़ में सभी अक्षरों को प्रदर्शित करने के लिए glyph नहीं रख सकता, या सभी सिस्टम पर सभी फ़ॉन्ट उपलब्ध नहीं होते, यह प्रॉपर्टी लेखकों को समान शैली और आकार के फ़ॉन्ट की सूची निर्दिष्ट करने की अनुमति देती है, जिन्हें क्रम में आज़माया जाता है कि क्या वे किसी विशेष अक्षर के लिए glyph रखते हैं। इस सूची को फ़ॉन्ट सेट कहा जाता है।

```java
public String FontFamily { get; set; }
```
