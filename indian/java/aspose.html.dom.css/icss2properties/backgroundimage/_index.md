## ICSS2Properties.BackgroundImage property

यह प्रॉपर्टी तत्व की बैकग्राउंड इमेज सेट करती है। बैकग्राउंड इमेज सेट करते समय, लेखकों को एक बैकग्राउंड रंग भी निर्दिष्ट करना चाहिए जो इमेज उपलब्ध न होने पर उपयोग किया जाएगा। जब इमेज उपलब्ध होती है, तो वह बैकग्राउंड रंग के ऊपर रेंडर की जाती है। (इस प्रकार, रंग इमेज के पारदर्शी भागों में दिखाई देता है)।

```java
public String BackgroundImage { get; set; }
```

### रिटर्न वैल्यू

background-image प्रॉपर्टी

### Property Value

इस प्रॉपर्टी के मान या तो , इमेज निर्दिष्ट करने के लिए होते हैं, या जब कोई इमेज उपयोग नहीं की जाती तो 'none'।
