## ICSS2Properties.CounterReset property

['counter-reset'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-counter-reset) प्रॉपर्टी में भी एक या अधिक काउंटर नामों की सूची होती है, प्रत्येक वैकल्पिक रूप से एक पूर्णांक के बाद आता है। पूर्णांक वह मान देता है जो प्रत्येक तत्व के प्रकट होने पर काउंटर को सेट किया जाता है। डिफ़ॉल्ट 0 है।

```java
public String CounterReset { get; set; }
```
