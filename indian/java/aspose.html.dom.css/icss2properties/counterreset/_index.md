## ICSS2Properties.CounterReset property

['counter-reset'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-counter-reset) प्रॉपर्टी में भी एक या अधिक काउंटर नामों की सूची शामिल है, प्रत्येक वैकल्पिक रूप से एक पूर्णांक के साथ। यह पूर्णांक प्रत्येक तत्व की उपस्थिति पर काउंटर को सेट किए जाने वाले मान को दर्शाता है। डिफ़ॉल्ट 0 है।

```java
public String CounterReset { get; set; }
```
