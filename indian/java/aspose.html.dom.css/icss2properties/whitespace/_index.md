## ICSS2Properties.WhiteSpace property

यह प्रॉपर्टी बताती है कि तत्व के भीतर [whitespace](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#whitespace) कैसे संभाला जाता है। मानों के निम्नलिखित अर्थ हैं:

normal - यह मान यूज़र एजेंट्स को व्हाइटस्पेस की श्रृंखलाओं को संकुचित करने और आवश्यकतानुसार लाइन बॉक्स भरने के लिए लाइनों को तोड़ने का निर्देश देता है। अतिरिक्त लाइन ब्रेक उत्पन्न सामग्री में "\A" की घटनाओं द्वारा बनाए जा सकते हैं (उदा., HTML में BR तत्व के लिए)।pre - यह मान यूज़र एजेंट्स को व्हाइटस्पेस की श्रृंखलाओं को संकुचित करने से रोकता है। लाइनों को केवल स्रोत में नई पंक्तियों पर या उत्पन्न सामग्री में "\A" की घटनाओं पर ही तोड़ा जाता है।nowrap - यह मान 'normal' की तरह व्हाइटस्पेस को संकुचित करता है, लेकिन टेक्स्ट के भीतर लाइन ब्रेक को दबा देता है, सिवाय उन ब्रेकों के जो उत्पन्न सामग्री में "\A" द्वारा बनाए गए हों (उदा., HTML में BR तत्व के लिए)।

public String WhiteSpace { get; set; }
