## ICSS2Properties.MaxWidth property

ये दो प्रॉपर्टी लेखकों को बॉक्स की चौड़ाई को एक निश्चित सीमा में सीमित करने की अनुमति देती हैं। मानों के निम्नलिखित अर्थ हैं:

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - एक निश्चित न्यूनतम या अधिकतम गणना की गई चौड़ाई निर्दिष्ट करता है।'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - गणना मान निर्धारित करने के लिए प्रतिशत निर्दिष्ट करता है। प्रतिशत को उत्पन्न बॉक्स के [containing block](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#containing-block) की चौड़ाई के सापेक्ष गणना किया जाता है।none - (केवल ['max-width'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-max-width) पर) बॉक्स की चौड़ाई पर कोई सीमा नहीं।

```java
public String MaxWidth { get; set; }
```
