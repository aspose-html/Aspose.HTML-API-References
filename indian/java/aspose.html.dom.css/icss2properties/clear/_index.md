## ICSS2Properties.Clear property

यह प्रॉपर्टी दर्शाती है कि तत्व के बॉक्स(ओं) के किन किन पक्षों को पहले के फ्लोटिंग बॉक्स के साथ सटा नहीं होना चाहिए। (यह संभव है कि तत्व के पास स्वयं फ्लोटिंग चाइल्ड हों; 'clear' प्रॉपर्टी का उन पर कोई प्रभाव नहीं पड़ता।)

यह प्रॉपर्टी केवल ब्लॉक-लेवल तत्वों (फ़्लोट्स सहित) के लिए निर्दिष्ट की जा सकती है। कॉम्पैक्ट और रन-इन बॉक्सों के लिए, यह प्रॉपर्टी उस अंतिम ब्लॉक बॉक्स पर लागू होती है जिससे कॉम्पैक्ट या रन-इन बॉक्स संबंधित होता है।

जब गैर-फ़्लोटिंग ब्लॉक बॉक्सों पर लागू किया जाता है, तो मानों के निम्नलिखित अर्थ होते हैं:

left - उत्पन्न बॉक्स का शीर्ष मार्जिन इतना बढ़ा दिया जाता है कि उसका शीर्ष बॉर्डर एज स्रोत दस्तावेज़ में पहले आए तत्वों से बने किसी भी बाएँ-फ़्लोटिंग बॉक्स के नीचे बाहरी किनारे से नीचे हो।right - उत्पन्न बॉक्स का शीर्ष मार्जिन इतना बढ़ा दिया जाता है कि उसका शीर्ष बॉर्डर एज स्रोत दस्तावेज़ में पहले आए तत्वों से बने किसी भी दाएँ-फ़्लोटिंग बॉक्स के नीचे बाहरी किनारे से नीचे हो।both - उत्पन्न बॉक्स को स्रोत दस्तावेज़ में पहले के सभी फ़्लोटिंग बॉक्सों के नीचे ले जाया जाता है।none - फ़्लोट्स के संबंध में बॉक्स की स्थिति पर कोई प्रतिबंध नहीं है।

```java
public String Clear { get; set; }
```
