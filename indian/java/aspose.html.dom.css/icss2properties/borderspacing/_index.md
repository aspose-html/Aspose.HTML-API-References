## ICSS2Properties.BorderSpacing property

लंबाइयाँ निकटवर्ती कोशिका सीमाओं के बीच की दूरी निर्दिष्ट करती हैं। यदि एक लंबाई निर्दिष्ट की जाती है, तो वह क्षैतिज और लंबवत दोनों स्पेसिंग देती है। यदि दो निर्दिष्ट की जाती हैं, तो पहली क्षैतिज स्पेसिंग देती है और दूसरी लंबवत स्पेसिंग। लंबाइयाँ नकारात्मक नहीं हो सकतीं।

```java
public String BorderSpacing { get; set; }
```
