## ICSS2Properties.FontSizeAdjust property

द्वि-लिपि स्क्रिप्ट्स में, फ़ॉन्ट का व्यक्तिपरक दिखाई देने वाला आकार और पठनीयता उनके 'font-size' मान की तुलना में उनके 'x-height' मान पर अधिक निर्भर करती है, या अधिक उपयोगी रूप से इन दो मानों के अनुपात जिसे aspect value (font size को x-height से विभाजित) कहा जाता है। aspect value जितना अधिक होगा, छोटे आकार में फ़ॉन्ट की पठनीयता उतनी ही अधिक संभावना होगी। इसके विपरीत, कम aspect value वाले फ़ॉन्ट निर्धारित सीमा आकार से नीचे जल्दी अपठनीय हो जाएंगे, जबकि उच्च aspect value वाले फ़ॉन्ट अधिक समय तक पठनीय रहेंगे। केवल फ़ॉन्ट आकार पर निर्भर सरल फ़ॉन्ट प्रतिस्थापन अपठनीय अक्षरों का कारण बन सकता है।

```java
public String FontSizeAdjust { get; set; }
```
