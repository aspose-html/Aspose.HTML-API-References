## ICSSRule.ParentRule property

यदि यह नियम किसी अन्य नियम के भीतर स्थित है (उदाहरण के लिए एक स्टाइल नियम @media ब्लॉक के भीतर), तो यह कंटेनिंग नियम है। यदि यह नियम किसी अन्य नियम के भीतर नेस्टेड नहीं है, तो यह null लौटाता है।

```java
public ICSSRule ParentRule { get; }
```

### Property Value

एक [`CSSRule`](../) जो कंटेनिंग नियमों का प्रकार है। यदि वर्तमान नियम एक मीडिया क्वेरी के भीतर है, तो यह [`CSSMediaRule`](../../icssmediarule/) लौटाएगा। अन्यथा यह null लौटाता है।
