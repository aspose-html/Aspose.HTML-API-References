## ICSSRule.Type property

नियम का प्रकार, जैसा कि [CSSOM # dom‑cssrule‑type](https://drafts.csswg.org/cssom/#dom-cssrule-type) में परिभाषित है। अपेक्षा है कि बाइंडिंग‑विशिष्ट कास्टिंग मेथड्स का उपयोग करके CSSRule इंटरफ़ेस के एक इंस्टेंस को उस प्रकार द्वारा संकेतित विशिष्ट डेराइव्ड इंटरफ़ेस में कास्ट किया जा सके।

```java
public short Type { get; }
```

### Property Value

एक गैर‑नकारात्मक पूर्णांक जो किसी विशिष्ट प्रकार के नियम से जुड़ा है। यह आइटम नियम के निर्माण पर इनिशियलाइज़ होता है और बदल नहीं सकता।
