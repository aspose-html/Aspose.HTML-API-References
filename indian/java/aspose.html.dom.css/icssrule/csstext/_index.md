## ICSSRule.CSSText property

[`CSSRule`](../) इंटरफ़ेस की cssText प्रॉपर्टी एक [`CSSStyleSheet`](../../icssstylesheet/) शैली-नियम का वास्तविक टेक्स्ट लौटाती है।

ध्यान दें: इस प्रॉपर्टी को element-style CSSStyleDeclaration.cssText के साथ भ्रमित न करें।

```java
public String CSSText { get; set; }
```

### Property Value

CSS नियम का सीरियलाइज़ेशन लौटाता है। cssText एट्रिब्यूट सेट करने पर कुछ नहीं करना चाहिए।
