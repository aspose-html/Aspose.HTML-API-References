## IElementCSSInlineStyle.Style property

style एट्रिब्यूट को एक CSS घोषणा ब्लॉक ऑब्जेक्ट लौटाना चाहिए जिसका computed फ़्लैग अनसेट हो, जिसका पैरेंट CSS नियम null हो, और जिसका ओनर नोड कंटेक्स्ट ऑब्जेक्ट हो।

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

नोड के लिए संबंधित CSS घोषणा ब्लॉक या null यदि कोई संबंधित CSS घोषणा ब्लॉक नहीं है।
