## IElementCSSInlineStyle interface

तत्वों से जुड़ी इनलाइन शैली जानकारी style एट्रिब्यूट के माध्यम से उजागर की जाती है। यह HTML तत्वों के लिए STYLE एट्रिब्यूट की सामग्री का प्रतिनिधित्व करता है (या अन्य स्कीमा या DTD में उन तत्वों की जो समान रूप से STYLE एट्रिब्यूट का उपयोग करते हैं)। अपेक्षा है कि ElementCSSInlineStyle इंटरफ़ेस का एक उदाहरण Element इंटरफ़ेस के एक उदाहरण पर बाइंडिंग-विशिष्ट कास्टिंग विधियों का उपयोग करके प्राप्त किया जा सके जब तत्व इनलाइन CSS शैली जानकारी का समर्थन करता हो।

इसके अलावा देखें [CSS Object Model (CSSOM) # IElementCSSInlineStyle](https://www.w3.org/TR/cssom-1/#the-elementcssinlinestyle-mixin)

```java
public interface IElementCSSInlineStyle
```
