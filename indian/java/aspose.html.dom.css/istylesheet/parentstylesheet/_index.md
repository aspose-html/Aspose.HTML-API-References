## IStyleSheet.ParentStyleSheet property

स्टाइल शीट भाषाओं के लिए जो स्टाइल शीट इन्क्लूज़न की अवधारणा का समर्थन करती हैं, यह एट्रिब्यूट शामिल करने वाली स्टाइल शीट को दर्शाता है, यदि वह मौजूद है। यदि स्टाइल शीट टॉप-लेवल स्टाइल शीट है, या स्टाइल शीट भाषा इन्क्लूज़न का समर्थन नहीं करती है, तो इस एट्रिब्यूट का मान null होता है।

```java
public IStyleSheet ParentStyleSheet { get; }
```

### Property Value

parentStyleSheet एट्रिब्यूट को पैरेंट [`CSS style sheet`](../../icssstylesheet/) लौटाना चाहिए।

## Remarks

यदि वर्तमान स्टाइलशीट टॉप-लेवल स्टाइलशीट है या स्टाइलशीट इन्क्लूज़न समर्थित नहीं है, तो यह प्रॉपर्टी null लौटाती है।
