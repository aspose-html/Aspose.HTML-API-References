## IStyleSheet.Title property

[`StyleSheet`](../) इंटरफ़ेस की title प्रॉपर्टी वर्तमान स्टाइल शीट का सलाहकार शीर्षक लौटाती है।

title अक्सर [`ownerNode`](../ownernode/) में निर्दिष्ट किया जाता है।

```java
public String Title { get; }
```

### Property Value

parentStyleSheet एट्रिब्यूट को पैरेंट [`CSS style sheet`](../../icssstylesheet/) लौटाना चाहिए।
