## IStyleSheet.Media property

[`StyleSheet`](../) इंटरफ़ेस की media property style जानकारी के इच्छित गंतव्य मीडिया को निर्दिष्ट करती है। यह एक read-only, array-like [`MediaList`](../../imedialist/) ऑब्जेक्ट है और इसे deleteMedium() से हटाया जा सकता है और appendMedium() से जोड़ा जा सकता है।

```java
public IMediaList Media { get; }
```

### Property Value

media attribute को CSS style sheet से संबंधित [`MediaList`](../../imedialist/) ऑब्जेक्ट लौटाना चाहिए।
