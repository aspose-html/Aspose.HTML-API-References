## IStyleSheet.Href property

`[`StyleSheet`](../)` इंटरफ़ेस की href प्रॉपर्टी स्टाइल शीट का स्थान लौटाती है।

```java
public String Href { get; }
```

### Property Value

uri एक स्ट्रिंग है जिसमें स्टाइलशीट का URI शामिल है।

## टिप्पणियाँ

यदि स्टाइल शीट एक लिंक्ड स्टाइल शीट है, तो उसके एट्रिब्यूट का मान उसका स्थान होता है। इनलाइन स्टाइल शीट्स के लिए, इस एट्रिब्यूट का मान NULL होता है।

यह प्रॉपर्टी Firefox, Opera, Google Chrome, और Safari में केवल-रीड है, और Internet Explorer में पढ़ने/लिखने योग्य है।
