### Property Value

## Remarks

यदि शैली पत्रक एक लिंक्ड शैली पत्रक है, तो उसके एट्रिब्यूट का मान उसका स्थान होता है। इनलाइन शैली पत्रकों के लिए, इस एट्रिब्यूट का मान NULL होता है।

यह प्रॉपर्टी Firefox, Opera, Google Chrome, और Safari में केवल-पढ़ने योग्य है, और Internet Explorer में पढ़ने/लिखने योग्य है।
