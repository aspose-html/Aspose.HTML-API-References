## RGBColor.Blue property

इस Color संरचना का नीला घटक मान प्राप्त करता है।

```java
public CSSPrimitiveValue Blue { get; }
```

### Property Value

इस Color का नीला घटक मान।

## टिप्पणियाँ

प्रत्येक पिक्सेल का रंग 32-बिट संख्या के रूप में दर्शाया जाता है: अल्फा, लाल, हरा और नीला (ARGB) के लिए प्रत्येक 8 बिट। अल्फा घटक रंग की पारदर्शिता को निर्दिष्ट करता है: 0 पूरी तरह पारदर्शी है, और 255 पूरी तरह अपारदर्शी है। इसी प्रकार, A मान 255 एक अपारदर्शी रंग दर्शाता है। A मान 1 से 254 के बीच एक अर्ध-पारदर्शी रंग दर्शाता है। जैसे-जैसे A 255 के निकट आता है, रंग अधिक अपारदर्शी हो जाता है।
