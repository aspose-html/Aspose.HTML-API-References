## IDocumentStyle.StyleSheets property

एक सूची जिसमें सभी स्टाइल शीट्स शामिल हैं जो स्पष्ट रूप से दस्तावेज़ में लिंक या एम्बेड किए गए हैं। HTML दस्तावेज़ों के लिए इसमें HTML LINK एलिमेंट के माध्यम से शामिल बाहरी स्टाइल शीट्स और इनलाइन STYLE एलिमेंट्स शामिल होते हैं।

```java
public IStyleSheetList StyleSheets { get; }
```
