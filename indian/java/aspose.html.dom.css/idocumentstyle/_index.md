## IDocumentStyle interface

DocumentStyle इंटरफ़ेस एक तंत्र प्रदान करता है जिससे दस्तावेज़ में एम्बेडेड स्टाइल शीट्स को प्राप्त किया जा सकता है। अपेक्षा है कि DocumentStyle इंटरफ़ेस का एक उदाहरण Document इंटरफ़ेस के एक उदाहरण पर बाइंडिंग‑विशिष्ट कास्टिंग विधियों का उपयोग करके प्राप्त किया जा सकता है।

इसके अलावा देखें [Document Object Model (DOM) Level 2 Style Specification](http://www.w3.org/TR/2000/REC-DOM-Level-2-Style-20001113)।

```java
public interface IDocumentStyle
```
