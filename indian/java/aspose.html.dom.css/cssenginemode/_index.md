## CSSEngineMode enumeration

CSSEngine मोड को निर्दिष्ट करता है। मानों का निम्नलिखित अर्थ है:

डिफ़ॉल्ट - CSS पार्सर w3c सिफ़ारिश के अनुसार काम करेगा और कस्टम एक्सटेंशन का समर्थन नहीं करता। नॉन-स्ट्रिक्ट - सभी अनडॉक्यूमेंटेड प्रॉपर्टीज़ को पार्स किया जाएगा और उन्हें एक्सेस किया जा सकता है।

```java
[Flags]
public enum CSSEngineMode
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| Default | `0` | CSS पार्सर w3c सिफ़ारिश के अनुसार काम करेगा और कस्टम एक्सटेंशन का समर्थन नहीं करता। |
| NotStrict | `1` | CSS पार्सर नॉन-स्ट्रिक्ट मोड में काम करेगा। सभी अनडॉक्यूमेंटेड प्रॉपर्टीज़ को पार्स किया जाएगा और उन्हें एक्सेस किया जा सकता है। |
