## IDocumentCSS.GetOverrideStyle method

यह मेथड किसी निर्दिष्ट तत्व और किसी निर्दिष्ट pseudo-element के लिए ओवरराइड स्टाइल घोषणा को पुनः प्राप्त करने के लिए उपयोग किया जाता है।

```java
public ICSSStyleDeclaration GetOverrideStyle(Element elt, String pseudoElt)
```

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| elt | तत्व | वह तत्व जिसका स्टाइल संशोधित किया जाना है। यह पैरामीटर null नहीं हो सकता। |
| pseudoElt | String | pseudo-element या यदि कोई नहीं हो तो null। |

### रिटर्न वैल्यू

ओवरराइड स्टाइल घोषणा।
