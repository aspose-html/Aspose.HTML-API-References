## ICSSMediaRule.InsertRule method

CSSGroupingRule इंटरफ़ेस की insertRule() मेथड एक नया CSS नियम CSS नियमों की सूची में जोड़ती है।

```java
public long InsertRule(String rule, long index)
```

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| नियम | String | मीडिया नियम को CSSOMString के रूप में। |
| index | Int64 | एक वैकल्पिक इंडेक्स जहाँ नियम डालना है; डिफ़ॉल्ट 0 है। |

### रिटर्न वैल्यू

insertRule(rule, index) मेथड इंडेक्स पर चाइल्ड CSS नियमों में एक CSS नियम डालने के परिणाम को लौटाता है।
