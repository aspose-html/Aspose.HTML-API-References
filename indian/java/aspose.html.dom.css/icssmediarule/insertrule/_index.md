## ICSSMediaRule.InsertRule method

CSSGroupingRule इंटरफ़ेस की insertRule() मेथड एक नया CSS नियम CSS नियमों की सूची में जोड़ती है।

```java
public long InsertRule(String rule, long index)
```

| Parameter | Type | विवरण |
| --- | --- | --- |
| नियम | String | मीडिया नियम को CSSOMString के रूप में। |
| index | Int64 | एक वैकल्पिक सूचकांक जहाँ नियम डालना है; डिफ़ॉल्ट 0 है। |

### रिटर्न वैल्यू

insertRule(rule, index) मेथड उस परिणाम को लौटाता है जो निर्दिष्ट सूचकांक पर चाइल्ड CSS नियमों में एक CSS नियम डालने पर प्राप्त होता है।
