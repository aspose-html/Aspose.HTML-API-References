## ICSSMediaRule interface

CSSMediaRule इंटरफ़ेस CSS स्टाइल शीट में एक @media नियम का प्रतिनिधित्व करता है। एक @media नियम का उपयोग विशिष्ट मीडिया प्रकारों के लिए स्टाइल नियमों को सीमित करने के लिए किया जा सकता है।

```java
public interface ICSSMediaRule : ICSSRule
```
