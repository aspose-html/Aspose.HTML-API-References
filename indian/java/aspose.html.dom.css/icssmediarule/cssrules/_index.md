## ICSSMediaRule.CSSRules property

CSSGroupingRule इंटरफ़ेस की cssRules प्रॉपर्टी एक [`CSSRuleList`](../../icssrulelist/) लौटाती है जिसमें [`CSSRule`](../../icssrule/) वस्तुओं का संग्रह होता है।

```java
public ICSSRuleList CSSRules { get; }
```

### Property Value

cssRules एट्रिब्यूट को चाइल्ड CSS नियमों के लिए एक [`CSSRuleList`](../../icssrulelist/) ऑब्जेक्ट लौटाना चाहिए।
