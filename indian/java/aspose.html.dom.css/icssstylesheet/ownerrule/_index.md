## ICSSStyleSheet.OwnerRule property

केवल-पढ़ने योग्य CSSStyleSheet प्रॉपर्टी ownerRule वह [`CSSImportRule`](../../icssimportrule/) लौटाती है जो @import at-rule से संबंधित है जिसने शैली पत्रक को दस्तावेज़ में आयात किया। यदि शैली पत्रक को @import द्वारा दस्तावेज़ में आयात नहीं किया गया, तो लौटाया मान null है।

```java
public ICSSRule OwnerRule { get; }
```

### Property Value

एक CSSImportRule जो @import नियम से संबंधित है जिसने शैली पत्रक को दस्तावेज़ में आयात किया। यदि शैली पत्रक को @import द्वारा दस्तावेज़ में आयात नहीं किया गया, तो लौटाया मान null है।
