## ICSSStyleSheet.OwnerRule property

रीड-ओनली CSSStyleSheet प्रॉपर्टी ownerRule वह [`CSSImportRule`](../../icssimportrule/) लौटाती है जो @import एट-रूल के अनुरूप है जिसने स्टाइलशीट को दस्तावेज़ में इम्पोर्ट किया था। यदि स्टाइलशीट को @import का उपयोग करके दस्तावेज़ में इम्पोर्ट नहीं किया गया, तो लौटाया गया मान null है।

```java
public ICSSRule OwnerRule { get; }
```

### Property Value

एक CSSImportRule जो @import नियम के अनुरूप है जिसने स्टाइलशीट को दस्तावेज़ में इम्पोर्ट किया था। यदि स्टाइलशीट को @import का उपयोग करके दस्तावेज़ में इम्पोर्ट नहीं किया गया, तो लौटाया गया मान null है।
