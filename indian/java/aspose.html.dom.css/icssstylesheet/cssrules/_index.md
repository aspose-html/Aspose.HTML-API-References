## ICSSStyleSheet.CSSRules property

read-only CSSStyleSheet प्रॉपर्टी cssRules एक लाइव [`CSSRuleList`](../../icssrulelist/) लौटाती है जो स्टाइलशीट में मौजूद प्रत्येक CSS नियम की वास्तविक-समय, अद्यतन सूची प्रदान करती है। सूची में प्रत्येक आइटम एक [`CSSRule`](../../icssrule/) है जो एकल नियम को परिभाषित करता है।

```java
public ICSSRuleList CSSRules { get; }
```

### Property Value

एक लाइव-अपडेटिंग [`CSSRuleList`](../../icssrulelist/) जिसमें स्टाइलशीट बनाते हुए सभी CSS नियम शामिल हैं। नियम सूची में प्रत्येक प्रविष्टि एक [`CSSRule`](../../icssrule/) ऑब्जेक्ट है जो स्टाइलशीट बनाते हुए एक नियम का वर्णन करता है।

## Remarks

[CSSOM](https://drafts.csswg.org/cssom/) defines APIs (including generic parsing and serialization rules) for Media Queries, Selectors, and of course CSS itself.
