## ILinkStyle interface

LinkStyle इंटरफ़ेस एक तंत्र प्रदान करता है जिससे एक स्टाइल शीट को उस नोड से प्राप्त किया जा सकता है जो इसे दस्तावेज़ में लिंक करने के लिए जिम्मेदार है। LinkStyle इंटरफ़ेस का एक उदाहरण बाइंडिंग-विशिष्ट कास्टिंग विधियों का उपयोग करके एक लिंकिंग नोड (HTMLLinkElement,

HTMLStyleElement या ProcessingInstruction DOM Level 2 में)।

इसके अलावा देखें [CSS Object Model (CSSOM) # ](https://www.w3.org/TR/cssom-1/#the-linkstyle-interface)[LinkStyle](https://www.w3.org/TR/cssom-1/#the-linkstyle-interface)।
