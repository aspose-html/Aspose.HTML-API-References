## ICSSStyleRule interface

CSSStyleRule इंटरफ़ेस एक एकल CSS शैली नियम का प्रतिनिधित्व करता है। selectorText एट्रिब्यूट, प्राप्त करने पर, संबंधित चयनकर्ताओं के समूह को क्रमबद्ध करने के परिणाम को लौटाना चाहिए।

```java
public interface ICSSStyleRule : ICSSRule
```
