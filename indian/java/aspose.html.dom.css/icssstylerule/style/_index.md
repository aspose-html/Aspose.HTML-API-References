## ICSSStyleRule.Style property

रीड-ओनली स्टाइल प्रॉपर्टी [`CSSStyleDeclaration`](../../icssstyledeclaration/) इंटरफ़ेस है जो [`CSSStyleRule`](../) की घोषणा ब्लॉक के लिए है।

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

स्टाइल एट्रिब्यूट को स्टाइल नियम के लिए CSSStyleDeclaration ऑब्जेक्ट लौटाना चाहिए, जिसमें निम्नलिखित प्रॉपर्टी हों:

computed flag - Unset.declarations - नियम में घोषित घोषणाएँ, निर्दिष्ट क्रम में। parent CSS rule - संदर्भ ऑब्जेक्ट। owner node - Null।
