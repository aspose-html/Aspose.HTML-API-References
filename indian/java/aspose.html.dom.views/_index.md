**com.aspose.html.dom.views** package describes AbstractView and DocumentView interfaces according Document Object Model Views specification.

## इंटरफ़ेस

| इंटरफ़ेस | विवरण |
| --- | --- |
| [IAbstractView](./iabstractview/) | एक बेस इंटरफ़ेस जिससे सभी व्यूज़ को व्युत्पन्न होना चाहिए। |
| [IDocumentView](./idocumentview/) | DocumentView इंटरफ़ेस DOM Views का समर्थन करने वाले DOM कार्यान्वयन में Document वस्तुओं द्वारा लागू किया जाता है। यह दस्तावेज़ के डिफ़ॉल्ट व्यू को प्राप्त करने के लिए एक एट्रिब्यूट प्रदान करता है। |
