**com.aspose.html.dom.views** package describes AbstractView and DocumentView interfaces according Document Object Model Views specification.

## इंटरफ़ेस

| इंटरफ़ेस | विवरण |
| --- | --- |
| [IAbstractView](./iabstractview/) | एक बेस इंटरफ़ेस जिससे सभी व्यूज़ व्युत्पन्न होंगे। |
| [IDocumentView](./idocumentview/) | DocumentView इंटरफ़ेस DOM व्यूज़ का समर्थन करने वाले DOM कार्यान्वयन में Document ऑब्जेक्ट्स द्वारा लागू किया जाता है। यह दस्तावेज़ के डिफ़ॉल्ट व्यू को प्राप्त करने के लिए एक एट्रिब्यूट प्रदान करता है। |
