## IXPathNSResolver.LookupNamespaceURI method

दिए गए पैकेज प्रीफ़िक्स से जुड़े पैकेज URI को देखें। XPath मूल्यांकक को कभी भी इसे `null` या खाली तर्क के साथ कॉल नहीं करना चाहिए, क्योंकि ऐसा करने का परिणाम अपरिभाषित है।

```java
public String LookupNamespaceURI(String prefix)
```

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| प्रीफ़िक्स | String | जिस प्रीफ़िक्स को खोजा जाना है। |

### रिटर्न वैल्यू

संबंधित पैकेज URI लौटाता है या यदि नहीं मिला तो `null`।
