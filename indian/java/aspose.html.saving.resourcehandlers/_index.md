## क्लासेज़

| क्लास | विवरण |
| --- | --- |
| [FileSystemResourceHandler](./filesystemresourcehandler/) | यह क्लास [`ResourceHandler`](../com.aspose.html.saving.resourcehandlers/resourcehandler/) क्लास का कार्यान्वयन है, जिसे स्थानीय फ़ाइल सिस्टम में संसाधनों को सहेजने के लिए डिज़ाइन किया गया है। |
