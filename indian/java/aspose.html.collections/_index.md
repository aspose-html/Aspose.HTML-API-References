The **com.aspose.html.collections** पैकेज में नोड्स और एलिमेंट्स को प्रदर्शित, संग्रहीत और हेरफेर करने वाली क्लासेज़ शामिल हैं।

## क्लासेस

| क्लास | विवरण |
| --- | --- |
| [DOMTokenList](./domtokenlist/) | DOMTokenList क्लास स्पेस-सेपरेटेड टोकन्स का एक सेट दर्शाती है। यह जावास्क्रिप्ट एरे ऑब्जेक्ट्स की तरह 0 से शुरू होकर इंडेक्स किया जाता है। DOMTokenList हमेशा केस-सेंसिटिव रहती है। |
| [HTMLCollection](./htmlcollection/) | `[HTMLCollection](../com.aspose.html.collections/htmlcollection/)` एक सामान्य संग्रह को दर्शाता है जिसमें `[Element](../com.aspose.html.dom/element/)` शामिल होते हैं। |
| [NamedNodeMap](./namednodemap/) | नाम द्वारा एक्सेस किए जा सकने वाले एट्रिब्यूट्स के संग्रह को दर्शाता है। |
| [NodeList](./nodelist/) | NodeList नोड्स के क्रमबद्ध संग्रह का एब्स्ट्रैक्शन प्रदान करता है, बिना यह परिभाषित या प्रतिबंधित किए कि यह संग्रह कैसे लागू किया गया है। |
