यह **com.aspose.html.collections** पैकेज नोड्स और एलिमेंट्स को प्रतिनिधित्व, संग्रहित और हेरफेर करने वाली क्लासों से बना है।

## क्लासेज़

| क्लास | विवरण |
| --- | --- |
| [DOMTokenList](./domtokenlist/) | DOMTokenList क्लास स्पेस-सेपरेटेड टोकन्स का एक सेट दर्शाती है। यह जावास्क्रिप्ट एरे ऑब्जेक्ट्स की तरह 0 से शुरू होने वाले इंडेक्स पर आधारित है। DOMTokenList हमेशा केस-सेंसिटिव रहती है। |
| [HTMLCollection](./htmlcollection/) | `HTMLCollection`([../com.aspose.html.collections/htmlcollection/]) एक सामान्य संग्रह को दर्शाता है जिसमें `Element`([../com.aspose.html.dom/element/]) शामिल होते हैं। |
| [NamedNodeMap](./namednodemap/) | ऐसे एट्रिब्यूट्स के संग्रह को दर्शाता है जिन्हें नाम द्वारा एक्सेस किया जा सकता है। |
| [NodeList](./nodelist/) | NodeList नोड्स के क्रमबद्ध संग्रह का एब्स्ट्रैक्शन प्रदान करता है, बिना यह परिभाषित या प्रतिबंधित किए कि यह संग्रह कैसे लागू किया गया है। |
