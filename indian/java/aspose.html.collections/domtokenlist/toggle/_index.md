## Toggle(String) {#toggle}

यदि टोकन मौजूद है तो उसे सूची से हटाता है, या यदि नहीं है तो टोकन को सूची में जोड़ता है।

```java
public bool Toggle(String token)
```

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| टोकन | String | वह टोकन जिसे आप टॉगल करना चाहते हैं। |

### रिटर्न वैल्यू

एक Boolean जो दर्शाता है कि कॉल के बाद टोकन सूची में है या नहीं।

## Toggle(String, bool) {#toggle_1}

यदि टोकन मौजूद है तो उसे सूची से हटाता है, या यदि नहीं है तो टोकन को सूची में जोड़ता है।

```java
public bool Toggle(String token, bool force)
```

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| टोकन | String | वह टोकन जिसे आप टॉगल करना चाहते हैं। |
| force | Boolean | एक Boolean जो, यदि शामिल किया गया हो, टॉगल को केवल‑एक‑तरफ़ा ऑपरेशन बनाता है। यदि false सेट किया गया है, तो टोकन केवल हटाया जाएगा, लेकिन जोड़ा नहीं जाएगा। यदि true सेट किया गया है, तो टोकन केवल जोड़ा जाएगा, लेकिन हटाया नहीं जाएगा। |

### रिटर्न वैल्यू

एक Boolean जो दर्शाता है कि कॉल के बाद टोकन सूची में है या नहीं।
