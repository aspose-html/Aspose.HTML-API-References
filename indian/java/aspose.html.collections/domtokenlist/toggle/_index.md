## Toggle(String, bool) {#toggle_1}

यदि टोकन मौजूद है तो उसे सूची से हटाता है, या यदि नहीं है तो टोकन को सूची में जोड़ता है।

```java
public bool Toggle(String token, bool force)
```

| Parameter | Type | विवरण |
| --- | --- | --- |
| token | String | वह टोकन जिसे आप टॉगल करना चाहते हैं। |
| force | Boolean | एक बूलियन जो, यदि शामिल किया गया हो, टॉगल को केवल‑एक‑तरफ़ा ऑपरेशन बनाता है। यदि false सेट किया गया है, तो टोकन केवल हटाया जाएगा, लेकिन नहीं जोड़ा जाएगा। यदि true सेट किया गया है, तो टोकन केवल जोड़ा जाएगा, लेकिन नहीं हटाया जाएगा। |

### रिटर्न वैल्यू
