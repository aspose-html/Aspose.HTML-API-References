## DOMTokenList.Replace method

एक मौजूदा टोकन को नए टोकन से बदलता है। यदि पहला टोकन मौजूद नहीं है तो कुछ नहीं करता।

```java
public bool Replace(String token, String newToken)
```

| Parameter | Type | विवरण |
| --- | --- | --- |
| token | String | आप जिस टोकन को बदलना चाहते हैं। |
| newToken | String | आप जिस टोकन से पुराने टोकन को बदलना चाहते हैं। |

### रिटर्न वैल्यू

यदि टोकन मिला और बदला गया हो तो Boolean `true`, अन्यथा `false`।
