## IWindow.Top property

Window वस्तु के Document के एक browsing context b में top IDL attribute को उसके top-level browsing context का WindowProxy object लौटाना चाहिए (यदि वह स्वयं एक top-level browsing context है तो उसका अपना WindowProxy object होगा), यदि उसके पास एक है, या अन्यथा उसका अपना WindowProxy object (उदाहरण के लिए यदि वह एक detached nested browsing context था)।

```java
public IWindow Top { get; }
```
