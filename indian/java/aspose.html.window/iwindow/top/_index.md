## IWindow.Top property

एक Document के Window ऑब्जेक्ट पर ब्राउज़िंग कॉन्टेक्स्ट b में शीर्ष IDL एट्रिब्यूट को उसके टॉप-लेवल ब्राउज़िंग कॉन्टेक्स्ट का WindowProxy ऑब्जेक्ट लौटाना चाहिए (जो कि यदि वह स्वयं टॉप-लेवल ब्राउज़िंग कॉन्टेक्स्ट है तो उसका अपना WindowProxy ऑब्जेक्ट होगा), यदि उसके पास एक है, अन्यथा उसका अपना WindowProxy ऑब्जेक्ट (उदाहरण के लिए यदि वह एक डिटैच्ड नेस्टेड ब्राउज़िंग कॉन्टेक्स्ट था)।

```java
public IWindow Top { get; }
```
