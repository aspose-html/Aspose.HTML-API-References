## IWindow.Prompt method

दिए गए संदेश के साथ एक मोडल टेक्स्ट फ़ील्ड प्रॉम्प्ट प्रदर्शित करता है, उपयोगकर्ता के इसे बंद करने की प्रतीक्षा करता है, और उपयोगकर्ता द्वारा दर्ज किया गया मान लौटाता है। यदि उपयोगकर्ता प्रॉम्प्ट को रद्द करता है तो null लौटाता है। यदि दूसरा तर्क मौजूद है, तो दिया गया मान डिफ़ॉल्ट के रूप में उपयोग किया जाता है।

```java
public String Prompt(String message, String @default)
```

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| message | String | संदेश। |
| डिफ़ॉल्ट | String | डिफ़ॉल्ट। |

### रिटर्न वैल्यू
