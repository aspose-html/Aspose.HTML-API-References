## IWindow.MatchMedia method

एक नया MediaQueryList ऑब्जेक्ट लौटाता है जिसे फिर दस्तावेज़ यह निर्धारित करने के लिए उपयोग किया जा सकता है कि वह मीडिया क्वेरी स्ट्रिंग से मेल खाता है या नहीं, साथ ही दस्तावेज़ की निगरानी करने के लिए ताकि पता चल सके कि वह कब मेल खाता है (या मेल नहीं खाता)। देखें CSSOM View Module विनिर्देशन: [https://www.w3.org/TR/cssom-view/#extensions-to-the-window-interface](https://www.w3.org/TR/cssom-view/#extensions-to-the-window-interface)

```java
public MediaQueryList MatchMedia(String query)
```

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| query | String | media query वाली स्ट्रिंग; विवरण के लिए देखें [https://drafts.csswg.org/mediaqueries/](https://drafts.csswg.org/mediaqueries/)। |
