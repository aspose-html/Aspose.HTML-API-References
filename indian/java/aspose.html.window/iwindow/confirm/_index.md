## IWindow.Confirm method

दिए गए संदेश के साथ एक मोडल OK/Cancel प्रॉम्प्ट प्रदर्शित करता है, उपयोगकर्ता के इसे बंद करने की प्रतीक्षा करता है, और यदि उपयोगकर्ता OK क्लिक करता है तो true लौटाता है और यदि Cancel क्लिक करता है तो false लौटाता है।

```java
public bool Confirm(String message)
```

| Parameter | Type | विवरण |
| --- | --- | --- |
| message | String | संदेश। |

### रिटर्न वैल्यू

यदि उपयोगकर्ता OK क्लिक करता है तो true लौटाता है और यदि उपयोगकर्ता Cancel क्लिक करता है तो false लौटाता है।
