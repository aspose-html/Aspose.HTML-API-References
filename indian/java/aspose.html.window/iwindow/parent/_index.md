## IWindow.Parent property

ब्राउज़िंग कॉन्टेक्स्ट b में एक दस्तावेज़ के Window ऑब्जेक्ट पर पैरेंट IDL एट्रिब्यूट को पैरेंट ब्राउज़िंग कॉन्टेक्स्ट का WindowProxy ऑब्जेक्ट लौटाना चाहिए, यदि वह मौजूद है (अर्थात यदि b एक चाइल्ड ब्राउज़िंग कॉन्टेक्स्ट है), या अन्यथा ब्राउज़िंग कॉन्टेक्स्ट b स्वयं का WindowProxy ऑब्जेक्ट (अर्थात यदि यह टॉप-लेवल ब्राउज़िंग कॉन्टेक्स्ट है या एक डिटैच्ड नेस्टेड ब्राउज़िंग कॉन्टेक्स्ट है)।
