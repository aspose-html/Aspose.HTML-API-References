यह **com.aspose.html.window** पैकेज विंडो ऑब्जेक्ट से संबंधित है जो DOM दस्तावेज़ को शामिल करने वाली विंडो का प्रतिनिधित्व करता है। इसमें सक्रिय दस्तावेज़ पते और ब्राउज़िंग इतिहास से संबंधित क्लासेस और इंटरफ़ेस शामिल हैं।
