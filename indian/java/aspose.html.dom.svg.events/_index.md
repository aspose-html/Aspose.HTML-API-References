यह पैकेज टाइम इवेंट्स और ज़ूमिंग जैसे इवेंट‑आधारित इंटरैक्टिविटी के लिए क्लासों से बना है।

## क्लासेज़

| क्लास | विवरण |
| --- | --- |
| [SVGZoomEvent](./svgzoomevent/) | ज़ूम इवेंट तब होता है जब उपयोगकर्ता कोई कार्रवाई शुरू करता है जिससे SVG दस्तावेज़ फ्रैगमेंट का वर्तमान दृश्य पुनः स्केल हो जाता है। इवेंट हैंडलर केवल ‘svg’ तत्वों पर ही मान्य होते हैं। |
| [TimeEvent](./timeevent/) | TimeEvent इंटरफ़ेस टाइम इवेंट्स से संबंधित विशिष्ट संदर्भात्मक जानकारी प्रदान करता है। उत्पन्न हो सकने वाले विभिन्न प्रकार के इवेंट्स हैं: beginEvent, endEvent और repeatEvent। |
