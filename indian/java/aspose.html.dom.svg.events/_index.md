पैकेज में टाइम इवेंट्स और ज़ूमिंग जैसी इवेंट‑आधारित इंटरैक्टिविटी के लिए क्लासेज़ शामिल हैं।

## क्लासेस

| क्लास | विवरण |
| --- | --- |
| [SVGZoomEvent](./svgzoomevent/) | ज़ूम इवेंट तब होता है जब उपयोगकर्ता कोई कार्रवाई शुरू करता है जिससे SVG दस्तावेज़ फ्रैगमेंट का वर्तमान दृश्य पुनः स्केल हो जाता है। इवेंट हैंडलर केवल ‘svg’ तत्वों पर मान्य होते हैं। |
| [TimeEvent](./timeevent/) | TimeEvent इंटरफ़ेस टाइम इवेंट्स से संबंधित विशिष्ट संदर्भात्मक जानकारी प्रदान करता है। विभिन्न प्रकार के इवेंट्स जो हो सकते हैं वे हैं: beginEvent, endEvent और repeatEvent। |
