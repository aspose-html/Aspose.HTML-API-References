यह **com.aspose.html.dom.mutations** DOM म्यूटेशन्स को निरीक्षण करने और विशिष्ट कॉलबैक जानकारी प्राप्त करने का अवसर प्रदान करता है।

## क्लासेज़

| क्लास | विवरण |
| --- | --- |
| [MutationCallback](./mutationcallback/) | एक मेथड को दर्शाता है जो म्यूटेशन इवेंट्स को संभालेगा। |
| [MutationObserver](./mutationobserver/) | एक ऑब्जेक्ट का उपयोग `.`([../com.aspose.html.dom/node/]) के ट्री में म्यूटेशन्स को देखने के लिए किया जा सकता है। |
| [MutationObserverInit](./mutationobserverinit/) | यह क्लास विकल्पों के संग्रह का प्रतिनिधित्व करती है जिसका उपयोग [`MutationObserver`](../com.aspose.html.dom.mutations/mutationobserver/) को कॉन्फ़िगर करने के लिए किया जाता है। |
| [MutationRecord](./mutationrecord/) | एक MutationRecord व्यक्तिगत DOM म्यूटेशन का प्रतिनिधित्व करता है। यह वह ऑब्जेक्ट है जो [`MutationObserver`](../com.aspose.html.dom.mutations/mutationobserver/)'s [`MutationCallback`](../com.aspose.html.dom.mutations/mutationcallback/) को पास किया जाता है। |
