**com.aspose.html.saving** पैकेज रूपांतरण/सेविंग प्रक्रिया में विशिष्ट सेव विकल्पों के विवरण के लिए डेटा क्लासेज़ द्वारा प्रस्तुत किया गया है।

## क्लासेज़

| क्लास | विवरण |
| --- | --- |
| [DocSaveOptions](./docsaveoptions/) | विशिष्ट विकल्पों की डेटा क्लास। गुणों को असाइन करके आप रिज़ॉल्यूशन, पेज आकार, बैकग्राउंड रंग जैसी रेंडरिंग विशेषताओं तथा फ़ॉन्ट एम्बेडिंग जैसे दस्तावेज़-विशिष्ट विकल्पों को प्रबंधित कर सकते हैं। अधिक जानकारी के लिए दस्तावेज़ देखें [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-docx/#save-options). |
| [HTMLSaveOptions](./htmlsaveoptions/) | HTML सहेजने के विकल्पों का प्रतिनिधित्व करता है। विशिष्ट गुणों को असाइन करके आप अधिकतम हैंडलिंग गहराई आदि जैसी संसाधन प्रोसेसिंग को प्रबंधित कर सकते हैं। अधिक जानकारी के लिए दस्तावेज़ देखें [article](https://docs.aspose.com/html/net/working-with-documents/saving-a-document/). |
| [ImageSaveOptions](./imagesaveoptions/) | विशिष्ट विकल्पों की डेटा क्लास। यह इमेज परिणाम रिज़ॉल्यूशन, स्मूदिंग क्वालिटी, फ़ॉर्मेट तथा पेज सेटिंग्स आदि को प्रबंधित करने के लिए गुण प्रदान करती है। अधिक जानकारी आप दस्तावेज़ में प्राप्त कर सकते हैं [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-jpg/#save-options). |
| [MarkdownSaveOptions](./markdownsaveoptions/) | Markdown सहेजने के विकल्पों का प्रतिनिधित्व करता है। उदाहरण के लिए, आप markdown फ़ॉर्मेटिंग शैली सेट कर सकते हैं, पूर्वनिर्धारित GitLab Flavored Markdown संगत विकल्पों का उपयोग कर सकते हैं और संसाधन हैंडलिंग को कॉन्फ़िगर कर सकते हैं। अधिक जानकारी के लिए देखें [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-markdown/#save-options). |
| [MHTMLSaveOptions](./mhtmlsaveoptions/) | MHTML सहेजने के विकल्पों का प्रतिनिधित्व करता है। विशिष्ट गुणों को असाइन करके आप अधिकतम हैंडलिंग गहराई आदि जैसी संसाधन प्रोसेसिंग को प्रबंधित कर सकते हैं। अधिक जानकारी के लिए दस्तावेज़ देखें [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-mhtml/#save-options). |
| [PdfSaveOptions](./pdfsaveoptions/) | विशिष्ट डेटा क्लास रूपांतरण परिणाम को प्रबंधित करने के लिए कुछ गुण प्रदान करती है। उदाहरण के लिए [`PageSetup`](../com.aspose.html.rendering/pagesetup/) पेज की विशेषताओं को निर्दिष्ट करता है। दस्तावेज़ देखें [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-pdf/#convert-html-to-pdf-using-pdfsaveoptions). |
| [Resource](./resource/) | यह क्लास एक संसाधन का वर्णन करती है और उसे प्रोसेस करने के लिए मेथड्स प्रदान करती है। |
| [ResourceHandlingContext](./resourcehandlingcontext/) | यह क्लास संसाधनों को प्रोसेस करते समय उपयोग की जाने वाली जानकारी रखती है। |
| [ResourceHandlingOptions](./resourcehandlingoptions/) | संसाधन हैंडलिंग विकल्पों का प्रतिनिधित्व करता है। |
| [SaveOptions](./saveoptions/) | यह एक एब्स्ट्रैक्ट बेस क्लास है उन क्लासों के लिए जो उपयोगकर्ता को किसी विशेष फ़ॉर्मेट में दस्तावेज़ सहेजते समय अतिरिक्त विकल्प निर्दिष्ट करने की अनुमति देती हैं। |
| [TextSaveOptions](./textsaveoptions/) | Text सहेजने के विकल्पों का प्रतिनिधित्व करता है |
| [XpsSaveOptions](./xpssaveoptions/) | विशिष्ट विकल्पों की डेटा क्लास रूपांतरण परिणाम को प्रबंधित करने के लिए कुछ गुण प्रदान करती है। उदाहरण के लिए [`PageSetup`](../com.aspose.html.rendering/pagesetup/) पेज की विशेषताओं को निर्दिष्ट करता है। दस्तावेज़ देखें [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-xps/#save-options). |
