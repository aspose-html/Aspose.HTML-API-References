## TextSaveOptions.EnableListItemMarkers property

HTML को टेक्स्ट में बदलते समय OL, UL तत्वों पर लागू विकल्प। वास्तव में यह निर्धारित करता है कि OL और UL तत्वों के बाहरी सूची मार्करों को कैसे प्रोसेस किया जाए। यदि true है, तो OL आइटम्स से पहले आइटम नंबर जोड़े जाते हैं, या UL आइटम्स से पहले डॉट्स जोड़े जाते हैं। यदि false है, तो उन्हें नहीं जोड़ा जाता (डिफ़ॉल्ट व्यवहार विनिर्देश के अनुसार)।

```java
public bool EnableListItemMarkers { get; set; }
```
