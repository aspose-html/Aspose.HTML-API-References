## DocDevice.MoveTo method

वर्तमान बिंदु को पैरामीटर pt के निर्देशांक पर ले जाकर एक नया उपपथ शुरू करता है, किसी भी जोड़ने वाली रेखा खंड को छोड़ते हुए। यदि वर्तमान पथ में पिछली पथ निर्माण विधि भी \"MoveTo\" थी, तो नई \"MoveTo\" उसे ओवरराइड करती है; पिछले \"MoveTo\" ऑपरेशन का कोई अंश पथ में नहीं रहता।

```java
public void MoveTo(PointF pt)
```
