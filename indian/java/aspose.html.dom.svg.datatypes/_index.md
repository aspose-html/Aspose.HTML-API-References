| [SVGLengthList](./svglengthlist/) | यह इंटरफ़ेस SVGLength ऑब्जेक्ट्स की एक सूची को परिभाषित करता है। |

| [SVGPointList](./svgpointlist/) | यह इंटरफ़ेस SVGPoint ऑब्जेक्ट्स की एक सूची को परिभाषित करता है। |

| [SVGRect](./svgrect/) | आयताकार ज्यामिति का प्रतिनिधित्व करता है। आयतें (x,y) निर्देशांक युग्म से बनी होती हैं जो न्यूनतम X मान, न्यूनतम Y मान, तथा चौड़ाई और ऊँचाई को पहचानती हैं, जो आमतौर पर गैर‑नकारात्मक होने तक सीमित रहती हैं। |
| [SVGStringList](./svgStringlist/) | SVGStringList में अन्य SVGxxxList इंटरफ़ेसों के समान गुण और विधियाँ हैं। कार्यान्वयनकर्ता विभिन्न SVGxxxList इंटरफ़ेसों को लागू करने के लिए एकल बेस क्लास का उपयोग करने पर विचार कर सकते हैं। |
