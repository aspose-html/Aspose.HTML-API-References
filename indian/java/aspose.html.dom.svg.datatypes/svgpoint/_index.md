## SVGPoint class

SVG DOM के कई इंटरफ़ेस क्लास SVGPoint की वस्तुओं का उल्लेख करते हैं। एक SVGPoint (x, y) निर्देशांक युग्म है। मैट्रिक्स ऑपरेशनों में उपयोग होने पर, SVGPoint को इस रूप के वेक्टर के रूप में माना जाता है: [x] [y] [1] यदि किसी SVGRect ऑब्जेक्ट को केवल‑पढ़ने योग्य निर्धारित किया जाता है, तो उसके किसी गुण को असाइन करने का प्रयास करने पर एक अपवाद उत्पन्न होगा।

```java
public class SVGPoint : SVGValueType
```
