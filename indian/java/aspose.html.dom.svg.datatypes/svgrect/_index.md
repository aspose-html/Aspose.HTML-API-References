## SVGRect class

आयताकार ज्यामिति का प्रतिनिधित्व करता है। आयतें (x,y) निर्देशांक युग्म से बनी होती हैं जो न्यूनतम X मान, न्यूनतम Y मान, तथा चौड़ाई और ऊँचाई को पहचानती हैं, जो आमतौर पर गैर‑नकारात्मक होने तक सीमित रहती हैं।

```java
public class SVGRect : SVGValueType
```
