## NodeFilter.SHOW_ENTITY field

Entity नोड्स दिखाएँ। यह केवल तब अर्थपूर्ण है जब Entity नोड को रूट के रूप में लेकर एक इटरेटर या ट्री-वॉकर बनाया जाता है; इस स्थिति में, इसका मतलब है कि Entity नोड ट्रैवर्सल की पहली स्थिति में दिखाई देगा। चूँकि एंटिटीज़ दस्तावेज़ ट्री का हिस्सा नहीं हैं, वे दस्तावेज़ ट्री पर ट्रैवर्स करते समय दिखाई नहीं देते।

```java
public const long SHOW_ENTITY;
```
