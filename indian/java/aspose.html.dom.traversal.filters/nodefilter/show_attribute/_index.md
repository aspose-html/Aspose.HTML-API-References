## NodeFilter.SHOW_ATTRIBUTE field

Attr नोड्स दिखाएँ। यह केवल तब अर्थपूर्ण है जब एट्रिब्यूट नोड को रूट के रूप में लेकर एक इटरेटर या ट्री-वॉकर बनाया जाता है; इस स्थिति में, इसका मतलब है कि एट्रिब्यूट नोड इटरेशन या ट्रैवर्सल की पहली स्थिति में दिखाई देगा। चूँकि एट्रिब्यूट कभी भी अन्य नोड्स के बच्चे नहीं होते, वे दस्तावेज़ ट्री पर ट्रैवर्स करते समय दिखाई नहीं देते।

```java
public const long SHOW_ATTRIBUTE;
```
