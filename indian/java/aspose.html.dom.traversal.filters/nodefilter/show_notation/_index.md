## NodeFilter.SHOW_NOTATION field

Notation नोड्स दिखाएँ। यह केवल तब अर्थपूर्ण होता है जब आप एक iterator या tree-walker को Notation नोड को मूल (root) के रूप में बनाते हैं; इस स्थिति में, इसका मतलब है कि Notation नोड traversal की पहली स्थिति में दिखाई देगा। चूँकि notations दस्तावेज़ वृक्ष (document tree) का हिस्सा नहीं हैं, वे दस्तावेज़ वृक्ष के ऊपर traversal करते समय दिखाई नहीं देते।

```java
public const long SHOW_NOTATION;
```
