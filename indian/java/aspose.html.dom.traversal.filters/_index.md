पैकेज नोड फ़िल्टरिंग कार्यक्षमता द्वारा प्रतिनिधित्व किया गया है। फ़िल्टर ऐसे ऑब्जेक्ट हैं जो नोड्स को "फ़िल्टर आउट" करना जानते हैं। यदि किसी नोड इटरेटर या ट्री वॉकर को नोड फ़िल्टर दिया जाता है, तो यह अगला नोड लौटाने से पहले फ़िल्टर लागू करता है। यदि फ़िल्टर नोड को स्वीकार करने को कहता है, तो ट्रैवर्सल लॉजिक उसे लौटाता है; अन्यथा, ट्रैवर्सल अगले नोड की तलाश करता है और यह मान लेता है कि अस्वीकृत नोड मौजूद नहीं था।
