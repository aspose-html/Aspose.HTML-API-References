## PageSetup.AdjustToWidestPage property

फ़्लैग प्राप्त करता है या सेट करता है जो निर्धारित करता है कि दस्तावेज़ में सबसे चौड़े पृष्ठ के अनुसार पृष्ठ आकार को कब समायोजित किया जाएगा। यह विकल्प समय‑साध्य है इसलिए दस्तावेज़ प्रसंस्करण का समय दो गुना बढ़ सकता है। समायोजन केवल तब होगा जब दस्तावेज़ में सबसे चौड़ा पृष्ठ [`PageSetup`](../) में निर्धारित पृष्ठ आकार से बड़ा हो। समायोजित पृष्ठ आकार सभी पृष्ठों में उपयोग किया जाएगा।

```java
public bool AdjustToWidestPage { get; set; }
```
