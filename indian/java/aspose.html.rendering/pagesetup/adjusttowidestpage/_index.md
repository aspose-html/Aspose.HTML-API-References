## PageSetup.AdjustToWidestPage property

फ़्लैग प्राप्त करता है या सेट करता है जो निर्धारित करता है कि दस्तावेज़ में सबसे चौड़े पेज के अनुसार पेज आकार कब समायोजित किया जाएगा। यह विकल्प समय‑साध्य है इसलिए दस्तावेज़ प्रोसेसिंग का समय दो गुना बढ़ सकता है। समायोजन केवल तभी होगा जब दस्तावेज़ में सबसे चौड़ा पेज, [`PageSetup`](../) में निर्धारित पेज आकार से बड़ा हो। समायोजित पेज आकार सभी पेजों में उपयोग किया जाएगा।

```java
public bool AdjustToWidestPage { get; set; }
```
