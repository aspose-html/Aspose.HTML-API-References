## FillRule enumeration

SVG और HTML रेंडरिंग में उपयोग किए जाने वाले फ़िल नियम को निर्दिष्ट करता है।

```java
public enum FillRule
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| EvenOdd | `0` | इवन-ऑड नियम का उपयोग करके फ़िल क्षेत्र निर्धारित करता है। यह व्यवहार System.Drawing.Drawing2D.FillMode.Alternate के अनुरूप है। |
| Nonzero | `1` | नॉन-ज़ीरो नियम का उपयोग करके फ़िल क्षेत्र निर्धारित करता है। यह व्यवहार System.Drawing.Drawing2D.FillMode.Winding के अनुरूप है। |
