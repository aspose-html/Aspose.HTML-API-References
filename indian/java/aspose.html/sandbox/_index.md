## Sandbox enumeration

सैंडबॉक्सिंग फ़्लैग सेट निम्नलिखित फ़्लैग्स में से शून्य या अधिक का सेट है, जिसका उपयोग संभावित अविश्वसनीय संसाधनों की क्षमताओं को सीमित करने के लिए किया जाता है।

```java
[Flags]
public enum Sandbox
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| None | `0` | कोई फ़्लैग सेट नहीं है, सभी सैंडबॉक्स सुविधाएँ स्वीकार की गई हैं |
| Navigation | `1` | यह फ़्लैग सामग्री को सैंडबॉक्स्ड ब्राउज़िंग कॉन्टेक्स्ट स्वयं (या उसके भीतर नेस्टेड अतिरिक्त ब्राउज़िंग कॉन्टेक्स्ट) के अलावा अन्य ब्राउज़िंग कॉन्टेक्स्ट में नेविगेट करने से रोकता है, सहायक ब्राउज़िंग कॉन्टेक्स्ट (जो अगले परिभाषित सैंडबॉक्स्ड सहायक नेविगेशन ब्राउज़िंग कॉन्टेक्स्ट फ़्लैग द्वारा संरक्षित हैं), और शीर्ष-स्तर ब्राउज़िंग कॉन्टेक्स्ट (जो नीचे परिभाषित सैंडबॉक्स्ड शीर्ष-स्तर नेविगेशन ब्राउज़िंग कॉन्टेक्स्ट फ़्लैग द्वारा संरक्षित है)। यदि सैंडबॉक्स्ड सहायक नेविगेशन ब्राउज़िंग कॉन्टेक्स्ट फ़्लैग सेट नहीं है, तो कुछ मामलों में प्रतिबंध फिर भी पॉपअप (नए शीर्ष-स्तर ब्राउज़िंग कॉन्टेक्स्ट) को खोलने की अनुमति देते हैं। ये ब्राउज़िंग कॉन्टेक्स्ट हमेशा एक अनुमत सैंडबॉक्स्ड नेविगेटर रखते हैं, जो ब्राउज़िंग कॉन्टेक्स्ट के निर्माण के समय सेट किया जाता है, और जिससे उन्हें बनाने वाला ब्राउज़िंग कॉन्टेक्स्ट वास्तव में उन्हें नेविगेट कर सकता है। (अन्यथा, सैंडबॉक्स्ड नेविगेशन ब्राउज़िंग कॉन्टेक्स्ट फ़्लैग उन्हें नेविगेट होने से रोक देगा, भले ही वे खोले गए हों)। |
| AuxiliaryNavigation | `2` | यह फ़्लैग सामग्री को नए सहायक ब्राउज़िंग कॉन्टेक्स्ट बनाने से रोकता है, जैसे कि target एट्रिब्यूट का उपयोग करना, या window.open() मेथड। |
| TopLevelNavigation | `4` | यह फ़्लैग सामग्री को उनके शीर्ष-स्तर ब्राउज़िंग कॉन्टेक्स्ट में नेविगेट करने और उसे बंद करने से रोकता है। जब सैंडबॉक्स्ड शीर्ष-स्तर नेविगेशन ब्राउज़िंग कॉन्टेक्स्ट फ़्लैग सेट नहीं होता, तो सामग्री अपने शीर्ष-स्तर ब्राउज़िंग कॉन्टेक्स्ट को नेविगेट कर सकती है, लेकिन अन्य ब्राउज़िंग कॉन्टेक्स्ट अभी भी सैंडबॉक्स्ड नेविगेशन ब्राउज़िंग कॉन्टेक्स्ट फ़्लैग और संभवतः सैंडबॉक्स्ड सहायक नेविगेशन ब्राउज़िंग कॉन्टेक्स्ट फ़्लैग द्वारा संरक्षित रहते हैं। |
| Plugins | `8` | यह फ़्लैग सामग्री को प्लगइन्स को इंस्टैंशिएट करने से रोकता है, चाहे embed एलिमेंट, object एलिमेंट, applet एलिमेंट का उपयोग हो, या नेस्टेड ब्राउज़िंग कॉन्टेक्स्ट के नेविगेशन के माध्यम से, जब तक कि उन प्लगइन्स को सुरक्षित नहीं किया जा सके। |
| Origin | `10` | यह फ़्लैग सामग्री को एक अद्वितीय मूल में बाध्य करता है, जिससे वह समान मूल की अन्य सामग्री तक पहुँचने से रोकता है। |
| Forms | `20` | यह फ़्लैग फ़ॉर्म सबमिशन को ब्लॉक करता है। |
| PointerLock | `40` | यह फ़्लैग पॉइंटर लॉक API को निष्क्रिय करता है। |
| Scripts | `80` | यह फ़्लैग स्क्रिप्ट निष्पादन को ब्लॉक करता है। |
| AutomaticFeatures | `100` | यह फ़्लैग उन सुविधाओं को ब्लॉक करता है जो स्वचालित रूप से ट्रिगर होती हैं, जैसे वीडियो का स्वचालित प्ले या फ़ॉर्म कंट्रोल का स्वचालित फोकस। |
| Fullscreen | `200` | यह फ़्लैग सामग्री को requestFullscreen() मेथड उपयोग करने से रोकता है। |
| DocumentDomain | `400` | यह फ़्लैग सामग्री को document.domain फीचर का उपयोग करके प्रभावी स्क्रिप्ट मूल को बदलने से रोकता है। |
| Images | `800` | यह फ़्लैग इमेज लोडिंग को निष्क्रिय करता है। |
