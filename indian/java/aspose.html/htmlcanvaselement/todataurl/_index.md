## ToDataURL() {#todataurl}

type पैरामीटर द्वारा निर्दिष्ट फ़ॉर्मेट (डिफ़ॉल्ट रूप से PNG) में छवि का प्रतिनिधित्व करने वाला एक डेटा URI लौटाता है। लौटाई गई छवि 96 dpi के रिज़ॉल्यूशन में है।

```java
public String ToDataURL()
```

### रिटर्न वैल्यू

एक DOMString जिसमें अनुरोधित डेटा URI होता है।

## ToDataURL(String, double) {#todataurl_2}

type पैरामीटर द्वारा निर्दिष्ट फ़ॉर्मेट (डिफ़ॉल्ट रूप से PNG) में छवि का प्रतिनिधित्व करने वाला एक डेटा URI लौटाता है। लौटाई गई छवि 96 dpi के रिज़ॉल्यूशन में है।

```java
public String ToDataURL(String type, double encoderOptions)
```

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| प्रकार | String | एक String जो इमेज फॉर्मेट दर्शाता है। डिफ़ॉल्ट फॉर्मेट टाइप image/png है। |
| encoderOptions | Double | एक Number जो 0 और 1 के बीच होता है और इमेज क्वालिटी दर्शाता है यदि अनुरोधित टाइप image/jpeg या image/webp है। |
