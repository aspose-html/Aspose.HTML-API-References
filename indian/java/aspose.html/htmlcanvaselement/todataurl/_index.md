## ToDataURL() {#todataurl}

एक डेटा URI लौटाता है जिसमें छवि का प्रतिनिधित्व उस फ़ॉर्मेट में होता है जो type पैरामीटर द्वारा निर्दिष्ट किया गया है (डिफ़ॉल्ट PNG)। लौटाई गई छवि 96 dpi के रिज़ॉल्यूशन में होती है।

```java
public String ToDataURL()
```

### रिटर्न वैल्यू

एक DOMString जिसमें अनुरोधित डेटा URI होता है।

## ToDataURL(String, double) {#todataurl_2}

एक डेटा URI लौटाता है जिसमें छवि का प्रतिनिधित्व उस फ़ॉर्मेट में होता है जो type पैरामीटर द्वारा निर्दिष्ट किया गया है (डिफ़ॉल्ट PNG)। लौटाई गई छवि 96 dpi के रिज़ॉल्यूशन में होती है।

```java
public String ToDataURL(String type, double encoderOptions)
```

| Parameter | Type | विवरण |
| --- | --- | --- |
| प्रकार | String | एक स्ट्रिंग जो इमेज फ़ॉर्मेट दर्शाती है। डिफ़ॉल्ट फ़ॉर्मेट टाइप image/png है। |
| encoderOptions | Double | 0 और 1 के बीच एक नंबर जो इमेज क्वालिटी दर्शाता है यदि अनुरोधित टाइप image/jpeg या image/webp है। |

### रिटर्न वैल्यू

एक DOMString जिसमें अनुरोधित डेटा URI होता है।
