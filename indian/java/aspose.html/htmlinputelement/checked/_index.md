## HTMLInputElement.Checked property

जब `type` एट्रिब्यूट का मान \"radio\" या \"checkbox\" हो, यह फॉर्म कंट्रोल की वर्तमान स्थिति को एक इंटरैक्टिव यूज़र एजेंट में दर्शाता है। इस एट्रिब्यूट में परिवर्तन फॉर्म कंट्रोल की स्थिति को बदलते हैं, लेकिन INPUT तत्व के HTML checked एट्रिब्यूट के मान को नहीं बदलते। जब किसी इनपुट तत्व पर क्लिक इवेंट को संभालते समय, जिसका type एट्रिब्यूट का मान \"radio\" या \"checkbox\" हो, कुछ इम्प्लीमेंटेशन इस प्रॉपर्टी के मान को इवेंट दस्तावेज़ में डिस्पैच होने से पहले बदल सकते हैं। यदि इवेंट की डिफ़ॉल्ट कार्रवाई रद्द की जाती है, तो प्रॉपर्टी का मान उसके मूल मान में वापस बदल सकता है। इसका अर्थ है कि क्लिक इवेंट्स को संभालते समय इस प्रॉपर्टी का मान इम्प्लीमेंटेशन पर निर्भर करता है।

```java
public bool Checked { get; set; }
```
