## HTMLInputElement.DefaultValue property

`type` एट्रिब्यूट का मान जब "text", "file" या "password" होता है, तो यह तत्व के HTML value एट्रिब्यूट को दर्शाता है। इस एट्रिब्यूट का मान तब नहीं बदलता जब इंटरैक्टिव यूज़र एजेंट में संबंधित फ़ॉर्म नियंत्रण की सामग्री बदलती है। HTML 4.01 में value एट्रिब्यूट की परिभाषा देखें।

```java
public String DefaultValue { get; set; }
```
