## HTMLInputElement.DefaultValue property

जब तत्व का `type` एट्रिब्यूट का मान "text", "file" या "password" होता है, तो यह तत्व के HTML value एट्रिब्यूट को दर्शाता है। इस एट्रिब्यूट का मान इंटरैक्टिव यूज़र एजेंट में संबंधित फ़ॉर्म कंट्रोल की सामग्री बदलने पर नहीं बदलता। HTML 4.01 में value एट्रिब्यूट की परिभाषा देखें।

```java
public String DefaultValue { get; set; }
```
