## HTMLInputElement.DefaultChecked property

`type` का मान जब "radio" या "checkbox" हो, तो यह एलिमेंट के HTML checked एट्रिब्यूट को दर्शाता है। यदि इंटरैक्टिव यूज़र एजेंट में संबंधित फ़ॉर्म कंट्रोल की स्थिति बदलती है, तो इस एट्रिब्यूट का मान नहीं बदलता। HTML 4.01 में checked एट्रिब्यूट की परिभाषा देखें।

```java
public bool DefaultChecked { get; set; }
```
