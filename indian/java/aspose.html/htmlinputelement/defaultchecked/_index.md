## HTMLInputElement.DefaultChecked property

जब `type` का मान "radio" या "checkbox" होता है, तो यह एलिमेंट के HTML checked एट्रिब्यूट को दर्शाता है। इस एट्रिब्यूट का मान नहीं बदलता यदि संबंधित फ़ॉर्म कंट्रोल की स्थिति, एक इंटरैक्टिव यूज़र एजेंट में, बदलती है। देखें checked एट्रिब्यूट परिभाषा HTML 4.01 में।

```java
public bool DefaultChecked { get; set; }
```
