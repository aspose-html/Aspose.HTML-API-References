## HTMLInputElement.Value property

`type` एट्रिब्यूट का मान "text", "file" या "password" होने पर, यह संबंधित फ़ॉर्म कंट्रोल की वर्तमान सामग्री को दर्शाता है एक इंटरैक्टिव यूज़र एजेंट में। इस एट्रिब्यूट को बदलने से फ़ॉर्म कंट्रोल की सामग्री बदलती है, लेकिन एलिमेंट के HTML value एट्रिब्यूट का मान नहीं बदलता। जब `type` एट्रिब्यूट का मान "button", "hidden", "submit", "reset", "image", "checkbox" या "radio" होता है, तो यह एलिमेंट के HTML value एट्रिब्यूट को दर्शाता है। देखें value एट्रिब्यूट परिभाषा HTML 4.01 में।

```java
public String Value { get; set; }
```
