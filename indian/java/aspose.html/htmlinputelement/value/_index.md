## HTMLInputElement.Value property

`type` एट्रिब्यूट का मान जब "text", "file" या "password" होता है, तो यह संबंधित फ़ॉर्म कंट्रोल की वर्तमान सामग्री को दर्शाता है, एक इंटरैक्टिव यूज़र एजेंट में। इस एट्रिब्यूट को बदलने से फ़ॉर्म कंट्रोल की सामग्री बदलती है, लेकिन एलिमेंट के HTML value एट्रिब्यूट के मान में परिवर्तन नहीं होता। जब `type` एट्रिब्यूट का मान "button", "hidden", "submit", "reset", "image", "checkbox" या "radio" होता है, तो यह एलिमेंट के HTML value एट्रिब्यूट को दर्शाता है। HTML 4.01 में value एट्रिब्यूट की परिभाषा देखें।

```java
public String Value { get; set; }
```
