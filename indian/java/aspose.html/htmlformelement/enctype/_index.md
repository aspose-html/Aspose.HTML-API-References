## HTMLFormElement.Enctype property

सबमिट किए गए फ़ॉर्म का कंटेंट टाइप, सामान्यतः "application/x-www-form-urlencoded" होता है। HTML 4.01 में enctype एट्रिब्यूट की परिभाषा देखें। इस मेथड को कॉल करने पर onsubmit इवेंट हैंडलर का ट्रिगर होना गारंटी नहीं है। यह व्यवहार ऐतिहासिक कारणों से असंगत है और लेखकों को किसी विशेष व्यवहार पर निर्भर नहीं होना चाहिए।

```java
public String Enctype { get; set; }
```
