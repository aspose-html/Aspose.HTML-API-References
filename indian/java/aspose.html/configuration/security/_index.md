## Configuration.Security property

कॉन्फ़िगरेशन का सैंडबॉक्सिंग फ़्लैग प्राप्त करता है या सेट करता है। [sandboxing](https://docs.aspose.com/html/net/working-with-documents/environment-configuration/#sandboxing) के बारे में लेख देखें।

```java
public Sandbox Security { get; set; }
```

### Property Value

सुरक्षा। एक [`sandboxing flag`](../../sandbox/) सेट शून्य या अधिक फ़्लैग्स का समूह है, जो संभावित अविश्वसनीय संसाधनों की क्षमताओं को सीमित करने के लिए उपयोग किए जाते हैं। सैंडबॉक्स एट्रिब्यूट आपको फ्रेम में लोड की गई सामग्री पर कई प्रतिबंध सेट करने की अनुमति देता है, उदाहरण के लिए, फ़ॉर्म और स्क्रिप्ट को ब्लॉक करना।
