## HTMLDocument.Images property

`IMG` तत्वों का संग्रह जो दस्तावेज़ में हैं। पिछली संगतता के लिए व्यवहार केवल `IMG` तत्वों तक सीमित है। [[HTML 4.01](http://www.w3.org/TR/1999/REC-html401-19991224)] के अनुसार, छवियों को शामिल करने के लिए लेखक `OBJECT` तत्व या `IMG` तत्व का उपयोग कर सकते हैं। इसलिए इस विशेषता का उपयोग करके दस्तावेज़ में छवियों को खोजने के बजाय `getElementsByTagName` के साथ HTML 4.01 या `getElementsByTagNameNS` के साथ XHTML 1.0 का उपयोग करने की सलाह दी जाती है।

```java
public HTMLCollection Images { get; }
```
