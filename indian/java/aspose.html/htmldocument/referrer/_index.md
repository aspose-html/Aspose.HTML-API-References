## HTMLDocument.Referrer property

इस पृष्ठ से लिंक करने वाले पृष्ठ का URI [[IETF RFC 2396](http://www.ietf.org/rfc/rfc2396.txt)] लौटाता है। यदि उपयोगकर्ता सीधे (लिंक के माध्यम से नहीं, बल्कि उदाहरण के लिए बुकमार्क द्वारा) पृष्ठ पर नेविगेट करता है, तो मान एक खाली String होता है।

```java
public String Referrer { get; }
```
