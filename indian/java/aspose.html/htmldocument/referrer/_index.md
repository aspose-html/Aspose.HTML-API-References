## HTMLDocument.Referrer property

इस पृष्ठ से लिंक करने वाले पृष्ठ का URI [[IETF RFC 2396](http://www.ietf.org/rfc/rfc2396.txt)] लौटाता है। यदि उपयोगकर्ता सीधे पृष्ठ पर नेविगेट करता है (लिंक के माध्यम से नहीं, बल्कि उदाहरण के तौर पर बुकमार्क द्वारा), तो मान एक खाली स्ट्रिंग होगा।

```java
public String Referrer { get; }
```
