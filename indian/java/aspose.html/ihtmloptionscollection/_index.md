## IHTMLOptionsCollection interface

`HTMLOptionsCollection` एक नोड्स की सूची है जो HTML option तत्व का प्रतिनिधित्व करती है। एक व्यक्तिगत नोड को क्रमिक इंडेक्स या नोड के `name` या `id` एट्रिब्यूट द्वारा एक्सेस किया जा सकता है। HTML DOM में कलेक्शन को लाइव माना जाता है, जिसका अर्थ है कि मूल दस्तावेज़ बदलने पर वे स्वचालित रूप से अपडेट हो जाते हैं।

इसके अलावा देखें [Document object Model (DOM) Level 2 HTML Specification](http://www.w3.org/TR/2003/REC-DOM-Level-2-HTML-20030109)। @since DOM Level 2

```java
public interface IHTMLOptionsCollection : IEnumerable<Element>
```
