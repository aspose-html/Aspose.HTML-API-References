## Text.IsElementContentWhitespace property

बताता है कि क्या इस टेक्स्ट नोड में तत्व सामग्री व्हाइटस्पेस है, जिसे अक्सर अनदेखा किया जाने वाला "ignorable whitespace" कहा जाता है।

```java
public bool IsElementContentWhitespace { get; }
```

### Property Value

`true` यदि यह उदाहरण तत्व सामग्री व्हाइटस्पेस है; अन्यथा, `false`।
