## Attr.TextContent property

यह एट्रिब्यूट इस नोड और उसके वंशजों की टेक्स्ट सामग्री लौटाता है। जब इसे null पर परिभाषित किया जाता है, तो इसे सेट करने का कोई प्रभाव नहीं पड़ता। सेट करने पर, इस नोड के सभी संभावित चाइल्ड हटाए जाते हैं और यदि नया स्ट्रिंग खाली या null नहीं है, तो इसे एकल Text नोड से प्रतिस्थापित किया जाता है जिसमें वह स्ट्रिंग होती है जिसे इस एट्रिब्यूट को सेट किया गया है।

```java
public String TextContent { get; set; }
```
