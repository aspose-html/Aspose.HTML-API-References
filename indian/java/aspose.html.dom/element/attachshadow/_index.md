## Element.AttachShadow method

एक शैडो रूट बनाता है और उसे वर्तमान तत्व से संलग्न करता है।

```java
public ShadowRoot AttachShadow(ShadowRootMode mode)
```

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| मोड | ShadowRootMode | वह मोड जिसमें shadow root बनाया जाएगा। |

### रिटर्न वैल्यू

बनाया गया [`ShadowRoot`](../../shadowroot/).

### अपवाद

| अपवाद | शर्त |
| --- | --- |
| त्रुटि | NotSupportedError: Element shadow tree को समर्थन नहीं देता। |
| त्रुटि | InvalidStateError: Element के पास पहले से ही shadow tree है। |
