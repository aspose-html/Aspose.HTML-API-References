## ToggleAttribute(String) {#toggleattribute}

यदि force नहीं दिया गया है, तो "toggles" qualifiedName करता है, यदि यह मौजूद है तो हटाता है और यदि नहीं है तो जोड़ता है। यदि force true है, तो qualifiedName जोड़ता है। यदि force false है, तो qualifiedName हटाता है।

```java
public bool ToggleAttribute(String qualifiedName)
```

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| qualifiedName | String | एट्रिब्यूट QualifiedName। |

### रिटर्न वैल्यू

यदि qualifiedName अब मौजूद है तो true लौटाता है; अन्यथा false।
