## ToggleAttribute(String) {#toggleattribute}

यदि force नहीं दिया गया है, तो qualifiedName को "टॉगल" करता है, यदि वह मौजूद है तो उसे हटाता है और यदि नहीं है तो जोड़ता है। यदि force true है, तो qualifiedName जोड़ता है। यदि force false है, तो qualifiedName हटाता है।

```java
public bool ToggleAttribute(String qualifiedName)
```

| Parameter | Type | विवरण |
| --- | --- | --- |
| qualifiedName | String | एट्रिब्यूट QualifiedName। |

### रिटर्न वैल्यू

यदि qualifiedName अब मौजूद है तो true लौटाता है; अन्यथा false।
