## Node.BaseURI property

पढ़ने‑के‑लिए‑केवल baseURI प्रॉपर्टी Node इंटरफ़ेस की उस दस्तावेज़ का पूर्ण बेस URL लौटाती है जिसमें नोड सम्मिलित है।

बेस URL का उपयोग सापेक्ष URL को हल करने के लिए किया जाता है जब ब्राउज़र को पूर्ण URL प्राप्त करना होता है, उदाहरण के तौर पर HTML img तत्व के src एट्रिब्यूट या SVG में xlink:href या href एट्रिब्यूट को प्रोसेस करते समय।

```java
public String BaseURI { get; }
```

### Property Value

baseURI गेटर इस नोड के दस्तावेज़ का बेस URL सीरियलाइज़्ड रूप में लौटाता है।
