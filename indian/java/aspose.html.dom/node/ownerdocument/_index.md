## Node.OwnerDocument property

Node इंटरफ़ेस की पढ़ने-के-लिए-केवल ownerDocument प्रॉपर्टी नोड का शीर्ष-स्तर दस्तावेज़ ऑब्जेक्ट लौटाती है।

```java
public Document OwnerDocument { get; }
```

### Property Value

एक [`Document`](../../document/) जो वह शीर्ष-स्तर ऑब्जेक्ट है जिसमें सभी चाइल्ड नोड बनाए जाते हैं।

यदि यह प्रॉपर्टी ऐसे नोड पर उपयोग की जाती है जो स्वयं एक दस्तावेज़ है, तो मान null होता है।
