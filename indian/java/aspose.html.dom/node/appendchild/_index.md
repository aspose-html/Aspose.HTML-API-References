## Node.AppendChild method

appendChild() मेथड Node इंटरफ़ेस का यह निर्दिष्ट पैरेंट नोड के बच्चों की सूची के अंत में एक नोड जोड़ता है। यदि दिया गया चाइल्ड दस्तावेज़ में मौजूदा नोड का संदर्भ है, तो appendChild() उसे उसकी वर्तमान स्थिति से नई स्थिति में ले जाता है (नोड को किसी अन्य नोड में जोड़ने से पहले पैरेंट नोड से हटाने की कोई आवश्यकता नहीं है)।

इसका मतलब है कि एक नोड एक साथ दस्तावेज़ के दो बिंदुओं पर नहीं हो सकता। इसलिए यदि नोड का पहले से कोई पैरेंट है, तो नोड को पहले हटाया जाता है, फिर नई स्थिति में जोड़ा जाता है। [`Node.cloneNode()`](../clonenode/) विधि का उपयोग नोड की एक प्रति बनाने के लिए किया जा सकता है, जिसे नए पैरेंट के तहत जोड़ने से पहले बनाया जाता है। [`cloneNode`](../clonenode/) से बनाई गई प्रतियां स्वतः सिंक्रनाइज़ नहीं रहतीं।

```java
public Node AppendChild(Node node)
```

| Parameter | Type | विवरण |
| --- | --- | --- |
| नोड | Node | दिए गए पैरेंट नोड (आमतौर पर एक तत्व) में जोड़ने के लिए नोड। |

### रिटर्न वैल्यू

एक Node जो जोड़ा गया चाइल्ड (aChild) है, सिवाय जब aChild एक [`DocumentFragment`](../../documentfragment/) हो, इस स्थिति में खाली [`DocumentFragment`](../../documentfragment/) लौटाया जाता है।
