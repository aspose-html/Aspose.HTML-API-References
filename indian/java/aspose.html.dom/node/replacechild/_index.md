## Node.ReplaceChild method

चाइल्ड नोड oldChild को newChild से बच्चों की सूची में बदलता है, और oldChild नोड लौटाता है। यदि newChild एक [`DocumentFragment`](../../documentfragment/) ऑब्जेक्ट है, तो oldChild को सभी [`DocumentFragment`](../../documentfragment/) चाइल्ड से बदल दिया जाता है, जो उसी क्रम में सम्मिलित होते हैं। यदि newChild पहले से ही ट्री में है, तो उसे पहले हटाया जाता है।

```java
public Node ReplaceChild(Node node, Node child)
```

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| नोड | Node | oldChild को बदलने के लिए नया नोड। |
| चाइल्ड | Node | जिस चाइल्ड को बदलना है। |

### रिटर्न वैल्यू

बदला गया Node। यह वही नोड है जो oldChild था।
