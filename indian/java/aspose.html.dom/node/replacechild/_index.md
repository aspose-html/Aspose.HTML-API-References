## Node.ReplaceChild method

चाइल्ड नोड oldChild को newChild से बच्चों की सूची में बदलता है, और oldChild नोड लौटाता है। यदि newChild एक `[`DocumentFragment`](../../documentfragment/)` ऑब्जेक्ट है, तो oldChild को सभी `[`DocumentFragment`](../../documentfragment/)` बच्चों से बदला जाता है, जो उसी क्रम में डाले जाते हैं। यदि newChild पहले से ही ट्री में है, तो उसे पहले हटाया जाता है।

```java
public Node ReplaceChild(Node node, Node child)
```

| Parameter | Type | विवरण |
| --- | --- | --- |
| नोड | Node | oldChild को बदलने के लिए नया नोड। |
| चाइल्ड | Node | जिस बच्चे को बदलना है वह। |

### रिटर्न वैल्यू

बदला गया Node। यह वही नोड है जो oldChild था।
