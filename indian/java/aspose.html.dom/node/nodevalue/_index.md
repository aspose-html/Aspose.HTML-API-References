## Node.NodeValue property

[`Node `](../) इंटरफ़ेस की nodeValue प्रॉपर्टी वर्तमान नोड का मान लौटाती या सेट करती है।

```java
public String NodeValue { get; set; }
```

### Property Value

एक String जिसमें वर्तमान नोड का मान होता है, यदि कोई हो। दस्तावेज़ स्वयं के लिए, nodeValue null लौटाता है। टेक्स्ट, कमेंट और CDATA नोड्स के लिए, nodeValue नोड की सामग्री लौटाता है। एट्रिब्यूट नोड्स के लिए, एट्रिब्यूट का मान लौटाया जाता है।
