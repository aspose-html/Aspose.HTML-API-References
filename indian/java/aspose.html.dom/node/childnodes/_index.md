## Node.ChildNodes property

Node इंटरफ़ेस की केवल‑रीड childNodes प्रॉपर्टी दिए गए एलिमेंट के चाइल्ड नोड्स की एक लाइव [`NodeList`](../../../com.aspose.html.collections/nodelist/) लौटाती है जहाँ पहला चाइल्ड नोड इंडेक्स 0 को सौंपा जाता है। चाइल्ड नोड्स में एलिमेंट्स, टेक्स्ट और कमेंट्स शामिल हैं।

नोट: लाइव होने का अर्थ है कि प्रत्येक बार नए चाइल्ड जोड़े या हटाए जाने पर [`NodeList`](../../../com.aspose.html.collections/nodelist/) की सामग्री बदलती है।

```java
public NodeList ChildNodes { get; }
```

### Property Value

एक लाइव [`NodeList`](../../../com.aspose.html.collections/nodelist/) जिसमें नोड के चाइल्ड शामिल हैं।

नोट: childNodes पर कई कॉल्स एक ही [`NodeList`](../../../com.aspose.html.collections/nodelist/) लौटाते हैं।
