## Node.ChildNodes property

Node इंटरफ़ेस की पढ़ने-केवल childNodes प्रॉपर्टी दिए गए तत्व के चाइल्ड नोड्स की एक लाइव `[`NodeList`](../../../com.aspose.html.collections/nodelist/)` लौटाती है जहाँ पहला चाइल्ड नोड इंडेक्स 0 को सौंपा जाता है। चाइल्ड नोड्स में तत्व, टेक्स्ट और कमेंट्स शामिल हैं।

नोट: `[`NodeList`](../../../com.aspose.html.collections/nodelist/)` का लाइव होना मतलब है कि प्रत्येक बार नए बच्चे जोड़े या हटाए जाने पर इसकी सामग्री बदलती रहती है।

```java
public NodeList ChildNodes { get; }
```

### Property Value

एक लाइव `[`NodeList`](../../../com.aspose.html.collections/nodelist/)` जो नोड के बच्चों को सम्मिलित करता है।

नोट: childNodes के कई कॉल्स एक ही `[`NodeList`](../../../com.aspose.html.collections/nodelist/)` लौटाते हैं।
