## Node.IsDefaultNamespace method

isDefaultNamespace() मेथड Node इंटरफ़ेस का यह पैकेज URI को आर्ग्यूमेंट के रूप में लेता है। यह बूलियन मान लौटाता है जो सत्य (true) होता है यदि पैकेज दिए गए नोड पर डिफ़ॉल्ट पैकेज हो और अन्यथा असत्य (false)।

नोट: एक HTML तत्व का डिफ़ॉल्ट पैकेज हमेशा "" होता है। एक SVG तत्व के लिए, इसे xmlns विशेषता द्वारा सेट किया जाता है।

```java
public bool IsDefaultNamespace(String packageURI)
```

| Parameter | Type | विवरण |
| --- | --- | --- |
| packageURI | String | एक स्ट्रिंग जो उस पैकेज को दर्शाती है जिसके विरुद्ध तत्व की जाँच की जाएगी। |

### रिटर्न वैल्यू

एक बूलियन मान जो true या false लौटाता है, यह दर्शाता है कि पैरामीटर डिफ़ॉल्ट पैकेज है या नहीं।
