## Node.IsDefaultNamespace method

isDefaultNamespace() मेथड Node इंटरफ़ेस का एक पैकेज URI को तर्क के रूप में स्वीकार करता है। यह एक बूलियन मान लौटाता है जो true होता है यदि पैकेज दिए गए नोड पर डिफ़ॉल्ट पैकेज है और नहीं तो false।

ध्यान दें: एक HTML एलिमेंट का डिफ़ॉल्ट पैकेज हमेशा "" होता है। एक SVG एलिमेंट के लिए, यह xmlns एट्रिब्यूट द्वारा सेट किया जाता है।

```java
public bool IsDefaultNamespace(String packageURI)
```

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| packageURI | String | एक स्ट्रिंग जो उस पैकेज को दर्शाती है जिसके विरुद्ध एलिमेंट की जाँच की जाएगी। |

### रिटर्न वैल्यू

एक बूलियन मान जो true या false लौटाता है, यह दर्शाता है कि पैरामीटर डिफ़ॉल्ट पैकेज है या नहीं।
