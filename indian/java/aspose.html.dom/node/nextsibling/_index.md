## Node.NextSibling property

पढ़ने-के-लिए-केवल nextSibling प्रॉपर्टी [`Node`](../) इंटरफ़ेस की निर्दिष्ट नोड के तुरंत बाद वाले नोड को लौटाती है, या यदि निर्दिष्ट नोड पैरेंट एलिमेंट में अंतिम चाइल्ड है तो null लौटाती है।

```java
public Node NextSibling { get; }
```

### Property Value

एक [`Node`](../) जो वर्तमान नोड का अगला भाई-बहन दर्शाता है, या यदि कोई नहीं हो तो null।
