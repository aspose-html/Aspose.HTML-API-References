## Node.IsEqualNode method

The [`Node`](../) interface की isEqualNode() मेथड जांचती है कि दो नोड समान हैं या नहीं। दो नोड समान होते हैं जब उनका प्रकार समान हो, विशेषताएँ (तत्वों के लिए, यह उनका ID, बच्चों की संख्या आदि हो), उनके एट्रीब्यूट्स मेल खाते हों, आदि। मिलाने वाले डेटा पॉइंट्स का विशिष्ट सेट नोड के प्रकार के अनुसार बदलता है।

```java
public bool IsEqualNode(Node otherNode)
```

| Parameter | Type | विवरण |
| --- | --- | --- |
| otherNode | Node | वह [`Node`](../) जिसके साथ समानता की तुलना की जाती है। |

### रिटर्न वैल्यू

एक बूलियन मान जो true होता है यदि दो नोड समान हैं, या false यदि नहीं। यदि otherNode null है, तो isEqualNode() हमेशा false लौटाता है।
