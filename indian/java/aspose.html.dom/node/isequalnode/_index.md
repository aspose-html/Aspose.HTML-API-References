## Node.IsEqualNode method

[`Node`](../) इंटरफ़ेस की isEqualNode() मेथड यह परीक्षण करती है कि दो नोड बराबर हैं या नहीं। दो नोड बराबर होते हैं जब उनका प्रकार समान हो, परिभाषित विशेषताएँ (तत्वों के लिए, यह उनका ID, बच्चों की संख्या आदि होगी), उनके एट्रिब्यूट मेल खाते हों, आदि। मिलाने वाले डेटा पॉइंट्स का विशिष्ट सेट नोड के प्रकार पर निर्भर करता है।

```java
public bool IsEqualNode(Node otherNode)
```

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| otherNode | Node | समानता की तुलना करने हेतु [`Node`](../) |

### रिटर्न वैल्यू

एक बूलियन मान जो सत्य होता है यदि दो नोड बराबर हों, अन्यथा असत्य। यदि otherNode null है, तो isEqualNode() हमेशा false लौटाता है।
