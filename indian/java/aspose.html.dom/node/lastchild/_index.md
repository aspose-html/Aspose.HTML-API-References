## Node.LastChild property

[`Node`](../) इंटरफ़ेस की केवल‑पढ़ने योग्य lastChild प्रॉपर्टी नोड का अंतिम चाइल्ड लौटाती है। यदि इसका पैरेंट एक एलिमेंट है, तो चाइल्ड आमतौर पर एक एलिमेंट नोड, एक टेक्स्ट नोड, या एक कमेंट नोड होता है। यदि कोई चाइल्ड एलिमेंट नहीं है तो यह null लौटाता है।

```java
public Node LastChild { get; }
```
