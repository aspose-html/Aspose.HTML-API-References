## Node.IsSameNode method

isSameNode() मेथड Node इंटरफ़ेस का === सख्त समानता ऑपरेटर का एक लेगेसी उपनाम है। अर्थात, यह परीक्षण करता है कि दो नोड्स समान हैं या नहीं (दूसरे शब्दों में, क्या वे एक ही ऑब्जेक्ट को संदर्भित करते हैं)।

ध्यान दें: isSameNode() का उपयोग करने की आवश्यकता नहीं है; इसके बजाय === कठोर समानता ऑपरेटर का उपयोग करें।

```java
public bool IsSameNode(Node otherNode)
```

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| otherNode | Node | जिस Node की तुलना की जानी है। |

### रिटर्न वैल्यू

एक बूलियन मान जो true होता है यदि दोनों नोड्स सख्ती से समान हैं, अन्यथा false।
