## Node.IsSameNode method

isSameNode() मेथड Node इंटरफ़ेस का यह एक लेगेसी उपनाम है === सख्त समानता ऑपरेटर के लिए। यह परीक्षण करता है कि दो नोड्स एक ही हैं (अर्थात् वे एक ही ऑब्जेक्ट को रेफ़र करते हैं) या नहीं।

नोट: isSameNode() का उपयोग करने की आवश्यकता नहीं है; इसके बजाय === सख्त समानता ऑपरेटर का उपयोग करें।

```java
public bool IsSameNode(Node otherNode)
```

| Parameter | Type | विवरण |
| --- | --- | --- |
| otherNode | Node | जाँच के लिए Node। |

### रिटर्न वैल्यू

एक बूलियन मान जो true होता है यदि दोनों नोड सख्ती से समान हैं, अन्यथा false।
