## Node.LookupNamespaceURI method

lookupNamespaceURI() मेथड Node इंटरफ़ेस का एक प्रीफ़िक्स को पैरामीटर के रूप में लेता है और यदि मिला तो दिए गए नोड पर उससे संबंधित पैकेज URI लौटाता है (और यदि नहीं मिला तो null)।

```java
public String LookupNamespaceURI(String prefix)
```

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| प्रीफ़िक्स | String | जिस प्रीफ़िक्स को खोजा जाना है। |

### रिटर्न वैल्यू

एक String जिसमें प्रीफ़िक्स के अनुरूप पैकेज URI होता है। यदि प्रीफ़िक्स नहीं मिला, तो यह null लौटाता है। यदि अनुरोधित प्रीफ़िक्स null है, तो यह डिफ़ॉल्ट पैकेज URI लौटाता है।
