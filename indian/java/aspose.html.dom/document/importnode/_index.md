## Document.ImportNode method

```java
public Node ImportNode(Node importedNode, bool deep)
```

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| importedNode | Node | आयात किया गया नोड। |
| गहरा | Boolean | यदि सेट किया गया है `true` [deep]. |
