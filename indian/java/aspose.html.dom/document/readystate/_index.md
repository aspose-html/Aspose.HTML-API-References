## Document.ReadyState property

दस्तावेज़ की तत्परता लौटाता है। "loading" तब जब Document लोड हो रहा है, "interactive" तब जब पार्सिंग समाप्त हो गई है लेकिन अभी भी सब‑रिसोर्स लोड हो रहे हैं, और "complete" तब जब यह लोड हो चुका है।

```java
public String ReadyState { get; }
```
