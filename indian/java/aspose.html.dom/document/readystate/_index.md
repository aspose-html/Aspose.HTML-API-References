## Document.ReadyState property

दस्तावेज़ की तत्परता लौटाता है। "loading" तब जब Document लोड हो रहा है, "interactive" जब यह पार्सिंग समाप्त कर लेता है लेकिन अभी भी सब‑रिसोर्स लोड हो रहे हैं, और "complete" जब यह पूरी तरह लोड हो चुका हो।

```java
public String ReadyState { get; }
```
