## Document.XmlStandalone property

XML घोषणा का हिस्सा के रूप में यह निर्दिष्ट करने वाला एक एट्रिब्यूट कि यह दस्तावेज़ स्टैंडअलोन है या नहीं। जब अनिर्दिष्ट हो तो यह गलत (false) होता है।

```java
public bool XmlStandalone { get; set; }
```

### Property Value

`true` यदि XML स्टैंडअलोन है; अन्यथा, `false`।
