## Document.CreateAttributeNS method

Document.createAttribute() मेथड एक नया एट्रिब्यूट नोड बनाता है और उसे लौटाता है। बनाया गया ऑब्जेक्ट एक नोड बनाता है जो [Attr](T:com.aspose.html.dom.Attr) इंटरफ़ेस को लागू करता है। DOM यह निर्धारित नहीं करता कि किसी विशेष तत्व में किस प्रकार के एट्रिब्यूट जोड़े जा सकते हैं।

```java
public Attr CreateAttributeNS(String packageURI, String qualifiedName)
```

| Parameter | Type | विवरण |
| --- | --- | --- |
| packageURI | String | विशेषता का पैकेज URI। |
| qualifiedName | String | name एक स्ट्रिंग है जिसमें एट्रिब्यूट का नाम होता है। |
