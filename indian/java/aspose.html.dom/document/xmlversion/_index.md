## Document.XmlVersion property

एक गुण जो XML घोषणा के हिस्से के रूप में इस दस्तावेज़ का संस्करण संख्या निर्दिष्ट करता है। यदि कोई घोषणा नहीं है और यदि यह दस्तावेज़ "XML" सुविधा का समर्थन करता है, तो मान "1.0" है। यदि यह दस्तावेज़ "XML" सुविधा का समर्थन नहीं करता है, तो मान हमेशा null रहता है।

```java
public String XmlVersion { get; set; }
```

### Property Value

XML संस्करण।
