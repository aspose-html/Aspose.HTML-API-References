## Document.StrictErrorChecking property

एक गुण जो यह निर्दिष्ट करता है कि त्रुटि जाँच लागू की गई है या नहीं। जब इसे false पर सेट किया जाता है, तो कार्यान्वयन को DOM ऑपरेशनों पर सामान्यतः परिभाषित प्रत्येक संभावित त्रुटि केस का परीक्षण न करने और DOM ऑपरेशनों पर कोई DOMException न उठाने या Document.normalizeDocument() का उपयोग करते समय त्रुटियों की रिपोर्ट न करने की स्वतंत्रता होती है। त्रुटि की स्थिति में व्यवहार अपरिभाषित रहता है। यह गुण डिफ़ॉल्ट रूप से true है।

```java
public bool StrictErrorChecking { get; set; }
```

### Property Value

`true` यदि सख्त त्रुटि जाँच; अन्यथा, `false`।
