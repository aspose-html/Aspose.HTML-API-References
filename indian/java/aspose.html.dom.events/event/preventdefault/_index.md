## Event.PreventDefault method

यदि कोई इवेंट रद्द करने योग्य है, तो `PreventDefault` मेथड का उपयोग यह दर्शाने के लिए किया जाता है कि इवेंट को रद्द किया जाना है, जिसका अर्थ है कि इवेंट के परिणामस्वरूप कार्यान्वयन द्वारा सामान्यतः ली जाने वाली कोई भी डिफ़ॉल्ट कार्रवाई नहीं होगी।

```java
public void PreventDefault()
```

## टिप्पणियाँ

यदि इवेंट प्रवाह के किसी भी चरण में `PreventDefault` मेथड को बुलाया जाता है, तो इवेंट रद्द हो जाता है। इवेंट से जुड़ी कोई भी डिफ़ॉल्ट कार्रवाई नहीं होगी। गैर-रद्द करने योग्य इवेंट के लिए इस मेथड को कॉल करने से कोई प्रभाव नहीं पड़ता। एक बार `PreventDefault` को कॉल करने के बाद यह इवेंट के प्रसार के शेष भाग तक प्रभावी रहेगा। इस मेथड का उपयोग इवेंट प्रवाह के किसी भी चरण में किया जा सकता है।
