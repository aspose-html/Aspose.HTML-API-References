## Event.StopPropagation method

`StopPropagation` मेथड का उपयोग इवेंट फ्लो के दौरान इवेंट के आगे प्रसार को रोकने के लिए किया जाता है।

```java
public void StopPropagation()
```

## टिप्पणियाँ

यदि यह मेथड किसी भी [`IEventListener`](../../ieventlistener/) द्वारा कॉल किया जाता है तो इवेंट ट्री के माध्यम से प्रसार बंद हो जाएगा। इवेंट वर्तमान [`IEventTarget`](../../ieventtarget/) पर सभी लिस्नर्स को डिस्पैच करना पूरा करेगा, फिर इवेंट फ्लो रुक जाएगा। यह मेथड इवेंट फ्लो के किसी भी चरण में उपयोग किया जा सकता है।
