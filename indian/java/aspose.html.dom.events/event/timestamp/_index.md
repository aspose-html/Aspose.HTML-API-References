## Event.TimeStamp property

इवेंट के निर्माण के समय को (epoch के सापेक्ष मिलीसेकंड में) निर्दिष्ट करने के लिए उपयोग किया जाता है। चूँकि कुछ सिस्टम यह जानकारी प्रदान नहीं कर सकते, इसलिए timeStamp का मान सभी इवेंट्स के लिए उपलब्ध नहीं हो सकता। जब उपलब्ध न हो तो 0 का मान लौटाया जाएगा। epoch समय के उदाहरण सिस्टम के प्रारम्भ का समय या 0:0:0 UTC 1 जनवरी 1970 हैं।

```java
public ulong TimeStamp { get; }
```
