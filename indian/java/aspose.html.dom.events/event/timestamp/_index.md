## Event.TimeStamp property

इवेंट के निर्माण के समय को दर्शाने वाले एपोक के सापेक्ष मिलीसेकंड में समय निर्दिष्ट करने के लिए उपयोग किया जाता है। चूँकि कुछ सिस्टम यह जानकारी प्रदान नहीं कर सकते, इसलिए सभी इवेंट्स के लिए timeStamp का मान उपलब्ध नहीं हो सकता। जब उपलब्ध न हो, तो 0 का मान लौटाया जाएगा। एपोक समय के उदाहरण सिस्टम के शुरू होने का समय या 0:0:0 UTC 1 जनवरी 1970 हैं।

```java
public ulong TimeStamp { get; }
```
