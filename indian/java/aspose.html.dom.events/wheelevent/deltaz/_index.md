## WheelEvent.DeltaZ property

उन यूज़र एजेंट्स में जहाँ व्हील इवेंट की डिफ़ॉल्ट कार्रवाई स्क्रॉल करना है, मूल्य को z‑axis के साथ (पिक्सेल, लाइन्स, या पेजेज में) मापना आवश्यक है, जिसे इवेंट के रद्द न होने की स्थिति में स्क्रॉल किया जाएगा। अन्यथा, यह व्हील डिवाइस की z‑axis के चारों ओर की गति का (पिक्सेल, लाइन्स, या पेजेज में) इम्प्लीमेंटेशन‑विशिष्ट माप होगा।

```java
public double DeltaZ { get; }
```
