## KeyboardEvent.IsComposing property

true यदि कुंजी घटना एक संयोजन सत्र का हिस्सा के रूप में होती है, अर्थात् compositionstart घटना के बाद और संबंधित compositionend घटना से पहले। इस attribute का अन-इनिशियलाइज़्ड मान MUST false होना चाहिए।

```java
public bool IsComposing { get; }
```

### Property Value

`true` यदि यह उदाहरण संयोजन कर रहा है; अन्यथा, `false`।
