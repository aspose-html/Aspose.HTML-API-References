## KeyboardEvent.Repeat property

true यदि कुंजी को निरंतर रूप से दबाया गया हो। एक कुंजी को दबाए रखने से सिस्टम कॉन्फ़िगरेशन द्वारा निर्धारित दर पर क्रमशः keydown, beforeinput, input इवेंट्स दोहराए जाने चाहिए। उन मोबाइल डिवाइसों के लिए जिनमें लंबा-की-प्रेस व्यवहार है, true repeat एट्रिब्यूट वाले पहले की इवेंट को लंबा-की-प्रेस संकेत के रूप में माना जाना चाहिए। दोहराव शुरू करने के लिए कुंजी को दबाए रखने का समय कॉन्फ़िगरेशन-निर्भर है।

```java
public bool Repeat { get; }
```

### Property Value

`true` यदि repeat; अन्यथा, `false`।
