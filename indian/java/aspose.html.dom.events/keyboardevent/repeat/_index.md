## KeyboardEvent.Repeat property

true यदि कुंजी निरंतर दबाए रखी गई हो। कुंजी को दबाए रखने से सिस्टम कॉन्फ़िगरेशन द्वारा निर्धारित गति पर क्रम में keydown, beforeinput, input इवेंट्स दोहराए जाने चाहिए। मोबाइल डिवाइसों में जहाँ लंबी‑की‑प्रेस व्यवहार है, true मान वाले repeat एट्रिब्यूट वाले पहले इवेंट को लंबी‑की‑प्रेस का संकेत माना जाना चाहिए। दोहराव शुरू करने के लिए कुंजी को दबाए रखने का समय कॉन्फ़िगरेशन‑निर्भर है।

```java
public bool Repeat { get; }
```

### Property Value

`true` यदि दोहराव; अन्यथा, `false`।
