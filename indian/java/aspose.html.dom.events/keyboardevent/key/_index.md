## KeyboardEvent.Key property

key दबाए गए कुंजी का मान रखती है। यदि मान की मुद्रित प्रस्तुति है तो उसे इस विनिर्देश में परिभाषित कुंजी मान निर्धारित करने के एल्गोरिद्म के अनुरूप एक गैर‑खाली Unicode अक्षर स्ट्रिंग होना चाहिए। यदि मान एक नियंत्रण कुंजी है जिसकी कोई मुद्रित प्रस्तुति नहीं है तो उसे कुंजी मान सेट में परिभाषित कुंजी मानों में से एक होना चाहिए, जैसा कि कुंजी मान निर्धारित करने के एल्गोरिद्म द्वारा निर्धारित किया गया है। ऐसी कार्यान्वयन जो कुंजी की पहचान नहीं कर सकते, उन्हें कुंजी मान Unidentified का उपयोग करना चाहिए।

```java
public String Key { get; }
```

### Property Value

कुंजी मान।
