## KeyboardEvent.Key property

key दबाए गए कुंजी का मान रखता है। यदि मान की मुद्रित प्रस्तुति है, तो वह इस विनिर्देशन में परिभाषित key value निर्धारित करने वाले एल्गोरिद्म के अनुरूप एक गैर-खाली Unicode अक्षर स्ट्रिंग होना चाहिए। यदि मान एक नियंत्रण कुंजी है जिसकी कोई मुद्रित प्रस्तुति नहीं है, तो उसे key value निर्धारित करने वाले एल्गोरिद्म द्वारा निर्धारित key values सेट में परिभाषित मानों में से एक होना चाहिए। जिन कार्यान्वयनों को कुंजी पहचानने में असमर्थता है, उन्हें key value “Unidentified” का उपयोग करना चाहिए।

```java
public String Key { get; }
```

### Property Value

कुंजी मान।
