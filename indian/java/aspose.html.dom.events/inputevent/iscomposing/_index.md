## InputEvent.IsComposing property

true यदि इनपुट इवेंट एक कंपोज़िशन सत्र का हिस्सा है, यानी compositionstart इवेंट के बाद और संबंधित compositionend इवेंट से पहले। इस एट्रिब्यूट का अनइनिशियलाइज़्ड मान false होना अनिवार्य है।

```java
public bool IsComposing { get; }
```

### Property Value

`true` यदि यह इंस्टेंस कंपोज़ कर रहा है; अन्यथा, `false`।
