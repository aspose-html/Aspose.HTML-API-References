## InputEvent.IsComposing property

यदि इनपुट इवेंट एक कंपोज़िशन सत्र का हिस्सा है, अर्थात् compositionstart इवेंट के बाद और संबंधित compositionend इवेंट से पहले, तो true। इस एट्रिब्यूट का अनइनिशियलाइज़्ड मान false होना अनिवार्य है।

```java
public bool IsComposing { get; }
```

### Property Value

`true` यदि यह उदाहरण संयोजन कर रहा है; अन्यथा, `false`।
