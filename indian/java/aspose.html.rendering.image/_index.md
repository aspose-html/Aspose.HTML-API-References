**com.aspose.html.rendering.image** पैकेज एक विशिष्ट डिवाइस क्लास और रास्टर फ़ॉर्मैट्स (jpeg, png, bmp, gif, tiff) में रेंडर करने के लिए जिम्मेदार कुछ रेंडरिंग विकल्प क्लासेस प्रदान करता है।

## क्लासेस

| क्लास | विवरण |
| --- | --- |
| [ImageDevice](./imagedevice/) | रास्टर फ़ॉर्मैट्स: jpeg, png, bmp, gif, tiff में रेंडरिंग का प्रतिनिधित्व करता है। |
| [ImageRenderingOptions](./imagerenderingoptions/) | `[`ImageDevice`](../com.aspose.html.rendering.image/imagedevice/)` के लिए रेंडरिंग विकल्पों का प्रतिनिधित्व करता है। यह विकल्प आउटपुट इमेज फ़ॉर्मैट, कंप्रेशन, रिज़ॉल्यूशन आदि निर्दिष्ट करने के लिए उपयोग किया जाता है। |
| [TextOptions](./textoptions/) | `[`ImageDevice`](../com.aspose.html.rendering.image/imagedevice/)` के लिए टेक्स्ट रेंडरिंग विकल्पों का प्रतिनिधित्व करता है। |
## एन्यूमरेशन

| एन्यूमरेशन | विवरण |
| --- | --- |
| [Compression](./compression/) | Tagged Image File Format (TIFF) बिटमैप इमेजेज़ के संभावित कंप्रेशन स्कीम्स को निर्दिष्ट करता है। |
| [ImageFormat](./imageformat/) | इमेज का फ़ाइल फ़ॉर्मैट निर्दिष्ट करता है। |
