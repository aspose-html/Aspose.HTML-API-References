## ICSSKeyframesRule.DeleteRule method

Metode deleteRule menghapus [`CSSKeyframeRule`](../../icsskeyframerule/) dengan kunci yang diberikan. Jika tidak ada aturan dengan kunci tersebut, metode ini tidak melakukan apa‑apa.

```java
public void DeleteRule(String key)
```

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| key | String | Kunci yang menggambarkan aturan yang akan dihapus. Kunci harus berupa angka antara 0 dan 1, atau aturan akan diabaikan. |
