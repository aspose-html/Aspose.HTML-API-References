## ICSSKeyframesRule.FindRule method

Metode findRule mengembalikan aturan dengan kunci yang cocok dengan kunci yang diberikan. Jika tidak ada aturan semacam itu, nilai null dikembalikan.

```java
public ICSSKeyframeRule FindRule(String key)
```

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| key | String | Kunci yang menggambarkan aturan yang akan dicari. Kunci harus berupa angka antara 0 dan 1, atau aturan akan diabaikan. |

### Nilai Kembali

Mengembalikan [`CSSKeyframeRule`](../../icsskeyframerule/) terakhir yang dideklarasikan yang cocok dengan pemilih keyframe yang ditentukan. Jika tidak ada aturan yang cocok, metode tidak melakukan apa‑apa.
