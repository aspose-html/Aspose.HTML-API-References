## IViewCSS interface

Antarmuka IViewCSS mewakili ekstensi pada objek Window yang memberikan akses ke nilai semua properti CSS dari sebuah elemen.

Gaya CSS untuk sebuah elemen dapat diperoleh menggunakan metode IViewCSS.GetComputedStyle().

```java
public interface IViewCSS : IAbstractView
```
