## ICSS2Properties.BorderSpacing property

Panjang menentukan jarak yang memisahkan batas sel yang berdekatan. Jika satu panjang ditentukan, itu memberikan jarak horizontal dan vertikal. Jika dua panjang ditentukan, yang pertama memberikan jarak horizontal dan yang kedua jarak vertikal. Panjang tidak boleh bernilai negatif.

```java
public String BorderSpacing { get; set; }
```
