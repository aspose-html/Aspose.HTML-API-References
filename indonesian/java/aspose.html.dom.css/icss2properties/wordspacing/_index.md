## ICSS2Properties.WordSpacing property

Properti ini menentukan perilaku spasi antar kata. Nilai memiliki arti berikut:

normal - Spasi antar kata normal, sebagaimana didefinisikan oleh font saat ini dan/atau UA. '[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - Nilai ini menunjukkan spasi antar kata tambahan di atas spasi default antar kata. Nilai dapat negatif, tetapi mungkin ada batasan spesifik implementasi.

```java
public String WordSpacing { get; set; }
```
