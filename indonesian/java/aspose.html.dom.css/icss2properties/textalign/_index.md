## ICSS2Properties.TextAlign property

Properti ini menjelaskan bagaimana konten inline dari sebuah blok disejajarkan. Nilai-nilai memiliki arti berikut:

left, right, center, and justify - Left, right, center, and double justify text, respectively.'[String](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-String)' - Menentukan String yang akan menjadi acuan perataan sel dalam kolom tabel (lihat bagian tentang [horizontal alignment in a column](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#column-alignment) untuk detail dan contoh). Nilai ini hanya berlaku untuk sel [table](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html). Jika diterapkan pada elemen lain, akan diperlakukan sebagai 'left' atau 'right', tergantung apakah ['direction'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-direction) adalah 'ltr' atau 'rtl', masing-masing.

public String TextAlign { get; set; }
