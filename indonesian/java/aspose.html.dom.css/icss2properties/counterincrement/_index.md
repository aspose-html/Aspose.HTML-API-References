## ICSS2Properties.CounterIncrement property

Properti ['counter-increment'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-counter-increment) menerima satu atau lebih nama penghitung (identifiers), masing-masing dapat diikuti secara opsional oleh sebuah bilangan bulat. Bilangan bulat tersebut menunjukkan berapa banyak penghitung ditambah untuk setiap kemunculan elemen. Increment default adalah 1. Bilangan bulat nol dan negatif diperbolehkan.

```java
public String CounterIncrement { get; set; }
```
