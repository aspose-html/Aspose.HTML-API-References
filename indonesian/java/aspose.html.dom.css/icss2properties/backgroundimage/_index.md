## ICSS2Properties.BackgroundImage property

Properti ini menetapkan gambar latar belakang sebuah elemen. Saat menetapkan gambar latar belakang, penulis juga harus menentukan warna latar belakang yang akan digunakan ketika gambar tidak tersedia. Ketika gambar tersedia, gambar tersebut dirender di atas warna latar belakang. (Dengan demikian, warna tersebut terlihat pada bagian transparan gambar).

```java
public String BackgroundImage { get; set; }
```

### Nilai Kembali

properti background-image

### Property Value

Nilai untuk properti ini adalah either , untuk menentukan gambar, atau 'none', ketika tidak ada gambar yang digunakan.
