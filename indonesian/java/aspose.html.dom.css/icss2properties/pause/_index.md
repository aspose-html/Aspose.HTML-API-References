## ICSS2Properties.Pause property

Properti ['pause'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause) adalah singkatan untuk mengatur ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) dan ['pause-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-after). Jika dua nilai diberikan, nilai pertama adalah ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) dan nilai kedua adalah ['pause-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-after). Jika hanya satu nilai yang diberikan, nilai tersebut berlaku untuk kedua properti.

```java
public String Pause { get; set; }
```
