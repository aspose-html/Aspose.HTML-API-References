## ICSS2Properties.OutlineStyle property

Outline yang dibuat dengan properti outline digambar "over" sebuah kotak, yaitu outline selalu berada di atas, dan tidak memengaruhi posisi atau ukuran kotak, atau kotak lainnya. Oleh karena itu, menampilkan atau menyembunyikan outline tidak menyebabkan reflow.

```java
public String OutlineStyle { get; set; }
```
