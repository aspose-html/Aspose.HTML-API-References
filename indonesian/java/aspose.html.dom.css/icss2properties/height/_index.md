## ICSS2Properties.Height property

Properti ini menentukan [content height](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#content-height) kotak yang dihasilkan oleh elemen tingkat blok dan elemen [replaced](https://www.w3.org/TR/1998/REC-CSS2-19980512/conform.html#replaced-element).

Properti ini tidak berlaku untuk elemen [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) yang tidak diganti. Tinggi kotak elemen inline yang tidak diganti diberikan oleh nilai ['line-height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-line-height) milik elemen (yang mungkin diwariskan).

```java
public String Height { get; set; }
```
