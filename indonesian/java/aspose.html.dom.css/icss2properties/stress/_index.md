## ICSS2Properties.Stress property

Menentukan tinggi "puncak lokal" dalam kontur intonasi suara. Misalnya, bahasa Inggris adalah bahasa yang menekankan stres, dan bagian-bagian berbeda dari sebuah kalimat diberikan stres primer, sekunder, atau tersier. Nilai dari ['stress'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-stress) mengontrol jumlah infleksi yang dihasilkan oleh penanda stres ini. Properti ini merupakan pasangan dengan properti ['pitch-range'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pitch-range) dan disediakan untuk memungkinkan pengembang memanfaatkan tampilan auditori tingkat tinggi.

```java
public String Stress { get; set; }
```
