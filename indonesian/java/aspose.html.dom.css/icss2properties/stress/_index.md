## ICSS2Properties.Stress property

Menentukan tinggi "puncak lokal" dalam kontur intonasi suara. Misalnya, bahasa Inggris adalah bahasa yang memiliki tekanan, dan bagian-bagian berbeda dari sebuah kalimat diberikan tekanan primer, sekunder, atau tersier. Nilai dari ['stress'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-stress) mengontrol jumlah infleksi yang dihasilkan dari penanda tekanan ini. Properti ini merupakan pasangan dengan properti ['pitch-range'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pitch-range) dan disediakan untuk memungkinkan pengembang memanfaatkan tampilan auditif tingkat tinggi.

```java
public String Stress { get; set; }
```
