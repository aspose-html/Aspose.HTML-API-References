## ICSS2Properties.TextDecoration property

Properti ini menjelaskan dekorasi yang ditambahkan ke teks suatu elemen. Jika properti ini ditetapkan untuk elemen [block-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#block-level), itu memengaruhi semua turunan inline-level dari elemen tersebut. Jika ditetapkan untuk (atau memengaruhi) elemen [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level), itu memengaruhi semua kotak yang dihasilkan oleh elemen tersebut. Jika elemen tidak memiliki konten atau tidak memiliki konten teks (misalnya, elemen IMG dalam HTML), agen pengguna harus [mengabaikan](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#ignore) properti ini.

Nilai memiliki arti berikut:

none - Tidak menghasilkan dekorasi teks.underline - Setiap baris teks digarisbawahi.overline - Setiap baris teks memiliki garis di atasnya.line-through - Setiap baris teks memiliki garis melalui tengahnya.blink - Teks berkedip (bergantian antara terlihat dan tidak terlihat).

public String TextDecoration { get; set; }
