## ICSS2Properties.PauseBefore property

Properti-properti ini menentukan jeda yang harus diamati sebelum (atau sesudah) membaca konten elemen. Nilai-nilai memiliki arti sebagai berikut:

'[time](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-time)' - Menyatakan jeda dalam satuan waktu absolut (detik dan milidetik). '[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - Mengacu pada invers dari nilai properti ['speech-rate'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-speech-rate). Misalnya, jika speech-rate adalah 120 kata per menit (yaitu, satu kata memakan setengah detik, atau 500ms) maka ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) sebesar 100% berarti jeda 500 ms dan ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) sebesar 20% berarti 100 ms.
