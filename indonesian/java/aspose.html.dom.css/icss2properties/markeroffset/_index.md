## ICSS2Properties.MarkerOffset property

Properti ini menentukan jarak antara [border edges](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#border-edge) terdekat dari kotak penanda dan [principal box](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#principal-box) yang terkait. Offset dapat berupa panjang yang ditentukan pengguna ([length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)) atau dipilih oleh UA ('auto'). Panjang dapat bernilai negatif, tetapi mungkin ada batasan spesifik implementasi.

```java
public String MarkerOffset { get; set; }
```
