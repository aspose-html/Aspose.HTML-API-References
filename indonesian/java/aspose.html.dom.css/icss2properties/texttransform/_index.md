## ICSS2Properties.TextTransform property

Properti ini mengontrol efek kapitalisasi pada teks elemen. Nilai-nilai memiliki makna berikut:

capitalize - Menempatkan karakter pertama setiap kata dalam huruf besar. uppercase - Menempatkan semua karakter setiap kata dalam huruf besar. lowercase - Menempatkan semua karakter setiap kata dalam huruf kecil. none - Tidak ada efek kapitalisasi.

```java
public String TextTransform { get; set; }
```
