## ICSS2Properties.Border property

Properti 'border' adalah properti singkat untuk mengatur lebar, warna, dan gaya yang sama pada keempat tepi sebuah kotak. Tidak seperti properti singkat 'margin' dan 'padding', properti 'border' tidak dapat mengatur nilai yang berbeda pada keempat tepi. Untuk melakukannya, satu atau lebih properti border lainnya harus digunakan.

```java
public String Border { get; set; }
```
