## ICSS2Properties.Border property

Properti 'border' adalah properti singkat untuk mengatur lebar, warna, dan gaya yang sama pada keempat sisi kotak. Tidak seperti properti singkat 'margin' dan 'padding', properti 'border' tidak dapat mengatur nilai berbeda pada keempat sisi. Untuk melakukannya, satu atau lebih properti border lainnya harus digunakan.

```java
public String Border { get; set; }
```
