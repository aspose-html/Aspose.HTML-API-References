## ICSS2Properties.SpeakNumeral property

Properti ini mengontrol cara angka diucapkan. Nilai-nilai memiliki arti berikut:

digits - Mengucapkan angka sebagai digit individu. Jadi, "237" diucapkan "Dua Tiga Tujuh".continuous - Mengucapkan angka sebagai satu angka lengkap. Jadi, "237" diucapkan "Dua ratus tiga puluh tujuh". Representasi kata tergantung pada bahasa.

```java
public String SpeakNumeral { get; set; }
```
