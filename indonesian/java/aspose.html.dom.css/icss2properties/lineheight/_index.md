## ICSS2Properties.LineHeight property

Jika properti ini diterapkan pada elemen [block-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#block-level) yang kontennya terdiri dari elemen [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level), maka properti ini menentukan tinggi minimal setiap kotak inline yang dihasilkan.

Jika properti ini diterapkan pada elemen [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level), maka properti ini menentukan tinggi tepat setiap kotak yang dihasilkan oleh elemen tersebut. (Kecuali untuk elemen inline [replaced](https://www.w3.org/TR/1998/REC-CSS2-19980512/conform.html#replaced-element), di mana tinggi kotak diberikan oleh properti ['height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-height).)

```java
public String LineHeight { get; set; }
```
