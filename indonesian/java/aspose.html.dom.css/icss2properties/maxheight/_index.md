## ICSS2Properties.MaxHeight property

Kedua properti ini memungkinkan penulis untuk membatasi tinggi kotak dalam rentang tertentu. Nilai memiliki arti berikut:

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - Menentukan tinggi terhitung minimum atau maksimum yang tetap.'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - Menentukan persentase untuk menghitung nilai terhitung. Persentase dihitung relatif terhadap tinggi [containing block](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#containing-block) dari kotak yang dihasilkan. Jika tinggi blok kontainer tidak ditentukan secara eksplisit (mis., tergantung pada tinggi konten), nilai persentase diinterpretasikan seperti 'auto'.none - (Hanya pada ['max-height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-max-height)) Tidak ada batas pada tinggi kotak.

```java
public String MaxHeight { get; set; }
```
