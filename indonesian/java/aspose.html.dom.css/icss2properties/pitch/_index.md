## ICSS2Properties.Pitch property

Menentukan nada rata-rata (frekuensi) dari suara yang diucapkan. Nada rata-rata sebuah suara tergantung pada keluarga suara. Misalnya, nada rata-rata untuk suara pria standar sekitar 120Hz, tetapi untuk suara wanita, sekitar 210Hz.

```java
public String Pitch { get; set; }
```
