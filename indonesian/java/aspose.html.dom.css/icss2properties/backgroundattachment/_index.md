## ICSS2Properties.BackgroundAttachment property

Jika gambar latar belakang ditentukan, properti ini menentukan apakah gambar tersebut tetap relatif terhadap viewport ('fixed') atau menggulir bersama dokumen ('scroll').

Bahkan jika gambar tersebut tetap, ia hanya akan terlihat ketika berada di area latar belakang atau padding elemen. Jadi, kecuali gambar tersebut diulang ('background-repeat: repeat'), ia mungkin tidak terlihat.

```java
public String BackgroundAttachment { get; set; }
```
