## ICSS2Properties.BackgroundAttachment property

Jika gambar latar belakang ditentukan, properti ini menentukan apakah gambar tersebut tetap ('fixed') relatif terhadap viewport atau menggulir bersama dokumen ('scroll').

Bahkan jika gambar tersebut tetap, ia hanya akan terlihat ketika berada di latar belakang atau area padding elemen. Oleh karena itu, kecuali gambar tersebut ditile ('background-repeat: repeat'), ia mungkin tidak terlihat.

```java
public String BackgroundAttachment { get; set; }
```
