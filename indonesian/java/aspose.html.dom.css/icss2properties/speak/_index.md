## ICSS2Properties.Speak property

Properti ini menentukan apakah teks akan dirender secara aurally dan jika ya, dalam cara apa (agak mirip dengan properti ['display'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-display) ). Nilai yang mungkin adalah:

none - Menekan rendering aurally sehingga elemen tidak memerlukan waktu untuk dirender. Catatan, bagaimanapun, bahwa keturunan dapat menimpa nilai ini dan akan dibacakan. (Untuk memastikan menekan rendering sebuah elemen dan keturunannya, gunakan properti ['display'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-display) ).normal - Menggunakan aturan pengucapan yang bergantung pada bahasa untuk merender sebuah elemen dan anak‑anaknya. spell-out - Mengeja teks satu huruf pada satu waktu (berguna untuk akronim dan singkatan).

```java
public String Speak { get; set; }
```
