## ICSS2Properties.Speak property

Properti ini menentukan apakah teks akan dirender secara auditori dan jika ya, dalam cara apa (agak mirip dengan properti ['display'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-display) property). Nilai yang mungkin adalah:

none - Menekan rendering auditori sehingga elemen tidak memerlukan waktu untuk dirender. Catatan, bagaimanapun, bahwa turunan dapat mengganti nilai ini dan akan diucapkan. (Untuk memastikan menekan rendering sebuah elemen dan turunannya, gunakan properti ['display'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-display) property).normal - Menggunakan aturan pengucapan yang bergantung pada bahasa untuk merender sebuah elemen dan anak-anaknya.spell-out - Mengeja teks satu huruf pada satu waktu (berguna untuk akronim dan singkatan).

```java
public String Speak { get; set; }
```
