## ICSS2Properties.BackgroundRepeat property

Jika gambar latar belakang ditentukan, properti ini menentukan apakah gambar diulang (tiled), dan bagaimana. Semua pengulangan menutupi area konten dan padding dari sebuah kotak. Nilai-nilai memiliki arti berikut:

repeat - Gambar diulang secara horizontal dan vertikal. repeat-x - Gambar diulang hanya secara horizontal. repeat-y - Gambar diulang hanya secara vertikal. no-repeat - Gambar tidak diulang: hanya satu salinan gambar yang digambar.

```java
public String BackgroundRepeat { get; set; }
```

### Nilai Kembali

properti background-repeat

### Property Value

Nilai background repeat dari daftar seperti yang didefinisikan di atas.
