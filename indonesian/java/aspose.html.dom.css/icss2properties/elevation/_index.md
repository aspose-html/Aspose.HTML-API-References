## ICSS2Properties.Elevation property

Nilai properti ini memiliki arti berikut:

'angle' - Menentukan elevasi sebagai sudut, antara '-90deg' dan '90deg'. '0deg' berarti pada horizon depan, yang secara longgar berarti sejajar dengan pendengar. '90deg' berarti tepat di atas dan '-90deg' berarti tepat di bawah.below - Sama dengan '-90deg'.level - Sama dengan '0deg'.above - Sama dengan '90deg'.higher - Menambahkan 10 derajat ke elevasi saat ini.lower - Mengurangi 10 derajat dari elevasi saat ini.

public String Elevation { get; set; }
