## ICSS2Properties.MaxWidth property

Kedua properti ini memungkinkan penulis membatasi lebar kotak ke rentang tertentu. Nilai memiliki arti sebagai berikut:

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - Menentukan lebar terhitung minimum atau maksimum yang tetap.'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - Menentukan persentase untuk menghitung nilai terhitung. Persentase dihitung relatif terhadap lebar [blok kontainer](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#containing-block) kotak yang dihasilkan.none - (Hanya pada ['max-width](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-max-width)') Tidak ada batas pada lebar kotak.

public String MaxWidth { get; set; }
