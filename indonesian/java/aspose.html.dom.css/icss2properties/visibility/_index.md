## ICSS2Properties.Visibility property

Properti ['visibility'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visufx.html#propdef-visibility) menentukan apakah kotak yang dihasilkan oleh sebuah elemen dirender. Kotak yang tidak terlihat tetap memengaruhi tata letak (atur properti ['display'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-display) ke 'none' untuk menekan pembuatan kotak sepenuhnya). Nilai-nilai memiliki arti sebagai berikut:

visible - Kotak yang dihasilkan terlihat. hidden - Kotak yang dihasilkan tidak terlihat (sepenuhnya transparan), tetapi tetap memengaruhi tata letak. collapse - Silakan lihat bagian tentang [dynamic row and column effects](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#dynamic-effects) dalam tabel. Jika digunakan pada elemen selain baris atau kolom, 'collapse' memiliki arti yang sama dengan 'hidden'.

```java
public String Visibility { get; set; }
```
