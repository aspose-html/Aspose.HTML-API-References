## ICSS2Properties.BorderRightWidth property

Properti ini adalah properti singkat untuk mengatur 'border-top-width', 'border-right-width', 'border-bottom-width', dan 'border-left-width' pada tempat yang sama dalam lembar gaya.

Jika hanya ada satu nilai, nilai tersebut diterapkan ke semua sisi. Jika ada dua nilai, batas atas dan bawah diatur ke nilai pertama dan kanan serta kiri diatur ke nilai kedua. Jika ada tiga nilai, atas diatur ke nilai pertama, kiri dan kanan diatur ke nilai kedua, dan bawah diatur ke nilai ketiga. Jika ada empat nilai, nilai tersebut diterapkan ke atas, kanan, bawah, dan kiri, masing‑masing.

```java
public String BorderRightWidth { get; set; }
```
