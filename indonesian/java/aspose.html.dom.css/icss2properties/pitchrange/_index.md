## ICSS2Properties.PitchRange property

Menentukan variasi dalam nada rata-rata. Nada yang dipersepsikan dari suara manusia ditentukan oleh frekuensi fundamental dan biasanya memiliki nilai 120Hz untuk suara pria dan 210Hz untuk suara wanita. Bahasa manusia diucapkan dengan variasi intonasi dan nada; variasi ini menyampaikan makna tambahan dan penekanan. Oleh karena itu, suara yang sangat bersemangat, yaitu yang sangat berintensitas, menampilkan rentang nada yang tinggi. Properti ini menentukan rentang di mana variasi tersebut terjadi, yaitu seberapa jauh frekuensi fundamental dapat menyimpang dari nada rata-rata.

```java
public String PitchRange { get; set; }
```
