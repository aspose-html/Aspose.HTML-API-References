## ICSS2Properties.PitchRange property

Menentukan variasi dalam pitch rata-rata. Pitch yang dipersepsikan dari suara manusia ditentukan oleh frekuensi fundamental dan biasanya memiliki nilai 120Hz untuk suara pria dan 210Hz untuk suara wanita. Bahasa manusia diucapkan dengan variasi intonasi dan pitch; variasi ini menyampaikan makna tambahan dan penekanan. Oleh karena itu, suara yang sangat bersemangat, yaitu yang sangat berintonasi, menampilkan rentang pitch yang tinggi. Properti ini menentukan rentang di mana variasi tersebut terjadi, yaitu seberapa banyak frekuensi fundamental dapat menyimpang dari pitch rata-rata.

```java
public String PitchRange { get; set; }
```
