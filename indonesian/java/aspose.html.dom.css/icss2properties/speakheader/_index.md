## ICSS2Properties.SpeakHeader property

Properti ini menentukan apakah header tabel diucapkan sebelum setiap sel, atau hanya sebelum sel ketika sel tersebut terkait dengan header yang berbeda dari sel sebelumnya. Nilai-nilai memiliki arti berikut

once - Header diucapkan satu kali, sebelum serangkaian sel. always - Header diucapkan sebelum setiap sel yang relevan.

```java
public String SpeakHeader { get; set; }
```
