## ICSS2Properties.SpeakHeader property

Properti ini menentukan apakah header tabel dibacakan sebelum setiap sel, atau hanya sebelum sel ketika sel tersebut terkait dengan header yang berbeda dari sel sebelumnya. Nilai memiliki arti berikut:

once - Header dibacakan satu kali, sebelum serangkaian sel. always - Header dibacakan sebelum setiap sel yang relevan.

```java
public String SpeakHeader { get; set; }
```
