## ICSS2Properties.Margin property

Properti ['margin'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin) adalah properti singkat untuk mengatur ['margin-top'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-top), ['margin-right'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-right), ['margin-bottom'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-bottom), dan ['margin-left'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-left) pada tempat yang sama dalam lembar gaya.

Jika hanya ada satu nilai, nilai itu diterapkan ke semua sisi. Jika ada dua nilai, margin atas dan bawah diatur ke nilai pertama dan margin kanan serta kiri diatur ke nilai kedua. Jika ada tiga nilai, atas diatur ke nilai pertama, kiri dan kanan diatur ke nilai kedua, dan bawah diatur ke nilai ketiga. Jika ada empat nilai, mereka diterapkan ke atas, kanan, bawah, dan kiri, masing‑masing.
