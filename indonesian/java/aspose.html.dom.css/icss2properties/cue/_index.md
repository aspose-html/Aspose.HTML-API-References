## ICSS2Properties.Cue property

Properti ['cue'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue) adalah singkatan untuk mengatur ['cue-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-before) dan ['cue-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-after). Jika dua nilai diberikan, nilai pertama adalah ['cue-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-before) dan nilai kedua adalah ['cue-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-after). Jika hanya satu nilai yang diberikan, itu berlaku untuk kedua properti.

```java
public String Cue { get; set; }
```
