## ICSS2Properties.EmptyCells property

Dalam model batas terpisah, properti ini mengontrol perenderan batas di sekitar sel yang tidak memiliki konten yang terlihat. Sel kosong dan sel dengan properti 'visibility' yang disetel ke 'hidden' dianggap tidak memiliki konten yang terlihat.

```java
public String EmptyCells { get; set; }
```
