## ICSS2Properties.ListStylePosition property

Properti ini menentukan posisi kotak penanda dalam kotak blok utama. Nilai-nilai memiliki arti berikut:

outside - Kotak penanda berada di luar kotak blok utama. Catatan. CSS1 tidak menentukan lokasi tepat kotak penanda dan demi kompatibilitas, CSS2 tetap sama ambigu. Untuk kontrol yang lebih tepat atas kotak penanda, silakan gunakan markers. inside - Kotak penanda adalah kotak inline pertama dalam kotak blok utama, setelah itu konten elemen mengalir.

```java
public String ListStylePosition { get; set; }
```
