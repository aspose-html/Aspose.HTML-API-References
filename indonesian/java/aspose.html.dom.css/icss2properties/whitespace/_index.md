## ICSS2Properties.WhiteSpace property

Properti ini menyatakan bagaimana [whitespace](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#whitespace) di dalam elemen ditangani. Nilai-nilai memiliki arti berikut:

normal - Nilai ini mengarahkan agen pengguna untuk menggabungkan rangkaian spasi putih, dan memutus baris bila diperlukan untuk mengisi kotak baris. Pemutusan baris tambahan dapat dibuat oleh kemunculan "\A" dalam konten yang dihasilkan (mis., untuk elemen BR dalam HTML). pre - Nilai ini mencegah agen pengguna menggabungkan rangkaian spasi putih. Baris hanya diputus pada baris baru dalam sumber, atau pada kemunculan "\A" dalam konten yang dihasilkan. nowrap - Nilai ini menggabungkan spasi putih seperti pada 'normal', tetapi menekan pemutusan baris dalam teks kecuali yang dibuat oleh "\A" dalam konten yang dihasilkan (mis., untuk elemen BR dalam HTML).

```java
public String WhiteSpace { get; set; }
```
