## ICSS2Properties.Padding property

Properti ['padding'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-padding) adalah properti singkat untuk mengatur ['padding-top'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-padding-top), ['padding-right'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-padding-right), ['padding-bottom'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-padding-bottom), dan ['padding-left'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-padding-left) pada tempat yang sama dalam lembar gaya.

Jika hanya ada satu nilai, nilai tersebut diterapkan ke semua sisi. Jika ada dua nilai, padding atas dan bawah diatur ke nilai pertama dan padding kanan serta kiri diatur ke nilai kedua. Jika ada tiga nilai, padding atas diatur ke nilai pertama, kiri dan kanan ke nilai kedua, dan bawah ke nilai ketiga. Jika ada empat nilai, mereka diterapkan masing‑masing ke atas, kanan, bawah, dan kiri.
