## ICSS2Properties.CaptionSide property

Properti ini menentukan posisi kotak keterangan relatif terhadap kotak tabel. Nilai-nilai memiliki arti sebagai berikut:

top - Menempatkan kotak keterangan di atas kotak tabel. bottom - Menempatkan kotak keterangan di bawah kotak tabel. left - Menempatkan kotak keterangan di sebelah kiri kotak tabel. right - Menempatkan kotak keterangan di sebelah kanan kotak tabel.

```java
public String CaptionSide { get; set; }
```
