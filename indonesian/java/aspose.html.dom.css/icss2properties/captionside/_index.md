## ICSS2Properties.CaptionSide property

Properti ini menentukan posisi kotak caption relatif terhadap kotak tabel. Nilai-nilai memiliki arti sebagai berikut:

top - Menempatkan kotak caption di atas kotak tabel.bottom - Menempatkan kotak caption di bawah kotak tabel.left - Menempatkan kotak caption di sebelah kiri kotak tabel.right - Menempatkan kotak caption di sebelah kanan kotak tabel.

```java
public String CaptionSide { get; set; }
```
