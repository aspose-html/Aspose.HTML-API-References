## ICSS2Properties.CounterReset property

Properti ['counter-reset'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-counter-reset) juga berisi daftar satu atau lebih nama penghitung, masing-masing dapat diikuti secara opsional oleh sebuah bilangan bulat. Bilangan bulat tersebut memberikan nilai yang ditetapkan pada penghitung setiap kali elemen muncul. Nilai default adalah 0.

```java
public String CounterReset { get; set; }
```
