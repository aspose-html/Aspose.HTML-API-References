## ICSS2Properties.VoiceFamily property

Nilainya adalah daftar terprioritas, dipisahkan koma, dari nama keluarga suara (bandingkan dengan ['font-family'](https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html#propdef-font-family)). Nilai memiliki makna berikut:

'generic-voice' - Nilainya adalah keluarga suara. Nilai yang mungkin adalah 'male', 'female', dan 'child'.'specific-voice' - Nilainya adalah contoh spesifik (mis., comedian, trinoids, carlos, lani).

```java
public String VoiceFamily { get; set; }
```
