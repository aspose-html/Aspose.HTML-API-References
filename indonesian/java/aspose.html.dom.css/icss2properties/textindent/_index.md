## ICSS2Properties.TextIndent property

Properti ini menentukan indentasi baris pertama teks dalam sebuah blok. Lebih tepatnya, ia menentukan indentasi kotak pertama yang mengalir ke dalam [line box](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#line-box) pertama blok. Kotak tersebut diindentasi relatif terhadap tepi kiri (atau kanan, untuk tata letak right-to-left) dari line box. Agen pengguna harus merender indentasi ini sebagai ruang kosong.

Nilai memiliki arti berikut:

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - Indentasi adalah panjang tetap.'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - Indentasi adalah persentase lebar blok kontainer.

public String TextIndent { get; set; }
