## ICSS2Properties.FontFamily property

Properti ini menentukan daftar prioritas nama keluarga font dan/atau nama keluarga generik. Untuk mengatasi masalah bahwa satu font mungkin tidak memiliki glif untuk menampilkan semua karakter dalam dokumen, atau bahwa tidak semua font tersedia di semua sistem, properti ini memungkinkan penulis menentukan daftar font, semua dengan gaya dan ukuran yang sama, yang dicoba secara berurutan untuk melihat apakah mereka memiliki glif untuk karakter tertentu. Daftar ini disebut set font.

```java
public String FontFamily { get; set; }
```
