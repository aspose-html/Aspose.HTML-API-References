## ICSS2Properties.Size property

Properti ini menentukan ukuran dan orientasi kotak halaman.

Ukuran kotak halaman dapat berupa "absolute" (ukuran tetap) atau "relative" (dapat diskalakan, yaitu menyesuaikan ukuran lembar yang tersedia). Kotak halaman relatif memungkinkan agen pengguna untuk menskalakan dokumen dan memanfaatkan ukuran target secara optimal.

Tiga nilai untuk properti ['size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-size) membuat kotak halaman relatif:

auto - Kotak halaman akan diatur ke ukuran dan orientasi lembar target. landscape - Menimpa orientasi target. Kotak halaman memiliki ukuran yang sama dengan target, dan sisi yang lebih panjang berada secara horizontal. portrait - Menimpa orientasi target. Kotak halaman memiliki ukuran yang sama dengan target, dan sisi yang lebih pendek berada secara horizontal.

public String Size { get; set; }
