## ICSS2Properties.FontSizeAdjust property

Dalam skrip bikameral, ukuran tampak subjektif dan keterbacaan sebuah font lebih sedikit bergantung pada nilai 'font-size' mereka dibandingkan nilai 'x-height', atau, lebih berguna, pada rasio kedua nilai tersebut, yang disebut nilai aspek (ukuran font dibagi x-height). Semakin tinggi nilai aspek, semakin besar kemungkinan sebuah font pada ukuran lebih kecil tetap terbaca. Sebaliknya, huruf dengan nilai aspek lebih rendah akan menjadi tidak terbaca lebih cepat di bawah ukuran ambang tertentu dibandingkan huruf dengan nilai aspek lebih tinggi. Substitusi font yang sederhana yang hanya mengandalkan ukuran font dapat menyebabkan karakter tidak terbaca.

```java
public String FontSizeAdjust { get; set; }
```
