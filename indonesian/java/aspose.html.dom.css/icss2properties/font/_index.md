## ICSS2Properties.Font property

Properti 'font' adalah, kecuali sebagaimana dijelaskan di bawah, properti singkat untuk mengatur 'font-style', 'font-variant', 'font-weight', 'font-size', 'line-height', dan 'font-family' pada tempat yang sama dalam lembar gaya. Sintaks properti ini didasarkan pada notasi singkat tipografi tradisional untuk mengatur banyak properti yang terkait dengan font.

```java
public String Font { get; set; }
```
