## ICSS2Properties.SpeechRate property

Properti ini menentukan kecepatan bicara. Perhatikan bahwa nilai kata kunci absolut dan relatif keduanya diizinkan (bandingkan dengan ['font-size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html#propdef-font-size)). Nilai-nilai memiliki arti berikut:

'[number](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-number)' - Menentukan kecepatan bicara dalam kata per menit, sebuah kuantitas yang sedikit bervariasi menurut bahasa tetapi tetap didukung secara luas oleh sintetis suara.

x-slow - Sama dengan 80 kata per menit.

slow - Sama dengan 120 kata per menit

medium - Sama dengan 180 - 200 kata per menit.

fast - Sama dengan 300 kata per menit.

x-fast - Sama dengan 500 kata per menit.

faster - Menambahkan 40 kata per menit ke kecepatan bicara saat ini.

slower - Mengurangi 40 kata per menit dari kecepatan bicara saat ini.

```java
public String SpeechRate { get; set; }
```
