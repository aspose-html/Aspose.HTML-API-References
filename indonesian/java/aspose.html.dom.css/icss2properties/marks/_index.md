## ICSS2Properties.Marks property

Pada pencetakan berkualitas tinggi, tanda sering ditambahkan di luar kotak halaman. Properti ini menentukan apakah tanda silang, tanda potong, atau keduanya harus dirender tepat di luar tepi [page box](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#page-box).

Tanda potong menunjukkan di mana halaman harus dipotong. Tanda silang (juga dikenal sebagai tanda register atau tanda registrasi) digunakan untuk menyelaraskan lembar.

Tanda hanya terlihat pada kotak halaman absolut (lihat properti ['size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-size)). Pada kotak halaman relatif, kotak halaman akan diselaraskan dengan target dan tanda akan berada di luar area yang dapat dicetak.

Ukuran, gaya, dan posisi tanda silang tergantung pada agen pengguna.

```java
public String Marks { get; set; }
```
