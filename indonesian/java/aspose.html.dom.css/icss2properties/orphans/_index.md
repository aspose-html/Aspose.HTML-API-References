## ICSS2Properties.Orphans property

Properti ['orphans'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-orphans) menentukan jumlah minimum baris dalam sebuah paragraf yang harus ditinggalkan di bagian bawah halaman. Properti ['widows'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-widows) menentukan jumlah minimum baris dalam sebuah paragraf yang harus ditinggalkan di bagian atas halaman. Contoh cara mereka digunakan untuk mengontrol pemutusan halaman diberikan di bawah.

```java
public String Orphans { get; set; }
```
