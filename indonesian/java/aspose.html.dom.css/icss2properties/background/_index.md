## ICSS2Properties.Background property

Properti 'background' adalah properti singkat untuk mengatur properti latar belakang individual (misalnya, 'background-color', 'background-image', 'background-repeat', 'background-attachment', dan 'background-position') pada tempat yang sama dalam lembar gaya.

```java
public String Background { get; set; }
```

### Nilai Kembali

properti background

### Property Value

Mendapatkan atau mengatur properti singkat untuk mengatur properti latar belakang individual pada tempat yang sama dalam lembar gaya.
