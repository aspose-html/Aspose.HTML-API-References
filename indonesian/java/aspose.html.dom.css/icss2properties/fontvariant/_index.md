## ICSS2Properties.FontVariant property

Pada font small-caps, glif untuk huruf kecil terlihat mirip dengan huruf besar, tetapi dalam ukuran yang lebih kecil dan dengan proporsi yang sedikit berbeda. Properti 'font-variant' meminta font semacam itu untuk sistem bicameral (memiliki dua bentuk huruf, seperti pada skrip Latin). Properti ini tidak memberikan efek visual untuk skrip yang unicameral (hanya memiliki satu bentuk huruf, seperti pada kebanyakan sistem penulisan di dunia).

```java
public String FontVariant { get; set; }
```
