## ICSS2Properties.FontVariant property

Dalam font small-caps, glif untuk huruf kecil terlihat mirip dengan huruf kapital, tetapi dalam ukuran yang lebih kecil dan dengan proporsi yang sedikit berbeda. Properti 'font-variant' meminta font semacam itu untuk bahasa bikameral (memiliki dua bentuk huruf, seperti pada skrip Latin). Properti ini tidak berpengaruh secara visual untuk skrip yang unikerameral (memiliki satu bentuk huruf, seperti pada kebanyakan sistem penulisan di dunia).

```java
public String FontVariant { get; set; }
```
