## ICSS2Properties.Richness property

Menentukan kekayaan, atau kecerahan, suara yang berbicara. Suara yang kaya akan "terbawa" di ruangan besar, suara yang halus tidak. (Istilah "halus" mengacu pada bagaimana bentuk gelombang terlihat ketika digambar.)

public String Richness { get; set; }
