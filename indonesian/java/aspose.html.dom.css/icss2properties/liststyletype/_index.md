## ICSS2Properties.ListStyleType property

Properti ini menentukan tampilan penanda item daftar jika ['list-style-image'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-list-style-image) memiliki nilai 'none' atau jika gambar yang ditunjuk oleh URI tidak dapat ditampilkan. Nilai 'none' berarti tidak ada penanda, selain itu ada tiga jenis penanda: glyph, sistem penomoran, dan sistem alfabet. Catatan. Daftar bernomor meningkatkan aksesibilitas dokumen dengan memudahkan navigasi daftar.

Glyph ditentukan dengan disc, circle, dan square. Rendering tepatnya tergantung pada agen pengguna.

Sistem penomoran ditentukan dengan:

decimal - Angka desimal, dimulai dengan 1. decimal-leading-zero - Angka desimal yang diisi dengan nol di depan (mis., 01, 02, 03, ..., 98, 99). lower-roman - Numeral Romawi huruf kecil (i, ii, iii, iv, v, dll.). upper-roman - Numeral Romawi huruf besar (I, II, III, IV, V, dll.). hebrew - Penomoran tradisional Ibrani. georgian - Penomoran tradisional Georgia (an, ban, gan, ..., he, tan, in, in-an, ...). armenian - Penomoran tradisional Armenia. cjk-ideographic - Angka ideografik polos. hiragana - a, i, u, e, o, ka, ki, ... katakana - A, I, U, E, O, KA, KI, ... hiragana-iroha - i, ro, ha, ni, ho, he, to, ... katakana-iroha - I, RO, HA, NI, HO, HE, TO, ...

public String ListStyleType { get; set; }
