## ICSS2Properties.PageBreakAfter property

Nilai-nilai untuk properti ini memiliki arti sebagai berikut:

auto - Tidak memaksa maupun melarang pemutusan halaman sebelum (setelah, di dalam) kotak yang dihasilkan.always - Selalu memaksa pemutusan halaman sebelum (setelah) kotak yang dihasilkan.avoid - Menghindari pemutusan halaman sebelum (setelah, di dalam) kotak yang dihasilkan.left - Memaksa satu atau dua pemutusan halaman sebelum (setelah) kotak yang dihasilkan sehingga halaman berikut diformat sebagai halaman kiri.right - Memaksa satu atau dua pemutusan halaman sebelum (setelah) kotak yang dihasilkan sehingga halaman berikut diformat sebagai halaman kanan.

```java
public String PageBreakAfter { get; set; }
```
