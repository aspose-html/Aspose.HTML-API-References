## ICSS2Properties.Direction property

Properti ini menentukan arah penulisan dasar blok dan arah embedding serta overrides (lihat ['unicode-bidi'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-unicode-bidi)) untuk algoritma bidirectional Unicode. Selain itu, properti ini menentukan arah tata letak kolom [table](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html), arah [overflow](https://www.w3.org/TR/1998/REC-CSS2-19980512/visufx.html#overflow) horizontal, dan posisi baris terakhir yang tidak lengkap dalam sebuah blok bila 'text-align: justify'.

```java
public String Direction { get; set; }
```
