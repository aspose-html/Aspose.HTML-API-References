## ICSSStyleDeclaration.CSSText property

Representasi teks yang dapat diparse dari blok deklarasi (tidak termasuk kurung kurawal di sekelilingnya). Menetapkan atribut ini akan menyebabkan parsing nilai baru dan mengatur ulang semua properti dalam blok deklarasi termasuk penghapusan atau penambahan properti.

```java
public String CSSText { get; set; }
```

### Property Value

Menetapkan atribut ini mengubah gaya inline. Jika Anda menginginkan representasi teks dari blok deklarasi yang dihitung, Anda dapat mendapatkannya dengan JSON.Stringify().
