## ICSSStyleDeclaration.GetPropertyCSSValue method

Digunakan untuk mengambil representasi objek dari nilai properti CSS jika telah secara eksplisit ditetapkan dalam blok deklarasi ini. Metode ini mengembalikan null jika properti tersebut adalah properti singkat. Nilai properti singkat hanya dapat diakses dan dimodifikasi sebagai String, menggunakan metode getPropertyValue dan setProperty.

```java
public CSSValue GetPropertyCSSValue(String propertyName)
```

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| propertyName | String | propertyName adalah String yang mewakili nama properti yang akan diambil. |

### Nilai Kembali

value adalah CSSValue yang berisi nilai CSS untuk sebuah properti. Jika tidak ada, mengembalikan null.
