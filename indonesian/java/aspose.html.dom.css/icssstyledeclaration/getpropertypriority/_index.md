## ICSSStyleDeclaration.GetPropertyPriority method

Digunakan untuk mengambil prioritas sebuah properti CSS (misalnya qualifier \"important\") jika properti tersebut telah secara eksplisit diatur dalam blok deklarasi ini.

```java
public String GetPropertyPriority(String propertyName)
```

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| propertyName | String | property adalah DOMString yang mewakili nama properti yang akan diperiksa. |

### Nilai Kembali

priority adalah DOMString yang mewakili prioritas (misalnya "important") jika ada. Jika tidak ada, mengembalikan String kosong.
