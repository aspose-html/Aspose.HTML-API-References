## SetProperty(String, String) {#setproperty}

Antarmuka metode CSSStyleDeclaration.setProperty() digunakan untuk menetapkan nilai properti dengan prioritas default dalam blok deklarasi ini. Prioritas default bukan "important", yaitu String.Empty.

```java
public void SetProperty(String propertyName, String value)
```

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| propertyName | String | String yang mewakili nama properti CSS (dengan tanda hubung) yang akan diubah. |
| nilai | String | String yang berisi nilai properti baru. Jika tidak ditentukan, dianggap sebagai String kosong. |

## SetProperty(String, String, String) {#setproperty_1}

Antarmuka metode CSSStyleDeclaration.setProperty() digunakan untuk menetapkan nilai properti dengan prioritas default dalam blok deklarasi ini. Prioritas default bukan "important", yaitu String.Empty.

```java
public void SetProperty(String propertyName, String value, String priority)
```

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| propertyName | String | String yang mewakili nama properti CSS (dengan tanda hubung) yang akan diubah. |
| nilai | String | String yang berisi nilai properti baru. Jika tidak ditentukan, dianggap sebagai String kosong. |
| prioritas | String | String yang memungkinkan prioritas CSS "important" diatur. Jika tidak ditentukan, dianggap sebagai String kosong. Nilai yang diterima: nilai String "important", kata kunci undefined, atau nilai String kosong "". |
