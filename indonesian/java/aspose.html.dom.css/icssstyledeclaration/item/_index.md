## ICSSStyleDeclaration indexer

Digunakan untuk mengambil properti yang secara eksplisit telah ditetapkan dalam blok deklarasi ini. Urutan properti yang diambil menggunakan metode ini tidak harus sama dengan urutan saat mereka ditetapkan. Metode ini dapat digunakan untuk mengiterasi semua properti dalam blok deklarasi ini.

```java
public String this[int index] { get; }
```

### Nilai Kembali

propertyName adalah String yang merupakan nama properti CSS pada indeks yang ditentukan.

### Property Value

index adalah indeks node yang akan diambil. Indeks dimulai dari nol.
