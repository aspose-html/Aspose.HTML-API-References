## ICSSStyleDeclaration.ParentRule property

Properti baca-saja CSSStyleDeclaration.parentRule mengembalikan sebuah CSSRule yang merupakan induk dari blok gaya ini, misalnya sebuah [`CSSStyleRule`](../../icssstylerule/) yang mewakili gaya untuk sebuah selector CSS.

```java
public ICSSRule ParentRule { get; }
```

### Property Value

Aturan CSS yang berisi blok deklarasi ini atau null jika [`CSSStyleDeclaration`](../) ini tidak terhubung ke sebuah [`CSSRule`](../../icssrule/).
