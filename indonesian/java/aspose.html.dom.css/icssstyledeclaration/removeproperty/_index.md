## ICSSStyleDeclaration.RemoveProperty method

Antarmuka metode CSSStyleDeclaration.removeProperty() menghapus sebuah properti dari objek deklarasi gaya CSS.

```java
public String RemoveProperty(String propertyName)
```

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| propertyName | String | propertyName adalah String yang mewakili nama properti yang akan dihapus. Perhatikan bahwa nama properti yang terdiri dari beberapa kata dipisahkan dengan tanda hubung dan tidak menggunakan camelCase. |

### Nilai Kembali

oldValue adalah DOMString yang sama dengan nilai properti CSS sebelum dihapus.

### Pengecualian

| pengecualian | kondisi |
| --- | --- |
| DOMException | NO_MODIFICATION_ALLOWED_ERR: jika properti atau blok deklarasi bersifat baca saja. |
