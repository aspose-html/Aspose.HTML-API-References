## ICSSStyleSheet.OwnerRule property

Properti CSSStyleSheet yang hanya-baca ownerRule mengembalikan [`CSSImportRule`](../../icssimportrule/) yang sesuai dengan at-rule @import yang mengimpor lembar gaya ke dalam dokumen. Jika lembar gaya tidak diimpor ke dalam dokumen menggunakan @import, nilai yang dikembalikan adalah null.

```java
public ICSSRule OwnerRule { get; }
```

### Property Value

CSSImportRule yang sesuai dengan aturan @import yang mengimpor lembar gaya ke dalam dokumen. Jika lembar gaya tidak diimpor ke dalam dokumen menggunakan @import, nilai yang dikembalikan adalah null.
