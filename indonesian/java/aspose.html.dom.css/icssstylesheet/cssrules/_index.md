## ICSSStyleSheet.CSSRules property

Properti read-only cssRules dari CSSStyleSheet mengembalikan [`CSSRuleList`](../../icssrulelist/) yang hidup yang menyediakan daftar terkini secara real-time dari setiap aturan CSS yang membentuk stylesheet. Setiap item dalam daftar adalah [`CSSRule`](../../icssrule/) yang mendefinisikan satu aturan.

```java
public ICSSRuleList CSSRules { get; }
```

### Property Value

Sebuah [`CSSRuleList`](../../icssrulelist/) yang terus diperbarui secara real-time berisi setiap aturan CSS yang membentuk stylesheet. Setiap entri dalam daftar aturan adalah objek [`CSSRule`](../../icssrule/) yang menggambarkan satu aturan yang membentuk stylesheet.

## Catatan

[CSSOM](https://drafts.csswg.org/cssom/) defines APIs (including generic parsing and serialization rules) for Media Queries, Selectors, and of course CSS itself.
