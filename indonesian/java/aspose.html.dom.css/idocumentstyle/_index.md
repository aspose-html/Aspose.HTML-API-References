## IDocumentStyle interface

Antarmuka DocumentStyle menyediakan mekanisme untuk mengambil lembar gaya yang disematkan dalam sebuah dokumen. Diharapkan bahwa sebuah instance dari antarmuka DocumentStyle dapat diperoleh dengan menggunakan metode casting spesifik binding pada sebuah instance dari antarmuka Document.

Lihat juga [Document Object Model (DOM) Level 2 Style Specification](http://www.w3.org/TR/2000/REC-DOM-Level-2-Style-20001113).

```java
public interface IDocumentStyle
```

## Properti

| Nama | Deskripsi |
| --- | --- |
| [getStyleSheets](../../com.aspose.html.dom.css/idocumentstyle/stylesheets/) Daftar yang berisi semua lembar gaya yang secara eksplisit ditautkan atau disematkan dalam sebuah dokumen. Untuk dokumen HTML, ini mencakup lembar gaya eksternal, yang disertakan melalui elemen HTML LINK, dan elemen STYLE inline. |
