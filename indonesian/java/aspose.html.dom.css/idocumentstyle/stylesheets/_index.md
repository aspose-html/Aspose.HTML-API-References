## IDocumentStyle.StyleSheets property

Daftar yang berisi semua lembar gaya yang secara eksplisit ditautkan atau disematkan dalam sebuah dokumen. Untuk dokumen HTML, ini mencakup lembar gaya eksternal yang disertakan melalui elemen HTML LINK, dan elemen STYLE inline.

```java
public IStyleSheetList StyleSheets { get; }
```

### Property Value

Daftar yang berisi semua lembar gaya yang secara eksplisit ditautkan atau disematkan dalam sebuah dokumen.
