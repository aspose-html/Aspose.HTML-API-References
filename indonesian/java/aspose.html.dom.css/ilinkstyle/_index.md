## ILinkStyle interface

Antarmuka LinkStyle menyediakan mekanisme untuk mengambil lembar gaya dari node yang bertanggung jawab menautkannya ke dalam dokumen. Sebuah instance dari antarmuka LinkStyle dapat diperoleh dengan menggunakan metode casting khusus binding pada sebuah instance dari node penaut (HTMLLinkElement,

HTMLStyleElement atau ProcessingInstruction dalam DOM Level 2).

Lihat juga [CSS Object Model (CSSOM) # ](https://www.w3.org/TR/cssom-1/#the-linkstyle-interface)[LinkStyle](https://www.w3.org/TR/cssom-1/#the-linkstyle-interface).
