## Rect class

Antarmuka Rect digunakan untuk merepresentasikan nilai rect apa pun. Antarmuka ini mencerminkan nilai-nilai dalam properti style yang mendasari. Oleh karena itu, modifikasi yang dilakukan pada objek [`CSSPrimitiveValue`](../cssprimitivevalue/) akan memodifikasi properti style.

public class Rect : DOMObject
