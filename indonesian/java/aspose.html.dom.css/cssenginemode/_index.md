## CSSEngineMode enumeration

Menentukan mode CSSEngine. Nilai-nilai memiliki arti berikut:

default - Parser CSS akan bekerja sesuai rekomendasi w3c dan tidak mendukung ekstensi khusus. not-strict - Semua properti yang tidak terdokumentasi akan diparsing dan dapat diakses melalui.

```java
[Flags]
public enum CSSEngineMode
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Default | `0` | Parser CSS akan bekerja sesuai rekomendasi w3c dan tidak mendukung ekstensi khusus. |
| NotStrict | `1` | Parser CSS akan bekerja dalam mode tidak ketat. Semua properti yang tidak terdokumentasi akan diparsing dan dapat diakses melalui. |
