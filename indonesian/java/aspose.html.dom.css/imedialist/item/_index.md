## IMediaList indexer

Metode item(index) harus mengembalikan serialisasi dari kueri media dalam koleksi kueri media yang diberikan oleh indeks, atau null, jika indeks lebih besar atau sama dengan jumlah kueri media dalam koleksi kueri media.

```java
public String this[int index] { get; }
```

### Nilai Kembali

Mengembalikan String yang mewakili kueri media sebagai teks, berdasarkan nilai indeks kueri media di dalam [`MediaList`](../).

### Property Value

Bilangan bulat yang merupakan indeks item dalam koleksi yang akan dikembalikan.
