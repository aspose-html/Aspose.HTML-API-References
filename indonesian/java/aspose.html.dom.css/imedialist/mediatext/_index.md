## IMediaList.MediaText property

Sebuah Stringifier yang mengembalikan DOMString yang mewakili MediaList sebagai teks, dan juga memungkinkan Anda mengatur MediaList baru.

```java
public String MediaText { get; }
```

### Property Value

Representasi tekstual yang dapat diparse dari daftar media. Ini adalah daftar media yang dipisahkan koma.

### Pengecualian

| pengecualian | kondisi |
| --- | --- |
| DOMException | SYNTAX_ERR: Dikeluarkan jika nilai String yang ditentukan memiliki kesalahan sintaks dan tidak dapat diparse. NO_MODIFICATION_ALLOWED_ERR: Dikeluarkan jika daftar media ini bersifat hanya-baca. |
