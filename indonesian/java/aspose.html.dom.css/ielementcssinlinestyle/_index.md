## IElementCSSInlineStyle interface

Informasi gaya inline yang terlampir pada elemen diekspos melalui atribut style. Ini mewakili isi atribut STYLE untuk elemen HTML (atau elemen dalam skema atau DTD lain yang menggunakan atribut STYLE dengan cara yang sama). Diharapkan bahwa sebuah instance dari antarmuka ElementCSSInlineStyle dapat diperoleh dengan menggunakan metode casting spesifik binding pada sebuah instance dari antarmuka Element ketika elemen tersebut mendukung informasi gaya CSS inline.
