## IElementCSSInlineStyle.Style property

Atribut style harus mengembalikan objek blok deklarasi CSS yang flag terhitungnya tidak disetel, aturan CSS induknya null, dan node pemiliknya adalah objek konteks.

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

Blok deklarasi CSS yang terkait untuk node atau null jika tidak ada blok deklarasi CSS yang terkait.
