## CSSValueList indexer

Metode item() dari antarmuka CSSValueList digunakan untuk mengambil CSSValue berdasarkan indeks ordinal.

Urutan dalam koleksi ini mewakili urutan nilai dalam properti gaya CSS. Jika indeks lebih besar atau sama dengan jumlah nilai dalam daftar, metode ini mengembalikan null.

```java
public CSSValue this[int index] { get; }
```

### Nilai Kembali

Objek CSSValue pada posisi indeks dalam CSSValueList, atau null jika indeks tersebut tidak valid.

### Property Value

Sebuah unsigned long yang mewakili indeks nilai CSS dalam koleksi.
