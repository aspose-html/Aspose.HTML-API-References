### Property Value

Nilai komponen merah dari Color ini.

## Catatan

Warna setiap piksel direpresentasikan sebagai angka 32-bit: 8 bit masing-masing untuk alfa, merah, hijau, dan biru (ARGB). Komponen alfa menentukan transparansi warna: 0 sepenuhnya transparan, dan 255 sepenuhnya opak. Demikian pula, nilai A 255 mewakili warna opak. Nilai A dari 1 hingga 254 mewakili warna semi-transparan. Warna menjadi lebih opak seiring A mendekati 255.
