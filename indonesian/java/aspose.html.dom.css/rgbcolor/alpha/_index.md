## RGBColor.Alpha property

Mengambil nilai komponen alpha dari struktur Color ini.

```java
public CSSPrimitiveValue Alpha { get; }
```

### Property Value

Nilai komponen alpha dari Color ini.

## Catatan

Warna setiap piksel direpresentasikan sebagai angka 32-bit: 8 bit masing-masing untuk alpha, merah, hijau, dan biru (ARGB). Komponen alpha menentukan tingkat transparansi warna: 0 berarti sepenuhnya transparan, dan 255 berarti sepenuhnya opak. Demikian pula, nilai A 255 mewakili warna opak. Nilai A antara 1 hingga 254 mewakili warna semi-transparan. Warna menjadi lebih opak seiring A mendekati 255.
