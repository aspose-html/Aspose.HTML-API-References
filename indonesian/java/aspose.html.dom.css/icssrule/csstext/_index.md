## ICSSRule.CSSText property

Properti cssText dari antarmuka [`CSSRule`](../) mengembalikan teks sebenarnya dari sebuah aturan gaya [`CSSStyleSheet`](../../icssstylesheet/).

Catatan: Jangan bingungkan properti ini dengan CSSStyleDeclaration.cssText gaya-elemen.

```java
public String CSSText { get; set; }
```

### Property Value

Mengembalikan serialisasi dari aturan CSS. Saat mengatur atribut cssText tidak melakukan apa-apa.
