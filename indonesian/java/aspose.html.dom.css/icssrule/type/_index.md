## ICSSRule.Type property

Tipe aturan, sebagaimana didefinisikan dalam [CSSOM # dom-cssrule-type](https://drafts.csswg.org/cssom/#dom-cssrule-type). Diharapkan metode casting khusus binding dapat digunakan untuk menurunkan tipe dari sebuah instance antarmuka CSSRule ke antarmuka turunan spesifik yang diimplikasikan oleh tipe tersebut.

```java
public short Type { get; }
```

### Property Value

Bilangan bulat non-negatif yang terkait dengan tipe aturan tertentu. Item ini diinisialisasi saat aturan dibuat dan tidak dapat diubah.
