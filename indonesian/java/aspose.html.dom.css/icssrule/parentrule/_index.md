## ICSSRule.ParentRule property

Jika aturan ini berada di dalam aturan lain (misalnya aturan gaya di dalam blok @media), ini adalah aturan yang memuatnya. Jika aturan ini tidak berada di dalam aturan lain, maka mengembalikan null.

```java
public ICSSRule ParentRule { get; }
```

### Property Value

Sebuah [`CSSRule`](../) yang merupakan tipe dari aturan yang memuatnya. Jika aturan saat ini berada dalam kueri media, ini akan mengembalikan [`CSSMediaRule`](../../icssmediarule/). Jika tidak, mengembalikan null.
