## IStyleSheetList indexer

Metode item(index) harus mengembalikan [`CSS style sheet`](../../icssstylesheet/) pada indeks ke‑index dalam koleksi. Jika tidak ada objek pada indeks tersebut dalam koleksi, maka metode harus mengembalikan null.

```java
public ICSSStyleSheet this[int index] { get; }
```

### Nilai Kembali

Objek [`CSSStyleSheet`](../../icssstylesheet/), atau null jika tidak ada untuk indeks ini.

### Property Value

Sebuah bilangan bulat yang merupakan indeks item dalam koleksi yang akan dikembalikan.
