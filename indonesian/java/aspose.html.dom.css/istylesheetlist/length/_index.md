## IStyleSheetList.Length property

Atribut length harus mengembalikan jumlah lembar gaya CSS yang diwakili oleh koleksi. Rentang indeks lembar gaya anak yang valid adalah 0 hingga length-1 termasuk.

```java
public int Length { get; }
```

### Property Value

Bilangan bulat yang menunjukkan jumlah item dalam koleksi.
