## ICSSImportRule.StyleSheet property

Lembar gaya yang dirujuk oleh aturan ini, jika telah dimuat. Nilai atribut ini null jika lembar gaya belum dimuat atau tidak akan dimuat (misalnya jika lembar gaya untuk tipe media yang tidak didukung oleh agen pengguna).

```java
public ICSSStyleSheet StyleSheet { get; }
```

### Property Value

Mengembalikan CSS Stylesheet yang ditentukan oleh aturan @import. Ini akan berupa objek [`CSSStyleSheet`](../../icssstylesheet/).
