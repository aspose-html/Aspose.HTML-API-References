## ICSSImportRule interface

Antarmuka CSSImportRule mewakili aturan @import dalam lembar gaya CSS. Aturan @import digunakan untuk mengimpor aturan gaya dari lembar gaya lain.

```java
public interface ICSSImportRule : ICSSRule
```

## Properti

| Nama | Deskripsi |
| --- | --- |
| [getHref](../../com.aspose.html.dom.css/icssimportrule/href/) Properti href yang hanya-baca dari antarmuka CSSImportRule mengembalikan URL yang ditentukan oleh aturan @import. |
| [getMedia](../../com.aspose.html.dom.css/icssimportrule/media/) Properti media yang hanya-baca dari antarmuka CSSImportRule mengembalikan objek MediaList, yang berisi nilai atribut media dari lembar gaya yang terkait. |
| [getStyleSheet](../../com.aspose.html.dom.css/icssimportrule/stylesheet/) Lembar gaya yang dirujuk oleh aturan ini, jika telah dimuat. Nilai atribut ini adalah null jika lembar gaya belum dimuat atau tidak akan dimuat (misalnya jika lembar gaya untuk tipe media yang tidak didukung oleh agen pengguna). |
