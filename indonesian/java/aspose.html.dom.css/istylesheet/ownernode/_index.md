## IStyleSheet.OwnerNode property

Node yang mengaitkan lembar gaya ini dengan dokumen. Untuk HTML, ini dapat berupa elemen LINK atau STYLE yang bersesuaian. Untuk XML, dapat berupa instruksi pemrosesan penghubung. Untuk lembar gaya yang disertakan oleh lembar gaya lain, nilai atribut ini adalah null.

```java
public Node OwnerNode { get; }
```

### Property Value

Atribut ownerNode harus mengembalikan node pemilik.

## Catatan

Untuk lembar gaya yang disertakan oleh lembar gaya lain, seperti dengan @import, nilai properti ini adalah null.
