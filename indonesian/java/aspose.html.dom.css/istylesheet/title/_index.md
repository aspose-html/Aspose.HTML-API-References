## IStyleSheet.Title property

Properti title dari antarmuka [`StyleSheet`](../) mengembalikan judul saran dari lembar gaya saat ini.

Title biasanya ditentukan dalam [`ownerNode`](../ownernode/).

```java
public String Title { get; }
```

### Property Value

Atribut parentStyleSheet harus mengembalikan [`CSS style sheet`](../../icssstylesheet/) induk.
