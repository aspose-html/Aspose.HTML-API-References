## IStyleSheet.Media property

Properti media dari antarmuka [`StyleSheet`](../) menentukan media tujuan yang dimaksud untuk informasi gaya. Ini adalah objek [`MediaList`](../../imedialist/) yang bersifat read-only dan berbentuk array, dan dapat dihapus dengan deleteMedium() serta ditambahkan dengan appendMedium().

```java
public IMediaList Media { get; }
```

### Property Value

Atribut media harus mengembalikan objek [`MediaList`](../../imedialist/) yang terkait dengan lembar gaya CSS.

## Catatan

[CSSOM](https://drafts.csswg.org/cssom/) defines APIs (including generic parsing and serialization rules) for Media Queries, Selectors, and of course CSS itself.
