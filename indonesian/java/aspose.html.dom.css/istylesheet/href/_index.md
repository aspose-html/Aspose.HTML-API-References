## IStyleSheet.Href property

Properti href dari antarmuka [`StyleSheet`](../) mengembalikan lokasi lembar gaya.

```java
public String Href { get; }
```

### Property Value

uri adalah String yang berisi URI lembar gaya.

## Catatan

Jika lembar gaya adalah lembar gaya yang ditautkan, nilai atributnya adalah lokasinya. Untuk lembar gaya inline, nilai atribut ini adalah NULL.

Properti ini bersifat read-only di Firefox, Opera, Google Chrome, dan Safari, dan bersifat read/write di Internet Explorer.
