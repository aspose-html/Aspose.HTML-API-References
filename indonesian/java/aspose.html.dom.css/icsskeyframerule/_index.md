## ICSSKeyframeRule interface

Antarmuka `CSSKeyframeRule` menggambarkan sebuah objek yang mewakili sekumpulan gaya untuk sebuah keyframe tertentu. Ini sesuai dengan isi satu keyframe dari at-rule @keyframes.

```java
public interface ICSSKeyframeRule : ICSSRule
```
