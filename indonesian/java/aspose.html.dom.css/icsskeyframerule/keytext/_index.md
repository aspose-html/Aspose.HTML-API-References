## ICSSKeyframeRule.KeyText property

Properti keyText dari antarmuka CSSKeyframeRule mewakili pemilih keyframe sebagai daftar nilai persentase yang dipisahkan koma. Kata kunci from dan to masing‑masing dipetakan ke 0% dan 100%.

```java
public String KeyText { get; }
```

### Property Value

Mengembalikan pemilih keyframe sebagai daftar nilai persentase yang dipisahkan koma.
