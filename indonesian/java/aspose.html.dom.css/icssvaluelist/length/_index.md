## ICSSValueList.Length property

Properti hanya-baca length dari antarmuka CSSValueList mewakili jumlah CSSValue dalam daftar. Rentang nilai indeks yang valid adalah 0 hingga length-1 termasuk.

```java
public int Length { get; }
```

### Property Value

Unsigned long yang mewakili jumlah CSSValue.

## Catatan

Fitur ini awalnya didefinisikan dalam spesifikasi [DOM Style Level 2](https://www.w3.org/TR/DOM-Level-2-Style), tetapi telah dihapus dari semua upaya standardisasi sejak saat itu.

Fitur ini telah digantikan oleh [CSS Typed Object Model API](https://developer.mozilla.org/en-US/docs/Web/API/CSS_Typed_OM_API) yang modern namun tidak kompatibel, yang kini berada di jalur standar.
