## ICSSValueList indexer

Metode ini digunakan untuk mengambil CSSValue berdasarkan indeks ordinal. Urutan dalam koleksi ini mewakili urutan nilai dalam properti gaya CSS. Jika indeks lebih besar atau sama dengan jumlah nilai dalam daftar, ini mengembalikan null.

Lihat juga [CSSOM](https://www.w3.org/TR/2000/REC-DOM-Level-2-Style-20001113/css.html#CSS-CSSValueList)[#CSSValueList](https://www.w3.org/TR/2000/REC-DOM-Level-2-Style-20001113/css.html#CSS-CSSValueList).

```java
public CSSValue this[int index] { get; }
```

### Nilai Kembali

[`CSSValue`](../../cssvalue/) pada posisi indeks dalam [`CSSValueList`](../../cssvaluelist/), atau null jika itu bukan indeks yang valid.

### Property Value

Indeks ke dalam koleksi.

## Catatan

Fitur ini awalnya didefinisikan dalam spesifikasi [DOM Style Level 2](https://www.w3.org/TR/DOM-Level-2-Style), tetapi telah dihapus dari semua upaya standardisasi sejak saat itu.

Fitur ini telah digantikan oleh [CSS Typed Object Model API](https://developer.mozilla.org/en-US/docs/Web/API/CSS_Typed_OM_API) yang modern namun tidak kompatibel, yang kini berada di jalur standar.
