## Element.TextContent property

Atribut ini mengembalikan konten teks dari node ini dan turunannya. Ketika diatur menjadi null, pengaturannya tidak berpengaruh. Saat diatur, semua anak yang mungkin dimiliki node ini dihapus dan, jika String baru tidak kosong atau null, digantikan oleh satu node Text yang berisi String yang ditetapkan pada atribut ini.

```java
public String TextContent { get; set; }
```

### Property Value

Konten teks.
