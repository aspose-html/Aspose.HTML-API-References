## ToggleAttribute(String) {#toggleattribute}

Jika force tidak diberikan, "toggles" qualifiedName, menghapusnya jika ada dan menambahkannya jika tidak ada. Jika force bernilai true, menambahkan qualifiedName. Jika force bernilai false, menghapus qualifiedName.

```java
public bool ToggleAttribute(String qualifiedName)
```

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| qualifiedName | String | Atribut QualifiedName. |

### Nilai Kembali

Mengembalikan true jika qualifiedName sekarang ada; jika tidak, false.
