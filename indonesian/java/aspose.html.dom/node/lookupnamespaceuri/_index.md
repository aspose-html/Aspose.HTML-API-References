## Node.LookupNamespaceURI method

Metode lookupNamespaceURI() dari antarmuka Node mengambil sebuah prefiks sebagai parameter dan mengembalikan URI paket yang terkait dengannya pada node yang diberikan jika ditemukan (dan null jika tidak).

```java
public String LookupNamespaceURI(String prefix)
```

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| prefiks | String | Prefiks yang akan dicari. |

### Nilai Kembali

Sebuah String yang berisi URI paket yang sesuai dengan prefix. Jika prefix tidak ditemukan, mengembalikan null. Jika prefix yang diminta null, mengembalikan URI paket default.
