## Node.ParentElement property

Properti read-only parentElement dari antarmuka [`Node`](../) mengembalikan parent [`Element`](../../element/) dari node DOM, atau null jika node tidak memiliki parent, atau parent-nya bukan Element DOM.

```java
public Element ParentElement { get; }
```

### Property Value

Sebuah [`Element`](../../element/) yang merupakan elemen induk dari node saat ini, atau null jika tidak ada.
