## Node.NextSibling property

Properti read-only nextSibling dari antarmuka [`Node`](../) mengembalikan node yang segera mengikuti node yang ditentukan dalam [`childNodes`](../childnodes/) milik orang tuanya, atau mengembalikan null jika node yang ditentukan adalah anak terakhir dalam elemen induk.

```java
public Node NextSibling { get; }
```

### Property Value

Sebuah [`Node`](../) yang mewakili saudara berikutnya dari node saat ini, atau null jika tidak ada.
