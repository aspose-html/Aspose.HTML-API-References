## Node.Prefix property

Properti read-only prefix mengembalikan awalan paket dari elemen yang ditentukan, atau null jika tidak ada awalan yang ditentukan.

```java
public String Prefix { get; set; }
```

### Property Value

Properti ini mengembalikan awalan paket yang terkait.
