## Node.ReplaceChild method

Mengganti node anak oldChild dengan newChild dalam daftar anak, dan mengembalikan node oldChild. Jika newChild adalah objek [`DocumentFragment`](../../documentfragment/), oldChild digantikan oleh semua anak [`DocumentFragment`](../../documentfragment/) yang dimasukkan dalam urutan yang sama. Jika newChild sudah berada di dalam pohon, ia pertama-tama dihapus.

```java
public Node ReplaceChild(Node node, Node child)
```

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| node | Node | Node baru untuk menggantikan oldChild. |
| anak | Node | Anak yang akan diganti. |

### Nilai Kembali

Node yang diganti. Ini adalah node yang sama dengan oldChild.
