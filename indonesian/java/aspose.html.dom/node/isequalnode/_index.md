## Node.IsEqualNode method

Metode isEqualNode() dari antarmuka [`Node`](../) menguji apakah dua node sama. Dua node dianggap sama ketika mereka memiliki tipe yang sama, karakteristik penentu (untuk elemen, ini meliputi ID, jumlah anak, dan sebagainya), atributnya cocok, dan seterusnya. Set data spesifik yang harus cocok bervariasi tergantung pada tipe node.

```java
public bool IsEqualNode(Node otherNode)
```

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| otherNode | Node | [`Node`](../) untuk dibandingkan kesetaraannya. |

### Nilai Kembali

Nilai boolean yang bernilai true jika kedua node sama, atau false jika tidak. Jika otherNode null, isEqualNode() selalu mengembalikan false.
