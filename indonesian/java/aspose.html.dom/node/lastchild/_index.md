## Node.LastChild property

Properti read-only lastChild dari antarmuka [`Node`](../) mengembalikan anak terakhir dari node. Jika induknya adalah elemen, maka anak biasanya berupa node elemen, node teks, atau node komentar. Mengembalikan null jika tidak ada elemen anak.

```java
public Node LastChild { get; }
```

### Property Value

Sebuah [`Node`](../) yang merupakan anak terakhir dari node, atau null jika tidak ada elemen anak.
