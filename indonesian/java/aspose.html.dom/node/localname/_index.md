## Node.LocalName property

Mengembalikan bagian lokal dari nama lengkap node ini. Untuk node dengan tipe apa pun selain [`ELEMENT_NODE`](../element_node/) dan [`ATTRIBUTE_NODE`](../attribute_node/) serta node yang dibuat dengan metode DOM Level 1, seperti [`Document.createElement()`](../../document/createelement/), nilai ini selalu null.

```java
public String LocalName { get; }
```

### Property Value

Sebuah String yang mewakili bagian lokal dari nama lengkap elemen.
