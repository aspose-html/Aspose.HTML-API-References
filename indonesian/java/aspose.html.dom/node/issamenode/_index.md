## Node.IsSameNode method

Metode isSameNode() dari antarmuka Node adalah alias warisan untuk operator kesetaraan ketat ===. Artinya, ia menguji apakah dua node sama (dengan kata lain, apakah mereka merujuk ke objek yang sama).

Catatan: Tidak perlu menggunakan isSameNode(); gunakan operator kesetaraan ketat === sebagai gantinya.

```java
public bool IsSameNode(Node otherNode)
```

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| otherNode | Node | Node yang akan diuji. |

### Nilai Kembali

Nilai boolean yang true jika kedua node secara ketat sama, false jika tidak.
