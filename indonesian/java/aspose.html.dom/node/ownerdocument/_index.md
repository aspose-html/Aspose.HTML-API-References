## Node.OwnerDocument property

The read-only ownerDocument property of the Node interface returns the top-level document object of the node.

```java
public Document OwnerDocument { get; }
```

### Property Value

Sebuah [`Document`](../../document/) yang merupakan objek tingkat atas di mana semua node anak dibuat.

Jika properti ini digunakan pada node yang sendiri merupakan dokumen, nilainya adalah null.
