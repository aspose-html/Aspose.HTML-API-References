## Node.NodeValue property

Properti nodeValue dari antarmuka [`Node `](../) mengembalikan atau mengatur nilai node saat ini.

```java
public String NodeValue { get; set; }
```

### Property Value

Sebuah String yang berisi nilai node saat ini, jika ada. Untuk dokumen itu sendiri, nodeValue mengembalikan null. Untuk node teks, komentar, dan CDATA, nodeValue mengembalikan isi node. Untuk node atribut, nilai atribut dikembalikan.
