## Node.ChildNodes property

Properti read-only childNodes dari antarmuka Node mengembalikan sebuah [`NodeList`](../../../com.aspose.html.collections/nodelist/) yang hidup berisi node anak dari elemen yang diberikan, di mana node anak pertama diberikan indeks 0. Node anak mencakup elemen, teks, dan komentar.

Catatan: [`NodeList`](../../../com.aspose.html.collections/nodelist/) yang hidup berarti isinya berubah setiap kali anak baru ditambahkan atau dihapus.

```java
public NodeList ChildNodes { get; }
```

### Property Value

Sebuah [`NodeList`](../../../com.aspose.html.collections/nodelist/) yang hidup berisi anak-anak node.

Catatan: Beberapa pemanggilan childNodes mengembalikan [`NodeList`](../../../com.aspose.html.collections/nodelist/) yang sama.
