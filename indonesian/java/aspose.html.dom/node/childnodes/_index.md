## Node.ChildNodes property

Properti read-only childNodes dari antarmuka Node mengembalikan [`NodeList`](../../../com.aspose.html.collections/nodelist/) live berisi node anak dari elemen yang diberikan dimana node anak pertama diberi indeks 0. Node anak mencakup elemen, teks, dan komentar.

Catatan: [`NodeList`](../../../com.aspose.html.collections/nodelist/) yang bersifat live berarti isinya berubah setiap kali anak baru ditambahkan atau dihapus.

```java
public NodeList ChildNodes { get; }
```

### Property Value

Sebuah [`NodeList`](../../../com.aspose.html.collections/nodelist/) live yang berisi anak-anak node.

Catatan: Beberapa pemanggilan childNodes mengembalikan [`NodeList`](../../../com.aspose.html.collections/nodelist/) yang sama.
