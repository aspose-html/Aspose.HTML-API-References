## Node.FirstChild property

Properti read-only firstChild dari antarmuka [`Node`](../) mengembalikan anak pertama node dalam pohon, atau null jika node tidak memiliki anak.

Jika node adalah Document, properti ini mengembalikan node pertama dalam daftar anak langsungnya.

```java
public Node FirstChild { get; }
```

### Property Value

Sebuah [`Node`](../), atau null jika tidak ada.
