## Node.BaseURI property

Properti read-only baseURI dari antarmuka Node mengembalikan URL dasar absolut dari dokumen yang berisi node.

URL dasar digunakan untuk menyelesaikan URL relatif ketika peramban perlu memperoleh URL absolut, misalnya saat memproses atribut src elemen img HTML atau atribut xlink:href atau href dalam SVG.

```java
public String BaseURI { get; }
```

### Property Value

Getter baseURI mengembalikan URL dasar dokumen node ini, dalam bentuk ter-serialisasi.
