## Document.XmlStandalone property

Sebuah atribut yang menentukan, sebagai bagian dari deklarasi XML, apakah dokumen ini berdiri sendiri. Nilai ini false bila tidak ditentukan.

```java
public bool XmlStandalone { get; set; }
```

### Property Value

`true` jika XML berdiri sendiri; jika tidak, `false`.
