## Document.XmlVersion property

Sebuah atribut yang menentukan, sebagai bagian dari deklarasi XML, nomor versi dokumen ini. Jika tidak ada deklarasi dan dokumen ini mendukung fitur \"XML\", nilainya adalah \"1.0\". Jika dokumen ini tidak mendukung fitur \"XML\", nilainya selalu null.

```java
public String XmlVersion { get; set; }
```

### Property Value

Versi XML.
