## Document.StrictErrorChecking property

Sebuah atribut yang menentukan apakah pemeriksaan kesalahan ditegakkan atau tidak. Ketika disetel ke false, implementasi bebas untuk tidak menguji setiap kemungkinan kasus kesalahan yang biasanya didefinisikan pada operasi DOM, dan tidak memunculkan DOMException pada operasi DOM atau melaporkan kesalahan saat menggunakan Document.normalizeDocument(). Jika terjadi kesalahan, perilakunya tidak terdefinisi. Atribut ini bernilai true secara default.

```java
public bool StrictErrorChecking { get; set; }
```

### Property Value

`true` jika pemeriksaan kesalahan ketat; jika tidak, `false`.
