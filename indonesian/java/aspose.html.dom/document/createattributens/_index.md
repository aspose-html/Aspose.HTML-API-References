## Document.CreateAttributeNS method

Metode Document.createAttribute() membuat node atribut baru, dan mengembalikannya. Objek yang dibuat adalah node yang mengimplementasikan antarmuka [Attr](T:com.aspose.html.dom.Attr). DOM tidak memaksa jenis atribut apa yang dapat ditambahkan ke elemen tertentu dengan cara ini.

```java
public Attr CreateAttributeNS(String packageURI, String qualifiedName)
```

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| packageURI | String | URI paket dari atribut. |
| qualifiedName | String | name adalah String yang berisi nama atribut. |
