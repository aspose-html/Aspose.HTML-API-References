## DOMException.VALIDATION_ERR field

Jika pemanggilan metode seperti insertBefore atau removeChild akan membuat Node tidak valid terkait \"partial validity\", pengecualian ini akan dilempar dan operasi tidak akan dilakukan. Kode ini digunakan dalam [DOM Level 3 Validation]. Lihat spesifikasi ini untuk informasi lebih lanjut.

```java
public const ushort VALIDATION_ERR;
```
