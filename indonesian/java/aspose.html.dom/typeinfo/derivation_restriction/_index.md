## TypeInfo.DERIVATION_RESTRICTION field

Jika skema dokumen adalah XML Schema [XML Schema Part 1], konstanta ini mewakili derivasi dengan restriksi jika tipe kompleks terlibat, atau restriksi jika tipe sederhana terlibat.

```java
public const ulong DERIVATION_RESTRICTION;
```
