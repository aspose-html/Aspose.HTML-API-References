## Attr.LocalName property

Mengembalikan bagian lokal dari nama yang memenuhi syarat untuk node ini. Untuk node dengan tipe apa pun selain ELEMENT_NODE dan ATTRIBUTE_NODE serta node yang dibuat dengan metode DOM Level 1, seperti Document.createElement(), nilai ini selalu null.

```java
public String LocalName { get; }
```

### Property Value

Nama lokal.
