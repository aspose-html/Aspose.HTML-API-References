## SVGGraphicsElement.GetScreenCTM method

Mengembalikan matriks transformasi dari unit pengguna saat ini (yaitu, setelah penerapan atribut ‘transform’, jika ada) ke pengenalan \"pixel\" oleh agen pengguna induk. Untuk perangkat tampilan, idealnya ini mewakili pixel layar fisik. Untuk perangkat atau lingkungan lain dimana ukuran pixel fisik tidak diketahui, maka algoritma serupa definisi \"pixel\" CSS2 dapat digunakan sebagai gantinya. Perhatikan bahwa null dikembalikan jika elemen ini tidak terhubung ke pohon dokumen. Metode ini seharusnya lebih tepat dinamai getClientCTM, tetapi nama getScreenCTM dipertahankan demi alasan historis.

```java
public SVGMatrix GetScreenCTM()
```
