## SVGGraphicsElement.GetBBox method

Mengembalikan kotak pembatas ketat dalam ruang pengguna saat ini (yaitu, setelah penerapan atribut ‘transform’, jika ada) pada geometri semua elemen grafik yang terkandung, tidak termasuk goresan, pemotongan, masking, dan efek filter). Perhatikan bahwa getBBox harus mengembalikan kotak pembatas aktual pada saat metode dipanggil, bahkan jika elemen belum dirender.

```java
public SVGRect GetBBox()
```
