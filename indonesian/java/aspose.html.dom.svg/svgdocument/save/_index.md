## Save(Url) {#save_3}

Menyimpan dokumen ke file lokal yang ditentukan oleh `url`. Semua sumber daya yang digunakan dalam dokumen ini akan disimpan ke folder terdekat, yang namanya akan dibangun sebagai: output_file_name + "_files".

```java
public void Save(Url url)
```

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| url | Url | URL lokal ke file output. |

| --- | --- |
| ArgumentException | Dilempar jika `url` yang ditentukan bukan URL file lokal yang valid. |
