## SVGDocument class

`SVGDocument` adalah akar hierarki SVG dan menyimpan seluruh konten. Selain menyediakan akses ke hierarki, ia juga menyediakan beberapa metode kemudahan untuk mengakses sekumpulan informasi tertentu dari dokumen. Ketika elemen ‘svg’ disisipkan secara inline sebagai komponen dokumen dari paket lain, seperti ketika elemen ‘svg’ disisipkan secara inline dalam dokumen XHTML [XHTML], maka objek SVGDocument tidak akan ada; sebagai gantinya, objek akar dalam hierarki objek dokumen akan menjadi objek Document dengan tipe berbeda, seperti objek HTMLDocument. Namun, objek SVGDocument memang akan ada ketika elemen akar hierarki dokumen XML adalah elemen ‘svg’, seperti saat melihat file SVG mandiri (mis., file dengan tipe MIME \"image/svg+xml\"). Dalam kasus ini, objek SVGDocument akan menjadi objek akar dari hierarki model objek dokumen.

```java
public class SVGDocument : Document, IDocumentCSS
```
