## SVGTextContentElement.GetNumberOfChars method

Mengembalikan total jumlah karakter yang tersedia untuk dirender dalam elemen saat ini, yang mencakup karakter yang direferensikan dari referensi ‘tref’, terlepas apakah mereka akan dirender atau tidak. Secara efektif, ini setara dengan panjang atribut Node::textContent dari DOM Level 3 Core ([DOM3], bagian 1.4), jika atribut tersebut juga memperluas elemen ‘tref’.

```java
public long GetNumberOfChars()
```

### Nilai Kembali

Jumlah total karakter.
