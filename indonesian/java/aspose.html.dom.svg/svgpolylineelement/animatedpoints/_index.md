## SVGPolylineElement.AnimatedPoints property

Menyediakan akses ke konten animasi saat ini dari atribut ‘points’. Jika atribut atau properti yang diberikan sedang dianimasikan, berisi nilai animasi saat ini dari atribut atau properti tersebut. Jika atribut atau properti yang diberikan tidak sedang dianimasikan, berisi nilai yang sama dengan points.

```java
public SVGPointList AnimatedPoints { get; }
```

### Property Value

Poin yang dianimasikan.
