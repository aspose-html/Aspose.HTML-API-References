## SVGMarkerElement.OrientAngle property

Menyatakan kesesuaian dengan atribut ‘orient’ pada elemen ‘marker’ yang diberikan. Jika markerUnits adalah SVG_MARKER_ORIENT_ANGLE, nilai sudut untuk atribut ‘orient’; jika tidak, akan diatur menjadi nol.

```java
public SVGAnimatedAngle OrientAngle { get; }
```

### Property Value

Atribut ‘orient’ dari elemen ‘marker’ yang diberikan.
