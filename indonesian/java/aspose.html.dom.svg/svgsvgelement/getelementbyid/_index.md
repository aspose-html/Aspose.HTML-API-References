## SVGSVGElement.GetElementById method

Mencari dalam fragmen dokumen SVG ini (yaitu, pencarian dibatasi pada subset pohon dokumen) sebuah Elemen yang id‑nya diberikan oleh elementId. Jika Elemen ditemukan, Elemen tersebut dikembalikan. Jika tidak ada elemen semacam itu, mengembalikan null. Perilaku tidak terdefinisi jika lebih dari satu elemen memiliki id ini.

```java
public Element GetElementById(String elementId)
```

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| elementId | String | Nilai id unik untuk sebuah elemen. |

Elemen yang cocok.
