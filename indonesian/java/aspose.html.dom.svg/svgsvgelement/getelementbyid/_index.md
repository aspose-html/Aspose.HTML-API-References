## SVGSVGElement.GetElementById method

Mencari dalam fragmen dokumen SVG ini (yaitu, pencarian dibatasi pada subset pohon dokumen) sebuah Element yang id‑nya diberikan oleh elementId. Jika Element ditemukan, Element tersebut dikembalikan. Jika tidak ada elemen seperti itu, mengembalikan null. Perilaku tidak didefinisikan jika lebih dari satu elemen memiliki id ini.

```java
public Element GetElementById(String elementId)
```

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| elementId | String | Nilai id unik untuk sebuah elemen. |
