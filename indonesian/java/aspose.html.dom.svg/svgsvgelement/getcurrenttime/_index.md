## SVGSVGElement.GetCurrentTime method

Mengembalikan waktu saat ini dalam detik relatif terhadap waktu mulai untuk fragmen dokumen SVG saat ini. Jika getCurrentTime dipanggil sebelum garis waktu dokumen dimulai (misalnya, oleh skrip yang berjalan dalam elemen ‘script’ sebelum peristiwa SVGLoad dokumen dikirim), maka 0 dikembalikan.

```java
public float GetCurrentTime()
```

### Nilai Kembali

Waktu saat ini dalam detik, atau 0 jika timeline dokumen belum dimulai.
