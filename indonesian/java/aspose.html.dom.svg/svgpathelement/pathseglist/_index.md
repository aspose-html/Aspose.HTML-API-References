## SVGPathElement.PathSegList property

Menyediakan akses ke konten dasar (yaitu statis) dari atribut ‘d’ dalam bentuk yang cocok satu-satu dengan sintaks SVG. Jadi, jika atribut ‘d’ memiliki "moveto absolut (M)" dan "arcto absolut (A)", maka pathSegList akan memiliki dua entri: SVG_PATHSEG_MOVETO_ABS dan SVG_PATHSEG_ARC_ABS.

```java
public SVGPathSegList PathSegList { get; set; }
```

### Property Value

Daftar segmen jalur.
