## SVGViewElement.ViewTarget property

Mengacu pada atribut ‘viewTarget’ pada elemen ‘view’ yang diberikan. Daftar nilai DOMString yang berisi nama-nama yang tercantum dalam atribut ‘viewTarget’. Setiap nilai DOMString dapat dikaitkan dengan elemen yang bersesuaian menggunakan pemanggilan metode getElementById().

```java
public SVGStringList ViewTarget { get; }
```

### Property Value

Atribut ‘viewTarget’ pada elemen ‘view’ yang diberikan.
