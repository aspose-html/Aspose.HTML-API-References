## PdfEncryptionInfo.OwnerPassword property

Mendapatkan atau mengatur kata sandi Owner.

```java
public String OwnerPassword { get; set; }
```

### Property Value

Kata sandi owner.

## Catatan

Membuka dokumen dengan kata sandi owner yang benar (dengan asumsi tidak sama dengan kata sandi pengguna) memungkinkan akses penuh (owner) ke dokumen. Akses tak terbatas ini mencakup kemampuan untuk mengubah kata sandi dokumen dan izin akses.
