## TemplateLoadOptions.NamesAreCaseSensitive property

Properti yang menentukan apakah nama templat dan elemen data akan dicocokkan terlepas dari huruf besar/kecil atau tidak. Jika true, pencocokan sensitif huruf; jika false, huruf akan diabaikan. Nilai default adalah true.

```java
public bool NamesAreCaseSensitive { get; set; }
```
