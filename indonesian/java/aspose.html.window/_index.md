Paket **com.aspose.html.window** terkait dengan objek window yang mewakili jendela yang berisi dokumen DOM. Paket ini mencakup kelas dan antarmuka yang berhubungan dengan alamat dokumen aktif dan riwayat penelusuran.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [Location](./location/) | Objek Location menyediakan representasi alamat dokumen aktif dari konteks penelusuran Document mereka, dan memungkinkan entri saat ini dari riwayat sesi konteks penelusuran diubah, dengan menambahkan atau mengganti entri dalam objek riwayat. |
| [MediaQueryList](./mediaquerylist/) | Objek MediaQueryList menyimpan informasi tentang kueri media yang diterapkan pada dokumen, dengan dukungan untuk pencocokan langsung maupun berbasis peristiwa terhadap status dokumen. Lihat spesifikasi CSSOM View Module: [https://www.w3.org/TR/cssom-view/#the-mediaquerylist-interface](https://www.w3.org/TR/cssom-view/#the-mediaquerylist-interface) |
## Antarmuka

| Antarmuka | Deskripsi |
| --- | --- |
| [IWindow](./iwindow/) | Objek window mewakili sebuah jendela yang berisi dokumen DOM. |
| [IWindowEventHandlers](./iwindoweventhandlers/) | Mewakili antarmuka yang harus diwarisi oleh objek window |
| [IWindowTimers](./iwindowtimers/) | Memungkinkan penulis menjadwalkan panggilan balik berbasis timer. |
