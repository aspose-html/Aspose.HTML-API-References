Paket ini menyediakan akses ke banyak objek (elemen) yang bertanggung jawab atas interaktivitas pengguna dalam formulir sebagai komponen halaman web.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [ButtonElement](./buttonelement/) | ButtonElement mewakili pembungkus yang terkait dengan HTMLButtonElement. |
| [DataListElement](./datalistelement/) | DataListElement mewakili pembungkus yang terkait dengan HTMLDataListElement. |
| [FormEditor](./formeditor/) | Kelas ini mewakili editor atas [`HTMLFormElement`](../com.aspose.html/htmlformelement/) yang menyediakan cara lebih mudah bagi pengembang .net untuk mengedit formulir HTML. |
| [FormElement](./formelement/) | Mewakili kelas dasar untuk elemen formulir. |
| [FormElement&lt;T&gt;](./formelement-1/) | [`FormElement`](../com.aspose.html.forms/formelement/) mewakili bidang generik. |
| [FormSubmitter](./formsubmitter/) | Kelas ini memungkinkan menyiapkan [`HTMLFormElement`](../com.aspose.html/htmlformelement/) yang ditentukan, mengumpulkan nilai dari elemen formulir, mengirimkannya ke server remote, dan menerima respons. |
| [InputElement](./inputelement/) | InputElement mewakili pembungkus yang terkait dengan HTMLInputElement. |
| [OptionCollection](./optioncollection/) | OptionElements mewakili pembungkus yang terkait dengan IHTMLOptionsCollection. |
| [OptionElement](./optionelement/) | OptionElement mewakili pembungkus yang terkait dengan HTMLOptionElement. |
| [SelectElement](./selectelement/) | SelectElement mewakili pembungkus yang terkait dengan HTMLSelectElement. |
| [SubmissionResult](./submissionresult/) | Kelas ini mewakili hasil pengiriman data formulir ke server. |
| [TextAreaElement](./textareaelement/) | TextAreaElement mewakili pembungkus yang terkait dengan HTMLTextAreaElement. |
