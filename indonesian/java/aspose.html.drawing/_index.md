Paket **com.aspose.html.drawing** berisi objek dan antarmuka untuk menentukan ukuran dan satuan serta objek atribut menggambar seperti kuas, warna, dan font.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [Angle](./angle/) | Tipe data sudut |
| [Color](./color/) | Kelas Color memungkinkan Anda menentukan warna sebagai nilai Merah-Hijau-Biru (RGB), nilai Hue-Saturation-Luminosity (HSL), nilai Hue-Saturation-Value (HSV), nilai Hue-Whiteness-Blackness (HWB), nilai lightness-A-B (LAB), nilai Luminance-Chroma-Hue (LCH), nilai Cyan-Magenta-Yellow-Key (CMYK), nilai Natural colors (NCOL), atau dengan nama warna. Saluran Alpha juga tersedia untuk menunjukkan transparansi. |
| [Dimension](./dimension/) | Menyediakan kelas dasar untuk dimensi. Istilah umum 'dimensi' mengacu pada angka dengan satuan yang terlampir, dan ditandai oleh [`UnitType`](../com.aspose.html.drawing/unittype/). |
| [Frequency](./frequency/) | Satuan 'frequency'. |
| [Length](./length/) | Mewakili satuan pengukuran panjang. |
| [LengthOrAuto](./lengthorauto/) | Mewakili wadah untuk menyimpan panjang atau satuan 'auto'. |
| [Margin](./margin/) | Mewakili margin halaman. |
| [Numeric](./numeric/) | Menyediakan kelas dasar untuk tipe numerik. |
| [Page](./page/) | Mewakili objek halaman yang digunakan untuk mengonfigurasi halaman output. Nilai default untuk ukuran halaman adalah A4 (210x297mm). |
| [Resolution](./resolution/) | Mewakili satuan resolusi. |
| [Size](./size/) | Menyimpan nilai yang menentukan Tinggi dan Lebar. |
| [Time](./time/) | Mewakili satuan waktu. |
| [Unit](./unit/) | Menyediakan kelas dasar untuk satuan pengukuran. |
| [UnitType](./unittype/) | Menentukan satuan pengukuran. |
## Antarmuka

| Antarmuka | Deskripsi |
| --- | --- |
| [IBrush](./ibrush/) | Mendeklarasikan metode untuk mendapatkan tipe kuas. |
| [IColorComponents](./icolorcomponents/) | Mendeklarasikan metode dan properti untuk memproses komponen warna. |
| [IDrawingFactory](./idrawingfactory/) | Mewakili pabrik untuk membuat objek terkait gambar. |
| [IGradientBrush](./igradientbrush/) | Mendeklarasikan metode untuk mendapatkan properti umum kuas gradien. |
| [IInterpolationColor](./iinterpolationcolor/) | Menyatakan metode untuk mendapatkan warna interpolasi. |
| [ILinearGradientBrush](./ilineargradientbrush/) | Mendefinisikan antarmuka kuas dengan gradien linier. |
| [IMatrix](./imatrix/) | Mewakili matriks yang digunakan untuk transformasi. |
| [ISolidBrush](./isolidbrush/) | Mendefinisikan antarmuka kuas dengan satu warna. |
| [ITextureBrush](./itexturebrush/) | Mendefinisikan antarmuka kuas yang menggunakan gambar untuk mengisi bagian dalam sebuah bentuk. |
| [ITransformableBrush](./itransformablebrush/) | Menyatakan metode untuk mendapatkan matriks transformasi dan mode pembungkus. |
| [ITrueTypeFont](./itruetypefont/) | Menyatakan metode untuk bekerja dengan font TrueType. |
