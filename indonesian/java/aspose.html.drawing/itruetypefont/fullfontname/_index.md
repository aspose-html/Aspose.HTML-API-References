## ITrueTypeFont.FullFontName property

Ini harus merupakan kombinasi dari "FamilyName" dan "SubFamilyName". Pengecualian: jika font adalah "Regular" seperti yang ditunjukkan dalam "SubFamilyName", maka gunakan hanya nama keluarga yang terdapat dalam "FamilyName". Pengecualian untuk definisi nama font lengkap di atas adalah untuk string platform Microsoft untuk font CFF OpenType: dalam kasus ini, string nama font lengkap harus identik dengan FontName PostScript dalam CFF Name INDEX.

```java
public String FullFontName { get; }
```
