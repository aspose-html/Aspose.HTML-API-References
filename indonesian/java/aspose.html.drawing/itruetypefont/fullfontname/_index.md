## ITrueTypeFont.FullFontName property

Ini harus merupakan kombinasi dari "FamilyName" dan "SubFamilyName". Pengecualian: jika font adalah "Regular" seperti yang ditunjukkan dalam "SubFamilyName", maka gunakan hanya nama keluarga yang terdapat dalam "FamilyName". Pengecualian lain untuk definisi Full font name di atas adalah untuk String platform Microsoft untuk font CFF OpenType: dalam kasus ini, String Full font name harus identik dengan PostScript FontName di CFF Name INDEX.

```java
public String FullFontName { get; }
```
