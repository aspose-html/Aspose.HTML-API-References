## ITrueTypeFont.SubFamilyName property

Nama Subfamily Font membedakan font dalam grup dengan nama Font Family yang sama. Ini diasumsikan untuk mengidentifikasi gaya (italic, oblique) dan berat (light, bold, black, dll). Sebuah font tanpa perbedaan khusus dalam berat atau gaya (misalnya berat medium, tidak italic, dan bit fsSelection 6 disetel) harus memiliki string "Regular" disimpan pada posisi ini.

```java
public String SubFamilyName { get; }
```
