## IXPathResult.InvalidIteratorState property

Menandakan bahwa iterator telah menjadi tidak valid. Benar jika `resultType` adalah tipe `UnorderedNodeIterator` atau `OrderedNodeIterator` dan dokumen telah dimodifikasi sejak hasil ini dikembalikan.

```java
public bool InvalidIteratorState { get; }
```
