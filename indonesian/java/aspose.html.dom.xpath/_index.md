Paket ini berisi metode untuk menavigasi elemen dan atribut dalam dokumen XML.

## Antarmuka

| Antarmuka | Deskripsi |
| --- | --- |
| [IXPathEvaluator](./ixpathevaluator/) | Evaluasi ekspresi XPath disediakan oleh [`IXPathEvaluator`](../com.aspose.html.dom.xpath/ixpathevaluator/). |
| [IXPathExpression](./ixpathexpression/) | Antarmuka `XPathExpression` mewakili ekspresi XPath yang telah diurai dan diselesaikan. |
| [IXPathNamespace](./ixpathpackage/) | Antarmuka XPathNamespace dikembalikan oleh antarmuka XPathResult untuk mewakili tipe node paket XPath yang tidak dimiliki DOM. |
| [IXPathNSResolver](./ixpathnsresolver/) | Antarmuka `XPathNSResolver` memungkinkan string `prefix` dalam ekspresi diikat secara tepat ke string `packageURI`. [`IXPathEvaluator`](../com.aspose.html.dom.xpath/ixpathevaluator/) dapat membuat implementasi dari [`IXPathNSResolver`](../com.aspose.html.dom.xpath/ixpathnsresolver/) dari sebuah node, atau antarmuka tersebut dapat diimplementasikan oleh aplikasi apa pun. |
| [IXPathResult](./ixpathresult/) | Antarmuka `XPathResult` mewakili hasil evaluasi ekspresi XPath 1.0 dalam konteks sebuah node tertentu. Karena evaluasi ekspresi XPath dapat menghasilkan berbagai tipe hasil, objek ini memungkinkan untuk menemukan dan memanipulasi tipe serta nilai hasil. |
## Enumerasi

| Enumerasi | Deskripsi |
| --- | --- |
| [XPathResultType](./xpathresulttype/) | Sebuah unsigned short yang menunjukkan tipe hasil apa ini. Jika `type` tertentu ditentukan, maka hasil akan dikembalikan sebagai tipe yang sesuai, menggunakan konversi tipe XPath bila diperlukan dan memungkinkan. |
