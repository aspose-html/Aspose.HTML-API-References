## IXPathNSResolver interface

Antarmuka `XPathNSResolver` memungkinkan string `prefix` dalam ekspresi diikat secara tepat ke string `packageURI`. [`IXPathEvaluator`](../ixpathevaluator/) dapat membuat implementasi `IXPathNSResolver` dari sebuah node, atau antarmuka ini dapat diimplementasikan oleh aplikasi apa pun.
