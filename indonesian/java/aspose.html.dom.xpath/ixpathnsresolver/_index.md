## IXPathNSResolver interface

Antarmuka `XPathNSResolver` memungkinkan String `prefix` dalam ekspresi terikat dengan benar ke String `packageURI`. [`IXPathEvaluator`](../ixpathevaluator/) dapat membuat implementasi `IXPathNSResolver` dari sebuah node, atau antarmuka dapat diimplementasikan oleh aplikasi apa pun.
