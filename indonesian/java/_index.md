## Ruang Nama

| Ruang Nama | Deskripsi |
| --- | --- |
| [com.aspose.html](./aspose.html/) | Paket Aspose.Html berisi kelas dan metode untuk memanipulasi [`HTML documents`](aspose.html/htmldocument/), baik yang sederhana maupun kompleks secara langsung. Aspose.HTML for Java memungkinkan pengembang untuk menyisipkan, menghapus, mengganti node HTML, mengekstrak informasi gaya CSS, menavigasi melalui [`HTML document`](aspose.html/htmldocument/) baik dengan [`NodeIterator`](aspose.html.dom.traversal/inodeiterator/), [`TreeWalker`](aspose.html.dom.traversal/itreewalker/) yang disediakan oleh Spesifikasi Traversal, XPath, atau kueri pemilih CSS. Ia juga menawarkan skrip yang memungkinkan manipulasi DOM HTML melalui JavaScript. Selain HTML, API ini juga menyediakan kemampuan untuk memuat EPUB dan MHTML. API Aspose terkenal dengan fitur konversi format file antar, dan API ini juga menyediakan kemampuan untuk memuat file HTML dan merender outputnya ke format PDF, XPS, serta format gambar raster termasuk JPEG, PNG, BMP, dan TIFF. |

DOM adalah model dokumen yang dimuat di peramban dan merepresentasikan dokumen sebagai pohon node, di mana setiap node mewakili bagian dari dokumen (misalnya elemen, string teks, atau komentar). |

| [com.aspose.html.dom.css](./aspose.html.dom.css/) | Menyediakan antarmuka untuk Spesifikasi Gaya Tingkat 2 DOM. Cascading Style Sheets (CSS) adalah bahasa lembar gaya yang memungkinkan penulis dan pengguna melampirkan gaya (misalnya, font dan spasi) ke dokumen terstruktur (misalnya dokumen HTML dan aplikasi XML). CSS mendukung lembar gaya khusus media sehingga penulis dapat menyesuaikan tampilan dokumen mereka untuk peramban visual, perangkat audio, printer, perangkat braille, perangkat genggam, dll. CSS juga mendukung penempatan konten, tata letak tabel, fitur internasionalisasi, dan beberapa properti terkait antarmuka pengguna. Dengan memisahkan gaya presentasi dokumen dari konten dokumen, CSS menyederhanakan penulisan Web dan pemeliharaan situs. |
