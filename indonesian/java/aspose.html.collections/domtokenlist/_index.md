## DOMTokenList class

Kelas DOMTokenList mewakili sekumpulan token yang dipisahkan spasi. Ia diindeks mulai dari 0 seperti objek Array JavaScript. DOMTokenList selalu sensitif terhadap huruf besar/kecil.

```java
public class DOMTokenList : DOMObject, IEnumerable<String>
```
