## Toggle(String, bool) {#toggle_1}

Menghapus token dari daftar jika ada, atau menambahkan token ke daftar jika tidak ada.

```java
public bool Toggle(String token, bool force)
```

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| token | String | Token yang ingin Anda toggle. |
| force | Boolean | Boolean yang, jika disertakan, mengubah toggle menjadi operasi satu arah saja. Jika disetel ke false, maka token hanya akan dihapus, bukan ditambahkan. Jika disetel ke true, maka token hanya akan ditambahkan, bukan dihapus. |

### Nilai Kembali

Boolean yang menunjukkan apakah token berada dalam daftar setelah pemanggilan.
