Paket **com.aspose.html.collections** terdiri dari kelas-kelas untuk merepresentasikan, menyimpan, dan memanipulasi node serta elemen.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [DOMTokenList](./domtokenlist/) | Kelas DOMTokenList mewakili sekumpulan token yang dipisahkan oleh spasi. Ia diindeks mulai dari 0 seperti objek Array JavaScript. DOMTokenList selalu peka huruf besar/kecil. |
| [HTMLCollection](./htmlcollection/) | [`HTMLCollection`](../com.aspose.html.collections/htmlcollection/) mewakili kumpulan generik dari [`Element`](../com.aspose.html.dom/element/). |
| [NamedNodeMap](./namednodemap/) | Mewakili kumpulan atribut yang dapat diakses berdasarkan nama. |
| [NodeList](./nodelist/) | NodeList menyediakan abstraksi dari kumpulan node yang terurut, tanpa mendefinisikan atau membatasi cara koleksi ini diimplementasikan. |
