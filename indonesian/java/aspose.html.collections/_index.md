Paket **com.aspose.html.collections** terdiri dari kelas untuk merepresentasikan, menyimpan, dan memanipulasi node serta elemen.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [DOMTokenList](./domtokenlist/) | Kelas DOMTokenList mewakili sekumpulan token yang dipisahkan spasi. Ia diindeks mulai dari 0 seperti objek Array JavaScript. DOMTokenList selalu sensitif terhadap huruf besar/kecil. |
| [HTMLCollection](./htmlcollection/) | [`HTMLCollection`](../com.aspose.html.collections/htmlcollection/) mewakili koleksi generik dari [`Element`](../com.aspose.html.dom/element/). |
| [NamedNodeMap](./namednodemap/) | Mewakili koleksi atribut yang dapat diakses berdasarkan nama. |
| [NodeList](./nodelist/) | NodeList menyediakan abstraksi dari koleksi node yang terurut, tanpa mendefinisikan atau membatasi cara koleksi ini diimplementasikan. |
