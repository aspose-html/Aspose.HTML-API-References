## Observe(Node) {#observe}

Menginstruksikan agen pengguna untuk mengamati target tertentu (sebuah node) dan melaporkan mutasi apa pun berdasarkan kriteria yang diberikan oleh opsi (sebuah objek). Argumen opsi memungkinkan pengaturan opsi pengamatan mutasi melalui anggota objek.

```java
public void Observe(Node target)
```

| target | Node | Target untuk observe. |
