## MutationObserver constructor

Membuat objek MutationObserver dan mengatur [`MutationCallback`](../../mutationcallback/)‑nya ke callback. Callback dipanggil dengan daftar objek MutationRecord sebagai argumen pertama dan objek MutationObserver yang dibuat sebagai argumen kedua. Callback dipanggil setelah node yang terdaftar dengan metode !:Observe(Node, IMutationObserverInit) mengalami mutasi.

```java
public MutationObserver(MutationCallback callback)
```

| callback | MutationCallback | Callback tersebut. |
