## MutationRecord.Target property

Mengembalikan node yang terpengaruh oleh mutasi, tergantung pada tipe. Untuk "attributes", itu adalah elemen yang atributnya berubah. Untuk "characterData", itu adalah node CharacterData. Untuk "childList", itu adalah node yang anaknya berubah.

```java
public Node Target { get; }
```

### Property Value

Target.
