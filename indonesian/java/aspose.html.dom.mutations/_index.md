Paket **com.aspose.html.dom.mutations** memberikan kesempatan untuk mengamati mutasi DOM dan memperoleh informasi callback spesifik.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [MutationCallback](./mutationcallback/) | Mewakili metode yang akan menangani peristiwa mutasi. |
| [MutationObserver](./mutationobserver/) | Sebuah objek dapat digunakan untuk mengamati mutasi pada pohon [`.`](../com.aspose.html.dom/node/). |
| [MutationObserverInit](./mutationobserverinit/) | Kelas ini mewakili koleksi opsi yang digunakan untuk mengkonfigurasi [`MutationObserver`](../com.aspose.html.dom.mutations/mutationobserver/). |
| [MutationRecord](./mutationrecord/) | Sebuah MutationRecord mewakili mutasi DOM individu. Ini adalah objek yang diteruskan ke [`MutationObserver`](../com.aspose.html.dom.mutations/mutationobserver/)'s [`MutationCallback`](../com.aspose.html.dom.mutations/mutationcallback/). |
