## HTMLSelectElement.SelectedIndex property

Indeks ordinal dari opsi yang dipilih, mulai dari 0. Nilai -1 dikembalikan jika tidak ada elemen yang dipilih. Jika beberapa opsi dipilih, indeks opsi pertama yang dipilih dikembalikan.

public int SelectedIndex { get; set; }
