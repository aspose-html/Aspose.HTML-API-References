## HTMLDocument.Referrer property

Mengembalikan URI [[IETF RFC 2396](http://www.ietf.org/rfc/rfc2396.txt)] dari halaman yang menautkan ke halaman ini. Nilainya adalah String kosong jika pengguna menavigasi ke halaman secara langsung (tidak melalui tautan, tetapi, misalnya, melalui bookmark).

```java
public String Referrer { get; }
```
