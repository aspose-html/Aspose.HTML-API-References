## HTMLDocument.Images property

Kumpulan semua elemen `IMG` dalam sebuah dokumen. Perilaku dibatasi pada elemen `IMG` untuk kompatibilitas mundur. Seperti yang disarankan oleh [[HTML 4.01](http://www.w3.org/TR/1999/REC-html401-19991224)], untuk menyertakan gambar, penulis dapat menggunakan elemen `OBJECT` atau elemen `IMG`. Oleh karena itu, disarankan untuk tidak menggunakan atribut ini untuk menemukan gambar dalam dokumen, melainkan `getElementsByTagName` dengan HTML 4.01 atau `getElementsByTagNameNS` dengan XHTML 1.0.

```java
public HTMLCollection Images { get; }
```
