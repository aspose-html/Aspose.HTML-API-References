## Metered.SetMeteredKey method

Mengatur kunci publik dan privat bermeter. Jika Anda membeli lisensi bermeter, saat memulai aplikasi, API ini harus dipanggil; biasanya, ini sudah cukup. Namun, jika selalu gagal mengunggah data konsumsi dan melewati 24 jam, lisensi akan beralih ke status evaluasi; untuk menghindari hal tersebut, Anda harus secara teratur memeriksa status lisensi, jika berada dalam status evaluasi, panggil kembali API ini.

public void SetMeteredKey(String publicKey, String privateKey)
