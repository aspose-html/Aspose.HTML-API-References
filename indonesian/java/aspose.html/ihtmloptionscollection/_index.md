## IHTMLOptionsCollection interface

`HTMLOptionsCollection` adalah daftar node yang mewakili elemen opsi HTML. Sebuah node individual dapat diakses baik melalui indeks ordinal maupun atribut `name` atau `id` node tersebut. Koleksi dalam DOM HTML diasumsikan bersifat live, yang berarti mereka secara otomatis diperbarui ketika dokumen yang mendasarinya berubah.

Lihat juga [Document object Model (DOM) Level 2 HTML Specification](http://www.w3.org/TR/2003/REC-DOM-Level-2-HTML-20030109). @since DOM Level 2

```java
public interface IHTMLOptionsCollection : IEnumerable<Element>
```
