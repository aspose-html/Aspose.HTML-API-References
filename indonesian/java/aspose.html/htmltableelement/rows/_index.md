## HTMLTableElement.Rows property

Mengembalikan `TFOOT` tabel, atau `null` jika tidak ada.

Mengembalikan koleksi semua baris dalam tabel, termasuk semua yang ada di `THEAD`, `TFOOT`, semua elemen `TBODY`.
