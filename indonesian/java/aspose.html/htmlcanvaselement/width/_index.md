## HTMLCanvasElement.Width property

Adalah integer positif yang mencerminkan atribut width HTML dari elemen kanvas yang diinterpretasikan dalam piksel CSS. Ketika atribut tidak ditentukan, atau diatur ke nilai tidak valid, seperti negatif, nilai default 300 digunakan.

```java
public ulong Width { get; set; }
```
