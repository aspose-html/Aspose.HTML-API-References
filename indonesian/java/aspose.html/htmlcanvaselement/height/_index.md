## HTMLCanvasElement.Height property

Adalah integer positif yang mencerminkan atribut height HTML dari elemen kanvas yang diinterpretasikan dalam piksel CSS. Ketika atribut tidak ditentukan, atau diatur ke nilai tidak valid, seperti negatif, nilai default 150 digunakan.

```java
public ulong Height { get; set; }
```
