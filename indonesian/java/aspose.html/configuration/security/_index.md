## Configuration.Security property

Gets or sets the sandboxing flag of the configuration. Refer to article about [sandboxing](https://docs.aspose.com/html/net/working-with-documents/environment-configuration/#sandboxing).

```java
public Sandbox Security { get; set; }
```

### Property Value

Keamanan. Sekumpulan [`sandboxing flag`](../../sandbox/) adalah kumpulan nol atau lebih flag, yang digunakan untuk membatasi kemampuan sumber daya yang berpotensi tidak tepercaya. Atribut sandbox memungkinkan Anda menetapkan sejumlah pembatasan pada konten yang dimuat dalam frame, misalnya, memblokir formulir dan skrip.
