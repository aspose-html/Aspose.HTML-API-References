## HTMLInputElement.DefaultValue property

Ketika atribut `type` elemen memiliki nilai "text", "file", atau "password", ini mewakili atribut value HTML dari elemen tersebut. Nilai atribut ini tidak berubah jika isi kontrol formulir yang bersangkutan, dalam agen pengguna interaktif, berubah. Lihat definisi atribut value dalam HTML 4.01.

```java
public String DefaultValue { get; set; }
```
