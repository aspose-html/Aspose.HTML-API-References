## HTMLInputElement.Value property

Ketika atribut `type` pada elemen memiliki nilai "text", "file", atau "password", ini mewakili isi saat ini dari kontrol form yang bersangkutan, dalam agen pengguna interaktif. Mengubah atribut ini mengubah isi kontrol form, tetapi tidak mengubah nilai atribut HTML value pada elemen. Ketika atribut `type` pada elemen memiliki nilai "button", "hidden", "submit", "reset", "image", "checkbox", atau "radio", ini mewakili atribut HTML value pada elemen. Lihat definisi atribut value di HTML 4.01.

```java
public String Value { get; set; }
```
