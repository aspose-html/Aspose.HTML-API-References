## HTMLInputElement.DefaultChecked property

Ketika `type` memiliki nilai "radio" atau "checkbox", ini mewakili atribut HTML checked pada elemen. Nilai atribut ini tidak berubah jika keadaan kontrol form yang bersangkutan, pada agen pengguna interaktif, berubah. Lihat definisi atribut checked di HTML 4.01.

```java
public bool DefaultChecked { get; set; }
```
