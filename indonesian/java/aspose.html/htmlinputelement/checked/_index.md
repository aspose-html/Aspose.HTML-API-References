## HTMLInputElement.Checked property

Ketika atribut `type` pada elemen memiliki nilai "radio" atau "checkbox", ini mewakili keadaan saat ini dari kontrol formulir, dalam agen pengguna interaktif. Perubahan pada atribut ini mengubah keadaan kontrol formulir, tetapi tidak mengubah nilai atribut HTML checked pada elemen INPUT. Selama penanganan peristiwa klik pada elemen input dengan atribut type yang memiliki nilai "radio" atau "checkbox", beberapa implementasi dapat mengubah nilai properti ini sebelum peristiwa didistribusikan dalam dokumen. Jika aksi default peristiwa dibatalkan, nilai properti dapat dikembalikan ke nilai aslinya. Ini berarti bahwa nilai properti ini selama penanganan peristiwa klik bergantung pada implementasi.

```java
public bool Checked { get; set; }
```
