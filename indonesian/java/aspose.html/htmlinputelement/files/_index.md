## HTMLInputElement.Files property

Atribut IDL files memungkinkan skrip mengakses file yang dipilih elemen. Saat diakses, jika atribut IDL berlaku, harus mengembalikan objek FileList yang mewakili file yang dipilih saat ini. Objek yang sama harus dikembalikan sampai daftar file yang dipilih berubah. Jika atribut IDL tidak berlaku, maka harus mengembalikan null. [FILEAPI]

```java
public IFileList Files { get; }
```
