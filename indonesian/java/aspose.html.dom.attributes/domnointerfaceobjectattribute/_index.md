## DOMNoInterfaceObjectAttribute class

Jika atribut ekstensi [NoInterfaceObject] muncul pada sebuah antarmuka, itu menunjukkan bahwa objek antarmuka tidak akan ada untuk antarmuka tersebut dalam binding ECMAScript.

```java
[AttributeUsage(AttributeTargets.All)]
public sealed class DOMNoInterfaceObjectAttribute : Attribute
```
