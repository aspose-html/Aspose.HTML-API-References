Paket **com.aspose.html.dom.attributes** berisi kelas atribut terpadu yang menentukan atau mengkualifikasi fitur atau perilaku objek apa pun (node, elemen, ...).

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [DOMConstructorAttribute](./domconstructorattribute/) | Menentukan konstruktor yang didefinisikan oleh W3C. |
| [DOMNameAttribute](./domnameattribute/) | Menentukan nama objek DOM resmi sebagaimana didefinisikan oleh W3C. |
| [DOMNamedPropertyGetterAttribute](./domnamedpropertygetterattribute/) | Menentukan bahwa metode akan digunakan sebagai getter properti bernama |
| [DOMNoInterfaceObjectAttribute](./domnointerfaceobjectattribute/) | Jika atribut ekstensi [NoInterfaceObject] muncul pada sebuah antarmuka, itu menunjukkan bahwa objek antarmuka tidak akan ada untuk antarmuka tersebut dalam binding ECMAScript. |
| [DOMNullableAttribute](./domnullableattribute/) | Menentukan bahwa objek DOM dapat diberikan nilai null. |
| [DOMObjectAttribute](./domobjectattribute/) | Menentukan bahwa objek yang ditandai dengan atribut ini didefinisikan oleh W3C. |
| [DOMTreatNullAsAttribute](./domtreatnullasattribute/) | Menunjukkan bahwa null dari nilai anggota akan diperlakukan sebagai nilai yang ditentukan |
