Paket **com.aspose.html.net** disajikan oleh kelas dan antarmuka yang bertanggung jawab membantu pemrosesan jaringan yang mudah.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [ByteArrayContent](./bytearraycontent/) | Mewakili konten berbasis array byte. |
| [Content](./content/) | Mewakili kelas dasar untuk badan entitas HTTP dan header konten. |
| [ContentHeaders](./contentheaders/) | Berisi header yang terkait dengan konten. |
| [FormUrlEncodedContent](./formurlencodedcontent/) | Kontainer untuk pasangan nama/nilai yang dikodekan menggunakan tipe MIME application/x-www-form-urlencoded. |
| [HttpMethod](./httpmethod/) | Mewakili kelas utilitas untuk mengambil dan membandingkan metode HTTP standar. |
| [MessageFilter](./messagefilter/) | Mewakili kelas dasar abstrak untuk berbagai kelas filter yang digunakan untuk menanyakan pesan |
| [MessageHandler](./messagehandler/) | Mewakili tipe dasar untuk penangan pesan. |
| [MessageHandlerCollection](./messagehandlercollection/) | Mewakili koleksi dari [`MessageHandler`](../com.aspose.html.net/messagehandler/). |
| [MultipartContent](./multipartcontent/) | Mewakili konten multipart/*. |
| [MultipartFormDataContent](./multipartformdatacontent/) | Mewakili konten untuk algoritma enkoding multipart/form-data |
| [RequestHeaders](./requestheaders/) | Berisi header protokol yang terkait dengan permintaan. |
| [RequestMessage](./requestmessage/) | Mewakili pesan permintaan. |
| [ResponseHeaders](./responseheaders/) | Berisi header protokol yang terkait dengan respons. |
| [ResponseMessage](./responsemessage/) | Mewakili pesan respons. |
| [StreamContent](./streamcontent/) | Mewakili konten berbasis aliran. |
| [StringContent](./Stringcontent/) | Mewakili konten berbasis String. |
| [UrlResolver](./urlresolver/) | Mewakili kelas utilitas untuk menyelesaikan URL absolut melalui Uniform Resource Identifier (URI). |
