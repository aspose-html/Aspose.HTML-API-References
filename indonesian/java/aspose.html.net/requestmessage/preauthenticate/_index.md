## RequestMessage.PreAuthenticate property

Mendapatkan atau mengatur nilai yang menunjukkan apakah mengirim header Authorization dengan permintaan.

```java
public bool PreAuthenticate { get; set; }
```

### Property Value

`true` untuk mengirim header Authorization HTTP dengan permintaan setelah otentikasi terjadi; jika tidak, `false`. Defaultnya adalah `false`.
