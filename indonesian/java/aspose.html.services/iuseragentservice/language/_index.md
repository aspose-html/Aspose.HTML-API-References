## IUserAgentService.Language property

`Language` menentukan bahasa utama untuk isi elemen dan untuk atribut elemen apa pun yang berisi teks. Nilainya harus berupa tag bahasa BCP 47 () yang valid, atau String kosong. Menetapkan atribut ke String kosong menunjukkan bahwa bahasa utama tidak diketahui.

```java
public String Language { get; set; }
```

### Property Value

Bahasa agen pengguna.
