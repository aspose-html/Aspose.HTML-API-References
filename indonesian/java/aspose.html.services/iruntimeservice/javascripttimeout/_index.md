## IRuntimeService.JavaScriptTimeout property

Mendapatkan atau mengatur TimeSpan yang membatasi waktu eksekusi JavaScript. Jika skrip dijalankan lebih lama dari TimeSpan yang diberikan, skrip akan dibatalkan. Anda dapat menentukan batas waktu tak terbatas dengan mengatur TimeSpan menjadi -1 milidetik. Nilai default adalah 1 menit.

```java
public TimeSpan JavaScriptTimeout { get; set; }
```
