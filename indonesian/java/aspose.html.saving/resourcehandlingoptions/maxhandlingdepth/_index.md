## ResourceHandlingOptions.MaxHandlingDepth property

Mendapatkan atau mengatur kedalaman maksimum halaman yang akan diproses. Kedalaman 1 berarti hanya halaman yang secara langsung direferensikan dari dokumen yang disimpan yang akan diproses. Menetapkan properti ini ke -1 akan menyebabkan pemrosesan semua halaman. Nilai default adalah 0.

```java
public int MaxHandlingDepth { get; set; }
```
