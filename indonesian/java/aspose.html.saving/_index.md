Paket **com.aspose.html.saving** disajikan oleh kelas data untuk deskripsi opsi penyimpanan khusus pada proses konversi/penyimpanan.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [DocSaveOptions](./docsaveoptions/) | Kelas data opsi spesifik. Dengan menetapkan properti, Anda dapat mengelola karakteristik rendering seperti resolusi, ukuran halaman, warna latar belakang serta opsi spesifik dokumen seperti penyematan font. Info lebih lanjut lihat di dokumentasi [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-docx/#save-options). |
| [HTMLSaveOptions](./htmlsaveoptions/) | Mewakili opsi penyimpanan HTML. Dengan menetapkan properti tertentu, Anda dapat mengelola pemrosesan sumber daya seperti kedalaman penanganan maksimum dan sebagainya. Info lebih lanjut lihat di dokumentasi [article](https://docs.aspose.com/html/net/working-with-documents/saving-a-document/). |
| [ImageSaveOptions](./imagesaveoptions/) | Kelas data opsi spesifik. Kelas ini menyediakan properti untuk mengelola resolusi hasil gambar, kualitas penyamaran, format serta pengaturan halaman, dll. Info lebih lanjut dapat Anda peroleh di dokumentasi [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-jpg/#save-options). |
| [MarkdownSaveOptions](./markdownsaveoptions/) | Mewakili opsi penyimpanan Markdown. Misalnya, Anda dapat mengatur gaya pemformatan markdown, menggunakan opsi kompatibel GitLab Flavored Markdown yang telah ditentukan, dan mengonfigurasi penanganan sumber daya. Lihat info lebih lanjut di [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-markdown/#save-options). |
| [MHTMLSaveOptions](./mhtmlsaveoptions/) | Mewakili opsi penyimpanan MHTML. Dengan menetapkan properti tertentu, Anda dapat mengelola pemrosesan sumber daya seperti kedalaman penanganan maksimum dan sebagainya. Info lebih lanjut lihat di dokumentasi [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-mhtml/#save-options). |
| [PdfSaveOptions](./pdfsaveoptions/) | Kelas data spesifik menyediakan beberapa properti untuk mengelola hasil konversi. Misalnya [`PageSetup`](../com.aspose.html.rendering/pagesetup/) menentukan karakteristik halaman. Lihat dokumentasi di [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-pdf/#convert-html-to-pdf-using-pdfsaveoptions). |
| [Resource](./resource/) | Kelas ini mendeskripsikan sebuah sumber daya dan menyediakan metode untuk memprosesnya. |
| [ResourceHandlingContext](./resourcehandlingcontext/) | Kelas ini berisi informasi yang digunakan saat memproses sumber daya. |
| [ResourceHandlingOptions](./resourcehandlingoptions/) | Mewakili opsi penanganan sumber daya. |
| [SaveOptions](./saveoptions/) | Ini adalah kelas dasar abstrak untuk kelas yang memungkinkan pengguna menentukan opsi tambahan saat menyimpan dokumen ke format tertentu. |
| [TextSaveOptions](./textsaveoptions/) | Mewakili opsi penyimpanan Teks |
| [XpsSaveOptions](./xpssaveoptions/) | Kelas data opsi spesifik menyediakan beberapa properti untuk mengelola hasil konversi. Misalnya [`PageSetup`](../com.aspose.html.rendering/pagesetup/) menentukan karakteristik halaman. Lihat dokumentasi di [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-xps/#save-options). |
## Enumerasi

| Enumerasi | Deskripsi |
| --- | --- |
| [HTMLSaveFormat](./htmlsaveformat/) | Menentukan format di mana dokumen disimpan. Anda dapat menemukan info lebih lanjut tentang penyimpanan [`HTMLDocument`](../com.aspose.html/htmldocument/) di [article](https://docs.aspose.com/html/net/working-with-documents/saving-a-document/). |
| [MarkdownFeatures](./markdownfeatures/) | Sebuah set flag [`MarkdownFeatures`](../com.aspose.html.saving/markdownfeatures/) adalah kumpulan nol atau lebih flag berikut, yang digunakan untuk memilih elemen yang dikonversi ke markdown. |
| [MarkdownFormatter](./markdownformatter/) | Menentukan cara output akan diformat. |
| [ResourceHandling](./resourcehandling/) | Enum ini mewakili opsi penanganan sumber daya. |
| [ResourceStatus](./resourcestatus/) | Menunjukkan status sumber daya. |
| [UrlRestriction](./urlrestriction/) | Enum ini mewakili pembatasan yang diterapkan pada URL sumber daya yang diproses. |
