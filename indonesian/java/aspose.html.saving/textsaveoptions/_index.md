[setEnableListItemMarkers] Option that is applied to OL, UL elements on HTML conversion to text. In fact, it defines how to process the outside list markers of OL and UL elements. If true, item numbers are added before OL items, or dots are added before UL items. If false, they are not added (default behavior following the specification) |
