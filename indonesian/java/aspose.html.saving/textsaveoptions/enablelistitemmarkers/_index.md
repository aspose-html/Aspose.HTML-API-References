## TextSaveOptions.EnableListItemMarkers property

Opsi yang diterapkan pada elemen OL, UL saat konversi HTML ke teks. Faktanya, opsi ini menentukan cara memproses penanda daftar luar pada elemen OL dan UL. Jika true, nomor item ditambahkan sebelum item OL, atau titik ditambahkan sebelum item UL. Jika false, tidak ditambahkan (perilaku default mengikuti spesifikasi).

```java
public bool EnableListItemMarkers { get; set; }
```
