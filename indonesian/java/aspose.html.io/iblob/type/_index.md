## IBlob.Type property

String yang dikodekan ASCII dalam huruf kecil yang mewakili tipe media Blob. Pada saat pengambilan, agen pengguna harus mengembalikan tipe Blob sebagai String ASCII dalam huruf kecil, sehingga ketika dikonversi menjadi urutan byte, menjadi tipe MIME yang dapat diparse, atau String kosong – 0 byte – jika tipe tidak dapat ditentukan.

public String Type { get; }
