## IBlob.Size property

Mengembalikan ukuran urutan byte dalam jumlah byte. Pada saat mendapatkan, agen pengguna yang sesuai harus mengembalikan total jumlah byte yang dapat dibaca oleh objek FileReader atau FileReaderSync, atau 0 jika Blob tidak memiliki byte yang dapat dibaca.

public ulong Size { get; }
