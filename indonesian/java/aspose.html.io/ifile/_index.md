## IFile interface

Objek File adalah objek Blob dengan atribut name, yang merupakan String; objek ini dapat dibuat dalam aplikasi web melalui konstruktor, atau merupakan referensi ke urutan byte dari sebuah file pada sistem file (OS) yang mendasarinya.

```java
public interface IFile : IBlob
```

## Properti

| Nama | Deskripsi |
| --- | --- |
| [getLastModified](../../com.aspose.html.io/ifile/lastmodified/) Tanggal terakhir file dimodifikasi. Pada saat diakses, jika agen pengguna dapat menyediakan informasi ini, harus mengembalikan nilai long long yang berisi waktu file terakhir dimodifikasi dalam milidetik sejak Epoch Unix. |
| [getName](../../com.aspose.html.io/ifile/name/) Nama file. Pada saat diakses, harus mengembalikan nama file sebagai String. |
