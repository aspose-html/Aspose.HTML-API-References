Selain alat IO (input-output) standar, paket **com.aspose.html.io** berisi kelas pembantu dan antarmuka.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [FileCreateStreamProvider](./filecreatestreamprovider/) | Mewakili implementasi FileStream untuk menyediakan aliran ke perangkat rendering. |
## Antarmuka

| Antarmuka | Deskripsi |
| --- | --- |
| [IBlob](./iblob/) | Objek Blob mengacu pada urutan byte, dan memiliki atribut ukuran yang merupakan total jumlah byte dalam urutan byte, serta atribut tipe, yang merupakan String berkode ASCII dalam huruf kecil yang mewakili tipe media dari urutan byte. |
| [ICreateStreamProvider](./icreatestreamprovider/) | Mewakili antarmuka yang dapat diimplementasikan oleh kelas yang menyediakan aliran ke perangkat rendering. |
| [IFile](./ifile/) | Objek File adalah objek Blob dengan atribut nama, yang merupakan String; dapat dibuat dalam aplikasi web melalui konstruktor, atau merupakan referensi ke urutan byte dari file pada sistem file (OS) yang mendasarinya. |
| [IFileList](./ifilelist/) | Mewakili antarmuka untuk daftar file. |
