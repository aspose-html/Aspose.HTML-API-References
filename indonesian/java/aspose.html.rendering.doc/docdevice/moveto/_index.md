## DocDevice.MoveTo method

Memulai subjalur baru dengan memindahkan titik saat ini ke koordinat parameter pt, tanpa menambahkan segmen garis penghubung. Jika metode konstruksi jalur sebelumnya dalam jalur saat ini juga "MoveTo", "MoveTo" baru akan menggantikannya; tidak ada jejak operasi "MoveTo" sebelumnya yang tersisa dalam jalur.

```java
public void MoveTo(PointF pt)
```

| pt | PointF | Titik tujuan memindahkan jalur ke. |
