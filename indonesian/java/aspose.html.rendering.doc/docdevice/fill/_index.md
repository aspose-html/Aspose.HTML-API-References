## DocDevice.Fill method

Mengisi seluruh wilayah yang dikelilingi oleh jalur saat ini. Jika jalur terdiri dari beberapa subjalur yang terputus, ia mengisi bagian dalam semua subjalur, dipertimbangkan bersama. Metode ini mengakhiri jalur saat ini.

```java
public void Fill(FillRule mode)
```

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| mode | FillRule | Mode pengisian menentukan bagaimana interior dari jalur tertutup diisi. |
