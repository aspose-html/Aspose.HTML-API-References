| Kelas | Deskripsi |
| --- | --- |

| [DocRenderingOptions](./docrenderingoptions/) | Mewakili opsi rendering untuk [`DocDevice`](../com.aspose.html.rendering.doc/docdevice/). |
## Enumerasi

| Enumerasi | Deskripsi |
| --- | --- |

| [FontEmbeddingRule](./fontembeddingrule/) | Mewakili aturan penyematan font. |
