## FontEmbeddingRule enumeration

Mewakili aturan penyematan font.

```java
public enum FontEmbeddingRule
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Full | `1` | Semua font yang digunakan akan disematkan apa adanya. Harap perhatikan bahwa beberapa font mungkin berlisensi, hal ini akan membuat dokumen yang dihasilkan tidak dapat diedit. Juga file font yang disematkan dapat secara signifikan meningkatkan ukuran dokumen yang dihasilkan. |
| None | `2` | Font tidak akan disematkan. |
