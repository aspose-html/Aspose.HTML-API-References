## PageSetup.AdjustToWidestPage property

Mendapatkan atau mengatur bendera yang menentukan kondisi ketika ukuran halaman akan disesuaikan ke halaman terlebar dalam dokumen. Opsi ini memakan waktu sehingga waktu pemrosesan dokumen dapat meningkat dua kali lipat. Penyesuaian akan terjadi hanya jika halaman terlebar dalam dokumen lebih lebar daripada ukuran halaman yang ditentukan dalam [`PageSetup`](../). Ukuran halaman yang disesuaikan akan digunakan untuk semua halaman dalam dokumen.

```java
public bool AdjustToWidestPage { get; set; }
```
