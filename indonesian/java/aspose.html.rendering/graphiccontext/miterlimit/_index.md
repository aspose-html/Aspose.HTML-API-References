## GraphicContext.MiterLimit property

Mengatur atau mendapatkan panjang maksimum sambungan garis miter untuk jalur yang digambar. Parameter ini membatasi panjang \"spikes\" yang dihasilkan ketika segmen garis bergabung pada sudut tajam.

```java
public float MiterLimit { get; set; }
```
