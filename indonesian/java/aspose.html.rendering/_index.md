Paket **com.aspose.html.rendering** terdiri dari banyak objek renderer serta kelas opsi tingkat rendah yang sesuai yang bertanggung jawab untuk merender dokumen/berkas ke implementasi IDevice.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [CssOptions](./cssoptions/) | Mewakili opsi rendering css. |
| [Device](./device/) | Mewakili kelas dasar untuk mengimplementasikan perangkat rendering yang digunakan untuk menggambar grafik dalam berbagai format dan lingkungan. |
| [Device&lt;TGraphicContext,TRenderingOptions&gt;](./device-2/) | Mewakili kelas dasar untuk implementasi perangkat rendering tertentu. |
| [EpubRenderer](./epubrenderer/) | Mewakili renderer dokumen EPub. |
| [GraphicContext](./graphiccontext/) | Menyimpan parameter kontrol grafik saat ini. Parameter ini mendefinisikan kerangka kerja global tempat operator grafik dijalankan. |
| [HtmlRenderer](./htmlrenderer/) | Mewakili renderer dokumen HTML. |
| [MhtmlRenderer](./mhtmlrenderer/) | Mewakili renderer dokumen MHTML. |
| [PageSetup](./pagesetup/) | Mewakili objek pengaturan halaman yang digunakan untuk mengkonfigurasi output page-set. |
| [Renderer](./renderer/) | Mewakili kelas dasar untuk semua renderer dan mengimplementasikan antarmuka IDisposable. |
| [Renderer&lt;TSource&gt;](./renderer-1/) | Mewakili kelas abstrak untuk semua renderer. |
| [RenderingOptions](./renderingoptions/) | Mewakili opsi rendering. |
| [SvgRenderer](./svgrenderer/) | Mewakili renderer dokumen SVG. |
| [TextInfo](./textinfo/) | Berisi informasi tentang teks yang dirender. |
