Paket **com.aspose.html.rendering.image** menyediakan kelas perangkat khusus serta beberapa kelas opsi rendering yang bertanggung jawab untuk merender ke format raster: jpeg, png, bmp, gif, tiff.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [ImageDevice](./imagedevice/) | Mewakili rendering ke format raster: jpeg, png, bmp, gif, tiff. |
| [ImageRenderingOptions](./imagerenderingoptions/) | Mewakili opsi rendering untuk [`ImageDevice`](../com.aspose.html.rendering.image/imagedevice/). Opsi ini digunakan untuk menentukan format gambar keluaran, kompresi, resolusi, dll. |
| [TextOptions](./textoptions/) | Mewakili opsi rendering teks untuk [`ImageDevice`](../com.aspose.html.rendering.image/imagedevice/). |
## Enumerasi

| Enumerasi | Deskripsi |
| --- | --- |
| [Compression](./compression/) | Menentukan skema kompresi yang mungkin untuk gambar bitmap Tagged Image File Format (TIFF). |
| [ImageFormat](./imageformat/) | Menentukan format berkas gambar. |
