## SVGAngle.ValueAsString property

Nilai sudut sebagai nilai String, dalam satuan yang ditentukan oleh unitType. Menetapkan atribut ini akan menyebabkan value, valueInSpecifiedUnits, dan unitType diperbarui secara otomatis untuk mencerminkan pengaturan ini.

```java
public String ValueAsString { get; set; }
```

### Property Value

Nilai sebagai String.
