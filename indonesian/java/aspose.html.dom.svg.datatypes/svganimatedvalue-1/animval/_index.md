## SVGAnimatedValue&lt;T&gt;.AnimVal property

Jika atribut atau properti yang diberikan sedang dianimasikan, berisi nilai animasi saat ini dari atribut atau properti tersebut. Jika atribut atau properti yang diberikan tidak sedang dianimasikan, berisi nilai yang sama dengan baseVal.

```java
public T AnimVal { get; }
```

### Property Value

`true` jika [nilai anim]; selainnya, `false`.
