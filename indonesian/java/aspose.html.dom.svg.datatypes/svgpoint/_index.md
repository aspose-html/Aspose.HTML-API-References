## SVGPoint class

Banyak antarmuka DOM SVG merujuk pada objek kelas **SVGPoint**. Sebuah **SVGPoint** adalah pasangan koordinat (x, y). Ketika digunakan dalam operasi matriks, **SVGPoint** diperlakukan sebagai vektor dengan bentuk: [x] [y] [1] Jika sebuah objek **SVGRect** ditetapkan sebagai hanya-baca, maka upaya untuk menetapkan salah satu atributnya akan menghasilkan pengecualian yang dilemparkan.

```java
public class SVGPoint : SVGValueType
```
