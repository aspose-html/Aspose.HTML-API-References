Paket ini menyediakan akses ke semua tipe data khusus SVG.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [SVGAngle](./svgangle/) | Antarmuka SVGAngle sesuai dengan tipe data dasar angle. |
| [SVGAnimatedAngle](./svganimatedangle/) | Digunakan untuk atribut tipe data dasar angle yang dapat dianimasikan. |
| [SVGAnimatedBoolean](./svganimatedboolean/) | Digunakan untuk atribut tipe boolean yang dapat dianimasikan. |
| [SVGAnimatedEnumeration](./svganimatedenumeration/) | Digunakan untuk atribut yang nilainya harus konstan dari enumerasi tertentu dan dapat dianimasikan. |
| [SVGAnimatedInteger](./svganimatedinteger/) | Digunakan untuk atribut tipe dasar integer yang dapat dianimasikan. |
| [SVGAnimatedLength](./svganimatedlength/) | Digunakan untuk atribut tipe dasar length yang dapat dianimasikan. |
| [SVGAnimatedLengthList](./svganimatedlengthlist/) | Digunakan untuk atribut tipe SVGLengthList yang dapat dianimasikan. |
| [SVGAnimatedNumber](./svganimatednumber/) | Digunakan untuk atribut tipe dasar number yang dapat dianimasikan. |
| [SVGAnimatedNumberList](./svganimatednumberlist/) | Digunakan untuk atribut yang menerima daftar angka dan dapat dianimasikan. |
| [SVGAnimatedPreserveAspectRatio](./svganimatedpreserveaspectratio/) | Digunakan untuk atribut tipe SVGPreserveAspectRatio yang dapat dianimasikan. |
| [SVGAnimatedRect](./svganimatedrect/) | Digunakan untuk atribut tipe SVGRect yang dapat dianimasikan. |
| [SVGAnimatedString](./svganimatedString/) | Digunakan untuk atribut tipe DOMString yang dapat dianimasikan. |
| [SVGAnimatedTransformList](./svganimatedtransformlist/) | Digunakan untuk berbagai atribut yang menentukan satu set transformasi, seperti atribut ‘transform’ yang tersedia untuk banyak elemen SVG, dan yang dapat dianimasikan. |
| [SVGAnimatedValue&lt;T&gt;](./svganimatedvalue-1/) | Digunakan untuk atribut tipe yang dapat dianimasikan. |
| [SVGLength](./svglength/) | Antarmuka **SVGLength** sesuai dengan tipe data dasar panjang. Sebuah objek **SVGLength** dapat ditetapkan sebagai hanya-baca, yang berarti bahwa upaya untuk memodifikasi objek akan menghasilkan pengecualian yang dilemparkan, seperti dijelaskan di bawah. |
| [SVGLengthList](./svglengthlist/) | Antarmuka ini mendefinisikan daftar objek **SVGLength**. |
| [SVGMatrix](./svgmatrix/) | Banyak operasi grafis SVG menggunakan matriks 2x3 dengan bentuk: [a c e] [b d f] yang, ketika diperluas menjadi matriks 3x3 untuk keperluan aritmetika matriks, menjadi: [a c e] [b d f] [0 0 1] |
| [SVGNumber](./svgnumber/) | Digunakan untuk atribut dengan tipe dasar number. |
| [SVGNumberList](./svgnumberlist/) | Antarmuka ini mendefinisikan daftar objek **SVGNumber**. |
| [SVGPoint](./svgpoint/) | Banyak antarmuka DOM SVG merujuk pada objek kelas **SVGPoint**. Sebuah **SVGPoint** adalah pasangan koordinat (x, y). Ketika digunakan dalam operasi matriks, **SVGPoint** diperlakukan sebagai vektor dengan bentuk: [x] [y] [1] Jika sebuah objek **SVGRect** ditetapkan sebagai hanya-baca, maka upaya untuk menetapkan salah satu atributnya akan menghasilkan pengecualian yang dilemparkan. |
| [SVGPointList](./svgpointlist/) | Antarmuka ini mendefinisikan daftar objek **SVGPoint**. |
| [SVGPreserveAspectRatio](./svgpreserveaspectratio/) | Antarmuka **SVGPreserveAspectRatio** sesuai dengan atribut ‘preserveAspectRatio’, yang tersedia untuk beberapa elemen SVG. |
| [SVGRect](./svgrect/) | Mewakili geometri persegi panjang. Persegi panjang didefinisikan sebagai terdiri dari pasangan koordinat (x,y) yang mengidentifikasi nilai X minimum, nilai Y minimum, serta lebar dan tinggi, yang biasanya dibatasi agar tidak negatif. |
| [SVGStringList](./svgStringlist/) | **SVGStringList** memiliki atribut dan metode yang sama dengan antarmuka **SVGxxxList** lainnya. Implementor dapat mempertimbangkan penggunaan satu kelas dasar untuk mengimplementasikan berbagai antarmuka **SVGxxxList**. |
| [SVGTransform](./svgtransform/) | **SVGTransform** adalah antarmuka untuk salah satu transformasi komponen dalam **SVGTransformList**; sehingga, sebuah objek **SVGTransform** sesuai dengan satu komponen (mis., 'scale(…)' atau 'matrix(…)') dalam spesifikasi atribut ‘transform’. |
| [SVGTransformList](./svgtransformlist/) | Antarmuka ini mendefinisikan daftar objek **SVGTransform**. |
| [SVGValueType](./svgvaluetype/) | Tipe **SVGValueType** digunakan untuk merepresentasikan tipe nilai dasar SVG. |
