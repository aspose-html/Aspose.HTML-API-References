## IImageData interface

Membuat objek ImageData dari Uint8ClampedArray yang diberikan dan ukuran gambar yang terkandung di dalamnya. Jika tidak ada array yang diberikan, ia membuat gambar berupa persegi panjang hitam.

```java
public interface IImageData
```

| Nama | Deskripsi |
| --- | --- |
| [getData](../../com.aspose.html.dom.canvas/iimagedata/data/) adalah Uint8ClampedArray yang mewakili array satu dimensi yang berisi data dalam urutan RGBA, dengan nilai integer antara 0 dan 255 (termasuk). |
| [getHeight](../../com.aspose.html.dom.canvas/iimagedata/height/) adalah unsigned long yang mewakili tinggi sebenarnya, dalam piksel, dari ImageData. |
| [getWidth](../../com.aspose.html.dom.canvas/iimagedata/width/) adalah unsigned long yang mewakili lebar sebenarnya, dalam piksel, dari ImageData. |
