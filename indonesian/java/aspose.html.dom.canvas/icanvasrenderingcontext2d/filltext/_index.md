
| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| teks | String | Teks yang akan digambar menggunakan font, textAlign, textBaseline, dan nilai direction saat ini. |
| x | Double | Sumbu x dari koordinat titik awal teks. |
| y | Double | Sumbu y dari koordinat titik awal teks. |
| maxWidth | Double | Lebar maksimum untuk menggambar. Jika ditentukan, dan string dihitung lebih lebar daripada lebar ini, font akan disesuaikan untuk menggunakan font yang lebih padat secara horizontal (jika tersedia atau jika font yang cukup terbaca dapat disintesis dengan menskalakan font saat ini secara horizontal) atau font yang lebih kecil. |
