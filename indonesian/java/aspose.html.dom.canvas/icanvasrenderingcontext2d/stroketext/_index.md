## StrokeText(String, double, double, double?) {#stroketext_1}

Menggambar (mengecat) teks yang diberikan pada posisi (x, y) yang diberikan.

```java
public void StrokeText(String text, double x, double y, double? maxWidth)
```

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| text | String | Teks yang akan digambar menggunakan font, textAlign, textBaseline, dan nilai direction saat ini. |
| x | Double | Sumbu x dari koordinat titik awal teks. |
| y | Double | Sumbu y dari koordinat titik awal teks. |
| maxWidth | Nullable`1 | Lebar maksimum untuk menggambar. Jika ditentukan, dan String dihitung lebih lebar dari lebar ini, font disesuaikan untuk menggunakan font yang lebih padat secara horizontal (jika tersedia atau jika font yang cukup terbaca dapat disintesis dengan menskalakan font saat ini secara horizontal) atau font yang lebih kecil. |
