## ICanvasRenderingContext2D.ClearRect method

Mengatur semua piksel dalam persegi panjang yang didefinisikan oleh titik awal (x, y) dan ukuran (lebar, tinggi) menjadi hitam transparan, menghapus konten yang sebelumnya digambar.

```java
public void ClearRect(double x, double y, double w, double h)
```

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| x | Double | Sumbu x dari koordinat titik awal persegi panjang. |
| y | Double | Sumbu y dari koordinat titik awal persegi panjang. |
| w | Double | Lebar persegi panjang. |
| h | Double | Tinggi persegi panjang. |
