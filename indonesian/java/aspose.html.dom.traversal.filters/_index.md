Paket yang mewakili fungsionalitas penyaringan node. Filter adalah objek yang tahu cara "menyaring" node. Jika iterator node atau penelusur pohon diberikan filter node, ia menerapkan filter sebelum mengembalikan node berikutnya. Jika filter menyatakan untuk menerima node, logika penelusuran mengembalikannya; jika tidak, penelusuran mencari node berikutnya dan menganggap bahwa node yang ditolak tidak ada.
