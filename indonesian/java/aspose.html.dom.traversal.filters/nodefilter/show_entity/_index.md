## NodeFilter.SHOW_ENTITY field

Tampilkan node Entity. Ini hanya bermakna saat membuat iterator atau tree-walker dengan node Entity sebagai akar; dalam hal ini, berarti node Entity akan muncul di posisi pertama penelusuran. Karena entitas bukan bagian dari pohon dokumen, mereka tidak muncul saat menelusuri pohon dokumen.

```java
public const long SHOW_ENTITY;
```
