**com.aspose.html.dom.views** package describes AbstractView and DocumentView interfaces according Document Object Model Views specification.

## Antarmuka

| Antarmuka | Deskripsi |
| --- | --- |
| [IAbstractView](./iabstractview/) | Antarmuka dasar yang menjadi turunan semua view. |
| [IDocumentView](./idocumentview/) | Antarmuka DocumentView diimplementasikan oleh objek Document dalam implementasi DOM yang mendukung DOM Views. Antarmuka ini menyediakan atribut untuk mengambil tampilan default sebuah dokumen. |
