Paket ini terdiri dari kelas untuk interaktivitas berbasis peristiwa seperti peristiwa waktu dan zoom.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [SVGZoomEvent](./svgzoomevent/) | Peristiwa zoom terjadi ketika pengguna memulai aksi yang menyebabkan tampilan saat ini dari fragmen dokumen SVG diubah skalanya. Penangan peristiwa hanya dikenali pada elemen ‘svg’. |
| [TimeEvent](./timeevent/) | Antarmuka TimeEvent menyediakan informasi kontekstual spesifik yang terkait dengan peristiwa Waktu. Jenis-jenis peristiwa yang dapat terjadi adalah: beginEvent, endEvent, dan repeatEvent. |
