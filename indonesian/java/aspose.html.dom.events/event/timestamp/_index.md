## Event.TimeStamp property

Digunakan untuk menentukan waktu (dalam milidetik relatif terhadap epoch) saat peristiwa dibuat. Karena beberapa sistem mungkin tidak menyediakan informasi ini, nilai timeStamp mungkin tidak tersedia untuk semua peristiwa. Jika tidak tersedia, nilai 0 akan dikembalikan. Contoh waktu epoch adalah waktu mulai sistem atau 0:0:0 UTC 1 Januari 1970.

```java
public ulong TimeStamp { get; }
```
