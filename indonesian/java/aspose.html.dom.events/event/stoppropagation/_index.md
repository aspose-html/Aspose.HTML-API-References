## Event.StopPropagation method

Metode `StopPropagation` digunakan untuk mencegah propagasi lebih lanjut dari sebuah peristiwa selama alur peristiwa.

```java
public void StopPropagation()
```

## Catatan

Jika metode ini dipanggil oleh setiap [`IEventListener`](../../ieventlistener/), peristiwa akan berhenti berpropagasi melalui pohon. Peristiwa akan menyelesaikan pengiriman ke semua pendengar pada [`IEventTarget`](../../ieventtarget/) saat ini sebelum alur peristiwa berhenti. Metode ini dapat digunakan pada tahap mana pun dari alur peristiwa.
