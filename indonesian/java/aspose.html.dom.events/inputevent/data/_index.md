## InputEvent.Data property

Data menyimpan nilai karakter yang dihasilkan oleh metode input. Ini BISA berupa satu karakter Unicode atau urutan karakter Unicode yang tidak kosong [Unicode]. Karakter SEHARUSNYA dinormalisasi sebagaimana didefinisikan oleh bentuk normalisasi Unicode NFC, yang didefinisikan dalam [UAX15]. Atribut ini BISA berisi String kosong.

```java
public String Data { get; }
```

### Property Value

Data peristiwa.
