## WheelEvent.DeltaZ property

Pada agen pengguna di mana aksi default dari wheel event adalah menggulir, nilai HARUS menjadi pengukuran sepanjang sumbu z (dalam piksel, baris, atau halaman) yang akan digulir jika event tidak dibatalkan. Jika tidak, ini adalah pengukuran spesifik implementasi (dalam piksel, baris, atau halaman) dari gerakan perangkat roda di sekitar sumbu z.

```java
public double DeltaZ { get; }
```

Atribut deltaZ.
