## WheelEvent.DeltaY property

Pada agen pengguna di mana aksi default peristiwa roda adalah menggulir, nilai HARUS menjadi ukuran sepanjang sumbu y (dalam piksel, baris, atau halaman) yang akan digulir jika peristiwa tidak dibatalkan. Jika tidak, ini adalah ukuran spesifik implementasi (dalam piksel, baris, atau halaman) dari gerakan perangkat roda di sekitar sumbu y.

```java
public double DeltaY { get; }
```

### Property Value

Atribut deltaY.
