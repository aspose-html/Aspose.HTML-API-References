## WheelEvent.DeltaX property

Pada agen pengguna di mana aksi default peristiwa roda adalah menggulir, nilai HARUS menjadi ukuran sepanjang sumbu x (dalam piksel, baris, atau halaman) yang akan digulir jika peristiwa tidak dibatalkan. Jika tidak, ini adalah ukuran spesifik implementasi (dalam piksel, baris, atau halaman) dari gerakan perangkat roda di sekitar sumbu x.

```java
public double DeltaX { get; }
```

### Property Value

Atribut deltaX.
