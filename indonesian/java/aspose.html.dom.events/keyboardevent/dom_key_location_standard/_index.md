## KeyboardEvent.DOM_KEY_LOCATION_STANDARD field

Aktivasi kunci TIDAK BOLEH dibedakan sebagai versi kiri atau kanan dari tombol, dan (selain tombol NumLock) tidak berasal dari keypad numerik (atau tidak berasal dengan tombol virtual yang sesuai dengan keypad numerik).

```java
public const ulong DOM_KEY_LOCATION_STANDARD;
```
