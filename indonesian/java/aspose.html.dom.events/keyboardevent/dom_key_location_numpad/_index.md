## KeyboardEvent.DOM_KEY_LOCATION_NUMPAD field

Aktivasi kunci berasal dari keypad numerik atau dengan tombol virtual yang sesuai dengan keypad numerik (ketika ada lebih dari satu lokasi yang memungkinkan untuk tombol ini). Perhatikan bahwa tombol NumLock harus selalu dikodekan dengan lokasi DOM_KEY_LOCATION_STANDARD.

```java
public const ulong DOM_KEY_LOCATION_NUMPAD;
```
