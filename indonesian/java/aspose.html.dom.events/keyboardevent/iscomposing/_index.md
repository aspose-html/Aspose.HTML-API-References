## KeyboardEvent.IsComposing property

true jika peristiwa tombol terjadi sebagai bagian dari sesi komposisi, yaitu setelah peristiwa compositionstart dan sebelum peristiwa compositionend yang bersesuaian. Nilai yang belum diinisialisasi dari atribut ini HARUS false.

```java
public bool IsComposing { get; }
```

### Property Value

`true` jika instance ini sedang melakukan komposisi; jika tidak, `false`.
