## KeyboardEvent.Repeat property

true jika tombol telah ditekan secara berkelanjutan. Menahan tombol HARUS menghasilkan pengulangan peristiwa keydown, beforeinput, input dalam urutan ini, dengan kecepatan yang ditentukan oleh konfigurasi sistem. Untuk perangkat seluler yang memiliki perilaku tekan-tombol lama, peristiwa tombol pertama dengan nilai atribut repeat true HARUS menjadi indikasi tekan-tombol lama. Durasi waktu yang harus tombol ditekan agar mulai mengulang bergantung pada konfigurasi.

```java
public bool Repeat { get; }
```

### Property Value

`true` jika repeat; selainnya, `false`.
