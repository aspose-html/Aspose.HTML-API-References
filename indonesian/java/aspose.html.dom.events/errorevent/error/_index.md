## ErrorEvent.Error property

Atribut error harus mengembalikan nilai yang diinisialisasi. Saat objek dibuat, atribut ini harus diinisialisasi ke null. Bila sesuai, atribut ini diatur ke objek yang mewakili kesalahan (misalnya objek pengecualian dalam kasus pengecualian DOM yang tidak tertangkap).

```java
public object Error { get; }
```

Kesalahan.
