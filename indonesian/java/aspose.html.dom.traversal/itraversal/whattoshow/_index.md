## ITraversal.WhatToShow property

Atribut ini menentukan jenis node mana yang disajikan melalui iterator. Set konstan yang tersedia didefinisikan dalam antarmuka NodeFilter. Node yang tidak diterima oleh whatToShow akan dilewati, tetapi anak‑anaknya masih dapat dipertimbangkan. Perhatikan bahwa pengabaian ini memiliki prioritas lebih tinggi daripada filter, jika ada.

```java
public long WhatToShow { get; }
```

### Property Value

Apa yang akan ditampilkan.
