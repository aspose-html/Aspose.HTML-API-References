## INodeIterator.Detach method

Melepaskan NodeIterator dari set yang telah diiterasinya, melepaskan sumber daya komputasi apa pun dan menempatkan iterator dalam keadaan INVALID. Setelah detach dipanggil, panggilan ke nextNode atau previousNode akan menghasilkan pengecualian INVALID_STATE_ERR.
