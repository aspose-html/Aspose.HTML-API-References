## ITreeWalker.NextNode method

Memindahkan TreeWalker ke node berikutnya yang terlihat dalam urutan dokumen relatif terhadap node saat ini, dan mengembalikan node baru. Jika node saat ini tidak memiliki node berikutnya, atau jika pencarian nextNode mencoba melangkah ke atas dari node akar TreeWalker, mengembalikan null, dan mempertahankan node saat ini.

```java
public Node NextNode()
```

### Nilai Kembali

Node baru, atau null jika node saat ini tidak memiliki node berikutnya dalam tampilan logis TreeWalker.
