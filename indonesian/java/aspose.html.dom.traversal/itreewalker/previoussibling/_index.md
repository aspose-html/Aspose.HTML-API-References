Memindahkan TreeWalker ke saudara sebelumnya dari node saat ini, dan mengembalikan node baru. Jika node saat ini tidak memiliki saudara sebelumnya yang terlihat, mengembalikan null, dan mempertahankan node saat ini.

```java
public Node PreviousSibling()
```

### Nilai Kembali
