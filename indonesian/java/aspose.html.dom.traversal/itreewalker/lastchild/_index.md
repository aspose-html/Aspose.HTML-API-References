## ITreeWalker.LastChild method

Memindahkan TreeWalker ke anak terakhir yang terlihat dari node saat ini, dan mengembalikan node baru. Jika node saat ini tidak memiliki anak yang terlihat, mengembalikan null, dan mempertahankan node saat ini.

```java
public Node LastChild()
```

### Nilai Kembali

Node baru, atau null jika node saat ini tidak memiliki anak dalam tampilan logis TreeWalker.
