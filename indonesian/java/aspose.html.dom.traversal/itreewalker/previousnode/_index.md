## ITreeWalker.PreviousNode method

Memindahkan TreeWalker ke node terlihat sebelumnya dalam urutan dokumen relatif terhadap node saat ini, dan mengembalikan node baru. Jika node saat ini tidak memiliki node sebelumnya, atau jika pencarian previousNode mencoba naik dari node akar TreeWalker, mengembalikan null, dan mempertahankan node saat ini.

```java
public Node PreviousNode()
```

### Nilai Kembali

Node baru, atau null jika node saat ini tidak memiliki node sebelumnya dalam tampilan logis TreeWalker.
