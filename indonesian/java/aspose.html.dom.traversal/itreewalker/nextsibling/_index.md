## ITreeWalker.NextSibling method

Memindahkan TreeWalker ke saudara berikutnya yang terlihat dari node saat ini, dan mengembalikan node baru. Jika node saat ini tidak memiliki saudara berikutnya yang terlihat, mengembalikan null, dan mempertahankan node saat ini.

```java
public Node NextSibling()
```

### Nilai Kembali

Node baru, atau null jika node saat ini tidak memiliki saudara berikutnya dalam tampilan logis TreeWalker.
