## ITreeWalker.ParentNode method

Berpindah ke dan mengembalikan node nenek moyang terdekat yang terlihat dari node saat ini. Jika pencarian parentNode mencoba melangkah ke atas dari node akar TreeWalker, atau jika tidak menemukan node nenek moyang yang terlihat, metode ini mempertahankan posisi saat ini dan mengembalikan null.

```java
public Node ParentNode()
```

### Nilai Kembali

Node induk baru, atau null jika node saat ini tidak memiliki induk dalam tampilan logis TreeWalker.
