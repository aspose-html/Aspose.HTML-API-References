**com.aspose.html.rendering.doc** パッケージは、DOCX ドキュメントへのレンダリングを担当する特定のデバイスクラスと、いくつかのレンダリングオプションクラスを提供します。

## クラス

| クラス | 説明 |
| --- | --- |
| [DocDevice](./docdevice/) | DOCX ドキュメントへのレンダリングを表します。 |
| [DocRenderingOptions](./docrenderingoptions/) | [`DocDevice`](../com.aspose.html.rendering.doc/docdevice/) のレンダリングオプションを表します。 |
## 列挙型

| 列挙型 | 説明 |
| --- | --- |
| [DocumentFormat](./documentformat/) | 出力ドキュメントのファイル形式を表します。 |
| [FontEmbeddingRule](./fontembeddingrule/) | フォント埋め込みルールを表します。 |
