## FontEmbeddingRule enumeration

フォント埋め込みルールを表します。

```java
public enum FontEmbeddingRule
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Full | `1` | 使用されたすべてのフォントはそのまま埋め込まれます。フォントの中にはライセンスが必要なものがあり、これにより生成されたドキュメントが編集できなくなることがあります。また、埋め込まれたフォントファイルは生成されたドキュメントのサイズを大幅に増加させる可能性があります。 |
| None | `2` | フォントは埋め込まれません。 |
