## DocDevice.MoveTo method

現在の点をパラメータ pt の座標へ移動させ、新しいサブパスを開始します。接続線は省略されます。もし現在のパスで前のパス構築メソッドも "MoveTo" だった場合、新しい "MoveTo" がそれを上書きし、以前の "MoveTo" 操作の痕跡はパスに残りません。

```java
public void MoveTo(PointF pt)
```

| Parameter | Type | 説明 |
| --- | --- | --- |
| pt | PointF | パスを移動させる点です。 |
