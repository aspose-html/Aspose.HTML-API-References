## DocDevice.Fill method

現在のパスで囲まれた全領域を塗りつぶします。パスが複数の切れ離されたサブパスで構成されている場合、すべてのサブパスの内部をまとめて塗りつぶします。このメソッドは現在のパスを終了します。

```java
public void Fill(FillRule mode)
```

| Parameter | Type | 説明 |
| --- | --- | --- |
| モード | FillRule | 塗りつぶしモードは、閉じたパスの内部がどのように塗りつぶされるかを指定します |
