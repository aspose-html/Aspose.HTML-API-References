## SVGAngle.ValueAsString property

unitType が表す単位での文字列としての角度値。 この属性を設定すると、value、valueInSpecifiedUnits、unitType が自動的に更新され、この設定を反映します。

```java
public String ValueAsString { get; set; }
```

### Property Value

文字列としての値。
