## SVGAngle.ValueAsString property

unitType で表される単位での角度値を文字列として表します。この属性を設定すると、value、valueInSpecifiedUnits、unitType が自動的に更新され、この設定を反映します。

```java
public String ValueAsString { get; set; }
```

### Property Value

文字列としての値です。
