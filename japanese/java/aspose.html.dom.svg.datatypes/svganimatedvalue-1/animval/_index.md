## SVGAnimatedValue&lt;T&gt;.AnimVal property

指定された属性またはプロパティがアニメーション中であれば、その属性またはプロパティの現在のアニメーション値が含まれます。指定された属性またはプロパティが現在アニメーションされていなければ、baseVal と同じ値が含まれます。

```java
public T AnimVal { get; }
```

### Property Value

`true` は [anim value] の場合、そうでなければ `false`です。
