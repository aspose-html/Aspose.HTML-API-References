このパッケージは、すべての SVG 固有データ型へのアクセスを提供します。

## クラス

| クラス | 説明 |
| --- | --- |
| [SVGAngle](./svgangle/) | SVGAngle インターフェイスは angle 基本データ型に対応しています。 |
| [SVGAnimatedAngle](./svganimatedangle/) | アニメーション可能な angle 基本データ型の属性に使用されます。 |
| [SVGAnimatedBoolean](./svganimatedboolean/) | アニメーション可能な boolean 型の属性に使用されます。 |
| [SVGAnimatedEnumeration](./svganimatedenumeration/) | 特定の列挙体からの定数である必要があり、かつアニメーション可能な属性に使用されます。 |
| [SVGAnimatedInteger](./svganimatedinteger/) | アニメーション可能な整数基本型の属性に使用されます。 |
| [SVGAnimatedLength](./svganimatedlength/) | アニメーション可能な length 基本型の属性に使用されます。 |
| [SVGAnimatedLengthList](./svganimatedlengthlist/) | アニメーション可能な SVGLengthList 型の属性に使用されます。 |
| [SVGAnimatedNumber](./svganimatednumber/) | アニメーション可能な number 基本型の属性に使用されます。 |
| [SVGAnimatedNumberList](./svganimatednumberlist/) | 数値のリストを受け取り、アニメーション可能な属性に使用されます。 |
| [SVGAnimatedPreserveAspectRatio](./svganimatedpreserveaspectratio/) | アニメーション可能な SVGPreserveAspectRatio 型の属性に使用されます。 |
| [SVGAnimatedRect](./svganimatedrect/) | アニメーション可能な SVGRect 型の属性に使用されます。 |
| [SVGAnimatedString](./svganimatedString/) | アニメーション可能な DOMString 型の属性に使用されます。 |
| [SVGAnimatedTransformList](./svganimatedtransformlist/) | さまざまな変換のセットを指定する属性（例として、多くの SVG 要素で利用可能でアニメーション可能な ‘transform’ 属性）に使用されます。 |
| [SVGAnimatedValue&lt;T&gt;](./svganimatedvalue-1/) | アニメーション可能な型の属性に使用されます。 |
| [SVGLength](./svglength/) | SVGLength インターフェイスは length 基本データ型に対応します。SVGLength オブジェクトは読み取り専用に指定でき、オブジェクトの変更を試みると例外がスローされます（以下参照）。 |
| [SVGLengthList](./svglengthlist/) | このインターフェイスは SVGLength オブジェクトのリストを定義します。 |
| [SVGMatrix](./svgmatrix/) | SVG の多くのグラフィック操作は、次の形の 2x3 行列を使用します: [a c e] [b d f]。行列演算のために 3x3 行列に拡張すると、次のようになります: [a c e] [b d f] [0 0 1] |
| [SVGNumber](./svgnumber/) | 基本型 number の属性に使用されます。 |
| [SVGNumberList](./svgnumberlist/) | このインターフェイスは SVGNumber オブジェクトのリストを定義します。 |
| [SVGPoint](./svgpoint/) | SVG DOM の多くのインターフェイスはクラス SVGPoint のオブジェクトを参照します。SVGPoint は (x, y) の座標ペアです。行列演算で使用される場合、SVGPoint は次の形のベクトルとして扱われます: [x] [y] [1]。SVGRect オブジェクトが読み取り専用に指定されている場合、その属性に代入しようとすると例外がスローされます。 |
| [SVGPointList](./svgpointlist/) | このインターフェイスは SVGPoint オブジェクトのリストを定義します。 |
| [SVGPreserveAspectRatio](./svgpreserveaspectratio/) | SVGPreserveAspectRatio インターフェイスは ‘preserveAspectRatio’ 属性に対応し、いくつかの SVG 要素で利用可能です。 |
| [SVGRect](./svgrect/) | 矩形ジオメトリを表します。矩形は (x,y) の座標ペアで最小 X 値と最小 Y 値を特定し、幅と高さで構成され、通常は非負に制限されます。 |
| [SVGStringList](./svgStringlist/) | SVGStringList は他の SVGxxxList インターフェイスと同じ属性とメソッドを持ちます。実装者はさまざまな SVGxxxList インターフェイスを実装するために単一の基底クラスの使用を検討できるでしょう。 |
| [SVGTransform](./svgtransform/) | SVGTransform は SVGTransformList 内のコンポーネント変換の一つのインターフェイスです。そのため、SVGTransform オブジェクトは ‘transform’ 属性指定内の単一コンポーネント（例: 'scale(…)' や 'matrix(…)') に対応します。 |
| [SVGTransformList](./svgtransformlist/) | このインターフェイスは SVGTransform オブジェクトのリストを定義します。 |
| [SVGValueType](./svgvaluetype/) | SVGValueType 型は基本的な SVG 値型を表すために使用されます。 |
