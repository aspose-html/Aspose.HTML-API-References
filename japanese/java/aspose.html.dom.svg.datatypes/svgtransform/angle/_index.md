## SVGTransform.Angle property

SVG_TRANSFORM_ROTATE、SVG_TRANSFORM_SKEWX、SVG_TRANSFORM_SKEWY 用の便利属性です。指定された角度を保持します。SVG_TRANSFORM_MATRIX、SVG_TRANSFORM_TRANSLATE、SVG_TRANSFORM_SCALE の場合、角度はゼロになります。

```java
public float Angle { get; }
```

### Property Value

指定された角度です。
