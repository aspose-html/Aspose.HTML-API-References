## SVGTransform.SetMatrix method

パラメータ matrix で新しい変換を定義し、変換タイプを SVG_TRANSFORM_MATRIX に設定します。パラメータ matrix の値はコピーされ、matrix パラメータは SVGTransform::matrix を置き換えません。

public void SetMatrix(SVGMatrix matrix)
