## SVGLength.ValueInSpecifiedUnits property

unitType が表す単位での浮動小数点値としての値。 この属性を設定すると、value と valueAsString が自動的に更新され、この設定を反映します。

```java
public float ValueInSpecifiedUnits { get; set; }
```

### Property Value

指定された単位での値です。
