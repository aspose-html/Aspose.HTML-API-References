## SVGLength.SVG_LENGTHTYPE_UNKNOWN field

単位タイプは事前定義された単位タイプのいずれでもありません。このタイプの新しい値を定義しようとしたり、既存の値をこのタイプに切り替えようとすることは無効です。

```java
public const ushort SVG_LENGTHTYPE_UNKNOWN;
```
