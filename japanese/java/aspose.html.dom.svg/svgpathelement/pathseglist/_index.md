## SVGPathElement.PathSegList property

d 属性の基本（すなわち静的）内容に、SVG の構文と 1 対 1 で対応する形でアクセスを提供します。したがって、d 属性に「絶対 moveto (M)」および「絶対 arcto (A)」コマンドがある場合、pathSegList には 2 つのエントリが含まれます：SVG_PATHSEG_MOVETO_ABS と SVG_PATHSEG_ARC_ABS。

```java
public SVGPathSegList PathSegList { get; set; }
```

### Property Value

パスセグメントリストです。
