## SVGTextContentElement.GetNumberOfChars method

現在の要素内でレンダリング可能な文字数の合計を返します。これには ‘tref’ 参照からの文字も含まれ、実際にレンダリングされるかどうかは問わないです。実質的には、DOM Level 3 Core（[DOM3]、セクション 1.4）の Node::textContent 属性の長さと同等で、もしその属性が ‘tref’ 要素も展開している場合です。

```java
public long GetNumberOfChars()
```

### 戻り値

文字数の合計。
