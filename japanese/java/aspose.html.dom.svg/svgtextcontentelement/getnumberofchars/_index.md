## SVGTextContentElement.GetNumberOfChars method

現在の要素内でレンダリング可能な文字数の合計を返します。これには ‘tref’ 参照からの文字も含まれ、レンダリングされるかどうかに関わりません。実質的には、DOM Level 3 Core（[DOM3], section 1.4）の Node::textContent 属性の長さに相当し、その属性が ‘tref’ 要素も展開している場合に同等です。

```java
public long GetNumberOfChars()
```

### 戻り値

文字数の合計。
