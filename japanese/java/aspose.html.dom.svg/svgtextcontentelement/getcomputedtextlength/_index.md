## SVGTextContentElement.GetComputedTextLength method

この要素内のすべての文字をレンダリングした際の全てのアドバンス値の合計で、グリフ（水平または垂直）のアドバンス値、プロパティ ‘kerning’、‘letter-spacing’、‘word-spacing’ の効果、そして ‘tspan’ 要素の属性 ‘dx’ と ‘dy’ による調整を含みます。レンダリングを行わない環境では、ユーザーエージェントはグリフメトリックについて合理的な仮定を行うものとします。

```java
public float GetComputedTextLength()
```

### 戻り値

テキストの進み距離。
