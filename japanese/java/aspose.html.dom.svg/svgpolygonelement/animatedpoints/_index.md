## SVGPolygonElement.AnimatedPoints property

‘points’ 属性の現在のアニメーション化された内容にアクセスできます。対象の属性またはプロパティがアニメーション化されている場合、属性またはプロパティの現在のアニメーション化された値が含まれます。対象の属性またはプロパティが現在アニメーション化されていない場合、points と同じ値が含まれます。

```java
public SVGPointList AnimatedPoints { get; }
```

### Property Value

アニメーション化されたポイント。
