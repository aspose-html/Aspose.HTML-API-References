## SVGSVGElement.CurrentTranslate property

最外層の svg 要素では、ユーザー \"magnification\"（拡大）を考慮した対応する平行移動係数を示します。最外層でない ‘svg’ 要素でアクセスした場合、この属性の動作は未定義です。

```java
public SVGPoint CurrentTranslate { get; }
```

### Property Value

現在の平行移動。
