## SVGSVGElement.PauseAnimations method

この ‘svg’ 要素に対応する SVG ドキュメントフラグメント内で定義された、現在実行中のすべてのアニメーションを一時停止（＝pause）します。これにより、ドキュメントフラグメントに対応するアニメーションクロックが停止し、再開されるまで停止したままになります。
