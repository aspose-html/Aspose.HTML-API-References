## SVGSVGElement.GetElementById method

この SVG ドキュメントフラグメント（すなわち、ドキュメントツリーのサブセットに限定された検索）内で、elementId で指定された id を持つ Element を検索します。要素が見つかればその Element を返します。該当する要素が存在しない場合は null を返します。複数の要素が同じ id を持つ場合の動作は未定義です。

```java
public Element GetElementById(String elementId)
```

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| elementId | 文字列 | 要素の一意の ID 値です。 |

### 戻り値

一致する要素です。
