## SVGPolylineElement.AnimatedPoints property

‘points’ 属性の現在のアニメーションされた内容にアクセスできます。対象の属性またはプロパティがアニメーション中の場合、属性またはプロパティの現在のアニメーション値が含まれます。対象の属性またはプロパティが現在アニメーションされていない場合、points と同じ値が含まれます。

```java
public SVGPointList AnimatedPoints { get; }
```

### Property Value

アニメーションされたポイント。
