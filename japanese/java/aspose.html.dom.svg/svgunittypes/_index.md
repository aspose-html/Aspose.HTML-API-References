## SVGUnitTypes enumeration

SVGUnitTypes 列挙体は、一般的に使用される定数のセットを定義し、SVGGradientElement、SVGPatternElement、SVGClipPathElement、SVGMaskElement、SVGFilterElement で使用される基底インターフェイスです。

```java
public enum SVGUnitTypes
```

| SVG_UNIT_TYPE_USERSPACEONUSE | `1` | 値 'userSpaceOnUse' に対応します。 |
