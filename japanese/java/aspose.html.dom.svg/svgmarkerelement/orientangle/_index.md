## SVGMarkerElement.OrientAngle property

指定された ‘marker’ 要素の属性 ‘orient’ に対応します。markerUnits が SVG_MARKER_ORIENT_ANGLE の場合、属性 ‘orient’ の角度値が使用され、そうでない場合は 0 に設定されます。

```java
public SVGAnimatedAngle OrientAngle { get; }
```

### Property Value

指定された ‘marker’ 要素の属性 ‘orient’。
