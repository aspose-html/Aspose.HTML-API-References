## TemplateLoadOptions.NamesAreCaseSensitive property

テンプレートとデータ要素の名前が大文字小文字を区別せずに一致するかどうかを指定するプロパティです。true の場合は大文字小文字を区別して一致し、false の場合は大文字小文字を無視します。既定値は true です。

```java
public bool NamesAreCaseSensitive { get; set; }
```
