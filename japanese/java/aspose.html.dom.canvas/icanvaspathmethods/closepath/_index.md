## ICanvasPathMethods.ClosePath method

ペンの位置を現在のサブパスの開始点に戻します。現在の点から開始点へ直線を描こうとします。形状がすでに閉じているか、点が1つしかない場合、この関数は何もしません。

public void ClosePath()
