## Path2D.BezierCurveTo method

パスに三次ベジェ曲線を追加します。3 つの点が必要です。最初の 2 点は制御点、3 番目の点が終点です。開始点は現在のパスの最後の点で、ベジェ曲線を作成する前に moveTo() で変更できます。

```java
public void BezierCurveTo(double cp1x, double cp1y, double cp2x, double cp2y, double x, double y)
```

| Parameter | Type | 説明 |
| --- | --- | --- |
| cp1x | Double | 最初の制御点の座標の x 軸です。 |
| cp1y | Double | 最初の制御点の座標の y 軸です。 |
| cp2x | Double | 2 番目の制御点の座標の x 軸です。 |
| cp2y | Double | 2 番目の制御点の座標の y 軸です。 |
| x | Double | 終点の座標の x 軸です。 |
| y | Double | 終点の座標の y 軸です。 |
