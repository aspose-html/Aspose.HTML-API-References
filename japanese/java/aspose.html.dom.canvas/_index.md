## クラス

| クラス | 説明 |
| --- | --- |
| [Path2D](./path2d/) | Canvas 2D API の Path2D インターフェイスは、後で CanvasRenderingContext2D オブジェクトで使用されるパスを宣言するために使用されます。このインターフェイスには CanvasRenderingContext2D インターフェイスのパスメソッドも含まれており、必要に応じてキャンバス上で保持・再生できるパスを作成することができます。 |
## インターフェイス

| インターフェイス | 説明 |
| --- | --- |
| [ICanvasDrawingStyles](./icanvasdrawingstyles/) | ICanvasDrawingStyles インターフェイスは、線の描画方法やテキストの配置方法を制御するメソッドとプロパティを提供します。 |
| [ICanvasGradient](./icanvasgradient/) | グラデーションを記述する不透明オブジェクトを表します。 |
| [ICanvasPathMethods](./icanvaspathmethods/) | ICanvasPathMethods インターフェイスは、オブジェクトのパスを操作するために使用されます。 |
| [ICanvasPattern](./icanvaspattern/) | 画像、キャンバス、またはビデオに基づくパターンを記述する不透明オブジェクトを表します。 |
| [ICanvasRenderingContext2D](./icanvasrenderingcontext2d/) | ICanvasRenderingContext2D インターフェイスは、キャンバス要素上に矩形、テキスト、画像、その他のオブジェクトを描画するために使用されます。キャンバス要素の描画表面に対する 2D レンダリングコンテキストを提供します。 |
| [IImageData](./iimagedata/) | 指定された Uint8ClampedArray とその画像サイズから ImageData オブジェクトを作成します。配列が指定されない場合は、黒い矩形の画像を作成します。 |
| [ITextMetrics](./itextmetrics/) | キャンバス上のテキストの寸法を表します。 |
