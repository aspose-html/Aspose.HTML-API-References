## DrawImage(HTMLImageElement, double, double, double, double) {#drawimage_4}

指定された画像を描画します。

```java
public void DrawImage(HTMLImageElement image, double dx, double dy, double dw, double dh)
```

| Parameter | Type | 説明 |
| --- | --- | --- |
| 画像 | HTMLImageElement | コンテキストに描画する HTMLImageElement。 |
| dx | Double | ソース画像の左上隅を配置するための、宛先キャンバス上の X 座標。 |

## DrawImage(HTMLImageElement, double, double, double, double, double, double, double, double) {#drawimage_5}

```java
public void DrawImage(HTMLImageElement image, double sx, double sy, double sw, double sh, 
    double dx, double dy, double dw, double dh)
```

| Parameter | Type | 説明 |
| --- | --- | --- |
| 画像 | HTMLImageElement | コンテキストに描画する HTMLImageElement。 |
| sx | Double | 宛先コンテキストに描画するための、ソース画像のサブ矩形の左上隅の X 座標。 |
| sy | Double | 宛先コンテキストに描画するための、ソース画像のサブ矩形の左上隅の Y 座標。 |
| sw | Double | 宛先コンテキストに描画するための、ソース画像のサブ矩形の幅。指定しない場合、sx と sy で指定された座標から画像の右下隅までの全矩形が使用されます。 |
| sh | Double | 宛先コンテキストに描画するための、ソース画像のサブ矩形の高さ。 |
| dx | Double | ソース画像の左上隅を配置するための、宛先キャンバス上の X 座標。 |
| dy | Double | ソース画像の左上隅を配置するための、宛先キャンバス上の Y 座標。 |
| dw | Double | 宛先キャンバスに画像を描画する幅。これにより描画された画像のスケーリングが可能です。指定しない場合、描画時に幅はスケーリングされません。 |
| dh | Double | 宛先キャンバスに画像を描画する高さ。これにより描画された画像のスケーリングが可能です。指定しない場合、描画時に高さはスケーリングされません。 |
