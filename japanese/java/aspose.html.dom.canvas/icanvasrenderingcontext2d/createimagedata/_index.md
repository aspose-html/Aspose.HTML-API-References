## CreateImageData(double, double) {#createimagedata_1}

指定された寸法で新しい空の ImageData オブジェクトを作成します。新しいオブジェクトのすべてのピクセルは透明な黒です。

```java
public IImageData CreateImageData(double sw, double sh)
```

| Parameter | Type | 説明 |
| --- | --- | --- |
| sw | Double | 新しい ImageData オブジェクトに設定する幅です。 |
| sh | Double | 新しい ImageData オブジェクトに設定する高さです。 |

### 戻り値

指定された幅と高さを持つ新しい ImageData オブジェクトです。新しいオブジェクトは透明な黒色ピクセルで埋められます。

## CreateImageData(IImageData) {#createimagedata}

```java
public IImageData CreateImageData(IImageData imagedata)
```

| Parameter | Type | 説明 |
| --- | --- | --- |
| imagedata | IImageData | 幅と高さをコピーするための既存の ImageData オブジェクトです。画像自体はコピーされません。 |
