## ICanvasRenderingContext2D.ClearRect method

開始点 (x, y) とサイズ (width, height) で定義された矩形内のすべてのピクセルを透明な黒に設定し、以前に描画された内容を消去します。

```java
public void ClearRect(double x, double y, double w, double h)
```

| Parameter | Type | 説明 |
| --- | --- | --- |
| x | Double | 矩形の開始点の座標の x 軸。 |
| y | Double | 矩形の開始点の座標の y 軸。 |
| w | Double | 矩形の幅。 |
| h | Double | 矩形の高さ。 |
