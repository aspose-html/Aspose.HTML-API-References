## IImageData interface

指定された Uint8ClampedArray とその画像サイズから ImageData オブジェクトを作成します。配列が指定されない場合は、黒い矩形の画像を作成します。

```java
public interface IImageData
```

## プロパティ

| 名前 | 説明 |
| --- | --- |
| [getData](../../com.aspose.html.dom.canvas/iimagedata/data/) は、RGBA の順序でデータを含む一次元配列を表す Uint8ClampedArray で、整数値は 0 から 255（含む）です。 |
| [getHeight](../../com.aspose.html.dom.canvas/iimagedata/height/) は、ImageData の実際の高さ（ピクセル単位）を表す符号なし長整数です。 |
| [getWidth](../../com.aspose.html.dom.canvas/iimagedata/width/) は、ImageData の実際の幅（ピクセル単位）を表す符号なし長整数です。 |
