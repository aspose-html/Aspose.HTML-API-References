## Location class

Location オブジェクトは、ドキュメントの閲覧コンテキストにおけるアクティブドキュメントのアドレスを表現し、履歴オブジェクトにエントリを追加または置換することで、閲覧コンテキストのセッション履歴の現在のエントリを変更できるようにします。

```java
public sealed class Location : DOMObject
```
