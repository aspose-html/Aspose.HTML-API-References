## IWindow.Prompt method

指定されたメッセージでモーダルのテキストフィールドプロンプトを表示し、ユーザーが閉じるまで待機し、ユーザーが入力した値を返します。ユーザーがキャンセルした場合は null を返します。第2引数が指定されている場合、その値がデフォルトとして使用されます。

```java
public String Prompt(String message, String @default)
```

| Parameter | Type | 説明 |
| --- | --- | --- |
| message | 文字列 | メッセージです。 |
| デフォルト | 文字列 | デフォルトです。 |

### 戻り値

ユーザーが入力した値を返します
