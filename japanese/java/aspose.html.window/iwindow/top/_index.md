## IWindow.Top property

top IDL 属性は、文書の Window オブジェクト上で、閲覧コンテキスト b のトップレベル閲覧コンテキストの WindowProxy オブジェクトを返す必要があります（それがトップレベル閲覧コンテキスト自身であればその自分自身の WindowProxy オブジェクトです）。もしそれが存在すればそれを、そうでなければ（例：分離された入れ子閲覧コンテキストの場合）自分自身の WindowProxy オブジェクトを返します。

```java
public IWindow Top { get; }
```
