## IWindow.Top property

ブラウジングコンテキスト b の Document の Window オブジェクト上の top IDL 属性は、そのトップレベルブラウジングコンテキストの WindowProxy オブジェクト（それがトップレベルブラウジングコンテキスト自身であれば自分自身の WindowProxy オブジェクト）を返す必要があります。存在すればそれを、存在しなければ自分自身の WindowProxy オブジェクトを返します（例：分離されたネストされたブラウジングコンテキストの場合）。

```java
public IWindow Top { get; }
```
