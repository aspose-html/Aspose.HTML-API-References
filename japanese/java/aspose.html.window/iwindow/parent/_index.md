## IWindow.Parent property

閲覧コンテキスト b 内の Document の Window オブジェクトにある parent IDL 属性は、親閲覧コンテキストが存在する場合（すなわち b が子閲覧コンテキストである場合）にはその親閲覧コンテキストの WindowProxy オブジェクトを、そうでない場合（すなわちトップレベルの閲覧コンテキストまたは分離された入れ子閲覧コンテキストである場合）には b 自身の閲覧コンテキストの WindowProxy オブジェクトを返します。

```java
public IWindow Parent { get; }
```
