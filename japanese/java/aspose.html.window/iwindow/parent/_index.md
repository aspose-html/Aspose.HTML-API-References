## IWindow.Parent property

閲覧コンテキスト b の Document の Window オブジェクト上の parent IDL 属性は、親閲覧コンテキストが存在する場合（すなわち b が子閲覧コンテキストである場合）にはその親閲覧コンテキストの WindowProxy オブジェクトを、存在しない場合（すなわちトップレベル閲覧コンテキストまたは分離された入れ子閲覧コンテキストである場合）には b 自身の閲覧コンテキストの WindowProxy オブジェクトを返さなければなりません。

```java
public IWindow Parent { get; }
```
