## Attr.LocalName property

このノードの修飾名のローカル部分を返します。ELEMENT_NODE および ATTRIBUTE_NODE 以外のタイプのノードや、Document.createElement() のような DOM Level 1 メソッドで作成されたノードの場合、常に null です。

```java
public String LocalName { get; }
```

### Property Value

ローカル名です。
