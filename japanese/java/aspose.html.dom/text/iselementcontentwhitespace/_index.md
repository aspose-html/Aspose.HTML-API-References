## Text.IsElementContentWhitespace property

このテキストノードが要素コンテンツの空白を含むかどうかを返します。しばしば「無視可能な空白」と呼ばれます。

```java
public bool IsElementContentWhitespace { get; }
```

### Property Value

`true` はこのインスタンスが要素コンテンツの空白である場合、そうでなければ `false` です。
