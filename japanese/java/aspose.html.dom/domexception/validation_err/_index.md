## DOMException.VALIDATION_ERR field

insertBefore や removeChild などのメソッド呼び出しが「部分的有効性」に関してノードを無効にする可能性がある場合、この例外がスローされ、操作は実行されません。このコードは [DOM Level 3 Validation] で使用されています。詳細はこの仕様を参照してください。

```java
public const ushort VALIDATION_ERR;
```
