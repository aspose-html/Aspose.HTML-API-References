## ProcessingInstruction.TextContent property

この属性は、このノードとその子孫のテキストコンテンツを返します。null に設定されている場合、設定しても効果はありません。設定すると、このノードが持つ可能性のあるすべての子ノードが削除され、かつ新しい文字列が空でなく null でもない場合は、その文字列を含む単一の Text ノードに置き換えられます。

```java
public String TextContent { get; set; }
```

### Property Value

テキストの内容。
