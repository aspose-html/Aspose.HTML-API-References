## Document.XmlStandalone property

XML 宣言の一部として、このドキュメントがスタンドアロンかどうかを指定する属性です。指定されていない場合は false です。

```java
public bool XmlStandalone { get; set; }
```

### Property Value

`true` は XML がスタンドアロンの場合、そうでなければ `false` です。
