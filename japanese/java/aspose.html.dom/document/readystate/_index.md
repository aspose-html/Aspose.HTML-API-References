## Document.ReadyState property

ドキュメントの準備状態を返します。Document が読み込み中のときは "loading"、解析が完了しサブリソースの読み込みが続くときは "interactive"、そして読み込みが完了したときは "complete" です。

```java
public String ReadyState { get; }
```
