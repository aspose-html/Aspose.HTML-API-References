## Document.StrictErrorChecking property

エラーチェックが強制されるかどうかを指定する属性です。false に設定すると、実装は通常 DOM 操作で定義されているすべてのエラーケースをテストせず、Document.normalizeDocument() を使用中に DOMException を発生させず、エラーを報告しない自由があります。エラーが発生した場合の動作は未定義です。この属性はデフォルトで true です。

```java
public bool StrictErrorChecking { get; set; }
```

### Property Value

`true` は厳格なエラーチェックが有効な場合、そうでなければ `false` です。
