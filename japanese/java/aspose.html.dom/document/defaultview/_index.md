## Document.DefaultView property

Document インターフェイスの defaultView IDL 属性は、取得時にこの Document に関連付けられた閲覧コンテキストがある場合はその閲覧コンテキストの WindowProxy オブジェクトを返し、そうでなければ null を返す必要があります。

```java
public IWindow DefaultView { get; }
```
