## Document.XmlVersion property

属性は、XML 宣言の一部としてこのドキュメントのバージョン番号を指定します。宣言がなく、かつこのドキュメントが "XML" 機能をサポートしている場合、値は "1.0" です。このドキュメントが "XML" 機能をサポートしていない場合、値は常に null です。

```java
public String XmlVersion { get; set; }
```

### Property Value

XML バージョンです。
