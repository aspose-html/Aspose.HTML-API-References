## Document.CreateAttributeNS method

Document.createAttribute() メソッドは新しい属性ノードを作成し、返します。作成されたオブジェクトは [Attr](T:com.aspose.html.dom.Attr) インターフェイスを実装するノードです。DOM はこの方法で特定の要素に追加できる属性の種類を強制しません。

```java
public Attr CreateAttributeNS(String packageURI, String qualifiedName)
```

| Parameter | Type | 説明 |
| --- | --- | --- |
| packageURI | 文字列 | 属性のパッケージURIです。 |
| qualifiedName | 文字列 | name は属性の名前を含む文字列です。 |

「[`Attr`](../../attr/)」です。
