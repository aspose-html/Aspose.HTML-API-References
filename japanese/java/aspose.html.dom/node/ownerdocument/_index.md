## Node.OwnerDocument property

Node インターフェイスの読み取り専用 ownerDocument プロパティは、ノードの最上位ドキュメントオブジェクトを返します。

```java
public Document OwnerDocument { get; }
```

### Property Value

すべての子ノードが作成される最上位オブジェクトである [`Document`](../../document/)。

このプロパティがドキュメント自体であるノードに使用された場合、値は null です。
