## Node.IsEqualNode method

`[`Node`](../)` インターフェイスの isEqualNode() メソッドは、2 つのノードが等しいかどうかをテストします。ノードが等しいとは、同じタイプであり、定義特性（要素の場合は ID、子ノード数など）が同じで、属性が一致するなどの条件を満たすことを意味します。必要となるデータ項目の具体的なセットは、ノードのタイプに応じて異なります。

```java
public bool IsEqualNode(Node otherNode)
```

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| otherNode | Node | 等価性を比較する対象の `[`Node`](../)` です。 |

### 戻り値

2 つのノードが等しい場合は true、そうでない場合は false となるブール値です。otherNode が null の場合、isEqualNode() は常に false を返します。
