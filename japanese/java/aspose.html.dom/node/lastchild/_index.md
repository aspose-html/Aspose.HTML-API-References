## Node.LastChild property

[`Node`](../) インターフェイスの読み取り専用 lastChild プロパティはノードの最後の子ノードを返します。親が要素である場合、子は通常、要素ノード、テキストノード、またはコメントノードです。子要素が存在しない場合は null を返します。

```java
public Node LastChild { get; }
```

### Property Value

ノードの最後の子である [`Node`](../) 、子要素がない場合は null です。
