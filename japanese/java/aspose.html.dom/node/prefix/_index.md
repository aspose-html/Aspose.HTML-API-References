## Node.Prefix property

prefix 読み取り専用プロパティは、指定された要素のパッケージプレフィックスを返し、プレフィックスが指定されていない場合は null を返します。

```java
public String Prefix { get; set; }
```

### Property Value

このプロパティは関連付けられたパッケージプレフィックスを返します。
