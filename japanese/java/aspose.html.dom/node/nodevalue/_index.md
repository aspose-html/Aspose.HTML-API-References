## Node.NodeValue property

[`Node `](../) インターフェイスの nodeValue プロパティは現在のノードの値を取得または設定します。

```java
public String NodeValue { get; set; }
```

### Property Value

現在のノードの値（存在する場合）を含む文字列です。ドキュメント自体の場合、nodeValue は null を返します。テキスト、コメント、CDATA ノードの場合、nodeValue はノードの内容を返します。属性ノードの場合、属性の値が返されます。
