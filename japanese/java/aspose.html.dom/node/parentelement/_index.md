## Node.ParentElement property

[`Node`](../) インターフェイスの読み取り専用 parentElement プロパティは、DOM ノードの親 [`Element`](../../element/) を返し、ノードに親がない、またはその親が DOM Element でない場合は null を返します。

```java
public Element ParentElement { get; }
```

### Property Value

現在のノードの親要素である [`Element`](../../element/)、存在しない場合は null。
