## Node.LocalName property

このノードの修飾名のローカル部分を返します。[`ELEMENT_NODE`](../element_node/) および [`ATTRIBUTE_NODE`](../attribute_node/) 以外のタイプのノードや、[`Document.createElement()`](../../document/createelement/) のような DOM Level 1 メソッドで作成されたノードの場合、常に null が返されます。

```java
public String LocalName { get; }
```

### Property Value

要素の修飾名のローカル部分を表す文字列。
