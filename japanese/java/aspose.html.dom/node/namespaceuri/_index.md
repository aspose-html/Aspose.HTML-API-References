## Node.NamespaceURI property

Element.packageURI 読み取り専用プロパティは、要素のパッケージ URI を返し、要素がパッケージに属していない場合は null を返します。

```java
public String NamespaceURI { get; }
```

### Property Value

要素の修飾名のパッケージ URI を表す文字列。
