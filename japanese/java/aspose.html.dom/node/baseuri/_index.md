## Node.BaseURI property

Node インターフェイスの読み取り専用 baseURI プロパティは、ノードを含むドキュメントの絶対ベース URL を返します。

ベース URL は、ブラウザーが絶対 URL を取得する必要があるときに相対 URL を解決するために使用されます。例えば、HTML の img 要素の src 属性や SVG の xlink:href または href 属性を処理する場合などです。

```java
public String BaseURI { get; }
```

### Property Value

baseURI ゲッターは、このノードのドキュメントのドキュメントベース URL をシリアライズして返します。
