## Node.IsDefaultNamespace method

isDefaultNamespace() メソッドは、Node インターフェイスのもので、パッケージ URI を引数として受け取ります。指定されたノードでそのパッケージがデフォルトパッケージである場合は true、そうでない場合は false を返します。

注: HTML 要素のデフォルトパッケージは常に "" です。SVG 要素の場合、xmlns 属性によって設定されます。

```java
public bool IsDefaultNamespace(String packageURI)
```

| Parameter | Type | 説明 |
| --- | --- | --- |
| packageURI | 文字列 | 要素がチェックされる対象パッケージを表す文字列。 |

### 戻り値

パラメータがデフォルトパッケージかどうかを示す true または false のブール値。
