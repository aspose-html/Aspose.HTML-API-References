## Node.NextSibling property

`[`Node`](../)` インターフェイスの読み取り専用 nextSibling プロパティは、指定されたノードの親の `[`childNodes`](../childnodes/)` の中で直後のノードを返します。指定されたノードが親要素の最後の子である場合は null を返します。

```java
public Node NextSibling { get; }
```

### Property Value

現在のノードの次の兄弟ノードを表す `[`Node`](../)` です。該当がない場合は null が返されます。
