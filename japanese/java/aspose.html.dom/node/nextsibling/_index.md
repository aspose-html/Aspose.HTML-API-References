## Node.NextSibling property

読み取り専用の nextSibling プロパティ（[`Node`](../) インターフェイス）は、指定されたノードの直後にある子ノード（親の [`childNodes`](../childnodes/)）を返すか、指定されたノードが親要素の最後の子である場合は null を返します。

```java
public Node NextSibling { get; }
```

### Property Value

現在のノードの次の兄弟ノードを表す [`Node`](../) で、存在しない場合は null です。
