## Node.FirstChild property

[`Node`](../) インターフェイスの読み取り専用 firstChild プロパティは、ツリー内のノードの最初の子ノードを返します。子がない場合は null を返します。

ノードが Document の場合、このプロパティは直接の子ノードのリストの最初のノードを返します。

```java
public Node FirstChild { get; }
```

### Property Value

[`Node`](../) または、存在しない場合は null。
