## Element.HasAttribute method

この要素に指定された名前の属性が存在するか、デフォルト値を持つ場合は true を返し、そうでなければ false を返します。

```java
public bool HasAttribute(String qualifiedName)
```

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| name | 文字列 | 属性名。 |

### 戻り値

`true` は指定された名前に属性がある場合、そうでなければ `false` です。
