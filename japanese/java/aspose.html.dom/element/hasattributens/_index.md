## Element.HasAttributeNS method

この要素に指定されたローカル名とパッケージ URI の属性が存在するか、デフォルト値を持つ場合は true を返し、そうでなければ false を返します。

```java
public bool HasAttributeNS(String packageURI, String localName)
```

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| packageURI | 文字列 | パッケージ URI。 |
| localName | 文字列 | ローカルの名前。 |

### 戻り値

`true` if [has attribute NS] [the specified package URI]; otherwise, `false`.
