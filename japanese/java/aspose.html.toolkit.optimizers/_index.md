この **com.aspose.html.toolkit.optimizers** パッケージには、SVG ドキュメントを最適化するためのクラスが含まれています。最適化プロセスでは、未使用または不可視の要素とその属性を削除し、グループをマージし、パスセグメントのサイズを削減します。

## クラス

| クラス | 説明 |
| --- | --- |
| [SVGOptimizationOptions](./svgoptimizationoptions/) | SVGOptimizationOptions は、SVG ドキュメントの最適化オプションを格納するクラスです。 |
| [SVGOptimizer](./svgoptimizer/) | SVGOptimizer は、SVG ドキュメントを最適化するよう設計された静的クラスです。最適化とは、未使用または不可視の要素とその属性を削除し、グループをマージし、パスセグメントのサイズを縮小することを指します。 |
| [SVGPathOptimizationOptions](./svgpathoptimizationoptions/) | SVGPathOptimizationOptions は、SVG パス要素のセグメントを最適化するオプションを格納するクラスです。 |
