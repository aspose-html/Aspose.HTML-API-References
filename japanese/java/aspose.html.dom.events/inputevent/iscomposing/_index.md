## InputEvent.IsComposing property

入力イベントが合成セッションの一部として発生した場合は `true`（すなわち、compositionstart イベントの後、対応する compositionend イベントの前）。この属性の未初期化値は必ず `false` でなければなりません。

```java
public bool IsComposing { get; }
```

### Property Value

`true` であればこのインスタンスは合成中です。そうでなければ `false`。
