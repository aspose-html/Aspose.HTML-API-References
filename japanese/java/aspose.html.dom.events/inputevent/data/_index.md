## InputEvent.Data property

data は、入力メソッドによって生成された文字の値を保持します。これは単一の Unicode 文字または空でない Unicode 文字列 [Unicode] になる可能性があります。文字は [UAX15] で定義された Unicode 正規化形式 NFC に従って正規化すべきです。この属性は空文字列を含む可能性があります。

public String Data { get; }
