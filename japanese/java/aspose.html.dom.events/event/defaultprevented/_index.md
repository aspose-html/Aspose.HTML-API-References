## Event.DefaultPrevented property

cancelable 属性が true のときに preventDefault() が呼び出された場合は true を返し、そうでなければ false を返します。

```java
public bool DefaultPrevented { get; }
```

### Property Value

`true` は [default prevented] の場合、そうでなければ `false`。
