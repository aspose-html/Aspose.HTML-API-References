## Event.IsTrusted property

isTrusted 属性は初期化された値を返す必要があります。イベントが作成されるとき、属性は false に初期化されなければなりません。

```java
public bool IsTrusted { get; }
```

### Property Value

`true` はこのインスタンスが信頼できる場合、そうでなければ `false`。
