## KeyboardEvent.AltKey property

Alt (alternative)（または \"Option\"）キー修飾子がアクティブな場合は true。 この属性の初期化されていない値は false でなければなりません。

```java
public bool AltKey { get; }
```

### Property Value

`true` は Alt の場合、そうでなければ `false`。
