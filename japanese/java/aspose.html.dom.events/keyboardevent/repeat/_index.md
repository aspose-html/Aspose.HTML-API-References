## KeyboardEvent.Repeat property

キーが長押しされた場合は true です。キーを押し続けると、システム設定で決定されたレートで、keydown、beforeinput、input の順にイベントが繰り返されなければなりません。長押し動作を持つモバイルデバイスでは、repeat 属性が true の最初のキーイベントは長押しの指標として扱われます。繰り返しが開始されるまでにキーを押し続ける必要がある時間は設定に依存します。

```java
public bool Repeat { get; }
```

### Property Value

`true` はリピートの場合、そうでなければ `false`。
