## KeyboardEvent.Code property

code は、押された物理キーを識別する文字列を保持します。その値は現在のキーボードレイアウトや修飾子の状態の影響を受けず、特定のキーは常に同じ値を返します。

```java
public String Code { get; }
```

### Property Value

キーコードです。
