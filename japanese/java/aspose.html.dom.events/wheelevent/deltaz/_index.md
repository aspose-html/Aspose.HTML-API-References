## WheelEvent.DeltaZ property

デフォルトのホイールイベントのアクションがスクロールであるユーザーエージェントでは、値はキャンセルされていない場合にスクロールされる z 軸方向の測定値（ピクセル、行、またはページ）でなければなりません。それ以外の場合、これは z 軸周りのホイールデバイスの動きの実装固有の測定値（ピクセル、行、またはページ）です。

```java
public double DeltaZ { get; }
```
