## WheelEvent.DeltaZ property

ホイールイベントのデフォルトアクションがスクロールであるユーザーエージェントでは、イベントがキャンセルされていない場合、値は z 軸に沿った測定値（ピクセル、行、またはページ単位）でなければなりません。そうでない場合、これは z 軸周りのホイールデバイスの動きをピクセル、行、またはページ単位で示す実装固有の測定値です。

```java
public double DeltaZ { get; }
```

### Property Value

deltaZ 属性です。
