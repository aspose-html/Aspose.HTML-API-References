## ErrorEvent.LineNo property

lineno 属性は初期化された値を返す必要があります。オブジェクトが作成されると、この属性は 0 に初期化されます。これはスクリプト内でエラーが発生した行番号を表します。

```java
public uint LineNo { get; }
```
