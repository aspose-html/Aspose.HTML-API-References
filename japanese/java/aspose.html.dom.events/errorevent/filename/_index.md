## ErrorEvent.FileName property

filename 属性は初期化された値を返す必要があります。オブジェクトが作成されると、この属性は空文字列に初期化されます。これはエラーが最初に発生したスクリプトの絶対 URL を表します。

```java
public String FileName { get; }
```

### Property Value

ファイル名です。
