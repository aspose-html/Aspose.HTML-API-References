## Converter class

最も一般的な変換シナリオ向けの共有ファサードです。PDF、XPS、画像フォーマットなどの一般的なフォーマットへの幅広い変換を提供します。より具体的な変換（レンダリング、保存）ユースケースは、よく知られた文書化された低レベル API 関数によって提供されます。

より詳細な変換固有情報は、[Aspose Documentation](https://docs.aspose.com/html/net/converting-between-formats/) で取得できます。

```java
public static class Converter
```
