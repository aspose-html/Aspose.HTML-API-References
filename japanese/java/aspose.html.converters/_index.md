The **com.aspose.html.converters** パッケージの目的は、変換メソッドへの簡単なアクセスを提供することです。PDF、XPS、画像形式などの一般的なフォーマットへの幅広い変換を提供します。より具体的な変換（レンダリング、保存）に関するユースケースは、対象別パッケージにあるよく知られた文書化された低レベル API 関数で提示されています。

## クラス

| クラス | 説明 |
| --- | --- |
| [Converter](./converter/) | 最も一般的な変換シナリオ向けの共有ファサードです。PDF、XPS、画像フォーマットなどの一般的なフォーマットへの幅広い変換を提供します。より具体的な変換（レンダリング、保存）ユースケースは、よく知られた文書化された低レベル API 関数によって提供されます。 |
| [TemplateContentOptions](./templatecontentoptions/) | マージ処理用のインラインコンテンツオブジェクトです。 |
| [TemplateData](./templatedata/) | マージ（ユーザー）データオブジェクトです。 |
## 列挙型

| 列挙型 | 説明 |
| --- | --- |
| [TemplateContent](./templatecontent/) | コンテンツタイプ識別子です。 |
