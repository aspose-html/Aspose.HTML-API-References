**com.aspose.html.accessibility.results** パッケージには、ルール検証の結果を記述するクラスが含まれています。

## クラス

| クラス | 説明 |
| --- | --- |
| [RuleValidationResult](./rulevalidationresult/) | クラス - ルールチェックの結果で、成功基準を満たす方法である [`ITechniqueResult`](../com.aspose.html.accessibility/itechniqueresult/) のリストを含みます。 |
| [ValidationResult](./validationresult/) | AccessibilityRules オブジェクトからのすべての基準に対する結果を含むメインの結果クラスです。 |
