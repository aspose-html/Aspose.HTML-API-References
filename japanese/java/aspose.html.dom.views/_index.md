**com.aspose.html.dom.views** package describes AbstractView and DocumentView interfaces according Document Object Model Views specification.

## インターフェイス

| インターフェイス | 説明 |
| --- | --- |
| [IAbstractView](./iabstractview/) | すべてのビューが派生すべき基本インターフェイスです。 |
| [IDocumentView](./idocumentview/) | DocumentView インターフェイスは、DOM Views をサポートする DOM 実装の Document オブジェクトによって実装されます。ドキュメントのデフォルトビューを取得する属性を提供します。 |
