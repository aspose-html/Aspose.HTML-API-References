## IBlob.Slice method

オプションの start パラメーターからオプションの end パラメーター（end は含まない）までのバイト範囲を持ち、type 属性がオプションの contentType パラメーターの値である新しい Blob オブジェクトを返します。

```java
public IBlob Slice(ulong start, ulong end, String contentType)
```

| Parameter | Type | 説明 |
| --- | --- | --- |
| 開始 | UInt64 | このパラメータはスライスの開始位置を示す値です。 |
| 終了 | UInt64 | このパラメータはスライスの開始位置を示す値です。 |
| contentType | 文字列 | このパラメータは Blob のメディアタイプです。 |

### 戻り値

オプションの start パラメーターからオプションの end パラメーター（end は含まない）までのバイト範囲を持ち、type 属性がオプションの contentType パラメーターの値である新しい Blob オブジェクトを返します。
