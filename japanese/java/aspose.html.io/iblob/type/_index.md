## IBlob.Type property

Blob のメディアタイプを表す、ASCII エンコードされた小文字の文字列。取得時、ユーザーエージェントは Blob のタイプを ASCII エンコードされた小文字の文字列として返す必要があり、バイト列に変換したときに解析可能な MIME タイプであるか、タイプが判別できない場合は空文字列（0 バイト）を返します。

```java
public String Type { get; }
```
