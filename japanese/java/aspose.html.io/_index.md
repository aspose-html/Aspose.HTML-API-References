標準的な IO（入力出力）ツールに加えて、**com.aspose.html.io** パッケージにはヘルパークラスとインターフェイスが含まれています。

## クラス

| クラス | 説明 |
| --- | --- |
| [FileCreateStreamProvider](./filecreatestreamprovider/) | レンダリングデバイスにストリームを提供するための FileStream 実装を表します。 |
## インターフェイス

| インターフェイス | 説明 |
| --- | --- |
| [IBlob](./iblob/) | Blob オブジェクトはバイトシーケンスを指し、バイトシーケンスの総バイト数を示す size 属性と、バイトシーケンスのメディアタイプを表す小文字の ASCII エンコード文字列である type 属性を持ちます。 |
| [ICreateStreamProvider](./icreatestreamprovider/) | レンダリングデバイスにストリームを提供するクラスが実装できるインターフェイスを表します。 |
| [IFile](./ifile/) | File オブジェクトは name 属性（文字列）を持つ Blob オブジェクトです。コンストラクタを使用してウェブアプリケーション内で作成することも、基盤となる（OS）ファイルシステムのファイルからのバイトシーケンスへの参照であることもあります。 |
| [IFileList](./ifilelist/) | ファイルのリストを表すインターフェイスを表します。 |
