**com.aspose.html.rendering.pdf.encryption** パッケージには、パスワードや暗号化アルゴリズムなど、PDF 暗号化の詳細を記述するデータクラスが含まれています。

## クラス

| クラス | 説明 |
| --- | --- |
| [PdfEncryptionInfo](./pdfencryptioninfo/) | PDF 暗号化の詳細を含みます。 |
## 列挙型

| 列挙型 | 説明 |
| --- | --- |
| [PdfEncryptionAlgorithm](./pdfencryptionalgorithm/) | 暗号化モード列挙型。アルゴリズムと鍵長を使用して記述します。この列挙型は機能をさらに拡張できるように拡張されています。この列挙型は「Base-to-Core」パターンを実装しています。 |
| [PdfPermissions](./pdfpermissions/) | この列挙型は PDF に対するユーザーの権限を表します。 |
