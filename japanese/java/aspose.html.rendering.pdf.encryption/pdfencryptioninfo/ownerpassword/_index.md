## PdfEncryptionInfo.OwnerPassword property

所有者パスワードを取得または設定します。

```java
public String OwnerPassword { get; set; }
```

### Property Value

所有者パスワード。

## Remarks

正しい所有者パスワードで文書を開くと（ユーザーパスワードと同じでないと仮定）、文書への完全な（所有者）アクセスが可能になります。この無制限のアクセスには、文書のパスワードやアクセス権限を変更する機能が含まれます。
