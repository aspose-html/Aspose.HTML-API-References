## XPathResultType enumeration

これは、結果のタイプを示す符号なしショートです。特定の `type` が指定された場合、必要に応じて XPath の型変換を使用し、対応するタイプとして結果が返されます。

```java
public enum XPathResultType
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Any | `0` | このコードは特定の型を表しません。XPath 式の評価でこの型が生成されることはありません。この型が要求された場合、式の評価から自然に得られる型が返されます。`Any` 型が要求されたときに自然な結果がノード集合である場合、常に `UnorderedNodeIterator` が結果の型となります。ノード集合の他の表現は明示的に要求する必要があります。 |
| Number | `1` | 結果は [XPath 1.0] で定義された数値です。ドキュメントの変更は数値を無効にしませんが、再評価で同じ数値が得られない可能性があります。 |
| String | `2` | 結果は [XPath 1.0] で定義された文字列です。ドキュメントの変更は文字列を無効にしませんが、文字列が現在のドキュメントと一致しなくなる可能性があります。 |
| Boolean | `3` | 結果は [XPath 1.0] で定義されたブール値です。ドキュメントの変更はブール値を無効にしませんが、再評価で同じブール値が得られない可能性があります。 |
| UnorderedNodeIterator | `4` | 結果は [XPath 1.0] で定義されたノード集合で、反復的にアクセスされますが、特定の順序でノードが生成される保証はありません。ドキュメントの変更はイテレーションを無効にします。結果がノード集合で `Any`type が要求された場合に返されるデフォルトの型です。 |
| OrderedNodeIterator | `5` | 結果は [XPath 1.0] で定義されたノード集合で、反復的にアクセスされ、ドキュメント順序のノードが生成されます。ドキュメントの変更はイテレーションを無効にします。 |
| UnorderedNodeSnapshot | `6` | 結果は [XPath 1.0] で定義されたノード集合で、特定の順序でない可能性があるスナップショットリストとしてアクセスされます。ドキュメントの変更はスナップショットを無効にしませんが、再評価で同じスナップショットが得られない可能性があり、スナップショット内のノードが変更、移動、または削除されていることがあります。 |
| OrderedNodeSnapshot | `7` | 結果は [XPath 1.0] で定義されたノード集合で、元のドキュメント順序でスナップショットリストとしてアクセスされます。ドキュメントの変更はスナップショットを無効にしませんが、再評価で同じスナップショットが得られない可能性があり、スナップショット内のノードが変更、移動、または削除されていることがあります。 |
| AnyUnorderedNode | `8` | 結果は [XPath 1.0] で定義されたノード集合で、単一ノードとしてアクセスされます。ノード集合が空の場合は `null` になることがあります。ドキュメントの変更はノードを無効にしませんが、結果ノードが現在のドキュメントと一致しなくなる可能性があります。これは、実装が結果集合内の任意のノードを見つけた時点で停止できるため最適化を可能にする便利な機能です。実際の結果に複数のノードがある場合、返される単一ノードはドキュメント順序の最初のノードでないことがあります。 |
| FirstOrderedNode | `9` | 結果は [XPath 1.0] で定義されたノード集合で、単一ノードとしてアクセスされます。ノード集合が空の場合は `null` になることがあります。ドキュメントの変更はノードを無効にしませんが、結果ノードが現在のドキュメントと一致しなくなる可能性があります。これは、実装が結果集合のドキュメント順序で最初のノードを見つけた時点で停止できるため最適化を可能にする便利な機能です。実際の結果に複数のノードがある場合、返される単一ノードはドキュメント順序の最初のノードになります。 |
