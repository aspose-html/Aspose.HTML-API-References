## XPathResultType enumeration

この結果がどのタイプかを示す符号なしショートです。特定の `type` が指定された場合、必要に応じて XPath の型変換を使用し、対応するタイプとして結果が返されます。

```java
public enum XPathResultType
```

| --- | --- | --- |
| Any | `0` | このコードは特定の型を表しません。XPath 式の評価でこの型が生成されることはありません。この型が要求された場合、評価は式の評価から自然に得られる型を返します。`Any` 型が要求されたときに自然な結果がノード集合である場合、結果の型は常に `UnorderedNodeIterator` です。ノード集合の他の表現は明示的に要求する必要があります。 |
