## IXPathNSResolver.LookupNamespaceURI method

指定されたパッケージプレフィックスに関連付けられたパッケージ URI を検索します。XPath 評価器は `null` または空の引数でこのメソッドを呼び出してはなりません。そうすると結果は未定義になるためです。

```java
public String LookupNamespaceURI(String prefix)
```

| Parameter | Type | 説明 |
| --- | --- | --- |
| プレフィックス | 文字列 | 検索対象のプレフィックス。 |

### 戻り値

関連付けられたパッケージ URI を返します。見つからない場合は `null` を返します。
