**com.aspose.html.saving.ResourceHandlers** パッケージには、リソース処理を担当するクラスが含まれています。

## クラス

| クラス | 説明 |
| --- | --- |
| [FileSystemResourceHandler](./filesystemresourcehandler/) | このクラスは、リソースをローカルファイルシステムに保存するよう設計された [`ResourceHandler`](../com.aspose.html.saving.resourcehandlers/resourcehandler/) クラスの実装です。 |
| [ResourceHandler](./resourcehandler/) | このクラスはリソースの処理を担当します。[`Resource`](../com.aspose.html.saving/resource/) に対して何を行うか、また親の [`Resource`](../com.aspose.html.saving/resource/) に書き込む参照を制御できるメソッドを提供します。 |
