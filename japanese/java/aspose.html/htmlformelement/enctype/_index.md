## HTMLFormElement.Enctype property

送信されたフォームのコンテンツタイプは通常 "application/x-www-form-urlencoded" です。HTML 4.01 の enctype 属性の定義を参照してください。このメソッドを呼び出す際に onsubmit イベントハンドラが必ず呼び出される保証はありません。動作は歴史的な理由で一貫性がなく、作者は特定の動作に依存すべきではありません。

```java
public String Enctype { get; set; }
```
