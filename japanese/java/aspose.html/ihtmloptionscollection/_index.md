## IHTMLOptionsCollection interface

`HTMLOptionsCollection` は HTML の option 要素を表すノードのリストです。個々のノードは順序インデックスまたはノードの `name` または `id` 属性でアクセスできます。HTML DOM のコレクションはライブとみなされ、基になるドキュメントが変更されると自動的に更新されます。

また、[Document object Model (DOM) Level 2 HTML Specification](http://www.w3.org/TR/2003/REC-DOM-Level-2-HTML-20030109) を参照してください。@since DOM Level 2

```java
public interface IHTMLOptionsCollection : IEnumerable<Element>
```
