## HTMLDocument.Referrer property

このページにリンクしたページの URI [[IETF RFC 2396](http://www.ietf.org/rfc/rfc2396.txt)] を返します。 ユーザーがリンクを介さずに直接ページに移動した場合（例としてブックマーク経由）、値は空の String です。

```java
public String Referrer { get; }
```
