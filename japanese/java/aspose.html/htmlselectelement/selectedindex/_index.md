## HTMLSelectElement.SelectedIndex property

選択されたオプションの序数インデックス（0 から開始）。要素が選択されていない場合は -1 が返されます。複数のオプションが選択されている場合は、最初に選択されたオプションのインデックスが返されます。

```java
public int SelectedIndex { get; set; }
```
