## HTMLInputElement.DefaultValue property

要素の `type` 属性が "text"、"file"、または "password" の値を持つ場合、これは要素の HTML value 属性を表します。この属性の値は、インタラクティブなユーザーエージェントで対応するフォームコントロールの内容が変化しても変更されません。HTML 4.01 の value 属性の定義を参照してください。

```java
public String DefaultValue { get; set; }
```
