## HTMLInputElement.Files property

files IDL 属性はスクリプトが要素の選択されたファイルにアクセスできるようにします。取得時に IDL 属性が適用される場合、現在選択されているファイルを表す FileList オブジェクトを返す必要があります。選択されたファイルのリストが変わるまで同じオブジェクトを返さなければなりません。IDL 属性が適用されない場合は、代わりに null を返す必要があります。[FILEAPI]

```java
public IFileList Files { get; }
```
