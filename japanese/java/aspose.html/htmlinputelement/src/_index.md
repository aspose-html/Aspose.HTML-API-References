## HTMLInputElement.Src property

`type` 属性の値が "image" のとき、この属性はグラフィカルな送信ボタンを装飾するために使用される画像の場所を指定します。HTML 4.01 の src 属性の定義を参照してください。

```java
public String Src { get; set; }
```
