## HTMLInputElement.Checked property

要素の `type` 属性の値が "radio" または "checkbox" のとき、これはインタラクティブなユーザーエージェントにおけるフォームコントロールの現在の状態を表します。この属性を変更するとフォームコントロールの状態は変わりますが、INPUT 要素の HTML checked 属性の値は変わりません。`type` 属性の値が "radio" または "checkbox" の input 要素に対するクリックイベントの処理中に、実装によってはイベントがドキュメントにディスパッチされる前にこのプロパティの値が変更されることがあります。イベントの既定動作がキャンセルされた場合、プロパティの値は元の値に戻されることがあります。つまり、クリックイベントの処理中のこのプロパティの値は実装依存であることを意味します。

```java
public bool Checked { get; set; }
```
