## HTMLInputElement.Checked property

`type` 属性の値が "radio" または "checkbox" のとき、これはインタラクティブなユーザーエージェントにおけるフォームコントロールの現在の状態を表します。この属性を変更するとフォームコントロールの状態は変わりますが、INPUT 要素の HTML checked 属性の値は変わりません。`type` 属性が "radio" または "checkbox" の入力要素に対するクリックイベントの処理中に、実装によってはイベントが文書にディスパッチされる前にこのプロパティの値が変更されることがあります。イベントのデフォルトアクションがキャンセルされた場合、プロパティの値は元の値に戻されることがあります。つまり、クリックイベントの処理中におけるこのプロパティの値は実装依存です。

```java
public bool Checked { get; set; }
```
