## HTMLInputElement.DefaultChecked property

`type` が "radio" または "checkbox" の値を持つ場合、これは要素の HTML checked 属性を表します。この属性の値は、インタラクティブなユーザーエージェントで対応するフォームコントロールの状態が変化しても変わりません。HTML 4.01 の checked 属性の定義を参照してください。

```java
public bool DefaultChecked { get; set; }
```
