## HTMLHeadingElement class

`H1` から `H6` 要素について。HTML 4.01 の H1 要素定義を参照してください。

また、[Document object Model (DOM) Level 2 HTML Specification](http://www.w3.org/TR/2003/REC-DOM-Level-2-HTML-20030109) も参照してください。

```java
public class HTMLHeadingElement : HTMLElement
```
