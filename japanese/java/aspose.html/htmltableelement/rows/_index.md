## HTMLTableElement.Rows property

テーブルの `TFOOT` を返し、存在しない場合は `null` を返します。

テーブル内のすべての行のコレクションを返します。`THEAD`、`TFOOT`、すべての `TBODY` 要素を含みます。

```java
public HTMLCollection Rows { get; }
```
