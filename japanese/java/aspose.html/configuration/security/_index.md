## Configuration.Security property

構成のサンドボックス フラグを取得または設定します。[sandboxing](https://docs.aspose.com/html/net/working-with-documents/environment-configuration/#sandboxing) に関する記事をご参照ください。

```java
public Sandbox Security { get; set; }
```

### Property Value

セキュリティ。[`sandboxing flag`](../../sandbox/) セットは、0 個以上のフラグの集合であり、潜在的に信頼できないリソースの機能を制限するために使用されます。sandbox 属性を使用すると、フレームに読み込まれるコンテンツに対して、たとえばフォームやスクリプトをブロックするなど、さまざまな制限を設定できます。
