Aspose.Html パッケージには、[`HTML documents`](aspose.html/htmldocument/) を操作するためのクラスとメソッドが含まれており、シンプルなものから複雑なものまでリアルタイムで処理できます。Aspose.HTML for Java は、開発者が HTML ノードの挿入、削除、置換を行い、CSS スタイル情報を抽出し、[`HTML document`](aspose.html/htmldocument/) を [`NodeIterator`](aspose.html.dom.traversal/inodeiterator/) や [`TreeWalker`](aspose.html.dom.traversal/itreewalker/)（Traversal Specification、XPath、CSS セレクタ クエリによって提供）でナビゲートできるようにします。また、JavaScript を使用して HTML DOM を操作できるスクリプト機能も提供します。HTML に加えて、この API は EPUB と MHTML の読み込み機能も提供します。Aspose API はファイル形式間の変換機能で有名であり、この API も HTML ファイルを読み込み、PDF、XPS、JPEG、PNG、BMP、TIFF などのラスタ画像形式で出力をレンダリングする機能を提供します。
