## Uint8ClampedArray class

0〜255 にクランプされた 8 ビット符号なし整数の配列を表します。範囲外の値 [0,255] を指定した場合、代わりに 0 または 255 が設定されます。

```java
public class Uint8ClampedArray : TypedArray<byte>
```
