## HTMLCanvasElement.GetContext method

キャンバス上の描画コンテキストを返します。サポートされていないコンテキスト ID の場合は null が返ります。描画コンテキストを使用するとキャンバスに描画できます。

```java
public object GetContext(String contextId)
```

| Parameter | Type | 説明 |
| --- | --- | --- |
| contextId | 文字列 | キャンバスに関連付けられた描画コンテキストを定義するコンテキスト識別子を含む文字列です。 |

### 戻り値

RenderingContext
