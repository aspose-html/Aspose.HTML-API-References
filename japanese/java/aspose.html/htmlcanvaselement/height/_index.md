## HTMLCanvasElement.Height property

キャンバス要素の height HTML 属性を CSS ピクセルで解釈した正の整数です。属性が指定されていない場合、または負のような無効な値が設定されている場合は、デフォルト値の 150 が使用されます。

```java
public ulong Height { get; set; }
```
