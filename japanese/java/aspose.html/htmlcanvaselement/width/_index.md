## HTMLCanvasElement.Width property

キャンバス要素の width HTML 属性を CSS ピクセルで解釈した正の整数です。属性が指定されていない場合、または負のような無効な値が設定されている場合は、デフォルト値の 300 が使用されます。

```java
public ulong Width { get; set; }
```
