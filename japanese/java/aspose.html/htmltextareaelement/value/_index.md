## HTMLTextAreaElement.Value property

インタラクティブなユーザーエージェントにおける対応するフォームコントロールの現在の内容を表します。この属性を変更するとフォームコントロールの内容は変わりますが、要素の内容は変わりません。データ全体が単一の `DOMString` に収まらない場合、実装はデータを切り捨てることがあります。

```java
public String Value { get; set; }
```
