## ITrueTypeFont.FullFontName property

これは "FamilyName" と "SubFamilyName" の組み合わせである必要があります。例外として、"SubFamilyName" に "Regular" と示されているフォントの場合は、"FamilyName" に含まれるファミリ名のみを使用してください。上記の Full フォント名の定義に対する例外として、Microsoft プラットフォームの CFF OpenType フォント用文字列の場合、Full フォント名文字列は CFF Name INDEX の PostScript FontName と同一でなければなりません。

```java
public String FullFontName { get; }
```
