The **com.aspose.html.dom.attributes** パッケージには、任意のオブジェクト（ノード、要素など）の機能や動作を指定または限定する統一属性クラスが含まれています。

## クラス

| クラス | 説明 |
| --- | --- |
| [DOMConstructorAttribute](./domconstructorattribute/) | W3C によって定義されたコンストラクタを指定します。 |
| [DOMNameAttribute](./domnameattribute/) | W3C によって定義された公式 DOM オブジェクト名を指定します。 |
| [DOMNamedPropertyGetterAttribute](./domnamedpropertygetterattribute/) | このメソッドが名前付きプロパティのゲッターとして使用されることを指定します。 |
| [DOMNoInterfaceObjectAttribute](./domnointerfaceobjectattribute/) | [NoInterfaceObject] 拡張属性がインターフェイスに現れる場合、ECMAScript バインディングにおいてそのインターフェイスのオブジェクトが存在しないことを示します。 |
| [DOMNullableAttribute](./domnullableattribute/) | DOM オブジェクトに null 値を割り当てられることを指定します。 |
| [DOMObjectAttribute](./domobjectattribute/) | この属性でマークされたオブジェクトが W3C によって定義されていることを指定します。 |
| [DOMTreatNullAsAttribute](./domtreatnullasattribute/) | メンバー値が null の場合、指定された値として扱われることを示します。 |
## 列挙型

| 列挙型 | 説明 |
| --- | --- |
| [Accessors](./accessors/) | W3C によって定義されたメンバーアクセサの列挙を表します。 |
