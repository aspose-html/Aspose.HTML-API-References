## ITreeWalker.FirstChild method

TreeWalker を現在のノードの最初の可視子ノードに移動し、新しいノードを返します。現在のノードに可視子ノードがない場合は null を返し、現在のノードを保持します。

```java
public Node FirstChild()
```

### 戻り値

TreeWalker の論理ビューで現在のノードに表示可能な子がない場合は、新しいノード、または null が返されます。
