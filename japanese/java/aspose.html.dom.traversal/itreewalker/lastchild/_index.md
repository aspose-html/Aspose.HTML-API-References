## ITreeWalker.LastChild method

TreeWalker を現在のノードの最後の可視子ノードへ移動し、新しいノードを返します。現在のノードに可視子がない場合は null を返し、現在のノードを保持します。

```java
public Node LastChild()
```

### 戻り値

新しいノード、または TreeWalker の論理ビューで現在のノードに子ノードがない場合は null。
