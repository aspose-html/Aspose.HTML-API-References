## INodeIterator.Detach method

NodeIterator を反復していたセットから切り離し、計算リソースを解放してイテレータを INVALID 状態にします。detach が呼び出された後は、nextNode または previousNode の呼び出しは例外 INVALID_STATE_ERR を送出します。
