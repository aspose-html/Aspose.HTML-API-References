## INodeIterator.Detach method

NodeIterator をイテレートしたセットから切り離し、計算リソースを解放してイテレータを INVALID 状態にします。detach が呼び出された後、nextNode または previousNode を呼び出すと例外 INVALID_STATE_ERR が発生します。
