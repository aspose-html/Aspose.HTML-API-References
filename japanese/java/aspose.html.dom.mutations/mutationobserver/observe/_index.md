## Observe(Node) {#observe}

ユーザーエージェントに対し、指定されたターゲット（ノード）を観測し、options（オブジェクト）で指定された基準に基づいて変異を報告するよう指示します。options 引数はオブジェクトのメンバーを通じて変異観測オプションを設定できるようにします。

```java
public void Observe(Node target)
```

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| target | Node | observe の対象。 |
