## Observe(Node) {#observe}

ユーザーエージェントに指定されたターゲット（ノード）を観測させ、options（オブジェクト）で指定された基準に基づいて変異を報告させます。options 引数はオブジェクトのメンバーを通じて変異観測オプションを設定できるようにします。

```java
public void Observe(Node target)
```

| --- | --- | --- |
| ターゲット | Node | observe の対象。 |
