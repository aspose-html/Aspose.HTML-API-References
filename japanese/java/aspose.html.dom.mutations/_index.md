**com.aspose.html.dom.mutations** は、DOM の変異を観測し、特定のコールバック情報を取得する機会を提供します。

## クラス

| クラス | 説明 |
| --- | --- |
| [MutationCallback](./mutationcallback/) | 変異イベントを処理するメソッドを表します。 |
| [MutationObserver](./mutationobserver/) | オブジェクトは、[`.`](../com.aspose.html.dom/node/) のツリーへの変異を観測するために使用できます。 |
| [MutationObserverInit](./mutationobserverinit/) | このクラスは、[`MutationObserver`](../com.aspose.html.dom.mutations/mutationobserver/) を構成するために使用されるオプションコレクションを表します。 |
| [MutationRecord](./mutationrecord/) | MutationRecord は個々の DOM 変異を表します。これは、[`MutationObserver`](../com.aspose.html.dom.mutations/mutationobserver/) の [`MutationCallback`](../com.aspose.html.dom.mutations/mutationcallback/) に渡されるオブジェクトです。 |
