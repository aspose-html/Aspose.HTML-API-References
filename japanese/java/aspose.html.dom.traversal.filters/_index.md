ノードフィルタリング機能を表すパッケージです。フィルタはノードを「除外」する方法を知っているオブジェクトです。ノードイテレータまたはツリーワーカーにノードフィルタが与えられると、次のノードを返す前にフィルタを適用します。フィルタがノードを受け入れると言えば、走査ロジックはそれを返します。そうでなければ、走査は次のノードを探し、拒否されたノードが存在しなかったかのように振る舞います。
