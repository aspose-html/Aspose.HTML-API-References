## NodeFilter.FILTER_SKIP field

この単一ノードをスキップする。NodeIterator または TreeWalker 用に定義されたナビゲーションメソッドはこのノードを返しません。NodeIterator と TreeWalker の両方で、このノードの子ノードは引き続き考慮されます。

```java
public const short FILTER_SKIP;
```
