## NodeFilter.SHOW_ENTITY field

エンティティノードを表示します。これはエンティティノードをルートとするイテレータまたはツリーワーカーを作成する場合にのみ意味があります。この場合、エンティティノードがトラバーサルの最初の位置に表示されます。エンティティはドキュメントツリーの一部ではないため、ドキュメントツリーを走査するときに表示されません。

```java
public const long SHOW_ENTITY;
```
