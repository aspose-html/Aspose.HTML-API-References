## NodeFilter.SHOW_ATTRIBUTE field

属性ノードを表示する。これは属性ノードをルートとするイテレータまたはツリーワーカーを作成する場合にのみ意味があります。この場合、属性ノードがイテレーションまたはトラバーサルの最初の位置に表示されます。属性は他のノードの子になることがないため、ドキュメントツリーを走査するときに表示されません。

```java
public const long SHOW_ATTRIBUTE;
```
