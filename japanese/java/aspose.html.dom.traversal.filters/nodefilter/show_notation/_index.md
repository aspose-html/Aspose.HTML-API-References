## NodeFilter.SHOW_NOTATION field

Notation ノードを表示します。これは、Notation ノードをルートとするイテレータまたはツリーワーカーを作成する場合にのみ意味があります。その場合、Traversal の最初の位置に Notation ノードが現れます。Notation は文書ツリーの一部ではないため、文書ツリーを走査しても表示されません。

```java
public const long SHOW_NOTATION;
```
