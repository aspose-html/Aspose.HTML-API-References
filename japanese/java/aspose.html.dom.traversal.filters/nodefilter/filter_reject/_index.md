## NodeFilter.FILTER_REJECT field

ノードを拒否する。NodeIterator または TreeWalker 用に定義されたナビゲーションメソッドはこのノードを返しません。TreeWalker の場合、このノードの子ノードも拒否されます。NodeIterators はこれを FILTER_SKIP の同義語として扱います。

```java
public const short FILTER_REJECT;
```
