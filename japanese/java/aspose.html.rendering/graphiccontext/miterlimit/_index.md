## GraphicContext.MiterLimit property

ストロークされたパスの斜め結合（ミーター）ラインジョイントの最大長さを設定または取得します。このパラメータは、線分が鋭角で結合したときに生成される「spikes」の長さを制限します。

```java
public float MiterLimit { get; set; }
```
