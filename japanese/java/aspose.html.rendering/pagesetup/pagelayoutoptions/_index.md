## PageSetup.PageLayoutOptions property

[`PageLayoutOptions`](../../pagelayoutoptions/) を取得または設定します。デフォルト値は None、他の値を設定すると [`AdjustToWidestPage`](../adjusttowidestpage/) の動作を上書きします。HTML ドキュメントでのみ機能します。

```java
public PageLayoutOptions PageLayoutOptions { get; set; }
```
