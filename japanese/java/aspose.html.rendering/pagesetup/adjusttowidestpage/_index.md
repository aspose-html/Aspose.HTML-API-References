## PageSetup.AdjustToWidestPage property

取得または設定します、ページサイズが文書内で最も幅の広いページに調整される場合を決定するフラグ。このオプションは時間がかかるため、文書処理時間が最大で2倍になる可能性があります。調整は、文書内の最も幅の広いページが [`PageSetup`](../) で決定されたページサイズよりも大きい場合にのみ行われます。調整されたページサイズは文書内のすべてのページに使用されます。

```java
public bool AdjustToWidestPage { get; set; }
```
