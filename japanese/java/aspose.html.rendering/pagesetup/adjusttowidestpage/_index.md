## PageSetup.AdjustToWidestPage property

ページサイズが文書内で最も幅の広いページに合わせて調整されるかどうかを決定するフラグを取得または設定します。このオプションは時間がかかるため、文書処理時間が最大で2倍になる可能性があります。調整は、文書内の最も幅の広いページが [`PageSetup`](../) で決定されたページサイズよりも広い場合にのみ行われます。調整されたページサイズは文書内のすべてのページに使用されます。

```java
public bool AdjustToWidestPage { get; set; }
```
