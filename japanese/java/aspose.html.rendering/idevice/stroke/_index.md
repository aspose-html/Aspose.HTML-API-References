## IDevice.Stroke method

現在のパスに沿って線を描画します。描画された線はパス内の各直線または曲線セグメントに沿い、セグメントの中心に配置され、側面はそれに平行になります。パスの各サブパスは個別に扱われます。このメソッドは現在のパスを終了します。
