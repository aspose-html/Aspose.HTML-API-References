## ICSSStyleSheet.CSSRules property

読み取り専用の CSSStyleSheet プロパティ cssRules は、ライブ [`CSSRuleList`](../../icssrulelist/) を返し、スタイルシートを構成するすべての CSS ルールのリアルタイムで最新のリストを提供します。リスト内の各項目は、単一のルールを定義する [`CSSRule`](../../icssrule/) です。

```java
public ICSSRuleList CSSRules { get; }
```

### Property Value

スタイルシートを構成するすべての CSS ルールを含むライブ更新される [`CSSRuleList`](../../icssrulelist/)。ルールリストの各エントリは、スタイルシートを構成する 1 つのルールを記述する [`CSSRule`](../../icssrule/) オブジェクトです。

## Remarks

[CSSOM](https://drafts.csswg.org/cssom/) defines APIs (including generic parsing and serialization rules) for Media Queries, Selectors, and of course CSS itself.
