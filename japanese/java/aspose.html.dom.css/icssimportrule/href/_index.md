## ICSSImportRule.Href property

CSSImportRule インターフェイスの読み取り専用 href プロパティは、@import at-rule で指定された URL を返します。

解決された URL は、関連付けられたスタイルシートの href 属性になります。

```java
public String Href { get; }
```

### Property Value

@import at-rule で指定された関連スタイルシートの URL を返します。
