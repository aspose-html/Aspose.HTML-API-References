## ICSSImportRule.StyleSheet property

このルールが参照するスタイルシート（読み込まれている場合）。スタイルシートがまだ読み込まれていないか、読み込まれない場合（例：ユーザーエージェントがサポートしていないメディアタイプ用の場合）、この属性の値は null です。

```java
public ICSSStyleSheet StyleSheet { get; }
```

### Property Value

@import at-rule で指定された CSS スタイルシートを返します。これは [`CSSStyleSheet`](../../icssstylesheet/) オブジェクトの形になります。
