### Property Value

この Color の赤成分の値です。

## 備考

各ピクセルの色は 32 ビットの数値で表されます：アルファ、赤、緑、青の各 8 ビット (ARGB)。アルファ成分は色の透明度を示し、0 が完全に透明、255 が完全に不透明です。同様に、A 値が 255 の場合は不透明な色を表します。A 値が 1 から 254 の間の場合は半透明の色を表します。A が 255 に近づくほど色はより不透明になります。
