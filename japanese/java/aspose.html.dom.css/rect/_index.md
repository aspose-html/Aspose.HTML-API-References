## Rect class

Rect インターフェイスは任意の rect 値を表すために使用されます。このインターフェイスは基礎となる style プロパティの値を反映します。そのため、[`CSSPrimitiveValue`](../cssprimitivevalue/) オブジェクトへの変更は style プロパティを変更します。

```java
public class Rect : DOMObject
```
