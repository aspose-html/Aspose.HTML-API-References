## IElementCSSInlineStyle.Style property

style 属性は、computed フラグが未設定で、親 CSS ルールが null で、所有ノードがコンテキストオブジェクトである CSS 宣言ブロックオブジェクトを返す必要があります。

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

ノードに関連付けられた CSS 宣言ブロック、または関連付けられた CSS 宣言ブロックが存在しない場合は null。
