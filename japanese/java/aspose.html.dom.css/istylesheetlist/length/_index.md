## IStyleSheetList.Length property

length 属性は、コレクションが表す CSS スタイルシートの数を返す必要があります。有効な子スタイルシートインデックスの範囲は 0 から length-1（含む）です。

```java
public int Length { get; }
```

### Property Value

コレクション内の項目数を示す整数です。
