## ICSSKeyframesRule.DeleteRule method

deleteRule メソッドは、渡されたキーを持つ [`CSSKeyframeRule`](../../icsskeyframerule/) を削除します。そのキーのルールが存在しない場合、メソッドは何もしません。

```java
public void DeleteRule(String key)
```

| Parameter | Type | 説明 |
| --- | --- | --- |
| キー | 文字列 | 削除対象のルールを示すキー。キーは 0 から 1 の間の数値に解決できなければならず、そうでない場合はルールは無視されます。 |
