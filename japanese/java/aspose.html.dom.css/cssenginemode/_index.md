## CSSEngineMode enumeration

CSSEngine モードを指定します。値は以下の意味を持ちます：

default - CSS パーサは w3c の推奨に従って動作し、カスタム拡張はサポートしません。not-strict - 文書化されていないすべてのプロパティが解析され、アクセス可能になります。

```java
[Flags]
public enum CSSEngineMode
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Default | `0` | CSS パーサは w3c の推奨に従って動作し、カスタム拡張はサポートしません。 |
| NotStrict | `1` | CSS パーサは非厳密モードで動作します。文書化されていないすべてのプロパティが解析され、アクセス可能になります。 |
