## IStyleSheet.Type property

このスタイルシートのスタイルシート言語を指定します。スタイルシート言語は、コンテンツタイプ（例: \"text/css\"）として指定されます。

```java
public String Type { get; }
```

### Property Value

type属性は、そのタイプを返す必要があります。
