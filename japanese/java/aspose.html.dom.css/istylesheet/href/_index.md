## IStyleSheet.Href property

[`StyleSheet`](../) インターフェイスの href プロパティは、スタイルシートの場所を返します。

```java
public String Href { get; }
```

### Property Value

uri は、スタイルシートの URI を含む文字列です。

## Remarks

スタイルシートがリンクされたスタイルシートの場合、その属性の値はその場所です。インラインスタイルシートの場合、この属性の値は NULL です。

このプロパティは Firefox、Opera、Google Chrome、Safari では読み取り専用で、Internet Explorer では読み書き可能です。
