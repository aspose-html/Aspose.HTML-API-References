## IStyleSheet.Media property

[`StyleSheet`](../) インターフェイスの media プロパティは、スタイル情報の対象メディアを指定します。これは読み取り専用の配列ライクな [`MediaList`](../../imedialist/) オブジェクトで、deleteMedium() で削除し、appendMedium() で追加できます。

```java
public IMediaList Media { get; }
```

### Property Value

media属性は、CSSスタイルシートに関連付けられた [`MediaList`](../../imedialist/) オブジェクトを返す必要があります。

## Remarks

[CSSOM](https://drafts.csswg.org/cssom/) defines APIs (including generic parsing and serialization rules) for Media Queries, Selectors, and of course CSS itself.
