## IStyleSheet.Title property

[`StyleSheet`](../) インターフェイスの title プロパティは、現在のスタイルシートの推奨タイトルを返します。

title は通常、[`ownerNode`](../ownernode/) で指定されます。

```java
public String Title { get; }
```

### Property Value

parentStyleSheet 属性は、親の [`CSS style sheet`](../../icssstylesheet/) を返す必要があります。
