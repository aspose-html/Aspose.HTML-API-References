## CSSValueList indexer

CSSValueList インターフェイスの item() メソッドは、順序インデックスで CSSValue を取得するために使用されます。

このコレクション内の順序は、CSS スタイルプロパティの値の順序を表します。インデックスがリスト内の値の数以上の場合、このメソッドは null を返します。

```java
public CSSValue this[int index] { get; }
```

### 戻り値

CSSValueList のインデックス位置にある CSSValue オブジェクト、または有効なインデックスでない場合は null。

### Property Value

コレクション内の CSS 値のインデックスを表す unsigned long。
