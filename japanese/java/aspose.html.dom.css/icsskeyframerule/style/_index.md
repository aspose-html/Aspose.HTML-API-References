## ICSSKeyframeRule.Style property

読み取り専用の CSSKeyframeRule.style プロパティは、[`CSSStyleDeclaration`](../../icssstyledeclaration/) インターフェイスで、[`CSSKeyframeRule`](../) の宣言ブロックを表します。

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

以下のプロパティを持つ [`CSSStyleDeclaration`](../../icssstyledeclaration/) オブジェクトです:

computed flag - Unset.declarations - ルール内で宣言された宣言を、指定された順序で、ショートハンドプロパティはロングハンドに展開したもの。parent CSS rule - this.owner のエイリアスであるコンテキストオブジェクト。node - Null。
