## ICSSKeyframeRule interface

`CSSKeyframeRule` インターフェイスは、特定のキーフレームに対するスタイルセットを表すオブジェクトを記述します。これは @keyframes at-rule の単一キーフレームの内容に対応します。

```java
public interface ICSSKeyframeRule : ICSSRule
```

## プロパティ

| 名前 | 説明 |
| --- | --- |
| [getKeyText](../../com.aspose.html.dom.css/icsskeyframerule/keytext/) CSSKeyframeRule インターフェイスの keyText プロパティは、パーセンテージ値のカンマ区切りリストとしてキーフレームセレクタを表します。from と to キーワードはそれぞれ 0% と 100% に対応します。 |
| [getStyle](../../com.aspose.html.dom.css/icsskeyframerule/style/) 読み取り専用の CSSKeyframeRule.style プロパティは、`CSSKeyframeRule` の宣言ブロック用の [`CSSStyleDeclaration`](../icssstyledeclaration/) インターフェイスです。 |
