## ICSSRule.CSSText property

[`CSSRule`](../) インターフェースの cssText プロパティは、[`CSSStyleSheet`](../../icssstylesheet/) スタイルルールの実際のテキストを返します。

注: このプロパティと要素スタイルの CSSStyleDeclaration.cssText を混同しないでください。

```java
public String CSSText { get; set; }
```

### Property Value

CSS ルールのシリアライズを返します。cssText 属性を設定しても何もしない必要があります。
