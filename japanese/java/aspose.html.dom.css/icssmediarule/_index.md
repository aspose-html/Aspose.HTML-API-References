## ICSSMediaRule interface

CSSMediaRule インターフェイスは CSS スタイルシート内の @media ルールを表します。@media ルールは特定のメディアタイプ向けにスタイルルールを区切るために使用できます。

```java
public interface ICSSMediaRule : ICSSRule
```
