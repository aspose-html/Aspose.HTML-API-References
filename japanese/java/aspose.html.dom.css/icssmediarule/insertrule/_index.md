## ICSSMediaRule.InsertRule method

CSSGroupingRule インターフェイスの insertRule() メソッドは、新しい CSS ルールを CSS ルールのリストに追加します。

```java
public long InsertRule(String rule, long index)
```

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| ルール | 文字列 | メディアルールを CSSOMString として表します。 |
| index | Int64 | ルールを挿入するオプションのインデックス。デフォルトは 0 です。 |

### 戻り値

insertRule(rule, index) メソッドは、指定されたインデックスで子 CSS ルールに CSS ルールを挿入した結果を返します。
