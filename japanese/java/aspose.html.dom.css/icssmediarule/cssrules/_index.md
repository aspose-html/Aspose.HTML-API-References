## ICSSMediaRule.CSSRules property

CSSGroupingRule インターフェイスの cssRules プロパティは、[`CSSRule`](../../icssrule/) オブジェクトのコレクションを含む [`CSSRuleList`](../../icssrulelist/) を返します。

```java
public ICSSRuleList CSSRules { get; }
```

### Property Value

cssRules 属性は、子 CSS ルールに対して [`CSSRuleList`](../../icssrulelist/) オブジェクトを返す必要があります。
