## ICSSStyleDeclaration indexer

この宣言ブロックで明示的に設定されたプロパティを取得するために使用されます。このメソッドで取得されるプロパティの順序は、設定された順序と一致する必要はありません。このメソッドは、この宣言ブロック内のすべてのプロパティを反復処理するために使用できます

```java
public String this[int index] { get; }
```

### 戻り値

propertyName は、指定されたインデックスの CSS プロパティ名を表す文字列です

### Property Value

index は取得するノードのインデックスです。インデックスはゼロベースです
