## SetProperty(String, String) {#setproperty}

CSSStyleDeclaration.setProperty() メソッドは、この宣言ブロック内でデフォルトの優先度でプロパティ値を設定するために使用されます。デフォルトの優先度は \"important\" ではなく、つまり String.Empty です。

```java
public void SetProperty(String propertyName, String value)
```

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| propertyName | 文字列 | 変更対象の CSS プロパティ名（ハイフンケース）を表す文字列 |
| 値 | 文字列 | 新しいプロパティ値を含む文字列です。指定されない場合は空文字列として扱われます |

## SetProperty(String, String, String) {#setproperty_1}

CSSStyleDeclaration.setProperty() メソッドは、この宣言ブロック内でデフォルトの優先度でプロパティ値を設定するために使用されます。デフォルトの優先度は \"important\" ではなく、つまり String.Empty です。

```java
public void SetProperty(String propertyName, String value, String priority)
```

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| propertyName | 文字列 | 変更対象の CSS プロパティ名（ハイフンケース）を表す文字列 |
| 値 | 文字列 | 新しいプロパティ値を含む文字列です。指定されない場合は空文字列として扱われます |
| priority | 文字列 | 「important」CSS 優先度を設定できる文字列です。指定されない場合は空文字列として扱われます。受け入れられる値は次のとおりです：文字列値 \"important\"、キーワード undefined、または空文字列 \"\" |
