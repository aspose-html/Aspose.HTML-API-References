## ICSSStyleDeclaration.GetPropertyPriority method

この宣言ブロックで明示的に設定された場合、CSS プロパティの優先度（例: \"important\" 修飾子）を取得するために使用されます。

```java
public String GetPropertyPriority(String propertyName)
```

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| propertyName | 文字列 | property は、チェックするプロパティ名を表す DOMString です。 |

### 戻り値

priority は、存在する場合は優先度（例: "important"）を表す DOMString です。存在しない場合は空文字列を返します。
