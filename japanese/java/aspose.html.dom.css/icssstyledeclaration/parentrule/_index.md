## ICSSStyleDeclaration.ParentRule property

CSSStyleDeclaration.parentRule 読み取り専用プロパティは、このスタイルブロックの親である CSSRule を返します。例として、[`CSSStyleRule`](../../icssstylerule/) が CSS セレクタのスタイルを表します。

```java
public ICSSRule ParentRule { get; }
```

### Property Value

この宣言ブロックを含む CSS ルール、またはこの [`CSSStyleDeclaration`](../) が [`CSSRule`](../../icssrule/) に添付されていない場合は null。
