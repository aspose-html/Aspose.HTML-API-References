## ICSSStyleDeclaration.CSSText property

宣言ブロックの解析可能なテキスト表現（波括弧を除く）。この属性を設定すると、新しい値の解析が行われ、プロパティの追加や削除を含むすべてのプロパティがリセットされます。

```java
public String CSSText { get; set; }
```

### Property Value

この属性を設定するとインラインスタイルが変更されます。計算された宣言ブロックのテキスト表現が必要な場合は、JSON.Stringify() で取得できます。
