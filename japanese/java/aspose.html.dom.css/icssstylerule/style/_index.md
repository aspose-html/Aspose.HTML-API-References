## ICSSStyleRule.Style property

読み取り専用の style プロパティは、[`CSSStyleDeclaration`](../../icssstyledeclaration/) インターフェイスで、[`CSSStyleRule`](../) の宣言ブロックに対応します。

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

style 属性は、スタイルルールに対して CSSStyleDeclaration オブジェクトを返す必要があります。以下のプロパティを含みます：

computed フラグ - Unset.declarations - ルール内で宣言された宣言を指定された順序で。parent CSS rule - コンテキストオブジェクト。owner node - Null。
