## ICSS2Properties.EmptyCells property

分離ボーダーモデルでは、このプロパティは可視コンテンツがないセルの周囲のボーダーの描画を制御します。空のセルや 'visibility' プロパティが 'hidden' に設定されたセルは、可視コンテンツがないとみなされます。

```java
public String EmptyCells { get; set; }
```
