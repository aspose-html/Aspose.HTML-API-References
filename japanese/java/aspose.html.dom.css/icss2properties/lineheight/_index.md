## ICSS2Properties.LineHeight property

プロパティが [block-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#block-level) 要素（その内容が [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) 要素で構成されている）に設定された場合、生成された各インラインボックスの最小高さを指定します。

プロパティが [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) 要素に設定された場合、要素によって生成された各ボックスの正確な高さを指定します。（インラインの [replaced](https://www.w3.org/TR/1998/REC-CSS2-19980512/conform.html#replaced-element) 要素を除き、そのボックスの高さは ['height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-height) プロパティによって与えられます。）

```java
public String LineHeight { get; set; }
```

line-height プロパティ
