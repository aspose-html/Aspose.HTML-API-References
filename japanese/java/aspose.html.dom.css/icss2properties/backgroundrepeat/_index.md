## ICSS2Properties.BackgroundRepeat property

背景画像が指定された場合、このプロパティは画像が繰り返されるか（タイル化されるか）とその方法を指定します。すべてのタイルはボックスのコンテンツ領域とパディング領域を覆います。値は以下の意味を持ちます：

repeat - 画像は水平・垂直の両方に繰り返されます。repeat-x - 画像は水平のみ繰り返されます。repeat-y - 画像は垂直のみ繰り返されます。no-repeat - 画像は繰り返されません。画像は1枚だけ描画されます。

```java
public String BackgroundRepeat { get; set; }
```

### 戻り値

background-repeat プロパティ

### Property Value

上記で定義されたリストからの background repeat 値です。
