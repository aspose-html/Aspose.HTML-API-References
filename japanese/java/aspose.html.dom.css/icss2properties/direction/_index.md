## ICSS2Properties.Direction property

このプロパティはブロックの基本的な書字方向と、埋め込みやオーバーライドの方向を指定します（Unicode の双方向アルゴリズムについては ['unicode-bidi'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-unicode-bidi) を参照）。さらに、[table](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html) 列レイアウトの方向、水平 [overflow](https://www.w3.org/TR/1998/REC-CSS2-19980512/visufx.html#overflow) の方向、そして 'text-align: justify' の場合のブロック内で最後の行が不完全になる位置を指定します。

```java
public String Direction { get; set; }
```
