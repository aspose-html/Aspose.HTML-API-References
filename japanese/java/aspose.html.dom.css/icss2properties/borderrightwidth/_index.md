## ICSS2Properties.BorderRightWidth property

このプロパティは、スタイルシート内で 'border-top-width'、'border-right-width'、'border-bottom-width'、および 'border-left-width' を同時に設定するためのショートハンドプロパティです。

値が1つだけの場合はすべての側面に適用されます。値が2つある場合、上部と下部のボーダーは最初の値に、右側と左側は2番目の値に設定されます。値が3つある場合、上部は最初の値に、左側と右側は2番目の値に、下部は3番目の値に設定されます。値が4つある場合、それらはそれぞれ上、右、下、左に適用されます。

```java
public String BorderRightWidth { get; set; }
```

### 戻り値

border-right-width プロパティ
