## ICSS2Properties.FontFamily property

このプロパティはフォントファミリ名および/または汎用ファミリ名の優先順位リストを指定します。単一のフォントが文書内のすべての文字を表示するためのグリフを持たない問題、またはすべてのシステムですべてのフォントが利用できない問題に対処するために、このプロパティは著者が同一のスタイルとサイズのフォントのリストを指定できるようにし、順に試して特定の文字のグリフが含まれているかを確認します。このリストはフォントセットと呼ばれます。

```java
public String FontFamily { get; set; }
```

font-family プロパティ
