## ICSS2Properties.FontFamily property

このプロパティは、フォントファミリ名および/または汎用ファミリ名の優先順位リストを指定します。単一のフォントが文書内のすべての文字を表示するためのグリフを持たない場合や、すべてのシステムでフォントが利用できない問題に対処するために、このプロパティは同じスタイルとサイズのフォントのリストを指定でき、順に試して特定の文字のグリフが含まれているか確認します。このリストはフォントセットと呼ばれます。

```java
public String FontFamily { get; set; }
```

### 戻り値

font-family プロパティ
