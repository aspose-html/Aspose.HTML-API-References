## ICSS2Properties.FontWeight property

‘font-weight’ プロパティはフォントの太さを指定します。値は以下の意味を持ちます:

100 から 900 - これらの値は順序付けられたシーケンスを形成し、各数値は前の値と同等かそれ以上に濃い太さを示します。normal - ‘400’ と同等です。bold - ‘700’ と同等です。bolder - 継承されたフォントよりも濃い次の太さを指定します。そのような太さが存在しない場合、単に次に濃い数値に置き換わります（フォントは変更されません）。ただし、継承された値が ‘900’ の場合、結果の太さも ‘900’ になります。lighter - 継承されたフォントよりも軽い次の太さを指定します。そのような太さが存在しない場合、単に次に軽い数値に置き換わります（フォントは変更されません）。ただし、継承された値が ‘100’ の場合、結果の太さも ‘100’ になります。

public String FontWeight { get; set; }
