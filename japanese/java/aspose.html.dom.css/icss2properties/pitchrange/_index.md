## ICSS2Properties.PitchRange property

平均ピッチの変動を指定します。人間の声の知覚されるピッチは基本周波数によって決まり、通常は男性の声で約120Hz、女性の声で約210Hzです。人間の言語は抑揚やピッチが変化しながら話され、これらの変動は追加の意味や強調を伝えます。したがって、非常に表情豊かな声、すなわち強く抑揚がついた声は広いピッチ範囲を示します。このプロパティは、これらの変動が起こる範囲、すなわち基本周波数が平均ピッチからどれだけ逸脱できるかを指定します。

```java
public String PitchRange { get; set; }
```
