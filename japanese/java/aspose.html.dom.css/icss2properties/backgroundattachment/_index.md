## ICSS2Properties.BackgroundAttachment property

背景画像が指定された場合、このプロパティはビューポートに対して固定（'fixed'）されているか、ドキュメントとともにスクロールするか（'scroll'）を指定します。

画像が固定されていても、要素の背景またはパディング領域にあるときだけ表示されます。そのため、画像がタイル状に繰り返されていない限り（'background-repeat: repeat'）、見えなくなることがあります。

```java
public String BackgroundAttachment { get; set; }
```

background-attachment プロパティ
