## ICSS2Properties.PageBreakAfter property

これらのプロパティの値は以下の意味を持ちます：

auto - 生成されたボックスの前（後、内部）にページブレークを強制もし禁止もしません。 always - 生成されたボックスの前（後）に常にページブレークを強制します。 avoid - 生成されたボックスの前（後、内部）のページブレークを回避します。 left - 生成されたボックスの前（後）に1〜2回ページブレークを強制し、次のページを左ページとしてレイアウトします。 right - 生成されたボックスの前（後）に1〜2回ページブレークを強制し、次のページを右ページとしてレイアウトします。

```java
public String PageBreakAfter { get; set; }
```
