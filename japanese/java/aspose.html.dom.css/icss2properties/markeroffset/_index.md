## ICSS2Properties.MarkerOffset property

このプロパティは、マーカー箱の最も近い[border edges](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#border-edge)とそれに関連付けられた[principal box](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#principal-box)との間の距離を指定します。オフセットはユーザー指定の([length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length))にすることも、UA が「auto」を選択することもできます。長さは負になる場合がありますが、実装固有の制限がある場合があります。

```java
public String MarkerOffset { get; set; }
```
