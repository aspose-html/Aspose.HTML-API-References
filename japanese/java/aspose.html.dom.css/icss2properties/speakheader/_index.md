## ICSS2Properties.SpeakHeader property

このプロパティは、テーブルヘッダーを各セルの前に読み上げるか、前のセルとは異なるヘッダーに関連付けられたセルの前だけに読み上げるかを指定します。値は以下の意味です：

once - ヘッダーは一度だけ、セルの系列の前に読み上げられます。 always - ヘッダーは該当するすべてのセルの前に読み上げられます。

```java
public String SpeakHeader { get; set; }
```
