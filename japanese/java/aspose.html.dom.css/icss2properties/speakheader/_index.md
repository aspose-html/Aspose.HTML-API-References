## ICSS2Properties.SpeakHeader property

このプロパティは、テーブルヘッダーが各セルの前に読み上げられるか、または前のセルと異なるヘッダーに関連付けられたセルの前にのみ読み上げられるかを指定します。値は以下の意味です：

once - ヘッダーは一度だけ、セルの系列の前に読み上げられます。always - ヘッダーは関連するすべてのセルの前に読み上げられます。

```java
public String SpeakHeader { get; set; }
```
