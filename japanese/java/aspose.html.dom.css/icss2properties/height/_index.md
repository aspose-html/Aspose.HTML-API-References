## ICSS2Properties.Height property

このプロパティは、ブロックレベル要素と[置換](https://www.w3.org/TR/1998/REC-CSS2-19980512/conform.html#replaced-element)要素によって生成されるボックスの[コンテンツ高さ](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#content-height)を指定します。

このプロパティは、非置換の[インラインレベル](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level)要素には適用されません。非置換インライン要素のボックスの高さは、要素の（継承される可能性のある）['line-height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-line-height)値によって決まります。

```java
public String Height { get; set; }
```
