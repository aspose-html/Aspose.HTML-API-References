## ICSS2Properties.Orphans property

The ['orphans'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-orphans) プロパティは、段落の下部に残す必要がある最小行数を指定します。['widows'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-widows) プロパティは、段落の上部に残す必要がある最小行数を指定します。ページ区切りを制御するためにそれらが使用される例を以下に示します。

```java
public String Orphans { get; set; }
```
