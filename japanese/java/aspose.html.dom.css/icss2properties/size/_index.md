## ICSS2Properties.Size property

このプロパティはページボックスのサイズと向きを指定します。

ページボックスのサイズは "absolute"（固定サイズ）または "relative"（スケーラブル、つまり利用可能な用紙サイズに合わせる）のいずれかです。相対的なページボックスは、ユーザーエージェントが文書を拡大縮小し、目標サイズを最適に活用できるようにします。

['size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-size) プロパティの 3 つの値が相対的なページボックスを作成します：

auto - ページボックスは対象シートのサイズと向きに設定されます。landscape - 対象の向きを上書きします。ページボックスは対象と同じサイズで、長辺が水平になります。portrait - 対象の向きを上書きします。ページボックスは対象と同じサイズで、短辺が水平になります。

```java
public String Size { get; set; }
```
