## ICSS2Properties.TableLayout property

['table-layout'](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#propdef-table-layout) プロパティは、テーブルのセル、行、列の配置に使用されるアルゴリズムを制御します。値は以下の意味です：

fixed - 固定テーブルレイアウトアルゴリズムを使用する auto - 任意の自動テーブルレイアウトアルゴリズムを使用する

```java
public String TableLayout { get; set; }
```
