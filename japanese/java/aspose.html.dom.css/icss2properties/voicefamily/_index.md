## ICSS2Properties.VoiceFamily property

値はカンマ区切りで優先順位付けされた音声ファミリ名のリストです（['font-family'](https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html#propdef-font-family) と比較）。値は以下の意味を持ちます：

'generic-voice' - 値は音声ファミリです。可能な値は 'male'、'female'、'child' です。'specific-voice' - 値は特定のインスタンスです（例: comedian、trinoids、carlos、lani）。

```java
public String VoiceFamily { get; set; }
```
