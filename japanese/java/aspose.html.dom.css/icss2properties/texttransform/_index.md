## ICSS2Properties.TextTransform property

このプロパティは要素のテキストの大文字化効果を制御します。値は以下の意味を持ちます:

capitalize - 各単語の最初の文字を大文字にします。uppercase - 各単語のすべての文字を大文字にします。lowercase - 各単語のすべての文字を小文字にします。none - 大文字化効果はありません。

```java
public String TextTransform { get; set; }
```

### 戻り値

text-transform プロパティ
