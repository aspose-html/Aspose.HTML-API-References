## ICSS2Properties.Elevation property

このプロパティの値は以下の意味を持ちます：

'angle' - 標高を角度で指定し、'-90deg' から '90deg' の範囲です。'0deg' は前方の地平線上を意味し、リスナーと同レベルという意味です。'90deg' は真上、'-90deg' は真下を意味します。below - '-90deg' と同じです。level - '0deg' と同じです。above - '90deg' と同じです。higher - 現在の標高に 10 度加算します。lower - 現在の標高から 10 度減算します。

```java
public String Elevation { get; set; }
```
