## ICSS2Properties.TextDecoration property

このプロパティは要素のテキストに追加される装飾を記述します。プロパティが [block-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#block-level) 要素に指定された場合、要素のすべてのインラインレベルの子孫に影響します。プロパティが [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) 要素に指定（または影響）された場合、要素が生成するすべてのボックスに影響します。要素にコンテンツやテキストコンテンツがない場合（例：HTML の IMG 要素）、ユーザーエージェントはこのプロパティを [ignore](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#ignore) しなければなりません。

値は以下の意味を持ちます：

none - テキスト装飾を行わない。underline - 各行のテキストに下線が付く。overline - 各行のテキストの上に線が付く。line-through - 各行のテキストに中間に線が入る。blink - テキストが点滅する（表示と非表示を交互に切り替える）。

public String TextDecoration { get; set; }
