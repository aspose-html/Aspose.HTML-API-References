## ICSS2Properties.Marks property

高品質印刷では、マークがページボックスの外側に追加されることがよくあります。このプロパティは、クロスマーク、クロップマーク、またはその両方を [page box](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#page-box) の端のすぐ外側に描画するかどうかを指定します。

クロップマークはページをカットすべき位置を示します。クロスマーク（レジスターマークまたはレジストレーションマークとも呼ばれます）はシートを揃えるために使用されます。

マークは絶対ページボックス上でのみ表示されます（['size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-size) プロパティを参照）。相対ページボックスでは、ページボックスはターゲットに合わせて配置され、マークは印刷可能領域の外側にあります。

十字マークのサイズ、スタイル、位置はユーザーエージェントに依存します。

```java
public String Marks { get; set; }
```
