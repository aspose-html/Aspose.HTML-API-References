## ICSS2Properties.SpeakNumeral property

このプロパティは数値の読み上げ方法を制御します。値は以下の意味を持ちます:

digits - 数字を個々の桁として読み上げます。したがって、"237" は "Two Three Seven" と読み上げられます。continuous - 数字全体として読み上げます。したがって、"237" は "Two hundred thirty seven" と読み上げられます。単語表現は言語に依存します。

```java
public String SpeakNumeral { get; set; }
```
