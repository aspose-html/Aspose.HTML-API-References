## ICSS2Properties.SpeakNumeral property

このプロパティは数字の発音方法を制御します。値は以下の意味を持ちます:

digits - 数字を個々の桁として発音します。したがって、\"237\" は \"Two Three Seven\" と発音されます。continuous - 数字を全体の数として発音します。したがって、\"237\" は \"Two hundred thirty seven\" と発音されます。単語表現は言語に依存します。

```java
public String SpeakNumeral { get; set; }
```
