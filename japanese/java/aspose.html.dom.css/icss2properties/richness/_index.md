## ICSS2Properties.Richness property

発話音声の豊かさ（明るさ）を指定します。豊かな声は大きな部屋で「届き」、滑らかな声は届きません。（「滑らか」とは、波形を描いたときの見た目を指します。）

```java
public String Richness { get; set; }
```
