## ICSS2Properties.ListStylePosition property

このプロパティは、主要ブロックボックス内のマーカーボックスの位置を指定します。値は以下の意味を持ちます:

outside - マーカーボックスは主要ブロックボックスの外側にあります。注記. CSS1 はマーカーボックスの正確な位置を指定しておらず、互換性の観点から CSS2 も同様に曖昧です。マーカーボックスをより正確に制御するには、markers を使用してください。inside - マーカーボックスは主要ブロックボックス内の最初のインラインボックスであり、その後要素の内容が流れます。

```java
public String ListStylePosition { get; set; }
```

list-style-position プロパティ
