## ICSS2Properties.ListStylePosition property

このプロパティは主ブロックボックス内のマーカーボックスの位置を指定します。値は以下の意味を持ちます:

outside - マーカーボックスは主ブロックボックスの外側にあります。注記: CSS1 はマーカーボックスの正確な位置を指定しておらず、互換性の観点から CSS2 も同様に曖昧です。マーカーボックスをより正確に制御するには、markers を使用してください。inside - マーカーボックスは主ブロックボックス内の最初のインラインボックスであり、その後要素のコンテンツが流れます。

```java
public String ListStylePosition { get; set; }
```

### 戻り値

list-style-position プロパティ
