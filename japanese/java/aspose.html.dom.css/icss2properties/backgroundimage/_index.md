## ICSS2Properties.BackgroundImage property

このプロパティは要素の背景画像を設定します。背景画像を設定する際、画像が利用できない場合に使用される背景色も指定すべきです。画像が利用可能な場合、背景色の上に画像が描画されます。（したがって、画像の透明部分では背景色が見えます）。

```java
public String BackgroundImage { get; set; }
```

### 戻り値

background-image プロパティ

### Property Value

このプロパティの値は、画像を指定する場合は ,、画像を使用しない場合は 'none' のいずれかです。
