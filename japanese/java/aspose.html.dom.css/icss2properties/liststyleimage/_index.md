## ICSS2Properties.ListStyleImage property

このプロパティはリスト項目のマーカーとして使用される画像を設定します。画像が利用可能な場合、['list-style-type'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-list-style-type) マーカーで設定されたマーカーを置き換えます。

```java
public String ListStyleImage { get; set; }
```

### 戻り値

list-style-image プロパティ
