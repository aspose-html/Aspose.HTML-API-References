## ICSS2Properties.TextIndent property

このプロパティはブロック内の最初のテキスト行のインデントを指定します。正確には、ブロックの最初の[line box](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#line-box)に流れ込む最初のボックスのインデントを指定します。そのボックスは、左側（右から左へのレイアウトの場合は右側）の行ボックスの端に対してインデントされます。ユーザーエージェントはこのインデントを空白として描画すべきです。

値は以下の意味を持ちます:

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - インデントは固定長です。'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - インデントはコンテナブロック幅のパーセンテージです。

```java
public String TextIndent { get; set; }
```
