## ICSS2Properties.MinHeight property

これら 2 つのプロパティは、作者がボックスの高さを特定の範囲に制限できるようにします。値は以下の意味を持ちます：

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - 固定された最小または最大の計算高さを指定します。'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - 計算値を決定するためのパーセンテージを指定します。パーセンテージは生成されたボックスの [containing block](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#containing-block) の高さに対して計算されます。コンテナブロックの高さが明示的に指定されていない場合（つまりコンテンツの高さに依存する場合）、パーセンテージ値は 'auto' のように解釈されます。none - （['max-height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-max-height) のみ） ボックスの高さに制限はありません。

public String MinHeight { get; set; }
