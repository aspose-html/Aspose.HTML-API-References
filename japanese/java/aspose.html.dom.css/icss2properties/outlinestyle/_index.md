## ICSS2Properties.OutlineStyle property

outline プロパティで作成されたアウトラインはボックスの「over」に描画されます。すなわち、アウトラインは常に最上位にあり、ボックスや他のボックスの位置やサイズに影響しません。そのため、アウトラインの表示や非表示は再フローを引き起こしません。

```java
public String OutlineStyle { get; set; }
```
