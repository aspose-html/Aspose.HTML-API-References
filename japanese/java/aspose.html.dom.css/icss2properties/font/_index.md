## ICSS2Properties.Font property

『font』プロパティは、以下で説明する場合を除き、style シート内の同一場所で『font-style』、『font-variant』、『font-weight』、『font-size』、『line-height』、および『font-family』を設定するための省略形プロパティです。このプロパティの構文は、フォントに関連する複数のプロパティを設定するための従来のタイポグラフィ的省略表記に基づいています。

```java
public String Font { get; set; }
```
