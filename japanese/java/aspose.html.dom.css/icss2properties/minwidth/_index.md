## ICSS2Properties.MinWidth property

これら2つのプロパティは、作者がボックスの幅を特定の範囲に制限できるようにします。値は以下の意味を持ちます：

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - 固定された最小または最大の計算幅を指定します。'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - 計算値を決定するためのパーセンテージを指定します。パーセンテージは生成されたボックスの [containing block](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#containing-block) の幅に対して計算されます。none - （['max-width'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-max-width)） ボックスの幅に制限はありません。

```java
public String MinWidth { get; set; }
```

min-width プロパティ
