## ICSS2Properties.FontStretch property

['font-stretch'](https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html#propdef-font-stretch) プロパティは、フォントファミリーから標準、コンデンス、またはエクステンドのフォントを選択します。絶対キーワード値は、最も狭いものから最も広いものへ以下の順序で並びます：

ultra-condensedextra-condensedcondensedsemi-condensednormalsemi-expandedexpandedextra-expandedultra-expanded

public String FontStretch { get; set; }
