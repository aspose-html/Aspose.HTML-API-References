## ICSS2Properties.CounterReset property

['counter-reset'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-counter-reset) プロパティも、1つ以上のカウンタ名のリストを含み、各カウンタ名はオプションで整数が続きます。その整数は要素が出現するたびにカウンタが設定される値を示します。デフォルトは 0 です。

```java
public String CounterReset { get; set; }
```
