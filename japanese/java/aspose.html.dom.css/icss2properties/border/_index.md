## ICSS2Properties.Border property

‘border’ プロパティは、ボックスの四辺すべてに同じ幅、色、スタイルを設定するためのショートハンドプロパティです。ショートハンドの ‘margin’ および ‘padding’ プロパティとは異なり、‘border’ プロパティでは四辺に異なる値を設定できません。そのためには、他の border プロパティの一つまたは複数を使用する必要があります。

```java
public String Border { get; set; }
```

### 戻り値

border プロパティ
