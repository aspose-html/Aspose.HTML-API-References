## ICSS2Properties.Border property

'border' プロパティは、ボックスの4つの境界すべてに同じ幅、色、スタイルを設定するためのショートハンドプロパティです。ショートハンドの 'margin' および 'padding' プロパティとは異なり、'border' プロパティは4つの境界に異なる値を設定できません。そのためには、他の border プロパティの1つ以上を使用する必要があります。

```java
public String Border { get; set; }
```

### 戻り値

border プロパティ
