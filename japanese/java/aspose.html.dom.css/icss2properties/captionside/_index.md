## ICSS2Properties.CaptionSide property

このプロパティは、テーブルボックスに対するキャプションボックスの位置を指定します。値は以下の意味を持ちます：

top - キャプションボックスをテーブルボックスの上に配置します。 bottom - キャプションボックスをテーブルボックスの下に配置します。 left - キャプションボックスをテーブルボックスの左側に配置します。 right - キャプションボックスをテーブルボックスの右側に配置します。

```java
public String CaptionSide { get; set; }
```
