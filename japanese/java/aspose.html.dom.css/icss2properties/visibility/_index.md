## ICSS2Properties.Visibility property

The ['visibility'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visufx.html#propdef-visibility) プロパティは、要素によって生成されたボックスが描画されるかどうかを指定します。不可視のボックスはレイアウトに影響を与え続けます（ボックス生成を完全に抑制するには ['display'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-display) プロパティを 'none' に設定します）。値は以下の意味を持ちます：

visible - 生成されたボックスは表示されます。hidden - 生成されたボックスは不可視（完全に透明）ですが、レイアウトには影響します。collapse - テーブルの [dynamic row and column effects](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#dynamic-effects) のセクションを参照してください。行や列以外の要素に使用された場合、'collapse' は 'hidden' と同じ意味です。

```java
public String Visibility { get; set; }
```
