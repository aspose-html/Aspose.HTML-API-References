## ICSS2Properties.Cue property

['cue'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue) プロパティは ['cue-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-before) と ['cue-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-after) を設定するショートハンドです。2 つの値が指定された場合、最初の値は ['cue-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-before) で、2 番目は ['cue-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-after) です。1 つの値だけが指定された場合は、両方のプロパティに適用されます。

```java
public String Cue { get; set; }
```
