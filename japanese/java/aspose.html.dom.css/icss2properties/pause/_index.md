## ICSS2Properties.Pause property

['pause'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause) プロパティは、['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) と ['pause-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-after) を設定するためのショートハンドです。2 つの値が指定された場合、最初の値は ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) で、2 番目の値は ['pause-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-after) です。1 つだけ値が指定された場合は、両方のプロパティに適用されます。

```java
public String Pause { get; set; }
```

pause プロパティ
