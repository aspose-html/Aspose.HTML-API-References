## ICSS2Properties.Margin property

この ['margin'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin) プロパティは、スタイルシート内の同じ場所で ['margin-top'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-top)、['margin-right'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-right)、['margin-bottom'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-bottom) および ['margin-left'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-left) を設定するためのショートハンドプロパティです。

値が1つだけの場合は、すべての側面に適用されます。値が2つある場合、上と下の余白は最初の値に、右と左の余白は2番目の値に設定されます。値が3つある場合、上は最初の値に、左右は2番目の値に、下は3番目の値に設定されます。値が4つある場合、上、右、下、左の順にそれぞれ適用されます。

public String Margin { get; set; }
