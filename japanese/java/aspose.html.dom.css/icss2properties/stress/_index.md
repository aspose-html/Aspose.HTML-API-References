## ICSS2Properties.Stress property

音声のイントネーション輪郭における「局所的なピーク」の高さを指定します。例えば、英語は強勢がある言語で、文のさまざまな部分に一次、二次、三次の強勢が割り当てられます。['stress'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-stress) の値は、これらの強勢マーカーから生じる抑揚の量を制御します。このプロパティは ['pitch-range'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pitch-range) プロパティの補完であり、開発者が高度な聴覚ディスプレイを活用できるように提供されています。

```java
public String Stress { get; set; }
```
