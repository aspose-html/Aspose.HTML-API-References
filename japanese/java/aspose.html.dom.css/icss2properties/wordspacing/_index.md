## ICSS2Properties.WordSpacing property

このプロパティは単語間の間隔の動作を指定します。値は以下の意味を持ちます：

normal - 現在のフォントおよび/または UA によって定義された標準の単語間スペースです。'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - この値は、単語間のデフォルトスペースに加えて追加の単語間スペースを示します。値は負になることがありますが、実装固有の制限がある場合があります。

```java
public String WordSpacing { get; set; }
```

word-spacing プロパティ
