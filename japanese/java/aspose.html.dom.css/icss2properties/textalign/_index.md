## ICSS2Properties.TextAlign property

このプロパティはブロックのインラインコンテンツの配置方法を説明します。値は以下の意味を持ちます:

left, right, center, and justify - 左、右、中央、そして両端揃えテキスト、それぞれ。'[String](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-String)' - テーブル列のセルが揃える文字列を指定します（詳細と例については [horizontal alignment in a column](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#column-alignment) のセクションを参照）。この値は [table](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html) セルにのみ適用されます。他の要素に設定された場合は、['direction'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-direction) が 'ltr' か 'rtl' に応じて、'left' または 'right' とみなされます。

```java
public String TextAlign { get; set; }
```
