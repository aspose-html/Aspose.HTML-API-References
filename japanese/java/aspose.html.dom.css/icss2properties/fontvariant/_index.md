## ICSS2Properties.FontVariant property

スモールキャップスフォントでは、小文字の字形が大文字に似ていますが、サイズが小さく、わずかに異なる比例を持ちます。'font-variant' プロパティは、ラテン文字のように二つのケースを持つ双字母体系のためにそのようなフォントを要求します。このプロパティは、ほとんどの世界の表記体系のように一つのケースしか持たない単字母体系のスクリプトには目に見える効果がありません。

```java
public String FontVariant { get; set; }
```

font-variant プロパティ
