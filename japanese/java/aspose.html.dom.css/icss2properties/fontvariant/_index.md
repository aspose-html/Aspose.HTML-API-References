## ICSS2Properties.FontVariant property

スモールキャップスフォントでは、小文字の字形が大文字に似ていますが、サイズが小さく、若干異なる比例を持ちます。'font-variant' プロパティは、ラテン文字のように二つのケース（大文字・小文字）を持つ双字形スクリプト用にそのようなフォントを要求します。このプロパティは、ほとんどの世界の表記体系のように一つのケースしか持たない単字形スクリプトには可視的な効果がありません。

```java
public String FontVariant { get; set; }
```

font-variant プロパティ
