## ICSS2Properties.CounterIncrement property

['counter-increment'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-counter-increment) プロパティは、カウンタ（識別子）の名前を1つ以上受け取り、各名前はオプションで整数を続けることができます。整数は要素が出現するたびにカウンタがどれだけ増加するかを示します。デフォルトの増分は 1 です。0 および負の整数も許可されます。

```java
public String CounterIncrement { get; set; }
```
