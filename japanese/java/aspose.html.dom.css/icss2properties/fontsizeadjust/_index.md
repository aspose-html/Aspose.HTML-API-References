## ICSS2Properties.FontSizeAdjust property

二文字体系のスクリプトでは、フォントの主観的な見た目のサイズと可読性は、'font-size' の値よりも 'x-height' の値、あるいはこれら二つの比率（アスペクト値（フォントサイズを x-height で割ったもの））に依存します。アスペクト値が高いほど、より小さいサイズのフォントでも可読性が保たれる可能性が高くなります。逆に、アスペクト値が低いフォントは、一定の閾値サイズ以下になると、アスペクト値が高いフォントよりも速く読めなくなります。フォントサイズだけに依存した単純なフォント置換は、文字が読めなくなる原因となる可能性があります。

```java
public String FontSizeAdjust { get; set; }
```
