## ICSS2Properties.SpeakPunctuation property

このプロパティは句読点の読み上げ方法を指定します。値は以下の意味を持ちます:

code - セミコロンや波括弧などの句読点は文字通り読み上げます。none - 句読点は読み上げず、代わりにさまざまなポーズとして自然に表現されます。

```java
public String SpeakPunctuation { get; set; }
```
