## ICSS2Properties.BorderSpacing property

長さは隣接するセル境界線の間隔を指定します。1 つの長さが指定された場合、水平間隔と垂直間隔の両方に適用されます。2 つ指定された場合、最初の値が水平間隔、2 番目の値が垂直間隔を表します。長さは負の値にできません。

```java
public String BorderSpacing { get; set; }
```
