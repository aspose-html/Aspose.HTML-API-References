## ICSS2Properties.BorderSpacing property

長さは隣接するセルの境界線を分離する距離を指定します。長さが1つ指定された場合、水平間隔と垂直間隔の両方を設定します。2つ指定された場合、最初が水平間隔、2番目が垂直間隔を設定します。長さは負の値にできません。

```java
public String BorderSpacing { get; set; }
```
