## ICSS2Properties.Position property

このプロパティの値は以下の意味を持ちます：

static - ボックスは通常のボックスで、[normal flow](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#normal-flow) に従って配置されます。['left'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-left) と ['top'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-top) プロパティは適用されません。

```java
public String Position { get; set; }
```

### 戻り値

relative - ボックスの位置は [normal flow](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#normal-flow) に基づいて計算されます（これを normal flow 中の位置と呼びます）。その後、ボックスは [relative](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#relative-positioning) によって通常位置からオフセットされます。ボックス B が相対位置指定されている場合、次のボックスの位置は B がオフセットされていないかのように計算されます。
