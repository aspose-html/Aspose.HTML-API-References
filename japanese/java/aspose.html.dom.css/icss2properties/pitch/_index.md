## ICSS2Properties.Pitch property

話し声の平均ピッチ（周波数）を指定します。声の平均ピッチは声の種類に依存します。例えば、標準的な男性の声の平均ピッチは約120Hz、女性の声は約210Hzです。

public String Pitch { get; set; }
