## ICSS2Properties.BackgroundPosition property

背景画像が指定されている場合、このプロパティはその初期位置を指定します。値は以下の意味を持ちます：

値のペアが '0% 0%' の場合、画像の左上隅はボックスのパディングエッジの左上隅に合わせられます。 値のペアが '100% 100%' の場合、画像の右下隅はパディング領域の右下隅に配置されます。 値のペアが '14% 84%' の場合、画像の横方向 14%、縦方向 84% の点がパディング領域の同じ位置に配置されます。 値のペアが '2cm 2cm' の場合、画像の左上隅はパディング領域の左上隅から右へ 2cm、下へ 2cm の位置に配置されます。 top left と left top - '0% 0%' と同じです。 top、top center、center top - '50% 0%' と同じです。 right top と top right - '100% 0%' と同じです。 left、left center、center left - '0% 50%' と同じです。 center、center center - '50% 50%' と同じです。 right、right center、center right - '100% 50%' と同じです。 bottom left と left bottom - '0% 100%' と同じです。 bottom、bottom center、center bottom - '50% 100%' と同じです。 bottom right と right bottom - '100% 100%' と同じです。

```java
public String BackgroundPosition { get; set; }
```

background-position プロパティ

上記で定義されたリストからの background position 値です。
