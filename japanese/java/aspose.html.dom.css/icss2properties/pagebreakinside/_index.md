## ICSS2Properties.PageBreakInside property

これらのプロパティの値は次の意味を持ちます：

auto - 生成されたボックスの前（後、内部）でページブレークを強制もし禁止もししない。always - 生成されたボックスの前（後）で常にページブレークを強制する。avoid - 生成されたボックスの前（後、内部）でページブレークを回避する。left - 生成されたボックスの前（後）で1〜2ページブレークを強制し、次のページを左ページとしてレイアウトする。right - 生成されたボックスの前（後）で1〜2ページブレークを強制し、次のページを右ページとしてレイアウトする。

```java
public String PageBreakInside { get; set; }
```
