このプロパティは要素の背景色を設定し、値またはキーワード 'transparent' を使用して下層の色が透けて見えるようにします。

```java
public String BackgroundColor { get; set; }
```

### 戻り値

background-color プロパティ

### Property Value

色はキーワードまたは数値の RGB 指定のいずれかです。
