## ICSSPageRule.SelectorText property

`[`CSSPageRule`](../)` インターフェイスの selectorText プロパティは、[`CSSPageRule`](../) に関連付けられたセレクタを取得および設定します。

```java
public String SelectorText { get; set; }
```

### Property Value

selectorText 属性は、取得時に、関連付けられた CSS ページセレクタのリストをシリアライズした結果を返す必要があります。
