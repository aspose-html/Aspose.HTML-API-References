## ICSSPageRule interface

CSSPageRule インターフェイスは CSS スタイルシート内の @page ルールを表します。@page ルールは、ページングメディア用のページボックスの寸法、向き、余白などを指定するために使用されます。

```java
public interface ICSSPageRule : ICSSRule
```
