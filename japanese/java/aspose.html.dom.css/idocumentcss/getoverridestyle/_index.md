## IDocumentCSS.GetOverrideStyle method

このメソッドは、指定された要素および指定された疑似要素のオーバーライドスタイル宣言を取得するために使用されます。

```java
public ICSSStyleDeclaration GetOverrideStyle(Element elt, String pseudoElt)
```

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| elt | 要素 | スタイルを変更する対象の要素。このパラメータは null にできません。 |
| pseudoElt | 文字列 | 疑似要素、存在しない場合は null。 |

### 戻り値

オーバーライドスタイル宣言。
