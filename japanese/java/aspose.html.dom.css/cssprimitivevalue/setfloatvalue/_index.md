## CSSPrimitiveValue.SetFloatValue method

指定された単位で浮動小数点値を設定するメソッドです。この値が付随するプロパティが指定された単位または浮動小数点値を受け付けない場合、値は変更されず、DOMException が発生します。

```java
public abstract void SetFloatValue(ushort unitType, float floatValue)
```

| unitType | UInt16 | 単位の型です。 |
