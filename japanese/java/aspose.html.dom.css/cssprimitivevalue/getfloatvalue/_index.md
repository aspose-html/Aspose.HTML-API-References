## CSSPrimitiveValue.GetFloatValue method

このメソッドは、指定された単位で浮動小数点値を取得するために使用されます。もしこの CSS 値に浮動小数点値が含まれていない、または指定された単位に変換できない場合、DOMException が発生します。

```java
public abstract float GetFloatValue(ushort unitType)
```

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| unitType | UInt16 | 単位の型。 |

### 戻り値

値を返します。
