## CSSPrimitiveValue.GetRectValue method

このメソッドは Rect 値を取得するために使用されます。もしこの CSS 値に rect 値が含まれていない場合、DOMException が発生します。対応するスタイルプロパティの変更は Rect インターフェイスを使用して行うことができます。

```java
public abstract Rect GetRectValue()
```

### 戻り値

Rect 値を返します
