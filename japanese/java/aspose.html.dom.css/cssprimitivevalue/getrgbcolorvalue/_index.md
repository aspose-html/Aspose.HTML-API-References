## CSSPrimitiveValue.GetRGBColorValue method

このメソッドは RGB カラーを取得するために使用されます。この CSS 値に RGB カラー値が含まれていない場合、DOMException が発生します。対応するスタイルプロパティの変更は RGBColor インターフェイスを使用して行うことができます。

```java
public abstract RGBColor GetRGBColorValue()
```

### 戻り値

RGB カラー値を返します
