## CSSPrimitiveValue.GetCounterValue method

このメソッドは Counter の値を取得するために使用されます。この CSS 値にカウンタ値が含まれていない場合、DOMException がスローされます。対応するスタイルプロパティの変更は Counter インターフェイスを使用して行うことができます。

```java
public abstract Counter GetCounterValue()
```

### 戻り値

Counter 値を返します
