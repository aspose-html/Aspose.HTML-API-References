## IRuntimeService.JavaScriptTimeout property

JavaScript の実行時間を制限する TimeSpan を取得または設定します。スクリプトが指定された TimeSpan より長く実行された場合、キャンセルされます。TimeSpan を -1 ミリ秒に設定することで無限タイムアウトを指定できます。デフォルト値は 1 分です。

```java
public TimeSpan JavaScriptTimeout { get; set; }
```
