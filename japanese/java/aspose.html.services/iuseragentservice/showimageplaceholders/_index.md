## IUserAgentService.ShowImagePlaceholders property

画像は代替コンテンツを持つことができます：外部リソースが使用できない場合（例：サポートされていない形式の場合）に使用すべきコンテンツです。`ShowImagePlaceholders` プロパティは、代替画像を表示するかどうかを指定します（デフォルトは true）。

public bool ShowImagePlaceholders { get; set; }
