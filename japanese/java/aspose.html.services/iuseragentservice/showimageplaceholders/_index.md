## IUserAgentService.ShowImagePlaceholders property

画像はフォールバックコンテンツを持つことができます：外部リソースが使用できない場合（例: サポートされていない形式の場合）に使用すべきコンテンツです。プロパティ `ShowImagePlaceholders` はフォールバック画像を表示するかどうかを指定します（デフォルトは true）。

```java
public bool ShowImagePlaceholders { get; set; }
```
