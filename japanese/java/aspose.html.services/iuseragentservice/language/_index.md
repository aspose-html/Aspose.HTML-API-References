## IUserAgentService.Language property

`Language` は要素の内容およびテキストを含む要素属性の主言語を指定します。その値は有効な BCP 47 () 言語タグまたは空の文字列でなければなりません。属性を空の文字列に設定すると、主言語が不明であることを示します。

```java
public String Language { get; set; }
```

### Property Value

ユーザーエージェントの言語です。
