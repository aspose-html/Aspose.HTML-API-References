このパッケージは、フォーム内の Web ページコンポーネントとしてユーザーのインタラクティブ性を担当する多数のオブジェクト（要素）へのアクセスを提供します。

## クラス

| クラス | 説明 |
| --- | --- |
| [ButtonElement](./buttonelement/) | ButtonElement は、HTMLButtonElement に関連付けられたラッパーを表します。 |
| [DataListElement](./datalistelement/) | DataListElement は、HTMLDataListElement に関連付けられたラッパーを表します。 |
| [FormEditor](./formeditor/) | このクラスは、[`HTMLFormElement`](../com.aspose.html/htmlformelement/) の上にあるエディタを表し、.net 開発者が HTML フォームを編集するための簡便な方法を提供します。 |
| [FormElement](./formelement/) | フォーム要素の基底クラスを表します。 |
| [FormElement&lt;T&gt;](./formelement-1/) | [`FormElement`](../com.aspose.html.forms/formelement/) は汎用フィールドを表します。 |
| [FormSubmitter](./formsubmitter/) | このクラスは、指定された [`HTMLFormElement`](../com.aspose.html/htmlformelement/) を準備し、フォーム要素から値を収集してリモートサーバーに送信し、応答を受け取ることを可能にします。 |
| [InputElement](./inputelement/) | InputElement は、HTMLInputElement に関連付けられたラッパーを表します。 |
| [OptionCollection](./optioncollection/) | OptionElements は、IHTMLOptionsCollection に関連付けられたラッパーを表します。 |
| [OptionElement](./optionelement/) | OptionElement は、HTMLOptionElement に関連付けられたラッパーを表します。 |
| [SelectElement](./selectelement/) | SelectElement は、HTMLSelectElement に関連付けられたラッパーを表します。 |
| [SubmissionResult](./submissionresult/) | このクラスは、サーバーへのフォームデータ送信結果を表します。 |
| [TextAreaElement](./textareaelement/) | TextAreaElement は、HTMLTextAreaElement に関連付けられたラッパーを表します。 |
## 列挙型

| 列挙型 | 説明 |
| --- | --- |
| [ButtonType](./buttontype/) | この列挙は、ボタンの状態を表します。 |
| [FormElementType](./formelementtype/) | フォーム要素のタイプとそれに対応する HTML 要素の列挙を表します。 |
| [InputElementType](./inputelementtype/) | 入力フィールドの状態を表します。 |
