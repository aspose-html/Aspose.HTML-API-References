## FormEditor.CreateNew method

新しい [`HTMLFormElement`](../../../com.aspose.html/htmlformelement/) を作成し、[`FormEditor`](../) に関連付けます。[`HTMLFormElement`](../../../com.aspose.html/htmlformelement/) はドキュメントから切り離された状態で作成されます。ドキュメントに添付するには、適切な場所を選択し、[`AppendChild`](../../../com.aspose.html.dom/node/appendchild/) メソッドを使用してください。

```java
public static FormEditor CreateNew(HTMLDocument document)
```

| Parameter | Type | 説明 |
| --- | --- | --- |
| document | HTMLDocument | [`HTMLDocument`](../../../com.aspose.html/htmldocument/)。 |

### 戻り値

[`FormEditor`](../) クラスの新しいインスタンスを返します。
