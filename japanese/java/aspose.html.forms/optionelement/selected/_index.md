## OptionElement.Selected property

インタラクティブなユーザーエージェントにおける対応するフォームコントロールの現在の状態を表します。この属性を変更するとフォームコントロールの状態が変わりますが、要素の HTML selected 属性の値は変わりません。

```java
public bool Selected { get; set; }
```
