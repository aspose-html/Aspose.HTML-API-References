**com.aspose.html.saving** パッケージは、変換/保存処理時の特定の保存オプションの記述用データクラスで構成されています。

## クラス

| クラス | 説明 |
| --- | --- |
| [DocSaveOptions](./docsaveoptions/) | 特定のオプションデータクラスです。プロパティを設定することで、解像度、ページサイズ、背景色などのレンダリング特性や、フォント埋め込みなどのドキュメント固有のオプションを管理できます。詳細はドキュメントの [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-docx/#save-options) をご覧ください。 |
| [HTMLSaveOptions](./htmlsaveoptions/) | HTML 保存オプションを表します。特定のプロパティを設定することで、最大処理深度などのリソース処理を管理できます。詳細はドキュメントの [article](https://docs.aspose.com/html/net/working-with-documents/saving-a-document/) をご覧ください。 |
| [ImageSaveOptions](./imagesaveoptions/) | 特定のオプションデータクラスです。画像の結果解像度、スムージング品質、フォーマット、ページ設定などを管理するプロパティを提供します。詳細はドキュメントの [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-jpg/#save-options) をご参照ください。 |
| [MarkdownSaveOptions](./markdownsaveoptions/) | Markdown 保存オプションを表します。たとえば、Markdown の書式スタイルを設定したり、事前定義された GitLab Flavored Markdown 互換オプションを使用したり、リソース処理を構成したりできます。詳細は [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-markdown/#save-options) をご参照ください。 |
| [MHTMLSaveOptions](./mhtmlsaveoptions/) | MHTML 保存オプションを表します。特定のプロパティを設定することで、最大処理深度などのリソース処理を管理できます。詳細はドキュメントの [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-mhtml/#save-options) をご覧ください。 |
| [PdfSaveOptions](./pdfsaveoptions/) | 特定のデータクラスは、変換結果を管理するためのいくつかのプロパティを提供します。例えば、[`PageSetup`](../com.aspose.html.rendering/pagesetup/) はページの特性を指定します。詳細はドキュメントの [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-pdf/#convert-html-to-pdf-using-pdfsaveoptions) をご参照ください。 |
| [Resource](./resource/) | このクラスはリソースを記述し、その処理のためのメソッドを提供します。 |
| [ResourceHandlingContext](./resourcehandlingcontext/) | このクラスはリソース処理時に使用される情報を含みます。 |
| [ResourceHandlingOptions](./resourcehandlingoptions/) | リソース処理オプションを表します。 |
| [SaveOptions](./saveoptions/) | これは、特定の形式でドキュメントを保存する際にユーザーが追加オプションを指定できるようにするクラスの抽象基底クラスです。 |
| [TextSaveOptions](./textsaveoptions/) | Text 保存オプションを表します |
| [XpsSaveOptions](./xpssaveoptions/) | 特定のオプションデータクラスは、変換結果を管理するためのいくつかのプロパティを提供します。例えば、[`PageSetup`](../com.aspose.html.rendering/pagesetup/) はページの特性を指定します。詳細はドキュメントの [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-xps/#save-options) をご参照ください。 |
## 列挙型

| 列挙型 | 説明 |
| --- | --- |
| [HTMLSaveFormat](./htmlsaveformat/) | ドキュメントが保存される形式を指定します。[`HTMLDocument`](../com.aspose.html/htmldocument/) の保存に関する詳細は、[article](https://docs.aspose.com/html/net/working-with-documents/saving-a-document/) をご覧ください。 |
| [MarkdownFeatures](./markdownfeatures/) | `[`MarkdownFeatures`](../com.aspose.html.saving/markdownfeatures/)` フラグセットは、以下のフラグの0個以上の集合で、マークダウンに変換される要素を選択するために使用されます。 |
| [MarkdownFormatter](./markdownformatter/) | 出力の書式設定方法を指定します。 |
| [ResourceHandling](./resourcehandling/) | この列挙型はリソース処理オプションを表します。 |
| [ResourceStatus](./resourcestatus/) | リソースの状態を示します。 |
| [UrlRestriction](./urlrestriction/) | この列挙型は処理されたリソースの URL に適用される制限を表します。 |
