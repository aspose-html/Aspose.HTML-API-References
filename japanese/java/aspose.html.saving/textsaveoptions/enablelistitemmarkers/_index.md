## TextSaveOptions.EnableListItemMarkers property

HTML をテキストに変換する際に OL、UL 要素に適用されるオプションです。実際には OL と UL 要素の外側リストマーカーの処理方法を定義します。true の場合、OL 項目の前に番号が、UL 項目の前にドットが追加されます。false の場合、（仕様に従ったデフォルトの動作として）追加されません。

```java
public bool EnableListItemMarkers { get; set; }
```
