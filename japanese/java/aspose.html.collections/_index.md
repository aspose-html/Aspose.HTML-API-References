The **com.aspose.html.collections** パッケージは、ノードや要素を表現、保存、操作するためのクラスで構成されています。

## クラス

| クラス | 説明 |
| --- | --- |
| [DOMTokenList](./domtokenlist/) | DOMTokenList クラスは、スペースで区切られたトークンの集合を表します。JavaScript の Array オブジェクトと同様に 0 からインデックス付けされます。DOMTokenList は常に大文字小文字を区別します。 |
| [HTMLCollection](./htmlcollection/) | [`HTMLCollection`](../com.aspose.html.collections/htmlcollection/) は、汎用的なコレクションの [`Element`](../com.aspose.html.dom/element/) を表します。 |
| [NamedNodeMap](./namednodemap/) | 名前でアクセスできる属性のコレクションを表します。 |
| [NodeList](./nodelist/) | NodeList は、ノードの順序付けられたコレクションの抽象化を提供しますが、このコレクションがどのように実装されるかは定義または制約しません。 |
