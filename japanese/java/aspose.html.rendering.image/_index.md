**com.aspose.html.rendering.image** パッケージは、jpeg、png、bmp、gif、tiff などのラスタ形式へのレンダリングを担当する特定のデバイスクラスと、いくつかのレンダリングオプションクラスを提供します。

## クラス

| クラス | 説明 |
| --- | --- |
| [ImageDevice](./imagedevice/) | ラスタ形式（jpeg、png、bmp、gif、tiff）へのレンダリングを表します。 |
| [ImageRenderingOptions](./imagerenderingoptions/) | [`ImageDevice`](../com.aspose.html.rendering.image/imagedevice/) のレンダリングオプションを表します。このオプションは、出力画像フォーマット、圧縮、解像度などを指定するために使用されます。 |
| [TextOptions](./textoptions/) | [`ImageDevice`](../com.aspose.html.rendering.image/imagedevice/) のテキストレンダリングオプションを表します。 |
## 列挙型

| 列挙型 | 説明 |
| --- | --- |
| [Compression](./compression/) | Tagged Image File Format（TIFF）ビットマップ画像の可能な圧縮方式を指定します。 |
| [ImageFormat](./imageformat/) | 画像のファイル形式を指定します。 |
