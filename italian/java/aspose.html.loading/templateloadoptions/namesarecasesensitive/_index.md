## TemplateLoadOptions.NamesAreCaseSensitive property

Proprietà che specifica se i nomi dei template e degli elementi dati devono essere confrontati indipendentemente dal caso dei caratteri o meno. Se true, il confronto è sensibile al maiuscolo/minuscolo; se false, il caso dei caratteri viene ignorato. Il valore predefinito è true.

```java
public bool NamesAreCaseSensitive { get; set; }
```
