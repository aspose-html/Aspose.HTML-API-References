## TemplateLoadOptions.NamesAreCaseSensitive property

Proprietà che specifica se i nomi degli elementi template e dati saranno confrontati indipendentemente dal caso dei caratteri o meno. Se true, il confronto è sensibile al caso; se false, il caso dei caratteri sarà ignorato. Il valore predefinito è true.

```java
public bool NamesAreCaseSensitive { get; set; }
```
