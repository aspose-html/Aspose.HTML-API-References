Il pacchetto **com.aspose.html.saving** è costituito da classi di dati per la descrizione di opzioni di salvataggio specifiche nel processo di conversione/salvataggio.

## Classi

| Classe | Descrizione |
| --- | --- |
| [DocSaveOptions](./docsaveoptions/) | Classe dati di opzioni specifiche. Assegnando le proprietà è possibile gestire le caratteristiche di rendering come risoluzione, dimensione della pagina, colore di sfondo così come opzioni specifiche del documento come l'incorporamento dei font. Maggiori informazioni nella documentazione [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-docx/#save-options). |
| [HTMLSaveOptions](./htmlsaveoptions/) | Rappresenta le opzioni di salvataggio HTML. Assegnando proprietà specifiche è possibile gestire l'elaborazione delle risorse, come la profondità massima di gestione e così via. Maggiori informazioni nella documentazione [article](https://docs.aspose.com/html/net/working-with-documents/saving-a-document/). |
| [ImageSaveOptions](./imagesaveoptions/) | Classe dati di opzioni specifiche. Fornisce proprietà per gestire la risoluzione dell'immagine risultante, la qualità di smussatura, il formato così come le impostazioni della pagina, ecc. Maggiori informazioni sono disponibili nella documentazione [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-jpg/#save-options). |
| [MarkdownSaveOptions](./markdownsaveoptions/) | Rappresenta le opzioni di salvataggio Markdown. Ad esempio, è possibile impostare lo stile di formattazione markdown, utilizzare opzioni compatibili predefinite GitLab Flavored Markdown e configurare la gestione delle risorse. Per ulteriori informazioni vedere [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-markdown/#save-options). |
| [MHTMLSaveOptions](./mhtmlsaveoptions/) | Rappresenta le opzioni di salvataggio MHTML. Assegnando proprietà specifiche è possibile gestire l'elaborazione delle risorse, come la profondità massima di gestione e così via. Maggiori informazioni nella documentazione [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-mhtml/#save-options). |
| [PdfSaveOptions](./pdfsaveoptions/) | Classe dati specifica che fornisce alcune proprietà per gestire il risultato della conversione. Ad esempio [`PageSetup`](../com.aspose.html.rendering/pagesetup/) specifica le caratteristiche della pagina. Consultare la documentazione [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-pdf/#convert-html-to-pdf-using-pdfsaveoptions). |
| [Resource](./resource/) | Questa classe descrive una risorsa e fornisce metodi per elaborarla. |
| [ResourceHandlingContext](./resourcehandlingcontext/) | Questa classe contiene informazioni utilizzate durante l'elaborazione delle risorse. |
| [ResourceHandlingOptions](./resourcehandlingoptions/) | Rappresenta le opzioni di gestione delle risorse. |
| [SaveOptions](./saveoptions/) | Questa è una classe base astratta per classi che consentono all'utente di specificare opzioni aggiuntive durante il salvataggio di un documento in un formato particolare. |
| [TextSaveOptions](./textsaveoptions/) | Rappresenta le opzioni di salvataggio Text |
| [XpsSaveOptions](./xpssaveoptions/) | Classe dati di opzioni specifiche che fornisce alcune proprietà per gestire il risultato della conversione. Ad esempio [`PageSetup`](../com.aspose.html.rendering/pagesetup/) specifica le caratteristiche della pagina. Consultare la documentazione [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-xps/#save-options). |
## Enumerazione

| Enumerazione | Descrizione |
| --- | --- |
| [HTMLSaveFormat](./htmlsaveformat/) | Specifica il formato in cui il documento viene salvato. Puoi trovare maggiori informazioni sul salvataggio di [`HTMLDocument`](../com.aspose.html/htmldocument/) nell'[article](https://docs.aspose.com/html/net/working-with-documents/saving-a-document/). |
| [MarkdownFeatures](./markdownfeatures/) | Un set di flag [`MarkdownFeatures`](../com.aspose.html.saving/markdownfeatures/) è un insieme di zero o più dei seguenti flag, che vengono utilizzati per selezionare gli elementi convertiti in markdown. |
| [MarkdownFormatter](./markdownformatter/) | Specifica il modo in cui l'output verrà formattato. |
| [ResourceHandling](./resourcehandling/) | Questo enum rappresenta le opzioni di gestione delle risorse. |
| [ResourceStatus](./resourcestatus/) | Indica lo stato della risorsa. |
| [UrlRestriction](./urlrestriction/) | Questo enum rappresenta le restrizioni applicate agli URL delle risorse elaborate. |
