## TextSaveOptions.EnableListItemMarkers property

Opzione applicata agli elementi OL e UL durante la conversione da HTML a testo. In effetti, definisce come elaborare i marcatori di elenco esterni degli elementi OL e UL. Se vero, i numeri degli elementi vengono aggiunti prima degli elementi OL, o i punti vengono aggiunti prima degli elementi UL. Se falso, non vengono aggiunti (comportamento predefinito secondo la specifica).

```java
public bool EnableListItemMarkers { get; set; }
```
