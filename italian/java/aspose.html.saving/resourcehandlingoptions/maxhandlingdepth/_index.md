## ResourceHandlingOptions.MaxHandlingDepth property

Ottiene o imposta la profondità massima delle pagine che verranno gestite. Una profondità di 1 significa che verranno gestite solo le pagine direttamente referenziate dal documento salvato. Impostare questa proprietà a -1 comporta la gestione di tutte le pagine. Il valore predefinito è 0.

```java
public int MaxHandlingDepth { get; set; }
```
