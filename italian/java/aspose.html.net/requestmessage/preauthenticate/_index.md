## RequestMessage.PreAuthenticate property

Ottiene o imposta un valore che indica se inviare un'intestazione Authorization con la richiesta.

```java
public bool PreAuthenticate { get; set; }
```

### Property Value

`true` per inviare un'intestazione HTTP Authorization con le richieste dopo che l'autenticazione è avvenuta; altrimenti, `false`. Il valore predefinito è `false`.
