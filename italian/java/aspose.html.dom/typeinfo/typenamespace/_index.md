## TypeInfo.TypeNamespace property

Ottiene il pacchetto del tipo. Il pacchetto del tipo dichiarato per l'elemento o attributo associato o null se l'elemento non ha dichiarazione o se non sono disponibili informazioni sul pacchetto.

```java
public String TypeNamespace { get; }
```

### Property Value

Il pacchetto del tipo.
