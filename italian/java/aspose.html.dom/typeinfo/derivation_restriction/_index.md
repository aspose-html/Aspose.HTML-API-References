## TypeInfo.DERIVATION_RESTRICTION field

Se lo schema del documento è uno XML Schema [XML Schema Part 1], questa costante rappresenta la derivazione per restrizione se sono coinvolti tipi complessi, o una restrizione se sono coinvolti tipi semplici.

```java
public const ulong DERIVATION_RESTRICTION;
```
