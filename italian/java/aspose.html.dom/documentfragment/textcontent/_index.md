## DocumentFragment.TextContent property

Questo attributo restituisce il contenuto testuale di questo nodo e dei suoi discendenti. Quando è definito come null, impostarlo non ha alcun effetto. All'impostazione, eventuali figli che questo nodo potrebbe avere vengono rimossi e, se la nuova stringa non è vuota o null, viene sostituito da un unico nodo Text contenente la stringa a cui è impostato questo attributo.

```java
public String TextContent { get; set; }
```

### Property Value

Il contenuto del testo.
