## Document.DefaultView property

L'attributo IDL defaultView dell'interfaccia Document, al momento del recupero, deve restituire l'oggetto WindowProxy del contesto di navigazione di questo Document, se il Document ha un contesto di navigazione associato, altrimenti null.

public IWindow DefaultView { get; }
