## Document.StrictErrorChecking property

Un attributo che specifica se il controllo degli errori è applicato o meno. Quando impostato su false, l'implementazione è libera di non testare ogni possibile caso di errore normalmente definito nelle operazioni DOM e di non sollevare alcuna DOMException durante le operazioni DOM o di non segnalare errori durante l'uso di Document.normalizeDocument(). In caso di errore, il comportamento è indefinito. Questo attributo è true per impostazione predefinita.

```java
public bool StrictErrorChecking { get; set; }
```

### Property Value

`true` se il controllo degli errori è rigoroso; altrimenti, `false`.
