## Node.PreviousSibling property

La proprietà di sola lettura previousSibling dell'interfaccia [`Node`](../) restituisce il nodo immediatamente precedente a quello specificato nella lista [`childNodes`](../firstchild/) del genitore, o null se il nodo specificato è il primo in tale lista.

```java
public Node PreviousSibling { get; }
```

### Property Value

Un [`Node`](../) che rappresenta il fratello precedente del nodo corrente, o null se non ce ne sono.
