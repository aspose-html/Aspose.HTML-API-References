## Node.NodeValue property

La proprietà nodeValue dell'interfaccia [`Node `](../) restituisce o imposta il valore del nodo corrente.

```java
public String NodeValue { get; set; }
```

### Property Value

Una Stringa contenente il valore del nodo corrente, se presente. Per il documento stesso, nodeValue restituisce null. Per i nodi di testo, commento e CDATA, nodeValue restituisce il contenuto del nodo. Per i nodi attributo, viene restituito il valore dell'attributo.
