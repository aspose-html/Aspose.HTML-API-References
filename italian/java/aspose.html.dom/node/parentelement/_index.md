## Node.ParentElement property

La proprietà di sola lettura parentElement dell'interfaccia [`Node`](../) restituisce il genitore [`Element`](../../element/) del nodo DOM, o null se il nodo non ha alcun genitore, o il suo genitore non è un Element DOM.

```java
public Element ParentElement { get; }
```

### Property Value

Un [`Element`](../../element/) che è l'elemento genitore del nodo corrente, o null se non ce n'è uno.
