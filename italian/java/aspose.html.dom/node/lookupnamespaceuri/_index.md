## Node.LookupNamespaceURI method

Il metodo lookupNamespaceURI() dell'interfaccia Node prende un prefisso come parametro e restituisce l'URI del pacchetto associato su quel nodo, se trovato (e null se non lo è).

```java
public String LookupNamespaceURI(String prefix)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| prefisso | String | Il prefisso da cercare. |

### Valore di ritorno

Una Stringa contenente l'URI del pacchetto corrispondente al prefisso. Se il prefisso non è trovato, restituisce null. Se il prefisso richiesto è null, restituisce l'URI del pacchetto predefinito.
