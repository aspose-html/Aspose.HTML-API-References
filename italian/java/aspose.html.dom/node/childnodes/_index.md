## Node.ChildNodes property

La proprietà di sola lettura childNodes dell'interfaccia Node restituisce una [`NodeList`](../../../com.aspose.html.collections/nodelist/) dinamica dei nodi figli dell'elemento specificato, dove il primo nodo figlio ha indice 0. I nodi figli includono elementi, testo e commenti.

Nota: La [`NodeList`](../../../com.aspose.html.collections/nodelist/) dinamica significa che il suo contenuto viene modificato ogni volta che vengono aggiunti o rimossi nuovi figli.

```java
public NodeList ChildNodes { get; }
```

### Property Value

Una [`NodeList`](../../../com.aspose.html.collections/nodelist/) dinamica contenente i figli del nodo.

Nota: Diverse chiamate a childNodes restituiscono la stessa [`NodeList`](../../../com.aspose.html.collections/nodelist/).
