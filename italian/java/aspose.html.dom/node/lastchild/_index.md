## Node.LastChild property

La proprietà di sola lettura lastChild dell'interfaccia [`Node`](../) restituisce l'ultimo figlio del nodo. Se il suo genitore è un elemento, il figlio è generalmente un nodo elemento, un nodo di testo o un nodo commento. Restituisce null se non ci sono elementi figli.

```java
public Node LastChild { get; }
```

### Property Value

Un [`Node`](../) che è l'ultimo figlio del nodo, oppure null se non ci sono elementi figli.
