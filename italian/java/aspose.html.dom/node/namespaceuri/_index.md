## Node.NamespaceURI property

La proprietà di sola lettura Element.packageURI restituisce l'URI del pacchetto dell'elemento, o null se l'elemento non è in un pacchetto.

```java
public String NamespaceURI { get; }
```

### Property Value

Una stringa che rappresenta l'URI del pacchetto del nome qualificato dell'elemento.
