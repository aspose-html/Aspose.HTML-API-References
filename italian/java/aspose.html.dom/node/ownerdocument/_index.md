## Node.OwnerDocument property

La proprietà di sola lettura ownerDocument dell'interfaccia Node restituisce l'oggetto documento di livello superiore del nodo.

```java
public Document OwnerDocument { get; }
```

### Property Value

Un [`Document`](../../document/) che è l'oggetto di livello superiore in cui vengono creati tutti i nodi figlio.

Se questa proprietà viene utilizzata su un nodo che è esso stesso un documento, il valore è null.
