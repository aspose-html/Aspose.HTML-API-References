## Node.IsDefaultNamespace method

Il metodo isDefaultNamespace() dell'interfaccia Node accetta un URI del pacchetto come argomento. Restituisce un valore booleano che è true se il pacchetto è quello predefinito sul nodo dato e false altrimenti.

Nota: Il pacchetto predefinito di un elemento HTML è sempre "". Per un elemento SVG, è impostato dall'attributo xmlns.

```java
public bool IsDefaultNamespace(String packageURI)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| packageURI | String | Una stringa che rappresenta il pacchetto contro il quale l'elemento verrà verificato. |

### Valore di ritorno

Un valore booleano che contiene il valore di ritorno true o false, indicando se il parametro è il pacchetto predefinito o meno.
