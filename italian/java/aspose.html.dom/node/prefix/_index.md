## Node.Prefix property

La proprietà di sola lettura prefix restituisce il prefisso del pacchetto dell'elemento specificato, o null se non è specificato alcun prefisso.

```java
public String Prefix { get; set; }
```

### Property Value

La proprietà restituisce il prefisso del pacchetto associato.
