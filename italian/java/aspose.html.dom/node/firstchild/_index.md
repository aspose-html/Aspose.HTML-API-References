## Node.FirstChild property

La proprietà read-only firstChild dell'interfaccia [`Node`](../) restituisce il primo figlio del nodo nell'albero, o null se il nodo non ha figli.

Se il nodo è un Document, questa proprietà restituisce il primo nodo nell'elenco dei suoi figli diretti.

```java
public Node FirstChild { get; }
```

### Property Value

Un [`Node`](../), o null se non ce ne sono.
