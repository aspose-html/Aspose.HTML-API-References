## Node.IsSameNode method

Il metodo isSameNode() dell'interfaccia Node è un alias legacy per l'operatore di uguaglianza stretta ===. Cioè, verifica se due nodi sono gli stessi (in altre parole, se fanno riferimento allo stesso oggetto).

Nota: Non è necessario utilizzare isSameNode(); invece usa l'operatore di uguaglianza stretta ===.

```java
public bool IsSameNode(Node otherNode)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| otherNode | Node | Il Node contro cui testare. |

### Valore di ritorno

Un valore booleano che è true se entrambi i nodi sono strettamente uguali, false altrimenti.
