## Node.BaseURI property

La proprietà baseURI di sola lettura dell'interfaccia Node restituisce l'URL base assoluto del documento che contiene il nodo.

L'URL base viene utilizzato per risolvere gli URL relativi quando il browser deve ottenere un URL assoluto, ad esempio durante l'elaborazione dell'attributo src dell'elemento HTML img o degli attributi xlink:href o href in SVG.

```java
public String BaseURI { get; }
```

### Property Value

Il getter baseURI restituisce l'URL base del documento del nodo corrente, serializzato.
