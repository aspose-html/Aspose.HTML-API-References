## Node.IsEqualNode method

Il metodo isEqualNode() dell'interfaccia [`Node`](../) verifica se due nodi sono uguali. Due nodi sono uguali quando hanno lo stesso tipo, caratteristiche definenti (per gli elementi, questo includerebbe il loro ID, il numero di figli, ecc.), i loro attributi corrispondono e così via. Il set specifico di dati che devono corrispondere varia a seconda del tipo dei nodi.

```java
public bool IsEqualNode(Node otherNode)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| otherNode | Node | Il [`Node`](../) con cui confrontare l'uguaglianza. |

### Valore di ritorno

Un valore booleano che è true se i due nodi sono uguali, o false altrimenti. Se otherNode è null, isEqualNode() restituisce sempre false.
