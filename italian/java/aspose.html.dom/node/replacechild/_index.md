## Node.ReplaceChild method

Sostituisce il nodo figlio oldChild con newChild nell'elenco dei figli e restituisce il nodo oldChild. Se newChild è un oggetto [`DocumentFragment`](../../documentfragment/), oldChild viene sostituito da tutti i figli del [`DocumentFragment`](../../documentfragment/) che vengono inseriti nello stesso ordine. Se newChild è già nell'albero, viene prima rimosso.

```java
public Node ReplaceChild(Node node, Node child)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| nodo | Node | Il nuovo nodo che sostituisce oldChild. |
| figlio | Node | Il figlio da sostituire. |

### Valore di ritorno

Il nodo sostituito. È lo stesso nodo di oldChild.
