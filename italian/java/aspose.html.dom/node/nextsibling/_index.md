## Node.NextSibling property

La proprietà read-only nextSibling dell'interfaccia [`Node`](../) restituisce il nodo immediatamente successivo a quello specificato nel [`childNodes`](../childnodes/) del genitore, o restituisce null se il nodo specificato è l'ultimo figlio nell'elemento genitore.

```java
public Node NextSibling { get; }
```

### Property Value

Un [`Node`](../) che rappresenta il fratello successivo del nodo corrente, o null se non ce ne sono.
