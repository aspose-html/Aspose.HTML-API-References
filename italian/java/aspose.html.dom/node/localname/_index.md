## Node.LocalName property

Restituisce la parte locale del nome qualificato di questo nodo. Per i nodi di qualsiasi tipo diverso da [`ELEMENT_NODE`](../element_node/) e [`ATTRIBUTE_NODE`](../attribute_node/) e per i nodi creati con un metodo DOM Level 1, come [`Document.createElement()`](../../document/createelement/), questo è sempre null.

```java
public String LocalName { get; }
```

### Property Value

Una stringa che rappresenta la parte locale del nome qualificato dell'elemento.
