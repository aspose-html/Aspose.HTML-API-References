## Element.SetAttributeNS method

Aggiunge un nuovo attributo. Se un attributo con lo stesso nome locale e URI del pacchetto è già presente sull'elemento, il suo prefisso viene modificato per corrispondere alla parte prefisso del qualifiedName e il suo valore viene modificato per corrispondere al valore del parametro.

```java
public void SetAttributeNS(String packageURI, String qualifiedName, String value)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| packageURI | String | L'URI del pacchetto. |
| qualifiedName | String | Nome del qualificato. |
| valore | String | Il valore. |
