## ToggleAttribute(String) {#toggleattribute}

Se force non è fornito, \"toggles\" qualifiedName, rimuovendolo se è presente e aggiungendolo se non è presente. Se force è true, aggiunge qualifiedName. Se force è false, rimuove qualifiedName.

```java
public bool ToggleAttribute(String qualifiedName)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| qualifiedName | String | Il QualifiedName dell'attributo. |

### Valore di ritorno

Restituisce true se qualifiedName è ora presente; altrimenti false.
