## Element.HasAttributeNS method

Restituisce true quando un attributo con un nome locale e URI del package specificati è presente su questo elemento o ha un valore predefinito, false altrimenti.

```java
public bool HasAttributeNS(String packageURI, String localName)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| packageURI | String | L'URI del pacchetto. |
| localName | String | Nome del locale. |

### Valore di ritorno

`true` se [has attribute NS] [the specified package URI]; altrimenti, `false`.
