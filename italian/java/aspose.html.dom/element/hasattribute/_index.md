## Element.HasAttribute method

Restituisce true quando un attributo con un nome specificato è presente su questo elemento o ha un valore predefinito, false altrimenti.

```java
public bool HasAttribute(String qualifiedName)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| nome | String | Il nome dell'attributo. |

### Valore di ritorno

`true` se il nome specificato ha l'attributo; altrimenti, `false`.
