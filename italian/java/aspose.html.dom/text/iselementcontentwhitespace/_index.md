## Text.IsElementContentWhitespace property

Restituisce se questo nodo di testo contiene spazi bianchi di contenuto elemento, spesso abusivamente chiamati "spazi bianchi ignorabili".

```java
public bool IsElementContentWhitespace { get; }
```

### Property Value

`true` se questa istanza è spazi bianchi di contenuto elemento; altrimenti, `false`.
