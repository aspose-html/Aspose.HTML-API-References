## DOMException.VALIDATION_ERR field

Se una chiamata a un metodo come insertBefore o removeChild rendesse il Nodo non valido rispetto alla "validità parziale", questa eccezione verrebbe sollevata e l'operazione non verrebbe eseguita. Questo codice è utilizzato in [DOM Level 3 Validation]. Fare riferimento a questa specifica per ulteriori informazioni.

```java
public const ushort VALIDATION_ERR;
```
