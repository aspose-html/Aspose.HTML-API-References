## Attr.LocalName property

Restituisce la parte locale del nome qualificato di questo nodo. Per i nodi di qualsiasi tipo diverso da ELEMENT_NODE e ATTRIBUTE_NODE e per i nodi creati con un metodo DOM Level 1, come Document.createElement(), questo è sempre null.

```java
public String LocalName { get; }
```

### Property Value

Il nome del locale.
