## Metodi

| Nome | Descrizione |
| --- | --- |
| [clear](../../com.aspose.html.dom/istorage/clear/)() | Rimuove tutte le coppie chiave/valore, se ce ne sono. |
| [getItem](../../com.aspose.html.dom/istorage/getitem/)(String) | Restituisce il valore corrente associato alla chiave fornita, oppure null se la chiave fornita non esiste. |
| [key](../../com.aspose.html.dom/istorage/key/)(long) | Restituisce il nome della n‑esima chiave, oppure null se n è maggiore o uguale al numero di coppie chiave/valore. |
| [removeItem](../../com.aspose.html.dom/istorage/removeitem/)(String) | Rimuove la coppia chiave/valore con la chiave fornita, se esiste una coppia chiave/valore con quella chiave. |
| [setItem](../../com.aspose.html.dom/istorage/setitem/)(String, String) | Imposta il valore della coppia identificata dalla chiave a valore, creando una nuova coppia chiave/valore se in precedenza non esisteva alcuna coppia per quella chiave. |
