## IDOMImplementation interface

L'interfaccia DOMImplementation fornisce numerosi metodi per eseguire operazioni indipendenti da qualsiasi specifica istanza del modello di oggetto documento.

```java
public interface IDOMImplementation
```

## Metodi

| Nome | Descrizione |
| --- | --- |
| [createDocument](../../com.aspose.html.dom/idomimplementation/createdocument/)(String, String, DocumentType) | Crea un oggetto DOM Document del tipo specificato con il suo elemento documento. |
| [createDocumentType](../../com.aspose.html.dom/idomimplementation/createdocumenttype/)(String, String, String) | Crea un nodo DocumentType vuoto. Le dichiarazioni di entità e le notazioni non sono rese disponibili. Le espansioni di riferimenti di entità e le aggiunte di attributi predefiniti non avvengono. |
| [createHTMLDocument](../../com.aspose.html.dom/idomimplementation/createhtmldocument/)(String) | Restituisce un documento, con un albero di base già costruito includendo un elemento title, a meno che l'argomento title non sia omesso. |
| [hasFeature](../../com.aspose.html.dom/idomimplementation/hasfeature/)() | Verifica se l'implementazione DOM supporta una specifica funzionalità e versione, come specificato in DOM Features. |
