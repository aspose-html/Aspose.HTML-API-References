## ICSSKeyframesRule.FindRule method

Il metodo findRule restituisce la regola con una chiave corrispondente a quella fornita. Se non esiste tale regola, viene restituito un valore null.

```java
public ICSSKeyframeRule FindRule(String key)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| key | String | La chiave che descrive la regola da trovare. La chiave deve corrispondere a un numero compreso tra 0 e 1, altrimenti la regola viene ignorata. |

### Valore di ritorno

Restituisce l'ultimo [`CSSKeyframeRule`](../../icsskeyframerule/) dichiarato che corrisponde al selettore di keyframe specificato. Se non esiste alcuna regola corrispondente, il metodo non fa nulla.
