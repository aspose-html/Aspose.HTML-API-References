## ICSSKeyframesRule.DeleteRule method

Il metodo deleteRule elimina il [`CSSKeyframeRule`](../../icsskeyframerule/) con la chiave fornita. Se non esiste una regola con questa chiave, il metodo non fa nulla.

```java
public void DeleteRule(String key)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| key | String | La chiave che descrive la regola da eliminare. La chiave deve risolvere a un numero compreso tra 0 e 1, altrimenti la regola viene ignorata. |
