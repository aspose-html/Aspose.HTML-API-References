## IDocumentStyle interface

L'interfaccia DocumentStyle fornisce un meccanismo per recuperare i fogli di stile incorporati in un documento. Si prevede che un'istanza dell'interfaccia DocumentStyle possa essere ottenuta utilizzando metodi di casting specifici per il binding su un'istanza dell'interfaccia Document.

Vedi anche la [Document Object Model (DOM) Level 2 Style Specification](http://www.w3.org/TR/2000/REC-DOM-Level-2-Style-20001113).

```java
public interface IDocumentStyle
```
