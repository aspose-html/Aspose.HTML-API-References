## IDocumentStyle.StyleSheets property

Un elenco contenente tutti i fogli di stile collegati esplicitamente o incorporati in un documento. Per i documenti HTML, ciò include i fogli di stile esterni, inclusi tramite l'elemento HTML LINK, e gli elementi STYLE in linea.

```java
public IStyleSheetList StyleSheets { get; }
```

### Property Value

L'elenco contenente tutti i fogli di stile collegati esplicitamente o incorporati in un documento.
