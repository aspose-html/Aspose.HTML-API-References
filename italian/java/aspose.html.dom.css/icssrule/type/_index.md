## ICSSRule.Type property

Il tipo della regola, come definito in [CSSOM # dom-cssrule-type](https://drafts.csswg.org/cssom/#dom-cssrule-type). Si prevede che i metodi di casting specifici per il binding possano essere usati per effettuare il downcast da un'istanza dell'interfaccia CSSRule all'interfaccia derivata specifica implicata dal tipo.

```java
public short Type { get; }
```

### Property Value

Un intero non negativo associato a un particolare tipo di regola. Questo elemento viene inizializzato quando una regola è creata e non può cambiare.
