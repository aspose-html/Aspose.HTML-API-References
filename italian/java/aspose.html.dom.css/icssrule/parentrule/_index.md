## ICSSRule.ParentRule property

Se questa regola è contenuta all'interno di un'altra regola (ad es. una regola di stile all'interno di un blocco @media), questa è la regola contenente. Se questa regola non è annidata all'interno di altre regole, restituisce null.

```java
public ICSSRule ParentRule { get; }
```

### Property Value

Un [`CSSRule`](../) che è il tipo delle regole contenenti. Se la regola corrente è all'interno di una query media, restituirà [`CSSMediaRule`](../../icssmediarule/). Altrimenti restituisce null.
