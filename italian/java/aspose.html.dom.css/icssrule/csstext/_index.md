## ICSSRule.CSSText property

La proprietà cssText dell'interfaccia [`CSSRule`](../) restituisce il testo effettivo di una regola di stile [`CSSStyleSheet`](../../icssstylesheet/).

Nota: non confondere questa proprietà con CSSStyleDeclaration.cssText a livello di elemento.

```java
public String CSSText { get; set; }
```

### Property Value

Restituisce una serializzazione della regola CSS. L'impostazione dell'attributo cssText non deve fare nulla.
