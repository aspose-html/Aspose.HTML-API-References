## ICSSStyleDeclaration.CSSText property

La rappresentazione testuale analizzabile del blocco di dichiarazione (escludendo le parentesi graffe circostanti). Impostare questo attributo comporterà l'analisi del nuovo valore e il ripristino di tutte le proprietà nel blocco di dichiarazione, inclusa la rimozione o l'aggiunta di proprietà.

```java
public String CSSText { get; set; }
```

### Property Value

Impostare questo attributo modifica lo stile inline. Se desideri una rappresentazione testuale di un blocco di dichiarazione calcolato, puoi ottenerla con JSON.Stringify().
