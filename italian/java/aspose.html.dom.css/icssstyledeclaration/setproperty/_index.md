## SetProperty(String, String) {#setproperty}

L'interfaccia del metodo CSSStyleDeclaration.setProperty() è usata per impostare il valore di una proprietà con priorità predefinita all'interno di questo blocco di dichiarazione. La priorità predefinita non è "important", cioè String.Empty

```java
public void SetProperty(String propertyName, String value)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| propertyName | String | Una Stringa che rappresenta il nome della proprietà CSS (in forma con trattino) da modificare. |
| valore | String | Una Stringa contenente il nuovo valore della proprietà. Se non specificata, viene trattata come una Stringa vuota. |

## SetProperty(String, String, String) {#setproperty_1}

L'interfaccia del metodo CSSStyleDeclaration.setProperty() è usata per impostare il valore di una proprietà con priorità predefinita all'interno di questo blocco di dichiarazione. La priorità predefinita non è "important", cioè String.Empty

```java
public void SetProperty(String propertyName, String value, String priority)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| propertyName | String | Una Stringa che rappresenta il nome della proprietà CSS (in forma con trattino) da modificare. |
| valore | String | Una Stringa contenente il nuovo valore della proprietà. Se non specificata, viene trattata come una Stringa vuota. |
| priorità | String | Una Stringa che consente di impostare la priorità CSS "important". Se non specificata, viene trattata come una Stringa vuota. I valori accettati sono: valore Stringa "important", parola chiave undefined o valore Stringa vuoto "". |
