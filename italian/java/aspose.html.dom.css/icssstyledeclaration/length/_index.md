## ICSSStyleDeclaration.Length property

La proprietà di sola lettura restituisce un numero intero di proprietà che sono state impostate esplicitamente in questo blocco di dichiarazione CSS. L'intervallo di indici validi è da 0 a length-1 inclusi.

```java
public int Length { get; }
```

### Property Value

Un intero che fornisce il numero di stili impostati esplicitamente sul genitore dell'istanza.
