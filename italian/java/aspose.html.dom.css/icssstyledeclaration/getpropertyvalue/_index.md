## ICSSStyleDeclaration.GetPropertyValue method

L'interfaccia del metodo CSSStyleDeclaration.getPropertyValue() restituisce una String contenente il valore di una proprietà CSS specificata.

```java
public String GetPropertyValue(String propertyName)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| propertyName | String | propertyName è una Stringa che rappresenta il nome della proprietà (in forma hyphen) da verificare. |

### Valore di ritorno

value è una Stringa che contiene il valore della proprietà. Se non impostata, restituisce la Stringa vuota.
