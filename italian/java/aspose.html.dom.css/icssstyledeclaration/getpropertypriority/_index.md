## ICSSStyleDeclaration.GetPropertyPriority method

Utilizzato per recuperare la priorità di una proprietà CSS (ad es. il qualificatore "important") se la proprietà è stata impostata esplicitamente in questo blocco di dichiarazione.

```java
public String GetPropertyPriority(String propertyName)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| propertyName | String | property è un DOMString che rappresenta il nome della proprietà da verificare. |

### Valore di ritorno

priority è un DOMString che rappresenta la priorità (e.g. "important") se esiste. Se non esiste, restituisce la Stringa vuota.
