## ICSSStyleDeclaration indexer

Utilizzata per recuperare le proprietà che sono state impostate esplicitamente in questo blocco di dichiarazione. L'ordine delle proprietà recuperate con questo metodo non deve corrispondere all'ordine in cui sono state impostate. Questo metodo può essere usato per iterare su tutte le proprietà in questo blocco di dichiarazione.

```java
public String this[int index] { get; }
```

### Valore di ritorno

propertyName è una Stringa che rappresenta il nome della proprietà CSS all'indice specificato.

### Property Value

index è l'indice del nodo da recuperare. L'indice parte da zero.
