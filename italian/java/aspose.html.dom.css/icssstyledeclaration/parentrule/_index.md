## ICSSStyleDeclaration.ParentRule property

La proprietà di sola lettura CSSStyleDeclaration.parentRule restituisce un CSSRule che è il genitore di questo blocco di stile, ad es. un [`CSSStyleRule`](../../icssstylerule/) che rappresenta lo stile per un selettore CSS.

```java
public ICSSRule ParentRule { get; }
```

### Property Value

La regola CSS che contiene questo blocco di dichiarazione o null se questo [`CSSStyleDeclaration`](../) non è collegato a un [`CSSRule`](../../icssrule/).
