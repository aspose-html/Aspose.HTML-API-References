## ICSS2Properties.PitchRange property

Specifica la variazione nella frequenza media. La frequenza percepita di una voce umana è determinata dalla frequenza fondamentale e tipicamente ha un valore di 120 Hz per una voce maschile e 210 Hz per una voce femminile. Le lingue umane sono parlate con variazioni di inflessione e di tono; queste variazioni trasmettono significati aggiuntivi e enfasi. Pertanto, una voce molto animata, cioè fortemente inflessa, presenta un ampio intervallo di tono. Questa proprietà specifica l’intervallo entro il quale si verificano queste variazioni, cioè quanto la frequenza fondamentale può discostarsi dalla frequenza media.

```java
public String PitchRange { get; set; }
```
