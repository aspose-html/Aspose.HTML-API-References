## ICSS2Properties.Font property

La proprietà 'font' è, salvo quanto descritto di seguito, una proprietà abbreviata per impostare 'font-style', 'font-variant', 'font-weight', 'font-size', 'line-height' e 'font-family' nello stesso punto del foglio di stile. La sintassi di questa proprietà si basa su una notazione tipografica tradizionale abbreviata per impostare più proprietà relative ai font.

public String Font { get; set; }
