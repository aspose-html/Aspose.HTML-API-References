## ICSS2Properties.Richness property

Specifica la ricchezza, o brillantezza, della voce parlata. Una voce ricca \"si farà sentire\" in una grande stanza, una voce morbida no. (Il termine \"morbida\" si riferisce a come appare la forma d'onda quando viene disegnata.)

```java
public String Richness { get; set; }
```
