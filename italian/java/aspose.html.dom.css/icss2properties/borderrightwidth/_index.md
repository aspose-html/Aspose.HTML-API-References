## ICSS2Properties.BorderRightWidth property

Questa proprietà è una proprietà abbreviata per impostare 'border-top-width', 'border-right-width', 'border-bottom-width' e 'border-left-width' nello stesso punto del foglio di stile.

Se è presente un solo valore, viene applicato a tutti i lati. Se ci sono due valori, i bordi superiore e inferiore sono impostati al primo valore e i bordi destro e sinistro al secondo. Se ci sono tre valori, il bordo superiore è impostato al primo valore, i bordi sinistro e destro al secondo, e il bordo inferiore al terzo. Se ci sono quattro valori, questi si applicano rispettivamente a superiore, destro, inferiore e sinistro.

```java
public String BorderRightWidth { get; set; }
```

### Valore di ritorno

proprietà border-right-width
