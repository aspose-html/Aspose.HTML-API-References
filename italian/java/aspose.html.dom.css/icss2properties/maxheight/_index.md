## ICSS2Properties.MaxHeight property

Queste due proprietà consentono agli autori di limitare le altezze delle caselle a un certo intervallo. I valori hanno i seguenti significati:

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - Specifica un'altezza calcolata minima o massima fissa.'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - Specifica una percentuale per determinare il valore calcolato. La percentuale è calcolata rispetto all'altezza del [blocco contenitore](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#containing-block) della casella generata. Se l'altezza del blocco contenitore non è specificata esplicitamente (cioè dipende dall'altezza del contenuto), il valore percentuale è interpretato come 'auto'.none - (Solo su ['max-height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-max-height)) Nessun limite all'altezza della casella.

public String MaxHeight { get; set; }
