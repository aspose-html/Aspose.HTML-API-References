## ICSS2Properties.PageBreakInside property

I valori per queste proprietà hanno i seguenti significati:

auto - Né forzare né vietare un'interruzione di pagina prima (dopo, all'interno) della scatola generata. always - Forzare sempre un'interruzione di pagina prima (dopo) della scatola generata. avoid - Evitare un'interruzione di pagina prima (dopo, all'interno) della scatola generata. left - Forzare una o due interruzioni di pagina prima (dopo) della scatola generata in modo che la pagina successiva sia formattata come pagina sinistra. right - Forzare una o due interruzioni di pagina prima (dopo) della scatola generata in modo che la pagina successiva sia formattata come pagina destra.

public String PageBreakInside { get; set; }
