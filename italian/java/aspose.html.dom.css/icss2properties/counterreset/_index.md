## ICSS2Properties.CounterReset property

La proprietà ['counter-reset'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-counter-reset) contiene anche un elenco di uno o più nomi di contatori, ognuno facoltativamente seguito da un intero. L'intero fornisce il valore a cui il contatore è impostato ad ogni occorrenza dell'elemento. Il valore predefinito è 0.

```java
public String CounterReset { get; set; }
```

### Valore di ritorno

proprietà counter-reset
