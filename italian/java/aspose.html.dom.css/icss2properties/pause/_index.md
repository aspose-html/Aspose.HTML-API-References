## ICSS2Properties.Pause property

La proprietà ['pause'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause) è una scorciatoia per impostare ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) e ['pause-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-after). Se vengono forniti due valori, il primo valore è ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) e il secondo è ['pause-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-after). Se viene fornito un solo valore, si applica a entrambe le proprietà.

```java
public String Pause { get; set; }
```

proprietà pause
