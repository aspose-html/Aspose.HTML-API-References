## ICSS2Properties.MarkerOffset property

Questa proprietà specifica la distanza tra i [bordi](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#border-edge) di una casella marker e la sua [casella principale](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#principal-box) associata. L'offset può essere una ([lunghezza](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)) specificata dall'utente o scelto dall'UA ('auto'). Le lunghezze possono essere negative, ma potrebbero esserci limiti specifici dell'implementazione.

```java
public String MarkerOffset { get; set; }
```
