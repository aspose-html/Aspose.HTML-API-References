## ICSS2Properties.BackgroundImage property

Questa proprietà imposta l'immagine di sfondo di un elemento. Quando si imposta un'immagine di sfondo, gli autori dovrebbero specificare anche un colore di sfondo che verrà usato quando l'immagine non è disponibile. Quando l'immagine è disponibile, viene renderizzata sopra il colore di sfondo. (Così, il colore è visibile nelle parti trasparenti dell'immagine).

```java
public String BackgroundImage { get; set; }
```

### Valore di ritorno

proprietà background-image

### Property Value

I valori per questa proprietà sono o , per specificare l'immagine, o 'none', quando non viene usata alcuna immagine.
