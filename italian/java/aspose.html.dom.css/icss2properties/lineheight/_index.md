## ICSS2Properties.LineHeight property

Se la proprietà è impostata su un elemento [block-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#block-level) il cui contenuto è composto da elementi [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level), specifica l'altezza minima di ogni casella inline generata.

Se la proprietà è impostata su un elemento [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level), specifica l'altezza esatta di ogni casella generata dall'elemento. (Eccezione per gli elementi inline [replaced](https://www.w3.org/TR/1998/REC-CSS2-19980512/conform.html#replaced-element), dove l'altezza della casella è fornita dalla proprietà ['height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-height).)

```java
public String LineHeight { get; set; }
```

### Valore di ritorno

proprietà line-height
