## ICSS2Properties.BorderCollapse property

Questa proprietà seleziona il modello di bordi di una tabella. Il valore 'separate' seleziona il modello di bordi separati. Il valore 'collapse' seleziona il modello di bordi collassati. I modelli sono descritti di seguito.

public String BorderCollapse { get; set; }
