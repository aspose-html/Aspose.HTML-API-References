## ICSS2Properties.Background property

La proprietà 'background' è una proprietà abbreviata per impostare le singole proprietà di sfondo (ad esempio, 'background-color', 'background-image', 'background-repeat', 'background-attachment' e 'background-position') nello stesso punto del foglio di stile.

```java
public String Background { get; set; }
```

### Valore di ritorno

la proprietà background

### Property Value

Ottiene o imposta una proprietà abbreviata per impostare le singole proprietà di sfondo nello stesso punto del foglio di stile.
