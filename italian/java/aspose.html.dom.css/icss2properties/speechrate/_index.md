## ICSS2Properties.SpeechRate property

Questa proprietà specifica la velocità di lettura. Nota che sono consentiti sia valori assoluti sia relativi delle parole chiave (confronta con ['font-size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html#propdef-font-size)). I valori hanno i seguenti significati:

'[number](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-number)' - Specifica la velocità di lettura in parole al minuto, una quantità che varia leggermente a seconda della lingua ma è comunque ampiamente supportata dai sintetizzatori vocali.

x-slow - Equivalente a 80 parole al minuto.

slow - Equivalente a 120 parole al minuto.

medio - Uguale a 180 - 200 parole al minuto.

veloce - Uguale a 300 parole al minuto.

x-veloce - Uguale a 500 parole al minuto.

più veloce - Aggiunge 40 parole al minuto al ritmo di parlato corrente.

più lento - Sottrae 40 parole al minuto dal ritmo di parlato corrente.

```java
public String SpeechRate { get; set; }
```
