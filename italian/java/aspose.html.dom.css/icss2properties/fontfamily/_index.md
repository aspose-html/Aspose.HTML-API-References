## ICSS2Properties.FontFamily property

Questa proprietà specifica un elenco prioritario di nomi di famiglie di caratteri e/o nomi di famiglie generiche. Per affrontare il problema che un singolo carattere potrebbe non contenere glifi per visualizzare tutti i caratteri in un documento, o che non tutti i caratteri sono disponibili su tutti i sistemi, questa proprietà consente agli autori di specificare un elenco di caratteri, tutti dello stesso stile e dimensione, provati in sequenza per verificare se contengono un glifo per un determinato carattere. Questo elenco è chiamato set di caratteri.

```java
public String FontFamily { get; set; }
```
