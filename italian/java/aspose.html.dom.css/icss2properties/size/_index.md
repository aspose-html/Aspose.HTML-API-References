## ICSS2Properties.Size property

Questa proprietà specifica la dimensione e l'orientamento di una casella di pagina.

La dimensione di una casella di pagina può essere "assoluta" (dimensione fissa) o "relativa" (scalabile, cioè adattabile alle dimensioni dei fogli disponibili). Le caselle di pagina relative consentono agli agenti utente di scalare un documento e di utilizzare in modo ottimale la dimensione di destinazione.

Tre valori per la proprietà ['size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-size) creano una casella di pagina relativa:

auto - La casella di pagina sarà impostata alla dimensione e all'orientamento del foglio di destinazione.landscape - Sovrascrive l'orientamento della destinazione. La casella di pagina ha la stessa dimensione della destinazione, e i lati più lunghi sono orizzontali.portrait - Sovrascrive l'orientamento della destinazione. La casella di pagina ha la stessa dimensione della destinazione, e i lati più corti sono orizzontali.

public String Size { get; set; }
