## ICSS2Properties.FontStretch property

La proprietà ['font-stretch'](https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html#propdef-font-stretch) seleziona un carattere normale, condensato o esteso da una famiglia di font. I valori assoluti delle parole chiave hanno il seguente ordine, dal più stretto al più largo:

ultra-condensedextra-condensedcondensedsemi-condensednormalsemi-expandedexpandedextra-expandedultra-expanded
