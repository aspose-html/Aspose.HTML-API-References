## ICSS2Properties.EmptyCells property

Nel modello dei bordi separati, questa proprietà controlla il rendering dei bordi attorno alle celle che non hanno contenuto visibile. Le celle vuote e le celle con la proprietà 'visibility' impostata su 'hidden' sono considerate prive di contenuto visibile.

```java
public String EmptyCells { get; set; }
```
