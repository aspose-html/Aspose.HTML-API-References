## ICSS2Properties.Direction property

Questa proprietà specifica la direzione di scrittura di base dei blocchi e la direzione di embedding e override (vedi ['unicode-bidi'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-unicode-bidi)) per l'algoritmo bidirezionale Unicode. Inoltre, specifica la direzione del layout delle colonne della [tabella](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html), la direzione dell'[overflow](https://www.w3.org/TR/1998/REC-CSS2-19980512/visufx.html#overflow) orizzontale e la posizione di un'ultima riga incompleta in un blocco nel caso di 'text-align: justify'.

```java
public String Direction { get; set; }
```

proprietà direction
