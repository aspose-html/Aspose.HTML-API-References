## ICSS2Properties.TableLayout property

La proprietà ['table-layout'](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#propdef-table-layout) controlla l'algoritmo usato per disporre le celle, le righe e le colonne della tabella. I valori hanno il significato seguente:

fixed - Utilizza l'algoritmo di layout della tabella fissoauto - Utilizza qualsiasi algoritmo di layout della tabella automatico

```java
public String TableLayout { get; set; }
```
