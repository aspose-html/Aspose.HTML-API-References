## ICSS2Properties.CounterIncrement property

La proprietà ['counter-increment'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-counter-increment) accetta uno o più nomi di contatori (identificatori), ognuno facoltativamente seguito da un intero. L'intero indica di quanto il contatore viene incrementato per ogni occorrenza dell'elemento. L'incremento predefinito è 1. Sono consentiti interi zero e negativi.

```java
public String CounterIncrement { get; set; }
```

proprietà counter-increment
