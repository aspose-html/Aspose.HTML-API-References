## ICSS2Properties.TextTransform property

Questa proprietà controlla gli effetti di capitalizzazione del testo di un elemento. I valori hanno i seguenti significati:

capitalize - Inserisce il primo carattere di ogni parola in maiuscolo. uppercase - Inserisce tutti i caratteri di ogni parola in maiuscolo. lowercase - Inserisce tutti i caratteri di ogni parola in minuscolo. none - Nessun effetto di capitalizzazione.

```java
public String TextTransform { get; set; }
```
