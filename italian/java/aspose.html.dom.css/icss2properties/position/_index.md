## ICSS2Properties.Position property

I valori di questa proprietà hanno i seguenti significati:

static - La casella è una casella normale, disposta secondo il [flusso normale](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#normal-flow). Le proprietà ['left'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-left) e ['top'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-top) non si applicano.
