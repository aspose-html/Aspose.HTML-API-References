## ICSS2Properties.BackgroundRepeat property

Se è specificata un'immagine di sfondo, questa proprietà indica se l'immagine è ripetuta (tiled) e come. Tutta la ripetizione copre le aree di contenuto e padding di un box. I valori hanno i seguenti significati:

repeat - L'immagine è ripetuta sia orizzontalmente che verticalmente. repeat-x - L'immagine è ripetuta solo orizzontalmente. repeat-y - L'immagine è ripetuta solo verticalmente. no-repeat - L'immagine non è ripetuta: viene disegnata una sola copia dell'immagine.

```java
public String BackgroundRepeat { get; set; }
```

proprietà background-repeat
