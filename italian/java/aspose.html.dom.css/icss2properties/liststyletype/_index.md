## ICSS2Properties.ListStyleType property

Questa proprietà specifica l'aspetto del marcatore dell'elemento di elenco se ['list-style-image'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-list-style-image) ha il valore 'none' o se l'immagine indicata dall'URI non può essere visualizzata. Il valore 'none' indica nessun marcatore, altrimenti esistono tre tipi di marcatori: glifi, sistemi di numerazione e sistemi alfabetici. Nota. Gli elenchi numerati migliorano l'accessibilità del documento rendendo più facile la navigazione degli elenchi.

I glifi sono specificati con disc, circle e square. Il loro rendering esatto dipende dall'agente utente.

I sistemi di numerazione sono specificati con:

decimal - Numeri decimali, a partire da 1. decimal-leading-zero - Numeri decimali con zeri iniziali (es., 01, 02, 03, ..., 98, 99). lower-roman - Numeri romani minuscoli (i, ii, iii, iv, v, ecc.). upper-roman - Numeri romani maiuscoli (I, II, III, IV, V, ecc.). hebrew - Numerazione tradizionale ebraica. georgian - Numerazione tradizionale georgiana (an, ban, gan, ..., he, tan, in, in-an, ...). armenian - Numerazione tradizionale armena. cjk-ideographic - Numeri ideografici semplici. hiragana - a, i, u, e, o, ka, ki, ... katakana - A, I, U, E, O, KA, KI, ... hiragana-iroha - i, ro, ha, ni, ... katakana-iroha - I, RO, HA, NI, HO, HE, TO, ...

public String ListStyleType { get; set; }
