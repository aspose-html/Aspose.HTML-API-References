## ICSS2Properties.Speak property

Questa proprietà specifica se il testo verrà renderizzato in modo uditivo e, in tal caso, in quale maniera (in modo alquanto analogo alla proprietà ['display'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-display) ). I valori possibili sono:

none - Sopprime il rendering uditivo in modo che l'elemento non richieda tempo per il rendering. Nota, tuttavia, che i discendenti possono sovrascrivere questo valore e saranno pronunciati. (Per essere sicuri di sopprimere il rendering di un elemento e dei suoi discendenti, usa la proprietà ['display'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-display) ).normal - Utilizza regole di pronuncia dipendenti dalla lingua per il rendering di un elemento e dei suoi figli.spell-out - Pronuncia il testo lettera per lettera (utile per acronimi e abbreviazioni).

public String Speak { get; set; }
