## ICSS2Properties.TextDecoration property

Questa proprietà descrive le decorazioni aggiunte al testo di un elemento. Se la proprietà è specificata per un elemento [block-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#block-level), influisce su tutti i discendenti inline-level dell'elemento. Se è specificata per (o influisce su) un elemento [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level), influisce su tutte le caselle generate dall'elemento. Se l'elemento non ha contenuto o contenuto testuale (ad esempio, l'elemento IMG in HTML), gli agenti utente devono [ignorare](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#ignore) questa proprietà.

I valori hanno i seguenti significati:

none - Non produce alcuna decorazione del testo. underline - Ogni riga di testo è sottolineata. overline - Ogni riga di testo ha una linea sopra di essa. line-through - Ogni riga di testo ha una linea attraversata al centro. blink - Il testo lampeggia (alterna tra visibile e invisibile).
