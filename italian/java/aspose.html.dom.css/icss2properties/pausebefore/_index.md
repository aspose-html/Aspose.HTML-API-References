## ICSS2Properties.PauseBefore property

Queste proprietà specificano una pausa da osservare prima (o dopo) la lettura del contenuto di un elemento. I valori hanno i seguenti significati:

'[time](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-time)' - Esprime la pausa in unità di tempo assolute (secondi e millisecondi).'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - Si riferisce all'inverso del valore della proprietà ['speech-rate'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-speech-rate). Per esempio, se il speech-rate è di 120 parole al minuto (cioè una parola dura mezzo secondo, o 500 ms), allora un ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) del 100 % corrisponde a una pausa di 500 ms e un ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) del 20 % corrisponde a 100 ms.

```java
public String PauseBefore { get; set; }
```

### Valore di ritorno

proprietà pause-before
