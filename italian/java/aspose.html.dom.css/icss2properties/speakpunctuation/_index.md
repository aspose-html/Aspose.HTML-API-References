## ICSS2Properties.SpeakPunctuation property

Questa proprietà specifica come viene pronunciata la punteggiatura. I valori hanno i seguenti significati:

code - La punteggiatura come punti e virgola, parentesi graffe, ecc. deve essere pronunciata letteralmente. none - La punteggiatura non deve essere pronunciata, ma viene resa naturalmente come varie pause.

```java
public String SpeakPunctuation { get; set; }
```
