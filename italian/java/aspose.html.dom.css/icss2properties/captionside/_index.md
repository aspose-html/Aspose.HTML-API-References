## ICSS2Properties.CaptionSide property

Questa proprietà specifica la posizione della casella della didascalia rispetto alla casella della tabella. I valori hanno i seguenti significati:

top - Posiziona la casella della didascalia sopra la casella della tabella. bottom - Posiziona la casella della didascalia sotto la casella della tabella. left - Posiziona la casella della didascalia a sinistra della casella della tabella. right - Posiziona la casella della didascalia a destra della casella della tabella.

```java
public String CaptionSide { get; set; }
```
