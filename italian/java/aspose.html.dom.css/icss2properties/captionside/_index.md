## ICSS2Properties.CaptionSide property

Questa proprietà specifica la posizione della scatola della didascalia rispetto alla scatola della tabella. I valori hanno i seguenti significati:

top - Posiziona la scatola della didascalia sopra la scatola della tabella. bottom - Posiziona la scatola della didascalia sotto la scatola della tabella. left - Posiziona la scatola della didascalia a sinistra della scatola della tabella. right - Posiziona la scatola della didascalia a destra della scatola della tabella.

```java
public String CaptionSide { get; set; }
```
