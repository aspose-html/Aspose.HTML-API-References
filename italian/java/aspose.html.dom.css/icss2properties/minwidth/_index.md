## ICSS2Properties.MinWidth property

Queste due proprietà consentono agli autori di limitare la larghezza delle caselle a un determinato intervallo. I valori hanno i seguenti significati:

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - Specifica una larghezza minima o massima calcolata fissa.'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - Specifica una percentuale per determinare il valore calcolato. La percentuale è calcolata rispetto alla larghezza del [blocco contenitore](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#containing-block).none - (Solo su ['max-width'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-max-width)) Nessun limite alla larghezza della casella.

public String MinWidth { get; set; }
