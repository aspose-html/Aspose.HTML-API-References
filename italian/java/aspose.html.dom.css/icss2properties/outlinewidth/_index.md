## ICSS2Properties.OutlineWidth property

Il contorno creato con le proprietà outline è disegnato "sopra" un box, cioè il contorno è sempre in primo piano e non influenza la posizione o le dimensioni del box o di altri box. Pertanto, visualizzare o sopprimere i contorni non provoca un reflow.

```java
public String OutlineWidth { get; set; }
```
