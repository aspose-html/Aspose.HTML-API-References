## ICSS2Properties.OutlineWidth property

Il contorno creato con le proprietà outline è disegnato "over" un box, cioè il contorno è sempre in cima e non influisce sulla posizione o dimensione del box o di altri box. Pertanto, la visualizzazione o la soppressione dei contorni non provoca il reflow.

```java
public String OutlineWidth { get; set; }
```

### Valore di ritorno

proprietà outline-width
