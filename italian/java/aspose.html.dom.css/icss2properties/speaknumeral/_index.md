## ICSS2Properties.SpeakNumeral property

Questa proprietà controlla come vengono pronunciati i numeri. I valori hanno i seguenti significati:

digits - Pronuncia il numero come cifre individuali. Ad esempio, "237" viene pronunciato "Due Tre Sette". continuous - Pronuncia il numero come un numero intero. Ad esempio, "237" viene pronunciato "Duecentotrentasette". Le rappresentazioni in parole dipendono dalla lingua.

```java
public String SpeakNumeral { get; set; }
```
