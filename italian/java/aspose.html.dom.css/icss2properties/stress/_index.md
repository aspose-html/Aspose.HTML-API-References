## ICSS2Properties.Stress property

Specifica l'altezza dei "picchi locali" nel contorno intonativo di una voce. Per esempio, l'inglese è una lingua con accento, e diverse parti di una frase sono assegnate a stress primario, secondario o terziario. Il valore di ['stress'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-stress) controlla la quantità di inflessione risultante da questi marcatori di stress. Questa proprietà è complementare alla proprietà ['pitch-range'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pitch-range) ed è fornita per consentire agli sviluppatori di sfruttare visualizzazioni uditive di alto livello.

```java
public String Stress { get; set; }
```
