## ICSS2Properties.Height property

Questa proprietà specifica l'[altezza del contenuto](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#content-height) delle caselle generate da elementi a livello di blocco e [sostituiti](https://www.w3.org/TR/1998/REC-CSS2-19980512/conform.html#replaced-element) elementi.

Questa proprietà non si applica agli elementi [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) non sostituiti. L'altezza delle caselle di un elemento inline non sostituito è data dal valore (eventualmente ereditato) della proprietà ['line-height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-line-height) dell'elemento.

```java
public String Height { get; set; }
```
