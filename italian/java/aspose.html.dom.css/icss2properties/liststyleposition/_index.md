## ICSS2Properties.ListStylePosition property

Questa proprietà specifica la posizione della casella del marcatore nella casella di blocco principale. I valori hanno i seguenti significati:

outside - La casella del marcatore è fuori dalla casella di blocco principale. Nota. CSS1 non specificava la posizione precisa della casella del marcatore e per motivi di compatibilità, CSS2 rimane altrettanto ambiguo. Per un controllo più preciso delle caselle del marcatore, si prega di usare markers. inside - La casella del marcatore è la prima casella inline nella casella di blocco principale, dopo la quale il contenuto dell'elemento fluisce.

```java
public String ListStylePosition { get; set; }
```
