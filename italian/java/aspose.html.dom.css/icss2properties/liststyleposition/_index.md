## ICSS2Properties.ListStylePosition property

Questa proprietà specifica la posizione della casella del marcatore nella casella di blocco principale. I valori hanno i seguenti significati:

outside - La casella del marcatore è al di fuori della casella di blocco principale. Nota. CSS1 non specificava la posizione precisa della casella del marcatore e, per motivi di compatibilità, CSS2 rimane altrettanto ambiguo. Per un controllo più preciso delle caselle dei marcatori, si prega di utilizzare markers. inside - La casella del marcatore è la prima casella inline nella casella di blocco principale, dopo la quale scorre il contenuto dell'elemento.

```java
public String ListStylePosition { get; set; }
```
