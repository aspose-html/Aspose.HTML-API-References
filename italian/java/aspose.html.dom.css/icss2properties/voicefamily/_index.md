## ICSS2Properties.VoiceFamily property

Il valore è un elenco prioritario, separato da virgole, di nomi di famiglie vocali (confronta con ['font-family'](https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html#propdef-font-family)). I valori hanno i seguenti significati:

'generic-voice' - I valori sono famiglie vocali. I valori possibili sono 'male', 'female' e 'child'.'specific-voice' - I valori sono istanze specifiche (ad es., comedian, trinoids, carlos, lani).

```java
public String VoiceFamily { get; set; }
```

proprietà voice-family
