## ICSS2Properties.BorderSpacing property

Le lunghezze specificano la distanza che separa i bordi delle celle adiacenti. Se viene specificata una sola lunghezza, essa fornisce sia la spaziatura orizzontale che quella verticale. Se ne vengono specificate due, la prima fornisce la spaziatura orizzontale e la seconda quella verticale. Le lunghezze non possono essere negative.

```java
public String BorderSpacing { get; set; }
```

proprietà border-spacing
