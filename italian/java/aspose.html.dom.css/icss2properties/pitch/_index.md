## ICSS2Properties.Pitch property

Specifica la frequenza media (una frequenza) della voce parlata. La frequenza media di una voce dipende dalla famiglia vocale. Per esempio, la frequenza media per una voce maschile standard è circa 120 Hz, ma per una voce femminile è circa 210 Hz.

public String Pitch { get; set; }
