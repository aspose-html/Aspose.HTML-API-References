## ICSS2Properties.BackgroundAttachment property

Se è specificata un'immagine di sfondo, questa proprietà specifica se è fissata rispetto al viewport ('fixed') o scorre insieme al documento ('scroll').

Anche se l'immagine è fissata, è visibile solo quando si trova nello sfondo o nell'area di padding dell'elemento. Pertanto, a meno che l'immagine non sia ripetuta ('background-repeat: repeat'), potrebbe risultare invisibile.

```java
public String BackgroundAttachment { get; set; }
```
