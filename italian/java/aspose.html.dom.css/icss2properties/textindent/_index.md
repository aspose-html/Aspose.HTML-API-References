## ICSS2Properties.TextIndent property

Questa proprietà specifica l'indentazione della prima riga di testo in un blocco. Più precisamente, specifica l'indentazione della prima box che fluisce nella prima [line box](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#line-box) del blocco. La box è indentata rispetto al bordo sinistro (o destro, per layout da destra a sinistra) della line box. Gli user agent dovrebbero renderizzare questa indentazione come spazio vuoto.

I valori hanno i seguenti significati:

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - L'indentazione è di lunghezza fissa.'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - L'indentazione è una percentuale della larghezza del blocco contenitore.

```java
public String TextIndent { get; set; }
```
