## ICSS2Properties.FontVariant property

In un font small-caps, i glifi delle lettere minuscole assomigliano a quelli delle maiuscole, ma in dimensioni più piccole e con proporzioni leggermente diverse. La proprietà 'font-variant' richiede un tale font per le scritture bicamerali (che hanno due casi, come lo script latino). Questa proprietà non ha effetto visibile per le scritture unicamerali (che hanno un solo caso, come la maggior parte dei sistemi di scrittura del mondo).

```java
public String FontVariant { get; set; }
```
