## ICSS2Properties.FontSizeAdjust property

Nei script bicamerali, la dimensione apparente soggettiva e la leggibilità di un carattere dipendono meno dal valore del loro 'font-size' rispetto al valore del loro 'x-height', o, più utilmente, dal rapporto di questi due valori, chiamato valore di aspetto (font-size diviso x-height). Più alto è il valore di aspetto, più è probabile che un carattere a dimensioni più piccole sia leggibile. Al contrario, i caratteri con un valore di aspetto più basso diventeranno illeggibili più rapidamente al di sotto di una certa soglia di dimensione rispetto a quelli con un valore di aspetto più alto. Una sostituzione di caratteri basata solo sulla dimensione del font può portare a caratteri illeggibili.

public String FontSizeAdjust { get; set; }
