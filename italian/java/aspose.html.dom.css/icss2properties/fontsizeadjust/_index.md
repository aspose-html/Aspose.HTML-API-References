## ICSS2Properties.FontSizeAdjust property

In script bicamerali, la dimensione apparente soggettiva e la leggibilità di un carattere dipendono meno dal valore della loro 'font-size' rispetto al valore della loro 'x-height', o, più utilmente, al rapporto di questi due valori, chiamato valore di aspetto (dimensione del carattere divisa per x-height). Più alto è il valore di aspetto, più è probabile che un carattere a dimensioni più piccole sia leggibile. Al contrario, i caratteri con un valore di aspetto più basso diventeranno illeggibili più rapidamente al di sotto di una certa soglia rispetto a quelli con un valore di aspetto più alto. Una semplice sostituzione dei caratteri basata solo sulla dimensione del carattere può portare a caratteri illeggibili.

```java
public String FontSizeAdjust { get; set; }
```
