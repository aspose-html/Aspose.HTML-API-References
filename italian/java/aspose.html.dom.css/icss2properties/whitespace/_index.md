## ICSS2Properties.WhiteSpace property

Questa proprietà dichiara come il [whitespace](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#whitespace) all'interno dell'elemento viene gestito. I valori hanno i seguenti significati:

normal - Questo valore indica agli user agent di comprimere le sequenze di spazi bianchi e di interrompere le righe quando necessario per riempire le caselle di linea. Interruzioni di linea aggiuntive possono essere create dalle occorrenze di "\A" nel contenuto generato (ad es., per l'elemento BR in HTML). pre - Questo valore impedisce agli user agent di comprimere le sequenze di spazi bianchi. Le righe vengono interrotte solo ai ritorni a capo nella sorgente, o alle occorrenze di "\A" nel contenuto generato. nowrap - Questo valore comprime gli spazi bianchi come per 'normal', ma sopprime le interruzioni di linea all'interno del testo eccetto quelle create da "\A" nel contenuto generato (ad es., per l'elemento BR in HTML).

```java
public String WhiteSpace { get; set; }
```

### Valore di ritorno

proprietà white-space
