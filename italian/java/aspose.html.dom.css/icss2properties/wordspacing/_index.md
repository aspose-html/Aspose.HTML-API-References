## ICSS2Properties.WordSpacing property

Questa proprietà specifica il comportamento della spaziatura tra le parole. I valori hanno i seguenti significati:

normal - Lo spazio inter-parola normale, come definito dal font corrente e/o dall'UA.'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - Questo valore indica lo spazio inter-parola in aggiunta allo spazio predefinito tra le parole. I valori possono essere negativi, ma potrebbero esserci limiti specifici dell'implementazione.

```java
public String WordSpacing { get; set; }
```

### Valore di ritorno

proprietà word-spacing
