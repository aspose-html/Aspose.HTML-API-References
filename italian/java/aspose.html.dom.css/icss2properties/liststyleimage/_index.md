## ICSS2Properties.ListStyleImage property

Questa proprietà imposta l'immagine che verrà usata come marcatore dell'elemento di elenco. Quando l'immagine è disponibile, sostituirà il marcatore impostato con il marcatore ['list-style-type'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-list-style-type).

```java
public String ListStyleImage { get; set; }
```

### Valore di ritorno

proprietà list-style-image
