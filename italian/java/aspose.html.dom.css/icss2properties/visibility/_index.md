## ICSS2Properties.Visibility property

La proprietà ['visibility'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visufx.html#propdef-visibility) specifica se le caselle generate da un elemento vengono renderizzate. Le caselle invisibili influenzano comunque il layout (imposta la proprietà ['display'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-display) su 'none' per sopprimere completamente la generazione delle caselle). I valori hanno i seguenti significati:

visible - La casella generata è visibile. hidden - La casella generata è invisibile (completamente trasparente), ma influisce comunque sul layout. collapse - Consulta la sezione sugli [effetti dinamici di righe e colonne](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#dynamic-effects) nelle tabelle. Se usato su elementi diversi da righe o colonne, 'collapse' ha lo stesso significato di 'hidden'.

```java
public String Visibility { get; set; }
```
