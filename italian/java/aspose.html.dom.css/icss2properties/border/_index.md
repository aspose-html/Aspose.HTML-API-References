## ICSS2Properties.Border property

La proprietà 'border' è una proprietà abbreviata per impostare la stessa larghezza, colore e stile per tutti e quattro i bordi di una casella. A differenza delle proprietà abbreviate 'margin' e 'padding', la proprietà 'border' non può impostare valori diversi sui quattro bordi. Per farlo, è necessario utilizzare una o più delle altre proprietà border.

```java
public String Border { get; set; }
```

proprietà border
