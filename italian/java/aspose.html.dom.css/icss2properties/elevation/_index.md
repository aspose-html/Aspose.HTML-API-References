## ICSS2Properties.Elevation property

I valori di questa proprietà hanno i seguenti significati:

'angle' - Specifica l'elevazione come un angolo, tra '-90deg' e '90deg'. '0deg' significa sull'orizzonte anteriore, che indica approssimativamente al livello dell'ascoltatore. '90deg' significa direttamente sopra e '-90deg' significa direttamente sotto. below - Stesso di '-90deg'. level - Stesso di '0deg'. above - Stesso di '90deg'. higher - Aggiunge 10 gradi all'elevazione corrente. lower - Sottrae 10 gradi dall'elevazione corrente.

public String Elevation { get; set; }
