## ICSS2Properties.Marks property

Nella stampa di alta qualità, i segni sono spesso aggiunti al di fuori del page box. Questa proprietà specifica se dovrebbero essere renderizzati segni di croce, segni di ritaglio o entrambi appena al di fuori del bordo del [page box](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#page-box).

I segni di ritaglio indicano dove la pagina dovrebbe essere tagliata. I segni di croce (noti anche come segni di registro o segni di registrazione) sono usati per allineare i fogli.

I segni sono visibili solo sui page box assoluti (vedi la proprietà ['size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-size)). Nei page box relativi, il page box sarà allineato con il bersaglio e i segni saranno al di fuori dell'area stampabile.

La dimensione, lo stile e la posizione dei segni di spunta dipendono dall'agente utente.

public String Marks { get; set; }
