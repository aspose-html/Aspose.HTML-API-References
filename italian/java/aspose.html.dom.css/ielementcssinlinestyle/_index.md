## IElementCSSInlineStyle interface

Le informazioni di stile inline associate agli elementi sono esposte tramite l'attributo style. Questo rappresenta il contenuto dell'attributo STYLE per gli elementi HTML (o per elementi in altri schemi o DTD che utilizzano l'attributo STYLE allo stesso modo). Ci si aspetta che un'istanza dell'interfaccia ElementCSSInlineStyle possa essere ottenuta utilizzando metodi di casting specifici del binding su un'istanza dell'interfaccia Element quando l'elemento supporta informazioni di stile CSS inline.

Vedi anche il [CSS Object Model (CSSOM) # IElementCSSInlineStyle](https://www.w3.org/TR/cssom-1/#the-elementcssinlinestyle-mixin)
