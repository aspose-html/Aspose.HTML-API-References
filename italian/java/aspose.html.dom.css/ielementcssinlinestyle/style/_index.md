## IElementCSSInlineStyle.Style property

L'attributo style deve restituire un oggetto blocco di dichiarazione CSS il cui flag computed è non impostato, la cui regola CSS genitore è null e il cui nodo proprietario è l'oggetto contesto.

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

Il blocco di dichiarazione CSS associato al nodo o null se non esiste alcun blocco di dichiarazione CSS associato.
