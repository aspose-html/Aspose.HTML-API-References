## IMediaList indexer

Il metodo item(index) deve restituire una serializzazione della query media nella collezione di query media fornita dall'indice, o null, se l'indice è maggiore o uguale al numero di query media nella collezione.

```java
public String this[int index] { get; }
```

### Valore di ritorno

Restituisce una String che rappresenta una query media come testo, dato il valore indice della query media all'interno della [`MediaList`](../).

### Property Value

Un intero che rappresenta l'indice dell'elemento nella collezione da restituire.
