## IMediaList.MediaText property

Un Stringifier che restituisce un DOMString che rappresenta la MediaList come testo e consente anche di impostare una nuova MediaList.

```java
public String MediaText { get; }
```

### Property Value

La rappresentazione testuale analizzabile della lista dei media. È un elenco di media separato da virgole.

### Eccezioni

| eccezione | condizione |
| --- | --- |
| DOMException | SYNTAX_ERR: Generato se il valore String specificato presenta un errore di sintassi e non è analizzabile. NO_MODIFICATION_ALLOWED_ERR: Generato se questa lista di media è di sola lettura. |
