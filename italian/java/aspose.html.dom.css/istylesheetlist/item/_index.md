## IStyleSheetList indexer

Il metodo item(index) deve restituire il [`CSS style sheet`](../../icssstylesheet/) all'indice specificato nella collezione. Se non esiste alcun oggetto all'indice specificato nella collezione, il metodo deve restituire null.

```java
public ICSSStyleSheet this[int index] { get; }
```

### Valore di ritorno

Un oggetto [`CSSStyleSheet`](../../icssstylesheet/), o null se non esiste per questo indice.

### Property Value

Un intero che rappresenta l'indice dell'elemento nella collezione da restituire.
