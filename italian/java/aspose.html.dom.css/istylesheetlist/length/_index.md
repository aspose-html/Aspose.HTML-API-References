## IStyleSheetList.Length property

L'attributo length deve restituire il numero di fogli di stile CSS rappresentati dalla collezione. L'intervallo di indici dei fogli di stile figlio validi è da 0 a length-1 inclusi.

```java
public int Length { get; }
```

### Property Value

Un intero che indica il numero di elementi nella collezione.
