## ICSSKeyframeRule interface

L'interfaccia `CSSKeyframeRule` descrive un oggetto che rappresenta un insieme di stili per un determinato keyframe. Corrisponde al contenuto di un singolo keyframe di una regola @keyframes.

```java
public interface ICSSKeyframeRule : ICSSRule
```

## Proprietà

| Nome | Descrizione |
| --- | --- |
| [getKeyText](../../com.aspose.html.dom.css/icsskeyframerule/keytext/) La proprietà keyText dell'interfaccia CSSKeyframeRule rappresenta il selettore del keyframe come un elenco separato da virgole di valori percentuali. Le parole chiave from e to corrispondono rispettivamente a 0% e 100%. |
| [getStyle](../../com.aspose.html.dom.css/icsskeyframerule/style/) La proprietà di sola lettura CSSKeyframeRule.style è l'interfaccia [`CSSStyleDeclaration`](../icssstyledeclaration/) per il blocco di dichiarazione del `CSSKeyframeRule`. |
