## ICSSKeyframeRule.KeyText property

La proprietà keyText dell'interfaccia CSSKeyframeRule rappresenta il selettore di keyframe come un elenco separato da virgole di valori percentuali. Le parole chiave from e to corrispondono rispettivamente a 0% e 100%.

```java
public String KeyText { get; }
```

### Property Value

Restituisce il selettore di keyframe come un elenco separato da virgole di valori percentuali.
