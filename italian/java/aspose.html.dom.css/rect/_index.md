## Rect class

L'interfaccia Rect è usata per rappresentare qualsiasi valore rect. Questa interfaccia riflette i valori nella proprietà di stile sottostante. Pertanto, le modifiche apportate agli oggetti [`CSSPrimitiveValue`](../cssprimitivevalue/) modificano la proprietà di stile.

```java
public class Rect : DOMObject
```
