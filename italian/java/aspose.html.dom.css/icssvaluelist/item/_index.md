## ICSSValueList indexer

Questo metodo è usato per recuperare un CSSValue tramite indice ordinale. L'ordine in questa collezione rappresenta l'ordine dei valori nella proprietà di stile CSS. Se l'indice è maggiore o uguale al numero di valori nella lista, restituisce null.

Vedi anche il [CSSOM](https://www.w3.org/TR/2000/REC-DOM-Level-2-Style-20001113/css.html#CSS-CSSValueList)[#CSSValueList](https://www.w3.org/TR/2000/REC-DOM-Level-2-Style-20001113/css.html#CSS-CSSValueList).

```java
public CSSValue this[int index] { get; }
```

### Valore di ritorno

Il [`CSSValue`](../../cssvalue/) nella posizione dell'indice nella [`CSSValueList`](../../cssvaluelist/), o null se non è un indice valido.

### Property Value

L'indice nella collezione.

## Osservazioni

Questa funzionalità è stata originariamente definita nella specifica [DOM Style Level 2](https://www.w3.org/TR/DOM-Level-2-Style), ma è stata rimossa da qualsiasi sforzo di standardizzazione da allora.

È stata sostituita da un'API moderna, ma incompatibile, [CSS Typed Object Model API](https://developer.mozilla.org/en-US/docs/Web/API/CSS_Typed_OM_API) che ora è sul percorso di standardizzazione.
