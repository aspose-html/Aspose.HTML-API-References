## ICSSMediaRule.InsertRule method

Il metodo insertRule() dell'interfaccia CSSGroupingRule aggiunge una nuova regola CSS a un elenco di regole CSS.

```java
public long InsertRule(String rule, long index)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| regola | String | La regola media come CSSOMString. |
| index | Int64 | Un indice opzionale in cui inserire la regola; il valore predefinito è 0. |

### Valore di ritorno

Il metodo insertRule(rule, index) restituisce il risultato dell'invocazione dell'inserimento di una regola CSS nelle regole CSS figlie all'indice specificato.
