## ICSSMediaRule.Media property

La proprietà di sola lettura media dell'interfaccia [`CSSMediaRule`](../) MediaList rappresenta il supporto di destinazione previsto per le informazioni di stile.

```java
public IMediaList Media { get; }
```

### Property Value

L'attributo media deve restituire un oggetto MediaList per l'elenco di query media specificate con la regola @media.
