## ICSSMediaRule.CSSRules property

La proprietà cssRules dell'interfaccia CSSGroupingRule restituisce un [`CSSRuleList`](../../icssrulelist/) contenente una collezione di oggetti [`CSSRule`](../../icssrule/).

```java
public ICSSRuleList CSSRules { get; }
```

### Property Value

L'attributo cssRules deve restituire un oggetto [`CSSRuleList`](../../icssrulelist/) per le regole CSS figlie.
