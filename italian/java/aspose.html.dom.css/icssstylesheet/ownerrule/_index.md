## ICSSStyleSheet.OwnerRule property

La proprietà di sola lettura ownerRule di CSSStyleSheet restituisce il [`CSSImportRule`](../../icssimportrule/) corrispondente alla regola at-rule @import che ha importato il foglio di stile nel documento. Se il foglio di stile non è stato importato nel documento usando @import, il valore restituito è null.

```java
public ICSSRule OwnerRule { get; }
```

### Property Value

Un CSSImportRule corrispondente alla regola @import che ha importato il foglio di stile nel documento. Se il foglio di stile non è stato importato nel documento usando @import, il valore restituito è null.
