## ICSSStyleSheet.CSSRules property

La proprietà di sola lettura cssRules di CSSStyleSheet restituisce un [`CSSRuleList`](../../icssrulelist/) live che fornisce un elenco aggiornato in tempo reale di tutte le regole CSS che compongono il foglio di stile. Ogni elemento dell'elenco è un [`CSSRule`](../../icssrule/) che definisce una singola regola.

```java
public ICSSRuleList CSSRules { get; }
```

### Property Value

Un [`CSSRuleList`](../../icssrulelist/) in aggiornamento continuo che contiene ciascuna delle regole CSS che compongono il foglio di stile. Ogni voce nell'elenco delle regole è un oggetto [`CSSRule`](../../icssrule/) che descrive una regola del foglio di stile.
