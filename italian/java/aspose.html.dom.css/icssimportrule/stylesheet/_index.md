## ICSSImportRule.StyleSheet property

Il foglio di stile a cui si riferisce questa regola, se è stato caricato. Il valore di questo attributo è null se il foglio di stile non è ancora stato caricato o se non verrà caricato (ad esempio se il foglio di stile è per un tipo di media non supportato dall'agente utente).

```java
public ICSSStyleSheet StyleSheet { get; }
```

### Property Value

Restituisce il foglio di stile CSS specificato dalla regola @import. Verrà fornito sotto forma di un oggetto [`CSSStyleSheet`](../../icssstylesheet/).
