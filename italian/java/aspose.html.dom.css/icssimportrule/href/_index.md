## ICSSImportRule.Href property

La proprietà href di sola lettura dell'interfaccia CSSImportRule restituisce l'URL specificato dalla regola @import.

L'URL risolto sarà l'attributo href del foglio di stile associato.

```java
public String Href { get; }
```

### Property Value

Restituisce l'URL del foglio di stile associato specificato dalla regola @import.
