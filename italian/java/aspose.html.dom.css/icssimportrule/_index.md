## ICSSImportRule interface

L'interfaccia CSSImportRule rappresenta una regola @import all'interno di un foglio di stile CSS. La regola @import è utilizzata per importare regole di stile da altri fogli di stile.

```java
public interface ICSSImportRule : ICSSRule
```

## Proprietà

| Nome | Descrizione |
| --- | --- |
| [getHref](../../com.aspose.html.dom.css/icssimportrule/href/) La proprietà href di sola lettura dell'interfaccia CSSImportRule restituisce l'URL specificato dalla regola @import. |
| [getMedia](../../com.aspose.html.dom.css/icssimportrule/media/) La proprietà media di sola lettura dell'interfaccia CSSImportRule restituisce un oggetto MediaList, contenente il valore dell'attributo media del foglio di stile associato. |
| [getStyleSheet](../../com.aspose.html.dom.css/icssimportrule/stylesheet/) Il foglio di stile a cui si riferisce questa regola, se è stato caricato. Il valore di questo attributo è null se il foglio di stile non è ancora stato caricato o non verrà caricato (ad esempio se il foglio di stile è per un tipo di media non supportato dall'agente utente). |
