## CSSPrimitiveValue.GetCounterValue method

Questo metodo è usato per ottenere il valore Counter. Se questo valore CSS non contiene un valore counter, viene sollevata una DOMException. La modifica della proprietà di stile corrispondente può essere effettuata usando l'interfaccia Counter.

```java
public abstract Counter GetCounterValue()
```

### Valore di ritorno

Restituisce il valore Counter
