## CSSPrimitiveValue.SetIntValue method

Un metodo per impostare il valore int con un'unità specificata. Se la proprietà associata a questo valore non può accettare l'unità specificata o il valore int, il valore rimarrà invariato e verrà sollevata una DOMException.

```java
public abstract void SetIntValue(ushort unitType, int intValue)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| unitType | UInt16 | Tipo dell'unità. |
| intValue | Int32 | Il valore int. |
