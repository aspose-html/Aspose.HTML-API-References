## CSSPrimitiveValue.SetStringValue method

Un metodo per impostare il valore String con l'unità specificata. Se la proprietà associata a questo valore non può accettare l'unità specificata o il valore String, il valore rimarrà invariato e verrà sollevata una DOMException.

```java
public abstract void SetStringValue(ushort StringType, String StringValue)
```

| --- | --- | --- |
| StringType | UInt16 | Tipo della stringa. |
| StringValue | String | Il valore della stringa. |
