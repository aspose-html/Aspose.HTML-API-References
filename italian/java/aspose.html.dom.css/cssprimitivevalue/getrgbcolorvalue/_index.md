## CSSPrimitiveValue.GetRGBColorValue method

Questo metodo è usato per ottenere il colore RGB. Se questo valore CSS non contiene un valore di colore RGB, viene sollevata una DOMException. La modifica della proprietà di stile corrispondente può essere effettuata usando l'interfaccia RGBColor.

```java
public abstract RGBColor GetRGBColorValue()
```

### Valore di ritorno

Restituisce il valore del colore RGB
