## CSSPrimitiveValue.GetRectValue method

Questo metodo è usato per ottenere il valore Rect. Se questo valore CSS non contiene un valore rect, viene sollevata una DOMException. La modifica della proprietà di stile corrispondente può essere effettuata usando l'interfaccia Rect.

```java
public abstract Rect GetRectValue()
```

### Valore di ritorno

Restituisce il valore Rect
