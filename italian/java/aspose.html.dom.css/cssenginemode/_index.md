## CSSEngineMode enumeration

Specifica la modalità CSSEngine. I valori hanno il significato seguente:

default - Il parser CSS funzionerà secondo le raccomandazioni w3c e non supporta estensioni personalizzate. not-strict - Tutte le proprietà non documentate saranno analizzate e potranno essere accessibili tramite.

```java
[Flags]
public enum CSSEngineMode
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Default | `0` | Il parser CSS funzionerà secondo le raccomandazioni w3c e non supporta le estensioni personalizzate. |
| NotStrict | `1` | Il parser CSS funzionerà in modalità non rigorosa. Tutte le proprietà non documentate saranno analizzate e potranno essere accessibili tramite. |
