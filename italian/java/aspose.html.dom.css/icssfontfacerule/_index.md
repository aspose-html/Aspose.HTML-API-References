## ICSSFontFaceRule interface

L'interfaccia CSSFontFaceRule rappresenta una regola @font-face in un foglio di stile CSS. La regola @font-face è utilizzata per contenere un insieme di descrizioni di font.

```java
public interface ICSSFontFaceRule : ICSSRule
```
