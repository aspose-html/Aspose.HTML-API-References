## ICSSStyleRule.Style property

La proprietà di stile in sola lettura è l'interfaccia [`CSSStyleDeclaration`](../../icssstyledeclaration/) per il blocco di dichiarazione del [`CSSStyleRule`](../).

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

L'attributo style deve restituire un oggetto CSSStyleDeclaration per la regola di stile, con le seguenti proprietà:

flag calcolato - Unset.declarations - Le dichiarazioni dichiarate nella regola, nell'ordine specificato.parent CSS rule - L'oggetto contesto.owner node - Null.
