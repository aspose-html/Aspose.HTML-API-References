## ICSSStyleRule interface

L'interfaccia CSSStyleRule rappresenta una singola regola di stile CSS. L'attributo selectorText, al recupero, deve restituire il risultato della serializzazione del gruppo di selettori associato.

```java
public interface ICSSStyleRule : ICSSRule
```

## Proprietà

| Nome | Descrizione |
| --- | --- |
| [getSelectorText](../../com.aspose.html.dom.css/icssstylerule/selectortext/) La rappresentazione testuale del selettore per il set di regole. L'implementazione potrebbe aver rimosso spazi bianchi insignificanti durante l'analisi del selettore. |
| [getStyle](../../com.aspose.html.dom.css/icssstylerule/style/) La proprietà di stile in sola lettura è l'interfaccia [`CSSStyleDeclaration`](../icssstyledeclaration/) per il blocco di dichiarazione del `CSSStyleRule`. |
