## ICSSCharsetRule interface

L'interfaccia CSSCharsetRule rappresenta una regola @charset in un foglio di stile CSS. Il valore dell'attributo encoding non influisce sulla codifica dei dati di testo negli oggetti DOM; questa codifica è sempre UTF-16. Dopo che un foglio di stile è stato caricato, il valore dell'attributo encoding è il valore trovato nella regola @charset. Se non c'era alcun @charset nel documento originale, non viene creata alcuna CSSCharsetRule. Il valore dell'attributo encoding può anche essere usato come suggerimento per la codifica utilizzata nella serializzazione del foglio di stile.
