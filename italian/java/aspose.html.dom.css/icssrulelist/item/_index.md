## ICSSRuleList indexer

Utilizzata per recuperare una regola CSS mediante il metodo item() (http://www.w3.org/TR/DOM-Level-2-Style/css.html#CSS-CSSRuleList). L'ordine in questa collezione rappresenta l'ordine delle regole nel foglio di stile CSS. Se l'indice è maggiore o uguale al numero di regole nella lista, restituisce null.

```java
public ICSSRule this[int index] { get; }
```

### Valore di ritorno

Il metodo item(index) deve restituire l'oggetto CSSRule in posizione indice nella collezione. Se non esiste alcun oggetto in quella posizione, il metodo deve restituire null.

### Property Value

L'indice nella collezione di regole CSS.
