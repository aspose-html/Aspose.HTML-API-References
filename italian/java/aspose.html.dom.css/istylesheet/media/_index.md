## IStyleSheet.Media property

La proprietà media dell'interfaccia [`StyleSheet`](../) specifica il media di destinazione previsto per le informazioni di stile. È un oggetto [`MediaList`](../../imedialist/) simile a un array, di sola lettura, e può essere rimosso con deleteMedium() e aggiunto con appendMedium().

```java
public IMediaList Media { get; }
```

### Property Value

L'attributo media deve restituire l'oggetto [`MediaList`](../../imedialist/) associato al foglio di stile CSS.
