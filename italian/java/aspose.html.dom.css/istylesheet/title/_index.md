## IStyleSheet.Title property

La proprietà title dell'interfaccia [`StyleSheet`](../) restituisce il titolo consigliato del foglio di stile corrente.

Il titolo è spesso specificato nel [`ownerNode`](../ownernode/).

```java
public String Title { get; }
```

### Property Value

L'attributo parentStyleSheet deve restituire il foglio di stile CSS genitore [`CSS style sheet`](../../icssstylesheet/).
