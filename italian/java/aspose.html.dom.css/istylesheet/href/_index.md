## IStyleSheet.Href property

La proprietà href dell'interfaccia [`StyleSheet`](../) restituisce la posizione del foglio di stile.

```java
public String Href { get; }
```

### Property Value

uri è una Stringa che contiene l'URI del foglio di stile.

## Osservazioni

Se il foglio di stile è un foglio di stile collegato, il valore del suo attributo è la sua posizione. Per i fogli di stile inline, il valore di questo attributo è NULL.

Questa proprietà è di sola lettura in Firefox, Opera, Google Chrome e Safari, ed è di lettura/scrittura in Internet Explorer.
