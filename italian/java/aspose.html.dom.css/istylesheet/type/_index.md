## IStyleSheet.Type property

Specifica il linguaggio del foglio di stile per questo foglio di stile. Il linguaggio del foglio di stile è specificato come tipo di contenuto (ad es. \"text/css\").

```java
public String Type { get; }
```

### Property Value

L'attributo type deve restituire il tipo.
