### Property Value

## Osservazioni

Il colore di ogni pixel è rappresentato come un numero a 32 bit: 8 bit per ciascuno dei componenti alfa, rosso, verde e blu (ARGB). Il componente alfa specifica la trasparenza del colore: 0 è completamente trasparente e 255 è completamente opaco. Allo stesso modo, un valore A di 255 rappresenta un colore opaco. Un valore A da 1 a 254 rappresenta un colore semitrasparente. Il colore diventa più opaco man mano che A si avvicina a 255.
