## CSSValueList.CSSText property

La proprietà cssText dell'interfaccia [`CSSValue`](../../cssvalue/) rappresenta il valore corrente della proprietà CSS calcolata.

Nota: Questa proprietà faceva parte di un tentativo di creare un modello di oggetti CSS tipizzato. Questo tentativo è stato abbandonato e la maggior parte dei browser non lo implementa.

```java
public String CSSText { get; set; }
```

### Property Value

Una DOMString che rappresenta il valore corrente della proprietà CSS.
