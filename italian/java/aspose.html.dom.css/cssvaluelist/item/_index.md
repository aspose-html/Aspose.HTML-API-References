## CSSValueList indexer

Il metodo item() dell'interfaccia CSSValueList viene usato per recuperare un CSSValue tramite indice ordinal.

L'ordine in questa collezione rappresenta l'ordine dei valori nella proprietà di stile CSS. Se l'indice è maggiore o uguale al numero di valori nella lista, questo metodo restituisce null.

```java
public CSSValue this[int index] { get; }
```

### Valore di ritorno

Un oggetto CSSValue nella posizione di indice nella CSSValueList, oppure null se l'indice non è valido.

### Property Value

Un unsigned long che rappresenta l'indice del valore CSS all'interno della collezione.
