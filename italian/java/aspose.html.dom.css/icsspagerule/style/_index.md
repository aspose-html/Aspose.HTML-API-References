## ICSSPageRule.Style property

La proprietà di sola lettura style dell'interfaccia [`CSSPageRule`](../) restituisce un oggetto [`CSSStyleDeclaration`](../../icssstyledeclaration/). Questo rappresenta un oggetto che è un blocco di dichiarazione CSS e espone informazioni di stile e vari metodi e proprietà correlati allo stile.

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

Un oggetto [`CSSStyleDeclaration`](../../icssstyledeclaration/) che rappresenta un blocco di dichiarazione CSS.
