## ICSSPageRule interface

L'interfaccia CSSPageRule rappresenta una regola @page all'interno di un foglio di stile CSS. La regola @page è utilizzata per specificare le dimensioni, l'orientamento, i margini, ecc. di una pagina per i media paginati.

```java
public interface ICSSPageRule : ICSSRule
```
