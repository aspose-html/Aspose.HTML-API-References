## ILinkStyle interface

L'interfaccia LinkStyle fornisce un meccanismo per recuperare un foglio di stile dal nodo responsabile del suo collegamento a un documento. Un'istanza dell'interfaccia LinkStyle può essere ottenuta utilizzando metodi di casting specifici per il binding su un'istanza di un nodo di collegamento (HTMLLinkElement,

HTMLStyleElement o ProcessingInstruction in DOM Level 2).

Vedi anche il [CSS Object Model (CSSOM) # ](https://www.w3.org/TR/cssom-1/#the-linkstyle-interface)[LinkStyle](https://www.w3.org/TR/cssom-1/#the-linkstyle-interface).
