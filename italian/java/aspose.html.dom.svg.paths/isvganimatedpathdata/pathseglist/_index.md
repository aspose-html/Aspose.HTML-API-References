## ISVGAnimatedPathData.PathSegList property

Fornisce l'accesso ai contenuti di base (cioè statici) dell'attributo ‘d’ in una forma che corrisponde uno a uno con la sintassi di SVG. Pertanto, se l'attributo ‘d’ ha un \"moveto assoluto (M)\" e un \"arcto assoluto (A)\", allora pathSegList conterrà due voci: un SVG_PATHSEG_MOVETO_ABS e un SVG_PATHSEG_ARC_ABS.

```java
public SVGPathSegList PathSegList { get; }
```

### Property Value

L'elenco dei segmenti di percorso.
