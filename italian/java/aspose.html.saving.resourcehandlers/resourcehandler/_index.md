## ResourceHandler class

Questa classe è responsabile della gestione delle risorse. Fornisce metodi che consentono di controllare cosa verrà fatto con il [`Resource`](../../com.aspose.html.saving/resource/), così come quale riferimento verrà scritto nella risorsa padre [`Resource`](../../com.aspose.html.saving/resource/).
