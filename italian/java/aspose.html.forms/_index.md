Il pacchetto fornisce l'accesso a numerosi oggetti (elementi) responsabili dell'interattività dell'utente all'interno del modulo come componente di pagina web.

## Classi

| Classe | Descrizione |
| --- | --- |
| [ButtonElement](./buttonelement/) | Il ButtonElement rappresenta un wrapper associato all'HTMLButtonElement. |
| [DataListElement](./datalistelement/) | Il DataListElement rappresenta un wrapper associato all'HTMLDataListElement. |
| [FormEditor](./formeditor/) | Questa classe rappresenta l'editor su [`HTMLFormElement`](../com.aspose.html/htmlformelement/) che crea un modo più semplice per gli sviluppatori .net di modificare i moduli HTML. |
| [FormElement](./formelement/) | Rappresenta la classe base per gli elementi del modulo. |
| [FormElement&lt;T&gt;](./formelement-1/) | Il [`FormElement`](../com.aspose.html.forms/formelement/) rappresenta il campo generico. |
| [FormSubmitter](./formsubmitter/) | Questa classe consente di preparare il [`HTMLFormElement`](../com.aspose.html/htmlformelement/) specificato, raccoglie i valori dall'elemento del modulo, li invia al server remoto e riceve una risposta. |
| [InputElement](./inputelement/) | Il InputElement rappresenta un wrapper associato all'HTMLInputElement. |
| [OptionCollection](./optioncollection/) | Il OptionElements rappresenta un wrapper associato a IHTMLOptionsCollection. |
| [OptionElement](./optionelement/) | Il OptionElement rappresenta un wrapper associato all'HTMLOptionElement. |
| [SelectElement](./selectelement/) | Il SelectElement rappresenta un wrapper associato all'HTMLSelectElement. |
| [SubmissionResult](./submissionresult/) | Questa classe rappresenta il risultato dell'invio dei dati del modulo al server. |
| [TextAreaElement](./textareaelement/) | Il TextAreaElement rappresenta un wrapper associato all'HTMLTextAreaElement. |
## Enumerazione

| Enumerazione | Descrizione |
| --- | --- |
| [ButtonType](./buttontype/) | Questa enumerazione rappresenta gli stati del pulsante. |
| [FormElementType](./formelementtype/) | Rappresenta un'enumerazione dei tipi di elementi del modulo e le loro corrispondenze con gli elementi HTML. |
| [InputElementType](./inputelementtype/) | Rappresenta gli stati del campo di input. |
