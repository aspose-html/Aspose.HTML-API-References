Il pacchetto **com.aspose.html.rendering.pdf.encryption** contiene classi di dati che descrivono i dettagli della crittografia PDF come password, algoritmo di crittografia e così via.

## Classi

| Classe | Descrizione |
| --- | --- |
| [PdfEncryptionInfo](./pdfencryptioninfo/) | Contiene dettagli per una crittografia PDF. |
## Enumerazione

| Enumerazione | Descrizione |
| --- | --- |
| [PdfEncryptionAlgorithm](./pdfencryptionalgorithm/) | Enum dei mode di crittografia. Descrive l'uso dell'algoritmo e della lunghezza della chiave. Questo enum è esteso per poter aumentare ulteriormente la funzionalità. Questo enum implementa il pattern \"Base-to-Core\". |
| [PdfPermissions](./pdfpermissions/) | Questo enum rappresenta i permessi dell'utente per un PDF. |
