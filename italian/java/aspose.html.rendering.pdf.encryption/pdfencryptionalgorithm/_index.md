## PdfEncryptionAlgorithm enumeration

Enum dei modi di crittografia. Descrive l'uso dell'algoritmo e della lunghezza della chiave. Questo enum è esteso per poter aumentare ulteriormente la funzionalità. Questo enum implementa il pattern "Base-to-Core".

```java
public enum PdfEncryptionAlgorithm
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| RC4_40 | `0` | Algoritmo, con una lunghezza della chiave di crittografia RC4 di 40 bit; |
| RC4_128 | `1` | Algoritmo, con una lunghezza della chiave di crittografia RC4 di 128 bit e un set di permessi avanzato; |
