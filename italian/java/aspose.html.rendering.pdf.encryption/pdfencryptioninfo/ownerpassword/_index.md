## PdfEncryptionInfo.OwnerPassword property

Ottiene o imposta la password Owner.

```java
public String OwnerPassword { get; set; }
```

### Property Value

La password Owner.

## Osservazioni

Aprire il documento con la password Owner corretta (presumendo che non sia la stessa della password utente) consente l'accesso completo (owner) al documento. Questo accesso illimitato include la possibilità di modificare le password del documento e le autorizzazioni di accesso.
