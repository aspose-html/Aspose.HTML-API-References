## PdfEncryptionInfo.UserPassword property

Ottiene o imposta la password dell'utente.

```java
public String UserPassword { get; set; }
```

### Property Value

La password dell'utente.

## Osservazioni

L'apertura del documento con la password utente corretta (o l'apertura di un documento che non ha una password utente) consente di eseguire operazioni aggiuntive in base alle autorizzazioni di accesso utente specificate nel dizionario di crittografia del documento.
