L'obiettivo del pacchetto **com.aspose.html.converters** è fornire un facile accesso ai metodi di conversione. Offre un'ampia gamma di conversioni verso i formati più popolari, come PDF, XPS, formati immagine, ecc. Casi d'uso di conversione più specifici (rendering, salvataggio) sono presentati da funzioni API di basso livello, ben note e documentate, nei pacchetti orientati al soggetto.

| Classe | Descrizione |
| --- | --- |
| [Converter](./converter/) | Facade condivisa solo per gli scenari di conversione più frequenti. Fornisce un'ampia gamma di conversioni verso i formati più popolari, come PDF, XPS, formati immagine, ecc. Casi d'uso più specifici di conversione (rendering, salvataggio) sono presentati da funzioni API di basso livello, ben note e documentate. |
