## Converter class

Facade condivisa solo per gli scenari di conversione più comuni. Fornisce un'ampia gamma di conversioni verso i formati più popolari, come PDF, XPS, formati immagine, ecc. Casi d'uso più specifici di conversione (rendering, salvataggio) sono presentati da funzioni API di basso livello, ben note e documentate.

Informazioni più dettagliate sulla conversione specifica sono disponibili nella [documentazione Aspose](https://docs.aspose.com/html/net/converting-between-formats/)
