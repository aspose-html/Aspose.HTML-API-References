## Spazi dei nomi

| Spazio dei nomi | Descrizione |

| [com.aspose.html](./aspose.html/) | Il pacchetto Aspose.Html contiene classi e metodi per manipolare i [`documenti HTML`](aspose.html/htmldocument/), sia semplici che complessi e in tempo reale. Aspose.HTML per Java consente agli sviluppatori di Inserire, Rimuovere, Sostituire nodi HTML, estrarre informazioni di stile CSS, Navigare attraverso il [`documento HTML`](aspose.html/htmldocument/) sia tramite [`NodeIterator`](aspose.html.dom.traversal/inodeiterator/), [`TreeWalker`](aspose.html.dom.traversal/itreewalker/) forniti dalle Specifiche di Traversal, XPath o query di selettori CSS. Offre anche lo scripting che permette di manipolare il DOM HTML tramite JavaScript. Oltre a HTML, questa API fornisce anche la capacità di caricare EPUB e MHTML. Le API Aspose sono famose per le loro funzionalità di conversione tra formati di file e questa API fornisce anche la capacità di caricare file HTML e renderizzare l'output in PDF, XPS e formati di immagine raster includendo JPEG, PNG, BMP e TIFF. |

I Cascading Style Sheets (CSS) sono un linguaggio di fogli di stile che consente a autori e utenti di applicare stili (ad es., caratteri e spaziature) a documenti strutturati (ad es., documenti HTML e applicazioni XML). Supporta fogli di stile specifici per media in modo che gli autori possano adattare la presentazione dei loro documenti a browser visuali, dispositivi aurali, stampanti, dispositivi braille, dispositivi portatili, ecc. Supporta inoltre il posizionamento dei contenuti, il layout delle tabelle, funzionalità per l'internazionalizzazione e alcune proprietà relative all'interfaccia utente.
