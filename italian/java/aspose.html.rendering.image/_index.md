Il pacchetto **com.aspose.html.rendering.image** fornisce una classe di dispositivo specifica e alcune classi di opzioni di rendering responsabili del rendering in formati raster: jpeg, png, bmp, gif, tiff.

## Classi

| Classe | Descrizione |
| --- | --- |
| [ImageDevice](./imagedevice/) | Rappresenta il rendering verso formati raster: jpeg, png, bmp, gif, tiff. |
| [ImageRenderingOptions](./imagerenderingoptions/) | Rappresenta le opzioni di rendering per [`ImageDevice`](../com.aspose.html.rendering.image/imagedevice/). Questa opzione è utilizzata per specificare il formato dell'immagine di output, la compressione, la risoluzione, ecc. |
| [TextOptions](./textoptions/) | Rappresenta le opzioni di rendering del testo per [`ImageDevice`](../com.aspose.html.rendering.image/imagedevice/). |
## Enumerazione

| Enumerazione | Descrizione |
| --- | --- |
| [Compression](./compression/) | Specifica gli schemi di compressione possibili per le immagini bitmap Tagged Image File Format (TIFF). |
| [ImageFormat](./imageformat/) | Specifica il formato file dell'immagine. |
