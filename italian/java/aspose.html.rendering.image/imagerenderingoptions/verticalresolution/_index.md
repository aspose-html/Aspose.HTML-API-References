## ImageRenderingOptions.VerticalResolution property

Imposta o ottiene la risoluzione verticale per le immagini di output e interne (utilizzate durante l'elaborazione dei filtri), in pixel per pollice. Per impostazione predefinita questa proprietà è 300 dpi.

```java
public Resolution VerticalResolution { get; set; }
```
