## INodeIterator.NextNode method

Restituisce il nodo successivo nel set e avanza la posizione dell'iteratore nel set. Dopo che un NodeIterator è stato creato, la prima chiamata a nextNode() restituisce il primo nodo del set.

```java
public Node NextNode()
```

### Valore di ritorno

Il nodo successivo nel set in fase di iterazione, o null se non ci sono più membri in quel set.
