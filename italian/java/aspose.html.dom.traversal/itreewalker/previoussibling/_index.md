## ITreeWalker.PreviousSibling method

Sposta il TreeWalker al fratello precedente del nodo corrente e restituisce il nuovo nodo. Se il nodo corrente non ha un fratello precedente visibile, restituisce null e mantiene il nodo corrente.

```java
public Node PreviousSibling()
```

### Valore di ritorno

Il nuovo nodo, o null se il nodo corrente non ha fratello precedente nella vista logica del TreeWalker.
