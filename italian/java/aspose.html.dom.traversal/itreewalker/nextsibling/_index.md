## ITreeWalker.NextSibling method

Sposta il TreeWalker sul fratello successivo del nodo corrente e restituisce il nuovo nodo. Se il nodo corrente non ha un fratello successivo visibile, restituisce null e mantiene il nodo corrente.

```java
public Node NextSibling()
```

### Valore di ritorno

Il nuovo nodo, oppure null se il nodo corrente non ha un fratello successivo nella vista logica del TreeWalker.
