## ITreeWalker.FirstChild method

Sposta il TreeWalker sul primo figlio visibile del nodo corrente e restituisce il nuovo nodo. Se il nodo corrente non ha figli visibili, restituisce null e mantiene il nodo corrente.

```java
public Node FirstChild()
```

### Valore di ritorno

Il nuovo nodo, o null se il nodo corrente non ha figli visibili nella vista logica del TreeWalker.
