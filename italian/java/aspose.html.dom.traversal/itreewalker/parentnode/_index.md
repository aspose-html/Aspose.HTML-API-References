## ITreeWalker.ParentNode method

Sposta e restituisce il nodo antenato visibile più vicino al nodo corrente. Se la ricerca di parentNode tenta di risalire dal nodo radice del TreeWalker, o se non riesce a trovare un nodo antenato visibile, questo metodo mantiene la posizione corrente e restituisce null.

```java
public Node ParentNode()
```

### Valore di ritorno

Il nuovo nodo padre, o null se il nodo corrente non ha un genitore nella vista logica del TreeWalker.
