## ITreeWalker.NextNode method

Sposta il TreeWalker sul prossimo nodo visibile in ordine documentale rispetto al nodo corrente e restituisce il nuovo nodo. Se il nodo corrente non ha un nodo successivo, o se la ricerca di nextNode tenta di risalire dal nodo radice del TreeWalker, restituisce null e mantiene il nodo corrente.

```java
public Node NextNode()
```

### Valore di ritorno

Il nuovo nodo, o null se il nodo corrente non ha un nodo successivo nella vista logica del TreeWalker.
