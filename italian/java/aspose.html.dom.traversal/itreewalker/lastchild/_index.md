## ITreeWalker.LastChild method

Sposta il TreeWalker sull'ultimo figlio visibile del nodo corrente e restituisce il nuovo nodo. Se il nodo corrente non ha figli visibili, restituisce null e mantiene il nodo corrente.

```java
public Node LastChild()
```

### Valore di ritorno

Il nuovo nodo, o null se il nodo corrente non ha figli nella vista logica del TreeWalker.
