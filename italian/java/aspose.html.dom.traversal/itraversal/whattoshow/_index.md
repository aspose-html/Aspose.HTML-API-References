## ITraversal.WhatToShow property

Questo attributo determina quali tipi di nodo sono presentati tramite l'iteratore. L'insieme disponibile di costanti è definito nell'interfaccia NodeFilter. I nodi non accettati da whatToShow saranno ignorati, ma i loro figli potrebbero comunque essere considerati. Nota che questa esclusione ha precedenza sul filtro, se presente.

```java
public long WhatToShow { get; }
```

### Property Value

Il what to show.
