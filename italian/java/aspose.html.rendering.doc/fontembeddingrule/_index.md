## FontEmbeddingRule enumeration

Rappresenta le regole di incorporamento dei font.

```java
public enum FontEmbeddingRule
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Full | `1` | Tutti i font utilizzati saranno incorporati così come sono. Tieni presente che alcuni font potrebbero essere soggetti a licenza, il che renderà il documento risultante non modificabile. Inoltre i file dei font incorporati potrebbero aumentare in modo significativo le dimensioni del documento risultante. |
| None | `2` | I font non saranno incorporati. |
