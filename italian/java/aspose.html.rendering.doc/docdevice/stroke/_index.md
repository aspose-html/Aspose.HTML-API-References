## DocDevice.Stroke method

Traccia una linea lungo il percorso corrente. La linea tracciata segue ogni segmento rettilineo o curvo del percorso, centrata sul segmento con i lati paralleli ad esso. Ciascuno dei sotto‑percorsi del percorso viene trattato separatamente. Questo metodo termina il percorso corrente.
