Il pacchetto **com.aspose.html.dom.attributes** contiene classi di attributi unificate che specificano o qualificano qualsiasi caratteristica o comportamento di un oggetto (nodo, elemento, ...).

## Classi

| Classe | Descrizione |
| --- | --- |
| [DOMConstructorAttribute](./domconstructorattribute/) | Specifica un costruttore definito dal W3C. |
| [DOMNameAttribute](./domnameattribute/) | Specifica il nome ufficiale dell'oggetto DOM così come definito dal W3C. |
| [DOMNamedPropertyGetterAttribute](./domnamedpropertygetterattribute/) | Specifica che il metodo sarà usato come getter di proprietà nominata. |
| [DOMNoInterfaceObjectAttribute](./domnointerfaceobjectattribute/) | Se l'attributo esteso [NoInterfaceObject] appare su un'interfaccia, indica che non esisterà un oggetto interfaccia per l'interfaccia nel binding ECMAScript. |
| [DOMNullableAttribute](./domnullableattribute/) | Specifica che a un oggetto DOM può essere assegnato il valore null. |
| [DOMObjectAttribute](./domobjectattribute/) | Specifica che l'oggetto contrassegnato con questo attributo è definito dal W3C. |
| [DOMTreatNullAsAttribute](./domtreatnullasattribute/) | Indica che il valore null del membro sarà trattato come valore specificato. |
