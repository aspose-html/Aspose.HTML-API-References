## IBlob.Type property

La stringa codificata ASCII in minuscolo che rappresenta il tipo media del Blob. In lettura, gli user agent devono restituire il tipo di un Blob come una stringa codificata ASCII in minuscolo, in modo che, quando viene convertita in una sequenza di byte, sia un tipo MIME analizzabile, o la stringa vuota – 0 byte – se il tipo non può essere determinato.

```java
public String Type { get; }
```
