## IBlob.Size property

Restituisce la dimensione della sequenza di byte in numero di byte. In lettura, gli user agent conformi devono restituire il numero totale di byte che possono essere letti da un oggetto FileReader o FileReaderSync, o 0 se il Blob non contiene byte da leggere.

```java
public ulong Size { get; }
```
