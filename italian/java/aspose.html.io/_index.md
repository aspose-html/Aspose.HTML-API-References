Oltre agli strumenti standard di I/O (input-output), il pacchetto **com.aspose.html.io** contiene classi e interfacce di supporto.

## Classi

| Classe | Descrizione |
| --- | --- |
| [FileCreateStreamProvider](./filecreatestreamprovider/) | Rappresenta l'implementazione di FileStream per fornire stream ai dispositivi di rendering. |
## Interfacce

| Interfaccia | Descrizione |
| --- | --- |
| [IBlob](./iblob/) | Un oggetto Blob si riferisce a una sequenza di byte e possiede un attributo size che è il numero totale di byte nella sequenza, e un attributo type, che è una stringa codificata ASCII in minuscolo che rappresenta il tipo media della sequenza di byte. |
| [ICreateStreamProvider](./icreatestreamprovider/) | Rappresenta un'interfaccia che può essere implementata da classi che forniscono stream ai dispositivi di rendering. |
| [IFile](./ifile/) | Un oggetto File è un oggetto Blob con un attributo name, che è una String; può essere creato all'interno dell'applicazione web tramite un costruttore, oppure è un riferimento a una sequenza di byte proveniente da un file del file system sottostante (OS). |
| [IFileList](./ifilelist/) | Rappresenta l'interfaccia per l'elenco di file. |
