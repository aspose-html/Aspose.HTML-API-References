**com.aspose.html.dom.views** package describes AbstractView and DocumentView interfaces according Document Object Model Views specification.

## Interfacce

| Interfaccia | Descrizione |
| --- | --- |
| [IAbstractView](./iabstractview/) | Un'interfaccia base da cui tutte le visualizzazioni devono derivare. |
| [IDocumentView](./idocumentview/) | L'interfaccia DocumentView è implementata dagli oggetti Document nelle implementazioni DOM che supportano le Visualizzazioni DOM. Fornisce un attributo per recuperare la visualizzazione predefinita di un documento. |
