## ErrorEvent.Error property

L'attributo error deve restituire il valore a cui è stato inizializzato. Quando l'oggetto viene creato, questo attributo deve essere inizializzato a null. Quando opportuno, viene impostato sull'oggetto che rappresenta l'errore (ad es. l'oggetto eccezione nel caso di un'eccezione DOM non catturata).

```java
public object Error { get; }
```

### Property Value

L'errore.
