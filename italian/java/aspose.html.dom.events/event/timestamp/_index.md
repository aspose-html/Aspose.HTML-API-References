## Event.TimeStamp property

Usato per specificare il tempo (in millisecondi relativo all'epoch) in cui l'evento è stato creato. Poiché alcuni sistemi potrebbero non fornire queste informazioni, il valore di timeStamp potrebbe non essere disponibile per tutti gli eventi. Quando non disponibile, verrà restituito 0. Esempi di tempo epoch sono il tempo di avvio del sistema o 0:0:0 UTC 1° gennaio 1970.

```java
public ulong TimeStamp { get; }
```
