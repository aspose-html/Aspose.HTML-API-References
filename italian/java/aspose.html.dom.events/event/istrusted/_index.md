## Event.IsTrusted property

L'attributo isTrusted deve restituire il valore con cui è stato inizializzato. Quando un evento viene creato, l'attributo deve essere inizializzato a false.

```java
public bool IsTrusted { get; }
```

### Property Value

`true` se questa istanza è attendibile; altrimenti, `false`.
