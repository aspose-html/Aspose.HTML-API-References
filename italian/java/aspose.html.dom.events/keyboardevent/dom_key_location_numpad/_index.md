## KeyboardEvent.DOM_KEY_LOCATION_NUMPAD field

L'attivazione del tasto ha avuto origine sul tastierino numerico o con un tasto virtuale corrispondente al tastierino numerico (quando esiste più di una possibile posizione per questo tasto). Nota che il tasto NumLock dovrebbe sempre essere codificato con una posizione di DOM_KEY_LOCATION_STANDARD.

```java
public const ulong DOM_KEY_LOCATION_NUMPAD;
```
