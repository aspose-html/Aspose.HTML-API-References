## KeyboardEvent.DOM_KEY_LOCATION_STANDARD field

L'attivazione del tasto NON DEVE essere distinta come la versione sinistra o destra del tasto e (ad eccezione del tasto NumLock) non ha avuto origine dal tastierino numerico (o non ha avuto origine con un tasto virtuale corrispondente al tastierino numerico).

```java
public const ulong DOM_KEY_LOCATION_STANDARD;
```
