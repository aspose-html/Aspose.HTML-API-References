## KeyboardEvent.Key property

La chiave contiene il valore del tasto premuto. Se il valore ha una rappresentazione stampata, DEVE essere una stringa di caratteri Unicode non vuota, conforme all'algoritmo per determinare il valore del tasto definito in questa specifica. Se il valore è un tasto di controllo senza rappresentazione stampata, DEVE essere uno dei valori di tasto definiti nel set di valori di tasto, come determinato dall'algoritmo per determinare il valore del tasto. Le implementazioni che non riescono a identificare un tasto DEVONO utilizzare il valore di tasto Unidentified.

```java
public String Key { get; }
```

### Property Value

Il valore del tasto.
