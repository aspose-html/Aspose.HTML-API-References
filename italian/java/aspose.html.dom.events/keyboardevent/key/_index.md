## KeyboardEvent.Key property

Il key contiene il valore del tasto premuto. Se il valore ha una rappresentazione stampata, DEVE essere una stringa Unicode di caratteri non vuota, conforme all'algoritmo per determinare il valore del tasto definito in questa specifica. Se il valore è un tasto di controllo che non ha una rappresentazione stampata, DEVE essere uno dei valori di tasto definiti nel set di valori di tasto, come determinato dall'algoritmo per determinare il valore del tasto. Le implementazioni che non sono in grado di identificare un tasto DEVONO usare il valore di tasto Unidentified.

```java
public String Key { get; }
```

### Property Value

Il valore del tasto.
