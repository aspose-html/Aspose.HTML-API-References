## KeyboardEvent.Code property

Il codice contiene una Stringa che identifica il tasto fisico premuto. Il valore non è influenzato dal layout della tastiera corrente o dallo stato dei modificatori, quindi un determinato tasto restituirà sempre lo stesso valore.

```java
public String Code { get; }
```

### Property Value

Il codice del tasto.
