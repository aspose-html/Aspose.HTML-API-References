## KeyboardEvent.Code property

Il codice contiene una String che identifica il tasto fisico premuto. Il valore non è influenzato dal layout della tastiera corrente o dallo stato dei modificatori, quindi un tasto specifico restituirà sempre lo stesso valore.

```java
public String Code { get; }
```

### Property Value

Il codice del tasto.
