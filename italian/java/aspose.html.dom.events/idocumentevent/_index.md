## IDocumentEvent interface

L'interfaccia DocumentEvent fornisce un meccanismo mediante il quale l'utente può creare un Event di un tipo supportato dall'implementazione. Si prevede che l'interfaccia DocumentEvent sarà implementata sullo stesso oggetto che implementa l'interfaccia Document in un'implementazione che supporta il modello Event.

```java
public interface IDocumentEvent
```

## Osservazioni

Si prevede che l'interfaccia sarà implementata sullo stesso oggetto che implementa l'interfaccia in un'implementazione che supporta il modello di eventi.
