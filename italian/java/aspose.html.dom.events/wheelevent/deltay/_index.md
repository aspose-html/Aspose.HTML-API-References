## WheelEvent.DeltaY property

Nei user agent in cui l'azione predefinita dell'evento wheel è lo scorrimento, il valore DEVONO essere la misura lungo l'asse y (in pixel, linee o pagine) da scorrere nel caso in cui l'evento non sia annullato. Altrimenti, si tratta di una misura specifica dell'implementazione (in pixel, linee o pagine) del movimento di un dispositivo wheel attorno all'asse y.

```java
public double DeltaY { get; }
```

L'attributo deltaY.
