## WheelEvent.DeltaZ property

Nei user agent in cui l'azione predefinita dell'evento wheel è lo scorrimento, il valore DEVE essere la misura lungo l'asse z (in pixel, linee o pagine) da scorrere nel caso in cui l'evento non sia annullato. Altrimenti, questa è una misura specifica dell'implementazione (in pixel, linee o pagine) del movimento di un dispositivo wheel attorno all'asse z.

```java
public double DeltaZ { get; }
```

### Property Value

L'attributo deltaZ.
