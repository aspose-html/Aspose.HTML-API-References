## WheelEvent.DeltaX property

Nei user agent in cui l'azione predefinita dell'evento wheel è lo scorrimento, il valore DEVONO essere la misura lungo l'asse x (in pixel, linee o pagine) da scorrere nel caso in cui l'evento non sia annullato. Altrimenti, si tratta di una misura specifica dell'implementazione (in pixel, linee o pagine) del movimento di un dispositivo wheel attorno all'asse x.

```java
public double DeltaX { get; }
```

### Property Value

L'attributo deltaX.
