## FillRule enumeration

Specifica la regola di riempimento utilizzata nel rendering di SVG e HTML.

```java
public enum FillRule
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| EvenOdd | `0` | Determina l'area di riempimento usando la regola pari-dispari. Il comportamento corrisponde a System.Drawing.Drawing2D.FillMode.Alternate. |
| Nonzero | `1` | Determina l'area di riempimento usando la regola non-zero. Il comportamento corrisponde a System.Drawing.Drawing2D.FillMode.Winding. |
