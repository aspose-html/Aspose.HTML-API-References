## AtPagePriority enumeration

Specifica gli ordini possibili di applicazione delle dichiarazioni di dimensione della pagina.

```java
public enum AtPagePriority
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| OptionsPriority | `0` | Specifica che i valori di [`PageSetup`](../pagesetup/) dichiarati in [`RenderingOptions`](../renderingoptions/) sovrascriveranno i valori definiti nel CSS dalle regole `@page`. |
| CssPriority | `1` | Specifica che le regole `@page` definite nel CSS sovrascriveranno i valori definiti in [`PageSetup`](../pagesetup/). |
