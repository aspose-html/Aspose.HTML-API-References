## PageSetup.AdjustToWidestPage property

Ottiene o imposta il flag che determina il caso in cui la dimensione della pagina verrà regolata alla pagina più larga nel documento. Questa opzione è dispendiosa in termini di tempo, quindi il tempo di elaborazione del documento può raddoppiare. La regolazione avverrà solo se la pagina più larga nel documento è più ampia della dimensione della pagina determinata in [`PageSetup`](../). La dimensione della pagina regolata verrà utilizzata per tutte le pagine del documento.

```java
public bool AdjustToWidestPage { get; set; }
```
