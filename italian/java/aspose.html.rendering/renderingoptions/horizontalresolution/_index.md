## RenderingOptions.HorizontalResolution property

Imposta o ottiene la risoluzione orizzontale per le immagini interne (utilizzate durante l'elaborazione dei filtri), in pixel per pollice. Per impostazione predefinita questa proprietà è 300 dpi.

```java
public Resolution HorizontalResolution { get; set; }
```
