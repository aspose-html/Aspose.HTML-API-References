Il pacchetto **com.aspose.html.rendering** è composto da numerosi oggetti renderer e da classi di opzioni a basso livello appropriate, responsabili del rendering di documenti/file in un'implementazione IDevice.

## Classi

| Classe | Descrizione |
| --- | --- |
| [CssOptions](./cssoptions/) | Rappresenta le opzioni di rendering css. |
| [Device](./device/) | Rappresenta una classe base per l'implementazione di dispositivi di rendering utilizzati per disegnare grafica in vari formati e ambienti. |
| [Device&lt;TGraphicContext,TRenderingOptions&gt;](./device-2/) | Rappresenta la classe base per l'implementazione di dispositivi di rendering particolari. |
| [EpubRenderer](./epubrenderer/) | Rappresenta un renderer di documenti EPub. |
| [GraphicContext](./graphiccontext/) | Contiene i parametri di controllo grafico correnti. Questi parametri definiscono il quadro globale entro il quale gli operatori grafici vengono eseguiti. |
| [HtmlRenderer](./htmlrenderer/) | Rappresenta un renderer di documenti HTML. |
| [MhtmlRenderer](./mhtmlrenderer/) | Rappresenta un renderer di documenti MHTML. |
| [PageSetup](./pagesetup/) | Rappresenta un oggetto di configurazione della pagina usato per la configurazione dell'output della pagina. |
| [Renderer](./renderer/) | Rappresenta una classe base per tutti i renderer e implementa l'interfaccia IDisposable. |
| [Renderer&lt;TSource&gt;](./renderer-1/) | Rappresenta una classe astratta per tutti i renderer. |
| [RenderingOptions](./renderingoptions/) | Rappresenta le opzioni di rendering. |
| [SvgRenderer](./svgrenderer/) | Rappresenta un renderer di documenti SVG. |
| [TextInfo](./textinfo/) | Contiene informazioni sul testo renderizzato. |

## Enumerazione

| Enumerazione | Descrizione |
| --- | --- |
| [AtPagePriority](./atpagepriority/) | Specifica gli ordini possibili di applicazione delle dichiarazioni di dimensione della pagina. |
| [FillRule](./fillrule/) | Specifica la regola di riempimento utilizzata nel rendering di SVG e HTML. |
| [MediaType](./mediatype/) | Specifica i tipi di media possibili utilizzati durante il rendering. |
| [PageLayoutOptions](./pagelayoutoptions/) | Specifica i flag che, insieme ad altre opzioni PageSetup, determinano le dimensioni e le disposizioni delle pagine. Questi flag possono essere combinati secondo le loro descrizioni. |
| [StrokeLineCap](./strokelinecap/) | Specifica il tipo di estremità di linea utilizzato nel rendering di SVG e HTML. |
| [StrokeLineJoin](./strokelinejoin/) | Specifica lo stile di unione delle linee utilizzato nel rendering di SVG e HTML. |
