## GraphicContext.MiterLimit property

Imposta o ottiene la lunghezza massima delle giunzioni a spigolo per i percorsi tracciati. Questo parametro limita la lunghezza dei "spikes" prodotti quando i segmenti di linea si uniscono ad angoli acuti.

```java
public float MiterLimit { get; set; }
```
