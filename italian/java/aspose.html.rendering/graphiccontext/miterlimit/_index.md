## GraphicContext.MiterLimit property

Imposta o ottiene la lunghezza massima delle giunzioni a spigolo per i percorsi tracciati. Questo parametro limita la lunghezza delle "spine" prodotte quando i segmenti di linea si uniscono ad angoli acuti.

```java
public float MiterLimit { get; set; }
```
