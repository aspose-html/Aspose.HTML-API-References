## SVGTransform.SetMatrix method

Imposta il tipo di trasformazione su SVG_TRANSFORM_MATRIX, con il parametro matrix che definisce la nuova trasformazione. I valori del parametro matrix vengono copiati, il parametro matrix non sostituisce SVGTransform::matrix.

```java
public void SetMatrix(SVGMatrix matrix)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| matrice | SVGMatrix | La nuova matrice per la trasformazione. |
