## SVGLength.Value property

Il valore come numero a virgola mobile, in unità utente. Impostare questo attributo farà sì che valueInSpecifiedUnits e valueAsString vengano aggiornati automaticamente per riflettere questa impostazione.

```java
public float Value { get; set; }
```

### Property Value

Il valore.
