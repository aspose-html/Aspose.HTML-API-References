## SVGLength.ValueAsString property

Il valore come una stringa, nelle unità espresse da unitType. Impostare questo attributo farà sì che value, valueInSpecifiedUnits e unitType vengano aggiornati automaticamente per riflettere questa impostazione.

```java
public String ValueAsString { get; set; }
```

### Property Value

Il valore come Stringa.
