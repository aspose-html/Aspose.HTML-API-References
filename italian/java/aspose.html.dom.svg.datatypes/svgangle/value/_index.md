## SVGAngle.Value property

Il valore dell'angolo come valore a virgola mobile, in gradi. L'impostazione di questo attributo farà sì che valueInSpecifiedUnits e valueAsString vengano aggiornati automaticamente per riflettere questa impostazione.

```java
public float Value { get; set; }
```

### Property Value

Il valore.
