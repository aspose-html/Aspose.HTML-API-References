## SVGAngle.SVG_ANGLETYPE_UNSPECIFIED field

Non è stato fornito alcun tipo di unità (cioè è stato specificato un valore senza unità). Per gli angoli, un valore senza unità è trattato come se fossero stati specificati i gradi.

```java
public const ushort SVG_ANGLETYPE_UNSPECIFIED;
```
