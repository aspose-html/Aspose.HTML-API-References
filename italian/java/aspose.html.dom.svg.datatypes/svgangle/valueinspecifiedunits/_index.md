## SVGAngle.ValueInSpecifiedUnits property

Il valore dell'angolo come valore in virgola mobile, nelle unità espresse da unitType. Impostare questo attributo farà sì che value e valueAsString vengano aggiornati automaticamente per riflettere questa impostazione.

```java
public float ValueInSpecifiedUnits { get; set; }
```

### Property Value

Il valore nelle unità specificate.
