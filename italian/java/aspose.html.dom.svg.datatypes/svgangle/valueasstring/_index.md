## SVGAngle.ValueAsString property

Il valore dell'angolo come valore Stringa, nelle unità espresse da unitType. Impostare questo attributo farà sì che value, valueInSpecifiedUnits e unitType vengano aggiornati automaticamente per riflettere questa impostazione.

```java
public String ValueAsString { get; set; }
```

### Property Value

Il valore come Stringa.
