Il pacchetto fornisce l'accesso a tutti i tipi di dati specifici SVG.

## Classi

| Classe | Descrizione |
| --- | --- |
| [SVGAngle](./svgangle/) | L'interfaccia SVGAngle corrisponde al tipo di dato base angolo. |
| [SVGAnimatedAngle](./svganimatedangle/) | Utilizzato per attributi del tipo di dato base angolo che possono essere animati. |
| [SVGAnimatedBoolean](./svganimatedboolean/) | Utilizzato per attributi di tipo booleano che possono essere animati. |
| [SVGAnimatedEnumeration](./svganimatedenumeration/) | Utilizzato per attributi il cui valore deve essere una costante di una particolare enumerazione e che possono essere animati. |
| [SVGAnimatedInteger](./svganimatedinteger/) | Utilizzato per attributi del tipo base intero che possono essere animati. |
| [SVGAnimatedLength](./svganimatedlength/) | Utilizzato per attributi del tipo base lunghezza che possono essere animati. |
| [SVGAnimatedLengthList](./svganimatedlengthlist/) | Utilizzato per attributi di tipo SVGLengthList che possono essere animati. |
| [SVGAnimatedNumber](./svganimatednumber/) | Utilizzato per attributi del tipo base numero che possono essere animati. |
| [SVGAnimatedNumberList](./svganimatednumberlist/) | Utilizzato per attributi che accettano una lista di numeri e che possono essere animati. |
| [SVGAnimatedPreserveAspectRatio](./svganimatedpreserveaspectratio/) | Utilizzato per attributi di tipo SVGPreserveAspectRatio che possono essere animati. |
| [SVGAnimatedRect](./svganimatedrect/) | Utilizzato per attributi di tipo SVGRect che possono essere animati. |
| [SVGAnimatedString](./svganimatedString/) | Utilizzato per attributi di tipo DOMString che possono essere animati. |
| [SVGAnimatedTransformList](./svganimatedtransformlist/) | Utilizzato per i vari attributi che specificano un insieme di trasformazioni, come l'attributo ‘transform’ disponibile per molti elementi SVG, e che può essere animato. |
| [SVGAnimatedValue&lt;T&gt;](./svganimatedvalue-1/) | Utilizzato per attributi di tipo che possono essere animati. |
| [SVGLength](./svglength/) | L'interfaccia SVGLength corrisponde al tipo di dato di base length. Un oggetto SVGLength può essere designato come sola lettura, il che significa che i tentativi di modificare l'oggetto genereranno un'eccezione, come descritto di seguito. |
| [SVGLengthList](./svglengthlist/) | Questa interfaccia definisce un elenco di oggetti SVGLength. |
| [SVGMatrix](./svgmatrix/) | Molte delle operazioni grafiche di SVG utilizzano matrici 2x3 della forma: [a c e] [b d f] che, quando espanse in una matrice 3x3 per scopi di aritmetica matriciale, diventano: [a c e] [b d f] [0 0 1] |
| [SVGNumber](./svgnumber/) | Utilizzato per attributi di tipo base number. |
| [SVGNumberList](./svgnumberlist/) | Questa interfaccia definisce un elenco di oggetti SVGNumber. |
| [SVGPoint](./svgpoint/) | Molte delle interfacce SVG DOM fanno riferimento a oggetti della classe SVGPoint. Un SVGPoint è una coppia di coordinate (x, y). Quando utilizzato in operazioni matriciali, un SVGPoint è trattato come un vettore della forma: [x] [y] [1] Se un oggetto SVGRect è designato come sola lettura, allora il tentativo di assegnare uno dei suoi attributi genererà un'eccezione. |
| [SVGPointList](./svgpointlist/) | Questa interfaccia definisce un elenco di oggetti SVGPoint. |
| [SVGPreserveAspectRatio](./svgpreserveaspectratio/) | L'interfaccia SVGPreserveAspectRatio corrisponde all'attributo ‘preserveAspectRatio’, disponibile per alcuni elementi SVG. |
| [SVGRect](./svgrect/) | Rappresenta la geometria rettangolare. I rettangoli sono definiti come costituiti da una coppia di coordinate (x,y) che identifica un valore minimo X, un valore minimo Y, e una larghezza e altezza, solitamente vincolate a valori non negativi. |
| [SVGStringList](./svgStringlist/) | SVGStringList ha gli stessi attributi e metodi delle altre interfacce SVGxxxList. Gli implementatori possono considerare l'uso di una singola classe base per implementare le varie interfacce SVGxxxList. |
| [SVGTransform](./svgtransform/) | SVGTransform è l'interfaccia per una delle trasformazioni componenti all'interno di una SVGTransformList; quindi, un oggetto SVGTransform corrisponde a una singola componente (ad esempio 'scale(…)' o 'matrix(…)') all'interno di una specifica dell'attributo ‘transform’. |
| [SVGTransformList](./svgtransformlist/) | Questa interfaccia definisce un elenco di oggetti SVGTransform. |
| [SVGValueType](./svgvaluetype/) | Il tipo SVGValueType è usato per rappresentare un tipo di valore base SVG. |
