## Classi

| Classe | Descrizione |
| --- | --- |
| [Path2D](./path2d/) | L'interfaccia Path2D dell'API Canvas 2D è usata per dichiarare percorsi che vengono poi successivamente utilizzati sugli oggetti CanvasRenderingContext2D. I metodi di percorso dell'interfaccia CanvasRenderingContext2D sono presenti anche su questa interfaccia e consentono di creare percorsi che è possibile conservare e riprodurre, se necessario, su un canvas. |
## Interfacce

| Interfaccia | Descrizione |
| --- | --- |
| [ICanvasDrawingStyles](./icanvasdrawingstyles/) | L'interfaccia ICanvasDrawingStyles fornisce metodi e proprietà per controllare come vengono disegnate le linee e come è disposto il testo. |
| [ICanvasGradient](./icanvasgradient/) | Rappresenta un oggetto opaco che descrive un gradiente. |
| [ICanvasPathMethods](./icanvaspathmethods/) | L'interfaccia ICanvasPathMethods è usata per manipolare i percorsi degli oggetti. |
| [ICanvasPattern](./icanvaspattern/) | Rappresenta un oggetto opaco che descrive un pattern, basato su un'immagine, un canvas o un video. |
| [ICanvasRenderingContext2D](./icanvasrenderingcontext2d/) | L'interfaccia ICanvasRenderingContext2D è usata per disegnare rettangoli, testo, immagini e altri oggetti sull'elemento canvas. Fornisce il contesto di rendering 2D per la superficie di disegno di un elemento canvas. |
| [IImageData](./iimagedata/) | Crea un oggetto ImageData da un Uint8ClampedArray fornito e dalle dimensioni dell'immagine contenuta. Se non viene fornito alcun array, crea un'immagine di un rettangolo nero. |
| [ITextMetrics](./itextmetrics/) | Rappresenta le dimensioni di un testo nel canvas. |
