## IImageData interface

Crea un oggetto ImageData da un Uint8ClampedArray fornito e dalle dimensioni dell'immagine contenuta. Se non viene fornito alcun array, crea un'immagine di un rettangolo nero.

```java
public interface IImageData
```

## Proprietà

| Nome | Descrizione |
| --- | --- |
| [getData](../../com.aspose.html.dom.canvas/iimagedata/data/) è un Uint8ClampedArray che rappresenta un array monodimensionale contenente i dati nell'ordine RGBA, con valori interi compresi tra 0 e 255 (inclusi). |
| [getHeight](../../com.aspose.html.dom.canvas/iimagedata/height/) è un unsigned long che rappresenta l'altezza reale, in pixel, dell'ImageData. |
| [getWidth](../../com.aspose.html.dom.canvas/iimagedata/width/) è un unsigned long che rappresenta la larghezza reale, in pixel, dell'ImageData. |
