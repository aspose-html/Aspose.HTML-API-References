## StrokeText(String, double, double, double?) {#stroketext_1}

Disegna (traccia) un testo dato nella posizione (x, y) specificata.

```java
public void StrokeText(String text, double x, double y, double? maxWidth)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| text | String | Il testo da disegnare usando il font corrente, textAlign, textBaseline e i valori di direction. |
| x | Double | L'asse x della coordinata per il punto di partenza del testo. |
| y | Double | L'asse y della coordinata per il punto di partenza del testo. |
| maxWidth | Nullable`1 | La larghezza massima da disegnare. Se specificata e la stringa risulta più larga di questa larghezza, il font viene regolato per utilizzare un font più orizzontalmente condensato (se disponibile o se è possibile sintetizzarne uno ragionevolmente leggibile scalando orizzontalmente il font corrente) oppure un font più piccolo. |
