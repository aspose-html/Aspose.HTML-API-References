## FillText(String, double, double, double) {#filltext_1}

Disegna (riempie) un testo dato nella posizione (x,y) specificata.

```java
public void FillText(String text, double x, double y, double maxWidth)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| testo | String | Il testo da disegnare usando i valori attuali di font, textAlign, textBaseline e direction. |
| x | Double | L'asse x della coordinata per il punto di partenza del testo. |
| y | Double | L'asse y della coordinata per il punto di partenza del testo. |
| maxWidth | Double | La larghezza massima da disegnare. Se specificata, e la stringa risulta più larga di questa larghezza, il font viene regolato per utilizzare un font più orizzontalmente condensato (se disponibile o se è possibile sintetizzarne uno ragionevolmente leggibile scalando orizzontalmente il font corrente) o un font più piccolo. |
