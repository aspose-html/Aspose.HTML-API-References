## IsPointInStroke(double, double) {#ispointinstroke_1}

Riporta se il punto specificato è all'interno dell'area contenuta dal tracciamento di un percorso.

```java
public bool IsPointInStroke(double x, double y)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| x | Double | La coordinata X del punto da verificare. |
| y | Double | La coordinata Y del punto da verificare. |
