## IsPointInPath(double, double) {#ispointinpath_2}

Riporta se il punto specificato è contenuto o meno nel percorso corrente.

```java
public bool IsPointInPath(double x, double y)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| x | Double | La coordinata X del punto da verificare. |
| y | Double | La coordinata Y del punto da controllare. |

### Valore di ritorno

Restituisce true se il punto è all'interno dell'area contenuta dal riempimento di un percorso, altrimenti false.
