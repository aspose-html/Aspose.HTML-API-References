```

| --- | --- | --- |
| immagine | HTMLImageElement | L'HTMLImageElement da disegnare nel contesto. |
| dx | Double | La coordinata X nella canvas di destinazione in cui posizionare l'angolo superiore sinistro dell'immagine sorgente. |

| dh | Double | L'altezza con cui disegnare l'immagine nella canvas di destinazione. Questo consente di scalare l'immagine disegnata. Se non specificato, l'immagine non viene scalata in altezza durante il disegno. |
