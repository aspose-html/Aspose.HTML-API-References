## CanvasFillRule enumeration

Questa enumerazione è usata per selezionare l'algoritmo della regola di riempimento con cui determinare se un punto è all'interno o all'esterno di un percorso.

```java
public enum CanvasFillRule
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| NonZero | `0` | Il valore "nonzero" indica la regola di avvolgimento non-zero, secondo la quale un punto è considerato fuori da una forma se il numero di volte in cui una linea retta seminfinità tracciata da quel punto attraversa il percorso della forma in una direzione è uguale al numero di volte che la attraversa nella direzione opposta. |
| EvenOdd | `1` | Il valore "evenodd" indica la regola pari-dispari, secondo la quale un punto è considerato fuori da una forma se il numero di volte in cui una linea retta seminfinità tracciata da quel punto attraversa il percorso della forma è pari. |
