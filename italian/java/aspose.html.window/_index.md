Il pacchetto **com.aspose.html.window** è relativo all'oggetto window che rappresenta una finestra contenente un documento DOM. Include classi e interfacce relative all'indirizzo del documento attivo e alla cronologia di navigazione.

## Classi

| Classe | Descrizione |
| --- | --- |
| [Location](./location/) | Gli oggetti Location forniscono una rappresentazione dell'indirizzo del documento attivo del contesto di navigazione del loro Document, e consentono di modificare la voce corrente della cronologia di sessione del contesto di navigazione, aggiungendo o sostituendo voci nell'oggetto history. |
| [MediaQueryList](./mediaquerylist/) | Un oggetto MediaQueryList memorizza informazioni su una query media applicata a un documento, con supporto sia per il matching immediato sia basato su eventi rispetto allo stato del documento. Vedi la specifica del modulo CSSOM View: [https://www.w3.org/TR/cssom-view/#the-mediaquerylist-interface](https://www.w3.org/TR/cssom-view/#the-mediaquerylist-interface) |
## Interfacce

| Interfaccia | Descrizione |
| --- | --- |
| [IWindow](./iwindow/) | L'oggetto window rappresenta una finestra contenente un documento DOM. |
| [IWindowEventHandlers](./iwindoweventhandlers/) | Rappresenta l'interfaccia che deve essere ereditata dall'oggetto window |
| [IWindowTimers](./iwindowtimers/) | Consente agli autori di programmare callback basati su timer. |
