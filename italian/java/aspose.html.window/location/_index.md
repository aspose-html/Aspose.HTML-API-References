## Location class

Gli oggetti Location forniscono una rappresentazione dell'indirizzo del documento attivo del contesto di navigazione del loro Document, e consentono di modificare la voce corrente della cronologia della sessione del contesto di navigazione, aggiungendo o sostituendo voci nell'oggetto history.

public sealed class Location : DOMObject
