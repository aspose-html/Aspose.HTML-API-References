## IWindow.Top property

L'attributo IDL top sull'oggetto Window di un Document in un contesto di navigazione b deve restituire l'oggetto WindowProxy del suo contesto di navigazione di livello superiore (che sarebbe il proprio oggetto WindowProxy se fosse esso stesso un contesto di livello superiore), se ne ha uno, oppure il proprio oggetto WindowProxy altrimenti (ad es. se fosse un contesto di navigazione annidato separato).

public IWindow Top { get; }
