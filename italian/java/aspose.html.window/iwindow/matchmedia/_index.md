## IWindow.MatchMedia method

Restituisce un nuovo oggetto MediaQueryList che può essere usato per determinare se il documento corrisponde alla stringa di query media, nonché per monitorare il documento e rilevare quando corrisponde (o smette di corrispondere) a tale query media. Vedi la specifica del modulo CSSOM View: [https://www.w3.org/TR/cssom-view/#extensions-to-the-window-interface](https://www.w3.org/TR/cssom-view/#extensions-to-the-window-interface)

```java
public MediaQueryList MatchMedia(String query)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| query | String | La String contenente una media query; vedi [https://drafts.csswg.org/mediaqueries/](https://drafts.csswg.org/mediaqueries/) per i dettagli. |

oggetto MediaQueryList
