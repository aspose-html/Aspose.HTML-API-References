## IWindow.Prompt method

Visualizza una finestra modale con campo di testo e il messaggio fornito, attende che l'utente la chiuda e restituisce il valore inserito dall'utente. Se l'utente annulla il prompt, restituisce null. Se è presente il secondo argomento, il valore fornito viene usato come predefinito.

```java
public String Prompt(String message, String @default)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| messaggio | String | Il messaggio. |
| predefinito | String | Il valore predefinito. |

### Valore di ritorno

Restituisce il valore inserito dall'utente
