Il pacchetto **com.aspose.html.dom.mutations** offre la possibilità di osservare le mutazioni del DOM e ottenere informazioni di callback specifiche.

## Classi

| Classe | Descrizione |
| --- | --- |
| [MutationCallback](./mutationcallback/) | Rappresenta il metodo che gestirà gli eventi di mutazione. |
| [MutationObserver](./mutationobserver/) | Un oggetto può essere usato per osservare le mutazioni dell'albero di [`.`](../com.aspose.html.dom/node/) |
| [MutationObserverInit](./mutationobserverinit/) | Questa classe rappresenta una raccolta di opzioni che viene utilizzata per configurare [`MutationObserver`](../com.aspose.html.dom.mutations/mutationobserver/). |
| [MutationRecord](./mutationrecord/) | Un MutationRecord rappresenta una singola mutazione del DOM. È l'oggetto che viene passato al [`MutationObserver`](../com.aspose.html.dom.mutations/mutationobserver/)'s [`MutationCallback`](../com.aspose.html.dom.mutations/mutationcallback/). |
