## Observe(Node) {#observe}

Istruisce l'agente utente a osservare un determinato target (un nodo) e a segnalare eventuali mutazioni in base ai criteri forniti dalle opzioni (un oggetto). L'argomento options consente di impostare le opzioni di osservazione delle mutazioni tramite i membri dell'oggetto.

```java
public void Observe(Node target)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| target | Node | Il target per observe. |
