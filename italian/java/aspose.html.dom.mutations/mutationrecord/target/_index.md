## MutationRecord.Target property

Restituisce il nodo interessato dalla mutazione, a seconda del tipo. Per "attributes", è l'elemento il cui attributo è cambiato. Per "characterData", è il nodo CharacterData. Per "childList", è il nodo i cui figli sono cambiati.

```java
public Node Target { get; }
```

### Property Value

Il target.
