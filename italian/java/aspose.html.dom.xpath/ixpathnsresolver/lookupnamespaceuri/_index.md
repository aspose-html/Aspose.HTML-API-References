## IXPathNSResolver.LookupNamespaceURI method

Cerca l'URI del pacchetto associato al prefisso di pacchetto fornito. L'evaluatore XPath non deve mai chiamare questo metodo con un argomento `null` o vuoto, poiché il risultato di tale operazione è indefinito.

```java
public String LookupNamespaceURI(String prefix)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| prefisso | String | Il prefisso da cercare. |

### Valore di ritorno

Restituisce l'URI del pacchetto associato o `null` se non ne viene trovato alcuno.
