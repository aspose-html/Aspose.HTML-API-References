## IXPathResult.InvalidIteratorState property

Indica che l'iteratore è diventato non valido. Vero se `resultType`is è di tipo `UnorderedNodeIterator` o `OrderedNodeIterator` e il documento è stato modificato da quando è stato restituito questo risultato.

```java
public bool InvalidIteratorState { get; }
```
