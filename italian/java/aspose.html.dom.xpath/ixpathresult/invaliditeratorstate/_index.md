## IXPathResult.InvalidIteratorState property

Indica che l'iteratore è diventato non valido. Vero se `resultType` è di tipo `UnorderedNodeIterator` o `OrderedNodeIterator` e il documento è stato modificato da quando questo risultato è stato restituito.

```java
public bool InvalidIteratorState { get; }
```
