## ITrueTypeFont.SubFamilyName property

Il nome della sottoclasse del carattere distingue il carattere in un gruppo con lo stesso nome della famiglia del carattere. Si presume che questo indichi lo stile (italic, oblique) e il peso (light, bold, black, ecc.). Un carattere senza particolari differenze di peso o stile (ad esempio peso medio, non italic e con il bit 6 di fsSelection impostato) dovrebbe avere la stringa "Regular" memorizzata in questa posizione.

```java
public String SubFamilyName { get; }
```

### Valore di ritorno

Nome della sottoclasse del carattere
