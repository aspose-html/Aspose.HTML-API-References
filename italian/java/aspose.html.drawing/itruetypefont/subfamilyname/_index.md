## ITrueTypeFont.SubFamilyName property

Il nome della sottoclasse del font distingue il font in un gruppo con lo stesso nome della famiglia del font. Si presume che indichi lo stile (italic, oblique) e il peso (light, bold, black, ecc.). Un font senza particolari differenze di peso o stile (ad es. peso medio, non italic e con il bit 6 di fsSelection impostato) dovrebbe avere la stringa "Regular" memorizzata in questa posizione.

```java
public String SubFamilyName { get; }
```

### Valore di ritorno

Nome della sottoclasse del font
