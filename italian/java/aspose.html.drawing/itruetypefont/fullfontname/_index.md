## ITrueTypeFont.FullFontName property

Questo dovrebbe essere una combinazione di "FamilyName" e "SubFamilyName". Eccezione: se il font è "Regular" come indicato in "SubFamilyName", allora usa solo il nome della famiglia contenuto in "FamilyName". Un'eccezione alla definizione sopra del nome completo del font riguarda le stringhe della piattaforma Microsoft per i font OpenType CFF: in questo caso, la stringa Full font name deve essere identica al PostScript FontName nel CFF Name INDEX.

```java
public String FullFontName { get; }
```

### Valore di ritorno

Nome completo del font
