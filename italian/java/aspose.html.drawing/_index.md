Il pacchetto **com.aspose.html.drawing** contiene oggetti e interfacce per specificare misure e unità, nonché oggetti di attributi di disegno come pennelli, colori e caratteri.

## Classi

| Classe | Descrizione |
| --- | --- |
| [Angle](./angle/) | Il tipo di dato angolo |
| [Color](./color/) | La classe Color consente di specificare i colori come valori Red-Green-Blue (RGB), Hue-Saturation-Luminosity (HSL), Hue-Saturation-Value (HSV), Hue-Whiteness-Blackness (HWB), valori lightness-A-B (LAB), Luminance-Chroma-Hue (LCH), Cyan-Magenta-Yellow-Key (CMYK), Natural colors (NCOL) o con un nome di colore. È disponibile anche un canale Alpha per indicare la trasparenza. |
| [Dimension](./dimension/) | Fornisce la classe base per le dimensioni. Il termine generale 'dimensione' si riferisce a un numero con un'unità allegata, ed è indicato da [`UnitType`](../com.aspose.html.drawing/unittype/). |
| [Frequency](./frequency/) | L'unità 'frequency'. |
| [Length](./length/) | Rappresenta un'unità di misura della lunghezza. |
| [LengthOrAuto](./lengthorauto/) | Rappresenta un contenitore per la lunghezza di archiviazione o unità 'auto'.. |
| [Margin](./margin/) | Rappresenta il margine della pagina. |
| [Numeric](./numeric/) | Fornisce la classe base per i tipi numerici. |
| [Page](./page/) | Rappresenta un oggetto pagina utilizzato per la configurazione della pagina di output. Il valore di lacuna per le dimensioni della pagina è A4 (210x297mm) |
| [Resolution](./resolution/) | Rappresenta un'unità di risoluzione. |
| [Size](./size/) | Memorizza valori che specificano altezza e larghezza. |
| [Time](./time/) | Rappresenta un'unità di tempo. |
| [Unit](./unit/) | Fornisce la classe base per le unità di misura. |
| [UnitType](./unittype/) | Specifica l'unità di misura. |
## Interfacce

| Interfaccia | Descrizione |
| --- | --- |
| [IBrush](./ibrush/) | Dichiara il metodo per ottenere il tipo di pennello. |
| [IColorComponents](./icolorcomponents/) | Dichiara metodi e proprietà per l'elaborazione dei componenti di colore. |
| [IDrawingFactory](./idrawingfactory/) | Rappresenta una fabbrica per la creazione di oggetti relativi al disegno. |
| [IGradientBrush](./igradientbrush/) | Dichiara i metodi per ottenere le proprietà comuni dei pennelli gradiente. |
| [IInterpolationColor](./iinterpolationcolor/) | Dichiara i metodi per ottenere il colore di interpolazione. |
| [ILinearGradientBrush](./ilineargradientbrush/) | Definisce l'interfaccia del pennello con un gradiente lineare. |
| [IMatrix](./imatrix/) | Rappresenta una matrice utilizzata per le trasformazioni. |
| [ISolidBrush](./isolidbrush/) | Definisce l'interfaccia del pennello di un colore singolo. |
| [ITextureBrush](./itexturebrush/) | Definisce l'interfaccia del pennello che utilizza un'immagine per riempire l'interno di una forma. |
| [ITransformableBrush](./itransformablebrush/) | Dichiara i metodi per ottenere la matrice di trasformazione e la modalità di avvolgimento. |
| [ITrueTypeFont](./itruetypefont/) | Dichiara i metodi per lavorare con i font TrueType. |
