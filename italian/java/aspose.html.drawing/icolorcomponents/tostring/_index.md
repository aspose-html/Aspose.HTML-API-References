## IColorComponents.ToString method

Converte i componenti di colore in una rappresentazione Stringa.

```java
public String ToString(bool includeAlpha, bool asDecimal, int digits)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| includeAlpha | Boolean | Specifica se aggiungere il componente Alpha. |
| asDecimal | Boolean | Specifica se i componenti di colore sono conservati come numero decimale o come percentuale. |
| digits | Int32 | Imposta la precisione di arrotondamento per i componenti di colore. |

Rappresentazione stringa dei componenti di colore.
