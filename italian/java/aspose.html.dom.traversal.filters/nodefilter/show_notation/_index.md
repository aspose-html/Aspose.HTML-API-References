## NodeFilter.SHOW_NOTATION field

Mostra i nodi Notation. Questo è significativo solo quando si crea un iteratore o un tree-walker con un nodo Notation come radice; in questo caso, significa che il nodo Notation apparirà nella prima posizione del percorso. Poiché le notazioni non fanno parte dell'albero del documento, non compaiono durante l'attraversamento dell'albero del documento.

```java
public const long SHOW_NOTATION;
```
