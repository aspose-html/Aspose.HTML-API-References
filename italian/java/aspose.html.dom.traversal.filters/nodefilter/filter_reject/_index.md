## NodeFilter.FILTER_REJECT field

Rifiuta il nodo. I metodi di navigazione definiti per NodeIterator o TreeWalker non restituiranno questo nodo. Per TreeWalker, anche i figli di questo nodo saranno rifiutati. I NodeIterators considerano questo come sinonimo di FILTER_SKIP.

```java
public const short FILTER_REJECT;
```
