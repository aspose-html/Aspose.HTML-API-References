## NodeFilter.FILTER_SKIP field

Salta questo singolo nodo. I metodi di navigazione definiti per NodeIterator o TreeWalker non restituiranno questo nodo. Per entrambi NodeIterator e TreeWalker, i figli di questo nodo saranno comunque considerati.

```java
public const short FILTER_SKIP;
```
