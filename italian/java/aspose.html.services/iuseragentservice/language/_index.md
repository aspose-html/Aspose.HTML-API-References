## IUserAgentService.Language property

Il `Language` specifica la lingua primaria per i contenuti dell'elemento e per tutti gli attributi dell'elemento che contengono testo. Il suo valore deve essere un tag linguistico BCP 47 () valido, o la Stringa vuota. Impostare l'attributo sulla Stringa vuota indica che la lingua primaria è sconosciuta.

```java
public String Language { get; set; }
```

### Property Value

La lingua dell'user agent.
