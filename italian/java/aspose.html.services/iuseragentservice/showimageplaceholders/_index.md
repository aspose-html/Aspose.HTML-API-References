## IUserAgentService.ShowImagePlaceholders property

Le immagini possono avere contenuto di riserva: contenuto che dovrebbe essere usato quando una risorsa esterna non può essere utilizzata (ad esempio, perché è in un formato non supportato). La proprietà `ShowImagePlaceholders` specifica se visualizzare l'immagine di riserva (il valore predefinito è true).

```java
public bool ShowImagePlaceholders { get; set; }
```
