## IRuntimeService.JavaScriptTimeout property

Ottiene o imposta TimeSpan che limita il tempo di esecuzione di JavaScript. Se lo script viene eseguito più a lungo del TimeSpan fornito, verrà annullato. È possibile specificare un timeout infinito impostando TimeSpan uguale a -1 millisecondo. Il valore predefinito è 1 minuto.

```java
public TimeSpan JavaScriptTimeout { get; set; }
```
