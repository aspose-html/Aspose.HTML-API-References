Il pacchetto **com.aspose.html.services** contiene interfacce come protocolli per le implementazioni di servizio.

## Interfacce

| Interfaccia | Descrizione |
| --- | --- |
| [IDeviceInformationService](./ideviceinformationservice/) | Un'interfaccia che descrive un ambiente in cui [`Document`](../com.aspose.html.dom/document/) è presentato all'utente. |
| [INetworkService](./inetworkservice/) | Fornisce un'interfaccia per le operazioni di rete. |
| [IRuntimeService](./iruntimeservice/) | Questo servizio è usato per configurare le proprietà relative al runtime. |
| [IUserAgentService](./iuseragentservice/) | Un'interfaccia che descrive un ambiente user agent. |
