## HTMLInputElement.Value property

Quando l'attributo `type` dell'elemento ha il valore "text", "file" o "password", questo rappresenta il contenuto attuale del corrispondente controllo del modulo, in un agente utente interattivo. Modificare questo attributo cambia il contenuto del controllo del modulo, ma non cambia il valore dell'attributo HTML value dell'elemento. Quando l'attributo `type` dell'elemento ha il valore "button", "hidden", "submit", "reset", "image", "checkbox" o "radio", questo rappresenta l'attributo HTML value dell'elemento. Vedi la definizione dell'attributo value in HTML 4.01.

```java
public String Value { get; set; }
```
