## HTMLInputElement.DefaultValue property

Quando l'attributo `type` dell'elemento ha il valore "text", "file" o "password", questo rappresenta l'attributo value HTML dell'elemento. Il valore di questo attributo non cambia se il contenuto del controllo del modulo corrispondente, in un agente utente interattivo, cambia. Vedi la definizione dell'attributo value in HTML 4.01.

```java
public String DefaultValue { get; set; }
```
