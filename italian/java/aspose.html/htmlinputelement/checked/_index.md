## HTMLInputElement.Checked property

Quando l'attributo `type` dell'elemento ha il valore "radio" o "checkbox", questo rappresenta lo stato corrente del controllo del modulo, in un agente utente interattivo. Le modifiche a questo attributo cambiano lo stato del controllo del modulo, ma non modificano il valore dell'attributo HTML checked dell'elemento INPUT. Durante la gestione di un evento click su un elemento input con un attributo type che ha il valore "radio" o "checkbox", alcune implementazioni possono modificare il valore di questa proprietà prima che l'evento venga distribuito nel documento. Se l'azione predefinita dell'evento viene annullata, il valore della proprietà può essere riportato al suo valore originale. Ciò significa che il valore di questa proprietà durante la gestione degli eventi click dipende dall'implementazione.

```java
public bool Checked { get; set; }
```
