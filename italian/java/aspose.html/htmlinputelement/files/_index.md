## HTMLInputElement.Files property

L'attributo IDL files consente agli script di accedere ai file selezionati dell'elemento. In lettura, se l'attributo IDL è applicabile, deve restituire un oggetto FileList che rappresenta i file attualmente selezionati. Lo stesso oggetto deve essere restituito finché l'elenco dei file selezionati non cambia. Se l'attributo IDL non è applicabile, deve invece restituire null. [FILEAPI]

```java
public IFileList Files { get; }
```
