## HTMLInputElement.DefaultChecked property

Quando `type` ha il valore "radio" o "checkbox", questo rappresenta l'attributo HTML checked dell'elemento. Il valore di questo attributo non cambia se lo stato del controllo di modulo corrispondente, in un agente utente interattivo, cambia. Vedi la definizione dell'attributo checked in HTML 4.01.

```java
public bool DefaultChecked { get; set; }
```
