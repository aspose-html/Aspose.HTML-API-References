## IUrlSearchParams.Set method

Imposta il valore della prima coppia nome-valore trovata al valore specificato e rimuove le altre. Se non vengono trovate coppie nome-valore con il nome specificato, ne verrà aggiunta una nuova alla lista.

```java
public void Set(String name, String value)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| nome | String | Chiave che sarà usata per trovare le coppie nome-valore. |
| valore | String | Valore che sarà impostato. |
