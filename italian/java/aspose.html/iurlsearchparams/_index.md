Fornisce metodi per lavorare con la stringa di query degli URL.

```java
public interface IUrlSearchParams : IEnumerable<String[]>
```

## Metodi

| Nome | Descrizione |
| --- | --- |
| [append](../../com.aspose.html/iurlsearchparams/append/)(String, String) | Aggiunge una nuova coppia nome-valore il cui nome è `name` e il valore è `value`. |
| [delete](../../com.aspose.html/iurlsearchparams/delete/)(String) | Rimuove tutte le coppie nome-valore il cui nome è `name`. |
| [get](../../com.aspose.html/iurlsearchparams/get/)(String) | Restituisce il valore della prima coppia nome-valore il cui nome è `name`. |
| [getAll](../../com.aspose.html/iurlsearchparams/getall/)(String) | Restituisce tutti i valori il cui nome è `name`. |
| [has](../../com.aspose.html/iurlsearchparams/has/)(String) | Verifica se nella lista esiste una coppia nome-valore il cui nome è `name`. |
| [set](../../com.aspose.html/iurlsearchparams/set/)(String, String) | Imposta il valore della prima coppia nome-valore trovata al valore specificato e rimuove le altre. Se non vengono trovate coppie nome-valore con il nome specificato, ne verrà aggiunta una nuova alla lista. |
| [sort](../../com.aspose.html/iurlsearchparams/sort/)() | Ordina tutte le coppie nome-valore, se presenti, in base ai loro nomi. |
