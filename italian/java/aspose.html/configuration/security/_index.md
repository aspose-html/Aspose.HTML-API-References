## Configuration.Security property

Ottiene o imposta il flag di sandboxing della configurazione. Consulta l'articolo su [sandboxing](https://docs.aspose.com/html/net/working-with-documents/environment-configuration/#sandboxing).

```java
public Sandbox Security { get; set; }
```

### Property Value

La sicurezza. Un set di [`sandboxing flag`](../../sandbox/) è un insieme di zero o più flag, utilizzati per limitare le capacità delle risorse potenzialmente non attendibili. L'attributo sandbox consente di impostare diverse restrizioni sul contenuto caricato nel frame, ad esempio bloccare moduli e script.
