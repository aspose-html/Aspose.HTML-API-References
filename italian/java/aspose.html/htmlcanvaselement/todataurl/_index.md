## ToDataURL() {#todataurl}

restituisce un URI dati contenente una rappresentazione dell'immagine nel formato specificato dal parametro type (predefinito PNG). L'immagine restituita ha una risoluzione di 96 dpi.

```java
public String ToDataURL()
```

### Valore di ritorno

Una DOMString contenente l'URI dati richiesto.

## ToDataURL(String, double) {#todataurl_2}

restituisce un URI dati contenente una rappresentazione dell'immagine nel formato specificato dal parametro type (predefinito PNG). L'immagine restituita ha una risoluzione di 96 dpi.

```java
public String ToDataURL(String type, double encoderOptions)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| tipo | String | Una String che indica il formato dell'immagine. Il tipo di formato predefinito è image/png. |
| encoderOptions | Double | Un Number compreso tra 0 e 1 che indica la qualità dell'immagine se il tipo richiesto è image/jpeg o image/webp. |

### Valore di ritorno

Una DOMString contenente l'URI dati richiesto.
