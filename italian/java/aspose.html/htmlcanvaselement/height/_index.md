## HTMLCanvasElement.Height property

È un intero positivo che riflette l'attributo height HTML dell'elemento canvas interpretato in pixel CSS. Quando l'attributo non è specificato, o è impostato a un valore non valido, come un negativo, viene usato il valore predefinito di 150.

```java
public ulong Height { get; set; }
```
