## HTMLCanvasElement.GetContext method

Restituisce un contesto di disegno sul canvas, o null se l'ID del contesto non è supportato. Un contesto di disegno consente di disegnare sul canvas.

```java
public object GetContext(String contextId)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| contextId | String | È una String contenente l'identificatore del contesto che definisce il contesto di disegno associato al canvas |
