## HTMLCanvasElement.Width property

È un intero positivo che riflette l'attributo width HTML dell'elemento canvas interpretato in pixel CSS. Quando l'attributo non è specificato, o è impostato a un valore non valido, come un numero negativo, viene usato il valore predefinito di 300.

```java
public ulong Width { get; set; }
```
