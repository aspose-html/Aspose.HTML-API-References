## IHTMLOptionsCollection interface

Una `HTMLOptionsCollection` è un elenco di nodi che rappresentano l'elemento option HTML. Un nodo individuale può essere accesso sia tramite indice ordinale sia tramite gli attributi `name` o `id` del nodo. Si presume che le collezioni nel DOM HTML siano live, il che significa che vengono aggiornate automaticamente quando il documento sottostante viene modificato.

Vedi anche la [Document object Model (DOM) Level 2 HTML Specification](http://www.w3.org/TR/2003/REC-DOM-Level-2-HTML-20030109). @since DOM Level 2

```java
public interface IHTMLOptionsCollection : IEnumerable<Element>
```
