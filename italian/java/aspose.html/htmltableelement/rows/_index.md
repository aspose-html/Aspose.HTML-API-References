## HTMLTableElement.Rows property

Restituisce il `TFOOT` della tabella, o `null` se non ne esiste.

Restituisce una collezione di tutte le righe della tabella, includendo tutte quelle in `THEAD`, `TFOOT` e tutti gli elementi `TBODY`.

```java
public HTMLCollection Rows { get; }
```
