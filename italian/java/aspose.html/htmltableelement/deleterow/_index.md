## HTMLTableElement.DeleteRow method

Elimina una riga della tabella.

```java
public void DeleteRow(int index)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| index | Int32 | L'indice della riga da eliminare. Questo indice parte da 0 ed è relativo all'ordine logico (non all'ordine del documento) di tutte le righe contenute nella tabella. Se l'indice è -1 viene eliminata l'ultima riga della tabella. |

### Eccezioni

| eccezione | condizione |
| --- | --- |
| [dOMException](../../../com.aspose.html.dom/domexception/) | INDEX_SIZE_ERR: Sollevato se l'indice specificato è maggiore o uguale al numero di righe o se l'indice è un numero negativo diverso da -1. @version DOM Level 2 |
