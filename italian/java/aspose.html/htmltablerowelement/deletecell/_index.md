## HTMLTableRowElement.DeleteCell method

Elimina una cella dalla riga corrente.

```java
public void DeleteCell(int index)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| index | Int32 | L'indice della cella da eliminare, a partire da 0. Se l'indice è -1 viene eliminata l'ultima cella della riga. |

### Eccezioni

| eccezione | condizione |
| --- | --- |
| [dOMException](../../../com.aspose.html.dom/domexception/) | INDEX_SIZE_ERR: Generato se l'`index` specificato è maggiore o uguale al numero di celle o se l'indice è un numero negativo diverso da -1. @version DOM Level 2 |
