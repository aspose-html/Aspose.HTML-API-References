## HTMLFormElement.Enctype property

Il tipo di contenuto del modulo inviato, generalmente "application/x-www-form-urlencoded". Vedi la definizione dell'attributo enctype in HTML 4.01. Il gestore dell'evento onsubmit non è garantito che venga attivato quando si invoca questo metodo. Il comportamento è incoerente per ragioni storiche e gli autori non dovrebbero fare affidamento su uno in particolare.

public String Enctype { get; set; }
