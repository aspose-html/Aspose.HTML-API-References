## HTMLDocument.Anchors property

Una raccolta di tutti gli elementi di ancoraggio (`A`) in un documento con un valore per l'attributo `name`. Per motivi di compatibilità retroattiva, il set restituito di ancore contiene solo quelle create con l'attributo `name`, non quelle create con l'attributo `id`. Si noti che in [[XHTML 1.0](http://www.w3.org/TR/2002/REC-xhtml1-20020801)], l'attributo `name` (vedi sezione 4.10) non ha semantica ed è presente solo per agenti utente legacy: l'attributo `id` è usato al suo posto. Gli utenti dovrebbero preferire i meccanismi di iterazione forniti da [[DOM Level 2 Traversal](http://www.w3.org/TR/2000/REC-DOM-Level-2-Traversal-Range-20001113)] invece.

```java
public HTMLCollection Anchors { get; }
```
