## HTMLDocument.Referrer property

Restituisce l'URI [[IETF RFC 2396](http://www.ietf.org/rfc/rfc2396.txt)] della pagina che ha collegato a questa pagina. Il valore è una stringa vuota se l'utente ha navigato direttamente alla pagina (non tramite un collegamento, ma, ad esempio, tramite un segnalibro).

```java
public String Referrer { get; }
```
