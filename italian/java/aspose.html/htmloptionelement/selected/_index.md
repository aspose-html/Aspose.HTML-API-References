## HTMLOptionElement.Selected property

Rappresenta lo stato corrente del controllo di modulo corrispondente, in un agente utente interattivo. Modificando questo attributo si modifica lo stato del controllo di modulo, ma non si modifica il valore dell'attributo HTML selected dell'elemento.

```java
public bool Selected { get; set; }
```
