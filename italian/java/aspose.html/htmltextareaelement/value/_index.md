## HTMLTextAreaElement.Value property

Rappresenta il contenuto corrente del controllo di modulo corrispondente, in un agente utente interattivo. Modificando questo attributo si modifica il contenuto del controllo di modulo, ma non quello dell'elemento. Se l'interezza dei dati non può essere contenuta in un singolo `DOMString`, l'implementazione può troncare i dati.

```java
public String Value { get; set; }
```
