## Uint8ClampedArray class

Rappresenta un array di interi senza segno a 8 bit limitati a 0-255; se specifichi un valore fuori dall'intervallo [0,255], verrà impostato 0 o 255 al suo posto;

```java
public class Uint8ClampedArray : TypedArray<byte>
```
