## HTMLTableSectionElement.DeleteRow method

Elimina una riga da questa sezione.

```java
public void DeleteRow(int index)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| index | Int32 | L'indice della riga da eliminare, o -1 per eliminare l'ultima riga. Questo indice parte da 0 ed è relativo solo alle righe contenute in questa sezione, non a tutte le righe della tabella. |

### Eccezioni

| eccezione | condizione |
| --- | --- |
| [dOMException](../../../com.aspose.html.dom/domexception/) | INDEX_SIZE_ERR: Sollevato se l'indice specificato è maggiore o uguale al numero di righe o se l'indice è un numero negativo diverso da -1. @version DOM Level 2 |
