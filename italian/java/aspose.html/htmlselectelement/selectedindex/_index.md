## HTMLSelectElement.SelectedIndex property

L'indice ordinale dell'opzione selezionata, a partire da 0. Il valore -1 viene restituito se nessun elemento è selezionato. Se sono selezionate più opzioni, viene restituito l'indice della prima opzione selezionata.

```java
public int SelectedIndex { get; set; }
```
