Il pacchetto **com.aspose.html.collections** è composto da classi per rappresentare, memorizzare e manipolare nodi ed elementi.

## Classi

| Classe | Descrizione |
| --- | --- |
| [DOMTokenList](./domtokenlist/) | La classe DOMTokenList rappresenta un insieme di token separati da spazi. È indicizzata a partire da 0 come gli oggetti Array di JavaScript. DOMTokenList è sempre sensibile al maiuscolo/minuscolo. |
| [HTMLCollection](./htmlcollection/) | La [`HTMLCollection`](../com.aspose.html.collections/htmlcollection/) rappresenta una collezione generica di [`Element`](../com.aspose.html.dom/element/). |
| [NamedNodeMap](./namednodemap/) | Rappresenta collezioni di attributi che possono essere accessibili per nome. |
| [NodeList](./nodelist/) | Il NodeList fornisce l'astrazione di una collezione ordinata di nodi, senza definire o vincolare il modo in cui questa collezione è implementata. |
