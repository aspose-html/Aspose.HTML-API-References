## NamedNodeMap class

Rappresenta collezioni di attributi che possono essere accessibili per nome.

```java
public class NamedNodeMap : DOMObject
```

## Proprietà

| Nome | Descrizione |
| --- | --- |
| [getItem](../../com.aspose.html.collections/namednodemap/item/) Restituisce l'elemento all'indice specificato nella mappa. Se l'indice è maggiore o uguale al numero di nodi in questa mappa, restituisce null. (2 indicizzatori) |
| [getLength](../../com.aspose.html.collections/namednodemap/length/) Il numero di nodi in questa mappa. |

## Metodi

| Nome | Descrizione |
| --- | --- |
| [getNamedItem](../../com.aspose.html.collections/namednodemap/getnameditem/)(String) | Recupera un nodo specificato per nome. |
| [getNamedItemNS](../../com.aspose.html.collections/namednodemap/getnameditemns/)(String, String) | Recupera un nodo specificato per nome locale e URI del pacchetto. |
| [getPlatformType](../../com.aspose.html.dom/domobject/getplatformtype/)() | Questo metodo è usato per recuperare l'oggetto ECMAScript. |
| [removeNamedItem](../../com.aspose.html.collections/namednodemap/removenameditem/)(String) | Rimuove un nodo specificato per nome. |
| [removeNamedItemNS](../../com.aspose.html.collections/namednodemap/removenameditemns/)(String, String) | Rimuove un nodo specificato per nome locale e URI del pacchetto. |
| [setNamedItem](../../com.aspose.html.collections/namednodemap/setnameditem/)(Attr) | Aggiunge un nodo usando il suo attributo nodeName. Se un nodo con quel nome è già presente in questa mappa, viene sostituito da quello nuovo. Sostituire un nodo con se stesso non ha effetto. |
| [setNamedItemNS](../../com.aspose.html.collections/namednodemap/setnameditemns/)(Attr) | Aggiunge un nodo usando il suo packageURI e localName. Se un nodo con quel package URI e quel nome locale è già presente in questa mappa, viene sostituito da quello nuovo. Sostituire un nodo con se stesso non ha effetto. |
