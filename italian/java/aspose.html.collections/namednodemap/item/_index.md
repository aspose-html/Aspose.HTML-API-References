## NamedNodeMap indexer (1 of 2)

Restituisce l'elemento all'indice specificato nella mappa. Se l'indice è maggiore o uguale al numero di nodi in questa mappa, restituisce null.

```java
public Attr this[int index] { get; }
```

| Parametro | Descrizione |
| --- | --- |
| index | L'indice. |

### Valore di ritorno

Restituisce il nodo.

### Property Value

Il [`Attr`](../../../com.aspose.html.dom/attr/).
