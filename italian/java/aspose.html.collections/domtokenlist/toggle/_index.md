## Toggle(String, bool) {#toggle_1}

Rimuove il token dalla lista se esiste, oppure aggiunge il token alla lista se non esiste.

```java
public bool Toggle(String token, bool force)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| token | String | Il token che vuoi attivare/disattivare. |
| force | Boolean | Un Boolean che, se incluso, trasforma il toggle in un'operazione unidirezionale. Se impostato su false, il token verrà solo rimosso, ma non aggiunto. Se impostato su true, il token verrà solo aggiunto, ma non rimosso. |

### Valore di ritorno

Un Boolean che indica se il token è nella lista dopo la chiamata.
