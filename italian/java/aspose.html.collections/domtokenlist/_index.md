## DOMTokenList class

La classe DOMTokenList rappresenta un insieme di token separati da spazi. È indicizzata a partire da 0 come gli oggetti Array di JavaScript. DOMTokenList è sempre sensibile al maiuscolo/minuscolo.

```java
public class DOMTokenList : DOMObject, IEnumerable<String>
```
