## NodeList indexer

Il metodo restituisce l'elemento all'indice nella collezione. Se l'indice è maggiore o uguale al numero di nodi nell'elenco, restituisce null.

```java
public abstract Node this[int index] { get; }
```

| Parametro | Descrizione |
| --- | --- |
| index | L'indice. |

### Valore di ritorno

Restituisce il nodo.
