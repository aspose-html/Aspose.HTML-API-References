## SVGPathElement.PathSegList property

Fornisce l'accesso al contenuto base (cioè statico) dell'attributo ‘d’ in una forma che corrisponde uno a uno alla sintassi SVG. Pertanto, se l'attributo ‘d’ ha un "moveto assoluto (M)" e un "arcto assoluto (A)", allora pathSegList conterrà due voci: SVG_PATHSEG_MOVETO_ABS e SVG_PATHSEG_ARC_ABS.

```java
public SVGPathSegList PathSegList { get; set; }
```

### Property Value

L'elenco dei segmenti di percorso.
