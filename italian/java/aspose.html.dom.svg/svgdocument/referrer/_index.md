## SVGDocument.Referrer property

Restituisce l'URI della pagina che ha collegato a questa pagina. Il valore è una String vuota se l'utente ha navigato direttamente alla pagina (non tramite un collegamento, ma, ad esempio, tramite un segnalibro).

```java
public String Referrer { get; }
```

### Property Value

Il referrer.
