## SVGDocument.GetOverrideStyle method

Questo metodo è usato per recuperare la dichiarazione di stile di override per un elemento specificato e un pseudo-elemento specificato.

```java
public ICSSStyleDeclaration GetOverrideStyle(Element elt, String pseudoElt)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| elt | Elemento | L'elemento il cui stile deve essere modificato. Questo parametro non può essere null. |
| pseudoElt | String | Il pseudo-elemento o null se assente. |

### Valore di ritorno

La dichiarazione di stile di override
