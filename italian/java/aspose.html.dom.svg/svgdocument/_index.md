## SVGDocument class

Un `SVGDocument` è la radice della gerarchia SVG e contiene l'intero contenuto. Oltre a fornire l'accesso alla gerarchia, fornisce anche alcuni metodi di comodità per accedere a determinati insiemi di informazioni dal documento. Quando un elemento ‘svg’ è incorporato inline come componente di un documento proveniente da un altro pacchetto, ad esempio quando un elemento ‘svg’ è incorporato inline all'interno di un documento XHTML [XHTML], allora non esisterà un oggetto SVGDocument; al suo posto, l'oggetto radice nella gerarchia degli oggetti documento sarà un oggetto Document di tipo diverso, come un oggetto HTMLDocument. Tuttavia, un oggetto SVGDocument esisterà effettivamente quando l'elemento radice della gerarchia del documento XML è un elemento ‘svg’, ad esempio visualizzando un file SVG autonomo (cioè, un file con tipo MIME "image/svg+xml"). In questo caso, l'oggetto SVGDocument sarà l'oggetto radice della gerarchia del modello di oggetti documento.

public class SVGDocument : Document, IDocumentCSS
