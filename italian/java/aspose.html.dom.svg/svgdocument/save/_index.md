## Save(Url) {#save_3}

Salva il documento nel file locale specificato da `url`. Tutte le risorse usate in questo documento saranno salvate in una cartella adiacente, il cui nome sarà costruito come: output_file_name + "_files".

```java
public void Save(Url url)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| url | Url | URL locale del file di output. |

### Eccezioni

| eccezione | condizione |
| --- | --- |
| ArgumentException | Generato se l'`url` specificato non è un URL di file locale valido. |
