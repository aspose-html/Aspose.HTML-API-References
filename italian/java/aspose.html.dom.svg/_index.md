Tutte le classi nel pacchetto **com.aspose.html.dom.svg** si basano sulle raccomandazioni w3c SVG2. Utilizzando questo pacchetto, è possibile caricare, navigare o renderizzare il file SVG secondo le proprie esigenze.

| [SVGDocument](./svgdocument/) | Un `SVGDocument` è la radice della gerarchia SVG e contiene l'intero contenuto. Oltre a fornire l'accesso alla gerarchia, fornisce anche alcuni metodi di comodità per accedere a determinati insiemi di informazioni dal documento. Quando un elemento ‘svg’ è incorporato inline come componente di un documento proveniente da un altro pacchetto, ad esempio quando un elemento ‘svg’ è incorporato inline all'interno di un documento XHTML [XHTML], allora non esisterà un oggetto SVGDocument; al suo posto, l'oggetto radice nella gerarchia degli oggetti documento sarà un oggetto Document di tipo diverso, come un oggetto HTMLDocument. Tuttavia, un oggetto SVGDocument esisterà effettivamente quando l'elemento radice della gerarchia del documento XML è un elemento ‘svg’, ad esempio visualizzando un file SVG autonomo (cioè, un file con tipo MIME "image/svg+xml"). In questo caso, l'oggetto SVGDocument sarà l'oggetto radice della gerarchia del modello di oggetti documento. |

| [SVGTextContentElement](./svgtextcontentelement/) | L'elemento SVGTextContentElement è ereditato da varie interfacce relative al testo, come SVGTextElement, SVGTSpanElement, SVGTRefElement, SVGAltGlyphElement e SVGTextPathElement. Per i metodi di questa interfaccia che si riferiscono a un indice di un carattere o a un numero di caratteri, tali riferimenti devono essere interpretati rispettivamente come un indice di un'unità di codice UTF-16 o come un numero di unità di codice UTF-16. Questo è per coerenza con DOM Level 2 Core, dove i metodi dell'interfaccia CharacterData usano unità di codice UTF-16 come indici e conteggi all'interno dei dati dei caratteri. Quindi, per esempio, se il contenuto testuale di un elemento ‘text’ è un singolo carattere non BMP, come U+10000, allora chiamare getNumberOfChars su quell'elemento restituirà 2 poiché sono utilizzate due unità di codice UTF-16 (la coppia surrogata) per rappresentare quel singolo carattere. |
