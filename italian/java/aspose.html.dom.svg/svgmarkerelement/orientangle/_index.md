## SVGMarkerElement.OrientAngle property

Corrisponde all'attributo ‘orient’ sull'elemento ‘marker’ specificato. Se markerUnits è SVG_MARKER_ORIENT_ANGLE, il valore angolare per l'attributo ‘orient’; altrimenti, verrà impostato a zero.

```java
public SVGAnimatedAngle OrientAngle { get; }
```

### Property Value

L'attributo ‘orient’ dell'elemento ‘marker’ specificato.
