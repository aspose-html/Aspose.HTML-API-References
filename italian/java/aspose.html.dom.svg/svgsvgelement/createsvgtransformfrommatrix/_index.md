## SVGSVGElement.CreateSVGTransformFromMatrix method

Crea un oggetto SVGTransform al di fuori di qualsiasi albero di documento. L'oggetto è inizializzato alla trasformazione matrice fornita (cioè SVG_TRANSFORM_MATRIX). I valori dalla matrice parametro sono copiati, il parametro matrice non è adottato come SVGTransform::matrix.

```java
public SVGTransform CreateSVGTransformFromMatrix(SVGMatrix matrix)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| matrice | SVGMatrix | La matrice di trasformazione. |

### Valore di ritorno

Un oggetto SVGTransform.
