## SVGSVGElement.CurrentTranslate property

Su un elemento svg più esterno, il fattore di traslazione corrispondente che tiene conto dell"ingrandimento" dell’utente. Quando viene acceduto su un elemento ‘svg’ che non è l’elemento svg più esterno, è indefinito quale comportamento abbia questo attributo.

```java
public SVGPoint CurrentTranslate { get; }
```

### Property Value

La traslazione corrente.
