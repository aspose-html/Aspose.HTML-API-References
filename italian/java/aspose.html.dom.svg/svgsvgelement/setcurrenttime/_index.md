## SVGSVGElement.SetCurrentTime method

Regola l'orologio per questo frammento di documento SVG, stabilendo un nuovo tempo corrente. Se setCurrentTime viene chiamato prima che la timeline del documento sia iniziata (ad esempio, da uno script eseguito in un elemento ‘script’ prima che venga inviato l'evento SVGLoad del documento), allora il valore dei secondi nell'ultima invocazione del metodo indica il tempo a cui il documento cercherà di spostarsi una volta che la timeline del documento è iniziata.

```java
public void SetCurrentTime(float seconds)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| secondi | Single | Il nuovo tempo corrente in secondi relativo al tempo di inizio del frammento di documento SVG corrente. |
