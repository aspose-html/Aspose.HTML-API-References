## SVGSVGElement.GetCurrentTime method

Restituisce il tempo corrente in secondi relativo al tempo di inizio per il frammento di documento SVG corrente. Se getCurrentTime viene chiamato prima che la timeline del documento sia iniziata (ad esempio, da uno script eseguito in un elemento ‘script’ prima che l'evento SVGLoad del documento sia stato inviato), allora viene restituito 0.

```java
public float GetCurrentTime()
```

### Valore di ritorno

Il tempo corrente in secondi, o 0 se la timeline del documento non è ancora iniziata.
