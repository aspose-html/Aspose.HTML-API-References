## SVGSVGElement class

Una definizione di interfaccia chiave è l'interfaccia SVGSVGElement, che è l'interfaccia che corrisponde all'elemento ‘svg’. Questa interfaccia contiene vari metodi di utilità diversi e comunemente usati, come le operazioni di matrice e la capacità di controllare il tempo di ridisegno sui dispositivi di rendering visivo.

```java
public class SVGSVGElement : SVGGraphicsElement, IDocumentEvent, ISVGFitToViewBox, ISVGZoomAndPan
```
