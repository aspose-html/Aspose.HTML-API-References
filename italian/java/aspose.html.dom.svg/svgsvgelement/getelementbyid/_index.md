## SVGSVGElement.GetElementById method

Cerca in questo frammento di documento SVG (cioè, la ricerca è limitata a un sottoinsieme dell'albero del documento) un Element il cui id è fornito da elementId. Se viene trovato un Element, quell'Element viene restituito. Se non esiste alcun elemento con tale id, restituisce null. Il comportamento non è definito se più di un elemento possiede questo id.

```java
public Element GetElementById(String elementId)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| elementId | String | Il valore ID univoco per un elemento. |

### Valore di ritorno

L'elemento corrispondente.
