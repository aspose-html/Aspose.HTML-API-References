## SVGGeometryElement.GetPointAtLength method

Restituisce la coordinata (x,y) nello spazio utente, espressa in unità di distanza lungo il percorso, utilizzando l'algoritmo distance-along-a-path dell'agente utente.

```java
public SVGPoint GetPointAtLength(float distance)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| distanza | Single | La distanza lungo il percorso, relativa all'inizio del percorso, come distanza nel sistema di coordinate utente corrente. |

### Valore di ritorno

Il punto restituito nello spazio utente.
