## SVGTextContentElement.GetNumberOfChars method

Restituisce il numero totale di caratteri disponibili per il rendering all'interno dell'elemento corrente, includendo i caratteri referenziati dal riferimento ‘tref’, indipendentemente dal fatto che vengano renderizzati o meno. In pratica, è equivalente alla lunghezza dell'attributo Node::textContent del DOM Level 3 Core ([DOM3], sezione 1.4), se tale attributo espande anche gli elementi ‘tref’.

```java
public long GetNumberOfChars()
```

### Valore di ritorno

Numero totale di caratteri.
