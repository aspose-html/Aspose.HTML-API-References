## SVGTextContentElement.GetComputedTextLength method

La somma totale di tutti i valori di avanzamento derivanti dal rendering di tutti i caratteri all'interno di questo elemento, includendo il valore di avanzamento sui glifi (orizzontale o verticale), l'effetto delle proprietà ‘kerning’, ‘letter-spacing’ e ‘word-spacing’ e le regolazioni dovute agli attributi ‘dx’ e ‘dy’ sugli elementi ‘tspan’. Per ambienti non di rendering, l'agente utente deve fare ipotesi ragionevoli sulle metriche dei glifi.

```java
public float GetComputedTextLength()
```

### Valore di ritorno

La distanza di avanzamento del testo.
