## SVGPolylineElement.AnimatedPoints property

Fornisce l'accesso al contenuto animato corrente dell'attributo ‘points’. Se l'attributo o la proprietà forniti sono animati, contiene il valore animato corrente dell'attributo o della proprietà. Se l'attributo o la proprietà forniti non sono attualmente animati, contiene lo stesso valore di points.

```java
public SVGPointList AnimatedPoints { get; }
```

### Property Value

I punti animati.
