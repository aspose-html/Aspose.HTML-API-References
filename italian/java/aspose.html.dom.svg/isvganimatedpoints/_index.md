## ISVGAnimatedPoints interface

L'interfaccia SVGAnimatedPoints supporta gli elementi che hanno un attributo ‘points’ che contiene un elenco di valori di coordinate e che supportano la possibilità di animare tale attributo. Inoltre, l'attributo ‘points’ sull'elemento originale accessibile tramite l'XML DOM (ad es., usando la chiamata al metodo getAttribute()) rifletterà qualsiasi modifica apportata ai punti.

```java
public interface ISVGAnimatedPoints
```
