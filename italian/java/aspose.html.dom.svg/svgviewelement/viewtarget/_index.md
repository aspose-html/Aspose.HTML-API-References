## SVGViewElement.ViewTarget property

Corrisponde all'attributo ‘viewTarget’ sull'elemento ‘view’ specificato. Un elenco di valori DOMString che contengono i nomi elencati nell'attributo ‘viewTarget’. Ognuno dei valori DOMString può essere associato all'elemento corrispondente usando la chiamata al metodo getElementById().

```java
public SVGStringList ViewTarget { get; }
```

### Property Value

L'attributo ‘viewTarget’ dell'elemento ‘view’ specificato.
