## SVGGraphicsElement.GetBBox method

Restituisce il riquadro di delimitazione stretto nello spazio utente corrente (cioè, dopo l'applicazione dell'attributo ‘transform’, se presente) sulla geometria di tutti gli elementi grafici contenuti, esclusi tratti, ritagli, mascheramenti ed effetti di filtro). Nota che getBBox deve restituire il riquadro di delimitazione reale al momento in cui il metodo è stato chiamato, anche nel caso in cui l'elemento non sia ancora stato renderizzato.

```java
public SVGRect GetBBox()
```

### Valore di ritorno

Un oggetto SVGRect che definisce il riquadro di delimitazione.
