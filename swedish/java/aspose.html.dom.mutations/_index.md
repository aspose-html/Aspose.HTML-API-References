Paketet **com.aspose.html.dom.mutations** ger möjlighet att observera DOM‑mutationer och erhålla specifik återuppringningsinformation.

## Klasser

| Klass | Beskrivning |
| --- | --- |
| [MutationCallback](./mutationcallback/) | Representerar metoden som kommer att hantera mutations‑händelser. |
| [MutationObserver](./mutationobserver/) | Ett objekt kan användas för att observera mutationer i trädet av [`.`](../com.aspose.html.dom/node/) |
| [MutationObserverInit](./mutationobserverinit/) | Denna klass representerar en alternativsamling som används för att konfigurera [`MutationObserver`](../com.aspose.html.dom.mutations/mutationobserver/). |
| [MutationRecord](./mutationrecord/) | Ett MutationRecord representerar en enskild DOM-mutation. Det är objektet som skickas till [`MutationObserver`](../com.aspose.html.dom.mutations/mutationobserver/)'s [`MutationCallback`](../com.aspose.html.dom.mutations/mutationcallback/). |
