## MutationObserver constructor

Skapar ett MutationObserver‑objekt och sätter dess [`MutationCallback`](../../mutationcallback/) till callback. Callbacken anropas med en lista av MutationRecord‑objekt som första argument och det konstruerade MutationObserver‑objektet som andra argument. Den anropas efter att noder registrerade med !:Observe(Node, IMutationObserverInit)-metoden har muterats.
