Paketet representerar nodfiltreringsfunktionalitet. Filter är objekt som vet hur man "filtrerar bort" noder. Om en noditerator eller trädvandring får ett nodfilter tillämpas filtret innan nästa nod returneras. Om filtret säger att noden ska accepteras returnerar traverseringslogiken den; annars letar traverseringen efter nästa nod och låtsas att den avvisade noden inte fanns.
