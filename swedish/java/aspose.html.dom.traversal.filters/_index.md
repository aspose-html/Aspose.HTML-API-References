Paketet representeras av nodfiltreringsfunktionalitet. Filter är objekt som vet hur man \"filtrerar bort\" noder. Om en noditerator eller trädvandring får ett nodfilter, tillämpar den filtret innan den returnerar nästa nod. Om filtret säger att acceptera noden, returnerar traverseringslogiken den; annars letar traverseringen efter nästa nod och låtsas att den avvisade noden inte fanns.
