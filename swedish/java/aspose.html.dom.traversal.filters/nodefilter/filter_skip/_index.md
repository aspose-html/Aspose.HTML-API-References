## NodeFilter.FILTER_SKIP field

Hoppa över denna enda nod. Navigationsmetoder som definierats för NodeIterator eller TreeWalker kommer inte att returnera denna nod. För både NodeIterator och TreeWalker kommer barnen till denna nod fortfarande att beaktas.

```java
public const short FILTER_SKIP;
```
