## NodeFilter.SHOW_ENTITY field

Visa Entity-noder. Detta är endast meningsfullt när man skapar en iterator eller tree-walker med en Entity-nod som rot; i så fall betyder det att Entity-noden kommer att visas i den första positionen i traverseringen. Eftersom entiteter inte är en del av dokumentträdet, visas de inte vid traversering av dokumentträdet.

```java
public const long SHOW_ENTITY;
```
