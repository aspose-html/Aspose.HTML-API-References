## NodeFilter.FILTER_REJECT field

Avvisa noden. Navigationsmetoder som definierats för NodeIterator eller TreeWalker kommer inte att returnera denna nod. För TreeWalker kommer även barnen till denna nod att avvisas. NodeIterators behandlar detta som en synonym för FILTER_SKIP.

```java
public const short FILTER_REJECT;
```
