## FontEmbeddingRule enumeration

Representerar reglerna för inbäddning av teckensnitt.

```java
public enum FontEmbeddingRule
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Full | `1` | Alla använda teckensnitt kommer att bäddas in som de är. Var medveten om att vissa teckensnitt kan vara licensierade, vilket gör det resulterande dokumentet ej redigerbart. Dessutom kan de inbäddade teckensnittsfilena avsevärt öka storleken på det resulterande dokumentet. |
| None | `2` | Teckensnitt kommer inte att bäddas in. |
