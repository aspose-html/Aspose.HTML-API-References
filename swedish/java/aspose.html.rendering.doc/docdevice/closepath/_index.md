## DocDevice.ClosePath method

Stänger den aktuella undervägen genom att lägga till ett rakt linjesegment från den aktuella punkten till startpunkten för undervägen. Om den aktuella undervägen redan är stängd gör "ClosePath" inget. Denna operator avslutar den aktuella undervägen. Att lägga till ett annat segment till den aktuella vägen startar en ny underväg, även om det nya segmentet börjar vid slutpunkten som nåddes av "ClosePath"‑metoden.
