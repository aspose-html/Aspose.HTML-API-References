## IUserAgentService.Language property

`Language` specificerar det primära språket för elementets innehåll och för alla elementets attribut som innehåller text. Dess värde måste vara en giltig BCP 47‑språktagg, eller den tomma strängen. Att sätta attributet till den tomma strängen indikerar att det primära språket är okänt.

```java
public String Language { get; set; }
```

### Property Value

Användaragentspråket.
