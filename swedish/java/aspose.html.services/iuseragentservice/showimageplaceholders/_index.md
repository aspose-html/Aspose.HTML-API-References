## IUserAgentService.ShowImagePlaceholders property

Bilder kan ha reservinnehåll: innehåll som ska användas när en extern resurs inte kan användas (till exempel eftersom den är i ett format som inte stöds). Egendomen `ShowImagePlaceholders` specificerar om reservbilden ska visas (standardvärdet är true).

public bool ShowImagePlaceholders { get; set; }
