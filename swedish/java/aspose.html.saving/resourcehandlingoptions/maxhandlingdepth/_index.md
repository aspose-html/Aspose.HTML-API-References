## ResourceHandlingOptions.MaxHandlingDepth property

Hämtar eller anger maximal djupnivå för sidor som ska hanteras. Djupet 1 betyder att endast sidor som direkt refereras från det sparade dokumentet hanteras. Att sätta denna egenskap till -1 innebär att alla sidor hanteras. Standardvärdet är 0.

```java
public int MaxHandlingDepth { get; set; }
```
