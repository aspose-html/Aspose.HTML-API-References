## TextSaveOptions.EnableListItemMarkers property

Alternativ som tillämpas på OL‑ och UL‑element vid HTML‑konvertering till text. I själva verket definierar det hur de yttre listmarkörerna för OL‑ och UL‑element ska behandlas. Om true läggs item‑nummer till före OL‑element, eller punkter läggs till före UL‑element. Om false läggs de inte till (standardbeteende enligt specifikationen).

```java
public bool EnableListItemMarkers { get; set; }
```
