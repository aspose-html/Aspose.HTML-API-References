Paketet **com.aspose.html.toolkit.optimizers** innehåller klasser för att optimera SVG-dokument. Optimeringsprocessen innebär att ta bort oanvända eller osynliga element och deras attribut, slå ihop grupper och minska storleken på bana-segmenten.

## Klasser

| Klass | Beskrivning |
| --- | --- |
| [SVGOptimizationOptions](./svgoptimizationoptions/) | SVGOptimizationOptions är en klass för att lagra alternativ för optimering av SVG-dokument. |
| [SVGOptimizer](./svgoptimizer/) | SVGOptimizer är en statisk klass avsedd för att optimera SVG-dokument. Med optimering menar vi att ta bort oanvända eller osynliga element och deras attribut, slå samman grupper och minska storleken på bansegment. |
| [SVGPathOptimizationOptions](./svgpathoptimizationoptions/) | SVGPathOptimizationOptions är en klass för att lagra alternativ för optimering av segment i SVG-banelement. |
