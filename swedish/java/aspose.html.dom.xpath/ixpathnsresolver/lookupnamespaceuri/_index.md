## IXPathNSResolver.LookupNamespaceURI method

Slå upp package‑URI:n som är associerad med det angivna paket‑prefixet. XPath‑utvärderaren får aldrig anropa detta med ett `null`‑ eller tomt argument, eftersom resultatet av detta är odefinierat.

```java
public String LookupNamespaceURI(String prefix)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| prefix | String | Prefixet att söka efter. |

### Returvärde

Returnerar den associerade paket‑URI:n eller `null` om ingen hittas.
