## KeyboardEvent.Key property

key innehåller nyckelvärdet för den nedtryckta tangenten. Om värdet har en tryckt representation MUST det vara en icke-tom Unicode-teckensnittssträng som följer algoritmen för att bestämma nyckelvärdet som definieras i denna specifikation. Om värdet är en kontrolltangent som saknar tryckt representation MUST det vara ett av nyckelvärdena som definieras i nyckelvärdesuppsättningen, enligt algoritmen för att bestämma nyckelvärdet. Implementationer som inte kan identifiera en tangent MUST använda nyckelvärdet Unidentified.

```java
public String Key { get; }
```

### Property Value

Nyckelvärdet.
