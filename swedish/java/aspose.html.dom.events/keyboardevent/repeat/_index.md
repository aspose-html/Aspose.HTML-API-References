## KeyboardEvent.Repeat property

true om tangenten har tryckts ned på ett ihållande sätt. Att hålla ner en tangent MUST resultera i att händelserna keydown, beforeinput, input upprepas i denna ordning med en hastighet som bestäms av systemkonfigurationen. För mobila enheter som har långtrycksbeteende ska den första tangent-händelsen med repeat-attributvärdet true MUST fungera som en indikation på ett långtryck. Den tid som tangenten MUST vara nedtryckt för att börja upprepas är konfigurationsberoende.

```java
public bool Repeat { get; }
```

### Property Value

`true` om repeat; annars `false`.
