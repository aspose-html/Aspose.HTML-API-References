## KeyboardEvent.Code property

Koden innehåller en String som identifierar den fysiska tangenten som trycks ned. Värdet påverkas inte av den aktuella tangentbordslayouten eller modifierartillståndet, så en viss tangent kommer alltid att returnera samma värde.

public String Code { get; }
