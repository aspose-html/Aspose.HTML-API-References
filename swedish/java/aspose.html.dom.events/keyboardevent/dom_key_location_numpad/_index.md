## KeyboardEvent.DOM_KEY_LOCATION_NUMPAD field

Tangentaktiveringen härstammar från det numeriska tangentbordet eller med en virtuell tangent som motsvarar det numeriska tangentbordet (när det finns mer än en möjlig plats för denna tangent). Observera att NumLock-tangenten alltid bör kodas med en plats av DOM_KEY_LOCATION_STANDARD.

```java
public const ulong DOM_KEY_LOCATION_NUMPAD;
```
