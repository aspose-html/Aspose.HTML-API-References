## KeyboardEvent.IsComposing property

true om tangentbeteendet inträffar som en del av en kompositionssession, d.v.s. efter ett compositionstart‑event och före motsvarande compositionend‑event. Det oinitierade värdet för detta attribut MÅSTE vara false.

```java
public bool IsComposing { get; }
```

### Property Value

`true` om detta objekt komponerar; annars, `false`.
