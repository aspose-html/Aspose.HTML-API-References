## InputEvent.Data property

Data innehåller värdet av de tecken som genererats av en inmatningsmetod. Detta KAN vara ett enskilt Unicode‑tecken eller en icke‑tom sekvens av Unicode‑tecken [Unicode]. Tecken SKALL normaliseras enligt Unicode‑normaliseringsformen NFC, definierad i [UAX15]. Detta attribut KAN innehålla den tomma strängen.

public String Data { get; }
