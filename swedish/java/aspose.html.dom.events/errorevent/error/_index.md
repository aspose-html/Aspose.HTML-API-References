## ErrorEvent.Error property

Attributet error måste returnera det värde som det initierades till. När objektet skapas måste detta attribut initieras till null. När det är lämpligt sätts det till objektet som representerar felet (t.ex. undantagsobjektet i fallet med ett oavlyssnat DOM‑undantag).

```java
public object Error { get; }
```

### Property Value

Felet.
