**com.aspose.html.rendering.image** paketet tillhandahåller en specifik enhetsklass samt några renderingsalternativklasser som ansvarar för rendering till rasterformat: jpeg, png, bmp, gif, tiff.

## Klasser

| Klass | Beskrivning |
| --- | --- |
| [ImageDevice](./imagedevice/) | Representerar rendering till rasterformat: jpeg, png, bmp, gif, tiff. |
| [ImageRenderingOptions](./imagerenderingoptions/) | Representerar renderingsalternativ för [`ImageDevice`](../com.aspose.html.rendering.image/imagedevice/). Detta alternativ används för att ange utdataformat för bilden, komprimering, upplösning etc. |
| [TextOptions](./textoptions/) | Representerar textrenderingsalternativ för [`ImageDevice`](../com.aspose.html.rendering.image/imagedevice/). |
## Uppräkning

| Uppräkning | Beskrivning |
| --- | --- |
| [Compression](./compression/) | Anger de möjliga komprimeringsschemana för Tagged Image File Format (TIFF) bitmap‑bilder. |
| [ImageFormat](./imageformat/) | Anger bildens filformat. |
