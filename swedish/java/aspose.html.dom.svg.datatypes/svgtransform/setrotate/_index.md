## SVGTransform.SetRotate method

Ställer in transformationstypen till SVG_TRANSFORM_ROTATE, med parametern angle som definierar rotationsvinkeln och parametrarna cx och cy som definierar det valfria rotationscentrumet.

```java
public void SetRotate(float angle, float cx, float cy)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| angle | Single | Rotationsvinkeln. |
| cx | Single | x‑koordinaten för rotationscentrumet. |
| cy | Single | y‑koordinaten för rotationscentrumet. |
