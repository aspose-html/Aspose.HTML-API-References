## SVGAngle.ValueAsString property

Vinkelvärdet som ett String‑värde, i de enheter som anges av unitType. Att sätta detta attribut kommer att göra att value, valueInSpecifiedUnits och unitType uppdateras automatiskt för att återspegla denna inställning.

```java
public String ValueAsString { get; set; }
```

### Property Value

Värdet som String.
