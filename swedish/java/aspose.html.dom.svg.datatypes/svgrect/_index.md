## SVGRect class

Representerar rektangulär geometri. Rektanglar definieras som bestående av ett (x,y)-koordinatpar som identifierar ett minsta X‑värde, ett minsta Y‑värde samt en bredd och höjd, vilka vanligtvis är begränsade till att vara icke‑negativa.
