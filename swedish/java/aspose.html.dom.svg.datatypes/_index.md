När den används i matrisoperationer behandlas en SVGPoint som en vektor av formen: [x] [y] [1] Om ett SVGRect‑objekt markeras som skrivskyddat, kommer ett försök att tilldela ett av dess attribut att resultera i ett undantag som kastas. |
