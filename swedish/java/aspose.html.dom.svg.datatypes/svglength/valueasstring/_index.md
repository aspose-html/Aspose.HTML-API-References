## SVGLength.ValueAsString property

Värdet som en String, i de enheter som uttrycks av unitType. Att sätta detta attribut kommer att göra att value, valueInSpecifiedUnits och unitType uppdateras automatiskt för att återspegla denna inställning.

public String ValueAsString { get; set; }
