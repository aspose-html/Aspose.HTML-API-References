## IBlob.Size property

Returnerar storleken på byte-sekvensen i antal byte. Vid hämtning måste efterlevande användaragenter returnera det totala antalet byte som kan läsas av ett FileReader- eller FileReaderSync-objekt, eller 0 om Blobben inte har några byte att läsa.

```java
public ulong Size { get; }
```
