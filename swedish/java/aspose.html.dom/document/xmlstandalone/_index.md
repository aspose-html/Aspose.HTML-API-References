## Document.XmlStandalone property

Ett attribut som specificerar, som en del av XML‑deklarationen, huruvida detta dokument är fristående. Detta är falskt när det inte anges.

```java
public bool XmlStandalone { get; set; }
```

### Property Value

`true` om XML är fristående; annars `false`.
