## Document.StyleSheets property

En lista som innehåller alla stilmallar som explicit länkas in eller bäddas in i ett dokument. För HTML-dokument inkluderar detta externa stilmallar, inkluderade via HTML-LINK-elementet, och inbäddade STYLE-element.

```java
public IStyleSheetList StyleSheets { get; }
```
