## Document.CreateAttributeNS method

Metoden Document.createAttribute() skapar en ny attributnod och returnerar den. Objektet skapar en nod som implementerar [Attr](T:com.aspose.html.dom.Attr)‑gränssnittet. DOM‑implementeringen påtvingar inte vilken typ av attribut som kan läggas till ett specifikt element på detta sätt.

```java
public Attr CreateAttributeNS(String packageURI, String qualifiedName)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| packageURI | String | Paket-URI för attributet. |
| qualifiedName | String | name är en String som innehåller attributets namn. |

### Returvärde

Den [`Attr`](../../attr/).
