## Document.StrictErrorChecking property

Ett attribut som specificerar om felkontroll verkställs eller inte. När den är satt till false är implementationen fri att inte testa varje möjlig felkod som normalt definieras för DOM‑operationer, och inte kasta någon DOMException vid DOM‑operationer eller rapportera fel vid användning av Document.normalizeDocument(). Vid fel är beteendet odefinierat. Detta attribut är true som standard.

```java
public bool StrictErrorChecking { get; set; }
```

### Property Value

`true` om strikt felkontroll; annars `false`.
