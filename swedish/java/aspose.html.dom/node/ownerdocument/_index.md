## Node.OwnerDocument property

Den skrivskyddade ownerDocument‑egenskapen i Node‑gränssnittet returnerar dokumentobjektet på högsta nivå för noden.

```java
public Document OwnerDocument { get; }
```

### Property Value

Ett [`Document`](../../document/) som är det översta objektet där alla barnnoder skapas.

Om den här egenskapen används på en nod som själv är ett dokument, är värdet null.
