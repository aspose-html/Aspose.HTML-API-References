## Node.PreviousSibling property

Den skrivskyddade previousSibling‑egenskapen i [`Node`](../)‑gränssnittet returnerar noden som omedelbart föregår den angivna i dess förälders [`childNodes`](../firstchild/)‑lista, eller null om den angivna noden är den första i listan.

```java
public Node PreviousSibling { get; }
```

### Property Value

Ett [`Node`](../) som representerar den föregående syskonnoden till den aktuella noden, eller null om det inte finns några.
