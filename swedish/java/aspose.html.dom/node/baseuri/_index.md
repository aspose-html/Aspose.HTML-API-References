## Node.BaseURI property

Den skrivskyddade baseURI‑egenskapen i Node‑gränssnittet returnerar den absoluta bas‑URL:en för dokumentet som innehåller noden.

Bas‑URL:en används för att lösa relativa URL:er när webbläsaren behöver erhålla en absolut URL, till exempel vid bearbetning av HTML‑elementets img‑elements src‑attribut eller xlink:href‑ eller href‑attributen i SVG.

```java
public String BaseURI { get; }
```

### Property Value

BaseURI‑getter‑metoden returnerar detta nod‑dokumentets dokumentbas‑URL, serialiserad.
