## Node.LocalName property

Returnerar den lokala delen av det kvalificerade namnet för denna nod. För noder av någon annan typ än [`ELEMENT_NODE`](../element_node/) och [`ATTRIBUTE_NODE`](../attribute_node/) samt noder skapade med en DOM Level 1‑metod, såsom [`Document.createElement()`](../../document/createelement/), är detta alltid null.

```java
public String LocalName { get; }
```

### Property Value

En String som representerar den lokala delen av elementets kvalificerade namn.
