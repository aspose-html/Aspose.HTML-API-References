## Node.NextSibling property

Den skrivskyddade nextSibling‑egenskapen för [`Node`](../)‑gränssnittet returnerar noden som omedelbart följer den angivna i deras förälders [`childNodes`](../childnodes/), eller returnerar null om den angivna noden är det sista barnet i föräldraelementet.

```java
public Node NextSibling { get; }
```

### Property Value

Ett [`Node`](../) som representerar nästa syskon till den aktuella noden, eller null om det inte finns några.
