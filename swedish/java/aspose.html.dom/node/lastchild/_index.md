## Node.LastChild property

Den skrivskyddade lastChild‑egenskapen i [`Node`](../)‑gränssnittet returnerar den sista barnet till noden. Om dess förälder är ett element är barnet vanligtvis ett elementnod, ett textnod eller ett kommentarsnod. Den returnerar null om det inte finns några barnnoder.

```java
public Node LastChild { get; }
```

### Property Value

Ett [`Node`](../) som är det sista barnet till noden, eller null om det inte finns några barnnoder.
