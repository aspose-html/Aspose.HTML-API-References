## Node.ParentElement property

Den skrivskyddade parentElement‑egenskapen i [`Node`](../)‑gränssnittet returnerar DOM‑nodens föräldra‑[`Element`](../../element/), eller null om noden antingen saknar förälder, eller dess förälder inte är ett DOM‑Element.

```java
public Element ParentElement { get; }
```

### Property Value

Ett [`Element`](../../element/) som är föräldraelementet till den aktuella noden, eller null om det inte finns något.
