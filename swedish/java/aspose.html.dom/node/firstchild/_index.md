## Node.FirstChild property

Den skrivskyddade firstChild‑egenskapen i [`Node`](../)‑gränssnittet returnerar nodens första barn i trädet, eller null om noden saknar barn.

Om noden är ett Document returnerar denna egenskap den första noden i listan över dess direkta barn.

```java
public Node FirstChild { get; }
```

### Property Value

Ett [`Node`](../), eller null om det inte finns några.
