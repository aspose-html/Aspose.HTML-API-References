## Node.IsEqualNode method

Metoden isEqualNode() för [`Node`](../)‑gränssnittet testar om två noder är lika. Två noder är lika när de har samma typ, definierande egenskaper (för element, detta skulle vara deras ID, antal barn och så vidare), deras attribut matchar och så vidare. Den specifika uppsättningen av datapunkter som måste matcha varierar beroende på nodernas typer.

```java
public bool IsEqualNode(Node otherNode)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| otherNode | Node | Den [`Node`](../) att jämföra likhet med. |

### Returvärde

Ett boolean‑värde som är true om de två noderna är lika, eller false om de inte är det. Om otherNode är null, returnerar isEqualNode() alltid false.
