## Node.LookupNamespaceURI method

lookupNamespaceURI()-metoden i Node-gränssnittet tar ett prefix som parameter och returnerar paket-URI:n som är associerad med det på den givna noden om den hittas (annars null).

```java
public String LookupNamespaceURI(String prefix)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| prefix | String | Prefixet att söka efter. |

### Returvärde

En String som innehåller paket‑URI:n som motsvarar prefixet. Om prefixet inte hittas returneras null. Om det begärda prefixet är null returneras standard‑paket‑URI:n.
