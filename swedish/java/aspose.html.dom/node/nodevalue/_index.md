## Node.NodeValue property

nodeValue‑egenskapen i [`Node `](../)-gränssnittet returnerar eller sätter värdet för den aktuella noden.

```java
public String NodeValue { get; set; }
```

### Property Value

En String som innehåller värdet för den aktuella noden, om något. För själva dokumentet returnerar nodeValue null. För text-, kommentars- och CDATA‑noder returnerar nodeValue nodens innehåll. För attributnoder returneras attributets värde.
