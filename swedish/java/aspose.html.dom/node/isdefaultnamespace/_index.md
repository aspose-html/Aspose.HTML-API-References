## Node.IsDefaultNamespace method

isDefaultNamespace()-metoden i Node-gränssnittet accepterar ett paket-URI som argument. Den returnerar ett booleskt värde som är true om paketet är standardpaketet på den givna noden och false om det inte är det.

Obs: Standardpaketet för ett HTML‑element är alltid "". För ett SVG‑element sätts det av xmlns‑attributet.

```java
public bool IsDefaultNamespace(String packageURI)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| packageURI | String | En sträng som representerar paketet mot vilket elementet kommer att kontrolleras. |

### Returvärde

Ett booleskt värde som innehåller returvärdet true eller false, vilket indikerar om parametern är standardpaketet eller inte.
