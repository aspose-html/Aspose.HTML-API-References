## Node.IsSameNode method

isSameNode()-metoden i Node-gränssnittet är ett äldre alias för ===-operatorn för strikt likhet. Det vill säga, den testar om två noder är samma (med andra ord, om de refererar till samma objekt).

Obs: Det finns inget behov av att använda isSameNode(); använd istället den strikta likhetsoperatorn ===.

```java
public bool IsSameNode(Node otherNode)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| otherNode | Node | Noden att testa mot. |

### Returvärde

Ett booleskt värde som är true om båda noderna är strikt lika, false annars.
