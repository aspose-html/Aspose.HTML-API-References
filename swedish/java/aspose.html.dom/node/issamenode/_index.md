## Node.IsSameNode method

isSameNode()-metoden i Node-gränssnittet är ett äldre alias för ===-operatorn för strikt likhet. Den testar alltså om två noder är desamma (med andra ord, om de refererar till samma objekt).

Obs: Det är inte nödvändigt att använda isSameNode(); använd i stället den strikta likhetsoperatorn ===.

```java
public bool IsSameNode(Node otherNode)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| otherNode | Node | Node som ska testas mot. |

### Returvärde

Ett booleskt värde som är true om båda noderna är strikt lika, false om de inte är det.
