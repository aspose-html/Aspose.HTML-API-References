## Text.IsElementContentWhitespace property

Returnerar huruvida den här textnoden innehåller elementinnehålls‑blanksteg, ofta felaktigt kallat "ignorerbart blanksteg".

```java
public bool IsElementContentWhitespace { get; }
```

### Property Value

`true` om detta objekt är elementinnehålls‑blanksteg; annars `false`.
