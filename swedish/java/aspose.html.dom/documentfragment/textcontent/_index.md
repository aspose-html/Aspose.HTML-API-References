## DocumentFragment.TextContent property

Detta attribut returnerar textinnehållet för denna nod och dess undernoder. När det är definierat som null har en eventuell inställning ingen effekt. Vid inställning tas eventuella befintliga barn till noden bort och, om den nya strängen inte är tom eller null, ersätts den med ett enda Text‑nod som innehåller den sträng som attributet sätts till.

```java
public String TextContent { get; set; }
```

### Property Value

Textens innehåll.
