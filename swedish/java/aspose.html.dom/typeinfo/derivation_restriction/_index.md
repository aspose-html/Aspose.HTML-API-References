## TypeInfo.DERIVATION_RESTRICTION field

Om dokumentets schema är ett XML-schema [XML Schema Part 1] representerar denna konstant derivationen genom restriktion om komplexa typer är inblandade, eller en restriktion om enkla typer är inblandade.

```java
public const ulong DERIVATION_RESTRICTION;
```
