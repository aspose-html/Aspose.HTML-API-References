## Element.LocalName property

Returnerar den lokala delen av det kvalificerade namnet för detta nod. För noder av någon annan typ än ELEMENT_NODE och ATTRIBUTE_NODE samt noder skapade med en DOM Level 1‑metod, såsom Document.createElement(), är detta alltid null.

```java
public String LocalName { get; }
```

### Property Value

Namnet på den lokala.
