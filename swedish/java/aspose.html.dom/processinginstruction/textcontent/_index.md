## ProcessingInstruction.TextContent property

Detta attribut returnerar textinnehållet för denna nod och dess undernoder. När det är definierat som null har en eventuell ändring ingen effekt. Vid en ändring tas alla eventuella barn till noden bort och, om den nya strängen inte är tom eller null, ersätts den med en enda Text‑nod som innehåller den sträng som attributet sätts till.

```java
public String TextContent { get; set; }
```

### Property Value

Textens innehåll.
