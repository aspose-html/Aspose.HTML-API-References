Paketet **com.aspose.html.dom.attributes** innehåller enhetliga attributklasser som specificerar eller kvalificerar någon objekts (nod, element, ...) egenskap eller beteende.

## Klasser

| Klass | Beskrivning |
| --- | --- |
| [DOMConstructorAttribute](./domconstructorattribute/) | Specificerar en konstruktor som definieras av W3C. |
| [DOMNameAttribute](./domnameattribute/) | Specificerar det officiella DOM‑objektnamnet som definieras av W3C. |
| [DOMNamedPropertyGetterAttribute](./domnamedpropertygetterattribute/) | Specificerar att metoden kommer att användas som en namngiven egenskaps‑getter. |
| [DOMNoInterfaceObjectAttribute](./domnointerfaceobjectattribute/) | Om det utökade attributet [NoInterfaceObject] förekommer på ett gränssnitt, indikerar det att ett gränssnittsobjekt inte kommer att finnas för gränssnittet i ECMAScript‑bindningen. |
| [DOMNullableAttribute](./domnullableattribute/) | Specificerar att ett DOM‑objekt kan tilldelas null‑värde. |
| [DOMObjectAttribute](./domobjectattribute/) | Specificerar att objektet som är markerat med detta attribut är definierat av W3C. |
| [DOMTreatNullAsAttribute](./domtreatnullasattribute/) | Indikerar att null för medlemsvärdet kommer att behandlas som det specificerade värdet. |
