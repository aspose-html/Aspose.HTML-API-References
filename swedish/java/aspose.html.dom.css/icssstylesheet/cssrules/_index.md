## ICSSStyleSheet.CSSRules property

Den skrivskyddade CSSStyleSheet‑egenskapen cssRules returnerar en levande [`CSSRuleList`](../../icssrulelist/) som ger en realtids‑uppdaterad lista över varje CSS‑regel som utgör stilarket. Varje objekt i listan är en [`CSSRule`](../../icssrule/) som definierar en enskild regel.

```java
public ICSSRuleList CSSRules { get; }
```

### Property Value

En levande uppdaterande [`CSSRuleList`](../../icssrulelist/) som innehåller alla CSS‑regler som utgör stilarket. Varje post i regel‑listan är ett [`CSSRule`](../../icssrule/)‑objekt som beskriver en regel i stilarket.
