## ICSSStyleSheet.OwnerRule property

Den skrivskyddade CSSStyleSheet‑egenskapen ownerRule returnerar [`CSSImportRule`](../../icssimportrule/) som motsvarar @import‑at‑regeln som importerade stilarket till dokumentet. Om stilarket inte importerades till dokumentet med @import är det returnerade värdet null.

```java
public ICSSRule OwnerRule { get; }
```

### Property Value

En CSSImportRule som motsvarar @import‑regeln som importerade stilarket till dokumentet. Om stilarket inte importerades till dokumentet med @import är det returnerade värdet null.
