## ICSSImportRule interface

CSSImportRule‑gränssnittet representerar en @import‑regel i ett CSS‑stilmall. @import‑regeln används för att importera stilregler från andra stilmallar.

```java
public interface ICSSImportRule : ICSSRule
```

| [getMedia](../../com.aspose.html.dom.css/icssimportrule/media/) Den skrivskyddade media‑egenskapen i CSSImportRule‑gränssnittet returnerar ett MediaList‑objekt som innehåller värdet av media‑attributet i det associerade formatarket. |
