## ICSSImportRule.StyleSheet property

Stilmallen som hänvisas till av denna regel, om den har laddats. Värdet för detta attribut är null om stilmallen ännu inte har laddats eller om den inte kommer att laddas (t.ex. om stilmallen är för en mediatyp som inte stöds av användaragenten).

```java
public ICSSStyleSheet StyleSheet { get; }
```

### Property Value

Returnerar CSS-stilmallen som specificeras av @import-at-regeln. Detta kommer att vara i form av ett [`CSSStyleSheet`](../../icssstylesheet/)‑objekt.
