## SetProperty(String, String) {#setproperty}

Metodgränssnittet CSSStyleDeclaration.setProperty() används för att sätta ett egenskapsvärde med standardprioritet i detta deklarationsblock. Standardprioriteten är inte "important", d.v.s. String.Empty.

```java
public void SetProperty(String propertyName, String value)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| propertyName | String | En String som representerar CSS-egenskapsnamnet (med bindestreck) som ska modifieras. |
| värde | String | En String som innehåller det nya egenskapsvärdet. Om den inte anges behandlas den som en tom String. |

## SetProperty(String, String, String) {#setproperty_1}

Metodgränssnittet CSSStyleDeclaration.setProperty() används för att sätta ett egenskapsvärde med standardprioritet i detta deklarationsblock. Standardprioriteten är inte "important", d.v.s. String.Empty.

```java
public void SetProperty(String propertyName, String value, String priority)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| propertyName | String | En String som representerar CSS-egenskapsnamnet (med bindestreck) som ska modifieras. |
| värde | String | En String som innehåller det nya egenskapsvärdet. Om den inte anges behandlas den som en tom String. |
| prioritet | String | En String som tillåter att CSS-prioriteten "important" sätts. Om den inte anges behandlas den som en tom String. Följande värden accepteras: String‑värdet "important", nyckelordet undefined eller en tom String "". |
