## ICSSStyleDeclaration.ParentRule property

Den skrivskyddade egenskapen CSSStyleDeclaration.parentRule returnerar en CSSRule som är föräldern till detta stilblock, t.ex. en [`CSSStyleRule`](../../icssstylerule/) som representerar stilen för en CSS-väljare.

```java
public ICSSRule ParentRule { get; }
```

### Property Value

CSS-regeln som innehåller detta deklarationsblock eller null om denna [`CSSStyleDeclaration`](../) inte är bifogad till en [`CSSRule`](../../icssrule/).
