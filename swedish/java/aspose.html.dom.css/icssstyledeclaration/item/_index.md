## ICSSStyleDeclaration indexer

Används för att hämta de egenskaper som har satts explicit i detta deklarationsblock. Ordningen på de egenskaper som hämtas med denna metod behöver inte vara den ordning de sattes i. Metoden kan användas för att iterera över alla egenskaper i detta deklarationsblock.

```java
public String this[int index] { get; }
```

### Returvärde

propertyName är en String som är namnet på CSS-egenskapen på det angivna indexet.

### Property Value

index är indexet för noden som ska hämtas. Indexet är nollbaserat.
