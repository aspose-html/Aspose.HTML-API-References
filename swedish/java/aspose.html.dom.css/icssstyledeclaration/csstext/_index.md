## ICSSStyleDeclaration.CSSText property

Den parsbara textrepresentationen av deklarationsblocket (utan de omgivande klammerparenteserna). Att sätta detta attribut kommer att leda till parsning av det nya värdet och återställning av alla egenskaper i deklarationsblocket, inklusive borttagning eller tillägg av egenskaper.

```java
public String CSSText { get; set; }
```

### Property Value

Att sätta detta attribut ändrar den inbäddade stilen. Om du vill ha en textrepresentation av ett beräknat deklarationsblock kan du hämta den med JSON.Stringify().
