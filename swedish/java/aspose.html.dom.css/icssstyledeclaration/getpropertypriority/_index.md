## ICSSStyleDeclaration.GetPropertyPriority method

Används för att hämta prioriteten för en CSS‑egenskap (t.ex. \"important\"‑kvalificeraren) om egenskapen har satts explicit i detta deklarationsblock.

```java
public String GetPropertyPriority(String propertyName)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| propertyName | String | property är en DOMString som representerar egenskapsnamnet som ska kontrolleras. |

### Returvärde

priority är en DOMString som representerar prioriteten (e.g. "important") om den finns. Om ingen finns returneras en tom Sträng.
