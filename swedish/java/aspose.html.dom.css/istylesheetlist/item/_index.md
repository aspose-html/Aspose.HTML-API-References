## IStyleSheetList indexer

Metoden item(index) måste returnera den index‑te [`CSS style sheet`](../../icssstylesheet/) i samlingen. Om det inte finns något objekt på det indexet i samlingen måste metoden returnera null.

```java
public ICSSStyleSheet this[int index] { get; }
```

### Returvärde

Ett [`CSSStyleSheet`](../../icssstylesheet/)‑objekt, eller null om ett sådant inte finns för detta index.

### Property Value

Ett heltal som är indexet för objektet i samlingen som ska returneras.
