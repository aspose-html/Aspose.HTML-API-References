## IStyleSheetList.Length property

Attributet length måste returnera antalet CSS‑stilmallar som representeras av samlingen. Intervallet för giltiga underordnade stilbladsindex är 0 till length‑1 inklusive.

```java
public int Length { get; }
```

### Property Value

Ett heltal som anger antalet objekt i samlingen.
