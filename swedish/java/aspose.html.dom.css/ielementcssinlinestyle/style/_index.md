## IElementCSSInlineStyle.Style property

Stil-attributet måste returnera ett CSS-deklarationsblockobjekt vars beräknade flagga är avaktiverad, vars föräldra-CSS-regel är null, och vars ägarnod är kontextobjektet.

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

Det associerade CSS-deklarationsblocket för noden eller null om det inte finns något associerat CSS-deklarationsblock.
