## CSSValueList indexer

item()-metoden i CSSValueList-gränssnittet används för att hämta ett CSSValue efter ordinalt index.

Ordningen i denna samling representerar ordningen på värdena i CSS-stilegenskapen. Om indexet är större än eller lika med antalet värden i listan returnerar metoden null.

```java
public CSSValue this[int index] { get; }
```

### Returvärde

Ett CSSValue-objekt på indexpositionen i CSSValueList, eller null om det inte är ett giltigt index.

### Property Value

En unsigned long som representerar indexet för CSS‑värdet inom samlingen.
