## Anmärkningar

Färgen på varje pixel representeras som ett 32‑bitars tal: 8 bitar vardera för alfa, röd, grön och blå (ARGB). Alfa‑komponenten anger färgens transparens: 0 är helt transparent, och 255 är helt ogenomskinlig. På samma sätt representerar ett A‑värde på 255 en ogenomskinlig färg. Ett A‑värde från 1 till 254 representerar en semitransparent färg. Färgen blir mer ogenomskinlig ju närmare 255 A‑värdet kommer.
