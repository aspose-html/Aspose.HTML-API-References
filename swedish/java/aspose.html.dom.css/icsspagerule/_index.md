## ICSSPageRule interface

CSSPageRule‑gränssnittet representerar en @page‑regel i ett CSS‑stilmall. @page‑regeln används för att specificera dimensioner, orientering, marginaler osv. för en sidlåda i paginerade medier.

public interface ICSSPageRule : ICSSRule
