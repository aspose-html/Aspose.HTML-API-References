## ICSSPageRule.Style property

Den skrivskyddade style‑egenskapen i [`CSSPageRule`](../)‑gränssnittet returnerar ett [`CSSStyleDeclaration`](../../icssstyledeclaration/)-objekt. Detta representerar ett objekt som är ett CSS‑deklarationsblock och exponerar stilinformation samt olika stilrelaterade metoder och egenskaper.

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

Ett [`CSSStyleDeclaration`](../../icssstyledeclaration/)-objekt som representerar ett CSS‑deklarationsblock.
