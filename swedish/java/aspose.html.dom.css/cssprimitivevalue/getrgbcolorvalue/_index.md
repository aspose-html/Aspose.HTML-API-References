## CSSPrimitiveValue.GetRGBColorValue method

Denna metod används för att hämta RGB‑färgen. Om detta CSS‑värde inte innehåller ett RGB‑färgvärde, kastas ett DOMException. Modifiering av motsvarande stil‑egenskap kan uppnås med hjälp av RGBColor‑gränssnittet.

```java
public abstract RGBColor GetRGBColorValue()
```

### Returvärde

Returnerar RGB‑färgvärde
