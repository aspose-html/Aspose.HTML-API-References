## CSSPrimitiveValue.SetFloatValue method

En metod för att sätta flyttalsvärdet med en specificerad enhet. Om egenskapen som är kopplad till detta värde inte kan acceptera den specificerade enheten eller flyttalsvärdet, förblir värdet oförändrat och ett DOMException kastas.

```java
public abstract void SetFloatValue(ushort unitType, float floatValue)
```

| unitType | UInt16 | Typ av enheten. |
