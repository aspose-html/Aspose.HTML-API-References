## CSSPrimitiveValue.SetFloatValue method

En metod för att sätta flyttalvärdet med en specificerad enhet. Om egenskapen som är kopplad till detta värde inte kan acceptera den specificerade enheten eller flyttalvärdet, förblir värdet oförändrat och ett DOMException kastas.

```java
public abstract void SetFloatValue(ushort unitType, float floatValue)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| unitType | UInt16 | Typ av enheten. |
| floatValue | Single | Det flytande värdet. |
