## IStyleSheet.Title property

title‑egenskapen i [`StyleSheet`](../)‑gränssnittet returnerar den rekommenderade titeln för det aktuella stilarket.

Titeln anges ofta i [`ownerNode`](../ownernode/).

```java
public String Title { get; }
```

### Property Value

parentStyleSheet‑attributet måste returnera den överordnade [`CSS style sheet`](../../icssstylesheet/).
