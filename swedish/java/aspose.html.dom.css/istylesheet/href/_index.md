## IStyleSheet.Href property

href‑egenskapen i [`StyleSheet`](../)‑gränssnittet returnerar platsen för stilarket.

```java
public String Href { get; }
```

### Property Value

uri är en String som innehåller stilarkets URI.

## Anmärkningar

Om stilarket är ett länkat stilark är värdet för dess attribut dess plats. För inbäddade stilark är värdet för detta attribut NULL.

Denna egenskap är skrivskyddad i Firefox, Opera, Google Chrome och Safari, och den är läs/skriv i Internet Explorer.
