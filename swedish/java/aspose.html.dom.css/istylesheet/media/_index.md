## IStyleSheet.Media property

Media‑egenskapen i [`StyleSheet`](../)-gränssnittet specificerar det avsedda målmediet för stilinformation. Det är ett skrivskyddat, array‑likt [`MediaList`](../../imedialist/)-objekt och kan tas bort med deleteMedium() och läggas till med appendMedium().

```java
public IMediaList Media { get; }
```

### Property Value

Media‑attributet måste returnera [`MediaList`](../../imedialist/)-objektet som är associerat med CSS‑stilmallen.
