## IDocumentCSS.GetOverrideStyle method

Denna metod används för att hämta override‑stildeklarationen för ett specificerat element och ett specificerat pseudo‑element.

```java
public ICSSStyleDeclaration GetOverrideStyle(Element elt, String pseudoElt)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| elt | Element | Elementet vars stil ska modifieras. Denna parameter får inte vara null. |
| pseudoElt | String | Pseudo‑elementet eller null om inget finns. |

### Returvärde

Överskrivnings‑stildeklarationen.
