## IMediaList.MediaText property

En Stringifier som returnerar en DOMString som representerar MediaList som text, och också låter dig ange en ny MediaList.

```java
public String MediaText { get; }
```

### Property Value

Den parsbara textrepresentationen av medialistan. Detta är en kommaseparerad lista över media.
