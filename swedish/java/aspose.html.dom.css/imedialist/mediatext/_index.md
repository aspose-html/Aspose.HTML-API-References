## IMediaList.MediaText property

En Stringifier som returnerar en DOMString som representerar MediaList som text, och även låter dig ange en ny MediaList.

```java
public String MediaText { get; }
```

### Property Value

Den parsbara textrepresentationen av medi­listan. Detta är en kommaseparerad lista av media.
