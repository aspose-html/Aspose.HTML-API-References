## IMediaList indexer

item(index)-metoden måste returnera en serialisering av medie‑frågan i samlingen av medie‑frågor som anges av index, eller null, om index är större än eller lika med antalet medie‑frågor i samlingen.

```java
public String this[int index] { get; }
```

### Returvärde

Returnerar en String som representerar en medie‑fråga som text, givet medie‑frågan indexvärde i [`MediaList`](../).

### Property Value

Ett heltal som är indexet för objektet i samlingen som ska returneras.
