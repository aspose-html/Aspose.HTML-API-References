## ICSSMediaRule.CSSRules property

cssRules-egenskapen i CSSGroupingRule-gränssnittet returnerar en [`CSSRuleList`](../../icssrulelist/) som innehåller en samling av [`CSSRule`](../../icssrule/) objekt.

```java
public ICSSRuleList CSSRules { get; }
```

### Property Value

cssRules-attributet måste returnera ett [`CSSRuleList`](../../icssrulelist/)‑objekt för de underordnade CSS‑reglerna.
