## ICSSMediaRule.InsertRule method

insertRule()-metoden för CSSGroupingRule‑gränssnittet lägger till en ny CSS‑regel i en lista med CSS‑regler.

```java
public long InsertRule(String rule, long index)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| regel | String | Media‑regeln som CSSOMString. |
| index | Int64 | Ett valfritt index där regeln ska infogas; standardvärdet är 0. |

### Returvärde

insertRule(rule, index)-metoden returnerar resultatet av att infoga en CSS‑regel i de underordnade CSS‑reglerna på angivet index.
