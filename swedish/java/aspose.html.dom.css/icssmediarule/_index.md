## ICSSMediaRule interface

CSSMediaRule‑gränssnittet representerar en @media‑regel i ett CSS‑stilmall. En @media‑regel kan användas för att avgränsa stilregler för specifika mediatyper.

```java
public interface ICSSMediaRule : ICSSRule
```

## Egenskaper

| Namn | Beskrivning |
| --- | --- |
| [getCSSRules](../../com.aspose.html.dom.css/icssmediarule/cssrules/) cssRules-egenskapen i CSSGroupingRule-gränssnittet returnerar en [`CSSRuleList`](../icssrulelist/) som innehåller en samling av [`CSSRule`](../icssrule/)-objekt. |
| [getMedia](../../com.aspose.html.dom.css/icssmediarule/media/) Den skrivskyddade media-egenskapen i `CSSMediaRule`-gränssnittet MediaList representerar det avsedda destinationsmediet för stilinformation. |
