## ICSSKeyframeRule interface

`CSSKeyframeRule`‑gränssnittet beskriver ett objekt som representerar en uppsättning stilar för ett givet nyckelbildruta. Det motsvarar innehållet i en enskild nyckelbildruta i en @keyframes‑at‑regel.

```java
public interface ICSSKeyframeRule : ICSSRule
```
