## ICSS2Properties.WordSpacing property

Denna egenskap anger avståndsbeteende mellan ord. Värdena har följande betydelser:

normal - Det normala mellanslaget mellan ord, som definieras av det aktuella teckensnittet och/eller UA.'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - Detta värde anger mellanslag mellan ord utöver standardmellanrummet mellan ord. Värden kan vara negativa, men det kan finnas implementationsspecifika gränser.

```java
public String WordSpacing { get; set; }
```
