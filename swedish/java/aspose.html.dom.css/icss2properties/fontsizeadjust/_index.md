## ICSS2Properties.FontSizeAdjust property

I bifoniska skript är den subjektiva upplevda storleken och läsbarheten för ett teckensnitt mindre beroende av deras 'font-size'-värde än av värdet för deras 'x-height', eller, mer praktiskt, av förhållandet mellan dessa två värden, kallat aspektvärdet (font size delat med x-height). Ju högre aspektvärde, desto mer sannolikt är det att ett teckensnitt i mindre storlekar är läsbart. Omvänt blir teckensnitt med ett lägre aspektvärde oläsliga snabbare under en given tröskelstorlek än teckensnitt med ett högre aspektvärde. En enkel teckensnittssubstitution som enbart förlitar sig på teckensnittsstorlek kan leda till oläsliga tecken.

```java
public String FontSizeAdjust { get; set; }
```
