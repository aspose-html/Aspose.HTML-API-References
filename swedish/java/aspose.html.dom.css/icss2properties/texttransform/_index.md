## ICSS2Properties.TextTransform property

Denna egenskap styr versaliserings-effekter på ett elements text. Värden har följande betydelser:

capitalize - Sätter det första tecknet i varje ord till versal. uppercase - Sätter alla tecken i varje ord till versal. lowercase - Sätter alla tecken i varje ord till gemen. none - Ingen versaliserings-effekt.

```java
public String TextTransform { get; set; }
```
