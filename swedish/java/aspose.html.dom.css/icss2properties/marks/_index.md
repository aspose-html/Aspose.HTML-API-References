## ICSS2Properties.Marks property

Vid högkvalitativ utskrift läggs ofta märken till utanför sidoboxen. Denna egenskap specificerar om korsmärken eller beskärningsmärken eller båda ska renderas precis utanför [sidoboxens](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#page-box) kant.

Beskärningsmärken visar var sidan ska skäras. Korsmärken (även kända som registermärken eller registreringsmärken) används för att justera ark.

Märken är endast synliga på absoluta sidoboxar (se egenskapen ['size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-size)). I relativa sidoboxar kommer sidoboxen att justeras med målet och märkena kommer att ligga utanför det utskrivbara området.

Storleken, stilen och positionen för korsmarkeringar beror på användaragenten.

```java
public String Marks { get; set; }
```
