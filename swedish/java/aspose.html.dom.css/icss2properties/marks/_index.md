## ICSS2Properties.Marks property

Vid högkvalitativ utskrift läggs ofta markeringar till utanför sidrutan. Denna egenskap specificerar om korsmarkeringar eller beskärningsmarkeringar eller båda ska renderas precis utanför [page box](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#page-box)-kanten.

Beskärningsmarkeringar visar var sidan ska skäras. Korsmarkeringar (även kända som registermarkeringar eller registreringsmarkeringar) används för att justera ark.

Markeringar är endast synliga på absoluta sidrutor (se egenskapen ['size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-size)). I relativa sidrutor kommer sidrutan att justeras med målet och markeringarna kommer att ligga utanför det utskrivbara området.

Storleken, stilen och positionen för korsmarkeringar beror på användaragenten.

```java
public String Marks { get; set; }
```
