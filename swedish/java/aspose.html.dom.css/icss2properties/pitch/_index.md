## ICSS2Properties.Pitch property

Anger den genomsnittliga tonhöjden (en frekvens) för den talande rösten. Den genomsnittliga tonhöjden för en röst beror på röstfamiljen. Till exempel är den genomsnittliga tonhöjden för en standard manlig röst omkring 120 Hz, men för en kvinnlig röst är den omkring 210 Hz.

```java
public String Pitch { get; set; }
```
