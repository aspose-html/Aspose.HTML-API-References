## ICSS2Properties.Margin property

Egenskapen ['margin'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin) är en förkortningsegenskap för att ange ['margin-top'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-top), ['margin-right'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-right), ['margin-bottom'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-bottom) och ['margin-left'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-left) på samma plats i stilarket.

Om det finns endast ett värde gäller det för alla sidor. Om det finns två värden sätts de övre och nedre marginalerna till det första värdet och de högra och vänstra marginalerna till det andra. Om det finns tre värden sätts den övre till det första värdet, de vänstra och högra till det andra, och den nedre till det tredje. Om det finns fyra värden gäller de för den övre, högra, nedre och vänstra respektive.

public String Margin { get; set; }
