## ICSS2Properties.BorderSpacing property

Längderna specificerar avståndet som separerar intilliggande cellgränser. Om en längd anges ger den både horisontellt och vertikalt avstånd. Om två anges ger den första horisontellt avstånd och den andra vertikalt avstånd. Längder får inte vara negativa.

public String BorderSpacing { get; set; }
