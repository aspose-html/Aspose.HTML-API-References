## ICSS2Properties.MarkerOffset property

Denna egenskap anger avståndet mellan de närmaste [border edges](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#border-edge) på en markeringsruta och dess tillhörande [principal box](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#principal-box). Offset kan antingen vara en användarspecificerad ([length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)) eller väljas av UA ('auto'). Längder kan vara negativa, men det kan finnas implementationsspecifika begränsningar.

```java
public String MarkerOffset { get; set; }
```
