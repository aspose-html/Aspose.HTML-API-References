## ICSS2Properties.FontVariant property

I ett small-caps-typsnitt ser glyferna för gemena bokstäver liknande ut som de versala, men i en mindre storlek och med något annorlunda proportioner. 'font-variant'-egenskapen begär ett sådant typsnitt för bikamerala (med två fall, som i latinskt skriftsystem). Denna egenskap har ingen synlig effekt för skript som är unika (med endast ett fall, som i de flesta av världens skriftsystem).

```java
public String FontVariant { get; set; }
```
