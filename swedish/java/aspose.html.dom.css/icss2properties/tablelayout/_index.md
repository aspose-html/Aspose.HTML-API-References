## ICSS2Properties.TableLayout property

Den ['table-layout'](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#propdef-table-layout)-egenskapen styr algoritmen som används för att placera tabellceller, rader och kolumner. Värden har följande betydelse:

fixed - Använd den fasta tabellayoutalgoritmen auto - Använd någon automatisk tabellayoutalgoritm

```java
public String TableLayout { get; set; }
```
