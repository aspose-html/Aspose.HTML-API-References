## ICSS2Properties.Outline property

Konturen som skapas med outline‑egenskaperna ritas "over" en ruta, d.v.s. konturen är alltid överst och påverkar inte positionen eller storleken på rutan eller någon annan ruta. Därför orsakar visning eller undertryckning av konturer ingen omflöde.

public String Outline { get; set; }
