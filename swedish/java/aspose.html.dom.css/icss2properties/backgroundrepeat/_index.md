## ICSS2Properties.BackgroundRepeat property

Om en bakgrundsbild anges specificerar denna egenskap huruvida bilden upprepas (tillkallas mosaik) och hur. All mosaik täcker innehålls- och paddingområdena i en ruta. Värdena har följande betydelser:

repeat - Bilden upprepas både horisontellt och vertikalt. repeat-x - Bilden upprepas endast horisontellt. repeat-y - Bilden upprepas endast vertikalt. no-repeat - Bilden upprepas inte: endast en kopia av bilden ritas.

```java
public String BackgroundRepeat { get; set; }
```

### Returvärde

background-repeat-egenskap

### Property Value

Bakgrundsupprepningsvärdet från listan som det definierades ovan.
