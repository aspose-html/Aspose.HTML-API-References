## ICSS2Properties.CaptionSide property

Denna egenskap specificerar positionen för bildtextlådan i förhållande till tabellådan. Värden har följande betydelser:

top - Positionerar bildtextlådan ovanför tabellådan. bottom - Positionerar bildtextlådan under tabellådan. left - Positionerar bildtextlådan till vänster om tabellådan. right - Positionerar bildtextlådan till höger om tabellådan.

```java
public String CaptionSide { get; set; }
```
