## ICSS2Properties.PitchRange property

Anger variation i genomsnittlig tonhöjd. Den uppfattade tonhöjden hos en mänsklig röst bestäms av grundfrekvensen och har vanligtvis ett värde på 120 Hz för en manlig röst och 210 Hz för en kvinnlig röst. Mänskliga språk talas med varierande intonation och tonhöjd; dessa variationer förmedlar ytterligare betydelse och betoning. Således visar en mycket livlig röst, d.v.s. en som är starkt intonerad, ett brett tonhöjdsintervall. Denna egenskap anger det intervall inom vilket dessa variationer sker, d.v.s. hur mycket grundfrekvensen kan avvika från den genomsnittliga tonhöjden.

```java
public String PitchRange { get; set; }
```
