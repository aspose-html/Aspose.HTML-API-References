## ICSS2Properties.SpeakNumeral property

Denna egenskap styr hur siffror uttalas. Värden har följande betydelser:

digits - Uttala siffran som enskilda siffror. Således uttalas "237" som "Två Tre Sju". continuous - Uttala siffran som ett helt tal. Således uttalas "237" som "Tvåhundra trettiotvå". Ordrepresentationer är språkberoende.

```java
public String SpeakNumeral { get; set; }
```
