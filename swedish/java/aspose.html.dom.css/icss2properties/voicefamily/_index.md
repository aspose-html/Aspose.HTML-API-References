## ICSS2Properties.VoiceFamily property

Värdet är en kommaseparerad, prioriterad lista med röstfamiljenamn (jämför med ['font-family'](https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html#propdef-font-family)). Värdena har följande betydelser:

'generic-voice' - Värdena är röstfamiljer. Möjliga värden är 'male', 'female' och 'child'.'specific-voice' - Värdena är specifika instanser (t.ex. comedian, trinoids, carlos, lani).

```java
public String VoiceFamily { get; set; }
```
