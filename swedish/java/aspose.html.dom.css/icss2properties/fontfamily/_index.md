## ICSS2Properties.FontFamily property

Denna egenskap specificerar en prioriterad lista av teckensnittsfamiljenamn och/eller generiska familjenamn. För att hantera problemet att ett enskilt teckensnitt kanske inte innehåller glyfer för att visa alla tecken i ett dokument, eller att inte alla teckensnitt är tillgängliga på alla system, tillåter denna egenskap författare att ange en lista av teckensnitt, alla med samma stil och storlek, som provas i sekvens för att se om de innehåller en glyf för ett visst tecken. Denna lista kallas ett font set.

```java
public String FontFamily { get; set; }
```
