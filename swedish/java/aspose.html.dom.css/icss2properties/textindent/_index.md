## ICSS2Properties.TextIndent property

Denna egenskap specificerar indraget för den första raden text i ett block. Mer exakt specificerar den indraget för den första lådan som flödar in i blockets första [line box](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#line-box). Lådan är indragen i förhållande till den vänstra (eller högra, för höger-till-vänster layout) kanten av radlådan. Användaragenter bör rendera detta indrag som blankt utrymme.

Värdena har följande betydelser:

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - Indenteringen är en fast längd.'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - Indenteringen är en procentandel av den omgivande blockets bredd.

public String TextIndent { get; set; }
