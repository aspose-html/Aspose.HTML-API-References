## ICSS2Properties.BackgroundColor property

Denna egenskap sätter bakgrundsfärgen på ett element, antingen ett värde eller nyckelordet 'transparent', för att låta underliggande färger lysa igenom.

```java
public String BackgroundColor { get; set; }
```

### Returvärde

background-color-egenskap

### Property Value

En färg är antingen ett nyckelord eller en numerisk RGB-specifikation.
