## ICSS2Properties.PauseBefore property

Dessa egenskaper specificerar en paus som ska observeras före (eller efter) att ett elements innehåll läses upp. Värden har följande betydelser:

'[time](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-time)' - Anger pausen i absoluta tidsenheter (sekunder och millisekunder). '[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - Avser inversen av värdet för egenskapen ['speech-rate'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-speech-rate). Till exempel, om speech-rate är 120 ord per minut (dvs ett ord tar en halv sekund, eller 500 ms) så betyder ett ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) på 100 % en paus på 500 ms och ett ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) på 20 % betyder 100 ms.

public String PauseBefore { get; set; }
