## ICSS2Properties.PageBreakBefore property

Värden för dessa egenskaper har följande betydelser:

auto - Varken tvinga eller förbjuda ett sidbrytning före (efter, inuti) den genererade lådan. always - Alltid tvinga ett sidbrytning före (efter) den genererade lådan. avoid - Undvika ett sidbrytning före (efter, inuti) den genererade lådan. left - Tvinga ett eller två sidbrytningar före (efter) den genererade lådan så att nästa sida formateras som en vänstersida. right - Tvinga ett eller två sidbrytningar före (efter) den genererade lådan så att nästa sida formateras som en högersida.

```java
public String PageBreakBefore { get; set; }
```
