## ICSS2Properties.PageBreakInside property

Värden för dessa egenskaper har följande betydelser:

auto - Varken tvinga eller förbjuda en sidbrytning före (efter, inuti) den genererade lådan. always - Alltid tvinga en sidbrytning före (efter) den genererade lådan. avoid - Undvik en sidbrytning före (efter, inuti) den genererade lådan. left - Tvinga en eller två sidbrytningar före (efter) den genererade lådan så att nästa sida formateras som en vänstersida. right - Tvinga en eller två sidbrytningar före (efter) den genererade lådan så att nästa sida formateras som en högersida.

```java
public String PageBreakInside { get; set; }
```
