## ICSS2Properties.Direction property

Denna egenskap specificerar den grundläggande skrivriktningen för block och riktningen för inbäddningar och överskrivningar (se ['unicode-bidi'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-unicode-bidi)) för Unicode:s bidi-algoritm. Dessutom specificerar den riktningen för [table](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html) kolumnlayout, riktningen för horisontell [overflow](https://www.w3.org/TR/1998/REC-CSS2-19980512/visufx.html#overflow), och positionen för en ofullständig sista rad i ett block vid 'text-align: justify'.

```java
public String Direction { get; set; }
```
