## ICSS2Properties.SpeechRate property

Denna egenskap anger talhastigheten. Observera att både absoluta och relativa nyckelordsvärden är tillåtna (jämför med ['font-size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html#propdef-font-size)). Värdena har följande betydelser:

'[number](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-number)' - Anger talhastigheten i ord per minut, en kvantitet som varierar något mellan språk men ändå är allmänt stöd av talsyntesare.

x-slow - Samma som 80 ord per minut.

slow - Samma som 120 ord per minut

medium - Samma som 180 - 200 ord per minut.

snabb - Samma som 300 ord per minut.

x-snabb - Samma som 500 ord per minut.

snabbare - Lägger till 40 ord per minut till den aktuella talhastigheten.

långsammare - Subtraherar 40 ord per minut från den aktuella talhastigheten.

```java
public String SpeechRate { get; set; }
```
