## ICSS2Properties.LineHeight property

Om egenskapen är inställd på ett [block-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#block-level) element vars innehåll består av [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) element, specificerar den den minsta höjden för varje genererad inline-box.

Om egenskapen är inställd på ett [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) element, specificerar den den exakta höjden för varje box som genereras av elementet. (Förutom inline [replaced](https://www.w3.org/TR/1998/REC-CSS2-19980512/conform.html#replaced-element) element, där höjden på boxen ges av ['height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-height) egenskap.)

```java
public String LineHeight { get; set; }
```

### Returvärde

line-height egenskap
