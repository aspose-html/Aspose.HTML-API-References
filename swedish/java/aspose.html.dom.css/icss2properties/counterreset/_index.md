## ICSS2Properties.CounterReset property

Den ['counter-reset'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-counter-reset) property innehåller också en lista med ett eller flera namn på räknare, var och en eventuellt följd av ett heltal. Heltalet anger det värde som räknaren sätts till vid varje förekomst av elementet. Standardvärdet är 0.

```java
public String CounterReset { get; set; }
```
