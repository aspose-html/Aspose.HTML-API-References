## ICSS2Properties.SpeakPunctuation property

Denna egenskap specificerar hur skiljetecken uttalas. Värden har följande betydelser:

code - Skiljetecken såsom semikolon, klammerparenteser och så vidare ska uttalas bokstavligt. none - Skiljetecken ska inte uttalas, utan istället återges naturligt som olika pauser.

public String SpeakPunctuation { get; set; }
