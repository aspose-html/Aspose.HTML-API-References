## ICSS2Properties.SpeakPunctuation property

Denna egenskap specificerar hur interpunktion uttalas. Värden har följande betydelser:

code - Interpunktion såsom semikolon, klammerparenteser och så vidare ska uttalas bokstavligt. none - Interpunktion ska inte uttalas, utan renderas naturligt som olika pauser.

public String SpeakPunctuation { get; set; }
