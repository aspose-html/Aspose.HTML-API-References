## ICSS2Properties.BorderRightWidth property

Denna egenskap är en förkortning för att ange 'border-top-width', 'border-right-width', 'border-bottom-width' och 'border-left-width' på samma ställe i stilmallen.

Om det finns endast ett värde gäller det för alla sidor. Om det finns två värden sätts de övre och nedre kanterna till det första värdet och de högra och vänstra till det andra. Om det finns tre värden sätts den övre till det första värdet, de vänstra och högra till det andra, och den nedre till det tredje. Om det finns fyra värden gäller de för den övre, högra, nedre och vänstra, i den ordningen.

```java
public String BorderRightWidth { get; set; }
```

### Returvärde

border-right-width egenskap
