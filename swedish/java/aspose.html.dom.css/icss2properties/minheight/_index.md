## ICSS2Properties.MinHeight property

Dessa två egenskaper låter författare begränsa boxhöjder till ett visst intervall. Värden har följande betydelser:

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - Anger en fast minsta eller största beräknade höjd.'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - Anger en procentandel för att bestämma det beräknade värdet. Procentandelen beräknas i förhållande till höjden på den genererade boxens [containing block](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#containing-block). Om höjden på det omgivande blocket inte anges explicit (dvs. den beror på innehållshöjden), tolkas procentvärdet som 'auto'.none - (Endast på ['max-height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-max-height)) Ingen begränsning på boxens höjd.

public String MinHeight { get; set; }
