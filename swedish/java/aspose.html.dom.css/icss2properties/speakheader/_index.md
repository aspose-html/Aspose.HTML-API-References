## ICSS2Properties.SpeakHeader property

Denna egenskap anger om tabellrubriker läses upp före varje cell, eller endast före en cell när den cellen är associerad med en annan rubrik än föregående cell. Värden har följande betydelser:

once - Rubriken läses upp en gång, före en serie celler. always - Rubriken läses upp före varje relevant cell.

```java
public String SpeakHeader { get; set; }
```
