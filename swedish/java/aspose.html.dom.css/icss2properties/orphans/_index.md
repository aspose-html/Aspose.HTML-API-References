## ICSS2Properties.Orphans property

Egenskapen ['orphans'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-orphans) specificerar det minsta antalet rader i ett stycke som måste lämnas kvar längst ner på en sida. Egenskapen ['widows'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-widows) specificerar det minsta antalet rader i ett stycke som måste lämnas kvar högst upp på en sida. Exempel på hur de används för att kontrollera sidbrytningar ges nedan.

```java
public String Orphans { get; set; }
```
