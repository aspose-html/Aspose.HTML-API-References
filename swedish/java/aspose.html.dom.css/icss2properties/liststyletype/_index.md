## ICSS2Properties.ListStyleType property

Denna egenskap specificerar utseendet på listobjektets markör om ['list-style-image'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-list-style-image) har värdet 'none' eller om bilden som URI:n pekar på inte kan visas. Värdet 'none' innebär ingen markör, annars finns tre typer av markörer: glyfer, numreringssystem och alfabetiska system. Obs. Numrerade listor förbättrar dokumenttillgänglighet genom att göra listor enklare att navigera.

Glyfer specificeras med disc, circle och square. Deras exakta rendering beror på användaragenten.

Numreringssystem specificeras med:

decimal - Decimala tal, med början från 1. decimal-leading-zero - Decimala tal med inledande nollor (t.ex. 01, 02, 03, ..., 98, 99). lower-roman - Gemena romerska siffror (i, ii, iii, iv, v, osv.). upper-roman - Stora romerska siffror (I, II, III, IV, V, osv.). hebrew - Traditionell hebreisk numrering. georgian - Traditionell georgisk numrering (an, ban, gan, ..., he, tan, in, in-an, ...). armenian - Traditionell armenisk numrering. cjk-ideographic - Vanliga ideografiska siffror. hiragana - a, i, u, e, o, ka, ki, ... katakana - A, I, U, E, O, KA, KI, ... hiragana-iroha - i, ro, ha, ni, ho, he, to, ... katakana-iroha - I, RO, HA, NI, HO, HE, TO, ...
