## ICSS2Properties.OutlineColor property

Konturen som skapas med outline‑egenskaperna ritas "over" en ruta, d.v.s. konturen är alltid överst och påverkar inte positionen eller storleken på rutan, eller på någon annan ruta. Därför orsakar varken visning eller undertryckning av konturer någon omflöde.

public String OutlineColor { get; set; }
