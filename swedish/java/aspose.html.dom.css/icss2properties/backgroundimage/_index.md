## ICSS2Properties.BackgroundImage property

Denna egenskap anger bakgrundsbilden för ett element. När en bakgrundsbild anges bör författare också specificera en bakgrundsfärg som används när bilden inte är tillgänglig. När bilden är tillgänglig renderas den ovanpå bakgrundsfärgen. (Därmed är färgen synlig i bildens transparenta delar).

```java
public String BackgroundImage { get; set; }
```

### Returvärde

background-image-egenskap

### Property Value

Värden för denna egenskap är antingen , för att ange bilden, eller 'none' när ingen bild används.
