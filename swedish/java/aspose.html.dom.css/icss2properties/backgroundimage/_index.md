## ICSS2Properties.BackgroundImage property

Denna egenskap anger bakgrundsbilden för ett element. När en bakgrundsbild sätts bör författare också ange en bakgrundsfärg som används när bilden inte är tillgänglig. När bilden är tillgänglig renderas den ovanpå bakgrundsfärgen. (Således är färgen synlig i bildens transparenta delar).

```java
public String BackgroundImage { get; set; }
```

### Returvärde

background-image-egenskap

### Property Value

Värden för denna egenskap är antingen , för att ange bilden, eller 'none' när ingen bild används.
