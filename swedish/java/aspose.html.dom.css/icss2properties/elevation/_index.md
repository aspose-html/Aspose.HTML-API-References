## ICSS2Properties.Elevation property

Värden för denna egenskap har följande betydelser:

'angle' - Anger höjden som en vinkel, mellan '-90deg' och '90deg'. '0deg' betyder på den främre horisonten, vilket löst betyder i nivå med lyssnaren. '90deg' betyder rakt ovanför och '-90deg' betyder rakt under. below - Samma som '-90deg'. level - Samma som '0deg'. above - Samma som '90deg'. higher - Lägger till 10 grader till den aktuella höjden. lower - Subtraherar 10 grader från den aktuella höjden.

```java
public String Elevation { get; set; }
```
