## ICSS2Properties.Elevation property

Värden för denna egenskap har följande betydelser:

'angle' - Anger höjden som en vinkel, mellan '-90deg' och '90deg'. '0deg' betyder på den främre horisonten, vilket löst betyder i nivå med lyssnaren. '90deg' betyder direkt ovanför och '-90deg' betyder direkt nedanför.below - Same as '-90deg'.level - Same as '0deg'.above - Same as '90deg'.higher - Adds 10 degrees to the current elevation.lower - Subtracts 10 degrees from the current elevation.

```java
public String Elevation { get; set; }
```
