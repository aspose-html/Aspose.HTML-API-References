## ICSS2Properties.Stress property

Specificerar höjden på "lokala toppar" i intonationskonturen för en röst. Till exempel är engelska ett betonat språk, och olika delar av en mening tilldelas primär, sekundär eller tertiär stress. Värdet av ['stress'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-stress) styr mängden inflektion som resultat av dessa stressmarkörer. Denna egenskap är en följeslagare till ['pitch-range'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pitch-range) property och tillhandahålls för att låta utvecklare utnyttja avancerade auditiva visningar.

```java
public String Stress { get; set; }
```
