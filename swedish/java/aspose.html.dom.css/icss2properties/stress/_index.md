## ICSS2Properties.Stress property

Anger höjden på "lokala toppar" i intonationskonturen för en röst. Till exempel är engelska ett betonat språk, och olika delar av en mening tilldelas primär, sekundär eller tertiär betoning. Värdet för ['stress'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-stress) styr mängden inflektion som ... Denna egenskap är en följeslagare till ['pitch-range'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pitch-range) egenskapen och tillhandahålls för att låta utvecklare utnyttja avancerade auditiva visningar.

```java
public String Stress { get; set; }
```
