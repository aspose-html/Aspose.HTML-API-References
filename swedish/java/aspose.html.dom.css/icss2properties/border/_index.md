## ICSS2Properties.Border property

'border'-egenskapen är en förkortningsegenskap för att ange samma bredd, färg och stil för alla fyra kanter på en ruta. Till skillnad från förkortnings‑egenskaperna 'margin' och 'padding' kan 'border'-egenskapen inte ange olika värden för de fyra kanterna. För att göra det måste en eller flera av de andra border‑egenskaperna användas.

```java
public String Border { get; set; }
```

border-egenskap
