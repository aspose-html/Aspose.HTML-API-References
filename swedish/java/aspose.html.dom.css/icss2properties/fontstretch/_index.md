## ICSS2Properties.FontStretch property

Egenskapen ['font-stretch'](https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html#propdef-font-stretch) väljer ett normalt, kompakt eller utvidgat teckensnitt från en teckensnittsfamilj. Absoluta nyckelordsvärden har följande ordning, från smalast till bredast:

ultra-condensedextra-condensedcondensedsemi-condensednormalsemi-expandedexpandedextra-expandedultra-expanded

public String FontStretch { get; set; }
