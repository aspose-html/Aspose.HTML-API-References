## ICSS2Properties.BackgroundAttachment property

Om en bakgrundsbild anges specificerar denna egenskap om den är fixerad i förhållande till visningsområdet ('fixed') eller rullar med dokumentet ('scroll').

Även om bilden är fixerad är den bara synlig när den befinner sig i bakgrunds- eller utfyllnadsområdet för elementet. Således, om bilden inte är upprepad ('background-repeat: repeat'), kan den vara osynlig.

```java
public String BackgroundAttachment { get; set; }
```
