## ICSS2Properties.WhiteSpace property

Denna egenskap deklarerar hur [whitespace](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#whitespace) inuti elementet hanteras. Värden har följande betydelser:

normal - Detta värde instruerar användaragenter att kollapsa sekvenser av blanksteg och bryta rader vid behov för att fylla radboxar. Ytterligare radbrytningar kan skapas av förekomster av \"\\A\" i genererat innehåll (t.ex. för BR-elementet i HTML). pre - Detta värde förhindrar att användaragenter kollapsar sekvenser av blanksteg. Rader bryts endast vid nyradstecken i källan, eller vid förekomster av \"\\A\" i genererat innehåll. nowrap - Detta värde kollapsar blanksteg som för 'normal', men undertrycker radbrytningar inom text förutom de som skapas av \"\\A\" i genererat innehåll (t.ex. för BR-elementet i HTML).

public String WhiteSpace { get; set; }
