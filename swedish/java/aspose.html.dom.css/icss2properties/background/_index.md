## ICSS2Properties.Background property

Den 'background'-egenskapen är en förkortningsegenskap för att ange de enskilda bakgrundsegenskaperna (t.ex. 'background-color', 'background-image', 'background-repeat', 'background-attachment' och 'background-position') på samma ställe i stilarket.

```java
public String Background { get; set; }
```

### Returvärde

background-egenskapen

### Property Value

Hämtar eller anger en förkortningsegenskap för att ange de enskilda bakgrundsegenskaperna på samma ställe i stilarket.
