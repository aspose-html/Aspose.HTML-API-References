## ICSS2Properties.TextDecoration property

Denna egenskap beskriver dekorationer som läggs till texten i ett element. Om egenskapen anges för ett [blocknivå](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#block-level)‑element påverkar den alla inline‑nivå‑underordnade till elementet. Om den anges för (eller påverkar) ett [inline‑nivå](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level)‑element påverkar den alla boxar som genereras av elementet. Om elementet saknar innehåll eller textinnehåll (t.ex. IMG‑elementet i HTML) måste användaragenter [ignorera](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#ignore) denna egenskap.

Värdena har följande betydelser:

none – Skapar ingen textdekoration. underline – Varje textrad är understruken. overline – Varje textrad har en linje ovanför. line-through – Varje textrad har en linje genom mitten. blink – Texten blinkar (växlar mellan synlig och osynlig).
