## ICSS2Properties.ListStyleImage property

Denna egenskap anger bilden som kommer att användas som listobjektmarkör. När bilden är tillgänglig kommer den att ersätta marköruppsättningen med ['list-style-type'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-list-style-type) markören.

public String ListStyleImage { get; set; }
