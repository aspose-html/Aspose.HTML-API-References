## ICSS2Properties.Padding property

['padding'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-padding) egenskapen är en förkortning för att ange ['padding-top'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-padding-top), ['padding-right'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-padding-right), ['padding-bottom'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-padding-bottom) och ['padding-left'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-padding-left) på samma ställe i stilmallen.

Om det finns bara ett värde gäller det för alla sidor. Om det finns två värden sätts topp- och bottenmarginalerna till det första värdet och högra och vänstra marginalerna till det andra. Om det finns tre värden sätts toppen till det första värdet, vänster och höger till det andra, och botten till det tredje. Om det finns fyra värden gäller de för topp, höger, botten och vänster, i den ordningen.

```java
public String Padding { get; set; }
```
