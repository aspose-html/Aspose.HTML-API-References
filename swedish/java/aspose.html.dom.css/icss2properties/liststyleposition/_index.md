## ICSS2Properties.ListStylePosition property

Denna egenskap specificerar positionen för markörboxen i den huvudsakliga blockboxen. Värden har följande betydelser:

outside - Markörboxen är utanför den huvudsakliga blockboxen. Obs. CSS1 specificerade inte den exakta placeringen av markörboxen och av kompatibilitetsskäl är CSS2 fortfarande lika tvetydig. För mer exakt kontroll av markörboxar, vänligen använd markers.inside - Markörboxen är den första inline-boxen i den huvudsakliga blockboxen, varefter elementets innehåll flyter.

```java
public String ListStylePosition { get; set; }
```
