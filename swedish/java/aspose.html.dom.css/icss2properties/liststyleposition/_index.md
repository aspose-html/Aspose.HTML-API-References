## ICSS2Properties.ListStylePosition property

Denna egenskap specificerar positionen för markeringsrutan i den primära blockrutan. Värden har följande betydelser:

outside - Markeringsrutan är utanför den primära blockrutan. Obs. CSS1 specificerade inte den exakta placeringen av markeringsrutan och av kompatibilitetsskäl är CSS2 fortfarande lika tvetydig. För mer exakt kontroll av markeringsrutor, vänligen använd markers. inside - Markeringsrutan är den första inline-rutan i den primära blockrutan, varefter elementets innehåll flödar.

```java
public String ListStylePosition { get; set; }
```

list-style-position egenskap
