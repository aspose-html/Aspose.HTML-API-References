## ICSS2Properties.Pause property

['pause'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause)-egenskapen är en förkortning för att ange ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) och ['pause-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-after). Om två värden ges är det första värdet ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) och det andra är ['pause-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-after). Om endast ett värde ges gäller det för båda egenskaperna.

```java
public String Pause { get; set; }
```
