## ICSS2Properties.TextAlign property

Denna egenskap beskriver hur inline‑innehåll i ett block är justerat. Värden har följande betydelser:

vänster, höger, centrerad och justerad - Vänster, höger, centrerad och dubbeljusterad text, respektive.'[String](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-String)' - Anger en Sträng som celler i en tabellkolumn kommer att justeras efter (se avsnittet om [horizontal alignment in a column](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#column-alignment) för detaljer och ett exempel). Detta värde gäller endast för [table](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html)‑celler. Om det sätts på andra element kommer det att behandlas som 'left' eller 'right', beroende på om ['direction'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-direction) är 'ltr' eller 'rtl', respektive.

```java
public String TextAlign { get; set; }
```
