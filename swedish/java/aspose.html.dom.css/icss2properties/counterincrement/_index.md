## ICSS2Properties.CounterIncrement property

Egenskapen ['counter-increment'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-counter-increment) accepterar ett eller flera namn på räknare (identifierare), var och en eventuellt följd av ett heltal. Heltalet anger med hur mycket räknaren ökas för varje förekomst av elementet. Standardökningen är 1. Noll och negativa heltal är tillåtna.

```java
public String CounterIncrement { get; set; }
```
