## ICSS2Properties.Font property

Font-egenskapen är, förutom som beskrivs nedan, en förkortningsegenskap för att ange 'font-style', 'font-variant', 'font-weight', 'font-size', 'line-height' och 'font-family' på samma plats i stilmallen. Syntaxen för denna egenskap är baserad på en traditionell typografisk förkortningsnotation för att ange flera egenskaper relaterade till typsnitt.

```java
public String Font { get; set; }
```
