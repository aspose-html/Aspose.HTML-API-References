## ICSS2Properties.Visibility property

Den ['visibility'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visufx.html#propdef-visibility) egenskapen specificerar om rutorna som genereras av ett element renderas. Osynliga rutor påverkar fortfarande layouten (sätt ['display'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-display) egenskapen till 'none' för att undertrycka ruta-generering helt). Värden har följande betydelser:

visible - Den genererade rutan är synlig. hidden - Den genererade rutan är osynlig (fullt transparent), men påverkar fortfarande layouten. collapse - Konsultera avsnittet om [dynamic row and column effects](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#dynamic-effects) i tabeller. Om den används på element som inte är rader eller kolumner, har 'collapse' samma betydelse som 'hidden'.

```java
public String Visibility { get; set; }
```
