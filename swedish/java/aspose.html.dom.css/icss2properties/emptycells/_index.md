## ICSS2Properties.EmptyCells property

I den separerade kantmodellen styr den här egenskapen rendering av kanter runt celler som saknar synligt innehåll. Tomma celler och celler med egenskapen 'visibility' satt till 'hidden' anses sakna synligt innehåll.
