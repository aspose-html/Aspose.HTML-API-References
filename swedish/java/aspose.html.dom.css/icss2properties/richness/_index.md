## ICSS2Properties.Richness property

Specificerar rikedom, eller klarhet, i talrösten. En rik röst kommer att "bäras" i ett stort rum, en mjuk röst kommer inte. (Termen "mjuk" avser hur vågformen ser ut när den ritas.)

public String Richness { get; set; }
