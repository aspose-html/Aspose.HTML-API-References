## ICSSStyleRule.Style property

Den skrivskyddade stil-egenskapen är [`CSSStyleDeclaration`](../../icssstyledeclaration/) gränssnittet för deklarationsblocket i [`CSSStyleRule`](../).

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

Stilattributet måste returnera ett CSSStyleDeclaration-objekt för stilregeln, med följande egenskaper:

beräknad flagga - Unset.declarations - De deklarerade deklarationerna i regeln, i angiven ordning.parent CSS rule - Kontextobjektet.owner node - Null.
