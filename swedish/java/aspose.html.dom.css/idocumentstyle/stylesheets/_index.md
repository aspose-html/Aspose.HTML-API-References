## IDocumentStyle.StyleSheets property

En lista som innehåller alla stilmallar som uttryckligen länkas in eller bäddas in i ett dokument. För HTML‑dokument inkluderar detta externa stilmallar som inkluderas via HTML‑LINK‑elementet och inbäddade STYLE‑element.

```java
public IStyleSheetList StyleSheets { get; }
```

### Property Value

Listan som innehåller alla stilmallar som uttryckligen länkas in eller bäddas in i ett dokument.
