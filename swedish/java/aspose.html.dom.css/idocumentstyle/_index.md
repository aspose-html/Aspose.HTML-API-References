## IDocumentStyle interface

DocumentStyle‑gränssnittet tillhandahåller en mekanism för att hämta de stilark som är inbäddade i ett dokument. Förväntningen är att en instans av DocumentStyle‑gränssnittet kan erhållas genom att använda bindningsspecifika kastmetoder på en instans av Document‑gränssnittet.

Se även [Document Object Model (DOM) Level 2 Style Specification](http://www.w3.org/TR/2000/REC-DOM-Level-2-Style-20001113).
