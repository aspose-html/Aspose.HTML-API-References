## Rect class

Rect-gränssnittet används för att representera vilket som helst rektangelvärde. Detta gränssnitt speglar värdena i den underliggande stilegenskapen. Därför modifierar ändringar som görs på [`CSSPrimitiveValue`](../cssprimitivevalue/)‑objekten stilegenskapen.

```java
public class Rect : DOMObject
```
