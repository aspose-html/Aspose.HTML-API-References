## ICSSRule.CSSText property

cssText‑egenskapen i [`CSSRule`](../)‑gränssnittet returnerar den faktiska texten för en [`CSSStyleSheet`](../../icssstylesheet/) stilregel.

Obs: Förväxla inte denna egenskap med element‑stil CSSStyleDeclaration.cssText.

```java
public String CSSText { get; set; }
```

### Property Value

Returnerar en serialisering av CSS‑regeln. Vid sättning av cssText‑attributet får inget göras.
