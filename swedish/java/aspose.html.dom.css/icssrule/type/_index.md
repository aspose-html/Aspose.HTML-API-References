## ICSSRule.Type property

Typen av regeln, enligt [CSSOM # dom‑cssrule‑type](https://drafts.csswg.org/cssom/#dom-cssrule-type). Förväntningen är att bindningsspecifika kastmetoder kan användas för att kasta ner från en instans av CSSRule‑gränssnittet till det specifika härledda gränssnitt som typen antyder.

```java
public short Type { get; }
```

### Property Value

Ett icke‑negativt heltal som är kopplat till en viss regeltyp. Detta värde initieras när en regel skapas och kan inte förändras.
