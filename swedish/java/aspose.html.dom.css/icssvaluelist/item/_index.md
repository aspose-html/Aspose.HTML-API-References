## ICSSValueList indexer

Denna metod används för att hämta ett CSSValue efter ordinalt index. Ordningen i denna samling representerar ordningen av värdena i CSS‑stilegenskapen. Om index är större än eller lika med antalet värden i listan returneras null.

Se även [CSSOM](https://www.w3.org/TR/2000/REC-DOM-Level-2-Style-20001113/css.html#CSS-CSSValueList)[#CSSValueList](https://www.w3.org/TR/2000/REC-DOM-Level-2-Style-20001113/css.html#CSS-CSSValueList).

```java
public CSSValue this[int index] { get; }
```

### Returvärde

Det [`CSSValue`](../../cssvalue/) på indexpositionen i [`CSSValueList`](../../cssvaluelist/), eller null om det inte är ett giltigt index.

### Property Value

Indexet i samlingen.

## Anmärkningar

Denna funktion definierades ursprungligen i specifikationen [DOM Style Level 2](https://www.w3.org/TR/DOM-Level-2-Style), men har sedan dess tagits bort från alla standardiseringsinsatser.

Den har ersatts av ett modernt, men inkompatibelt, [CSS Typed Object Model API](https://developer.mozilla.org/en-US/docs/Web/API/CSS_Typed_OM_API) som nu är på den standardiserade vägen.
