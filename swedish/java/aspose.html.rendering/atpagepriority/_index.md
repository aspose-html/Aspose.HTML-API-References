## AtPagePriority enumeration

Anger möjliga ordningsföljder för tillämpning av sidstorleksdeklarationer.

```java
public enum AtPagePriority
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| OptionsPriority | `0` | Anger att [`PageSetup`](../pagesetup/)‑värden som deklarerats i [`RenderingOptions`](../renderingoptions/) kommer att åsidosätta värden som definierats i CSS av `@page`‑regler. |
| CssPriority | `1` | Anger att `@page`‑regler definierade i CSS kommer att åsidosätta värden definierade i [`PageSetup`](../pagesetup/). |
