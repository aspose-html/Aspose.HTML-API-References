## PageSetup.AdjustToWidestPage property

Hämtar eller anger en flagga som bestämmer när sidstorleken ska justeras till den bredaste sidan i dokumentet. Detta alternativ är tidskrävande så dokumentets bearbetningstid kan fördubblas. Justeringen sker endast om den bredaste sidan i dokumentet är bredare än den sidstorlek som bestäms i [`PageSetup`](../). Den justerade sidstorleken kommer att användas för alla sidor i dokumentet.

```java
public bool AdjustToWidestPage { get; set; }
```
