## Device&lt;TGraphicContext,TRenderingOptions&gt;.MoveTo method

Påbörjar en ny delväg genom att flytta den aktuella punkten till koordinaterna för parametern pt, utan att lägga till något anslutande linjesegment. Om den tidigare väggenereringsmetoden i den aktuella vägen också var \"MoveTo\", så ersätter den nya \"MoveTo\" den; ingen spår av den tidigare \"MoveTo\"-operationen finns kvar i vägen.

```java
public void MoveTo(PointF pt)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| pt | PointF | Punkt dit vägen ska flyttas. |
