## Device&lt;TGraphicContext,TRenderingOptions&gt;.ClosePath method

Stänger den aktuella underbanan genom att lägga till ett rakt linjesegment från den aktuella punkten till startpunkten för underbanan. Om den aktuella underbanan redan är stängd gör \"ClosePath\" inget. Denna operator avslutar den aktuella underbanan. Att lägga till ett annat segment till den aktuella banan startar en ny underbana, även om det nya segmentet börjar vid slutpunkten som nås av \"ClosePath\"‑metoden.
