## GraphicContext.MiterLimit property

Ställer in eller hämtar maximal längd på snedställda linjeskarvar för strokade banor. Denna parameter begränsar längden på \"spikar\" som bildas när linjesegment möts i skarpa vinklar.

```java
public float MiterLimit { get; set; }
```
