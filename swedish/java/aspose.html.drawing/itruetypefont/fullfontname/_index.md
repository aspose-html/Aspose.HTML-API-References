## ITrueTypeFont.FullFontName property

Detta bör vara en kombination av "FamilyName" och "SubFamilyName". Undantag: om teckensnittet är "Regular" enligt "SubFamilyName", använd då endast familjenamnet som finns i "FamilyName". Ett undantag från ovanstående definition av fullständigt teckensnittsnamn gäller för Microsoft-plattformens strängar för CFF OpenType-teckensnitt: i detta fall måste den fullständiga teckensnittsnamnsträngen vara identisk med PostScript FontName i CFF Name INDEX.

```java
public String FullFontName { get; }
```

### Returvärde

Fullständigt namn på teckensnitt
