## ITrueTypeFont.SubFamilyName property

Fontens subfamiljenamn särskiljer teckensnittet i en grupp med samma teckensnittsfamiljenamn. Detta antas hantera stil (kursiv, sned) och vikt (lätt, fet, svart, osv.). Ett teckensnitt utan särskilda skillnader i vikt eller stil (t.ex. medium vikt, inte kursiv och fsSelection bit 6 satt) bör ha strängen "Regular" lagrad på denna position.

```java
public String SubFamilyName { get; }
```

### Returvärde

Subfamiljenamn för teckensnitt
