## ITrueTypeFont.SubFamilyName property

Font Subfamily-namnet skiljer teckensnittet i en grupp med samma Font Family-namn. Detta antas hantera stil (italic, oblique) och vikt (light, bold, black, etc.). Ett teckensnitt utan särskilda skillnader i vikt eller stil (t.ex. medium vikt, inte italic och fsSelection bit 6 satt) bör ha strängen \"Regular\" lagrad på denna position.

```java
public String SubFamilyName { get; }
```

### Returvärde

Subfamiljenamn för teckensnitt
