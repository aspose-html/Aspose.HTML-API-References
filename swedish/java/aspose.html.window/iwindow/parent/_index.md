## IWindow.Parent property

Det föräldra-IDL-attributet på Window-objektet för ett Document i en webbläsarkontext b måste returnera WindowProxy-objektet för den överordnade webbläsarkontexten, om det finns ett (d.v.s. om b är en barnwebbläsarkontext), eller WindowProxy-objektet för webbläsarkontexten b själv, annars (d.v.s. om det är en toppnivåwebbläsarkontext eller en fristående nästlad webbläsarkontext).

```java
public IWindow Parent { get; }
```
