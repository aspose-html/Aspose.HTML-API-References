## IWindow.Parent property

Det föräldra-IDL-attributet på Window-objektet i ett Document i en webbläsarkontext b måste returnera WindowProxy-objektet för den föräldrawebbläsarkontexten, om det finns en (d.v.s. om b är en barnwebbläsarkontext), eller WindowProxy-objektet för webbläsarkontexten b själv, annars (d.v.s. om det är en toppnivåwebbläsarkontext eller en fristående inbäddad webbläsarkontext).

```java
public IWindow Parent { get; }
```

### Property Value

Föräldern.
