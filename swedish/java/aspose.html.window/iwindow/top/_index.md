## IWindow.Top property

Det övre IDL-attributet på Window-objektet för ett Dokument i en bläddringskontext b måste returnera WindowProxy-objektet för dess överordnade bläddringskontext (vilket skulle vara dess eget WindowProxy-objekt om det var en överordnad bläddringskontext själv), om det har ett, eller dess eget WindowProxy-objekt annars (t.ex. om det var en fristående inbäddad bläddringskontext).

```java
public IWindow Top { get; }
```
