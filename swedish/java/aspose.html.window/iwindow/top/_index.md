## IWindow.Top property

Det översta IDL-attributet på Window-objektet för ett Document i en bläddringskontext b måste returnera WindowProxy-objektet för dess toppnivåbläddringskontext (vilket skulle vara dess eget WindowProxy-objekt om det var en toppnivåbläddringskontext själv), om det har ett, eller dess eget WindowProxy-objekt annars (t.ex. om det var en fristående inbäddad bläddringskontext).

```java
public IWindow Top { get; }
```
