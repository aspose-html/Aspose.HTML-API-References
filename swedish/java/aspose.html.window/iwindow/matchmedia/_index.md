## IWindow.MatchMedia method

Returnerar ett nytt MediaQueryList-objekt som sedan kan användas för att avgöra om dokumentet matchar media query-strängen, samt för att övervaka dokumentet för att upptäcka när det matchar (eller slutar matcha) den media queryn. Se CSSOM View Module-specifikationen: [https://www.w3.org/TR/cssom-view/#extensions-to-the-window-interface](https://www.w3.org/TR/cssom-view/#extensions-to-the-window-interface)

```java
public MediaQueryList MatchMedia(String query)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| query | String | Strängen som innehåller en media‑fråga; se [https://drafts.csswg.org/mediaqueries/](https://drafts.csswg.org/mediaqueries/) för detaljer. |

### Returvärde

MediaQueryList‑objekt
