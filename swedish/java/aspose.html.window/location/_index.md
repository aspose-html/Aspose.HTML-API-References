## Location class

Location‑objekt ger en representation av adressen till det aktiva dokumentet i deras Documents bläddringskontext, och möjliggör att den aktuella posten i bläddringskontextens sessionshistorik kan ändras genom att lägga till eller ersätta poster i historikobjektet.

```java
public sealed class Location : DOMObject
```
