Paketet **com.aspose.html.window** är relaterat till fönsterobjektet som representerar ett fönster som innehåller ett DOM-dokument. Det inkluderar klasser och gränssnitt relaterade till aktiv dokumentadress och surfhistorik.

## Klasser

| Klass | Beskrivning |
| --- | --- |
| [Location](./location/) | Location‑objekt ger en representation av adressen till det aktiva dokumentet i deras Documents bläddringskontext, och möjliggör att den aktuella posten i bläddringskontextens sessionshistorik kan ändras genom att lägga till eller ersätta poster i historikobjektet. |
| [MediaQueryList](./mediaquerylist/) | Ett MediaQueryList-objekt lagrar information om en mediefråga som tillämpas på ett dokument, med stöd för både omedelbar och händelsedriven matchning mot dokumentets tillstånd. Se CSSOM View Module-specifikationen: [https://www.w3.org/TR/cssom-view/#the-mediaquerylist-interface](https://www.w3.org/TR/cssom-view/#the-mediaquerylist-interface) |
## Gränssnitt

| Gränssnitt | Beskrivning |
| --- | --- |
| [IWindow](./iwindow/) | window-objektet representerar ett fönster som innehåller ett DOM-dokument. |
| [IWindowEventHandlers](./iwindoweventhandlers/) | Representerar ett gränssnitt som måste ärvas av window-objektet. |
| [IWindowTimers](./iwindowtimers/) | Tillåter författare att schemalägga timerbaserade återanrop. |
