Paketet **com.aspose.html.window** är relaterat till fönsterobjektet som representerar ett fönster som innehåller ett DOM-dokument. Det inkluderar klasser och gränssnitt relaterade till aktiv dokumentadress och webbläsarhistorik.

## Klasser

| Klass | Beskrivning |
| --- | --- |
| [Location](./location/) | Platsobjekt ger en representation av adressen till det aktiva dokumentet i deras dokuments webbläsarkontext, och tillåter att den aktuella posten i webbläsarkontextens sessionshistorik ändras genom att lägga till eller ersätta poster i historikobjektet. |
| [MediaQueryList](./mediaquerylist/) | Ett MediaQueryList‑objekt lagrar information om en mediefråga som tillämpas på ett dokument, med stöd för både omedelbar och händelsedriven matchning mot dokumentets tillstånd. Se CSSOM View Module‑specifikationen: [https://www.w3.org/TR/cssom-view/#the-mediaquerylist-interface](https://www.w3.org/TR/cssom-view/#the-mediaquerylist-interface) |
## Gränssnitt

| Gränssnitt | Beskrivning |
| --- | --- |
| [IWindow](./iwindow/) | Fönsterobjektet representerar ett fönster som innehåller ett DOM‑dokument. |
| [IWindowEventHandlers](./iwindoweventhandlers/) | Representerar ett gränssnitt som måste ärvas av fönsterobjektet |
| [IWindowTimers](./iwindowtimers/) | Tillåter författare att schemalägga timerbaserade återanrop. |
