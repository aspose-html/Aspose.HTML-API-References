## SVGSVGElement.GetCurrentTime method

Returnerar den aktuella tiden i sekunder relativt starttiden för det aktuella SVG-dokumentfragmentet. Om getCurrentTime anropas innan dokumentets tidslinje har börjat (t.ex. av skript som körs i ett ‘script’-element innan dokumentets SVGLoad‑händelse har skickats), returneras 0.

```java
public float GetCurrentTime()
```

### Returvärde

Den aktuella tiden i sekunder, eller 0 om dokumentets tidslinje ännu inte har påbörjats.
