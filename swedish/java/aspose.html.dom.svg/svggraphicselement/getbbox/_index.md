## SVGGraphicsElement.GetBBox method

Returnerar den täta omgivningsrutan i det aktuella användarutrymmet (dvs. efter tillämpning av attributet ‘transform’, om någon) på geometrin för alla inneslutna grafikelement, exklusive kontur, beskärning, maskning och filtereffekter). Observera att getBBox måste returnera den faktiska omgivningsrutan vid den tidpunkt metoden anropas, även om elementet ännu inte har renderats.

```java
public SVGRect GetBBox()
```

### Returvärde

Ett SVGRect-objekt som definierar omgivningsrutan.
