## SVGGraphicsElement.GetBBox method

Returnerar den täta omgivande lådan i det aktuella användarutrymmet (dvs. efter tillämpning av attributet ‘transform’, om det finns) på geometrin för alla innehållna grafikelement, exklusive kantlinjer, beskärning, maskning och filtereffekter). Observera att getBBox måste returnera den faktiska omgivande lådan vid den tid metoden anropas, även om elementet ännu inte har renderats.

```java
public SVGRect GetBBox()
```

### Returvärde

Ett SVGRect‑objekt som definierar omgivningsrutan.
