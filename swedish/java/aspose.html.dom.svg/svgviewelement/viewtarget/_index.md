## SVGViewElement.ViewTarget property

Motsvarar attributet ‘viewTarget’ på det angivna ‘view’-elementet. En lista med DOMString-värden som innehåller namnen som anges i ‘viewTarget’-attributet. Varje DOMString-värde kan associeras med motsvarande element med hjälp av getElementById()-metodanropet.

```java
public SVGStringList ViewTarget { get; }
```

### Property Value

Attributet ‘viewTarget’ på det angivna ‘view’-elementet.
