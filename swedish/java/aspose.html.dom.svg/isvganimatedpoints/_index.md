## ISVGAnimatedPoints interface

The SVGAnimatedPoints-gränssnittet stöder element som har ett ‘points’-attribut som innehåller en lista med koordinatvärden och som stödjer möjligheten att animera det attributet. Dessutom kommer ‘points’-attributet på det ursprungliga elementet som nås via XML DOM (t.ex. med getAttribute()-metodanrop) att återspegla eventuella ändringar som gjorts i points.

```java
public interface ISVGAnimatedPoints
```
