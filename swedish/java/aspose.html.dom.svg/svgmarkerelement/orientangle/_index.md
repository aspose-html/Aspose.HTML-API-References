## SVGMarkerElement.OrientAngle property

Motsvarar attributet ‘orient’ på det givna ‘marker’-elementet. Om markerUnits är SVG_MARKER_ORIENT_ANGLE är vinkelvärdet för attributet ‘orient’; annars sätts det till noll.

```java
public SVGAnimatedAngle OrientAngle { get; }
```

### Property Value

Attributet ‘orient’ för det givna ‘marker’-elementet.
