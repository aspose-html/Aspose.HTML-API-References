## SVGPathElement.PathSegList property

Ger åtkomst till de grundläggande (d.v.s. statiska) innehållen i ‘d’-attributet i ett format som matchar en‑till‑en med SVG:s syntax. Således, om ‘d’-attributet har ett "absolut moveto (M)" och ett "absolut arcto (A)"-kommando, kommer pathSegList att ha två poster: ett SVG_PATHSEG_MOVETO_ABS och ett SVG_PATHSEG_ARC_ABS.

```java
public SVGPathSegList PathSegList { get; set; }
```

### Property Value

Sökvägssegmentlistan.
