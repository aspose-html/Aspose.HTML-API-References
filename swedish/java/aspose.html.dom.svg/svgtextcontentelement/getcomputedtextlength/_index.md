## SVGTextContentElement.GetComputedTextLength method

Den totala summan av alla förskjutningsvärden från rendering av alla tecken inom detta element, inklusive förskjutningsvärdet på glyferna (horisontellt eller vertikalt), effekten av egenskaperna ‘kerning’, ‘letter-spacing’ och ‘word-spacing’ samt justeringar på grund av attributen ‘dx’ och ‘dy’ på ‘tspan’-element. För icke-renderande miljöer ska användaragenten göra rimliga antaganden om glyfmetrik.

```java
public float GetComputedTextLength()
```

### Returvärde

Textens förskjutningsavstånd.
