## SVGTextContentElement.GetNumberOfChars method

Returnerar det totala antalet tecken som är tillgängliga för rendering inom det aktuella elementet, vilket inkluderar refererade tecken från ‘tref’-referensen, oavsett om de kommer att renderas. I praktiken är detta motsvarande längden på attributet Node::textContent från DOM Level 3 Core ([DOM3], avsnitt 1.4), om det attributet även expanderade ‘tref’-element.

```java
public long GetNumberOfChars()
```

### Returvärde

Totalt antal tecken.
