## ITreeWalker.NextNode method

Flyttar TreeWalker till nästa synliga nod i dokumentordning relativt den aktuella noden och returnerar den nya noden. Om den aktuella noden saknar nästa nod, eller om sökningen efter nextNode försöker gå uppåt från TreeWalkers rotnod, returneras null och den aktuella noden behålls.

```java
public Node NextNode()
```

### Returvärde

Den nya noden, eller null om den aktuella noden saknar nästa nod i TreeWalkers logiska vy.
