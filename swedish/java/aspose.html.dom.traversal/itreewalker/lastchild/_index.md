## ITreeWalker.LastChild method

Flyttar TreeWalker till det sista synliga barnet till den aktuella noden och returnerar den nya noden. Om den aktuella noden saknar synliga barn returneras null och den aktuella noden behålls.

```java
public Node LastChild()
```

### Returvärde

Den nya noden, eller null om den aktuella noden inte har några barn i TreeWalkers logiska vy.
