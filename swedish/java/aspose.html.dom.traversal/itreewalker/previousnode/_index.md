## ITreeWalker.PreviousNode method

Flyttar TreeWalker till den föregående synliga noden i dokumentordning relativt den aktuella noden och returnerar den nya noden. Om den aktuella noden inte har någon föregående nod, eller om sökningen efter previousNode försöker gå uppåt från TreeWalkerns rotnod, returneras null och den aktuella noden behålls.

```java
public Node PreviousNode()
```

### Returvärde

Den nya noden, eller null om den aktuella noden saknar föregående nod i TreeWalkers logiska vy.
