## ITreeWalker.ParentNode method

Flyttar till och returnerar den närmaste synliga föräldranoden till den aktuella noden. Om sökningen efter parentNode försöker gå uppåt från TreeWalkers rotnod, eller om den misslyckas med att hitta en synlig föräldranod, behåller metoden den aktuella positionen och returnerar null.

```java
public Node ParentNode()
```

### Returvärde

Den nya föräldranoden, eller null om den aktuella noden saknar förälder i TreeWalkers logiska vy.
