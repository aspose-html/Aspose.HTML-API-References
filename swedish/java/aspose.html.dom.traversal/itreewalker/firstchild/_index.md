## ITreeWalker.FirstChild method

Flyttar TreeWalker till det första synliga barnet till den aktuella noden och returnerar den nya noden. Om den aktuella noden saknar synliga barn returneras null och den aktuella noden behålls.

```java
public Node FirstChild()
```

### Returvärde

Den nya noden, eller null om den aktuella noden inte har synliga barn i TreeWalkers logiska vy.
