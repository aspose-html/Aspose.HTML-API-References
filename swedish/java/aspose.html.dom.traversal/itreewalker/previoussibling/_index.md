## ITreeWalker.PreviousSibling method

Flyttar TreeWalker till den föregående syskonnoden till den aktuella noden och returnerar den nya noden. Om den aktuella noden inte har någon synlig föregående syskonnod, returneras null och den aktuella noden behålls.

```java
public Node PreviousSibling()
```

### Returvärde

Den nya noden, eller null om den aktuella noden saknar föregående syskon i TreeWalkers logiska vy.
