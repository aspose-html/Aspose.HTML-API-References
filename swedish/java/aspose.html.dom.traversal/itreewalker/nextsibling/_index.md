## ITreeWalker.NextSibling method

Flyttar TreeWalker till nästa syskon till den aktuella noden och returnerar den nya noden. Om den aktuella noden saknar synligt nästa syskon returneras null och den aktuella noden behålls.

```java
public Node NextSibling()
```

### Returvärde

Den nya noden, eller null om den aktuella noden saknar nästa syskon i TreeWalkers logiska vy.
