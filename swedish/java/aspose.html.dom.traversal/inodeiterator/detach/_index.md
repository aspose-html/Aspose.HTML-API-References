## INodeIterator.Detach method

Kopplar bort NodeIterator från den mängd den itererade över, frigör eventuella beräkningsresurser och placerar iteratorn i det OGILTIGA tillståndet. Efter att detach har anropats kommer anrop till nextNode eller previousNode att kasta undantaget INVALID_STATE_ERR.
