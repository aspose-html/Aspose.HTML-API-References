## ITraversal.WhatToShow property

Detta attribut bestämmer vilka nodtyper som presenteras via iteratorn. Den tillgängliga uppsättningen av konstanter definieras i NodeFilter-gränssnittet. Noder som inte accepteras av whatToShow kommer att hoppas över, men deras barn kan fortfarande beaktas. Observera att detta hopp har företräde framför filtret, om något.
