Aspose.Html-paketet innehåller klasser och metoder för att manipulera [`HTML-dokument`](aspose.html/htmldocument/), oavsett om de är enkla eller komplexa och i realtid. Aspose.HTML for Java låter utvecklare Infoga, Ta bort, Ersätta HTML‑noder, extrahera CSS‑stilinformations, Navigera genom [`HTML-dokument`](aspose.html/htmldocument/) antingen via [`NodeIterator`](aspose.html.dom.traversal/inodeiterator/), [`TreeWalker`](aspose.html.dom.traversal/itreewalker/) som tillhandahålls av Traversal Specifications, XPath‑ eller CSS‑selektorfrågor. Det erbjuder också skriptning som möjliggör manipulation av HTML‑DOM via JavaScript. Förutom HTML ger detta API även möjlighet att läsa in EPUB och MHTML. Aspose API:er är kända för sina funktioner för konvertering mellan filformat och detta API ger också möjlighet att läsa in HTML‑filer och rendera resultatet i PDF, XPS och rasterbildformat inklusive JPEG, PNG, BMP och TIFF.
