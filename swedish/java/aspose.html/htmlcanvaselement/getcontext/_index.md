## HTMLCanvasElement.GetContext method

Returnerar ett ritkontext på canvas, eller null om kontext-ID inte stöds. En ritkontext låter dig rita på canvas.

```java
public object GetContext(String contextId)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| contextId | String | Är en sträng som innehåller kontextidentifieraren som definierar ritkontexten som är associerad med canvasen. |

### Returvärde

Ett RenderingContext
