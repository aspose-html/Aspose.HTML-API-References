## HTMLCanvasElement.Width property

Är ett positivt heltal som speglar width‑attributet i HTML för canvas‑elementet, tolkad i CSS‑pixlar. När attributet inte anges, eller om det sätts till ett ogiltigt värde, t.ex. ett negativt, används standardvärdet 300.

```java
public ulong Width { get; set; }
```
