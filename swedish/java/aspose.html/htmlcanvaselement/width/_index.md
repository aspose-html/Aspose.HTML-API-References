## HTMLCanvasElement.Width property

Är ett positivt heltal som speglar bredd‑HTML‑attributet för canvas‑elementet, tolkad i CSS‑pixlar. När attributet inte är specificerat, eller om det sätts till ett ogiltigt värde, t.ex. ett negativt, används standardvärdet 300.

```java
public ulong Width { get; set; }
```
