## ToDataURL() {#todataurl}

returnerar en data-URI som innehåller en representation av bilden i det format som anges av typparametern (standard är PNG). Den returnerade bilden har en upplösning på 96 dpi.

```java
public String ToDataURL()
```

### Returvärde

En DOMString som innehåller den begärda data-URI:n.
