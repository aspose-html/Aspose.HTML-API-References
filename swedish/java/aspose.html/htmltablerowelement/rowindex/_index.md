## HTMLTableRowElement.RowIndex property

Detta är i logisk ordning och inte i dokumentordning. `rowIndex` tar hänsyn till sektionerna (`THEAD`, `TFOOT` eller `TBODY`) inom tabellen och placerar `THEAD`-rader först i indexet, följt av `TBODY`-rader och sedan `TFOOT`-rader. @version DOM Level 2

public int RowIndex { get; }
