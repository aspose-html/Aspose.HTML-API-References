## HTMLInputElement.Files property

files IDL‑attributet tillåter skript att komma åt elementets valda filer. Vid hämtning, om IDL‑attributet gäller, måste det returnera ett FileList‑objekt som representerar de för närvarande valda filerna. Samma objekt måste returneras tills listan över valda filer ändras. Om IDL‑attributet inte gäller måste det i stället returnera null. [FILEAPI]

```java
public IFileList Files { get; }
```
