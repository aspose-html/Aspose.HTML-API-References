## HTMLInputElement.DefaultChecked property

När `type` har värdet "radio" eller "checkbox" representerar detta HTML‑checked‑attributet för elementet. Värdet på detta attribut ändras inte om tillståndet för motsvarande formulärkontroll, i en interaktiv användaragent, förändras. Se definitionen av checked‑attributet i HTML 4.01.

```java
public bool DefaultChecked { get; set; }
```
