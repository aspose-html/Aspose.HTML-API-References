## HTMLInputElement.DefaultValue property

När `type`-attributet för elementet har värdet "text", "file" eller "password" representerar detta HTML‑value‑attributet för elementet. Värdet för detta attribut ändras inte om innehållet i motsvarande formulärkontroll, i en interaktiv användaragent, ändras. Se definitionen av value-attributet i HTML 4.01.

```java
public String DefaultValue { get; set; }
```
