## HTMLInputElement.Value property

När `type`-attributet för elementet har värdet "text", "file" eller "password" representerar detta det aktuella innehållet i motsvarande formulärkontroll i en interaktiv användaragent. Att ändra detta attribut ändrar innehållet i formulärkontrollen, men ändrar inte värdet på HTML‑value‑attributet för elementet. När `type`-attributet för elementet har värdet "button", "hidden", "submit", "reset", "image", "checkbox" eller "radio" representerar detta HTML‑value‑attributet för elementet. Se definitionen av value‑attributet i HTML 4.01.

```java
public String Value { get; set; }
```
