## HTMLDocument.Images property

En samling av alla `IMG`-element i ett dokument. Beteendet är begränsat till `IMG`-element för bakåtkompatibilitet. Enligt [[HTML 4.01](http://www.w3.org/TR/1999/REC-html401-19991224)] kan för att inkludera bilder författare använda `OBJECT`-elementet eller `IMG`-elementet. Därför rekommenderas det att inte använda detta attribut för att hitta bilder i dokumentet utan `getElementsByTagName` med HTML 4.01 eller `getElementsByTagNameNS` med XHTML 1.0.

```java
public HTMLCollection Images { get; }
```
