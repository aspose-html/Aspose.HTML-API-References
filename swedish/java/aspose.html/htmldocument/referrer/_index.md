## HTMLDocument.Referrer property

Returnerar URI [[IETF RFC 2396](http://www.ietf.org/rfc/rfc2396.txt)] för sidan som länkat till denna sida. Värdet är en tom sträng om användaren navigerade till sidan direkt (inte via en länk, men till exempel via ett bokmärke).

```java
public String Referrer { get; }
```
