## Configuration.Security property

Hämtar eller anger sandlådeflaggan för konfigurationen. Se artikel om [sandboxing](https://docs.aspose.com/html/net/working-with-documents/environment-configuration/#sandboxing).

```java
public Sandbox Security { get; set; }
```

### Property Value

Säkerheten. En [`sandboxing flag`](../../sandbox/) uppsättning är en samling av noll eller fler av flaggorna, som används för att begränsa de funktioner som potentiellt opålitliga resurser har. Sandbox‑attributet låter dig ange ett antal restriktioner på innehållet som laddas i ramen, till exempel blockera formulär och skript.
