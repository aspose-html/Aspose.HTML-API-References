## IHTMLOptionsCollection interface

En `HTMLOptionsCollection` är en lista med noder som representerar HTML‑option‑element. En enskild nod kan nås antingen via ett ordinalt index eller nodens `name`‑ eller `id`‑attribut. Samlingar i HTML‑DOM antas vara levande, vilket betyder att de automatiskt uppdateras när det underliggande dokumentet ändras.

Se även [Document object Model (DOM) Level 2 HTML Specification](http://www.w3.org/TR/2003/REC-DOM-Level-2-HTML-20030109). @since DOM Level 2

```java
public interface IHTMLOptionsCollection : IEnumerable<Element>
```
