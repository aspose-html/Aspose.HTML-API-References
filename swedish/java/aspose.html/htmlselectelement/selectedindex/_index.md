## HTMLSelectElement.SelectedIndex property

Det ordningsmässiga indexet för det valda alternativet, räknat från 0. Värdet -1 returneras om inget element är valt. Om flera alternativ är valda returneras indexet för det första valda alternativet.

```java
public int SelectedIndex { get; set; }
```
