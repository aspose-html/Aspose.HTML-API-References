## HTMLFormElement.Enctype property

Innehållstypen för det inskickade formuläret är vanligtvis "application/x-www-form-urlencoded". Se definitionen av attributet enctype i HTML 4.01. Händelsehanteraren onsubmit garanteras inte att utlösas när denna metod anropas. Beteendet är inkonsekvent av historiska skäl och författare bör inte förlita sig på ett specifikt.

```java
public String Enctype { get; set; }
```
