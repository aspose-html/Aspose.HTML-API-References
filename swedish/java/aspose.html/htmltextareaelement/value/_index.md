## HTMLTextAreaElement.Value property

Representerar det aktuella innehållet i motsvarande formulärkontroll i en interaktiv användaragenter. Att ändra detta attribut ändrar innehållet i formulärkontrollen, men ändrar inte elementets innehåll. Om hela datamängden inte får plats i en enda `DOMString`, kan implementationen trunkera data.

```java
public String Value { get; set; }
```
