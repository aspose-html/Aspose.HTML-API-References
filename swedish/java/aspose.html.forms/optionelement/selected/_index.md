## OptionElement.Selected property

Representerar det aktuella tillståndet för den motsvarande formulärkontrollen i en interaktiv användaragent. Att ändra detta attribut ändrar kontrollens tillstånd, men ändrar inte värdet på HTML selected-attributet för elementet.

```java
public bool Selected { get; set; }
```
