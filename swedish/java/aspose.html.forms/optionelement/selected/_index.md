## OptionElement.Selected property

Representerar det aktuella tillståndet för motsvarande formulärkontroll i en interaktiv användaragent. Att ändra detta attribut ändrar kontrollens tillstånd, men ändrar inte värdet för HTML selected attribute på elementet.

```java
public bool Selected { get; set; }
```
