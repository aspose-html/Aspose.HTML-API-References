## FormEditor.CreateNew method

[`HTMLFormElement`](../../../com.aspose.html/htmlformelement/) skapas i ett frånkopplat tillstånd från dokumentet; för att fästa det i dokumentet, välj en lämplig plats och använd [`AppendChild`](../../../com.aspose.html.dom/node/appendchild/)‑metoden.

public static FormEditor CreateNew(HTMLDocument document)
