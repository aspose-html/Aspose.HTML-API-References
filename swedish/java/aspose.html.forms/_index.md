Paketet ger åtkomst till många objekt (element) som ansvarar för användarinteraktivitet inom formulär som webbkomponent.

## Klasser

| Klass | Beskrivning |
| --- | --- |
| [ButtonElement](./buttonelement/) | ButtonElement representerar en omslag som är associerad med HTMLButtonElement. |
| [DataListElement](./datalistelement/) | DataListElement representerar en omslag som är associerad med HTMLDataListElement. |
| [FormEditor](./formeditor/) | Denna klass representerar redigeraren över [`HTMLFormElement`](../com.aspose.html/htmlformelement/) som skapar ett enklare sätt för .net‑utvecklare att redigera HTML‑formulär. |
| [FormElement](./formelement/) | Representerar basklass för formelement. |
| [FormElement&lt;T&gt;](./formelement-1/) | [`FormElement`](../com.aspose.html.forms/formelement/) representerar det generiska fältet |
| [FormSubmitter](./formsubmitter/) | Denna klass möjliggör att förbereda specificerat [`HTMLFormElement`](../com.aspose.html/htmlformelement/), samla värden från formelementet, skicka dem till fjärrservern och ta emot ett svar. |
| [InputElement](./inputelement/) | InputElement representerar en omslag som är associerad med HTMLInputElement. |
| [OptionCollection](./optioncollection/) | OptionElements representerar en omslag som är associerad med IHTMLOptionsCollection. |
| [OptionElement](./optionelement/) | OptionElement representerar en omslag som är associerad med HTMLOptionElement. |
| [SelectElement](./selectelement/) | SelectElement representerar en omslag som är associerad med HTMLSelectElement. |
| [SubmissionResult](./submissionresult/) | Denna klass representerar resultatet av att skicka formulärdata till servern. |
| [TextAreaElement](./textareaelement/) | TextAreaElement representerar en omslag som är associerad med HTMLTextAreaElement. |
