## TemplateLoadOptions.NamesAreCaseSensitive property

Egenskap som specificerar huruvida mall- och dataelementnamn ska matchas oavsett teckenkänslighet eller inte. Om true är matchning skiftlägeskänslig; om false ignoreras teckenkänsligheten. Standardvärdet är true.

```java
public bool NamesAreCaseSensitive { get; set; }
```
