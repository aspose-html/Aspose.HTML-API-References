## Toggle(String, bool) {#toggle_1}

Tar bort token från listan om den finns, eller lägger till token i listan om den inte finns.

```java
public bool Toggle(String token, bool force)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| token | String | Token som du vill växla. |
| force | Boolean | Ett booleskt värde som, om det inkluderas, gör växlingen till en endragsoperation. Om det är falskt tas token bara bort, men läggs inte till. Om det är sant läggs token bara till, men tas inte bort. |

### Returvärde

Ett booleskt värde som indikerar om token finns i listan efter anropet.
