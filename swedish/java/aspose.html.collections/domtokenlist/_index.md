## DOMTokenList class

Klassen DOMTokenList representerar en uppsättning mellanslagsseparerade token. Den indexeras med början från 0 precis som JavaScript‑Array‑objekt. DOMTokenList är alltid skiftlägeskänslig.

```java
public class DOMTokenList : DOMObject, IEnumerable<String>
```
