## IsPointInPath(double, double) {#ispointinpath_2}

Rapporterar om den angivna punkten är innehållen i den aktuella vägen eller inte.

```java
public bool IsPointInPath(double x, double y)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| x | Double | X‑koordinaten för den punkt som ska kontrolleras. |
| y | Double | Y-koordinaten för den punkt som ska kontrolleras. |

### Returvärde

Returnerar true om punkten är inom området som definieras av fyllningen av en bana, annars false.
