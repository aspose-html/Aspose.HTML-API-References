## CreateImageData(double, double) {#createimagedata_1}

Skapar ett nytt, tomt ImageData‑objekt med de angivna dimensionerna. Alla pixlar i det nya objektet är transparent svarta.

```java
public IImageData CreateImageData(double sw, double sh)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| sw | Double | Bredden som ska ges till det nya ImageData‑objektet. |
| sh | Double | Höjden som ska ges till det nya ImageData‑objektet. |

### Returvärde

Ett nytt ImageData-objekt med den angivna bredden och höjden. Det nya objektet är fyllt med transparenta svarta pixlar.
