## ICanvasRenderingContext2D.CreateRadialGradient method

Skapar ett radiellt gradient givet av koordinaterna för de två cirklarna som representeras av parametrarna.

```java
public ICanvasGradient CreateRadialGradient(double x0, double y0, double r0, double x1, double y1, 
    double r1)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| x0 | Double | x-axeln för koordinaten för startcirkeln. |
| y0 | Double | y-axeln för koordinaten för startcirkeln |
| r0 | Double | Radien för startcirkeln. |
| x1 | Double | x-axeln för koordinaten för slutcirkeln. |
| y1 | Double | y-axeln för koordinaten för slutcirkeln |
| r1 | Double | Radien för slutcirkeln. |

### Returvärde

En radiell CanvasGradient initierad med de två angivna cirklarna.
