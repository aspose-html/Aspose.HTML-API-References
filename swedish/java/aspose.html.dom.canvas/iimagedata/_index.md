## IImageData interface

Skapar ett ImageData‑objekt från en given Uint8ClampedArray och bildens storlek som den innehåller. Om ingen array anges skapas en bild av en svart rektangel.

```java
public interface IImageData
```

| --- | --- |
| [getData](../../com.aspose.html.dom.canvas/iimagedata/data/) är en Uint8ClampedArray som representerar en endimensionell array som innehåller data i RGBA-ordning, med heltalsvärden mellan 0 och 255 (inkluderat). |
| [getHeight](../../com.aspose.html.dom.canvas/iimagedata/height/) är en unsigned long som representerar den faktiska höjden, i pixlar, för ImageData. |
