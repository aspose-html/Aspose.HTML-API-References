## Arc(double, double, double, double, double) {#arc}

Lägger till en båge i banan som är centrerad vid positionen (x, y) med radien r, startar vid startAngle och slutar vid endAngle och går i den angivna riktningen moturs (standard är medurs).

```java
public void Arc(double x, double y, double radius, double startAngle, double endAngle)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| x | Double | x‑koordinaten för bågens centrum. |
| y | Double | y‑koordinaten för bågens centrum. |
| radie | Double | Bågens radie. |
| startAngle | Double | Vinkeln där bågen startar, mätt medurs från den positiva x‑axeln och uttryckt i radianer. |
| endAngle | Double | Vinkeln där bågen slutar, mätt medurs från den positiva x‑axeln och uttryckt i radianer. |
