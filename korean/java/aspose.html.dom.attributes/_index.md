**com.aspose.html.dom.attributes** 패키지는 객체(노드, 요소 등)의 특징이나 동작을 지정하거나 정의하는 통합 속성 클래스를 포함합니다.

## 클래스

| 클래스 | 설명 |
| --- | --- |
| [DOMConstructorAttribute](./domconstructorattribute/) | W3C에서 정의한 생성자를 지정합니다. |
| [DOMNameAttribute](./domnameattribute/) | W3C에서 정의한 공식 DOM 객체 이름을 지정합니다. |
| [DOMNamedPropertyGetterAttribute](./domnamedpropertygetterattribute/) | 해당 메서드가 명명된 속성 getter로 사용됨을 지정합니다. |
| [DOMNoInterfaceObjectAttribute](./domnointerfaceobjectattribute/) | [NoInterfaceObject] 확장 속성이 인터페이스에 나타나면, ECMAScript 바인딩에서 해당 인터페이스에 대한 인터페이스 객체가 존재하지 않음을 나타냅니다. |
| [DOMNullableAttribute](./domnullableattribute/) | DOM 객체에 null 값을 할당할 수 있음을 지정합니다. |
| [DOMObjectAttribute](./domobjectattribute/) | 이 속성으로 표시된 객체가 W3C에 의해 정의되었음을 지정합니다. |
| [DOMTreatNullAsAttribute](./domtreatnullasattribute/) | 멤버 값이 null인 경우 지정된 값으로 처리됨을 나타냅니다. |
