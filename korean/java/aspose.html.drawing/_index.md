**com.aspose.html.drawing** 패키지는 측정 및 단위를 지정하는 객체와 인터페이스뿐만 아니라 브러시, 색상 및 글꼴과 같은 그리기 속성 객체를 포함합니다.

## 클래스

| 클래스 | 설명 |
| --- | --- |
| [Angle](./angle/) | 각도 데이터 형식 |
| [Color](./color/) | Color 클래스는 빨강-초록-파랑 (RGB) 값, 색조-채도-명도 (HSL) 값, 색조-채도-값 (HSV) 값, 색조-백색도-흑색도 (HWB) 값, 밝기-A-B (LAB) 값, 휘도-채도-색조 (LCH) 값, 시안-마젠타-노랑-키 (CMYK) 값, 자연 색상 (NCOL) 값 또는 색상 이름으로 색상을 지정할 수 있게 해줍니다. 투명도를 나타내는 알파 채널도 사용할 수 있습니다. |
| [Dimension](./dimension/) | 차원에 대한 기본 클래스를 제공합니다. 일반적인 용어 'dimension'은 단위가 붙은 숫자를 의미하며, [`UnitType`](../com.aspose.html.drawing/unittype/) 로 표시됩니다. |
| [Frequency](./frequency/) | 'frequency' 단위. |
| [Length](./length/) | 길이 측정 단위를 나타냅니다. |
| [LengthOrAuto](./lengthorauto/) | 길이 저장 또는 'auto' 단위를 위한 컨테이너를 나타냅니다. |
| [Margin](./margin/) | 페이지 여백을 나타냅니다. |
| [Numeric](./numeric/) | 숫자형에 대한 기본 클래스를 제공합니다. |
| [Page](./page/) | 페이지 객체를 나타내며, 출력 페이지 구성을 위해 사용됩니다. 페이지 크기의 기본값은 A4(210x297mm)입니다. |
| [Resolution](./resolution/) | 해상도 단위를 나타냅니다. |
| [Size](./size/) | 높이와 너비를 지정하는 값을 저장합니다. |
| [Time](./time/) | 시간 단위를 나타냅니다. |
| [Unit](./unit/) | 측정 단위에 대한 기본 클래스를 제공합니다. |
| [UnitType](./unittype/) | 측정 단위를 지정합니다. |
