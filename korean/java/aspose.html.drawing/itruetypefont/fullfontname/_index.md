## ITrueTypeFont.FullFontName property

이는 "FamilyName"과 "SubFamilyName"의 조합이어야 합니다. "SubFamilyName"에 "Regular" 로 표시된 경우에는 "FamilyName"에 포함된 패밀리 이름만 사용합니다. 위의 Full font name 정의에 대한 예외는 Microsoft 플랫폼용 CFF OpenType 폰트의 문자열에 적용되며, 이 경우 Full font name 문자열은 CFF Name INDEX에 있는 PostScript FontName과 동일해야 합니다.

```java
public String FullFontName { get; }
```
