## ITrueTypeFont.SubFamilyName property

Font Subfamily 이름은 동일한 Font Family 이름을 가진 그룹 내에서 폰트를 구분합니다. 이는 스타일 (italic, oblique) 및 무게 (light, bold, black 등)를 다루기 위한 것으로 가정됩니다. 무게나 스타일에 특별한 차이가 없는 폰트(예: 중간 무게, 이탤릭이 아니며 fsSelection 비트 6이 설정된 경우)에는 이 위치에 문자열 "Regular"가 저장되어야 합니다.

```java
public String SubFamilyName { get; }
```

### 반환 값

폰트 서브패밀리 이름
