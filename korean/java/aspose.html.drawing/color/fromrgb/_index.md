## FromRgb(byte, byte, byte) {#fromrgb}

요청된 ged, 녹색, 파란색 값을 사용하여 새로운 Color를 반환합니다. 모든 색 구성 요소는 0-255 범위여야 합니다.

```java
public static Color FromRgb(byte red, byte green, byte blue)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| red | Byte | 색상의 빨강 구성 요소를 나타내는 바이트. |
| green | Byte | 색상의 초록 구성 요소를 나타내는 바이트. |
| blue | Byte | 색상의 파랑 구성 요소를 나타내는 바이트. |
