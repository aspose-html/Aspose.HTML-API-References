패키지는 웹 페이지 구성 요소인 폼 내에서 사용자 상호 작용을 담당하는 수많은 객체(요소)에 대한 접근을 제공합니다.

## 클래스

| 클래스 | 설명 |
| --- | --- |
| [ButtonElement](./buttonelement/) | ButtonElement는 HTMLButtonElement와 연결된 래퍼를 나타냅니다. |
| [DataListElement](./datalistelement/) | DataListElement는 HTMLDataListElement와 연결된 래퍼를 나타냅니다. |
| [FormEditor](./formeditor/) | 이 클래스는 .net 개발자가 HTML 폼을 더 쉽게 편집할 수 있도록 하는 [`HTMLFormElement`](../com.aspose.html/htmlformelement/) 위의 편집기를 나타냅니다. |
| [FormElement](./formelement/) | 폼 요소의 기본 클래스를 나타냅니다. |
| [FormElement&lt;T&gt;](./formelement-1/) | 이 [`FormElement`](../com.aspose.html.forms/formelement/)은 일반 필드를 나타냅니다. |
| [FormSubmitter](./formsubmitter/) | 이 클래스는 지정된 [`HTMLFormElement`](../com.aspose.html/htmlformelement/)을 준비하고, 폼 요소에서 값을 수집하여 원격 서버에 제출하고 응답을 받도록 허용합니다. |
| [InputElement](./inputelement/) | InputElement는 HTMLInputElement와 연결된 래퍼를 나타냅니다. |
| [OptionCollection](./optioncollection/) | OptionElements는 IHTMLOptionsCollection과 연결된 래퍼를 나타냅니다. |
| [OptionElement](./optionelement/) | OptionElement는 HTMLOptionElement와 연결된 래퍼를 나타냅니다. |
| [SelectElement](./selectelement/) | SelectElement는 HTMLSelectElement와 연결된 래퍼를 나타냅니다. |
| [SubmissionResult](./submissionresult/) | 이 클래스는 서버에 폼 데이터를 제출한 결과를 나타냅니다. |
| [TextAreaElement](./textareaelement/) | TextAreaElement는 HTMLTextAreaElement와 연결된 래퍼를 나타냅니다. |
