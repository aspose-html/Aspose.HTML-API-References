## NodeFilter.SHOW_ATTRIBUTE field

Attr 노드를 표시합니다. 이는 속성 노드를 루트로 하는 iterator 또는 tree-walker를 만들 때만 의미가 있습니다; 이 경우 속성 노드가 반복 또는 순회의 첫 번째 위치에 나타납니다. 속성은 다른 노드의 자식이 아니므로 문서 트리를 순회할 때 나타나지 않습니다.

```java
public const long SHOW_ATTRIBUTE;
```
