## NodeFilter.SHOW_ENTITY field

Entity 노드를 표시합니다. 이는 Entity 노드를 루트로 하는 iterator 또는 tree-walker를 만들 때만 의미가 있습니다; 이 경우 Entity 노드가 순회의 첫 번째 위치에 나타납니다. 엔터티는 문서 트리의 일부가 아니므로 문서 트리를 순회할 때 나타나지 않습니다.

```java
public const long SHOW_ENTITY;
```
