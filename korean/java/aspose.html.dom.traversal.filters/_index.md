노드 필터링 기능을 제공하는 패키지입니다. 필터는 노드를 "filter out"하는 방법을 아는 객체입니다. 노드 이터레이터나 트리 워커에 노드 필터가 제공되면, 다음 노드를 반환하기 전에 필터를 적용합니다. 필터가 노드를 허용한다고 하면, 탐색 로직이 해당 노드를 반환합니다; 그렇지 않으면 탐색은 다음 노드를 찾아 거부된 노드가 없었던 것처럼 처리합니다.
