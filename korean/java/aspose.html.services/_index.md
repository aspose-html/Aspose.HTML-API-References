**com.aspose.html.services** 패키지는 서비스 구현을 위한 프로토콜 역할을 하는 인터페이스를 포함합니다.

## 인터페이스

| 인터페이스 | 설명 |
| --- | --- |
| [IDeviceInformationService](./ideviceinformationservice/) | 사용자에게 [`Document`](../com.aspose.html.dom/document/)가 제공되는 환경을 설명하는 인터페이스입니다. |
| [INetworkService](./inetworkservice/) | 네트워크 작업을 위한 인터페이스를 제공합니다. |
| [IRuntimeService](./iruntimeservice/) | 이 서비스는 런타임 관련 속성을 구성하는 데 사용됩니다. |
| [IUserAgentService](./iuseragentservice/) | 사용자 에이전트 환경을 설명하는 인터페이스입니다. |
