## IRuntimeService.JavaScriptTimeout property

JavaScript 실행 시간을 제한하는 TimeSpan을 가져오거나 설정합니다. 스크립트가 제공된 TimeSpan보다 오래 실행되면 취소됩니다. TimeSpan을 -1밀리초로 설정하면 무한 타임아웃을 지정할 수 있습니다. 기본값은 1분입니다.

```java
public TimeSpan JavaScriptTimeout { get; set; }
```
