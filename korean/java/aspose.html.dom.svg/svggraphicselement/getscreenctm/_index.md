## SVGGraphicsElement.GetScreenCTM method

현재 사용자 단위(‘transform’ 속성이 적용된 경우)에서 부모 사용자 에이전트가 인식하는 "픽셀"까지의 변환 행렬을 반환합니다. 디스플레이 장치의 경우 이는 물리적인 화면 픽셀을 나타냅니다. 물리적 픽셀 크기를 알 수 없는 다른 장치나 환경에서는 CSS2 정의의 "픽셀"과 유사한 알고리즘을 사용할 수 있습니다. 이 요소가 문서 트리에 연결되어 있지 않으면 null이 반환됩니다. 이 메서드는 getClientCTM이라는 이름이 더 적절했겠지만, 역사적 이유로 getScreenCTM이라는 이름을 유지합니다.

```java
public SVGMatrix GetScreenCTM()
```

### 반환 값

주어진 변환 행렬을 정의하는 SVGMatrix 객체.
