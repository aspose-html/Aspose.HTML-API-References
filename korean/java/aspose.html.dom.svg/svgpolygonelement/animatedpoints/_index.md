## SVGPolygonElement.AnimatedPoints property

‘points’ 속성의 현재 애니메이션된 내용을 액세스할 수 있습니다. 지정된 속성이나 속성이 애니메이션 중인 경우 해당 속성이나 속성의 현재 애니메이션 값을 포함합니다. 지정된 속성이나 속성이 현재 애니메이션되지 않은 경우 points와 동일한 값을 포함합니다.

```java
public SVGPointList AnimatedPoints { get; }
```

### Property Value

애니메이션된 points.
