## SVGDocument(RequestMessage, Configuration) {#constructor_3}

[`SVGDocument`](../) 클래스의 새 인스턴스를 초기화합니다. 생성자는 동기적으로 작동하며, 모든 외부 리소스(이미지, 스크립트 등)의 로딩이 완료될 때까지 기다립니다. 문서를 비동기적으로 로드하려면 [`Navigate`](../../../com.aspose.html.dom/document/navigate/) 메서드 또는 해당 오버로드를 사용하세요. 또는 [`Security`](../../../com.aspose.html.dom/ibrowsingcontext/security/)에서 적절한 플래그를 설정하여 일부 외부 리소스 로드를 비활성화할 수 있습니다.
