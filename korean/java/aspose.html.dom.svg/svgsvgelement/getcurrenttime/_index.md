## SVGSVGElement.GetCurrentTime method

현재 SVG 문서 조각의 시작 시간에 대한 상대적인 현재 시간을 초 단위로 반환합니다. 문서 타임라인이 시작되기 전에 getCurrentTime이 호출되면(예: ‘script’ 요소에서 실행되는 스크립트가 문서의 SVGLoad 이벤트가 발생하기 전에 호출되는 경우) 0을 반환합니다.

```java
public float GetCurrentTime()
```

### 반환 값

초 단위 현재 시간, 또는 문서 타임라인이 아직 시작되지 않은 경우 0.
