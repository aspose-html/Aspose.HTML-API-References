## SVGSVGElement.SetCurrentTime method

이 SVG 문서 조각의 시계를 조정하여 새로운 현재 시간을 설정합니다. setCurrentTime이 문서 타임라인이 시작되기 전에 호출되면(예: 문서의 SVGLoad 이벤트가 발생하기 전에 ‘script’ 요소에서 실행되는 스크립트에 의해), 메서드의 마지막 호출에서 초 값은 문서 타임라인이 시작된 후 문서가 이동할 시간을 나타냅니다.

```java
public void SetCurrentTime(float seconds)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| 초 | Single | 현재 SVG 문서 조각의 시작 시간에 대한 초 단위 새로운 현재 시간. |
