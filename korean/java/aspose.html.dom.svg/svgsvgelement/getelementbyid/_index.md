## SVGSVGElement.GetElementById method

이 SVG 문서 조각(즉, 검색이 문서 트리의 일부에 제한됨)에서 elementId로 지정된 id를 가진 Element를 검색합니다. Element가 발견되면 해당 Element를 반환합니다. 존재하지 않으면 null을 반환합니다. 동일한 id를 가진 요소가 둘 이상인 경우 동작은 정의되지 않습니다.

```java
public Element GetElementById(String elementId)
```

| Parameter | Type | 설명 |
| --- | --- | --- |
| elementId | String | 요소에 대한 고유 ID 값입니다. |

### 반환 값

일치하는 요소입니다.
