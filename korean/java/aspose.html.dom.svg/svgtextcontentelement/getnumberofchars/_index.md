## SVGTextContentElement.GetNumberOfChars method

현재 요소 내에서 렌더링 가능한 전체 문자 수를 반환합니다. 여기에는 렌더링 여부와 관계없이 ‘tref’ 참조에서 가져온 문자도 포함됩니다. 실제로 이는 DOM Level 3 Core([DOM3], 섹션 1.4)의 Node::textContent 속성 길이와 동일하며, 해당 속성이 ‘tref’ 요소까지 확장된 경우에도 적용됩니다.

```java
public long GetNumberOfChars()
```

### 반환 값

전체 문자 수.
