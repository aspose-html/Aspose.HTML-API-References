## SVGTextContentElement.GetComputedTextLength method

이 요소 내의 모든 문자들을 렌더링하면서 발생하는 전진값들의 총합으로, 글리프(수평 또는 수직)의 전진값, ‘kerning’, ‘letter-spacing’, ‘word-spacing’ 속성의 효과, 그리고 ‘tspan’ 요소의 ‘dx’ 및 ‘dy’ 속성에 의한 조정이 포함됩니다. 렌더링되지 않는 환경에서는 사용자 에이전트가 글리프 메트릭에 대해 합리적인 가정을 해야 합니다.

```java
public float GetComputedTextLength()
```

### 반환 값

텍스트 전진 거리.
