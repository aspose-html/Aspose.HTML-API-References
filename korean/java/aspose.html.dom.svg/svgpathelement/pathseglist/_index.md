## SVGPathElement.PathSegList property

‘d’ 속성의 기본(즉, 정적) 내용을 SVG의 구문과 일대일로 일치하는 형태로 제공합니다. 따라서 ‘d’ 속성에 "절대 이동(M)" 및 "절대 호(A)" 명령이 있으면 pathSegList는 두 개의 항목, SVG_PATHSEG_MOVETO_ABS와 SVG_PATHSEG_ARC_ABS를 갖게 됩니다.

```java
public SVGPathSegList PathSegList { get; set; }
```

### Property Value

경로 세그먼트 목록.
