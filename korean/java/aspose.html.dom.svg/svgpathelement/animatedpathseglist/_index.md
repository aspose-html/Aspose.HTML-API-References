## SVGPathElement.AnimatedPathSegList property

‘d’ 속성의 현재 애니메이션된 내용을 SVG 구문과 일대일로 일치하는 형태로 제공합니다. 해당 속성이나 속성이 애니메이션 중인 경우, 해당 속성 또는 속성의 현재 애니메이션 값이 포함되며 객체 자체와 그 내용은 읽기 전용입니다. 해당 속성이나 속성이 현재 애니메이션되지 않은 경우, pathSegList와 동일한 값을 포함합니다.

```java
public SVGPathSegList AnimatedPathSegList { get; }
```

### Property Value

애니메이션된 경로 세그먼트 목록.
