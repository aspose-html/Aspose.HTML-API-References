## SVGGeometryElement.GetPointAtLength method

```java
public SVGPoint GetPointAtLength(float distance)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| 거리 | Single | 경로 시작점에 대한 상대적인 경로상의 거리이며, 현재 사용자 좌표계의 거리 단위로 표시됩니다. |

### 반환 값

사용자 공간에서 반환된 점.
