## FillText(String, double, double, double) {#filltext_1}

주어진 (x,y) 위치에 지정된 텍스트를 그리거나(채웁니다).

```java
public void FillText(String text, double x, double y, double maxWidth)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| 텍스트 | String | 현재 폰트, textAlign, textBaseline 및 direction 값을 사용하여 그릴 텍스트입니다. |
| x | Double | 텍스트 시작점 좌표의 x 축입니다. |
| y | Double | 텍스트 시작점 좌표의 y 축입니다. |
| maxWidth | Double | 그릴 최대 너비입니다. 지정된 경우 문자열이 이 너비보다 넓게 계산되면, 폰트를 더 가로로 압축된 폰트(사용 가능한 경우 또는 현재 폰트를 가로로 스케일링하여 충분히 읽을 수 있는 폰트를 합성할 수 있는 경우) 또는 더 작은 폰트로 조정합니다. |
