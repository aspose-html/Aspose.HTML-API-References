이 패키지는 시간 이벤트 및 확대와 같은 이벤트 기반 상호작용을 위한 클래스로 구성됩니다.

## 클래스

| 클래스 | 설명 |
| --- | --- |
| [SVGZoomEvent](./svgzoomevent/) | 줌 이벤트는 사용자가 현재 SVG 문서 조각의 뷰를 재조정하는 동작을 시작할 때 발생합니다. 이벤트 핸들러는 ‘svg’ 요소에서만 인식됩니다. |
| [TimeEvent](./timeevent/) | TimeEvent 인터페이스는 시간 이벤트와 관련된 특정 컨텍스트 정보를 제공합니다. 발생할 수 있는 다양한 이벤트 유형은: beginEvent, endEvent 및 repeatEvent입니다. |
