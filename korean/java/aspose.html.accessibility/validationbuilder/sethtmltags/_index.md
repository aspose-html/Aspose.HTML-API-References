## ValidationBuilder.SetHTMLTags method

검사할 HTML 태그 목록. 태그가 명시적으로 지정되지 않으면, 태그 배열이 비어 있으며 모든 태그를 대상으로 검사가 진행됩니다.

```java
public ValidationBuilder SetHTMLTags(params String[] tags)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| tags | String[] | HTML 태그 목록 - 값은 해당 태그에 대한 문자열 설명입니다. |

### 반환 값

설정에서 태그를 설정하고 초기화합니다.
