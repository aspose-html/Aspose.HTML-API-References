## HTMLInputElement.Value property

`type` 속성 값이 "text", "file" 또는 "password"인 경우, 이는 대화형 사용자 에이전트에서 해당 폼 컨트롤의 현재 내용을 나타냅니다. 이 속성을 변경하면 폼 컨트롤의 내용이 바뀌지만 요소의 HTML value 속성 값은 변경되지 않습니다. `type` 속성 값이 "button", "hidden", "submit", "reset", "image", "checkbox" 또는 "radio"인 경우, 이는 요소의 HTML value 속성을 나타냅니다. HTML 4.01의 value 속성 정의를 참조하십시오.

```java
public String Value { get; set; }
```
