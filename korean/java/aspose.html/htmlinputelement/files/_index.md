## HTMLInputElement.Files property

files IDL 속성은 스크립트가 요소의 선택된 파일에 접근하도록 허용합니다. 가져올 때 IDL 속성이 적용되면 현재 선택된 파일을 나타내는 FileList 객체를 반환해야 합니다. 선택된 파일 목록이 변경될 때까지 동일한 객체를 반환해야 합니다. IDL 속성이 적용되지 않으면 null을 반환해야 합니다. [FILEAPI]

```java
public IFileList Files { get; }
```
