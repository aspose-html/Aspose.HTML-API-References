## HTMLInputElement.Checked property

`type` 속성의 값이 "radio" 또는 "checkbox"인 경우, 이는 인터랙티브 사용자 에이전트에서 폼 컨트롤의 현재 상태를 나타냅니다. 이 속성을 변경하면 폼 컨트롤의 상태가 바뀌지만 INPUT 요소의 HTML checked 속성 값은 변경되지 않습니다. "radio" 또는 "checkbox" 값을 가진 type 속성을 가진 입력 요소에 대한 클릭 이벤트를 처리하는 동안 일부 구현에서는 이벤트가 문서에 전달되기 전에 이 속성의 값을 변경할 수 있습니다. 이벤트의 기본 동작이 취소되면 속성 값이 원래 값으로 되돌아갈 수 있습니다. 이는 클릭 이벤트를 처리하는 동안 이 속성의 값이 구현에 따라 달라짐을 의미합니다.

```java
public bool Checked { get; set; }
```
