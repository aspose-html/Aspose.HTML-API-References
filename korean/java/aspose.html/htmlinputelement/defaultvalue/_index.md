## HTMLInputElement.DefaultValue property

요소의 `type` 속성 값이 "text", "file" 또는 "password"인 경우, 이는 요소의 HTML value 속성을 나타냅니다. 인터랙티브 사용자 에이전트에서 해당 폼 컨트롤의 내용이 변경되어도 이 속성의 값은 변하지 않습니다. HTML 4.01의 value 속성 정의를 참조하십시오.

```java
public String DefaultValue { get; set; }
```
