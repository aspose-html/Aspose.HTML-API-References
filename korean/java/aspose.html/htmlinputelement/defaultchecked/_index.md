## HTMLInputElement.DefaultChecked property

`type`이 "radio" 또는 "checkbox"인 경우, 이는 요소의 HTML checked 속성을 나타냅니다. 대화형 사용자 에이전트에서 해당 폼 컨트롤의 상태가 변경되어도 이 속성 값은 변하지 않습니다. HTML 4.01의 checked 속성 정의를 참조하십시오.

```java
public bool DefaultChecked { get; set; }
```
