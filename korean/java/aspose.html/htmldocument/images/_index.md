## HTMLDocument.Images property

`IMG` 요소의 모든 컬렉션입니다. 이전 호환성을 위해 동작이 `IMG` 요소에만 제한됩니다. [[HTML 4.01](http://www.w3.org/TR/1999/REC-html401-19991224)]에서 권장하듯 이미지를 포함하려면 저자는 `OBJECT` 요소나 `IMG` 요소를 사용할 수 있습니다. 따라서 이 속성을 사용해 문서에서 이미지를 찾기보다는 HTML 4.01에서는 `getElementsByTagName`을, XHTML 1.0에서는 `getElementsByTagNameNS`를 사용하는 것이 권장됩니다.

```java
public HTMLCollection Images { get; }
```
