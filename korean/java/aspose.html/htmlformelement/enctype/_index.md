## HTMLFormElement.Enctype property

제출된 양식의 콘텐츠 유형은 일반적으로 "application/x-www-form-urlencoded"입니다. HTML 4.01의 enctype 속성 정의를 참조하십시오. 이 메서드를 호출할 때 onsubmit 이벤트 핸들러가 반드시 트리거된다는 보장은 없습니다. 동작은 역사적 이유로 일관되지 않으며 작성자는 특정 동작에 의존해서는 안 됩니다.

```java
public String Enctype { get; set; }
```
