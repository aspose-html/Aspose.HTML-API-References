## Sandbox enumeration

샌드박스 플래그 집합은 다음 플래그 중 0개 이상으로 구성되며, 잠재적으로 신뢰할 수 없는 리소스의 기능을 제한하는 데 사용됩니다.

```java
[Flags]
public enum Sandbox
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| None | `0` | 플래그가 설정되지 않았으며, 모든 샌드박스 기능이 허용됩니다 |
| Navigation | `1` | 이 플래그는 샌드박스된 브라우징 컨텍스트 자체(또는 그 안에 더 중첩된 브라우징 컨텍스트)를 제외한 다른 브라우징 컨텍스트, 보조 브라우징 컨텍스트(다음에 정의된 샌드박스 보조 탐색 브라우징 컨텍스트 플래그에 의해 보호됨), 그리고 최상위 브라우징 컨텍스트(아래에 정의된 샌드박스 최상위 탐색 브라우징 컨텍스트 플래그에 의해 보호됨)로의 탐색을 방지합니다. 샌드박스 보조 탐색 브라우징 컨텍스트 플래그가 설정되지 않은 경우, 특정 상황에서는 제한에도 불구하고 팝업(새 최상위 브라우징 컨텍스트)의 열림을 허용합니다. 이러한 브라우징 컨텍스트는 항상 하나의 허용된 샌드박스 탐색자를 가지고 있으며, 이는 브라우징 컨텍스트가 생성될 때 설정되어 해당 컨텍스트를 만든 컨텍스트가 실제로 탐색할 수 있게 합니다. (그렇지 않으면 샌드박스 탐색 브라우징 컨텍스트 플래그가 열려 있더라도 탐색을 방지했을 것입니다.) |
| AuxiliaryNavigation | `2` | 이 플래그는 target 속성을 사용하거나 window.open() 메서드를 호출하는 등 새로운 보조 브라우징 컨텍스트 생성을 방지합니다. |
| TopLevelNavigation | `4` | 이 플래그는 콘텐츠가 최상위 브라우징 컨텍스트를 탐색하거나 닫는 것을 방지합니다. 샌드박스 최상위 탐색 브라우징 컨텍스트 플래그가 설정되지 않은 경우, 콘텐츠는 자신의 최상위 브라우징 컨텍스트를 탐색할 수 있지만, 다른 브라우징 컨텍스트는 여전히 샌드박스 탐색 브라우징 컨텍스트 플래그 및 경우에 따라 샌드박스 보조 탐색 브라우징 컨텍스트 플래그에 의해 보호됩니다. |
| Plugins | `8` | 이 플래그는 embed 요소, object 요소, applet 요소를 사용하거나 중첩된 브라우징 컨텍스트를 탐색하는 경우 등, 플러그인을 인스턴스화하는 것을 방지합니다(플러그인을 보안할 수 있는 경우를 제외). |
| Origin | `10` | 이 플래그는 콘텐츠를 고유한 출처로 강제하여 동일한 출처의 다른 콘텐츠에 접근하는 것을 방지합니다. |
| Forms | `20` | 이 플래그는 폼 제출을 차단합니다. |
| PointerLock | `40` | 이 플래그는 Pointer Lock API를 비활성화합니다. |
| Scripts | `80` | 이 플래그는 스크립트 실행을 차단합니다. |
| AutomaticFeatures | `100` | 이 플래그는 비디오 자동 재생이나 폼 컨트롤 자동 포커스와 같이 자동으로 트리거되는 기능을 차단합니다. |
| Fullscreen | `200` | 이 플래그는 콘텐츠가 requestFullscreen() 메서드를 사용하는 것을 방지합니다. |
| DocumentDomain | `400` | 이 플래그는 콘텐츠가 document.domain 기능을 사용하여 실제 스크립트 출처를 변경하는 것을 방지합니다. |
| Images | `800` | 이 플래그는 이미지 로드를 비활성화합니다. |
