## HTMLSelectElement.SelectedIndex property

선택된 옵션의 순서 인덱스로, 0부터 시작합니다. 요소가 선택되지 않은 경우 -1이 반환됩니다. 여러 옵션이 선택된 경우 첫 번째 선택된 옵션의 인덱스가 반환됩니다.

```java
public int SelectedIndex { get; set; }
```
