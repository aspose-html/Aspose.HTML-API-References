## Configuration.Security property

구성의 샌드박싱 플래그를 가져오거나 설정합니다. [sandboxing](https://docs.aspose.com/html/net/working-with-documents/environment-configuration/#sandboxing) 문서를 참조하십시오.

```java
public Sandbox Security { get; set; }
```

### Property Value

보안. [`sandboxing flag`](../../sandbox/) 집합은 0개 이상의 플래그로 구성되며, 잠재적으로 신뢰할 수 없는 리소스의 기능을 제한하는 데 사용됩니다. sandbox 속성을 사용하면 프레임에 로드된 콘텐츠에 여러 제한을 설정할 수 있습니다. 예를 들어, 양식 및 스크립트를 차단합니다.
