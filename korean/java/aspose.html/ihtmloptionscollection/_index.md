## IHTMLOptionsCollection interface

`HTMLOptionsCollection`은 HTML 옵션 요소를 나타내는 노드 목록입니다. 개별 노드는 순서 인덱스 또는 노드의 `name` 또는 `id` 속성을 통해 접근할 수 있습니다. HTML DOM의 컬렉션은 실시간(live)으로 가정되며, 이는 기본 문서가 변경될 때 자동으로 업데이트됨을 의미합니다.

또한 [Document object Model (DOM) Level 2 HTML Specification](http://www.w3.org/TR/2003/REC-DOM-Level-2-HTML-20030109)을 참조하십시오. @since DOM Level 2

```java
public interface IHTMLOptionsCollection : IEnumerable<Element>
```
