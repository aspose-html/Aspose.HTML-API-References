## SVGLength.ValueAsString property

unitType에 의해 표현된 단위의 문자열 값으로서의 값입니다. 이 속성을 설정하면 value, valueInSpecifiedUnits 및 unitType이 이 설정을 반영하도록 자동으로 업데이트됩니다.

```java
public String ValueAsString { get; set; }
```

### Property Value

값을 문자열로 나타냅니다.
