## SVGAngle.ValueAsString property

unitType으로 표현된 단위의 문자열 값으로 각도 값을 나타냅니다. 이 속성을 설정하면 value, valueInSpecifiedUnits 및 unitType이 자동으로 업데이트되어 이 설정을 반영합니다.

```java
public String ValueAsString { get; set; }
```

### Property Value

값을 문자열로 나타냅니다.
