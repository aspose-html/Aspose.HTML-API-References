## SVGTransform.SetRotate method

변환 유형을 SVG_TRANSFORM_ROTATE로 설정하고, 매개변수 angle가 회전 각도를 정의하며, 매개변수 cx와 cy가 선택적인 회전 중심을 정의합니다.

```java
public void SetRotate(float angle, float cx, float cy)
```

| Parameter | Type | 설명 |
| --- | --- | --- |
| angle | Single | 회전 각도. |
| cx | Single | 회전 중심의 x 좌표. |
| cy | Single | 회전 중심의 y 좌표. |
