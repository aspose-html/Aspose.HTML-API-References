**com.aspose.html.rendering.image** 패키지는 jpeg, png, bmp, gif, tiff와 같은 래스터 형식으로 렌더링하는 데 필요한 특정 디바이스 클래스와 몇몇 렌더링 옵션 클래스를 제공합니다.

## 클래스

| 클래스 | 설명 |
| --- | --- |
| [ImageDevice](./imagedevice/) | 래스터 형식인 jpeg, png, bmp, gif, tiff에 대한 렌더링을 나타냅니다. |
| [ImageRenderingOptions](./imagerenderingoptions/) | [`ImageDevice`](../com.aspose.html.rendering.image/imagedevice/)에 대한 렌더링 옵션을 나타냅니다. 이 옵션은 출력 이미지 형식, 압축, 해상도 등을 지정하는 데 사용됩니다. |
| [TextOptions](./textoptions/) | [`ImageDevice`](../com.aspose.html.rendering.image/imagedevice/)에 대한 텍스트 렌더링 옵션을 나타냅니다. |
## 열거형

| 열거형 | 설명 |
| --- | --- |
| [Compression](./compression/) | Tagged Image File Format (TIFF) 비트맵 이미지에 대한 가능한 압축 방식들을 지정합니다. |
| [ImageFormat](./imageformat/) | 이미지의 파일 형식을 지정합니다. |
