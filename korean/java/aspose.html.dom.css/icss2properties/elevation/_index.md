## ICSS2Properties.Elevation property

이 속성의 값은 다음과 같은 의미를 가집니다:

'angle' - 고도( elevation)를 각도로 지정하며, '-90deg'와 '90deg' 사이입니다. '0deg'는 앞쪽 수평선에 해당하며, 청취자와 같은 수준을 의미합니다. '90deg'는 바로 위를, '-90deg'는 바로 아래를 의미합니다.below - '-90deg'와 동일합니다.level - '0deg'와 동일합니다.above - '90deg'와 동일합니다.higher - 현재 고도에 10도를 추가합니다.lower - 현재 고도에서 10도를 빼습니다.

```java
public String Elevation { get; set; }
```

### 반환 값

elevation 속성
