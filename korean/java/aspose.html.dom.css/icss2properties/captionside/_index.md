## ICSS2Properties.CaptionSide property

이 속성은 캡션 박스가 테이블 박스에 대해 어느 위치에 있는지를 지정합니다. 값은 다음과 같은 의미를 가집니다:

top - 캡션 박스를 테이블 박스 위에 배치합니다. bottom - 캡션 박스를 테이블 박스 아래에 배치합니다. left - 캡션 박스를 테이블 박스 왼쪽에 배치합니다. right - 캡션 박스를 테이블 박스 오른쪽에 배치합니다.

```java
public String CaptionSide { get; set; }
```

### 반환 값

caption-side 속성
