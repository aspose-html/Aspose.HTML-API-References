## ICSS2Properties.LineHeight property

속성이 [block-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#block-level) 요소에 설정되고 해당 요소의 내용이 [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) 요소로 구성된 경우, 각 생성된 인라인 박스의 최소 높이를 지정합니다.

속성이 [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) 요소에 설정된 경우, 해당 요소에 의해 생성된 각 박스의 정확한 높이를 지정합니다. (인라인 [replaced](https://www.w3.org/TR/1998/REC-CSS2-19980512/conform.html#replaced-element) 요소는 제외하며, 이 경우 박스의 높이는 ['height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-height) 속성에 의해 지정됩니다.)

```java
public String LineHeight { get; set; }
```

### 반환 값

line-height 속성
