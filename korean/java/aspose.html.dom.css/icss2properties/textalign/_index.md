## ICSS2Properties.TextAlign property

이 속성은 블록의 인라인 콘텐츠가 어떻게 정렬되는지를 설명합니다. 값은 다음과 같은 의미를 가집니다:

left, right, center, and justify - 각각 left, right, center, 그리고 double justify 텍스트.'[String](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-String)' - 표 열의 셀을 정렬할 문자열을 지정합니다 (자세한 내용 및 예시는 [horizontal alignment in a column](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#column-alignment) 섹션을 참조하십시오). 이 값은 [table](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html) 셀에만 적용됩니다. 다른 요소에 설정하면, ['direction'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-direction)이 'ltr'인지 'rtl'인지에 따라 각각 'left' 또는 'right'로 처리됩니다.

```java
public String TextAlign { get; set; }
```

### 반환 값

text-align 속성
