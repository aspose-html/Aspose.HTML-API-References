## ICSS2Properties.TextTransform property

이 속성은 요소 텍스트의 대문자 변환 효과를 제어합니다. 값은 다음과 같은 의미를 가집니다:

capitalize - 각 단어의 첫 번째 문자를 대문자로 변환합니다. uppercase - 각 단어의 모든 문자를 대문자로 변환합니다. lowercase - 각 단어의 모든 문자를 소문자로 변환합니다. none - 대문자 변환 효과가 없습니다.

```java
public String TextTransform { get; set; }
```

### 반환 값

text-transform 속성
