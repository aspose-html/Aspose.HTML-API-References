## ICSS2Properties.PageBreakAfter property

이러한 속성들의 값은 다음과 같은 의미를 가집니다:

auto - 생성된 박스 앞(뒤, 내부)에 페이지 나누기를 강제하거나 금지하지 않습니다. always - 생성된 박스 앞(뒤)에 항상 페이지 나누기를 강제합니다. avoid - 생성된 박스 앞(뒤, 내부)에 페이지 나누기를 피합니다. left - 생성된 박스 앞(뒤)에 한두 번 페이지 나누기를 강제하여 다음 페이지가 왼쪽 페이지로 형식화되도록 합니다. right - 생성된 박스 앞(뒤)에 한두 번 페이지 나누기를 강제하여 다음 페이지가 오른쪽 페이지로 형식화되도록 합니다.

```java
public String PageBreakAfter { get; set; }
```

### 반환 값

page-break-after 속성
