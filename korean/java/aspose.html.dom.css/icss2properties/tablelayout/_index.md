## ICSS2Properties.TableLayout property

['table-layout'](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#propdef-table-layout) 속성은 테이블 셀, 행 및 열을 배치하는 알고리즘을 제어합니다. 값은 다음과 같은 의미를 가집니다:

fixed - 고정 테이블 레이아웃 알고리즘을 사용합니다auto - 자동 테이블 레이아웃 알고리즘을 사용합니다

```java
public String TableLayout { get; set; }
```

### 반환 값

table-layout 속성
