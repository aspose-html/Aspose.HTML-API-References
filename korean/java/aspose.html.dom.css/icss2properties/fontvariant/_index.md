## ICSS2Properties.FontVariant property

소문자 글리프가 대문자와 비슷하지만 더 작은 크기와 약간 다른 비율을 가진 작은 대문자 글꼴에서는, 'font-variant' 속성이 라틴 스크립트와 같이 두 가지 대소문자를 갖는 양문자용 글꼴을 요청합니다. 이 속성은 대부분의 세계 문자 체계와 같이 한 가지 대소문자만 갖는 단문자 스크립트에는 눈에 보이는 효과가 없습니다.

```java
public String FontVariant { get; set; }
```

### 반환 값

font-variant 속성
