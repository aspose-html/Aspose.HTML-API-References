## ICSS2Properties.MinWidth property

이 두 속성은 저자들이 박스 너비를 특정 범위로 제한하도록 허용합니다. 값은 다음과 같은 의미를 가집니다:

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - 고정된 최소 또는 최대 계산된 너비를 지정합니다. '[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - 계산된 값을 결정하기 위한 백분율을 지정합니다. 백분율은 생성된 박스의 [포함 블록](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#containing-block) 너비를 기준으로 계산됩니다. none - (['max-width'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-max-width)에만 적용) 박스 너비에 제한이 없습니다.

```java
public String MinWidth { get; set; }
```

### 반환 값

min-width 속성
