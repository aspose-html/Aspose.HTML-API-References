## ICSS2Properties.BackgroundImage property

이 속성은 요소의 배경 이미지를 설정합니다. 배경 이미지를 설정할 때, 저자는 이미지가 없을 경우 사용할 배경 색상을 지정해야 합니다. 이미지가 사용 가능할 경우, 배경 색상 위에 이미지가 렌더링됩니다. (따라서 투명한 부분에서는 색상이 보이게 됩니다).

```java
public String BackgroundImage { get; set; }
```

### 반환 값

background-image 속성

### Property Value

이 속성의 값은 이미지를 지정할 때 , 혹은 이미지가 사용되지 않을 때 'none' 중 하나입니다.
