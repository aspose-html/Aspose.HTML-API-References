## ICSS2Properties.SpeakHeader property

이 속성은 테이블 헤더가 각 셀 앞에 모두 읽히는지, 아니면 해당 셀이 이전 셀과 다른 헤더와 연결될 때만 읽히는지를 지정합니다. 값은 다음과 같은 의미를 가집니다:

once - 헤더가 한 번만, 일련의 셀 앞에서 읽힙니다.always - 헤더가 모든 해당 셀 앞에서 읽힙니다.

```java
public String SpeakHeader { get; set; }
```
