## ICSS2Properties.SpeakPunctuation property

이 속성은 구두점이 어떻게 읽히는지를 지정합니다. 값은 다음과 같은 의미를 가집니다:

code - 세미콜론, 중괄호 등과 같은 구두점은 문자 그대로 읽혀야 합니다.none - 구두점은 읽히지 않고, 대신 다양한 일시 정지로 자연스럽게 표시됩니다.

```java
public String SpeakPunctuation { get; set; }
```
