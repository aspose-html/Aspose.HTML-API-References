## ICSS2Properties.Size property

이 속성은 페이지 상자의 크기와 방향을 지정합니다.

페이지 상자의 크기는 "absolute"(고정 크기) 또는 "relative"(확장 가능, 즉 사용 가능한 시트 크기에 맞춤) 중 하나일 수 있습니다. Relative 페이지 상자는 사용자 에이전트가 문서를 확대/축소하여 목표 크기를 최적화하도록 허용합니다.

['size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-size) 속성의 세 가지 값이 상대 페이지 상자를 생성합니다:

auto - 페이지 상자는 대상 시트의 크기와 방향으로 설정됩니다.landscape - 대상의 방향을 무시합니다. 페이지 상자는 대상과 같은 크기이며, 긴 면이 가로입니다.portrait - 대상의 방향을 무시합니다. 페이지 상자는 대상과 같은 크기이며, 짧은 면이 가로입니다.

```java
public String Size { get; set; }
```

### 반환 값

size 속성
