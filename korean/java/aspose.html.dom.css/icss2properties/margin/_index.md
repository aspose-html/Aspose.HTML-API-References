## ICSS2Properties.Margin property

The ['margin'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin) 속성은 스타일 시트에서 같은 위치에 ['margin-top'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-top), ['margin-right'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-right), ['margin-bottom'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-bottom), 그리고 ['margin-left'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-margin-left) 을 설정하기 위한 축약 속성입니다.

값이 하나만 있으면 모든 면에 적용됩니다. 값이 두 개이면 위와 아래 여백은 첫 번째 값으로, 오른쪽과 왼쪽 여백은 두 번째 값으로 설정됩니다. 값이 세 개이면 위는 첫 번째 값으로, 좌우는 두 번째 값으로, 아래는 세 번째 값으로 설정됩니다. 값이 네 개이면 각각 위, 오른쪽, 아래, 왼쪽에 적용됩니다.

```java
public String Margin { get; set; }
```

### 반환 값

margin 속성
