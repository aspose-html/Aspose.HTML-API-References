## ICSS2Properties.ListStylePosition property

이 속성은 기본 블록 상자에서 마커 상자의 위치를 지정합니다. 값은 다음과 같은 의미를 가집니다:

outside - 마커 상자는 기본 블록 상자 밖에 있습니다. 참고: CSS1은 마커 상자의 정확한 위치를 지정하지 않았으며 호환성 문제로 CSS2도 동일하게 모호합니다. 마커 상자를 보다 정확하게 제어하려면 markers를 사용하십시오. inside - 마커 상자는 기본 블록 상자 안의 첫 번째 인라인 상자이며, 그 뒤로 요소의 내용이 흐릅니다.

```java
public String ListStylePosition { get; set; }
```

### 반환 값

list-style-position 속성
