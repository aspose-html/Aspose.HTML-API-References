## ICSS2Properties.Font property

'font' 속성은 아래에 설명된 경우를 제외하고, 스타일 시트의 같은 위치에서 'font-style', 'font-variant', 'font-weight', 'font-size', 'line-height', 그리고 'font-family'를 설정하기 위한 축약 속성입니다. 이 속성의 구문은 글꼴과 관련된 여러 속성을 설정하기 위한 전통적인 타이포그래피 축약 표기법을 기반으로 합니다.

```java
public String Font { get; set; }
```

font 속성
