## ICSS2Properties.FontWeight property

'font-weight' 속성은 글꼴의 두께를 지정합니다. 값은 다음과 같은 의미를 가집니다:

100에서 900까지 - 이 값들은 순서가 있는 시퀀스를 이루며, 각 숫자는 이전 값보다 최소한 더 어두운 두께를 나타냅니다. normal - '400'과 동일합니다. bold - '700'과 동일합니다. bolder - 상속된 글꼴보다 더 어두운 두께를 가진 다음 두께를 지정합니다. 해당 두께가 없으면 단순히 다음으로 더 어두운 숫자 값이 적용되며(글꼴은 변하지 않음), 단, 상속값이 '900'인 경우 결과 두께도 '900'이 됩니다. lighter - 상속된 글꼴보다 더 가벼운 두께를 가진 다음 두께를 지정합니다. 해당 두께가 없으면 단순히 다음으로 더 가벼운 숫자 값이 적용되며(글꼴은 변하지 않음), 단, 상속값이 '100'인 경우 결과 두께도 '100'이 됩니다.

```java
public String FontWeight { get; set; }
```
