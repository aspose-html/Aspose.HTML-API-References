## ICSS2Properties.Stress property

음성의 억양 윤곽에서 \"국부적인 피크\"의 높이를 지정합니다. 예를 들어, 영어는 강세가 있는 언어이며 문장의 다양한 부분에 1차, 2차, 3차 강세가 할당됩니다. ['stress'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-stress) 값은 이러한 강세 표시로 인한 억양 변화량을 제어합니다. 이 속성은 ['pitch-range'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pitch-range) 속성과 함께 사용되며 개발자가 고급 청각 디스플레이를 활용할 수 있도록 제공됩니다.

```java
public String Stress { get; set; }
```

### 반환 값

stress 속성
