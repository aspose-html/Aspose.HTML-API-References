## ICSS2Properties.BackgroundAttachment property

배경 이미지가 지정된 경우, 이 속성은 뷰포트에 대해 고정('fixed')되는지 또는 문서와 함께 스크롤('scroll')되는지를 지정합니다.

이미지가 고정되어 있더라도 요소의 배경 또는 패딩 영역에 있을 때만 표시됩니다. 따라서 이미지가 타일링되지 않은 경우('background-repeat: repeat'), 보이지 않을 수 있습니다.

```java
public String BackgroundAttachment { get; set; }
```

### 반환 값

background-attachment 속성
