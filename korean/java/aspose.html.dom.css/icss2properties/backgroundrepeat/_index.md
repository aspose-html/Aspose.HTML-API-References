## ICSS2Properties.BackgroundRepeat property

배경 이미지가 지정된 경우, 이 속성은 이미지가 반복(타일링)되는지와 그 방식을 지정합니다. 모든 타일링은 박스의 내용 영역과 패딩 영역을 덮습니다. 값은 다음과 같은 의미를 가집니다:

repeat - 이미지는 수평 및 수직으로 모두 반복됩니다. repeat-x - 이미지는 수평으로만 반복됩니다. repeat-y - 이미지는 수직으로만 반복됩니다. no-repeat - 이미지는 반복되지 않으며, 한 번만 그려집니다.

```java
public String BackgroundRepeat { get; set; }
```

### 반환 값

background-repeat 속성

### Property Value

위에서 정의된 목록의 background repeat 값입니다.
