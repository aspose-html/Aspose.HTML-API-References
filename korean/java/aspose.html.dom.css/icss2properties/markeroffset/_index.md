## ICSS2Properties.MarkerOffset property

이 속성은 마커 박스의 가장 가까운 [경계 가장자리](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#border-edge)와 연관된 [주 박스](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#principal-box) 사이의 거리를 지정합니다. 오프셋은 사용자 지정 ([길이](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length))일 수도 있고 UA가 'auto'를 선택할 수도 있습니다. 길이는 음수일 수 있지만 구현에 따라 제한이 있을 수 있습니다.

```java
public String MarkerOffset { get; set; }
```

### 반환 값

marker-offset 속성
