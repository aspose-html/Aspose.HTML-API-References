## ICSS2Properties.MarkerOffset property

이 속성은 마커 박스의 가장 가까운 [border edges](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#border-edge)와 연결된 [principal box](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#principal-box) 사이의 거리를 지정합니다. 오프셋은 사용자 지정 ([length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length))이거나 UA가 'auto'를 선택할 수 있습니다. 길이는 음수일 수 있지만 구현마다 제한이 있을 수 있습니다.

```java
public String MarkerOffset { get; set; }
```

### 반환 값

marker-offset 속성
