## ICSS2Properties.MaxHeight property

이 두 속성을 사용하면 작성자가 상자 높이를 특정 범위로 제한할 수 있습니다. 값은 다음과 같은 의미를 가집니다:

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - 고정된 최소 또는 최대 계산 높이를 지정합니다.'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - 계산값을 결정하기 위한 백분율을 지정합니다. 백분율은 생성된 상자의 [containing block](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#containing-block) 높이를 기준으로 계산됩니다. 포함 블록의 높이가 명시적으로 지정되지 않은 경우(즉, 내용 높이에 따라 달라지는 경우), 백분율 값은 'auto'와 같이 해석됩니다.none - (Only on ['max-height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-max-height)) 상자의 높이에 제한이 없습니다.

```java
public String MaxHeight { get; set; }
```

### 반환 값

max-height 속성
