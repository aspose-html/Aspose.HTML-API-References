## ICSS2Properties.BorderRightWidth property

이 속성은 스타일 시트에서 'border-top-width', 'border-right-width', 'border-bottom-width', 및 'border-left-width'를 한 곳에서 설정하기 위한 단축 속성입니다.

값이 하나만 있으면 모든 면에 적용됩니다. 값이 두 개이면 위와 아래 테두리는 첫 번째 값으로, 오른쪽과 왼쪽은 두 번째 값으로 설정됩니다. 값이 세 개이면 위는 첫 번째 값으로, 왼쪽과 오른쪽은 두 번째 값으로, 아래는 세 번째 값으로 설정됩니다. 값이 네 개이면 각각 위, 오른쪽, 아래, 왼쪽에 적용됩니다.

```java
public String BorderRightWidth { get; set; }
```

### 반환 값

border-right-width 속성
