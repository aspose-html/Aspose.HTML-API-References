## ICSS2Properties.CounterIncrement property

['counter-increment'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-counter-increment) 속성은 하나 이상의 카운터(식별자) 이름을 받아들이며, 각 이름 뒤에 선택적으로 정수를 붙일 수 있습니다. 정수는 요소가 나타날 때마다 카운터가 증가하는 양을 나타냅니다. 기본 증가값은 1이며, 0 및 음수 정수가 허용됩니다.

```java
public String CounterIncrement { get; set; }
```

### 반환 값

counter-increment 속성
