## ICSS2Properties.VoiceFamily property

값은 쉼표로 구분된 우선 순위 목록의 voice family 이름입니다 (['font-family'](https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html#propdef-font-family)와 비교). 값은 다음과 같은 의미를 가집니다:

'generic-voice' - 값은 voice family입니다. 가능한 값은 'male', 'female', 'child'입니다.'specific-voice' - 값은 특정 인스턴스입니다 (예: comedian, trinoids, carlos, lani).

```java
public String VoiceFamily { get; set; }
```

### 반환 값

voice-family 속성
