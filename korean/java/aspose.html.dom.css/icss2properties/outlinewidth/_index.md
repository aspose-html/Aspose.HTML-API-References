## ICSS2Properties.OutlineWidth property

outline 속성으로 만든 외곽선은 박스 "위에" 그려지며, 외곽선은 항상 최상위에 표시되고 박스나 다른 박스들의 위치나 크기에 영향을 주지 않습니다. 따라서 외곽선을 표시하거나 숨겨도 레이아웃 재배열이 발생하지 않습니다.

```java
public String OutlineWidth { get; set; }
```

### 반환 값

outline-width 속성
