## ICSS2Properties.Orphans property

['orphans'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-orphans) 속성은 페이지 하단에 남겨야 하는 단락의 최소 줄 수를 지정합니다. ['widows'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-widows) 속성은 페이지 상단에 남겨야 하는 단락의 최소 줄 수를 지정합니다. 페이지 나눔을 제어하는 데 어떻게 사용되는지에 대한 예는 아래에 제시됩니다.

```java
public String Orphans { get; set; }
```
