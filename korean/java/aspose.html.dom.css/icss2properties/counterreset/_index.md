## ICSS2Properties.CounterReset property

['counter-reset'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-counter-reset) 속성도 하나 이상의 카운터 이름 목록을 포함하며, 각 이름 뒤에 선택적으로 정수가 올 수 있습니다. 정수는 요소가 나타날 때마다 카운터가 설정되는 값을 지정합니다. 기본값은 0입니다.

```java
public String CounterReset { get; set; }
```

### 반환 값

counter-reset 속성
