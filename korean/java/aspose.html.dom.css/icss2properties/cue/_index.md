## ICSS2Properties.Cue property

['cue'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue) 속성은 ['cue-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-before)와 ['cue-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-after)를 설정하기 위한 축약형입니다. 두 개의 값이 주어지면 첫 번째 값은 ['cue-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-before)이고 두 번째는 ['cue-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-after)입니다. 값이 하나만 주어지면 두 속성 모두에 적용됩니다.

```java
public String Cue { get; set; }
```

### 반환 값

cue 속성
