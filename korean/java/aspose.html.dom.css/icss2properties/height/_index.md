## ICSS2Properties.Height property

이 속성은 블록 레벨 및 [대체](https://www.w3.org/TR/1998/REC-CSS2-19980512/conform.html#replaced-element) 요소에 의해 생성된 박스의 [콘텐츠 높이](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#content-height)를 지정합니다.

이 속성은 비대체 [인라인 레벨](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) 요소에는 적용되지 않습니다. 비대체 인라인 요소의 박스 높이는 요소의 (상속될 수 있는) ['line-height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-line-height) 값에 의해 결정됩니다.

```java
public String Height { get; set; }
```

### 반환 값

height 속성
