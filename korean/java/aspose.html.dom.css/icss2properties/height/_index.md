## ICSS2Properties.Height property

이 속성은 블록 레벨 및 [replaced](https://www.w3.org/TR/1998/REC-CSS2-19980512/conform.html#replaced-element) 요소에 의해 생성된 상자의 [content height](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#content-height)를 지정합니다.

이 속성은 비교체된 [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) 요소에는 적용되지 않습니다. 비교체된 인라인 요소의 상자 높이는 요소의 (가능한 경우 상속된) ['line-height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-line-height) 값에 의해 결정됩니다.

```java
public String Height { get; set; }
```

### 반환 값

height 속성
