## ICSS2Properties.Border property

‘border’ 속성은 박스의 네 면 모두에 동일한 너비, 색상 및 스타일을 설정하는 단축 속성입니다. ‘margin’ 및 ‘padding’ 단축 속성과 달리, ‘border’ 속성은 네 면에 서로 다른 값을 지정할 수 없습니다. 이를 위해서는 하나 이상의 다른 border 속성을 사용해야 합니다.

```java
public String Border { get; set; }
```

### 반환 값

border 속성
