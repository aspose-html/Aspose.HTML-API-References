## ICSS2Properties.Pitch property

말하는 목소리의 평균 피치(주파수)를 지정합니다. 목소리의 평균 피치는 음성군에 따라 달라집니다. 예를 들어 표준 남성 목소리의 평균 피치는 약 120Hz이며, 여성 목소리의 경우 약 210Hz입니다.

```java
public String Pitch { get; set; }
```

### 반환 값

pitch 속성
