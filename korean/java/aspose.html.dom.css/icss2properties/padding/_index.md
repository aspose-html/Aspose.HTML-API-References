## ICSS2Properties.Padding property

['padding'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-padding) 속성은 스타일 시트에서 ['padding-top'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-padding-top), ['padding-right'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-padding-right), ['padding-bottom'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-padding-bottom), 그리고 ['padding-left'](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#propdef-padding-left) 를 한 곳에서 설정할 수 있는 단축 속성입니다.

값이 하나만 있으면 모든 면에 적용됩니다. 값이 두 개이면 위와 아래 패딩은 첫 번째 값으로, 오른쪽과 왼쪽 패딩은 두 번째 값으로 설정됩니다. 값이 세 개이면 위는 첫 번째 값, 좌우는 두 번째 값, 아래는 세 번째 값으로 설정됩니다. 값이 네 개이면 각각 위, 오른쪽, 아래, 왼쪽에 적용됩니다.

```java
public String Padding { get; set; }
```

### 반환 값

padding 속성
