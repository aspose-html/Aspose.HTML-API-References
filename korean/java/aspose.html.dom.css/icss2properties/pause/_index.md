## ICSS2Properties.Pause property

['pause'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause) 속성은 ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before)와 ['pause-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-after)를 설정하기 위한 축약형입니다. 두 개의 값이 주어지면 첫 번째 값은 ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before)이고 두 번째 값은 ['pause-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-after)입니다. 값이 하나만 주어지면 두 속성 모두에 적용됩니다.

```java
public String Pause { get; set; }
```

### 반환 값

pause 속성
