## ICSS2Properties.Position property

이 속성의 값은 다음과 같은 의미를 가집니다:

static - 박스는 일반 박스로, [normal flow](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#normal-flow)에 따라 배치됩니다. ['left'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-left)와 ['top'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-top) 속성은 적용되지 않습니다.

```java
public String Position { get; set; }
```

### 반환 값

relative - 박스의 위치는 [normal flow](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#normal-flow)에 따라 계산됩니다(이를 정상 흐름 내 위치라고 합니다). 그런 다음 박스는 [relative](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#relative-positioning) 방식으로 정상 위치에서 오프셋됩니다. 박스 B가 상대적으로 배치될 때, 다음 박스의 위치는 B가 오프셋되지 않은 것처럼 계산됩니다.
