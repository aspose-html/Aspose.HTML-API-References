## ICSS2Properties.FontSizeAdjust property

양각 스크립트에서 글꼴의 주관적인 겉보기 크기와 가독성은 'font-size' 값보다 'x-height' 값에 더 의존합니다. 또는 더 유용하게는 두 값의 비율인 aspect value(글꼴 크기를 x-height 로 나눈 값)로 표현됩니다. aspect value가 높을수록 작은 크기에서도 글꼴이 가독성을 유지할 가능성이 높습니다. 반대로 aspect value가 낮은 글꼴은 특정 임계 크기 이하에서 더 빨리 가독성을 잃습니다. 글꼴 크기만을 기준으로 하는 단순한 글꼴 교체는 가독성 없는 문자를 초래할 수 있습니다.

```java
public String FontSizeAdjust { get; set; }
```

### 반환 값

font-size-adjust 속성
