## ICSS2Properties.BorderSpacing property

길이는 인접한 셀 경계 사이의 거리를 지정합니다. 길이가 하나만 지정되면 가로와 세로 간격을 모두 제공합니다. 두 개가 지정되면 첫 번째는 가로 간격을, 두 번째는 세로 간격을 제공합니다. 길이는 음수일 수 없습니다.

```java
public String BorderSpacing { get; set; }
```

### 반환 값

border-spacing 속성
