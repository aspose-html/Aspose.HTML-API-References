## ICSS2Properties.FontFamily property

이 속성은 글꼴 패밀리 이름 및/또는 일반 패밀리 이름의 우선 순위 목록을 지정합니다. 단일 글꼴에 문서의 모든 문자를 표시할 글리프가 없거나 모든 시스템에 모든 글꼴이 존재하지 않을 수 있는 문제를 해결하기 위해, 이 속성은 저자에게 동일한 스타일과 크기의 글꼴 목록을 순차적으로 시도하여 특정 문자에 대한 글리프가 있는지 확인하도록 허용합니다. 이 목록을 글꼴 집합이라고 합니다.

```java
public String FontFamily { get; set; }
```

### 반환 값

font-family 속성
