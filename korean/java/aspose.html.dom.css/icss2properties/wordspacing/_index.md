## ICSS2Properties.WordSpacing property

이 속성은 단어 사이의 간격 동작을 지정합니다. 값은 다음과 같은 의미를 가집니다:

normal - 현재 글꼴 및/또는 UA에 의해 정의된 일반적인 단어 사이 간격입니다. '[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - 이 값은 기본 단어 사이 간격에 추가적인 간격을 나타냅니다. 값은 음수일 수 있지만 구현에 따라 제한이 있을 수 있습니다.

```java
public String WordSpacing { get; set; }
```

### 반환 값

word-spacing 속성
