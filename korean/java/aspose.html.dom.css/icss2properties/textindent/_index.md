## ICSS2Properties.TextIndent property

이 속성은 블록 내 첫 번째 텍스트 줄의 들여쓰기를 지정합니다. 보다 정확히 말하면 블록의 첫 번째 [line box](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#line-box)로 흐르는 첫 번째 박스의 들여쓰기를 지정합니다. 박스는 라인 박스의 왼쪽(또는 오른쪽, right-to-left 레이아웃의 경우) 가장자리를 기준으로 들여쓰기 됩니다. 사용자 에이전트는 이 들여쓰기를 빈 공간으로 렌더링해야 합니다.

값은 다음과 같은 의미를 가집니다:

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - 들여쓰기는 고정 길이입니다.'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - 들여쓰기는 포함 블록 너비의 백분율입니다.

```java
public String TextIndent { get; set; }
```

### 반환 값

text-indent 속성
