## ICSS2Properties.Background property

'background' 속성은 개별 배경 속성(예: 'background-color', 'background-image', 'background-repeat', 'background-attachment' 및 'background-position')을 스타일 시트의 동일한 위치에 설정하기 위한 단축 속성입니다.

```java
public String Background { get; set; }
```

### 반환 값

background 속성

### Property Value

스타일 시트의 동일한 위치에 개별 배경 속성을 설정하기 위한 단축 속성을 가져오거나 설정합니다.
