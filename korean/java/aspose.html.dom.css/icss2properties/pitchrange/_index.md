## ICSS2Properties.PitchRange property

평균 음높이의 변동을 지정합니다. 인간 음성의 인지된 음높이는 기본 주파수에 의해 결정되며 일반적으로 남성 음성은 120Hz, 여성 음성은 210Hz 값을 가집니다. 인간 언어는 다양한 억양과 음높이로 말해지며, 이러한 변동은 추가 의미와 강조를 전달합니다. 따라서 억양이 풍부한, 즉 강하게 억양된 목소리는 높은 음높이 범위를 나타냅니다. 이 속성은 이러한 변동이 발생하는 범위를 지정하며, 즉 기본 주파수가 평균 음높이에서 얼마나 벗어날 수 있는지를 정의합니다.

```java
public String PitchRange { get; set; }
```

### 반환 값

pitch-range 속성
