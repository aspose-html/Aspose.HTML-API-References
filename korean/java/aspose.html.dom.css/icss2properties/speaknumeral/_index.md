## ICSS2Properties.SpeakNumeral property

이 속성은 숫자가 어떻게 발음되는지를 제어합니다. 값은 다음과 같은 의미를 가집니다:

digits - 숫자를 개별 자리수로 발음합니다. 예를 들어 "237"은 "Two Three Seven"와 같이 발음됩니다. continuous - 숫자를 전체 숫자로 발음합니다. 예를 들어 "237"은 "Two hundred thirty seven"와 같이 발음됩니다. 단어 표현은 언어에 따라 다릅니다.

```java
public String SpeakNumeral { get; set; }
```

### 반환 값

speak-numeral 속성
