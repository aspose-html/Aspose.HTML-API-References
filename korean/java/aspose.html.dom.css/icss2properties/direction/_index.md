## ICSS2Properties.Direction property

이 속성은 블록의 기본 쓰기 방향과 임베딩 및 오버라이드 방향을 지정합니다(Unicode 양방향 알고리즘에 대한 ['unicode-bidi'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-unicode-bidi) 참고). 또한 [table](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html) 열 레이아웃 방향, 수평 [overflow](https://www.w3.org/TR/1998/REC-CSS2-19980512/visufx.html#overflow) 방향, 그리고 'text-align: justify'인 경우 블록 내 마지막 줄이 불완전할 때의 위치를 지정합니다.

```java
public String Direction { get; set; }
```

### 반환 값

direction 속성
