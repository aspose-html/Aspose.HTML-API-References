## ICSS2Properties.Volume property

Volume은 파형의 중간 볼륨을 나타냅니다. 즉, 볼륨이 50인 매우 억양이 풍부한 음성은 그보다 훨씬 높은 피크를 가질 수 있습니다. 전체 값은 예를 들어 물리적인 볼륨 컨트롤(0과 100 값을 비례적으로 증가시킴)을 사용해 인간이 편안하게 조절할 수 있도록 설계되었습니다; 이 속성은 동적 범위를 조정합니다.

값은 다음과 같은 의미를 가집니다:

'[number](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-number)' - '0'과 '100' 사이의 모든 숫자입니다. '0'은 최소 가청 볼륨 레벨을 나타내며 100은 최대 편안한 레벨에 해당합니다.'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - 백분율 값은 상속된 값에 상대적으로 계산되며, 이후 '0'에서 '100' 범위로 잘립니다.silent - 전혀 소리가 없습니다. 값 '0'은 'silent'와 동일한 의미가 아닙니다.x-soft - '0'과 동일합니다.soft - '25'와 동일합니다.medium - '50'와 동일합니다.loud - '75'와 동일합니다.x-loud - '100'와 동일합니다.

```java
public String Volume { get; set; }
```
