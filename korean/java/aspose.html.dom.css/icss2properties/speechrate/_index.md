## ICSS2Properties.SpeechRate property

이 속성은 말하기 속도를 지정합니다. 절대 및 상대 키워드 값이 모두 허용된다는 점에 유의하십시오( ['font-size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html#propdef-font-size)와 비교). 값은 다음과 같은 의미를 가집니다:

'[number](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-number)' - 말하기 속도를 분당 단어 수로 지정합니다. 이 수치는 언어에 따라 다소 차이가 있지만 음성 합성기에서 널리 지원됩니다.

x-slow - 분당 80단어와 동일합니다.

slow - 분당 120단어와 동일합니다.

medium - 분당 180 - 200 단어와 동일합니다.

fast - 분당 300 단어와 동일합니다.

x-fast - 분당 500 단어와 동일합니다.

faster - 현재 음성 속도에 분당 40 단어를 추가합니다.

slower - 현재 음성 속도에서 분당 40 단어를 빼습니다.

```java
public String SpeechRate { get; set; }
```

### 반환 값

speech-rate 속성
