## ICSS2Properties.Visibility property

['visibility'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visufx.html#propdef-visibility) 속성은 요소에 의해 생성된 박스가 렌더링되는지를 지정합니다. 보이지 않는 박스도 레이아웃에 영향을 미칩니다 (['display'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-display) 속성을 'none'으로 설정하면 박스 생성을 완전히 억제합니다). 값은 다음과 같은 의미를 가집니다:

visible - 생성된 박스가 보입니다. hidden - 생성된 박스가 보이지 않으며(완전히 투명), 그러나 레이아웃에 여전히 영향을 미칩니다. collapse - 표의 [dynamic row and column effects](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#dynamic-effects) 섹션을 참고하십시오. 행이나 열이 아닌 요소에 사용될 경우, 'collapse'는 'hidden'과 동일한 의미를 가집니다.

```java
public String Visibility { get; set; }
```

### 반환 값

visibility 속성
