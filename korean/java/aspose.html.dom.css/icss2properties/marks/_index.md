## ICSS2Properties.Marks property

고품질 인쇄에서는 마크가 종종 페이지 박스 외부에 추가됩니다. 이 속성은 교차 마크 또는 절단 마크 또는 두 가지 모두를 [page box](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#page-box) 가장자리 바로 외부에 렌더링할지 여부를 지정합니다.

절단 마크는 페이지를 자를 위치를 나타냅니다. 교차 마크(등록 마크 또는 레지스트레이션 마크라고도 함)는 시트를 정렬하는 데 사용됩니다.

마크는 절대 페이지 박스에서만 표시됩니다(['size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-size) 속성을 참조). 상대 페이지 박스에서는 페이지 박스가 대상에 맞춰 정렬되고 마크는 인쇄 가능한 영역 밖에 위치합니다.

교차 표시의 크기, 스타일 및 위치는 사용자 에이전트에 따라 달라집니다.

```java
public String Marks { get; set; }
```
