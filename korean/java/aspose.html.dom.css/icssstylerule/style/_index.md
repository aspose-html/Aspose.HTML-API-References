## ICSSStyleRule.Style property

읽기 전용 style 속성은 선언 블록에 대한 [`CSSStyleDeclaration`](../../icssstyledeclaration/) 인터페이스이며, [`CSSStyleRule`](../)의 것입니다.

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

style 속성은 스타일 규칙에 대한 CSSStyleDeclaration 객체를 반환해야 하며, 다음 속성을 포함합니다:

computed flag - Unset. declarations - 규칙에 선언된 선언들로, 지정된 순서대로. parent CSS rule - 컨텍스트 객체. owner node - Null.
