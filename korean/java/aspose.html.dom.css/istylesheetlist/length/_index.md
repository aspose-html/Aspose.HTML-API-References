## IStyleSheetList.Length property

length 속성은 컬렉션이 나타내는 CSS 스타일시트의 수를 반환해야 합니다. 유효한 자식 스타일시트 인덱스 범위는 0부터 length-1까지 포함합니다.

```java
public int Length { get; }
```

### Property Value

컬렉션에 포함된 항목 수를 나타내는 정수입니다.
