## IStyleSheetList indexer

item(index) 메서드는 컬렉션에서 지정된 인덱스의 [`CSS style sheet`](../../icssstylesheet/)을 반환해야 합니다. 컬렉션에 해당 인덱스의 객체가 없으면 메서드는 null을 반환해야 합니다.

```java
public ICSSStyleSheet this[int index] { get; }
```

### 반환 값

[`CSSStyleSheet`](../../icssstylesheet/) 객체, 또는 해당 인덱스에 존재하지 않으면 null.

### Property Value

반환될 컬렉션 내 항목의 인덱스를 나타내는 정수입니다.
