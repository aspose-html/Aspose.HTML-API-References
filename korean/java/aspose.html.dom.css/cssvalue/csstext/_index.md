## CSSValue.CSSText property

[`CSSValue`](../) 인터페이스의 cssText 속성은 현재 계산된 CSS 속성 값을 나타냅니다.

참고: 이 속성은 타입이 지정된 CSS 객체 모델을 만들려는 시도의 일부였습니다. 이 시도는 포기되었으며 대부분의 브라우저가 이를 구현하지 않습니다.

```java
public abstract String CSSText { get; set; }
```

### Property Value

현재 CSS 속성 값을 나타내는 DOMString.
