## IDocumentCSS.GetOverrideStyle method

이 메서드는 지정된 요소와 지정된 의사 요소에 대한 override 스타일 선언을 검색하는 데 사용됩니다.

```java
public ICSSStyleDeclaration GetOverrideStyle(Element elt, String pseudoElt)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| elt | 요소 | 스타일을 수정할 요소입니다. 이 매개변수는 null일 수 없습니다. |
| pseudoElt | String | 의사 요소이며, 없을 경우 null입니다. |

### 반환 값

오버라이드 스타일 선언입니다.
