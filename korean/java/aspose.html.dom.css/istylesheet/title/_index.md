## IStyleSheet.Title property

[`StyleSheet`](../) 인터페이스의 title 속성은 현재 스타일 시트의 권고 제목을 반환합니다.

title은 종종 [`ownerNode`](../ownernode/)에 지정됩니다.

```java
public String Title { get; }
```

### Property Value

parentStyleSheet 속성은 부모 [`CSS style sheet`](../../icssstylesheet/)를 반환해야 합니다.
