## IStyleSheet.Media property

[`StyleSheet`](../) 인터페이스의 media 속성은 스타일 정보의 대상 미디어를 지정합니다. 이는 읽기 전용이며 배열 형태의 [`MediaList`](../../imedialist/) 객체이며 deleteMedium()으로 제거하고 appendMedium()으로 추가할 수 있습니다.

```java
public IMediaList Media { get; }
```

### Property Value

media 속성은 CSS 스타일시트와 연결된 [`MediaList`](../../imedialist/) 객체를 반환해야 합니다.
