## IStyleSheet.Href property

[`StyleSheet`](../) 인터페이스의 href 속성은 스타일 시트의 위치를 반환합니다.

```java
public String Href { get; }
```

### Property Value

uri는 스타일 시트의 URI를 포함하는 문자열입니다.

## 비고

스타일 시트가 연결된 스타일 시트인 경우 해당 속성의 값은 그 위치입니다. 인라인 스타일 시트의 경우 이 속성의 값은 NULL입니다.

이 속성은 Firefox, Opera, Google Chrome 및 Safari에서는 읽기 전용이며, Internet Explorer에서는 읽기/쓰기 가능합니다.
