```java
public void DeleteRule(String key)
```

| Parameter | Type | 설명 |

| 키 | String | 삭제할 규칙을 설명하는 키입니다. 키는 0과 1 사이의 숫자로 해석되어야 하며, 그렇지 않으면 규칙이 무시됩니다. |
