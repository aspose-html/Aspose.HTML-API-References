## ICSSKeyframesRule.FindRule method

findRule 메서드는 전달된 키와 일치하는 규칙을 반환합니다. 해당 규칙이 없으면 null 값을 반환합니다.

```java
public ICSSKeyframeRule FindRule(String key)
```

| Parameter | Type | 설명 |
| --- | --- | --- |
| 키 | String | 찾을 규칙을 설명하는 키입니다. 키는 0과 1 사이의 숫자로 해석되어야 하며, 그렇지 않으면 규칙이 무시됩니다. |

### 반환 값

지정된 키프레임 선택자와 일치하는 마지막 선언된 [`CSSKeyframeRule`](../../icsskeyframerule/)을 반환합니다. 일치하는 규칙이 없으면 메서드는 아무 작업도 수행하지 않습니다.
