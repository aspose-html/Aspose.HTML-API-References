## RGBColor.Alpha property

이 Color 구조체의 알파 구성 요소 값을 가져옵니다.

```java
public CSSPrimitiveValue Alpha { get; }
```

### Property Value

이 Color의 알파 구성 요소 값.

## 비고

각 픽셀의 색상은 32비트 숫자로 표현됩니다: 알파, 빨강, 초록, 파랑 각각 8비트(ARGB). 알파 구성 요소는 색상의 투명도를 지정하며, 0은 완전 투명, 255는 완전 불투명합니다. 마찬가지로 A 값이 255이면 불투명한 색상이며, 1부터 254까지의 A 값은 반투명 색상을 나타냅니다. A 값이 255에 가까워질수록 색상은 더 불투명해집니다.
