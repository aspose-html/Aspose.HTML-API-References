## RGBColor.Red property

이 Color 구조체의 빨간색 구성 요소 값을 가져옵니다.

```java
public CSSPrimitiveValue Red { get; }
```

### Property Value

이 Color의 빨간색 구성 요소 값.

## 비고

각 픽셀의 색은 32비트 숫자로 표현됩니다: 알파, 빨강, 초록, 파랑(ARGB) 각각 8비트씩. 알파 구성 요소는 색상의 투명도를 지정합니다: 0은 완전 투명, 255는 완전 불투명합니다. 마찬가지로 알파 값이 255이면 불투명한 색이며, 1부터 254까지의 알파 값은 반투명 색을 나타냅니다. 알파 값이 255에 가까워질수록 색은 더 불투명해집니다.
