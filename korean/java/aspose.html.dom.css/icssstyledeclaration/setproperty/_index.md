## SetProperty(String, String) {#setproperty}

CSSStyleDeclaration.setProperty() 메서드 인터페이스는 이 선언 블록 내에서 기본 우선순위로 속성 값을 설정하는 데 사용됩니다. 기본 우선순위는 "important"가 아니며, 즉 String.Empty입니다.

```java
public void SetProperty(String propertyName, String value)
```

| Parameter | Type | 설명 |
| --- | --- | --- |
| propertyName | String | 수정할 CSS 속성 이름(하이픈 표기)을 나타내는 문자열입니다. |
| 값 | String | 새 속성 값을 포함하는 문자열입니다. 지정되지 않으면 빈 문자열로 처리됩니다. |

## SetProperty(String, String, String) {#setproperty_1}

CSSStyleDeclaration.setProperty() 메서드 인터페이스는 이 선언 블록 내에서 기본 우선순위로 속성 값을 설정하는 데 사용됩니다. 기본 우선순위는 "important"가 아니며, 즉 String.Empty입니다.

```java
public void SetProperty(String propertyName, String value, String priority)
```

| Parameter | Type | 설명 |
| --- | --- | --- |
| propertyName | String | 수정할 CSS 속성 이름(하이픈 표기)을 나타내는 문자열입니다. |
| 값 | String | 새 속성 값을 포함하는 문자열입니다. 지정되지 않으면 빈 문자열로 처리됩니다. |
| priority | String | "important" CSS 우선순위를 설정할 수 있는 문자열입니다. 지정되지 않으면 빈 문자열로 처리됩니다. 허용되는 값은 다음과 같습니다: 문자열 값 "important", 키워드 undefined 또는 빈 문자열 "". |
