## ICSSStyleDeclaration.GetPropertyPriority method

이 메서드는 선언 블록에서 명시적으로 설정된 CSS 속성의 우선순위(예: "important" 한정자)를 검색하는 데 사용됩니다.

```java
public String GetPropertyPriority(String propertyName)
```

| Parameter | Type | 설명 |
| --- | --- | --- |
| propertyName | String | property는 확인할 속성 이름을 나타내는 DOMString입니다. |

### 반환 값

priority는 존재하는 경우 우선순위(예: "important")를 나타내는 DOMString입니다. 존재하지 않으면 빈 문자열을 반환합니다.
