## ICSSStyleDeclaration.GetPropertyValue method

CSSStyleDeclaration.getPropertyValue() 메서드 인터페이스는 지정된 CSS 속성의 값을 포함하는 문자열을 반환합니다.

```java
public String GetPropertyValue(String propertyName)
```

| Parameter | Type | 설명 |
| --- | --- | --- |
| propertyName | String | propertyName은 확인할 속성 이름(하이픈 표기)을 나타내는 문자열입니다. |

### 반환 값

value는 속성 값을 포함하는 문자열입니다. 설정되지 않은 경우 빈 문자열을 반환합니다.
