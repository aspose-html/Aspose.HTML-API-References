## ICSSStyleDeclaration indexer

이 선언 블록에서 명시적으로 설정된 속성을 검색하는 데 사용됩니다. 이 메서드로 검색된 속성들의 순서는 설정된 순서와 일치할 필요가 없습니다. 이 메서드는 선언 블록의 모든 속성을 반복하는 데 사용할 수 있습니다.

```java
public String this[int index] { get; }
```

### 반환 값

propertyName은 지정된 인덱스에 있는 CSS 속성의 이름을 나타내는 문자열입니다.

### Property Value

index는 가져올 노드의 인덱스이며, 인덱스는 0부터 시작합니다.
