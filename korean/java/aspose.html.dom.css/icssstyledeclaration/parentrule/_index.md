## ICSSStyleDeclaration.ParentRule property

CSSStyleDeclaration.parentRule 읽기 전용 속성은 이 스타일 블록의 부모인 CSSRule을 반환합니다. 예를 들어 CSS 선택자를 위한 스타일을 나타내는 [`CSSStyleRule`](../../icssstylerule/)입니다.

```java
public ICSSRule ParentRule { get; }
```

### Property Value

이 선언 블록을 포함하는 CSS 규칙이며, 이 [`CSSStyleDeclaration`](../)이 [`CSSRule`](../../icssrule/)에 연결되지 않은 경우 null을 반환합니다.
