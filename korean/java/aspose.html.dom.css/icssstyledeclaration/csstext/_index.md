## ICSSStyleDeclaration.CSSText property

중괄호를 제외한 선언 블록의 구문 분석 가능한 텍스트 표현입니다. 이 속성을 설정하면 새로운 값을 구문 분석하고 선언 블록의 모든 속성을 재설정하며, 속성의 제거 또는 추가도 포함됩니다.

```java
public String CSSText { get; set; }
```

### Property Value

이 속성을 설정하면 인라인 스타일이 변경됩니다. 계산된 선언 블록의 텍스트 표현이 필요하면 JSON.Stringify()를 사용하여 얻을 수 있습니다.
