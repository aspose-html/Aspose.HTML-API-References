## ICSSImportRule.Href property

CSSImportRule 인터페이스의 읽기 전용 href 속성은 @import at-rule에 지정된 URL을 반환합니다.

해결된 URL은 연관된 스타일시트의 href 속성이 됩니다.

```java
public String Href { get; }
```

### Property Value

@import at-rule에 의해 지정된 연관된 스타일시트의 URL을 반환합니다.
