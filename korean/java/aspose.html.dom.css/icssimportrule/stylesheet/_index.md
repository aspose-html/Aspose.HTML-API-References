## ICSSImportRule.StyleSheet property

이 규칙이 가리키는 스타일 시트가 로드된 경우. 스타일 시트가 아직 로드되지 않았거나 로드되지 않을 경우(예: 사용자 에이전트가 지원하지 않는 미디어 유형의 스타일 시트인 경우) 이 속성의 값은 null입니다.

```java
public ICSSStyleSheet StyleSheet { get; }
```

### Property Value

`@import` at-rule에 의해 지정된 CSS 스타일시트를 반환합니다. 이는 [`CSSStyleSheet`](../../icssstylesheet/) 객체 형태가 됩니다.
