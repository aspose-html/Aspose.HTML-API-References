## IMediaList indexer

item(index) 메서드는 인덱스로 지정된 미디어 쿼리 컬렉션에서 해당 미디어 쿼리의 직렬화를 반환해야 하며, 인덱스가 컬렉션의 미디어 쿼리 수보다 크거나 같으면 null을 반환합니다.

```java
public String this[int index] { get; }
```

### 반환 값

[`MediaList`](../) 내부의 미디어 쿼리 인덱스 값을 사용하여 미디어 쿼리를 텍스트 문자열로 반환합니다.

### Property Value

반환될 컬렉션 내 항목의 인덱스를 나타내는 정수입니다.
