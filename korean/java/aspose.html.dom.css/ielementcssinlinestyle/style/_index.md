## IElementCSSInlineStyle.Style property

style 속성은 계산된 플래그가 설정되지 않고, 상위 CSS 규칙이 null이며, 소유 노드가 컨텍스트 객체인 CSS 선언 블록 객체를 반환해야 합니다.

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

노드에 연결된 CSS 선언 블록을 반환하거나, 연결된 CSS 선언 블록이 없으면 null을 반환합니다.
