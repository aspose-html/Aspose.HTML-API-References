## CSSValueList indexer

CSSValueList 인터페이스의 item() 메서드는 순서 인덱스로 CSSValue를 검색하는 데 사용됩니다.

이 컬렉션의 순서는 CSS 스타일 속성의 값 순서를 나타냅니다. 인덱스가 리스트의 값 개수보다 크거나 같으면 이 메서드는 null을 반환합니다.

```java
public CSSValue this[int index] { get; }
```

### 반환 값

CSSValueList의 인덱스 위치에 있는 CSSValue 객체이며, 유효한 인덱스가 아니면 null을 반환합니다.

### Property Value

컬렉션 내 CSS 값의 인덱스를 나타내는 부호 없는 긴 정수.
