## CSSValueList.Length property

CSSValueList 인터페이스의 읽기 전용 length 속성은 리스트에 있는 CSSValue의 수를 나타냅니다. 인덱스의 유효값 범위는 0부터 length-1까지 포함합니다.

```java
public int Length { get; }
```

### Property Value

현재 인스턴스에 포함된 CSSValue 수를 나타내는 부호 없는 정수형(long)입니다.
