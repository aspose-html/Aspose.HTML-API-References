## ICSSKeyframeRule.KeyText property

CSSKeyframeRule 인터페이스의 keyText 속성은 키프레임 선택자를 백분율 값의 쉼표 구분 목록으로 나타냅니다. from 및 to 키워드는 각각 0%와 100%에 매핑됩니다.

```java
public String KeyText { get; }
```

### Property Value

키프레임 선택자를 백분율 값의 쉼표 구분 목록으로 반환합니다.
