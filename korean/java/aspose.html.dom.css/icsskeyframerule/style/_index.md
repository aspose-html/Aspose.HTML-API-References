## ICSSKeyframeRule.Style property

The read-only CSSKeyframeRule.style 속성은 [`CSSStyleDeclaration`](../../icssstyledeclaration/) 인터페이스이며, 이는 [`CSSKeyframeRule`](../)의 선언 블록에 해당합니다.

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

`[`CSSStyleDeclaration`](../../icssstyledeclaration/)` 객체이며, 다음 속성을 포함합니다:

computed flag - Unset. declarations - 규칙에 선언된 선언들로, 지정된 순서대로이며, 축약 속성은 긴 형태로 확장됩니다. parent CSS rule - this.owner에 대한 별칭인 컨텍스트 객체 - Null.
