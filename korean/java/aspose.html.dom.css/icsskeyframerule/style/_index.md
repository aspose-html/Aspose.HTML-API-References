public ICSSStyleDeclaration Style { get; }

### Property Value

다음 속성을 가진 [`CSSStyleDeclaration`](../../icssstyledeclaration/) 객체:

computed flag - Unset. declarations - 규칙에 선언된 선언문으로, 지정된 순서대로이며, 축약 속성은 장식 속성으로 확장됩니다. parent CSS rule - this.owner의 별칭인 컨텍스트 객체 - Null.
