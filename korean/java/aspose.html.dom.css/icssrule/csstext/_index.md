## ICSSRule.CSSText property

[`CSSRule`](../) 인터페이스의 cssText 속성은 [`CSSStyleSheet`](../../icssstylesheet/) 스타일 규칙의 실제 텍스트를 반환합니다.

참고: 이 속성을 element-style CSSStyleDeclaration.cssText와 혼동하지 마세요.

```java
public String CSSText { get; set; }
```

### Property Value

CSS 규칙의 직렬화를 반환합니다. cssText 속성을 설정해도 아무 동작도 하지 않아야 합니다.
