## ICSSRule.Type property

규칙의 유형은 [CSSOM # dom-cssrule-type](https://drafts.csswg.org/cssom/#dom-cssrule-type)에서 정의된 바와 같습니다. 바인딩 전용 캐스팅 메서드를 사용하여 CSSRule 인터페이스의 인스턴스를 해당 유형이 암시하는 특정 파생 인터페이스로 다운캐스트할 수 있다고 기대합니다.

```java
public short Type { get; }
```

### Property Value

특정 유형의 규칙과 연관된 음수가 아닌 정수입니다. 이 값은 규칙이 생성될 때 초기화되며 변경할 수 없습니다.
