## ICSSStyleSheet.CSSRules property

읽기 전용 CSSStyleSheet 속성인 cssRules는 스타일시트를 구성하는 모든 CSS 규칙의 실시간 최신 목록을 제공하는 라이브 [`CSSRuleList`](../../icssrulelist/)를 반환합니다. 목록의 각 항목은 단일 규칙을 정의하는 [`CSSRule`](../../icssrule/)입니다.

```java
public ICSSRuleList CSSRules { get; }
```

### Property Value

스타일시트를 구성하는 모든 CSS 규칙을 포함하는 실시간 업데이트되는 [`CSSRuleList`](../../icssrulelist/)입니다. 규칙 목록의 각 항목은 스타일시트를 구성하는 하나의 규칙을 설명하는 [`CSSRule`](../../icssrule/) 객체입니다.
