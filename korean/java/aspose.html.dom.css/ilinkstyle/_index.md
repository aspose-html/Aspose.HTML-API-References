## ILinkStyle interface

LinkStyle 인터페이스는 스타일시트를 문서에 연결하는 노드로부터 검색할 수 있는 메커니즘을 제공합니다. 연결 노드(HTMLLinkElement 등)의 인스턴스에 바인딩 전용 캐스팅 메서드를 사용하여 LinkStyle 인터페이스의 인스턴스를 얻을 수 있습니다.

DOM Level 2의 HTMLStyleElement 또는 ProcessingInstruction).

또한 다음을 참조하십시오: [CSS Object Model (CSSOM) # ](https://www.w3.org/TR/cssom-1/#the-linkstyle-interface)[LinkStyle](https://www.w3.org/TR/cssom-1/#the-linkstyle-interface).
