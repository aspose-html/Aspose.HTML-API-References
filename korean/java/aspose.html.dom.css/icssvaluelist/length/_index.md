## ICSSValueList.Length property

CSSValueList 인터페이스의 읽기 전용 length 속성은 리스트에 있는 CSSValue의 수를 나타냅니다. 인덱스의 유효값 범위는 0부터 length-1까지 포함합니다.

```java
public int Length { get; }
```

### Property Value

CSSValue 개수를 나타내는 부호 없는 정수(long)입니다.

## 비고

이 기능은 원래 [DOM Style Level 2](https://www.w3.org/TR/DOM-Level-2-Style) 사양에 정의되었지만, 그 이후 어떤 표준화 작업에서도 제외되었습니다.

현재 표준 트랙에 포함된 최신이지만 호환되지 않는 [CSS Typed Object Model API](https://developer.mozilla.org/en-US/docs/Web/API/CSS_Typed_OM_API)로 대체되었습니다.
