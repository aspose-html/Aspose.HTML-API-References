## IDocumentStyle interface

DocumentStyle 인터페이스는 문서에 포함된 스타일시트를 검색할 수 있는 메커니즘을 제공합니다. Document 인터페이스의 인스턴스에 바인딩 전용 캐스팅 메서드를 사용하여 DocumentStyle 인터페이스의 인스턴스를 얻을 수 있다고 기대합니다.

또한 [Document Object Model (DOM) Level 2 Style Specification](http://www.w3.org/TR/2000/REC-DOM-Level-2-Style-20001113)을 참조하십시오.

```java
public interface IDocumentStyle
```
