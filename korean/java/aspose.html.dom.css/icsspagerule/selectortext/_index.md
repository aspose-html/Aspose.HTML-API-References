## ICSSPageRule.SelectorText property

`[`CSSPageRule`](../)` 인터페이스의 selectorText 속성은 `[`CSSPageRule`](../)`와 연결된 선택자를 가져오고 설정합니다.

```java
public String SelectorText { get; set; }
```

### Property Value

selectorText 속성을 가져올 때는 연결된 CSS 페이지 선택자 목록을 직렬화한 결과를 반환해야 합니다.
