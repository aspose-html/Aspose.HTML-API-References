## CSSEngineMode enumeration

CSSEngine 모드를 지정합니다. 값은 다음과 같은 의미를 가집니다:

default - CSS 파서는 w3c 권고에 따라 작동하며 사용자 정의 확장을 지원하지 않습니다. not-strict - 문서화되지 않은 모든 속성이 파싱되며 접근할 수 있습니다.

```java
[Flags]
public enum CSSEngineMode
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Default | `0` | CSS 파서는 w3c 권고에 따라 작동하며 사용자 정의 확장을 지원하지 않습니다. |
| NotStrict | `1` | CSS 파서는 비엄격 모드에서 작동합니다. 문서화되지 않은 모든 속성이 파싱되며 접근할 수 있습니다. |
