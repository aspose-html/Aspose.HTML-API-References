CSSGroupingRule 인터페이스의 cssRules 속성은 [`CSSRule`](../../icssrule/) 객체들의 컬렉션을 포함하는 [`CSSRuleList`](../../icssrulelist/)를 반환합니다.

```java
public ICSSRuleList CSSRules { get; }
```

### Property Value

cssRules 속성은 하위 CSS 규칙에 대한 [`CSSRuleList`](../../icssrulelist/) 객체를 반환해야 합니다.
