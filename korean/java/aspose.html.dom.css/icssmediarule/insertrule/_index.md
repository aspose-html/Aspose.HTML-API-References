## ICSSMediaRule.InsertRule method

CSSGroupingRule 인터페이스의 insertRule() 메서드는 CSS 규칙 목록에 새 CSS 규칙을 추가합니다.

```java
public long InsertRule(String rule, long index)
```

| Parameter | Type | 설명 |
| --- | --- | --- |
| 규칙 | String | 미디어 규칙을 CSSOMString으로 표현합니다. |
| index | Int64 | 규칙을 삽입할 선택적 인덱스이며, 기본값은 0입니다. |

### 반환 값

insertRule(rule, index) 메서드는 지정된 인덱스에서 하위 CSS 규칙에 CSS 규칙을 삽입한 결과를 반환합니다.
