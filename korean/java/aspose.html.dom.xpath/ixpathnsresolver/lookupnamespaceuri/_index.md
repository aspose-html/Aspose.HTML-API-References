## IXPathNSResolver.LookupNamespaceURI method

주어진 패키지 접두사와 연결된 package URI를 조회합니다. XPath 평가자는 `null` 또는 빈 인수를 사용해서는 안 되며, 이렇게 할 경우 결과는 정의되지 않습니다.

```java
public String LookupNamespaceURI(String prefix)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| 접두사 | String | 찾을 접두사입니다. |

### 반환 값

연결된 패키지 URI를 반환하며, 찾지 못한 경우 `null`을 반환합니다.
