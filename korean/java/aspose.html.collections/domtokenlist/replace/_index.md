## DOMTokenList.Replace method

기존 토큰을 새 토큰으로 교체합니다. 첫 번째 토큰이 존재하지 않으면 아무 작업도 수행하지 않습니다.

```java
public bool Replace(String token, String newToken)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| 토큰 | String | 교체하려는 토큰. |
| newToken | String | 기존 토큰을 교체할 토큰. |

### 반환 값

Boolean `true`인 경우 토큰이 찾아서 교체되었으며, 그렇지 않으면 `false`.
