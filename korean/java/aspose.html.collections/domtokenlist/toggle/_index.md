## Toggle(String, bool) {#toggle_1}

토큰이 리스트에 존재하면 제거하고, 존재하지 않으면 리스트에 추가합니다.

```java
public bool Toggle(String token, bool force)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| 토큰 | String | 토글하려는 토큰. |
| force | Boolean | 포함될 경우 토글을 단방향 작업으로 전환하는 Boolean. false로 설정하면 토큰이 제거만 되고 추가되지 않으며, true로 설정하면 토큰이 추가만 되고 제거되지 않습니다. |

### 반환 값

호출 후 토큰이 리스트에 있는지 여부를 나타내는 Boolean.
