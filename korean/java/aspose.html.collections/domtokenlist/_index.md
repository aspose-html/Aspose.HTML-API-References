## DOMTokenList class

DOMTokenList 클래스는 공백으로 구분된 토큰 집합을 나타냅니다. JavaScript Array 객체와 마찬가지로 0부터 인덱싱됩니다. DOMTokenList는 항상 대소문자를 구분합니다.

public class DOMTokenList : DOMObject, IEnumerable<String>
