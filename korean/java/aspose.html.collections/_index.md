The **com.aspose.html.collections** 패키지는 노드와 요소를 표현, 저장 및 조작하는 클래스로 구성됩니다.

## 클래스

| 클래스 | 설명 |
| --- | --- |
| [DOMTokenList](./domtokenlist/) | DOMTokenList 클래스는 공백으로 구분된 토큰 집합을 나타냅니다. JavaScript Array 객체와 마찬가지로 0부터 인덱싱됩니다. DOMTokenList는 항상 대소문자를 구분합니다. |
| [HTMLCollection](./htmlcollection/) | The [`HTMLCollection`](../com.aspose.html.collections/htmlcollection/)은 일반적인 [`Element`](../com.aspose.html.dom/element/) 컬렉션을 나타냅니다. |
| [NamedNodeMap](./namednodemap/) | 이름으로 접근할 수 있는 속성 컬렉션을 나타냅니다. |
| [NodeList](./nodelist/) | NodeList는 컬렉션이 어떻게 구현되는지 정의하거나 제한하지 않고, 노드의 순서가 있는 컬렉션에 대한 추상화를 제공합니다. |
