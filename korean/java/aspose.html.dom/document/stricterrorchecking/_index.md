## Document.StrictErrorChecking property

오류 검사가 적용되는지 여부를 지정하는 속성입니다. false로 설정하면 구현은 일반적으로 DOM 작업에 정의된 모든 가능한 오류 사례를 테스트하지 않을 자유가 있으며, DOM 작업 중 DOMException을 발생시키지 않거나 Document.normalizeDocument()를 사용할 때 오류를 보고하지 않을 수 있습니다. 오류가 발생할 경우 동작은 정의되지 않습니다. 이 속성은 기본값이 true입니다.

```java
public bool StrictErrorChecking { get; set; }
```

### Property Value

엄격한 오류 검사가 적용되면 `true`, 그렇지 않으면 `false`.
