## Document.CreateAttributeNS method

Document.createAttribute() 메서드는 새로운 속성 노드를 생성하고 반환합니다. 생성된 객체는 [Attr](T:com.aspose.html.dom.Attr) 인터페이스를 구현하는 노드입니다. DOM은 이 방식으로 특정 요소에 추가할 수 있는 속성 종류를 강제하지 않습니다.

```java
public Attr CreateAttributeNS(String packageURI, String qualifiedName)
```

| Parameter | Type | 설명 |
| --- | --- | --- |
| packageURI | String | 속성의 패키지 URI. |
| qualifiedName | String | name은 속성의 이름을 포함하는 문자열입니다. |
