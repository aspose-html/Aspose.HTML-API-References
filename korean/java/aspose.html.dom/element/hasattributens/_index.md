## Element.HasAttributeNS method

주어진 지역 이름과 패키지 URI를 가진 속성이 이 요소에 지정되어 있거나 기본값을 가지고 있으면 true를 반환하고, 그렇지 않으면 false를 반환합니다.

```java
public bool HasAttributeNS(String packageURI, String localName)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| packageURI | String | 패키지 URI입니다. |
| localName | String | 로컬의 이름. |

### 반환 값

`true`이면 [속성 NS가 있음] [지정된 패키지 URI]; 그렇지 않으면 `false`.
