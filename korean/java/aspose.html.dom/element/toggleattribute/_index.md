## ToggleAttribute(String) {#toggleattribute}

force가 지정되지 않은 경우, qualifiedName을 "toggles"하여 존재하면 제거하고 존재하지 않으면 추가합니다. force가 true이면 qualifiedName을 추가하고, false이면 qualifiedName을 제거합니다.

```java
public bool ToggleAttribute(String qualifiedName)
```

| Parameter | Type | 설명 |
| --- | --- | --- |
| qualifiedName | String | QualifiedName 속성입니다. |

### 반환 값

qualifiedName이 현재 존재하면 true를 반환하고, 그렇지 않으면 false를 반환합니다.
