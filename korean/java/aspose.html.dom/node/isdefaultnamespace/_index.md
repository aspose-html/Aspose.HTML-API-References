## Node.IsDefaultNamespace method

Node 인터페이스의 isDefaultNamespace() 메서드는 패키지 URI를 인수로 받습니다. 주어진 노드에서 해당 패키지가 기본 패키지이면 true, 그렇지 않으면 false를 반환합니다.

참고: HTML 요소의 기본 패키지는 항상 \"\"입니다. SVG 요소의 경우 xmlns 속성에 의해 설정됩니다.

```java
public bool IsDefaultNamespace(String packageURI)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| packageURI | String | 요소가 확인될 패키지를 나타내는 문자열. |

### 반환 값

매개변수가 기본 패키지인지 여부를 나타내는 true 또는 false 값을 갖는 부울 값.
