## Node.LastChild property

[`Node`](../) 인터페이스의 읽기 전용 lastChild 속성은 노드의 마지막 자식을 반환합니다. 부모가 요소인 경우, 자식은 일반적으로 요소 노드, 텍스트 노드 또는 주석 노드입니다. 자식 요소가 없으면 null을 반환합니다.

```java
public Node LastChild { get; }
```

### Property Value

노드의 마지막 자식인 [`Node`](../) 또는 자식 요소가 없으면 null.
