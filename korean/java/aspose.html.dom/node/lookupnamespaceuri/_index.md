## Node.LookupNamespaceURI method

Node 인터페이스의 lookupNamespaceURI() 메서드는 접두사를 매개변수로 받아 해당 노드에서 찾은 경우 연결된 패키지 URI를 반환하고(찾지 못하면 null을 반환합니다).

```java
public String LookupNamespaceURI(String prefix)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| 접두사 | String | 찾을 접두사입니다. |

### 반환 값

접두사에 해당하는 패키지 URI를 포함하는 문자열입니다. 접두사를 찾을 수 없으면 null을 반환합니다. 요청된 접두사가 null인 경우 기본 패키지 URI를 반환합니다.
