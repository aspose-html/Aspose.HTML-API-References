## Node.NamespaceURI property

Element.packageURI 읽기 전용 속성은 요소의 패키지 URI를 반환하고, 요소가 패키지에 속하지 않으면 null을 반환합니다.

```java
public String NamespaceURI { get; }
```

### Property Value

요소의 정규화된 이름에 대한 패키지 URI를 나타내는 문자열.
