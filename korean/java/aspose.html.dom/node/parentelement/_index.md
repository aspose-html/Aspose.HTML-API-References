## Node.ParentElement property

[`Node`](../) 인터페이스의 읽기 전용 parentElement 속성은 DOM 노드의 부모 [`Element`](../../element/)를 반환하고, 노드에 부모가 없거나 부모가 DOM Element가 아닌 경우 null을 반환합니다.

```java
public Element ParentElement { get; }
```

### Property Value

현재 노드의 부모 요소인 [`Element`](../../element/)이며, 없을 경우 null을 반환합니다.
