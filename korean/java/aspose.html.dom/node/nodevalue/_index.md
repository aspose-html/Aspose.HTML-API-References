## Node.NodeValue property

[`Node `](../) 인터페이스의 nodeValue 속성은 현재 노드의 값을 반환하거나 설정합니다.

```java
public String NodeValue { get; set; }
```

### Property Value

현재 노드의 값이 있는 경우 이를 포함하는 문자열입니다. 문서 자체의 경우 nodeValue는 null을 반환합니다. 텍스트, 주석 및 CDATA 노드의 경우 nodeValue는 노드의 내용을 반환합니다. 속성 노드의 경우 해당 속성의 값이 반환됩니다.
