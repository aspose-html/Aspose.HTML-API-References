## Node.FirstChild property

[`Node`](../) 인터페이스의 읽기 전용 firstChild 속성은 트리에서 노드의 첫 번째 자식을 반환하며, 자식이 없으면 null을 반환합니다.

노드가 Document인 경우, 이 속성은 직접 자식 목록에서 첫 번째 노드를 반환합니다.

```java
public Node FirstChild { get; }
```

### Property Value

[`Node`](../) 또는 없을 경우 null.
