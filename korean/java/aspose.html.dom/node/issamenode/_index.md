## Node.IsSameNode method

Node 인터페이스의 isSameNode() 메서드는 === 엄격 동등 연산자의 레거시 별칭입니다. 즉, 두 노드가 동일한지(다시 말해, 같은 객체를 참조하는지) 테스트합니다.

참고: isSameNode()를 사용할 필요가 없으며, 대신 === 엄격 동등 연산자를 사용하십시오.

```java
public bool IsSameNode(Node otherNode)
```

| Parameter | Type | 설명 |
| --- | --- | --- |
| otherNode | Node | 비교 대상 Node. |

### 반환 값

두 노드가 엄격히 동일하면 true, 그렇지 않으면 false인 부울 값.
