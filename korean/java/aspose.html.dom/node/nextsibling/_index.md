## Node.NextSibling property

읽기 전용 nextSibling 속성은 [`Node`](../) 인터페이스에서 지정된 노드 바로 다음에 있는 노드를 반환하며, 부모의 [`childNodes`](../childnodes/) 중 마지막 자식인 경우 null을 반환합니다.

```java
public Node NextSibling { get; }
```

### Property Value

현재 노드의 다음 형제 노드를 나타내는 [`Node`](../)이며, 없을 경우 null을 반환합니다.
