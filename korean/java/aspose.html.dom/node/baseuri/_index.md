## Node.BaseURI property

Node 인터페이스의 읽기 전용 baseURI 속성은 해당 노드를 포함하는 문서의 절대 기본 URL을 반환합니다.

브라우저가 절대 URL을 얻어야 할 때, 예를 들어 HTML img 요소의 src 속성이나 SVG의 xlink:href 또는 href 속성을 처리할 때, 기본 URL은 상대 URL을 해결하는 데 사용됩니다.

```java
public String BaseURI { get; }
```

### Property Value

baseURI getter는 이 노드 문서의 문서 기본 URL을 직렬화된 형태로 반환합니다.
