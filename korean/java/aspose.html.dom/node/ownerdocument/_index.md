## Node.OwnerDocument property

Node 인터페이스의 읽기 전용 ownerDocument 속성은 해당 노드의 최상위 문서 객체를 반환합니다.

```java
public Document OwnerDocument { get; }
```

### Property Value

모든 자식 노드가 생성되는 최상위 객체인 [`Document`](../../document/)입니다.

이 속성이 자체가 문서인 노드에 사용될 경우, 값은 null입니다.
