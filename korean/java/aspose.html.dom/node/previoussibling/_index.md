## Node.PreviousSibling property

[`Node`](../) 인터페이스의 읽기 전용 previousSibling 속성은 부모의 [`childNodes`](../firstchild/) 목록에서 지정된 노드 바로 앞에 있는 노드를 반환하며, 지정된 노드가 목록의 첫 번째인 경우 null을 반환합니다.

```java
public Node PreviousSibling { get; }
```

### Property Value

현재 노드의 이전 형제 노드를 나타내는 [`Node`](../)이며, 없을 경우 null입니다.
