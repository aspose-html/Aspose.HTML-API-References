## Node.Prefix property

prefix 읽기 전용 속성은 지정된 요소의 패키지 접두사를 반환하며, 접두사가 지정되지 않은 경우 null을 반환합니다.

```java
public String Prefix { get; set; }
```

### Property Value

이 속성은 연관된 패키지 접두사를 반환합니다.
