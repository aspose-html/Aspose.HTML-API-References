## Node.LocalName property

이 노드의 정규화된 이름 중 로컬 부분을 반환합니다. [`ELEMENT_NODE`](../element_node/) 및 [`ATTRIBUTE_NODE`](../attribute_node/)가 아닌 모든 유형의 노드와 [`Document.createElement()`](../../document/createelement/)와 같은 DOM Level 1 메서드로 생성된 노드의 경우 항상 null입니다.

```java
public String LocalName { get; }
```

### Property Value

요소의 정규화된 이름 중 로컬 부분을 나타내는 문자열.
