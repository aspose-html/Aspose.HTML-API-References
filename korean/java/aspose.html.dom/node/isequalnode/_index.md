## Node.IsEqualNode method

`[`Node`](../)` 인터페이스의 isEqualNode() 메서드는 두 노드가 동일한지 테스트합니다. 두 노드는 같은 유형과 정의된 특성(요소의 경우 ID, 자식 수 등)을 가지고 속성이 일치하면 동일합니다. 일치해야 하는 구체적인 데이터 포인트는 노드 유형에 따라 달라집니다.

```java
public bool IsEqualNode(Node otherNode)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| otherNode | Node | 동등성을 비교할 [`Node`](../) |

### 반환 값

두 노드가 동일하면 true, 그렇지 않으면 false인 부울 값입니다. otherNode가 null이면 isEqualNode()는 항상 false를 반환합니다.
