## Text.IsElementContentWhitespace property

이 텍스트 노드가 요소 내용 공백을 포함하는지 여부를 반환합니다. 종종 무시 가능한 공백이라고 부릅니다.

```java
public bool IsElementContentWhitespace { get; }
```

### Property Value

`true`이면 이 인스턴스가 요소 내용 공백이며, 그렇지 않으면 `false`입니다.
