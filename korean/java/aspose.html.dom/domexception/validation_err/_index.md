## DOMException.VALIDATION_ERR field

insertBefore 또는 removeChild와 같은 메서드 호출이 \"partial validity\"에 대해 노드를 무효화시킬 경우, 이 예외가 발생하고 작업이 수행되지 않습니다. 이 코드는 [DOM Level 3 Validation]에 사용됩니다. 자세한 내용은 이 사양을 참조하십시오.

```java
public const ushort VALIDATION_ERR;
```
