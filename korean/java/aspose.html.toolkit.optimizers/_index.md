이 **com.aspose.html.toolkit.optimizers** 패키지는 SVG 문서를 최적화하기 위한 클래스를 포함합니다. 최적화 과정은 사용되지 않거나 보이지 않는 요소와 해당 속성을 제거하고, 그룹을 병합하며, 경로 세그먼트의 크기를 줄이는 작업을 포함합니다.

## 클래스

| 클래스 | 설명 |
| --- | --- |
| [SVGOptimizationOptions](./svgoptimizationoptions/) | SVGOptimizationOptions는 SVG 문서를 최적화하기 위한 옵션을 저장하는 클래스입니다. |
| [SVGOptimizer](./svgoptimizer/) | SVGOptimizer는 SVG 문서를 최적화하도록 설계된 정적 클래스입니다. 최적화란 사용되지 않거나 보이지 않는 요소와 해당 속성을 제거하고, 그룹을 병합하며, 경로 세그먼트의 크기를 줄이는 것을 의미합니다. |
| [SVGPathOptimizationOptions](./svgpathoptimizationoptions/) | SVGPathOptimizationOptions는 SVG 경로 요소의 세그먼트를 최적화하기 위한 옵션을 저장하는 클래스입니다. |
