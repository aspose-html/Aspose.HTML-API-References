HTML뿐만 아니라 이 API는 EPUB 및 MHTML을 로드하는 기능도 제공합니다. Aspose API는 파일 형식 간 변환 기능으로 유명하며, 이 API는 HTML 파일을 로드하고 PDF, XPS 및 JPEG, PNG, BMP, TIFF를 포함한 래스터 이미지 형식으로 출력 렌더링하는 기능도 제공합니다. |
