## ITreeWalker.NextNode method

TreeWalker를 현재 노드에 대한 문서 순서상의 다음 보이는 노드로 이동하고 새 노드를 반환합니다. 현재 노드에 다음 노드가 없거나 nextNode 검색이 TreeWalker의 루트 노드에서 위로 이동하려 할 경우 null을 반환하고 현재 노드를 유지합니다.

```java
public Node NextNode()
```

### 반환 값

새 노드, 또는 현재 노드에 TreeWalker의 논리적 뷰에서 다음 노드가 없을 경우 null.
