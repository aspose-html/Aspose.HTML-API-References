## ITraversal.WhatToShow property

이 속성은 반복자를 통해 표시되는 노드 유형을 결정합니다. 사용 가능한 상수 집합은 NodeFilter 인터페이스에 정의되어 있습니다. whatToShow에 의해 허용되지 않는 노드는 건너뛰지만, 해당 자식 노드는 여전히 고려될 수 있습니다. 이 건너뛰기는 필터가 있는 경우 필터보다 우선합니다.
