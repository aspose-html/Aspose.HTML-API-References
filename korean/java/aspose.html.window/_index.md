이 **com.aspose.html.window** 패키지는 DOM 문서를 포함하는 창을 나타내는 window 객체와 관련됩니다. 활성 문서 주소와 탐색 기록과 관련된 클래스와 인터페이스를 포함합니다.

## 클래스

| 클래스 | 설명 |
| --- | --- |
| [Location](./location/) | Location 객체는 해당 Document의 탐색 컨텍스트에서 활성 문서 주소를 나타내며, 히스토리 객체에 항목을 추가하거나 교체하여 탐색 컨텍스트 세션 기록의 현재 항목을 변경할 수 있게 합니다. |
| [MediaQueryList](./mediaquerylist/) | MediaQueryList 객체는 문서에 적용된 미디어 쿼리 정보를 저장하며, 문서 상태에 대한 즉시 및 이벤트 기반 매칭을 모두 지원합니다. CSSOM View Module 사양을 확인하십시오: [https://www.w3.org/TR/cssom-view/#the-mediaquerylist-interface](https://www.w3.org/TR/cssom-view/#the-mediaquerylist-interface) |

| [IWindowTimers](./iwindowtimers/) | 작성자가 타이머 기반 콜백을 예약하도록 허용합니다. |
