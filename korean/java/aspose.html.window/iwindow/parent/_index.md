## IWindow.Parent property

탐색 컨텍스트 b에 있는 Document의 Window 객체에 대한 parent IDL 속성은, 존재하는 경우(즉, b가 하위 탐색 컨텍스트인 경우) 상위 탐색 컨텍스트의 WindowProxy 객체를 반환하고, 그렇지 않은 경우(즉, 최상위 탐색 컨텍스트이거나 분리된 중첩 탐색 컨텍스트인 경우) b 자체의 탐색 컨텍스트에 대한 WindowProxy 객체를 반환합니다.
