## IWindow.MatchMedia method

새 MediaQueryList 객체를 반환합니다. 이 객체는 문서가 미디어 쿼리 문자열과 일치하는지 여부를 판단하고, 일치하거나 일치하지 않게 될 때를 감시하는 데 사용할 수 있습니다. CSSOM View Module 사양을 참조하십시오: [https://www.w3.org/TR/cssom-view/#extensions-to-the-window-interface](https://www.w3.org/TR/cssom-view/#extensions-to-the-window-interface)

```java
public MediaQueryList MatchMedia(String query)
```

| Parameter | Type | 설명 |
| --- | --- | --- |
| query | String | 미디어 쿼리를 포함하는 문자열입니다; 자세한 내용은 [https://drafts.csswg.org/mediaqueries/](https://drafts.csswg.org/mediaqueries/)를 참조하십시오. |

### 반환 값

MediaQueryList 객체
