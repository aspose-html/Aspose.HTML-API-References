## IWindow.Top property

Document의 Window 객체에 있는 top IDL 속성은 브라우징 컨텍스트 b에서 최상위 브라우징 컨텍스트의 WindowProxy 객체를 반환해야 합니다(해당 컨텍스트가 자체가 최상위 브라우징 컨텍스트인 경우 자신의 WindowProxy 객체), 존재한다면, 그렇지 않으면 자체 WindowProxy 객체를 반환합니다(예: 분리된 중첩 브라우징 컨텍스트인 경우).

```java
public IWindow Top { get; }
```
