## IWindow.Top property

브라우징 컨텍스트 b에 있는 Document의 Window 객체에 대한 top IDL 속성은 해당 최상위 브라우징 컨텍스트의 WindowProxy 객체를 반환해야 합니다(최상위 브라우징 컨텍스트 자체인 경우 자신의 WindowProxy 객체가 됩니다), 존재한다면 그 객체를, 그렇지 않으면 자체 WindowProxy 객체를 반환합니다(예: 분리된 중첩 브라우징 컨텍스트인 경우).

```java
public IWindow Top { get; }
```
