## IDevice.MoveTo method

현재 점을 매개변수 pt의 좌표로 이동하여 새로운 서브경로를 시작하고, 연결 선 구간은 생략합니다. 현재 경로에서 이전 경로 구성 방법이 또한 "MoveTo"였던 경우, 새로운 "MoveTo"가 이를 대체합니다; 이전 "MoveTo" 작업의 흔적은 경로에 남지 않습니다.

```java
public void MoveTo(PointF pt)
```

| Parameter | Type | 설명 |
| --- | --- | --- |
| pt | PointF | 경로를 이동시킬 점. |
