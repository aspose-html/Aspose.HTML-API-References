## PageSetup.AdjustToWidestPage property

문서에서 가장 넓은 페이지에 맞게 페이지 크기가 조정되는 경우를 결정하는 플래그를 가져오거나 설정합니다. 이 옵션은 시간이 많이 소요되어 문서 처리 시간이 두 배로 증가할 수 있습니다. 조정은 문서의 가장 넓은 페이지가 [`PageSetup`](../)에서 결정된 페이지 크기보다 넓을 때만 수행됩니다. 조정된 페이지 크기는 문서의 모든 페이지에 사용됩니다.

```java
public bool AdjustToWidestPage { get; set; }
```
