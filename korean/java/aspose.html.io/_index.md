표준 IO(입출력) 도구 외에도 **com.aspose.html.io** 패키지는 도우미 클래스와 인터페이스를 포함합니다.

## 클래스

| 클래스 | 설명 |
| --- | --- |
| [FileCreateStreamProvider](./filecreatestreamprovider/) | 렌더링 장치에 스트림을 제공하기 위한 FileStream 구현을 나타냅니다. |
## 인터페이스

| 인터페이스 | 설명 |
| --- | --- |
| [IBlob](./iblob/) | Blob 객체는 바이트 시퀀스를 나타내며, 바이트 시퀀스의 전체 바이트 수인 size 속성과, 바이트 시퀀스의 미디어 유형을 소문자 ASCII 문자열로 나타내는 type 속성을 가집니다. |
| [ICreateStreamProvider](./icreatestreamprovider/) | 렌더링 장치에 스트림을 제공하는 클래스가 구현할 수 있는 인터페이스를 나타냅니다. |
| [IFile](./ifile/) | File 객체는 name 속성을 가진 Blob 객체이며, 이는 문자열입니다; 웹 애플리케이션 내에서 생성자를 통해 생성될 수 있거나, 기본(OS) 파일 시스템의 파일에서 바이트 시퀀스를 참조합니다. |
| [IFileList](./ifilelist/) | 파일 목록을 위한 인터페이스를 나타냅니다. |
