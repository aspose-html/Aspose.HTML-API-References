## IBlob.Slice method

옵션인 start 매개변수부터 (end 매개변수를 포함하지 않고)까지의 바이트를 포함하고, type 속성이 옵션인 contentType 매개변수의 값인 새로운 Blob 객체를 반환합니다.

```java
public IBlob Slice(ulong start, ulong end, String contentType)
```

| Parameter | Type | 설명 |
| --- | --- | --- |
| 시작 | UInt64 | 이 매개변수는 슬라이스의 시작 지점을 나타내는 값입니다. |
| 끝 | UInt64 | 이 매개변수는 슬라이스의 시작 지점을 나타내는 값입니다. |
| contentType | String | 이 매개변수는 Blob의 미디어 타입입니다. |

### 반환 값

옵션인 start 매개변수부터 (end 매개변수를 포함하지 않고)까지의 바이트를 포함하고, type 속성이 옵션인 contentType 매개변수의 값인 새로운 Blob 객체를 반환합니다.
