## IBlob.Type property

Blob의 미디어 타입을 나타내는 소문자 ASCII 인코딩 문자열입니다. 가져올 때, 사용자 에이전트는 Blob의 타입을 소문자 ASCII 인코딩 문자열로 반환해야 하며, 이를 바이트 시퀀스로 변환했을 때 파싱 가능한 MIME 타입이거나, 타입을 결정할 수 없을 경우 빈 문자열(0 바이트)이어야 합니다.

```java
public String Type { get; }
```
