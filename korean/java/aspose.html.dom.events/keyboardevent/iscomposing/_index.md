## KeyboardEvent.IsComposing property

키 이벤트가 composition 세션의 일부로 발생하는 경우 true, 즉 compositionstart 이벤트 이후와 해당 compositionend 이벤트 이전에 발생하는 경우입니다. 이 속성의 초기화되지 않은 값은 반드시 false이어야 합니다.

```java
public bool IsComposing { get; }
```

### Property Value

`true`이면 이 인스턴스가 구성 중이며, 그렇지 않으면 `false`입니다.
