## KeyboardEvent.CtrlKey property

Control (control) 키 수정자가 활성화된 경우 true. 이 속성의 초기화되지 않은 값은 반드시 false이어야 합니다.

```java
public bool CtrlKey { get; }
```

### Property Value

`true`이면 Control; 그렇지 않으면 `false`.
