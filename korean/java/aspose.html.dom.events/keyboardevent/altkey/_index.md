## KeyboardEvent.AltKey property

Alt (alternative) (또는 \"Option\") 키 수정자가 활성화된 경우 true. 이 속성의 초기화되지 않은 값은 반드시 false이어야 합니다.

```java
public bool AltKey { get; }
```

### Property Value

Alt인 경우 `true`; 그렇지 않으면 `false`.
