## KeyboardEvent.Repeat property

키가 지속적으로 눌렸을 경우 true. 키를 누르고 있으면 시스템 구성에 따라 정해진 속도로 keydown, beforeinput, input 이벤트가 순서대로 반복되어야 합니다. 장기 눌림 동작을 가진 모바일 장치에서는 repeat 속성 값이 true인 첫 번째 키 이벤트가 장기 눌림을 나타내야 합니다. 반복을 시작하기 위해 키를 눌러야 하는 시간은 구성에 따라 다릅니다.

```java
public bool Repeat { get; }
```

### Property Value

`true`이면 repeat, 그렇지 않으면 `false`.
