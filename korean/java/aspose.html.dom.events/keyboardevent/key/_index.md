## KeyboardEvent.Key property

key는 눌린 키의 키 값을 보유합니다. 값에 인쇄 가능한 표현이 있는 경우, 비어 있지 않은 Unicode 문자 문자열이어야 하며, 이 사양에 정의된 키 값을 결정하는 알고리즘을 따라야 합니다. 인쇄 가능한 표현이 없는 제어 키인 경우, 키 값을 결정하는 알고리즘에 의해 결정된 키 값 집합에 정의된 키 값 중 하나여야 합니다. 키를 식별할 수 없는 구현은 키 값으로 Unidentified를 사용해야 합니다.

```java
public String Key { get; }
```

### Property Value

키 값.
