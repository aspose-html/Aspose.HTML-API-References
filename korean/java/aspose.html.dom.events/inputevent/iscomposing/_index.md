## InputEvent.IsComposing property

true 입력 이벤트가 composition 세션의 일부로 발생하는 경우, 즉 compositionstart 이벤트 이후이면서 해당 compositionend 이벤트 이전인 경우. 이 속성의 초기값은 반드시 false 이어야 합니다.

```java
public bool IsComposing { get; }
```

### Property Value

`true`이면 이 인스턴스가 구성 중이며, 그렇지 않으면 `false`.
