## InputEvent.Data property

data는 입력 방법에 의해 생성된 문자들의 값을 보유합니다. 이는 단일 Unicode 문자이거나 비어 있지 않은 Unicode 문자 시퀀스일 수 있습니다[Unicode]. 문자는 Unicode 정규화 형식 NFC에 따라 정규화되어야 하며, 이는 [UAX15]에 정의되어 있습니다. 이 속성은 빈 문자열을 포함할 수 있습니다.

```java
public String Data { get; }
```
