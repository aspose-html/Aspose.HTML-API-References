## WheelEvent.DeltaY property

사용자 에이전트에서 휠 이벤트의 기본 동작이 스크롤인 경우, 이벤트가 취소되지 않은 경우 스크롤될 y축 방향의 측정값(픽셀, 라인 또는 페이지)이어야 합니다. 그렇지 않으면 휠 장치가 y축을 중심으로 움직인 픽셀, 라인 또는 페이지 단위의 구현별 측정값입니다.

```java
public double DeltaY { get; }
```

deltaY 속성.
