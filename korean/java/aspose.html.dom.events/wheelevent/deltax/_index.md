## WheelEvent.DeltaX property

휠 이벤트의 기본 동작이 스크롤인 사용자 에이전트에서는, 이벤트가 취소되지 않은 경우 값은 x축을 따라 스크롤될 측정값(픽셀, 라인 또는 페이지)이어야 합니다. 그렇지 않은 경우, 이는 x축을 중심으로 휠 장치의 움직임에 대한 구현별 측정값(픽셀, 라인 또는 페이지)입니다.

public double DeltaX { get; }
