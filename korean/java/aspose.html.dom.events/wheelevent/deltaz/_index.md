## WheelEvent.DeltaZ property

휠 이벤트의 기본 동작이 스크롤인 사용자 에이전트에서는, 이벤트가 취소되지 않은 경우 값은 z축을 따라 (픽셀, 라인 또는 페이지 단위) 스크롤될 측정값이어야 합니다. 그렇지 않은 경우, 이는 z축을 중심으로 휠 장치가 움직인 (픽셀, 라인 또는 페이지 단위) 구현별 측정값입니다.

```java
public double DeltaZ { get; }
```

deltaZ 속성.
