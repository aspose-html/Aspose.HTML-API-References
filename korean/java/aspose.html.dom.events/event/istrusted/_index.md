## Event.IsTrusted property

isTrusted 속성은 초기화된 값을 반환해야 합니다. 이벤트가 생성될 때 이 속성은 false로 초기화되어야 합니다.

```java
public bool IsTrusted { get; }
```

### Property Value

`true`이면 이 인스턴스가 신뢰할 수 있습니다; 그렇지 않으면 `false`.
