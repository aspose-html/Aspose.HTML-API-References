## Event.DefaultPrevented property

cancelable 속성 값이 true인 동안 preventDefault()가 호출되면 true를 반환하고, 그렇지 않으면 false를 반환합니다.

```java
public bool DefaultPrevented { get; }
```

### Property Value

`true`이면 [default prevented]; 그렇지 않으면 `false`.
