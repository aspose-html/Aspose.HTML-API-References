## Event.TimeStamp property

이벤트가 생성된 시점을 에포크를 기준으로 밀리초 단위로 지정하는 데 사용됩니다. 일부 시스템에서는 이 정보를 제공하지 않을 수 있어 timeStamp 값이 모든 이벤트에 대해 제공되지 않을 수 있습니다. 제공되지 않을 경우 0이 반환됩니다. 에포크 시간의 예로는 시스템 시작 시점이나 1970년 1월 1일 00:00:00 UTC가 있습니다.

```java
public ulong TimeStamp { get; }
```
