**com.aspose.html.rendering.pdf.encryption** 패키지는 비밀번호, 암호화 알고리즘 등 PDF 암호화 세부 정보를 설명하는 데이터 클래스를 포함합니다.

## 클래스

| 클래스 | 설명 |
| --- | --- |
| [PdfEncryptionInfo](./pdfencryptioninfo/) | PDF 암호화에 대한 세부 정보를 포함합니다. |
## 열거형

| 열거형 | 설명 |
| --- | --- |
| [PdfEncryptionAlgorithm](./pdfencryptionalgorithm/) | 암호화 모드 열거형. 알고리즘 및 키 길이를 사용하여 설명합니다. 이 열거형은 기능을 추가로 확장할 수 있도록 확장되었습니다. 이 열거형은 "Base-to-Core" 패턴을 구현합니다. |
| [PdfPermissions](./pdfpermissions/) | 이 열거형은 PDF에 대한 사용자의 권한을 나타냅니다. |
