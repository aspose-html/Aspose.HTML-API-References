## Converter class

가장 일반적인 변환 시나리오를 위한 공유 파사드입니다. PDF, XPS, 이미지 포맷 등 인기 있는 형식으로의 다양한 변환을 제공합니다. 보다 구체적인 변환(렌더링, 저장) 사용 사례는 잘 알려지고 문서화된 저수준 API 함수들을 통해 제공됩니다.

```java
public static class Converter
```
