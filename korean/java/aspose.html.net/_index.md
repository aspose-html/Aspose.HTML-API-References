**com.aspose.html.net** 패키지는 손쉬운 네트워크 처리를 돕는 클래스와 인터페이스로 구성됩니다.

## 클래스

| 클래스 | 설명 |
| --- | --- |
| [ByteArrayContent](./bytearraycontent/) | 바이트 배열 기반의 콘텐츠를 나타냅니다. |
| [Content](./content/) | HTTP 엔터티 본문 및 콘텐츠 헤더를 위한 기본 클래스를 나타냅니다. |
| [ContentHeaders](./contentheaders/) | 콘텐츠와 연관된 헤더를 포함합니다. |
| [FormUrlEncodedContent](./formurlencodedcontent/) | application/x-www-form-urlencoded MIME 타입으로 인코딩된 이름/값 튜플을 저장하는 컨테이너입니다. |
| [HttpMethod](./httpmethod/) | 표준 HTTP 메서드를 검색하고 비교하기 위한 유틸리티 클래스를 나타냅니다. |
| [MessageFilter](./messagefilter/) | 메시지를 조회하는 데 사용되는 다양한 필터 클래스의 추상 기본 클래스를 나타냅니다 |
| [MessageHandler](./messagehandler/) | 메시지 핸들러의 기본 유형을 나타냅니다. |
| [MessageHandlerCollection](./messagehandlercollection/) | [`MessageHandler`](../com.aspose.html.net/messagehandler/) 컬렉션을 나타냅니다. |
| [MultipartContent](./multipartcontent/) | multipart/* 콘텐츠를 나타냅니다. |
| [MultipartFormDataContent](./multipartformdatacontent/) | multipart/form-data 인코딩 알고리즘용 콘텐츠를 나타냅니다 |
| [RequestHeaders](./requestheaders/) | 요청과 관련된 프로토콜 헤더를 포함합니다. |
| [RequestMessage](./requestmessage/) | 요청 메시지를 나타냅니다. |
| [ResponseHeaders](./responseheaders/) | 응답과 관련된 프로토콜 헤더를 포함합니다. |
| [ResponseMessage](./responsemessage/) | 응답 메시지를 나타냅니다. |
| [StreamContent](./streamcontent/) | 스트림 기반 콘텐츠를 나타냅니다. |
| [StringContent](./Stringcontent/) | 문자열 기반 콘텐츠를 나타냅니다. |
| [UrlResolver](./urlresolver/) | Uniform Resource Identifier(URI)를 사용하여 절대 URL을 해결하는 유틸리티 클래스를 나타냅니다. |
