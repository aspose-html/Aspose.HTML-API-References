## RequestMessage.PreAuthenticate property

요청에 Authorization 헤더를 보낼지 여부를 나타내는 값을 가져오거나 설정합니다.

```java
public bool PreAuthenticate { get; set; }
```

### Property Value

`true`는 인증이 완료된 후 요청에 HTTP Authorization 헤더를 보내도록 합니다; 그렇지 않으면 `false`입니다. 기본값은 `false`입니다.
