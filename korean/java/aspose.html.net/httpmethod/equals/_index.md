## Equals(HttpMethod) {#equals}

현재 객체가 동일한 유형의 다른 객체와 같은지 여부를 나타냅니다.

```java
public bool Equals(HttpMethod other)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| 다른 | HttpMethod | 이 객체와 비교할 객체. |

### 반환 값

현재 객체가 *other* 매개변수와 같은 경우 true; 그렇지 않으면 false.
