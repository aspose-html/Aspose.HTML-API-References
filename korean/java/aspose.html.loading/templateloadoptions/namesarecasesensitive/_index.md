## TemplateLoadOptions.NamesAreCaseSensitive property

템플릿 및 데이터 요소 이름을 대소문자와 관계없이 일치시킬지 여부를 지정하는 속성입니다. true이면 일치는 대소문자를 구분하고, false이면 대소문자를 무시합니다. 기본값은 true입니다.

```java
public bool NamesAreCaseSensitive { get; set; }
```
