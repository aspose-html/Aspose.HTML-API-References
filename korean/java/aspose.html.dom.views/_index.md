**com.aspose.html.dom.views** package describes AbstractView and DocumentView interfaces according Document Object Model Views specification.

## 인터페이스

| 인터페이스 | 설명 |
| --- | --- |
| [IAbstractView](./iabstractview/) | 모든 뷰가 파생되어야 하는 기본 인터페이스입니다. |
| [IDocumentView](./idocumentview/) | DocumentView 인터페이스는 DOM Views를 지원하는 DOM 구현의 Document 객체에 의해 구현됩니다. 이 인터페이스는 문서의 기본 뷰를 가져오는 속성을 제공합니다. |
