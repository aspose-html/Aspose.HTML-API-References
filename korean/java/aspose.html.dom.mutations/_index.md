**com.aspose.html.dom.mutations**는 DOM 변이를 관찰하고 특정 콜백 정보를 얻을 수 있는 기회를 제공합니다.

## 클래스

| 클래스 | 설명 |
| --- | --- |
| [MutationCallback](./mutationcallback/) | 변이 이벤트를 처리할 메서드를 나타냅니다. |
| [MutationObserver](./mutationobserver/) | 객체를 사용하여 [`.`](../com.aspose.html.dom/node/) 트리의 변이를 관찰할 수 있습니다. |
| [MutationObserverInit](./mutationobserverinit/) | 이 클래스는 [`MutationObserver`](../com.aspose.html.dom.mutations/mutationobserver/)를 구성하는 데 사용되는 옵션 컬렉션을 나타냅니다. |
| [MutationRecord](./mutationrecord/) | MutationRecord는 개별 DOM 변이를 나타냅니다. 이는 [`MutationObserver`](../com.aspose.html.dom.mutations/mutationobserver/)의 [`MutationCallback`](../com.aspose.html.dom.mutations/mutationcallback/)에 전달되는 객체입니다. |
