## TextSaveOptions.EnableListItemMarkers property

HTML을 텍스트로 변환할 때 OL 및 UL 요소에 적용되는 옵션입니다. 실제로 OL 및 UL 요소의 외부 리스트 마커를 처리하는 방식을 정의합니다. true인 경우 OL 항목 앞에 번호가 추가되고, UL 항목 앞에 점이 추가됩니다. false인 경우 추가되지 않으며(사양에 따른 기본 동작).

```java
public bool EnableListItemMarkers { get; set; }
```
