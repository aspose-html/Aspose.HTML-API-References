**com.aspose.html.saving** 패키지는 변환/저장 과정에서 특정 저장 옵션을 설명하는 데이터 클래스로 구성됩니다.

## 클래스

| 클래스 | 설명 |
| --- | --- |
| [DocSaveOptions](./docsaveoptions/) | 특정 옵션 데이터 클래스입니다. 속성을 할당함으로써 해상도, 페이지 크기, 배경 색상과 같은 렌더링 특성 및 글꼴 포함과 같은 문서별 옵션을 관리할 수 있습니다. 자세한 내용은 문서의 [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-docx/#save-options)를 참고하십시오. |
| [HTMLSaveOptions](./htmlsaveoptions/) | HTML 저장 옵션을 나타냅니다. 특정 속성을 할당하여 최대 처리 깊이와 같은 리소스 처리 등을 관리할 수 있습니다. 자세한 내용은 문서의 [article](https://docs.aspose.com/html/net/working-with-documents/saving-a-document/)를 참고하십시오. |
| [ImageSaveOptions](./imagesaveoptions/) | 특정 옵션 데이터 클래스입니다. 이미지 결과 해상도, 스무딩 품질, 형식 및 페이지 설정 등을 관리하는 속성을 제공합니다. 자세한 내용은 문서의 [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-jpg/#save-options)에서 확인할 수 있습니다. |
| [MarkdownSaveOptions](./markdownsaveoptions/) | Markdown 저장 옵션을 나타냅니다. 예를 들어, Markdown 서식 스타일을 설정하고, 미리 정의된 GitLab Flavored Markdown 호환 옵션을 사용하며, 리소스 처리를 구성할 수 있습니다. 자세한 내용은 [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-markdown/#save-options)를 참고하십시오. |
| [MHTMLSaveOptions](./mhtmlsaveoptions/) | MHTML 저장 옵션을 나타냅니다. 특정 속성을 할당하여 최대 처리 깊이와 같은 리소스 처리를 관리할 수 있습니다. 자세한 내용은 문서의 [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-mhtml/#save-options)를 참고하십시오. |
| [PdfSaveOptions](./pdfsaveoptions/) | 특정 데이터 클래스는 변환 결과를 관리하기 위한 몇 가지 속성을 제공합니다. 예를 들어 [`PageSetup`](../com.aspose.html.rendering/pagesetup/)은 페이지 특성을 지정합니다. 자세한 내용은 문서의 [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-pdf/#convert-html-to-pdf-using-pdfsaveoptions)를 참고하십시오. |
| [Resource](./resource/) | 이 클래스는 리소스를 설명하고 이를 처리하기 위한 메서드를 제공합니다. |
| [ResourceHandlingContext](./resourcehandlingcontext/) | 이 클래스는 리소스를 처리할 때 사용되는 정보를 포함합니다. |
| [ResourceHandlingOptions](./resourcehandlingoptions/) | 리소스 처리 옵션을 나타냅니다. |
| [SaveOptions](./saveoptions/) | 이는 사용자가 특정 형식으로 문서를 저장할 때 추가 옵션을 지정할 수 있도록 하는 클래스들의 추상 기본 클래스입니다. |
| [TextSaveOptions](./textsaveoptions/) | Text 저장 옵션을 나타냅니다. |
| [XpsSaveOptions](./xpssaveoptions/) | 특정 옵션 데이터 클래스는 변환 결과를 관리하기 위한 몇 가지 속성을 제공합니다. 예를 들어 [`PageSetup`](../com.aspose.html.rendering/pagesetup/)은 페이지 특성을 지정합니다. 자세한 내용은 문서의 [article](https://docs.aspose.com/html/net/converting-between-formats/html-to-xps/#save-options)를 참고하십시오. |
## 열거형

| 열거형 | 설명 |
| --- | --- |
| [HTMLSaveFormat](./htmlsaveformat/) | 문서가 저장되는 형식을 지정합니다. [`HTMLDocument`](../com.aspose.html/htmldocument/) 저장에 대한 자세한 내용은 [article](https://docs.aspose.com/html/net/working-with-documents/saving-a-document/)에서 확인할 수 있습니다. |
| [MarkdownFeatures](./markdownfeatures/) | 하나의 [`MarkdownFeatures`](../com.aspose.html.saving/markdownfeatures/) 플래그 집합은 다음 플래그 중 0개 이상으로 구성되며, 마크다운으로 변환되는 요소를 선택하는 데 사용됩니다. |
| [MarkdownFormatter](./markdownformatter/) | 출력 형식이 지정되는 방식을 정의합니다. |
| [ResourceHandling](./resourcehandling/) | 이 열거형은 리소스 처리 옵션을 나타냅니다. |
| [ResourceStatus](./resourcestatus/) | 리소스 상태를 나타냅니다. |
| [UrlRestriction](./urlrestriction/) | 이 열거형은 처리된 리소스의 URL에 적용되는 제한을 나타냅니다. |
