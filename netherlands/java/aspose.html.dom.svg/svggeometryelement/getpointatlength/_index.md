## SVGGeometryElement.GetPointAtLength method

Retourneert de (x,y)-coördinaat in de gebruikersruimte, uitgedrukt in afstandseenheden langs het pad, met gebruikmaking van het distance‑along‑a‑path‑algoritme van de user agent.

```java
public SVGPoint GetPointAtLength(float distance)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| afstand | Single | De afstand langs het pad, relatief ten opzichte van het begin van het pad, als een afstand in het huidige gebruikerscoördinatensysteem. |

### Retourwaarde

Het geretourneerde punt in de gebruikersruimte.
