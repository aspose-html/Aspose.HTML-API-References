## SVGSVGElement class

Een belangrijke interface-definitie is de SVGSVGElement-interface, die de interface is die overeenkomt met het ‘svg’-element. Deze interface bevat verschillende diverse vaak gebruikte hulpmethoden, zoals matrixbewerkingen en de mogelijkheid om de tijd van opnieuw tekenen op visuele renderapparaten te regelen.

```java
public class SVGSVGElement : SVGGraphicsElement, IDocumentEvent, ISVGFitToViewBox, ISVGZoomAndPan
```
