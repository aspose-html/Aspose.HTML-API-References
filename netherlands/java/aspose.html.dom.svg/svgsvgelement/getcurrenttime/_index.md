## SVGSVGElement.GetCurrentTime method

Retourneert de huidige tijd in seconden ten opzichte van de starttijd van het huidige SVG‑documentfragment. Als getCurrentTime wordt aangeroepen voordat de documenttijdlijn is begonnen (bijvoorbeeld door een script dat draait in een ‘script’-element vóór het SVGLoad‑event van het document wordt verzonden), wordt 0 geretourneerd.

```java
public float GetCurrentTime()
```

### Retourwaarde

De huidige tijd in seconden, of 0 als de documenttijdlijn nog niet is begonnen.
