## SVGSVGElement.GetElementById method

Doorzoekt dit SVG‑documentfragment (d.w.z. de zoekopdracht is beperkt tot een subset van de documentboom) naar een Element waarvan de id gelijk is aan elementId. Als een Element wordt gevonden, wordt dat Element geretourneerd. Als er geen dergelijk element bestaat, wordt null geretourneerd. Het gedrag is niet gedefinieerd als meer dan één element deze id heeft.

```java
public Element GetElementById(String elementId)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| elementId | String | De unieke id-waarde voor een element. |

### Retourwaarde

Het overeenkomende element.
