## SVGSVGElement.SetCurrentTime method

Past de klok voor dit SVG-documentfragment aan en stelt een nieuwe huidige tijd in. Als setCurrentTime wordt aangeroepen voordat de documenttijdlijn is begonnen (bijvoorbeeld door een script dat wordt uitgevoerd in een ‘script’-element voordat het SVGLoad‑evenement van het document wordt verzonden), dan geeft de waarde van seconden in de laatste aanroep van de methode de tijd weer waarnaar het document zal zoeken zodra de documenttijdlijn is begonnen.

```java
public void SetCurrentTime(float seconds)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| seconden | Single | De nieuwe huidige tijd in seconden ten opzichte van de starttijd voor het huidige SVG-documentfragment. |
