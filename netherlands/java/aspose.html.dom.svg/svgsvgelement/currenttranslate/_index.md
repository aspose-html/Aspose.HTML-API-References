## SVGSVGElement.CurrentTranslate property

Op een buitenste svg‑element de bijbehorende translatiefactor die rekening houdt met gebruikers-\"vergroting\". Wanneer benaderd op een ‘svg’-element dat geen buitenste svg‑element is, is het gedrag van dit attribuut ongedefinieerd.

```java
public SVGPoint CurrentTranslate { get; }
```

### Property Value

De huidige translatie.
