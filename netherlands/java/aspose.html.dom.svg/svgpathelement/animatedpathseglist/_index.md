## SVGPathElement.AnimatedPathSegList property

Biedt toegang tot de huidige geanimeerde inhoud van het ‘d’-attribuut in een vorm die één-op-één overeenkomt met de syntaxis van SVG. Als het opgegeven attribuut of de eigenschap wordt geanimeerd, bevat het de huidige geanimeerde waarde van het attribuut of de eigenschap, en zijn zowel het object zelf als de inhoud alleen-lezen. Als het opgegeven attribuut of de eigenschap momenteel niet wordt geanimeerd, bevat het dezelfde waarde als pathSegList.

```java
public SVGPathSegList AnimatedPathSegList { get; }
```

### Property Value

De geanimeerde padsegmentlijst.
