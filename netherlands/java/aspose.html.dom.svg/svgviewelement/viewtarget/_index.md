## SVGViewElement.ViewTarget property

Komt overeen met attribuut ‘viewTarget’ op het opgegeven ‘view’-element. Een lijst van DOMString-waarden die de namen bevatten die in het ‘viewTarget’-attribuut zijn vermeld. Elke DOMString-waarde kan worden geassocieerd met het overeenkomstige element via de getElementById()-methodeaanroep.

```java
public SVGStringList ViewTarget { get; }
```

### Property Value

Het attribuut ‘viewTarget’ van het opgegeven ‘view’-element.
