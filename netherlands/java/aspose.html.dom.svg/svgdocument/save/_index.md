## Save(Url) {#save_3}

Slaat het document op naar een lokaal bestand opgegeven door `url`. Alle bronnen die in dit document worden gebruikt, worden opgeslagen in een aangrenzende map, waarvan de naam wordt samengesteld als: output_file_name + "_files".

```java
public void Save(Url url)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| url | Url | Lokale URL naar uitvoerbestand. |

### Uitzonderingen

| uitzondering | conditie |
| --- | --- |
| ArgumentException | Wordt opgegooid als de opgegeven `url` geen geldige lokale bestands‑URL is. |
