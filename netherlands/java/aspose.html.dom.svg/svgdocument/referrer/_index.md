## SVGDocument.Referrer property

Retourneert de URI van de pagina die naar deze pagina linkte. De waarde is een lege String als de gebruiker rechtstreeks naar de pagina navigeerde (niet via een link, maar bijvoorbeeld via een bladwijzer).

```java
public String Referrer { get; }
```

### Property Value

De referrer.
