## SVGDocument class

Een `SVGDocument` is de root van de SVG‑hiërarchie en bevat de volledige inhoud. Naast het bieden van toegang tot de hiërarchie, biedt het ook enkele handige methoden voor het benaderen van bepaalde verzamelingen informatie uit het document. Wanneer een ‘svg’-element inline wordt ingebed als onderdeel van een document uit een ander pakket, bijvoorbeeld wanneer een ‘svg’-element inline wordt ingebed binnen een XHTML‑document [XHTML], dan bestaat er geen SVGDocument‑object; in plaats daarvan zal het root‑object in de documentobject‑hiërarchie een Document‑object van een ander type zijn, zoals een HTMLDocument‑object. Een SVGDocument‑object bestaat echter wel wanneer het root‑element van de XML‑documenthiërarchie een ‘svg’-element is, bijvoorbeeld bij het bekijken van een zelfstandig SVG‑bestand (d.w.z. een bestand met MIME‑type "image/svg+xml"). In dat geval zal het SVGDocument‑object het root‑object van de documentobject‑model‑hiërarchie zijn.

```java
public class SVGDocument : Document, IDocumentCSS
```
