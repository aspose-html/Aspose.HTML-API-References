## SVGGraphicsElement.GetBBox method

Retourneert de nauwsluitende begrenzingsdoos in de huidige gebruikersruimte (d.w.z. na toepassing van het ‘transform’-attribuut, indien aanwezig) op de geometrie van alle ingesloten grafische elementen, exclusief stroken, bijsnijden, maskeren en filtereffecten). Merk op dat getBBox de werkelijke begrenzingsdoos moet retourneren op het moment dat de methode wordt aangeroepen, zelfs als het element nog niet is gerenderd.

```java
public SVGRect GetBBox()
```

### Retourwaarde

Een SVGRect-object dat de begrenzingsdoos definieert.
