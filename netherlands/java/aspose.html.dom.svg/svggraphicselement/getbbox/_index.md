## SVGGraphicsElement.GetBBox method

Geeft de nauwsluitende begrenzingsdoos terug in de huidige gebruikersruimte (d.w.z. na toepassing van het ‘transform’ attribuut, indien aanwezig) op de geometrie van alle ingesloten grafische elementen, exclusief van stroken, bijsnijden, maskeren en filtereffecten). Merk op dat getBBox de werkelijke begrenzingsdoos moet retourneren op het moment dat de methode werd aangeroepen, zelfs als het element nog niet is gerenderd.

```java
public SVGRect GetBBox()
```

### Retourwaarde

Een SVGRect-object dat de omhullende rechthoek definieert.
