## SVGGraphicsElement.GetCTM method

Geeft de transformatiematrix terug van de huidige gebruikerseenheden (d.w.z. na toepassing van het ‘transform’ attribuut, indien aanwezig) naar het viewport‑coördinatensysteem voor het nearestViewportElement.

```java
public SVGMatrix GetCTM()
```

### Retourwaarde

Een SVGMatrix-object dat de CTM definieert.
