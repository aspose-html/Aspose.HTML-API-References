## SVGMarkerElement.OrientAngle property

Komt overeen met attribuut ‘orient’ op het opgegeven ‘marker’-element. Als markerUnits SVG_MARKER_ORIENT_ANGLE is, de hoekwaarde voor attribuut ‘orient’; anders wordt deze op nul gezet.

```java
public SVGAnimatedAngle OrientAngle { get; }
```

### Property Value

Het attribuut ‘orient’ van het opgegeven ‘marker’ element.
