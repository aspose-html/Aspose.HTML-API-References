## SVGTextContentElement.GetComputedTextLength method

De totale som van alle voortschrijdende waarden bij het renderen van alle tekens binnen dit element, inclusief de voortschrijdende waarde op de glyphs (horizontaal of verticaal), het effect van de eigenschappen ‘kerning’, ‘letter-spacing’ en ‘word-spacing’ en aanpassingen door attributen ‘dx’ en ‘dy’ op ‘tspan’-elementen. Voor niet-renderende omgevingen moet de user agent redelijke aannames maken over glyph-metrieken.

```java
public float GetComputedTextLength()
```

### Retourwaarde

De tekstvoortschrijdingsafstand.
