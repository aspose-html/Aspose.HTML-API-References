| [com.aspose.html](./aspose.html/) | Het Aspose.Html-pakket bevat klassen en methoden om [`HTML documents`](aspose.html/htmldocument/) te manipuleren, of ze nu eenvoudig of complex zijn en direct. Aspose.HTML for Java stelt ontwikkelaars in staat HTML-knooppunten in te voegen, te verwijderen en te vervangen, CSS-stijlinformatie te extraheren, te navigeren door [`HTML document`](aspose.html/htmldocument/) via [`NodeIterator`](aspose.html.dom.traversal/inodeiterator/), [`TreeWalker`](aspose.html.dom.traversal/itreewalker/) die worden geleverd door Traversal Specificaties, XPath- of CSS-selectiequery's. Het biedt ook scripting waarmee de HTML-DOM via JavaScript kan worden gemanipuleerd. Naast HTML biedt deze API ook de mogelijkheid om EPUB en MHTML te laden. Aspose API's staan bekend om hun inter‑bestandsformaatconversiefuncties en deze API biedt eveneens de mogelijkheid om HTML-bestanden te laden en de uitvoer te renderen in PDF, XPS en rasterafbeeldingsformaten, waaronder JPEG, PNG, BMP en TIFF. |
