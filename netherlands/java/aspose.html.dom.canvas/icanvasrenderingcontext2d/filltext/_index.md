```java
public void FillText(String text, double x, double y, double maxWidth)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| text | String | De tekst die getekend moet worden met het huidige lettertype, textAlign, textBaseline en direction waarden. |
| x | Double | De x-as van de coördinaat voor het startpunt van de tekst. |
| y | Double | De y-as van de coördinaat voor het startpunt van de tekst. |
| maxWidth | Double | De maximale breedte om te tekenen. Indien gespecificeerd en de String wordt berekend breder te zijn dan deze breedte, wordt het lettertype aangepast om een meer horizontaal gecondenseerd lettertype te gebruiken (indien beschikbaar of indien een redelijk leesbaar lettertype kan worden gesynthetiseerd door het huidige lettertype horizontaal te schalen) of een kleiner lettertype. |
