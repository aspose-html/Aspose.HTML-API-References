## CreatePattern(HTMLImageElement, String) {#createpattern_1}

Maakt een patroon met de opgegeven afbeelding (een CanvasImageSource). Het herhaalt de bron in de richtingen die door het herhalingsargument worden opgegeven.

```java
public ICanvasPattern CreatePattern(HTMLImageElement image, String repetition)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| afbeelding | HTMLImageElement | Een HTMLImageElement dat wordt gebruikt als de te herhalen afbeelding |
| repetition | String | Een String die aangeeft hoe de afbeelding moet worden herhaald. |

### Retourwaarde

Een ondoorzichtig object dat een patroon beschrijft.
