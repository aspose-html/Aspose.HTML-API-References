## IsPointInPath(double, double) {#ispointinpath_2}

Rapporteert of het opgegeven punt al dan niet in het huidige pad zit.

```java
public bool IsPointInPath(double x, double y)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| x | Double | De X-coördinaat van het te controleren punt. |
| y | Double | De Y-coördinaat van het punt dat moet worden gecontroleerd. |

### Retourwaarde

Retourneert true als het punt zich binnen het gebied bevindt dat wordt gevormd door het vullen van een pad, anders false.
