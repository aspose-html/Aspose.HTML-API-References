## CreateImageData(double, double) {#createimagedata_1}

Creëert een nieuw, leeg ImageData‑object met de opgegeven afmetingen. Alle pixels in het nieuwe object zijn transparante zwart.

```java
public IImageData CreateImageData(double sw, double sh)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| sw | Double | De breedte die aan het nieuwe ImageData-object wordt gegeven. |
| sh | Double | De hoogte die aan het nieuwe ImageData-object wordt gegeven. |

### Retourwaarde

Een nieuw ImageData-object met de opgegeven breedte en hoogte. Het nieuwe object is gevuld met transparante zwarte pixels.
