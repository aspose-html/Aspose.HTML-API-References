## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [Path2D](./path2d/) | De **Path2D**-interface van de **Canvas 2D API** wordt gebruikt om paden te declareren die later worden gebruikt op **CanvasRenderingContext2D**-objecten. De padmethoden van de **CanvasRenderingContext2D**-interface zijn ook op deze interface aanwezig en stellen je in staat om paden te maken die je kunt behouden en opnieuw kunt afspelen wanneer dat nodig is op een canvas. |

| Interface | Beschrijving |
