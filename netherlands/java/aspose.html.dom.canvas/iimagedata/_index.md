## IImageData interface

Maakt een ImageData-object aan vanuit een gegeven Uint8ClampedArray en de grootte van de afbeelding die het bevat. Als er geen array wordt opgegeven, maakt het een afbeelding van een zwart rechthoek.

```java
public interface IImageData
```

## Eigenschappen

| Naam | Beschrijving |
| --- | --- |
| [getData](../../com.aspose.html.dom.canvas/iimagedata/data/) is een Uint8ClampedArray die een eendimensionale array vertegenwoordigt die de gegevens in RGBA-volgorde bevat, met gehele waarden tussen 0 en 255 (inclusief). |
| [getHeight](../../com.aspose.html.dom.canvas/iimagedata/height/) is een unsigned long die de werkelijke hoogte, in pixels, van de ImageData vertegenwoordigt. |
| [getWidth](../../com.aspose.html.dom.canvas/iimagedata/width/) is een unsigned long die de werkelijke breedte, in pixels, van de ImageData vertegenwoordigt. |
