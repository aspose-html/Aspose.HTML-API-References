## Arc(double, double, double, double, double) {#arc}

Voegt een boog toe aan het pad die gecentreerd is op positie (x, y) met straal r, beginnend bij startAngle en eindigend bij endAngle, bewegend in de opgegeven richting tegen de klok in (standaard met de klok mee).

```java
public void Arc(double x, double y, double radius, double startAngle, double endAngle)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| x | Double | De x-coördinaat van het middelpunt van de boog. |
| y | Double | De y-coördinaat van het middelpunt van de boog. |
| straal | Double | De straal van de boog. |
| startAngle | Double | De hoek waarop de boog begint, gemeten met de klok mee vanaf de positieve x-as en uitgedrukt in radialen. |
| endAngle | Double | De hoek waarop de boog eindigt, gemeten met de klok mee vanaf de positieve x-as en uitgedrukt in radialen. |

## Arc(double, double, double, double, double, bool) {#arc_1}

```java
public void Arc(double x, double y, double radius, double startAngle, double endAngle,
```
