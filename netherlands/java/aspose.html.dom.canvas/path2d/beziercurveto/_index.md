## Path2D.BezierCurveTo method

Voegt een kubieke Bézier-curve toe aan het pad. Het vereist drie punten. De eerste twee punten zijn controlepunten en het derde punt is het eindpunt. Het startpunt is het laatste punt in het huidige pad, dat kan worden gewijzigd met moveTo() voordat de Bézier-curve wordt gemaakt.

```java
public void BezierCurveTo(double cp1x, double cp1y, double cp2x, double cp2y, double x, double y)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| cp1x | Double | De x-as van de coördinaat voor het eerste controlepunt. |
| cp1y | Double | De y-as van de coördinaat voor het eerste controlepunt. |
| cp2x | Double | De x-as van de coördinaat voor het tweede controlepunt. |
| cp2y | Double | De y-as van de coördinaat voor het tweede controlepunt. |
| x | Double | De x-as van de coördinaat voor het eindpunt. |
| y | Double | De y-as van de coördinaat voor het eindpunt. |
