## Ellipse(double, double, double, double, double, double, double) {#ellipse}

Voegt een ellips toe aan het pad die gecentreerd is op positie (x, y) met de stralen radiusX en radiusY, beginnend bij startAngle en eindigend bij endAngle, bewegend in de opgegeven richting tegen de klok in (standaard met de klok mee).

```java
public void Ellipse(double x, double y, double radiusX, double radiusY, double rotation, 
    double startAngle, double endAngle)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| x | Double | De x-as van de coördinaat voor het middelpunt van de ellips. |
| y | Double | De y-as van de coördinaat voor het middelpunt van de ellips. |
| radiusX | Double | De radius van de hoofd-as van de ellips. |
| radiusY | Double | De radius van de kleine-as van de ellips. |
| rotation | Double | De rotatie voor deze ellips, uitgedrukt in radialen. |
| startAngle | Double | Het startpunt, gemeten vanaf de x-as, vanaf waar deze getekend wordt, uitgedrukt in radialen. |
| endAngle | Double | De eindhoek van de ellips waartoe deze getekend wordt, uitgedrukt in radialen. |

## Ellipse(double, double, double, double, double, double, double, bool) {#ellipse_1}

```java
public void Ellipse(double x, double y, double radiusX, double radiusY, double rotation, 
    double startAngle, double endAngle, bool anticlockwise)
```

| Parameter | Type | Beschrijving |
