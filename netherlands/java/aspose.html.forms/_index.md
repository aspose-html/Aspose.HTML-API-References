Het pakket biedt toegang tot talrijke objecten (elementen) die verantwoordelijk zijn voor gebruikersinteractiviteit binnen een formulier als webpagina‑component.

## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [ButtonElement](./buttonelement/) | De ButtonElement vertegenwoordigt een wrapper die geassocieerd is met de HTMLButtonElement. |
| [DataListElement](./datalistelement/) | De DataListElement vertegenwoordigt een wrapper die geassocieerd is met de HTMLDataListElement. |
| [FormEditor](./formeditor/) | Deze klasse vertegenwoordigt de editor boven de [`HTMLFormElement`](../com.aspose.html/htmlformelement/) die een eenvoudigere manier biedt voor .net-ontwikkelaars om HTML-formulieren te bewerken. |
| [FormElement](./formelement/) | Stelt de basisklasse voor formulierelementen voor. |
| [FormElement&lt;T&gt;](./formelement-1/) | De [`FormElement`](../com.aspose.html.forms/formelement/) vertegenwoordigt het generieke veld |
| [FormSubmitter](./formsubmitter/) | Deze klasse maakt het mogelijk om een opgegeven [`HTMLFormElement`](../com.aspose.html/htmlformelement/) voor te bereiden, waarden van het formulierelement te verzamelen, ze naar de externe server te verzenden en een reactie te ontvangen. |
| [InputElement](./inputelement/) | De InputElement vertegenwoordigt een wrapper die geassocieerd is met de HTMLInputElement. |
| [OptionCollection](./optioncollection/) | De OptionElements vertegenwoordigt een wrapper die geassocieerd is met de IHTMLOptionsCollection. |
| [OptionElement](./optionelement/) | De OptionElement vertegenwoordigt een wrapper die geassocieerd is met de HTMLOptionElement. |
| [SelectElement](./selectelement/) | De SelectElement vertegenwoordigt een wrapper die geassocieerd is met de HTMLSelectElement. |
| [SubmissionResult](./submissionresult/) | Deze klasse vertegenwoordigt het resultaat van het indienen van formuliergegevens naar de server. |
| [TextAreaElement](./textareaelement/) | De TextAreaElement vertegenwoordigt een wrapper die geassocieerd is met de HTMLTextAreaElement. |
