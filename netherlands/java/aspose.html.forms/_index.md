Het pakket biedt toegang tot talrijke objecten (elementen) die verantwoordelijk zijn voor gebruikersinteractie binnen een formulier als webpagina-component.

## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [ButtonElement](./buttonelement/) | Het ButtonElement vertegenwoordigt een wrapper die geassocieerd is met het HTMLButtonElement. |
| [DataListElement](./datalistelement/) | Het DataListElement vertegenwoordigt een wrapper die geassocieerd is met het HTMLDataListElement. |
| [FormEditor](./formeditor/) | Deze klasse vertegenwoordigt de editor voor de [`HTMLFormElement`](../com.aspose.html/htmlformelement/) die een eenvoudigere manier biedt voor .net-ontwikkelaars om HTML-formulieren te bewerken. |
| [FormElement](./formelement/) | Vertegenwoordigt de basisklasse voor formulierelementen. |
| [FormElement&lt;T&gt;](./formelement-1/) | De [`FormElement`](../com.aspose.html.forms/formelement/) vertegenwoordigt het generieke veld. |
| [FormSubmitter](./formsubmitter/) | Deze klasse maakt het mogelijk om een opgegeven [`HTMLFormElement`](../com.aspose.html/htmlformelement/) voor te bereiden, waarden van het formulierelement te verzamelen, deze naar de externe server te verzenden en een reactie te ontvangen. |
| [InputElement](./inputelement/) | Het InputElement vertegenwoordigt een wrapper die geassocieerd is met het HTMLInputElement. |
| [OptionCollection](./optioncollection/) | Het OptionElements vertegenwoordigt een wrapper die geassocieerd is met de IHTMLOptionsCollection. |
| [OptionElement](./optionelement/) | Het OptionElement vertegenwoordigt een wrapper die geassocieerd is met het HTMLOptionElement. |
| [SelectElement](./selectelement/) | Het SelectElement vertegenwoordigt een wrapper die geassocieerd is met het HTMLSelectElement. |
| [SubmissionResult](./submissionresult/) | Deze klasse vertegenwoordigt het resultaat van het indienen van formuliergegevens naar de server. |
| [TextAreaElement](./textareaelement/) | Het TextAreaElement vertegenwoordigt een wrapper die geassocieerd is met het HTMLTextAreaElement. |
## Enumeratie

| [InputElementType](./inputelementtype/) | Stel de toestanden van het invoerveld voor. |
