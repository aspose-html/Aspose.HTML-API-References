## FontEmbeddingRule enumeration

Stelt de regels voor het insluiten van lettertypen voor.

```java
public enum FontEmbeddingRule
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| Full | `1` | Alle gebruikte lettertypen worden onveranderd ingesloten. Houd er rekening mee dat sommige lettertypen gelicentieerd kunnen zijn, waardoor het resulterende document niet bewerkbaar wordt. Ook kunnen de ingesloten lettertypebestanden de grootte van het resulterende document aanzienlijk vergroten. |
| None | `2` | Lettertypen worden niet ingesloten. |
