Het pakket biedt toegang tot alle SVG‑specifieke gegevenstypen.

## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [SVGAngle](./svgangle/) | De SVGAngle-interface komt overeen met het basisgegevenstype hoek. |
| [SVGAnimatedAngle](./svganimatedangle/) | Gebruikt voor attributen van het basisgegevenstype hoek die geanimeerd kunnen worden. |
| [SVGAnimatedBoolean](./svganimatedboolean/) | Gebruikt voor attributen van het type boolean die geanimeerd kunnen worden. |
| [SVGAnimatedEnumeration](./svganimatedenumeration/) | Gebruikt voor attributen waarvan de waarde een constante uit een specifieke enumeratie moet zijn en die geanimeerd kunnen worden. |
| [SVGAnimatedInteger](./svganimatedinteger/) | Gebruikt voor attributen van het basistype integer die geanimeerd kunnen worden. |
| [SVGAnimatedLength](./svganimatedlength/) | Gebruikt voor attributen van het basistype lengte die geanimeerd kunnen worden. |
| [SVGAnimatedLengthList](./svganimatedlengthlist/) | Gebruikt voor attributen van het type SVGLengthList die geanimeerd kunnen worden. |
| [SVGAnimatedNumber](./svganimatednumber/) | Gebruikt voor attributen van het basistype number die geanimeerd kunnen worden. |
| [SVGAnimatedNumberList](./svganimatednumberlist/) | Gebruikt voor attributen die een lijst van getallen accepteren en die geanimeerd kunnen worden. |
| [SVGAnimatedPreserveAspectRatio](./svganimatedpreserveaspectratio/) | Gebruikt voor attributen van het type SVGPreserveAspectRatio die geanimeerd kunnen worden. |
| [SVGAnimatedRect](./svganimatedrect/) | Gebruikt voor attributen van het type SVGRect die geanimeerd kunnen worden. |
| [SVGAnimatedString](./svganimatedString/) | Gebruikt voor attributen van het type DOMString die geanimeerd kunnen worden. |
| [SVGAnimatedTransformList](./svganimatedtransformlist/) | Gebruikt voor de verschillende attributen die een reeks transformaties specificeren, zoals het ‘transform’-attribuut dat beschikbaar is voor veel SVG-elementen en dat geanimeerd kan worden. |
| [SVGAnimatedValue&lt;T&gt;](./svganimatedvalue-1/) | Gebruikt voor attributen van typen die geanimeerd kunnen worden. |
| [SVGLength](./svglength/) | De SVGLength-interface komt overeen met het basisgegevenstype lengte. Een SVGLength-object kan als alleen-lezen worden aangemerkt, wat betekent dat pogingen om het object te wijzigen zullen resulteren in een gegooide uitzondering, zoals hieronder beschreven. |
| [SVGLengthList](./svglengthlist/) | Deze interface definieert een lijst van SVGLength-objecten. |
| [SVGMatrix](./svgmatrix/) | Veel van de grafische bewerkingen van SVG gebruiken 2x3-matrices van de vorm: [a c e] [b d f] die, wanneer uitgebreid tot een 3x3-matrix voor matrixrekenkunde, worden: [a c e] [b d f] [0 0 1] |
| [SVGNumber](./svgnumber/) | Gebruikt voor attributen van het basistype getal. |
| [SVGNumberList](./svgnumberlist/) | Deze interface definieert een lijst van SVGNumber-objecten. |
| [SVGPoint](./svgpoint/) | Veel van de SVG DOM-interfaces verwijzen naar objecten van de klasse SVGPoint. Een SVGPoint is een (x, y)-coördinaatpaar. Wanneer gebruikt in matrixbewerkingen, wordt een SVGPoint behandeld als een vector van de vorm: [x] [y] [1] Als een SVGRect-object als alleen-lezen wordt aangemerkt, zal een poging om een van zijn attributen toe te wijzen resulteren in een gegooide uitzondering. |
| [SVGPointList](./svgpointlist/) | Deze interface definieert een lijst van SVGPoint-objecten. |
| [SVGPreserveAspectRatio](./svgpreserveaspectratio/) | De SVGPreserveAspectRatio-interface komt overeen met het ‘preserveAspectRatio’-attribuut, dat beschikbaar is voor sommige SVG-elementen. |
| [SVGRect](./svgrect/) | Stelt rechthoekige geometrie voor. Rechthoeken worden gedefinieerd als een (x,y)-coördinaatpaar dat een minimale X-waarde, een minimale Y-waarde, en een breedte en hoogte identificeert, die meestal beperkt zijn tot niet-negatief. |
| [SVGStringList](./svgStringlist/) | SVGStringList heeft dezelfde attributen en methoden als andere SVGxxxList-interfaces. Implementatoren kunnen overwegen een enkele basisklasse te gebruiken om de verschillende SVGxxxList-interfaces te implementeren. |
| [SVGTransform](./svgtransform/) | SVGTransform is de interface voor een van de componenttransformaties binnen een SVGTransformList; dus komt een SVGTransform-object overeen met een enkele component (bijv. 'scale(…)' of 'matrix(…)') binnen een ‘transform’-attribuutspecificatie. |
| [SVGTransformList](./svgtransformlist/) | Deze interface definieert een lijst van SVGTransform-objecten. |
| [SVGValueType](./svgvaluetype/) | Het SVGValueType-type wordt gebruikt om een basistype van SVG-waarde te vertegenwoordigen. |
