## SVGPoint class

Veel van de SVG DOM‑interfaces verwijzen naar objecten van de klasse SVGPoint. Een SVGPoint is een (x, y)-coördinaatpaar. Wanneer gebruikt in matrixbewerkingen, wordt een SVGPoint behandeld als een vector van de vorm: [x] [y] [1]. Als een SVGRect‑object als alleen‑lezen wordt aangemerkt, zal een poging om een van zijn attributen toe te wijzen resulteren in een gegooide uitzondering.

```java
public class SVGPoint : SVGValueType
```
