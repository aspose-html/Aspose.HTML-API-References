## SVGLength.ValueInSpecifiedUnits property

De waarde als een zwevendekommagetal, in de eenheden die door unitType worden uitgedrukt. Het instellen van dit attribuut zorgt ervoor dat value en valueAsString automatisch worden bijgewerkt om deze instelling weer te geven.

```java
public float ValueInSpecifiedUnits { get; set; }
```

### Property Value

De waarde in gespecificeerde eenheden.
