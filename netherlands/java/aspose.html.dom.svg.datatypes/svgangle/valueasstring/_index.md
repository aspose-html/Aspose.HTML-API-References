## SVGAngle.ValueAsString property

De hoekwaarde als een String-waarde, in de eenheden die door unitType worden uitgedrukt. Het instellen van dit attribuut zal ervoor zorgen dat value, valueInSpecifiedUnits en unitType automatisch worden bijgewerkt om deze instelling weer te geven.

```java
public String ValueAsString { get; set; }
```

### Property Value

De waarde als String.
