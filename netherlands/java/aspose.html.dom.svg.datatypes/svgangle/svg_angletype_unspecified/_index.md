## SVGAngle.SVG_ANGLETYPE_UNSPECIFIED field

Er werd geen eenheidstype opgegeven (d.w.z. een eenheidsloze waarde werd gespecificeerd). Voor hoeken wordt een eenheidsloze waarde op dezelfde manier behandeld alsof graden waren opgegeven.

```java
public const ushort SVG_ANGLETYPE_UNSPECIFIED;
```
