## SVGAngle.SVG_ANGLETYPE_UNKNOWN field

Het eenheidstype behoort niet tot de vooraf gedefinieerde eenheidstypen. Het is ongeldig om te proberen een nieuwe waarde van dit type te definiëren of om te proberen een bestaande waarde naar dit type te wijzigen.

```java
public const ushort SVG_ANGLETYPE_UNKNOWN;
```
