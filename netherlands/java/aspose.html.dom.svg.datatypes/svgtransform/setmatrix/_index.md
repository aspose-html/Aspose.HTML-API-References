## SVGTransform.SetMatrix method

Stelt het transformatietype in op SVG_TRANSFORM_MATRIX, met parameter matrix die de nieuwe transformatie definieert. De waarden van de matrixparameter worden gekopieerd; de matrixparameter vervangt SVGTransform::matrix niet.

```java
public void SetMatrix(SVGMatrix matrix)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| matrix | SVGMatrix | De nieuwe matrix voor de transformatie. |
