Het **com.aspose.html.saving.ResourceHandlers** pakket bevat klassen die verantwoordelijk zijn voor het afhandelen van bronnen.

## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [FileSystemResourceHandler](./filesystemresourcehandler/) | Deze klasse is een implementatie van de [`ResourceHandler`](../com.aspose.html.saving.resourcehandlers/resourcehandler/) klasse die is ontworpen om resources op te slaan op het lokale bestandssysteem. |
| [ResourceHandler](./resourcehandler/) | Deze klasse is verantwoordelijk voor het afhandelen van resources. Ze biedt methoden waarmee u kunt bepalen wat er met de [`Resource`](../com.aspose.html.saving/resource/) wordt gedaan, en welke referentie wordt geschreven naar de bovenliggende [`Resource`](../com.aspose.html.saving/resource/). |
