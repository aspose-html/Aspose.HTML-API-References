## ResourceHandler class

Deze klasse is verantwoordelijk voor het verwerken van bronnen. Het biedt methoden die u in staat stellen te bepalen wat er met de [`Resource`](../../com.aspose.html.saving/resource/) zal gebeuren, en welke referentie naar de bovenliggende [`Resource`](../../com.aspose.html.saving/resource/) wordt geschreven.
