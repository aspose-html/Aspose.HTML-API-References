Het **com.aspose.html.rendering.image** pakket biedt een specifieke apparaatklasse evenals enkele renderoptieklassen die verantwoordelijk zijn voor het renderen naar rasterformaten: jpeg, png, bmp, gif, tiff.

## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [ImageDevice](./imagedevice/) | Vertegenwoordigt renderen naar rasterformaten: jpeg, png, bmp, gif, tiff. |
| [ImageRenderingOptions](./imagerenderingoptions/) | Vertegenwoordigt renderopties voor [`ImageDevice`](../com.aspose.html.rendering.image/imagedevice/). Deze optie wordt gebruikt om het uitvoerafbeeldingsformaat, compressie, resolutie enz. op te geven. |
| [TextOptions](./textoptions/) | Vertegenwoordigt tekstrenderopties voor [`ImageDevice`](../com.aspose.html.rendering.image/imagedevice/). |
## Enumeratie

| Enumeratie | Beschrijving |
| --- | --- |
| [Compression](./compression/) | Specificeert de mogelijke compressieschema's voor Tagged Image File Format (TIFF) bitmap-afbeeldingen. |
| [ImageFormat](./imageformat/) | Specificeert het bestandsformaat van de afbeelding. |
