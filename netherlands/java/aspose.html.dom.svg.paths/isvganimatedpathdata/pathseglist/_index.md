## ISVGAnimatedPathData.PathSegList property

Biedt toegang tot de basis (d.w.z. statische) inhoud van het ‘d’-attribuut in een vorm die één-op-één overeenkomt met de syntaxis van SVG. Dus, als het ‘d’-attribuut een "absolute moveto (M)" en een "absolute arcto (A)" commando heeft, zal pathSegList twee items bevatten: een SVG_PATHSEG_MOVETO_ABS en een SVG_PATHSEG_ARC_ABS.

```java
public SVGPathSegList PathSegList { get; }
```

### Property Value

De padsegmentlijst.
