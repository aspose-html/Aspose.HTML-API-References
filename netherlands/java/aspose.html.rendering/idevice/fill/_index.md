## IDevice.Fill method

Vult het volledige gebied dat door het huidige pad wordt omsloten. Als het pad bestaat uit meerdere losgekoppelde subpaden, vult het de binnenkant van alle subpaden, samen beschouwd. Deze methode beëindigt het huidige pad.

```java
public void Fill(FillRule rule)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| regel | FillRule | Vullingsregel geeft aan hoe het interieur van een gesloten pad wordt gevuld |
