## IDevice.Fill method

Vult het gehele gebied dat door het huidige pad wordt omsloten. Als het pad bestaat uit meerdere losgekoppelde subpaden, vult het de binnenkanten van alle subpaden, samen beschouwd. Deze methode beëindigt het huidige pad.

```java
public void Fill(FillRule rule)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| regel | FillRule | Vulregel geeft aan hoe het binnenste van een gesloten pad wordt gevuld |
