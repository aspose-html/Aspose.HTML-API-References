## GraphicContext.MiterLimit property

Stelt de maximale lengte in of haalt deze op van verstekte lijnverbindingen voor getekende paden. Deze parameter beperkt de lengte van \"spikes\" die ontstaan wanneer lijnsegmenten samenkomen onder scherpe hoeken.

```java
public float MiterLimit { get; set; }
```
