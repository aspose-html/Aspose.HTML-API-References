## PageSetup.AdjustToWidestPage property

Haalt op of stelt een vlag in die bepaalt wanneer de paginagrootte wordt aangepast aan de breedste pagina in het document. Deze optie is tijdrovend, waardoor de verwerkingstijd van het document tot twee keer kan toenemen. Aanpassing vindt alleen plaats als de breedste pagina in het document breder is dan de paginagrootte die in [`PageSetup`](../) is bepaald. De aangepaste paginagrootte wordt voor alle pagina's in het document gebruikt.

```java
public bool AdjustToWidestPage { get; set; }
```
