## IDocumentEvent interface

De DocumentEvent-interface biedt een mechanisme waarmee de gebruiker een gebeurtenis van een type kan creëren dat door de implementatie wordt ondersteund. Er wordt verwacht dat de DocumentEvent-interface wordt geïmplementeerd op hetzelfde object dat de Document-interface implementeert in een implementatie die het gebeurtenismodel ondersteunt.

```java
public interface IDocumentEvent
```

## Opmerkingen

Er wordt verwacht dat de interface wordt geïmplementeerd op hetzelfde object dat de interface implementeert in een implementatie die het Event‑model ondersteunt.
