## ErrorEvent.ColNo property

Het colno‑attribuut moet de waarde teruggeven waarmee het is geïnitialiseerd. Wanneer het object wordt aangemaakt, moet dit attribuut worden geïnitialiseerd op nul. Het vertegenwoordigt het kolomnummer waarop de fout in het script optrad.

```java
public uint ColNo { get; }
```
