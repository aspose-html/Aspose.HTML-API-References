## ErrorEvent.FileName property

Het filename-attribuut moet de waarde retourneren waarmee het is geïnitialiseerd. Wanneer het object wordt aangemaakt, moet dit attribuut worden geïnitialiseerd op de lege tekenreeks. Het vertegenwoordigt de absolute URL van het script waarin de fout oorspronkelijk optrad.
