## ErrorEvent.FileName property

Het filename‑attribuut moet de waarde teruggeven waarmee het is geïnitialiseerd. Wanneer het object wordt aangemaakt, moet dit attribuut worden geïnitialiseerd op een lege tekenreeks. Het vertegenwoordigt de absolute URL van het script waarin de fout oorspronkelijk optrad.
