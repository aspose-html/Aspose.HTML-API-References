## ErrorEvent.LineNo property

Het lineno-attribuut moet de waarde retourneren waarmee het is geïnitialiseerd. Wanneer het object wordt aangemaakt, moet dit attribuut worden geïnitialiseerd op nul. Het vertegenwoordigt het regelnummer waar de fout in het script optrad.

```java
public uint LineNo { get; }
```
