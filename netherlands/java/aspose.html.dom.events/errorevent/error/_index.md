## ErrorEvent.Error property

Het error‑attribuut moet de waarde teruggeven waarmee het is geïnitialiseerd. Wanneer het object wordt aangemaakt, moet dit attribuut worden geïnitialiseerd op null. Waar toepasselijk wordt het ingesteld op het object dat de fout vertegenwoordigt (bijv. het uitzonderingsobject in het geval van een niet-afgevangen DOM‑uitzondering).

```java
public object Error { get; }
```

### Property Value

De fout.
