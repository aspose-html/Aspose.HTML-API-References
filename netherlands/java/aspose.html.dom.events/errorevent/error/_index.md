## ErrorEvent.Error property

Het error-attribuut moet de waarde retourneren waarmee het is geïnitialiseerd. Wanneer het object wordt aangemaakt, moet dit attribuut worden geïnitialiseerd op null. Waar toepasselijk wordt het ingesteld op het object dat de fout vertegenwoordigt (bijv. het exceptie‑object in het geval van een niet‑afgevangen DOM‑exceptie).

```java
public object Error { get; }
```

### Property Value

De fout.
