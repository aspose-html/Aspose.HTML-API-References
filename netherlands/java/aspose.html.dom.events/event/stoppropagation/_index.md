## Event.StopPropagation method

De `StopPropagation`‑methode wordt gebruikt om verdere verspreiding van een gebeurtenis tijdens de gebeurtenisstroom te voorkomen.

```java
public void StopPropagation()
```

## Opmerkingen

Als deze methode wordt aangeroepen door een [`IEventListener`](../../ieventlistener/), stopt de gebeurtenis met zich door de boom te verspreiden. De gebeurtenis voltooit de verzending naar alle luisteraars op de huidige [`IEventTarget`](../../ieventtarget/) voordat de gebeurtenisstroom stopt. Deze methode kan tijdens elke fase van de gebeurtenisstroom worden gebruikt.
