## Event.IsTrusted property

Het isTrusted‑attribuut moet de waarde retourneren waarmee het is geïnitialiseerd. Wanneer een gebeurtenis wordt gemaakt, moet het attribuut worden geïnitialiseerd op false.

```java
public bool IsTrusted { get; }
```

### Property Value

`true` als deze instantie vertrouwd is; anders `false`.
