## Event.TimeStamp property

Gebruikt om de tijd (in milliseconden ten opzichte van het epoch) te specificeren waarop het evenement is gemaakt. Omdat sommige systemen deze informatie mogelijk niet leveren, kan de waarde van timeStamp niet beschikbaar zijn voor alle evenementen. Wanneer niet beschikbaar, wordt een waarde van 0 geretourneerd. Voorbeelden van epoch-tijd zijn de tijd van het systeemstart of 0:0:0 UTC 1 januari 1970.

```java
public ulong TimeStamp { get; }
```
