## WheelEvent.DeltaX property

In user agents waarbij de standaardactie van het wiel‑event scrollen is, MOET de waarde de meting langs de x-as (in pixels, regels of pagina's) zijn die moet worden gescrold wanneer het event niet wordt geannuleerd. Anders is dit een implementatiespecifieke meting (in pixels, regels of pagina's) van de beweging van een wielapparaat rond de x-as.

```java
public double DeltaX { get; }
```

### Property Value

Het deltaX-attribuut.
