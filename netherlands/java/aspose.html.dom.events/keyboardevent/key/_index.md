## KeyboardEvent.Key property

De key bevat de sleutelwaarde van de ingedrukte toets. Als de waarde een afgedrukte weergave heeft, MOET deze een niet‑lege Unicode‑karakterreeks zijn, die voldoet aan het algoritme voor het bepalen van de sleutelwaarde zoals gedefinieerd in deze specificatie. Als de waarde een controle‑toets is zonder afgedrukte weergave, MOET deze een van de sleutelwaarden zijn die gedefinieerd zijn in de set sleutelwaarden, zoals bepaald door het algoritme voor het bepalen van de sleutelwaarde. Implementaties die geen toets kunnen identificeren MOETEN de sleutelwaarde Unidentified gebruiken.

```java
public String Key { get; }
```

### Property Value

De sleutelwaarde.
