## KeyboardEvent.DOM_KEY_LOCATION_STANDARD field

De toetsactivatie MAG NIET worden onderscheiden als de linker- of rechterversie van de toets, en (behalve de NumLock-toets) is niet ontstaan vanaf het numerieke toetsenbord (of is niet ontstaan met een virtuele toets die overeenkomt met het numerieke toetsenbord).

```java
public const ulong DOM_KEY_LOCATION_STANDARD;
```
