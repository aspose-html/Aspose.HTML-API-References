## KeyboardEvent.DOM_KEY_LOCATION_STANDARD field

De activering van de toets MAG NIET worden onderscheiden als de linker- of rechterversie van de toets, en (anders dan de NumLock-toets) is niet afkomstig van het numerieke toetsenblok (of is niet afkomstig van een virtuele toets die overeenkomt met het numerieke toetsenblok).

```java
public const ulong DOM_KEY_LOCATION_STANDARD;
```
