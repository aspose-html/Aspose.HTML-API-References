## KeyboardEvent.Repeat property

true als de toets gedurende een langere tijd is ingedrukt. Het ingedrukt houden van een toets MOET resulteren in het herhalen van de gebeurtenissen keydown, beforeinput, input in deze volgorde, met een snelheid bepaald door de systeemconfiguratie. Voor mobiele apparaten met lang‑toets‑gedrag moet het eerste toetsevent met een repeat‑attribuutwaarde true dienen als indicatie van een lang‑toets‑druk. De tijdsduur dat de toets MOET worden ingedrukt om te beginnen met herhalen is afhankelijk van de configuratie.

```java
public bool Repeat { get; }
```

### Property Value

`true` als herhalen; anders `false`.
