## KeyboardEvent.IsComposing property

true als het toetsaanduidings‑event plaatsvindt als onderdeel van een compositiesessie, d.w.z. na een compositionstart‑event en vóór het bijbehorende compositionend‑event. De niet‑geïnitialiseerde waarde van dit attribuut MOET false zijn.

```java
public bool IsComposing { get; }
```

### Property Value

`true` als deze instantie composeert; anders, `false`.
