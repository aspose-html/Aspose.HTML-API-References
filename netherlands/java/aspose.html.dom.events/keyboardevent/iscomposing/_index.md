## KeyboardEvent.IsComposing property

true als het toetsaanduiding plaatsvindt als onderdeel van een compositiesessie, d.w.z., na een compositionstart‑event en vóór het bijbehorende compositionend‑event. De niet‑geïnitieerde waarde van dit attribuut MOET false zijn

```java
public bool IsComposing { get; }
```

### Property Value

`true` als deze instantie aan het componeren is; anders `false`.
