## KeyboardEvent.Code property

De code bevat een String die de fysieke toets identificeert die wordt ingedrukt. De waarde wordt niet beïnvloed door de huidige toetsenbordindeling of modifierstatus, zodat een bepaalde toets altijd dezelfde waarde retourneert.

```java
public String Code { get; }
```

### Property Value

De toetscode.
