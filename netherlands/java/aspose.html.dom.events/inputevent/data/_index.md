## InputEvent.Data property

De data bevat de waarde van de tekens die door een invoermethode zijn gegenereerd. Dit KAN een enkel Unicode‑teken of een niet‑lege reeks Unicode‑tekens zijn [Unicode]. Tekens MOETEN worden genormaliseerd volgens de Unicode‑normalisatievorm NFC, gedefinieerd in [UAX15]. Dit attribuut KAN een lege String bevatten.
