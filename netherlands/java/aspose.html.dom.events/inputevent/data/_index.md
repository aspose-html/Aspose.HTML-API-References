## InputEvent.Data property

De data bevat de waarde van de tekens die door een invoermethode zijn gegenereerd. Dit KAN een enkel Unicode‑teken zijn of een niet‑lege reeks Unicode‑tekens [Unicode]. Tekens ZOUEN genormaliseerd moeten worden volgens de Unicode‑normalisatievorm NFC, gedefinieerd in [UAX15]. Dit attribuut KAN de lege string bevatten.
