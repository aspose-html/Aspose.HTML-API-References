## InputEvent.IsComposing property

true als het invoergebeurtenis plaatsvindt als onderdeel van een compositiesessie, d.w.z. na een compositionstart‑gebeurtenis en vóór de bijbehorende compositionend‑gebeurtenis. De niet‑geïnitieerde waarde van dit attribuut MOET false zijn.

```java
public bool IsComposing { get; }
```

### Property Value

`true` als deze instantie composeert; anders, `false`.
