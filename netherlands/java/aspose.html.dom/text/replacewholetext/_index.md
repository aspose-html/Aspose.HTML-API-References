## Text.ReplaceWholeText method

Vervangt de tekst van het huidige node en alle logisch-aangrenzende tekstnodes met de opgegeven tekst. Alle logisch-aangrenzende tekstnodes worden verwijderd, inclusief het huidige node, tenzij het de ontvanger van de vervangende tekst was.
