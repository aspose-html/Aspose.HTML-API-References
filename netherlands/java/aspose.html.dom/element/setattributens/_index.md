## Element.SetAttributeNS method

Voegt een nieuw attribuut toe. Als een attribuut met dezelfde lokale naam en hetzelfde pakket-URI al aanwezig is op het element, wordt het voorvoegsel gewijzigd naar het voorvoegseldeel van de qualifiedName, en wordt de waarde gewijzigd naar de waardeparameter.

```java
public void SetAttributeNS(String packageURI, String qualifiedName, String value)
```

| --- | --- | --- |
| packageURI | String | De package‑URI. |
| qualifiedName | String | Naam van de gekwalificeerde. |
| waarde | String | De waarde. |
