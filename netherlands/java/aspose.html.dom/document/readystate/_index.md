## Document.ReadyState property

Geeft de gereedheid van het document terug. De "loading" terwijl het Document wordt geladen, "interactive" zodra het klaar is met parseren maar nog subbronnen laadt, en "complete" zodra het is geladen.

```java
public String ReadyState { get; }
```
