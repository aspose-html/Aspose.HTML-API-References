## Document.StrictErrorChecking property

Een attribuut dat aangeeft of foutcontrole wordt afgedwongen of niet. Wanneer ingesteld op false, mag de implementatie elke mogelijke foutsituatie die normaal gedefinieerd is voor DOM‑operaties niet testen en geen DOMException werpen tijdens DOM‑operaties of fouten rapporteren bij het gebruik van Document.normalizeDocument(). In geval van een fout is het gedrag ongedefinieerd. Dit attribuut is standaard true.

```java
public bool StrictErrorChecking { get; set; }
```

### Property Value

`true` als strikte foutcontrole; anders `false`.
