## Document.XmlVersion property

Een attribuut dat, als onderdeel van de XML-declaratie, het versienummer van dit document specificeert. Als er geen declaratie is en als dit document de "XML"-functie ondersteunt, is de waarde "1.0". Als dit document de "XML"-functie niet ondersteunt, is de waarde altijd null.

```java
public String XmlVersion { get; set; }
```

### Property Value

De XML-versie.
