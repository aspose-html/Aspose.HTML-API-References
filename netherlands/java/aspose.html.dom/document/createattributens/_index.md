## Document.CreateAttributeNS method

De Document.createAttribute()‑methode maakt een nieuw attribuutknooppunt aan en retourneert dit. Het object creëert een knooppunt dat de [Attr](T:com.aspose.html.dom.Attr) interface implementeert. De DOM dwingt niet af welk type attributen op deze manier aan een bepaald element kan worden toegevoegd.

```java
public Attr CreateAttributeNS(String packageURI, String qualifiedName)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| packageURI | String | De pakket-URI van het attribuut. |
| qualifiedName | String | name is een String die de naam van het attribuut bevat. |

### Retourwaarde

De [`Attr`](../../attr/).
