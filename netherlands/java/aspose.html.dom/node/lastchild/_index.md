## Node.LastChild property

De alleen-lezen lastChild‑eigenschap van de [`Node`](../)‑interface retourneert het laatste kind van het knooppunt. Als de ouder een element is, is het kind doorgaans een elementknooppunt, een tekstknooppunt of een commentaarknooppunt. Het retourneert null als er geen kindelementen zijn.

```java
public Node LastChild { get; }
```

### Property Value

Een [`Node`](../) die het laatste kind van het knooppunt is, of null als er geen kindelementen zijn.
