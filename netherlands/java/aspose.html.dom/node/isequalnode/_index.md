## Node.IsEqualNode method

De isEqualNode()-methode van de [`Node`](../)‑interface test of twee knooppunten gelijk zijn. Twee knooppunten zijn gelijk wanneer ze hetzelfde type hebben, met dezelfde kenmerkende eigenschappen (voor elementen zou dit hun ID, aantal kinderen, enzovoort zijn), hun attributen overeenkomen, enzovoort. De specifieke set gegevenspunten die moeten overeenkomen varieert afhankelijk van de typen knooppunten.

```java
public bool IsEqualNode(Node otherNode)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| otherNode | Node | De [`Node`](../) om mee te vergelijken op gelijkheid. |

### Retourwaarde

Een booleaanse waarde die true is als de twee knooppunten gelijk zijn, of false als dat niet zo is. Als otherNode null is, retourneert isEqualNode() altijd false.
