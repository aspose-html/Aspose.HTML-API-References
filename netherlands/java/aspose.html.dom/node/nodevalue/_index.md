## Node.NodeValue property

De nodeValue‑eigenschap van de [`Node `](../)‑interface retourneert of stelt de waarde van het huidige knooppunt in.

```java
public String NodeValue { get; set; }
```

### Property Value

Een String die de waarde van het huidige knooppunt bevat, indien aanwezig. Voor het document zelf retourneert nodeValue null. Voor tekst-, commentaar- en CDATA‑knooppunten retourneert nodeValue de inhoud van het knooppunt. Voor attribuutknooppunten wordt de waarde van het attribuut geretourneerd.
