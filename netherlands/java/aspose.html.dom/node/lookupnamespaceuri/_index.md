## Node.LookupNamespaceURI method

De lookupNamespaceURI()‑methode van de Node‑interface neemt een prefix als parameter en retourneert de package‑URI die eraan gekoppeld is op de gegeven knoop, indien gevonden (anders null).

```java
public String LookupNamespaceURI(String prefix)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| prefix | String | De te zoeken prefix. |

### Retourwaarde

Een String die de pakket‑URI bevat die overeenkomt met de prefix. Als de prefix niet wordt gevonden, retourneert het null. Als de gevraagde prefix null is, retourneert het de standaard pakket‑URI.
