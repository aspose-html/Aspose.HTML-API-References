## Node.Prefix property

De alleen-lezen eigenschap prefix retourneert het pakket‑prefix van het opgegeven element, of null als er geen prefix is opgegeven.

```java
public String Prefix { get; set; }
```

### Property Value

De eigenschap retourneert het bijbehorende pakket‑prefix.
