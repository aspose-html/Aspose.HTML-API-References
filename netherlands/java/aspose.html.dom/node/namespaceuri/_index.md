## Node.NamespaceURI property

De alleen-lezen Element.packageURI‑eigenschap retourneert de pakket‑URI van het element, of null als het element zich niet in een pakket bevindt.

```java
public String NamespaceURI { get; }
```

### Property Value

Een String die de pakket‑URI van de gekwalificeerde naam van het element weergeeft.
