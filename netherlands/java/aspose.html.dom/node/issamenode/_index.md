## Node.IsSameNode method

De isSameNode()‑methode van de Node‑interface is een legacy‑alias voor de === strikte gelijkheidsoperator. Dat wil zeggen, ze test of twee knopen identiek zijn (met andere woorden, of ze naar hetzelfde object verwijzen).

Opmerking: Het is niet nodig om isSameNode() te gebruiken; gebruik in plaats daarvan de === strikte gelijkheidsoperator.

```java
public bool IsSameNode(Node otherNode)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| otherNode | Node | De Node om tegen te testen. |

### Retourwaarde

Een booleaanse waarde die true is als beide knopen strikt gelijk zijn, anders false.
