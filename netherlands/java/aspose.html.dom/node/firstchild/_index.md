## Node.FirstChild property

De alleen-lezen firstChild-eigenschap van de [`Node`](../)-interface retourneert het eerste kind van de node in de boom, of null als de node geen kinderen heeft.

Als de node een Document is, retourneert deze eigenschap de eerste node in de lijst van zijn directe kinderen.

```java
public Node FirstChild { get; }
```

### Property Value

Een [`Node`](../), of null als er geen zijn.
