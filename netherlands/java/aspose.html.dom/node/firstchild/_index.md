## Node.FirstChild property

De alleen-lezen firstChild-eigenschap van de [`Node`](../)-interface retourneert het eerste kind van het knooppunt in de boom, of null als het knooppunt geen kinderen heeft.

Als het knooppunt een Document is, retourneert deze eigenschap het eerste knooppunt in de lijst van zijn directe kinderen.

```java
public Node FirstChild { get; }
```

### Property Value

Een [`Node`](../), of null als er geen zijn.
