## Node.NextSibling property

De alleen-lezen nextSibling‑eigenschap van de [`Node`](../)‑interface retourneert het knooppunt dat direct volgt op het opgegeven knooppunt in de [`childNodes`](../childnodes/) van hun ouder, of retourneert null als het opgegeven knooppunt het laatste kind in het bovenliggende element is.

```java
public Node NextSibling { get; }
```

### Property Value

Een [`Node`](../) die de volgende sibling van het huidige knooppunt vertegenwoordigt, of null als er geen zijn.
