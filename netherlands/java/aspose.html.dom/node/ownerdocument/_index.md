## Node.OwnerDocument property

De alleen-lezen ownerDocument‑eigenschap van de Node‑interface retourneert het bovenliggende documentobject van het knooppunt.

```java
public Document OwnerDocument { get; }
```

### Property Value

Een [`Document`](../../document/) dat het bovenliggende object is waarin alle kindknooppunten worden aangemaakt.

Als deze eigenschap wordt gebruikt op een knooppunt dat zelf een document is, is de waarde null.
