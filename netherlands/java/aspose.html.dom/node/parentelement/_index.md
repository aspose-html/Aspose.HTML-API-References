## Node.ParentElement property

De alleen-lezen parentElement‑eigenschap van [`Node`](../) interface retourneert het bovenliggende [`Element`](../../element/) van het DOM‑knooppunt, of null als het knooppunt geen ouder heeft, of zijn ouder geen DOM‑Element is.

```java
public Element ParentElement { get; }
```

### Property Value

Een [`Element`](../../element/) dat het bovenliggende element van het huidige knooppunt is, of null als er geen is.
