## Node.BaseURI property

De alleen-lezen baseURI-eigenschap van de Node-interface retourneert de absolute basis-URL van het document dat de node bevat.

De basis-URL wordt gebruikt om relatieve URL's op te lossen wanneer de browser een absolute URL moet verkrijgen, bijvoorbeeld bij het verwerken van het src-attribuut van het HTML‑img‑element of de xlink:href‑ of href‑attributen in SVG.

```java
public String BaseURI { get; }
```

### Property Value

De baseURI‑getter retourneert de basis-URL van het document van deze node, geserialiseerd.
