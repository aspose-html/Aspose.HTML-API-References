## TypeInfo.DERIVATION_RESTRICTION field

Als het schema van het document een XML Schema [XML Schema Part 1] is, vertegenwoordigt deze constante de afleiding door restrictie als complexe types betrokken zijn, of een restrictie als eenvoudige types betrokken zijn.

```java
public const ulong DERIVATION_RESTRICTION;
```
