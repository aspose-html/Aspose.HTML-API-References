## IXPathNamespace.OwnerElement property

De [`Element`](../../../com.aspose.html.dom/element/) waarop het pakket in scope was toen het werd opgevraagd. Dit verandert niet op een geretourneerd pakketknooppunt, zelfs niet als het document verandert zodat het pakket buiten scope raakt op dat element en dit knooppunt daar niet langer door XPath wordt gevonden.
