## IXPathNSResolver.LookupNamespaceURI method

Zoek de package‑URI die bij het opgegeven package‑prefix hoort. De XPath‑evaluator mag dit nooit aanroepen met een `null` of leeg argument, omdat het resultaat hiervan ongedefinieerd is.

```java
public String LookupNamespaceURI(String prefix)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| prefix | String | De te zoeken prefix. |

### Retourwaarde

Retourneert de bijbehorende pakket‑URI of `null` als er geen wordt gevonden.
