## IFile.LastModified property

De laatste wijzigingsdatum van het bestand. Bij ophalen, als gebruikersagenten deze informatie beschikbaar kunnen maken, moet dit een long long retourneren die is ingesteld op de tijd waarop het bestand voor het laatst is gewijzigd als het aantal milliseconden sinds de Unix Epoch.

```java
public long LastModified { get; }
```
