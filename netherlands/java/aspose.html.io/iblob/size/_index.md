## IBlob.Size property

Retourneert de grootte van de byte‑reeks in aantal bytes. Bij ophalen moeten conforme gebruikersagenten het totale aantal bytes retourneren dat gelezen kan worden door een FileReader‑ of FileReaderSync‑object, of 0 als de Blob geen bytes heeft om te lezen.

public ulong Size { get; }
