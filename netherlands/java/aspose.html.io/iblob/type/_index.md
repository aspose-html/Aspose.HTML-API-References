## IBlob.Type property

De ASCII‑gecodeerde string in kleine letters die het mediatype van de Blob weergeeft. Bij ophalen moeten gebruikersagenten het type van een Blob retourneren als een ASCII‑gecodeerde string in kleine letters, zodanig dat wanneer deze wordt omgezet naar een byte‑reeks het een parseerbaar MIME‑type is, of de lege string – 0 bytes – als het type niet kan worden bepaald.

public String Type { get; }
