## DOMTokenList.Replace method

Vervangt een bestaand token door een nieuw token. Doet niets als het eerste token niet bestaat.

```java
public bool Replace(String token, String newToken)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| token | String | Het token dat je wilt vervangen. |
| newToken | String | Het token waarmee je het oude token wilt vervangen. |

### Retourwaarde

Boolean `true` als het token is gevonden en vervangen, `false` anders.
