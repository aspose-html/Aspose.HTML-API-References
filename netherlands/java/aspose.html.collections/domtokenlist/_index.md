## DOMTokenList class

De DOMTokenList‑klasse vertegenwoordigt een set van door spaties gescheiden tokens. Het is geïndexeerd beginnend bij 0, net als JavaScript‑array‑objecten. DOMTokenList is altijd hoofdlettergevoelig.

```java
public class DOMTokenList : DOMObject, IEnumerable<String>
```
