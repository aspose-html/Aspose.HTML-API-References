## Toggle(String, bool) {#toggle_1}

Verwijdert het token uit de lijst als het bestaat, of voegt het token toe aan de lijst als het niet bestaat.

```java
public bool Toggle(String token, bool force)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| token | String | Het token dat u wilt schakelen. |
| force | Boolean | Een Boolean die, indien opgegeven, de toggle omzet in een eenrichtingsoperatie. Als deze op false is ingesteld, wordt het token alleen verwijderd, maar niet toegevoegd. Als deze op true is ingesteld, wordt het token alleen toegevoegd, maar niet verwijderd. |

### Retourwaarde

Een Boolean die aangeeft of het token zich in de lijst bevindt na de oproep.
