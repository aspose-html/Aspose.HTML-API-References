## NamedNodeMap.SetNamedItem method

Voegt een knooppunt toe met behulp van zijn nodeName-attribuut. Als er al een knooppunt met die naam in deze map aanwezig is, wordt het vervangen door het nieuwe. Een knooppunt door zichzelf vervangen heeft geen effect.

```java
public Attr SetNamedItem(Attr attr)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| attr | Attr | Het attribuut. |

### Retourwaarde

Retourneert knooppunt.
