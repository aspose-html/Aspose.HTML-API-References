Het **com.aspose.html.collections**-pakket bestaat uit klassen om knooppunten en elementen te representeren, op te slaan en te manipuleren.

## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [DOMTokenList](./domtokenlist/) | De DOMTokenList‑klasse vertegenwoordigt een set van door spaties gescheiden tokens. Het is geïndexeerd beginnend bij 0, net als JavaScript‑array‑objecten. DOMTokenList is altijd hoofdlettergevoelig. |
| [HTMLCollection](./htmlcollection/) | De [`HTMLCollection`](../com.aspose.html.collections/htmlcollection/) vertegenwoordigt een algemene collectie van [`Element`](../com.aspose.html.dom/element/). |
| [NamedNodeMap](./namednodemap/) | Vertegenwoordigt collecties van attributen die op naam benaderd kunnen worden. |
| [NodeList](./nodelist/) | De NodeList biedt de abstractie van een geordende collectie knooppunten, zonder te definiëren of te beperken hoe deze collectie is geïmplementeerd. |
