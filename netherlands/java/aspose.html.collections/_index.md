Het **com.aspose.html.collections**-pakket bestaat uit klassen om knooppunten en elementen te vertegenwoordigen, op te slaan en te manipuleren.

## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [DOMTokenList](./domtokenlist/) | De DOMTokenList‑klasse vertegenwoordigt een set van door spaties gescheiden tokens. Deze is geïndexeerd vanaf 0, net als JavaScript‑Array‑objecten. DOMTokenList is altijd hoofdlettergevoelig. |
| [HTMLCollection](./htmlcollection/) | De [`HTMLCollection`](../com.aspose.html.collections/htmlcollection/) vertegenwoordigt een generieke collectie van [`Element`](../com.aspose.html.dom/element/). |
| [NamedNodeMap](./namednodemap/) | Vertegenwoordigt collecties van attributen die op naam benaderbaar zijn. |
| [NodeList](./nodelist/) | De NodeList biedt de abstractie van een geordende collectie van knooppunten, zonder te definiëren of te beperken hoe deze collectie wordt geïmplementeerd. |
