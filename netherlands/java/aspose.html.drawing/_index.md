Het **com.aspose.html.drawing** pakket bevat objecten en interfaces om metingen en eenheden te specificeren, evenals tekenattribuutobjecten zoals penselen, kleuren en lettertypen.

## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [Angle](./angle/) | Het hoekdatatype |
| [Color](./color/) | De Color-klasse stelt je in staat kleuren op te geven als Red-Green-Blue (RGB)-waarden, Hue-Saturation-Luminosity (HSL)-waarden, Hue-Saturation-Value (HSV)-waarden, Hue-Whiteness-Blackness (HWB)-waarden, lightness-A-B (LAB)-waarden, Luminance-Chroma-Hue (LCH)-waarden, Cyan-Magenta-Yellow-Key (CMYK)-waarden, Natural colors (NCOL)-waarden, of met een kleurnaam. Een Alpha-kanaal is ook beschikbaar om transparantie aan te geven. |
| [Dimension](./dimension/) | Biedt de basisklasse voor dimensies. De algemene term 'dimensie' verwijst naar een getal met een eenheid eraan gekoppeld, en wordt aangeduid met [`UnitType`](../com.aspose.html.drawing/unittype/). |
| [Frequency](./frequency/) | De 'frequency'-eenheid. |
| [Length](./length/) | Stelt een lengtemetingeenheid voor. |
| [LengthOrAuto](./lengthorauto/) | Stelt een container voor opslaglengte of 'auto'-eenheden voor. |
| [Margin](./margin/) | Stelt paginamarge voor. |
| [Numeric](./numeric/) | Biedt de basisklasse voor numerieke typen. |
| [Page](./page/) | Stelt een pagina-object voor dat wordt gebruikt voor configuratie van de uitvoerpagina. De lacuna-waarde voor paginagrootte is A4 (210x297mm). |
| [Resolution](./resolution/) | Stelt een resolutie-eenheid voor. |
| [Size](./size/) | Slaat waarden op die een hoogte en breedte specificeren. |
| [Time](./time/) | Stelt een tijdseenheid voor. |
| [Unit](./unit/) | Biedt de basisklasse voor meeteenheden. |
| [UnitType](./unittype/) | Specificeert de meeteenheid. |
