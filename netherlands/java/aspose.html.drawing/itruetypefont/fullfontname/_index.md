## ITrueTypeFont.FullFontName property

Dit moet een combinatie zijn van "FamilyName" en "SubFamilyName". Uitzondering: als het lettertype "Regular" is zoals aangegeven in "SubFamilyName", gebruik dan alleen de familienaam die in "FamilyName" staat. Een uitzondering op de bovenstaande definitie van de volledige lettertype‑naam is voor Microsoft‑platformstrings voor CFF OpenType‑lettertypen: in dit geval moet de volledige lettertype‑naamidentiek zijn aan de PostScript FontName in de CFF Name INDEX.

```java
public String FullFontName { get; }
```

### Retourwaarde

Volledige naam van het lettertype
