## ITrueTypeFont.SubFamilyName property

De naam van de subfamilie van het lettertype onderscheidt het lettertype in een groep met dezelfde lettertypefamilienaam. Dit wordt verondersteld om stijl (italic, oblique) en gewicht (light, bold, black, etc.) aan te geven. Een lettertype zonder specifieke verschillen in gewicht of stijl (bijv. medium gewicht, niet cursief en met fsSelection-bit 6 ingesteld) moet de tekenreeks "Regular" op deze positie bevatten.

```java
public String SubFamilyName { get; }
```

### Retourwaarde

Subfamilienaam van het lettertype
