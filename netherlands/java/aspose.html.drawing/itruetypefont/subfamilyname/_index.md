## ITrueTypeFont.SubFamilyName property

De Font Subfamily-naam onderscheidt het lettertype in een groep met dezelfde Font Family-naam. Dit wordt verondersteld om stijl (italic, oblique) en gewicht (light, bold, black, enz.) aan te geven. Een lettertype zonder specifieke verschillen in gewicht of stijl (bijv. medium gewicht, niet italic en fsSelection bit 6 ingesteld) moet de tekenreeks \"Regular\" op deze positie hebben opgeslagen.

```java
public String SubFamilyName { get; }
```

### Retourwaarde

Subfamily-naam van het lettertype
