## SpreadMode enumeration

Specificeert hoe een textuur of gradiënt wordt getegeld wanneer deze kleiner is dan het gebied dat wordt gevuld.

```java
public enum SpreadMode
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| Tile | `0` | De textuur of gradient wordt getegeld. |
| TileFlipX | `1` | De textuur of gradient wordt getegeld en horizontaal gespiegeld. |
| TileFlipY | `2` | De textuur of gradient wordt getegeld en verticaal gespiegeld. |
| TileFlipXY | `3` | De textuur of gradient wordt getegeld en zowel horizontaal als verticaal gespiegeld. |
| Clamp | `4` | De textuur of gradient wordt vastgezet aan de rand. |
