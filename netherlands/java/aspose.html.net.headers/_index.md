De **com.aspose.html.net.headers** biedt enkele dataklassen voor het beschrijven van headerinhoud bij netwerken.

## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [ContentDispositionHeaderValue](./contentdispositionheadervalue/) | Stelt de Content-Disposition headerwaarde voor. |
| [ContentTypeHeaderValue](./contenttypeheadervalue/) | Stelt een Content-Type headerwaarde voor. |
| [NameValueHeaderValue](./namevalueheadervalue/) | Stelt een naam/waarde-paar voor dat een headerwaarde beschrijft. |
