Het **com.aspose.html.net.headers**-pakket biedt enkele dataklassen voor het beschrijven van header‑inhoud bij netwerken.

## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [ContentDispositionHeaderValue](./contentdispositionheadervalue/) | Stelt de Content-Disposition-headervalue voor. |
| [ContentTypeHeaderValue](./contenttypeheadervalue/) | Stelt een Content-Type-headervalue voor. |
| [NameValueHeaderValue](./namevalueheadervalue/) | Stelt een naam/waarde-paar voor dat een headerwaarde beschrijft. |
