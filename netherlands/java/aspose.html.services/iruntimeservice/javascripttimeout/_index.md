## IRuntimeService.JavaScriptTimeout property

Haalt of stelt een TimeSpan in die de uitvoeringstijd van JavaScript beperkt. Als het script langer wordt uitgevoerd dan de opgegeven TimeSpan, wordt het geannuleerd. Je kunt een oneindige time-out opgeven door de TimeSpan gelijk te stellen aan -1 milliseconden. Standaardwaarde is 1 minuut.

```java
public TimeSpan JavaScriptTimeout { get; set; }
```
