## IUserAgentService.Language property

De `Language` specificeert de primaire taal voor de inhoud van het element en voor alle attributen van het element die tekst bevatten. De waarde moet een geldige BCP 47 () taaltag zijn, of de lege String. Het instellen van het attribuut op de lege String geeft aan dat de primaire taal onbekend is.

```java
public String Language { get; set; }
```

### Property Value

De taal van de user agent.
