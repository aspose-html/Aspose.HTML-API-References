## IUserAgentService.ShowImagePlaceholders property

Afbeeldingen kunnen fallback‑inhoud hebben: inhoud die moet worden gebruikt wanneer een externe bron niet kan worden gebruikt (bijvoorbeeld omdat deze in een niet‑ondersteund formaat is). De eigenschap `ShowImagePlaceholders` geeft aan of de fallback‑afbeelding moet worden weergegeven (standaard is true)
