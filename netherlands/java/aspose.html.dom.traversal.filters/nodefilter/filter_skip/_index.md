## NodeFilter.FILTER_SKIP field

Sla dit enkele knooppunt over. Navigatiemethoden die zijn gedefinieerd voor NodeIterator of TreeWalker zullen dit knooppunt niet retourneren. Voor zowel NodeIterator als TreeWalker worden de kinderen van dit knooppunt nog steeds in aanmerking genomen.

```java
public const short FILTER_SKIP;
```
