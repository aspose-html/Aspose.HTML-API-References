## NodeFilter.SHOW_NOTATION field

Toon Notation‑knooppunten. Dit is alleen zinvol bij het maken van een iterator of tree-walker met een Notation‑knooppunt als wortel; in dat geval betekent dit dat het Notation‑knooppunt op de eerste positie van de traversie verschijnt. Aangezien notaties geen deel uitmaken van de documentboom, verschijnen ze niet tijdens het doorlopen van de documentboom.

```java
public const long SHOW_NOTATION;
```
