## NodeFilter.SHOW_ATTRIBUTE field

Toon Attr-knooppunten. Dit is alleen zinvol bij het maken van een iterator of tree-walker met een attribuutknooppunt als root; in dit geval betekent dit dat het attribuutknooppunt op de eerste positie van de iteratie of traversie verschijnt. Aangezien attributen nooit kinderen van andere knooppunten zijn, verschijnen ze niet bij het traverseren van de documentboom.

```java
public const long SHOW_ATTRIBUTE;
```
