## NodeFilter.SHOW_ENTITY field

Toon entiteitsknooppunten. Dit is alleen zinvol bij het maken van een iterator of tree-walker met een entiteitsknooppunt als root; in dit geval betekent dit dat het entiteitsknooppunt op de eerste positie van de traversie verschijnt. Aangezien entiteiten geen deel uitmaken van de documentboom, verschijnen ze niet bij het doorlopen van de documentboom.

```java
public const long SHOW_ENTITY;
```
