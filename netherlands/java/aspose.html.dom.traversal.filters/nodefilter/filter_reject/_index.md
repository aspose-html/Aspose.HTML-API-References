## NodeFilter.FILTER_REJECT field

Weiger het knooppunt. Navigatiemethoden die zijn gedefinieerd voor NodeIterator of TreeWalker zullen dit knooppunt niet retourneren. Voor TreeWalker worden de kinderen van dit knooppunt ook geweigerd. NodeIterators beschouwen dit als een synoniem voor FILTER_SKIP.

```java
public const short FILTER_REJECT;
```
