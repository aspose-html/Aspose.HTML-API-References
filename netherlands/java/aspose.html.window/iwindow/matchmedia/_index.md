## IWindow.MatchMedia method

Retourneert een nieuw MediaQueryList-object dat vervolgens kan worden gebruikt om te bepalen of het document overeenkomt met de media-query-String, en om het document te monitoren om te detecteren wanneer het overeenkomt (of niet meer overeenkomt) met die media-query. Zie de CSSOM View Module-specificatie: [https://www.w3.org/TR/cssom-view/#extensions-to-the-window-interface](https://www.w3.org/TR/cssom-view/#extensions-to-the-window-interface)

```java
public MediaQueryList MatchMedia(String query)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| query | String | De string die een media-query bevat; zie [https://drafts.csswg.org/mediaqueries/](https://drafts.csswg.org/mediaqueries/) voor details. |

### Retourwaarde

MediaQueryList-object
