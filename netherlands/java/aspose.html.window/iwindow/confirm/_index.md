## IWindow.Confirm method

Toont een modale OK/Cancel‑prompt met het opgegeven bericht, wacht tot de gebruiker deze sluit, en retourneert true als de gebruiker op OK klikt en false als de gebruiker op Annuleren klikt.

```java
public bool Confirm(String message)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| message | String | Het bericht. |

### Retourwaarde

Retourneert true als de gebruiker op OK klikt en false als de gebruiker op Annuleren klikt.
