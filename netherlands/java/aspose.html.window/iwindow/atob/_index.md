## IWindow.Atob method

Neemt de invoergegevens in de vorm van een Unicode‑string die base64‑gecodeerde binaire gegevens bevat, decodeert deze en retourneert een string bestaande uit tekens in het bereik U+0000 tot U+00FF, elk een binair byte met waarden 0x00 tot 0xFF respectievelijk, overeenkomend met die binaire gegevens.

```java
public String Atob(String data)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| gegevens | String | De Unicode‑string die base64‑gecodeerde binaire data bevat |

### Retourwaarde

De string die bestaat uit tekens in het bereik U+0000 tot U+00FF

| uitzondering | conditie |
