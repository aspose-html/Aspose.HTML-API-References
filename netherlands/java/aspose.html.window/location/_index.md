## Location class

Locatie‑objecten bieden een weergave van het adres van het actieve document van hun Document‑browsing‑context, en stellen toe dat de huidige invoer van de sessiegeschiedenis van de browsing‑context wordt gewijzigd door invoer toe te voegen of te vervangen in het geschiedenis‑object.

public sealed class Location : DOMObject
