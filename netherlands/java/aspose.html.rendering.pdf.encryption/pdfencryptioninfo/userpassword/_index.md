## PdfEncryptionInfo.UserPassword property

Geeft of stelt het gebruikerswachtwoord in.

```java
public String UserPassword { get; set; }
```

### Property Value

Het gebruikerswachtwoord.

## Opmerkingen

Het openen van het document met het juiste gebruikerswachtwoord (of het openen van een document dat geen gebruikerswachtwoord heeft) maakt extra bewerkingen mogelijk die worden uitgevoerd volgens de gebruikers-toegangsrechten die zijn gespecificeerd in het encryptie‑woordenboek van het document.
