## PdfEncryptionInfo.UserPassword property

Geeft het gebruikerswachtwoord terug of stelt dit in.

```java
public String UserPassword { get; set; }
```

### Property Value

Het gebruikerswachtwoord.

## Opmerkingen

Het openen van het document met het juiste gebruikerswachtwoord (of het openen van een document dat geen gebruikerswachtwoord heeft) maakt het mogelijk extra bewerkingen uit te voeren volgens de toegangsrechten voor de gebruiker die zijn gespecificeerd in het encryptiewoordenboek van het document.
