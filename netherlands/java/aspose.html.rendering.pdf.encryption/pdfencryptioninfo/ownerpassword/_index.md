## PdfEncryptionInfo.OwnerPassword property

Haalt het Owner‑wachtwoord op of stelt het in.

```java
public String OwnerPassword { get; set; }
```

### Property Value

Het owner‑wachtwoord.

## Opmerkingen

Het openen van het document met het juiste owner‑wachtwoord (ervan uitgaande dat dit niet hetzelfde is als het gebruikerswachtwoord) geeft volledige (owner) toegang tot het document. Deze onbeperkte toegang omvat de mogelijkheid om de wachtwoorden van het document en de toegangsrechten te wijzigen.
