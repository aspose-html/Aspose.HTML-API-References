## PdfEncryptionInfo.OwnerPassword property

Haalt het eigenaarswachtwoord op of stelt het in.

```java
public String OwnerPassword { get; set; }
```

### Property Value

Het eigenaarswachtwoord.

## Opmerkingen

Het openen van het document met het juiste eigenaarswachtwoord (ervan uitgaande dat het niet hetzelfde is als het gebruikerswachtwoord) geeft volledige (eigenaars‑)toegang tot het document. Deze onbeperkte toegang omvat de mogelijkheid om de wachtwoorden van het document en de toegangspermissies te wijzigen.
