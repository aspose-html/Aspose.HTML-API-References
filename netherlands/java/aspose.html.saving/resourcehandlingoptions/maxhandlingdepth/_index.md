## ResourceHandlingOptions.MaxHandlingDepth property

Haalt of stelt de maximale diepte van pagina's in die zullen worden verwerkt. Een diepte van 1 betekent dat alleen pagina's die rechtstreeks vanuit het opgeslagen document worden verwezen, worden verwerkt. Het instellen van deze eigenschap op -1 leidt tot verwerking van alle pagina's. Standaardwaarde is 0.

```java
public int MaxHandlingDepth { get; set; }
```
