## TextSaveOptions.EnableListItemMarkers property

Optie die wordt toegepast op OL- en UL-elementen bij HTML-conversie naar tekst. In feite definieert het hoe de buitenste lijstmarkeringen van OL- en UL-elementen worden verwerkt. Als true worden itemnummers toegevoegd vóór OL-items, of punten vóór UL-items. Als false worden ze niet toegevoegd (standaardgedrag volgens de specificatie).

```java
public bool EnableListItemMarkers { get; set; }
```
