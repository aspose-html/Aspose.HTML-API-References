## INodeIterator.Detach method

Ontkoppelt de NodeIterator van de set waarover deze itereerde, maakt eventuele computationele bronnen vrij en plaatst de iterator in de STATUS INVALID. Nadat detach is aangeroepen, zullen oproepen naar nextNode of previousNode de uitzondering INVALID_STATE_ERR veroorzaken.
