## IElementTraversal interface

De ElementTraversal‑interface is een reeks alleen‑lees‑attributen die een auteur in staat stellen gemakkelijk tussen elementen in een document te navigeren. In conforme implementaties van Element Traversal moeten alle objecten die Element implementeren ook de ElementTraversal‑interface implementeren.

```java
public interface IElementTraversal
```
