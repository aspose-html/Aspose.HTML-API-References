## ITreeWalker.NextSibling method

Verplaatst de TreeWalker naar de volgende broer of zus van het huidige knooppunt en retourneert het nieuwe knooppunt. Als het huidige knooppunt geen zichtbaar volgend broertje of zusje heeft, wordt null geretourneerd en blijft het huidige knooppunt behouden.

```java
public Node NextSibling()
```

### Retourwaarde

Het nieuwe knooppunt, of null als het huidige knooppunt geen volgende sibling heeft in de logische weergave van de TreeWalker.
