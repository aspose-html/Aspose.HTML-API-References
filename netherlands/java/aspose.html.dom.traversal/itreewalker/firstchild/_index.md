## ITreeWalker.FirstChild method

Verplaatst de TreeWalker naar het eerste zichtbare kind van het huidige knooppunt en retourneert het nieuwe knooppunt. Als het huidige knooppunt geen zichtbare kinderen heeft, wordt null geretourneerd en blijft het huidige knooppunt behouden.

```java
public Node FirstChild()
```

### Retourwaarde

Het nieuwe knooppunt, of null als het huidige knooppunt geen zichtbare kinderen heeft in de logische weergave van de TreeWalker.
