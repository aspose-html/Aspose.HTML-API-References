## ITreeWalker.ParentNode method

Verplaatst naar en retourneert het dichtstbijzijnde zichtbare bovenliggende knooppunt van het huidige knooppunt. Als de zoektocht naar parentNode omhoog probeert te gaan vanaf de root van de TreeWalker, of als er geen zichtbaar bovenliggend knooppunt wordt gevonden, behoudt deze methode de huidige positie en retourneert null.

```java
public Node ParentNode()
```

### Retourwaarde

Het nieuwe bovenliggende knooppunt, of null als het huidige knooppunt geen bovenliggend knooppunt heeft in de logische weergave van de TreeWalker.
