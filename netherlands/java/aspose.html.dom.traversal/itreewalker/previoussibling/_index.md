## ITreeWalker.PreviousSibling method

Verplaatst de TreeWalker naar de vorige sibling van het huidige knooppunt, en retourneert het nieuwe knooppunt. Als het huidige knooppunt geen zichtbaar vorige sibling heeft, wordt null geretourneerd en blijft het huidige knooppunt behouden.

```java
public Node PreviousSibling()
```

### Retourwaarde

Het nieuwe knooppunt, of null als het huidige knooppunt geen vorige sibling heeft in de logische weergave van de TreeWalker.
