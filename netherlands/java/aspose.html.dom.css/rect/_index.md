## Rect class

De Rect-interface wordt gebruikt om elke rect‑waarde te vertegenwoordigen. Deze interface weerspiegelt de waarden in de onderliggende stijl‑eigenschap. Daarom wijzigen aanpassingen aan de [`CSSPrimitiveValue`](../cssprimitivevalue/)‑objecten de stijl‑eigenschap.

```java
public class Rect : DOMObject
```
