## ICSSImportRule.Href property

De alleen-lezen href-eigenschap van de CSSImportRule-interface retourneert de URL die is opgegeven door de @import-atregel.

De opgeloste URL zal het href-attribuut van het bijbehorende stylesheet zijn.

```java
public String Href { get; }
```

### Property Value

Retourneert de URL van het bijbehorende stylesheet dat is opgegeven door de @import-atregel.
