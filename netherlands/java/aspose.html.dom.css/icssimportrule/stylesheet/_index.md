## ICSSImportRule.StyleSheet property

Het stylesheet waarnaar deze regel verwijst, als het is geladen. De waarde van dit attribuut is null als het stylesheet nog niet is geladen of als het niet zal worden geladen (bijv. als het stylesheet voor een mediatype is dat niet wordt ondersteund door de user agent).

```java
public ICSSStyleSheet StyleSheet { get; }
```

### Property Value

Retourneert het CSS-stylesheet dat is opgegeven door de @import-at-regel. Dit zal worden weergegeven als een [`CSSStyleSheet`](../../icssstylesheet/) object.
