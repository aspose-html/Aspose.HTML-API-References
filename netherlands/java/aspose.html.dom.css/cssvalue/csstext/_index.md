## CSSValue.CSSText property

De cssText-eigenschap van de [`CSSValue`](../) interface vertegenwoordigt de momenteel berekende CSS-eigenschapswaarde.

Opmerking: Deze eigenschap maakte deel uit van een poging om een getypeerd CSS Object Model te maken. Deze poging is verlaten, en de meeste browsers implementeren het niet.

```java
public abstract String CSSText { get; set; }
```

### Property Value

Een DOMString die de huidige CSS‑eigenschapwaarde vertegenwoordigt.
