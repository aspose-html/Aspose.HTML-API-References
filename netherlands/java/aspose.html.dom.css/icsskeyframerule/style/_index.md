## ICSSKeyframeRule.Style property

De alleen‑lezen CSSKeyframeRule.style‑eigenschap is de [`CSSStyleDeclaration`](../../icssstyledeclaration/) interface voor het declaratieblok van de [`CSSKeyframeRule`](../).

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

Een [`CSSStyleDeclaration`](../../icssstyledeclaration/) object, met de volgende eigenschappen:

computed flag - Unset. declarations - De gedeclareerde declaraties in de regel, in de volgorde waarin ze zijn opgegeven, verkorte eigenschappen uitgebreid naar lange vormen. parent CSS rule - Het contextobject, dat een alias is voor this.owner node - Null.
