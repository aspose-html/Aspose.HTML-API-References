## ICSSKeyframeRule interface

De `CSSKeyframeRule`-interface beschrijft een object dat een set stijlen voor een bepaalde keyframe vertegenwoordigt. Het correspondeert met de inhoud van een enkele keyframe van een @keyframes‑at‑rule.

```java
public interface ICSSKeyframeRule : ICSSRule
```
