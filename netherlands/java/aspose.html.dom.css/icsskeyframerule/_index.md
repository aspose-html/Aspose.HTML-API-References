## ICSSKeyframeRule interface

De `CSSKeyframeRule`‑interface beschrijft een object dat een set stijlen voor een gegeven keyframe vertegenwoordigt. Het komt overeen met de inhoud van een enkel keyframe van een @keyframes‑at‑rule.

```java
public interface ICSSKeyframeRule : ICSSRule
```
