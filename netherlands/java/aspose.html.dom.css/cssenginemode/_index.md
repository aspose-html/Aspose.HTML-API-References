## CSSEngineMode enumeration

Specificeert de CSSEngine-modus. Waarden hebben de volgende betekenis:

default - CSS-parser werkt volgens de w3c‑aanbeveling en ondersteunt geen aangepaste extensies. not-strict - Alle niet‑gedocumenteerde eigenschappen worden geparseerd en kunnen via worden benaderd.

```java
[Flags]
public enum CSSEngineMode
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| Default | `0` | CSS-parser werkt volgens de w3c‑aanbeveling en ondersteunt de aangepaste extensies niet. |
| NotStrict | `1` | CSS-parser werkt in niet‑strikte modus. Alle niet‑gedocumenteerde eigenschappen worden geparseerd en kunnen via worden benaderd. |
