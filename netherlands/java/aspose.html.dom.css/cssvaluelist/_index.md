## CSSValueList class

De CSSValueList-interface biedt de abstractie van een geordende collectie van CSS‑waarden.

Opmerking: Deze interface maakte deel uit van een poging om een getypeerd CSS Object Model te creëren. Deze poging is opgegeven, en de meeste browsers implementeren het niet.

```java
public class CSSValueList : CSSValue, ICSSValueList, IEnumerable<CSSValue>
```
