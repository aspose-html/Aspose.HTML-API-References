## CSSValueList.Length property

De alleen-lezen eigenschap length van de CSSValueList-interface geeft het aantal CSSValues in de lijst weer. Het bereik van geldige indexwaarden is 0 tot en met length-1.

```java
public int Length { get; }
```

### Property Value

Een unsigned long die het aantal CSSValues in de huidige instantie weergeeft.
