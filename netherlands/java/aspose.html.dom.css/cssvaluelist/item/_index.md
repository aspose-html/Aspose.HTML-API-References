## CSSValueList indexer

De item()‑methode van de CSSValueList‑interface wordt gebruikt om een CSSValue op te halen via een ordinale index.

De volgorde in deze collectie vertegenwoordigt de volgorde van de waarden in de CSS‑stijleigenschap. Als de index groter dan of gelijk is aan het aantal waarden in de lijst, retourneert deze methode null.

```java
public CSSValue this[int index] { get; }
```

### Retourwaarde

Een CSSValue‑object op de indexpositie in de CSSValueList, of null als dat geen geldige index is.

### Property Value

Een unsigned long die de index van de CSS‑waarde binnen de collectie weergeeft.
