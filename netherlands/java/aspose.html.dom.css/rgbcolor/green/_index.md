### Property Value

De groene componentwaarde van deze Color.

## Opmerkingen

De kleur van elke pixel wordt weergegeven als een 32‑bit getal: 8 bits elk voor alfa, rood, groen en blauw (ARGB). De alfa‑component geeft de transparantie van de kleur aan: 0 is volledig transparant en 255 is volledig ondoorzichtig. Evenzo vertegenwoordigt een A‑waarde van 255 een ondoorzichtige kleur. Een A‑waarde van 1 tot en met 254 vertegenwoordigt een halfdoorzichtige kleur. De kleur wordt meer ondoorzichtig naarmate A nadert tot 255.
