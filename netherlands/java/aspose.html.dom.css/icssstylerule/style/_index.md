## ICSSStyleRule.Style property

De alleen-lezen style-eigenschap is de [`CSSStyleDeclaration`](../../icssstyledeclaration/) interface voor het declaratieblok van de [`CSSStyleRule`](../).

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

Het style-attribuut moet een CSSStyleDeclaration-object retourneren voor de stijlregel, met de volgende eigenschappen:

computed flag - Unset.declarations - De gedeclareerde declaraties in de regel, in opgegeven volgorde.parent CSS rule - Het contextobject.owner node - Null.
