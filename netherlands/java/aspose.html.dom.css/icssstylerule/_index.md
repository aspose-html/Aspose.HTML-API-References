## ICSSStyleRule interface

De CSSStyleRule-interface vertegenwoordigt een enkele CSS-stijlregel. Het selectorText‑attribuut moet bij ophalen het resultaat van het serialiseren van de bijbehorende groep selectors teruggeven.

```java
public interface ICSSStyleRule : ICSSRule
```
