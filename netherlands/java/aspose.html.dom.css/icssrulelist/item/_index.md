## ICSSRuleList indexer

Gebruikt om een CSS‑regel op te halen via de methode item() (http://www.w3.org/TR/DOM-Level-2-Style/css.html#CSS-CSSRuleList). De volgorde in deze collectie vertegenwoordigt de volgorde van de regels in het CSS‑stylesheet. Als index groter dan of gelijk is aan het aantal regels in de lijst, wordt null geretourneerd.

```java
public ICSSRule this[int index] { get; }
```

### Retourwaarde

De item(index)‑methode moet het indexde CSSRule‑object in de collectie retourneren. Als er geen indexde object in de collectie bestaat, moet de methode null retourneren.

### Property Value

De index in de collectie van CSS‑regels.
