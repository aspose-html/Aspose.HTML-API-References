## IStyleSheetList indexer

De item(index)-methode moet het indexde [`CSS style sheet`](../../icssstylesheet/) in de collectie retourneren. Als er geen object op die index in de collectie bestaat, moet de methode null retourneren.

```java
public ICSSStyleSheet this[int index] { get; }
```

### Retourwaarde

Een [`CSSStyleSheet`](../../icssstylesheet/) object, of null als er geen bestaat voor deze index.

### Property Value

Een geheel getal dat de index van het item in de collectie aangeeft dat moet worden geretourneerd.

## Opmerkingen
