## IStyleSheetList.Length property

Het length‑attribuut moet het aantal CSS‑stylesheets dat door de collectie wordt vertegenwoordigd retourneren. Het bereik van geldige child‑stylesheet‑indices is 0 tot en met length‑1.

```java
public int Length { get; }
```

### Property Value

Een geheel getal dat het aantal items in de collectie aangeeft.
