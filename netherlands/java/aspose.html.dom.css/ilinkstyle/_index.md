## ILinkStyle interface

De LinkStyle-interface biedt een mechanisme waarmee een stylesheet kan worden opgehaald van het knooppunt dat verantwoordelijk is voor het koppelen ervan aan een document. Een instantie van de LinkStyle-interface kan worden verkregen met bindingspecifieke cast‑methoden op een instantie van een koppelingsknooppunt (HTMLLinkElement,

HTMLStyleElement of ProcessingInstruction in DOM Level 2).

Zie ook de [CSS Object Model (CSSOM) # ](https://www.w3.org/TR/cssom-1/#the-linkstyle-interface)[LinkStyle](https://www.w3.org/TR/cssom-1/#the-linkstyle-interface).
