## ICSSRule.Type property

Het type van de regel, zoals gedefinieerd in [CSSOM # dom‑cssrule‑type](https://drafts.csswg.org/cssom/#dom-cssrule-type). Er wordt verwacht dat bindingspecifieke cast‑methoden kunnen worden gebruikt om van een instantie van de CSSRule‑interface naar de specifieke afgeleide interface die door het type wordt geïmpliceerd te casten.

```java
public short Type { get; }
```

### Property Value

Een niet‑negatief geheel getal dat is gekoppeld aan een bepaald type regel. Dit item wordt geïnitialiseerd wanneer een regel wordt aangemaakt en kan niet worden gewijzigd.
