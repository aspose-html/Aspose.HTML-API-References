## ICSSRule.ParentRule property

Als deze regel zich bevindt binnen een andere regel (bijv. een stijlsregel binnen een @media‑blok), is dit de omvattende regel. Als deze regel niet genest is binnen andere regels, retourneert dit null.

```java
public ICSSRule ParentRule { get; }
```

### Property Value

Een [`CSSRule`](../) die het type is van de omvattende regels. Als de huidige regel zich binnen een media‑query bevindt, zou dit [`CSSMediaRule`](../../icssmediarule/) retourneren. Anders retourneert het null.
