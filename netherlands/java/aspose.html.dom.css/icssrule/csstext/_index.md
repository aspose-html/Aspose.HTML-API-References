## ICSSRule.CSSText property

De cssText-eigenschap van de [`CSSRule`](../)-interface retourneert de feitelijke tekst van een [`CSSStyleSheet`](../../icssstylesheet/)-stijlregel.

Opmerking: Verwarring met deze eigenschap en element-style CSSStyleDeclaration.cssText vermijden.

```java
public String CSSText { get; set; }
```

### Property Value

Retourneert een serialisatie van de CSS-regel. Bij het instellen van het cssText-attribuut moet er niets gebeuren.
