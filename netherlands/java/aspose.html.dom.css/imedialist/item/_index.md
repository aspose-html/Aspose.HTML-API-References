## IMediaList indexer

De item(index)-methode moet een serialisatie van de mediavraag in de verzameling mediavragen teruggeven die wordt opgegeven door index, of null, als index groter dan of gelijk is aan het aantal mediavragen in de verzameling.

```java
public String this[int index] { get; }
```

### Retourwaarde

Retourneert een String die een mediavraag als tekst weergeeft, gegeven de indexwaarde van de mediavraag binnen de [`MediaList`](../).

### Property Value

Een geheel getal dat de index van het item in de collectie aangeeft dat moet worden geretourneerd.
