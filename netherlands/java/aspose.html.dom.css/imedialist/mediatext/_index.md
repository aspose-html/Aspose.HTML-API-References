## IMediaList.MediaText property

Een Stringifier die een DOMString retourneert die de MediaList als tekst weergeeft, en ook toestaat een nieuwe MediaList in te stellen.

```java
public String MediaText { get; }
```

### Property Value

De parseerbare tekstuele weergave van de medialijst. Dit is een door komma's gescheiden lijst van media.

### Uitzonderingen

| uitzondering | conditie |
| --- | --- |
| DOMException | SYNTAX_ERR: Wordt opgegeven als de opgegeven String-waarde een syntaxisfout bevat en niet parseerbaar is. NO_MODIFICATION_ALLOWED_ERR: Wordt opgegeven als deze medialijst alleen-lezen is. |
