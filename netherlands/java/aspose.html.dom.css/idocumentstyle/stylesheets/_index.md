## IDocumentStyle.StyleSheets property

Een lijst met alle stijlbladen die expliciet zijn gekoppeld aan of ingebed in een document. Voor HTML‑documenten omvat dit externe stijlbladen, opgenomen via het HTML‑LINK‑element, en inline STYLE‑elementen.

```java
public IStyleSheetList StyleSheets { get; }
```

### Property Value

De lijst met alle stijlbladen die expliciet zijn gekoppeld aan of ingebed in een document.
