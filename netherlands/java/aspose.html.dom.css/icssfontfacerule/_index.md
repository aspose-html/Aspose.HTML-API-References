## ICSSFontFaceRule interface

De CSSFontFaceRule-interface vertegenwoordigt een @font-face‑regel in een CSS‑stijlblad. De @font-face‑regel wordt gebruikt om een set van lettertype‑beschrijvingen vast te leggen.

```java
public interface ICSSFontFaceRule : ICSSRule
```
