## ICSSKeyframesRule.DeleteRule method

De deleteRule‑methode verwijdert de [`CSSKeyframeRule`](../../icsskeyframerule/) met de opgegeven sleutel. Als er geen regel met deze sleutel bestaat, doet de methode niets.

```java
public void DeleteRule(String key)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| key | String | De sleutel die de te verwijderen regel beschrijft. De sleutel moet overeenkomen met een getal tussen 0 en 1, anders wordt de regel genegeerd. |
