## ICSSKeyframesRule.FindRule method

De findRule‑methode retourneert de regel met een sleutel die overeenkomt met de meegegeven sleutel. Als zo’n regel niet bestaat, wordt een null‑waarde geretourneerd.

```java
public ICSSKeyframeRule FindRule(String key)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| key | String | De sleutel die de te vinden regel beschrijft. De sleutel moet overeenkomen met een getal tussen 0 en 1, anders wordt de regel genegeerd. |

### Retourwaarde

Retourneert de laatst gedeclareerde [`CSSKeyframeRule`](../../icsskeyframerule/) die overeenkomt met de opgegeven keyframe-selector. Als er geen overeenkomende regel bestaat, doet de methode niets.
