## IStyleSheet.Media property

De media‑eigenschap van de [`StyleSheet`](../) interface specificeert de beoogde bestemmingsmedia voor stijl‑informatie. Het is een alleen‑lezen, array‑achtig [`MediaList`](../../imedialist/) object en kan worden verwijderd met deleteMedium() en toegevoegd met appendMedium().

```java
public IMediaList Media { get; }
```

### Property Value

Het media‑attribuut moet het [`MediaList`](../../imedialist/) object retourneren dat aan het CSS‑stylesheet is gekoppeld.

## Opmerkingen

[CSSOM](https://drafts.csswg.org/cssom/) defines APIs (including generic parsing and serialization rules) for Media Queries, Selectors, and of course CSS itself.
