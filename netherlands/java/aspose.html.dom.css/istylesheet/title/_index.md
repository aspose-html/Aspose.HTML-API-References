## IStyleSheet.Title property

De title‑eigenschap van de [`StyleSheet`](../) interface retourneert de adviserende titel van het huidige stijlblad.

De title wordt vaak gespecificeerd in de [`ownerNode`](../ownernode/).

```java
public String Title { get; }
```

### Property Value

Het parentStyleSheet‑attribuut moet het bovenliggende [`CSS style sheet`](../../icssstylesheet/) retourneren.
