## IStyleSheet.Href property

De href-eigenschap van de [`StyleSheet`](../)-interface retourneert de locatie van het stylesheet.

```java
public String Href { get; }
```

### Property Value

uri is een String die de URI van het stylesheet bevat.

## Opmerkingen

Als het stylesheet een gekoppeld stylesheet is, is de waarde van het attribuut de locatie. Voor inline stylesheets is de waarde van dit attribuut NULL.

Deze eigenschap is alleen-lezen in Firefox, Opera, Google Chrome en Safari, en lees/schrijf in Internet Explorer.
