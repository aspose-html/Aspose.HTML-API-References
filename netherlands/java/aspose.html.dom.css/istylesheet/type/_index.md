## IStyleSheet.Type property

Dit specificeert de stylesheet-taal voor dit stylesheet. De stylesheet-taal wordt gespecificeerd als een contenttype (bijv. "text/css").

```java
public String Type { get; }
```

### Property Value

Het type-attribuut moet het type retourneren.
