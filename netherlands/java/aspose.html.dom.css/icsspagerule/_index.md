## ICSSPageRule interface

De CSSPageRule‑interface vertegenwoordigt een @page‑regel binnen een CSS‑stijlblad. De @page‑regel wordt gebruikt om de afmetingen, oriëntatie, marges, enz. van een paginabox voor paginagestuurde media te specificeren.

```java
public interface ICSSPageRule : ICSSRule
```
