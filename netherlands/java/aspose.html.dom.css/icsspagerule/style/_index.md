## ICSSPageRule.Style property

De alleen‑lezen style‑eigenschap van de [`CSSPageRule`](../) interface retourneert een [`CSSStyleDeclaration`](../../icssstyledeclaration/) object. Dit vertegenwoordigt een object dat een CSS‑declaratieblok is en stijl‑informatie en diverse stijlgerelateerde methoden en eigenschappen blootlegt.

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

Een [`CSSStyleDeclaration`](../../icssstyledeclaration/) object dat een CSS‑declaratieblok vertegenwoordigt.
