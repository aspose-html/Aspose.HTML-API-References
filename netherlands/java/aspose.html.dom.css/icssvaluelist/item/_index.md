## ICSSValueList indexer

Deze methode wordt gebruikt om een CSSValue op te halen via een ordinale index. De volgorde in deze collectie vertegenwoordigt de volgorde van de waarden in de CSS‑stijleigenschap. Als de index groter dan of gelijk aan het aantal waarden in de lijst is, retourneert dit null.

Zie ook de [CSSOM](https://www.w3.org/TR/2000/REC-DOM-Level-2-Style-20001113/css.html#CSS-CSSValueList)[#CSSValueList](https://www.w3.org/TR/2000/REC-DOM-Level-2-Style-20001113/css.html#CSS-CSSValueList).

```java
public CSSValue this[int index] { get; }
```

### Retourwaarde

De [`CSSValue`](../../cssvalue/) op de indexpositie in de [`CSSValueList`](../../cssvaluelist/), of null als dat geen geldige index is.

### Property Value

De index in de collectie.

## Opmerkingen

Deze functie werd oorspronkelijk gedefinieerd in de [DOM Style Level 2](https://www.w3.org/TR/DOM-Level-2-Style) specificatie, maar is sindsdien uit alle standaardiseringsinspanningen verwijderd.

Het is vervangen door een moderne, maar incompatibele, [CSS Typed Object Model API](https://developer.mozilla.org/en-US/docs/Web/API/CSS_Typed_OM_API) die nu op de standaardroute staat.
