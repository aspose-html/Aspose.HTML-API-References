## ICSSMediaRule.InsertRule method

De insertRule()‑methode van de CSSGroupingRule interface voegt een nieuwe CSS‑regel toe aan een lijst met CSS‑regels.

```java
public long InsertRule(String rule, long index)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| regel | String | De media-regel als CSSOMString. |
| index | Int64 | Een optionele index waarop de regel moet worden ingevoegd; standaard 0. |

### Retourwaarde

De insertRule(rule, index)-methode retourneert het resultaat van het invoegen van een CSS-regel in de onderliggende CSS-regels op de opgegeven index.
