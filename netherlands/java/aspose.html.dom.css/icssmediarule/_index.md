## ICSSMediaRule interface

De CSSMediaRule‑interface vertegenwoordigt een @media‑regel in een CSS‑stijlblad. Een @media‑regel kan worden gebruikt om stijlregels af te bakenen voor specifieke mediatypen.

```java
public interface ICSSMediaRule : ICSSRule
```
