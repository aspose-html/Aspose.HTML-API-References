De cssRules-eigenschap van de CSSGroupingRule-interface retourneert een [`CSSRuleList`](../../icssrulelist/) die een verzameling van [`CSSRule`](../../icssrule/) objecten bevat.

```java
public ICSSRuleList CSSRules { get; }
```

### Property Value

Het cssRules-attribuut moet een [`CSSRuleList`](../../icssrulelist/) object retourneren voor de onderliggende CSS-regels.
