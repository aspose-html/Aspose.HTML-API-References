## ICSSStyleSheet.CSSRules property

De alleen-lezen CSSStyleSheet eigenschap cssRules retourneert een live [`CSSRuleList`](../../icssrulelist/) die een realtime, up-to-date lijst biedt van elke CSS-regel die de stylesheet bevat. Elk item in de lijst is een [`CSSRule`](../../icssrule/) die een enkele regel definieert.

```java
public ICSSRuleList CSSRules { get; }
```

### Property Value

Een live-updating [`CSSRuleList`](../../icssrulelist/) die elke CSS-regel bevat waaruit de stylesheet bestaat. Elke invoer in de regelijst is een [`CSSRule`](../../icssrule/) object dat één regel beschrijft waaruit de stylesheet bestaat.

## Opmerkingen

[CSSOM](https://drafts.csswg.org/cssom/) defines APIs (including generic parsing and serialization rules) for Media Queries, Selectors, and of course CSS itself.
