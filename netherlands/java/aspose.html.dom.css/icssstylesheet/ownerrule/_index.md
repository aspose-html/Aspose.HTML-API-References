## ICSSStyleSheet.OwnerRule property

De alleen‑lezen CSSStyleSheet‑eigenschap ownerRule retourneert de [`CSSImportRule`](../../icssimportrule/) die overeenkomt met de @import‑at‑rule die het stylesheet in het document heeft geïmporteerd. Als het stylesheet niet met @import in het document is geïmporteerd, is de geretourneerde waarde null.

```java
public ICSSRule OwnerRule { get; }
```

### Property Value

Een CSSImportRule die overeenkomt met de @import‑regel die het stylesheet in het document heeft geïmporteerd. Als het stylesheet niet met @import in het document is geïmporteerd, is de geretourneerde waarde null.
