## IElementCSSInlineStyle interface

Inline‑stijl‑informatie die aan elementen is gekoppeld, wordt blootgesteld via het style‑attribuut. Dit vertegenwoordigt de inhoud van het STYLE‑attribuut voor HTML‑elementen (of elementen in andere schema's of DTD's die het STYLE‑attribuut op dezelfde manier gebruiken). Verwacht wordt dat een instantie van de ElementCSSInlineStyle-interface verkregen kan worden door bindingspecifieke cast‑methoden te gebruiken op een instantie van de Element-interface wanneer het element inline CSS‑stijl‑informatie ondersteunt.
