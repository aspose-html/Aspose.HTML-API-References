## IElementCSSInlineStyle.Style property

Het style-attribuut moet een CSS-declaratieblokobject retourneren waarvan de berekende vlag niet is ingesteld, waarvan de bovenliggende CSS-regel null is, en waarvan het eigenaarknooppunt het contextobject is.

```java
public ICSSStyleDeclaration Style { get; }
```

### Property Value

Het bijbehorende CSS-declaratieblok voor het knooppunt of null als er geen bijbehorend CSS-declaratieblok bestaat.
