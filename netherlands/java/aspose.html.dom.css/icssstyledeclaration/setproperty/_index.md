## SetProperty(String, String) {#setproperty}

De CSSStyleDeclaration.setProperty()-methode‑interface wordt gebruikt om een eigenschapswaarde met standaardprioriteit in te stellen binnen dit declaratieblok. Standaardprioriteit is niet "important", d.w.z. String.Empty.

```java
public void SetProperty(String propertyName, String value)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| propertyName | String | Een String die de te wijzigen CSS-eigenschapsnaam (koppeltekennotatie) vertegenwoordigt. |
| waarde | String | Een String die de nieuwe eigenschapswaarde bevat. Indien niet opgegeven, wordt deze behandeld als een lege String. |

## SetProperty(String, String, String) {#setproperty_1}

De CSSStyleDeclaration.setProperty()-methode‑interface wordt gebruikt om een eigenschapswaarde met standaardprioriteit in te stellen binnen dit declaratieblok. Standaardprioriteit is niet "important", d.w.z. String.Empty.

```java
public void SetProperty(String propertyName, String value, String priority)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| propertyName | String | Een String die de te wijzigen CSS-eigenschapsnaam (koppeltekennotatie) vertegenwoordigt. |
| waarde | String | Een String die de nieuwe eigenschapswaarde bevat. Indien niet opgegeven, wordt deze behandeld als een lege String. |
| priority | String | Een String die het instellen van de \"important\" CSS-prioriteit mogelijk maakt. Indien niet opgegeven, wordt deze behandeld als een lege String. De volgende waarden worden geaccepteerd: String-waarde \"important\", sleutelwoord undefined of lege String-waarde \"\". |
