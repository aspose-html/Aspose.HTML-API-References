## ICSSStyleDeclaration.GetPropertyValue method

De CSSStyleDeclaration.getPropertyValue()‑methodinterface retourneert een String die de waarde van een opgegeven CSS‑eigenschap bevat.

```java
public String GetPropertyValue(String propertyName)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| propertyName | String | propertyName is een String die de naam van de te controleren eigenschap (koppeltekennotatie) vertegenwoordigt. |

### Retourwaarde

value is een String die de waarde van de eigenschap bevat. Als deze niet is ingesteld, retourneert het een lege String.
