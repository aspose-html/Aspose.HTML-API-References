## ICSSStyleDeclaration.GetPropertyPriority method

Gebruikt om de prioriteit van een CSS‑eigenschap op te halen (bijv. de "important"‑qualificatie) als de eigenschap expliciet is ingesteld in dit declaratie‑blok.

```java
public String GetPropertyPriority(String propertyName)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| propertyName | String | property is een DOMString die de naam van de te controleren eigenschap vertegenwoordigt. |

### Retourwaarde

priority is een DOMString die de prioriteit (bijv. \"important\") weergeeft als deze bestaat. Als er geen bestaat, retourneert het een lege String.
