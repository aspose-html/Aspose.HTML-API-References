## ICSSStyleDeclaration.RemoveProperty method

De CSSStyleDeclaration.removeProperty()‑methodinterface verwijdert een eigenschap uit een CSS‑stijl‑declaratie‑object.

```java
public String RemoveProperty(String propertyName)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| propertyName | String | propertyName is een String die de te verwijderen eigenschapsnaam weergeeft. Merk op dat meerwoordige eigenschapsnamen worden geschreven met koppeltekens en niet in camelCase. |

### Retourwaarde

oldValue is een DOMString die gelijk is aan de waarde van de CSS‑eigenschap voordat deze werd verwijderd.

### Uitzonderingen

| uitzondering | conditie |
| --- | --- |
| DOMException | NO_MODIFICATION_ALLOWED_ERR: als de eigenschap of het declaratieblok alleen-lezen is. |
