## ICSSStyleDeclaration.Length property

De alleen-lezen eigenschap retourneert een geheel getal dat het aantal eigenschappen aangeeft dat expliciet is ingesteld in dit CSS-declaratieblok. Het bereik van geldige indexen is 0 tot en met length-1.

```java
public int Length { get; }
```

### Property Value

Een geheel getal dat het aantal stijlen aangeeft dat expliciet is ingesteld op de bovenliggende instantie.
