## ICSSStyleDeclaration indexer

Wordt gebruikt om de eigenschappen op te halen die expliciet zijn ingesteld in dit declaratieblok. De volgorde van de opgehaalde eigenschappen met deze methode hoeft niet de volgorde te zijn waarin ze zijn ingesteld. Deze methode kan worden gebruikt om over alle eigenschappen in dit declaratieblok te itereren.

```java
public String this[int index] { get; }
```

### Retourwaarde

propertyName is een String die de naam van de CSS‑eigenschap op de opgegeven index is.

### Property Value

index is de index van het op te halen knooppunt. De index is nulgebaseerd.
