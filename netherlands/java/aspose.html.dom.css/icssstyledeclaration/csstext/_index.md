## ICSSStyleDeclaration.CSSText property

De parseerbare tekstuele weergave van het declaratieblok (exclusief de omringende accolades). Het instellen van dit attribuut leidt tot het parseren van de nieuwe waarde en het resetten van alle eigenschappen in het declaratieblok, inclusief het verwijderen of toevoegen van eigenschappen.

```java
public String CSSText { get; set; }
```

### Property Value

Het instellen van dit attribuut wijzigt de inline-stijl. Als je een tekstuele weergave van een berekend declaratieblok wilt, kun je deze verkrijgen met JSON.Stringify().
