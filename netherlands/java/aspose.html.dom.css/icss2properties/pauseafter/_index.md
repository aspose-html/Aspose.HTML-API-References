## ICSS2Properties.PauseAfter property

Deze eigenschappen geven een pauze aan die moet worden waargenomen vóór (of na) het uitspreken van de inhoud van een element. Waarden hebben de volgende betekenissen:

'[time](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-time)' - Geeft de pauze weer in absolute tijdseenheden (seconden en milliseconden).'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - Verwijst naar het inverse van de waarde van de ['speech-rate'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-speech-rate) eigenschap. Bijvoorbeeld, als de speech-rate 120 woorden per minuut is (d.w.z. een woord duurt een halve seconde, of 500 ms), dan betekent een ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) van 100 % een pauze van 500 ms en een ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) van 20 % betekent 100 ms.
