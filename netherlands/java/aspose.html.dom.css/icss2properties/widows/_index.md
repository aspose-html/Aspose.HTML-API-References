## ICSS2Properties.Widows property

De ['orphans'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-orphans) eigenschap specificeert het minimum aantal regels van een alinea dat onderaan een pagina moet blijven staan. De ['widows'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-widows) eigenschap specificeert het minimum aantal regels van een alinea dat bovenaan een pagina moet blijven staan. Voorbeelden van hoe ze worden gebruikt om pagina-eindes te beheersen worden hieronder gegeven.

```java
public String Widows { get; set; }
```
