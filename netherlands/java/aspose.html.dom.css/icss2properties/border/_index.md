## ICSS2Properties.Border property

De 'border' eigenschap is een afkorting voor het instellen van dezelfde breedte, kleur en stijl voor alle vier de randen van een vak. In tegenstelling tot de afkortingen 'margin' en 'padding' kan de 'border' eigenschap geen verschillende waarden voor de vier randen instellen. Om dit te doen moet een of meer van de andere border‑eigenschappen worden gebruikt.

```java
public String Border { get; set; }
```
