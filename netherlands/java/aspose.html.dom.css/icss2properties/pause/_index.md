## ICSS2Properties.Pause property

De ['pause'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause) eigenschap is een afkorting voor het instellen van ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) en ['pause-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-after). Als twee waarden worden opgegeven, is de eerste waarde ['pause-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-before) en de tweede ['pause-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pause-after). Als slechts één waarde wordt opgegeven, geldt deze voor beide eigenschappen.

```java
public String Pause { get; set; }
```
