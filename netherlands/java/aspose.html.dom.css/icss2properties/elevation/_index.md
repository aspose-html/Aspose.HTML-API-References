## ICSS2Properties.Elevation property

Waarden van deze eigenschap hebben de volgende betekenissen:

'angle' - Specificeert de elevatie als een hoek, tussen '-90deg' en '90deg'. '0deg' betekent op de voorste horizon, wat losjes betekent op niveau met de luisteraar. '90deg' betekent direct boven en '-90deg' betekent direct onder. below - Hetzelfde als '-90deg'. level - Hetzelfde als '0deg'. above - Hetzelfde als '90deg'. higher - Voegt 10 graden toe aan de huidige elevatie. lower - Trekt 10 graden af van de huidige elevatie.

public String Elevation { get; set; }
