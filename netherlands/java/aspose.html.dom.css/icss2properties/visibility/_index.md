## ICSS2Properties.Visibility property

De ['visibility'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visufx.html#propdef-visibility) eigenschap bepaalt of de door een element gegenereerde vakken worden weergegeven. Onzichtbare vakken beïnvloeden nog steeds de lay-out (stel de ['display'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-display) eigenschap in op 'none' om de vakgeneratie volledig te onderdrukken). Waarden hebben de volgende betekenissen:

visible - Het gegenereerde vak is zichtbaar. hidden - Het gegenereerde vak is onzichtbaar (volledig transparant), maar beïnvloedt nog steeds de lay-out. collapse - Raadpleeg de sectie over [dynamic row and column effects](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#dynamic-effects) in tabellen. Indien toegepast op elementen anders dan rijen of kolommen, heeft 'collapse' dezelfde betekenis als 'hidden'.

public String Visibility { get; set; }
