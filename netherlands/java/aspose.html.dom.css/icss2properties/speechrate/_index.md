## ICSS2Properties.SpeechRate property

Deze eigenschap specificeert de spreektempo. Merk op dat zowel absolute als relatieve sleutelwoordwaarden zijn toegestaan (vergelijk met ['font-size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html#propdef-font-size)). Waarden hebben de volgende betekenissen:

'[number](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-number)' - Specificeert de spreektempo in woorden per minuut, een hoeveelheid die enigszins per taal varieert maar desalniettemin breed ondersteund wordt door spraaksynthesizers.

x-slow - Hetzelfde als 80 woorden per minuut.

slow - Hetzelfde als 120 woorden per minuut.

medium - Hetzelfde als 180 - 200 woorden per minuut.

fast - Hetzelfde als 300 woorden per minuut.

x-fast - Hetzelfde als 500 woorden per minuut.

faster - Voegt 40 woorden per minuut toe aan de huidige spraaksnelheid.

slower - Trekt 40 woorden per minuut af van de huidige spraaksnelheid.

```java
public String SpeechRate { get; set; }
```
