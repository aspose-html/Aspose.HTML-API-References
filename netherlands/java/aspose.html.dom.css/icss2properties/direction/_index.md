## ICSS2Properties.Direction property

Deze eigenschap specificeert de basis schrijfrichting van blokken en de richting van insluitingen en overschrijvingen (zie ['unicode-bidi'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-unicode-bidi)) voor het Unicode bidirectionele algoritme. Daarnaast specificeert het de richting van [tabel](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html) kolomlay-out, de richting van horizontale [overflow](https://www.w3.org/TR/1998/REC-CSS2-19980512/visufx.html#overflow), en de positie van een onvolledige laatste regel in een blok in het geval van 'text-align: justify'.

```java
public String Direction { get; set; }
```
