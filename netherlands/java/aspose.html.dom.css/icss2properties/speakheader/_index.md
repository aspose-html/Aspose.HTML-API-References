## ICSS2Properties.SpeakHeader property

Deze eigenschap specificeert of tabelkoppen vóór elke cel worden uitgesproken, of alleen vóór een cel wanneer die cel is gekoppeld aan een andere kop dan de vorige cel. De waarden hebben de volgende betekenis:

once - De kop wordt één keer uitgesproken, vóór een reeks cellen. always - De kop wordt vóór elke relevante cel uitgesproken.

```java
public String SpeakHeader { get; set; }
```
