## ICSS2Properties.SpeakHeader property

Deze eigenschap geeft aan of tabelkoppen vóór elke cel worden uitgesproken, of alleen vóór een cel wanneer die cel geassocieerd is met een andere kop dan de vorige cel. De waarden hebben de volgende betekenissen:

once - De kop wordt één keer uitgesproken, vóór een reeks cellen. always - De kop wordt vóór elke relevante cel uitgesproken.

```java
public String SpeakHeader { get; set; }
```
