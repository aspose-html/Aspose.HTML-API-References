## ICSS2Properties.BorderRightWidth property

Deze eigenschap is een afkorting voor het instellen van 'border-top-width', 'border-right-width', 'border-bottom-width' en 'border-left-width' op dezelfde plaats in het stylesheet.

Als er slechts één waarde is, wordt deze op alle zijden toegepast. Als er twee waarden zijn, worden de boven- en onderranden op de eerste waarde ingesteld en de rechter- en linkerzijde op de tweede. Als er drie waarden zijn, wordt de bovenkant op de eerste waarde ingesteld, de linker- en rechterkant op de tweede, en de onderkant op de derde. Als er vier waarden zijn, worden ze respectievelijk op de bovenkant, rechts, onderkant en links toegepast.

```java
public String BorderRightWidth { get; set; }
```
