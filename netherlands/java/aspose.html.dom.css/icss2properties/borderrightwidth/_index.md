## ICSS2Properties.BorderRightWidth property

Deze eigenschap is een verkorte eigenschap voor het instellen van 'border-top-width', 'border-right-width', 'border-bottom-width' en 'border-left-width' op dezelfde plaats in het stylesheet.

Als er slechts één waarde is, geldt deze voor alle zijden. Als er twee waarden zijn, worden de boven- en onderranden ingesteld op de eerste waarde en de rechter- en linkerrand op de tweede. Als er drie waarden zijn, wordt de bovenkant ingesteld op de eerste waarde, de linker- en rechterkant op de tweede, en de onderkant op de derde. Als er vier waarden zijn, gelden ze respectievelijk voor boven, rechts, onder en links.

```java
public String BorderRightWidth { get; set; }
```
