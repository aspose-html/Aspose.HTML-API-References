## ICSS2Properties.BackgroundColor property

Deze eigenschap stelt de achtergrondkleur van een element in, ofwel een waarde of het sleutelwoord 'transparent', om de onderliggende kleuren door te laten schijnen.

```java
public String BackgroundColor { get; set; }
```

### Retourwaarde

background-color eigenschap

### Property Value

Een kleur is ofwel een trefwoord of een numerieke RGB-specificatie.
