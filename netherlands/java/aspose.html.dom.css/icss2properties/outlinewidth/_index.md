## ICSS2Properties.OutlineWidth property

De omtrek die met de outline-eigenschappen wordt gecreëerd, wordt "over" een box getekend, d.w.z. de omtrek staat altijd bovenop en beïnvloedt de positie of grootte van de box, of van andere boxen, niet. Daarom veroorzaakt het weergeven of onderdrukken van omtrekken geen reflow.

```java
public String OutlineWidth { get; set; }
```
