## ICSS2Properties.BackgroundAttachment property

Als een achtergrondafbeelding is opgegeven, specificeert deze eigenschap of deze vast staat ten opzichte van het viewport ('fixed') of meebeweegt met het document ('scroll').

Zelfs als de afbeelding vast staat, is deze alleen zichtbaar wanneer ze zich in de achtergrond- of opvulruimte van het element bevindt. Dus, tenzij de afbeelding getegeld is ('background-repeat: repeat'), kan ze onzichtbaar zijn.

```java
public String BackgroundAttachment { get; set; }
```
