## ICSS2Properties.EmptyCells property

In het gescheiden randenmodel regelt deze eigenschap de weergave van randen rond cellen die geen zichtbare inhoud hebben. Lege cellen en cellen met de 'visibility' property ingesteld op 'hidden' worden beschouwd als geen zichtbare inhoud.

```java
public String EmptyCells { get; set; }
```
