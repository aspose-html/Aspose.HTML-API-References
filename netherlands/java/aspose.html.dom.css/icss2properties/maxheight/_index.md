## ICSS2Properties.MaxHeight property

Deze twee eigenschappen stellen auteurs in staat om de hoogte van boxen te beperken tot een bepaald bereik. Waarden hebben de volgende betekenissen:

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - Specificeert een vaste minimum- of maximumberekende hoogte.'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - Specificeert een percentage voor het bepalen van de berekende waarde. Het percentage wordt berekend ten opzichte van de hoogte van het gegenereerde vak's [containing block](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#containing-block). Als de hoogte van het omvattende blok niet expliciet is gespecificeerd (i.e., het hangt af van de inhoudshoogte), wordt de procentuele waarde geïnterpreteerd als 'auto'.none - (Alleen op ['max-height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-max-height)) Geen limiet op de hoogte van de box.

public String MaxHeight { get; set; }
