## ICSS2Properties.LineHeight property

Als de eigenschap is ingesteld op een [block-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#block-level) element waarvan de inhoud bestaat uit [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) elementen, specificeert het de minimale hoogte van elk gegenereerd inline vak.

Als de eigenschap is ingesteld op een [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) element, specificeert het de exacte hoogte van elk door het element gegenereerd vak. (Behalve voor inline [replaced](https://www.w3.org/TR/1998/REC-CSS2-19980512/conform.html#replaced-element) elementen, waarbij de hoogte van het vak wordt gegeven door de ['height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-height) eigenschap.)

```java
public String LineHeight { get; set; }
```
