## ICSS2Properties.MinWidth property

Deze twee eigenschappen stellen auteurs in staat om de breedte van boxen te beperken tot een bepaald bereik. Waarden hebben de volgende betekenissen:

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - Specificeert een vaste minimum- of maximumberekende breedte. '[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - Specificeert een percentage voor het bepalen van de berekende waarde. Het percentage wordt berekend ten opzichte van de breedte van het gegenereerde box's [containing block](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#containing-block). none - (Alleen op ['max-width'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-max-width)) Geen limiet op de breedte van de box.

```java
public String MinWidth { get; set; }
```
