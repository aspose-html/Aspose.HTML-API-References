## ICSS2Properties.Richness property

Specificeert de rijkdom, of helderheid, van de spreekstem. Een rijke stem zal zich voortplanten in een grote ruimte, een gladde stem niet. (De term "gladde" verwijst naar hoe de golfvorm eruitziet wanneer getekend.)

```java
public String Richness { get; set; }
```
