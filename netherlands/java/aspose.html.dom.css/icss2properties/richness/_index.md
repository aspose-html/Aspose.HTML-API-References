## ICSS2Properties.Richness property

Specificeert de rijkheid, of helderheid, van de spreekstem. Een rijke stem zal "doordringen" in een grote ruimte, een zachte stem niet. (De term "zacht" verwijst naar hoe de golfvorm eruitziet wanneer getekend.)

```java
public String Richness { get; set; }
```
