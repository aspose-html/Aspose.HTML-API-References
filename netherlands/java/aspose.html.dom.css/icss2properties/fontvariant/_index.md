## ICSS2Properties.FontVariant property

In een small-caps lettertype zien de glyphs voor kleine letters er vergelijkbaar uit als de hoofdletters, maar dan in een kleinere grootte en met iets andere verhoudingen. De 'font-variant' eigenschap vraagt zo'n lettertype aan voor bicameraal (met twee gevallen, zoals het Latijnse schrift). Deze eigenschap heeft geen zichtbaar effect voor scripts die unicameraal (met slechts één geval, zoals de meeste van de wereldschrijfsystemen) zijn.

```java
public String FontVariant { get; set; }
```
