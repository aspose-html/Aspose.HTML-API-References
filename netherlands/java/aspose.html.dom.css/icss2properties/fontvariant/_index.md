## ICSS2Properties.FontVariant property

In een small-caps lettertype lijken de glyphs voor kleine letters op die voor hoofdletters, maar dan in een kleinere grootte en met iets andere verhoudingen. De 'font-variant' property vraagt zo'n lettertype voor bicamerale (met twee hoofdletters, zoals bij het Latijnse schrift). Deze eigenschap heeft geen zichtbaar effect voor scripts die unicamerale (met slechts één hoofdletter, zoals bij de meeste wereldschriften) zijn.

```java
public String FontVariant { get; set; }
```
