## ICSS2Properties.SpeakPunctuation property

Deze eigenschap specificeert hoe interpunctie wordt uitgesproken. Waarden hebben de volgende betekenissen:

code - Interpunctie zoals puntkomma's, accolades en dergelijke moet letterlijk worden uitgesproken. none - Interpunctie wordt niet uitgesproken, maar in plaats daarvan natuurlijk weergegeven als verschillende pauzes.

```java
public String SpeakPunctuation { get; set; }
```
