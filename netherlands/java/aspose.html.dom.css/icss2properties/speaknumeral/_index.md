## ICSS2Properties.SpeakNumeral property

Deze eigenschap bepaalt hoe cijfers worden uitgesproken. Waarden hebben de volgende betekenissen:

cijfers - Spreek het cijfer uit als afzonderlijke cijfers. Dus, "237" wordt uitgesproken als "Twee Drie Zeven".continuous - Spreek het cijfer uit als een volledig getal. Dus, "237" wordt uitgesproken als "Twee honderd drieënzeventig". Woordrepresentaties zijn taalafhankelijk.

```java
public String SpeakNumeral { get; set; }
```
