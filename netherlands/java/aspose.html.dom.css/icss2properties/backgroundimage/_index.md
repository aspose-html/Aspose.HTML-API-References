## ICSS2Properties.BackgroundImage property

Deze eigenschap stelt de achtergrondafbeelding van een element in. Bij het instellen van een achtergrondafbeelding moeten auteurs ook een achtergrondkleur opgeven die wordt gebruikt wanneer de afbeelding niet beschikbaar is. Wanneer de afbeelding beschikbaar is, wordt deze bovenop de achtergrondkleur gerenderd. (Zo is de kleur zichtbaar in de transparante delen van de afbeelding).

```java
public String BackgroundImage { get; set; }
```

### Retourwaarde

background-image-eigenschap

### Property Value

Waarden voor deze eigenschap zijn of , om de afbeelding op te geven, of 'none' wanneer er geen afbeelding wordt gebruikt.
