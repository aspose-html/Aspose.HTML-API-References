## ICSS2Properties.Font property

De 'font' eigenschap is, behalve zoals hieronder beschreven, een verkorte eigenschap voor het instellen van 'font-style', 'font-variant', 'font-weight', 'font-size', 'line-height' en 'font-family' op dezelfde plaats in het stijlblad. De syntaxis van deze eigenschap is gebaseerd op een traditionele typografische afkortingsnotatie om meerdere eigenschappen met betrekking tot lettertypen in te stellen.

```java
public String Font { get; set; }
```
