## ICSS2Properties.CounterReset property

The ['counter-reset'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-counter-reset) eigenschap bevat ook een lijst van één of meer namen van tellers, elk optioneel gevolgd door een geheel getal. Het geheel getal geeft de waarde die de teller krijgt bij elke verschijning van het element. De standaardwaarde is 0.

```java
public String CounterReset { get; set; }
```
