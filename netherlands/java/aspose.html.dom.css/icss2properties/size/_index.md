## ICSS2Properties.Size property

Deze eigenschap specificeert de grootte en oriëntatie van een pagina-box.

De grootte van een pagina-box kan "absoluut" (vaste grootte) of "relatief" (schaalbaar, d.w.z. passend bij beschikbare bladgroottes) zijn. Relatieve pagina-boxen stellen gebruikersagenten in staat een document te schalen en optimaal gebruik te maken van de doelformaat.

Drie waarden voor de ['size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-size) eigenschap creëren een relatieve pagina-box:

auto - De pagina-box wordt ingesteld op de grootte en oriëntatie van het doelformaat.landscape - Overschrijft de oriëntatie van het doel. De pagina-box heeft dezelfde grootte als het doel, en de langere zijden zijn horizontaal.portrait - Overschrijft de oriëntatie van het doel. De pagina-box heeft dezelfde grootte als het doel, en de kortere zijden zijn horizontaal.

```java
public String Size { get; set; }
```
