## ICSS2Properties.Size property

Deze eigenschap specificeert de grootte en oriëntatie van een pagina‑vak.

De grootte van een pagina‑vak kan zowel "absolute" (vaste grootte) als "relative" (schaalbaar, i.e., passend bij beschikbare bladgroottes) zijn. Relatieve pagina‑vakken stellen gebruikersagenten in staat een document te schalen en optimaal gebruik te maken van de doelformaat.

Drie waarden voor de ['size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-size) eigenschap creëren een relatief pagina‑vak:

auto - Het pagina‑vak wordt ingesteld op de grootte en oriëntatie van het doelformaat.landscape - Overschrijft de oriëntatie van het doel. Het pagina‑vak heeft dezelfde grootte als het doel, en de langere zijden zijn horizontaal.portrait - Overschrijft de oriëntatie van het doel. Het pagina‑vak heeft dezelfde grootte als het doel, en de kortere zijden zijn horizontaal.

```java
public String Size { get; set; }
```
