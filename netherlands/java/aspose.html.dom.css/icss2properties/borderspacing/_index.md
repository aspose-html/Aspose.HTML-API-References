## ICSS2Properties.BorderSpacing property

De lengtes geven de afstand aan die aangrenzende celranden scheidt. Als één lengte wordt opgegeven, geldt deze zowel voor de horizontale als verticale spatiëring. Als er twee worden opgegeven, geeft de eerste de horizontale spatiëring en de tweede de verticale spatiëring. Lengtes mogen niet negatief zijn.

```java
public String BorderSpacing { get; set; }
```
