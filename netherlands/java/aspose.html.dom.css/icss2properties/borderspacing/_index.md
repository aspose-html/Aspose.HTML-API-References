## ICSS2Properties.BorderSpacing property

De lengtes geven de afstand aan die aangrenzende celranden scheidt. Als één lengte wordt opgegeven, geeft deze zowel de horizontale als verticale afstand. Als er twee worden opgegeven, geeft de eerste de horizontale afstand en de tweede de verticale afstand. Lengtes mogen niet negatief zijn.

```java
public String BorderSpacing { get; set; }
```
