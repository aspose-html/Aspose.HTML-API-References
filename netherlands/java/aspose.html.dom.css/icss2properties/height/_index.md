## ICSS2Properties.Height property

Deze eigenschap specificeert de [inhoudshoogte](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#content-height) van vakken die worden gegenereerd door blokniveau en [vervangen](https://www.w3.org/TR/1998/REC-CSS2-19980512/conform.html#replaced-element) elementen.

Deze eigenschap is niet van toepassing op niet-vervangen [inline-level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) elementen. De hoogte van de vakken van een niet-vervangen inline-element wordt gegeven door de (mogelijk geërfde) ['line-height'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visudet.html#propdef-line-height) waarde.

```java
public String Height { get; set; }
```
