## ICSS2Properties.TextDecoration property

Deze eigenschap beschrijft decoraties die aan de tekst van een element worden toegevoegd. Als de eigenschap is gespecificeerd voor een [block‑level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#block-level) element, beïnvloedt deze alle inline‑level afstammelingen van het element. Als deze is gespecificeerd voor (of een) [inline‑level](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#inline-level) element, beïnvloedt deze alle door het element gegenereerde boxen. Als het element geen inhoud of geen tekstinhoud heeft (bijv. het IMG‑element in HTML), moeten gebruikersagenten deze eigenschap [negeren](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#ignore).

De waarden hebben de volgende betekenissen:

none - Produceert geen tekstdecoratie. underline - Elke regel tekst wordt onderstreept. overline - Elke regel tekst heeft een lijn erboven. line-through - Elke regel tekst heeft een lijn door het midden. blink - Tekst knippert (wisselt tussen zichtbaar en onzichtbaar).
