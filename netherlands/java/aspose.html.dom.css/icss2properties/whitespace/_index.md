## ICSS2Properties.WhiteSpace property

Deze eigenschap geeft aan hoe [whitespace](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#whitespace) binnen het element wordt behandeld. Waarden hebben de volgende betekenissen:

normal - Deze waarde instrueert gebruikersagenten om reeksen van witruimte samen te voegen, en regels te breken wanneer nodig om regelvakken te vullen. Extra regeleinden kunnen worden gecreëerd door voorkomen van "\A" in gegenereerde inhoud (bijv. voor het BR-element in HTML).pre - Deze waarde voorkomt dat gebruikersagenten reeksen van witruimte samenvoegen. Regels worden alleen gebroken bij nieuwe regels in de bron, of bij voorkomen van "\A" in gegenereerde inhoud.nowrap - Deze waarde voegt witruimte samen zoals bij 'normal', maar onderdrukt regeleinden binnen tekst behalve die gecreëerd door "\A" in gegenereerde inhoud (bijv. voor het BR-element in HTML).

```java
public String WhiteSpace { get; set; }
```
