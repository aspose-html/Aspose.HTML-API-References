## ICSS2Properties.CaptionSide property

Deze eigenschap specificeert de positie van de bijschriftbox ten opzichte van de tabelbox. Waarden hebben de volgende betekenissen:

top - Plaatst de bijschriftbox boven de tabelbox.bottom - Plaatst de bijschriftbox onder de tabelbox.left - Plaatst de bijschriftbox links van de tabelbox.right - Plaatst de bijschriftbox rechts van de tabelbox.

```java
public String CaptionSide { get; set; }
```
