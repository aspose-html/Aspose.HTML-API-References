## ICSS2Properties.TextTransform property

Deze eigenschap regelt hoofdlettereffecten van de tekst van een element. De waarden hebben de volgende betekenissen:

capitalize - Zet het eerste teken van elk woord in hoofdletters. uppercase - Zet alle tekens van elk woord in hoofdletters. lowercase - Zet alle tekens van elk woord in kleine letters. none - Geen hoofdlettereffecten.

public String TextTransform { get; set; }
