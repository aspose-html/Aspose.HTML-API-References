## ICSS2Properties.FontSizeAdjust property

In bicamerale scripts zijn de subjectieve schijnbare grootte en leesbaarheid van een lettertype minder afhankelijk van hun 'font-size'-waarde dan van de waarde van hun 'x-height', of, praktischer, van de verhouding tussen deze twee waarden, de aspectwaarde (lettergrootte gedeeld door x-height). Hoe hoger de aspectwaarde, hoe waarschijnlijker het is dat een lettertype bij kleinere groottes leesbaar blijft. Omgekeerd zullen lettertypen met een lagere aspectwaarde sneller onleesbaar worden onder een bepaalde drempelgrootte dan lettertypen met een hogere aspectwaarde. Eenvoudige lettertypevervanging die alleen op font-grootte vertrouwt, kan leiden tot onleesbare tekens.

```java
public String FontSizeAdjust { get; set; }
```
