## ICSS2Properties.TextIndent property

Deze eigenschap specificeert de inspringing van de eerste regel tekst in een blok. Preciezer specificeert het de inspringing van de eerste box die in de eerste [line box](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#line-box) van het blok stroomt. De box wordt ingesprongen ten opzichte van de linker (of rechter, voor rechts-naar-links lay-out) rand van de regelbox. Gebruikersagenten moeten deze inspringing weergeven als lege ruimte.

De waarden hebben de volgende betekenissen:

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - De inspringing is een vaste lengte.'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - De inspringing is een percentage van de breedte van het omvattende blok.
