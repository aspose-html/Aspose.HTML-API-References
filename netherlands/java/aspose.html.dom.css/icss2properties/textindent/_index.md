## ICSS2Properties.TextIndent property

Deze eigenschap specificeert de inspringing van de eerste regel tekst in een blok. Nauwkeuriger specificeert het de inspringing van het eerste vak dat in de eerste [line box](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#line-box) van het blok stroomt. Het vak wordt ingesprongen ten opzichte van de linker (of rechter, bij rechts-naar-links lay-out) rand van de regelvak. Gebruikersagenten moeten deze inspringing weergeven als lege ruimte.

De waarden hebben de volgende betekenissen:

'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - De inspringing is een vaste lengte.'[percentage](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-percentage)' - De inspringing is een percentage van de breedte van het omvattende blok.
