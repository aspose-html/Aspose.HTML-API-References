## ICSS2Properties.ZIndex property

Voor een gepositioneerd element, specificeert de ['z-index'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-z-index) eigenschap:

Het stapelniveau van het element in de huidige stapelcontext. Of het element een lokale stapelcontext creëert.

```java
public String ZIndex { get; set; }
```
