## ICSS2Properties.ZIndex property

Voor een gepositioneerde box specificeert de ['z-index'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-z-index) eigenschap:

Het stapelniveau van de box in de huidige stapelcontext. Of de box een lokale stapelcontext tot stand brengt.

```java
public String ZIndex { get; set; }
```
