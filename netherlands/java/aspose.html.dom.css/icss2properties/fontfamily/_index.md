## ICSS2Properties.FontFamily property

Deze eigenschap specificeert een geprioriteerde lijst van lettertypefamilienamen en/of generieke familienamen. Om het probleem op te lossen dat een enkel lettertype mogelijk niet alle tekens in een document kan weergeven, of dat niet alle lettertypen op alle systemen beschikbaar zijn, maakt deze eigenschap het mogelijk voor auteurs om een lijst van lettertypen, allemaal van dezelfde stijl en grootte, op te geven die achtereenvolgens worden geprobeerd om te zien of ze een glyf voor een bepaald teken bevatten. Deze lijst wordt een lettertype‑set genoemd.

```java
public String FontFamily { get; set; }
```
