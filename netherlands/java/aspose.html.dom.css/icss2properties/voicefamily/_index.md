## ICSS2Properties.VoiceFamily property

De waarde is een door komma's gescheiden, geprioriteerde lijst van stemfamilienamen (vergelijk met ['font-family'](https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html#propdef-font-family)). Waarden hebben de volgende betekenissen:

'generic-voice' - Waarden zijn stemfamilies. Mogelijke waarden zijn 'male', 'female' en 'child'.'specific-voice' - Waarden zijn specifieke instanties (bijv. comedian, trinoids, carlos, lani).

```java
public String VoiceFamily { get; set; }
```
