## ICSS2Properties.TableLayout property

De ['table-layout'](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#propdef-table-layout) eigenschap bepaalt het algoritme dat wordt gebruikt om de tabelcellen, rijen en kolommen te rangschikken. De waarden hebben de volgende betekenis:

fixed - Gebruik het vaste tabelindelingsalgoritme auto - Gebruik elk automatisch tabelindelingsalgoritme

```java
public String TableLayout { get; set; }
```
