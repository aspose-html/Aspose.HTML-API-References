## ICSS2Properties.Position property

De waarden van deze eigenschap hebben de volgende betekenissen:

static - De box is een normale box, opgesteld volgens de [normale stroom](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#normal-flow). De ['left'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-left) en ['top'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-top) eigenschappen worden niet toegepast.

```java
public String Position { get; set; }
```

### Retourwaarde

relative - De positie van de box wordt berekend volgens de [normale stroom](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#normal-flow) (dit wordt de positie in normale stroom genoemd). Vervolgens wordt de box [relatief](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#relative-positioning) ten opzichte van zijn normale positie verplaatst. Wanneer een box B relatief gepositioneerd is, wordt de positie van de volgende box berekend alsof B niet verplaatst is.
