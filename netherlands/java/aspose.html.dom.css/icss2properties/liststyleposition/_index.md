## ICSS2Properties.ListStylePosition property

Deze eigenschap specificeert de positie van het markeringsvak in de hoofdblokvak. De waarden hebben de volgende betekenissen:

outside - Het markeringsvak bevindt zich buiten de hoofdblokvak. Opmerking. CSS1 specificeerde de precieze locatie van het markeringsvak niet en om compatibiliteitsredenen blijft CSS2 even onduidelijk. Voor meer precieze controle over markeringsvakken, gebruik alstublieft markers. inside - Het markeringsvak is het eerste inline vak in de hoofdblokvak, waarna de inhoud van het element stroomt.

```java
public String ListStylePosition { get; set; }
```
