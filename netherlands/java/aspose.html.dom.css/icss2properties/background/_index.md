## ICSS2Properties.Background property

De 'background' eigenschap is een verkorte eigenschap voor het instellen van de individuele achtergrond‑eigenschappen (d.w.z. 'background-color', 'background-image', 'background-repeat', 'background-attachment' en 'background-position') op dezelfde plaats in het stylesheet.

```java
public String Background { get; set; }
```

### Retourwaarde

de background eigenschap

### Property Value

Haalt een verkorte eigenschap op of stelt deze in voor het instellen van de individuele achtergrond‑eigenschappen op dezelfde plaats in het stylesheet.
