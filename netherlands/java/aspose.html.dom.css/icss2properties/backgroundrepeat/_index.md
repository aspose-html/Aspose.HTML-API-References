## ICSS2Properties.BackgroundRepeat property

Als een achtergrondafbeelding is opgegeven, bepaalt deze eigenschap of de afbeelding wordt herhaald (getegeld) en hoe. Alle tegelpatronen bestrijken de inhouds- en opvulgebieden van een box. De waarden hebben de volgende betekenissen:

repeat - De afbeelding wordt zowel horizontaal als verticaal herhaald. repeat-x - De afbeelding wordt alleen horizontaal herhaald. repeat-y - De afbeelding wordt alleen verticaal herhaald. no-repeat - De afbeelding wordt niet herhaald: er wordt slechts één exemplaar van de afbeelding getekend.

```java
public String BackgroundRepeat { get; set; }
```
