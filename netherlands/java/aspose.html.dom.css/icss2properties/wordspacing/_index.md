## ICSS2Properties.WordSpacing property

Deze eigenschap specificeert het spatiëringsgedrag tussen woorden. Waarden hebben de volgende betekenissen:

normal - De normale tussen-woordruimte, zoals gedefinieerd door het huidige lettertype en/of de UA.'[length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)' - Deze waarde geeft een tussen-woordruimte aan naast de standaardruimte tussen woorden. Waarden kunnen negatief zijn, maar er kunnen implementatie‑specifieke limieten bestaan.

```java
public String WordSpacing { get; set; }
```
