## ICSS2Properties.ListStyleImage property

Deze eigenschap stelt de afbeelding in die wordt gebruikt als lijstitemmarkering. Wanneer de afbeelding beschikbaar is, zal deze de marker-set vervangen door de ['list-style-type'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-list-style-type) marker.

public String ListStyleImage { get; set; }
