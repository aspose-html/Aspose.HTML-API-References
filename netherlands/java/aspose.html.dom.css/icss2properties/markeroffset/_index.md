## ICSS2Properties.MarkerOffset property

Deze eigenschap specificeert de afstand tussen de dichtstbijzijnde [randranden](https://www.w3.org/TR/1998/REC-CSS2-19980512/box.html#border-edge) van een marker-box en de bijbehorende [principal-box](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#principal-box). De offset kan een door de gebruiker opgegeven ([length](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-length)) zijn of door de UA gekozen worden ('auto'). Lengtes kunnen negatief zijn, maar er kunnen implementatie‑specifieke limieten bestaan.

```java
public String MarkerOffset { get; set; }
```
