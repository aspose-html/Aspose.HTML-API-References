## ICSS2Properties.Marks property

Bij hoogwaardig afdrukken worden markeringen vaak buiten de pagina‑box toegevoegd. Deze eigenschap specificeert of kruismarkeringen, snijmarkeringen of beide moeten worden weergegeven net buiten de rand van de [page box](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#page-box).

Snijmarkeringen geven aan waar de pagina moet worden gesneden. Kruismarkeringen (ook bekend als register‑ of registratie‑markeringen) worden gebruikt om vellen uit te lijnen.

Markeringen zijn alleen zichtbaar op absolute pagina‑boxen (zie de ['size'](https://www.w3.org/TR/1998/REC-CSS2-19980512/page.html#propdef-size) eigenschap). In relatieve pagina‑boxen wordt de pagina‑box uitgelijnd met het doel en bevinden de markeringen zich buiten het afdrukbare gebied.

De grootte, stijl en positie van kruistekens zijn afhankelijk van de user agent.

public String Marks { get; set; }
