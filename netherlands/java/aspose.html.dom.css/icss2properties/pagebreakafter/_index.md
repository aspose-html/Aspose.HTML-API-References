## ICSS2Properties.PageBreakAfter property

Waarden voor deze eigenschappen hebben de volgende betekenissen:

auto - Noch dwingt noch verbiedt een pagina-einde vóór (na, binnen) de gegenereerde box. always - Dwingt altijd een pagina-einde vóór (na) de gegenereerde box. avoid - Vermijd een pagina-einde vóór (na, binnen) de gegenereerde box. left - Dwingt één of twee pagina-einden vóór (na) de gegenereerde box zodat de volgende pagina wordt opgemaakt als een linkerpagina. right - Dwingt één of twee pagina-einden vóór (na) de gegenereerde box zodat de volgende pagina wordt opgemaakt als een rechterpagina.

public String PageBreakAfter { get; set; }
