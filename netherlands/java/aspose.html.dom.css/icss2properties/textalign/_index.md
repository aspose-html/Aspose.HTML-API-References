## ICSS2Properties.TextAlign property

Deze eigenschap beschrijft hoe inline-inhoud van een blok wordt uitgelijnd. Waarden hebben de volgende betekenissen:

left, right, center, and justify - Links, rechts, gecentreerd en dubbel uitvullen tekst, respectievelijk.'[String](https://www.w3.org/TR/1998/REC-CSS2-19980512/syndata.html#value-def-String)' - Specificeert een String waarop cellen in een tabelkolom worden uitgelijnd (zie de sectie over [horizontal alignment in a column](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html#column-alignment) voor details en een voorbeeld). Deze waarde is alleen van toepassing op [table](https://www.w3.org/TR/1998/REC-CSS2-19980512/tables.html) cellen. Indien ingesteld op andere elementen, wordt het behandeld als 'left' of 'right', afhankelijk van of ['direction'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-direction) 'ltr' of 'rtl' is, respectievelijk.

public String TextAlign { get; set; }
