## ICSS2Properties.Speak property

Deze eigenschap specificeert of tekst aurale weergave krijgt en zo ja, op welke manier (enigszins analoog aan de ['display'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-display) eigenschap). De mogelijke waarden zijn:

none - Onderdrukt aurale weergave zodat het element geen tijd nodig heeft om te renderen. Merk op dat afstammelingen deze waarde echter kunnen overschrijven en uitgesproken zullen worden. (Om er zeker van te zijn dat zowel een element als zijn afstammelingen niet worden gerenderd, gebruik de ['display'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-display) eigenschap).normal - Gebruikt taalonafhankelijke uitspraakregels voor het renderen van een element en zijn kinderen.spell-out - Spelt de tekst letter voor letter (handig voor acroniemen en afkortingen).

```java
public String Speak { get; set; }
```
