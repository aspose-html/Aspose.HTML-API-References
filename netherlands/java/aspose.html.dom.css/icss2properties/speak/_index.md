## ICSS2Properties.Speak property

Deze eigenschap specificeert of tekst auditief wordt weergegeven en, zo ja, op welke wijze (enigszins analoog aan de ['display'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-display) property). De mogelijke waarden zijn:

none - Onderdrukt auditieve weergave zodat het element geen tijd nodig heeft om te renderen. Merk op dat afstammelingen deze waarde echter kunnen overschrijven en zullen worden uitgesproken. (Om er zeker van te zijn dat zowel een element als zijn afstammelingen niet worden gerenderd, gebruik de ['display'](https://www.w3.org/TR/1998/REC-CSS2-19980512/visuren.html#propdef-display) property).normal - Gebruikt taalonafhankelijke uitspraakregels voor het weergeven van een element en zijn kinderen. spell-out - Spelt de tekst letter voor letter (handig voor acroniemen en afkortingen).

public String Speak { get; set; }
