## ICSS2Properties.Cue property

De ['cue'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue) eigenschap is een afkorting voor het instellen van ['cue-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-before) en ['cue-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-after). Als er twee waarden worden gegeven, is de eerste waarde ['cue-before'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-before) en de tweede ['cue-after'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-cue-after). Als er slechts één waarde wordt gegeven, geldt deze voor beide eigenschappen.

```java
public String Cue { get; set; }
```
