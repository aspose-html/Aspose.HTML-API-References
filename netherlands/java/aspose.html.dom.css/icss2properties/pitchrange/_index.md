## ICSS2Properties.PitchRange property

Specificeert variatie in gemiddelde toonhoogte. De waargenomen toonhoogte van een menselijke stem wordt bepaald door de fundamentele frequentie en heeft doorgaans een waarde van 120 Hz voor een mannelijke stem en 210 Hz voor een vrouwelijke stem. Menselijke talen worden gesproken met variërende intonatie en toonhoogte; deze variaties dragen extra betekenis en nadruk over. Dus een zeer levendige stem, d.w.z. een stem die sterk geïntoneerd is, vertoont een groot toonhoogtebereik. Deze eigenschap specificeert het bereik waarbinnen deze variaties optreden, d.w.z. hoeveel de fundamentele frequentie kan afwijken van de gemiddelde toonhoogte.

```java
public String PitchRange { get; set; }
```
