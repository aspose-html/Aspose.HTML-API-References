## ICSS2Properties.CounterIncrement property

De ['counter-increment'](https://www.w3.org/TR/1998/REC-CSS2-19980512/generate.html#propdef-counter-increment) eigenschap accepteert één of meer namen van tellers (identifiers), elk eventueel gevolgd door een geheel getal. Het geheel getal geeft aan met hoeveel de teller wordt verhoogd voor elke keer dat het element voorkomt. De standaardverhoging is 1. Nul en negatieve gehele getallen zijn toegestaan.

```java
public String CounterIncrement { get; set; }
```
