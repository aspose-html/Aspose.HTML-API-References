## ICSS2Properties.FontStretch property

De ['font-stretch'](https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html#propdef-font-stretch) eigenschap selecteert een normaal, samengedrukt of uitgerekt lettertype uit een lettertypefamilie. Absolute sleutelwoordwaarden hebben de volgende volgorde, van smalste naar breedste:

ultra-condensedextra-condensedcondensedsemi-condensednormalsemi-expandedexpandedextra-expandedultra-expanded
