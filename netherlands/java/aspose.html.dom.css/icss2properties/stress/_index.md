## ICSS2Properties.Stress property

Specificeert de hoogte van "lokale pieken" in de intonatiecontour van een stem. Bijvoorbeeld, Engels is een getoonde taal, en verschillende delen van een zin krijgen primaire, secundaire of tertiaire stress. De waarde van ['stress'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-stress) bepaalt de hoeveelheid inflectie die voortkomt uit deze stressmarkeringen. Deze eigenschap is een aanvulling op de ['pitch-range'](https://www.w3.org/TR/1998/REC-CSS2-19980512/aural.html#propdef-pitch-range) eigenschap en wordt geleverd om ontwikkelaars in staat te stellen geavanceerde auditieve weergaven te benutten.

```java
public String Stress { get; set; }
```
