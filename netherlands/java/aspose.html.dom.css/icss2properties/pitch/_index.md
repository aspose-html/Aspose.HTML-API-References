## ICSS2Properties.Pitch property

Specificeert de gemiddelde toonhoogte (een frequentie) van de spraakstem. De gemiddelde toonhoogte van een stem hangt af van de stemfamilie. Bijvoorbeeld, de gemiddelde toonhoogte voor een standaard mannelijke stem is ongeveer 120 Hz, maar voor een vrouwelijke stem is deze ongeveer 210 Hz.

```java
public String Pitch { get; set; }
```
