## Uint8ClampedArray class

Stelt een array van 8-bit onondertekende gehele getallen voor, begrensd tot 0-255; als u een waarde opgeeft die buiten het bereik [0,255] ligt, wordt in plaats daarvan 0 of 255 ingesteld;

```java
public class Uint8ClampedArray : TypedArray<byte>
```
