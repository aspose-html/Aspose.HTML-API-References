## HTMLInputElement.Files property

Het files IDL‑attribuut stelt scripts in staat om toegang te krijgen tot de geselecteerde bestanden van het element. Bij het ophalen, als het IDL‑attribuut van toepassing is, moet het een FileList‑object retourneren dat de momenteel geselecteerde bestanden vertegenwoordigt. Hetzelfde object moet worden geretourneerd totdat de lijst met geselecteerde bestanden verandert. Als het IDL‑attribuut niet van toepassing is, moet het in plaats daarvan null retourneren. [FILEAPI]

```java
public IFileList Files { get; }
```
