## HTMLInputElement.Checked property

Wanneer het `type`-attribuut van het element de waarde "radio" of "checkbox" heeft, vertegenwoordigt dit de huidige staat van het formulierelement in een interactieve user agent. Wijzigingen aan dit attribuut wijzigen de staat van het formulierelement, maar veranderen niet de waarde van het HTML checked-attribuut van het INPUT-element. Tijdens de afhandeling van een klik‑event op een invoerelement met een type‑attribuut dat de waarde "radio" of "checkbox" heeft, kunnen sommige implementaties de waarde van deze eigenschap wijzigen voordat het event wordt gedistribueerd in het document. Als de standaardactie van het event wordt geannuleerd, kan de waarde van de eigenschap teruggezet worden naar de oorspronkelijke waarde. Dit betekent dat de waarde van deze eigenschap tijdens de afhandeling van klik‑events implementatie‑afhankelijk is.

```java
public bool Checked { get; set; }
```
