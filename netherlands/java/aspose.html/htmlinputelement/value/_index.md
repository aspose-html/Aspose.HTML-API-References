## HTMLInputElement.Value property

Wanneer het `type`‑attribuut van het element de waarde "text", "file" of "password" heeft, vertegenwoordigt dit de huidige inhoud van de overeenkomstige formulierbesturing in een interactieve user‑agent. Het wijzigen van dit attribuut wijzigt de inhoud van de formulierbesturing, maar verandert niet de waarde van het HTML‑value‑attribuut van het element. Wanneer het `type`‑attribuut van het element de waarde "button", "hidden", "submit", "reset", "image", "checkbox" of "radio" heeft, vertegenwoordigt dit het HTML‑value‑attribuut van het element. Zie de definitie van het value‑attribuut in HTML 4.01.

```java
public String Value { get; set; }
```
