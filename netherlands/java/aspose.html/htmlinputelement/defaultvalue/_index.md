## HTMLInputElement.DefaultValue property

Wanneer het `type`-attribuut van het element de waarde "text", "file" of "password" heeft, vertegenwoordigt dit het HTML value-attribuut van het element. De waarde van dit attribuut verandert niet als de inhoud van de corresponderende formuliercontrole, in een interactieve user agent, verandert. Zie de definitie van het value-attribuut in HTML 4.01.

```java
public String DefaultValue { get; set; }
```
