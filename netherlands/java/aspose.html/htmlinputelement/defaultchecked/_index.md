## HTMLInputElement.DefaultChecked property

Wanneer `type` de waarde "radio" of "checkbox" heeft, vertegenwoordigt dit het HTML‑checked‑attribuut van het element. De waarde van dit attribuut verandert niet als de staat van de overeenkomstige formulierbesturing, in een interactieve user‑agent, verandert. Zie de definitie van het checked‑attribuut in HTML 4.01.

```java
public bool DefaultChecked { get; set; }
```
