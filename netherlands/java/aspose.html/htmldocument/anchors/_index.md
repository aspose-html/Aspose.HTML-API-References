## HTMLDocument.Anchors property

Een verzameling van alle anker‑(`A`)-elementen in een document met een waarde voor het `name`-attribuut. Om redenen van achterwaartse compatibiliteit bevat de geretourneerde set ankers alleen die ankers die met het `name`-attribuut zijn aangemaakt, niet die met het `id`-attribuut. Merk op dat in [[XHTML 1.0](http://www.w3.org/TR/2002/REC-xhtml1-20020801)] het `name`-attribuut (zie sectie 4.10) geen semantiek heeft en alleen aanwezig is voor verouderde gebruikersagenten: het `id`-attribuut wordt in plaats daarvan gebruikt. Gebruikers moeten de iteratormechanismen die door [[DOM Level 2 Traversal](http://www.w3.org/TR/2000/REC-DOM-Level-2-Traversal-Range-20001113)] worden geleverd, verkiezen.
