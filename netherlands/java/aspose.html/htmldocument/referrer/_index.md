## HTMLDocument.Referrer property

Retourneert de URI [[IETF RFC 2396](http://www.ietf.org/rfc/rfc2396.txt)] van de pagina die naar deze pagina linkte. De waarde is een lege String als de gebruiker rechtstreeks naar de pagina navigeerde (niet via een link, maar bijvoorbeeld via een bladwijzer).

```java
public String Referrer { get; }
```
