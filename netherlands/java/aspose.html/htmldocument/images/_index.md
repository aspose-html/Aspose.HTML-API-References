## HTMLDocument.Images property

Een verzameling van alle `IMG`-elementen in een document. Het gedrag is beperkt tot `IMG`-elementen voor achterwaartse compatibiliteit. Zoals gesuggereerd door [[HTML 4.01](http://www.w3.org/TR/1999/REC-html401-19991224)], om afbeeldingen op te nemen, kunnen auteurs het `OBJECT`-element of het `IMG`-element gebruiken. Daarom wordt aanbevolen dit attribuut niet te gebruiken om de afbeeldingen in het document te vinden, maar `getElementsByTagName` met HTML 4.01 of `getElementsByTagNameNS` met XHTML 1.0.

```java
public HTMLCollection Images { get; }
```
