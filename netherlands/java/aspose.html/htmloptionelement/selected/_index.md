## HTMLOptionElement.Selected property

Geeft de huidige staat van de overeenkomstige formulierbesturing weer, in een interactieve user agent. Het wijzigen van dit attribuut wijzigt de staat van de formulierbesturing, maar verandert niet de waarde van het HTML selected attribuut van het element.

```java
public bool Selected { get; set; }
```
