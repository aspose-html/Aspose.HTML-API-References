## HTMLTableElement.Rows property

Retourneert de `TFOOT` van de tabel, of `null` als deze niet bestaat.

Retourneert een collectie van alle rijen in de tabel, inclusief alle in `THEAD`, `TFOOT`, alle `TBODY`-elementen.
