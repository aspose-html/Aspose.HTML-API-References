## IUrlSearchParams.Set method

Stelt de waarde van het eerst gevonden naam-waarde-paar in op de opgegeven waarde en verwijdert de overige. Als er geen naam-waarde-paren met de opgegeven naam worden gevonden, wordt er een nieuw paar aan de lijst toegevoegd.

```java
public void Set(String name, String value)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| name | String | Sleutel die wordt gebruikt om naam-waarde paren te vinden. |
| waarde | String | Waarde die zal worden ingesteld. |
