## HTMLFormElement.Enctype property

Het contenttype van het verzonden formulier, doorgaans "application/x-www-form-urlencoded". Zie de definitie van het enctype‑attribuut in HTML 4.01. De onsubmit‑evenementhandler wordt niet gegarandeerd geactiveerd bij het aanroepen van deze methode. Het gedrag is om historische redenen inconsistent en auteurs mogen niet op een specifieke versie vertrouwen.

```java
public String Enctype { get; set; }
```
