## HTMLFormElement.Enctype property

De inhoudstype van het verzonden formulier, doorgaans "application/x-www-form-urlencoded". Zie de definitie van het enctype-attribuut in HTML 4.01. De onsubmit‑evenementhandler wordt niet gegarandeerd geactiveerd bij het aanroepen van deze methode. Het gedrag is inconsistent om historische redenen en auteurs moeten niet op een specifieke variant vertrouwen.

```java
public String Enctype { get; set; }
```
