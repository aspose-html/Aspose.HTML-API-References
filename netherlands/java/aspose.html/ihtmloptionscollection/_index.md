## IHTMLOptionsCollection interface

Een `HTMLOptionsCollection` is een lijst van knooppunten die een HTML‑option‑element vertegenwoordigen. Een individueel knooppunt kan worden benaderd via de ordinale index of via de `name`‑ of `id`‑attributen van het knooppunt. Verzameling­en in de HTML‑DOM worden verondersteld live te zijn, wat betekent dat ze automatisch worden bijgewerkt wanneer het onderliggende document wordt gewijzigd.

Zie ook de [Document object Model (DOM) Level 2 HTML Specification](http://www.w3.org/TR/2003/REC-DOM-Level-2-HTML-20030109). @since DOM Level 2

```java
public interface IHTMLOptionsCollection : IEnumerable<Element>
```
