## ToDataURL() {#todataurl}

retourneert een data-URI die een weergave van de afbeelding bevat in het formaat gespecificeerd door de typeparameter (standaard PNG). De geretourneerde afbeelding heeft een resolutie van 96 dpi.

```java
public String ToDataURL()
```

### Retourwaarde

Een DOMString die de gevraagde data‑URI bevat.

retourneert een data-URI die een weergave van de afbeelding bevat in het formaat gespecificeerd door de typeparameter (standaard PNG). De geretourneerde afbeelding heeft een resolutie van 96 dpi.

