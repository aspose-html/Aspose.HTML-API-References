## HTMLCanvasElement.GetContext method

Retourneert een tekencontext op het canvas, of null als de context-ID niet wordt ondersteund. Een tekencontext stelt je in staat om op het canvas te tekenen.

```java
public object GetContext(String contextId)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| contextId | String | Is een String die de context‑identifier bevat die de tekencontext definieert die aan het canvas is gekoppeld. |

### Retourwaarde

Een RenderingContext
