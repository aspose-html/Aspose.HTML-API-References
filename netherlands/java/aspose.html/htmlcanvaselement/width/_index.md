## HTMLCanvasElement.Width property

Is een positief geheel getal dat de breedte‑HTML‑attribuut van het canvas‑element weergeeft, geïnterpreteerd in CSS‑pixels. Wanneer het attribuut niet is gespecificeerd, of een ongeldige waarde zoals een negatieve heeft, wordt de standaardwaarde van 300 gebruikt.

```java
public ulong Width { get; set; }
```
