## HTMLCanvasElement.Height property

Is een positief geheel getal dat de hoogte‑HTML‑attribuut van het canvas‑element weergeeft, geïnterpreteerd in CSS‑pixels. Wanneer het attribuut niet is gespecificeerd, of een ongeldige waarde zoals een negatieve heeft, wordt de standaardwaarde van 150 gebruikt.

```java
public ulong Height { get; set; }
```
