## HTMLTextAreaElement.Value property

Vertegenwoordigt de huidige inhoud van de overeenkomstige formulierbesturing, in een interactieve user agent. Het wijzigen van dit attribuut wijzigt de inhoud van de formulierbesturing, maar wijzigt niet de inhoud van het element. Als de volledige gegevens niet in één enkele `DOMString` passen, kan de implementatie de gegevens afkappen.

```java
public String Value { get; set; }
```
