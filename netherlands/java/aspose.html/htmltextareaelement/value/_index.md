## HTMLTextAreaElement.Value property

Vertegenwoordigt de huidige inhoud van het overeenkomstige formulierelement, in een interactieve user agent. Het wijzigen van dit attribuut wijzigt de inhoud van het formulierelement, maar verandert de inhoud van het element niet. Als de volledige gegevens niet in één enkele `DOMString` passen, kan de implementatie de gegevens afkappen.

```java
public String Value { get; set; }
```
