## HTMLTableRowElement.RowIndex property

Dit is in logische volgorde en niet in documentvolgorde. De `rowIndex` houdt rekening met secties (`THEAD`, `TFOOT` of `TBODY`) binnen de tabel, waarbij `THEAD`‑rijen eerst in de index worden geplaatst, gevolgd door `TBODY`‑rijen en daarna `TFOOT`‑rijen. @versie DOM Level 2

```java
public int RowIndex { get; }
```
