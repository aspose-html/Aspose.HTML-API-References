## Configuration.Security property

Haalt op of stelt de sandboxing‑vlag van de configuratie in. Zie het artikel over [sandboxing](https://docs.aspose.com/html/net/working-with-documents/environment-configuration/#sandboxing).

```java
public Sandbox Security { get; set; }
```

### Property Value

De beveiliging. Een [`sandboxing flag`](../../sandbox/) set is een verzameling van nul of meer van de vlaggen, die worden gebruikt om de mogelijkheden van potentieel onbetrouwbare bronnen te beperken. Het sandbox‑attribuut stelt je in staat een aantal beperkingen in te stellen op de inhoud die in het frame wordt geladen, bijvoorbeeld formulieren en scripts te blokkeren.
