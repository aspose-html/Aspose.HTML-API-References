## TemplateLoadOptions.NamesAreCaseSensitive property

Eigenschap die aangeeft of de namen van sjabloon- en gegevenselementen worden vergeleken ongeacht hoofdlettergebruik. Als true is de vergelijking hoofdlettergevoelig; als false wordt hoofdlettergebruik genegeerd. Standaardwaarde is true.

```java
public bool NamesAreCaseSensitive { get; set; }
```
