## MutationObserver constructor

Maakt een MutationObserver-object aan en stelt zijn [`MutationCallback`](../../mutationcallback/) in op callback. De callback wordt aangeroepen met een lijst van MutationRecord-objecten als eerste argument en het geconstrueerde MutationObserver-object als tweede argument. Hij wordt aangeroepen nadat knooppunten die zijn geregistreerd met de !:Observe(Node, IMutationObserverInit)-methode, zijn gemuteerd.

```java
public MutationObserver(MutationCallback callback)
```

| callback | MutationCallback | De callback. |
