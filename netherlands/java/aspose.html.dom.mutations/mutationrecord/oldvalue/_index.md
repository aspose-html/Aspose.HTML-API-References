## MutationRecord.OldValue property

De geretourneerde waarde hangt af van het type. Voor \"attributes\" is het de waarde van het gewijzigde attribuut vóór de wijziging. Voor \"characterData\" zijn het de gegevens van het gewijzigde knooppunt vóór de wijziging. Voor \"childList\" is het null.

```java
public String OldValue { get; }
```

### Property Value

De oude waarde.
