## MutationRecord.Target property

Retourneert het knooppunt dat door de mutatie is beïnvloed, afhankelijk van het type. Voor "attributes" is dit het element waarvan het attribuut is gewijzigd. Voor "characterData" is dit het CharacterData-knooppunt. Voor "childList" is dit het knooppunt waarvan de kinderen zijn gewijzigd.

public Node Target { get; }
